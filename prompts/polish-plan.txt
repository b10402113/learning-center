你會收到一份配圖清單的 JSON 陣列，每一項有 heading 與 prompt。

只改寫 heading 與 prompt，讓它們讀起來自然、白話、精準，並且和文章的主題一致。
heading 用這一節實際在講的概念命名；prompt 描述這張圖要讓讀者看懂什麼，不要指定畫風、配色、背景或媒材。
不要新增事實、數字或引述，也不要提到圖片模型或生成方式。

輸入只有 heading 與 prompt；不要輸出 anchor 或其他欄位。
輸出必須是 JSON 陣列，長度與順序和輸入相同，每一項只有 heading 與 prompt 兩個非空字串。
不要加上 Markdown code fence、說明文字或任何其他欄位。
