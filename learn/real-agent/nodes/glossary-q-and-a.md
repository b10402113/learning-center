# Q&A：一個 glossary 夠不夠？

## Lesson

一個 glossary 撐不住整個產品時會發生兩件事：Quiz question 與 Discussion question 撞名，或兩個 bounded context 各有一套字。這個 node 把散落的問答收斂成規則：什麼時候加前綴、什麼時候拆成 GLOSSARY-MAP、更新該在 spec 之前還是之後推、以及為什麼不能讓 agent 獨自擁有這份字表。
