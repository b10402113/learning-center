# Retro：把 review 意見變成規則

## Lesson

同一句 review 意見講第二次就是系統的問題。這個 node 先用人的視角留幾條「可以變成規則」的 PR 留言，再讓 `/retro` 讀一整個 PR 背後的六個 session 與這些留言，產出候選清單，最後只挑真正該變成 CODING_STANDARDS.md 的那幾條。
