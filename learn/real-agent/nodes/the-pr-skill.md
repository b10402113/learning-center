# The PR Skill：讓 PR 值得人看

## Lesson

人 review 的瓶頸不是不想看，是進入狀況太慢。這個 node 改寫 PR 的寫法：短 summary、before/after evidence、Merge Danger，讓 reviewer 先知道這個 PR 該花多少注意力。練習會看到一個證據薄弱、撞到隱私、又開了一扇 one-way door 的 PR 被誠實地標出來。
