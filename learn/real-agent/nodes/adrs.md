# ADRs：把被否掉的選項留下來

## Lesson

程式碼記得你做了什麼，卻不記得你否掉了什麼，於是下一個 agent 會把同一個問題重想一遍。這個 node 給 ADR 的最小格式與三問判準，再用「退款視窗算整天還是算小時」當例子，示範一個值得留下來的決策長什麼樣。練習會把同一套判準用在核准退款後的學員進度上。
