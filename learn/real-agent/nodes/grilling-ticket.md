# Grilling Ticket：一個 session 解一個決策

## Lesson

地圖上的決策，一次 session 只解一個。這個 node 連跑兩張 grilling ticket：第一張問通知的範圍與命名，第二張問要不要押在 Knock 上。兩次都從 ticket URL 開場、讀 blocking 關係、問到收斂、把決定寫成 resolution 貼回 issue，途中順手補 glossary。
