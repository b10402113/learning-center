挑點子、改寫成腳本、教會 /latest 你的口味

Step 5/5 · Idea Sources 與 Well of Knowledge＋/latest

前言：cart 滿了，影片還是零支

你的 cart 裡已經有幾個點子了，每個都附了連結，看起來都不錯。但如果就這樣放著，一週過去你會發現 cart 越來越滿，錄影的次數卻是零。這是很多人在內容起步時會遇到的情況：收集的動作很有成就感，真正把點子變成一支影片的那一步，反而一直往後拖。

這一步要處理的就是這個缺口。你要把點子改寫成自己會說的腳本，然後把你的選擇回饋給 /latest，讓它下一次給你的點子更接近你會拍的樣子。如果不做這一步，/latest 就只是一台每次都從零開始的搜尋機器，永遠不會越用越懂你。

學習目標

從 cart 挑出真的想發的點子，改寫成你自己語氣的腳本，並把你的選擇回貼給 /latest，讓它一次一次調得更貼近你的口味。

第一步：從 cart 挑一個今天能拍的

挑的時候，先問自己三件事。第一，我能不能說出一句自己的看法，而不是只把新聞轉述一遍？第二，我能不能用手機拍，或是對著螢幕講？第三，它跟我的利基和觀眾直接有關嗎？三個問題都答得出來，就是今天的第一支。

課程示範的做法很直接：挑中之後，就請 agent 把點子寫成腳本，然後開始錄。不必等到腳本完美，也不必先把所有點子都想清楚。

第二步：把點子改寫成你的腳本

把挑中的點子交給 agent，請它寫成一支 TikTok 或 Instagram 的口播腳本，而且要用你自己的語氣。你可以這樣描述（以下是範例提示，不是課程原文）：

把這個點子寫成一支約一分鐘的口播腳本，開頭用一個具體的情境，中間講我的看法，結尾給觀眾一個可以立刻試的動作。語氣參考我貼給你的這段文字。

「用你自己的語氣」很重要。最簡單的做法，是把你以前寫過的一段文字（例如一則貼文或一段筆記）貼給 agent 當範本。它會抓出你常用的句型與節奏，改寫出來的腳本才比較像你。

如果讀起來還不太像你，不必急著硬改。課程的說法是，怎麼把內容變得更好，會在後面的模組再講。這一階段的重點是先把腳本寫出來，錄一次，看看自己的樣子。

第三步：把你的選擇回饋給 /latest

在結果頁的 cart 裡，有一個「Copy for my agent」按鈕。按下去，它會複製一段以 Idea cart: 開頭的文字，裡面記著你選了哪些點子、它們的來源、角度，以及你寫的註記。把這段文字整段貼回 agent，agent 就會把它寫進 skill 資料夾裡的 taste.md。

skill 的 SKILL.md 裡寫了 agent 要怎麼做這件事。下面是它給的指令範例：

python scripts/taste.py add - <<'CART'
Idea cart: 2 picks, in my order.
(the rest of the pasted text)
CART

這行指令的意思是：taste.py 是負責寫入口味檔的腳本，add 表示新增選擇，最後的 - 表示內容從標準輸入讀進來。<<'CART' 到 CART 之間的那幾行，就是要交給腳本的文字，也就是你貼回來的 cart。你不需要自己打這些指令，agent 會替你執行。但了解它在做什麼，才知道出了問題該往哪裡看。

腳本一次能記下哪些欄位，是由它的程式定義的。下面這行列出了每個點子會帶的欄位：

FIELDS = ("From", "Source", "Numbers", "Link", "Angle", "Why it helps", "Your version", "Fit my taste file", "My note")

其中 Link 是關鍵。腳本在解析 cart 的時候，只保留有連結的點子：

    return [p for p in picks if p.get("Link")]

換句話說，沒有連結的點子不會被存進口味檔。這跟前面的原則一致：/latest 只留下能查證的點子，你的口味紀錄也只記錄能回頭點開的東西。

第四步：整理「What you like」清單

存完選擇之後，agent 還要做一件事：看看你選過的點子，歸納出你偏好的主題、格式、來源與角度，寫成最多八行的清單，放在口味檔的 What you like 區塊。這個清單會成為之後每次跑 /latest 的參考。

腳本的用法說明寫在它的開頭註解裡，主要有三個指令：

    python scripts/taste.py add -      # the pasted idea cart on standard input (or a file path instead of -)
    python scripts/taste.py like -     # the rewritten "What you like" list on standard input, one line each
    python scripts/taste.py show       # print the taste file

add 寫入選擇，like 寫入清單，show 把口味檔印出來給你看。口味檔是你的，檔案開頭就寫著你可以自由編輯。如果 agent 寫的清單不符合你的感覺，直接改成你要的樣子就好，你的備註比 agent 的猜測更準。

第五步：下一次跑 /latest 會有什麼不同

有了口味檔，下一次跑 /latest 時，skill 會先讀它再排名。符合你口味的點子會排得比較前面，角度也會朝你喜歡的格式靠攏。結果頁上，符合口味的卡片會多一行說明，告訴你為什麼它符合。

skill 也有一條限制：口味只能調整排序與角度，不能把本週最重要的真消息擠掉，也不能憑空編出點子。換句話說，口味是在真實的消息裡做選擇，而不是替你創造消息。

要注意的是，口味會往你選過的方向收斂。如果你連續好幾次都只選同一類題目，之後的結果很可能越來越偏向那一類，題目也會變得越來越窄。這時候應該有意識地選一些不同類型的點子，讓口味檔保有彈性。

口味是從你的選擇慢慢長出來的。你選得越有判斷，它給的點子就越接近你會拍的樣子。

做完長什麼樣

  • 至少有一個點子已經改寫成腳本，並且錄了第一版，或是已經排定今天要錄。
  • 口味檔 taste.md 裡有你的選擇紀錄，而且「What you like」是八行以內、你看得懂的句子。
  • 下一次跑 /latest 時，結果頁會顯示已經根據你的選擇調整過。

小結

從 cart 挑一個今天能拍的點子，用你自己的語氣寫成腳本，錄一次。接著把 cart 的內容貼回 agent，讓它寫入口味檔並整理「What you like」清單。口味會讓下一次的排序更貼近你，但它只能在真實的消息裡調整，也會往你選過的方向收斂，所以要有意識地保持多樣。
