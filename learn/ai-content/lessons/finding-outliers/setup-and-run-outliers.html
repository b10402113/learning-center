設定並執行 /outliers：YouTube API key、掃描與結果頁

Step 3/5 · Finding Outliers 與 /inspo

學習目標

這一步位在 Finding Outliers 與 /inspo 流程中，目的是把前兩節學到的 outlier 判斷，變成一份你能實際挑選的候選清單。你會提供自己的利基、關鍵字和 YouTube API key，設定好 /outliers，跑出結果頁，再把想進一步發展的影片放進 cart。

前言：做完之後，你手上會有什麼？

前面兩節談的是觀念和計算：outlier 是相對於平常表現特別突出的內容；倍數則是觀看數除以平常水準。這一節會把這套判斷放進你的工具裡，讓你輸入 /outliers，就能掃描自己關注的利基，找出表現突出的影片。

開始前，先確認需要的條件。大多數設定只做一次，之後每次掃描都能沿用。

Setup:
- [ ] 1 Node.js 22.13 or newer
- [ ] 2 YouTube key in .env
- [ ] 3 Niche written into scripts/keywords.json
- [ ] 4 Peers in data/peers.json (recommended)
- [ ] 5 Sources for the other platforms, if wanted
- [ ] 6 Self-test passes

如果你熟悉 Node，安裝和執行應該不難。對新手來說，比較需要留意的是 YouTube API key：它是讓程式讀取 YouTube 資料的金鑰。下面依序完成設定。

步驟 1：安裝 skill

先下載課程附的 zip 檔，預設會放在 Downloads 資料夾。接著把下面這段安裝提示整段交給 agent。agent 會依照 README 設定，先用幾個問題確認你的需求，再開始安裝。

"""I'm giving you a resource called Outliers. It's in the file robonuggets-outliers.zip (in my Downloads folder unless I say otherwise).

Follow the README to set it up.
Recommend how it would best apply to our setup in plain language,
and ask me a few questions to clarify my intent before you install it."""

預期會看到：agent 讀完 README 後，用白話說明安裝方式，並詢問你的利基，以及你是否有自己的頻道。它也可能順手提供後續設定需要的連結。

步驟 2：打開 YouTube Data API、建立金鑰

要讀取 YouTube 資料，必須啟用 YouTube Data API，並建立一組 API key。這組金鑰免費、唯讀，也不需要登入 YouTube 帳號。skill 附的環境範本列出了取得方式與注意事項：

# Copy this file to a new file named .env in the same folder (the skill folder), then paste your keys after the = signs.
# Never share your .env file and never paste a key into a chat. Only the scripts in scripts/ read it.

# REQUIRED for YouTube. Free, read-only, no sign-in needed. Get one at console.cloud.google.com
# (create a project, turn on "YouTube Data API v3", then Credentials > Create credentials > API key).
YOUTUBE_API_KEY=

依序到 console.cloud.google.com 建立專案、啟用「YouTube Data API v3」，再到 Credentials 建立 API key。最後把金鑰填進 skill 資料夾裡的 .env 檔。

注意：API key 只放進 .env，不要貼到任何聊天視窗。你可以請 agent 打開檔案，再由你自己把金鑰貼進去。範本也特別提醒：「Never share your .env file and never paste a key into a chat.」金鑰外流，別人就可能使用你的額度。

預期會看到：設定完成後，再次掃描時不會出現缺少 key 的錯誤。

步驟 3：把你的利基寫進去

利基（niche）是你想專注服務或創作的主題範圍。skill 會讀取 keywords.json，依照裡面的利基和關鍵字決定要掃描什麼。檔案一開始放的是「AI and automation 創作者」的範例，你需要換成自己的主題；每次掃描時，skill 都會重新讀取這份檔案，因此修改後就會生效。

  "_niche": "AI and automation",
…
  "sets": {
    "default": [
      "ai coding agent",
      "ai agents",
      "vibe coding",
      "mcp server",
      "ai automation",
      "build app with ai",
      "ai coding tools",
      "n8n automation",
      "ai agent business",
      "ai tutorial for beginners"
    ],

這份檔案有三個地方要設定：

  • _niche：用幾個字描述你的主題，結果頁會用它當標題。
  • _own_channel：填入你自己的頻道名稱，避免自己的影片出現在候選結果中。
  • sets.default：填入一組你的觀眾真的可能拿去 YouTube 搜尋的關鍵字，約五到十個。

關鍵字不要只寫很大的領域名稱，也要想想觀眾會怎麼搜尋。關鍵字太廣，清單裡就容易混進不相關的影片。skill 說明提到，只要檔案裡還留著以 EXAMPLE 開頭的備註，就代表尚未設定；agent 會主動問你相關問題。

預期會看到：EXAMPLE 備註已移除，關鍵字也換成你的領域。這表示利基設定完成，而且掃描結果會更貼近你真正想找的內容。

步驟 4：跑第一次掃描

最簡單的方式，是直接請 agent 執行 /outliers。掃描會使用你的關鍵字和設定的頻道，找出最近 14 天內、倍數超過門檻的影片，計算倍數並排序。如果想自己執行，可以使用以下指令：

node scripts/scan.mjs --no-open                             # keyword set + YouTube peers, last 14 days
node scripts/scan.mjs --shorts --no-open                    # Shorts run: the "shorts" set + YouTube peers, Shorts only
node scripts/scan.mjs --channels @handle,@other --no-open   # just these channels, no searches
node scripts/scan.mjs --report-only --new-only              # zero quota, only what the user hasn't seen

第一次先看第一行即可：它會用關鍵字組合和 YouTube peers 掃描最近 14 天。peer 指的是同領域、可供比較的參考頻道。預設選最近 14 天，是為了先找出近期的題材；如果要掃 Shorts，就用第二行。

若要只重建報告、列出尚未看過的結果，可以用第四行的 --report-only 和 --new-only。如果第一次掃描的結果太少，依序試兩件事：先把關鍵字換成範圍更大的主題，再把掃描時間拉長。這樣會找到更多候選，但也可能混入較舊的題材。

步驟 5：讀結果頁，把候選放進 cart

掃描完成後，skill 會用附帶的結果頁模板開啟一張網頁。每支影片都有縮圖和倍數，方便你快速比較；卡片展開後，還能看到「為什麼它有效」和「你的版本」兩項內容。

接下來要做的不是照抄倍數最高的影片，而是挑出你覺得有共鳴、而且這週就能講出自己觀點的候選。把選中的影片加入 cart，也就是結果頁上的候選收藏區。cart 會記住你的選擇，重新整理頁面也不會消失。

預期會看到：一張可以搜尋、依平台和倍數篩選或排序的結果頁，影片依倍數由高到低排列；你選中的候選則留在 cart 裡。到這裡，/outliers 就設定完成，也有了一組可以繼續發展的點子。

小結

一次性設定分成三件事：把 zip 交給 agent 安裝、申請免費的 YouTube API key 並填進 .env（絕對不要貼進聊天視窗），再把自己的利基和關鍵字寫進 keywords.json。之後請 agent 執行 /outliers，就能用你的關鍵字和 peer 頻道掃描、計算倍數，並打開可排序的結果頁。挑出這週能講出自己觀點的影片，加入 cart。若結果太少，先放大主題，再延長掃描時間。

現在你有一份依倍數排序的清單，也把幾個候選放進 cart 了。不過，倍數最高的影片不一定最適合你做。下一節會接著說明，該怎麼判斷哪些點子值得挑選。
