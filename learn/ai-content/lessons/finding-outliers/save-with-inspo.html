把影片存進 /inspo 靈感牆，之後再依主題取用

Step 5/5 · Finding Outliers 與 /inspo

學習目標

完成這一步後，你會有一面自己的 YouTube 靈感牆：把影片存成卡片，記下當初收藏的原因，之後再請 agent 依主題挑出合適的參考。

前言：挑好的那幾支，下週還找得回來嗎？

上一節你挑出了幾支值得研究的爆款。這裡的 outlier，指的是表現明顯高於頻道平常水準的內容；找出它們，就能看見哪些做法正在你的利基市場裡發酵。

但挑出影片只是開始。如果它們散落在瀏覽器分頁或其他地方，過幾天你可能忘了當初為什麼收藏，甚至找不到影片。這一步要把研究成果收好：用 /inspo 把影片存成卡片，並留下你自己的筆記。

/outliers 和 /inspo 是一組搭檔：前者幫你找出值得注意的內容，後者把值得學的影片存下來，慢慢整理成「我這個領域裡什麼有效」的清單。完成後，你會有一面可以持續累積、也能交給 agent 搜尋的靈感牆。

動手前確認環境：只需要 Node.js 18 以上，不需要 API 金鑰或帳號。若已安裝 yt-dlp，讀取 YouTube 資料會更穩定；沒有安裝也能使用。

步驟 1：安裝 /inspo

下載課程附的 zip，把以下提示交給 agent。它會依照 README 設定，並先問你幾個問題確認需求。

"""I'm giving you a resource called Inspo. It's in the file robonuggets-inspo.zip (in my Downloads folder unless I say otherwise).

Follow the README to set it up.
Recommend how it would best apply to our setup in plain language,
and ask me a few questions to clarify my intent before you install it."""

這個 skill 也提供選用的 Chrome 擴充功能和 RUBRIC console 分頁，之後可以直接在瀏覽器收藏影片。命令列、擴充功能和分頁操作的都是同一個檔案，所以從哪裡收藏，看到的靈感牆都相同。

步驟 2：存一支影片

最基本的做法，是把影片連結交給工具。以下是 skill 說明中的操作方式：

1. Run `node <this skill's folder>/scripts/add-inspo.mjs "<link>"`. Several links in one call is fine. Shorts, youtu.be links and bare 11-character ids all work. If the user says why they are saving it, add `--note "<their words>"` (one link per call when there is a note).

工具接受一般的 watch 連結、youtu.be 短連結、Shorts 連結，也接受只有十一個字元的影片 id。下面這段程式會從輸入內容中找出影片 id：

function extractId(input) {
  const s = String(input || '').trim();
  if (/^[A-Za-z0-9_-]{11}$/.test(s)) return s;
  const m = s.match(/(?:v=|\/shorts\/|youtu\.be\/|\/embed\/|\/live\/|\/v\/)([A-Za-z0-9_-]{11})/);
  return m ? m[1] : null;
}

辨識出影片 id 後，工具會讀取影片的公開資訊：優先使用 yt-dlp；如果沒有安裝，就改讀 YouTube 的公開頁面。接著它會顯示標題、觀看數、發布時間、影片長度和頻道，讓你確認資料。這一步主要是核對資訊，不需要做太多判斷。

步驟 3：為什麼要把當下的數字凍結下來？

靈感牆存的不只是影片連結，而是一份影片的快照：標題、頻道、訂閱數、觀看數、發布多久、長度、標籤、描述，以及你自己寫的筆記。快照會保留你收藏當下的資訊，不會一路更新成最新數字。

這樣設計，是因為你當初決定收藏時，看到的數字可能正是重要線索。比如影片的觀看數遠高於該頻道平常的表現，這可能就是你覺得它值得研究的原因。如果數字之後一直變動，你回頭看時就不容易還原當初的判斷。

同一支影片只會保留一張卡片，處理方式如下：

  const video = { ...prev, ...fresh };
  if (note) video.note = note;
  store.inspos = store.inspos.filter(v => v.id !== id); // one card per video
  store.inspos.unshift(video);                          // newest first
  writeStore(store);

這段程式會先移除牆上同一支影片的舊卡片，再把新資料放到最上方。重新收藏時，數字會更新，你原本的筆記則會保留下來。這樣一來，靈感牆不會重複堆放同一支影片，最新收藏的也會排在前面。

步驟 4：補上自己的話，或把卡片拿掉

快照裡最值得你親手補上的，是「我為什麼要存這支影片」。收藏時加上 --note "為什麼我要存它"，這句話就會跟卡片一起留下來；之後重新收藏，也不會被新資料蓋掉。加上筆記時，一次只能處理一支影片。

幾個月後，影片的數字可能已經不再新鮮，但你當初看上它哪一點，仍然能幫你理解這張卡片的用途。若某支影片後來證明用不到，可以用以下指令移除：node add-inspo.mjs --remove "<連結>"。

步驟 5：之後請 agent 依主題取用

靈感牆真正派上用場，是你需要找參考的時候。比如你想決定今天要做什麼，或想找符合某個主題、格式或氛圍的影片，就可以請 agent 從牆上幫你挑選。

工具可以列出整面牆，也可以依關鍵字篩選。接著，請 agent 根據意思而不只是字面關鍵字，挑出最合適的三到五支，並各用一句話說明推薦原因。

例如，你想找「平靜、有畫面」的參考，合適的影片不一定真的把「平靜」寫在標籤裡。agent 可以依影片內容判斷它是否符合這種感覺，而不只是搜尋有沒有出現某個字。

靈感牆是一般的 JSON 檔案，除了透過工具搜尋，也可以請 agent 直接讀取檔案，查看影片的完整描述、標籤或發布日期。工具會印出檔案路徑，方便你找到它。

小結

/inspo 會把值得研究的 YouTube 影片存成快照卡片，保留收藏當下的影片資料，也能加上你自己的筆記。安裝只需要 Node.js，不需要金鑰；存入影片、記下收藏原因，之後再請 agent 依主題挑出三到五支參考。它和 /outliers 一起完成這段流程：先找出值得注意的內容，再把值得學的收進自己的靈感牆。
