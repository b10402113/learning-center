審片與教 /cut：用評論修正，讓下一輪剪得更準

Step 4/6 · Automated Editing：RUBRIC Editor＋/cut

學習目標

這一步接在 /cut 產生第一批 clip 之後：你會在 RUBRIC Editor 裡審片、調整剪輯，再把評論交回 agent，讓它修正這一輪，也記住你的偏好。開始前，請先安裝好 RUBRIC Editor，並用 /cut 產生過 clip。做完後，你會有一套可重複使用的審片流程，以及一份能回饋給 agent 的留言清單。

操作時，你會用到幾個主要功能：延伸 clip、按 C 切分、用 + 救回片段，以及開啟 Teach my /cut。

前言：預設規則不一定適合你

上一節提到，/cut 會參考逐字稿的時間戳，並預設保留每一行最後一次乾淨的 take。這個預設適合多數人的說話方式，卻未必完全符合你：你的停頓可能比較長，重來的習慣也可能不同，說話速度更是各有差異。

要讓「多數人的規則」逐漸貼近你的習慣，就得親自審片，逐一指出差異。你留言、agent 修正，再輸出給你確認，這個反覆調整的循環稱為強化學習（reinforcement learning）：簡單來說，就是透過回饋，讓下一次的結果更符合你的偏好。你在 RUBRIC Editor 裡做的，就是這個循環的迷你版。

接下來會一步步走過這個流程：先檢查 clip，再修正並留言，最後把回饋交給 agent。

操作步驟：在 RUBRIC Editor 裡審片

  1. 把所有 clip 播一遍。課程的做法是一次播完全部 clip，通常用 2 倍速。邊聽邊留意有沒有誤放進來的 false start，也就是講錯後重新開始的片段。

  2. 該保留的段落被砍掉了，就延伸 clip。把 clip 延伸到需要保留的部分即可。延伸時，系統會自動替這個 clip 加上對應註解，讓你修剪的同時也留下原因。

  3. 需要拆開的地方，按 C 切分。遇到停頓，或需要把內容拆成兩段時，按 C 切開 clip，再拖曳調整。反過來，如果 clip 太長，也可以拖曳並刪除不需要的部分。

  4. 被誤刪的片段，用 + 加回來。如果 agent 刪掉了你想保留的段落，使用 + marker 把它救回來。

  5. 打開 Teach my /cut。介面頂端有兩個開關：Teach my /cut 和 Teach my /animate。開啟 Teach my /cut，這一輪的修正才會納入訓練資料。

  6. 集中留言，再交給 agent。按 Copy comments for all clips，就能一次複製所有 clip 上尚未處理的留言。把內容貼給 Claude，比重新打字更快，也能保留每則留言對應的 clip、時間點和問題。

常用操作可以透過快捷鍵或手勢完成。如果你用過 Premiere 這類剪輯軟體，操作方式會很熟悉：

動作快捷鍵／手勢
縮放時間軸按住 Ctrl
水平捲動（scrub）按住 Shift，左右拖曳
只播放原始素材R（或點 raw footage）
調播放速度S / D
切分 clipC
救回被刪的片段+ marker
延伸 clip（會自動加註解）拖曳邊緣

這些功能是依照講師自己的工作習慣設計的。快捷鍵和面板配置都可以依你的偏好調整，不必照單全收。

讓 /cut 一步步來：把留言回饋給它

完成審片並整理好留言後，就可以把回饋交給 agent，請它修正這一批剪輯，也記下你的偏好。如果你希望它逐步操作、每次只問一個問題，可以使用這段提示：

/cut my recording. go one step at a time and ask me one question at a time.

- first ask me where the raw recording is, then what it is (a short, a long video or a lesson)
- transcribe it, keep the last clean take of every line, and cut the pauses and false starts
- do a dry run first and show me the kept text before you render anything
- then put the cut on RUBRIC Editor so i can listen to it and trim it
- when i send my notes back, fix the cut and write down what i liked and didn't like, so the next cut starts closer

最後一行是這個回饋循環的重點：收到你的筆記後，agent 不只要修好這一支，也要記下你喜歡和不喜歡的地方，讓下一次剪輯一開始就更接近你的偏好。這就是強化學習在這裡的實際做法：每一輪修正，都為下一輪提供參考。

一開始，你可能會對 Claude 剪出的結果不滿意。持續用這種方式提供回饋，它就能逐步調整，慢慢剪得更符合你的要求。

做完長什麼樣

檢查幾件看得見的結果：誤刪的段落是否救回來、該砍掉的 false start 是否清除，以及有問題的 clip 是否都留有對應評論。最後，再確認這些評論已集中成一份可以貼回去的清單。完成這些檢查，這一輪審片與回饋就做好了，也替下一輪剪輯留下參考。

小結

審片時，把所有 clip 播一遍，再逐一修正：該保留的片段被砍，就延伸 clip（系統會自動加註解）；需要拆分就按 C；被誤刪的內容就用 + marker 救回。接著開啟 Teach my /cut，按 Copy comments for all clips 集中留言，再把留言交給 agent。記下你喜歡和不喜歡的地方，能讓下一輪剪輯更接近你的偏好。

當 clip 修到滿意、留言也回饋完成，agent 就會處理這些評論。接下來是最後一步：將核准的成品算圖並匯出。
