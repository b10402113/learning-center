先親手剪一輪：自動化前，先自己剪幾支

Step 1/6 · Automated Editing：RUBRIC Editor＋/cut

學習目標

這一步位於自動化剪輯之前：拿一段原始錄影，用你平常發文的 App 或 CapCut 親手剪一兩支，做出自己的剪輯成品。這麼做是為了練出判斷剪輯好壞的眼力；有了這份經驗，之後才看得出 agent 哪裡剪得不對，也更知道哪些工作適合交給 /cut。

前言：說不出哪裡怪，就是最大的問題

想像一下：你把一段十幾分鐘的原始錄影交給 agent，幾分鐘後收到剪好的成品。你點開來看，總覺得哪裡不太對，卻說不出問題在哪，最後只能回一句：「就……感覺怪怪的。」

這種「講不出來」不是因為你不夠聰明，而是因為你還沒有剪過片。你可能還不知道，一句話重來三次時，通常該留哪一次；沒有這些經驗，也就很難指出 agent 做錯了什麼。這一節要補上的正是這份經驗：在把剪輯交出去之前，先親手剪一兩支，練出判斷的眼光。

為什麼不直接全部交給 agent？

自動剪輯聽起來很省事。但如果你分不出剪得好不好，agent 剪對了，你可能看不出來；剪錯了，你也只能覺得「怪怪的」。所以課程建議先親手剪幾支，這樣 agent 出錯時你才察覺得到。

這就像學開車。坐在副駕看別人開一百次，仍然不等於自己握過方向盤；只有親自開過，才會知道「這個彎要提早煞車」是什麼感覺。手剪一兩支，就是第一次握上方向盤。目的不是把你訓練成賽車手，而是讓你之後坐在副駕時，看得出駕駛有沒有開歪。

好消息是，這一輪的門檻不高。課程講得很清楚，第一支或第二支就夠了。目標是熟悉剪輯的手感、體驗剪完一支片的過程，不是練成剪接師。

順帶的好處：暖帳號

「暖帳號」指的是讓平台上的帳號看起來像有人正常使用。直接用 TikTok 或 Instagram 內建的編輯器剪片，除了累積剪輯經驗，也能順便暖帳號。

背後的想法是，平台會觀察你是不是正常使用它：你有使用內建功能，也有互動，帳號就更像真人在使用。這件事本身很重要，課程會在後續的「該用哪個帳號」模組專門說明；這裡先記得它是個額外好處就好，不必現在深究。

這一輪實際上要怎麼做

做法很簡單：從這一週的影片裡挑幾支親手剪，用平常發文的 App 或 CapCut 都可以。重複出現的工作交給工具，需要你判斷的決定則留在自己手上。

什麼算是「需要你判斷的決定」？課程舉的例子是：「哪一次 take 聽起來最像你？」（take 指的是同一段內容錄製的一次版本。）這種選擇沒有通用的標準答案，只有你最清楚哪個版本像自己，因此不適合直接交給自動化。

相對地，機械又重複的剪切就適合交給 /cut，例如刪掉明顯的停頓和 NG 開頭。簡單來說，選哪個版本由你決定；把重複的剪切工作交給工具處理。

手剪時可以選 CapCut，課程推薦它的原因是對新手友善，而且手機和電腦都能使用。你也可以用平常發文的平台，例如 TikTok 或 Instagram 的內建編輯器，還能順便暖帳號。

小結

自動化剪輯之前，先用發文 App 或 CapCut 親手剪一兩支。目的不是變成剪接師，而是練出看得出 agent 剪錯的眼光。剪一兩支就夠；用平台內建的編輯器，還能順便暖帳號。記住這條分工：重複的剪切交給工具，需要你判斷的事（例如哪個 take 最像你）留在自己手上。
