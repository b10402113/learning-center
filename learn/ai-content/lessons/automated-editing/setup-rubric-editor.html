安裝 RUBRIC Editor 與 /cut：在本機執行，用瀏覽器開啟

Step 2/6 · Automated Editing：RUBRIC Editor＋/cut

學習目標

這一步接在你親手剪過一兩支影片之後：先把 RUBRIC Editor 裝到自己的電腦，再用內建的 /cut 把原始錄影剪成短片，放進 Editor 裡檢查。完成後，你會有一個可在瀏覽器開啟的本機介面，以及一批等著你審看的剪輯。

開始前，先準備一支原始錄影檔（MKV 或 MP4 都可以），並確認你的電腦跑得動本機程式。RUBRIC 系列的安裝方式都和 RUBRIC Scripts 一樣。

前言：要交給 agent 剪，先準備好接收的地方

上一節，你在貼文 App 或 CapCut 親手剪了一兩支影片，開始熟悉「這樣剪對不對」。接下來要把剪輯交給 agent，但在它動手之前，得先準備好 RUBRIC Editor，讓剪好的片段有地方可以查看和審核。

RUBRIC Editor 是在你自己電腦上跑、用瀏覽器操作的軟體；/cut 則是它內建的 skill，也就是讓 agent 執行剪輯工作的工具。這一節會先安裝 Editor，再把原始錄影交給 /cut。

安裝步驟

  1. 下載 RUBRIC Editor。到 RUBRIC 課程的 Micro Apps 下載。下載後會有一個 zip 檔，以及附帶的安裝提示（install prompt）。

  2. 把安裝提示整段複製，貼給你的 agent。這和安裝 RUBRIC Scripts 的做法相同：讓 agent 按照提示帶你完成設定，不必自己逐項摸索。

  3. 確認 Editor 在本機開啟。安裝完成後，RUBRIC Editor 會出現在一個本機網址（local host URL）。簡單說，程式是在你的電腦上執行，只是操作介面開在瀏覽器裡。之後用 Chrome 開啟這個網址即可使用。

  4. 確認 /cut 已經就緒。RUBRIC Editor 內建 /cut，不用另外安裝。把原始錄影交給 agent 後，它會剪輯影片，並放到 RUBRIC Editor 供你審核。

安裝完成後，你應該能用本機網址開啟 RUBRIC Editor，也能在 agent 那邊使用 /cut。

第一次用 /cut：把原始錄影交出去

準備好 Editor 後，第一次使用時，把原始錄影的路徑交給 /cut。下面是課程提供的起手式；照抄後，換成你自己的檔案路徑和影片標題即可：

/cut [path to my raw recording, for example C:/Videos/my-shorts.mkv]

this is one long take of me reading [7] short videos from my teleprompter, one after another: [the titles, one per line]. cut each one into its own clean vertical clip and put them all on one RUBRIC Editor so i can review them.

這段指令分成幾個部分。第一行的 /cut 後面，要接原始錄影檔的路徑，例如 C:/Videos/my-shorts.mkv，讓 agent 知道要處理哪個檔案。

接著，告訴它影片的內容：這是一段連續錄影，你對著提詞器依序唸了幾支短片，並把每支短片的標題逐行列出。最後，交代希望它怎麼處理：把每支短片各自剪成乾淨的直式片段，再全部放進同一個 RUBRIC Editor，方便你一起檢查。

這段上下文不是絕對必要，因為現在的模型通常能自行分辨長片裡的不同短片。不過，補上影片內容和標題，能提高第一次剪對的機會，也讓結果更可靠。多寫這一句，就能少一點來回修正。

做完長什麼樣

打開 RUBRIC Editor，你應該會看到幾支剪好的 clip，可以逐一播放和審核。看到這些片段，表示 Editor 已安裝完成，/cut 也已成功把原始錄影送進剪輯流程。

至於 /cut 如何判斷哪些內容要保留、哪些要剪掉，下一節會再說明。先完成安裝並跑過一次，接下來才有具體的剪輯結果可以檢視。

小結

安裝 RUBRIC Editor 的流程是「下載 zip → 複製安裝提示 → 整段貼給 agent」，和安裝 RUBRIC Scripts 的方式相同。Editor 在自己的電腦上執行，透過瀏覽器開啟，而且內建 /cut。第一次使用時，提供原始錄影路徑和影片上下文，agent 就會剪輯片段並放進 RUBRIC Editor。

裝好 Editor、交出第一段原始錄影後，下一節就來看：/cut 是怎麼判斷哪些片段該留的。
