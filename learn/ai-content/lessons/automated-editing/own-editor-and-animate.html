Step 6/6 · Automated Editing：RUBRIC Editor＋/cut

這是 Automated Editing 的第六步，也是最後一步。前面五步使用 RUBRIC Editor；這一步整理其他輸出方式，讓已經有慣用剪輯軟體的人可以查閱。輸入是排好順序的 cut，產出則是匯出的剪輯，或加上動畫的版本。

學習目標

這一節列出直接匯出、透過 MCP connector 連接 Premiere／DaVinci／Final Cut，以及選配的 /animate。

名詞定義

MCP（Model Context Protocol）是一種開放標準，讓 agent 能操作其他應用程式；MCP connector 是接在 Claude Code 上的連接器，安裝後可用來操作 Premiere 等軟體。/animate 是一個 skill，可在 cut 排序後，從現成元素庫加入動畫。

三種把剪輯交出去的方式

方式說明適用情境
直接在 RUBRIC Editor 算圖匯出課程預設路線，修剪後直接匯出短影音
用 MCP connector 接自己的剪輯軟體讓 Claude Code 在 Premiere／DaVinci／Final Cut 裡與你協作已有慣用軟體，尤其是長影音
/animate（選配）在已排序的 cut 上加入動畫需要動畫效果的成品

課程提到，講師會直接算圖匯出短影音；長影音則偏好進 Premiere Pro 再審一遍。這類連接器有不少以開源形式釋出。

連接 Premiere Pro 的提示

以下是課程示範的 Premiere Pro 連接器提示：

Connect my Premiere Pro so you can work in it with me, using the Adobe Premiere Pro MCP: github.com/hetpatel-11/adobe_premiere_pro_mcp

1. Read its README first, and tell me in plain words what it can do and what it needs.
2. Walk me through the install one step at a time, and wait for me at each step.
3. Test it: open my project, list my sequences, and tell me what you see.
4. Wait for my go before you change anything in my projects.

提示包含四項要求：先讀 README，並用白話說明連接器的能力與需求；一步一步帶你安裝；開啟專案並列出序列來測試；等你同意後才修改專案。

找其他編輯器的連接器：/search-connectors

/search-connectors 是用來尋找其他編輯器連接器的 skill。以下是課程提供的提示：

/search-connectors for my video editor. first ask me which editor i use (premiere pro, davinci resolve, final cut pro or something else).

- look for official connectors first, then community ones, and check each one is still kept up
- tell me the best one and how to install it, in plain words
- wait for my go before you install anything

提示要求 agent 先詢問你使用哪一種編輯器，再優先尋找官方連接器、其次尋找社群連接器，並確認它們仍在維護。接著，agent 會用白話說明建議選項與安裝方式，並等你同意後才安裝。

/animate（選配）

項目內容

課程列出的起步方式包括用手機對著螢幕錄影，再剪掉不要的部分。想加入更複雜的動態效果時，可再使用 /animate。

小結

輸出方式有三種：在 RUBRIC Editor 直接算圖匯出、使用 MCP connector 連接 Premiere／DaVinci／Final Cut，或在排好順序的 cut 上使用選配的 /animate。/search-connectors 可用來尋找其他編輯器的連接器；兩段連接器提示都要求 agent 先說明、逐步安裝，並在你同意前不修改專案或安裝連接器。

這一步的成果是完成並匯出一支經過自己核准的剪輯，也整理了連接其他剪輯軟體與加入動畫的方式。想了解 /cut 背後的原理，可回到第三步；想複習匯出流程，可回到第五步。
