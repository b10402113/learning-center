輸出成品：Render 與 1080p 匯出

Step 5/6 · Automated Editing：RUBRIC Editor＋/cut

學習目標

這一步在剪輯與審片之後、發布之前：把你已核准的 cut（剪輯版本）算圖並匯出成影片檔。開始前，請先確認所有評論都已處理完成，而且你已核准 cut。完成後，你會得到一支或多支 1080p 成品，並確認檔案位置、修剪內容與音訊都正確。

前言：修到滿意了，只差變成檔案

上一節，你在 RUBRIC Editor 裡把 clip（影片片段）修到滿意，也集中送出留言，讓 agent 逐一處理。剪輯和審片完成後，還要把核准的 cut 轉成可以發布的影片檔；這個把剪輯結果輸出成影片的動作，稱為算圖（render）。接下來，我們就來完成算圖與匯出。

前置條件很單純：所有評論都已由 agent 解決，而且你已核准 cut。做完後，你會拿到一支或多支 1080p 成品，準備進入下週的發布與排程。

步驟一：請 agent 算圖，或手動挑解析度

修剪完成後，可以請 Claude 幫你算圖。課程也提到，如果你想自己控制匯出設定，介面上有一個 expert 按鈕，可讓你挑選不同解析度。想省事就交給 agent；想自行選擇，就使用按鈕。

步驟二：送出匯出指令

要 agent 輸出成品，可以使用課程提供的這段指令。算圖是剪輯流程的最後一道手續，所以要明確交代：前面做過的修剪都必須保留。

export my approved cut at 1080p. ask me one question at a time.

- first ask me which project, then whether you should render this clip or all of them
- render from the cut i approved, with every trim i made in RUBRIC Editor
- when it's done, tell me where the file is and check the sound plays all the way through

這段指令分成三個重點。第一，指定輸出規格為 1080p，並要求 agent 一次只問一個問題，避免你同時要回答好幾項設定。

第二，agent 要先問你是哪個專案，再確認要算這支 clip，還是全部 clip。若你手上有好幾支影片，這能避免算錯範圍。

第三，也是最重要的一點：從你核准的 cut 開始算圖，並保留你在 RUBRIC Editor 裡做過的每一個修剪。完成後，agent 還要告訴你成品檔案的位置，並確認音訊從頭到尾都能播放。

步驟三：檢查三件事

匯出完成後，先別急著把檔案交出去。花一分鐘檢查以下三件事，確認成品符合預期：

  1. 檔案位置。agent 應該清楚告訴你成品存在哪個路徑，不能只含糊地說已完成。

  2. 每個修剪都在。對照你在 RUBRIC Editor 做過的編輯：該砍掉或留下的內容，以及你手動切分的地方，都應該出現在成品裡。

  3. 音訊正常。從頭到尾播放成品，確認聲音一路正常，沒有中途消失或斷掉。

為什麼要強調「從核准的 cut 算」

算圖看起來是按一下按鈕就能完成；但如果 agent 從自己的版本，而不是你核准的版本開始算，你之前逐段修好的內容就可能不會出現在成品裡。

因此，指令要明確寫出「從我核准的 cut 算起，並帶上我每一個修剪」。這句話能提醒 agent 以你確認過的版本為準，保留前面完成的編輯。

做完長什麼樣

完成後，你會拿到一支或多支 1080p 成品檔案。這些就是下週要發布、排程的短影音，接下來的課程會談如何把它們分發到各平台。

到這一步，你已經完成「錄一支長 take → 自動剪成多支短片 → 審片修正 → 匯出成品」的整套製作流程。

小結

剪輯與留言回饋完成後，最後一步是算圖並匯出。你可以請 agent render，也可以按 expert 按鈕自行挑選解析度。送出 1080p 匯出指令時，記得交代 agent 一次只問一個問題、先確認專案與算圖範圍，並從你核准的 cut 開始、保留所有修剪。完成後，確認檔案位置、修剪內容與音訊都正確。
