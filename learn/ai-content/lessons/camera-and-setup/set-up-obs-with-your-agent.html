跟著 agent 一步步設好 OBS：先顧聲音，再擺場景

Step 4/5 · Camera and Setup：手機就夠，先投資聲音

學習目標

這是設定 OBS 的實作步驟：你會把一段 prompt 交給 agent，讓它依序帶你完成安裝檢查、收音、場景設定和測試錄影。動手前需要準備一台電腦、一個可用的 agent、一支麥克風，以及一個鏡頭；做完後，你會得到一段能播放、有聲音、畫面比例正確的測試影片。

前言：這次不用自己摸選單

前三節已經準備好基本觀念和工具：手機就能當鏡頭、錄影先顧聲音、OBS 可以使用，也找到 connector 並開啟了 WebSocket。現在要把 OBS 設定好。對新手來說，這一步常讓人卡關：選單很多，像是麥克風音量該調到哪裡，就可能讓人研究半天。

這次不用自己一個個摸索選單。你只要把一整段 prompt 貼給 agent，讓它按順序帶你完成設定。過程中，你需要回答它的問題，並照著它的指示操作。

前置條件：準備一台電腦、一個可以使用的 agent、一支麥克風，以及一個鏡頭。鏡頭可以是手機或電腦內建鏡頭。開始前，先決定影片要錄成橫式（例如電腦課程或教學）還是直式（例如短影音），因為這會決定後面的畫布形狀，agent 一開始就會問你。

把整段 prompt 交給 agent

打開 agent，把下面整段 prompt 貼上並送出。agent 會一步步帶你操作，每完成一步就等你繼續。

"""Help me set up OBS Studio so I can record my screen and my camera together. Go one step at a time, and wait for me after each one.

1. Ask me, one at a time: am I on Windows or Mac, which camera and mic I'm using, and am I recording landscape (lessons on my computer) or vertical (shorts).

2. Check if OBS is installed. If it isn't, install it from obsproject.com, or give me the link if you can't install apps.

3. Check for a connector: run /search-connectors for OBS (or search for an OBS MCP server). If there's one that's still looked after, tell me what it can do and help me turn on the WebSocket server in OBS (Tools, WebSocket Server Settings), so you can control OBS yourself. If not, walk me through each click instead.

4. Audio first: add my mic, have me talk for 10 seconds at my normal volume, and help me set the level so my voice sits in the upper yellow of the meter and only just touches the red when I'm loud. Mute any sound I don't need.

5. Make two scenes: "Screen + camera" (my screen full size, my camera in a corner) and "Camera" (just me, full frame). Set the canvas to the shape I picked.

6. Ask me which editing app I use, then set where my recordings save, in a format that app can open.

7. Do a 30-second test recording. Check the file plays, has sound and has the right shape, and tell me in plain words what to fix.

This is for recording only, so never start a stream."""

這七步各自在做什麼

送出 prompt 後，agent 會依照這七步操作。先了解每一步的目的，你就能知道它為什麼這樣問，也比較清楚自己要怎麼回答。

  1. 先了解你的設備和需求，一次問一題。agent 會問你使用 Windows 還是 Mac、使用哪個鏡頭和麥克風，以及要錄橫式還是直式。這些答案會影響後續設定；一次問一題，也比較不容易漏答。
  2. 確認是否已安裝 OBS。如果還沒安裝，agent 會嘗試從 obsproject.com 安裝。如果它無法替你安裝程式，就會提供連結，讓你自行下載安裝。
  3. 確認 connector，並設定 WebSocket。connector 是讓 agent 連接並操作 OBS 的工具；WebSocket 則是 OBS 提供的連線功能，開啟後，符合條件的 connector 就能與 OBS 溝通。agent 會用 /search-connectors 尋找 OBS connector，或搜尋 OBS MCP server。如果找到仍在維護的工具，它會說明功能並幫你開啟 OBS 的 WebSocket；若找不到，就改為逐步帶你點選設定。這也接上了上一節介紹的判斷方式。
  4. 先調整麥克風音量。agent 會加入你的麥克風，請你用平常的音量說 10 秒，再依照音量表幫你調整：平常說話時落在黃色區的上半段，大聲說話時才剛碰到紅色。最後，它會把不需要的聲音來源靜音。
  5. 建立兩個場景。「Screen + camera」會讓螢幕占滿畫面、鏡頭縮在角落；「Camera」則只有你，鏡頭占滿整個畫面。畫布會依照第一步選好的橫式或直式設定。
  6. 設定錄影檔的存放位置與格式。agent 會先問你使用哪個剪輯軟體，再設定存檔位置與該軟體能開啟的格式。
  7. 錄一段 30 秒測試影片。錄完後，agent 會確認檔案能不能播放、有沒有聲音、畫面比例是否正確，並用白話告訴你需要修正的地方。
注意：這段 prompt 只用來錄影，絕對不要開始直播。prompt 最後一句明確寫著 This is for recording only, so never start a stream. 開始串流會把畫面播出去，因此設定時要記得：只錄影，不直播。

預期會看到什麼

完成後，你應該會有一個實際錄好的測試檔案：長度約 30 秒，能正常播放、有聲音，而且畫面比例符合你選的橫式或直式。如果 agent 指出聲音太小或比例不對，就照它的建議調整，再錄一次。等影片聽起來、看起來都正確，OBS 的基本設定就完成了。

課程的 resources 區也整理了會用到的工具，方便你之後查找：OBS Studio（免費開源，適用於 Windows、Mac 和 Linux），以及 OBS MCP（由社群維護的非官方 connector；使用前要確認它是否仍在維護）。

小結

把「Set up OBS with your agent」prompt 整段交給 agent，讓它照七個步驟帶你完成設定：確認設備與錄影方向、檢查 OBS、尋找 connector 並設定 WebSocket、調整麥克風音量、建立兩個場景、設定錄影檔的存放位置與格式，最後錄一段 30 秒測試影片。完成的標準很明確：檔案能播放、有聲音，畫面比例也正確。記得，這段流程只用來錄影，不要開始串流。

OBS 設好並確認能錄影後，接下來要學會在錄影時切換場景。下一節會介紹場景切換快捷鍵和讀稿機，最後帶你錄下第一支乾淨的 take。
