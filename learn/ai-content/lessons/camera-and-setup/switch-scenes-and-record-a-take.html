用快捷鍵切換場景、搭配讀稿機：錄下第一支乾淨的 take

學習目標

這是 Camera and Setup 的最後一步。你會為 OBS 場景設定快捷鍵，錄影時不必停下來也能切換畫面，再搭配讀稿機，錄下一支乾淨的 take，也就是一段完整、順暢的錄影。

動手前，你需要先完成上一節的 OBS 設定，並測過一段 30 秒的錄影。這一步會用到你現有的 OBS 場景；完成後，你會有一組可在錄影中使用的快捷鍵，也能確認每次切換都錄進檔案裡。

前言：錄到一半想換畫面，難道要停下來嗎

真正開始錄影時，你可能會想從「你的臉」切換到「螢幕畫面」，或暫時遮住畫面處理事情。如果每次都得停錄、用滑鼠點選場景，再重新開始，整段影片就容易變得零零落落。

這一步要解決的，就是如何在錄影中順順地換畫面。你會事先設定快捷鍵，錄影時按一下就能切換，不必停下來；再搭配讀稿機，讓你看著稿子唸，也能看著鏡頭。完成後，就能錄下第一支乾淨的 take。

為什麼要用快捷鍵：講師實際怎麼用

還記得第二節提到，課程講師最常用的 OBS 功能之一就是快捷鍵嗎？快捷鍵是預先指定好的按鍵組合，按下後就能直接執行某個操作。講師會用 Shift+Control+1 切到自己比較大的畫面；按 Shift+Control+2，則會切換到白色或黑色的空白幕，同時把麥克風靜音。

第二個快捷鍵特別實用。講師錄影時如果要咳嗽、喝水或處理事情，可以先切到空白幕，不必停止整段錄影。由於這個場景也會把麥克風靜音，觀眾只會看到乾淨的空白畫面。快捷鍵讓換畫面變成錄影時順手按一下就能完成的事。

把第二段 prompt 交給 agent

設定快捷鍵時，可以把下面這段 prompt 整段交給 agent。它會逐步處理，每一步都會等你：

"""Set up hotkeys in OBS so I can switch views while I record, without stopping. Go one step at a time.

1. Show me the scenes I have, and ask which views I want, for example: me large, my full screen, and a blank screen to hide what I'm doing.

2. Make any scene that's missing. For the blank screen, use a plain black or white colour and mute my mic in that scene.

3. Set a hotkey for each scene (for example Ctrl+Shift+1, 2 and 3), using keys no other app I use already takes.

4. Make a vertical version of my main scene too, for shorts.

5. Do a short test recording where I switch between them, and check each switch shows up in the file."""

這五步各自在做什麼

這段 prompt 會依序完成五件事。知道每一步的用途，也能幫你確認 agent 是否做對：

  1. 先列出現有場景，再詢問你需要哪些視角。場景是 OBS 裡先設定好的畫面配置。agent 會列出你已經有的場景，並詢問你想使用哪些視角，例如「我放大」、「我的全螢幕」或「用空白幕遮住我正在做的事」。
  2. 補上缺少的場景。如果你需要某個場景、但目前還沒有，agent 會幫你建立。空白幕可以用純黑或純白，而且要在該場景把麥克風靜音。這樣切換過去時，畫面和聲音都會暫停，方便你暫時離開。
  3. 為每個場景設定快捷鍵。例如 Ctrl+Shift+1、2、3。prompt 特別提醒，要選用沒有被其他 app 占用的按鍵組合，避免按下後觸發其他軟體的功能，而不是切換 OBS 場景。
  4. 建立主要場景的直式版本。直式畫面之後可以用來製作短影音。
  5. 錄一小段測試影片。測試時切換不同場景，錄完再檢查影片檔，確認每次切換都有出現在畫面中。如果沒看到切換，就代表還需要檢查快捷鍵設定。
注意：切到空白幕時，聲音也會一起消失。這是預期的設定，不是故障，因為該場景會把麥克風靜音。要繼續說話，記得先切回正常場景。

搭配讀稿機：看著稿唸，又能看著鏡頭

場景設定完成後，還可以準備讀稿機（teleprompter）。它會顯示你的腳本，讓你一邊看著稿子唸、一邊看著鏡頭，不必低頭讀稿。課程提供簡單的讀稿機，有電腦版和手機版；它是選用工具，不使用也沒關係。如果你要錄有腳本的內容，讀稿機讓你看起來更自然。

現在，OBS、場景與快捷鍵都準備好了，讀稿機也可以就位。接下來只要按下錄影，就能錄下第一支乾淨的 take。

預期會看到什麼

完成測試後，打開錄好的檔案，確認畫面會隨著快捷鍵切換：從你放大的畫面，到全螢幕，再到空白幕，而且每次切換都確實出現在影片裡。確認無誤後，就正式錄一支影片。

課程建議用手邊已有的設備，今天就錄一支乾淨的 take。第五支會比第一支更好，不是因為換了相機，而是因為你多練習了幾次。

小結

錄影中要順順切換畫面，先在 OBS 設好快捷鍵。把「Switch scenes with hotkeys」的 prompt 交給 agent 後，它會列出現有場景、詢問你需要哪些視角、補上缺少的場景，再為每個場景設定快捷鍵。空白幕使用純黑或純白，並在該場景中將麥克風靜音。接著建立直式版本，錄一小段測試影片，確認每次切換都有錄進檔案。搭配讀稿機後，你就能看著稿、對著鏡頭，錄下第一支乾淨的 take。

走完這五步，你就能用現有器材錄完一支影片。下一步會進入自動剪輯：把今天錄下的原始素材交給 agent，剪成成品。
