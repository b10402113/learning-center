把任何題目改寫成觀眾版本

Step 2/4 · Selfless Content

學習目標

跟著四個動作走一遍，你就能把手上「以我為主」的題目，翻成觀眾拿得走的版本。

前言：知道自己太自我，然後呢？

上一節我們認出了問題：內容若以創作者為主角，陌生人就沒有理由停下來。可是光知道「我太自我了」還不夠。真正卡住的時候，是坐在電腦前，盯著一個明明想講、卻講不出要點給誰的題目。這一節要給的，就是那個能重複使用的改寫動作。

動手前需要先具備兩樣東西：一個你真實想做的點子，以及上一節那個「主角是誰」的判準。做完之後你會得到什麼？同一批題目，但每一條前面都掛上了一句「觀眾能帶走什麼」。這不是靈感，是一套照著做就會動的流程。

改寫動作：四個步驟

這套動作的核心只有一句話：把主詞從「我」換成「觀眾」。實際操作時，拆成四步會比較好下手。

  1. 用一句話寫下你原本想講的題目。先不求好，把腦袋裡那個版本照抄出來就好，例如「我的一天」、「我考到 AWS 證照了」。這一步的用意是把隱形的題目變成看得見的字，方便下一步動手。
  2. 圈出題目裡「以我為主」的字。找「我、我的、我考到、我做了」這類詞。它們就是主詞站錯邊的地方。以「我考到 AWS 證照了」為例，圈起來的就是開頭那個「我」。
  3. 問一句：這段經歷裡，別人也能拿去用的是什麼？答案通常是一個做法、一組判斷，或一則資訊。考證照的經驗裡，別人能拿去用的不是「你拿到了」，而是「你是怎麼準備、怎麼報名、怎麼通過的」。這一步是整段流程的心臟，因為它逼你把焦點從自己的成果，移到觀眾能複製的路徑。
  4. 把主詞換成觀眾，或把「我的成果」換成「怎麼做到」。「我考到 AWS 證照了」就變成「怎麼考到 AWS 證照」。預期會看到：題目裡原本的主角消失了，換成了一個觀眾可以走進去的位置。

四步走完，你會拿到一句觀眾版的題目。接下來拿它去對照原版，兩者講的其實是同一段經歷，差別只在視角。

看兩個真實例子

我在課程裡示範了兩次這個改寫，一次是日常類型，一次是成就類型。

第一種是原本的「我的一天」vlog。改寫的方向，是把它講成「我做的那份工作的一天」，讓同樣在做這行、或想進這行的人，能在裡面看到可以參考的東西。課程裡舉的例子，是一位資料工程師拍了自己工作的日常，因為內容是針對資料工程這個領域的觀眾，最後觸及了八萬人。同一台攝影機、同樣是記錄一天，改變的是「拍給誰看」。

第二種是「我考到證照了」這種成就公告。我說，這種內容如果只包成「我拿到 AWS 認證」，大概就只是一則 LinkedIn 貼文，看一看就過去了。但你可以把它轉向觀眾，把重點放在「教別人怎麼也考到 AWS 認證」。經歷沒有變，只是從「我做到了」改成「你也可以這樣做」。

原本的題目圈出以我為主的字觀眾能拿走什麼改寫後
我的一天我這份工作的內容長什麼樣資料工程師的一天
我考到 AWS 證照了我怎麼準備、怎麼報名、怎麼通過怎麼考到 AWS 認證

把這兩組並排看，你會發現改寫不是把內容砍掉重寫，也不是要你隱藏自己。它更像換一個鏡頭：本來鏡頭對準你，現在鏡頭對準觀眾要去的方向，而你剛好站在那條路上，可以指路。

以我為主（原版）：「我考到 AWS 證照了，準備了三個月，終於通過。」
以觀眾為主（改寫後）：「想考 AWS 證照？我把準備流程、報名步驟和通過的關鍵整理給你。」

檢查有沒有改對

改完之後，用一個小動作驗收：把改寫後的題目念一遍，然後問「一個不認識我的人，看得出來他能拿到什麼嗎？」如果答案具體（他會學到怎麼準備考試），改寫就成立；如果答案還是繞回你自己（他會知道我考上了），那第 3 步通常還沒做透，回去再問一次「別人能拿去用的是什麼」。

至於「為什麼這套動作有效」、「它跟陌生測試的關係」這類原理，交給這個節點的觀念段落去交代，你在這裡先把流程跑順就好。

小結

改寫的核心是換主詞：先用一句話寫下原版題目，圈出「我、我的」這些以我為主的字，再問「別人能拿去用的是什麼」，最後把主詞換成觀眾、或把「我的成果」換成「怎麼做到」。同一段經歷，改完就從日記變成指南。原版是我做到了，改寫後是你也可以這樣做。

會改寫自己的日常與成就之後，還會遇到一種更難的題目：當你是在賣東西呢？下一節要看兩個真實案例，說明連廣告和產品發布，都能用同一套邏輯包成教學。
