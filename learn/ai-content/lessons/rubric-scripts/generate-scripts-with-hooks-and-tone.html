用 /rubricscripts 生腳本：候選點子進、3 個 hook＋腳本出

Step 3/5 · RUBRIC Scripts：從點子到腳本

學習目標

用 /rubricscripts 載入候選點子，讓 agent 用你的 /hooks 與 /tone 為每個點子寫出腳本與 3 個 hook 選項，並學會在頁面上搜尋、排序、開啟腳本。

前言：動手前，先確認前置和產出

這一節做完，你的工作台上會有一批可以直接 review 的腳本：每個點子一支，各自附 3 個 hook 選項、一份 caption，以及你參考用的連結。前置只有兩件事：RUBRIC Scripts 已經裝好、開在 localhost；你手邊有一份候選點子（上週 /outliers、/latest 的結果，或你自己存下來的）。

接下來的主體就是「指令」。因為這套軟體是 agent-ready，真正決定產出好壞的，不是你怎麼點介面，而是你怎麼把指令交給 agent。所以下面會把課程提供的指令逐字放上來，並逐段說明它在做什麼。

步驟 1：準備候選點子

把這週想做的點子列出來，或直接沿用上週的 shortlist。點子可以很簡短，也可以寫得詳細一點，你給的細節越多，等於給 agent 的方向越多，生出來的腳本就越接近你要的。有來源連結的話，一併附上。

步驟 2：把點子連同 /rubricscripts 交給 agent

在 agent 裡輸入 /rubricscripts，後面接你的點子。課程提供了一段可以直接照抄的指令模板：

"""/rubricscripts turn these ideas into scripts for short videos:

1. [idea one, plus the link it came from if I have one]
2. [idea two]
3. [idea three]

Use my /hooks and /tone skills, give me 3 hooks for each script, write a caption for each one, and add the links you used as references. Never make up a fact, a number or a link. When they're in RUBRIC Scripts, give me the link to open it."""

逐段拆開來看。第一行的 /rubricscripts 是在告訴 agent「這是一個生稿任務」，後面接著「把這些點子變成短影音的腳本」。中間的 1、2、3 就是你的點子；如果點子有出處連結，就附在後面。接著那一段要求是重點，它一次講清楚四件事：用我的 /hooks 和 /tone skill、每支腳本給 3 個 hook、每支寫一份 caption、並附上你參考用到的連結。最後一句是護欄：Never make up a fact, a number or a link，也就是明確要求它不要編造事實、數字或連結；再要它把成品放進 RUBRIC Scripts 後，給你一個開啟的連結。

替代做法：先載入、先別寫稿

如果你還想先從清單裡挑，而不是一次全部生出來，課程也準備了另一段指令。它會先確認 RUBRIC Scripts 裝好了、撈出你的 shortlist、問你要載入哪幾個，最後才逐個生稿：

"""Load my content ideas into RUBRIC Scripts, so I can turn them into scripts.

1. Run /rubricscripts first, so you know how RUBRIC Scripts works. If it isn't installed, tell me and stop there.
2. Find my shortlist: my latest /outliers and /latest results, and any ideas I saved myself. Show them to me as a short numbered list.
3. Ask me which ones to load, and wait for my answer. If I don't have a shortlist yet, offer to run /latest and /outliers again first.
4. Write a script for each idea I pick, with 3 hooks to choose from, and load them into RUBRIC Scripts.
5. Tell me how many scripts are ready and give me the link to open RUBRIC Scripts."""

它的五個步驟依序是：一、先跑一次 /rubricscripts，確認它懂 RUBRIC Scripts 怎麼運作；沒裝就停下來告訴你。二、撈出你的 shortlist：最近的 /outliers 和 /latest 結果，以及你自己存的點子，用編號清單列給你看。三、問你要載入哪些，並等你回答；如果你根本還沒有 shortlist，它會提議先重跑 /latest 和 /outliers。四、對你挑中的每個點子寫一支腳本，各附 3 個 hook，載進 RUBRIC Scripts。五、回報有幾支好了，並給你開啟連結。

看出差別了嗎？第一段是「點子都在你腦中，直接生」；第二段是「先讓 agent 幫你把候選撈出來、你挑，再生成」。兩種都行，看你當下手上是想法還是清單。

步驟 3：打開連結，看第一批腳本

送出指令後，agent 會回你一個連結，多數是本機的 localhost 網址。點開它，你就會看到頁面上列著剛生好的腳本，上方也會顯示你目前有幾支可以 review。

預期會看到：頁面出現一批腳本，每個點子一支，上面標著各是哪個點子生出來的。

步驟 4：在頁面上搜尋、篩選、排序

腳本一多，靠這幾招就能管得動，不必一支一支找：

  • 搜尋與篩選：直接搜尋腳本，或用篩選器把範圍縮小，先找出你今天想看的那幾支。
  • 排序：可以依自訂順序、最後編輯、最新加入、閱讀時間最短、或字母順序來排。
  • 檢視方式：卡片或清單兩種版面，看當下哪種順眼就切哪種。
  • 明暗模式：有 light 和 dark 兩種，晚上看眼睛比較舒服。
  • 新增腳本：想再加一支時，按新增的彈窗會提示你「用 rubric scripts skill」，也就是回到 /rubricscripts 那條路，而不是在頁面上手工輸入。

有個小地方值得一提：連「新增」都把你導回 skill，這就是 agent-ready 的意思。頁面負責呈現與整理，生成一律交給 skill 和 agent 來做。

步驟 5：打開一支腳本，認識它的版面

點開任何一支腳本，版面大致固定：左邊是你所有的點子，可以一一切換過去；腳本本身預設提供 3 個 hook 讓你挑，想手動改也可以直接編輯；旁邊是它的 caption，而且附上一些 EEO（讓內容更容易被搜尋與理解）的最佳實務，以及這支影片在講什麼的說明；底部放的則是你參考用的連結，方便你回頭核對內容正不正確。

把 hook、caption、參考資料放在同一頁，就是這個工作台相對「對話框」最直接的好處：你 review 一篇文章該看的東西，全在一個畫面裡。

預期會看到：一支腳本上有 3 個可挑選的 hook、一份 caption、一組參考連結，左側可以切換到其他點子。

小結

/rubricscripts 是生稿的入口指令。把點子（連同來源連結）交給它，agent 就用你的 /hooks 與 /tone，為每個點子生一支腳本、3 個 hook 選項和一份 caption，並把成品載進 RUBRIC Scripts。想先挑清單再寫，就改用「先載入」那段指令。之後在頁面上用搜尋、篩選、排序與卡片／清單來管理，打開腳本就能看到 hook、caption 與參考資料。

生出來的只是第一版。下一節要教你怎麼在腳本上直接留下回饋，一則指令改好全部，順便教會你的 /tone。
