<LearningGoal>
用 /search-connectors 找到目前還能用的 OBS connector，並開啟 WebSocket 讓 agent 能真正操控 OBS。
</LearningGoal>

## Lesson

找 connector 的判準是：先用 <code>/search-connectors</code> 查最新的、確認它還有人維護，是就打開 WebSocket（Tools → WebSocket Server Settings）讓 agent 連上，不是就讓 agent 一步步帶你點，不要硬裝。
