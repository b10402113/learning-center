# 先手動，再自動：用手機親手編輯與發文

<LearningGoal>
能判斷為什麼起步時要親手用手機編輯與發文，把自動化留到你已經摸熟製作的手感之後。
</LearningGoal>

## Lesson

起步階段課程建議用手機親手編輯與發文、先別急著自動化，因為你還沒長出「什麼叫做得好」的判斷力；等你摸熟、重複動作變成瓶頸時，再讓工具接手，把已經有的手感放大。
