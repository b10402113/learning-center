<LearningGoal>
能說明 `/inspo` 如何把 YouTube 影片一鍵存成靈感牆卡片，並請 agent 之後依主題挑出合適的參考。
</LearningGoal>

## Lesson

`/inspo` 用一支腳本把 YouTube 影片存成靈感牆上的快照卡片——標題、頻道、訂閱數、觀看數、標籤、描述，加上你自己的一句筆記，而且數字刻意凍結在收藏當下；之後請 agent 依「意思」挑出最合適的三到五支參考。它只需要 Node.js 18+，不需要任何金鑰。
