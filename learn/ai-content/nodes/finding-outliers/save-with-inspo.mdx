# 存進 /inspo 靈感牆：一鍵收藏與之後取用

<LearningGoal>
把值得研究的 outlier 存進自己的 `/inspo` 靈感牆，並能請 agent 依主題或情境從靈感牆取出最合適的幾支。
</LearningGoal>

## Lesson

用 `/inspo` 的 helper 一鍵把影片存成「數字凍結在存檔當下、筆記保留」的卡片，之後先 `--list`、再由 agent 用意思比對從靈感牆挑出 3–5 支參考。
