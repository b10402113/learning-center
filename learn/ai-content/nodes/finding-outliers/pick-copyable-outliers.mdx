# 挑出能複製的爆款：看模式，不看單支影片

<LearningGoal>
從 outlier 清單中挑出你這週講得出來、又能複製或加上自己角度的題材，判斷依據是跨帳號重複出現的模式，而不是單一支爆紅影片。
</LearningGoal>

## Lesson

挑選看「跨帳號重複出現的模式」和「你這週講不講得出來」，不看倍數大小；選定後照抄或加上自己的角度，倍數最高那張反而常常不是答案。
