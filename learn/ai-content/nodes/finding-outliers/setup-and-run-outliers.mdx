# 設定並跑 /outliers：YouTube API key、掃描、結果頁

<LearningGoal>
完成 `/outliers` 的一次性設定（YouTube API key），跑出自己利基的 outlier 清單，並能讀懂結果頁上的倍數與排序。
</LearningGoal>

## Lesson

完成 Node 與免費 YouTube key 的一次性設定、把利基寫進 `keywords.json`，跑完「掃描、補角度、重建、回報」四步，得到一張依倍數排序的結果頁。
