<LearningGoal>
能完成 `/outliers` 的一次性設定（zip 安裝、免費 YouTube API key、設定利基）並跑出、讀懂結果頁、把候選放進 cart。
</LearningGoal>

## Lesson

`/outliers` 的一次性設定只有三段：把 zip 交給 agent 安裝、申請免費的 YouTube API key 填進 `.env`（金鑰永不貼進聊天）、把利基關鍵字寫進 `keywords.json`；之後請 agent 跑 `/outliers`，就會得到一張按倍數排序、可把候選放進 cart 的結果頁。清單太薄時，先放大主題、再把時間區間拉長。
