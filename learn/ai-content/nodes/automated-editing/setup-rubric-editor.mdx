<LearningGoal>
用 zip 與安裝提示裝好 RUBRIC Editor，理解它在你電腦本機跑、在瀏覽器開啟，並內建 /cut。
</LearningGoal>

## Lesson

RUBRIC Editor 的安裝是「下載 zip → 複製安裝提示 → 整段貼給 agent」，它跑在你自己的電腦上、用瀏覽器開本機網址，且內建 `/cut`；第一次用 `/cut` 就是給它原始錄影的路徑加一行上下文。
