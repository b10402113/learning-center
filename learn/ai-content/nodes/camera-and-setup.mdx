# Camera and Setup：手機就夠，先投資聲音

## Learning goal

用你現有的器材（手機＋麥克風）配 agent 一步一步設好 OBS，錄一支乾淨的 take。

## Steps

1. [[learn/ai-content/nodes/camera-and-setup/gear-doesnt-matter-audio-does|相機不重要，聲音才重要]] — 搞懂為什麼手機就夠，而唯一值得先投資的器材是聲音
2. [[learn/ai-content/nodes/camera-and-setup/obs-and-your-agent|OBS：免費錄螢幕＋鏡頭，讓 agent 幫你操控]] — 認識 OBS 是什麼、能錄什麼，以及為何適合讓 agent 接手（after step 1）
3. [[learn/ai-content/nodes/camera-and-setup/find-a-live-obs-connector|找一個還活著的 OBS connector：/search-connectors 與 WebSocket]] — 挑到目前可用的 connector，開好 WebSocket 讓 agent 真的能操控（after step 2）
4. [[learn/ai-content/nodes/camera-and-setup/set-up-obs-with-your-agent|跟 agent 一步步設好 OBS：先顧聲音，再擺場景]] — 用一段現成 prompt 把安裝、收音、場景、測試錄影一次設好（after step 3）
5. [[learn/ai-content/nodes/camera-and-setup/switch-scenes-and-record-a-take|快捷鍵換場景＋讀稿機：錄下你的第一個乾淨 take]] — 錄影中切場景、讀稿對鏡頭，今天錄一支乾淨的 take（after step 4）

## Lesson

這節課要拆掉一個最常見的入門卡點：以為要先買好相機才能開始做內容。課程的立場很明確——你手上那支手機就夠了，因為在現在的內容生態裡，畫質早就不是品質的主要指標；真正讓人留下或滑走的，是「聽不聽得清楚」。所以如果只能升級一樣東西，先升級你的**聲音**，而不是換一台更貴的相機。

有了這個優先順序，剩下的就是把它變成一個做得到的流程。課程挑的工具是 **OBS Studio**：一套免費、開源、能同時錄螢幕與鏡頭的軟體，而且因為社群已經替它寫了 connector，你的 agent 可以直接驅動它——你只要把需求講清楚，從安裝、收音、場景到測試錄影都能交給 agent 一步做完。這個節點會先講清楚「為什麼是手機＋聲音」，再認識 OBS 與 agent 的關係，然後處理 connector 這個容易過期的環節（用 `/search-connectors` 找目前還能用的版本、開好 WebSocket），最後跟著現成 prompt 把 OBS 設好、用快捷鍵在錄影中切換場景，並在讀稿機的輔助下錄下一支乾淨的 take。

走完這五步，你應該能用現有器材端到端錄完一支影片，而不用先花錢。第五支會比第一支好——但那不會是因為換了相機，而是因為你多練了幾次。
