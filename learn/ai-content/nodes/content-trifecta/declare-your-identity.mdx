# Wk1 里程碑：宣告並發布你的內容定位

<LearningGoal>
能完成 Wk1 里程碑——寫出並發布你的內容定位宣言、在社群請大家回饋（最好用投票）、知道可選的 agent 訪談 prompt 怎麼用——並說出為什麼「發出來」比「想清楚」更重要。
</LearningGoal>

## Lesson

Week 1 里程碑是寫出並發布一則內容定位宣言、附上三選項投票請社群回饋（卡住時可用我提供的 agent prompt 訪問你）；重點是先發出來——定位不必訂死，發出去才有回饋可以修正。
