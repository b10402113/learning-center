# 安裝並跑 `/latest`：7 天熱點變候選點子

<LearningGoal>
安裝 `/latest`、指定你的利基並跑出結果，讀懂「最多 10 個、每個都帶真實連結」的候選清單，並用搜尋／篩選把有共鳴的點子放進 cart。
</LearningGoal>

## Lesson

安裝 `/latest` 後輸入指令，它會看最近七天、翻出最多十個排好序且各帶真實連結的候選點子，開成可搜尋篩選的結果頁；你把有共鳴的加進 cart，而自己的 well of knowledge 是最關鍵的來源設定。
