# 安裝並跑 `/latest`

<LearningGoal>
安裝 `/latest` skill、設定你的利基，跑出一次結果，並得到一組帶真實連結的候選點子。
</LearningGoal>

## Lesson

安裝 `/latest` 並把預設利基換成你的領域，跑出一次結果，點開幾個連結確認後，把兩到三個想拍的點子放進 cart。
