# 起點是你：AI 放大而非取代你的想法

<LearningGoal>
說出為什麼最好的內容點子常來自你自己的經驗（呼應 Content Trifecta 的 unique），以及 AI agent 在點子發想裡扮演的角色是放大器而不是替代品。
</LearningGoal>

## Lesson

好點子的起點是你自己的經驗與專業（對應 Content Trifecta 的 unique），AI agent 的角色是把你要的候選放大、蒐集與排序，而不是取代你的想法。
