# 起點是你：AI 放大而非取代你的想法

<LearningGoal>
理解最好的點子來自你自己的經驗與專業，AI 只負責放大你的發想量，而不是替代你的判斷。
</LearningGoal>

## Lesson

好點子先從你自己的經驗與專業來，AI 的角色是放大發想的數量，判斷仍然由你來做。
