# 第一手來源與 agent 警示：X、GitHub、官方文件

<LearningGoal>
分辨「第一手」即時來源（X、GitHub、官方文件）與「二手」延遲來源（TikTok／Instagram／YouTube），並能把日常瀏覽與 agent 警示改造成持續的點子研究流。
</LearningGoal>

## Lesson

第一手來源（X、GitHub、官方文件）因為離事情發生最近而領先，TikTok／IG／YouTube 則因製作延遲成為二手來源；把瀏覽變成研究流的兩個動作，是隨手書籤（可請 Claude 讀）與用 prompt 讓 agent 主動發警示。
