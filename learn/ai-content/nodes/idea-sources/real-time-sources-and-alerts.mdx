# 第一手來源與 agent 警示

<LearningGoal>
分辨 X、GitHub、官方文件與 TikTok、Instagram、YouTube 的資訊延遲差，並用 agent 警示與書籤把日常瀏覽變成持續的研究流。
</LearningGoal>

## Lesson

X、GitHub 與官方文件比短影音平台更接近消息源頭，用收藏與 agent 警示把瀏覽變成持續的研究，並讓每則消息都先過你利基的篩選。
