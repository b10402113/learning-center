# 一開始要不要露臉

<LearningGoal>
決定第一步要不要露臉，以及之後如何從不露臉轉成露臉。
</LearningGoal>

## Lesson

一開始不露臉完全可以，若已有信心則露臉更被推薦（建立信任更快）；判準是你有沒有信心、題材需不需要「人」，不露臉是一條可以隨時轉成露臉的起跑線。
