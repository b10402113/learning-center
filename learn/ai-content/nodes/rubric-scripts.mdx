# RUBRIC Scripts：從點子到腳本

## Learning goal

安裝並跑通 RUBRIC Scripts：載入候選點子、用你的 `/hooks` 與 `/tone` 產生 3 個 hook 與腳本，走一趟註解回饋迴路。

## Steps

1. [[learn/ai-content/nodes/rubric-scripts/why-rubric-scripts|為什麼要有 RUBRIC Scripts：別讓腳本散落在對話框裡]] — RUBRIC 家族與 agent-ready 的設計，以及「腳本不該散在對話框裡」的理由
2. [[learn/ai-content/nodes/rubric-scripts/install-rubric-scripts|安裝 RUBRIC Scripts：zip 加安裝指令，跑在本機 localhost]] — 下載 zip、把安裝指令交給 agent，開在本機並接上 `/hooks` 與 `/tone`（after step 1）
3. [[learn/ai-content/nodes/rubric-scripts/generate-scripts-with-hooks-and-tone|用 `/rubricscripts` 生腳本：候選點子進、3 個 hook＋腳本出]] — 載入 shortlist、生成腳本與 3 個 hook，並在頁面上搜尋、排序、開啟（after step 2）
4. [[learn/ai-content/nodes/rubric-scripts/refine-with-comments-and-teach-tone|標註回饋與 Teach my `/tone`：一次改好所有腳本]] — 畫重點留言、複製全部留言一次改稿，並讓回饋同時教會 tone skill（after step 3）
5. [[learn/ai-content/nodes/rubric-scripts/record-in-one-go|一次錄完一批：Telegram、電腦或提詞機]] — 把完成的腳本送上一頁長稿，一次錄完整批交給 agent 剪（after step 4）

## Lesson

Wk3 走到這裡，你已經有了九種 hook 句型和一份 `/tone`，真正的痛點變成「腳本散在對話框裡，之後要改、要比較、要照讀都找不到」。**RUBRIC Scripts** 就是為此存在的：它是 RUBRIC 家族（RoboNuggets 社群自建、每個都設計成跟 AI agent 搭配）中的一套，把點子到腳本整條流程收進一個跑在你電腦上的本機網頁，而不是留在對話視窗裡。

這個節點把 RUBRIC Scripts 跑通一次：先把候選點子（上週 `/outliers`、`/latest` 的 shortlist）餵給 `/rubricscripts`，讓 agent 用你的 `/hooks` 與 `/tone` 生出 3 個 hook 與腳本；再用「畫重點、留言」的回饋迴路，一則指令改好全部腳本，並用 Teach my `/tone` 把同一批意見沉澱進你的 tone skill，讓下一批稿子更像你自己；最後把腳本送上一頁提詞機稿，一次錄完整批。整個迴圈的價值在於它會複利——你越修 `/tone` 與 hook 品味，RUBRIC Scripts 產出的稿子就越準，這正是 Content Pyramid 從「量大」走向「品質」的那一段。
