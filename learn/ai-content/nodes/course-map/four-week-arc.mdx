# 四週弧線：Identity → Ideation → Creation → Distribution

<LearningGoal>
記住四週的主題順序與每週會做出的里程碑，知道每週的產出如何餵給下一週。
</LearningGoal>

## Lesson

課程把 30 天切成四個每週模組，順序是 Identity → Ideation → Creation → Distribution（定位 → 發想 → 製作 → 發布）；每週各有一個要分享到社群的里程碑，而且前一週的產出就是後一週的輸入。
