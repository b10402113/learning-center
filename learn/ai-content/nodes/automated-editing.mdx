# Automated Editing：RUBRIC Editor＋/cut

## Learning goal

先手剪一輪，再用 RUBRIC Editor 跑「評論→修正→輸出」的強化學習迴路，輸出核准的成品剪輯（`/animate` 為選配）。

## Steps

1. [[learn/ai-content/nodes/automated-editing/edit-by-hand-first|先手剪一輪：自動化前先自己剪幾支]] — 為什麼要先手剪一兩支，累積判斷力、順便暖帳號
2. [[learn/ai-content/nodes/automated-editing/setup-rubric-editor|安裝 RUBRIC Editor 與 /cut：本地跑、瀏覽器開]] — 裝好 RUBRIC Editor 與它內建的 /cut（after step 1）
3. [[learn/ai-content/nodes/automated-editing/how-cut-works|/cut 怎麼運作：逐字時間戳與 last clean take]] — 看懂 /cut 怎麼決定留哪段、會挑哪個轉錄服務（after step 2）
4. [[learn/ai-content/nodes/automated-editing/review-and-teach-loop|審片與教 /cut：評論→修正的強化學習迴路]] — 在 RUBRIC Editor 修剪、切分、留言，並訓練 /cut（after step 3）
5. [[learn/ai-content/nodes/automated-editing/render-and-export|輸出成品：Render 與 1080p 匯出]] — 把核准的 cut 算圖並匯出成品（after step 4）
6. [[learn/ai-content/nodes/automated-editing/own-editor-and-animate|用自己的剪輯軟體，與選配的 /animate]] — 接上自己的剪輯軟體，並知道 /animate 是之後的選配（after step 4）

## Lesson

剪片是 Wk3 製作階段的最後一哩：腳本有了、也錄了一支乾淨的 take，接下來要把它變成可以發布的短片。這個節點的核心主張是——**先把剪輯交到 agent 手上之前，自己親手剪一兩支**。理由不是要你變成剪接師，而是給自己一雙能判斷的眼睛：只有摸過剪點、感受過節奏，你才有能力一眼看出 agent 剪錯的地方。順帶的好處是，用平台自己的編輯器或 CapCut 剪這幾支，也等於在暖你的帳號。

第二個主張是把剪輯重新定義成一個**迴路**，而不是一次性的動作。你把原始錄影（一支十幾分鐘、對著提詞機唸的長 take）交給 `/cut`，它在背後幫影片做逐字轉錄、替每個字打上時間戳，於是它能判斷哪一段要留、哪一段是 NG 重來——預設規則是留下每個句子的「最後一次乾淨 take」。接著成品進到 RUBRIC Editor，你在那裡修剪、切分、把被誤刪的段落救回來、逐段留言；把「Teach my /cut」打開，這些留言就成了訓練資料，讓下一次的剪輯更接近你想要的樣子。課程把這個「評論→修正→再輸出」的循環直接叫做強化學習（reinforcement learning）——你在 RUBRIC Editor 裡做的，就是它的迷你版。

六步會沿著這條流程走：先手剪一輪 → 裝好 RUBRIC Editor 與 `/cut` → 搞懂 `/cut` 的運作與轉錄服務的取捨 → 在 RUBRIC Editor 跑審片與教學迴路 → 把核准的成品算圖、以 1080p 匯出 → 最後知道你可以改用自己熟悉的剪輯軟體（透過 MCP connector 接上 Premiere、DaVinci 或 Final Cut），以及 `/animate` 是之後再回來學的選配。走完之後，你手上會有一支被自己核准過的成品剪輯，而不只是看懂了自動剪輯這回事。
