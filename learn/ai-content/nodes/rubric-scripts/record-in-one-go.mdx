<LearningGoal>
把完成的腳本送上 Telegram、電腦或提詞機，用一頁長稿一次錄完整批，之後再交給 agent 剪開。
</LearningGoal>

## Lesson

三條路任選一條把定稿送上你唸得到的地方——手機用 Telegram、電腦開一頁閱讀頁、想更順用提詞機；真正省時的是批次錄：把整批腳本放上一頁長稿、一次連續錄完，之後再讓 agent 剪開成一支支影片。
