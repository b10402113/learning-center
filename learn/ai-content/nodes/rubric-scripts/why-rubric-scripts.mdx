<LearningGoal>
說出 RUBRIC Scripts 存在的理由——把腳本從對話框集中到一個地方、與 agent 搭配運作，並讓你的 `/hooks` 與 `/tone` 越用越強。
</LearningGoal>

## Lesson

RUBRIC Scripts 存在的理由不是替你生稿，而是把「生稿之後」的整理、比較與優化集中到一個跑在自己電腦上的本機工作台；它用 skill 驅動、以 agent 當引擎，你留下的回饋會同時改稿也回饋進 `/tone`，形成越用越準的複利。
