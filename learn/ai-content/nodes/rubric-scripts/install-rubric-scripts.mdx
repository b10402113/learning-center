<LearningGoal>
取得 RUBRIC Scripts 的 zip 與安裝指令交給 agent 裝好，在本機 localhost 開起來，並確認它會讀你的 `/hooks` 與 `/tone`。
</LearningGoal>

## Lesson

安裝只有四步：到 RUBRIC course（Micro Apps）下載 zip 並複製安裝指令，把整段指令交給 agent 讓它照 README 裝好，點開它給的 localhost 連結（代表軟體跑在你自己的電腦上），最後確認它已讀到你的 `/hooks` 與 `/tone`；裝好後會自帶 `/rubricscripts` skill，頁面上的影片與平台區塊是 Wk4 的事。
