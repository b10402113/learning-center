# 端到端：點子 → /hooks＋/tone → 可照讀的稿

<LearningGoal>
能拿一個點子走完 `/hooks` 出 3 個 hook 選項、`/tone` 定稿，自己套行業品味與真實成果（絕不捏造），產出一份可以照著念的腳本。
</LearningGoal>

## Lesson

拿一個點子貼上課程那段 Instagram 短影片 prompt，讓 agent 一次問一個問題（哪個點子、給誰看、你有什麼真實成果、絕不編造），用 `/hooks` 寫出 3 個 hook 供你選、用 `/tone` 寫出短到能照念的整段腳本，再唸一遍砍掉你會卡住的字，並把還像 AI 的模式加進 `/tone`。
