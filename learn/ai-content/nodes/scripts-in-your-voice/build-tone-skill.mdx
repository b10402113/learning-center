# 用一句指令建出你的 /tone

<LearningGoal>
能跑「依你既有的對話建立一個 tone of voice skill」這道指令（或接受 agent 訪談），產出一份記住你用詞、句長、開場收尾、玩笑怪癖與「從不說的東西」的 `/tone`。
</LearningGoal>

## Lesson

把課程那段完整 prompt 貼給 agent，它會先讀它手上關於你的一切、再一個問題一個問題訪談你，最後把你的用詞、句長、開場收尾、玩笑怪癖與「從不說的東西」存成一份 `/tone`；素材不足時 prompt 會自動改成訪談模式，先建一個初版再慢慢修。
