# 用創作者字幕 bootstrap 你的聲音

<LearningGoal>
能用 YouTube 字幕或 yt-dlp 抓一位（或混合兩位）創作者近期影片的逐字稿，請 agent 學其風格當靈感、不照抄，替自己補出一份初版 `/tone`。
</LearningGoal>

## Lesson

用 YouTube 的 Show transcript 按鈕或免費開源的 yt-dlp 拿到一位（或混合兩位）創作者近期影片的逐字稿，把課程那段 prompt 貼給 agent，讓它研究對方怎麼開場、解釋、收尾並寫成幾條可讀的風格規則，經你逐條確認後當成「可以靠攏的風格」加進 `/tone`——學的是風格，不是抄句子。
