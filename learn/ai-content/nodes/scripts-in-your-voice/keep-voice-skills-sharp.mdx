# 每次 session 都讓 skill 更像你

<LearningGoal>
能請 agent 依這次 session 的回饋更新 `/hooks` 與 `/tone`，逐項檢視它列出的改動決定留哪些，並知道之後可用 RUBRIC Scripts 集中管理腳本、送進提詞機。
</LearningGoal>

## Lesson

下載來的 skill 只是 baseline：每次 session 結束時貼上課程那段更新 prompt，讓 agent 回顧你這次提過的每個要求、逐條歸類到 `/hooks` 或 `/tone` 並寫成白話規則，由你逐項把關只留普遍成立的做法；之後腳本變多，可用 RUBRIC Scripts 集中管理、送進提詞機、一口氣錄完短影片。
