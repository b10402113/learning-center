# Finding Outliers 與 /inspo

## Learning goal

用「相對倍數」找出已被市場證明有效的題材，設定 `/outliers`，並把參考存進 `/inspo` 靈感牆。

## Steps

1. [[learn/ai-content/nodes/finding-outliers/what-an-outlier-is|什麼是 Outlier：相對倍數，不是絕對數字]] — 破解「爆款要有百萬觀看」的迷思，改用「這篇有沒有打敗這個帳號的平常水準」來看題材
2. [[learn/ai-content/nodes/finding-outliers/the-outlier-score|Outlier Score 怎麼算：倍數、vidIQ 與 /outliers]] — 看懂倍數的算法，並比較現成工具與免費 DIY 兩種找法（after step 1）
3. [[learn/ai-content/nodes/finding-outliers/setup-and-run-outliers|設定並跑 /outliers：YouTube API key、掃描、結果頁]] — 完成一次性設定、跑出你利基的爆款清單並讀懂結果頁（after step 2）
4. [[learn/ai-content/nodes/finding-outliers/pick-copyable-outliers|挑出能複製的爆款：看模式，不看單支影片]] — 選出你這週講得出來、又能複製的主題，照抄或加上自己的角度（after step 3）
5. [[learn/ai-content/nodes/finding-outliers/save-with-inspo|存進 /inspo 靈感牆：一鍵收藏與之後取用]] — 把值得研究的爆款存進自己的靈感牆，之後請 agent 依主題取用（after step 4）

## Lesson

上一課的 `/latest` 回答的是「**現在大家都在聊什麼**」，這一課的 outliers 回答的是「**什麼題材真的有效**」。這兩個是發想階段最可靠的兩種點子來源——一個給你新鮮度，一個給你已被市場驗證過的證明。關鍵是換一個衡量方式：不再問「這支影片有幾萬觀看」，而是問「它比這個帳號平常的水準高出幾倍」。一篇 33,000 觀看、但這個頻道平常只有 4,000 的影片，是將近 8 倍的異常；反過來，百萬觀看如果本來就是這個帳號的日常，那它一點也不異常。用「相對倍數」看，小創作者才找得到自己真的追得上的題材。

五步走完，你手上會有一套可重複的流程：先理解 outlier 是相對倍數，再看懂這個倍數怎麼算、有哪些工具能算，然後真的把 `/outliers` 裝起來、跑出自己利基的爆款清單，用判斷力挑出能複製又能講的那幾支，最後用 `/inspo` 把它們收進你自己的靈感牆。重點不在工具，而在那個判斷：看的是「跨帳號重複出現的模式」，不是單一支爆紅影片本身。
