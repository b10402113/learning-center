# 1,000 真粉的算式：把 $100k/年拆開

<LearningGoal>
算得出「1,000 個真粉各付約 $100/年 ≈ $100k/年（≈ $8/月／人）」這筆帳，並說出同一套算式如何套在 $10/月的軟體產品（$10k MRR）與生意品牌上。
</LearningGoal>

## Lesson

1,000 個真粉各付約 $100/年就是約 $100,000/年（平均每人每月約 $8），把同一套算式換成每月 $10 的軟體產品，1,000 人就是 $10,000 MRR，全靠自然流量，個人品牌與生意品牌都適用。
