# 不必先追十萬：追蹤數不是終點

<LearningGoal>
拆掉「做內容事業得先有十萬追蹤」這個迷思，並理解為什麼這門課要先更新你對內容的「firmware」。
</LearningGoal>

## Lesson

「先有十萬追蹤才有內容事業」是一個沒被驗證過的預設，不是門檻；動手做內容之前得先更新底層 firmware——追蹤數是手段不是終點，真正的終點是一群願意為你的價值付費的人。
