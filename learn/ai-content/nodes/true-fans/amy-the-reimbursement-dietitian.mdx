# 案例：6,000 粉的營養師如何做近 $1M

<LearningGoal>
用營養師 Amy 的案例說明「窄題目＋低追蹤＋高收入」怎麼發生，並指出她做對的關鍵動作（找到痛點、內容鎖定同業、用證照提供服務）。
</LearningGoal>

## Lesson

營養師 Amy 用不到一萬的追蹤做到接近 $1M 年收，關鍵不是爆量而是窄而深：選一個同業真實的痛點（保險給付）、把內容只做給這群人看、用專業憑證建立信任，最後把同一群人變成付費服務的客戶。
