# MrBeast 測試：娛樂與教育的價值差

<LearningGoal>

</LearningGoal>

## Lesson

用 MrBeast 測試可證明觀眾對娛樂只肯付很低的價，卻願意為教育——也就是換到一項技能——付出上千美元的高價。
