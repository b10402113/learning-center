# MEMORY — ai-content

## Goal

照講師的節奏，把整門 **AI Content Accelerator Program**（robonuggets，4 週 46 課）從頭走到尾，不重排、不跳段：Wk1 內容定位 → Wk2 內容發想 → Wk3 內容製作 → Wk4 內容發布。每週照課程示範操作、做出該週里程碑（Wk1 宣告內容定位、Wk2 發一篇、Wk3 再發 5 篇並逐步改進、Wk4 跨平台發布 ≥15 篇）。終點是能在自己的題目上，端到端跑完一次「Content OS」流程——選定位、用 AI 找點子、用自己的聲音寫稿與錄影、排程跨平台發布——而不只是讀懂這套策略。

## Why

以**初學者**身分，跟著一位已被驗證的創作者（RoboNuggets / Jay）的節奏，把「一個人＋一群 agent 做內容」從口號變成可複製的流程。延續自己長期的主線「一人當一個團隊」：把內容這一半也從「不會做」補到「能自己操作、能重複」。課程本身的定位是「內容驅動事業（content that drives a business）」——用內容累積信任、帶回客戶與機會。

## Prior experience

- **內容經營方面是初學者**：沒有社群成長、發文節奏、內容定位的實務經驗——這正是本主題要補的斷層。
- **工具與技術底強**：重度使用 Claude Code / opencode，寫過 skill／slash command；能跑 Node / Python；做過 AI 產內容的流程（`ai-html`、`video-editing`、`cliff-note`）。所以安裝、跑 script、看懂 agent skill 這類操作不吃力，卡點會在「內容策略與判斷」，不在工具。
- 已有 / 未有個人帳號、目前追蹤數——未說明（之後若用到再定）。

## Anchors

- 課程的三大框架：**Content Trifecta**（useful + enjoyed + unique）、**Content Pyramid**（volume → improve → quality）、**1,000 true fans**／interest media／educate over entertain。
- 自己想做內容的題目與對象（Wk1 要用：想講什麼、講給誰聽）——尚未指名，之後在 Wk1 定。
- 既有 AI 內容產線（`ai-html` 素材轉影片、`video-editing` 個人品牌／開發者內容、`cliff-note` 旁白動畫）——發布管道與素材可直接接上。
- Claude skills 生態：`/latest`（本週熱點→點子）、`/outliers`（爆款相對倍數）、`/inspo`（靈感牆）、RUBRIC Scripts / Editor、`/post`（排程發布）——與自己既有的 agent skill 習慣直接對照。
- Mac（darwin）環境；YouTube Data API key、Blotato 等為課程會用到的外部服務。

## Habits & constraints

- 每週約 1–3 小時，時間零碎、不固定；長段落在週末或晚間。
- 無硬性 deadline，中等壓力；每課要能一次讀完、可隨時中斷再續。
- 成本敏感：課程工具多為免費／本地，但 `/outliers` 需免費的 YouTube API key，`/post` 走 Blotato（付費）、部分社群平台資料源需付費 key——優先免費路徑，必要時才付費。
- 環境：Mac；能跑 Node.js 18+ / Python 3.12+。

## Knowledge type

mixed，**procedural 為主**。核心是「照講師節奏真的做出來、真的發文」——宣告定位、跑一次點子研究、寫稿錄影、設定排程。declarative 那層（1,000 true fans、interest media、內容驅動事業、Hook 是什麼、為什麼要暖帳號）是支撐判斷力的背景，要在操作的脈絡裡講，不空談理論。

## How to teach me

- **完全 follow 講師的章節順序與節奏**——不重排、不合併、不自行跳段；講師先講什麼就先講什麼。
- **當初學者帶**：不預設任何內容經營的先備知識；新名詞（hook、outlier、AEO、暖帳號…）出現時先用一句話講清楚它是什麼、拿來幹嘛，再進核心。
- 每課開頭先用**「這一步在整條流程的哪裡、為什麼存在、要吃什麼、產出什麼」**帶出價值，再示範操作。
- 工具操作（安裝 skill、跑 `/latest`、設定 Blotato）可略讀，因為技術底強；**內容策略與判斷（怎麼定位、怎麼挑點子、怎麼寫得像自己）要深教**。
- 每課收在一個「**做得出、看得到**」的結果：一篇貼文、一份定位宣言、一組候選點子、一支腳本、一個排程設定。
- 簡潔、密度高、不要廢話；碎片化可讀。
- 用課程的框架（Content Trifecta / Content Pyramid / 四週迴圈）當記憶錨點，把後面的課掛回前面。
- 輸出語言 **zh-Hant**；工具名、指令、skill 名稱（`/latest`、RUBRIC、Blotato…）保持英文。
