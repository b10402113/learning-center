# ROADMAP — ai-content

## Goal

照講師的節奏，把整門 **AI Content Accelerator Program**（robonuggets，4 週 46 課）從頭走到尾，不重排、不跳段：Wk1 內容定位 → Wk2 內容發想 → Wk3 內容製作 → Wk4 內容發布。每週照課程示範操作、做出該週里程碑（Wk1 宣告內容定位、Wk2 發一篇、Wk3 再發 5 篇並逐步改進、Wk4 跨平台發布 ≥15 篇）。終點是能在自己的題目上，端到端跑完一次「Content OS」流程——選定位、用 AI 找點子、用自己的聲音寫稿與錄影、排程跨平台發布——而不只是讀懂這套策略。

## Learning path

**Course-native（講師原序 / concept-first）**——完全照課程的 4 週弧線與模組順序走，先建立「內容作為一門事業」的心智模型（Wk1 Identity），再依序補上發想規則（Wk2 Ideation）、製作機制（Wk3 Creation）、發布與系統整合（Wk4 Distribution）。

- **角度**：把講師的章節順序當成唯一的排序骨架；同一週內的模組按編號依序排，不重排、不合併不同目標的課。
- **最佳化**：忠實貼合 MEMORY「follow 講師的順序與節奏」的約束；每週先給判斷力（為什麼），再給操作（怎麼做），最後收在一個做得到的里程碑。
- **適合**：想一次把整套 Content OS 內化、之後能自行重複流程的初學者（本課程的學習者）。

Tiers：Tier 1 建立心智模型（Wk1）→ Tier 2 操作規則（Wk2）→ Tier 3 製作機制（Wk3）→ Tier 4 發布與系統整合（Wk4）。

## How to use

Read the nodes in order. Each node is a step-DAG. Run `/probe <subject>/<node-id>` to measure a node, then `/nodes <subject>/<node-id>` to confirm and start work on it.
