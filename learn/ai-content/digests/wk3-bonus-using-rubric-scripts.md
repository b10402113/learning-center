# Digest — 🎁 Bonus: Using RUBRIC Scripts

## Overview (L1)

- A short (~two-and-a-half-minute) walkthrough of **RUBRIC Scripts** that shows the whole flow from your ideas to a script you can read off a teleprompter.
- Its through-line: RUBRIC Scripts is one page for all your scripts so you don't dig through old chats; you install it, run `/rubric scripts`, load your shortlist, and your agent writes scripts with 3 hook options in your own voice.
- Teaches the review mechanic: each script lands with its hook highlighted; you highlight any text and comment like in a Google Doc, then copy the comments and send them back to your agent.
- Teaches two outcomes of sending comments: the agent rewrites the scripts from your comments, and (with Teach my Tone switched on) it refines your `/tone` skill so future scripts sound more like you.
- Gives tips: be specific in comments, and read every script out loud before recording — if you stumble on a line, that's the line to fix.
- Learner outcome: know how to drive RUBRIC Scripts end to end and get a script to wherever you read it while recording.

### commenting-and-rewriting

- Locator: `[[sources/ai-content/20261015/4-Wk3 - Content Creation/9-🎁 Bonus- Using RUBRIC Scripts/9-🎁_Bonus-_Using_RUBRIC_Scripts.en.vtt#commenting-and-rewriting]]`
- Summary: How to leave feedback and get scripts fixed, then sent to where you read them.
