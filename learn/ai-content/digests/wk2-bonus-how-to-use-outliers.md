# Digest — 🎁 Bonus: How to use /outliers

## Overview (L1)

- A short walkthrough of the `/outliers` skill, from setup to your first outliers.
- Through-line: an outlier doesn't need millions of views—if a channel usually gets 4,000 and one video gets 33,000, that's 8x normal, so the topic clearly worked.
- Teaches that under the hood it is just math: each post's views divided by that account's usual views, across YouTube, TikTok, X and other platforms.
- Covers setup (download the zip, paste the install prompt, then turn on the free YouTube data API and create a key) and reading the results page with thumbnails and multipliers.
- Shows the workflow: add the outliers that resonate and that you can talk about this week to your cart, turn them into scripts in your own voice, and refine the skill to learn your taste.
- Learner outcome: set up `/outliers`, pull your niche's outliers, and start recording because volume is the game.
