# Digest — Module 14 - Welcome to Creation

## Overview (L1)

- Welcome module for Week 3, where the course moves from content identity and idea sourcing into actually making content.
- Recaps that prior weeks covered content identity, updating how to think about content, and automating idea sourcing; this week is practice: making the content itself.
- Because it is RoboNuggets, the AI agent is used to automate and assist many of the creation steps.
- Milestone framing: produce five content pieces by the end of the week, improving each one using the tools introduced in the modules.
- Roadmap for the week: say it well (hooks, scripting, captions), make it (camera/setup, automated editing), and set up to grow (account choice, reputation, trust, warming up accounts).
