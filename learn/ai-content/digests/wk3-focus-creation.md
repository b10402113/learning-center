# Digest — 🔳 This Week's Focus: Creation

## Overview (L1)

- Week 3 kickoff: turn the ideas gathered in earlier weeks into actual content, with the learner's AI agent doing much of the work.
- The week splits into three moves: "say it well" (hooks, scripts in your voice, captions), "make it" (content OS, RUBRIC Scripts, camera/setup, RUBRIC Editor editing), and "set up to grow" (trust and truth, choosing an account and warming it up).
- Names the tools used this week: RUBRIC Scripts (ideas into scripts) and RUBRIC Editor (automated editing), after setting up the camera.
- Learner outcome: post 5 more content pieces by the end of Week 3, each one a bit better than the last.
