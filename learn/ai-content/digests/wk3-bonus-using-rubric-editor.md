# Digest — 🎁 Bonus: Using RUBRIC Editor

## Overview (L1)

- A short (~two-minute) walkthrough of **RUBRIC Editor**, from your raw recording to clips your agent cuts and renders.
- Its through-line: this is the hands-on companion to Module 22, showing how to set up the app and do the manual editing moves that feed the automated-editing loop.
- Teaches setup with the zip and the install prompt (the app itself is on RUBRIC Editor in the RUBRIC course).
- Teaches the core editing gestures: trim, split a clip with **C**, and bring back a cut with the **+** marker.
- Teaches that the "Teach my /cut" switch makes every cut need fewer fixes — the improvement loop.
- Learner outcome: be able to open RUBRIC Editor from a raw recording and make the basic edits the /cut review loop depends on.
- This lesson has no transcript; the digest is grounded in the written lesson page only.
