# Digest — Module 17 - Captions

## Overview (L1)

- Captions are no longer the main driver of views/reach, but every post still carries one, and they help people find you.
- Captions matter most for photos or carousels (pure text input); for video, platforms already transcribe what you say.
- Social platforms are becoming search engines (YouTube is the world's #2 search engine after Google), and AI answers now top Google results, so write captions for AEO (answer engine optimization).
- Practical tactics: name the specific tool instead of repeating the vague hook, make lines that stand alone, add a "Questions we answered" section, and keep hashtags to a few relevant ones.
- The creator mostly automates captions; later RUBRIC Scripts writes a caption with every script. The hook + content remain the real "meat".

### name-the-tool
- Locator: `[[sources/ai-content/20261015/4-Wk3 - Content Creation/5-Module 17 - Captions/5-Module_17_-_Captions.en.vtt#name-the-tool]]`
- Summary: Don't just repeat the hook (which maximizes curiosity by staying vague); in the caption, name exactly what you're talking about, e.g. "Claude Code".
- Key claims: caption should say exactly what the topic/tool is so search and AI answers can match it; clear naming beats vagueness for discoverability.
- Learner-relevant: a concrete, high-value caption rule.

### questions-we-answered

- Summary: Add a simple "Questions we answered" section to the caption; it appears below the fold (after "read more"), so most people won't see it.
- Key claims: this metadata attributes the questions the post answered, useful now and increasingly important as AI search grows.
- Learner-relevant: an easy AEO win that doesn't clutter the visible caption.

### hashtags
