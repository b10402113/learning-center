# Digest — 🎁 Bonus: How to use /latest

## Overview (L1)

- A short walkthrough of the `/latest` skill, positioned as a way to get fresh content ideas without scrolling all day.
- Through-line: `/latest` checks what's new in your niche from the last seven days and turns it into up to 10 ranked content ideas, with both the window and count as changeable defaults.
- Teaches where the skill reads from: Reddit, X, YouTube, GitHub and the web, plus your own go-to sources (which matter most), and that it only keeps ideas with a real link.
- Covers setup (download the zip, paste the install prompt, answer questions about your niche—or ask Claude to suggest topics if you don't have a niche yet).
- Shows the workflow: search/filter the results page, add liked ideas to a cart, then turn them into a script in your own tone of voice, or refine the skill to learn your taste.
- Learner outcome: install `/latest`, run it for a niche, and actually post about an idea because volume is the game.

### setup

- Summary: Walks through installing and configuring the skill.
- Key claims: Setup takes about five minutes—download the zip from the classroom page, paste the install prompt into Claude or your agent, and answer a few questions about your niche; if you don't have a niche yet, ask Claude to suggest things you can talk about based on what it knows about you; then type `/latest` or add your niche after it.
- Learner-relevant: Removes the setup barrier and shows a way to start even without a defined niche.

### search-filter-and-cart

- Locator: `[[sources/ai-content/20261015/3-Wk2 - Content Ideation/6-🎁 Bonus- How to use -latest/6-🎁_Bonus-_How_to_use_-latest.en.vtt#search-filter-and-cart]]`

### turn-ideas-into-scripts-and-taste
