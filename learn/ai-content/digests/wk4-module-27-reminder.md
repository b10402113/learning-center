# Digest — Module 27 - Reminder

## Overview (L1)

- A short reminder module: before handing posting to a scheduler, make sure the account is **warmed up**.
- Core warning: a brand-new account that only posts through software doesn't look like a person using the app.
- Warm-up guidance: use a new account like a person first — log in, post, watch, like, and comment in your niche.
- Decision rule: brand new → post by hand this week and connect later; had it a while → connect it now.
- Start-small tip: when connecting an account, schedule one post first and confirm it goes live before scheduling the rest.
- Cites Blotato's own advice: use a new account normally for a few weeks before connecting it.
