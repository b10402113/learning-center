# 智能體設計空間 (Agentic Design Space)

## Problem Statement

很多人第一次聽到 AI agent，會以為這是 2023 年憑空長出來的新物種——LLM 一出手，agent 就誕生了。這個印象有個實際後果：你會把所有設計智慧都押在 prompt 和模型上，遇到問題就想換模型、改提示，卻看不見前人已經把「自主軟體」的坑踩了幾十年。老王說句實話：把歷史砍掉，你就得把歷史重學一遍。

## Why it matters

知道設計空間早於 LLM，你才會把 LLM 放對位置——它是空間裡新加入的一種「決策引擎」，讓一個 agent 能推理的題材突然變寬；但它不是空間的起點，也不取代空間裡其他位置的用法。混合式設計（LLM 處理模糊、規則處硬邊界）之所以顯得自然，正是因為它們本來就是空間裡並存的鄰居。

## How it works

**智能體設計空間（agentic design space）**指「會感知、決策、行動的自主軟體」的全部設計可能。書中點名的幾個地標：

- **規則式系統（rule-based）**：行為寫死在規則裡，可預測、可審計，但遇新狀況即失效。
- **符號系統（symbolic）**：以符號與邏輯推理表達世界，擅長明確定義的領域。
- **BDI（Belief-Desire-Intention）**：信念-願望-意圖架構，把「心智狀態」明確建模成三層，讓 agent 在變動環境裡權衡與承諾。
- **強化學習（RL）**：從環境回饋學策略，決策藏在學出來的參數裡。
- **神經符號（neuro-symbolic）**：神經網路的感知能力 + 符號系統的推理嚴謹性，兩者拼接。

然後 LLM 進場。它帶來的改變是**擴展了單一智能體所能推理的範圍**：自然語言目標、沒預先定義的題材、跨領域的常識，現在都在一個 agent 的推理半徑內。注意措辭——是「擴展範圍」，不是「發明類別」。天文學沒有望遠鏡也是天文學；agent 沒有 LLM 也是 agent。

## In plain terms

一條老街，LLM 是後來才開的那家大商場。商場確實什麼都賣，但街道本身——雜貨店（規則式）、當鋪（符號）、武館（BDI）——都開了幾十年了。商場開了之後，很多人專程只逛商場；但真要修一把老鑰匙，你還是得去那家老鎖匠。

## Practical use

設計任何 agent 時，先問：「這個決策點需要 LLM 嗎？」低風險、定義清楚的分支交給規則；模糊、需要語義理解的才交給模型。這就是設計空間的日常用法——你不是在「用 LLM」與「不用 LLM」之間二選一，而是在一條本來就很多座位的老街上，替每個決策點挑位子。

## Questions

### Q1. 為什麼把 LLM 稱為 agent 定義的必要條件是個時代錯置？
A1. 因為規則式、符號、BDI、強化學習、神經符號系統都在 LLM 之前就構成了 agent 的設計空間；LLM 是後來擴展推理範圍的新成員，不是類別的發明者。

### Q2. 關係題：BDI 與 SPAL 迴圈是什麼關係？
A2. 兩者都是自主系統的循環式心智模型：BDI 以信念-願望-意圖建模決策，SPAL 以感知-規劃-行動-學習描述迴圈；書中將 SPAL 視為與 BDI、OODA 同族的模式，LLM 的推理是新加入的 plan 引擎。

### Q3. 價值判斷題：安全關鍵系統裡，LLM 應該佔決策的多大比例？
A3. 書中立場是保守的：安全關鍵或受監管任務永遠要在模型推理之上疊加結構化約束。LLM 適合承擔模糊理解的部份，硬邊界交給規則與人類核准——比例不是重點，層次才是。
