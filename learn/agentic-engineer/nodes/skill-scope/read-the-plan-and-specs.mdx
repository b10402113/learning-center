<LearningGoal>
讀懂 /scope 產出的 plan 與後續的 spec：分清楚 build 讀的 index 與你留著讀的 rationale、看懂每個 Status 的意義，以及認得 Assumed 與 Superseded 兩種狀態。
</LearningGoal>

## Lesson

spec 是 `docs/specs/` 底下的 markdown：`index.md` 是 build 讀的決定、`rationale.md` 是你留著讀的論證；Status 分綁功能與獨立決定兩套生命週期，另有 Assumed（欠著的決定）與 Superseded（被換掉而非改寫）兩種狀態。
