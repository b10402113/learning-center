## Lesson

`/scope` 用一句話或 brain dump 起頭，判斷專案種類後以分批決策面板追問推不出來的部分，最後把結果寫成 `docs/scope/scope.md`（slim index＋分階段計畫），並依情境分成 plan／replan／add 三種模式。
