# Setup Design System and UI Foundation

## Lesson

「我想要好看一點」先被 architect 面談逼成一份 design spec：近黑表面、一個暖琥珀重點色、一款幾何無襯線、只做深色主題。覺得太樸素時，做法是把 UI kit 截圖丟回去重新 architect，而不是在畫面上補丁；那個 session 是 compact 而不是 clear，因為前一份 spec 還要用。
