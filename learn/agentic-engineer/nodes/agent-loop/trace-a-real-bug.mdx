<LearningGoal>
在一個登入按鈕沒反應的真實小 bug 上，逐階段認出 Read、Decide、Act、Observe，並說出那個 bug 為什麼會安靜地壞掉。
</LearningGoal>

## Lesson

在登入按鈕沒反應的 demo 上，Read 是 grep 找 login、開元件，Decide 是決定去查 handler 呼叫了什麼，Act 是真的開檔（一次 tool call）並用 bash 跑型別檢查與 build，Observe 是發現 handler 呼叫的函式已被改名；這個 bug 之所以安靜地壞掉，是因為查表 miss 後用 optional chaining 呼叫 undefined，且這種寫法躲得過 TypeScript。
