能說出每個 coding agent 共用的 Read→Decide→Act→Observe 迴圈，並解釋為什麼這一圈是它所有行為的原子單位。
</LearningGoal>

## Lesson

不論哪一套工具，每個 coding agent 都跑同一個 Read→Decide→Act→Observe 迴圈，反覆到任務完成；這一圈是它所有行為的原子單位（五分鐘任務約八圈、複雜功能約八十圈），也是架構師真正要指揮的對象。
