<LearningGoal>
判斷卡住 session 的 context 該留（compact）還是該丟（clear），並說出兩種判斷顛倒的代價。
</LearningGoal>

## Lesson

卡住 session 的 context 要先判斷是資產（有生產力、只差空間 → compact）還是負債（充滿失敗嘗試與重複假設 → clear）；兩種搞反的代價都很高，尤其 compact 負債會把壓縮過的錯誤帶進下一步，反而更難看穿。
