<LearningGoal>
能判斷卡住 session 的 context 是值得 compact 的資產還是該 clear 的負債，並說出判斷顛倒的兩種代價。
</LearningGoal>

## Lesson

卡住的 session 只有一個關鍵判斷：這個 context 值不值得留。有生產力、只是快滿了，它是資產，用 compact；塞滿失敗嘗試與重複假設，它是負債，用 clear。用「新 session 需要我重講哪幾件事」來判別；清掉資產會丟掉已收集的證據，壓縮負債會把錯誤推理打包帶走、而且更難看穿。
