<LearningGoal>
能認出四種 AI 寫碼的反覆失敗模式與各自的破綻，並用「bug 幾乎不在出錯的那一行」把調查往前推。
</LearningGoal>

## Lesson

四種模式：發明出來的函式、看似合理但邏輯錯、檔案中途做的決定、沒被考慮到的邊界，各自的難度與第一個檢查都不同。共同破綻是 bug 幾乎不在出錯的那一行，而在更早、沒有人寫下來的某個決定，所以調查要多問一句「這件事有沒有被決定過」。
