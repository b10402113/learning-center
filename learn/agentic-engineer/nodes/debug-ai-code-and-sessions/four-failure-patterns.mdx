認出 invented function、plausible but wrong logic、mid-file decision、unconsidered edge case 四種失敗模式，並記住 bug 幾乎不在出錯的那一行。
</LearningGoal>

## Lesson

四種 AI 失敗模式分別是發明函式、貌似合理的錯誤邏輯、檔案中途做出的決定、沒被考慮到的邊界情況；它們共用的破綻是——bug 幾乎不在出錯的那一行，而在更早、某個沒被寫下來的決定。
