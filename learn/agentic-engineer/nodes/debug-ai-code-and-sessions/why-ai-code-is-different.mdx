<LearningGoal>
說出除錯 AI 寫的碼與除錯自己寫的碼差在哪，並用「把它當陌生人寫的」避免對著自己猜的意圖除錯。
</LearningGoal>

## Lesson

除錯 AI 寫的碼之所以特別難，是因為你少了那份默默做掉一半工作的作者記憶；所以第一招是把它當陌生人寫的，把「這行大概想幹嘛」降級成待證明的假設。
