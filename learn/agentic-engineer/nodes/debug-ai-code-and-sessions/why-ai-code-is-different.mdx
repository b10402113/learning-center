<LearningGoal>
能說明除錯 AI 寫的碼時少了「作者記憶」這項隱形資源，並用「當陌生人寫的」讀法避免對著自己猜測的意圖除錯。
</LearningGoal>

## Lesson

除錯自己的碼時，作者記憶默默做掉一半工作；AI 寫的碼沒有這份記憶，看著它生成也補不回來，因為你看到的是輸出、不是推理。把碼當陌生人寫的讀，是為了阻止你把「這行大概想幹嘛」當前提，然後對著自己的猜測除錯；意圖要另外從 spec、周邊程式與執行行為收集。
