<LearningGoal>
能用 spec 驗收條件、周邊程式慣例與實際執行行為三處還原一段陌生碼的意圖，並在沒有 spec 時判斷這是「從沒做過的決定」而非 bug。
</LearningGoal>

## Lesson

用 spec 的驗收條件、周邊程式的慣例、實際執行的行為三處交叉，寫成一句可推翻的意圖假設，再動手修改。三處都給不出答案時，你面對的不是 bug，而是一個從沒被做過的決定——那屬於 `/architect`，不屬於 `/debug`。
