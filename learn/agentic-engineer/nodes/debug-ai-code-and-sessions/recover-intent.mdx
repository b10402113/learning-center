<LearningGoal>
從 spec 驗收條件、周邊程式與執行行為還原 AI 碼的意圖，並在沒有 spec 時判斷這是「沒做過的決定」而非 bug。
</LearningGoal>

## Lesson

意圖要從 spec 的驗收條件、周邊程式的慣例與實際執行行為三處還原，把調查變成一場「承諾 vs 實際」的比較；三處都沒有時，你找到的不是 bug，而是一個從沒被做過的決定，那屬於 /architect 而不是 /debug。
