<LearningGoal>
能照順序執行五步升級救回卡住的 session，並用事前計畫與三種結局判斷現在該 steer、reset 還是回頭重想。
</LearningGoal>

## Lesson

五步升級照順序走：按 `Esc` 停下來（不是 `Ctrl+C`）、問它相信什麼、把任務縮小並加上硬邊界、用 Git 退回已知良好狀態、最後清掉 context 但帶著精確錯誤與失敗測試進新 session。事前預防是讓它先計畫、不要編輯；每個卡住的 session 只會有三種結局——steer out、reset to good、rethink，計畫錯了就回 `/architect` 或 `/scope`。
