## Lesson

救回 session 的五步是 stop、問它相信什麼、給更少的任務、rollback、clear 並帶證據，事前用「先計畫再編輯」預防；而每個 session 最後只會走向導回正軌、重置回好的狀態，或認清計畫本身錯了這三種結局。
