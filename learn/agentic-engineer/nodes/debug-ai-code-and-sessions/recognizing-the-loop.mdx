<LearningGoal>
能用「重複而沒有進展」認出 agent 卡在迴圈，並說出為什麼這種情況加指示只會更糟。
</LearningGoal>

## Lesson

迴圈的訊號是重複而沒有進展：同一個函式反覆重寫、同樣的檔案反覆打開、diff 越來越亂、跟自己先前的決定矛盾。幻覺給你錯的內容，迴圈給你壞掉的流程；內容錯可以換掉，流程壞會把你後續的指示也吃掉，所以加指示只會更糟。判斷有沒有進展，只看這次嘗試排除了哪個可能性。
