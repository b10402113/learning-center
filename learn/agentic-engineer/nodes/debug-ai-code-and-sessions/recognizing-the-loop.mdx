<LearningGoal>
用「重複但沒有進展」認出 agent 卡住的 session，並說明為什麼加指示只會讓迴圈更糟。
</LearningGoal>

## Lesson

用「重複但沒有進展」認出 agent 卡住的第三種壞（壞的是流程，不是程式碼）；面對它，加指示只會更糟，因為你正在指揮的那個東西本身就是故障的一部分。
