# scope：Challenge the Idea Before Any Code

## Lesson

每個專案都跑在預設值上：預設的 build 順序、預設的用心程度、預設的「沒有人決定時」的答案。`/scope` 做的事就是在 code 出現之前，把這些看不見的預設換成寫得下來的選擇——MVP 邊界、明確被排除的東西、以及一個端到端可跑的切片順序。
