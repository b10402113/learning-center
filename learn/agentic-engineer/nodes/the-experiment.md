# The Experiment：One App, Two Builds

## Lesson

同一個開發者、同一天、同一組模型，把一個電影推薦 app 蓋兩次：一次純 vibe，一次走 workflow。vibe 版能跑、demo 也好看，所以誠實的問題是 demo 之後會怎樣——40 秒的 feed、三個 tab 三個答案，每一個都是沒人做過的決定，而不是打錯的字。
