<LearningGoal>
說出 broken 的三種壞法（一般 code bug、AI 特有失敗、agent 迷失路徑）各自長什麼樣，並用「無法解釋的修好等於沒抓到 bug」這條規則拒絕假修好。
</LearningGoal>

## Lesson

東西壞掉時，先問「這是哪一種壞」——一般 code bug、AI 特有失敗、agent 迷失路徑三種要的回應完全不同；而在三種之上壓著同一條規則：你無法解釋的修好，就是還沒抓到的 bug。
