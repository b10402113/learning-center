<LearningGoal>
用徵兆判斷是哪一種壞、選出對應的回應，並說出選錯的代價。
</LearningGoal>

## Lesson

分流不是在選工具，是在選接下來十分鐘注意力放在哪裡。先問「有沒有一個穩定重現的行為錯誤」：沒有就先取得重現或加觀測，還不要分類；有，再問「錯誤的形狀是某一行算錯，還是某個情境沒被想過」——前者是普通 code bug，自己重現並跑科學方法；後者是 AI 寫的程式那種失敗，先回頭重建作者當初的假設，而不是急著把症狀 clamp 掉。如果錯誤根本沒有穩定行為，而是 agent 的動作在原地打轉、diff 持續發散，那是第三種，該處理的是 session 不是程式。翻轉條件的關鍵不是「作者是誰」，而是錯誤的形狀：同一段 agent 寫的程式，只要錯誤變成普遍、單點、可指認的算錯，它就回到第一種。
