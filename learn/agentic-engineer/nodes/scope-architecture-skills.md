# Scope Architecture Skills

## Lesson

一句「build me a movie recommendation app」進來，scope 面談把它逼成一個有 MVP 邊界、有明確排除項、有智慧上限的產品；architect 面談再逐項決定 stack、資料平台、向量索引與背景工作。真正值得學的是收尾那一步：換一個模型複核 spec，挑出六個真缺陷——決策痕跡就是這樣長出來的。
