能分辨 context 裡哪些活動很貴、哪些很便宜，並用「這個任務逼它廣泛閱讀還是精準閱讀」事前判斷成本。
</LearningGoal>

## Lesson

不是所有進到 window 的東西成本都一樣，核心原則是一句「讀很貴、想很便宜」：貴的是讀檔案（整份載入）、搜尋結果、冗長的對話歷史與輸出，便宜的是短而精準的推理、精準的問題與小範圍的讀取；唯一要養成的習慣是交派任務前先問它逼的是廣泛閱讀還是精準閱讀，並可用 Claude Code 的 `/context` 看即時分解。
