<LearningGoal>
能說明 context window 是一個裝下所有讀取、輸入與回覆的單一容器，且它填滿的主因是「尋找答案的成本」，不是答案本身。
</LearningGoal>

## Lesson

context window 是一個裝下整個 session 所有讀取、輸入與回覆的單一容器，有硬性上限；它填滿的主因不是專案大，而是探索很貴——搜尋結果、整個檔案、猜錯的無關檔都留在裡面且不退費，而你真正要的答案只是最末端的一小段。
