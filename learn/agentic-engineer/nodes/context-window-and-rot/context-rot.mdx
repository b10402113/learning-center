<LearningGoal>
能說明 context rot 為什麼在 window 裝滿之前就開始，並分辨位置衰減（U 形）與長度衰減這兩種不同的機制。
</LearningGoal>

## Lesson

context rot 指的是越多 token 進入 window 輸出品質越低，且在 window 填滿之前就開始（二十萬 token 的 window 在五萬 token 就能量測到下滑）；它分成位置衰減（U 形，中間最差，可差 20–30 分）與長度衰減（與位置無關，周圍越長越不可靠，推理準確率 92%→68%）兩種機制。
