<LearningGoal>
走完 /develop 的建置流程：讀 scope 與 spec index、只裝這一刀需要的依賴、在宣告完成前證明它跑得起來、推進 scope 的 checkbox 並產生 verify.md；並認出 flexible route（把工作指到一張截圖、一句話或一段未規劃的工作）與 UI／Logical 兩軌。
</LearningGoal>

## Lesson

閘門通過後 `/develop` 讀 `flow/build.md`，依序分類軌道、載入 spec 與慣例、派唯讀子代理探索、在主執行緒建置並 just-in-time 安裝依賴，資料層以 migration 真的套用為準，完成後只勾做得到的項目、推進 scope 並產生可被 `/check verify` 與 `/test` 接手的 `verify.md`；也能走彈性路線，把 develop 直接指到一張截圖再讓 `/scope` 追上現實。
