<LearningGoal>
在 /develop 於資料模型停下並詢問路徑時，接上 Supabase MCP（建專案並連 GitHub、把 server 指令加進 Claude Code、用 /mcp 認證、reload 確認已連線），再續跑 develop，讓它自己對 live database 跑 migration。
</LearningGoal>

## Lesson

當 `/develop` 在資料模型停下問你要不要把資料庫接起來時，在 Supabase 建專案（連 GitHub、存好 database password）、從它的 MCP 文件取得指令、在終端機貼上新增 HTTP MCP server、reload 後用 `/mcp` 認證並確認已連線，再續跑 `develop data model`，讓它自己對 live database 跑 migration。
