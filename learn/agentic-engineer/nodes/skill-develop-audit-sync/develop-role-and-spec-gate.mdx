<LearningGoal>
認出 /develop 的職責與在 workflow 的位置，並說出 Step 0 spec gate 的機械判準（input coverage）與三個選項，含「先做、記成 Assumed stub」這個逃生口的意義。
</LearningGoal>

## Lesson

`/develop` 是 builder，讀 spec 與專案慣例把功能做成能跑的程式碼；它不做決定，Step 0 用機械的 input coverage 判準把關，遇到欠下的決定時給你回 `/architect`、確認不需要、或先做但把假設寫成一張 `Assumed` 規格三個選項。
