<LearningGoal>
說出為什麼每個後續 skill 都需要共享 context 檔，以及 /audit 如何依 repo 型態（greenfield／whole-repo／area／gap-fill）寫出短小、有證據的 AGENTS.md（root 與 nested）、只留一行指標的 CLAUDE.md，並在 spec 與 scope 衝突時回報兩個檔案。
</LearningGoal>

## Lesson

`AGENTS.md` 是 agent 讀其他檔案前先讀的專案說明，也是後續所有 skill 的共享底座（`CLAUDE.md` 只是一行指標）；`/audit` 靠 pre-flight 訊號在 greenfield、whole-repo、area、gap-fill 四種模式間路由，產出一份短而有證據的 `AGENTS.md`、只在真有獨特長久慣例的區域加 nested 檔案，並在 spec 與 scope 衝突時回報兩個檔案。
