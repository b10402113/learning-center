<LearningGoal>
對照 vibe 版逐項說明 workflow 版同三個功能各自用哪個決定解掉哪個殺手，並分辨「用 prompt 要求它乖」與「用結構讓它不可能亂來」這兩種防線的差別。
</LearningGoal>

## Lesson

同一個 App、同樣三個功能，workflow 版把每個 vibe 殺手換成一個刻意做下的決定：feed 用口味向量一次檢索、結果寫進 recommendations 表、讀取零模型呼叫，快取決定有了名字（isFeedStale），被否決的即時生成留在 ADR 007 裡；匯入分塊加退避重試、upsert 加去重，因為「匯入不能丟資料」是動手前寫下的驗收條件；Vibe 搜尋用便宜模型解析、向量檢索、中等模型只從清單裡挑，真正防幻覺的是固定下來的 movie schema——這就是「規則」與「保證」的差別。程式庫更大，但每一行都承重、都追得回一個決定。
