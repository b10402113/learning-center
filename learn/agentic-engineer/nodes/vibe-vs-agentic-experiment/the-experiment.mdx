<LearningGoal>
說出這場 A/B 實驗的受控條件（同一天、同一個人、同一批模型）與兩個版本的差別，並解釋為什麼「demo 會動」不等於「上線撐得住」。
</LearningGoal>

## Lesson

這場 A/B 實驗用同一天、同一個人、同一批模型，把一個電影推薦 App 建兩次：vibe 版一句 prompt 生出來、沒有寫下任何決定或測試，卻真的能跑、demo 起來也帥；workflow 版先 scope、把每個 load-bearing 決定在動手前捕捉起來。關鍵不是 vibe 版會不會動，而是 demo 藏住了併發負載、每次載入的成本，以及一個 agent 偷偷做下、沒人拍板的決定——判斷一個 build 要看生產環境與未來改動，而不是看 demo。
