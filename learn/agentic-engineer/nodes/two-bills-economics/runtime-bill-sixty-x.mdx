<LearningGoal>
用量級說出 vibe 與 workflow 的執行成本差在哪裡，並解釋為什麼 vibe build 是「架構上無法資助」。
</LearningGoal>

## Lesson

執行帳單是「跑起來要多少錢」：vibe build 每開一次 feed 約 0.35 美元而且每次都重算，workflow build 只是一次快取資料表讀取、幾乎為零；換算成每月每人約 5 美元對不到十分之一美元，差距約六十倍，放大到規模只會更開。真正的致命點不是「貴」而是「架構上無法資助」——成本隨頁面瀏覽量成長、營收永遠追不上，而且這個 35 美分的決定沒有人真正做過，是程式產生器為了「demo 能跑」在檔案中間默默做掉的。
