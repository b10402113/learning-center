<LearningGoal>
能跑 <code>analyze-token-usage.mjs</code> 並讀懂它的輸出，知道每個 token 種類的成本權重，以及該先砍哪一種。
</LearningGoal>

## Lesson

`analyze-token-usage.mjs` 是一支唯讀的 Claude Code session 分析器，回答「這次跑的 token 到底花去哪了」。它把成本拆成 fresh input（1.0）、cache-write（1.25）、cache-read（0.1）、output（5.0）四種權重，分開列出主線與 subagent，並在 READ ME 段直接告訴你該先砍 output 與 fresh input，因為 cache-read 本來就便宜、讓「總數很大」跟「錢花很多」變成兩回事。
