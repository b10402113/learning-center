<LearningGoal>
說出建置帳單的違直覺結論，並分辨那些多出來的 token 裡，哪些是真正的思考、哪些只是浪費。
</LearningGoal>

## Lesson

建置帳單的結論跟直覺相反：workflow build 反而用了更多 token，因為 scope、訪談、寫 spec、驗證都是真工作。但實際支出並不痛——兩個 app 都在一天內、用單一 Claude Max 訂閱做完，只撞了幾次五小時上限。真正的教訓是那些多出來的 token 大多不是思考，而是浪費：沒清的長 session 反覆重讀過期歷史、最貴的模型在做粗活。這不是「把事做對」的代價，而是「在沒有 session 衛生的情況下把事做對」的代價。
