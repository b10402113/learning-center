<LearningGoal>
解釋為什麼大檔案會把不相關的程式碼一起拖進 window、形成自找的 context rot，並說出拆成小檔案如何讓 agent 只載入真正需要的那一小塊。
</LearningGoal>

## Lesson

讀取很貴且常多讀，所以大檔案會讓 agent「只改一個小函式」卻賠上一堆無關程式碼，形成自找的 context rot；拆成小而聚焦的檔案能讓它只載入接近真正需要的那一塊，但目標是聚焦、不是越小越好。
