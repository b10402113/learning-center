<LearningGoal>
用「auth.ts 對上 utils2.ts／handleThing」與「一個鄰居對上五個資料夾」兩組對比，說明可預測命名如何砍掉搜尋成本、colocation 如何把尋寶變成一次讀取。
</LearningGoal>

## Lesson

沒有索引的 agent 只能靠搜尋找路，可預測的命名與位置讓它一次命中（`auth.ts` 一次搜尋就中，`utils2.ts`／`handleThing` 逼它多搜、多開錯檔），colocation 則讓一個功能的零件住在一起，把跑五個資料夾變成一趟單次讀取。
