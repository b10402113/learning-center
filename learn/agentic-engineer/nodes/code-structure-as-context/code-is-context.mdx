<LearningGoal>
說明為什麼 agent 每次讀你的原始碼都算一次 context 成本，並指出程式結構決定了它「讀得多貴」與「找得多累」這兩件事。
</LearningGoal>

## Lesson

你的程式碼本身就是 agent 每次工作時要讀進 window 的一種 context；所以程式結構不是審美，而是經濟——它決定 agent 讀得多貴（檔案大小）與找得多累（命名與 colocation），而這筆成本每次 session 都要重付。
