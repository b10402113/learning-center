<LearningGoal>
把結構選擇看成每次 session 都在付的固定成本，並用「當有人回來改它，agent 得載入多少才能安全地找到並改動？」這句檢查問句，判斷一個結構提案乾不乾淨。
</LearningGoal>

## Lesson

結構是每次 session 都重付的固定成本，好結構是長期折扣、壞結構是課稅；接受任何結構前，用「當有人回來改它，agent 得載入多少才能找到並安全地改動？」這句問句判斷，答案若是「很多」就不算乾淨，唯獨用完即丟的程式可不勉強投資。
