<LearningGoal>
能拆開一個 skill 的資料夾，說出 frontmatter 的 name 與 description、body、以及 scripts／references／assets 三種輔助檔案各自在什麼時候被載入。
</LearningGoal>

## Lesson

一個 skill 是一整個資料夾：`SKILL.md` 的 frontmatter 用 name 與 description 當觸發器，body 寫怎麼做，旁邊的 scripts／references／assets 只在任務真的伸手去拿時才載入。
