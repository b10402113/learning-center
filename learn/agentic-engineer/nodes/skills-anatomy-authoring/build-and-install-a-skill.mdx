<LearningGoal>
能用 Anthropic 的 skill-creator 做出一個 skill，並判斷它該裝在個人的 ~/.claude/skills/ 還是專案的 .claude/skills/。
</LearningGoal>

## Lesson

用 `/plugin install skill-creator@anthropic-agent-skills` 裝官方工具、在 prompt 裡把觸發時機與行為講具體，就能幾分鐘做出一個 skill，再依用途決定裝在個人 `~/.claude/skills/` 或專案 `.claude/skills/`。
