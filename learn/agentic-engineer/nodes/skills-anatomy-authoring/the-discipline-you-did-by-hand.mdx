<LearningGoal>
能說明 skill 是「把反覆手做的程序寫成檔案」，並解釋為什麼它靠結構（description 常駐、body 按需）而不是靠意志力省下 context。
</LearningGoal>

## Lesson

skill 就是一段你一直得手做的程序被寫成檔案：上層的 name 與 description 每次被掃過以決定要不要用，下層的 body 只有被挑中才載入，所以它用結構而非意志力省下 context，也讓你的注意力回到只有你能做的判斷。
