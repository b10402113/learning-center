說出 /document 為什麼從 diff、spec、review findings、tests 四個輸入取材料，以及「code beats commit message」「不編造 timeline」的誠實紀律。
</LearningGoal>

## Lesson

`/document` 從 commits 與 diff、spec、review findings、tests 四個輸入取材料，讓一份好 PR 描述裡最難的理由與風險直接來自磁碟、不必靠記憶重建；它的紀律是 diff 勝過 commit message，且不編造效益、數字或時間線。
