<LearningGoal>
跑一次 /document：讀懂 PR body 的結構、知道何時該跑哪一型，並記住它只寫 prose、推前先問、不 commit／push／merge 的邊界。
</LearningGoal>

## Lesson

`/document` 先選型別、收集輕量歷史，再由主執行緒自己讀 diff，照模板寫出六段式的 PR body，或寫到對應路徑的 changelog／release note／postmortem；它只寫散文，不 commit、不 push、不 merge，任何對外動作之前一定先把內文給你看並問過你。
