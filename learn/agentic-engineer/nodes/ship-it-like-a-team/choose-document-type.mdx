<LearningGoal>
依「你在哪裡、寫給誰」選出 PR、changelog、release-note 或 postmortem，並說出每型對應的讀者與開頭該講什麼。
</LearningGoal>

## Lesson

用「你在哪裡、寫給誰」兩個座標挑型別——分支在 base 前選 `pr`、剛合併選 `changelog`、發版本選 `release-note`、事件後選 `postmortem`；場合決定材料從哪來，讀者決定開頭講什麼，而沒有 tag 或要動 `gh`／推送時，規則會翻轉成先問。
