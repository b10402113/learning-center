<LearningGoal>
跑一次 check review：從專案設定判斷作者模型、問一句確認、換一個唯讀模型讀 diff 加全檔，並讀懂它回的 findings。
</LearningGoal>

## Lesson

`check review` 從專案設定檔（而不是問模型自己是誰）判定作者模型並請你確認一句，再換一個不同家族的模型、在沒有 `Edit` 權限的唯讀子代理裡讀 diff 加整份檔案，回一份依嚴重度排序的 findings；它只判斷、不重跑 app、不寫測試，也不修改程式碼。
