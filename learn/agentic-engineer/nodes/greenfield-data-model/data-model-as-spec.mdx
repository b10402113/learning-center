## Lesson

`architect data model` 這一輪只產出設計與規格（程式碼留給之後的 `develop`），而「完成」的判準是實體與關聯能承載兩條 onboarding 路徑的評分、存下一個 taste profile、產生帶理由的 picks，且之後都不需要破壞性變更；先規格也讓對話清空後仍能從原處接續。
