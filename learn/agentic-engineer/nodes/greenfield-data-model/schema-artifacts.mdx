## Lesson

schema 產物落在 `source/db/schema`、一 entity 一檔並由 index re-export；固定值集用 Postgres enum；`movies` 用 UUID 主鍵＋唯一 TMDB ID＋nullable embedding 搭配 partial index；`ratings` 一列一組 user＋movie 原地更新；`taste_vectors` 每 facet 一列；`model_usage` 每人每天每模型一列；此刻沒有任何外鍵約束。
