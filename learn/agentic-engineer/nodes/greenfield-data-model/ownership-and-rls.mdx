<LearningGoal>
說出 rule one（helper 自己套用 user ID、不信任呼叫端）、typed registry 如何關掉「忘記註冊 user-owned 表」的缺口，以及為何在沒有測試、DB 也無法驗證 ownership 時，RLS deny-all 加 scoped helper 是唯一真正的防線。
</LearningGoal>

## Lesson

rule one 要求 scoped query helper 自己套用 user ID、不信任呼叫端，並用一份 helper 為唯一消費者的 typed registry 補上「新表忘了註冊」的缺口；因為專案沒有測試套件、資料庫在這條路徑上也無法驗證 ownership，唯一真正的防線是讓不安全的路徑在結構上不存在——RLS deny-all 加上 scoped helper。
