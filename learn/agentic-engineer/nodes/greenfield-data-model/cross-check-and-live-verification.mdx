<LearningGoal>
跑第二模型的 cross-check 消化它的發現、接上 Supabase MCP，把遷移在單一交易內套用到 live DB，並用驗收條件（seed 20 部電影、2 個 auth user → 2 個 profiles、anon 對九表回零列、刪 user 清空 owned 表）證明行為。
</LearningGoal>

## Lesson

把 spec 交給第二個模型 cross-check 並套用它的十筆發現，授權 Supabase MCP 接上 live 專案，遷移在單一交易內原樣套用、seed 20 部電影，再用驗收條件把行為跑出來（2 auth user → 2 profiles、anon 回零列、刪 user 清空七張 owned 表、audit 不 cascade），最後把驗證步驟存進 VerifyMD、commit，並把 region 修成 EU West。
