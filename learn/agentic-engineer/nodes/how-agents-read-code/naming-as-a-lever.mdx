<LearningGoal>
判斷什麼時候值得為 agent 投資清楚的命名與可預測的結構、什麼時候不必，並用「auth.ts 對 utils2.ts」的對比說明這如何換成更少的搜尋與更少的 context 消耗。
</LearningGoal>

## Lesson

命名與結構是給 agent 的效能槓桿，不是風格偏好：清楚命名讓它一次 grep 命中，通用命名（如 `utils2.ts`／`handleThing`）則逼它多搜、多開檔、多猜、多燒 context；判斷該不該投資，就問它會不會被反覆導航、會不會活很久，用完即丟就不必勉強。
