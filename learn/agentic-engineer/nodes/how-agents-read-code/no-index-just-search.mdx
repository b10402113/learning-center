解釋 agent 為什麼沒有索引或預建地圖，只能靠 grep、glob、read 三個工具現場找路，並說出它每次找東西的動作順序。
</LearningGoal>

## Lesson

agent 背後沒有索引、沒有 embeddings、也沒有預建地圖，只有 grep（搜文字）、glob（依檔名找）、read（開檔）三個工具，每次都得當場呼叫；所以它面對「auth 在哪」會先搜尋撒一張大網，再篩選、再讀取，而不是先回答。
