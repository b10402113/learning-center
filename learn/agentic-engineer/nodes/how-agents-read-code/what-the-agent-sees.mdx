<LearningGoal>
說出 agent 的 context window 裡實際裝了哪四種東西，並用「你沒說、它沒讀＝它不知道」判斷它當下到底知不知道某件事。
</LearningGoal>

## Lesson

agent 沒有「認識整個 codebase」這回事，它只知道 context window 裡當前載入的東西（當前對話、它讀過的檔案、你設定的 always-on context、系統指令），所以「你沒說、它沒讀，它就不知道」——下 prompt 前先問一句：它有沒有拿到做對這件事需要的東西。
