<LearningGoal>
照著 agent 的順序追一次「auth 在哪裡」：先 grep 撒網、再依檔名與上下文篩選、最後逐檔讀取，並說出一個簡單問題要花幾個 tool call 才答得出來。
</LearningGoal>

## Lesson

追一次「auth 在哪」的完整路徑是：grep 撒網（不開檔）→ 依檔名與上下文篩選 → 讀 `lib/auth.ts` 找到核心實作 → 順著 import 摸到 session、actions、proxy → 給出「auth 分四層」的答案，全程只花一次搜尋、一個篩選決定、四次檔案讀取。
