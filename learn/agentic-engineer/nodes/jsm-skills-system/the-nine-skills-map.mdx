## Lesson

九個 skill 構成一條從 idea 到 `/sync` 的完整迴圈（`/architect` 起的 feature loop 會反覆繞回，`/debug` 隨時可插），每個 skill 各據一格、各交出自己的產物，而真正要交東西只需要其中五個。
