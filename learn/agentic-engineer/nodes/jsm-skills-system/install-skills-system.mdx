<LearningGoal>
用一條指令安裝 JSM Skills System，認出九個 skill 的全域安裝位置，並說出「skill 只是一份 markdown 指令檔」代表什麼（沒有帳號、沒有 API key）。
</LearningGoal>

## Lesson

一條 `npx skills@latest add jsmastery-pro/skills -a claude-code` 就能全域安裝 JSM Skills System 的九個 skill；它們不過是給 agent 讀的 markdown，住在 agent 的全域 skills 目錄，不需要帳號、也不需要 API key。
