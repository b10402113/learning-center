<LearningGoal>
說出 MCP 連的是「你自己那個實例」，並在 Supabase 這個例子上分辨它與 skill 各自負責哪一半。
</LearningGoal>

## Lesson

MCP 不教慣例，而是把 agent 接到你自己那個實例：你真實的表、真實的資料、真實的查詢。在同一個工具（例如 Supabase）上，skill 負責「知道這工具怎麼運作」，MCP 負責「有一條通往你實例的線」——一個是知識，一個是連線，做的是兩件不同的事。
