<LearningGoal>
用一條可操作的規則，判斷某個工具你該帶一個 skill、接一個 MCP，還是兩個都要。
</LearningGoal>

## Lesson

用兩個判別問句決定一個工具需要哪一種：需要 agent 寫出這工具現在正確的程式碼，就帶 skill；需要碰到你自己那份活的資料或實例，就接 MCP；兩個都要，就兩個都上（這最常見）。原則是不要因為「可以接」而接——線要開，是因為任務真的需要活的資料。
