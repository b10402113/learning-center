<LearningGoal>
說出 skill 為什麼能讓 agent 跟著某個工具「現在真正的做法」走，以及它補的是訓練資料過期造成的哪個缺口。
</LearningGoal>

## Lesson

為某個特定工具而寫的 skill，帶的是這個工具現在真正的慣例——auth 怎麼設、row-level security 怎麼寫、當下的 API 與官方推薦的做法——補上模型訓練資料過期、只能憑半記得舊印象的那個缺口。工具改得越快，這份 skill 越有價值；它不讓模型變聰明，只讓 agent 跟著現況做事。
