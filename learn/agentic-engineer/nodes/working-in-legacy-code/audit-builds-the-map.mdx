<LearningGoal>
說出 /audit 在一個已成熟的舊專案上如何改成整庫掃描、寫出 root AGENTS.md 與 CLAUDE.md 指標、只在真正需要的區域放 nested 檔，並記下 stack、指令、慣例與新人第一天會被交代的細節。
</LearningGoal>

## Lesson

在已成熟的舊專案上，`/audit` 因偵測到足夠的既有訊號而改走整庫掃描，寫出 root `AGENTS.md` 與一行 `CLAUDE.md` 指標，並只在真有獨特慣例的區域（示範中是 `database` 與 `app`）放 nested 檔；root 記的是資深工程師第一天會交代的事，而貫穿所有專案型態的原則是讀既有的、只補缺的、保護別人已寫的。
