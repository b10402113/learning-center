<LearningGoal>
用 /develop 在舊碼庫做一個最小安全變更：沿用既有模式與工具、在「改一個函式」與「新增實作再遷移呼叫端」之間選對、換路徑前搜尋所有引用，並把改動收在 spec 邊界內。
</LearningGoal>

## Lesson

`/develop` 先讀周邊檔案、沿用既有模式，選對「改既有函式」或「新增實作再遷移」，換路徑前搜尋所有引用，並把改動收在 spec 邊界內；示範結果是四個檔案、不需要 migration 的還書功能。
