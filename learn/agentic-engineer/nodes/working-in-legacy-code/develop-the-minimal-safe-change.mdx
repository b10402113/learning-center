用 /develop 在舊碼庫做出最小安全變更：讀周邊檔案、沿用既有模式與工具、能用改一個現有函式解決就不另起爐灶、換路徑前先搜尋所有引用，把變更收在 spec 邊界內，做出一個不必 migration、只動四檔的成果。
</LearningGoal>

## Lesson

`/develop` 在舊碼庫動手前先讀變更周邊的檔案並沿用既有模式，能用改一個現有函式解決就不另起爐灶、重用既有工具並跟隨當地命名，換路徑前先搜尋所有引用以避免新舊路徑並存，把變更收在 spec 邊界內，交出一個不必 migration、只動四個檔案的成果。
