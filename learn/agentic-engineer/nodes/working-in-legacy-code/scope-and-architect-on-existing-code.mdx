<LearningGoal>
在已建好地圖的舊碼庫上跑 /scope 規劃一個 slice（existing／planned／deferred、寫進 docs/scope.md），再用 /architect 先讀功能現況、追請求路徑、查誰依賴它，才決定變更要落在哪裡，並守住「看不懂的程式碼不要拆」。
</LearningGoal>

## Lesson

在已建好地圖的舊碼庫上，`/scope` 先讀 audit 的 `AGENTS.md`、掃描既有碼庫並把 existing／planned／deferred 的規劃寫進 `docs/scope.md`，`/architect` 則先讀功能現況、追請求路徑、查誰依賴它才決定變更落點，並守住「看不懂的程式碼不要拆」。
