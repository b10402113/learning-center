跑一次舊碼庫版的 /scope→/architect：讓 scope 讀地圖把功能分成 existing／planned／deferred 寫進 docs/scope.md，再讓 architect 追過現有實作與依賴後才決定變更落點，並寫出保留既有行為的 spec。

## Lesson

`/scope` 先讀 audit 地圖、盤點既有功能，把 slice 分成 existing／planned／deferred 寫進 `docs/scope.md`；`/architect` 追過現有實作與依賴後才決定變更落點，並在 spec 寫明哪些既有行為必須保留、以及之後如何證明。
