<LearningGoal>
能照著步驟在你的編輯器裡裝好課程要用的 coding agent CLI（示範用 Claude Code）與 VS Code 擴充，並知道為什麼選這個工具、以及付費方案該怎麼挑。
</LearningGoal>

## Lesson

設定只有兩步：安裝 CLI，以及（若用 VS Code）安裝 Claude Code 擴充。工具無關是這門課的保證——workflow、skill 與看待 context 的方式都能原樣搬到 Cursor、Codex，在 Claude Code 裡示範只是選了一個具體例子。付費方案是實務前提：免費層只能玩玩，真正 build 要付費方案，從最小方案起步、持續撞到上限再升級。做完的驗收標準很簡單：打開編輯器，你叫得出 agent。
