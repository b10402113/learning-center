<LearningGoal>
能說出課程的核心主張——寫程式已被 AI 商品化，開發者的差異化在判斷力，而這門課教的就是判斷力，且它刻意不教你「用 prompt 生出自己看不懂的碼」。
</LearningGoal>

## Lesson

寫程式已被 AI 商品化，真正的差異化是判斷力——知道做什麼、把 agent 指對方向、像資深工程師審 junior 的 PR 一樣驗收它的產出；agent 不會給你判斷力，只會拉高「沒有判斷力」的代價，而判斷力可以被教，這就是整門課的存在理由。課程也刻意畫出反目標：它不會把你變成用 prompt 生出自己看不懂的碼的人，你仍然是那個拍板與負責的工程師，AI 只是你帶的最快、最聰明的 junior 或 mid 開發者。
