<LearningGoal>
能說出並執行這門課的五條學習守則——邊做邊學、知道課程的形狀、不要跳過比較模組、自己動手填速查表、照順序走——並說明每一條背後的道理。
</LearningGoal>

## Lesson

五條學習守則：一、build along——開著編輯器跟著動手做，只看示範只有動手做的十分之一價值；二、知道課程的形狀——fundamentals → 一段沒有 skill 的痛 → JSM workflow（每個 skill 對應一個你剛感受過的痛）→ 真實場景；三、別跳過 A/B 比較模組，它是讓後面全部接上的關鍵；四、速查表刻意留白讓你親手填，自己寫的才會留下；五、照順序走，挑戰題先試再看解答，因為掙扎本身就是課。核心邏輯是：這是 workflow 課不是理論課，方法要落在手上，而不是停在耳朵裡。
