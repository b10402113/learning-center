<LearningGoal>
能對照自己的情況做一次先備條件自檢——技術門檻（會寫碼、會用終端機與編輯器）、必備的付費方案、以及最關鍵的心態前提——並判斷自己該用什麼節奏走這門課。
</LearningGoal>

## Lesson

用三個訊號自檢——能不能獨立做出小東西、有沒有遇過聊天視窗做法在專案變大後失效、是不是把單一 CLAUDE.md 拿去扛整個真專案；技術門檻只要會寫碼、會用終端機與編輯器，實務上需要一個 coding agent 的付費方案並從最小方案起步。真正決定成敗的前提是心態：贏的人不是最資深而是最願意改變工作方式的；已是資深且天天用 agent 的人可以快轉前期但別跳過，並在 legacy 與 session 救援章節慢下來。
