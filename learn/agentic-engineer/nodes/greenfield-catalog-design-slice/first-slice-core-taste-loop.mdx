# 第一個 Slice：core taste loop 這條 walking skeleton

## Learning goal

用 architect→develop 蓋出 core taste loop 這條端到端 thin slice（auth／pool／taste vector／weighting／quota／gating），15 個 task 上 branch，再用 Playwright 驗證。

## Lesson

用 architect 把 core taste loop 的 load-bearing 決定（auth、候選池、swipe 權重、build 狀態、選擇邏輯、每日 quota、gating）釘成 spec，再 clear+develop 為 15 個 task 上分支，最後用手動與 Playwright 兩條路驗證（含 next/image 的 priority 已棄用改 preload）。
