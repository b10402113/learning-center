# 改主意時：compact 而非 clear，重跑 architect→develop

## Learning goal

在已經看到成品後要改方向時，判斷該 compact 還是 clear，並用「重新 architect → develop → verify」把 design system 改版而不弄丟先前狀態。

## Lesson

看到成品想改方向時，用「下一句是否指涉剛做的決定」判斷該 compact（保留它記得的）還是 clear；光換顏色通常重現不了參考圖，要完整重調，並重跑 architect→develop→verify。
