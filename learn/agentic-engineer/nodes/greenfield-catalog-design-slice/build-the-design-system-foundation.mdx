# Develop Design System：tokens、components 與 /design 契約

## Learning goal

用 develop 把 design system 蓋成 tokens、fonts、ShadCN、swipe deck、PWA，用 Playwright 驗證，並讀懂 /design route 為何是可重用的設計契約。

## Lesson

用 develop 把 design.md 蓋成真的畫面——tokens 進 globals.css、ShadCN 長在 token 上、做出元件與 PWA，用 Playwright 實測並自行修掉只有排上畫面才看得到的 defect，並用 dev-only 的 /design 路由當作之後所有 feature 共用的設計契約。
