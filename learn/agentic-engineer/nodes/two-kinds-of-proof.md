# Two Kinds of Proof

## Lesson

evidence 要回答兩個不同的問題，所以需要兩個不同的機制：這個 feature 今天能不能用，是 verify 的事；它以後還會不會壞，是 test 的事。這個 node 把 prototype / alpha / beta 三層對到「建好、被證明、被保護」，並說明為什麼順序一定是先 verify 再 test，而且兩者都讀同一套 AC。
