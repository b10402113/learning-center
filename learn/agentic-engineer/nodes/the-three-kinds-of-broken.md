# The Three Kinds of Broken

## Lesson

東西壞掉時第一個動作不是技術，是一個問題：這是哪一種壞？普通的 code bug、AI 寫的 code 特有的缺陷、還是 agent 自己任務跑掉了卻還很自信——三者長得很像，卻需要相反的反應。分類錯了，你會去 prompt 一個它看不見的 bug，或清掉一個其實已經蒐集完證據的 session。
