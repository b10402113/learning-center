用「最大的風險在哪」在 Tracer Bullet、Skateboard、Journey、Facade 之間選出這一刻的切法，並知道 scope 選完後會據此讀哪一個 approach 檔。
</LearningGoal>

## Lesson

Build approach 決定「先退掉哪個風險」：各層接不起來選 Tracer Bullet、怕沒人要選 Skateboard、體驗本身是產品選 Journey、先驗證長相選 Facade；認真 production build 預設 Tracer Bullet，選定後 agent 才讀對應的 approach 檔並採用那個角色。
