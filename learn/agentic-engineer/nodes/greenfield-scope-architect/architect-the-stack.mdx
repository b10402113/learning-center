<LearningGoal>
跑 /architect stack and architecture，走完多輪帶建議選項的決策訪談（需要時並行 web 查證），把 load-bearing 的 stack 決定寫成一份帶 index 與 rationale 的 spec，並知道它不產 build plan。
</LearningGoal>

## Lesson

`/architect stack and architecture` 先讀 scope、決定要不要 web 查證，再用多輪「一題一決定、各附一個建議選項」的訪談收齊 stack 承重選擇，寫出帶 `index.md`（summary／decision／proposed stack／consequences／follow-up）與 `rationale.md` 的 spec，且刻意不產 build plan。
