## Lesson

依選定的 stack 比對出 agent skills（Supabase／Vercel React／shadcn-ui／AI SDK 等）與 MCP servers（Supabase／Vercel／Playwright），看得懂風險等級看的是授權範圍，並用 `npx skills@latest add`、`npx skills remove`、`claude mcp add`（須在真實終端機）接上。
