<LearningGoal>
在一個乾淨的 greenfield 視窗裝好 skills package 並驗證可用，接著用一句話跑 /scope，走完 greenfield 偵測與分批問答，產出 docs/scope/scope.md。
</LearningGoal>

## Lesson

先在乾淨視窗用 `npx skills@latest add … -a claude-code` 裝好 skills package 並重啟驗證，再對一句話的點子跑 `/scope`；它會偵測 greenfield、用分批問答逼出決定，產出磁碟上的 `docs/scope/scope.md` 作為專案狀態。
