<LearningGoal>
說出「skill 帶狀態與流程、人帶判斷」這條分工線，並解釋為什麼 agent 跑得再快、再不知疲倦也取代不了判斷——因為它對結果沒有任何利害關係。
</LearningGoal>

## Lesson

skill 帶狀態與流程、人帶判斷：skill 把專案做到哪、下一步跑什麼、誰擁有哪份檔案固定進專案檔案，讓工作跨 session 與跨人延續；人負責回答「對不對、值不值得、能不能放行」這類檔案沒有答案的問題。agent 跑得再快、再不知疲倦也取代不了判斷，因為它對結果沒有任何利害關係。
