<LearningGoal>
說出五個只有人能做的放行決定——(1) 這個建議適不適合我的產品、(2) 對話變泥時清掉 session、(3) 獎勵誠實的紅燈勝過方便的綠燈、(4) 向 agent 要證據、(5) 挑一個不跟作者共享盲點的審查者——並在每一個上說明為什麼不能交給 agent。
</LearningGoal>

## Lesson

整個迴圈真正需要人出手放行的只有五個地方：(1) 判斷 `/architect` 的建議適不適合自己的產品、(2) 對話變泥時清掉 session、(3) 獎勵誠實的紅燈勝過方便的綠燈、(4) 向 agent 要證據（沒證據就不算通過）、(5) 挑一個不跟作者共享盲點、不同模型的審查者。這五者共用同一個理由：agent 對結果沒有任何利害關係，所以取代不了判斷——但當風險對稱、你已明確選擇不驗證時，放手讓它跑才是對的。
