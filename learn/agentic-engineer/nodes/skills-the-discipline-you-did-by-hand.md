# Skills：你本來用手做的紀律

## Lesson

前五個 node 教的是一套紀律——先工程化 context、刻意做決定、always-on 保持精簡、檢查回來的東西——而紀律是一疊你每次都得記得照順序跑的小程序，偏偏在你最忙的時候最容易漏。skill 就是把它寫成檔案一次，讓 agent 每次都跑同一套；它跑流程，你做判斷。
