<LearningGoal>
跑 test 或 test <feature>，把未測的資料邏輯補成單元／整合測試並跑到 green，留下 test-preferences.json。
</LearningGoal>

## Lesson

跑 `test`／`test <feature>` 讓它寫出測試、用專案指令跑到 green，只修測試本身的錯、不為過關改應用程式碼，最後留下測試檔與 `test-preferences.json`。
