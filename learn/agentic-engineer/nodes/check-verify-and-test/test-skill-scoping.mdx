## Lesson

`test` 只測這條 branch 上尚未 commit 的變更，依檔案類型（component／page-flow／api-server／logic／cli）挑測試策略，把可自動化的耐久條件追到 `AC-N`，並拒絕替還在做假的 scaffolding 上鎖。
