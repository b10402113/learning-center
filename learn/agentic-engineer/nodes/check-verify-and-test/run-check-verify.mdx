<LearningGoal>
跑 check verify <feature>，讀懂驗證報告，並把失敗分流到 /debug 或 /develop。
</LearningGoal>

## Lesson

用 `check verify <feature>` 載入 `verify.md` 合約、在真 App 上逐條操作並留下證據，讀 PASS／FAIL／BLOCKED 報告，再把失敗分流到 `/debug`（真 bug）或 `/develop`（沒建的表面）。
