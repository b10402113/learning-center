<LearningGoal>
定義 tool 是什麼，說出每個 coding agent 都有的五個核心工具，並講清楚「模型決定」與「工具執行」是分開的兩件事，以及每一次 tool call 都有真實成本。
</LearningGoal>

## Lesson

一個 tool 是 agent 被允許執行的一個具體、定義明確的動作——不是描述，而是真的能被觸發、拿回結果的操作，像一個函式或一次 API 呼叫。每個 coding agent 都給模型五個核心工具：Read、Write、Edit、Search（grep／glob）與 Run a command，負責看、改、跑。但模型本身不執行，它只發出結構化的 tool call，執行是另一件事；而每一次 tool call 都會產生內容、落進 context，所以它不是免費的背景動作。
