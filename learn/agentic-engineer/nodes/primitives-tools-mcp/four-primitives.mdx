<LearningGoal>
說出四大原語（tools／MCP／subagents／skills），並解釋為什麼這四個學會一次就夠，之後每一個新工具你只是在學它的口音。
</LearningGoal>

## Lesson

coding agent 能伸手去拿的東西只有四類：tools（它被允許執行的動作）、MCP（把外部服務接成可呼叫工具）、subagents（在獨立 context 裡做重活的幫手）、skills（按需載入的操作說明書）。這四類是跨工具共通的骨架，所以只要學一次；之後每一個新工具，你只是在學它的口音。同一個問題永遠成立：這個工具，是對哪一個原語的口音？
