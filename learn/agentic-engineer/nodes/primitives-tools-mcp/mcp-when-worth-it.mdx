<LearningGoal>
用自己的話說明 MCP 是什麼、為什麼它是開放標準而不是某一家工具的功能，並在「該不該接這個 MCP server」上做出判斷。
</LearningGoal>

## Lesson

MCP 是把外部服務接成 agent 可呼叫工具的標準橋樑：服務做一次 server，任何 agent 都能連，所以它是開放標準，不是某一家工具的功能。但接一條線不是免費的——它多一個會壞的依賴，也交給 agent 一份真實權限。判斷的尺只有一句：這個任務需要「活的、會自己變、又無法手動貼上」的外部資料嗎？需要就接，靜態或貼一下就有的，就別接。
