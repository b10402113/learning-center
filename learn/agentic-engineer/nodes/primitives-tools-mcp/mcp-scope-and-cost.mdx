<LearningGoal>
在 global（user）與 project 兩種 scope 之間做對選擇，並說出 security、context 與 maintainability 三個 MCP 要付的代價。
</LearningGoal>

## Lesson

接不接是上一步的決定，接在哪裡是這一步的決定。Claude Code 有三個 scope：local（預設、只在當前專案、只有你）、user／global（每個專案都看得到）、project（寫進 repo 的 .mcp.json、跟團隊共享）。判準是：通用且與專案資料無關的放全域，綁特定專案系統或資料的放專案。不管放哪都要付三筆帳——安全（縮小波及範圍、給最小權限）、context（工具定義開場就吃掉可觀的 token）、可維護性（專案設定跟著 repo 走最省事）。有疑慮就 scope 到專案。
