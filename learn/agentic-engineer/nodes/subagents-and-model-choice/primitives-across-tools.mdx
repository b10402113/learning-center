<LearningGoal>
拿四大原語對照一個新工具，知道哪些東西會一字不改地通用、唯一真正的分歧在哪裡。
</LearningGoal>

## Lesson

四大原語幾乎原封不動地跨工具通用：tools 是同樣的動作、MCP 是同一套協定、subagents 是同一種機制，而 skills 更是同一份檔案——一個 `SKILL.md` 資料夾可以從 Claude Code 原樣複製到 Codex，不改一個 byte。唯一真正的分歧是 always-on 檔：Codex 直讀 `AGENTS.md`，Claude Code 讀 `CLAUDE.md`，得靠一行 `@AGENTS.md` 把共用 context 帶進來。面對任何新工具，只要問四題：能做哪些動作、支不支持按需指示、能不能連到 codebase 之外、能不能把重活交給一個有自己 context 的東西。原語學會一次，工具只是它被講出來時的口音。
