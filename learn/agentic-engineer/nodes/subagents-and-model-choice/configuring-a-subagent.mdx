<LearningGoal>
用 `/agents` 或手寫一個 markdown 檔建立 subagent，並用自動或指名兩種方式把它派出去。
</LearningGoal>

## Lesson

建立 subagent 有兩條路：跑 `/agents` 的引導流程，或親手寫一個 markdown 加 YAML 的檔——frontmatter 放 `name`、當觸發器用的 `description`、可選的 `tools` 與 `model` 限制，底下接一段系統提示，放進 `agents` 資料夾（`.claude/agents/` 專案共享，或 `~/.claude/agents/` 個人）。description 決定它何時自動接手，tools 是一道真實的安全界線；而要記住 `/agents` 只用來「建」，真正派它工作靠一般訊息——符合 description 就自動接手，或直接指名。內建的 Explore、Plan、general-purpose 也會自動接手。
