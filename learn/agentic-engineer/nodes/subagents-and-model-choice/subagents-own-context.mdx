<LearningGoal>
說出 subagent 為什麼要用自己的 context、它替你省下什麼，以及哪一種任務才值得派一個出去。
</LearningGoal>

## Lesson

subagent 是一個有自己獨立 context 的工人：它把大量閱讀與搜尋在自己的空間裡做完，只把結果交回主線，所以主線的 window 不會被重讀取塞滿；因為每個 agent 各有空間，主 agent 還能同時派好幾個出去平行加速。判斷跟 MCP 是同一套——只有當工作夠重、而你只要結果，或工作能拆成互不依賴的幾塊時才值得派；又小又精確、讀一兩個檔就能答的任務，派了只會多繞一步。
