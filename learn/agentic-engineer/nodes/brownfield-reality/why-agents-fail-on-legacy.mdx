<LearningGoal>
說出 agent 在舊碼庫失手的根因不是不會寫程式，而是只讀得到 what、讀不到 why，並用三個具體症狀認出「沒有地圖」造成的猜測。
</LearningGoal>

## Lesson

agent 在舊碼庫失手的根因不是不會寫程式，而是讀得到 what、讀不到 why；缺少脈絡時它不會留白，而是用一般經驗填空，於是產出看起來更乾淨、卻違反專案隱性規則的改動。新專案裡這種猜測多半無害，公司系統裡同樣的猜測可能影響客戶與營收。
