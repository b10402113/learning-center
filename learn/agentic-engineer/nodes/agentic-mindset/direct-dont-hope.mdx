<LearningGoal>
能用「你是架構師、agent 是引擎」的心態取代許願式的 prompt，說出該交給 agent 什麼、該由自己保留什麼，並用「一件事、完整 context、可審的輸出」描述一個被指揮的任務。
</LearningGoal>

## Lesson

兩個根因底下是一顆錯誤的心態：把 agent 當神燈精靈，許願、祈禱、把願望改得更長。正確的心態是「你是架構師，agent 是引擎」——你設限制、做真正的決定、定義什麼叫做好，agent 提供速度與不知疲倦；這就像資深工程師帶 junior：不代寫每一行，但給 context、給方向、在出錯前攔下來。agent 是放大器，放大你灌進去的方向，所以會被取代的是只會許願的人，更有價值的是能把模糊問題變成清楚方向的人。行動指令只有一句：發現自己又在許願時先停下，問「資深工程師會怎麼做」，並用「這是什麼、會動到哪、做完長什麼樣、哪些這次不做」的形狀去指揮。
