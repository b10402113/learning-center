<LearningGoal>
能在 vibe coding 與 agentic engineering 之間做出選擇，用判別問句檢查自己現在是「在反應、在許願」還是「在指揮」，並說出為什麼這個差距是被放大、而不是被 AI 創造出來的。
</LearningGoal>

## Lesson

同一句「幫我做結帳功能」，A（vibe coding）丟一句 prompt、八分鐘生出 240 行讀不完的碼就推上線，兩小時後在 production 撞上 agent 悄悄做錯的決定；B（agentic engineering）先讀專案慣例、把 context 更新進 AGENTS.md、把任務切到「先做一個 payment intent endpoint」、逐行審出漏掉的 auth guard、測試通過才 commit，再切下一步。差別不是技術、也不是模型，而是誰在主導。判別方式是一組可當場回答的問句：這份 diff 我讀得完嗎？我給的是一件可 review 的事嗎？我知道它替我做了哪些決定嗎？而重點是：vibe coding 不是新手錯，是「沒有系統時的預設值」；AI 只是把 A 與 B 的差距從要好幾週才看得出，壓縮成幾個小時，還讓它複利。真正的解不是意志力，而是換上一套系統。
