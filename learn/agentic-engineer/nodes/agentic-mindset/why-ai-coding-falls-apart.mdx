<LearningGoal>
能用「沒有真 context（只給你公開碼的平均版本）」與「沒有真計畫（把你不曾說出口的決定全用預設值填滿）」兩個根因，說出 AI coding 為什麼前一陣子很神、之後開始崩壞，並記住「是缺 context，還是缺你的決定？」這個診斷問句。
</LearningGoal>

## Lesson

AI coding 會崩壞有兩個根因：一是「沒有真 context」——模型在海量公開程式碼上預測下一個 token，給你的是「這件事通常怎麼寫」的平均版，而不是你專案的版本，除非你親手把它放進它眼前；二是「沒有真計畫」——現代 agent 其實會計畫，但它朝著你沒講清楚的目標計畫，把你沒說出口的決定全用最可能的預設值填掉。兩者疊起來就是「大 prompt → 大輸出 → 驗證不了 → 壞掉 → 更大的 prompt」的迴圈，而修它的不是更厲害的 prompt，是一套會工程 context、會先計畫的系統。帶走的診斷問句：這次是 agent 缺 context，還是它替你扛下了本該由你做的決定？
