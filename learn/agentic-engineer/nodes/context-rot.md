# Context Rot：品質在窗口滿之前就先掉

## Lesson

窗口不是快滿才出事：宣稱 200k 的模型在 50k 就可測退化，埋在長 context 中間的事實會多掉 20–30 分。再加上無關主題會搶注意力，日常症狀就是重複、遺忘、自我矛盾。這個 node 用 clear 與 compact 的分野，把「什麼該背著、什麼該放下」變成一個可操作的判斷。
