# Build Your Own Skill：以及 Skills vs. MCP

## Lesson

讀懂 SKILL.md 之後，下一步是自己做一個：用 skill-creator 把行為講清楚，讓它寫出 frontmatter，而因為 description 是它寫的，你那段 prompt 就變成整件事最關鍵的部分。最後用 Supabase 把界線切開——skill 帶的是工具真正的慣例，MCP 開的是通往你真實 instance 的線。
