<LearningGoal>
換一個沒寫過這段碼的模型跑 check review：從專案設定判定作者、讀全檔找出一個 major 問題與四個 minor，並用新 migration 而非改舊 migration 修。
</LearningGoal>

## Lesson

驗證證明「今天會跑」，review 問的是「這東西是怎麼被造出來的」：從專案設定檔判斷作者模型（不是問當前模型），換一個沒參與撰寫的唯讀模型讀 37 個檔案，挑出一個 major（ratings schema 沒有 DB constraint 把 score 可為空性綁在 state 上）與四個 minor，並用一筆新 migration 而非改舊的 000 來修。
