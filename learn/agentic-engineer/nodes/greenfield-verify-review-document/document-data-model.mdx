<LearningGoal>
用 document 產出 PR 描述：選對文件類型、從 branch commits 與 diff 組出 PR body，再 commit、開 PR、merge。
</LearningGoal>

## Lesson

把 branch 上的 commits 與 diff 交給 `document`，選 PR description，讓它組出「實作了什麼／設計理由／驗證紀錄／串接方式／怎麼測／給 reviewer 的提醒」的 PR body，再 commit、開 PR #2、merge 進 main；skill 只產文字與打勾 `Document it`，開 PR 與 push 前一定先過你。
