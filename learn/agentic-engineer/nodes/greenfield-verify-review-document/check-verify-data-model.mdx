<LearningGoal>
對資料模型跑 check verify：讀 verify.md 的驗收清單、解開缺 .env.local 的阻塞、把 11 條 acceptance criteria 全部跑過。
</LearningGoal>

## Lesson

就算功能早就 develop 完，只要 `verify.md` 的 checkbox 沒全打勾就不算數：跑 `check verify` 讀清單、用 MCP 補公開 Supabase 變數而把帶密碼的連線字串留給人、解開缺 `.env.local` 的阻塞，最後驅動真實 app 跑出 11 條 AC 全數 checked、零 unexercised、零 blocker、零 fail 的單次通過報告。
