<LearningGoal>
分辨 always-on、on-demand、reference 三種 context，並用「成本節奏」（每次都付 vs 用到才付）說出它們的差別。
</LearningGoal>

## Lesson

context 分三種，只差成本節奏：always-on 每個 session 都付（住在 AGENTS.md），on-demand 是 agent 自己伸手去拿，reference 是被明確指到才載入。也因為每次都付，always-on 必須很小——判準是「我在大多數任務上都會需要它嗎？」
