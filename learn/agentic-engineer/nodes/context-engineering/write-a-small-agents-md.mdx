<LearningGoal>
照著做，在一個新專案裡寫出一份只放「每個任務都成立」規則的 AGENTS.md，用 CLAUDE.md 的 import 讓它保證載入，並用 /context 驗證。
</LearningGoal>

## Lesson

四步做出一個夠小的 AGENTS.md：建專案、只寫每個任務都成立的規則（技術棧、金額用整數分、API 用 snake_case）、在 CLAUDE.md 用 `@AGENTS.md` 讓它保證載入、再用 `/context` 與 `/memory` 驗證。具體程式碼留在 repo 等 agent 來讀，不塞進 always-on。
