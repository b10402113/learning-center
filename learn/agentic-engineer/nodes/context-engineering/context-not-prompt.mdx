<LearningGoal>
說明為什麼把 prompt 寫得更漂亮是「錯的槓桿」，並講清楚 context engineering 是在 agent 讀到 prompt 之前，就先設計好它會知道什麼。
</LearningGoal>

## Lesson

輸出變差時直覺會去改 prompt，但那不是槓桿：prompt 落在 agent 當下已載入的 context 之上，答案品質取決於那個環境。真正的技能是 context engineering——在 agent 讀到 prompt 之前，就刻意決定它會知道什麼。
