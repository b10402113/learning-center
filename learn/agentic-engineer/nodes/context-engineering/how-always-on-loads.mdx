<LearningGoal>
說出 exploration（也許）與 always-on（保證）兩種規則送達方式的差別，知道 Claude Code 開機只讀 CLAUDE.md、AGENTS.md 要靠 import 帶進來，並用 /context 與 /memory 驗證到底載入了哪些檔。
</LearningGoal>

## Lesson

規則有兩條到達 agent 的路：exploration 是「也許」，always-on 是「保證」。Claude Code 啟動只讀 CLAUDE.md、沒有 fallback，AGENTS.md 要在 CLAUDE.md 用 `@AGENTS.md` import 才進得來；用 `/context` 與 `/memory` 驗證，別猜。
