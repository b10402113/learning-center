安裝 JSM Skills System

Step 1/5 · JSM Skills System：安裝與九步驟地圖

學習目標

完成安裝後，你能找到九個 skill 存放的位置，也能說明「skill 只是一份 Markdown 檔」對安裝有什麼影響：不必註冊帳號，也不必設定 API key。

前言：這次不用填帳號

安裝開發工具時，常常只是漫長流程的第一步：確認 Node 版本、找全域設定位置、註冊帳號，最後再把 API key 貼進某個檔案。一次要裝九個 skill，聽起來似乎也得經過這一套。

但這次不用。前面幾章你已經看過，skill 是一份按需載入的說明書。這裡要做的只是把講師準備好的九份說明書放到你的機器上；安裝方式和一般 CLI 工具不太一樣。

動手前先決定：裝給哪個 agent

這九個 skill 採用 Agent Skills 開放格式，Claude Code、Cursor、Codex 和 Gemini CLI 等支援這個格式的工具都能讀取。安裝前只要決定要裝給哪個 agent。課程以 Claude Code 示範；要安裝給其他 agent，只需調整指令參數。

安裝：其實只有一行指令

打開終端機，執行下面的指令。第一段是安裝給 Claude Code；第二段是通用版，會安裝到 .agents/skills，供 Codex 和其他 agent 讀取。

# Claude Code (installs into .claude/skills, then restart Claude Code)
npx skills@latest add jsmastery-pro/skills -a claude-code

# Generic .agents/skills, read by Codex and other agents
npx skills@latest add jsmastery-pro/skills

這裡由 npx skills 這個安裝器負責安裝。add jsmastery-pro/skills 指定要安裝的來源；-a claude-code 則指定安裝對象是 Claude Code。有加這個參數，安裝器就不必再詢問要裝給哪個 agent；沒加的話，它會改用互動方式詢問。

安裝精靈會問你三件事

執行指令後，安裝器會依序詢問幾個問題。講師示範的流程如下：

  1. 是否安裝 skills 安裝器。這是在確認你同意使用 npx skills，同意後即可繼續。
  2. 要安裝哪些 skill。清單列出接下來會用到的九個 skill；全選後按 Enter。
  3. 要安裝給哪個 agent。只有未加 -a 參數時才會詢問。前面的指令已用 -a claude-code 指定 Claude Code，因此這一步會略過。

選完後，安裝器就會把這些 skill 裝到全域位置。講師也提到，示範當下這九個 skill 的風險標記都是最低等級，可以安心安裝。若日後有 skill 被標記為中或高風險，這也可能是正常變動；回報後會再確認原因。

東西裝到哪去了

全域安裝不會把 skill 放進目前的專案資料夾。以 Claude Code 為例，它們會安裝到全域 skills 目錄 .claude/skills/。打開這個資料夾，就會看到九個子資料夾，每個裡面都有一份 SKILL.md。

.claude/skills/
├── scope/SKILL.md
├── audit/SKILL.md
├── architect/SKILL.md
├── develop/SKILL.md
├── check/SKILL.md
├── test/SKILL.md
├── document/SKILL.md
├── sync/SKILL.md
└── debug/SKILL.md

如果沒有指定安裝路徑，安裝器會使用這個位置。你也可以把安裝好的 skills 資料夾 commit 到專案裡，讓團隊共用同一套流程；之後談團隊協作時會再提到這個做法。

「skill 只是 markdown」是什麼意思

看到這九個資料夾，就能理解為什麼安裝不需要帳號或 API key。每個 skill 都是由一個或多個純文字檔組成，SKILL.md 裡寫著要給 agent 讀取的指示。安裝時，只要把這些檔案複製到 agent 找得到的位置。

有些 skill 除了 SKILL.md，還會附上 modes/ 或 patterns/ 等資料夾，提供特定情境需要的補充說明。這也呼應前面學過的概念：skill 是一整個資料夾，而 SKILL.md 是最核心的入口。

小結

安裝這九個 skill，只要執行一行 npx skills@latest add jsmastery-pro/skills -a claude-code，再回答安裝精靈的問題即可。全域安裝後，它們會放在 agent 的 skills 目錄，不會自動進入你的專案資料夾。每個 skill 都是一個資料夾，裡面有一份 SKILL.md；不需要帳號或金鑰，因為這些檔案只是寫給 agent 讀的 Markdown 指示。

安裝只是把工具準備好，接下來還要弄清楚：九個 skill 分別在什麼時候使用，又該如何串成一套流程？下一節會先回答一個常見疑問：這套設計是不是只反映某個人的個人偏好？
