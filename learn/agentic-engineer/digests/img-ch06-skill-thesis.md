# L1 overview

A slide card from the "Skills" module that states the thesis of the whole part. Read by OCR from the PNG.

- Definition: a skill is a procedure you kept doing by hand, written down, so the agent runs it instead of you remembering to.
- Context economics: a skill has a short name + description and a long body. The agent reads only the name and description, decides whether the skill applies, and loads the body only if it picks that one. This is the "always-on rent" problem from the context module solved by structure instead of willpower — many procedures available, but you pay for the one in use and two lines each for the rest.
- Division of labour: the skill runs the procedure, you make the calls. It is not a smarter agent and it does not improve the model; it removes the procedural overhead that was burying your judgement, so attention goes to the decisions that were always yours.
