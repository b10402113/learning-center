# L1 overview

- **9. Setup Design System and UI Foundation** — Uses the `architect` skill to turn a vague visual wish into a fully interrogated design spec (spec 0004), choosing "quiet cinema" near-black surfaces, one warm-amber accent, one geometric sans, and dark-only theming. It pins the two product shapes (swipe card, feed pick card), a phone-first app shell with a bottom tab bar, three swipe outcomes (like / dislike / skip), Motion for drag physics, and a native-feel/PWA toolkit. `develop` then builds tokens, fonts, shadcn primitives, skeletons, the deck and pick card, and a gated design route, self-tests with Playwright, and fixes a real shell-height defect before the learner reviews it on desktop and mobile.
- **10. Update the Design System** — When the generated look feels too plain, the learner passes UI-kit screenshots back in and re-architects instead of patching. The session is *compacted*, not cleared, so the agent keeps the prior spec while adopting the references: white primary action, violet-to-magenta brand gradient, amber demoted to star ratings only, icon-only tab bar with dot, new composition primitives (full-bleed hero with gradient scrim, horizontal rail, glass panel, star rating), and a backdrop path added to the catalog. Re-running `develop` lands a visibly more modern app, and the spec is only closed by `check-verify`.
