# L1 overview

- **1. Scope Architecture Skills** — Runs the greenfield kickoff end to end: installs the skill pack, turns a one-line idea ("build me a movie recommendation app") into a scoped product through a structured interview, then uses the architect skill to decide the stack and write a decision spec. The scope interview settles the MVP (sign-in, Letterboxd CSV import or swipe onboarding, feed with per-pick reasons, vibe search), the platform (web app plus marketing site), and the intelligence ceiling (taste profile plus an LLM writing reasons, not a trained recommender), and it explicitly defers watchlist-adjacent extras, social, billing, analytics, and accessibility. The architecture interview then makes each call deliberately: single full-stack Next.js 16 app, Supabase Postgres, Drizzle, Supabase Auth, Vercel AI SDK with Sonnet for vibe parsing and Haiku for reasons, pgvector with an HNSW index, Inngest for import/embedding jobs, Vercel hosting, Tailwind v4 plus shadcn/ui, Zod, TMDB as the catalog source, and OpenAI text-embedding-3-small. A second model cross-checks the spec and finds six real defects (an inert RLS backstop, prepared-statement breakage on the Supabase pooler, an over-claimed email justification, unnamed Inngest connections, and others) which are all applied before the spec is accepted.
- **2. Stack Tooling** — Turns the accepted spec into a running project: the develop skill scaffolds Next.js into a scratchpad, writes the env example, passes a production build, and serves a 200 on localhost. The audit phase then captures project-wide conventions into AGENTS.md/CLAUDE.md — functional style, feature-based folders, Biome over ESLint+Prettier, pre-commit lint/format/typecheck, no test suite, no CI, Git handled by the workflow — and the tooling phase installs Biome plus Lefthook and mechanically enforces the spec's import ban on the raw DB handle. The lesson's spine is drift control: when the author drops tests, the agent pushes back on what then protects ownership scoping, and the answer is a scoped query helper recorded in the spec instead of an untested promise. The remaining sync/scope passes reconcile scope, architecture, and AGENTS.md, the repo is pushed to GitHub with main plus a feature branch, and the project is cleared for the data model.
