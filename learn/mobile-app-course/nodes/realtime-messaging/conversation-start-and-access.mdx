<LearningGoal>
能用 start 建立或重用唯一的對話，並用 requireConversation 擋下非參與者與不可用帳號。
</LearningGoal>

## Lesson

用 start 以排序後的參與者配對找到或建立唯一對話並初始化兩列 inbox，再用 requireConversation 在任何讀寫前確認呼叫者是參與者。
