<LearningGoal>
能判斷一份 PR 是否已大到人眼無法逐行審查，並說明為什麼這種規模的改動需要結構化的 AI 審查輸出。
</LearningGoal>

## Lesson

規模本身就是一個獨立的問題：上萬行的 PR 無法逐行審查，而「能跑」只代表正常路徑沒壞、不代表沒人能繞進去；讓審查重新可行的不是更努力，而是嚴重度排序、Change Stack 與安全清單這類結構化輸出。
