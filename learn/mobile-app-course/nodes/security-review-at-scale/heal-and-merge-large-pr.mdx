# 修完、驗證、合併

<LearningGoal>
平行套用修復、二次 commit，驗證後合併回 master。
</LearningGoal>

## Lesson

替每一則要修的問題開獨立 session、平行套用修復，確認無誤後在同一個 branch 上 stage、commit、push，讓 PR 累積成兩個 commit；CodeRabbit 的二次複審可等可不等，接著 merge PR 並切回 master 執行 pull 同步。
