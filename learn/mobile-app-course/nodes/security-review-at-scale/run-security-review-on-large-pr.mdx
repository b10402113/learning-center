<LearningGoal>
能把上萬行的改動開成一條分支與 PR，讓 CodeRabbit 完成 review 與安全掃描，並讀出它整理好的安全問題清單與 Change Stack。
</LearningGoal>

## Lesson

把上萬行改動集中到一條分支（動手前先確認 .env 已被 gitignore）、commit、推上遠端開 PR，讓 CodeRabbit 完成 review 與安全掃描（約十分鐘），再依「安全清單 → critical 行內註解 → Change Stack」的順序讀成一張可用清單，並保留彙整好的修正 prompt。
