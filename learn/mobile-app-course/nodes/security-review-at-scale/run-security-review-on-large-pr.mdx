# 在大型 PR 上跑安全審查

<LearningGoal>
把上萬行改動開成 PR，讓 CodeRabbit 產出安全清單與 Change Stack。
</LearningGoal>

## Lesson

在 master 之外開一個描述性 branch（如 `web-and-api`），stage、commit、publish 後於 GitHub 建立 PR；先確認規模，再依序讀 CodeRabbit 的 summary 與逐檔 walkthrough、打開 Change Stack 看分類、進安全區塊鎖定 major findings，最後複製可貼給 AI agent 的修復指令。
