<LearningGoal>
能說出 Expo Observe 量的是哪幾個真實使用者指標（啟動、JS 載入、首屏、可互動時間），並解釋為什麼「在我手機上很順」不能代表數千台裝置上線後沒問題。
</LearningGoal>

## Lesson

Expo Observe 量的是真實使用者端的啟動時間、JavaScript 載入、首屏與可互動時間。因為它跨裝置、OS 與網路條件長期比較，某次更新讓啟動悄悄變慢時，你能看見的是「隨時間變化的退步」，而不是「我這台手機現在跑起來還行」這種沒有代表性的印象。
