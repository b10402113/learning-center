<LearningGoal>
能說明 Sentry agent tracing 追蹤哪些指標（token、成本、延遲、工具呼叫、錯誤率），以及為什麼 AI 功能要用獨立的 Sentry 專案、並在保留指標的同時把病歷內容擋在 gen_ai span 之外。
</LearningGoal>

## Lesson

Agent tracing 追蹤的是 AI 功能的 token 用量、成本、延遲、工具呼叫與錯誤率。做法是在 Next.js 端用 `Sentry.instrumentOpenAiClient` 產生 gen_ai span，用 `setConversationId` 把同一條對話串起來，並用獨立的 Sentry 專案接住這些資料；同時關掉 `genAI` 的 inputs / outputs，讓指標留下、病歷內容不進 Sentry。
