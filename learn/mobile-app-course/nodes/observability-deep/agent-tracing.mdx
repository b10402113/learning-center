<LearningGoal>
解釋 Sentry agent tracing 捕捉哪些東西（token 用量、延遲、工具呼叫、錯誤率、使用者輸入），以及它為什麼要用獨立的 Next.js Sentry 專案、又要關掉哪些資料收集才不會夾帶病歷。
</LearningGoal>

## Lesson

Agent tracing 用獨立的 Next.js Sentry 專案追蹤 AI 的 token、延遲、工具呼叫、錯誤率與使用者輸入；它把身分與內容拆開，只帶 id 與 conversationId，並整類關閉生成式 AI 的輸入輸出以守住病歷。
