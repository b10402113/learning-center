# 建立 Expo 專案與 NativeWind

## Learning goal

scaffold 出乾淨的 Expo app、reset demo、裝好 NativeWind 並在模擬器跑起來

## Steps

1. [[learn/mobile-app-course/nodes/expo-scaffold-nativewind/scaffold-expo-app|用 create-expo-app 建立專案]] — 在目前資料夾 scaffold 出 Expo 專案，看懂它生了哪些檔案並開進模擬器
2. [[learn/mobile-app-course/nodes/expo-scaffold-nativewind/reset-to-blank|reset-project：把範例清成空白]] — 用 reset script 移除 starter 範例，得到單一畫面的乾淨起點（after step 1）
3. [[learn/mobile-app-course/nodes/expo-scaffold-nativewind/nativewind-mental-model|NativeWind 是什麼：Tailwind 怎麼跑進 React Native]] — 理解 className 如何被翻成 RN 的 style，以及為何要動到多個設定檔（after step 2）
4. [[learn/mobile-app-course/nodes/expo-scaffold-nativewind/nativewind-setup|安裝與接線 NativeWind]] — 安裝套件並接好 tailwind/babel/metro/global.css（after step 3）
5. [[learn/mobile-app-course/nodes/expo-scaffold-nativewind/run-and-verify-styling|跑起來並確認樣式生效]] — 用 className 改畫面、驗證 hot reload，排除樣式沒出現的原因（after step 4）

## Lesson

規劃完成之後，第一個要動手的時刻來了：把 `plan.md` 變成一個真的能在手機上跑起來的空專案。這個節點處理的不是功能，而是「地基」——用 `create-expo-app` 在目前資料夾長出專案，跑一次 `reset-project` 把 Expo 附的範例畫面清乾淨，接著裝上 NativeWind，讓之後每一張畫面都能用 Tailwind 的 className 來寫。這五步走完，你會得到一個能在模擬器跑、存檔即時更新、而且 `className="..."` 真的會生效的空白 Expo app。它同時也是你之後在 Cal AI 這條 pipeline 上反覆使用的工作環境：先把地基打好，後面設計到 UI、登入、資料庫的每一步才有地方落腳。
