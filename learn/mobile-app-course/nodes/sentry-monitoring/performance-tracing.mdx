# 用 tracing 找出慢在哪一段

<LearningGoal>
能解釋 tracing 與 error reporting 的差別、span 與 transaction 的階層關係，並知道在 Expo app 裡開啟 tracing 需要的取樣率與 wrapper 設定。
</LearningGoal>

## Lesson

Error reporting 只在出錯時出聲，tracing 則在每次執行時記錄效能；一個 transaction 是一整趟操作，內含可嵌套的 span，能看出每一段耗時與瓶頸。在 Expo 裡靠 `tracesSampleRate`、React Navigation 整合與 `Sentry.wrap` 開啟，取樣率是成本槓桿，部分指標需要 dev build 才量得到。
