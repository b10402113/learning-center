# 安裝並設定 Sentry：DSN、source map 與 native rebuild

<LearningGoal>
能在 Expo app 裡建立 Sentry 專案、把 DSN 放進 `.env`、用 org auth token 設定 source map 上傳，並在新增 native module 後重建 dev build，讓 SDK 真的開始回報。
</LearningGoal>

## Lesson

接 Sentry 的流程：建立 React Native 專案拿 DSN、把 wizard 指示交給 agent 安裝、DSN 進 `.env`、建 org auth token 用 EAS 存 secret 以還原 source map；初始化用取樣率控制資料量、遮罩 dev 放寬 production 收緊，最後因為 Sentry 是 native module，務必重建 dev build。
