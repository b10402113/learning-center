# Sentry logs 與 console.log：什麼時候用哪個

<LearningGoal>
能判斷什麼情況該用 console.log、什麼情況該用 Sentry 的結構化 logs，並說出 log level、tag 與「logs 連回 errors / traces / replays」在實務上解決了什麼。
</LearningGoal>

## Lesson

判準是「這行 log 是開發時看還是上線後要回頭查」：開發除錯用 `console.log`，上線需要查的事件用 Sentry 結構化 logger；後者存在雲端、可用 trace 到 fatal 六個等級與 tag 搜尋、並自動連到 error/trace/replay，但高頻迴圈與含敏感資料的訊息不該無腦上傳。
