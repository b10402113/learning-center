# 用測試頁驗證並在 Dashboard 判讀錯誤

<LearningGoal>
能做出一個會刻意丟錯的測試頁，確認錯誤與 session replay 真的進到 Sentry，並在 Issue 頁面讀懂裝置、code 區塊、breadcrumbs、replay 與 trace，找到問題後把測試頁移除。
</LearningGoal>

## Lesson

用一個刻意丟錯的測試頁把錯誤管線走通：涵蓋 render、事件處理、promise rejection 等不同形狀，用命名過的錯誤類別與 tag/context/fingerprint 讓 issue 可辨識、可分群；再用 Dashboard 的訊息、裝置、程式碼區塊、breadcrumbs、replay、logs 與 traces 讀懂一則 Issue，確認後移除測試頁。
