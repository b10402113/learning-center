# 把使用者回饋接進 Sentry

<LearningGoal>
能在 app 裡加入 Sentry 的 feedback widget，讓使用者送出姓名、email 與問題描述，並在 Dashboard 的 User Feedback 找到回饋、理解它如何跟錯誤串在一起。
</LearningGoal>

## Lesson

在 `Sentry.init` 掛上 `feedbackIntegration`、於設定或個人頁放一顆按鈕呼叫 `Sentry.showFeedbackWidget()`，讓使用者直接送出姓名、email 與描述；回饋會落在 User Feedback 並可連結對應錯誤，測試回饋自動歸為 spam，重點是接了要記得定期處理。
