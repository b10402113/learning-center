<LearningGoal>
能把 plan.md 轉成 UI 生成 prompt，跑出整份 app 的 UI 設計，並拆出 design system 與各畫面參考圖，知道 design/ 與 assets/images/ 各放什麼。
</LearningGoal>

## Lesson

先有看得見的設計，才談得上做得對不對：從 plan.md 產生 UI 生成 prompt，跑出整份設計，第一版靠參考圖與限制迭代收斂，最後拆出 design system 與各畫面參考圖放進 `design/`，runtime 資產放進 `assets/images/`。
