<LearningGoal>
能在後端還不存在時，用假資料（含空狀態）先把整個 UI 建出來，之後再把真資料換進去。
</LearningGoal>

## Lesson

設計與資料是可以分開的兩條線：後端還沒好之前，先用形狀正確的假資料把整個 UI 做完整，並把空狀態一起設計進去；真資料到位後只換來源，版面幾乎不用動。
