<LearningGoal>
能對一個畫面跑完 screenshot-compare 迴圈：附上參考圖、下 loop 指令、截圖比對、修正、重跑，直到畫面與參考一致到可接受。
</LearningGoal>

## Lesson

把驗收標準交給截圖：附上參考圖，讓 agent 進入「建畫面 → 從模擬器截圖 → 跟設計比對 → 修正 → 重跑」的迴圈，一樣就停、不一樣就繼續；它卡住時自己截圖加一句精準修正，迴圈追求的是一致到可接受，而非像素級全等。
