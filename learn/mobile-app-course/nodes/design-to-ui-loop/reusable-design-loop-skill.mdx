<LearningGoal>
能把「截圖比對到一致」的迴圈寫成 skill / AGENTS.md 慣例，之後一句話就能觸發，不再每次重打。
</LearningGoal>

## Lesson

把重複使用的比對迴圈固化成 skill：請 agent 建立並放到 `.agents/skills/` 與 `.claude/skills/`，對話開始時自動載入，之後一句話就能觸發；專案層級的長期規則則寫進 `AGENTS.md`。
