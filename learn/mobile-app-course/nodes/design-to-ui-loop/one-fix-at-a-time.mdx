<LearningGoal>
能判斷什麼時候該一次只改一個問題、什麼時候該做外科手術式局部修改，並用 design system 讓畫面變體維持一致。
</LearningGoal>

## Lesson

修改要一次一項還是整批處理，取決於它們會不會互相牽動：可能互相影響的視覺修正一次只改一項，照文件執行的機械步驟整批交給 agent；只改局部時明確說出「只動這裡、其餘保留」，生成新變體時附上 design system 維持風格一致。
