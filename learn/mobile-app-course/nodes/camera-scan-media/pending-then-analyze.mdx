<LearningGoal>
說清楚為什麼餐點照片要先落成一列 analyzing 狀態，再交給背景 task 分析，並能追出每個出口如何把狀態收斂到 completed 或 failed。
</LearningGoal>

## Lesson

耗時的 AI 分析不能卡在請求路徑上，所以要拆成非同步管線：API route 快速完成上傳 ImageKit、建立預設為 analyzing 的 meals 列、觸發 analyze-meal task、記下 run id 並回傳 meal、runId、publicAccessToken；背景 task 用結構化輸出請視覺模型看圖，三條出口分別是 not-food 刪列、成功寫回欄位並標 completed、重試耗盡由 onFailure 標 failed，每條都必須把列移出 analyzing。
