<LearningGoal>
把 base64 照片安全地送進 ImageKit，讓 private key 留在 server，並用檔名前綴與 transform 同時解決刪除與尺寸問題。
</LearningGoal>

## Lesson

照片上傳全程在 server：private key 用環境變數注入、只被 server 模組 import，用 Basic 認證呼叫 ImageKit 上傳端點，回傳的 url 才寫進資料庫；檔名取 `meal-<userId>-<時間戳>` 讓刪帳號時能以前綴一次清光（含 not-food 留下的孤兒檔）；傳 base64 是因為原生 fetch 讀不到磁碟檔案 part；尺寸靠 ImageKit transform 即時產生，顯示用原圖、送模型的那份縮到 1024 寬省 token。
