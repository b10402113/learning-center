<LearningGoal>
能用「分批 + 設計參考 + 自我驗證迴圈」的流程，讓 agent 把多頁 onboarding 一次做完，並知道為什麼 mockup 只能當參考、題目要回到 `plan.md`。
</LearningGoal>

## Lesson

多頁 onboarding 要分批交給 agent（例如一次五頁），先清掉 mockup 上不該存在的元素，再把設計稿與 `plan.md` 分開餵：前者決定長相，後者決定題目。實作用驗證迴圈逐頁比對，再用自動走訪確認流程串得起來；完成的標準是你比對過確實一致，而不是 agent 回報完成。
