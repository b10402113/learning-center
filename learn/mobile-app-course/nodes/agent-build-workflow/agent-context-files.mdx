## Lesson

AGENTS.md 與 CLAUDE.md 是放在 repo 裡、session 開始就自動載入的專案說明書；慣例是把「永遠／絕不」這類規則集中在跨工具的 AGENTS.md，CLAUDE.md 只留一行引用它，並在 agent 重複犯同一個錯時補上新規則。
