<LearningGoal>
能跑起 build → 截圖 → 對照參考圖 → 修正的迴圈，直到模擬器畫面與設計一致。
</LearningGoal>

## Lesson

self-check 的核心是截圖比對迴圈：跑起 <code>npx expo start</code>、把參考圖放進 <code>design/</code> 並在指令裡指名、叫 agent 只做一個畫面，再要它截圖、比對、重做到一致；回饋一次只講一個落差，新增 native module 一定得用 <code>npx expo run ios</code> 重建，收斂標準是「夠接近」而非像素級相同。
