能說出 agent 建造迴圈的五個階段各自產出什麼、為什麼這個順序不能跳過，以及 agent 在哪裡接手。
</LearningGoal>

## Lesson

用 AI agent 蓋 app 的核心是一條會反覆繞的建造迴圈：plan 把想法逼成 <code>plan.md</code> 規格，build 一次只做一個畫面，self-check 用截圖與資料庫實測證明功能能跑，review 讓 AI 工具換個視角抓錯，commit 把可用狀態固定下來；跳過任何一段，錯誤都會被帶進下一圈並放大。
