面對一個新工具或重複流程時，能判斷該用 skill、貼官方文件、Context7 或開平行 instance。
</LearningGoal>

## Lesson

餵 context 的手段要對應知識類型：會重複的流程寫成 skill，第三方套件的操作方式第一次用時貼官方文件，公開且持續更新的 API 交給 Context7，專案內部慣例則寫進 AGENTS.md；平行 instance 只適合兩件不共用檔案的獨立工作。
