# reset-project：把範例清成空白

<LearningGoal>
能跑 npm run reset-project 把 Expo starter 的範例程式碼清掉，說出這支腳本實際搬走與重建了哪些檔案，並確認畫面只剩一張空白頁。
</LearningGoal>

## Lesson

Expo starter 附的範例畫面不是你的產品，留著會讓 agent 抄錯寫法；用 `npm run reset-project` 把 `src/` 與 `scripts/` 搬走或刪掉，讓它重建只有 `index.tsx`（一行置中文字）與 `_layout.tsx`（空的 `<Stack />`）的 `src/app/`，這支腳本不可逆，只能在還沒寫自己的程式碼之前執行。
