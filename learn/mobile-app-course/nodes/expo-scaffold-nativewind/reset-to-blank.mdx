# reset-project：把範例清成空白

<LearningGoal>
能跑 npm run reset-project 把 Expo starter 的多餘檔案清成單一畫面，並說明 archive 與 delete 兩種選擇的差別。
</LearningGoal>

## Lesson

跑 `npm run reset-project`，把 Expo starter 的 `src` 與 `scripts` 搬到 `example/` 或直接刪除，腳本再重建只含 `index.tsx` 與 `_layout.tsx` 的 `src/app`；重啟後畫面只剩一行字，你就得到一個乾淨的空白起點（這是有破壞性的操作，只能在新專案上做）。
