# 安裝與接線 NativeWind

<LearningGoal>
能照著安裝 nativewind 與 tailwindcss、建立 tailwind.config.js 與 global.css、接好 babel.config.js 與 metro.config.js，並在 root layout 匯入 global.css，完成 NativeWind 的設定。
</LearningGoal>

## Lesson

安裝 `nativewind` 與 `tailwindcss` v3、建立 `tailwind.config.js`（content 指向 `./src/**`、載入 `nativewind/preset`）與 `src/global.css`、接好 `babel.config.js`（`jsxImportSource: 'nativewind'` 與 `nativewind/babel`）與 `metro.config.js`（`withNativeWind` 指定 global.css），並在 root layout import `global.css`，最後用 `npx expo start -c` 清快取重啟。
