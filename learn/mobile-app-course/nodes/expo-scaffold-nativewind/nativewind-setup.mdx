# 安裝與接線 NativeWind

<LearningGoal>
能照著安裝 nativewind 與 tailwindcss，並把 tailwind.config、babel.config、metro.config 與 global.css 四處接好，讓 className 被編譯進 bundle。
</LearningGoal>

## Lesson

照著接力站施工：安裝 `nativewind` 與 `tailwindcss`、建立 `tailwind.config.js` 與 `global.css`、修改 `babel.config.js` 與 `metro.config.js`、補上 `nativewind-env.d.ts` 並在根 layout 匯入 CSS，最後用 `npx expo start --clear` 重啟，`className` 才會真的被編進 bundle。
