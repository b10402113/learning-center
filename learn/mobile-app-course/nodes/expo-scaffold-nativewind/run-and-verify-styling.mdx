# 跑起來並確認樣式生效

<LearningGoal>
能用一個 className 改畫面、存檔後驗證 hot reload 生效，並在樣式沒出現時依序排查快取、設定檔與 CSS 引入位置。
</LearningGoal>

## Lesson

用一個明顯的 `className`（例如把背景改成 `bg-yellow-200`）改畫面、存檔驗證熱更新，因為未編譯的 class 不會報錯；樣式沒出現時依序查：清快取重啟、Tailwind 的 `content` 範圍、Metro 的 `input` 路徑、根 layout 的 CSS 匯入，以及 class 名稱是否被動態拼接掉。
