# 跑起來並確認樣式生效

<LearningGoal>
能在模擬器用 className 改畫面並靠存檔即時更新驗證 NativeWind 生效，並在樣式沒出現時依序檢查匯入、content glob 與 Babel/Metro 設定。
</LearningGoal>

## Lesson

在 `index.tsx` 用 className 寫樣式並存檔，看模擬器有沒有變成預期樣子來驗證整條管線；沒生效就依序檢查 root layout 的 global.css import、`tailwind.config.js` 的 content glob、Babel/Metro 設定，並記得設定檔改動要清快取重啟，而這個「改、存、看」的循環之後會用在做每一張畫面上。
