# NativeWind 是什麼：Tailwind 怎麼跑進 React Native

<LearningGoal>
能說出 React Native 為什麼沒有網頁那種 CSS，以及 NativeWind 如何把 Tailwind 的 className 轉譯成 RN 的 style 物件，並解釋為什麼這個轉譯需要 Babel、Metro、Tailwind 設定與 global.css 一起配合。
</LearningGoal>

## Lesson

React Native 沒有 DOM 與瀏覽器，樣式只能是傳給元件的 JS 物件，所以網頁的 Tailwind 不能直接搬過來；NativeWind 是建置階段的翻譯官，把 className 翻成 RN 的 style 物件，因為 RN 執行環境沒有瀏覽器能即時套用樣式，翻譯才必須提前在 Babel、Metro、`tailwind.config.js` 與 `global.css` 這些環節完成。
