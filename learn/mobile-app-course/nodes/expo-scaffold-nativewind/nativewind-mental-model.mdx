# NativeWind 是什麼：Tailwind 怎麼跑進 React Native

<LearningGoal>
能解釋 NativeWind 如何把 className 翻成 React Native 的 style，並說出為什麼這件事需要同時動到 tailwind、babel 與 metro 三個設定檔。
</LearningGoal>

## Lesson

React Native 只懂 `style` 物件、Tailwind 只產生 CSS，兩者中間需要一個翻譯層——NativeWind：Tailwind 掃描原始碼產生 CSS、Babel 改寫 JSX 讓 `className` 被辨識、Metro 把 CSS 打包進 bundle。會動到多個設定檔，是因為它在串接三個獨立工具，而不是打開一個開關。
