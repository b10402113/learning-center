# 用 create-expo-app 建立專案

<LearningGoal>
能在空資料夾用 create-expo-app 生出一個 Expo 專案，說出它生了哪些檔案，並把第一個預設畫面開進 iOS 模擬器。
</LearningGoal>

## Lesson

在目前的空資料夾用 `create-expo-app`（指令結尾加一個 `.`）生出 Expo 專案，回答 SDK 版本提問後，用 `npx expo start` 搭配 `i` 或 `a` 開進模擬器；你會看到 Expo 附的多 tab 範例畫面，也看懂 `package.json`、`app.json` 與 `src/app` 各自的位置——這就是接著要清掉的起點。
