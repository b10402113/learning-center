# 用 create-expo-app 建立專案

<LearningGoal>
能在目前的空資料夾用 create-expo-app scaffold 出一個 Expo 專案，說出它生成的關鍵檔案各是什麼，並在 iOS/Android 模擬器把它開起來。
</LearningGoal>

## Lesson

用 `npx create-expo-app@latest .`（別忘了最後的點）在空資料夾生成 Expo 專案；它會長出以 `src/app/` 為核心的檔案樹（`_layout.tsx` 是路由外框、`index.tsx` 是首頁、`package.json` 的進入點是 Expo Router），用 `npx expo start` 按 `i`／`a` 就能在模擬器跑起來，模擬器向本機 Metro 取得 JS，改檔存檔即時更新。
