<LearningGoal>
能讀懂 working_hours、time_off、services、dentist_services 與 appointments 的欄位與關聯，並說明每個設計正在解決預約系統的哪個問題。
</LearningGoal>

## Lesson

working_hours 存的是每週重複的牆鐘作息，time_off 與已約的 appointments 是絕對瞬間、實作時合併成同一種忙碌區間；services 提供療程長度、dentist_services 用多對多回答誰會做，appointments 則用 enum 鎖狀態、由伺服器算 endsAt、用 restrict 外鍵保護歷史。
