<LearningGoal>
能說明 GET /api/availability 與 POST /api/appointments 為什麼要共用同一份 loadSchedulingInputs 與 classifySlot，並把這個接線做出來。
</LearningGoal>

## Lesson

讓 `GET /api/availability` 與 `POST /api/appointments` 共用同一份 `loadSchedulingInputs` 與同一個 `classifySlot`：讀取端把資料庫載成引擎輸入並算出時段，寫入端在寫入前重跑同一套引擎，只接受讀取端會提供的時間，並把 `taken` 轉成 409、`invalid` 轉成 400。時長由伺服器依服務推導，因此使用者無法自己捏造一個預約時間。
