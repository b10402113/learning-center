<LearningGoal>
能照著把 GET /api/availability 與 POST /api/appointments 接到同一份 loadSchedulingInputs 與 classifySlot，讓 API 提供的時段與它接受的時段不會分岔，並正確回傳 409 與 400。
</LearningGoal>

## Lesson

讓 GET /api/availability 與 POST /api/appointments 共用同一份 loadSchedulingInputs 與 classifySlot：endsAt 由伺服器用療程時長算出、改期時排除自己，並把 verdict 的 taken 轉成 409、invalid 轉成 400，讓「提供」與「接受」的時段不會分岔。
