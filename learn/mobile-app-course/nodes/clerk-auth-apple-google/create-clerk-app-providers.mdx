# 建立 Clerk 專案並打開 Google / Apple

<LearningGoal>
能在 Clerk dashboard 建立 app、只打開 Google 與 Apple、選對 Expo quick start 把 publishable key 放進 `.env`，並確定 native applications 已啟用。
</LearningGoal>

## Lesson

在 Clerk 建立 application、只打開 Google 與 Apple 並關掉 Email、啟用 native applications，再把 publishable key 以 `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` 放進被 git 忽略的 `.env`。
