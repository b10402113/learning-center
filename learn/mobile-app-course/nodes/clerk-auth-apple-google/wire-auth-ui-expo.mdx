# 把登入接進 Expo：SDK 設定與登入按鈕

<LearningGoal>
能把 Clerk 的 Expo SDK 設定交給 agent 實作，做出放在 onboarding 尾端的 Google / Apple 登入按鈕，並說出自製原生登入畫面與 Clerk 預製 UI 的取捨。
</LearningGoal>

## Lesson

用 Clerk 的 Expo SDK 在根層包上 Provider、從環境變數讀取 publishable key，並在 onboarding 最後一頁做出會發起 Google / Apple 流程的登入按鈕。
