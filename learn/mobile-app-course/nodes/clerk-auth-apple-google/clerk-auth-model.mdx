# Clerk 與多供應商登入：身分放在哪裡

<LearningGoal>
能說出 Clerk 這類身分驗證服務負責什麼、OAuth 供應商（Google / Apple）在登入流程中扮演的角色，以及為什麼「登入成功」不等於「app 已經拿到使用者資料」。
</LearningGoal>

## Lesson

Clerk 保管的是登入身分、Google / Apple 是負責證明身分的 OAuth 供應商，而「登入成功」不等於你的資料庫已經拿到使用者資料——這條「誰管身分、誰管 app 資料」的分工線，是後面每個步驟的基礎。
