# 身分歸 Clerk，資料歸你：為什麼登入了 DB 還是空的

<LearningGoal>
能說出 Clerk 與 app 資料庫為什麼是兩個各自獨立的身分與資料來源，並解釋登入成功後 DB 仍是空的原因。
</LearningGoal>

## Lesson

Clerk 是身分來源、Postgres 是應用資料來源，兩座倉庫預設互不干涉，所以登入成功後 DB 仍是空的；需要以 `clerk_user_id` 為橋樑，靠 webhook 自動把使用者同步進來。
