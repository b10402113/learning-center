# Webhook 收到之後：直接寫 DB 還是丟背景任務？

<LearningGoal>
能判斷 webhook 的資料庫工作該在 handler 內直接做完、還是丟給 trigger.dev 背景任務，並說出 retry 語意與失敗處理的判準。
</LearningGoal>

## Lesson

用「失敗時想重跑整個 webhook 還是只重跑這一步」、工作的快慢與副作用，以及有沒有另一條保證資料存在的路徑，判斷同步工作該在 handler 內直接做、還是交給 trigger.dev 任務。
