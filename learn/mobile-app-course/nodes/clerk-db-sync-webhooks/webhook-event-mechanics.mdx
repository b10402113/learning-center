# Webhook 是什麼：事件、簽章與重送

<LearningGoal>
能說明 webhook 的事件模型、簽章驗證如何證明事件來自 Clerk，以及為什麼每個已驗證的事件都要回 200 並用冪等鍵防重送。
</LearningGoal>

## Lesson

Webhook 是事件發生時由來源主動送出的 HTTP 通知；每則訊息要用 signing secret 驗簽，並以 `svix-id` 建冪等鍵防止重送造成重複，而只要驗簽通過就一律回 200。
