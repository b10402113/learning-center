# 本機接 Clerk Webhook：ngrok 與簽章密鑰

<LearningGoal>
能在 Clerk 後台建立訂閱 user 事件的 webhook endpoint、用 ngrok 把本機 URL 公開、把簽章密鑰寫進 .env，並把 ngrok 與 Expo 一起跑起來。
</LearningGoal>

## Lesson

用 ngrok 把本機 port 轉成公開網址、在 Clerk 建立訂閱三個 user 事件的 endpoint、把 signing secret 寫進 `.env` 並重啟 server，再用 Expo／ngrok／trigger.dev 三個終端機驗證事件真的送達。
