# 實作同步：signature → task → upsert/delete，並端到端驗證

<LearningGoal>
能寫出驗簽後觸發背景 task 的 Clerk webhook handler、用 upsert 冪等地同步 created/updated、用 cascade delete 處理 deleted，並用刪帳號再註冊的方式端到端驗證。
</LearningGoal>

## Lesson

寫出驗簽後觸發 trigger.dev 任務、以 `clerk_user_id` 為衝突目標 upsert、刪除靠外鍵 cascade 的同步鏈路，並用「刪帳號再註冊」同時檢查 Clerk 與資料庫來端到端驗證。
