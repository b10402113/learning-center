<LearningGoal>
能讀懂 users 與 meals 兩張表的欄位、關聯、索引與時間設計，並說出每個設計決定解決了什麼問題。
</LearningGoal>

## Lesson

users 一對多 meals：用 enum 鎖住合法值、用獨立主鍵搭配 clerkUserId 對應外部身分、用 date 存沒有時區的生日、用 timestamptz 存絕對時間，meals 靠 cascade 外鍵處理刪除，並用 (userId, loggedAt desc) 索引服務首頁查詢，整體以公制加 UTC 儲存、只在顯示時換算。
