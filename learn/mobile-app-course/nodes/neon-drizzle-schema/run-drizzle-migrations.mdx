</LearningGoal>

## Lesson

edit schema → `db:generate` → `db:migrate` 是可重複的建表迴圈：generate 比對最近的 snapshot 產生帶編號的 SQL 與 meta 檔，migrate 才把變更依序套用到資料庫；模型要演進時新增一份 migration（例如用 ALTER TYPE 加 enum 值），而不是回頭改已套用的舊檔。
