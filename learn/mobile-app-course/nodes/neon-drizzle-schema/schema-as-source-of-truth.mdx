<LearningGoal>
能說出為什麼資料模型要用 TypeScript 定義成 schema，以及為什麼它會成為 mobile app 與背景 task 共用的單一真相。
</LearningGoal>

## Lesson

schema-as-code 讓手機 app 與背景 task 共用同一份資料定義，欄位一改兩邊同時更新、型別不符在編譯期就現形；而 schema 決定的是「資料長什麼樣子」，真正讓資料庫改變的是 migration，兩件事要分開看。
