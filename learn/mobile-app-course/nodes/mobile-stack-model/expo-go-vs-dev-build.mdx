<LearningGoal>
能在動手前判斷一個 app 該用 Expo Go 還是 development build，並說出判斷的依據是「有沒有用到 Expo Go 內建不了的 native module」。
</LearningGoal>

## Lesson

判準只有一條：功能清單裡只要出現一個 Expo Go 內建不了的 native module，就必須用 development build；全是純 JavaScript 畫面時，先用 Expo Go 起步最快。真正的陷阱是新增 native module 後忘了重建。
