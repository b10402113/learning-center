<LearningGoal>
能解釋 native module 是什麼、為什麼新增一個 native module 之後必須重新跑原生建置，並分辨 Metro 的 JS 熱更新與原生重建各更新了哪一層。
</LearningGoal>

## Lesson

native module 是用原生語言寫好、包成 JS 介面的模組；JS 層由 Metro 打成 bundle 可以熱更新，但新增 native module 改變了 app binary 的組成，必須用 npx expo run ios 重新編譯與安裝——第一次慢，之後只改 JS 就快。
