<LearningGoal>
能區分 React Native 與 Expo 各自負責什麼，並說出 Expo 提供的 SDK、CLI、Expo Router 與 EAS 各自在開發流程的哪個位置。
</LearningGoal>

## Lesson

React Native 是引擎，Expo 是包住它的整條工具鏈：CLI 與 create-expo-app 負責生出與啟動專案，SDK 提供一組相容套件，Expo Router 提供檔案式路由，EAS 負責雲端建置與上架；Expo Go 只是其中練習用的通用容器。
