<LearningGoal>
能說清楚 React Native 的 JavaScript 跑在哪裡、畫面怎麼變成手機上的原生元件，以及為什麼它跟瀏覽器裡的 React 是兩套不同的執行環境。
</LearningGoal>

## Lesson

React Native 保留 React 的元件樹與資料流，但把渲染終點從瀏覽器 DOM 換成 iOS / Android 原生畫面；app 邏輯大多在 JS 這一側，碰到手機硬體或系統能力時就靠另一側的 native module——這條界線是後面「Expo Go 不夠用」「裝套件要重建」的共同根源。
