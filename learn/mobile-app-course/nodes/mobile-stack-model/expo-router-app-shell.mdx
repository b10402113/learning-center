<LearningGoal>
能讀懂一個 Expo Router 專案的 root layout：檔案式路由怎麼對應畫面、Provider 為什麼要一層層疊起來，以及 Stack.Protected 如何依登入狀態分流。
</LearningGoal>

## Lesson

Expo Router 用 app/ 目錄的檔案結構當路由地圖，每層的 _layout.tsx 是該層共用的外框；root layout 把 Sentry、Clerk、Convex 一層層疊起來讓內層取用，再用 Stack.Protected 依登入狀態決定看得到哪些畫面——之後每個 app 都從這個骨架長出來。
