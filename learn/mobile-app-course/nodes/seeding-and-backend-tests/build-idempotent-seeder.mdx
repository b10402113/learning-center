<LearningGoal>
用 seedKey、確定性的 postPlan 與分批 action 拆解出一個可重複執行、不重複資料也不弄壞計數器的 seeder。
</LearningGoal>

## Lesson

一份可反覆執行的 seeder 靠三個手法成立：穩定的 `seedKey` 認身分、確定性的 `postPlan` 產生同樣的資料、以及用 internal action 分批複製檔案，讓重跑既不重複資料也不弄壞計數器。
