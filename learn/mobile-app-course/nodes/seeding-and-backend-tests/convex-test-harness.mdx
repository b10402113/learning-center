## Lesson

用 `convexTest(schema, modules)` 起一個記憶體後端，靠 `withIdentity` 切換登入身分、`t.run` 直接檢查底層狀態、`t.fetch` 呼叫 HTTP action，就能在沒有真實資料庫的情況下寫出會過的後端測試。
