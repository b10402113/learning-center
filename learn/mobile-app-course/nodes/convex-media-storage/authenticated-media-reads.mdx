<LearningGoal>
能解釋為什麼「拿到 URL」不等於「有權讀取」，以及 `/media` 如何從登入身分推導可讀的檔案、用 HTTP Range 分段回傳影片。
</LearningGoal>

## Lesson

`/media` 是授權端點：每次請求都從登入身分查出使用者，再由 internal query 依 kind 把貼文、頭像或限動 id 解成 `storageId`，同時檢查帳號狀態與限動是否過期。client 傳的是業務 id 而非 `storageId`，所以猜到 id 也不能直接讀。影片支援 HTTP Range，以 206 與 Content-Range 分段回傳、單次上限 8MB，回應設定 `private, no-store` 避免私人媒體被共用快取。
