<LearningGoal>
能在「信任 client 帶來的檔名與型別」和「server 端重新驗證」之間做出選擇，並為不同用途挑對格式、尺寸與時長限制。
</LearningGoal>

## Lesson

媒體驗證是分工：client 端做早期回饋，server 端做不可繞過的安全邊界。Content-Type、檔名與 picker 回報的 mimeType 都不可信，要讀檔頭 magic bytes 才能確認真格式；大小與時長依 purpose 分開限制，影片時長必須由 server 重新解析；HEIC、HEIF 這類真實裝置格式要納入允許清單，否則 iOS 使用者會大量失敗。
