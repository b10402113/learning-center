<LearningGoal>
能寫出一個通過驗證的 `/upload` HTTP action：在不超過 action 記憶體上限的前提下串流檔案、用 magic bytes 認出真正格式、解析 MP4/MOV 時長，最後把 blob 存進 Convex 並以 internal mutation 綁定。
</LearningGoal>

## Lesson

`/upload` 用 HTTP action：先從登入身分與上傳 id 找回單子，用 Content-Type 與 Content-Length 做早期拒絕，再用 `TransformStream` 邊串流邊限流，避免 50MB 檔案撐爆 action 記憶體；以 32 bytes magic bytes 驗證真正格式，影片用 `videoDuration` 只讀 MP4 box 檔頭算出時長；`ctx.storage.store` 存檔後呼叫 internal `finish` 綁定，綁定失敗或回傳的是別的檔案時一律刪掉這次多存的 blob，避免孤兒。
