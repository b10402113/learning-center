<LearningGoal>
能說出 Convex 內建檔案儲存（`_storage`）如何運作、storageId 與資料庫文件的關係，以及它跟 S3／ImageKit 這類外部物件儲存的根本差異。
</LearningGoal>

## Lesson

Convex 把檔案本體放在內建的 `_storage` 檔案庫，資料庫文件只存一個 `storageId` 當指標；store / get / delete 是全部介面，metadata 要走 `ctx.db.system.get` 讀。`storageId` 不是公開網址，`ctx.storage.getUrl` 產生的是「有連結就能讀」的能力網址，只適合公開內容，私人媒體要靠授權端點逐次驗身分。
