# Task 是什麼：schemaTask 的 id、schema 與 run

<LearningGoal>
能說清楚一個 trigger.dev task 由 id、schema 與 run 組成，並解釋它和一般 async function 在執行生命週期上的差別。
</LearningGoal>

## Lesson

一個 Trigger.dev task 由 id、schema 與 run 三個零件組成，每次執行都是一次被登記、可重試、可追蹤的 run，這正是它與一般 async function 的根本差別。
