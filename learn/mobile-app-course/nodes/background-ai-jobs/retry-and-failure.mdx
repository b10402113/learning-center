# 失敗之後：重試語意、退路與標記失敗

<LearningGoal>
能依工作性質決定重試次數與失敗處理策略，並分辨哪些失敗該重試、哪些該有退路或直接標記失敗。
</LearningGoal>

## Lesson

依「失敗重跑是否可能不同、有無確定性退路、有無重複副作用、UI 是否需要知道」來選擇自動重試、公式退路或標記失敗，並記得「不是食物」是成功的 run、不該重試。
