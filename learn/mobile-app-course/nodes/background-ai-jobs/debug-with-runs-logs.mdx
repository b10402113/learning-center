# 用 runs 與 logs 除錯：從 dashboard 追回程式碼

<LearningGoal>
能在 Trigger.dev dashboard 用一次 run 的 payload、logs 與歷次嘗試找出背景任務失敗的原因。
</LearningGoal>

## Lesson

從 worker 與 secret 檢查起，在 Runs 讀取 payload、logs、output 與 attempts，用 logger 把失敗追回程式碼那一行，並分開確認 run 狀態與資料庫狀態是否一致。
