<LearningGoal>
能解釋 Convex reactive query 的運作機制：前端為什麼不用輪詢或手動 refetch，資料變動如何自動推送，以及樂觀更新與 reactive 之間的先後關係。
</LearningGoal>

## Lesson

Convex 查詢是訂閱：後端追蹤依賴、資料變動就重跑並推送，所以 query 必須是確定性的純函式，而樂觀更新負責補上等待後端的那段空窗。
