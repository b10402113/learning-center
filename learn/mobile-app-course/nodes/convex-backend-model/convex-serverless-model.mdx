<LearningGoal>
能說出 Convex 的後端心智模型：為什麼社群功能需要後端、`convex/` 資料夾裡放什麼、query 與 mutation 各負責什麼，以及為什麼開發時要同時開著 Expo 與 Convex 兩個終端。
</LearningGoal>

## Lesson

Convex 把「自己開 API 端點」換成「在 `convex/` 放函式」：query 負責讀、mutation 負責寫，Convex 幫你部署、生成型別，並讓查詢變成即時訂閱。
