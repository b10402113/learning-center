<LearningGoal>
能在 Convex 與自寫 API server（例如 Next.js Route Handlers）之間做出有理由的選擇：講清楚各自的取捨、適用條件與反例，並用檢查表判斷下一個功能該用哪一邊。
</LearningGoal>

## Lesson

以即時互動為主、無複雜 SQL 需求的新功能預設用 Convex；涉及複雜關聯查詢、既有資料庫或多端共用同一份真相時，預設自寫 API 加關聯式資料庫。
