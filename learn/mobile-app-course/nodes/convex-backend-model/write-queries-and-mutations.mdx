<LearningGoal>
能照著 posts.ts 的模式寫出一個 query 與一個 mutation：定義 args validator、用索引查資料、在 server 端推導身分、回傳前端要的 view，並加上 idempotent 寫入與 cascade 清理。
</LearningGoal>

## Lesson

一個 query 的骨架是宣告 args/returns、用索引分頁讀、在後端認身分、整理成 view；一個 mutation 的骨架是先驗證與冪等判斷，再於單一交易寫入並維護計數。
