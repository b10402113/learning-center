# Zod 請求邊界：不信任 client 傳來的欄位

<LearningGoal>
能用 Zod schema 在 handler 入口擋掉不合法輸入，並說明為什麼像服務長度、通話 id 這類欄位要由 server 推導、而不是讓 client 傳。
</LearningGoal>

## Lesson

在 handler 入口用 Zod `parse` 把未知的請求變成可信任的型別，以 `discriminatedUnion` 區分取消與改期，並讓 `endsAt`、`streamCallId`、`canCancel` 這些能由伺服器算出的欄位不交給 client；驗證失敗由 `route()` 轉成 400。
