# Zod 請求邊界：不信任 client 傳來的欄位

<LearningGoal>
能說出 Zod 在 handler 入口驗證了什麼，以及哪些關鍵欄位必須由 server 自己推導、不能相信 client。
</LearningGoal>

## Lesson

Zod 在 handler 入口驗證欄位形狀，但格式合法不等於內容正確；所有權交給守衛、合理性交給商業邏輯，而 `endsAt`、`streamCallId` 這類關鍵欄位一律由 server 自己推導，client 就算想送也沒有欄位可送。
