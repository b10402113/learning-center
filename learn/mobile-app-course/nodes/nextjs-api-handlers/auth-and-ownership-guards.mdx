# requireAuth 與守衛：身分只從 session 來

<LearningGoal>
能解釋 requireAuth、requireStaff 與 requireOwnedPatient 各自擋下什麼，並說出身分為什麼只能從 session 推導。
</LearningGoal>

## Lesson

身分只從 session 推導；`requireAuth` 確認登入並用 upsert 補上 webhook 的時序落差，`requireStaff` 檢查員工角色，`requireOwnedPatient` 把擁有權直接寫進查詢條件，失敗時回 404 以免洩漏資料存在與否。
