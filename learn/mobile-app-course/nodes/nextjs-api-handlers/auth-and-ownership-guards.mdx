# requireAuth 與守衛：身分只從 session 來

<LearningGoal>
能分辨 requireAuth、requireStaff、requireOwnedPatient 各自的職責，並說明為什麼身分必須由 server 從 session 推導、以及別人的資料為什麼回 404 而不是 403。
</LearningGoal>

## Lesson

身分只從 session 推導：`requireAuth` 驗 token 並從 session upsert 使用者、`requireStaff` 以 token 或資料庫任一邊判斷角色、`requireOwnedPatient` 把擁有權檢查收斂成一處，並用 404 取代 403 以免洩漏資料是否存在。
