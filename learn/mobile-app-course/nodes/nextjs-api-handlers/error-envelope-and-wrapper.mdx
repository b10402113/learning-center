# route() 包裝與錯誤信封：讓每個 handler 只留商業邏輯

<LearningGoal>
能說出 route() 包裝把 ApiError、ZodError 與未知例外各自轉成什麼回應，並解釋 json() 為何一律加上 no-store、以及為什麼錯誤訊息不能原樣回傳。
</LearningGoal>

## Lesson

用 `route()` 把 `ApiError`、`ZodError` 與未知例外統一翻譯成一致的 JSON 錯誤信封，`json()` 一律加上 `no-store`，500 不回傳內部細節並以 `scrubQuery()` 清除 PHI，讓每個 handler 只留下商業邏輯。
