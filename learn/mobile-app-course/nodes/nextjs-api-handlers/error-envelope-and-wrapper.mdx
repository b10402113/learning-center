# route() 包裝與錯誤信封

<LearningGoal>
能說明 route() 如何把丟出的 ApiError／ZodError 收斂成一致的 JSON 回應，以及為什麼錯誤不能原封不動回給 client。
</LearningGoal>

## Lesson

`route()` 把每個 handler 包進一個 `try/catch`，讓 `ApiError`、`ZodError` 與未預期錯誤分別變成一致的 JSON 信封，handler 本體只留下商業邏輯；原始錯誤則先洗掉綁定參數，才寫入 Sentry 與 log。
