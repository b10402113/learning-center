# 手機要的 API：Next.js Route Handler 入門

<LearningGoal>
能說出 Route Handler 的檔案位置與 HTTP method 匯出慣例，並解釋手機為什麼只能透過 HTTP API 拿到資料。
</LearningGoal>

## Lesson

Route Handler 是 `app/api` 底下的檔案，資料夾路徑決定網址、匯出的 `GET`／`POST` 決定接受的 HTTP method；手機因為不在伺服器裡、也不能持有資料庫鑰匙，只能透過這層標準 Web 物件的 HTTP API 取得資料。
