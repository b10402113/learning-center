# 手機要的 API：Next.js Route Handler 入門

<LearningGoal>
能說明 Next.js Route Handler 是什麼、檔案與 HTTP method 的對應規則，以及為什麼手機 app 需要一個走 HTTP 的 JSON API，而不是直接讀資料庫。
</LearningGoal>

## Lesson

Route Handler 是 `app/api` 底下的一個 `route.ts`，用匯出的函式名稱對應 HTTP method、用標準 `Request`／`Response` 收送資料；手機不能直接連資料庫，所以需要這層 HTTP API，而同一支 Next.js app 同時服務 dashboard、手機與 webhook，商業邏輯只寫一份。
