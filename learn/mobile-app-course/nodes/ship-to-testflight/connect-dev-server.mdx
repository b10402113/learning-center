# 讓真機上的 app 連上 Metro：dev server 與 tunnel

<LearningGoal>
能在 build 安裝後啟動 Metro dev server、在連不上時改用 `--tunnel`，並把 dev server URL 手動貼進真機上的 dev client 讓 app 啟動。
</LearningGoal>

## Lesson

dev build 只是原生外殼，畫面與 JavaScript 由電腦上的 Metro 提供；執行 `npx expo start` 啟動伺服器，連不上時改用 `npx expo start --tunnel`，再把從 `http` 到 `/direct` 結尾的網址手動貼進 app 的 dev client，就能在真機上跑出介面。
