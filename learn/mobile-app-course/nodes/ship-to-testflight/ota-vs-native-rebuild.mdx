# OTA 熱更新與 native rebuild 的界線

<LearningGoal>
能判斷一個改動該走 OTA（over-the-air）更新、還是必須重新 build 並送審，並說出這條界線背後的判準。
</LearningGoal>

## Lesson

判斷改動能不能走 OTA 只需問一句「有沒有動到 native」：只改 JavaScript 或 UI 可以熱更新、不必重新送審，一旦新增或更動 native module 就必須重新 build 並送審，因為 native 程式碼被編進 App Store 審核的那個二進位檔。
