# dev build、TestFlight 還是正式上架？

<LearningGoal>
能依「誰要測、測什麼、要不要給外人」在 dev build、internal distribution 與 TestFlight 之間做出選擇，並說出 TestFlight 相對於 dev build 的位置。
</LearningGoal>

## Lesson

依「誰要測、要不要即時看到改動」來選：dev build 連著你的伺服器適合開發迭代，internal distribution 給已註冊裝置一個獨立可跑的版本，TestFlight 部署得像已上架、適合邀請外部測試者，production 才是給所有使用者的正式上架。
