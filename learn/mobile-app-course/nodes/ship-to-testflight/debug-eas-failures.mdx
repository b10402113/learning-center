# build 失敗時：用 log 讓 AI 修配置

<LearningGoal>
能在 EAS build 失敗時找到失敗步驟、複製完整 log 交給 AI 取得修法，並在重建前先 commit，套用「貼 log → 修 → 重建」的迴圈。
</LearningGoal>

## Lesson

EAS build 失敗時，到儀表板找到第一個標紅的步驟、取得完整 log 整份貼給 AI 請它找出設定問題，套用修法後先 commit 再重跑建置，把「貼 log、修配置、重新建置」變成可重複的除錯迴圈。
