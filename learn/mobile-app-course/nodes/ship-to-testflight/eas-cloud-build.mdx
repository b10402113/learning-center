# 用 EAS 在雲端出 dev build：從 eas.json 到掃 QR 安裝

<LearningGoal>
能在 Expo 專案裡產生 `eas.json`、註冊 iPhone、用 EAS 在雲端跑出 development build，並掃 QR code 把 build 裝進實機。
</LearningGoal>

## Lesson

雲端建置的流程是切進行動專案、產生 EAS 需要的 `eas.json`、註冊 iPhone、執行 `eas build --profile development --platform ios`，最後掃 QR code 把 dev build 裝進實機；Android 只差把 platform 換掉，而裝好後 app 還需要連上開發伺服器才有畫面。
