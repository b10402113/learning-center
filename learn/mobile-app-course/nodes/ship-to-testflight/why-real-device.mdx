# 從模擬器到真機：Expo、EAS、TestFlight 各在做什麼

<LearningGoal>
說出從「模擬器能跑」到「真機與測試者裝得到」之間，Expo、EAS、Apple Developer Program 與 TestFlight 各自的角色，以及兩條把 dev build 裝上 iPhone 的路。
</LearningGoal>

## Lesson

模擬器能跑不代表別人的手機裝得起來；要交付 app 得經過建置與散布。Expo 讓一份程式碼跨 iOS 與 Android，EAS 在雲端負責建置與散布，Apple Developer Program 是送審與對外的資格，TestFlight 則是上架前邀請測試者真機安裝的沙盒；把 dev build 裝進 iPhone 有 USB 本機建置與 EAS 雲端建置兩條路。
