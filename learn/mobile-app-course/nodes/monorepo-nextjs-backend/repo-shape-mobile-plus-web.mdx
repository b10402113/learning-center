<LearningGoal>
能說出 apps/mobile 與 apps/web 各自負責什麼、為什麼 web 是唯一部署，以及為什麼商業邏輯一律留在 web。
</LearningGoal>

## Lesson

一個 monorepo 裝兩個 app：`apps/mobile` 負責病人端體驗，`apps/web` 同時當員工後台、手機 API 與 webhook 接收端，商業邏輯與安全判斷一律留在 web。
