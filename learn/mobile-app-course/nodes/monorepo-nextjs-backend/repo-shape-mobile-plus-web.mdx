<LearningGoal>
能說出 apps/mobile 與 apps/web 各自負責什麼、為什麼 web 要同時是 dashboard、API 與 webhook 的唯一部署，以及 business logic 為什麼集中在 web。
</LearningGoal>

## Lesson

monorepo 把 apps/mobile（病人用）與 apps/web（後台＋API＋webhook 的唯一部署）放進同一個 repo，共用一份 schema 與商業邏輯；商業邏輯集中在 web，手機只渲染 API 回傳的內容。
