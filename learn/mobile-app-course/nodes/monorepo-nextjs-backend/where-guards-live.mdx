<LearningGoal>
能用判準決定路由保護該寫在 proxy 的 matcher 還是 resource-based guard（requireStaff／requireAuth），並說出為什麼 Clerk Core 3 放棄 createRouteMatcher。
</LearningGoal>

## Lesson

授權判斷要放在資料旁邊的 resource-based guard，proxy 的 matcher 只做身分附掛與 UX 轉址；Core 3 放棄 createRouteMatcher，因為路徑比對可能與實際路由分岔而漏掉保護。
