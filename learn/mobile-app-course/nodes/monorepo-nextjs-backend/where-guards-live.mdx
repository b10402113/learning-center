<LearningGoal>
用一套判準決定路由保護要寫在 proxy 的 matcher 還是資料旁邊的 resource-based guard，並說明 Clerk Core 3 為什麼放棄 createRouteMatcher。
</LearningGoal>

## Lesson

路由保護判斷的是資料就放資料旁邊、只是登入門檻就放共同 layout；`proxy` 只辨識身分，Clerk Core 3 因此放棄 `createRouteMatcher`。
