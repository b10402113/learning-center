能把 Expo app 移進 apps/mobile、建立 apps/web，用根目錄 npm workspaces 與 scripts 從根目錄啟動兩個 app，並說出 Expo 為何選 npm 而不是 pnpm。
</LearningGoal>

## Lesson

用 npm workspaces 把 Expo app 放進 apps/mobile、Next.js 放進 apps/web，並用根目錄 `-w` scripts 從根目錄啟動兩個 app；依賴只在根目錄 `npm install` 一次。
