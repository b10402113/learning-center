# 圖片附件：存進 ImageKit 的助理回合

<LearningGoal>
能完成照片上傳的助理回合：上傳前先確認對話歸屬、照片不送進模型、回覆用固定文案，並用 ImageKit 的模糊轉換做點擊才顯示的縮圖。
</LearningGoal>

## Lesson

圖片附件是一條不經模型的獨立回合：手機先在裝置上縮圖並用 Expo `File` 上傳，附件端點先確認對話歸屬再走伺服器端私有上傳，寫入空內容照片回合與固定 `PHOTO_REPLY`，最後用 `signedPhoto` 對同一份檔案簽出模糊與完整兩個網址供點擊揭示。
