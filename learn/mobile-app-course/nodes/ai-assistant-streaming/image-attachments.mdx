<LearningGoal>
能替助理加上圖片附件：把照片上傳到 ImageKit 的私人資料夾、用一個不呼叫模型的固定照片回合回覆使用者，並用 URL 轉換參數做出預設模糊、點擊才顯示的效果。
</LearningGoal>

## Lesson

替助理加上圖片附件：先驗對話所有權再上傳 ImageKit 私人資料夾、一次寫入「空內容的圖片訊息 + 寫死的固定回覆」兩則訊息（照片永不進模型、空內容會被送 prompt 前濾掉），並用 ImageKit 的 URL 轉換做出默認模糊、點擊才顯示的版本——模糊是體貼，隱私來自私人儲存與簽名。
