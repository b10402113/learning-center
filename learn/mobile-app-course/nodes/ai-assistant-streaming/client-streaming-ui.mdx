# 手機端逐字渲染與對話介面

<LearningGoal>
能用 useApiStream 邊收邊畫，分辨 JSON 分支與串流分支，並用 pending 閘門與錯誤降級避免過期回應蓋掉畫面。
</LearningGoal>

## Lesson

手機端用 Expo 的 `streamingFetch` 發請求，先看內容型別分辨 JSON 與串流分支，串流時把累積文字逐段交給尾端氣泡覆蓋顯示；`pending` 當閘門確保一次只有一輪在飛、歷史只載入一次，並把 503 等錯誤文案直接寫進氣泡作為降級。
