<LearningGoal>
能在 React Native 端做出逐字浮現的助理對話：用 useApiStream 送帶有 Clerk token 的請求、邊收邊更新畫面、用 request sequencing 丟掉過期回應，並處理空狀態、輸入區與錯誤降級。
</LearningGoal>

## Lesson

在 React Native 端用 `useApiStream` 逐字渲染助理回覆：用 `expo/fetch` 讀取串流、帶著 Clerk token 送出，先看內容型別決定走 JSON 或純文字，並用先放空氣泡、防重入旗標、游標與錯誤寫進氣泡等手法讓「還在寫」被看見。
