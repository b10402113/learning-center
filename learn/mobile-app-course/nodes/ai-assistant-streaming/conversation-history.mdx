# 把對話歷史持久化到資料庫

<LearningGoal>
能寫出受 ownership 檢查的對話 resolver，用 GET 回灌最新一串對話，並用 DELETE 同時清掉訊息與 ImageKit 照片。
</LearningGoal>

## Lesson

對話歷史靠 `ai_conversations` 與 `ai_messages` 兩張表落地，用 cascade 讓刪一列就清掉訊息；歸屬檢查集中在 `getOrCreateConversation`，找不到別人的對話回 404，GET 撈最新一串並重新簽圖片網址，DELETE 先刪資料列再盡力清 ImageKit 照片。
