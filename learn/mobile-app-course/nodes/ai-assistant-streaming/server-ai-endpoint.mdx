# 在 Next.js Route Handler 串出 AI 回應

<LearningGoal>
能寫出一個會串流的 AI 端點：用領域 system prompt 界定回答範圍、在模型之前短路緊急訊息、用 fail-closed 閘門擋下外送，再把 OpenAI 的串流轉成純文字 ReadableStream。
</LearningGoal>

## Lesson

端點先認人與驗 body、存下使用者這一輪，緊急訊息在模型之前短路並以 JSON 回應，再用 fail-closed 閘門擋下未設定或未核准的外送；通過後組最近 30 則歷史、用 system prompt 界定範圍並開啟串流，以 `replyStream` 把模型增量編碼進 ReadableStream，最後用純文字回應並在 `X-Conversation-Id` 標頭帶上對話 id。
