<LearningGoal>
能在 Next.js Route Handler 寫出一個會串流的 AI 端點：用領域 system prompt 框住助理範圍、在模型之前先攔截緊急訊息、用 fail-closed 的傳輸閘門決定要不要送 OpenAI，並把 OpenAI 的串流轉成純文字 ReadableStream 回傳。
</LearningGoal>

## Lesson

在 Next.js Route Handler 逐步串出 AI 回應：先驗身分與輸入、在模型之前用寫死的規則攔截緊急訊息、用預設關閉的傳輸閘門決定要不要送 OpenAI，最後把模型的非同步輸出轉成純文字 `ReadableStream`，並在關閉前完成持久化。
