# 串流回應的心智模型：為什麼 AI 助理不該只轉圈圈

<LearningGoal>
能講清楚逐字串流與一般 JSON 端點在資料傳輸上的差別，並說明它解決了 AI 助理體驗裡的哪個問題。
</LearningGoal>

## Lesson

一般 JSON 端點要等整包資料到齊才交出來，串流則是一產生就送、客戶端邊收邊畫；LLM 逐詞元生成、耗時數秒，這個 app 只讓模型生成那條路走純文字串流，緊急回覆與錯誤仍走 JSON，讓客戶端用內容型別分辨兩者。
