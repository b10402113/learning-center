<LearningGoal>
能說清楚為什麼 AI 助理的回應要用逐字串流而不是轉圈圈等待，以及串流發生在請求／回應邊界的哪一層、為什麼它和一般回傳 JSON 的端點不是同一種東西。
</LearningGoal>

## Lesson

LLM 的答案本質上是一點一點生成的，串流就是把「答案是水管、不是箱子」這件事對齊：用回應型別當分岔點——錯誤與緊急訊息走 JSON，真正要生成的回覆走 `text/plain` 逐字送出，對話編號改放標頭——並連帶改變了錯誤處理與持久化的時機。
