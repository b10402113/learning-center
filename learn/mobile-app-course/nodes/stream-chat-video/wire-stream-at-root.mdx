# 在 app root 接上兩個 client：一個 token、Chat 與 Video

<LearningGoal>
能在 app root 用同一張 server token 建立 Stream Chat 與 Video 兩個 client，並加上連線逾時降級，讓非即時功能不被拖垮。
</LearningGoal>

## Lesson

在 app root 用同一張 token 建立 Stream Chat 與 Video 兩個 client，Video 用 getOrCreateInstance 保證單例，並替 token POST 與聊天 socket 各設 12 秒截止時間，連不上就降級成「沒有聊天但其他功能照常」的 app。
