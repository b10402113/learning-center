<LearningGoal>
能分辨兩種視訊通話入口：排程的 teleconsult 用 server 推導的固定 call id，即時 ring 用一次性 call id 並在 root 以 overlay 呈現；並知道通話控制由 SDK 提供。
</LearningGoal>

## Lesson

視訊通話有兩種入口：排程 teleconsult 用 server 推導的固定 call id `appointment-{id}` 搭配 `CallContent`，即時 ring 每次用新的 id 並以掛在 root 的 `RingingCalls` 覆蓋層呈現，通話控制由 SDK 內建。
