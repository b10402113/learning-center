# 視訊通話：排程 teleconsult 與即時 ring 的兩種入口

<LearningGoal>
能分辨排程通話的固定 call id 與即時 ring 的一次性 call id，並說明 ring overlay 為什麼要掛在 root 而不是各畫面。
</LearningGoal>

## Lesson

排程看診用 server 在預約時推導的固定 call id appointment-{id}，即時來電每次用 randomUUID 產生新 id；RingingCallContent 掛在 root 蓋住任何畫面，接通後的靜音、鏡頭、掛斷等控制由 CallContent 內建。
