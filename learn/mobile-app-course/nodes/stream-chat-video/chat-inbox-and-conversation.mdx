<LearningGoal>
能用 Stream Chat SDK 做出兩個角色的訊息畫面：patient 直接進入唯一對話，staff 從共享收件匣開啟個別對話，並知道 typing、已讀、附件等 UX 由 SDK 內建。
</LearningGoal>

## Lesson

Messages 分頁依角色分岔：病人直接進入唯一對話，員工用 `ChannelList` 收件匣再開啟個別對話，兩者共用 `Conversation` 元件，打字、已讀、附件、threads 等體驗由 Stream Chat SDK 內建提供。
