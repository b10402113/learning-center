<LearningGoal>
能說出 Stream 的身分模型：為什麼 Stream user id 要由 server 從登入 session 推導、為什麼 Chat 與 Video 共用同一個身分與 token，以及 API secret 絕對不能進到 app。
</LearningGoal>

## Lesson

Stream 是託管的聊天與視訊後端；server 從登入 session 推導 Stream user id、以只留在 server 的 API secret 簽發短效 token，並讓 Chat 與 Video 共用同一個身分與 token，client 只在拿到 token 後使用它。
