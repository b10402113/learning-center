# Stream 的身分與 token：為什麼 user id 只能由 server 決定

<LearningGoal>
能說出為什麼 Stream 的 user id 必須由 server 從 Clerk session 推導，以及 Chat 與 Video 為什麼共用同一個 token。
</LearningGoal>

## Lesson

Stream 是託管的聊天與視訊後端，身分由 server 從 Clerk session 推導、簽出短效 token，Chat 與 Video 共用同一組身分；手機永遠不能自己報 user id 或持有 API secret，而病人名字送到 Stream 是因為它簽了 BAA 的允許例外。
