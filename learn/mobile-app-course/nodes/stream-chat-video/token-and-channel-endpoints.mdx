<LearningGoal>
能寫出 `/api/stream/token` 與 `/api/stream/channel` 兩個 Route Handler，以及背後的 server wrapper：短效 token、依身分推導的 Stream user id、冪等建立的對話 channel。
</LearningGoal>

## Lesson

在 `/api/stream/token` 用 `requireAuth()` 取得身分並簽發四小時 token，在 `/api/stream/channel` 依角色回傳推導出的 clinic channel（病人）或 `null`（員工），背後由 `lib/stream.ts` 集中管理 secret、token 與冪等的 channel 建立。
