<LearningGoal>
能判斷一個檔案該不該進 repo，把 .env 這類 secrets 擋在 .gitignore 之外，並在 agent 偷偷改了東西時看得出來。
</LearningGoal>

## Lesson

真正的憑證放 .env 並在提交前加進 .gitignore，提交沒有真實值的 .env.example 讓別人知道要補哪些變數。判斷靠三個問句：這裡面有沒有外流就會被冒用的東西、拿掉值別人還知道要補什麼嗎、這筆改動是怎麼冒出來的；看到 agent 在背景加的改動，先看 diff 再決定。
