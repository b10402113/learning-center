<LearningGoal>
能把 PR 交給 CodeRabbit 審查，讀懂它的嚴重度排序與 Change Stack，並把彙整後的 review 意見交回 agent 修完、再合併。
</LearningGoal>

## Lesson

開好 PR 後讓 CodeRabbit 逐行審查，它會給出摘要、逐檔導覽、嚴重度排序的行內註解與 Change Stack。修正的關鍵不是一則一則手動改，而是複製它彙整好的「給 AI agent 的意見」整份交回 agent 一次修完，再 commit、合併，不必等第二輪重審。
