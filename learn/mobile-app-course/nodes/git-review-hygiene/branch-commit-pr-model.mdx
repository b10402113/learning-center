<LearningGoal>
能用「時間線上的四個動作」說出 branch、commit、PR、merge 各自在做什麼，以及為什麼不該直接把功能 commit 到 main。
</LearningGoal>

## Lesson

main 是永遠可用的主線，branch 從它切出平行線隔離功能，commit 在分支上留快照讓你能回溯，PR 提出改動讓審查有地方發生，merge 把通過的東西併回 main、不滿意則 discard——這四個動作就是那張 git 時間線。
