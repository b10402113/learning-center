<LearningGoal>
能說出為什麼 AI agent 大量生成程式碼之後，版控與 code review 反而變成流程的關鍵，而不是可有可無的收尾。
</LearningGoal>

## Lesson

agent 把寫程式的成本壓低之後，開發的瓶頸從「寫」換到了「審」；能跑不代表安全、也不代表符合慣例，所以自我檢查之外還需要一個獨立的角度。版控不是存檔而是安全網——分支隔離風險、commit 讓你能精準回溯，這是讓高速產出變得可信任的前提。
