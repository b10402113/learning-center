# 砍出 V1：該留什麼、該砍什麼

<LearningGoal>
能用「先做一個能動的 demo、其餘延後」的判準把功能砍成可上線的 V1，並知道什麼時候要推翻 AI 推薦的選項。
</LearningGoal>

## Lesson

V1 的目標是能動的 demo 而不是功能齊全，用「砍掉它 app 還能不能動、是否需要新服務或原生模組、demo 還說不說得完整」三個問題分類，必留的比想像中少；AI 的推薦選項只是一般情況的預設，和你的產品價值衝突時就該推翻，沒有理由時則大方接受。
