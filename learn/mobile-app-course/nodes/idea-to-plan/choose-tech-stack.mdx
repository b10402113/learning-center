# 選定 tech stack：三種後端範式的取捨

<LearningGoal>
能在規劃階段就明確指定 auth、後端與樣式的組合，並說出三門課的三種後端範式各自適合什麼樣的 app。
</LearningGoal>

## Lesson

plan 階段就要定下 auth、後端與樣式：有長時易失敗的背景工作就用 trigger.dev 這類任務平台，核心體驗是即時更新就選 Convex 這類託管 reactive 後端，需要網頁後台與強關聯模型就走 Next.js 加 Drizzle／Neon；而且只要提供 Google 登入，就必須同時提供 Apple 登入。
