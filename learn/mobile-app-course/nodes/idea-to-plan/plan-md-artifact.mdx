# plan.md 的結構與用途

<LearningGoal>
能照固定欄位（idea / goals / features / pages / user flow / stack）讀寫一份 plan.md，並說出它如何餵給後續的 UI 生成與功能拆解。
</LearningGoal>

## Lesson

plan.md 是放在專案根目錄、以 Markdown 寫成的計畫文件，欄位固定為 idea、goals、features、pages、user flow、tech stack，既是訪談與取捨的收斂點，也是後續生成 UI 設計與拆解功能的依據。
