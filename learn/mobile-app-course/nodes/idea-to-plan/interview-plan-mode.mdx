# 訪談式 plan mode：讓 AI 反問你

<LearningGoal>
能開好 plan mode、貼上訪談式規劃 prompt，並用「分批反問、逐題回答」的方式把 idea、goals、features、pages、user flow、stack 交代清楚。
</LearningGoal>

## Lesson

用一段要求「不准假設、分批反問」的 prompt 開啟訪談，讓 agent 一次問三到六題、你一輪一輪回答，並用 `/by the way` 處理臨時補充，直到對話裡沒有未經你同意的決定，再退出 plan mode 把結果寫成 plan.md。
