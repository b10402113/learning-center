# Dashboard 外殼與守衛：把 requireStaff 放在資料旁邊

<LearningGoal>
能解釋 dashboard 的守衛為什麼放在 layout 而不是 proxy，並說出未登入與登入但非員工兩種情況各自發生什麼。
</LearningGoal>

## Lesson

守衛放在 dashboard/layout.tsx 而非 proxy 的路徑比對：一次檢查守住整個子樹、規則與資料同層；未登入 redirect('/')，登入但非員工則渲染 NotStaff 說明補上 Clerk 角色。
