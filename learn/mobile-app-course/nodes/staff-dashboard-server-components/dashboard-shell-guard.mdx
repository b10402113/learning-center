<LearningGoal>
說明為什麼 dashboard 的權限守衛放在 layout 這種「資源旁邊」，而不是放進 proxy 做路徑比對，以及未登入與非員工兩種情況各自怎麼被處理。
</LearningGoal>

## Lesson

後台的守衛放在 `dashboard/layout.tsx`，因為它一次包住整個子樹又緊鄰資料；未登入者被 `redirect('/')` 送走、已登入的非員工看到 `NotStaff`，而 layout 與 page 是平行渲染，所以每個 page 仍要自己再 `requireStaff()` 一次。
