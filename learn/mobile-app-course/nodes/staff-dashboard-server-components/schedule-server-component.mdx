# 今日行程 Server Component：typed params 與診所日查詢

<LearningGoal>
能照著寫出一個讀 searchParams、把診所當地的一天換成 UTC 時間窗、再用 join 撈出當日行程的 Server Component。
</LearningGoal>

## Lesson

在 async 元件裡 await searchParams、把診所當地日解析成 CalendarDay、用 clinicInstant 建出當天 +24 小時的 UTC 半開窗，再以 innerJoin 串起病人／牙醫／服務並用 gte／lt 撈出當日行程。
