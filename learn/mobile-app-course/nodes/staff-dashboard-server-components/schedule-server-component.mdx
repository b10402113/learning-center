<LearningGoal>
照著 dashboard 首頁的程式碼，用 async Server Component 讀取 typed searchParams、算出診所日時間窗，join 出當日行程並渲染成表格。
</LearningGoal>

## Lesson

今日行程頁是一個 async Server Component：等待 typed `searchParams`、用診所日時間窗搭配 `innerJoin` 與 `gte`／`lt` 查詢，再把同一批結果算成統計與表格，全程不經 API。
