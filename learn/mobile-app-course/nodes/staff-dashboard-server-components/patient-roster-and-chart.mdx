# 病患名冊與病歷頁：聚合查詢與 PHI 讀取紀錄

<LearningGoal>
能用 count() 加 groupBy 做出看診次數聚合，並把筆記與附件嚴格鎖在該病患身上、每次讀取都寫一筆 audit。
</LearningGoal>

## Lesson

名冊用 count() 加 groupBy 算看診次數、用 leftJoin 保住零預約病人，並連「讀名冊」都寫稽核；病歷頁對 patients 與 medical_histories 各留一筆紀錄，筆記與附件用 inArray 鎖在該病患的預約 id 上，附件再現簽會過期的私有網址。
