<LearningGoal>
用 count + groupBy 做病患名冊的聚合查詢，並在單一病患病歷頁把筆記與附件鎖在該病患的預約上，同時為每次 PHI 讀取留下稽核紀錄。
</LearningGoal>

## Lesson

病患名冊用 `count` 加 `groupBy` 一次算出看診次數，而且讀名冊本身也要寫稽核；單一病患病歷頁把筆記與附件用 `inArray` 鎖在該病患的預約上，並為每次 PHI 讀取留下 `audit` 紀錄。
