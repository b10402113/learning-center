<LearningGoal>
說出為什麼 mobile app 只能繞 HTTP API、而網頁 dashboard 的 Server Component 可以直接 import Drizzle 查 DB，並認得這條分界對型別、密鑰與互動性的影響。
</LearningGoal>

## Lesson

手機 App 執行在信任邊界之外、只能呼叫 API；網頁後台的 Server Component 與資料庫同住一台伺服器，所以能 `import db` 直讀，換來端到端型別與少一層序列化，代價是互動要切成 client component，而且每個頁面仍須自己驗身分。
