<LearningGoal>
用 'use server' 寫出 addVisitNote 與 completeAppointment 兩個 Server Action，在裡面完成授權、驗證、稽核與 revalidatePath，並用 useActionState／useTransition 從 client 呼叫。
</LearningGoal>

## Lesson

用 `'use server'` 的 Server Action 取代自建 API：在函式內完成 `requireStaff`、Zod 驗證、`audit` 與 `revalidatePath`，client 端再用 `useActionState`／`useTransition` 呼叫並顯示 pending 與錯誤。
