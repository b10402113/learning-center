# Server Actions：不用寫 API 也能寫入，revalidatePath 自動更新

<LearningGoal>
能用 'use server' 寫出直接寫 DB 的 Server Action，跑完 revalidatePath 讓畫面自動更新，並在 client 端用 useActionState／useTransition 接住狀態。
</LearningGoal>

## Lesson

以 'use server' 把伺服器函式變成可呼叫端點，寫入流程照樣 requireStaff、Zod 驗證與 audit，完成後 revalidatePath 讓被改到的畫面重新查詢渲染；client 端用 useActionState 接表單、useTransition 接按鈕。
