<LearningGoal>
用 cursor 分頁回傳可能被過濾的列表，並解釋稀疏 feed 為什麼要保留 cursor。
</LearningGoal>

## Lesson

社群列表用 cursor 分頁取代 offset/limit，Convex 的 paginate 回傳 page / isDone / continueCursor；最關鍵的是「先分頁再過濾」的 home feed 過濾後頁面變少是正常的，務必保留上游 cursor，不要為了補滿而重算。
