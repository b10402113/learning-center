<LearningGoal>
用 withIndex 查 home / explore / profile 三種 feed 與 followers / following 清單，並說明 per-viewer 衍生欄位從哪來。
</LearningGoal>

## Lesson

三種 feed 都走索引：explore 用 by_creation_time、profile 用 by_authorId、home 先掃一頁再用 follows 複合索引逐篇檢查作者；追蹤清單靠方向相反的兩條 follows 索引，回傳前用 publicPost / publicProfile 塑形，並依當下 viewer 即時算出 isLiked、isFollowing、isOwn。
