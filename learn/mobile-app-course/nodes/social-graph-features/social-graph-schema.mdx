<LearningGoal>
說出社交圖為什麼拆成 posts / likes / comments / follows / bookmarks 等表，以及每個複合索引在保證什麼。
</LearningGoal>

## Lesson

社交圖的正確骨架，是把每一次互動存成一列獨立的關係表（likes / follows / comments / bookmarks），用複合索引保證「一人一讚、一人一追蹤」、用反向索引回答另一個方向的查詢、用反正規化計數器換取讀取速度，並為模糊文字搜尋另外掛一條 searchIndex。
