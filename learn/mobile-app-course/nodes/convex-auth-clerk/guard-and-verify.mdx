# 把 guard 套進 query/mutation 並驗證

<LearningGoal>
能在 Convex query/mutation 開頭套用 requireProfile，並用未登入、已登入未建 profile、已登入有 profile 三種情境驗證授權真的生效。
</LearningGoal>

## Lesson

受保護的函式從 `requireProfile(ctx)` 開始、參數移除所有身分欄位、後續寫入與查詢都使用 guard 回傳的 profile，只有純需登入的操作才用 `requireIdentity`；最後以未登入、未建 profile、正常使用三種情境加上即時同步，驗證授權真的生效。
