# 為什麼不能相信 client 傳來的 identity

<LearningGoal>
能說出為什麼把 client 傳來的 userId 當成身分會出錯，並解釋 server 端如何從驗證過的 token 推導出可信的呼叫者。
</LearningGoal>

## Lesson

client 傳來的 `userId` 只是普通資料、可被任意改寫，所以它不能當成身分；正確做法是讓 client 出示 Clerk 簽發的 JWT，由 Convex 在 server 端驗證後推導出呼叫者，程式碼只信任 `ctx.auth`。
