# requireIdentity 還是 requireProfile？

<LearningGoal>
能依操作需不需要 app profile，判斷該用 requireIdentity 還是 requireProfile，並說明 requireProfile 的三種拒絕條件。
</LearningGoal>

## Lesson

`requireIdentity` 只確認有人登入，`requireProfile` 會再查 profiles 並擋下刪帳中、示範帳號與尚未建立 profile 這三種情況；判準是這個操作需不需要一個真實可用的 profile，選定之後一律使用 guard 回傳的物件，不再相信 client 傳來的識別碼。
