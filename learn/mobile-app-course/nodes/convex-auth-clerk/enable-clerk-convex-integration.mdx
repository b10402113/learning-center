# 開通 Clerk↔Convex 整合並寫 auth.config

<LearningGoal>
能在 Clerk dashboard 打開 Convex 整合、設定 issuer domain 環境變數、寫出 auth.config.ts，並確認 ctx.auth.getUserIdentity() 不再回傳 null。
</LearningGoal>

## Lesson

開通整合的順序是：在 Clerk dashboard 的 Configure → Integrations → Developers 打開 Convex 整合以建立 `convex` JWT 範本，於 Convex 部署環境設定 `CLERK_JWT_ISSUER_DOMAIN`，寫下 `auth.config.ts` 宣告 provider 的 domain 與 applicationID，重新部署後從 app 呼叫 `getUserIdentity` 就會拿到身分（dashboard 的測試器永遠是 null）。
