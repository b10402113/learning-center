安裝與接線 NativeWind

Step 4/5 · 建立 Expo 專案與 NativeWind

學習目標

能安裝 nativewind 與 tailwindcss，並把 tailwind.config.js、babel.config.js、metro.config.js 與 global.css 四處接好，讓 className 被編譯進 bundle。

前言：知道原理之後，把管線真的接起來

上一節把 NativeWind 的翻譯流程拆開看過了：Tailwind 負責掃描與產生 CSS，Babel 改寫 JSX，Metro 把 CSS 打包進 bundle。你也理解了為什麼不能只改一個設定檔。

但理解流程不等於接得對。實際動手時，只要有一站的設定寫錯、路徑沒對上，樣式就會默默失效——React Native 不會報錯，畫面只是原封不動。這一節就是把那條管線真的接起來：安裝套件、建立設定檔、把 global.css 接進 app，最後用清快取重啟來確認設定被讀到。

動手前先確認的事

  • 你已經有一個 reset 過、可以在模擬器跑的空白 Expo 專案（Step 1、2 的成果）。
  • 你知道 NativeWind 的四個接力站各在做什麼（Step 3）；這一節是照著那張圖施工，不是重新解釋原理。
  • 終端機在專案根目錄，並且開發伺服器已經停掉。接下來會改到 Babel 與 Metro 設定，這兩者都需要重啟才會生效。

第一步：安裝套件

NativeWind 本體是正式執行的套件，而 tailwindcss 只負責建置階段產生 CSS，因此放在開發相依（devDependencies）即可。完成後的 package.json 會看到這兩個項目：

"nativewind": "^4.2.6",
"tailwindcss": "^3.4.19",

實際安裝時，對應的指令是這樣（版本約束以官方當下相容的為準）：

npm install nativewind
npm install --save-dev tailwindcss@^3.4.19
課程裡用的是 NativeWind v4。錄影當下 v5 還在預覽階段，所以選擇比較穩定的 v4。這個決定不需要你背數字，重點是「安裝時確認目前穩定版是哪一個」。

第二步：建立 Tailwind 設定檔

在專案根目錄建立 tailwind.config.js。它要告訴 Tailwind 兩件事：要去哪裡找 class，以及掛上 NativeWind 提供的 preset：

/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ['./src/**/*.{js,jsx,ts,tsx}'],
  presets: [require('nativewind/preset')],
  theme: {
    extend: {},
  },
  plugins: [],
};

如果你之後要加自訂顏色或字型，會寫在 theme.extend 裡；現階段留空即可。content 這一行請照你的目錄結構調整，原則是「你的程式碼放在哪，就掃哪裡」。

第三步：建立 CSS 入口

建立 src/global.css，內容就是 Tailwind 的三行指令：

@tailwind base;
@tailwind components;
@tailwind utilities;

這三行分別對應 Tailwind 的基礎樣式、元件類與工具類。真正的專案可能還會在下面追加 :root 變數，例如字型堆疊；但作為起點，三行就夠了。記得這個檔案路徑，下一步 Metro 會用到它。

第四步：接上 Babel

修改 babel.config.js，讓 JSX 在編譯時走 NativeWind 的 runtime：

module.exports = function (api) {
  api.cache(true);
  return {
    presets: [['babel-preset-expo', { jsxImportSource: 'nativewind' }], 'nativewind/babel'],
  };
};

這裡有兩個重點：babel-preset-expo 的選項加上 jsxImportSource: 'nativewind'，以及 presets 陣列裡多了 'nativewind/babel'。這兩個是 Babel 認得 className 的關鍵。Babel 屬於建置期，改完之後光靠熱更新不會生效，後面要重啟並清快取。

第五步：接上 Metro

修改 metro.config.js，用 NativeWind 提供的包裝函式把 CSS 入口接進去。最基本的長相是：

const { getDefaultConfig } = require('expo/metro-config');
const { withNativeWind } = require('nativewind/metro');

const config = getDefaultConfig(__dirname);

module.exports = withNativeWind(config, { input: './src/global.css' });

真實課程專案的 metro.config.js 因為同時接了 Sentry，所以用的是 getSentryExpoConfig 而不是 Expo 預設的設定；但 NativeWind 的部分完全一樣，都是最後這一行：

module.exports = withNativeWind(config, { input: './src/global.css' });

input 的值必須和你剛才建立的 CSS 檔路徑一致。如果一個寫 ./src/global.css、另一個放在 ./global.css，Metro 就找不到入口，樣式自然不會被編進 bundle。

第六步：補上 TypeScript 型別

如果你用 TypeScript，加一個 nativewind-env.d.ts，內容一行就好：

/// <reference types="nativewind/types" />

這讓編輯器認得 NativeWind 型別，避免在使用 className 時跳出型別錯誤。它不影響執行結果，但能讓開發體驗順暢很多。

第七步：把 CSS 匯入 app

最後，在根 layout 檔案（src/app/_layout.tsx）裡把 CSS 匯入，這段在開頭即可：

import "@/global.css";

這一行讓整包樣式跟著 app 的根元件一起被載入。少了它，前六步都接好了，執行期還是沒有任何樣式可用。

重啟並清快取

設定檔改完之後，停掉開發伺服器，用清快取的方式重新啟動：

npx expo start --clear

--clear 會清掉 Metro 的快取，確保新的 Babel 與 Metro 設定真的被讀進來。如果只是一般的熱更新，舊的設定可能還留著，讓你誤以為沒接成功。

為什麼要特別強調這件事？因為 Babel 與 Metro 都是在建置階段工作的工具，它們讀的是你上次啟動時的設定。你在檔案裡改了 preset、改了 input 路徑，但已經在跑的伺服器不會自動重讀，於是新設定形同不存在。清快取重啟，就是強迫這兩個工具重新讀一遍。養成「動到設定檔就清快取」的習慣，可以省下大量「明明照著做卻沒效」的困惑。

另外，套件版本也是一個常見的坑。Expo 對每個 SDK 版本建議的套件版本組合是經過測試的，隨意把某個套件升到最新，可能和其他套件打架。安裝時盡量讓 Expo 幫你挑相容版本，或至少確認你裝的版本和目前的 SDK 對得上；真的出現版本衝突時，先確認版本，再考慮升級，而不是直接硬上最新版。

課程裡還示範了一個很省力的做法：把 NativeWind 官方文件整頁複製給 AI agent，並附上一句話——「照著文件一步一步來，不要多做也不要少做，確保它在這個專案裡能運作」。Agent 就會替你安裝套件、更新 global CSS 與 Babel 設定。這個模式可以搬到任何套件的安裝上；重點是把「不要多做也不要少做」講清楚，避免 agent 自作主張。課程作者也習慣一次只交辦一件事，而不是同時開好幾個 agent 平行處理。

做完會看到什麼

重啟後，專案應該能正常編譯、跑起來，而且 className 已經可以被 Babel 與 Metro 處理。此時畫面上還看不出明顯變化，因為你還沒把 className 寫進任何元件。下一步就是把 index.tsx 改成用 className 寫樣式，並刻意驗證它真的生效。

如果編譯就報錯，先回頭檢查兩個地方：Babel 的 preset 是否正確、Metro 的 input 路徑是否和 CSS 檔對得上。這兩處是最常見的接線錯誤。

小結

接 NativeWind 是照著五個接力站施工：安裝 nativewind 與 tailwindcss、建立 tailwind.config.js、建立 global.css、改 babel.config.js、改 metro.config.js，再補上型別並在根 layout 匯入 CSS。改完一定要用 npx expo start --clear 重啟，設定才會生效。

管線接好了，但「接好」和「真的會動」是兩回事。下一節要用一個實際的 className 改畫面，並學會在樣式沒出現時，沿著這條管線把問題一段一段找出來。
