Lesson 001 · AWS 基礎

建立 AWS 帳號

Node: aws-account-and-iam · Step 1/3

學習目標

完成 AWS 帳號註冊，並理解 root user 為什麼是全帳號最大的安全隱患。

為什麼要先有帳號？

部署任何 AWS 服務之前，你必須先有一個帳號。帳號一建立就會產生一個 root user——它擁有所有資源的完整權限，包括帳單。

這一步聽起來很瑣碎，但它是所有後續工作的前提。好消息是：帳號建立是整個課程中最麻煩的一步，之後每一步都會越來越簡單。

註冊過程需要：email、密碼、聯絡資訊、信用卡、身份驗證。大概 10-15 分鐘。撐過去就贏了。

註冊步驟

  1. 前往 aws.amazon.com，點擊「Sign In to the Console」
  2. 選擇「Create a new AWS account」
  3. 輸入 root user 的 email 和密碼（這就是你的 root 憑證）
  4. 填寫聯絡資訊（個人或公司皆可）
  5. 輸入信用卡資訊（用於身份驗證和未來計費）
  6. 完成身份驗證（可能需要電話驗證）
  7. 選擇支援方案（選「Basic support — 免費」即可）

Root User 的安全風險

Root User 是全帳號最大的安全隱患

root user 擁有不受限制的存取權限——所有 AWS 資源、所有帳單設定、所有 IAM 操作。一旦被盜用，攻擊者可以立刻啟動高價運算資源（例如比特幣挖礦），而帳單是你的。

這不是假設性的風險。 AWS 帳號被盜用後被用來挖礦的案例屢見不鮮。信用卡直接暴露在風險中。

核心原則：完成帳號建立後，你就不应该再用 root user 做日常操作。建立一個 IAM 管理員帳號來取代它——這正是下一個 lesson 要做的事。
類比：Root user 就像一棟大樓的總钥匙。它能打開每一扇門、修改保全系統、甚至更改大樓所有者。你不會帶著總钥匙去買午餐——同理，你不會用 root user 去開 EC2 實例。

註冊完成後的清單

  • 記下你的 AWS Account ID（12 位數字）
  • 記下你註冊用的 root email
  • 登入一次 Console，確認帳號正常運作
  • 關掉 Console——不要再用 root 登入了

自我檢測

Q1. 建立 AWS 帳號時，哪個身份預設會被建立？

  • IAM 管理員
  • root user
  • Power User
  • ReadOnly 使用者

Q2. 為什麼不應該用 root user 做日常操作？

  • 因為 root user 不能開 EC2
  • 因為 root user 不能看帳單
  • 因為 root user 擁有全部權限，被盜用會造成財務損失
  • 因為 root user 有使用時間限制

Q3. 註冊 AWS 帳號時，以下哪項不是必需的？

  • Email 和密碼
  • 信用卡
  • 身份驗證
  • 域名
