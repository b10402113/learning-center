加密、版本控制與存取日誌

學習目標：了解 S3 伺服器端加密、版本控制與存取日誌的用途與開啟方式，判斷何時需要啟用。

你的靜態網站需要這些嗎？

對於一個公開的靜態網站，加密、版本控制和存取日誌不是必要功能——但它們是生產環境的標準配置。即使你現在不需要，面試官會問你「在生產環境中你會怎麼保護 S3 資料？」，了解這些選項能讓你的回答更有深度。

1. 伺服器端加密 (Server-Side Encryption)

加密保護的是靜態資料（data at rest）。當你把檔案上傳到 S3，S3 可以自動在儲存時加密檔案，讀取時自動解密——對你的應用完全透明。

三種加密選項

加密方式金鑰管理適用場景
SSE-S3AWS 完全管理（S3 自己的金鑰）簡單、零配置、一般用途
SSE-KMSAWS KMS 管理（你可以控制金鑰存取）需要稽核金鑰使用紀錄
SSE-C你自己提供金鑰你管理金鑰，AWS 只做加解密

對於靜態網站，SSE-S3 就夠了。開啟方式：

  1. S3 console → 你的 bucket → Properties
  2. 找到 Default encryption → 按 Edit
  3. 選擇 Server-side encryption with Amazon S3 managed keys (SSE-S3)
  4. 按 Save changes

或者用 CLI：

aws s3api put-bucket-encryption \
  --bucket my-portfolio-site \
  --server-side-encryption-configuration '{
    "Rules": [{
      "ApplyServerSideEncryptionByDefault": {
        "SSEAlgorithm": "AES256"
      }
    }]
  }'
核心概念 伺服器端加密對你的應用是透明的——S3 在儲存時加密、讀取時自動解密。你不需要改任何代碼，只需要在 bucket 設定裡開啟。

2. 版本控制 (Versioning)

版本控制讓 S3 保留每一個物件的每一個版本。這意味著：

  • 誤刪可以復原——刪除只是加了一個 "delete marker"，真實資料還在
  • 誤覆可以回退——上傳新版本不會覆蓋舊版本，舊版本依然保留
  • 可以搭配 MFA Delete——需要多因素認證才能永久刪除版本

開啟版本控制

  1. S3 console → 你的 bucket → Properties
  2. 找到 Versioning → 按 Edit
  3. 選擇 Enable
  4. 按 Save changes

或者用 CLI：

aws s3api put-bucket-versioning \
  --bucket my-portfolio-site \
  --versioning-configuration Status=Enabled
面試要點 「版本控制是防止資料意外遺失的安全網。誤刪檔案時，只是加了一個 delete marker，真實資料還在，可以輕鬆復原。在生產環境中幾乎所有 bucket 都應該開啟版本控制。」

3. 存取日誌 (Access Logging)

存取日誌記錄了「誰在什麼時候對什麼資源做了什麼操作」。這是安全稽核的基礎——當異常發生時，日誌能幫你還原事件經過。

開啟存取日誌

  1. 先建立一個「日誌 bucket」（專門存放日誌的 bucket）
  2. 在來源 bucket → Properties → Server access logging → Edit
  3. 開啟 logging，選擇目標 bucket
  4. 按 Save changes
核心概念 存取日誌需要一個專門的日誌 bucket。不要把日誌和網站檔案放在同一個 bucket——這會造成循環依賴（日誌寫入觸發更多日誌）。

三個功能的比較

功能保護什麼免費？必要性
加密靜態資料不被未授權讀取SSE-S3 免費生產環境必備
版本控制資料不被意外覆蓋或刪除免費（但多版本佔儲存空間）生產環境強烈建議
存取日誌提供安全事件的稽核軌跡日誌寫入的 S3 費用合規要求時必備

什麼時候開啟什麼？

個人專案 / 試驗性部署
  → SSE-S3 加密（零成本，一鍵開啟）
  → 版本控制（防止誤刪）

正式上線的網站
  → SSE-S3 或 SSE-KMS 加密
  → 版本控制
  → 存取日誌（導到專門的 log bucket）

處理敏感資料（用戶個資、金融資料）
  → SSE-KMS（可追蹤金鑰使用）
  → 版本控制 + MFA Delete
  → 存取日誌 + CloudTrail
面試要點 「生產環境的 S3 應該預設開啟伺服器端加密（SSE-S3）和版本控制。加密保護靜態資料不被未授權讀取，版本控制防止資料意外遺失。如果需要安全稽核，再加上存取日誌。這些功能免費或低成本，沒有理由不開。」
