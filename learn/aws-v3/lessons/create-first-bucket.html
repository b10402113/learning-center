建立你的第一個 S3 bucket

學習目標：能在 AWS Console 建立一個 S3 bucket，並理解 general purpose 型別與 region 選擇。

動手前，先想一件事

你已經知道 S3 是「用 bucket 裝物件」的物件儲存。現在要實際動手：在 AWS Console 建立你的第一個 bucket。動手之前，先記住一條關鍵規則——你的 bucket 名稱會被全世界共用。

一步一步來

  1. 登入 AWS Console，搜尋並進入 S3 服務。
  2. 點 Create bucket（建立儲存桶）。
  3. 輸入一個 全域唯一的 bucket 名稱——這個名字在整個 AWS、所有帳號、全世界只能有一個，沒有第二個人能用同一個名字。
  4. 選擇 bucket 型別（bucket type）——預設選 General purpose（一般用途） 就好，它取代了舊的 legacy 格式，是最標準的選擇。
  5. 選擇 Region（區域）——決定你的資料實際存放在地球的哪個地區。
  6. 點 Create bucket，完成。
核心概念 名稱一旦被別人用走，你就只能換一個。所以常見做法是幫 bucket 加上自己的識別字，例如 andy-portfolio-site——確保它足夠獨特。

兩個容易忽略的點

第一，名稱裡如果有斜線（/），Console 看起來會像資料夾分層，例如 my-app/images/logo.png。這是視覺錯覺——S3 其實是扁平儲存，斜線只是 key 的一部分，不是真的資料夾。真正的資料夾結構在 S3 裡不存在。

第二，region 的選擇會影響延遲。你的使用者離哪個 region 近，存取速度就快。你現在先選一個（例如離你近的亞太區），之後可以再調整策略。

面試要點 「建立 bucket 時，名稱必須在 AWS 全域唯一，型別選 general purpose，並在建立時指定 region——bucket 名稱是全世界的命名空間，但資料實際儲存在你選的那個 region。」
