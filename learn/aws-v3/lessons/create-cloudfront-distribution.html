aws-v3 · CloudFront CDN setup · Step 3/4

建立 CloudFront Distribution

學習目標：在 Console 建立 CloudFront distribution、把 S3 bucket 設為 origin，並理解它自動更新 bucket policy 的機制。

前置：關掉 S3 靜態網站託管

在設定 CloudFront 之前，先把 S3 的靜態網站託管關閉（Properties → Static website hosting → Disable）。原因：S3 靜態託管和 CloudFront 用的是不同的存取入口——website endpoint 走的是網站端點，CloudFront 走的是 S3 的 REST API endpoint。兩個入口同時開著會造成混亂；S3 靜態託管是階梯，不是目的地（disabling-s3-website-hosting）。

重點 CloudFront 從 origin 抓檔時用的是 S3 的 REST API endpoint（object URL），不是 website endpoint。所以就算關掉靜態託管，CloudFront 依然能正常取檔。

建立 Distribution

  1. CloudFront console → Create distribution
  2. Origin：選你的 S3 bucket。名稱隨意（Steve 統一用同一個名字避免記錯）。
  3. Origin access：選「Origin access control settings (recommended)」——這會產生一個 OAC 身分，讓 CloudFront 用它存取 bucket
  4. Cache behavior：用推薦的 S3 快取設定
  5. Web Application Firewall (WAF)：可選。Steve 建議用 CloudFront 內建的 general 設定即可，可擋 DDoS 與惡意請求，成本約 $14 / 每 1 千萬次請求
  6. 按 Create distribution

它會自動幫你補 bucket policy

建立時 CloudFront 會要求你更新 bucket 的 policy。記得嗎？你之前把 `"Principal": "*"` 撤掉了——現在 CloudFront 幫你補一個更精確的版本：

{
  "Version": "2008-10-17",
  "Id": "PolicyForCloudFrontPrivateContent",
  "Statement": [{
    "Effect": "Allow",
    "Principal": {
      "Service": "cloudfront.amazonaws.com"
    },
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::你的-bucket/*",
    "Condition": {
      "StringEquals": {
        "AWS:SourceArn": "arn:aws:cloudfront::你的帳號:distribution/你的-ID"
      }
    }
  }]
}
最小權限的實踐 原本的 `Principal: "*"` 是「全世界都能讀」。現在改成：只有「你的這個 CloudFront distribution」能讀。條件用 `AWS:SourceArn` 精確鎖定到單一 distribution——這正是你學過的最小權限原則，由 AWS 幫你套用。公有網路不能直接讀 bucket，只能透過 CloudFront。

部署需要時間

distribution 要花約 5–15 分鐘才會 global deploy——因為它要把節點鋪到全球各地。Console 裡的狀態會從 In Progress 變成 Deployed。

驗證：訪問它給你的 xxxxx.cloudfront.net 網址。根路徑會先看到錯誤——這是預期的，因為還沒設定 default root object（下一步處理）。加上 /index.html 就能看到你的網站了，而且內容確實是「從 S3 來、由 CloudFront 快取」。

面試要點 「建立 CloudFront distribution 時，我選擇 OAC（Origin Access Control）作為 origin 存取方式。CloudFront 自動更新 bucket policy，把 principal 從 `*` 改成只有該 distribution 能讀——用 `AWS:SourceArn` 條件精確鎖定，體現最小權限。這讓公有網路只能透過 CloudFront 存取，不能直接連 bucket。」
