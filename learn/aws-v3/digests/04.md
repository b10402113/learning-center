# Digest — 04

## Overview (L1)

- Account alias — Create a custom alias for your AWS account that becomes a unique login URL for the console, replacing the need to remember a root email or account ID.
- Login alternatives — AWS console can be accessed via root email, account ID, or a custom alias URL.

## Sections (L2)

### account-alias

- Locator: `[[sources/aws-v3/04#account-alias]]`
- Summary: Set a custom alias in the IAM dashboard. This alias becomes part of a URL (e.g. `https://<alias>.signin.aws.amazon.com/console`) that serves as the login entry point.
- Key claims: A custom alias creates a bookmarkable, shareable login URL; the alias must be globally unique across all AWS accounts.
- Learner-relevant: Simplifies future logins — the learner no longer needs to look up an account ID or root email.

### login-alternatives

- Locator: `[[sources/aws-v3/04#login-alternatives]]`
- Summary: There are three ways to reach the AWS console login page: root user email, account ID, or the custom alias URL.
- Key claims: Root email and account ID both work but are harder to remember; the alias URL is the most convenient.
- Learner-relevant: Gives the learner options if they forget their alias — they are not locked out.
