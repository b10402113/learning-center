# Digest — 11

## Overview (L1)

- Additional S3 features — Beyond basic hosting, S3 offers server-side encryption, versioning, and access logging. These are important for production deployments.
- Server-side operations — Code examples demonstrate programmatic S3 access using the AWS SDK, showing how to upload and manage objects from code.
- Production considerations — Security features like encryption and logging become critical when serving real users with real data.

## Sections (L2)

### additional-s3-features

- Locator: `[[sources/aws-v3/11#additional-s3-features]]`
- Summary: S3 provides built-in features for production use: server-side encryption (data is encrypted at rest), versioning (preserve, retrieve, and restore every version of every object), and access logging (record who accessed what and when).
- Key claims: Encryption protects data at rest; versioning prevents accidental overwrites; access logging provides an audit trail; none are required for a static workshop site but all matter in production.
- Learner-relevant: The learner does not need these for the workshop deployment, but encountering them here prepares them to make production-grade decisions later.

### server-side-operations

- Locator: `[[sources/aws-v3/11#server-side-operations]]`
- Summary: The AWS SDK provides programmatic access to S3. Code examples show how to put and get objects, list bucket contents, and manage permissions from application code.
- Key claims: The SDK abstracts HTTP calls into method calls; put/get operations mirror the console upload/download workflow; programmatic access is how most real applications interact with S3.
- Learner-relevant: Bridges the gap between manual console operations and automated deployment — the learner sees that the same upload they did by hand can be scripted.

### production-considerations

- Locator: `[[sources/aws-v3/11#production-considerations]]`
- Summary: For real deployments, S3 features like encryption, versioning, and logging should be enabled. These protect against data loss, unauthorized access, and provide forensic capability.
- Key claims: Production deployments require encryption and logging; versioning protects against accidental deletion; these features are free or low-cost and should be on by default.
- Learner-relevant: Frames security features as standard practice, not optional extras — the learner builds the habit of thinking about security from the start.
