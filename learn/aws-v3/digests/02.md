# Digest — 02

## Overview (L1)

- Account creation — Walk through signing up for AWS with the root user: email, password, contact info, credit card, and identity verification.
- Security stakes — The root user has full access to everything. If compromised, an attacker can run up charges (e.g. Bitcoin mining). The credit card is on the line.
- The pain is front-loaded — Account setup is the hardest part. Everything after this is easier.

## Sections (L2)

### account-creation

- Locator: `[[sources/aws-v3/02#account-creation]]`
- Summary: Go to aws.amazon.com, create an account, provide root user email and password, fill in contact info, enter credit card details, and complete identity verification.
- Key claims: The root user is created at sign-up; a credit card is required; identity verification is part of the process.
- Learner-relevant: The learner needs to get through this once — it's a prerequisite for every other step in the course.

### security-stakes

- Locator: `[[sources/aws-v3/02#security-stakes]]`
- Summary: The root user has unrestricted access to all AWS resources and billing. Compromise means potential financial damage — attackers have been known to spin up instances for crypto mining.
- Key claims: Root user compromise is "game over"; credit card is directly at risk; Bitcoin mining is a real attack scenario.
- Learner-relevant: Creates urgency around protecting the root user and not using it day-to-day — motivation for the IAM admin user created in the next lesson.

### the-pain-is-front-loaded

- Locator: `[[sources/aws-v3/02#the-pain-is-front-loaded]]`
- Summary: Creating the account is the most tedious step. After that, everything else in the course gets progressively easier.
- Key claims: Account setup is the hardest part; subsequent steps are easier.
- Learner-relevant: Encouragement to push through the setup — the payoff is coming.
