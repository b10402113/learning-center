# MEMORY — aws-v3

## Goal
 Deploy a static site to S3 + CloudFront with HTTPS and a custom domain, and build enough AWS fluency to talk about it confidently in interviews.

## Why
 Get interview-ready with AWS skills — able to explain what you deployed, why you chose each service, and how the pieces connect.

## Prior experience
- React + Python FastAPI stack; comfortable with `npm run build` producing static files
- No AWS experience at all — console, CLI, services are all new
- No prior domain name or DNS configuration experience
- Has used CDNs indirectly (npm/pip package downloads are fast globally)

## Anchors
- A React project (portfolio or side project) ready to deploy
- The `npm run build → dist/` workflow as a familiar starting point
- Vercel/Netlify as a mental model for "what a CDN does" (fast global access)

## Habits & constraints
- 3–5 hours per week, evenings or weekends
- Do-first, then explain — hands-on first, concept reinforcement after
- Prefers a mix of doing and reading; avoids long lectures

## Knowledge type
 mixed — procedural (creating buckets, setting policies, configuring CloudFront) and declarative (explaining IAM, least privilege, how CDNs work for interviews). Procedural dominates early; declarative grows as interview prep deepens.

## How to teach me
 Walk me through doing it first (console + CLI), then explain what happened and why. After each hands-on session, reinforce with elements and edges so the concepts stick for interviews. Build something real, break it, fix it. No long lectures or doc-reading marathons.
