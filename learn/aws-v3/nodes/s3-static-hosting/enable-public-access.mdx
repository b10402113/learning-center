# 開啟 S3 公開存取

<LearningGoal>
關閉 S3 的公開存取封鎖，並用 bucket policy 授予公開讀取權限，避開「上傳後 403」的常見陷阱。
</LearningGoal>

## Lesson

S3 bucket 預設完全封鎖公開存取——即使你加了 bucket policy，如果封鎖還開著，S3 會無視那個 policy，檔案照樣 403。這是最常見的新手陷阱：上傳了檔案卻看到 403 Forbidden。要讓網站公開可見，必須做兩件事且缺一不可：先關閉 Public access block（在 Permissions → Block public access 取消全部勾選），再附上 bucket policy。

Bucket policy 用 JSON 格式描述權限規則。核心是 `Principal: "*"`（任何人）、`Action: "s3:GetObject"`（允許讀取）、`Resource: "arn:aws:s3:::bucket-name/*"`（bucket 裡所有物件）。這三者組合在一起的語義是：「不設限的所有人，都允許讀取這個 bucket 裡的任何物件。」

AWS 這樣設計出發點是安全——預設封閉，需要你明確地「打開門」。面試時能講清楚「兩步缺一不可」以及 policy 每個欄位的語義，就是對 S3 權限模型有紮實理解的證據。
