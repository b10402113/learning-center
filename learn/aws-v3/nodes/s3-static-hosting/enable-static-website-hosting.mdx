# 開啟靜態網站託管

<LearningGoal>
在 bucket 的 Properties 開啟靜態網站託管，並分辨 object URL 與 website endpoint URL 的差別。
</LearningGoal>

## Lesson

S3 為同一個 bucket 提供兩種 URL：Object URL（格式 `bucket.s3.region.amazonaws.com`）用於原始物件存取，顯示 XML 目錄；Website endpoint URL（格式 `bucket.s3-website-region.amazonaws.com`）用於網站託管，會把 `index.html` 當成預設文件並支援自訂 error page。對靜態網站來說，只會用到 website endpoint URL。

開啟方式是在 bucket 的 Properties → Static website hosting → Edit → Enable，設定 Index document 為 `index.html`。對於使用 client-side routing 的 SPA（如 React Router），Error document 也要設成 `index.html`——因為 S3 找不到子路由對應的 HTML 檔案時，需要返回 `index.html` 讓前端接管路由，而不是回傳 403/404。

這兩個 URL 的差別是 S3 靜態託管的核心概念：object URL 是儲存系統的入口，website endpoint 是網站託管的入口。面試時能清楚分辨兩者的格式和行為差異，以及解釋 SPA 為什麼要把 error document 設成 index.html，就能展示對 S3 託管機制的完整理解。
