# Build 出可部署的靜態產物

<LearningGoal>
跑 `npm run build`，理解輸出資料夾裡的內容，以及為什麼這個靜態產物可以直接被 S3 託管。
</LearningGoal>

## Lesson

React app 透過 `npm run build` 編譯後，會產出一個靜態資料夾（通常是 `dist/`）。裡面只有一個 `index.html` 入口、打包過的 JS 和 CSS 檔案，以及靜態資源——沒有 `node_modules`，沒有伺服器端程式碼。這是 SPA（單頁應用）的典型結構：整個網站由一個 HTML 檔案和 JavaScript 在瀏覽器端渲染出所有頁面。

S3 是物件儲存服務，它不做任何伺服器端處理——只是把檔案原封不動地透過 URL 交給瀏覽器。React 的 build 產物恰好就是純靜態檔案，不需要伺服器才能執行。所以 `dist/` 資料夾可以直接對接 S3，不需要改寫或額外處理。

流程上，你從熟悉的 `npm run build` 開始，得到靜態產物後，下一步就是把那個資料夾「搬」到 S3 上。你的前端技能——寫出好的 HTML/JS/CSS——就是你需要的全部；AWS 只是提供了一個更好的「放檔案的地方」。
