# 建立 CloudFront Distribution

<LearningGoal>
在 Console 建立 CloudFront distribution，把 S3 bucket 設為 origin，並關閉 S3 靜態網站託管。
</LearningGoal>

## Lesson

建立 CloudFront 之前，先把 S3 靜態網站託管關閉——因為兩者用不同的存取入口：S3 靜態託管走 website endpoint，CloudFront 走 S3 的 REST API endpoint。兩個入口同時開著會造成混亂；關掉靜態託管後 CloudFront 依然能正常取檔。接著在 CloudFront console 按 Create distribution：選你的 S3 bucket 作為 origin，Origin access 選擇「Origin access control settings (recommended)」，快取行為用推薦的 S3 設定，WAF 用內建 general 設定即可（可擋 DDoS，成本約 $14 / 每 1 千萬次請求），然後 Create distribution。

建立時 CloudFront 會要求你更新 bucket policy——它會補上一個比原本 `Principal: "*"` 更精確的版本：principal 改成 `cloudfront.amazonaws.com` 這個服務，`Action: s3:GetObject`，並用 `Condition: AWS:SourceArn` 精確鎖定到「你的這個 distribution」。這正是最小權限原則的實踐：公有網路不能直接讀 bucket，只能透過你的 CloudFront 存取。distribution 建立後要花約 5–15 分鐘全球部署，狀態會從 In Progress 變成 Deployed。驗證時訪問 `xxxxx.cloudfront.net` 的根路徑會先看到錯誤（尚未設定 default root object，下一步處理），加上 `/index.html` 就能看到網站——內容確實「從 S3 來、由 CloudFront 快取」。
