# S3 policies and security

## Learning goal

Write bucket policies with least privilege, understand ARNs, enable encryption and versioning

## Steps

1. [[learn/aws-v3/nodes/s3-policies-and-security/arn-format|ARN 的格式與用途]] — 理解 ARN 結構，能自行建構 bucket 和 object 的 ARN
2. [[learn/aws-v3/nodes/s3-policies-and-security/bucket-policy-structure|Bucket Policy 的四個欄位]] — 能讀寫 S3 bucket policy，掌握四欄位意義（after step 1）
3. [[learn/aws-v3/nodes/s3-policies-and-security/least-privilege-policy|實作最小權限 Policy]] — 寫出只開放必要操作的 policy，理解爆炸半徑（after step 2）
4. [[learn/aws-v3/nodes/s3-policies-and-security/encryption-and-versioning|加密、版本控制與存取日誌]] — 了解 S3 安全防護的生產級選項（after step 3）

## Lesson

S3 預設的存取控制太粗 — 要嘛全開、要嘛全關，不適合真實部署。這節課教你看懂和寫出精準的 bucket policy：先搞懂 ARN 是 S3 資源的「地址」，再拆解 policy JSON 的四個欄位，然後用最小權限原則寫出你的第一個正式 policy，最後加上加密、版本控制等生產級防護。
