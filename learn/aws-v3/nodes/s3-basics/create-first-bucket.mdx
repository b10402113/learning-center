# 建立你的第一個 S3 bucket

## Learning goal

能在 AWS Console 建立一個 S3 bucket，並理解 general purpose 型別與 region 選擇。

## Lesson

你已經知道 S3 是「用 bucket 裝物件」的物件儲存。現在實際動手，在 AWS Console 建立你的第一個 bucket。動手前先記住一條關鍵規則：**你的 bucket 名稱會被全世界共用**。登入 AWS Console，進入 S3 服務，點 Create bucket（建立儲存桶），輸入名稱、選型別、選 region，按下建立——步驟就完成了，但每一步背後都有值得懂的事。

第一件事是**名稱必須全域唯一**。這個名字在整個 AWS、所有帳號、全世界只能用一次——別人先用走，你就只能換一個。所以常見做法是加上自己的識別字，例如 `andy-portfolio-site`，確保它足夠獨特。第二件事是**型別**：建立時預設的 General purpose（一般用途）就是最標準的選擇，它取代了舊的 legacy 格式，不需要猶豫。第三件事是 **Region（區域）**：它決定你的資料實際存放在地球的哪個地區，而且會影響使用者存取你的網站的延遲。

還有兩個容易忽略的點。第一，名稱裡如果有斜線（`/`），例如 `my-app/images/logo.png`，Console 看起來像資料夾分層，但這是視覺錯覺——S3 是扁平儲存，斜線只是 key 的一部分，不是真的資料夾。第二，region 的選擇會影響延遲：使用者離哪個 region 近，存取就快。你先選一個離你近的（例如亞太區），之後可以再調整。建立完這個 bucket，下一步我們把命名規則與 region 的關係一次講透。
