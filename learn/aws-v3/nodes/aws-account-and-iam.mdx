# AWS account and IAM

## Learning goal

Set up a secure AWS account with an admin user and understand IAM's role.

## Steps

1. [[learn/aws-v3/nodes/aws-account-and-iam/create-aws-account|建立 AWS 帳號]] — 完成帳號註冊，理解 root user 的安全風險
2. [[learn/aws-v3/nodes/aws-account-and-iam/iam-concepts|IAM 概念與最小權限原則]] — 認識 IAM 的身份驗證與授權機制，讀懂 policy JSON
3. [[learn/aws-v3/nodes/aws-account-and-iam/admin-user-setup|建立 IAM 管理員群組與日常帳號]] — 建立群組、使用者、設定帳號別名（after steps 1–2）

## Lesson

部署任何 AWS 服務之前，你必須先有一個帳號。帳號一建立就會產生一個 root user——它擁有所有資源的完整權限，包括帳單。這正是為什麼你不能用 root 做日常操作：一旦被盜用，攻擊者可以立刻啟動高價運算資源（例如挖礦），而帳單是你的。

IAM（Identity and Access Management）是 AWS 的中央門禁系統。它回答兩個問題：你是誰（身份驗證），你能做什麼（授權）。透過建立群組、使用者和 policy，你可以把 root 的權限精確地分配給不同的人和程式，每個人只拿到需要的最小權限。完成這三步之後，你會有一個安全的日常登入帳號，不再需要碰 root。
