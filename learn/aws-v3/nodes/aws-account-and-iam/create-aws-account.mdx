# 建立 AWS 帳號

## Learning goal

完成 AWS 帳號註冊，並理解 root user 為什麼是全帳號最大的安全隱患。

## Lesson

部署任何 AWS 服務之前，你必須先有一個帳號。帳號一建立就會產生一個 root user——它擁有所有資源的完整權限，包括帳單。這正是為什麼你不能用 root 做日常操作：一旦被盜用，攻擊者可以立刻啟動高價運算資源（例如挖礦），而帳單是你的。

註冊過程需要 email、密碼、聯絡資訊、信用卡和身份驗證，大概 10-15 分鐘。這是整個課程中最麻煩的一步——撐過去就贏了，之後每一步都會越來越簡單。完成後，記下你的 Account ID 和 root email，登入一次確認帳號正常，然後關掉 Console。你不再需要以 root 身分登入。

Root user 就像一棟大樓的總钥匙——它能打開每一扇門、修改保全系統、甚至更改大樓所有者。你不會帶著總钥匙去買午餐，同理，你不會用 root user 去開 EC2 實例。完成帳號建立後，下一步就是建立一個 IAM 管理員帳號來取代它。
