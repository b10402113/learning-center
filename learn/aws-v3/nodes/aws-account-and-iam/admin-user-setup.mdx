# 建立 IAM 管理員群組與日常帳號

## Learning goal

在 AWS Console 建立一個帶有 AdministratorAccess 權限的 IAM 群組，建立一個日常使用的 IAM 使用者，並設定帳號別名讓登入更方便。

## Lesson

完成帳號建立和 IAM 概念理解後，下一步是建立你每天登入用的 IAM 使用者。用 root user 登入 IAM Dashboard，建立一個名為 Admins 的群組，附加 AWS Managed 的 AdministratorAccess policy——這條 policy 給了幾乎所有權限，root user 始終保留 revoke 能力，所以安全網還在。

接著建立一個 IAM 使用者（例如 daily-admin），把它加入 Admins 群組，設定密碼。以 daily-admin 登入 Console 確認能正常操作 IAM 和 S3 等服務。最後設定帳號別名——在 IAM Dashboard 的 sign-in link 區域自訂一個全球唯一的別名，讓你的登入 URL 從一串帳號 ID 變成一個容易記住的地址。

完成後，root user 收好不再日常使用，daily-admin 成為你所有後續操作的日常帳號。整個課程的剩餘部分，都以這個身份進行。
