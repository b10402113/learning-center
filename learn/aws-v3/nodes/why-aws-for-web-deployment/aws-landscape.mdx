# AWS 服務全景 — 聚焦 S3 與 CloudFront

## Learning goal

瀏覽 AWS 服務全景，聚焦到 S3 + CloudFront 這條部署路徑。

## Lesson

AWS Console 首頁展示了數十個服務——計算、儲存、資料庫、機器學習、IoT、安全——很容易讓人不知所措。但對於靜態網站部署，你只需要其中兩個核心服務：S3 負責儲存靜態檔案，CloudFront 負責全球 CDN 分發。其他數百個服務暫時與你無關。

S3 負責儲存你的 HTML、JS、CSS 和圖片檔案，並提供 URL 讓人存取。CloudFront 是 AWS 的 CDN 服務，它從你的 S3 Bucket 拉取檔案，複製到全球數十個 Edge Location，讓使用者從最近的位置取檔案。S3 + CloudFront 是 AWS 靜態網站部署的黃金組合——S3 負責存儲，CloudFront 負責全球分發。

完整的部署路徑是：<code>npm run build</code> 產生 <code>dist/</code> 資料夾 → <code>aws s3 sync</code> 把檔案同步到 S3 → CloudFront 從 S3 拉取並分發到全球 Edge Location → 使用者從最近的節點取檔案。之後你會再加入 Route 53（DNS 管理）和 ACM（免費 SSL 憑證），完成帶有 HTTPS 和自訂網域的完整部署。
