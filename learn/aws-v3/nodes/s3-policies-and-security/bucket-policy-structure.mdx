# Bucket Policy 的四個欄位

<LearningGoal>
能讀寫 S3 bucket policy，掌握 Effect / Principal / Action / Resource 四欄位的意義與互動方式。
</LearningGoal>

## Lesson

Bucket policy 是一份 JSON 文件，貼在 S3 bucket 的 Permissions 裡，由四個核心欄位組成。**Effect** 只有 `Allow` 或 `Deny` 兩個值——Deny 永遠優先於 Allow，這是 AWS 安全模型的基石。**Principal** 指定「誰」，`*` 代表所有人，也可以指定特定 IAM user、role 或 AWS 服務。**Action** 指定「做什麼操作」，公開靜態網站只需要 `s3:GetObject`（讀取），不需要 `s3:PutObject`（寫入）或 `s3:DeleteObject`（刪除）。**Resource** 用 ARN 指定「作用在哪些資源上」，通常用 `/*` 萬用字元涵蓋所有物件。四個欄位串起來就是一句完整的權限聲明：`Effect + Principal + Action + Resource = 一句話描述誰能對什麼做什麼`。
