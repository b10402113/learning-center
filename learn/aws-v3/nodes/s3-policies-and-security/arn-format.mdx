# ARN 的格式與用途

<LearningGoal>
理解 ARN 的格式與用途，能自行建構 bucket 和 object 的 ARN。
</LearningGoal>

## Lesson

ARN (Amazon Resource Name) 是 AWS 資源的唯一識別碼，格式為 `arn:partition:service:region:account:resource`。S3 是全域服務，region 和 account 欄位留空，因此 bucket ARN 有三個連續冒號：`arn:aws:s3:::bucket-name`。要涵蓋 bucket 裡的所有物件，加上 `/*` 尾碼：`arn:aws:s3:::bucket-name/*`。Bucket ARN 用於 bucket 級別操作（如 `s3:ListBucket`），Object ARN 用於物件級別操作（如 `s3:GetObject`）。ARN 出現在每一份 policy 的 `Resource` 欄位——掌握格式後，就能自行建構任何 bucket 的 policy，不必每次都查文件。
