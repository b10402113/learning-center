# 實作最小權限 Policy

<LearningGoal>
寫出一個只開放必要操作的 bucket policy，理解為什麼最小權限原則能降低爆炸半徑。
</LearningGoal>

## Lesson

最小權限原則（Principle of Least Privilege）的核心是「只給必要權限，不多給」。對於公開靜態網站，訪客只需讀取檔案，policy 應只開 `s3:GetObject` 作用在 `arn:aws:s3:::bucket/*`。用 `s3:*` 雖然省事，但授予了寫入、刪除、列出等所有操作，大幅增加爆炸半徑——一旦 API key 洩漏，攻擊者能做任何事。爆炸半徑是安全概念，指系統被入侵時損害的範圍。實戰建議：先想需求再寫 policy；用具體 ARN 而非 `*` 萬用字元；大型組織先 Deny 高風險操作再 Allow 必要的；定期用 IAM Access Analyzer 審計未使用的權限。
