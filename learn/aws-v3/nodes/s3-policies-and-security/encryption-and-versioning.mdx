# 加密、版本控制與存取日誌

<LearningGoal>
了解 S3 伺服器端加密、版本控制與存取日誌的用途與開啟方式，判斷何時需要啟用。
</LearningGoal>

## Lesson

S3 提供三個生產級安全功能：伺服器端加密、版本控制和存取日誌。**伺服器端加密**（SSE-S3）在儲存時自動加密檔案、讀取時自動解密，對應用完全透明，免費且一鍵開啟。**版本控制**保留每一個物件的每一個版本——誤刪只是加 delete marker，真實資料還在；誤覆也不會丟失舊版本。**存取日誌**記錄誰在什麼時候做了什麼操作，需要獨立的日誌 bucket 避免循環依賴。個人專案至少開 SSE-S3 + 版本控制；正式上線加上存取日誌；處理敏感資料用 SSE-KMS + MFA Delete。這些功能免費或低成本，生產環境沒有理由不開。
