# S3 static hosting

## Learning goal

Deploy a React app to S3 with public access and static website hosting

## Steps

1. [[learn/aws-v3/nodes/s3-static-hosting/build-the-app|Build 出可部署的靜態產物]] — 跑 `npm run build`，理解輸出資料夾與為何可被 S3 託管
2. [[learn/aws-v3/nodes/s3-static-hosting/enable-public-access|開啟 S3 公開存取]] — 關閉公開存取封鎖，用 bucket policy 授予公開讀取（after step 1）
3. [[learn/aws-v3/nodes/s3-static-hosting/enable-static-website-hosting|開啟靜態網站託管]] — 開啟託管、分辨 object URL 與 website endpoint URL（after step 2）
4. [[learn/aws-v3/nodes/s3-static-hosting/upload-and-deploy|上傳並驗證首次部署]] — 上傳 build 產物，開啟 website URL 驗證 app 上線（after steps 1–3）

## Lesson

這個節點把「部署一個網站到 AWS」第一次變成現實。重點在於：你上傳的不是一個程式，而是一堆靜態檔案（HTML、JS、CSS）。所以第一步先用 `npm run build` 把 React app 編譯成一個純靜態的輸出資料夾——沒有伺服器、沒有後端，只有瀏覽器能直接執行的檔案。

有了可部署的產物之後，S3 要做兩件事：第一，把 bucket 從「預設完全私有」改成允許公開讀取（關閉公開存取封鎖 + 加上 bucket policy）；第二，開啟內建的靜態網站託管，讓 S3 把這個 bucket 當成網站來服務，並給你一個專屬的網址。最後把檔案上傳進去，在瀏覽器打開那個網址，你本機的 React app 就變成了一個真的在網路上可以被任何人訪問的網站。四步走完，你就掌握了一套可重複的「build → 公開 → 託管 → 上傳」靜態部署流程。
