# Why AWS for web deployment

## Learning goal

Explain why front-end devs need AWS — static files, latency problem, CDN concept

## Steps

1. [[learn/aws-v3/nodes/why-aws-for-web-deployment/static-files-to-cloud|從 FTP 到 S3 — 靜態檔案的部署演進]] — 理解靜態檔案如何從 FTP 伺服器遷移到 S3 雲端儲存
2. [[learn/aws-v3/nodes/why-aws-for-web-deployment/latency-and-cdn|距離的代价 — 延遲問題與 CDN 概念]] — 理解距離造成的延遲問題，以及 CDN 如何透過全球分散解決它（after step 1）
3. [[learn/aws-v3/nodes/why-aws-for-web-deployment/aws-landscape|AWS 服務全景 — 聚焦 S3 與 CloudFront]] — 瀏覽 AWS 服務全景，聚焦到 S3 + CloudFront 這條部署路徑（after step 2）

## Lesson

前端開發者的核心技能——HTML、JavaScript、CSS——最終產出的是靜態檔案。這些文字檔需要被放到網路上，讓任何人透過瀏覽器存取。早期的做法是把檔案 FTP 到伺服器，但這帶來了一個根本問題：伺服器在一個城市，使用者在全球，距離會造成延遲。解決方案是把內容分散到全球各地的邊緣節點，這就是 CDN（內容傳遞網路）的概念。AWS 提供了完整的基礎設施來實現這一切，而本節點的三步會帶你走過這條路線的全貌。
