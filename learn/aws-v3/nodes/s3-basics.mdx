# S3 basics

## Learning goal

Create an S3 bucket, understand object storage vs file systems, bucket naming and regions.

## Steps

1. [[learn/aws-v3/nodes/s3-basics/what-is-s3|S3 是什麼？物件儲存與 key/value 心智模型]] — 建立「S3 = 物件儲存 + key/value」的心智模型
2. [[learn/aws-v3/nodes/s3-basics/s3-vs-file-system|物件儲存 vs 檔案系統：差異與 EFS]] — 分辨物件儲存與檔案系統的差異，知道何時該用 EFS（after step 1）
3. [[learn/aws-v3/nodes/s3-basics/create-first-bucket|建立你的第一個 S3 bucket]] — 在 Console 建立 bucket，認識型別與 region（after step 1）
4. [[learn/aws-v3/nodes/s3-basics/bucket-naming-and-regions|Bucket 命名與 Region 的關係]] — 掌握全域唯一命名、斜線資料夾錯覺與 global/regional（after step 3）

## Lesson

這個節點從「S3 到底是什麼」開始，建立物件儲存的心智模型：S3 用 bucket 裝物件，每個物件以一個 key 唯一識別，它不是檔案系統。接著把物件儲存與檔案系統攤開比較，讓你看清楚哪些操作 S3 做不到、什麼時候才需要改用 EFS。心智模型建立後，實際動手在 Console 建立第一個 bucket，最後把最容易踩坑的命名規則與 region 的關係講透。四步走完，你就能親手建好 bucket，也能向面試官解釋 S3 的物件模型、命名約束，以及全域命名空間與區域儲存之間的差別。
