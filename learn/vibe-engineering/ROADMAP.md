# ROADMAP — vibe-engineering

## Goal

Ship features via AI agents: direct an AI coding agent to build real features on real projects, reviewing plans instead of code.

## How to use

Read the paths tier by tier and in order. Tier 1 establishes the mental model; later tiers add operating rules and practice. Each path is a 10–15 minute lesson. Run `/nodes vibe-engineering/<path-id>` to confirm and start work on that path.
