# MEMORY — three-js

## Goal
打造一個 3D IC 可視化編輯器 — 能夠在 3D 場景中操控 die 和 stack，變換座標、調整大小，零延遲，即使在 200 個 die 的場景中也能流暢運作。

## Why
工作需要。現有工具無法滿足 die stacking 的快速編輯需求，團隊需要一個自定義的 3D 可視化工具。

## Prior experience
- React 框架開發
- TypeScript
- 軟體開發工程師背景
- 無 WebGL / Three.js / 3D 函式庫經驗

## Anchors
- VS Code 日常開發環境
- Claude（AI 助理協作）
- 自定義格式（非 GDS/OASIS 標準格式）
- 現有產業工具：EDA 軟體、Blender viewport、Figma 等可作為 UI/UX 參考

## Habits & constraints
- 每週約 5–8 小時（平日晚上 + 週末碎片時間）
- 無明確死線，中等壓力

## Knowledge type
Mixed — procedural-dominant。前期快速灌 declarative 基礎（場景圖、座標系統、渲染迴圈），隨後立即進入 procedural 實作。

## How to teach me
由淺入深。先建立直覺，再進入細節；概念搭配實作，避免純理論灌輸。
