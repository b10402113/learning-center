# 為什麼邊緣會出現鋸齒？

## Learning goal

## Lesson

鋸齒是因為螢幕像素是不可分割的最小單位，斜線和曲線無法對齊像素網格，只能用階梯狀的方格近似，造成邊緣呈現不平整的階梯現象。
