<LearningGoal>
掌握 `requestAnimationFrame` 的遞迴呼叫模式，理解它如何與螢幕刷新率同步、為什麼比 `setInterval` 和 `while` 迴圈更適合做渲染。
</LearningGoal>

## Lesson

用 `requestAnimationFrame` 的遞迴預約模式取代 `setInterval`，讓渲染迴圈與螢幕刷新率同步，並自動適配不同 Hz 的裝置。
