# 什麼是 Three.js

## Learning goal

理解 Three.js 是什麼、GPU/WebGL/Three.js 的技術棧，以及學習前的預備知識與文件閱讀習慣。

## Lesson

Three.js 是建於 WebGL 之上的高階 JavaScript API，把低階 GPU 繪圖包裝成直覺的物件操作，讓開發者用 JavaScript 就能在瀏覽器裡創造即時 3D。
