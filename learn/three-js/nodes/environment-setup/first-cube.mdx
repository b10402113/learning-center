# 畫出第一個 3D 方塊

## Learning goal

用 Scene、PerspectiveCamera、WebGLRenderer 和 BoxGeometry + MeshBasicMaterial 畫出第一個 mesh，理解渲染管線的基本流程。

## Lesson

每個 Three.js 應用都圍繞 Scene、Camera、Renderer 三根柱子建立；Mesh 由 Geometry 決定形狀、Material 決定外觀，呼叫 `renderer.render(scene, camera)` 就能把場景畫到 canvas 上。
