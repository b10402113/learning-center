# 安裝並匯入 Three.js

## Learning goal

安裝 three 套件、用 `import * as THREE from 'three'` 匯入，並在瀏覽器主控台確認載入成功。

## Lesson

用 `npm install three` 安裝套件，再以 `import * as THREE from 'three'` 匯入整個核心庫，這是所有 Three.js 專案的標準起點。
