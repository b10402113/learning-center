# 動畫模式

## Learning goal

用 sin/cos 做振盪動畫，frame-rate independent。

## Steps

1. [[learn/three-js/nodes/animation-patterns/animation-basics|動畫的本質：在 render loop 裡每幀動態改變 transform]] — 理解動畫 = 每幀動態改變 transform
2. [[learn/three-js/nodes/animation-patterns/clock-delta|用 Clock + delta 做 frame-rate independent 動畫]] — 用 delta 時間讓動畫速度不受幀率影響（after step 1）
3. [[learn/three-js/nodes/animation-patterns/oscillation-patterns|用 sin/cos 做 bounded 振盪動畫]] — 用 sin/cos 產生有界振盪（after step 2）

## Lesson

這一節把之前學到的 transform 和 render loop 串成動畫。第一步理解動畫的本質：在 render loop 裡面每一幀都去動 mesh 的 position、rotation 或 scale，就會產生運動——跟黏土動畫一樣，先微調、再拍攝、再微拍，連續起來就是動畫。

第二步學 frame-rate independent 的寫法。直接用 `+= speed` 會讓動畫在 144Hz 螢幕上比 60Hz 快三倍多，解法是引入 `THREE.Clock`，把每幀的速度乘上 `delta`（離上幀過了幾秒），這樣不管螢幕跑多少幀，物件每秒移動的距離都一樣。

第三步學振盪。線性成長的動畫（`position += 0.01`）會無限增長直到漂出畫面，而 `Math.sin(time)` 永遠在 -1 到 1 之間來回。把 sin 套到 position 或 scale 上，就能做出呼吸般的縮放、漂浮、旋轉，而且永遠不會跑掉。
