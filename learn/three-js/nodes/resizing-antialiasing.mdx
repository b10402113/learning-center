# 視窗調整與抗鋸齒

## Learning goal

處理 window resize、devicePixelRatio、antialiasing。

## Steps

1. [[learn/three-js/nodes/resizing-antialiasing/resize-recipe|視窗調整的標準做法]] — 用 resize 事件更新 renderer 與 camera
2. [[learn/three-js/nodes/resizing-antialiasing/aliasing-cause|為什麼邊緣會出現鋸齒？]] — 理解像素網格造成的階梯現象（after step 1）
3. [[learn/three-js/nodes/resizing-antialiasing/antialiasing-solutions|抗鋸齒的兩大路線]] — 硬體（高像素密度）與軟體（邊緣柔化）的取捨（after step 2）
4. [[learn/three-js/nodes/resizing-antialiasing/antialiasing-practice|在程式裡實作抗鋸齒]] — setPixelRatio 與 antialias 旗標的實際寫法（after steps 1, 3）

## Lesson

瀏覽器視窗大小隨時會變，但 Three.js 的渲染器不會自動跟上。這一節教你在視窗改變時，如何同時更新渲染器尺寸與攝影機比例，讓畫面不變形。同時，旋轉的方塊邊緣會出現鋸齒狀的階梯，這是因為螢幕像素是的最小單位無法渲染半個像素。我們會在實作中比較兩種解決方案：提高像素密度（硬體）與在邊緣做顏色漸層（軟體），最後用一行程式碼把兩者組合進你的渲染器。
