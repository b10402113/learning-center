# WebGLRenderer 畫面上屏

## Learning goal

能建立 WebGLRenderer、綁定 canvas、設定尺寸，並呼叫 `renderer.render()` 完成第一幀。

## Lesson

 WebGLRenderer 需要綁定 canvas、用 setSize 設定輸出尺寸，並呼叫 renderer.render(scene, camera) 才能畫出第一幀。
