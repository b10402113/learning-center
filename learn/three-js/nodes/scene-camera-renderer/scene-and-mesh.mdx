# Scene 容器與第一個 Mesh

## Learning goal

能建立 Scene、組合 Geometry + Material 為 Mesh，並用 `scene.add()` 加入場景。

## Lesson

 Scene 是容器，Mesh 是 Geometry Material 的組合；建立 Mesh 後必須用 scene.add() 放進場景，Renderer 才會畫它。
