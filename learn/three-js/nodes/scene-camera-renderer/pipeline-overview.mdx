# 三大支柱：Scene、Camera、Renderer

## Learning goal

能說出 Scene、Camera、Renderer 各自的角色，並畫出它們之間的資料流。

## Lesson

 Scene、Camera、Renderer 是 Three.js 的三大支柱：Scene 是容器，Camera 決定視角，Renderer 把場景算成圖片輸出到 canvas。
