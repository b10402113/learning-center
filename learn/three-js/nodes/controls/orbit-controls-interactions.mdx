# 滑鼠互動與渲染迴圈整合

## Learning goal

理解 OrbitControls 的三種滑鼠操作（旋轉、平移、縮放），並知道controls 必須在渲染迴圈中持續運作才能即時回應。

## Lesson

OrbitControls 提供左鍵旋轉、右鍵平移、滾輪縮放三種基本操作，必須在 requestAnimationFrame 渲染迴圈中持續渲染才能即時回應；啟用 damping 或 autoRotate 時則必須每幀呼叫 controls.update()。
