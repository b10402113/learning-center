# Damping、AutoRotate 與其他控件

## Learning goal

能設定 damping 和 autoRotate 讓視角控制更自然，並了解 FlyControls、TrackballControls、DragControls 等替代控件的使用場景。

## Lesson

Damping 讓旋轉有慣性、autoRotate 讓場景自動展示，兩者都需在 animate() 中呼叫 controls.update()；OrbitControls 適合俯視型編輯器，FlyControls、TrackballControls、DragControls 則分別對應飛行模擬、自由旋轉、物件拖拽等場景。
