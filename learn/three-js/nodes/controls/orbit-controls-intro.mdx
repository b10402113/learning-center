# 引入 OrbitControls

## Learning goal

能從 three/addons 正確引入 OrbitControls，完成初始化並理解它需要的兩個參數。

## Lesson

OrbitControls 是 Three.js 的附加控件，需從 three/addons/controls/OrbitControls.js 導入，初始化時傳入 camera 與 renderer.domElement，並搭配渲染迴圈才能即時回應操作。
