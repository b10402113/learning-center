# 搭建 Three.js 環境

## Learning goal

Vite + TypeScript 起一個能顯示 3D 方塊的頁面，理解 Three.js 是什麼、為什麼用它、以及如何把第一個 mesh 畫到螢幕上。

## Steps

1. [[learn/three-js/nodes/environment-setup/what-is-threejs|什麼是 Three.js]] — 理解 Three.js 是什麼、GPU/WebGL/Three.js 技術棧，以及學習前的預備知識。
2. [[learn/three-js/nodes/environment-setup/vite-toolchain|Vite 開發工具鏈]] — 用 Node.js + npm + Vite 架起開發伺服器。
3. [[learn/three-js/nodes/environment-setup/install-three|安裝並匯入 Three.js]] — 安裝 three 套件並用 `import * as THREE from 'three'` 匯入。
4. [[learn/three-js/nodes/environment-setup/first-cube|畫出第一個 3D 方塊]] — 用 Scene、Camera、Renderer 和 BoxGeometry 畫出第一個 mesh。

## Lesson

這個節點帶你從零到第一個 3D 方塊出現在瀏覽器上。我們會先理解 Three.js 在 Web 圖形棧中的位置——它是建在 WebGL 之上的高階 JavaScript API，幫我們避開低階 GPU 繪圖的複雜度，同時保留足夠的彈性。接著用 Vite 搭建TypeScript 開發環境，這會讓之後的模組匯入、_hot reload_ 和打包都順暢許多。

安裝 `three` 套件後，我們用 `import * as THREE from 'three'` 把整個核心庫匯進專案，這就是所有 Three.js 專案的標準起點。最後一步，我們會建立三個核心物件——**Scene**（容納所有物件的容器）、**PerspectiveCamera**（決定觀眾看到什麼）和 **WebGLRenderer**（把場景畫到 canvas 上），再加上一個由 `BoxGeometry` 和 `MeshBasicMaterial` 組成的方塊，完成第一個渲染管線。

你不需要 WebGL 經驗就能完成這個節點。Three.js 的價值就在於：你只要會 JavaScript，就能在瀏覽器裡創造即時 3D。之後的節點會繼續擴充這個骨架，加入攝影機控制、光照、材質，最終讓你建出能編輯 200 個 die 的 3D IC 編輯器。
