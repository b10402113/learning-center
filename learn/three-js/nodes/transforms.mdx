# 物件變換

## Learning goal

能移動/旋轉/縮放物件，理解 Euler 旋轉順序。

## Steps

1. [[learn/three-js/nodes/transforms/scale-transforms|Scale 縮放變換]] — 能使用 scale 屬性縮放物件，理解 per-axis 與 set() 的差異
2. [[learn/three-js/nodes/transforms/rotation-basics|Rotation 基礎與可視化]] — 能設置 rotation 屬性並用 wireframe + AxisHelper 可視化旋轉
3. [[learn/three-js/nodes/transforms/euler-and-reorder|Euler 角度與旋轉順序]] — 理解 rotation 是 Euler 弧度，能轉換度數並用 reorder 修正旋轉順序（after step 2）

## Lesson

物件的三大變換屬性 — `position`、`rotation`、`scale` — 都是同一個 `Object3D` 的內建屬性，它們決定了物件在三維空間中的位置、朝向和大小。`position` 和 `Vector3` 已經在座標系統一節學過；本節先補齊 `scale`，再深入 `rotation` — 它不是 `Vector3`，而是一個 `Euler` 角度物件，默認用弧度表示旋轉，XYZ 順序影響最終朝向。學完之後，你能在場景中隨意移動、旋轉、縮放任何物件，也知道為什麼轉 X 再轉 Y 跟轉 Y 再轉 X 的結果會不一樣。
