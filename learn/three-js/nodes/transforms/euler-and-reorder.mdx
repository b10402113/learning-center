# Euler 角度與旋轉順序

## Learning goal

理解 rotation 是 Euler 弧度，能轉換度數並用 reorder 修正旋轉順序。

## Lesson

<code>rotation</code> 是 <code>Euler</code> 弧度，預設以 XYZ 順序套用三軸旋轉——<code>MathUtils.degToRad()</code> 轉換度數，<code>.reorder()</code> 修正奇怪的旋轉順序。
