# Rotation 基礎與可視化

## Learning goal

能設置 rotation 屬性並用 wireframe + AxisHelper 可視化旋轉。

## Lesson

<code>rotation</code> 是 <code>Euler</code> 角，三軸用弧度控制繞對應軸的旋轉——<code>MathUtils.degToRad()</code> 可把度數轉成弧度，wireframe 模式與 AxisHelper 讓旋轉可視化。
