# Scale 縮放變換

## Learning goal

能使用 scale 屬性縮放物件，理解 per-axis 與 set() 的差異。

## Lesson

<code>scale</code> 是一個 <code>Vector3</code>，三軸獨立控制物件的縮放倍率——per-axis 指派只動單軸，<code>set()</code> 一次覆寫三軸，<code>setScalar()</code> 等比例縮放，負值會翻轉物件。
