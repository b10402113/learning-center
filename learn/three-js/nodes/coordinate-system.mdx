# 座標系統

## Learning goal

理解 AxesHelper、Vector3、世界座標 vs 本地座標。

## Steps

1. [[learn/three-js/nodes/coordinate-system/axes-and-units|座標軸與單位]] — 用 AxesHelper 定位方向，理解 Three.js 的相對單位慣例
2. [[learn/three-js/nodes/coordinate-system/vector3-and-position|Vector3 與位置屬性]] — 理解 position 是 Vector3 實例，繼承自 Object3D（在 step 1 之後）
3. [[learn/three-js/nodes/coordinate-system/spatial-operations|空間操作：距離與鄰近偵測]] — 用 copy() 與 distance2() 計算距離（在 step 2 之後）

## Lesson

在三維場景中，每個物件都透過一個數學上的「向量」來描述自己的位置。Three.js 把這個向量封裝成 `Vector3` 類別，掛在每個 `Object3D` 的 `position` 屬性上。理解座標系統的第一步，是先用 `AxesHelper` 把抽象的 x、y、z 軸畫出來：紅色是 x 軸（右），綠色是 y 軸（上），藍色是 z軸（朝向攝影機）。當你移動物件時，就是在修改這個 `Vector3` 的 x、y、z 值。

Three.js 的單位是相對的，你可以自行定義「1 單位 = 1 公尺」或其他慣例，只要整份專案保持一致。`Vector3` 不只是三個數字的容器，它還提供 `copy()`、`distance2()` 等方法，讓你不需要自己寫數學就能計算兩個物件之間的距離。這在 IC 編輯器中很實用——例如判斷滑鼠游標是否靠近某個 die，或是在 200 個 die 之間做碰撞偵測。
