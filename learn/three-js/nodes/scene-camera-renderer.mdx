# 場景、攝影機、渲染器

## Learning goal

理解 Scene → Camera → Renderer 管線，第一個 mesh 畫上畫面。

## Steps

1. [[learn/three-js/nodes/scene-camera-renderer/pipeline-overview|三大支柱：Scene、Camera、Renderer]] — 能說出三者的角色與資料流
2. [[learn/three-js/nodes/scene-camera-renderer/scene-and-mesh|Scene 容器與第一個 Mesh]] — 建立場景、組合 mesh（after step 1）
3. [[learn/three-js/nodes/scene-camera-renderer/camera-setup|PerspectiveCamera 與視角定位]] — 建立攝影機、定位（after step 1）
4. [[learn/three-js/nodes/scene-camera-renderer/renderer-to-canvas|WebGLRenderer 畫面上屏]] — 綁定 canvas、呼叫 render（after steps 2–3）

## Lesson

 這個節點把 Three.js 的核心管線拆成四步：先理解 Scene、Camera、Renderer 三大支柱的角色與資料流，再學會建立 Scene 容器並把第一個 Mesh（Geometry + Material）放進去，接著設定 PerspectiveCamera 的四個參數並把攝影機拉回 Z 軸，最後用 WebGLRenderer 綁定 canvas、設定尺寸、呼叫 render() 完成第一幀。四步走完，你就具備了「把任何物件畫上畫面」的基礎能力，後面的節點會在這個骨架上加入燈光、材質、動畫和互動。
