# OrthographicCamera 參數與寬高比校正

<LearningGoal>
理解 OrthographicCamera 的參數意義、無透視特性，以及如何用寬高比校正避免畫面拉伸。
</LearningGoal>

## Lesson

OrthographicCamera 用六個距離值定義可視盒子，物體大小不隨距離改變，但直接用 -1,1,-1,1 會在矩形螢幕上產生拉伸，必須將 left/right 乘以螢幕寬高比才能校正。
