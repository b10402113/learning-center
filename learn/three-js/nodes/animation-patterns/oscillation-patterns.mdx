<LearningGoal>

</LearningGoal>

## Lesson

用 Math.sin 和 Math.cos 產生有界振盪來做動畫，透過公式 value = base + amplitude × sin(time × frequency) 可以做出呼吸縮放、上下漂浮、左右擺動等效果，由於 sin/cos 永遠在 -1 到 1 之間來回，動畫不會像線性累加那樣漂出畫面，適合需要反覆運動的視覺效果。
