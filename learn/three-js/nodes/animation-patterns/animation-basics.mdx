<LearningGoal>
理解動畫的本質：在 render loop 裡每幀動態改變 transform，就能讓靜止的 mesh 動起來。
</LearningGoal>

## Lesson

動畫的本質是在 render loop 裡每幀動態改變 mesh 的 transform（position、rotation、scale），就像黏土動畫先微調再拍攝的流程一樣，利用 requestAnimationFrame 每秒約 60 次的呼叫頻率，讓連續的靜態畫面產生運動感。
