# 場景層級

## Learning goal

理解父子關係、Group、變換繼承。

## Steps

1. [[learn/three-js/nodes/scene-hierarchy/group-as-container|Group 是什麼，如何建立父子關係]] — 理解 Group 作為隱形容器，並建立父子關係
2. [[learn/three-js/nodes/scene-hierarchy/transform-inheritance|變換繼承：子物件如何繼承父物件的移動、旋轉、縮放]] — 理解變換疊加（after step 1）
3. [[learn/three-js/nodes/scene-hierarchy/local-vs-world|本地座標 vs 世界座標]] — 區分本地與世界座標（after steps 1–2）
4. [[learn/three-js/nodes/scene-hierarchy/practical-hierarchy|實戰：用 Group 組織 die/stack 場景]] — 用 Group 分層組織場景（after steps 2–3）

## Lesson

這個節點帶你離開「單一物件」的世界，進入 Three.js 真正的組織能力：場景層級。第一步先認識 Group——一個看不見的 3D 容器，你能把多個 mesh 放進去，再把 Group 放進場景。第二步理解「變換繼承」：當你移動 Group 時，裡面的所有 child 會跟著動，但 child 之間互不干擾。第三步把這個概念拆得更細——每個物件的 `position` 是相對於它的父物件，不是相對於世界原點；這解釋了為什麼把 child 的 `position.y` 設成 `-1`，它在畫面上是往「父物件的下方」移動，而不是往世界下方。第四步把前三步的知識用在實際場景：把 die 和 stack 用 Group 分層，之後做動畫或互動時，就能整群移動而不亂。四步走完，你就具備了「組織複雜場景」的能力，這是從「範例玩具」走向「IC 編輯器」的關鍵一步。
