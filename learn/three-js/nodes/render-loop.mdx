# 渲染迴圈

## Learning goal

用 requestAnimationFrame + Clock 寫出零延遲 render loop。

## Steps

1. [[learn/three-js/nodes/render-loop/why-render-loop|為什麼需要渲染迴圈]] — 理解單次渲染的限制與渲染迴圈的角色
2. [[learn/three-js/nodes/render-loop/request-animation-frame|requestAnimationFrame 渲染迴圈]] — 掌握遞迴呼叫模式與螢幕刷新率同步（after step 1）
3. [[learn/three-js/nodes/render-loop/clock-and-delta|THREE.Clock 與影格獨立時間]] — 用 `getDelta()` 實現影格率獨立動畫（after step 2）
4. [[learn/three-js/nodes/render-loop/complete-render-loop|完整渲染迴圈與 controls.update()]] — 組合出零延遲的完整迴圈（after step 3）

## Lesson

這個節點把 Three.js 應用從「畫一張圖」升級到「持續動畫」。我們會先理解為什麼單次 `renderer.render()` 無法呈現動畫與互動，接著用 `requestAnimationFrame` 建立與螢幕刷新率同步的渲染迴圈，再用 `THREE.Clock` 的 `getDelta()` 讓動畫在不同影格率的裝置上保持一致速度，最後把 `controls.update()` 與動畫更新放進迴圈，寫出零延遲的完整渲染迴圈。
