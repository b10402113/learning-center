# 變換繼承：子物件如何繼承父物件的移動、旋轉、縮放

## Learning goal

理解子物件的變換如何與父物件的變換疊加，並能預測移動父物件時子物件的最終位置。

## Lesson

子物件的移動、旋轉、縮放會與父物件的變換疊加——移動相加、旋轉相加、縮放相乘，Three.js 在渲染時自動把每一層的本地變換計算成世界變換。
