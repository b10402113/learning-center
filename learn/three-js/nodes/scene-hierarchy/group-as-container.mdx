# Group 是什麼，如何建立父子關係

## Learning goal

理解 Group 作為隱形容器的角色，並能用 `scene.add(group)` 與 `group.add(mesh)` 建立父子關係。

## Lesson

Group 是 Three.js 的隱形容器，用 `scene.add(group)` 與 `group.add(mesh)` 建立父子關係後，child 的本地座標就是相對於 Group 的值，不是世界原點。
