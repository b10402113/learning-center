# 實戰：用 Group 組織 die/stack 場景

## Learning goal

能將場景中的多個物件用 Group 分層組織，並理解層級結構對后续動畫與互動的影響。

## Lesson

IC 編輯器的 stack/die 結構天然適合用 Group 分層——每個 stack 是一個 Group，移動整疊 die 只要操作 stackGroup，巢套 Group（waferGroup 包 stackGroup）能進一步對應真實世界的容器結構。
