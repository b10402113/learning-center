# 本地座標 vs 世界座標

## Learning goal

區分本地座標與世界座標，並理解 `position` 是相對於父物件而非世界原點。

## Lesson

每個物件的 `position` 都是本地座標，相對於父物件而非世界原點；巢狀結構中，Three.js 從外到內依次乘加每一層的本地座標，最終算出世界座標。
