Step 1 / 3 · 動畫模式

動畫的本質：在 render loop 裡每幀動態改變 transform

理解動畫的本質：在 render loop 裡每幀動態改變 transform，就能讓靜止的 mesh 動起來。

黏土動畫類比

想像你在做黏土動畫（claymation）。流程很簡單：

  1. 微調黏土的形狀
  2. 拍一張照片
  3. 再微調一點
  4. 再拍一張
  5. 把所有照片快速播放——動畫出現了

Three.js 的動畫完全一樣。你的 render loop 就是那個「每秒拍 60 張照片」的攝影機，而你要做的，就是在每次「拍照」之前，把 mesh 的屬性改一點。

render loop 的角色

之前學過 renderer.render(scene, camera) 叫一次就畫一張圖。要讓它變成動畫，你需要一個迴圈不停呼叫它：

function animate() {
  requestAnimationFrame(animate);  // 下一幀再執行

  // 這裡放 transform 變化
  cube.rotation.x += 0.01;

  renderer.render(scene, camera);  // 拍一張
}
animate();

requestAnimationFrame 會在瀏覽器下一個重繪時刻呼叫你的函式，通常是每秒 60 次（60 FPS）。每次呼叫時，你先改變 mesh 的 transform，再呼叫 renderer——跟黏土動畫一樣，先微調、再拍攝。

動態 transform = 動畫

動畫的本質就是每幀動態改變 transform。你可以改變任何 transform 屬性：

  • mesh.position.x += 0.01 — 往右移
  • mesh.rotation.y += 0.02 — 繞 Y 軸旋轉
  • mesh.scale.x = 1 + Math.sin(time) — 呼吸般的縮放

重要觀念：render loop 裡的任何 transform 變化，都會在下一幀被渲染出來。這就是從「靜態物件」到「動態動畫」的橋樑。

為什麼要學這個？

之前你學了 position、rotation、scale 這些 transform，但它們都是「設定一次就停在那裡」。動畫把它們從「靜態設定」變成「每幀更新」。這是 Three.js 所有互動視覺效果的基礎——不管是物件旋轉、鏡頭移動、還是粒子飄動，都是同一個模式：render loop 裡的動態 transform。
