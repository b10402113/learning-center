Damping、AutoRotate 與其他控件

能設定 damping 和 autoRotate 讓視角控制更自然，並了解 FlyControls、TrackballControls、DragControls 等替代控件的使用場景。

Damping：讓旋轉有慣性

預設情況下，你一放開滑鼠，旋轉就立刻停下。這在操作精密物件時會覺得「太硬」。Damping（阻尼）讓旋轉像有摩擦力一樣，慢慢停下來，手感更自然。

controls.enableDamping = true;   // 開啟阻尼
controls.dampingFactor = 0.05;   // 阻尼係數，越小越滑順
dampingFactor 手感 適用場景
0.01 – 0.05 非常滑順，停下來很慢 展示用、簡報
0.05 – 0.1 適中，有慣性但不會太慢 一般 3D 編輯器
0.1 – 0.3 較硬，幾乎等於無阻尼 需要精準定位的場景
開啟 damping 之後，一定要在 animate() 裡呼叫 controls.update()，否則阻尼效果不會運作。

AutoRotate：自動展示

有時候你希望場景自己轉，像產品展示或背景動畫。autoRotate 讓攝影機繞著目標點不停旋轉，不需要使用者操作。

controls.autoRotate = true;
controls.autoRotateSpeed = 2.0;  // 旋轉速度，越大越快

當使用者開始拖拽時，autoRotate 會暫停，放開後繼續轉。這讓自動展示和手動操作可以並存。

同樣地，開啟 autoRotate 也必須在 animate() 裡呼叫 controls.update()。

限制旋轉角度

在 IC 編輯器裡，你可能不希望使用者把場景轉到「倒過來」。OrbitControls 提供角度限制：

controls.minPolarAngle = 0;                // 垂直旋轉上限（0 = 從正上方看）
controls.maxPolarAngle = Math.PI / 2;      // 垂直旋轉下限（PI/2 = 不能看到水平面以下）
controls.minAzimuthAngle = -Math.PI / 4;   // 水平旋轉左限
controls.maxAzimuthAngle = Math.PI / 4;    // 水平旋轉右限

把 maxPolarAngle 設為 Math.PI / 2，就能防止使用者把視角轉到物體正下方，這在俯視型的編輯器裡很實用。

其他 Controls 一覽

OrbitControls 是最常用的，但 Three.js 還提供其他導航控件，適合不同場景：

控件 操作方式 典型用途
FlyControls 滑鼠指向 + WASD 鍵 飛機式飛行模擬，第一人稱探索
FirstPersonControls 滑鼠看 + WASD 移動 FPS 遊戲風格，有重力感
TrackballControls 自由旋轉，無垂直限位 需要任意角度觀看的場景
DragControls 直接拖拽場景物件 移動物體本身，不是移攝影機

對 IC 編輯器來說，OrbitControls 是首選，因為它符合「從上方俯視、偶爾旋轉查看」的操作直覺。DragControls 在需要拖拽 die 的時候會用到，但那屬於後面的互動節點。

完整設定範例

const controls = new OrbitControls(camera, renderer.domElement);

controls.enableDamping = true;
controls.dampingFactor = 0.05;
controls.autoRotate = false;
controls.target.set(0, 0, 0);
controls.maxPolarAngle = Math.PI / 2;

function animate() {
  requestAnimationFrame(animate);
  controls.update();
  renderer.render(scene, camera);
}
animate();

這個設定組合在多數 3D 編輯器裡都是好的起點：有阻尼、不自動旋轉、不能轉到水平面以下。
