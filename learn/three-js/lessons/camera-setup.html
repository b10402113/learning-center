PerspectiveCamera 與視角定位

能建立 PerspectiveCamera、設定四個參數，並把攝影機拉回 Z 軸使物體可見。

PerspectiveCamera 的四個參數

建立一個透視攝影機需要四個數字：

const camera = new THREE.PerspectiveCamera(fov, aspect, near, far);
參數 意義 常見值
fov 視野（field of view），垂直方向的可見角度。越大看到的範圍越廣，但物體越小。 75（教學預設）
aspect 寬高比。必須等於 canvas 的寬除以高，否則畫面會變形。 window.innerWidth / innerHeight
near 近裁面。比這個距離更近的物體會被裁切掉，不顯示。 0.1
far 遠裁面。比這個距離更遠的物體會被裁切掉，不顯示。 1000

為什麼 fov 是垂直角度？

fov 指的是垂直方向的可見角度，不是水平。這是攝影和遊戲產業的慣例。一個 75° 的 fov 在垂直方向看到 75°，水平方向看到的範圍會更廣（因為螢幕是橫的）。

攝影常用的參考值：35°–50° 看起來接近人眼，75° 是 Three.js 教學的預設值，超過 90° 會有明顯的魚眼變形。

aspect 為什麼要用除法？

寬高比（aspect ratio）如果不對，圓會變成橢圓、正方體會被拉長。最簡單的做法是讓它跟著視窗尺寸走：

const aspect = window.innerWidth / window.innerHeight;
const camera = new THREE.PerspectiveCamera(75, aspect, 0.1, 1000);

當視窗大小改變時，你必須重新計算 aspect 並通知攝影機：camera.aspect = newAspect; camera.updateProjectionMatrix();。這在後面的「視窗調整」節點會詳細教。

把攝影機拉回 Z 軸

Mesh 和 Camera 預設都誕生在座標原點 (0, 0, 0)。如果攝影機和物體重疊，什麼也看不到。所以我們要把攝影機沿著 Z 軸往後拉：

camera.position.z = 5;

Three.js 的預設攝影機是沿著 -Z 方向看的。所以把攝影機放在 Z = 5，它就會往 -Z 方向看，正好看到原點附近的物體。

物體放在原點、攝影機放在 Z = 5，這是一個最起手的標準配置。

near 和 far 的裁切作用

near 和 far 定義了攝影機的可見範圍。任何比 near 更近或比 far 更遠的物體都不會被畫出來。這個機制叫做視錐裁切（frustum culling）。

設定時要注意：near 不能設為 0，far 不能設為無限大。兩者之間差距過大會影響深度精度。一般場景用 0.1 到 1000 就很夠用。
