Step 2 / 4 · 搭建 Three.js 環境

Vite 開發工具鏈

用 Node.js + npm + Vite 架起開發伺服器，理解為什麼需要 build tool 以及如何跑起第一個本地頁面。

為什麼需要 Build Tool？

你可能想過直接在 HTML 裡寫 <script src="three.js"> 就好——為什麼還需要 npm、Vite 這些工具？原因有二：

  1. 模組匯入：現代 JavaScript 用 ES modules（import / export）組織程式碼。瀏覽器支援 ES modules，但它們不允許從本地檔案直接載入模組（安全限制）。
  2. 開發體驗：Vite 提供即時伺服器（改一個檔案，瀏覽器秒更新），而且在打包階段會自動最佳化你的程式碼。

簡單說：沒有 Vite，你就得手動管理檔案路徑、手動刷新頁面。有 Vite，你就專注在寫程式碼就好。

三個必要工具

Node.js
讓 JavaScript 能在你的電腦（而非瀏覽器）上跑。npm 就是跟著 Node.js 一起裝的。
npm（Node Package Manager）
專案的「套件管理員」。你寫的專案可能用到 Three.js、Vite 等套件，npm 負責下載並管理它們的版本。
Vite
開發伺服器 + 打包工具。關鍵特色：伺服器啟動瞬間、熱模組置換（Hot Module Replacement, HMR），以及最佳化的打包輸出。

實戰：從零架起專案

打開終端機，依序執行：

# 1. 用 npm 建立一個 Vite 專案（選 Vanilla 或 TypeScript）
npm create vite@latest my-three-app

# 2. 進到專案目錄
cd my-three-app

# 3. 安裝所有依賴（從 package.json 讀取並下載）
npm install

# 4. 啟動開發伺服器
npm run dev

執行 npm run dev 後，終端機會顯示一個本地網址（通常是 http://localhost:5173）。在瀏覽器打開它，你會看到 Vite 的預設頁面。

專案目錄長什麼樣？

架起來之後，你的專案目錄大概長這樣：

my-three-app/
├── index.html          ← 入口頁面
├── package.json        ← 專案設定，記錄所有依賴
├── vite.config.js      ← Vite 設定（預設就好，不用改）
├── src/
│   ├── main.js         ← 你寫程式碼的主檔案
│   └── style.css       ← 預設樣式
└── node_modules/       ← npm 下載的套件（不用管它）

重點：src/main.js 是你的主戰場，index.html 是瀏覽器載入的頁面。Vite 會自動把 main.js 注入到 index.html 裡。

HMR：為什麼改一行就秒更新？

Vite 的熱模組置換（Hot Module Replacement）讓你在不重新整理頁面的情況下，直接替換你改過的模組。例如你改了 main.js 的某一行，瀏覽器會在幾百毫秒內更新畫面，而不需要重跑整個專案。這是 Vite 比舊式 bundler 快很多的原因之一。
