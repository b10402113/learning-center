Rotation 基礎與可視化

three-js / transforms / step 2 — 約 8 分鐘

Learning goal

能設置 rotation 屬性並用 wireframe + AxisHelper 可視化旋轉。

Lesson

物件的第二大變換屬性是 rotation。與 position 和 scale 一樣，它掛在 mesh 上，可以直接操作。但 rotation 不是 Vector3——它是一個 Euler 角度物件（下一節會深入），先來學最直觀的用法。

旋轉的基本操作

假設你有一個方塊，想讓它繞著 Y 軸轉 90 度：

// 用弧度：Math.PI / 2 = 90°
mesh.rotation.y = Math.PI / 2;

或者用度數（更直觀，但需要轉換）：

// 需要 MathUtils.degToRad
import { MathUtils } from 'three';
mesh.rotation.y = MathUtils.degToRad(90);

無論用弧度還是度數，最終效果一樣。rotation 的三個分量（x, y, z）分別控制繞對應軸的旋轉量。

可視化工具：wireframe + AxisHelper

當你旋轉一個實心 mesh 時，很難直覺看出它繞著哪個軸轉。解決辦法有兩個，可以同時用：

1. Wireframe 模式：把材質設成 wireframe，讓 mesh 只顯示邊線。

const material = new THREE.MeshBasicMaterial({ wireframe: true });
const mesh = new THREE.Mesh(geometry, material);

wireframe 模式下，旋轉軸在視覺上清晰很多。在 IC 編輯器的場景調整階段，wireframe 是非常實用的 debug 模式。

2. AxisHelper：Three.js 提供一個三軸紅綠藍的小物件，放在場景裡可以看 X/Y/Z 的方向。

const axes = new THREE.AxesHelper(5); // 長度 5 的三軸
scene.add(axes);

AxisHelper 的三條線：紅色 = X、綠色 = Y、藍色 = Z。它預設不跟著 mesh 移動，所以你要把它加成 mesh 的子物件才能追蹤。

另一個做法是把 AxisHelper 當成 mesh 的子節點：

mesh.add(axes); // axes 跟著 mesh 一起動

Rotation 的本質

在 Three.js 裡，rotation 的值不是 Vector3，而是 Euler（歐拉角）。這帶來一個微妙的差異：Vector3 的三個分量互不干擾，但 Euler 的三個角度是有「順序」的——先轉 X 再轉 Y，跟先轉 Y 再轉 X，結果會不同。下一節會深入。

記住一個直覺：rotation 的 x、y、z 分量分別控制繞 X（紅）、Y（綠）、Z（藍）軸的旋轉。把這個顏色記住，搭配 AxisHelper 的顏色，你就知道「mesh.rotation.y = …」到底是讓物件繞哪條軸在轉。

Key takeaways

  • rotation 有 x/y/z 三個分量，分別控制繞對應軸的旋轉。
  • 值的單位是弧度，用 MathUtils.degToRad(角度) 可以把度數轉成弧度。
  • Wireframe 模式（material.wireframe = true）讓旋轉可視化。
  • AxisHelper 的顏色：紅 = X，綠 = Y，藍 = Z。
  • rotation 是 Euler 角，有旋轉順序問題，下一節會討論。
