引入 OrbitControls

能從 three/addons 正確引入 OrbitControls，完成初始化並理解它需要的兩個參數。

OrbitControls 不是核心套件

Three.js 核心套件只負責場景、攝影機、渲染器這些基礎元件。視角控制屬於「附加功能（addons）」，放在 three/addons/ 資料夾裡。OrbitControls 已經隨 three 一起安裝好了，不需要額外下載，但必須用正確的路径導入：

import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
路徑最後是 OrbitControls.js，不是 OrbitControls。省略副檔名在某些打包器會報錯，直接寫全名最穩。

初始化需要兩個東西

OrbitControls 的建構式需要兩個參數：攝影機和 DOM 元素。

const controls = new OrbitControls(camera, renderer.domElement);
參數 傳入什麼 為什麼需要
camera 場景中已建立的攝影機 OrbitControls 會根據滑鼠操作調整攝影機的位置和角度
renderer.domElement renderer 對應的 canvas 元素 OrbitControls 要在這個 DOM 元素上監聽滑鼠和觸控事件

把 renderer.domElement 傳入，而不是自己手動選 canvas。這樣能確保控件監聽的元素和渲染器輸出的元素是同一個。

單次渲染看不到效果

如果只呼叫一次 renderer.render(scene, camera)，就算加了 OrbitControls，畫面也不會動。因為 OrbitControls 只是改變了攝影機的狀態，你必須在每一幀重新渲染，才能看到攝影機位置的變化。這就是為什麼 OrbitControls 必須搭配渲染迴圈（render loop）使用——我們會在下一步詳細說明。

最小可運作的程式碼

import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();

renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);

function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();

到這一步，你已經可以用滑鼠操作視角了。但畫面會感覺「卡卡的」，因為我們還沒教 OrbitControls 如何平滑移動。
