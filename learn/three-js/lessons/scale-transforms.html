Scale 縮放變換

three-js / transforms / step 1 — 約 8 分鐘

Learning goal

能使用 scale 屬性縮放物件，理解 per-axis 與 set() 的差異。

Lesson

拿到一個 mesh 之後，除了移動它，最直接的操作就是改變大小。Three.js 把這件看似簡單的事設計得異常一致：scale 跟 position 一樣，都是一個 Vector3。也就是說，mesh.scale.x、mesh.scale.y、mesh.scale.z 分別代表物件在三軸上的縮放倍率，預設值都是 1。

假設你有一個方塊，想要它在 Y 軸上變成兩倍高，你會直接寫：

mesh.scale.y = 2;

這行代碼把 Y 軸的縮放倍率設為 2，X 和 Z 保持不動。如果你想要三個軸一次設好，則用 scale.set(x, y, z)：

mesh.scale.set(2, 1, 1); // X 兩倍，Y、Z 不變

set() 會一口氣覆寫三個值。如果你發現某軸該是 0.5 卻忘了設，set() 不會幫你保留舊值——它只認你傳進去的數字。

另外一個常用操作是「等比例縮放」。Three.js 提供了 scale.setScalar(v)，把三個軸同時設成同一個值：

mesh.scale.setScalar(0.5); // 整體縮小一半

這比自己寫 scale.set(0.5, 0.5, 0.5) 乾淨，也比較不會漏掉某一軸。

縮放還有幾個容易踩到的坑。scale 的值可以是負數——負值會把物件沿著該軸翻轉。這在做鏡像效果時很有用，但如果在算表面法線或碰撞偵測時忽略負 scale，結果會很奇怪。另外，scale 是相對於物件自己的本地座標系；如果物件有父節點，最終效果會跟父節點的縮放相乘。

在 IC 編輯器裡，scale 的實際用途之一就是根據 die 的實際尺寸調整方塊大小。如果一個 die 是 10mm × 20mm × 1mm，你可以直接把 scale 設成 (10, 20, 1)，再搭配一個單位立方體當基礎 mesh，就能快速把實際尺寸「套」上去。

Key takeaways

  • scale 是 Vector3，三軸獨立控制。
  • Per-axis 指派（mesh.scale.y = 2）只動該軸。
  • scale.set(x, y, z) 一次覆寫三軸。
  • scale.setScalar(v) 等比例縮放。
  • 負值會翻轉物件，父子層級的 scale 會相乘。
