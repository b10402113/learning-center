Step 2 / 4

變換繼承：子物件如何繼承父物件的移動、旋轉、縮放

理解子物件的變換如何與父物件的變換疊加，並能預測移動父物件時子物件的最終位置。

移動父物件，子物件跟著動

上一節你學會了把 mesh 放進 Group。現在來觀察一個關鍵行為：當你改變 Group 的 position，裡面的所有 child mesh 都會跟著移動。

group.position.x = 2;  // Group 往右移 2 個單位
// Group 裡面的 box 和 sphere 也會一起往右移 2 個單位

這就是變換繼承（transform inheritance）：child 會繼承 parent 的移動、旋轉、縮放。你不需要手動更新每個 child，Three.js 在渲染時會自動把 parent 的變換和 child 的變換疊加起來。

兩層疊加，不是覆蓋

繼承不是覆蓋。假設 Group 在 x = 2，而 Group 裡面的 box 在 Group 的本地座標裡設了 x = 1。box 在世界座標上的最終位置是 2 + 1 = 3，不是 1，也不是 2。

層級 本地 position.x 世界 position.x
Group 2 2
box（在 Group 裡面） 1 3

這個「本地 + 父級 = 世界」的規則是 Three.js 場景層級的核心。只要理解這一行，後面所有巢狀結構都暢通無阻。

旋轉也會繼承

旋轉的繼承方式一模一樣。把 Group 旋轉 90 度，裡面的所有 child 都會跟著轉 90 度——但 child 自己的旋轉是額外疊加上去的。

group.rotation.y = Math.PI / 2;  // Group 繞 Y 軸轉 90 度
box.rotation.y = Math.PI / 4;      // box 自己再繞 Y 軸轉 45 度
// box 最終的世界旋轉 = 90 + 45 = 135 度

這讓你能做出像太陽系這樣的結構：太陽自轉，地球繞太陽轉，月球繞地球轉——每一層只關心自己的本地旋轉，外層的旋轉會自動被繼承。

縮放也會繼承，而且會相乘

縮放同樣會繼承，但它的規則是相乘，不是相加。如果 Group 的 scale.x = 2，而 child 的 scale.x = 3，child 在世界座標上的最終縮放是 2 × 3 = 6。

group.scale.set(2, 2, 2);   // Group 放大兩倍
box.scale.set(3, 3, 3);       // box 自己再放大三倍
// box 最終的世界縮放 = 2 × 3 = 6 倍

這個乘法規則在巢狀多層時會一直累積。如果你發現某個 mesh 被意外放大或縮小，記得往上檢查每一層 Group 的 scale 值。
