滑鼠互動與渲染迴圈整合

理解 OrbitControls 的三種滑鼠操作（旋轉、平移、縮放），並知道 controls 必須在渲染迴圈中持續運作才能即時回應。

三種基本操作

OrbitControls 把滑鼠的三種操作對應到三種視角變化。記住這些預設行為，你在操作 3D 場景時就不會覺得「畫面亂跑」。

操作 滑鼠動作 效果
旋轉（Rotate） 左鍵拖拽 攝影機繞著目標點旋轉，就像繞著物件飛行
平移（Pan） 右鍵拖拽 攝影機和目標點一起平移，畫面平行移動
縮放（Zoom） 滾輪前後滾 攝影機靠近或遠離目標點，物體變大或變小
在 Mac 的觸控板上，雙指拖拽通常是平移，雙指捏合是旋轉。OrbitControls 會根據不同裝置自動對應。

為什麼需要渲染迴圈

OrbitControls 只是根據滑鼠事件去「改攝影機的位置和角度」。如果你只渲染一次，攝影機位置變了，但畫面沒有重新繪製，所以看起來沒反應。

渲染迴圈（render loop）就是一個不斷重複的函式，每一幀都重新畫一次畫面。把放進 requestAnimationFrame 的遞迴迴圈，就能和螢幕刷新率同步：

function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();

到這一步，拖拽滑鼠就能看到畫面即時跟著動了。

controls.update() 的時機

OrbitControls 有一個 update() 方法。在預設情況下（沒有開 damping、沒有開 autoRotate），你不需要手動呼叫它——OrbitControls 會在內部根據滑鼠事件自動更新攝影機。

但如果你啟用了 damping（阻尼）或 autoRotate（自動旋轉），就必須在每一幀呼叫 controls.update()，否則這些效果不會運作：

function animate() {
  requestAnimationFrame(animate);
  controls.update();  // 啟用 damping 或 autoRotate 時必須呼叫
  renderer.render(scene, camera);
}
現在先記住這個規則。下一課會實際設定 damping 和 autoRotate，到時候你就知道為什麼這裡要加那一行。

target：旋轉的中心點

OrbitControls 預設繞著原點 (0, 0, 0) 旋轉。如果你的物件不在原點，操作起來會覺得「飛很遠」。你可以透過 controls.target 改變旋轉中心：

controls.target.set(2, 1, 0);  // 把旋轉中心移到 (2, 1, 0)
controls.update();           // 改了 target 之後要呼叫 update 才會生效

這在 IC 編輯器裡很實用——你可以把旋轉中心設到整個 die 陣列的正中央，操作起來更直覺。
