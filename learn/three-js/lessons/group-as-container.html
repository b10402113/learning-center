Group 是什麼，如何建立父子關係

理解 Group 作為隱形容器的角色，並能用 scene.add(group) 與 group.add(mesh) 建立父子關係。

從單一物件到一群物件

到目前為止，我們都是一個一個把 mesh 放進 Scene。但現實場景很少是散落的零件——你可能想讓整組物件一起移動、一起旋轉、一起縮放。這時候你需要一個「資料夾」把物件打包起來，Three.js 把這個資料夾叫做 Group。

Group 是一個看不見的 3D 物件。它沒有形狀、沒有材質、不會出現在畫面上，但它有兩個關鍵能力：它能成為其他物件的父物件（parent），也能被放進 Scene 或另一個 Group 裡。

建立父子關係的兩步

把一個 mesh 放進 Group，需要兩行：

const group = new THREE.Group();
scene.add(group);          // 第一步：把 Group 放進場景
group.add(mesh);           // 第二步：把 mesh 放進 Group

第一行建立 Group。第二行把 Group 掛到 Scene 下面。第三行把 mesh 掛到 Group 下面——從這一刻起，mesh 的父物件就是 Group，不是 Scene。

掛好之後，mesh 的 position、rotation、scale 都是相對於 Group 的值，不是相對於世界原點。這個「相對」的概念會在下一步變得至關重要。

Group 就像桌面上的資料夾

電腦桌面 Three.js 場景
資料夾本身不顯示內容，只是一個容器 Group 本身不可見，只是一個隱形容器
把檔案拖進資料夾，檔案就歸它管 用 group.add(mesh)，mesh 就歸它管
移動資料夾，裡面的檔案跟著動 移動 Group，所有 child mesh 跟著動
資料夾可以巢狀——資料夾裡還有資料夾 Group 裡面可以再放 Group，形成巢狀結構

一個 Group 可以放多個 child

Group 不只限於一個 mesh。你可以一口氣把盒子、球體、圓柱都放進去，它們就變成同一國的：

const box = new THREE.Mesh(geometry, material);
const sphere = new THREE.Mesh(geometry2, material2);
const cylinder = new THREE.Mesh(geometry3, material3);

group.add(box);
group.add(sphere);
group.add(cylinder);
// 現在移動 group，三個 mesh 會一起動

三個 mesh 之間仍然是獨立的——你可以單獨調整 sphere 的位置，讓它偏離 box 一段距離，這個距離是相對於 Group 的本地座標，不是世界座標。
