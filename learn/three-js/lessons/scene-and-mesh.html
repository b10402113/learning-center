Scene 容器與第一個 Mesh

能建立 Scene、組合 Geometry + Material 為 Mesh，並用 scene.add() 加入場景。

Scene 是容器，不是自動收納盒

建立一個 Scene 只是創造一個空的容器。之後你建立的任何物件——網格、燈光、攝影機——都不會自動出現在場景裡。你必須顯式呼叫 scene.add() 把它們放進去。

這是新手最常踩的坑：明明建立了 mesh，畫面卻全白。原因幾乎都是忘了 scene.add(mesh)。

Mesh = Geometry + Material

一個看得見的 3D 物件叫做 Mesh（網格）。它由兩部分組成：

  • Geometry（幾何體）：描述物件的形狀——頂點、面、尺寸。例如 BoxGeometry 就是一個長方體。
  • Material（材質）：描述物件的表面外觀——顏色、光澤、是否受光影響。例如 MeshBasicMaterial 就是一個不受光、純色的材質。

把兩者組合起來，就是一個完整的 Mesh：

const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const cube = new THREE.Mesh(geometry, material);

為什麼用 MeshBasicMaterial？

第一幀的教學通常使用 MeshBasicMaterial，因為它不受場景燈光影響。你設什麼顏色，它就是什麼顏色。這讓初學者可以專注在「把東西放進場景並看到它」，而不必先搞懂光照系統。

缺點是它看起來很平、沒有立體感。等你加入燈光之後，就會換成 MeshStandardMaterial 這類受光材質。

加入場景：scene.add()

建立 mesh 之後，還要把它放進 Scene 的階層裡，Renderer 才會知道要畫它：

scene.add(cube);

Scene 的階層是樹狀的：Scene 是根，下面可以有多個子物件，子物件下面還可以有子物件。父物件移動、旋轉、縮放時，子物件會跟著動。這個機制在之後做動畫和群組時會經常用到。

完整第一幀程式碼

把到目前為止的概念組合起來，就是一個最簡範例：

const scene = new THREE.Scene();

const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const cube = new THREE.Mesh(geometry, material);

scene.add(cube);

// 注意：還沒有 Camera 和 Renderer，所以這行程式碼還不會畫出東西
