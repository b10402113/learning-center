Vector3 與位置屬性

Three.js 座標系統 · Step 2/3
你以為 position 只是三個數字？其實它是一個「向量物件」，內建了十幾種數學方法。
學會 Vector3，你就不用自己寫三角函數了。

觀察：position 不只是三個數字

上一課我們學到，改變 cubeMesh.position.y = 1 會移動物件。但 position 真正的身份不是三個獨立變數，而是一個 Vector3 實例——一個封裝了 x、y、z 的物件。

你可以在 console 裡面印出來看看：

console.log(cubeMesh.position)
// Vector3 { x: 0, y: 1, z: 0 }

這個 Vector3 不是 Three.js 自己明的，而是從 Object3D 繼承來的。Object3D 是所有三維物件的基礎類別，除了 position，它還提供了 rotation 和 scale——這兩個屬性也是向量類（Euler 和 Vector3）。

理解：Object3D 是物件的「基底」

在 Three.js 裡，幾乎所有你能加進場景的東西——Mesh、Light、Group——都繼承自 Object3D。這表示它們全部都有位置、旋轉、縮放這些屬性。

屬性型別用途
positionVector3物件在三維空間中的座標
rotationEuler物件繞各軸的旋轉角度
scaleVector3物件在各軸的縮放倍率

因為這些屬性都是物件（不只是數字），它們內建了方法。Vector3 提供的工具包括：copy()、distanceTo()、set()、add()、clone() 等等。

理解：Vector3 的實用方法

直接用程式碼操作 Vector3，比手動改 x、y、z 更安全、更好讀：

// 一次設定三個座標
cubeMesh.position.set(2, 3, 4)

// 把 A 的位置複製給 B
meshA.position.copy(meshB.position)

// 克隆一份，避免參照同一個物件
const saved = cubeMesh.position.clone()

注意 copy() 和 clone() 的差別：copy() 是把別人的值複製到「我」身上；clone() 是創造一個全新的 Vector3 副本。
