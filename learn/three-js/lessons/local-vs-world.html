本地座標 vs 世界座標

區分本地座標與世界座標，並理解 position 是相對於父物件而非世界原點。

每個 position 都是相對的

上一節學到 child 會繼承 parent 的變換。這一節要把這個概念拆得更精確：每個物件的 position 都是相對於它的父物件，不是相對於世界原點。

當一個 mesh 直接掛在 Scene 下面，它的父物件就是 Scene，而 Scene 的世界原點就是 (0, 0, 0)。這時候 mesh 的本地座標剛好等於世界座標，所以你會誤以為 position 是絕對的。

但一旦 mesh 被放進 Group，它的本地座標就變成相對於 Group 的位置。Group 移動，mesh 就跟著移動——但 mesh 自己的 position 數值沒有變。

一個實際的數字例子

// Group 放在世界座標 (5, 0, 0)
group.position.x = 5;

// box 放在 Group 裡面的 (0, -1, 0)
box.position.y = -1;

box 的 position.y = -1 是什麼意思？它的意思是「在 Group 的座標系裡，往下 1 個單位」。因為 Group 本身在世界的 x = 5，所以 box 最終會出現在世界的 (5, -1, 0)。

如果你把 Group 移動到 x = 10，box 會跟著跑到 (10, -1, 0)——box 自己的 position.y 從頭到尾都是 -1，但它的世界位置變了。

本地座標 vs 世界座標對照表

座標系 參考點 什麼時候用
本地座標（local） 父物件的位置 設定 child 在 parent 內部的相對位置
世界座標（world） Scene 的原點 (0,0,0) 計算物件在整個場景中的絕對位置

Three.js 的 position 屬性永遠是本地座標。如果你需要取得物件的世界座標，可以用 mesh.getWorldPosition(vec) 來計算。

巢狀結構會一直累加

如果 Group 裡面還有 Group，本地座標的參考點就是各自的父物件。每一層只關心自己的 parent，Three.js 在渲染時會從最外層一路乘加到最內層。

scene.position = (0, 0, 0)
  └─ groupA.position = (2, 0, 0)     // 世界 = (2, 0, 0)
      └─ groupB.position = (0, 3, 0) // 世界 = (2, 3, 0)
          └─ box.position = (1, 0, 0) // 世界 = (3, 3, 0)

box 的世界座標是 (3, 3, 0)：x 來自 groupA 的 2 加上 box 的 1，y 來自 groupB 的 3。每一層的本地座標都只參考自己的 parent。
