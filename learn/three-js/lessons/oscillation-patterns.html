用 sin/cos 做 bounded 振盪動畫

用 Math.sin 與 Math.cos 產生有界振盪，做出呼吸、漂浮、縮放等不會漂出畫面的動畫效果。

線性動畫的問題

之前的寫法：mesh.position.x += 0.01 * delta。這會讓方塊一直往右走，直到漂出畫面外。如果你想要「反覆來回」或「原地呼吸」，線性成長用不上。

你需要一個函式，它的輸出永遠在一個範圍內來回震盪，不會無限變大或變小。

Math.sin 的magic

Math.sin(x) 永遠回傳 -1 到 1 之間的值：

  • Math.sin(0) = 0
  • Math.sin(π/2) = 1
  • Math.sin(π) = 0
  • Math.sin(3π/2) = -1
  • Math.sin(2π) = 0（週期重複）

把 x 換成時間 time，Math.sin(time) 就會跟著時間在 -1 和 1 之間來回震盪。

三種經典振盪效果

1. 呼吸縮放（Pulsing Scale）

const time = clock.getElapsedTime();
mesh.scale.x = 1 + Math.sin(time) * 0.5;
mesh.scale.y = 1 + Math.sin(time) * 0.5;

縮放比例會在 0.5 到 1.5 之間來回，像呼吸一樣。

2. 上下漂浮（Bobbing）

const time = clock.getElapsedTime();
mesh.position.y = Math.sin(time) * 2;

物件會在 y = -2 到 y = 2 之間上下漂浮。

3. 左右擺動（Swinging）

const time = clock.getElapsedTime();
mesh.rotation.z = Math.sin(time) * 0.5;

物件會在 -0.5 到 0.5 弧度之間左右搖擺。

調整公式：base + amplitude × sin

通用公式：value = base + amplitude × Math.sin(time × frequency)

  • base：中心值（振盪的中點）
  • amplitude：振幅（離開中點的最大距離）
  • frequency：頻率（乘以 time，控制震盪速度）

例如 mesh.position.y = 3 + Math.sin(time * 2) * 1.5 代表：中心在 y=3，振幅 1.5，每秒來回 2 次。

sin vs cos

Math.sin 和 Math.cos 形狀完全一樣，只是差了 90 度（π/2）的相位：

  • sin(0) = 0，從中間開始往上
  • cos(0) = 1，從最高點開始往下

如果你想要兩個物件「反向振盪」（一個往上時另一個往下），一個用 sin，另一個用 cos 就行了。

負值的副作用

注意：Math.sin 會回傳負值。如果你把 sin 直接套到 mesh.scale 上，scale 會變負，導致 mesh「翻面」（面朝內）。

解法：mesh.scale.x = 1 + Math.sin(time) * 0.5，讓 scale 維持在正數範圍。

完整程式碼：漂浮的方塊

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const time = clock.getElapsedTime();

  // 上下漂浮
  mesh.position.y = Math.sin(time) * 2;

  // 同時呼吸縮放
  mesh.scale.x = 1 + Math.sin(time) * 0.3;
  mesh.scale.y = 1 + Math.sin(time) * 0.3;
  mesh.scale.z = 1 + Math.sin(time) * 0.3;

  renderer.render(scene, camera);
}
animate();

一個方塊同時漂浮和呼吸，兩種效果用同一個 time 參數就能組合。
