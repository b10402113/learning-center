Step 1 / 4 · 攝影機類型

PerspectiveCamera 四參數與相機位置

理解 PerspectiveCamera 四個參數的意義、aspect ratio 如何影響畫面比例，以及相機位置與觀察方向的關係。

為什麼需要攝影機？

在 Three.js 裡，場景（Scene）只是物件的容器。要讓這些物件變成螢幕上的 2D 圖片，你需要一個「觀察者」——這就是攝影機（Camera）。攝影機決定了兩件事：從哪裡看（位置）和怎麼看（投影方式）。

Three.js 最常用的攝影機是 PerspectiveCamera（透視攝影機），它的行為最接近人類眼睛：近處物體看起來大、遠處物體看起來小。

四個參數決定一切

建立一個 PerspectiveCamera 需要四個數字：

const camera = new THREE.PerspectiveCamera(fov, aspect, near, far);
參數意義常見值
fov視野角度（Field of View），單位是度。越大看到的越多，越小越像望遠鏡。75
aspect寬高比。寬度除以高度，通常等於螢幕比例。window.innerWidth / window.innerHeight
near近裁剪面。比這個距離更近的物體會被切掉，看不到。0.1
far遠裁剪面。比這個距離更遠的物體也會被切掉。1000

aspect ratio 為什麼重要？

如果 aspect 不等於螢幕的實際寬高比，畫面會變形——圓會變橢圓，正方形會變長方形。最簡單的做法是讓它跟著視窗尺寸走：

const aspect = window.innerWidth / window.innerHeight;
const camera = new THREE.PerspectiveCamera(75, aspect, 0.1, 1000);

當視窗大小改變時，你必須更新這個值，否則畫面又會變形。這就是為什麼在渲染迴圈或 resize 事件裡，常會看到 camera.aspect = newAspect; camera.updateProjectionMatrix();。

相機位置與觀察方向

攝影機和所有物件一樣，預設都出生在原點 (0, 0, 0)。如果你把一個方塊也放在原點，相機就會「貼在方塊臉上」，什麼都看不到。

解法：把相機沿著 Z 軸往後移。Three.js 的攝影機預設往 -Z 方向看，所以把相機放到正 Z 位置，就能拍到原點的物體：

camera.position.z = 5;

這行程式碼的意思是：「我站在 z=5 的位置，往 -Z 方向看，所以原點附近的物體都在我視線內。」

第一個可運作的攝影機

把上面幾段組合起來，就是一個最簡單的透視攝影機設定：

const camera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);
camera.position.z = 5;

這四行程式碼就是幾乎所有 Three.js 專案的起點。下一步我們會深入 fov 和 near/far 的視覺意義，理解它們「為什麼」這樣設計。
