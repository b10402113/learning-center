WebGLRenderer 畫面上屏

能建立 WebGLRenderer、綁定 canvas、設定尺寸，並呼叫 renderer.render() 完成第一幀。

Renderer 需要一個 canvas

WebGLRenderer 是 Three.js 和瀏覽器繪圖系統之間的橋樑。它需要一個 canvas 元素當作畫布。這個 canvas 必須已經存在於 HTML 裡，Renderer 才能綁上去。

HTML 裡先放一個 canvas：

<canvas class="threejs"></canvas>

JavaScript 裡用 document.querySelector 找到它，再傳給 Renderer：

const canvas = document.querySelector('canvas.threejs');
const renderer = new THREE.WebGLRenderer({ canvas });

setSize：告訴 Renderer 畫多大

Renderer 預設的輸出尺寸很小（通常 800x600），不會自動填滿視窗。你必須用 setSize 明確告訴它畫布的像素尺寸：

renderer.setSize(window.innerWidth, window.innerHeight);

如果不呼叫 setSize，畫面會很小、被裁切，或者看起來像一個縮圖貼在左上角。

render()：畫出一幀

有了 Scene、Camera、Renderer 之後，只要呼叫一次 render 就能畫出第一幀：

renderer.render(scene, camera);

這個呼叫會把 Scene 裡所有物件，依 Camera 的視角，算成一張圖片寫進 canvas。

但要注意：只畫一幀。如果之後移動物件或改變視角，必須再呼叫一次 render 才會更新畫面。要讓畫面持續動起來，就要在渲染迴圈裡每秒呼叫約 60 次——這會在「渲染迴圈」節點詳細教。

完整最小範例

把四個步驟全部組合起來，就是一個能畫出紅色方塊的最簡 Three.js 程式：

// 1. Scene
const scene = new THREE.Scene();

// 2. Mesh
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 3. Camera
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 5;

// 4. Renderer
const canvas = document.querySelector('canvas.threejs');
const renderer = new THREE.WebGLRenderer({ canvas });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.render(scene, camera);

常見錯誤排查

症狀 可能原因
畫面全黑或全白 Camera 和物體重疊，或 Camera 沒有對到物體
畫面很小或裁切 忘了呼叫 renderer.setSize()
圓變橢圓 aspect 不等於 canvas 寬高比
完全沒畫面 canvas 不存在於 DOM，或選擇器寫錯
