Step 3 / 4 · 搭建 Three.js 環境

安裝並匯入 Three.js

安裝 three 套件、用 `import * as THREE from 'three'` 匯入，並在瀏覽器主控台確認載入成功。

把 Three.js 加進專案

在上一課我們用 Vite 架好了專案。現在要把 Three.js 裝進來。在終端機執行：

npm install three

npm 會做兩件事：把 three 套件下載到 node_modules/，並在 package.json 的 dependencies 裡記錄「這個專案需要 three 這個套件」。

標準匯入寫法

打開 src/main.js，在最上面加入這一行：

import * as THREE from 'three';

這行的意思是：從 node_modules/three 匯出「整個核心庫」，放進一個叫 THREE 的物件裡。之後你要用任何 Three.js 功能，就是 THREE.場景名稱。例如：

  • THREE.Scene — 場景
  • THREE.PerspectiveCamera — 透視攝影機
  • THREE.WebGLRenderer — 渲染器
  • THREE.BoxGeometry — 方塊幾何體

THREE 這個命名是社群慣例，幾乎所有 Three.js 範例和文件都這樣寫。不要自作聰明改成 import * as T from 'three'——你会跟全世界格格不入。

確認載入成功：打開瀏覽器主控台

在 main.js 裡加一行：

import * as THREE from 'three';
console.log(THREE);

接著：

  1. 確保 Vite 開發伺服器還在跑（npm run dev）。
  2. 在瀏覽器打開 http://localhost:5173。
  3. 按 Shift + Cmd + C（Mac）或 Shift + Ctrl + C（Windows）打開開發者工具，切到 Console 分頁。

你應該會看到主控台印出一個巨大的物件——那就是 Three.js 核心庫的所有內容。如果你看到 undefined 或錯誤訊息，代表匯入路徑有問題。

為什麼是 import * as THREE而不是 import { Scene }？

兩種寫法都可以，但 import * as THREE 有幾個好處：

  • 命名空間清晰：new THREE.Scene() 比 new Scene() 更容易追蹤來源。
  • 範例一致：官方文件、教學、Stack Overflow 上的答案都用 THREE 前綴。你現在就習慣這個模式，之後看別人程式碼才不會卡住。
  • 自動完成更友善：在 VS Code 打 THREE. 就能看到所有可用的類別。
