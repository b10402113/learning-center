Step 4 / 4 · 搭建 Three.js 環境

畫出第一個 3D 方塊

用 Scene、PerspectiveCamera、WebGLRenderer 和 BoxGeometry + MeshBasicMaterial 畫出第一個 mesh，理解渲染管線的基本流程。

Three.js 的三根柱子

每一個 Three.js 應用程式都離不開這三個物件：

Scene（場景）
一個容器，裝著所有你想畫的東西——網格、燈光、背景。物件必須用 scene.add(obj) 放進場景裡，否則畫不出來。
Camera（攝影機）
決定「觀眾從哪個角度看這個世界」。透視攝影機（PerspectiveCamera）模擬人眼：愈遠的東西看起來愈小。
Renderer（渲染器）
把 Scene 和 Camera 的資訊，變成螢幕上的一個 2D 圖片。你要它畫一次，它就畫一次。

Mesh = Geometry + Material

Scene 裡面放的不是抽象物件，而是網格（Mesh）。一個 Mesh 由兩部分組成：

  • Geometry（幾何體）：決定「形狀」。Three.js 內建了方塊、球體、平面等現成幾何體。BoxGeometry(width, height, depth) 就是一個長方體。
  • Material（材質）：決定「表面看起來如何」。MeshBasicMaterial 是最簡單的材質——它不理會燈光，就是單純塗上你指定的顏色。

把它們合起來：new THREE.Mesh(geometry, material)。

完整程式碼：第一個方塊

把 src/main.js 清空，貼上這段：

import * as THREE from 'three';

// 1. 建立場景
const scene = new THREE.Scene();

// 2. 建立攝影機
const camera = new THREE.PerspectiveCamera(
  75,                                   // 視野角度（FOV）
  window.innerWidth / window.innerHeight, // 寬高比
  0.1,                                  // 近裁剪面
  1000                                  // 遠裁剪面
);
camera.position.z = 5; // 把攝影機往後拉，否則會和方塊重疊

// 3. 建立渲染器，綁定到 canvas
const canvas = document.querySelector('canvas.threejs');
const renderer = new THREE.WebGLRenderer({ canvas });
renderer.setSize(window.innerWidth, window.innerHeight);

// 4. 建立方塊網格
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 5. 渲染一次
renderer.render(scene, camera);

同時，在 index.html 的 <body> 裡加上 <canvas class="threejs"></canvas>。

為什麼方塊是黑色的？

如果你看到一個黑色方塊，別緊張——這是對的。MeshBasicMaterial 不理會燈光，所以它顯示的就是你指定的顏色（綠色 0x00ff00）。如果看起來是黑色，通常是因為：

  • 攝影機位置不對（方塊在攝影機後面或被裁剪）。
  • Canvas 尺寸是 0（忘記加 CSS 或 setSize）。

確認 camera.position.z = 5 有寫，而且 renderer.setSize 有正確設定。

Hollywood 類比

你可以這樣記憶三根柱子的關係：

  • Scene = 片場，所有演員和道具都在這裡。
  • Camera = 攝影師，決定鏡頭要拍哪裡。
  • Renderer = 底片，把攝影師看到的畫面沖洗成照片。

每「拍一張照片」，就是呼叫一次 renderer.render(scene, camera)。之後學到 render loop 時，你會讓它每秒拍 60 張，形成動畫。
