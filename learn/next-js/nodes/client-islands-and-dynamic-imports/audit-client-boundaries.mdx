# 驗收 AI 的 client 邊界：一張檢查表

<LearningGoal>
拿到一份 AI 產出的 Next.js 元件樹，能用判別問句抓出 `"use client"` 濫用、漏掉的 dynamic import（ssr:false），以及被拉進 client bundle 的 server component。
</LearningGoal>

## Lesson

驗收 client 邊界就是在元件樹上依序問五個問題——需要互動嗎、邊界掛在哪一層、import 了什麼、有沒有把 server component 拉進 client、browser-only 套件有沒有搭 `ssr: false`；留在 server 最便宜、client island 要小、dynamic import 是最後手段，而規則在高度互動的區塊刻意翻轉。
