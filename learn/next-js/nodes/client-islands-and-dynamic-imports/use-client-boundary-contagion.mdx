# "use client" 的傳染性：邊界是怎麼擴散的？

<LearningGoal>
能解釋 `"use client"` 是一個「子樹標記」，被它引入的模組（包含原本的 server component）都會被打包進 client bundle，並指出「把 `"use client"` 掛太高」和「在 client 裡 import server component」這兩種常見錯誤。
</LearningGoal>

## Lesson

`"use client"` 是模組層級的子樹標記：被它 import 的模組，包含原本的 server component 與第三方套件，都會被打包進 client bundle；正解是把 client 推到真正互動的葉節點，別把指令掛在 page / layout / 大容器上，也別在 client component 裡 import server component。
