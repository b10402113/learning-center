# client-only 套件：為什麼 MDX editor 與 next-themes 不能直接在 server 跑？

<LearningGoal>
能辨認哪些第三方套件是 browser-only（MDX editor、next-themes），說明它們為什麼會在 server render 出錯，並知道正解是把 client-only 的部分隔離成一個 client island。
</LearningGoal>

## Lesson

有一類第三方套件是 browser-only（MDX editor 需要 DOM、next-themes 需要 localStorage），加 `"use client"` 只讓它變成 client code，仍會在 server 被預先渲染而爆 `window is not defined`；正解是把 client-only 的部分隔離成小島——provider 用薄的 client 包裝，需 DOM 的元件再用 `next/dynamic` + `ssr: false`，把 `"use client"` 的範圍壓到最小。
