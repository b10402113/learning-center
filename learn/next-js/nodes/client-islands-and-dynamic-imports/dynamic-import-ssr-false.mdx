# 用 `next/dynamic` + `ssr:false` 隔離 browser-only 元件

<LearningGoal>
能用 `next/dynamic` + `ssr:false` 把 browser-only 元件（MDX editor）動態載入，並把它的 value / onChange 接進 react-hook-form。
</LearningGoal>

## Lesson

在 client component 裡用 `const Comp = dynamic(() => import(...), { ssr: false })` 取代靜態 import，讓 browser-only 模組完全不經伺服器渲染；被載入的模組自己仍要標 `"use client"`，再用 ref 與 `value` / `fieldChange` 把它接上 react-hook-form，build 就不再爆 `window is not defined`。
