# 動態區段與 params

<LearningGoal>
用方括號 `[param]` 建立動態路由，並解釋 `params` 的值與 key 各自從哪裡來。
</LearningGoal>

## Lesson

把資料夾名稱用方括號包起來（例如 `[slug]`）就建立了動態區段，讓一個 `page` 檔案服務無限多條同結構的 URL；Next.js 會把網址裡實際那段值包成 `params` 傳給頁面，而 key 就是你方括號裡取的名字（`[id]` 對 `params.id`），在 Next.js 15 取值前記得 `await`。
