# 實戰：從資料夾樹推導完整路由樹

<LearningGoal>
拿到一棵真實的 `app/` 資料夾樹，能逐步推導出每一條路由、每個 URL 區段對應的檔案，以及每層 layout 的包覆關係。
</LearningGoal>

## Lesson

推導路由樹的固定流程：先列出所有 `page` 檔，把括號資料夾從 URL 移除，逐層拼出每條路徑（動態區段標成變數），再從 `app/` 往上收集每一層 `layout.tsx` 得到外框鏈；真實專案用 `(auth)`／`(root)` 兩組各套不同外框，而且靜態區段（`/profile/edit`）會優先於動態區段（`/profile/:id`）被匹配。
