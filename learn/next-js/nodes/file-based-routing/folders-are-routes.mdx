# 資料夾就是路由：檔案路由的第一條規則

<LearningGoal>
說出檔案路由的兩條規則（資料夾定義 URL 區段、page 檔定義該區段的 UI），並解釋它如何取代 React Router 的設定檔。
</LearningGoal>

## Lesson

Next.js 的檔案路由只有兩條規則：資料夾定義 URL 區段、`page` 檔定義該區段的 UI；它把 React Router 那種要手動維護的路由設定檔換成「資料夾結構本身就是路由」，因此不需要外部套件，資料夾命名（小寫、kebab case）就直接決定 URL。
