# 巢狀路由與巢狀 layout

<LearningGoal>
由巢狀資料夾推出巢狀 URL，並說明每一層 layout 如何包住它的子樹、透過 children 串成一條外框鏈。
</LearningGoal>

## Lesson

巢狀資料夾產生巢狀 URL（每一段斜線就是資料夾樹的一層），而共用外框交給 `layout.tsx`：每個 layout 只管它所在資料夾的那棵子樹，並透過 `children` 把內容插進自己的外框，多層 layout 從 root 一路套到目標頁疊成外框鏈，讓不同子樹能有不同外框卻共用同一個根。
