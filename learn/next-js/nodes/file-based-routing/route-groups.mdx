# Route Groups：組織檔案，但不進 URL

<LearningGoal>
判斷何時該用 route group 來組織檔案並套用群組專屬 layout，而不用讓資料夾名進入 URL。
</LearningGoal>

## Lesson

Route group 用括號把資料夾名從 URL 裡拿掉（`(auth)/sign-in` 對外就是 `/sign-in`），讓「檔案怎麼分類」與「URL 長什麼樣」脫鉤，並可在群組內放專屬 `layout.tsx`；判準是兩個問題——這個名字要不要出現在網址、這一組要不要自己的外框——但要注意不同 group 的最終路徑不能互相衝突。
