<LearningGoal>
拿到一段 code 或一棵檔案樹時，能判斷哪些是 Next.js「多做的事」、哪些其實只是一般 React，並說出判斷理由。
</LearningGoal>

## Lesson

讀一份專案時，依序問檔名是否框架慣例、這行是否框架自動處理、搬去純 React 還能不能跑、AI 有沒有重做框架已做的事，就能判斷哪些是 Next.js 多做的、哪些只是一般 React。
