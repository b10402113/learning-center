<LearningGoal>
能說出 library 與 framework 的差別（誰呼叫誰、控制反轉），並解釋 Next.js 如何「加在 React 上」而不是取代它。
</LearningGoal>

## Lesson

Library 是你主動呼叫的工具，framework 掌握流程、會回過頭呼叫你寫的檔案；Next.js 是把 React 包起來、在上層加慣例與預建功能的 framework，所以是加在 React 上，而不是取代它。
