能說出 React 單獨用時留下的缺口（路由、資料、後端、首屏與 SEO、bundle），以及 Next.js 為何出現、解決了什麼。
</LearningGoal>

## Lesson

React 只負責畫 UI，搜尋引擎看得見的首屏、可直接寫的後端、工具鏈與 Server Components 都留給開發者自己補；Next.js 就是為了把這些缺口一次填齊而出現。
