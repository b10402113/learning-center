# 傳遞 promise：server 不 await、client 用 use() 解

<LearningGoal>
能把尚未 await 的 promise 從 server component 傳給 client component，在 client 用 React 19 的 `use()` 解開，並說出為什麼這樣做不會阻塞 server 渲染。
</LearningGoal>

## Lesson

在 server component 呼叫 action 但刻意不 `await`，把接住的 promise 當 prop 傳給 client component，由 client 用 React 19 的 `use()` 解開；因為 `await` 會阻塞 server 渲染，不 await 才能把等待移到 Suspense 邊界上，而 `use()` 又比 `useEffect` 少一趟往返、避免請求瀑布。
