# 從整頁等待到串流：RSC、SSR 與 Suspense 的角色

<LearningGoal>
能說出傳統 SSR 為什麼要等整頁生成、串流與選擇性 hydration 如何縮短等待，以及 Suspense 在串流與 PPR 裡扮演的邊界角色。
</LearningGoal>

## Lesson

傳統 SSR 要整頁生成完才送出，最慢的區塊決定整頁等待時間；串流讓伺服器做好一塊送一塊，選擇性 hydration 讓瀏覽器收到一塊就接手一塊，而 Suspense 是標記「這裡可能慢、先給 fallback」的界線，PPR 則把整頁拆成靜態外殼與用 Suspense 標出的動態洞。
