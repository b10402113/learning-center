# 用 Suspense 切出可串流的邊界

<LearningGoal>
能用 Suspense 包住慢的區塊並給 fallback，讓獨立資料邊串流邊出現；也能判斷該用檔案式 loading 邊界還是行內 Suspense，並看懂 PPR 的靜態外殼如何被動態洞填滿。
</LearningGoal>

## Lesson

先找出真正需要等非同步資料的慢子樹，再用 `<Suspense>` 包起來並給一個貼近版型的 fallback，最後驗證 HTML 是否分段到達；範圍小用行內 Suspense、範圍大用 `loading.tsx`，而 PPR 的動態洞正是這些 Suspense 邊界的位置。
