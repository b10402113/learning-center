# Server Components 的誕生：React 為什麼往伺服器走

<LearningGoal>
能說出 React Server Components 的動機與時間線：React 原本只活在瀏覽器、Instagram 撞上 bundle 極限、2020 年 React 團隊提出 RSC、Next.js 於 2022 導入並在 Next.js 13 的 App Router 中把它變成預設。
</LearningGoal>

## Lesson

React 原本只活在瀏覽器，整個應用被打包成一大包 JavaScript 下載。Meta 開發 Instagram 網頁版時撞上這個模式的極限，催生了 Server Components：讓元件可以在伺服器上執行，只把必要的 HTML 送到使用者。2020 年 12 月 React 團隊提出 RSC，2022 年中 Next.js 導入，2022 年底 Next.js 13 的 App Router 更把它設為預設。要注意的是，RSC 是「元件在哪執行」，和 SSR 的「何時渲染 HTML」是不同層次的事。
