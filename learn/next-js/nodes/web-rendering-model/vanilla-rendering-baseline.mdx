# 傳統模型：伺服器送檔、瀏覽器幹活

<LearningGoal>
能說出傳統 HTML/CSS/JS 模型一次請求的往返流程（瀏覽器請求 → 伺服器回傳完整檔案 → 瀏覽器解析渲染），以及它在處理、頻寬、載入時間上的三個代價。
</LearningGoal>

## Lesson

傳統模型的分工是「伺服器送檔、瀏覽器幹活」：瀏覽器送出請求，伺服器回傳完整的 HTML、CSS、JS，瀏覽器再自己解析、套樣式、跑互動。好處是單純，代價是工作多壓在客戶端、每頁重送完整檔案讓頻寬吃緊，而且必須等檔案全部到齊才看得到內容。這個模型是後面每一種做法拿來對照的基準。
