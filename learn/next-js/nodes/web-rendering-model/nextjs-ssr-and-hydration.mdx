# Next.js 的 SSR：先畫出來，再 hydration 接上互動

<LearningGoal>
能分兩段說明 Next.js 的伺服器渲染流程：伺服器執行 React 元件回傳已渲染 HTML，客戶端先畫出畫面，接著 hydration 把事件處理接上去。
</LearningGoal>

## Lesson

Next.js 把兩種模型接起來：首訪時伺服器先執行 React 元件，回傳已經渲染好的完整 HTML，讓瀏覽器立刻顯示內容（這就是 SSR）。JavaScript 之後才依互動需求送達，由 hydration 把事件處理與互動接回這份 HTML。畫面先到、互動後補，是這個模型最大的特徵。
