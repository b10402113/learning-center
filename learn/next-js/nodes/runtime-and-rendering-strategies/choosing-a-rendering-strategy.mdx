# 挑渲染策略：內容多久變一次、要不要即時

<LearningGoal>
能依「這頁每次請求的內容是否相同、是否需要秒級更新」兩問，選出 SSG／ISR／SSR／PPR，說出理由，並看出 AI 一律用預設 SSG 或一律 SSR 的踩雷。
</LearningGoal>

## Lesson

挑渲染策略只靠兩個問題：內容每次請求都一樣嗎（→ SSG）、需要秒級更新嗎（→ SSR），落在中間用 ISR、同頁混合靜態與動態則用 PPR；最常見的踩雷是把因人而異的內容用 SSG 快取，或把永不改變的頁面硬用 SSR。
