# 渲染的三條軸線：環境、時間、runtime

<LearningGoal>
能說出 rendering 是什麼，並用三條軸線（環境 client／server、時間 build time／run time、runtime 環境 Node／Edge）定位任何一段渲染，同時認得 SSG／ISR／SSR／PPR 各自落在哪個位置。
</LearningGoal>

## Lesson

渲染是把程式碼變成使用者介面的過程，而 Next.js 讓它能在不同環境（client／server）、不同時間（build time／run time）與不同 runtime（Node／Edge）發生；SSG、ISR、SSR、PPR 都是 server 側的策略，差別只在產生的時機與更新的方式。
