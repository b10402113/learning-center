# 三種伺服器渲染策略：SSG、ISR、SSR 與 PPR

<LearningGoal>
能解釋 SSG、ISR、SSR 各自在什麼時間點產生內容、如何快取與更新，以及 PPR 如何在同一頁把靜態外殼與動態串流混在一起。
</LearningGoal>

## Lesson

SSG 在 build time 產生靜態內容並快取、從 CDN 送出；ISR 讓靜態頁在 build 之後仍能按需或定時重新生成；SSR 每次請求都重新渲染、最即時但 server 負載最高；PPR 則在 build time 做靜態外殼，把動態區塊用 `Suspense` 串流，讓靜態與動態在同一頁並存。
