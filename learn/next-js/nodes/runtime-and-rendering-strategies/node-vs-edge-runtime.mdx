# 挑 runtime：Node 還是 Edge

<LearningGoal>
能依「這個任務是否對延遲敏感、是否踩到 Edge 的限制」，決定一段 route 該跑 Node 還是 Edge，並說出 Edge 與 serverless function 的差別與各自的限制。
</LearningGoal>

## Lesson

runtime 決定程式在哪裡執行：Edge 靠近使用者、延遲低但環境受限（約 25 秒與 4 MB 上限、部分 Node API 不支援、受資料源距離影響），Node 功能完整但在超低延遲場景吃虧；判斷順序是先問任務對延遲敏不敏感，再問是否踩到 Edge 的限制，兩關都過才選 Edge。
