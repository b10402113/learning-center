# 用程式碼打開策略與 runtime

<LearningGoal>
能查表說出把 SSG／ISR／SSR／PPR 打開、以及把 route 切成 Edge 的對應程式碼寫法（`revalidate`、`cache`、`next.revalidate`、`Suspense`、`export const runtime`），並知道每個選項的預設值。
</LearningGoal>

## Lesson

查閱對照表：SSG 是預設；ISR 用 `export const revalidate = 秒數` 或 `fetch` 的 `next.revalidate`；SSR 用 `export const revalidate = 0` 或 `cache: 'no-store'`；PPR 用 `Suspense` 包住動態元件；Edge runtime 則用 `export const runtime = 'edge'`。
