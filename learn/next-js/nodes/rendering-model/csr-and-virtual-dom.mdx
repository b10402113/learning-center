<LearningGoal>
能說明 CSR 的運作鏈（最小 HTML + JS bundle → 瀏覽器執行 React → virtual DOM diff 更新畫面 → React Router 換頁），並指出它在首次載入與 SEO 上付出的代價。
</LearningGoal>

## Lesson

這一節拆解 CSR 的運作鏈：server 只送最小 HTML 與一包 JavaScript，瀏覽器執行 bundle、用 React 在 client 渲染，virtual DOM 比對差異後只套用必要變更，React Router 換頁則不整頁重新載入；代價是首次畫面要等 JavaScript，以及 SEO 的風險。
