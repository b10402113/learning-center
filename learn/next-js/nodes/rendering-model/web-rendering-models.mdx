<LearningGoal>
能依「伺服器送什麼、使用者的瀏覽器做多少事」說出 vanilla、React CSR、Next.js 三種送頁面模型的差別，並把它們各自解決與留下的問題連起來。
</LearningGoal>

## Lesson

這一節用「server 送什麼、瀏覽器做多少」比較 vanilla、React CSR 與 Next.js 三種送頁面的模型，並把它們各自解決與留下的問題連成一條演進線：vanilla 送完整檔案、CSR 把渲染交給瀏覽器、Next.js 先送渲染好的 HTML 再補互動。
