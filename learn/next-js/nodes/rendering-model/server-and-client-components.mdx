<LearningGoal>
能說出 App Router 裡元件預設是 Server Component、`"use client"` 如何在檔案層級標出 client 邊界，以及為什麼 import 進 client 檔案的模組（含 server 元件）都會變成 client bundle。
</LearningGoal>

## Lesson

這一節說明 App Router 裡的元件預設都是 Server Component，在 server 執行、產生 HTML 並能直接存取伺服器資源；要用瀏覽器互動時才在檔案頂端加 `"use client"`，而它是一條檔案層級的界線，所有被 import 進 client 檔案的模組（含 server 元件）都會變成 client bundle，因此不要把 Server Component 放進 Client Component。
