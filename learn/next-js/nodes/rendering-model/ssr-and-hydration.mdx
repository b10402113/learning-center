<LearningGoal>
能解釋 Next.js 首次請求時 server 執行 React 元件、回傳完整 HTML、再由 client 做 hydration 接上事件處理器的流程，並說出 hydration mismatch 是怎麼發生的。
</LearningGoal>

## Lesson

這一節說明 Next.js 首次請求時，server 執行 React 元件並回傳完整的 HTML，讓瀏覽器立刻畫出畫面；互動所需的 JavaScript 隨後才到，由 client 的 hydration 把事件處理器接到那份已渲染的 HTML 上，並解釋 server 與 client 算出不同畫面時會發生 hydration mismatch。
