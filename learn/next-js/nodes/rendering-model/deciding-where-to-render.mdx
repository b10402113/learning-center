<LearningGoal>
能用「這個元件需要瀏覽器互動嗎」這個判準決定任一元件該留在 server 還是標成 client，並指出把 server 元件塞進 client 檔案、或無腦加 `"use client"` 這兩種常見錯誤的代價。
</LearningGoal>

## Lesson

這一節把 server / client 的取捨整理成一套決策流程：先問「這個元件需要使用者互動嗎」，需要才標成 client，不需要就留在 server；需要互動時只把真正的那一小塊抽成 client island，不要把整頁拖下水，也永遠不要把 Server Component 放進 Client Component 的檔案裡。
