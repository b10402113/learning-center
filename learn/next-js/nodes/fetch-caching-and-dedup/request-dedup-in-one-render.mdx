# Request dedup：同一次 render 內的請求只發一次

<LearningGoal>
能說出 request dedup 發生在哪一層、辨識它的 key 是「相同 URL 加相同 options」，並分清它與 fetch 快取是壽命完全不同的兩層機制。
</LearningGoal>

## Lesson

request dedup 是 React 在同一輪 render 內把相同 URL 加相同 options 的請求合併成一次；它只活在單輪 render、同一 route 內，和跨請求持久的 fetch 快取是不同兩層，而且只對 fetch 自動生效。
