# 用 React 的 cache() 幫 server action 去重

<LearningGoal>
能照著步驟用 React 的 `cache()` 把一個 server action 或資料庫查詢包起來，讓同一次 render 裡對同一參數的第二次呼叫直接回傳第一次的結果，不再打一次資料庫。
</LearningGoal>

## Lesson

當來源是 server action 或直接查資料庫時，用 React 的 `cache()` 包住原本的 async 函式再匯出，就能讓同一次 render 內同參數的第二次呼叫直接回傳第一次結果，函式本體與呼叫端都不用改。
