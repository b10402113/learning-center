# 為什麼 Next.js 的 fetch 會自動快取

<LearningGoal>
能說出 Next.js 的 fetch 相對瀏覽器原生 fetch 多了哪一層、預設為什麼會自動快取，並解釋 `cache: 'no-store'`、`cache: 'force-cache'` 與 `next: { revalidate }` 各自把行為切成什麼。
</LearningGoal>

## Lesson

Next.js 把瀏覽器原生的 fetch 換成擴充版，讓它預設就接上 Data Cache；用 `cache: 'no-store'`、`cache: 'force-cache'` 與 `next: { revalidate }` 決定一份資料要不要快取、快取多久。
