# 邊界畫在哪，會付出什麼代價？

<LearningGoal>
說出 `"use client"` 邊界的位置如何影響 bundle 大小、SEO、安全性與依賴，並用這四個角度檢查 AI 生成的元件拆分。
</LearningGoal>

## Lesson

這節拆解 `"use client"` 邊界位置的代價：從 bundle、SEO、安全與依賴四條軸線說明凡是被劃進 client 的東西都會被送到瀏覽器，並提醒需要互動的元件終究得當 client、client 元件仍會被預先渲染成靜態外殼。
