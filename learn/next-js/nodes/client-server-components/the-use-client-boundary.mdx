# 「use client」這條線劃在哪裡？

<LearningGoal>
解釋 `"use client"` 如何把整個模組（連同它 import 的東西）標成 client 程式碼，並說明為什麼不能在 Client Component 裡塞 Server Component。
</LearningGoal>

## Lesson

這節解釋 `"use client"` 標記的是整個檔案模組，會把它 import 的東西（含子 server 元件）一起拉進 client；因此不要把 Server Component 放進 Client Component，要保住 server 身分就得讓它在 import 關係上留在外層。
