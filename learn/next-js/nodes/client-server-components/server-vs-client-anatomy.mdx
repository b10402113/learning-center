# Server Component 與 Client Component 到底是什麼？

<LearningGoal>
說出兩種元件各自在哪裡執行、哪一種是預設，並用 console.log 實驗分辨日誌會出現在終端機還是瀏覽器。
</LearningGoal>

## Lesson

這節定義 Server Component（伺服器端渲染、能直接存取資料庫與檔案系統、只把 HTML 送出）與 Client Component（瀏覽器渲染、需在檔案最上方加 `"use client"`），並用 console.log 出現在終端機或瀏覽器，證明兩者的差別與「預設是 server」的規則。
