# 為什麼選擇要落到元件層級？

<LearningGoal>
說出 Next.js 13 之前「只能在整個路由頁面上做 SSR」的限制，以及 app directory 為什麼要把渲染環境的選擇權下放到單一元件。
</LearningGoal>

## Lesson

這節說明 Next.js 13 之前伺服器渲染只能綁在整個路由頁面，因而造成 prop drilling 與重複呼叫 API；app directory 把渲染環境的選擇權下放到單一元件，這正是 Server 與 Client 兩種元件誕生的原因。
