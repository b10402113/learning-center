# 這個元件該放 Server 還是 Client？

<LearningGoal>
用「它需不需要瀏覽器互動？」這一個問題，對任一元件做出 Server 或 Client 的可辯護判斷。
</LearningGoal>

## Lesson

這節用「這個元件需不需要使用者互動？」一個問句，搭配「資料、秘密、大套件留 server；互動、狀態、瀏覽器留 client」的對照表，判斷任一元件該放哪一邊，並說明 `"use client"` 要盡量往真正需要互動的最內層推。
