# route group：何時該分組、何時不該

<LearningGoal>
能判斷一個區塊該用一般巢狀資料夾還是 route group，並說明 route group 為什麼能不影響 URL 卻讓每個區塊擁有自己的 layout。
</LearningGoal>

## Lesson

route group 把資料夾名稱用括號包住（例如 `(auth)`），只做檔案分組、不進 URL，因此能讓不同區塊各自擁有 layout 又不弄髒網址；判準是「這個名稱要出現在 URL 裡嗎」——要就用一般巢狀資料夾，不要才用括號，且同一條路徑不可被兩個頁面解析。
