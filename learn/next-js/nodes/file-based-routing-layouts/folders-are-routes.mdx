# 資料夾就是路由：page.tsx 與巢狀路由

<LearningGoal>
能解釋 Next.js 為什麼不需要額外的 router 套件，並由 app/ 底下的資料夾與 page.tsx 反推出實際的 URL。
</LearningGoal>

## Lesson

Next.js 用檔案式路由：`app/` 底下每個資料夾代表一段 URL，裡面的 `page.tsx` 是那一段網址的畫面，巢狀資料夾就產生巢狀網址（例如 `app/projects/list/page.tsx` 對到 `/projects/list`），因此可以雙向反推 URL 與檔案位置，也不需要額外的 router 套件。
