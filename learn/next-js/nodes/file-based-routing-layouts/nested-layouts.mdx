# layout.tsx 疊層：root layout 與區塊外框

<LearningGoal>
能說明 root layout 為什麼是必要的、children 插槽如何把頁面接進來，以及巢狀 layout 由外到內的套疊順序。
</LearningGoal>

## Lesson

`layout.tsx` 接受 `children` 並用外框把子頁面包起來；root layout（`app/layout.tsx`）是唯一必要的 layout，負責 `<html>`、字型、provider 等全站關注點，資料夾可再放自己的 layout，套疊順序由外到內是 root layout → 區塊 layout → 頁面。
