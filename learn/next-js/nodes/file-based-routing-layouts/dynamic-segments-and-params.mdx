# 動態路由：用 [id] 吃下不確定的 URL

<LearningGoal>
能建立 [id] 形式的動態路由、從 params 取得 URL 中的變動值，並說明為什麼動態路由能取代複製貼上的多個頁面。
</LearningGoal>

## Lesson

動態路由把資料夾名稱用方括號包住（例如 `app/tags/[id]/page.tsx`），一個資料夾就能吃下 `/tags/react`、`/tags/nextjs` 這一整類網址；URL 中變動的那一段以同名 key 放進 `params`，在 App Router 裡 `params` 是 Promise，要用 `await params` 取值。
