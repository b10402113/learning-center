# 由 URL 反推檔案樹：抓出 AI 路由結構的錯

<LearningGoal>
能從一串 URL 或一份 AI 給的 app/ 檔案樹互相反推，並找出會產生錯誤 URL 或重複 layout 的結構問題。
</LearningGoal>

## Lesson

驗收路由結構時，先確定需求要的每一條 URL，再由 URL 畫出檔案樹、由檔案樹回推 URL 互相對照（括號跳過、中括號視為可變值），並檢查三個常見地雷：括號吃掉了該留的路徑段、某一層缺 `page.tsx` 導致 404、同一條路徑被兩個檔案解析。
