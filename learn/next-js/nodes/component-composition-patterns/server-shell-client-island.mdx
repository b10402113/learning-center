# server shell + client island：一個畫面是怎麼拼起來的

<LearningGoal>
能說出一個畫面是怎麼被組起來的：大部分用 server component 當外框，只在需要互動的地方放一小塊 client component，並解釋為什麼要這樣分而不是整頁都掛 client。
</LearningGoal>

## Lesson

一個畫面是一大片 server shell 加上少數 client island：元件預設是 server，只有需要互動的葉節點才加 `"use client"`，這樣瀏覽器下載的 JavaScript 最小；組合方向是單向的，server 可以包 client，client 不能反過來包 server。
