# props-in / JSX-out：不需要 "use client" 的純展示元件

<LearningGoal>
能看懂 props-in / JSX-out 的純展示元件（以 QuestionCard 為例），說出它為什麼不需要 `"use client"`，以及它如何只靠 props 就把畫面組合出來。
</LearningGoal>

## Lesson

props-in / JSX-out 的純展示元件只接收 props、回傳 JSX，沒有 state、事件或瀏覽器 API，因此不需要 `"use client"`，例如 `QuestionCard`；它靠 props 這個合約在多處重用，本身可以是 server，卻仍能在需要時渲染一顆 client 子元件。
