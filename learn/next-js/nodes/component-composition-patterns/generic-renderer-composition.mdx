# 用一個泛型 renderer 收斂列表畫面：DataRenderer 的 render prop

<LearningGoal>
能用「一個泛型 renderer + render prop」把 success / error / empty / 有資料四種狀態收斂進同一個元件，並在 server shell 裡組出一整個列表畫面。
</LearningGoal>

## Lesson

用一顆泛型 `DataRenderer` 把列表的錯誤、空、有資料三種狀態收斂起來：以 `success`、`error`、`data`、`empty` 描述狀態，用 `render` 這個 render prop 把版面交還給呼叫端；它本身是 server 元件，能直接嵌在 shell 裡，互動則留在 render 回傳的子元件中。
