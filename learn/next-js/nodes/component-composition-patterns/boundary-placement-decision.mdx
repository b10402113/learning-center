# 邊界該畫在哪裡：哪些元件留 server、哪些下沉成 client island

<LearningGoal>
拿到一個元件時，能用判別問句決定它該留在 server 還是下沉成 client island，並認出「整棵樹頂端掛 `"use client"`」與「把 server component 塞進 client」這兩種把邊界畫錯的後果。
</LearningGoal>

## Lesson

邊界的預設策略是先假設 server、只有真正需要互動時才下沉，並沉到最貼近需求的一層；用四題判別——元件自己需要互動嗎、需要的是整塊還是小處、要讀伺服器專屬資源嗎、是否只因子元件而想標父元件——同時避開把 `"use client"` 掛在頁面頂端與在 client 裡 import server 元件這兩個反例。
