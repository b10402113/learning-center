# 多層快取：四層快取各自的壽命與範圍

<LearningGoal>
能說出 Next.js 四層快取——Request Memoization、Data Cache、Full Route Cache、Router Cache——各自的壽命與範圍，並分辨 revalidation 是在刷新哪一層。
</LearningGoal>

## Lesson

Next.js 的快取是四層疊起來的——只活一輪 render 的 Request Memoization、跨請求存資料的 Data Cache、存整個 route 成品的 Full Route Cache，以及住在瀏覽器裡的 Router Cache，各有不同的壽命與範圍；「設定快取」和「更新快取」也是兩件事，除錯「資料不更新」的第一步，永遠是先確認舊資料活在哪一層。
