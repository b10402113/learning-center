# 非 fetch 的資料要自己包：unstable_cache 與 React cache

<LearningGoal>
能比較 `unstable_cache`（跨請求、可用 tag 作廢）與 `React.cache()`（只活在單輪 render）的壽命與適用時機，並用 tag 把 `unstable_cache` 接上 `revalidateTag`。
</LearningGoal>

## Lesson

Next.js 的自動快取只認擴充版 `fetch`；來源是 DB、ORM 或 server action 時要自己包：`React.cache()` 從 `react` 匯入，只在同一輪 render 內去重，`unstable_cache` 從 `next/cache` 匯入，把結果存進 Data Cache、跨請求持久，還能掛 tag 讓 `revalidateTag` 作廢它。
