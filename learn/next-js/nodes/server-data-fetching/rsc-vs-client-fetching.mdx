# 兩種抓資料的方式：useEffect 還是 RSC？

<LearningGoal>
能說出 client 用 useEffect 抓資料與 RSC 直接 async 抓資料的差別，並解釋 server 抓資料在 FCP、SEO、request dedup、金鑰安全與 network waterfall 上的優勢。
</LearningGoal>

## Lesson

傳統 client 用 `useEffect` 抓資料，會先給出空白畫面，並在 SEO、request dedup、金鑰安全與 network waterfall 上吃虧；RSC 讓你在伺服器直接 async 抓資料（甚至直接查資料庫），HTML 送出時內容已就緒，一次解掉這些問題。
