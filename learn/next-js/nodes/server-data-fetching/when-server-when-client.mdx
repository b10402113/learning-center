# 何時 server、何時 client：畫出資料邊界

<LearningGoal>
能依互動需求、SEO、金鑰安全與即時性，判斷一段資料該在 server 還是 client 抓，並認出「什麼都用 useEffect」與「什麼都塞 server」兩種常見踩雷。
</LearningGoal>

## Lesson

資料邊界是一道取捨：要用資料庫或金鑰、要 SEO 與首屏，交給 server；要即時互動、瀏覽器 API、事件與狀態，交給 client。正解通常是 server shell 抓好資料，只把互動的葉節點切成 client island，並避開「整頁 `"use client"`」與「什麼都塞 server」兩種極端。
