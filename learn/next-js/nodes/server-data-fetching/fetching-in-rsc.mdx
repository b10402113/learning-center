# 在 server component 裡抓資料：async、await 與直接查 DB

<LearningGoal>
能在 server component 裡用 async/await 抓資料或呼叫 server action，把回傳結果交給元件渲染，並正確處理 `searchParams`、`params` 與查不到資料時的 404。
</LearningGoal>

## Lesson

在 server component 抓資料的骨架：把元件宣告成 async，先 `await searchParams`／`await params` 拿參數並轉型，再 `await` server action 或直接查 DB，用 `{ success, data, error }` 解構，查不到就 `redirect` 到 404，最後把資料交給子元件渲染。
