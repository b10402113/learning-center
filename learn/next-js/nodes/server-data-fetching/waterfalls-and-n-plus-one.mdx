# 瀑布與 N+1：資料為什麼抓得慢

<LearningGoal>
能辨認 sequential await 造成的 network waterfall 與 N+1 query，並說出用 Promise.all 與 `.populate()` 消除它們的原理。
</LearningGoal>

## Lesson

network waterfall 是「無依賴的請求卻排隊」，讓總時間變成各段相加；N+1 query 是「先抓清單、再逐筆查關聯」，讓查詢次數變成 1 + N。前者用 `Promise.all` 平行化，後者用 `.populate()` 一次帶回關聯，判準都是先問動作之間有沒有真正的依賴。
