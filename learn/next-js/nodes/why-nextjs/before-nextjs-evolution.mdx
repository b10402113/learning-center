# Next.js 之前：Web 工具鏈怎麼一路演進

<LearningGoal>
能說出 Next.js 之前 web 工具鏈的演進順序（vanilla JavaScript → jQuery → Angular → Node.js → React），以及每一代是為了解決上一代的什麼問題而出現。
</LearningGoal>

## Lesson

Next.js 之前的工具鏈是踩著一代代的痛點長出來的：JavaScript 在 1995 年由 Brendan Eich 寫出、靠 Google 地圖走紅，jQuery 補 vanilla JavaScript 的不足，Angular 帶入元件化，Node.js 讓 JavaScript 能寫後端，React 用元件與 Virtual DOM 改變前端寫法，Next.js 則接手處理 React 沒解決好的問題。同一個 Hello World，用愈新的工具寫行數反而愈多，但真正要比的是大專案——元件化、Virtual DOM 與社群生態帶來的效率，要在規模變大時才顯現。
