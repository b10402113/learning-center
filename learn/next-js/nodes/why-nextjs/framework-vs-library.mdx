# 什麼是 Framework？React 留下的坑與 Next.js 的角色

<LearningGoal>
能分辨 framework 與 library 的差別，說出 React 自己留下了哪些坑，以及 Next.js 如何用「蓋在 React 之上的框架」補起這些坑。
</LearningGoal>

## Lesson

React 本身偏向函式庫，只負責用元件把畫面組起來，卻沒內建路由、資料抓取、伺服器渲染與認證這些整合工作；Next.js 則是蓋在 React 之上的框架，用預先定義好的規則與慣例把這些洞補起來，控制權反過來由框架主導，你只填應用邏輯。這個定位也說明了一件事：學 Next.js 不用打掉重練，但前提是你最好先懂 React 的元件、state 與程式碼結構。
