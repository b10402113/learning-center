# 代價與時機：什麼時候不該用 Next.js

<LearningGoal>
能判斷一個專案值不值得用 Next.js，並說出採用它要付的代價（學習前提、抽象與設定成本、框架更迭的追趕壓力）。
</LearningGoal>

## Lesson

要不要用 Next.js，先問專案的痛在哪：需要 SEO 或首屏效能、需要後端在同一份專案、或專案規模會長大——只要命中其中一項、而且你已經懂 React，Next.js 才划算；若答案多半是否，純 React 或純 HTML/CSS/JS 反而更輕。採用它的代價也很具體：需要 React 前提、要接受框架慣例帶來的限制，以及版本快速更迭的追趕成本。
