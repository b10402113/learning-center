# Next.js 到底幫你買到什麼

<LearningGoal>
能說出 Next.js 的四類回報——省下工具配置、全端能力、效能、SEO——並解釋每一類各自對應什麼問題。
</LearningGoal>

## Lesson

Next.js 買到四類回報：省下工具配置（慣例優於設定，少寫大量編譯、打包、部署的基礎建設）、全端能力（前後端收進同一份專案，不必再開兩個 repo）、更好的效能（內建 SSR、SSG 與自動程式碼分割）、以及 SEO（伺服器直接送出完整 HTML，讓爬蟲收得到內容）。一句話對應一種痛：工具串接、前後端分離、首屏白畫面、爬蟲看不到內容。
