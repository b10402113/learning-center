# app/ 的核心：layout、page 與 children

<LearningGoal>
能分辨 `layout.tsx` 與 `page.tsx` 的角色，並說出 `children` 這個 prop 如何把兩者接成一棵渲染樹。
</LearningGoal>

## Lesson

`layout.tsx` 是套用到整棵子樹的共用外框，`page.tsx` 只代表單一路由的內容；Next.js 把當前路由的頁面元件當成 `children` 這個 prop 傳進 root layout，插在哪裡就渲染在哪裡，註解掉它頁面內容就會消失。真實專案會把字型、metadata、Provider、Navbar、Toaster 這些「每頁都需要」的東西集中放在 root layout，並用 `globals.css` 管全域樣式、`*.module.css` 管單一元件樣式。
