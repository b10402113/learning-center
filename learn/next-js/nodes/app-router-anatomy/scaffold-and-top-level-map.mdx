# create-next-app 產出什麼？專案頂層地圖

<LearningGoal>
能說出 `create-next-app` 產生的每個頂層檔案與資料夾各自負責什麼，並解釋它們為什麼存在。
</LearningGoal>

## Lesson

`create-next-app` 用官方樣板一次生出整個專案；頂層檔案分成三種角色——工廠區（`app/`、`public/`）是你每天動手的地方，設定檔（`package.json`、`package-lock.json`、`next.config.ts`、`tsconfig.json`、`jsconfig.json` 等）決定專案行為、只在需要調整時才碰，產物（`node_modules/`、`next-env.d.ts`）由工具生成、不該動手。其中最核心的是 `app/`，所有頁面與路由都從這裡長出來。
