# 新程式碼該放哪？檔案配置的抉擇

<LearningGoal>
拿到一個新需求時，能判斷它該放進 `layout`、`page`、`app/` 子資料夾、`public/` 還是設定檔，並說出這樣放的理由。
</LearningGoal>

## Lesson

面對新需求，先問四個問題——它會出現在幾條路由上、是一條網址還是一塊零件、會不會被當成路由、改了影響誰——再決定放 `layout`、`page`、`components/`、`public/`、`globals.css` 還是 `.env`。兩個最常見的錯誤是：把所有共用都塞進 root layout，以及把全站共享的狀態只包在單一 `page` 裡。
