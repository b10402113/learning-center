# 把專案跑起來：dev server 與 Fast Refresh

<LearningGoal>
能啟動 dev server、在瀏覽器看到頁面，並用 Fast Refresh 邊改 `layout` 與 `page` 邊驗證渲染樹的改變。
</LearningGoal>

## Lesson

開發迴圈只有三步：`npm run dev` 在本機 3000 埠啟動服務、編輯 `app/` 裡的檔案、存檔後靠 Fast Refresh（HMR）立即在瀏覽器看到結果。改 `page` 只影響那一頁，改 `layout` 會影響底下每條路由，把 `{children}` 註解掉則頁面內容消失——這三個實驗就是渲染樹最直接的體感證明。
