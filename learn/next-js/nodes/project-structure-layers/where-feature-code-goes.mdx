# 新 feature 該放哪裡：一層一層問下去

<LearningGoal>
給定一段新 feature code，能判斷它該放在頂層設定、app/ 路由、可重用元件，還是資料／工具層，並用「AI 常犯版 vs 正解版」檢查自己的決定。
</LearningGoal>

## Lesson

決定一段新 code 的位置可依序問四題：會影響整個 app 的建置嗎（→ 頂層設定）？只屬一條 URL 還是整區共用（→ page 或 layout）？是純 UI 且已被第二處重用（→ `components/`）？完全不碰畫面（→ `lib/`／`database/`／`actions/`）？並記得反例：只有一個使用者先別抽、共用元件要只吃 props、全站關注點不能降級到某一區、資料查詢不要散落各頁。
