# app/ 裡的檔案公約：page、layout 與 globals

<LearningGoal>
能說明 app/ 資料夾裡每個檔案的角色（page、layout、globals.css、fonts/、favicon），並解釋 root layout 如何用 children 包住所有路由。
</LearningGoal>

## Lesson

`app/` 靠檔名決定角色：`page.tsx` 是某條路由要顯示的內容（資料夾路徑決定網址），`layout.tsx` 用 `children` 把子路由嵌進共用外框，`globals.css` 是全站樣式，`fonts/` 與 `favicon.ico` 是資源。root layout 是全站最外框，字型、metadata、provider 這些跨頁面關注點集中放在這一層，而不是每一頁重貼。
