# 頂層檔案與資料夾：一個新專案先看懂哪幾層

<LearningGoal>
能區分一個全新 App Router 專案頂層的檔案與資料夾各屬於哪一層（設定與依賴、靜態資源、應用原始碼），並說出每個檔案存在的目的。
</LearningGoal>

## Lesson

App Router 專案的頂層分成三層：設定與依賴層（`tsconfig.json`、`next.config.ts`、`postcss.config.mjs`、`package.json`、`package-lock.json`、`next-env.d.ts`、`eslint.config.mjs`）決定專案怎麼被編譯、檢查與啟動；靜態資源層（`public/`、`node_modules/`）放原物料與依賴；應用原始碼層（`app/`）才是每天寫 feature 的地方。其中 `next-env.d.ts` 不要改、`package-lock.json` 不要刪、`node_modules/` 不手動編輯。
