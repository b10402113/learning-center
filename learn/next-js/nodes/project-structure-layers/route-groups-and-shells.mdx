# route group 與分層 shell：URL 不變，版面重組

<LearningGoal>
能解釋 (root)、(auth) 這類 route group 如何在不改變 URL 的前提下把 app/ 分層，並說明 nested layout 如何為不同區塊組成各自的 shell。
</LearningGoal>

## Lesson

route group 用括號命名（如 `(root)`、`(auth)`），只做檔案分組、不會出現在 URL；每個 group 都能有自己的 `layout.tsx`，所以不同區塊可共用不同 shell——`(root)` 掛 navbar 與側欄，`(auth)` 只留置中卡片。這些 group layout 是疊在 root layout 之下，不是取代它。
