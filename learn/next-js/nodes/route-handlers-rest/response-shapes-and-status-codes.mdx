# 狀態碼與 response 信封：端點對外的合約

<LearningGoal>
查得到每個常用 HTTP 狀態碼的語意、`NextResponse.json` 的用法，以及一致的 response 信封（success / data / error / status）長什麼樣。
</LearningGoal>

## Lesson

端點的回應合約由狀態碼（`200`／`201`／`204`／`400`／`404`／`500`）與統一的 `ActionResponse` 信封（`success`／`data`／`error`／`status`）組成；回傳 JSON 用 `NextResponse.json()`，它會自動處理標頭，需要 cookie 或 redirect 時也靠它。
