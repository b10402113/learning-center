# route.ts 就是你的後端：檔案式 API 端點

<LearningGoal>
能解釋 route handler 為什麼是「一個資料夾加一個 route.ts 就成一個端點」，說出它相對傳統 Express 後端省下哪些設定，並認得 HTTP method 匯出的慣例。
</LearningGoal>

## Lesson

route handler 把後端收進框架：`app/` 底下一個資料夾放一個 `route.ts`，匯出的 `GET`／`POST`／`PUT`／`DELETE` 等函式就是對應 HTTP method 的端點，不需要另外啟動伺服器，前端用一般的 `fetch` 就能呼叫。
