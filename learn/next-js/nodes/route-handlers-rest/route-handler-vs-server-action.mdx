# 要端點還是要 action？route handler vs server action

<LearningGoal>
用「這個介面需要對外暴露嗎、有沒有外部呼叫者」等可測試的判準，決定一個寫入或查詢該用 route handler 還是 server action。
</LearningGoal>

## Lesson

對外、有非自家 app 的呼叫者、需要 webhook 或要用 Postman 測試時，用 route handler；只有自家 UI 會用、想少寫路由與狀態碼時，用 server action——因為 server action 的入口不公開、一律以 POST 執行。
