# 一步步建出有驗證的 CRUD route

<LearningGoal>
照著 DevFlow 的 users route 建出一個有 Zod 驗證、重複檢查、正確狀態碼與集中錯誤處理的 CRUD 端點，並說出每一段程式碼在做什麼。
</LearningGoal>

## Lesson

照著 DevFlow 的 users route：`try` 裡先 `dbConnect`；`POST` 用 Zod 的 `safeParse` 驗證、做唯一性檢查後才 `create` 並回 `201`；`catch` 一律交給 `handleError`。單筆資源放在 `[id]/route.ts`，更新時用 `UserSchema.partial()`，`findByIdAndUpdate` 要帶 `{ new: true }`。
