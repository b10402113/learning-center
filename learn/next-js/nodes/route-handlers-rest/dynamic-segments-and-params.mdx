# 動態 segment 與 params：路徑參數 vs 查詢參數

<LearningGoal>
能用巢狀與 `[id]` 動態資料夾建出參數化端點，從 `params` 取得路徑上的變動值，並分辨「路徑參數」與「查詢參數（searchParams）」各自該用在哪裡。
</LearningGoal>

## Lesson

動態 segment 用 `[id]` 這種中括號資料夾吃下不確定的路徑，值從 `params` 讀出（在 Next 15 是 Promise，要 `await`，且一律是字串）；查詢參數則放在 URL 問號後面，用 `request.nextUrl.searchParams.get()` 讀取。判準是：少了它就說不出要哪一筆資源的放路徑，只是篩選、排序、分頁的放問號。
