Step 5/5 · Node / Edge、SSG / ISR / SSR / PPR 的設定語法與預設值

需要查詢某個頁面要使用哪種渲染策略，或確認 route 要切換到哪個 runtime 時，可以直接對照本頁的設定名稱、寫法與預設值。

策略與對應寫法

本頁只列出 SSG、ISR、SSR、PPR 與 runtime 的實際程式碼寫法，不提供策略取捨建議。

想要的結果寫在哪裡寫法預設
SSG什麼都不用寫不設定Next.js 預設策略
SSG（明確）頁面或 route 檔案export const revalidate = false—
ISR（整頁）頁面或 route 檔案export const revalidate = 秒數—
ISR（單一 fetch）fetch 選項fetch(url, { next: { revalidate: 秒數 } })—
SSR（整頁）頁面或 route 檔案export const revalidate = 0—
SSR（單一 fetch）fetch 選項fetch(url, { cache: 'no-store' })—
PPR頁面 + 元件用 <Suspense> 包住動態元件（需啟用 PPR）—
Edge runtime檔案頂端export const runtime = 'edge''nodejs'

revalidate 的值

revalidate 可以設定在頁面層級，也可以放在單一 fetch 的 next 選項中。

值意義
false盡可能長期保留快取；等同 Infinity。HTTP 快取仍可能基於空間考量淘汰舊項目。
0不快取，每次請求都重新渲染（SSR 效果）。
一個數字快取保留該秒數，時間到之後刷新並繼續循環。

寫成 export const revalidate 時，這是 route segment config，會影響整頁，包含頁面內所有資料抓取。寫成 fetch 的 next.revalidate 時，只影響該筆請求。

cache 的值

cache 是傳給 Next.js 擴充版 fetch 的選項，用來設定單一請求的快取行為。

值意義
'no-store'完全不使用快取，每次都直接向 server 要最新的資料，也不儲存結果。
'force-cache'若快取中有且仍新鮮就直接使用；否則重新取得並存回快取。

runtime 的值

值意義
未設定預設使用 Node.js runtime。
'nodejs'Node.js runtime，可存取完整 Node.js API 與生態系。
'edge'Edge runtime，以 Web API 為基礎，只支援部分 Node.js API。

runtime 可以設定在 layout、page 或 route 任一層級。

最小使用範例

切換 runtime，在檔案頂端加入以下設定：

export const runtime = 'edge' // 'nodejs' (default) | 'edge'

設定 ISR 的整頁快取時間，數字單位是秒：

export const revalidate = 5000; // (seconds)

只對單一 fetch 請求設定 ISR：

const response = await fetch('https://api.example.com/data', {
  next: { revalidate: 5000 },
});

設定 SSR 的整頁寫法：

export const revalidate = 0;

只對單一 fetch 請求設定 SSR：

const response = await fetch('https://api.example.com/data', {
  cache: 'no-store',
});

PPR 使用 <Suspense> 包住動態元件，並設定 fallback：

import { Suspense } from 'react';

export default function Page() {
  return (
    <>
      <Header />
      <Suspense fallback={<Skeleton />}>
        <DynamicSection />
      </Suspense>
    </>
  );
}

Node 與 Edge 的 route 對照

以下兩段 route 的處理內容相同，差異在於第二段加入了 runtime = 'edge'：

import { NextResponse } from 'next/server';

export async function GET() {
  // purposefully delay the response by 1 second
  await new Promise((resolve) => setTimeout(resolve, 1000));

  return NextResponse.json(
    { name: 'Hello from Node Runtime' },
    { status: 200 },
  );
}
import { NextResponse } from 'next/server';

export const runtime = 'edge';

export async function GET() {
  // purposefully delay the response by 1 second
  await new Promise((resolve) => setTimeout(resolve, 1000));

  return NextResponse.json(
    { name: 'Hello from Edge Runtime' },
    { status: 200 },
  );
}

設定摘要

SSG 是預設，不設定即可；ISR 用 export const revalidate = 秒數 或 fetch 的 next.revalidate；SSR 用 export const revalidate = 0 或 cache: 'no-store'；PPR 用 <Suspense> 包住動態元件。revalidate 的值有 false／Infinity（長期保留）、0（不快取）、數字（保留秒數）；cache 的值有 'no-store' 與 'force-cache'。runtime 預設為 'nodejs'，切成 Edge 則寫 export const runtime = 'edge'。
