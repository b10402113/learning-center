代價與時機：什麼時候不該用 Next.js

Step 4/4 · Why Next.js

學習目標

能判斷一個專案值不值得用 Next.js，並說出採用它要付的代價。

前言：既然它什麼都幫你做好，為什麼不每個專案都用？

前三節一路聽下來，Next.js 幾乎像是萬靈丹：省工具、能寫後端、效能好、SEO 佳，還有大公司在用。那照理說，任何新專案都該直接選它，不是嗎？

這裡就是張力所在。框架幫你省事的代價，是它也替你做了很多決定：它有一套慣例要你遵循，需要你先懂 React，還改版改得很快、要你持續追。當這些「好處」用錯了場景，就會變成負擔。這一節要練的，不是「哪個工具最好」這種沒有標準答案的問題，而是「我這個專案，痛在哪、值不值得付這些代價」的判斷力。這也是你在審查 AI 生成的架構時最需要的一課，AI 很容易把 Next.js 當預設值，逢需求就套。

先把三個選項並排看清楚

要不要用 Next.js，其實就是在三條路線裡選一條：純 React（搭配 Vite 這類工具）、純 HTML/CSS/JavaScript、或 Next.js。它們各有擅長的場景。

面向純 HTML/CSS/JS純 React（Vite 等）Next.js
適合規模小型、內容固定的網站中大型、重互動的應用中大型、需要伺服器能力的應用
SEO／首屏天生就有完整 HTML客戶端渲染，較吃虧SSR／SSG，表現好
後端另外準備另外準備同一份專案內建

從這張表可以看出一件事：Next.js 的價值，全建立在「你需要伺服器端能力或規模化」的前提上。前提不成立，它的優勢就沒有著力點。

三到五個判別問句，自己問自己

不用背規則，把下面幾個問題依序問一遍，答案自然會浮現：

  1. 這個網站需要被搜尋引擎收錄，或首屏速度很關鍵嗎？若是，Next.js 的 SSR／SSG 幫得上忙；若只是內部工具、登入後才用，這條就沒那麼重要。
  2. 需要後端嗎？需要 API、資料庫、身分驗證嗎？若需要，Next.js 把前後端收進一份專案的優勢就成立。
  3. 團隊或你本人已經懂 React 了嗎？如果沒有，先補 React 的元件、state、程式碼結構，再來談框架。
  4. 這只是幾頁、不會長大的東西嗎？例如一份活動頁、一個三頁的個人網站。若是，框架帶來的架構反而超出需求。
  5. 你願意跟著框架的慣例與版本節奏走嗎？Next.js 一年可以推出七個以上版本，採用它就得持續關注更新。

規則會翻轉的時候

決策規則不是鐵律，以下幾種情境會讓「該用 Next.js」的答案翻盤。

第一，專案小到不需要它。回頭看第一節的 Hello World 比較：同一個功能，用現代框架寫的行數反而更多。如果專案只是一個小頁面，框架的架構、慣例與設定只會是額外負擔；它的報酬要在大規模專案裡才顯現。這也是 AI 常犯的誤判：把 Next.js 當成所有網站專案的預設答案，卻沒先問規模。

第二，你其實是在學 React，而不是在做專案。Next.js 是蓋在 React 之上的延伸，前提是你要懂 React。如果連元件、state、程式碼結構都還不熟，直接跳進框架，會同時面對兩層新東西，反而更難學。先把 React 的地基打好，再來一層。

第三，你不想被框架的慣例綁住，或需要高度客製的架構。「慣例優於設定」是 Next.js 的賣點，但它的另一面就是：框架替你決定好路由、渲染、資料流該怎麼寫。若你的專案有很特殊的架構需求、不希望被既定慣例框住，這份便利就會變成限制。

第四，你無法承受持續追版本的維護成本。框架族群的常態就是「唯一不變的是改變」，工具一代接一代。Next.js 本身改版也快，選擇它等於選擇長期關注升級與相容性。若團隊沒有這個餘裕，就得把這件事算進成本。

小結

Next.js 的回報不是免費的。它的代價包括：需要你先懂 React、要你接受框架的慣例（便利的另一面是限制）、以及框架快速改版帶來的追趕壓力。再加上「小專案用框架反而寫更多行」這個事實，結論就很清楚：先判斷專案的痛在哪，要 SEO 嗎？要後端嗎？規模會長大嗎？三者都指向「是」，Next.js 才划算；若答案多半是「否」，純 React 或純 HTML/CSS/JS 反而更輕。

帶走這張檢查表

下次要決定用不用 Next.js（或要審查 AI 為什麼用它），先跑一遍：

要用 Next.js，當且僅當：需要 SEO 或首屏效能 或 需要後端在同一份專案 或 專案規模會長大，而且你已經懂 React。
用純 React：重互動、但沒有 SEO 與後端需求。
用純 HTML/CSS/JS：幾頁靜態內容，不會長大。

把這條檢查表記住，你就完成了這個節點的核心目標：說得出 Next.js 解決了什麼問題，也說得出它的代價。之後每一節深入單一功能時，都可以回頭問一句「它當初是為了補哪個洞」，觀念才不會散掉。
