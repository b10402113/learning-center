# MEMORY — ai-html

## Goal
將任意素材（PDF、筆記、程式碼、文章、逐字稿）直接轉成全動畫知識講解影片。中間產物是 HTML slides 和 HTML articles，最終成品是帶動畫的知識影片，用於公開發布。

## Why
建立一條從「素材進」到「影片出」的完整內容產線，用來發布教學與知識內容給中文受眾。

## Prior experience
- 無 HTML / CSS / 動畫製作經驗
- 無 agent skill 開發經驗
- 無影片錄製或剪輯經驗
- 已有開發環境：Node.js、Claude Code、VS Code、Git

## Anchors
- 素材來源不限：PDF、書籍、筆記、程式碼倉庫、別人的演講逐字稿皆可
- 最終成品是全動畫影片（motion graphics），不是螢幕錄影或投影片配旁白
- 目標語言為繁體中文

## Habits & constraints
- 每週可用時間：< 3 小時
- 學習環境：Mac，已有 Node.js / Claude Code / VS Code / Git
- 需要先理解架構再動手做

## Knowledge type
mixed，偏 declarative — 先理解 skill 架構、元件協議、主題系統、工作流設計，再動手建自己的 skill

## How to teach me
以真實專案為載體學習。給一個我真正想做的東西，邊做邊學。偏好：理解原理 → 動手實作 → 迭代產出品質。厭倦：純理論講解、脫離實務的練習。
