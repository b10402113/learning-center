# 簡報模式

## Learning goal

雙窗口同步簡報模式：BroadcastChannel、鍵盤控制、演示者視圖

## Steps

1. [[learn/ai-html/nodes/presenter-mode/dual-window-architecture|雙窗口同步架構]] — BroadcastChannel 與 postMessage 的同步機制
2. [[learn/ai-html/nodes/presenter-mode/speaker-notes-contract|Speaker Notes 資料合約]] — SPEAKER_NOTES schema 與三條黃金規則
3. [[learn/ai-html/nodes/presenter-mode/presenter-view-tools|演示者視圖與工具列]] — 四卡片佈局、計時器、雷射筆（after steps 1–2）
4. [[learn/ai-html/nodes/presenter-mode/rehearsal-workflow|排練流程與自動前進]] — 排練計時、localStorage 持久化、pre-flight check（after step 3）

## Lesson

HTML 投影片的最大優勢之一，是不需要額外軟體就能跑出完整的簡報體驗。其中最強大的功能是**簡報模式**（presenter mode）—— 一個雙窗口同步系統：觀眾看到全螢幕投影片，演示者看到一個包含當前頁、下一頁、講稿摘要、計時器的控制面板。這整套機制建立在兩個瀏覽器原生 API 上：**BroadcastChannel** 負責跨視窗即時通訊，**postMessage** 負責 iframe 內的像素級精確導航。四步走完，你會理解從資料合約到工具列互動的完整架構，並能自己為任何 HTML 投影片加上簡報模式。
