# 動畫組合與節制

## Learning goal

能說出「每張投影片最多一個強調動畫」的節制原則，並解釋 CSS 進入動畫與 Canvas FX 如何在同一張投影片上分工協作而不衝突。

## Lesson

### 動畫的密度問題

一份投影片如果有 30 張 slide，每張都加了 3 個 CSS 動畫和 1 個 Canvas FX，結果會怎樣？觀眾會疲勞。動畫的刺激感來自對比——如果每張都有動畫，動畫就變成了噪音。

這就是「動畫節制」的核心原則：動畫的價值來自它不出現的時候。一張全靜止的投影片之後接一張有 `rise-in` 的投影片，那個 `rise-in` 就有衝擊力。如果前後都有動畫，衝擊力就消失了。

### 每張投影片最多一個強調動畫

這套系統的節制規則是：每張投影片最多一個「強調動畫」（accent animation）。所謂強調動畫，是指視覺衝擊最強的那個——通常是 `rise-in`、`zoom-pop`、`glitch-in` 這類戲劇性效果。

其餘元素用中性動畫（`fade-up`、`fade-left`）或不用動畫。這樣做的效果是：觀眾的注意力會自然落在那個唯一的強調動畫上，而不會被多個動畫分散。

舉個例子：

```html
<!-- 不好：兩個強調動畫 -->
<div data-anim="zoom-pop">重要數據</div>
<div data-anim="glitch-in">關鍵結論</div>

<!-- 好：一個強調 + 一個中性 -->
<div data-anim="zoom-pop">重要數據</div>
<div data-anim="fade-up" style="animation-delay: 0.15s">關鍵結論</div>
```

左邊兩個都是高衝擊動畫，觀眾不知道該看哪個。右邊只有數據用了 `zoom-pop`，結論用 `fade-up` 淡入，焦點清楚。

### CSS 進入動畫與 Canvas FX 的分工

在同一張投影片上，CSS 和 Canvas 各有角色：

| 層 | 誰負責 | 什麼時候播放 | 效果類型 |
| --- | --- | --- | --- |
| CSS 進入動畫 | DOM 元素（標題、段落、圖片） | 投影片切換時，播放一次 | 位移、縮放、透明度 |
| Canvas FX | `<canvas>` 背景 | 投影片顯示期間，持續運行 | 粒子、幾何、數據視覺化 |

兩者互不干擾：CSS 動畫操作 DOM 元素的 CSS 屬性，Canvas FX 在自己的 canvas 畫布上繪製。唯一的交集是顏色——兩者都讀 CSS custom properties，所以主題換色時兩者同步。

典型的組合模式是：Canvas FX 作為背景氛圍（例如一片緩慢旋轉的星海），CSS 動畫作為前景元素的出場方式（標題 `rise-in`、要點 `fade-up`）。背景是持續的、低調的；前景是短暫的、有節奏的。

### 節奏設計：三分法

一份好投影片的動畫節奏像音樂：有高潮、有低谷、有呼吸。一個實用的框架是「三分法」：

**第一個三分之一**（開場）：一到兩張有強調動畫的投影片，建立基調。通常是 `rise-in` 或 `zoom-pop`，讓觀眾知道「這份投影片有動畫，但不會太吵」。

**第二個三分之一**（主體）：大部分投影片用中性動畫或無動畫。讓觀眾專注在內容上。偶爾（每 5-8 張）插入一張有 Canvas FX 的投影片，換換視覺節奏。

**第三個三分之一**（收尾）：回到有動畫的投影片，但用 Calm 或 Editorial 類型的動畫，營造收束感。最後一張投影片可以用 `kenburns` 或 `float-drift` 做緩慢的持續效果，讓結束感覺自然而不是突然。

### 常見的動畫反模式

**反模式一：每張都有動畫。** 觀眾疲勞，動畫失去意義。

**反模式二：同一張有多個強調動畫。** 注意力分散，視覺混亂。

**反模式三：Canvas FX 不設尺寸。** `data-fx` 的容器沒有設定 `width` 和 `height`，fx-runtime.js 無法正確初始化，canvas 畫面為空白或畸形。

**反模式四：動畫和內容情緒不匹配。** 技術架構圖用了 `confetti-cannon`，嚴肅財報用了 `zoom-pop`。動畫應該服務內容，不是炫技。

**反模式五：忽略 `prefers-reduced-motion`。** 有些觀眾對動畫敏感或暈眩，系統設定減少動態效果時，所有動畫應該被跳過。如果你自己加了 JavaScript 控制動畫，記得也尊重這個 media query。

### 從節制到品質

動畫的品質不是看「用了多少效果」，而是看「每一個效果是否恰當」。一份只有 3 個動畫但每個都精準匹配內容情緒的投影片，比一份 30 個動畫但毫無節奏的投影片好得多。

這也是為什麼這套系統把動畫分成 CSS 和 Canvas 兩層，並提供明確的感覺類別指引。它不是限制你的創意，而是幫你在「想要加動畫」和「應該加動畫」之間建立判斷框架。
