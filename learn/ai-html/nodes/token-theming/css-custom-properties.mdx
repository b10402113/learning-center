# CSS Custom Properties 基礎

## Learning goal

能解釋 CSS custom properties 的宣告、作用域與動態覆蓋機制，並分辨它與 CSS 預處理器變數的根本差異。

## Lesson

CSS Custom Properties 是瀏覽器原生的變數機制——用 `--` 前綴宣告、`var()` 引用，與 Sass 變數的根本差異在於它是執行期的：留在瀏覽器裡，可以被 JavaScript 動態修改、被作用域覆蓋、被媒體查詢觸發，這才是主題切換的基礎。
