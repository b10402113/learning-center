# 主題開發實作

## Learning goal

能從既有主題檔案複製、修改變數值，產出一個合法的新主題檔案，並驗證它在投影片中的視覺效果。

## Lesson

主題開發是從現有主題複製、只改核心變數值、保持 < 200 行的精簡流程，主題檔案只負責覆蓋 semantic tokens，不加新 CSS 規則、不漏任何變數，選主題的本質是選視覺情緒而非選顏色。
