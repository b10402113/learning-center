# 雙設計系統實戰

## Learning goal

能對照 magazine-ink（5 色調主題）與 Swiss International（單色點綴）的 token 設計差異，並說明每套系統的硬性約束。

## Lesson

Magazine-Ink 用雙色調（ink + paper）+ 5 套主題，Swiss International 用單色點綴 + 4 套主題，兩套系統在相同的 CSS custom properties 架構上長出截然不同的設計語言，各自的硬性約束（禁止自訂 hex / 禁止混搭 / 單一 accent）是確保 agent 輸出品質穩定的品質閘門。
