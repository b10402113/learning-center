# Token 分層架構

## Learning goal

能描述 base → semantic → component 三層 token 的命名邏輯，並說出 `base.css` 裡 30+ 變數如何組織成一套完整的設計系統。

## Lesson

Token 分層架構把變數分成 base（原始色票）、semantic（語意命名）、component（元件綁定）三層，元件引用 semantic tokens、主題覆蓋 semantic tokens，兩者透過語意橋接層解耦，一套 30+ 變數的 base.css 就能支撐數十個主題。
