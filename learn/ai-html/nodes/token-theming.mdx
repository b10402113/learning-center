# Token 主題系統

## Learning goal

用 CSS custom properties 做 token-driven 主題系統，一套 token 換整體外觀

## Steps

1. [[learn/ai-html/nodes/token-theming/css-custom-properties|CSS Custom Properties 基礎]] — 理解 CSS 自訂屬性的宣告、作用域與動態覆蓋機制
2. [[learn/ai-html/nodes/token-theming/token-system-architecture|Token 分層架構]] — base → semantic → component 三層 token 的命名與組織（after step 1）
3. [[learn/ai-html/nodes/token-theming/dual-design-systems|雙設計系統實戰]] — magazine-ink 與 Swiss International 兩套真實主題系統的 token 對照（after step 2）
4. [[learn/ai-html/nodes/token-theming/theme-authoring|主題開發實作]] — 從 copy 到 override，寫一個 < 200 行的主題檔案（after step 2）

## Lesson

Token 主題系統的核心想法只有一個：把所有視覺決策（顏色、字型、間距、圓角、陰影）抽成 CSS custom properties，然後讓整份投影片的樣式全部引用這些變數。當你想換主題時，只需覆蓋變數值——不用改任何 HTML 或 layout 程式碼。

這個節點帶你走過四個層次：先搞懂 CSS custom properties 本身的機制（宣告、作用域、動態覆蓋），再看一套真實的 token 分層架構（30+ 變數怎麼命名、怎麼分 base / semantic / component 三層），接著對照兩套真實的設計系統（magazine-ink 的 5 色調 vs Swiss International 的單色點綴），最後你會親手寫一個新主題。
