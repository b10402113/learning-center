# HTML 演示文稿工具生態與選擇

## Learning goal

能分辨 HTML 演示文稿的三種常見形式，並說出選擇工具時應該看哪個環節。

## Lesson

HTML 演示文稿有三種實現形式（框架驅動、Markdown 驅動、Agent 構建），選擇時應根據審閱環節而非生成環節來決策。
