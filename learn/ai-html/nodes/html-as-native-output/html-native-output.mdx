# 為什麼 HTML 是 AI 原生輸出語言

## Learning goal

能說出為什麼 AI 模型特別擅長生成 HTML，以及 HTML 和 Markdown 在 AI 工作流中分別扮演什麼角色。

## Lesson

AI 模型的訓練資料充滿了 HTML 網頁，所以它生成 HTML 的能力遠超其他格式；Markdown 是輸入側原生語言，HTML 是輸出側原生語言。
