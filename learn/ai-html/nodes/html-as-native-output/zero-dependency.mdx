# 零依賴單檔輸出的設計哲學

## Learning goal

能說出零依賴單檔輸出的架構設計，以及為什麼這種模式特別適合 AI 生成的內容。

## Lesson

零依賴單檔把結構、樣式、行為全部塞進一個 .html 檔案，用固定 1920×1080 舞台和 CSS transform 縮放，讓 AI 產出的內容能立即預覽和分享。
