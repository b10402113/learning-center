# Agent Skill 架構

## Learning goal

理解 agent skill 的結構：SKILL.md、references、模板、驗證腳本

## Steps

1. [[learn/ai-html/nodes/agent-skill-architecture/what-is-agent-skill|什麼是 Agent Skill？]] — 定義 agent skill，分辨它跟一般 prompt template 的差異
2. [[learn/ai-html/nodes/agent-skill-architecture/skill-folder-anatomy|Skill 資料夾結構]] — 資料夾結構：SKILL.md、manifest.json、references/、scripts/、templates/、themes/（after step 1）
3. [[learn/ai-html/nodes/agent-skill-architecture/skill-md-structure|SKILL.md 工作流設計]] — SKILL.md 的階段劃分、非妥協規則、引用文件載入策略（after step 2）
4. [[learn/ai-html/nodes/agent-skill-architecture/progressive-disclosure|Progressive Disclosure 載入模式]] — 為什麼大型 skill 不能一次全部載入、index → preview → full reference 的三層載入（after step 3）

## Lesson

Agent skill 是一套給 AI 編程代理（coding agent）執行的結構化工作說明。它不是一段 prompt，而是一個完整的資料夾：裡面有工作流腳本（SKILL.md）、參考文件（references/）、範本（templates/）、工具腳本（scripts/），甚至有自己的版本號和發佈設定。一個 skill 就是一條從輸入到產出的完整管線——代理按照 SKILL.md 裡的階段逐步執行，遇到需要判斷的環節再按需載入 reference 文件。

這套架構解決的核心問題是：怎麼把「人類腦中的設計方法論」打包成代理可以穩定複製執行的工作單元。傳統的 prompt 只是一段指令，skill 則是把工作流、品質門檻、設計約束、參考資料全部組織在一起。代理不用每次從零開始想怎麼做，而是按照 skill 定義好的階段走完流程。

四步走完之後，你會知道：skill 長什麼樣、裡面每個檔案有什麼用、SKILL.md 怎麼規劃工作流、以及為什麼大型 skill 要用 progressive disclosure 分層載入 reference。
