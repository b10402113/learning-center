# 模板架構全景

## Learning goal

能說出 frontend-slides 的 34 個模板與 guizang-ppt-skill 的 31 個版面如何組合，以及 progressive-disclosure 載入策略的核心原理。

## Lesson

前端投影片的模板系統分兩套：34 個 bold templates 管視覺風格（配色、字型、裝飾語彙），31 個 locked layouts 管頁面結構（每一頁的骨架）；兩套各自獨立但不能混用，選風格後只能用對應風格的版面，且都採用 progressive-disclosure 策略——先讀輕量索引再按需載入完整規格——避免一次載入拖垮 context window。
