# 兩層文件設計

## Learning goal

能解釋 preview.md 與 design.md 的分工，以及 selection-index.json 如何驅動候選篩選。

## Lesson

每個 bold template 有兩層文件：preview.md 是輕量風格名片（色票快照、signature moves），design.md 是完整設計系統 recipe（CSS 變數、字型層級、元件語法、間距系統）；selection-index.json 是機器可讀的元數據索引，讓代理在不讀任何 markdown 的情況下用 mood/tone/formality/density/scheme 完成初步篩選，整個流程從 20KB 索引到 5-10KB design recipe，實現 progressive-disclosure。
