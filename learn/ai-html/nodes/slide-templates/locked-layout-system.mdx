# Locked Layout 系統

## Learning goal

能說明 locked layout 如何透過註冊機制保障設計完整性，以及違反規則時會發生什麼。

## Lesson

Swiss locked layout 把 22 個已登記的頁面結構（S01-S22）鎖定為唯一可用的版面，每個版面用 data-layout="Sxx" 屬性標記，validate-swiss-deck.mjs 在生成後自動驗證——未登記的版面或 SVG 中的可見文字都會被攔截；這種「先註冊、再使用」的機制保障了設計完整性，讓代理只能在已驗證的版面範圍內自由組合，而不會脫離原始模板的視覺系統。
