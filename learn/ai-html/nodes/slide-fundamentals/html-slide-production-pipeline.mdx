# 完整製作流程

## Learning goal

走完從素材到可播放投影片的完整流程：6 階段 pipeline 的每一步做什麼、品質檢查要點、以及匯出與分享。

## Lesson

從素材到可播放投影片的完整流程分 6 個階段：偵測模式 → 內容發現 → 風格發現 → 生成 → 交付（品質檢查） → 分享/匯出。生成階段把 viewport-base CSS、選定模板的設計 token、slide HTML 結構、導航 JS 全部內聯成一個零依賴的 HTML 檔。品質檢查用 P0-P3 四級清單和自動化驗證腳本（validate-swiss-deck.mjs、validate-presenter-mode.mjs）。匯出方式包括直接分享 HTML、部署到 Vercel、用 Playwright 截圖匯出 PDF。guizang 把 pipeline 細化為 10 步，從 7 問 intake 開始確保需求對齊。
