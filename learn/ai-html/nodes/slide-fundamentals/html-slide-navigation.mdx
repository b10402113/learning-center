# 導航與互動控制

## Learning goal

掌握投影片的導航機制：鍵盤方向鍵、觸控滑動、滾輪切換如何驅動 slide 切換，以及 `<deck-stage>` Web Component 的自動縮放。

## Lesson

投影片的導覽器（SlidePresentation class 或 <deck-stage> Web Component）把使用者的鍵盤、觸控、滾輪輸入轉換成 slide 切換。鍵盤用 keydown 事件加 preventDefault 阻止預設捲動；觸控用 touchstart/touchend 的水平位移差偵測滑動方向；滾輪用 wheel 事件的 deltaY 判斷方向（需 passive: false）。<deck-stage> 是一個 Web Component，用 Shadow DOM 封裝了所有導航邏輯和自動縮放，公開 next/prev/goTo/reset API 和 slidechange 自訂事件，事件的 reason 欄位辨識觸發來源。系統還支援 tap zones（手機點擊左右兩側切換）和 postMessage 驅動的講者備註同步。
