# 模板系統與設計選型

## Learning goal

理解 34 套模板的組織方式：如何用 selection-index.json 快速選型、preview.md 輕量比較、design.md 完整實作，以及 Safe/Bold/Wildcard 三選一策略。

## Lesson

模板系統用 progressive-disclosure 架構管理 34 套設計模板：先讀 selection-index.json 的 compact metadata 快速篩選候選，再讀 preview.md 的輕量風格卡片做比較，最後只讀被選中的 design.md 獲得完整設計規範。Safe/Bold/Wildcard 三選一策略把從 34 個中選一個的決策負擔降低到從 3 個中選一個。另有 12 套 Style Presets（CSS variable 集合）做快速換膚。guizang 的雙系統（Style A 雜誌風 / Style B 瑞士風）則用鎖定佈局（22 種已註冊 class）防止視覺漂移，兩者的 CSS class 完全不能混用。
