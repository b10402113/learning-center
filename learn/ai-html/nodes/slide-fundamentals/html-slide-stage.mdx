# 固定舞台與視窗模型

## Learning goal

理解 1920×1080 固定舞台的設計原理：為什麼用 CSS transform 縮放而不是自適應佈局，以及 slide 堆疊與可見性切換的機制。

## Lesson

HTML 投影片的核心是一個 1920×1080 固定畫布（stage），透過 CSS transform 縮放到瀏覽器視窗大小，而非採用自適應佈局。DOM 結構分三層：viewport（佔滿視窗、overflow hidden）→ stage（固定尺寸、transform 縮放）→ slide（多張堆疊、visibility/opacity 切換）。用 CSS transform 而非 vw/vh 單位是為了保持像素完美；用 visibility + opacity 而非 display: none 是為了避免元素脫離文件流。系統還內建 print 樣式（每張 slide 一頁）和 prefers-reduced-motion 無障礙支援。所有程式碼內聯在一個 HTML 檔裡，零依賴、單檔輸出。
