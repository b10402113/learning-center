# HTML 作為 AI 原生輸出

## Learning goal

為什麼 HTML 是 AI 原生輸出語言；零依賴單檔輸出的設計哲學

## Steps

1. [[learn/ai-html/nodes/html-as-native-output/html-native-output|為什麼 HTML 是 AI 原生輸出語言]] — 訓練數據、輸入側 vs 輸出側原生語言
2. [[learn/ai-html/nodes/html-as-native-output/zero-dependency|零依賴單檔輸出的設計哲學]] — 單檔架構、CSS 內聯、Web Component（after step 1）
3. [[learn/ai-html/nodes/html-as-native-output/tool-comparison|HTML 演示文稿工具生態與選擇]] — 三種形式、選擇框架、常見錯誤（after steps 1–2）

## Lesson

HTML 不只是瀏覽器的標記語言——它是 AI 模型最自然的輸出格式。模型的訓練資料充滿了網頁，所以它生成 HTML 的能力遠超其他格式。理解這一點，才能明白為什麼「零依賴單檔輸出」是 AI 工作流中最實際的交付模式：一個 `.html` 檔案，打開就能看，不需安裝任何東西。
