# SKILL.md 工作流設計

## Learning goal

能拆解一份 SKILL.md 的段落結構，說出工作流階段、非妥協規則（non-negotiable rules）、和引用文件載入策略的角色。

## Lesson

SKILL.md 透過段落結構（角色定義、工作流階段、非妥協規則、引用文件策略、交付規格）把複雜任務拆成有序步驟，品質門檻分硬門檻（需使用者確認）和軟門檻（代理自動檢查），確保每次執行結果穩定可控。
