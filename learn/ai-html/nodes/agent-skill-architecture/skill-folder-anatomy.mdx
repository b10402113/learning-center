# Skill 資料夾結構

## Learning goal

能畫出一個 agent skill 的資料夾樹狀圖，說出每個目錄和檔案的角色，並解釋為什麼要這樣分層。

## Lesson

Agent Skill 的資料夾結構由 SKILL.md（主工作流）、references/（按需載入參考）、scripts/（確定性腳本）、templates/（輸出骨架）、themes/（設計系統）和 manifest.json（版本資訊）組成，分層的目的是控制上下文佔用，讓代理在正確時機載入正確文件。
