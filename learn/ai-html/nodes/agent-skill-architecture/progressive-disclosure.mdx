# Progressive Disclosure 載入模式

## Learning goal

能解釋為什麼大型 agent skill 不能把所有 reference 一次塞進 context，並畫出 index → preview → full reference 的三層載入流程。

## Lesson

Progressive Disclosure 把參考文件分成 Index → Preview → Full Reference 三層，代理只在需要時才載入更詳細的那一層，從而把上下文佔用從 ~272KB 壓縮到 ~13KB，解決了大型 skill 的上下文爆炸問題。
