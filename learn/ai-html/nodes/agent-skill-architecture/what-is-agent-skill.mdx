# 什麼是 Agent Skill？

## Learning goal

能說出 agent skill 的定義，分辨它跟一般 prompt template 的差異，並用一句話解釋為什麼需要 skill 這種結構。

## Lesson

Agent Skill 是一套給 AI 代理執行的結構化工作說明，不只是一段 prompt——它把工作流、品質門檻、設計約束和參考資料組織成一個完整資料夾，讓代理按階段走完流程而不是每次從零開始。
