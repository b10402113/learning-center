# 投影片基礎

## Learning goal

用 agent skill 生成一組可播放的 HTML 投影片（1920×1080 固定舞台、鍵盤/觸控導航）

## Steps

1. [[learn/ai-html/nodes/slide-fundamentals/html-slide-stage|固定舞台與視窗模型]] — 1920×1080 畫布、CSS transform 縮放、slide 堆疊與可見性切換
2. [[learn/ai-html/nodes/slide-fundamentals/html-slide-navigation|導航與互動控制]] — 鍵盤/觸控/滾輪導航、自動縮放、Web Component 封裝（after step 1）
3. [[learn/ai-html/nodes/slide-fundamentals/html-slide-templates|模板系統與設計選型]] — 34 套模板的 selection-index → preview → design 三層選型（after step 1）
4. [[learn/ai-html/nodes/slide-fundamentals/html-slide-production-pipeline|完整製作流程]] — 6 階段 pipeline：從素材到可播放投影片（after steps 2–3）

## Lesson

HTML 投影片的核心是一個零依賴的單檔輸出——瀏覽器就是你的播放器。這套系統用 1920×1080 固定畫布取代自適應佈局，用 CSS transform 縮放讓它在任何螢幕上都正確呈現，用鍵盤和觸控驅動導航，用模板系統管理視覺風格。四步走完，你會理解從一個空白瀏覽器到一組可播放投影片的完整路徑。
