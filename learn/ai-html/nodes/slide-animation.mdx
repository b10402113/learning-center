# 投影片動畫

## Learning goal

理解兩 tier 動畫系統——CSS 進入效果和即時 Canvas FX——的架構、情感-動畫對應，以及動畫組合的節制原則。

## Steps

1. [[learn/ai-html/nodes/slide-animation/css-entry-animations|CSS 進入動畫]] — 認識 data-anim 屬性、27 種動畫分類、transition-delay 疊加
2. [[learn/ai-html/nodes/slide-animation/emotion-animation-mapping|情感-動畫對應]] — 六種感覺類別如何決定動畫選擇（after step 1）
3. [[learn/ai-html/nodes/slide-animation/canvas-fx-layer|Canvas FX 即時效果]] — 20 個 canvas 模組、fx-runtime.js 生命週期、DPR 修正（after step 1）
4. [[learn/ai-html/nodes/slide-animation/animation-composition|動畫組合與節制]] — 每張投影片的動畫密度、CSS+Canvas 協同、反模式（after steps 1–3）

## Lesson

投影片動畫不是單一技術，而是兩層系統的協作。第一層是 CSS 進入動畫——用 `data-anim` 屬性驅動，元素出場時播放一次，輕量且自動。第二層是 Canvas FX——用 `<canvas>` 繪製持續運行的視覺效果，由 fx-runtime.js 管理生命週期。兩層共享主題顏色（CSS custom properties），換主題時自動跟著換。

但技術只是基礎。更重要的是「什麼時候用什麼動畫」——這由情感-動畫對應決定。六種感覺類別（Dramatic、Techy、Playful、Professional、Calm、Editorial）各自偏好不同的動畫類型。最後，動畫的品質來自節制：每張投影片最多一個強調動畫，背景 FX 和前景 CSS 分工協作，整份投影片的節奏像音樂一樣有起有落。
