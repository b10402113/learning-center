# Digest — frontend-slides.md

## Overview (L1)

- HTML 演示文稿工具对比文章（2026年8月验证）
- 对比五种方案：Reveal.js、Slidev、Marp、WebSlides、Raw HTML/CSS
- 按工作流场景给出选择建议，而非简单排名

## Sections (L2)

### HTML 演示文稿概览

- Locator: `[[sources/ai-html/20260910/frontend-slides.md#7]]`
- Summary: HTML 演示文稿有三种常见形式：框架驱动（Reveal.js）、Markdown 驱动（Slidev/Marp）、Agent 构建的本地项目
- Key claims: 搜索意图分裂——有人要框架，有人要 Markdown，有人要 AI 生成的 HTML
- Learner-relevant: 理解 HTML 演示文稿的生态全景

### 各工具对比

- Locator: `[[sources/ai-html/20260910/frontend-slides.md#62]]`
- Summary: Reveal.js 控制力最强但编辑摩擦大；Slidev 开发者友好但 PPTX 导出为图片；Marp 最简洁但交互弱；WebSlides 模板化快速但生态老旧；Raw HTML/CSS 自由度最高但团队协作脆弱
- Key claims: 选择应基于 review 步骤而非 generation 步骤；首稿 rarely 是难的部分
- Learner-relevant: 根据自身场景选择合适工具的决策框架

### 常见错误

- Locator: `[[sources/ai-html/20260910/frontend-slides.md#184]]`
- Summary: 四个常见错误：选框架而非编辑器、假设导出是原生 PPTX、让 AI 草稿成为 source of truth、混用运行时目标
- Key claims: 导出是翻译不是原生转换；AI 草稿后需要稳定的编辑路径
- Learner-relevant: 避免 HTML 演示文稿项目中的典型陷阱
