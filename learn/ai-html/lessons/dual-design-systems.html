雙設計系統實戰

Token 主題系統 · Step 3/4 · 約 15 分鐘

兩種設計哲學

投影片的主題系統不是只有一種風格。在同一個技術架構（CSS custom properties）上，可以長出截然不同的設計語言。這一課對照兩套真實的設計系統：magazine-ink（雜誌墨水風格）和 Swiss International（瑞士國際排版），看它們的 token 設計有何不同、各自有什麼硬性約束。

Style-A：Magazine-Ink（雜誌墨水）

Magazine-ink 的核心意象是紙本雜誌——溫暖的紙色、深沉的墨色、有機的質感。它提供 5 套主題，每套用一組 CSS 變數定義：

主題名 --ink（墨色） --paper（紙色） 適用場景
Ink Classic深黑墨色米白紙色預設，通用
Indigo Porcelain靛藍深色瓷器白科技、研究
Forest Ink深綠墨色自然紙色自然、文化
Kraft Paper深棕墨色牛皮紙色懷舊、文學
Dune沙棕墨色沙漠紙色藝術、設計

每套主題定義 6 個核心變數：

/* Ink Classic 主題 */
:root {
  --ink: #1a1a1a;
  --ink-rgb: 26, 26, 26;
  --paper: #fafaf8;
  --paper-rgb: 250, 250, 248;
  --paper-tint: rgba(250, 250, 248, 0.05);
  --ink-tint: rgba(26, 26, 26, 0.05);
}

Style-A 的硬性約束

  • 禁止自訂 hex 顏色——只能用 5 套預設主題的變數值，不能手動填入任意 hex
  • 禁止混搭主題——一份投影片只能用一套主題的變數，不能 A 主題的墨色配 B 主題的紙色
  • 紙色和墨色是成對的——每個主題的 --paper 和 --ink 經過對比度校驗，分開替換會破壞可讀性

Style-B：Swiss International（瑞士國際排版）

Swiss International 的設計語言完全相反：冷靜、數學、極簡。它用單一強調色（anchor color）作為整份投影片的唯一彩色，其他一切都是黑白灰。

Swiss 提供 4 套強調色預設：

強調色 --accent 適用場景
Klein Blue IKB#002fa7預設，通用
Lemon Yellow#fff44f活潑、年輕
Lemon Green#a3c940自然、環保
Safety Orange#ff6700警示、工程

每套主題定義 7 個核心變數：

/* Klein Blue IKB 主題 */
:root {
  --paper: #ffffff;
  --ink: #111111;
  --grey-1: #f5f5f5;
  --grey-2: #e0e0e0;
  --grey-3: #999999;
  --accent: #002fa7;
  --accent-rgb: 0, 47, 167;
  --accent-on: #ffffff;
}

Style-B 的硬性約束

  • 單一強調色——每份投影片只能有一個 --accent，不能同時用多個強調色
  • 禁止漸層和陰影——不允許 gradient 或 box-shadow，保持平面設計的純粹
  • 灰色階跨主題恆定——--grey-1/2/3 在所有 4 套主題裡數值相同，只有 --accent 不同
  • 字重-尺寸反比——字越大、字重越輕（heading 用 weight 200，body 用 weight 400，這是 Swiss 的經典規則）

兩套系統的 token 對照

雖然風格截然不同，兩套系統的 token 架構遵循相同的邏輯：

面向 Style-A (Magazine-Ink) Style-B (Swiss)
核心隱喻紙本雜誌瑞士國際排版
色彩策略雙色調（ink + paper）+ 漸層單色點綴（accent only）
主題數量5 套4 套
核心變數數6 個7 個
硬性約束禁止自訂 hex、禁止混搭單一 accent、禁止漸層陰影
灰色處理由 ink/paper tint 派生跨主題恆定的 grey-1/2/3

為什麼要約束？

你可能覺得「禁止自訂 hex」或「只能用一個強調色」很限制自由。但這些約束正是品質的來源。一個 agent（AI 程式）在生成投影片時，如果可以任意填入顏色值，它會每次都做出不一樣的視覺決策——有時好看，有時災難。預設主題 + 硬性約束確保：不管誰生成、什麼時候生成，視覺品質都是穩定的。

約束即品質：主題系統的硬性約束不是限制，是品質閘門。它們確保 agent 的輸出始終在一個可控的視覺空間內。
