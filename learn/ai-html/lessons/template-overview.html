模板架構全景

投影片模板 · Step 1/3

Learning goal

能說出 frontend-slides 的 34 個模板與 guizang-ppt-skill 的 31 個版面如何組合，以及 progressive-disclosure 載入策略的核心原理。

兩套模板系統

前端投影片的模板不是一套，而是兩套：一套管「視覺風格」，一套管「頁面結構」。兩者各自獨立，但最終在生成 HTML 投影片時合在一起。

Frontend-slides 的 Bold Template Pack

這套系統管的是整體視覺風格——配色、字型、裝飾語彙、氣氛。它包含 34 個設計模板，每個模板是一個完整的設計系統 recipe，定義了：

元素說明
色票主色、輔色、背景色、文字色，全部用 CSS custom properties 定義
字型層級從 display 到 meta，每一級的字型、字重、字號
裝飾語彙signature elements——每個模板的視覺標誌（如 8-Bit Orbit 的像素霓虹、Monochrome 的全黑排版）
情緒對應mood + tone 元數據，描述模板適合的情境

34 個模板涵蓋了從「retro neon arcade」到「quiet literary serif」的完整光譜。每個模板都是一個獨立的目錄，裡面有兩個文件：一個輕量的 preview 卡片和一個完整的 design recipe。

Guizang-ppt-skill 的 Locked Layouts

這套系統管的是頁面結構——每一頁投影片的骨架。它分兩種風格：

風格版面數設計語言
Style A（電子雜誌 × 電子墨水）10 個襯線字型、深淺交替、墨水質感
Style B（瑞士國際主義）22 個無襯線、極細字重、單色強調、嚴格網格

Style A 的 10 個版面是「可選」的——你可以自由挑選、混搭。Style B 的 22 個版面則是「locked」的——一旦選了瑞士風格，你就只能從這 22 個已登記的版面中選擇，不能自己發明新的。

兩套系統的組合

當你用 agent skill 生成一組投影片時，流程是：

  1. 選風格：從 34 個 bold templates 中選一個（或從 Style A/B 預設中選）
  2. 選版面：為每一頁從版面庫中選一個骨架
  3. 填內容：把文字、圖片、數據填進骨架

風格決定「看起來像什麼」，版面決定「東西放在哪裡」。一個 Bold Poster 風格可以用 Swiss 的 S04 六格版面嗎？不行——Style A 和 Style B 的 CSS class name 是不通用的。每一份 deck 只能選一套風格系統。

Progressive-disclosure 載入

34 個模板的完整 design recipe 加起來是非常大的資訊量。如果代理一次全部載入，會嚴重佔用 context window，影響生成品質。所以 frontend-slides 用了一個三層載入策略：

層級檔案大小用途
L0selection-index.json~20KB機器可讀的元數據索引，用於初步篩選
L1preview.md~2KB/個輕量風格卡片，用於標題頁預覽
L2design.md~5-10KB/個完整設計系統 recipe，只在使用者選定後載入

工作流程是：先讀 L0 索引 → 根據 mood/tone/best_for 篩選出 2-3 個候選 → 讀候選的 L1 preview 卡片 → 使用者選一個 → 才讀那個模板的 L2 design recipe。

關鍵規則：不要一次讀所有 design.md。每次只讀使用者選定的那一個。這就是 progressive-disclosure——按需載入，而非一次全讀。

Guizang 的版面載入

Guizang-ppt-skill 的版面系統用了另一種策略：索引表格 + 按需查閱。SKILL.md 裡有一張完整的版面註冊表（S01-S22），列出每個版面的用途、骨架、關鍵 class name。代理在生成時先查表選版面，然後只讀那個版面的完整規格。

Style A 的 10 個版面也一樣——layouts.md 裡有所有版面的 paste-ready HTML 程式碼塊，代理直接複製對應的 `

` 骨架，替換文案即可。
