模板系統與設計選型

投影片基礎 · Step 3/4

學習目標

理解 34 套模板的組織方式：如何用 selection-index.json 快速選型、preview.md 輕量比較、design.md 完整實作，以及 Safe/Bold/Wildcard 三選一策略。

為什麼需要模板系統？

有了固定舞台和導航機制，你已經可以做出一組能播放的投影片。但「能播放」和「好看」之間的差距是巨大的。手動為每一組投影片設計顏色、字型、排版既耗時又容易不一致。

模板系統解決的是設計一致性的問題：你選定一個設計風格（例如「科技感」或「雜誌風」），模板會提供完整的設計規範——顏色 token、字型階層、排版規則、裝飾語彙——讓 agent 生成的每一張投影片都符合同一套視覺語言。

34 套模板的結構

每套模板是一個獨立的目錄，裡面包含兩個核心文件：

文件用途大小
preview.md輕量風格卡片：色票快照、招牌招式、適用場景~1 KB
design.md完整設計系統：顏色 token、字型比例、元件文法、間奏節奏、裝飾語彙~5-10 KB

這個兩層結構是刻意的：先用 preview.md 快速比較多個候選，再只讀被選中的那一個 design.md。這是 progressive-disclosure（漸進式揭露）的實踐——避免一次載入 34 個完整設計規範。

selection-index.json：機器可讀的目錄

34 套模板的 metadata 被壓縮成一個 JSON 檔案：selection-index.json。每筆記錄包含：

{
  "slug": "bold-signal",
  "name": "Bold Signal",
  "tagline": "大膽、自信、科技感",
  "mood": "powerful",
  "tone": "confident",
  "formality": "semi-formal",
  "density": "medium",
  "scheme": "dark",
  "best_for": "產品發布、技術演講",
  "avoid_for": "學術報告、法律文件"
}

agent 的選型流程從這裡開始：讀取 JSON、根據投影片的主題和受眾篩選候選、然後只載入候選模板的 preview.md。這比直接掃描 34 個目錄高效得多。

Safe / Bold / Wildcard 三選一策略

從 34 個候選中挑出最合適的模板，最怕的是兩個極端：永遠選最安全的（無聊），或永遠選最大膽的（失控）。三選一策略是解方：

類型策略目的
Safe（安全）選一個最匹配主題的保守選項確保基本品質
Bold（大膽）選一個風格強烈但主題仍合適的選項帶來視覺衝擊
Wildcard（意外）選一個風格反差大的選項可能有驚喜，也可能翻車

讓使用者從這三個候選中挑一個。Safe 保底，Bold 創新，Wildcard 賭一把。這種策略把「從 34 個中選一個」的決策負擔，降低到「從 3 個中選一個」。

preview.md：風格卡片

每個 preview.md 是一張緊湊的風格卡片，包含：

  • 色票快照——2-3 個主要顏色的 hex 值和 CSS variable 名稱
  • 字型快照——標題和內文各用什麼字型、什麼 weight
  • 招牌招式——這個模板最有特色的視覺元素（例如「大標題 + 細字」對比、「深色背景 + 霓虹色」搭配）
  • 適用場景——什麼類型的投影片適合這個模板
  • 不適合場景——什麼類型的投影片不該用這個模板

preview.md 的設計哲學是：不看 design.md 也能做出判斷。它足夠輕量，可以一次載入多個做比較。

design.md：完整設計規範

一旦選定模板，就讀取它的 design.md。這是一份完整的設計系統說明書，包含：

  • 顏色 token——所有 CSS custom properties 的定義和用途
  • 字型比例——從 display 到 body 到 caption 的完整字型階層
  • 元件文法——標題、段落、數據卡片、時間軸等元件的 HTML 結構和 CSS class
  • 間奏節奏——投影片之間的主題切換節奏（light/dark/hero 交替）
  • 裝飾語彙——背景紋理、裝飾線條、圖案等視覺元素
  • CJK 支援——中文/日文/韓文的字型 fallback 和排版調整
  • 投影片類型藍圖——封面頁、內容頁、數據頁、結尾頁等的排版模板

Style Presets：12 套預設主題

除了 34 套 bold 模板，還有一套 12 個的 Style Presets。每個 preset 是一個 CSS variable 集合——你把它貼到投影片的 :root 裡，整體外觀就會改變。

Style Presets 和 bold 模板的區別：

FeatureStyle PresetsBold Templates
內容CSS variable 值完整 design system
適用快速換膚深度客製
數量12 個34 個
選擇方式從 STYLE_PRESETS.md 中選從 selection-index.json 中選

如果使用者只是想快速換個顏色風格，Style Presets 就夠了。如果需要深度客製排版和元件，就走 bold template 路線。

Guizang 的雙系統

另一套投影片技能（guizang-ppt-skill）採用了類似但不同的雙系統：Style A（雜誌墨印風）和 Style B（瑞士國際排版風）。

Style A 有 10 種佈局和 5 個主題色，Style B 有 22 種鎖定佈局和 4 個強調色。兩者共享同一個簡報模式運行時（presenter mode runtime），但 CSS class 完全不能混用——這是一個硬性約束。

guizang 的核心教訓是：鎖定佈局比開放佈局更安全。當你限制 agent 只能使用已註冊的佈局時，視覺漂移就被結構性地防止了。
