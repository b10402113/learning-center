主題開發實作

Token 主題系統 · Step 4/4 · 約 12 分鐘

從理解到動手

前三課我們理解了 CSS custom properties 的機制、三層 token 架構、以及兩套真實設計系統的 token 設計。這一課你會親手寫一個新主題檔案——從 copy 到 override，產出一個 < 200 行的合法主題。

主題檔案的結構

一個主題檔案本質上就是一個 CSS 檔案，裡面只有一個 :root 區塊，定義語意層的覆蓋值。以 Magazine-Ink 為例，最簡單的主題檔案只有 6 個變數：

/* my-custom-ink.css */
:root {
  --ink: #2d1b69;
  --ink-rgb: 45, 27, 105;
  --paper: #f0eef5;
  --paper-rgb: 240, 238, 245;
  --paper-tint: rgba(240, 238, 245, 0.05);
  --ink-tint: rgba(45, 27, 105, 0.05);
}

以 Swiss 為例，需要 7 個變數：

/* my-custom-swiss.css */
:root {
  --paper: #ffffff;
  --ink: #1a1a1a;
  --grey-1: #f5f5f5;
  --grey-2: #e0e0e0;
  --grey-3: #999999;
  --accent: #8b5cf6;
  --accent-rgb: 139, 92, 246;
  --accent-on: #ffffff;
}

開發流程：四步驟

Step 1：選擇基礎主題

不要從空白檔案開始。從最接近你想要的風格的現有主題複製。想要暖色調？從 Ink Classic 出發。想要冷靜極簡？從 Klein Blue 出發。

複製的目的不是偷懶——是確保你不會漏掉任何必要的變數。每個主題檔案都是一個完整的變數清單，漏掉任何一個，元件就會回退到 base.css 的預設值，可能跟你想要的風格不一致。

Step 2：修改核心變數

只改核心變數。Magazine-Ink 改 6 個，Swiss 改 7 個。不要在主題檔案裡加新變數——新變數屬於 base.css。

修改時注意：

  • 對比度：文字和背景的對比度至少 4.5:1（WCAG AA 標準）
  • 一致性：--ink 和 --paper 要成對考虑，不能只改一個
  • 語意：--accent 要有足够的視覺重量，能從背景中脫穎而出

Step 3：驗證視覺效果

把主題檔案連結到投影片，在瀏覽器中打開：

<link rel="stylesheet" href="../assets/base.css">
<link rel="stylesheet" href="../assets/themes/my-custom-ink.css">

檢查三個地方：

  1. 首頁——標題、副標題、背景是否協調
  2. 內容頁——文字可讀性、強調色是否突出
  3. 代碼頁——等寬字型、代碼區塊的對比度

Step 4：保持檔案精簡

一個主題檔案的行數上限是 200 行。這不是任意的數字——超過 200 行通常意味著你在主題檔案裡做了不該做的事（比如加了新的 CSS 規則、定義了新的元件樣式、或加了動畫）。主題檔案只負責覆蓋變數值，不負責其他任何事。

常見錯誤

錯誤 為什麼是問題 正確做法
在主題檔案裡加新的 CSS 規則 主題檔案只負責覆蓋變數，加規則會跟 base.css 產生衝突 新規則加到 base.css 或元件 CSS 裡
漏掉某個變數 元件會回退到 base.css 的預設值，可能跟主題不協調 從現有主題複製，確保所有變數都被覆蓋
用 eyedropper 隨意取色 可能選到對比度不足的顏色組合 用對比度檢查工具驗證（至少 4.5:1）
在 Swiss 主題裡加漸層 違反 Swiss 設計語言的硬性約束 遵守主題系統的硬性約束
在 Magazine-Ink 裡混搭兩套主題的變數 破壞主題的整體協調性 一套主題用到底，不混搭

進階：36 個主題的分類

在一個成熟的投影片系統中，通常有 30+ 個主題。這些主題按風格分為幾個類別：

  • Light & calm（6 個）——minimal-white, editorial-serif, soft-pastel, solarized-light 等
  • Bold & statement（5 個）——sharp-mono, neo-brutalism, bauhaus, swiss-grid 等
  • Cool & dark（7 個）——catppuccin-mocha, dracula, tokyo-night, nord 等
  • Effect-heavy（5 個）——glassmorphism, aurora, rainbow-gradient 等
  • v2 additions（12 個）——corporate-clean, pitch-deck-vc, academic-paper 等

每個類別是一種「視覺情緒」。選主題不是選顏色，是選情緒——工程師的提案用 Cool & dark，設計師的作品集用 Light & calm，給消費者的行銷用 Warm & vibrant。
