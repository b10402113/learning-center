CSS Custom Properties 基礎

Token 主題系統 · Step 1/4 · 約 12 分鐘

為什麼需要 CSS 變數？

假設你在設計一套投影片的配色。深色背景用 #1e293b，淺色文字用 #e2e8f0，強調色用 #2563eb。如果你要換主題，得把每一個 color: 和 background: 宣告都找出來、逐一替換。

這就是硬編碼顏色（hardcoded colors）的痛點：視覺決策散落在數十個 CSS 規則裡，改一個顏色要改十幾個地方，而且很容易漏改。

Custom Properties 是什麼？

CSS Custom Properties（CSS 自訂屬性）是瀏覽器原生的變數機制。你用 -- 前綴宣告一個變數，用 var() 引用它：

:root {
  --bg: #1e293b;
  --text: #e2e8f0;
  --accent: #2563eb;
}

body {
  background: var(--bg);
  color: var(--text);
}

a {
  color: var(--accent);
}

現在想換主題？只要覆蓋 :root 上的變數值，所有引用這些變數的規則會自動更新：

:root {
  --bg: #fafaf8;
  --text: #1a1a1a;
  --accent: #dc2626;
}

從深色主題切到淺色主題，只需要改這三行。不用動任何 body 或 a 的規則。

與 CSS 預處理器變數的根本差異

Sass（$variable）和 Less（@variable）也有變數，但它們是編譯期的——瀏覽器拿到的 CSS 裡已經被替換成實際值了。瀏覽器不認識 Sass 變數，也沒辦法在執行時改它們。

CSS Custom Properties 則是執行期的。瀏覽器在渲染時解析 var()，所以你可以：

  • 用 JavaScript 動態修改變數值（document.documentElement.style.setProperty('--bg', '#fff')）
  • 在不同的作用域（scope）覆蓋變數——同一份 CSS，.dark 裡的 --bg 可以跟 .light 裡的不同
  • 在 prefers-color-scheme 媒體查詢裡切換變數值
關鍵差異：Sass 變數在編譯後消失；CSS Custom Properties 留在瀏覽器裡，可以被 JavaScript 修改、被作用域覆蓋、被媒體查詢觸發。這才是主題切換的基礎。

作用域（Scope）

Custom properties 遵循 CSS 的作用域規則。宣告在 :root 上的變數，全頁可用；宣告在某個 class 裡的變數，只在那個 class 的子元素裡有效：

:root {
  --accent: #2563eb;   /* 全頁預設 */
}

.dark {
  --accent: #60a5fa;   /* .dark 內的子元素用這個 */
}

.dark a {
  color: var(--accent); /* 拿到 #60a5fa，不是 #2563eb */
}

這個作用域機制是主題系統的核心：每個主題就是一組在特定 class 或 :root 裡覆蓋的變數值。

fallback 值

var() 支援第二個參數作為 fallback——當變數未宣告時使用：

color: var(--accent, #2563eb);

這讓你在新增變數時不會破壞現有樣式：老主題沒宣告新變數，就用 fallback 值。

實戰觀察

在投影片的設計系統裡，一個典型的 :root 區塊會定義 30+ 個變數。你不需要一次記住所有變數名稱——重要的是理解變數分為幾個類別（顏色、字型、間距、圓角、陰影），以及每一類別的命名邏輯。下一課會深入這套分層架構。
