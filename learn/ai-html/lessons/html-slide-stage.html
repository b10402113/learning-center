固定舞台與視窗模型

投影片基礎 · Step 1/4

學習目標

理解 1920×1080 固定舞台的設計原理：為什麼用 CSS transform 縮放而不是自適應佈局，以及 slide 堆疊與可見性切換的機制。

為什麼是「固定畫布」而不是「自適應」？

大多數網頁是自適應的——你拉大瀏覽器視窗，內容就跟著放大。但投影片不一樣。每一張投影片都是一幅精心排版的畫面：標題的大小、文字和圖片的位置、留白的比例，都是設計好的。如果你讓它「自適應」，排版就會在不同螢幕上崩掉。

所以 HTML 投影片選擇了一條反直覺的路：先在一個固定尺寸的畫布（stage）上把排版鎖死，然後用 CSS transform 把整個畫布縮放到當前瀏覽器視窗的大小。畫布永遠是 1920×1080 像素，不管你的螢幕是 13 吋筆電還是 27 吋桌面螢幕。

核心思路：排版在固定畫布上完成，顯示時由瀏覽器統一縮放。設計師控制每一像素，瀏覽器只負責「把它塞進螢幕」。

三層結構：viewport → stage → slide

HTML 投影片的 DOM 結構分三層，每一層各司其職：

層級CSS class職責
外框.deck-viewport佔滿整個瀏覽器視窗，溢位藏掉（overflow: hidden）
舞台.deck-stage固定 1920×1080，透過 CSS transform 縮放到視窗大小
投影片.slide多張堆疊，同一時間只有一張可見

用一句話記住：viewport 是瀏覽器的「鏡頭」，stage 是「畫布」，slide 是畫布上的「頁面」。

CSS transform 縮放機制

舞台的縮放是整個系統的靈魂。核心邏輯很簡單：

/* 計算縮放比例 */
const scaleX = window.innerWidth / 1920;
const scaleY = window.innerHeight / 1080;
const scale = Math.min(scaleX, scaleY);

/* 套用到舞台 */
stage.style.transform = `scale(${scale})`;
stage.style.transformOrigin = 'top left';

用 Math.min 取較小的縮放比例，確保畫布完全塞進視窗而不裁切。配合 transform-origin: top left，畫布從左上角開始縮放，剩餘空間用背景色填滿。

當瀏覽器視窗大小改變時，觸發 resize 事件重新計算。這就是為什麼你在開發者工具裡拉動視窗邊框，投影片會即時跟著縮放。

關鍵概念：CSS transform 縮放是「像素完美」的——所有文字、圖片、間距都保持設計時的比例，不會像 CSS vw/vh 單位那樣產生非整數像素的模糊。

Slide 堆疊與可見性切換

所有投影片在 DOM 裡是「堆疊」的——它們全部疊在同一個位置，就像一疊撲克牌。但你一次只能看到一張。切換方式是透過 CSS class 控制 visibility 和 opacity：

狀態CSS class效果
當前顯示.slide.activevisibility: visible; opacity: 1
已載入但隱藏.slide.visiblevisibility: visible; opacity: 0（佔位但看不見）
未載入（無 class）visibility: hidden（不佔位）

為什麼用 visibility + opacity 而不是 display: none？因為 display: none 會讓元素完全脫離文件流——瀏覽器不渲染它，也不會載入裡面的圖片。用 visibility: hidden + opacity: 0，元素仍然佔位、仍然被渲染，只是看不見。這樣切換時不需要重新渲染，動畫也更流暢。

列印樣式與無障礙支援

一個完整的投影片系統還要處理兩個邊界情況：

列印（Print）

當使用者按 Ctrl+P 列印時，@media print 樣式會把每一張 slide 顯示為獨立的列印頁面，隱藏其他 slide 和導航元素。這樣你就能直接從瀏覽器列印出 PDF。

減少動畫（Reduced Motion）

@media (prefers-reduced-motion: reduce) 是系統級的無障礙設定。如果使用者在作業系統裡開啟了「減少動畫」，投影片會跳過所有進入動畫，直接顯示最終狀態。這是對前庭障礙（vestibular disorder）使用者的基本尊重。

零依賴的單檔輸出

所有這些——viewport CSS、stage 縮放 JS、slide 堆疊邏輯、列印樣式、無障礙支援——全部內聯在一個 HTML 檔案裡。不需要任何外部 CSS 檔、JS 檔或套件管理器。瀏覽器就是播放器，一個 HTML 檔就是一部投影片。

這是 HTML 投影片最強大的地方：你可以把一個 .html 檔傳給任何人，對方不需要安裝任何東西，打開瀏覽器就能看。不需要 PowerPoint、不需要 Google Slides、不需要網路連線。
