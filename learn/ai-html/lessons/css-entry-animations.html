CSS 進入動畫

投影片動畫 · Step 1/4

學習目標

能說出 CSS 進入動畫的觸發機制（data-anim 屬性），並分辨 27 種動畫的七個分類、各分類的代表動畫，以及 transition-delay 疊加的基本原理。

什麼是 CSS 進入動畫

在 HTML 投影片裡，動畫分兩種：一種是元素「出場」時播放一次就結束的進入動畫（entry animation），另一種是持續運行的背景效果。這一步專注前者。

所謂「進入動畫」，指的是投影片切換時，畫面上的標題、段落、圖片、卡片等元素依照設定的動畫類型，從無到有地出場。它們本質上是 CSS animation，瀏覽器在元素被觸發時播放一次，播完就停在最終狀態。不需要 JavaScript 控制每一幀，也不需要外部動畫函式庫。

data-anim 屬性：觸發機制

這套系統用一個 HTML 屬性來驅動：data-anim。你把動畫名稱寫在屬性值裡，瀏覽器播放時自動套用對應的 CSS animation。例如：

<h2 data-anim="rise-in">架構總覽</h2>
<p data-anim="fade-up" style="animation-delay: 0.2s">從底層到頂層</p>

當投影片切換到這張 slide 時，<h2> 會執行 rise-in 動畫，<p> 會在 0.2 秒後執行 fade-up。動畫名稱對應到 CSS 裡的 @keyframes 定義——每一個名稱都是一段預寫好的關鍵幀規則。

這種屬性驅動的設計有一個關鍵好處：作者不需要寫任何 JavaScript，只需要在 HTML 標記上加一個屬性。技能（skill）在生成投影片時，自動把 data-anim 加到需要動畫的元素上。

27 種動畫的七個分類

系統提供 27 種命名動畫，按視覺效果分成七類：

分類動畫名稱效果描述
方向淡入fade-up, fade-down, fade-left, fade-right從指定方向滑入並淡入
戲劇性出場rise-in, zoom-pop, glitch-in, scale-bounce大幅度位移或縮放，視覺衝擊強
文字效果typewriter, neon-glow, blur-in逐字出現、發光、模糊清晰化
列表動畫stagger-list, counter-up, slide-in-list依序出現的列表項目
SVG 幾何path-draw, morph-shape, rotate-in路徑描繪、形狀變形、旋轉進入
3D 透視card-flip-3d, cube-rotate-3d, perspective-in帶透視的三維翻轉與旋轉
持續 Ambientkenburns, marquee-scroll, pulse-glow, float-drift慢速持續播放的背景效果

每一種動畫都是一個 CSS class 或 data-anim 值，觸發時瀏覽器播放對應的 @keyframes。

transition-delay 疊加原理

一張投影片上往往不只一個元素要動畫。如果所有元素同時出場，畫面會很混亂。解決方法是用 animation-delay 錯開每個元素的開始時間。

例如一張有標題和三個要點的投影片：

<h1 data-anim="rise-in">季度回顧</h1>
<div data-anim="fade-up" style="animation-delay: 0.1s">1. 營收成長 23%</div>
<div data-anim="fade-up" style="animation-delay: 0.2s">2. 新客比例 40%</div>
<div data-anim="fade-up" style="animation-delay: 0.3s">3. 續約率 91%</div>

標題先出，0.1 秒後第一個要點出，再 0.1 秒後第二個要點出。這種「階梯式出場」讓視線有時間跟隨，是投影片動畫最基本的節奏控制。

在技能生成的投影片裡，這個延遲通常是自動計算的：作者不需要手動寫每個 delay，技能會根據元素順序自動遞增。

為什麼不用 JavaScript

純 CSS 動畫有幾個實際優勢。首先，瀏覽器可以用 GPU 加速 CSS animation，效能比 JavaScript 逐幀更新好。其次，CSS 動畫在投影片切換時自動播放、離開時自動停止，不需要額外的生命週期管理。最後，它和主題系統（token-driven design）完全兼容：動畫的顏色可以讀 CSS custom properties，換主題時自動跟著換。

唯一的限制是 CSS 動畫只能做「播放一次就停」的效果。如果你想做持續運行的粒子效果或背景動畫，就需要 Canvas——這是第三步的主題。

prefers-reduced-motion 無障礙支持

一個重要的細節：這套動畫系統尊重使用者的系統設定。如果使用者在作業系統裡開啟了「減少動態效果」（reduced motion），所有 CSS 進入動畫會被跳過，元素直接以最終狀態顯示。這是透過 CSS media query 實現的：

@media (prefers-reduced-motion: reduce) {
  [data-anim] {
    animation: none !important;
  }
}

這不只是無障礙法規的要求——它也讓你在演示時遇到對動畫敏感的觀眾，能一鍵關閉所有效果。
