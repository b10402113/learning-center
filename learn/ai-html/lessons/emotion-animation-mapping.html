情感-動畫對應

投影片動畫 · Step 2/4

學習目標

能說出六種感覺類別（Dramatic、Techy、Playful、Professional、Calm、Editorial）各自的動畫偏好，並根據投影片的內容情緒選擇合適的動畫類型。

為什麼要按感覺選動畫

動畫不是裝飾。每一種動畫都帶有情緒色彩：rise-in 帶來力量感，typewriter 帶來節奏感，fade-up 帶來平穩感。如果一張嚴肅的財報投影片用了 zoom-pop，觀眾會覺得不協調；一張創意提案用了 fade-up，又會覺得無聊。

這就是「情感-動畫對應」的核心：動畫的選擇應該跟隨投影片的情緒基調，而不是隨便挑一個好看的。

六種感覺類別

動畫按情緒分成六個感覺類別，每個類別對應一組動畫偏好：

Dramatic（戲劇性）

適合：關鍵轉折、震撼數據、標題揭幕。動畫特徵是大幅度位移、強烈對比、視覺衝擊。

代表動畫：rise-in（從底部升起）、zoom-pop（放大彈出）、glitch-in（故障效果進入）、scale-bounce（縮放彈跳）。

使用場景：產品發布會的第一張投影片、營收翻倍的數字揭幕、新功能名稱的宣布。這類動畫說的是「注意，這很重要」。

Techy（科技感）

適合：程式碼展示、系統架構、數據視覺化。動畫特徵是精確、規律、帶有數位感。

代表動畫：typewriter（打字機效果）、neon-glow（霓虹發光）、blur-in（從模糊到清晰）、counter-up（數字跳動）。

使用場景：展示 API 請求流程、呈現系統架構圖、顯示即時數據。這類動畫說的是「這是精密的技術」。

Playful（活潑）

適合：團隊內部分享、輕鬆的教學、腦力激盪。動畫特徵是彈性、有趣、帶有驚喜感。

代表動畫：scale-bounce（彈跳）、stagger-list（依序彈出列表）、morph-shape（形狀變形）。

使用場景：新手教學步驟、團隊回顧、創意發想。這類動畫說的是「讓我們輕鬆地學」。

Professional（專業）

適合：商業報告、客戶提案、正式演講。動畫特徵是克制、平穩、不搶焦點。

代表動畫：fade-up、fade-left、fade-right、slide-in-list。

使用場景：季度報告、專案進度更新、客戶提案。這類動畫說的是「專注在內容上」。

Calm（平靜）

適合：反思性內容、心理學/哲學主題、慢節奏分享。動畫特徵是緩慢、柔和、不打擾。

代表動畫：kenburns（慢速縮放平移）、float-drift（漂浮）、pulse-glow（輕微脈動）。

使用場景：讀書心得、人生經驗分享、冥想引導。這類動畫說的是「慢慢來」。

Editorial（編輯感）

適合：長文導讀、設計評論、文化內容。動畫特徵是手工感、幾何感、帶有排版意識。

代表動畫：path-draw（路徑描繪）、morph-shape（形狀變形）、rotate-in（旋轉進入）。

使用場景：設計系統介紹、品牌手冊解說、文化評論。這類動畫說的是「這是精心設計的」。

怎麼做選擇：三個判斷依據

第一，看內容的情緒。 一張投影片有一個主導情緒。如果內容是「我們的營收翻了三倍」，那是 Dramatic；如果是「以下是系統架構的三個層級」，那是 Techy；如果是「每週回顧的三個反思」，那是 Calm。

第二，看觀眾的預期。 同樣的內容給不同觀眾，情緒基調不同。給工程師的技術分享用 Techy，給高階主管的報告用 Professional，給創意團隊的腦力激盪用 Playful。

第三，看整份投影片的節奏。 一份 30 張的投影片不可能全部 Dramatic——觀眾會疲勞。通常的模式是：開頭一張 Dramatic 鎮場，中間大部分用 Professional 或 Techy，偶爾插入一張 Playful 或 Editorial 換換節奏，結尾再一張 Dramatic 或 Calm 收尾。

動畫選擇不是一對一

一個常見誤區是把感覺類別和動畫名稱做一對一對應。事實上，同一個動畫可以在不同語境下服務不同情緒。fade-up 在一份 Calm 投影片裡是柔和的出場，在一份 Professional 投影片裡是中性的過渡。關鍵不是動畫名稱本身，而是它搭配的時間（duration）、延遲（delay）和上下文。

一個 rise-in 用了 0.3 秒 duration 是 Dramatic，用了 1.2 秒 duration 就變成 Calm。動畫的「感覺」是名稱、速度、節奏的組合，不是名稱 alone 決定的。

動畫作為內容的信號

最終，動畫的作用是信號（signal）。它告訴觀眾：「注意這個」、「這裡有節奏變化」、「現在換話題了」。選錯動畫就像在演講時用錯語氣——內容對了，但感受不對。

好的動畫選擇讓觀眾覺得「自然」——他們不會注意到動畫本身，但會感受到節奏和重點。壞的動畫選擇讓觀眾覺得「奇怪」——他們說不出哪裡不對，但就是不舒服。

這就是為什麼情感-動畫對應是動畫系統裡最重要的一層：它不是技術問題，是設計判斷。
