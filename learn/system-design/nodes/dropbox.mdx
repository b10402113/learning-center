# Dropbox

本節點將從零開始設計一個類似 Dropbox 的檔案同步與雲端儲存系統，涵蓋需求分析、架構設計、元件細節、同步流程與關鍵優化。這是系統設計面試中常見的經典題目，重點考察分塊策略、同步機制與多設備一致性處理。

## Learning goal
設計一個可擴展的檔案同步與雲端儲存系統，能夠支持多設備自動同步、檔案分享與離線編輯。

## Steps

1. **[[learn/system-design/nodes/dropbox/requirements-estimation|需求分析與容量估算]]** — 定義功能與非功能需求，估算系統儲存與流量規模
2. **[[learn/system-design/nodes/dropbox/high-level-architecture|高層次系統架構]]** — 整體工作流程與核心模塊劃分
3. **[[learn/system-design/nodes/dropbox/core-components|核心元件設計]]** — 客戶端、元數據庫、同步服務、消息隊列與雲端儲存的細節設計
4. **[[learn/system-design/nodes/dropbox/file-sync-workflow|檔案同步工作流程]]** — 變更傳播、離線處理與衝突解決
5. **[[learn/system-design/nodes/dropbox/design-optimizations|設計優化與考量]]** — 檔案分塊、去重與容錯機制

## Lesson
設計 Dropbox 的核心挑戰在於如何實現高效的多設備同步，平衡一致性與性能。採用檔案分塊（4KB-4MB）可以只同步變更的部分，減少數據傳輸；分離元數據與實際檔案存儲允許我們獨立擴展兩個部分；通過消息隊列實現異步通知，確保離線設備上線後能及時獲取更新。整體架構遵循「客戶端跟蹤變更 → 同步服務協調 → 雲端存儲保存數據」的經典模式。
