# 快取

## Learning goal
理解快取層的作用、核心概念、常見類型與失效策略，能在系統設計中正確選擇快取架構與策略。

## Steps
1. [[learn/system-design/nodes/caching/what-is-caching|什麼是快取]] — 理解快取基本定義與核心術語
2. [[learn/system-design/nodes/caching/caching-types|快取的常見類型]] — 認識不同部署位置的快取類型與適用場景
3. [[learn/system-design/nodes/caching/cache-invalidation|快取失效機制]] — 掌握快取失效問題與常見解決方法
4. [[learn/system-design/nodes/caching/cache-read-strategies|快取讀取策略]] — 比較 read-through 與 read-aside 策略的差異

## Lesson
快取是系統設計中提升效能最常用的技術之一，核心想法是**將常用的資料存在更快的存儲層，減少對底層緩慢數據源的訪問次數**。無論是前端瀏覽器、後端服務器還是全球分發的CDN，快取無處不在。

本節將從基礎定義開始，逐步介紹不同類型的快取、為什麼快取失效是個難題，以及常見的讀取策略，幫助你在面試中能清晰分析快取設計的取捨。
