# 資料分片

## Learning goal
理解 Partitioning 的分片策略與挑戰，能夠在系統設計中選擇合適的分片方案，並預見可能遇到的問題

## Steps

1. [[learn/system-design/nodes/data-partitioning/partitioning-methods|分片方法]] — 認識水平分片與垂直分片，瞭解不同方法的適用場景
2. [[learn/system-design/nodes/data-partitioning/partitioning-criteria|分片標準]] — 學習雜湊、範圍、列表等常見分片標準，比較各自的優缺點
3. [[learn/system-design/nodes/data-partitioning/partitioning-challenges|分片常見挑戰]] — 瞭解分片帶來的額外複雜性，比如跨分片查詢、重新分片等常見問題與解決思路

## Lesson
當單一資料庫無法容納整個資料集，或是單一節點的負載達到瓶頸時，資料分片（Data Partitioning）就是不可或缺的擴展手段。它將大型資料庫切割成多個較小、獨立的部分，分散到不同的節點上，讓每個節點只需要處理自己分區內的請求，從而提升系統的整體性能與可擴展性。

本節點將從分片方法開始，介紹不同分片方式的特點，再深入常見的分片標準，最後探討分片帶來的常見挑戰與解決方向，幫助你在面試中能夠清晰地說明分片設計的取捨。
