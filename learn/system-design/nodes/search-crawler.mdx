# Twitter Search & Web Crawler

## Learning goal
本節點將帶你從零開始設計兩個經典系統：Twitter Search 即時推文搜尋系統，以及能夠爬取整個網路的大規模網路爬蟲。你將學會如何分析需求、估算容量、設計核心架構，並處理各種大規模場景下的挑戰。

## Steps

1. **[[learn/system-design/nodes/search-crawler/twitter-search|Twitter Search 系統設計]]** — 完整覆蓋推文搜尋系統的需求分析、容量估算、索引設計、儲存分區、排名機制與最佳化
2. **[[learn/system-design/nodes/search-crawler/web-crawler-overview|網路爬蟲基礎與需求分析]]** — 認識網路爬蟲的作用、核心需求、設計考量與容量估算
3. **[[learn/system-design/nodes/search-crawler/web-crawler-architecture|網路爬蟲架構設計]]** — 學習大規模網路爬蟲的基本演算法與整體架構設計
4. **[[learn/system-design/nodes/search-crawler/web-crawler-challenges|網路爬蟲關鍵挑戰與解決方案]]** — 掌握重複 URL 移除、爬蟲陷阱、容錯處理與資料分區等核心挑戰的解決方案

## Lesson

本節點包含兩個獨立但相關的系統設計議題：

1. **Twitter Search**：面對每天數億條新推文與數億次搜尋請求，如何設計一個能夠快速回應查詢的推文搜尋系統。重點在於倒排索引的設計與資料分區。
2. **Web Crawler**：如何設計一個能夠大規模並行爬取整個網路的爬蟲系統，面對無限網頁、動態更新、重複內容與爬蟲陷阱等挑戰。

兩個系統都圍繞「搜尋」這個核心主題 — Twitter Search 是對使用者生成內容的搜尋，而 Web Crawler 是對公開網路內容的收集，為後續搜尋建立索引。學習完本節點，你將能夠在面試中從容應對這兩個經典系統設計題目。
