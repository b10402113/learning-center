## Lesson

Proxy（代理）伺服器是一段介於用戶端（client）和伺服器（server）之間的中介軟體，代替其中一方轉發請求。它的核心概念可以用快遞站來比喻：你不直接把信寄給朋友，而是交給快遞站代寄——收件人看到的寄件地址是快遞站的，不是你的。

Proxy 最基礎的分類是正向代理（Forward Proxy）和反向代理（Reverse Proxy）。這一課先看正向代理。正向代理站在用戶端這邊，代表用戶端向伺服器發出請求。伺服器看到的是 Proxy 的身份，不知道真正發請求的人是誰。

正向代理的功能遠比「單純轉發」豐富。它可以快取常用資源（全公司共用一份快取，減少外部頻寬）、過濾不當內容（學校封鎖社群媒體）、記錄所有經過的請求（企業审计）、以及轉換請求內容（自動壓縮圖片、加加密 header）。這些功能讓正向代理成為企業網路管理的核心元件。

在系統設計中，正向代理的核心價值在於：讓多個用戶端共享一個受控的出口，集中管理流量。對比直接連接（每台機器各自對外），經過正向代理的流量有統一的審計、過濾和快取能力。

在面試中，Proxy 是高頻基礎概念。面試官期望你能一句話定義它（中介，轉發請求），分辨正向代理和反向代理的核心差異（代理的對象不同），並列舉正向代理的實際用途。正向代理代表用戶端；下一課會看到站在伺服器那邊的反向代理，兩者的角色完全相反。
