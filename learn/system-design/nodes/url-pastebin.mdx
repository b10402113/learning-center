# URL Shortener & Pastebin

## Learning goal
設計短網址服務與文字分享平台，整合前面章節學到的系統設計概念，從需求澄清到最終擴展優化，一步步完成完整設計。

## Steps

以下是本節點的學習步驟：

1. **[[learn/system-design/nodes/url-pastebin/requirements-capacity|需求分析與容量估算]]** — 澄清功能性與非功能性需求，比較短網址與 Pastebin 的需求差異，並進行合理的容量估算。
2. **[[learn/system-design/nodes/url-pastebin/data-modeling|資料建模與金鑰生成]]** — 設計資料表結構，比較各種短金鑰生成策略的優缺點，選擇適合的資料庫類型。
3. **[[learn/system-design/nodes/url-pastebin/high-level-architecture|高層級架構設計]]** — 劃分系統組件，設計高層級架構，比較兩種服務的架構異同。
4. **[[learn/system-design/nodes/url-pastebin/advanced-optimizations|進階擴展與優化]]** — 學習資料分片、複製、快取、清理等擴展技術，解決大流量場景下的挑戰。

## Lesson
本節點是系統設計實戰的第一個案例，結合了兩個經典面試題：設計短網址服務（如 TinyURL）與設計 Pastebin 文字分享平台。這兩個問題有很多共同點，同時也有一些不同的設計考慮。透過這個案例，你將練習從零開始一步步完成系統設計，運用前面章節學到的所有核心概念，包括需求分析、容量估算、資料分片、快取、負載均衡等。

整個設計過程遵循標準的系統設計面試流程：先澄清需求，再估算容量，接著設計資料模型，然後提出高層級架構，最後討論進階優化和擴展。每個步驟都會強調設計取捨，幫助你理解為什麼選擇這個方案，而不是另一個。
