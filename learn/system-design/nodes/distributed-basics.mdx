# 分散式系統基礎

## Learning goal
掌握可擴展性、可靠性、可用性、效率、可管理性等核心特徵，這些是設計可擴展分散式系統的基礎概念，每個特性都影響著系統設計的決策方向。

## Steps

1. **[[learn/system-design/nodes/distributed-basics/distributed-system-overview|分散式系統概述]]** — 什麼是分散式系統，為什麼需要它，整體介紹五大核心特性
2. **[[learn/system-design/nodes/distributed-basics/scalability|可擴展性]]** — 深入理解可擴展性，區分垂直擴展與水平擴展
3. **[[learn/system-design/nodes/distributed-basics/reliability-availability|可靠性與可用性]]** — 理解可靠性、容錯與可用性的概念，以及它們之間的差異
4. **[[learn/system-design/nodes/distributed-basics/efficiency|效率]]** — 學習延遲與吞吐量，如何衡量分散式系統的效率
5. **[[learn/system-design/nodes/distributed-basics/manageability|可管理性]]** — 認識可管理性對長期系統營運的重要性

## Lesson
分散式系統是由多個獨立節點組成的系統，這些節點通過網絡通信來協同完成共同的目標。在設計分散式系統時，我們需要圍繞五個核心特性來做出設計決策：

1. **可擴展性**：系統應對增長需求的能力
2. **可靠性**：系統在故障環境下持續正確運行的能力
3. **可用性**：系統在正常條件下保持可操作的時間百分比
4. **效率**：系統響應時間與吞吐量的表現
5. **可管理性**：系統維護與運營的難易程度

每個特性都有其權衡取捨，在後續步驟中我們將逐一深入學習。
