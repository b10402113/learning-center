<LearningGoal>
理解負載均衡為使用者和服務提供者帶來的具體好處
</LearningGoal>

## Lesson

負載均衡對使用者和服務提供者都帶來了明顯的好處。對使用者來說，最直接的好處就是更快的回應速度與更高的服務可用性：不會因為單一伺服器過載而等待很久，也不會因為單一伺服器故障而無法使用服務。

更快的回應速度來自於流量分配——負載均衡器把新請求導向比較閒的伺服器，避免使用者排在慢請求後面等待。更高的可用性來自於故障轉移（Failover）——當某台伺服器當機時，負載均衡器自動偵測並把流量導到其他正常節點，使用者完全無感知。

對服務提供者來說，負載均衡帶來了三個關鍵價值：可擴展性、高可用性和靈活的流量管理。可擴展性讓系統可以透過增加伺服器來應對流量增長，不需要動核心架構——這就是水平擴展（Horizontal Scaling），與升級單一機器硬體的垂直擴展相對。高可用性來自於自動隔離故障節點和流量轉移，確保即使部分伺服器掛了，服務仍然正常運作。

靈活的流量管理則支援了各種營運需求：藍綠部署（Blue-Green Deployment）讓新版上線時先導少量流量測試再逐步切換；滾動更新逐台更新伺服器確保任何時候都有足夠容量；異地流量分配把使用者導到最近的資料中心降低延遲；A/B 測試把不同使用者導到不同版本比較效果。這些功能讓負載均衡器不只是技術元件，更是營運工具。

在面試中，負載均衡的優點不是一個獨立考點，而是你回答「為什麼要加負載均衡」時的論據。你應該能從使用者體驗（更快、更穩定）和系統設計（可擴展、高可用、靈活部署）兩個角度回答。
