# 負載均衡演算法

## Learning goal
掌握各負載均衡演算法的原理、優缺點，並能依據不同系統場景選擇合適的演算法。

## Steps

閱讀順序按照下列步驟，每個步驟深入讲解一種演算法或比較維度：

1. [[learn/system-design/nodes/lb-algorithms/static-algorithms-round-robin|靜態演算法：Round Robin]] — 最基礎的循環分配演算法，適合同質伺服器環境
2. [[learn/system-design/nodes/lb-algorithms/static-algorithms-weighted-round-robin|靜態演算法：Weighted Round Robin]] — 考慮伺服器容量差異的改進版本
3. [[learn/system-design/nodes/lb-algorithms/dynamic-algorithms-least-connections|動態演算法：Least Connections]] — 根據當前連接數動態分配，更適合變動負載
4. [[learn/system-design/nodes/lb-algorithms/dynamic-algorithms-weighted-least-connections|動態演算法：Weighted Least Connections]] — 結合容量權重與動態負載的高級演算法
5. [[learn/system-design/nodes/lb-algorithms/session-persistence-ip-hash|會話持久化：IP Hash]] — 實現同一客戶端始終路由到同一伺服器的方法
6. [[learn/system-design/nodes/lb-algorithms/algorithm-selection|演算法選擇與取捨]] — 總結各演算法的優缺點與適用場景，學習如何選擇

## Lesson

本節點將逐步讲解所有經典負載均衡演算法，從最簡單的靜態分配到考慮即時負載的動態分配，再到會話持久化的特殊需求。每個步驟會深入讲解一種演算法的工作原理、優缺點分析，並給出具體的適用場景建議。完成所有步驟後，你將能夠依據系統的具體條件（伺服器是否同質、負載是否變動、是否需要會話保持）選擇最合適的負載均衡策略。
