# 通訊與可靠度

## Learning goal
理解分散式系統中不同的即時通訊模式，以及如何確保連線存活與資料傳輸的正確性，能夠在系統設計中選擇合適的通訊方案與可靠性機制。

## Steps
1. [[learn/system-design/nodes/communication/communication-patterns|即時通訊模式比較]] — 比較 Polling、Long Polling、SSE 與 WebSocket 的運作原理與適用場景
2. [[learn/system-design/nodes/communication/heartbeat-mechanism|Heartbeat 存活偵測機制]] — 學習如何透過 Heartbeat 檢測節點與連線的存活狀態
3. [[learn/system-design/nodes/communication/checksum-error-detection|Checksum 錯誤偵測]] — 理解如何透過校驗和檢測資料傳輸過程中的錯誤

## Lesson
在分散式系統中，不同節點需要互相通訊來完成協同工作。選擇合適的通訊模式取決於應用的需求：是否需要即時性、是單向還是雙向通訊、能接受的額開開銷是多少。除了連線建立與資料傳輸，我們還需要機制來確保連線依然存活（透過 Heartbeat），以及確保傳輸的資料沒有出錯（透過 Checksum）。這三個步驟分別深入介紹這三個核心概念，幫助你在設計系統時做出正確的取捨。
