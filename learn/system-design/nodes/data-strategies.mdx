# 資料策略

## Learning goal
理解各種常見資料策略的核心取捨，包括快取讀寫模式、壓縮與去重、複製架構、批次vs串流處理，以及 SQL vs NoSQL 的選擇，能夠依據不同場景選擇適合的資料策略。

## Steps

1. [[learn/system-design/nodes/data-strategies/cache-strategies|快取策略：讀寫模式與快取位置]] — 理解不同快取讀寫模式與伺服器端/用戶端快取的差異和適用場景
2. [[learn/system-design/nodes/data-strategies/compression-deduplication|資料最佳化：壓縮與去重]] — 比較資料壓縮與重複數據刪除的差異與適用場景
3. [[learn/system-design/nodes/data-strategies/replication-strategies|複製策略：主從與對等]] — 理解主從複製與對等複製兩種架構的取捨
4. [[learn/system-design/nodes/data-strategies/batch-vs-stream|處理模式：批次與串流]] — 區分批次處理與串流處理的差異與使用時機
5. [[learn/system-design/nodes/data-strategies/sql-vs-nosql|資料庫選擇：SQL vs NoSQL]] — 全面比較 SQL 與 NoSQL，依系統需求做出適當選擇

## Lesson

資料策略是系統設計中最核心的決策之一，不同的資料處理與存儲策略會直接影響系統的可擴展性、一致性、效能與維護成本。本節點從不同角度拆解常見的資料策略取捨：從快取的讀寫模式到資料最佳化技術，從複製架構到處理模式，最終來到最經典的 SQL vs NoSQL 選擇問題。每個步驟聚焦一組對比概念，幫助你建立清晰的判斷框架。

所有這些決策都不是非黑即白的，關鍵在於理解不同選擇背後的 trade-off，並依據你的系統需求（一致性要求、讀寫比例、資料結構彈性等）做出最適合的選擇。
