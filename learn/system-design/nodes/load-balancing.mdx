## Learning goal
理解負載均衡器的作用、部署位置、冗餘設計

## Lesson

負載均衡是分散式系統中關鍵的基礎元件，它負責將進來的流量分散到多個後端伺服器，從而提升系統的回應速度、可用性和可擴展性。本節課將從基礎概念開始，逐步介紹負載均衡能帶來什麼好處、可以放在系統的哪些位置，以及如何設計不會單點故障的冗餘架構。
