# YouTube/Netflix

## Learning goal
設計可擴展的影片串流平台，支援大規模使用者上傳、轉碼、儲存與全球內容分發，理解讀取密集型系統的設計取捨。

## Lesson

YouTube/Netflix 是經典的**讀取密集型**大規模系統設計範例，核心挑戰在於如何處理高比例的讀取流量（讀寫比約 200:1），同時支援影片上傳、處理與全球低延遲串流。本節點從需求分析開始，逐步推導出完整架構，強調每個設計決策的取捨：

- 影片是大檔案，需要分散式儲存與CDN靠近使用者
- 非同步處理影片轉碼，避免阻塞上傳流程
- 元數據需要分片來支援高並行讀寫
- 去重複可以節省儲存空間但需要額外比對邏輯
- 全域內容分發依賴CDN與分層快取來降低源頭伺服器壓力

每個步驟深入探討一個子問題，逐步建構出完整系統。
