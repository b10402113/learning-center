# 代理與冗餘

## Learning goal
理解 Proxy/Reverse Proxy 角色、冗餘與複製模式，並能設計具備冗餘的 Proxy 架構來消除單點故障。

## Steps

1. [[learn/system-design/nodes/proxy-redundancy/proxy-fundamentals|Proxy 基礎概念]] — 理解 Proxy 定義與正向代理的核心角色
2. [[learn/system-design/nodes/proxy-redundancy/reverse-proxy|反向代理（Reverse Proxy）]] — 比較反向代理與正向代理，認識常見使用場景
3. [[learn/system-design/nodes/proxy-redundancy/redundancy-replication|冗餘與複製基礎]] — 學習冗餘與複製如何提升系統可靠度
4. [[learn/system-design/nodes/proxy-redundancy/redundant-proxy-architecture|冗餘 Proxy 架構設計]] — 整合概念，設計具備冗餘的 Proxy 架構

## Lesson
代理是系統設計中最基礎的中間元件，扮演客戶端與伺服器之間的交通樞紐；而冗餘與複製則是提升系統可靠度最核心的手段，透過重複關鍵元件來消除單點故障。本節先從代理的基本分類（正向 vs 反向）開始，再介紹冗餘與複製的核心概念，最後整合這些知識來設計不會因為單一代理故障而導致整個服務中斷的架構。
