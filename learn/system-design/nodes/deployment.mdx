# 部署與儲存

本節點涵蓋部署模型與雲端儲存的核心設計議題，從應用狀態管理到部署架構選擇，再到內容傳遞與儲存模型比較，幫助你在不同場景下做出合適的部署與儲存決策。

## 閱讀順序

1. [[learn/system-design/nodes/deployment/stateful-stateless|有狀態 vs 無狀態架構]]
2. [[learn/system-design/nodes/deployment/serverless-vs-traditional|Serverless vs 傳統部署]]
3. [[learn/system-design/nodes/deployment/cdn-fundamentals|CDN 基礎原理]]
4. [[learn/system-design/nodes/deployment/cloud-storage-models|混合雲 vs 全雲端儲存]]

## 學習目標

- 能夠區分有狀態與無狀態架構，說明其對擴展性與部署的影響
- 能夠比較 Serverless 與傳統部署模型的成本、擴展性與營運複雜度取捨
- 理解 CDN 的運作機制，何時該使用 CDN 而非直接由源伺服器提供服務
- 能夠依據企業需求選擇混合雲或全雲端儲存架構

## 核心概念

部署與儲存是系統設計中影響營運成本、擴展性與安全性的關鍵決策。不同的部署模型適合不同的工作負載，而儲存方案的選擇則取決於數據主權、合規要求與成本考量。本節點將透過對比不同選項的方式，幫助你掌握每種方案的適用場景。
