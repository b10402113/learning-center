# 索引

## Learning goal
理解資料庫索引原理與查詢優化，能夠在系統設計中判斷何時使用索引、選擇合適的索引類型，並理解索引帶來的取捨。

## Steps

1. **[[learn/system-design/nodes/indexes/what-is-an-index|什麼是索引]]** — 認識索引的核心概念，透過類比理解索引的作用
2. **[[learn/system-design/nodes/indexes/how-indexes-work|索引如何運作]]** — 學習索引背後的資料結構與查找機制
3. **[[learn/system-design/nodes/indexes/trade-offs-read-write|讀寫效能取捨]]** — 理解索引加速讀取但降低寫入的原因，權衡設計取捨
4. **[[learn/system-design/nodes/indexes/index-types-best-practices|索引類型與最佳實踐]]** — 認識不同索引類型，學習正確使用索引的原則

## Lesson

索引是資料系統中最基礎也最重要的優化手段之一，其核心思想是透過額外的空間交換更快的查詢速度。本節點從基礎概念開始，一步步解構索引的運作原理、效能特徵與實務應用，幫助你在系統設計中做出正確的索引決策。
