# 限流與讀寫模式

## Learning goal
理解 Token Bucket/Leaky Bucket 限流演算法、讀寫密集系統的設計差異，能夠針對不同工作負載選擇合適的限流與架構設計策略。

## Steps

1. [[learn/system-design/nodes/rate-readwrite/rate-limiting-intro|什麼是限流，為什麼需要限流]] — 理解限流的基本概念與應用場景
2. [[learn/system-design/nodes/rate-readwrite/token-leaky-comparison|Token Bucket 與 Leaky Bucket 演算法比較]] — 掌握兩種限流演算法的原理、差異與適用場景 (需要先完成步驟 1)
3. [[learn/system-design/nodes/rate-readwrite/read-write-workloads|讀寫密集型工作負載的特徵]] — 區分讀密集與寫密集系統的特徵與核心挑戰
4. [[learn/system-design/nodes/rate-readwrite/read-write-strategies|讀寫密集系統的設計策略]] — 學習針對不同工作負載的優化設計策略 (需要先完成步驟 3)

## Lesson

本節點將探討兩個重要的系統設計主題：流量限流控制，以及讀寫密集系統的設計差異。限流是保護系統免於過大流量衝擊的關鍵機制，而理解讀寫工作負載的差異，能幫助我們選擇正確的技術與架構來解決問題。我們會先從限流的基本概念開始，深入比較兩種經典限流演算法，接著轉向探討不同工作負載類型的特徵，最後整理出針對讀取密集與寫入密集系統的設計策略。
