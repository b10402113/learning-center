# 先起地基，再寫業務

<LearningGoal>
能解釋 OryxOS 為何先起工程地基再寫業務、兩階段的內容分別是什麼，以及為什麼這一步直接決定整體工程品質。
</LearningGoal>

## Lesson

OryxOS 刻意採用「先起地基，再寫業務」的兩階段順序：先安裝與業務無關、所有專案都需要的六塊工程地基（日誌、監控、HTTP、API 規範、代碼標準、安全檢查），再在此之上建造五大業務能力，因為沒有標準的地基會讓每個新功能都為前面的混亂付出代價。
