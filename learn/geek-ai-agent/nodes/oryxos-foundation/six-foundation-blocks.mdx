# 六塊工程地基

<LearningGoal>
能說出六塊工程地基各自是什麼、用什麼工具落地，以及為什麼它們都是與業務無關、每個專案都需要的通用能力。
</LearningGoal>

## Lesson

六塊工程地基——結構化日誌（SLF4J + Logback、JSON + traceId）、監控（Actuator + Micrometer + Prometheus）、HTTP server（Spring MVC + JDK 21 Virtual Thread）、API 規範（springdoc OpenAPI＋統一回應＋全局異常）、代碼標準（Spotless Google 格式＋Alibaba P3C）、安全檢查（SpotBugs + Find Security Bugs + PMD + OWASP 依賴掃描）——都是與業務無關、每個專案都需要、因而可以一次標準化安裝的通用能力。
