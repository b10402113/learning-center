# 為什麼要寫自己的 init skill

<LearningGoal>
能對比通用 init skill 與專屬 init skill 的得失，說出 OryxOS 為何要寫自己的 init skill，以及這背後的「何時把流程磨成 skill」方法論。
</LearningGoal>

## Lesson

通用 init skill 不知道 OryxOS 的九模組結構、憲法技術選型與命名慣例，需要大量改造，因此 OryxOS 寫自己的 init skill——訂製專案結構與慣例、同時照樣落地標準工具；判斷「何時把流程磨成 skill」的三問是：它反覆發生嗎、結果明確嗎、包含專案慣例嗎。
