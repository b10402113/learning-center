# oryxos-init skill 做什麼

<LearningGoal>
能描述 oryxos-init 的一份 SKILL.md 如何把十個初始化步驟壓成六個階段，以及 skill、constitution、CI、Spec-Kit 四者之間的分工。
</LearningGoal>

## Lesson

oryxos-init 用一份 SKILL.md 把十個初始化步驟壓成六階段（骨架 → 日誌／監控 → HTTP／API → 代碼標準 → 安全檢查 → CI／驗證），代碼標準分機械格式化（Spotless Google）與規約（Alibaba P3C）兩層、安全四件套全部接進 mvn verify；整體分工為「skill 安裝、constitution 釘死、CI 執行、Spec-Kit 隨後寫業務」。
