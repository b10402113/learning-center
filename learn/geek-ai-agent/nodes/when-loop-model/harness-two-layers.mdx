# 兩層 Harness：公開護欄與模組自帶驗收

<LearningGoal>
能分清公開 Harness（一次建好的紅線）與模組 Harness（跟著任務卡走的驗收），並說出每一層各放什麼。
</LearningGoal>

## Lesson

Harness 的品質決定 Loop 的可用性，因為每一輪「對嗎、合規嗎、安全嗎」的答案全來自它。Harness 分成兩層：公開 Harness 一次建好、全專案共用（安全紅線、代碼規範與 lint、CLAUDE.md、CI gate），模組 Harness 跟著任務卡走（該部分專屬的驗收測試與邊界約束）。順序是先公開後模組，讓所有 Loop 都跑在同一組護欄裡；CLAUDE.md、Skills、Hooks、Plan Mode 則是把這些規則落成可執行的機制。
