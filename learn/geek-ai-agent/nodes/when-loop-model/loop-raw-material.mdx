# Loop 原料與一輪迴圈：把計畫變成可判定驗收

<LearningGoal>
能寫出一份可收斂的 Loop 原料（part doc／任務卡），特別是把它收成可判定的驗收與必測項目。
</LearningGoal>

## Lesson

一份 part doc 要一次寫清楚六塊：功能、互動與時序、介面、參數、可判定的驗收與必測項目、邊界與禁止。其中驗收必須可判定，能寫成自動測試，Loop 才知道自己對不對、什麼時候算完成；跑完一輪全綠再交棒 review，不滿意就改文件、從乾淨狀態重跑，而不是在對話裡來回爭辯。往下拆成一張任務卡對一個 Issue、一個 PR，粒度抓在核心程式碼 100 到 500 行。
