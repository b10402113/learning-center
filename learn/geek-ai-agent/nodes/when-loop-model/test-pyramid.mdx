# 測試金字塔：五層判官與分散式正確性

<LearningGoal>
能講出 When 五層測試各抓什麼、為什麼分散式正確性最難，以及兩個部分各自的驗收重點。
</LearningGoal>

## Lesson

驗收體系是五層測試金字塔：單元（時間輪演算法、一致性雜湊、序列化）、整合（真實 Redis／ETCD）、端到端（提交到投遞）、分散式正確性與混沌（殺節點、注入分割）、效能與負載。判官必須在 Loop 開跑前造好，因為 Loop 的對錯全靠它。分散式正確性最難，它只在最糟的時刻失敗，只能用反覆注入故障加上不變式（不遺失、不重複語意、10 秒時效、唯一）來逼近；兩個 Loop 也因此有各自的驗收重點。
