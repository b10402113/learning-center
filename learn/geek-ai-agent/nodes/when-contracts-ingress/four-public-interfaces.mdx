# 四大公共介面與契約地圖

<LearningGoal>
能說出 StoragePlugin、TimeWheel、Sink、Router 四個公共介面各自的職責，並用契約地圖指出每個契約是誰定義、誰實作、誰使用。
</LearningGoal>

## Lesson

四個公共介面——StoragePlugin、TimeWheel、Sink、Router——是模組之間的四道接縫，各自有明確職責；搭配一張契約地圖寫明每個契約由誰定義、誰實作、誰使用，改動時才有唯一入口。模組只依賴介面而非具體實作，因此能替換實作、也能在測試注入假實作，公共 Harness 再補上安全、分層、依賴與驗收的共通護欄。
