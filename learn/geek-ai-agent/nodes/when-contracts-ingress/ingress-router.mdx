# 接入層七步寫路徑與一致雜湊路由

<LearningGoal>
能走完 Submit 的七步寫路徑，說明 Snowflake 產生 message_id、一致雜湊把同一個 id 固定映射到同一個 time wheel、跨節點以 gRPC 轉發，以及「先持久化、再進輪、才回傳」為何是防丢訊的第一道保證。
</LearningGoal>

## Lesson

接入與路由層把零件串成寫入路徑：Submit 七步依序接收、驗證、用 Snowflake 在本機產生 message_id、一致雜湊選定 tw_id、Master 不在本機時以內部 gRPC 轉發、先持久化再加入時間輪、最後回傳 PENDING。同一個 message_id 永遠映射到同一個輪子，查詢與取消才找得到；「先持久化、再進輪、才回傳」則是防丢訊的第一道保證。
