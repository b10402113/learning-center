# 定時任務：第三個觸發源

<LearningGoal>
能認出定時任務不是一個新能力，而是第三個觸發源（clock-push）：到點時由系統組裝訊息、餵進同一條 AgentService 入口，ReActLoop、Provider、工具執行全都零改動。
</LearningGoal>

## Lesson

定時任務在 OryxOS 裡不是一個新能力，而是第三個觸發源（clock-push）：到點時由系統組裝一個訊息，投進與 CLI／Web 完全同一條 `AgentService` 入口，ReActLoop、Tool、Provider 全都一行不改。
