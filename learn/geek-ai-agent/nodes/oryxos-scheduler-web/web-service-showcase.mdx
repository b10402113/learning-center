# Web Service：10 端點把引擎變成 REST 介面

<LearningGoal>
能說清 oryxos serve 如何把引擎變成對外 REST 介面：10 個端點、6 個控制器、兩條整合路徑，以及 admin 平台只靠這 10 個端點就能運作、反過來證明 API 的完整性。
</LearningGoal>

## Lesson

Web Service 是 OryxOS 的對外門面：`oryxos serve` 開啟 Spring MVC 於 8080，以 6 支控制器提供 10 個 `/api/v1` 端點，涵蓋 session 管理、Agent 呼叫、資訊查詢與系統狀態四類工作，而 admin 平台純粹只消費這 10 個端點，反過來證明 API 已完整。
