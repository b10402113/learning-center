# 動手前先想清楚到驗收：五個決定與統一異常出口

<LearningGoal>
能複述 Web Service 動手前的五個決定（薄控制器共用引擎、單一異常出口、核心期非目標、serve 單 key、admin 唯讀），並說清 400／404／500／503／504 錯誤碼的對應與「內部細節絕不漏進 500」的驗收。
</LearningGoal>

## Lesson

動手前的五個決定（薄控制器共用引擎、單一異常出口、核心期非目標、serve 單 key、admin 唯讀）配合 `GlobalExceptionHandler` 的 400／404／500／503／504 錯誤碼，以及「內部細節絕不漏進 500」的 `GlobalExceptionHandlerTest` 驗收，把 Web Service 釘成一層不岔開引擎的薄皮。
