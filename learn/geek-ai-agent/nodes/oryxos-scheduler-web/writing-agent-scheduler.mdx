# AgentScheduler 實作與驗收：動態註冊、本地鎖、第二次進入

<LearningGoal>
能手寫 registerAll／runOnce：用 ThreadPoolTaskScheduler 動態 schedule（CronTrigger 帶時區）、每任務一個 ReentrantLock 做 tryLock、固定 scheduler session 身分、finally 解鎖，並用「第二次進入」的斷言證明鎖確實釋放。
</LearningGoal>

## Lesson

`AgentScheduler` 用 `ThreadPoolTaskScheduler.schedule` 動態註冊（`CronTrigger` 帶時區），`runOnce` 以每任務一把 `ReentrantLock` 做 tryLock、使用固定 `(scheduler, scheduler, profileName)` session 身分、`finally` 必定解鎖，驗收則靠「第二次進入」斷言證明鎖已釋放。
