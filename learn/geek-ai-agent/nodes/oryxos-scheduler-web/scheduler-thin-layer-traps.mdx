# 動手前先想清楚：薄排程層與四個陷阱

<LearningGoal>
能界定 AgentScheduler 只做「讀排程、觸發、組裝訊息、防重疊、記成敗」五件事，選擇 Spring 內建 TaskScheduler 而非自寫，並講出配置來源、重疊、失敗隔離、時區四個陷阱。
</LearningGoal>

## Lesson

動手前把 `AgentScheduler` 界定為一片只做「讀排程、觸發、組裝訊息、防重疊、記成敗」的薄層，直接用 Spring 內建 `TaskScheduler` 不自造排程引擎，並以「配置即 Agent、重疊靠程序內鎖、失敗照樣走審計、時區必須顯式指定」四個陷阱當作設計檢查清單。
