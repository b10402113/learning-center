# Tool 是什麼：Agent 的「手」與內建工具全景

<LearningGoal>
能說出 LLM 只產文字、工具讓 Agent 真正動手（讀檔案／跑命令／呼叫 API），並數出核心階段九個內建工具各自的定位，以及內建 Tool 與 Plugin Tool 的分界。
</LearningGoal>

## Lesson

LLM 本質上只產文字，Agent 真正動手（讀檔案、跑命令、呼叫 API、記筆記、通知人）全靠工具，核心階段內建九個工具分屬檔案／命令／網路／記憶＋通知四個領域；內建 Tool 是跨 Agent 共通的平台底座，Plugin Tool 是業務帶來的特定能力，而這個分界正是下一課統一大抽象要兌現的。
