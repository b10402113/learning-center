# 把內建工具補齊到業界水準

<LearningGoal>
能說出對標 Claude Code／Cursor／OpenAI Assistants 後補上的五個高頻工具（edit_file／ask_user／grep／glob／web_search）各自的設計要點，並解釋「好抽象讓新增工具成本恆定」的道理。
</LearningGoal>

## Lesson

對標 Claude Code／Cursor／OpenAI Assistants 補上五個高頻內建工具：edit_file（唯一舊文本，找不到或多重匹配都報錯）、grep（regex、200 筆上限、跳過二進位與非 UTF-8）、glob（wildcard 檔名搜尋）、ask_user（經 UserInteraction 介面把人類拉進審查迴路）、web_search（經 SearchProvider 介面、走網域白名單）；因為 Sandbox、tool_invocations 審計與 Profile 過濾都會自動套用，每加一個工具成本恒定——這正是統一抽象的兌現，再用「名稱／描述／inputSchema 契約測試＋精確子集過濾測試＋正常與被擋雙路測試＋MCP 失敗隔離測試」四區塊 harness 驗證。
