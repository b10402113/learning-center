# OryxTool 單一抽象與 ToolResult

<LearningGoal>
能說明 OryxTool 的四個方法（getDescription／getName／getInputSchema／execute）與 ToolResult 的四個欄位，並解釋為何 ReAct 迴圈不必知道工具來自內建、MCP 還是 Java Bean。
</LearningGoal>

## Lesson

OryxTool 只用四個方法（getDescription／getName／getInputSchema／execute）與 ToolResult 的四個欄位（success／content／errorMessage／retryable）就把內建、MCP、Java Bean 三種來源全部抽象成同一張臉，getInputSchema 缺失會卡死 Function Calling，統一介面讓 ReAct 迴圈保持來源無知、也為統一治理留下入口。
