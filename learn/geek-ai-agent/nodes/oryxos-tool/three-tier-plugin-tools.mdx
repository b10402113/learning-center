# 三級 Plugin Tool：零代碼、輕代碼、重代碼

<LearningGoal>
能說出三級 Plugin Tool 各自的適用場景與代碼量（方式一零代碼 SKILL.md＋MCP、方式二自寫 MCP server、方式三 @Tool Java Bean），並遵循「能用方式一就不用方式二，能用方式二就不用方式三」的選型規則。
</LearningGoal>

## Lesson

三級 Plugin Tool 依代碼量排成階梯：方式一零代碼（SKILL.md 給模型看＋複用現成 MCP server，歸 ContextLoader 而非 Tool）、方式二輕代碼（自己寫 MCP server，經 mcp_servers.yaml 接上，連不上只 WARN 不阻斷啟動）、方式三重代碼（@Tool Java Bean 進程內深度整合），選型規則恒為「能用方式一就不用方式二，能用方式二就不用方式三」。
