# ToolRegistry、ToolExecutor 與安全白名單

<LearningGoal>
能說出 ToolRegistry 如何匯集三種工具來源、Profile 如何用 tools 欄位過濾工具子集，以及每次工具執行前為何必須先通過路徑／命令／網域白名單的 Sandbox 檢查。
</LearningGoal>

## Lesson

ToolRegistry 是匯集所有工具來源的總清冊、Profile 用 tools 欄位過濾出該 Agent 的子集，而 ToolExecutor 是唯一執行路徑（找工具→過 Sandbox 白名單→執行包 ToolResult→寫 tool_invocations）；檔案／命令／網域三張白名單是核心階段唯一的工具治理手段，且「先檢查、後執行」內建工具自己也要遵守。
