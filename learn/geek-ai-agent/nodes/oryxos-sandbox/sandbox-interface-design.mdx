# 介面先行的 Sandbox 抽象：不讓第一檔帶偏

<LearningGoal>
能把「方向／介面／實作」三層拆開設計 Sandbox，讓介面只表達意圖（enforce 一個動作），並用「microVM 能不能乾淨塞進去」作為介面中性的反向驗證，且背出兩個升級訊號。
</LearningGoal>

## Lesson

設計沙箱守「方向現在定、介面現在釘、實作只做現在需要的」三層原則：介面只表達意圖（enforce 一個動作），隔離需求放在含隔離等級的策略物件裡讓每一檔成為獨立可插實作，並用「microVM 能不能乾淨塞進來」反向驗證防止介面被第一檔（checkPath／checkCommand 這類字眼）帶偏；升級則嚴格由兩個訊號觸發——要跑相對不可信的程式或需要多租戶（應用層 → 容器）、要跑完全不可信程式或放大互不信任沙箱（容器 → microVM），沒有訊號就不升級，全程出口管控、配額、審計不變。
