# 實作 WhitelistSandbox 並接進既有工具

<LearningGoal>
能用 Sandbox／SandboxAction／ActionType 最小物件先釘介面，實作 WhitelistSandbox 的三個私有檢查，並在每個 @Tool 方法開頭只加一行 enforce 接進既有工具。
</LearningGoal>

## Lesson

實作按「最小物件先釘介面」順序走：定義 Sandbox／SandboxAction／ActionType／SandboxViolationException 並凍結，寫 WhitelistSandbox 用三個私有檢查（checkFilePath 以 normalise＋toAbsolutePath 擋目錄穿越、checkShellCommand 比第一個空白 token、checkHttpUrl 精確或含點邊界的萬用網域），再在 FileTools／ShellTools／HttpTools／NotifyTools 的每個 @Tool 方法開頭只插一行 sandbox.enforce——Sandbox 違規只是一隻普通 RuntimeException，自動走既有 success=false 工具審計路徑；空白名單是「什麼都不准」而非跳過驗證，且 acknowledge 目前 enforce 只覆蓋工具執行路徑。
