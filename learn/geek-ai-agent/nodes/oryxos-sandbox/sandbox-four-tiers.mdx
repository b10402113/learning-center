# 四檔方案與隔離強度/開銷光譜

<LearningGoal>
能沿「越深越安全、越貴越重」的光譜定位四檔隔離方案，並用「你跑的是誰的程式」與「亂鬥的誤信助理（confused deputy）」判斷業界系統為何選不同檔。
</LearningGoal>

## Lesson

四檔方案（應用層白名單 → 容器 → microVM → 完整 VM／物理）站在同一條「隔離越深越安全、越貴越重」的線上取點，本質是回答「你跑的是多不可信的程式、願付多少價」；第一檔是勸阻不是禁錮，容器共享 host 核心有天花板，microVM 因 VM 邊界＋近容器啟動成為當代黃金標準，而防禦永遠要分層——出口管控、配額、審計每一檔都得有。選檔由「跑誰的程式」決定（Claude Code 走第一檔、雲端直譯器直接上 microVM），且要知道誤信助理困局：純白名單只驗請求形狀，攔不住被髒資料誘發的合法動作——審計與最小權限與隔離同等重要。
