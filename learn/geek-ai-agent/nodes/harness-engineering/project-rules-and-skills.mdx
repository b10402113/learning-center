# 專案規則與能力槓桿：CLAUDE.md 與 Skills

<LearningGoal>
能寫出一份堪用的 CLAUDE.md（含四大區塊），並說清 Skill 是什麼、SKILL.md 如何組成、Capability Uplift 與 Encoded Preference 的差別，以及何時該自己沉澱一個 Skill。
</LearningGoal>

## Lesson

CLAUDE.md 是 AI 每輪自動載入的專案手冊（專案概述、執行指令、程式規範、禁區四區塊，隨專案迭代成長）；Skill 則是「流程沉澱 + 工具調用」的能力封裝，核心是 SKILL.md，靠三層漸進揭露控制 context 成本，並分 Capability Uplift（學會新能力）與 Encoded Preference（照你的方式做）兩類價值，在重複第三次、AI 一直做錯或跨專案重用時自己沉澱。
