# 何時該加哪一道：選型、克制與業界範例

<LearningGoal>
能依任務風險與熟悉度決定要加哪幾道 Harness，並用 Superpowers（Skills 強制流程）與 Hermes（自主技能與記憶）校準自己對 Harness 的判斷。
</LearningGoal>

## Lesson

依任務風險與熟悉度決定加哪幾道（熟悉的增量只需 CLAUDE.md 加 Skill，風險、不可逆、長時間、大型多模組才逐步補上 Plan Mode、Permission、Hooks、Subagents），落地從半小時的最小 CLAUDE.md 起步再增量補工具；Superpowers 示範把工程紀律打包成會自動觸發的 Skills 與強制流程，Hermes 示範 agent 自主創建與改進技能、自己維護 harness——收束於「工具會換，工程紀律不會」。
