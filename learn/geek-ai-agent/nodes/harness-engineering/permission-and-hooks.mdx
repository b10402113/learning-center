# 事中與事後防線：Permission 與 Hooks

<LearningGoal>
能用 allow／ask／deny 規則設出動作前的邊界，並用 PreToolUse／PostToolUse Hooks 掛上 lint 與相關測試的事後檢查。
</LearningGoal>

## Lesson

Permission 用 allow／ask／deny 規則在動作前劃出邊界，判準是「做錯的代價是幾秒還是幾小時」；Hooks 用 PreToolUse／PostToolUse 在動作後自動跑 lint 與相關測試，把「AI 說它完成了」換成「機器證明它完成了」，在你不在場時尤其關鍵。兩者與 Plan Mode 合成前、中、後三道互補防線。
