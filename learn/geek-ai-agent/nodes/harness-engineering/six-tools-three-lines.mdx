# 六大工具與三道防線總覽

<LearningGoal>
能逐一說出 CLAUDE.md、Skills、Subagents、Plan Mode、Permission、Hooks 各自解決什麼問題，並把它們歸到專案規則、能力槓桿、上下文隔離與前中後三道防線。
</LearningGoal>

## Lesson

Harness 落地成六個可動手的工具：CLAUDE.md／AGENTS.md 是每輪自動載入的專案規則地基，Skills 與 Subagents 是能力槓桿與上下文隔離，Plan Mode、Permission、Hooks 則沿動作時間軸構成前、中、後三道防線；工具不是照順序跑一遍，而是在同一任務中依情境一起叫用，且只在需要時才加。
