# 上下文隔離與計畫先行：Subagents 與 Plan Mode

<LearningGoal>
能判斷何時該派 Subagent 做上下文隔離（並看懂 4 個 subagent 並行初始化 11 個模組的案例），以及哪些情境必須先進 Plan Mode 才動手。
</LearningGoal>

## Lesson

Subagents 把子任務丟進乾淨、獨立的 context 執行、只交回結果，用來對治上下文污染（四個並行初始化十一個模組，品質穩定且約快四倍，但小任務反而成負擔）；Plan Mode 則要求動手前先產出計畫給你確認，對有風險、不熟悉、第一次做的情境幾乎必用——兩者分別回答「在哪裡做」與「什麼時候做」。
