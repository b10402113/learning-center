# 三週 MVP 與驗收標準

<LearningGoal>
能界定三週 MVP 的做與不做、非功能指標，並複述七項驗收標準（包含 AI 產出驗收）。
</LearningGoal>

## Lesson

三週 MVP 守「主流程優先、能 demo 勝過完美」：做提交與投遞主流程、三個 HTTP API、HTTP 與 Kafka 兩種 SPI Sink、Redis 分片持久化與單機多層時間輪、管理台與基本可觀測，明確不做叢集、故障接管、其他 Sink、驗證限流與 SDK；非功能門檻是 QPS ≥1000、穩定 10 萬則、99% ±1 秒、API P99 ≤100ms；驗收七項涵蓋功能、精度、效能、部署、可觀測、Demo 與 AI 產出（比例 ≥90% 且每個 PR 都有真 review），最後一項為整體通過的必要條件。
