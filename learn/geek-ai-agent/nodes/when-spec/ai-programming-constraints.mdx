# AI 編程約束：讓 AI 寫 90%

<LearningGoal>
能說明 When 為何把「≥90% 核心程式碼由 AI 撰寫」訂為硬約束，並說出可量測方式、強制 review 與工程化用法的具體要求。
</LearningGoal>

## Lesson

When 把「≥90% 核心程式碼由 AI 撰寫（目標 95%）」列為硬約束，因為它同時是 AI 編程教學樣本；核心程式碼只算產品功能，且強制 review 比比例更重要；正確用法是工程化地使用 AI——先寫 Spec、每模組有 CLAUDE.md、重複模式做成 Skills、用 Hooks 自動檢查、重要操作先 Plan Mode——並以每 commit 的 AI 比例、PR review 記錄與各階段真實產出來量測。
