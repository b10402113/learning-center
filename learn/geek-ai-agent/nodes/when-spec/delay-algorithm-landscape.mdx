# 延遲投遞的底層演算法與選型

<LearningGoal>
能列出延遲投遞的六種底層實作路徑，並用寫入吞吐、調度精度、時間跨度、記憶體、多副本、實作複雜度六個維度說明為什麼沒有萬能解。
</LearningGoal>

## Lesson

延遲投遞有六種底層實作路徑（DB 掃描、RocksDB 加時間輪、Redis ZSet、RocketMQ 固定級別、QMQ 多層時間輪、多層時間輪加 LSM），每種都在寫入吞吐、調度精度、時間跨度、記憶體、多副本、實作複雜度之間取捨；QMQ 的磁碟排程檔加記憶體雜湊輪示範了 O(1) 且大跨度又省記憶體的設計，但沒有任何一種演算法能同時最佳化所有維度。
