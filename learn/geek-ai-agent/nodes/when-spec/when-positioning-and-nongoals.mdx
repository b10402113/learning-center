# When 的定位與非目標

<LearningGoal>
能說明 When 是什麼、它的雙重定位與三階段發展路線，並說出五大設計目標與它明確不做的事。
</LearningGoal>

## Lesson

When 是通用、可獨立部署的分散式延遲投遞元件，同時背負「真實元件」與「AI 編程教學樣本」雙重定位，分三階段演進；它有通用、可擴展、可靠、易整合、可運維五大目標，但更關鍵的是明確的非目標——不當任務調度器、訊息佇列、worker 框架或 all-in-one MQ，也不解析 payload、不保證下游業務邏輯，只承諾 at-least-once 投遞。
