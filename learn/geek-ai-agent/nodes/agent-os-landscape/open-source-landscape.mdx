# 開源賽局：OpenClaw、Hermes 與它們留下的空白

<LearningGoal>
比較 OpenClaw 與 Hermes 的定位與安全取捨，並指出兩者共同留下的三個空白，說明這為何是 OryxOS 的起點。
</LearningGoal>

## Lesson

OpenClaw 把個人體驗做到極致、Hermes 往企業方向探路，兩者共同留下企業治理、企業 IT 深度整合與 Java 生態三個空白，而這三個空白定義出 OryxOS 的切入象限。
