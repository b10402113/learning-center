# OryxOS 的定位、邊界與安全設計

<LearningGoal>
用一句話定義 OryxOS，說清它的四字願景、做 runtime 不做編排的邊界，以及它與框架、編排平台、其他開源專案的關係與 day-one 安全設計。
</LearningGoal>

## Lesson

OryxOS 是企業完全可控、Java 原生、私有、可審計的統一 Agent 底座；它以四字願景（統一、私有、易接入、可觀測）定調，堅守做 runtime 不做編排的邊界，並把安全當第一天設計。
