# 為什麼企業要私有底座，又為什麼是 Java

<LearningGoal>
用嚴監管企業的四條鐵律說明為何需要私有可控底座，並用「有框架、沒底座」與六個支點說明為何這個底座該用 Java 寫。
</LearningGoal>

## Lesson

嚴監管企業的四條鐵律（資料不出企業、全程可審計、通過既有安全合規、技術棧對齊）把選項收斂到私有可控底座，而 Java 生態「有框架、沒底座」加六個支點，說明這個底座該用 Java 寫。
