# 從單機到分散式：狀態外置與 Agent 協作的遠景

<LearningGoal>
說明「實例無狀態、狀態外置」為何是分散式的第一步，並描述多實例要解決的協調問題、高可用與水平擴展的模型，以及更遠的跨節點 Agent 協作遠景。
</LearningGoal>

## Lesson

從單機到分散式的第一步不是多開機器，而是「實例無狀態、狀態外置」；之後才處理重複消費、調度歸屬與多租戶隔離，進而得到高可用與水平擴展，更遠的願景才是跨節點的 Agent 協作。
