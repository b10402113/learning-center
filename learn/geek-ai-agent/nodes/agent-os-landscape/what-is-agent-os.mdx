# Agent OS 是什麼：運行時之上的作業系統

<LearningGoal>
說出 Agent OS 的定義與五大職責，並分辨它與 agent runtime（代理運行時）、編排平台、框架、SaaS 的差別。
</LearningGoal>

## Lesson

Agent OS 是「讓一群 Agent 在企業裡被管理起來」的底座層：runtime 只讓一個 Agent 跑，Agent OS 補上生命週期、統一渠道、統一接入、統一記憶與工具沙箱，並與編排平台、框架、SaaS 各據不同層級。
