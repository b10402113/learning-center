# ReAct 迴圈是什麼：決定、行動、觀察

<LearningGoal>
能說出 ReAct 迴圈的單輪結構（Reason→Act→Observe）與兩條停止條件，並講清「單次 LLM 呼叫＝聊天機器人、達成迴圈＝Agent」的分界。
</LearningGoal>

## Lesson

ReAct 迴圈把每一輪固定成 Reason（決定下一步）→ Act（呼叫一個工具）→ Observe（把結果收回上下文），靠「模型不再發出工具呼叫」或「到達 MAX_ITERATIONS=10」兩條停止條件結束；它自己不呼叫模型也不執行工具，只負責指揮——呼叫 LLM 委派給 Provider、執行工具委派給 ToolExecutor，而單次 LLM 呼叫只是聊天機器人、有了自主決策迴圈才成 Agent。
