# 用測試與 Demo 釘死迴圈

<LearningGoal>
能設計五個單元測試類的覆蓋重點與兩個最值錢的回歸測試，並說出 Demo 1（北京天氣＋穿搭建議）的驗收標準為什麼能證明迴圈是手寫的。
</LearningGoal>

## Lesson

用五個不需網路的單元測試類（ReActLoop／PromptBuilder／ToolExecutor／AgentService／ContextLoaderTest）各自釘死一類行為，其中兩個最值錢的回歸是「模型一直要求工具→第 10 次被強制停住」與「process 拋異常時 ProfileContext 仍在 finally 清除」；最後用 Demo 1（查北京天氣給穿搭建議）端到端附上 code review 證明迴圈是手寫的、沒有框架 Agent 包裝，才能作為過關驗收。
