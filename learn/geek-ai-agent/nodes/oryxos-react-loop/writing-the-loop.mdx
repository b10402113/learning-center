# 手寫 ReActLoop、PromptBuilder、ToolExecutor

<LearningGoal>
能手寫 ReActLoop 的主迴圈、PromptBuilder 的四段組裝與 ToolExecutor 的執行路徑，並解釋「執行權只放在 ToolExecutor 一處」這條規則。
</LearningGoal>

## Lesson

ReActLoop.run 每輪先由 promptBuilder.build 組出四段上下文、委派 providerService.chat(session.id(), …)、把回應與工具結果都累積回 Session，靠「沒工具呼叫」或「MAX_ITERATIONS」停止；PromptBuilder 依固定四段組裝（system＋日期、長期記憶、最近 20 輪歷史、可用工具清單）控制 context 有界，ToolExecutor 是唯一執行路徑（找工具→Sandbox 白名單→執行包 ToolResult→寫稽核），因此執行權只放一處、關掉 Spring AI 自動工具執行，防止同一工具被呼叫兩次。
