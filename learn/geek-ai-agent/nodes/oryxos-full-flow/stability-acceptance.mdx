# 從能跑到跑得穩：穩定打磨與兩線驗收

<LearningGoal>
能列出讓底座「跑得穩」的打磨項目，並把對賬固化成「無 key 機制驗證 + 真 key 鏈路驗證」兩線驗收，讓 mvn verify 回答整台機器是否可用。
</LearningGoal>

## Lesson

把底座從能跑打磨到跑得穩（逾時、可讀錯誤訊息、單一觸發日誌主線、外部 MCP 隔離）之後，用無 key 的 mock provider 機制線進 gate、真 key 的鏈路線驗實際鏈路，讓 `mvn verify` 回答整台機器是否可用。
