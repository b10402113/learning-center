# 定時任務子系統：定義、執行、持久化、管理

<LearningGoal>
能把薄排程層長成完整子系統：skill 定義任務、共用 scheduler 會話執行、兩張表持久化狀態與歷史、四個端點加上管理台可即時執行與啟停。
</LearningGoal>

## Lesson

定時任務子系統由四塊組成——skill 定義任務、共用 scheduler 會話執行、兩張表持久化狀態與歷史、四個端點加管理台可即時執行與啟停；定義永遠只有 skill 一個來源，儲存永遠藏在介面之後。
