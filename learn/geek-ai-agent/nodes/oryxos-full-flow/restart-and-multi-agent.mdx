# 跨重啟恢復與多 Agent 並存

<LearningGoal>
能用一次 kill／重啟驗證狀態全數外置，並用兩個不同 Profile 驗證工具、會話、排程三條隔離邊界互不打架。
</LearningGoal>

## Lesson

「狀態全在進程之外」要靠一次 kill／重啟來驗，任何一項沒回來都代表有狀態暗藏在進程記憶體；同一實例跑多個 Profile 則要驗工具、會話、排程三條隔離邊界互不打架。
