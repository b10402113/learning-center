# 全流程串聯：真能用的標準與對賬方法

<LearningGoal>
能用一個可證偽的標準定義「主流程真能用」，並用對表與逐表對賬兩步方法，判斷一台組裝好的 Agent 底座是否真的打通。
</LearningGoal>

## Lesson

全流程串聯的驗收方法不新增能力，而是先對表確認每個模組承諾的對外能力都還在位，再拉一句有代表性的話走完整條鏈、逐表對賬——「該有的要在」與「不該有的不能有」同等重要。
