# Loop：ReAct 迴圈與它必須處理的四件事

<LearningGoal>
能畫出 ReAct 迴圈（Reasoning → Acting → Observation）並解釋為什麼「單次 LLM 呼叫是聊天機器人、只有循環的決策—行動—觀察才是 Agent」，以及一個好迴圈必須處理的四件事（停止條件、錯誤恢復、上下文壓縮、多模型切換）。
</LearningGoal>

## Lesson

單次 LLM 呼叫是聊天機器人，只有 Reasoning → Acting → Observation 的 ReAct 迴圈才是 Agent；好迴圈必須處理停止條件、錯誤恢復、上下文壓縮、多模型切換四件事，它們占了框架八成複雜度。
