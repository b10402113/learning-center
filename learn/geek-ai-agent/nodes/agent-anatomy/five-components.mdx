# 五元件拆解：LLM + Tools + Memory + Loop + Environment

<LearningGoal>
能用 LLM（決策引擎）、Tools（行動能力）、Memory（狀態載體）、Loop（循環執行）、Environment（互動目標）五個元件拆解任何一個號稱 Agent 的系統，並說出每個元件負責什麼、少了它會怎樣。
</LearningGoal>

## Lesson

任何 Agent 都能拆成 LLM（決策引擎）、Tools（行動能力，其邊界即自主邊界）、Memory（狀態載體，短期必要、長期進階）、Loop（循環執行）、Environment（互動目標，Sandbox 是其安全設計）五個元件加一個迴圈，再複雜的系統都只是這五塊各自做深。
