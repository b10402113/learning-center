# Agent 的技術定義：感知、決策、行動、回饋迴圈

<LearningGoal>
能說出 Agent 的技術定義（感知環境、自主決策、行動、靠回饋迴圈迭代），並解釋為什麼這個定義刻意不提 LLM——「用 LLM 做的」不等於「Agent」。
</LearningGoal>

## Lesson

Agent 的技術定義是「感知環境、自主決策、行動、靠回饋迴圈迭代」；定義刻意不提 LLM，因為 Agent 比 LLM 更早存在，LLM 只是把工程門檻拉低——「用 LLM 做的」不構成 Agent 的本質。
