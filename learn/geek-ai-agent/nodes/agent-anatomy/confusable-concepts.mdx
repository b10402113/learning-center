# 真偽判別：Agent vs LLM、聊天機器人、工作流

<LearningGoal>
能分辨 Agent 與 LLM（元件 vs 整台機器）、聊天機器人（拿掉 Tools 與 Loop 的 Agent）、工作流（確定性流程 vs 探索性迴圈）的差別，並用「有沒有自主決策迴圈」這個缺席測試判斷一個系統是不是真 Agent。
</LearningGoal>

## Lesson

Agent 與 LLM 是「整台機器 vs 元件」、聊天機器人是「拿掉 Tools 與 Loop 的 Agent」、工作流是「確定性流程」而 Agent 是「探索性迴圈」；三者收斂成同一個缺席測試——找不到自主決策迴圈，就不是 Agent。
