# 用五元件拆解真實產品與 Agent OS

<LearningGoal>
能用「五個問題」的儀式拆解任何新 Agent 產品（以 ChatGPT、Claude Code、Cursor Agent mode、LangChain、Hermes Agent、AutoGPT 為例），並說清 Agent（一個應用）與 Agent OS（跑很多 Agent 的作業系統）的差別。
</LearningGoal>

## Lesson

用「LLM／Tools／Memory／Loop／Environment 各是什麼」五個問題拆解任何產品（ChatGPT 加 Code Interpreter 才算 Agent、Claude Code 五元件全開、LangChain 只是框架、Hermes 勝在跨 session 記憶），並分清 Agent（應用）與 Agent OS（跑很多 Agent 的作業系統）——多 Agent 是複雜度更高的新問題，不是單 Agent 的升級。
