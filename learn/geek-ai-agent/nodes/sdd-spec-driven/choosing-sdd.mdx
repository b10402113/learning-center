# 選型：什麼情況用哪種 SDD

<LearningGoal>
能用 greenfield／brownfield、專案規模與團隊成熟度選出對的 SDD 落地模式（Spec-Kit／OpenSpec delta／輕量手工），並判斷什麼情況根本不該用 SDD。
</LearningGoal>

## Lesson

SDD 有三種落地模式——Spec-Kit 自動化、OpenSpec 手動控制、以及只用 CLAUDE.md 加 Skill 的輕量手工——選型靠 greenfield／brownfield、規模、團隊成熟度與工程師能力判斷，核心差異在全局視角在誰手裡、AI 誤差放大倍數、任務粒度與發現問題的時機；個人小工具、單檔改動與探索性研究則根本不該用 SDD。
