# OpenSpec：delta-spec 與三態流程

<LearningGoal>
掌握 OpenSpec 的 delta-spec（ADDED／MODIFIED／REMOVED）與 Propose → Apply → Archive 三態流程，並說清 brownfield-first 為什麼是它不可被模仿的差異化。
</LearningGoal>

## Lesson

OpenSpec 是輕量、增量友好的 SDD 工具，用 delta-spec（ADDED／MODIFIED／REMOVED）只描述這次改動的差異、以 Propose → Apply → Archive 三態流程管理每個 change，並以 brownfield-first 為核心定位；delta-spec 讓並行 change 互不衝突，是 Spec-Kit 當下無法模仿的差異化。
