# 為什麼需要 SDD：vibe coding 的四個硬問題

<LearningGoal>
能說出 vibe coding（憑感覺寫程式）在中大型專案上暴露的四個硬問題——需求漂移、架構失控、回退困難、無法協作——並解釋為什麼「在提示詞之上加一層結構化需求層」是解法。
</LearningGoal>

## Lesson

vibe coding（憑感覺寫程式）在中大型專案上會暴露需求漂移、架構失控、回退困難、無法協作四個硬問題，根源是需求沒有被固定下來；解法是在提示詞之上加一層結構化的需求層 SDD，把隱性需求變成可審查、可共享、可被 AI 消化的顯性 spec。
