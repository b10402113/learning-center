# Spec-Kit：四階段閉環與 6+3 命令

<LearningGoal>
掌握 Spec-Kit 的 6 個核心命令加 3 個可選命令與四階段工作流，並說清它為什麼是「重武器」、適合與不適合哪些場景。
</LearningGoal>

## Lesson

Spec-Kit 是套在 AI agent 之上的工作流層與 spec-as-source 最純粹形式，用 6 個核心命令（constitution / specify / plan / tasks / taskstoissues / implement）加 3 個可選命令（clarify / analyze / checklist）跑四階段閉環；它是「重武器」，兩輪推斷疊加使產出上限約 64%，適合需求清楚的中大型 greenfield，不適合小型改動與大型 brownfield 改造。
