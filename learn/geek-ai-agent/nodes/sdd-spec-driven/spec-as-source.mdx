# spec-as-source：規格即源頭與三大支柱

<LearningGoal>
能講清 spec-as-source（規格即源頭）的推導鏈 spec → plan → tasks → code，以及支撐它的三大支柱（constitution、四階段閉環、analyze 防漂移），並分辨 SDD 與瀑布、Cursor Rules／AGENTS.md 的差別。
</LearningGoal>

## Lesson

spec-as-source 指 spec 是專案源頭，plan、tasks、code 都從它派生，並由三大支柱撐住——constitution 固化非協商原則、四階段閉環禁止跳步、analyze 跨 artifact 檢查防漂移；它與瀑布（死的 spec）和 Cursor Rules／AGENTS.md（靜態背景、不約束工作流）的關鍵差別在於 spec 是活的、且強制階段化。
