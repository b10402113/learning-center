能說明延遲訊息為何必須先寫入儲存才能進記憶體與回傳，並說出 StoragePlugin 五個方法各自的職責。
</LearningGoal>

## Lesson

延遲訊息是跨越多天的未來承諾，必須在進入記憶體時間輪前先寫入儲存，並以只依賴介面的 StoragePlugin 落地；介面用 `type()` 加 `create`／`get`／`transition`／`loadPendingByTimeWheel`／`deleteExpired` 五個資料方法切開職責，第一個實作是 Redis，換儲存只需新增一個實作。
