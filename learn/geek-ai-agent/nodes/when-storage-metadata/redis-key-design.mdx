<LearningGoal>
能畫出 When 的三類 Redis key、說出每類的型別與 TTL 規則，並解釋這樣設計如何避開 big-key。
</LearningGoal>

## Lesson

Redis 只放三類 key：`when:msg:{id}` 存訊息本體、`when:tw:{tw_id}:idx:{id}` 存到期索引、`when:tw:{tw_id}:slot:{slot_key}` 僅供重啟恢復；索引按時間輪拆開、一則一 key 以避開 big-key，TTL 必須不早於 `max(deliverAt, nextAttemptAt, deliveredAt)` 加保留期，計畫時間延後時也要跟著延長。
