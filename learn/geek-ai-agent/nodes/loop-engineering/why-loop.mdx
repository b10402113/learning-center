# 為什麼是 Loop：從下指令到設計迴圈

<LearningGoal>
能說出 Loop Engineering 的定義與它真正解決的問題（確信感），並解釋為什麼人只從「執行」退守、從不從「判斷」退守。
</LearningGoal>

## Lesson

Loop Engineering 是把執行交給一個能自我判定的迴圈、把判斷留給人的做法，它真正解決的是確信感，而人從 2023 到 2026 一路退守的永遠只是執行，定義目標、設定規則與判斷結果從不外包。
