# 三層關係與邊界：什麼交給 Loop、什麼留給人

<LearningGoal>
能畫出 SDD → Harness → Loop 的三層依賴，並用「可驗證性／出錯成本」判準決定一個任務該進 Loop 還是留給人。
</LearningGoal>

## Lesson

Loop 站在 SDD（想清楚）與 Harness（造環境）之上，並用可驗證性與出錯成本這條線決定分工：便宜、可確定驗證、錯了也便宜的工作交給迴圈，難驗證、錯了很貴的一致性、金錢與安全永遠由人主導——判斷力、思考力、產品感是 AI 拿不走的三件事。
