# Loop 五要素：讓迴圈轉得動、安全、可信

<LearningGoal>
能列出 Loop 的五個要素，並說出前兩者決定迴圈能不能轉、中間兩者決定安不安全、最後一者決定可不可信。
</LearningGoal>

## Lesson

一個可用的 Loop 需要五個要素——可判目標、可驗證的判官、隔離工作區、邊界與停止、人類檢查點；前兩者決定迴圈能不能轉，中間兩者決定安不安全，最後一者決定可不可信，其中判官最常被跳過、也最能決定成敗。
