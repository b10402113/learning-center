# 跑一輪：循環、停止條件與任務卡

<LearningGoal>
能走完一輪「讀任務卡 → 先寫測試 → 實作 → 跑驗收 → 讀失敗修正」，講出四個停止條件，並寫出一張六欄位的任務卡交給 `/loop`。
</LearningGoal>

## Lesson

跑一輪就是「讀任務卡 → 先寫測試 → 實作 → 跑驗收 → 讀失敗修正」直到全綠或撞上四個停止條件（全綠、超過迭代上限、卡片有歧義、需要越界），而任務卡六欄位中可判定的驗收標準就是迴圈的輸入合約。
