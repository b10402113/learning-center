# 項目：OryxOS——從 0 寫一個 Agent OS

## Learning goal

真動手跑通 Spec-Kit 主導的 AI 編程全流程，從 0 寫出可運行的 OryxOS（JDK 21 + Spring Boot + 自研 ReAct loop）——本課程唯一真動手項目。

## Steps

1. [[learn/geek-ai-agent/nodes/oryxos-build/agent-os-oryxos-positioning|Agent OS 概念與 OryxOS 定位]] — 理解 Agent OS 的定義、五大能力、與相鄰概念的邊界，以及 OryxOS 為何選 Java、如何定位
2. [[learn/geek-ai-agent/nodes/oryxos-build/spec-kit-workflow-constitution|Spec-Kit 工作流與七條憲法]] — 掌握 Spec-Kit 驅動的 AI 編程全流程，理解七條憲法原則與九模塊技術架構（after step 1）
3. [[learn/geek-ai-agent/nodes/oryxos-build/provider-llm-integration|Provider 抽象層與 LLM 對接]] — 實作 Provider 抽象層，透過 Spring AI Alibaba 對接主流 LLM，實現 provider-name→ChatModel 顯式映射（after step 2）
4. [[learn/geek-ai-agent/nodes/oryxos-build/react-loop-core|ReAct 循環引擎]] — 實作自研 ReAct 循環引擎（~數十行 Java），包含 PromptBuilder、ToolExecutor、迭代控制與 Session 管理（after step 3）
5. [[learn/geek-ai-agent/nodes/oryxos-build/memory-tool-webservice|Memory、Tool 與 Web Service]] — 實作 Memory 三層記憶（含 MEMORY.md 長期記憶）、Plugin Tool 三級體系（含 MCP Client）、以及 Web Service 10 個核心 Endpoint，完成 OryxOS 1.0（after step 4）

## Lesson

OryxOS 是本課程唯一真動手的項目。它的目標不是「學會 Java」或「學會 Spring Boot」，而是把前面認知篇和擴展篇建立的方法論（SDD + Harness、Spec-Kit 工作流、Agent 五組件）落到一個真實的九模塊 Java 項目上，讓「用 AI 把一件事做成」變成肌肉記憶。

整個項目按 Spec-Kit 主導的雙階段策略推進：主構建用 Spec-Kit 跑完整的 specify → plan → tasks → implement 流程，增量用手動提示詞。五個 user story 按依賴排序（US-1→US-2→(US-3∥US-4)→US-5），每個 story 以一個可演示的 demo 收尾，七條憲法原則全程守護代碼不偏離技術方案。
