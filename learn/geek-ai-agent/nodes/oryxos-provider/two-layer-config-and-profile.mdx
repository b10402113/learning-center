# 兩層配置與 Profile 系統

<LearningGoal>
能解釋 Provider 的「兩層配置」：應用層宣告 provider 與憑證、Profile 層宣告用哪個模型與溫度，並闡述 ProfileLoader／ProfileRegistry 如何載入、驗證與索引 Profile，以及「引用不存在的 Provider 必須硬失敗」的理由。
</LearningGoal>

## Lesson

配置拆兩層：應用層只用 name＋${ENV} 憑證＋base URL 宣告系統認識哪些 provider，Profile 層宣告這一個 Agent 用哪個模型與溫度並以 name 引用；ProfileLoader 負責掃描與 ${ENV} 解析，ProfileRegistry 建按名索引並在放入時驗證 provider 存在——Profile 本身壞掉是軟失敗，引用不存在的 provider 必須硬失敗。
