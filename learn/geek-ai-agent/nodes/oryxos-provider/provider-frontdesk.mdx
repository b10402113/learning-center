# 什麼是 Provider：Agent 與 LLM 之間的前台

<LearningGoal>
能說出 Provider 在整個 Agent 架構中的位置（前台）、它承擔的四件事與絕不承擔的一件事，並解釋為什麼換模型可以只改配置。
</LearningGoal>

## Lesson

Provider 是 Agent 與各家大模型之間的前台：它只做選模、一次呼叫、工具 schema 轉換與審計四件事，把各家 API 差異藏在接縫後，絕不執行工具——工具執行權留在 ToolExecutor；因此換模型只要改 Profile 裡的 provider name。
