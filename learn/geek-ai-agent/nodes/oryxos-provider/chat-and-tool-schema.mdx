# 一次呼叫與工具 schema 轉換

<LearningGoal>
能說出 ProviderService.chat 一次同步呼叫的完整路徑（Profile 路由 → 構建 Prompt → 關閉工具自動執行 → 呼叫 ChatModel → 回傳 text／toolCall／usage），並解釋 ToolSchemaAdapter 為何「只翻譯不執行」。
</LearningGoal>

## Lesson

一次呼叫的路徑很清楚：依 Profile 路由到顯式映射的 ChatModel → 構建 Prompt（關閉 internalToolExecutionEnabled 並保留結構化消息配對）→ ToolSchemaAdapter 把 OryxTool 翻譯成只攜帶 schema 的描述（call() 永遠拋例外，作為不執行的第二道保險）→ model.call 後把 text／toolCalls／usage 原樣交回迴圈；chatStream 有預設回退實作，不強迫支援流式。
