# 驗證瓶頸與認知債：生成變便宜之後的代價

<LearningGoal>
解釋瓶頸為何從「生成」位移到「驗證」，以及認知債與當責崩壞如何在 12–24 個月後反噬，並用 Anthropic 隨機對照實驗說明為什麼卡關不能外包。
</LearningGoal>

## Lesson

生成變便宜後瓶頸位移到驗證：程式碼看似合理的「意圖缺口」造成 96% 不信任卻只有 48% 驗證的落差，未理解的 AI 程式碼累積成 12–24 個月後才反噬的認知債與當責崩壞，而 Anthropic 實驗證明卡關（尤其是除錯）一旦外包就會退步。
