# 30% 現實：自動化天花板與能自動的案子長什麼樣

<LearningGoal>
用「30% 提速是頂級水平」的現實與成功自動化案例的五個共同條件，判斷一個具體任務 AI 能不能自動做。
</LearningGoal>

## Lesson

真實生產力天花板是 30% 而非十倍，瓶頸在可靠性而非能力；能安全自動的任務共享「範圍清楚、可驗證、上下文有限、不是從零、有參考實作」五個條件，Bun 案例與企業全流程 AI 化的失敗都印證了這條界線。
