# 六階段人+AI 交付管線與三個傳動裝置

<LearningGoal>
畫出需求 → 設計 → 開發 → 測試 → 部署 → 運維六階段，並說出每階段 AI 做什麼、人負責什麼，以及三個讓管線真正跑起來的傳動裝置。
</LearningGoal>

## Lesson

需求、設計、開發、測試、部署、運維六個階段都由人+AI 共同跑、AI 執行而人把關，並靠「產出物有兩個讀者、人+AI 分工、自動回饋工程化」三個傳動裝置讓整條管線真正轉動。
