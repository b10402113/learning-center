# 設計你自己的可複製工作流：理解 → 約束 → 驗證 → 累積

<LearningGoal>
用「理解 → 約束 → 驗證 → 累積」底層模式與四前提三動作，設計並養成自己可複製的人+AI 工作流，且能對外講清楚自己的判斷。
</LearningGoal>

## Lesson

個人工作流是可複製的「理解 → 約束 → 驗證 → 累積」模式，靠四前提與三動作一輪輪養成，關鍵是刻意保留卡關、不外包理解，並能用「做什麼／為什麼／變了怎麼辦」與四段公式把判斷講清楚。
