# 工作流不是流程圖：從模糊需求到上線的完整系統

<LearningGoal>
說清工作流是「從模糊需求到上線的完整系統」而非零散動作的集合，並用六個元件檢查它是否真的能跑。
</LearningGoal>

## Lesson

工作流不是流程圖，而是一套講清楚產出物、人責、AI 責、回饋、例外與累積六個元件後才會自己運轉的完整系統——它比工具更值得投資，因為工具會過期，工作流可複製。
