# 動手前先想清楚：介面先行與四個決策

<LearningGoal>
能複述動手前的四個決策（介面表達意圖、核心只做通用 webhook、安全留給 Sandbox、目的地放 Profile），並解釋入站 ChannelAdapter 與出站 NotifyChannelAdapter 的對稱性。
</LearningGoal>

## Lesson

動手前先訂四個決策：介面只表達「把內容送達一個通知目標」的意圖、不含渠道詞彙（核心階段只實作一支通用 webhook）、安全驗證留給 Sandbox 的佔位而非自創、目的地放 Profile 的 notify_channels 設定；入站 ChannelAdapter 與出站 NotifyChannelAdapter 是方向相反的對稱插件，而 NotifyTools 的完整實作要等 @Tool 與 Sandbox.enforce 就位。
