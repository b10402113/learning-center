# 為什麼需要 Notify：觸發斷裂與出站職責

<LearningGoal>
能說出「到點自動」觸發如何讓入站請求／回應路徑失效，並指出 Notify 是 Agent 主動決定「把結果送到哪」的對應補位。
</LearningGoal>

## Lesson

CLI 與 Web Service 都是「人問機器答」的入站請求／回應路徑；當觸發變成「到點自動」（定時），就沒有請求方在現場等回應，結果會爛在 Session 裡——Notify 正是這個出站補位：讓 Agent 主動決定把結果推送到哪個通知目標，並與入站 ChannelAdapter 對稱地採用 adapter 插件模式。
