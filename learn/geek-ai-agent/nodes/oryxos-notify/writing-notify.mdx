# 程式碼怎麼寫：NotifyChannelAdapter、NotifyTarget、WebhookNotifyAdapter、NotifyTools

<LearningGoal>
能說出四個類別各自的職責、介面簽名為何不含任何渠道概念，以及 channel 非必填時的行為。
</LearningGoal>

## Lesson

四個類別三層分工：`NotifyChannelAdapter` 用不含渠道概念的 `send(NotifyTarget, String)` 簽名表達意圖，`NotifyTarget(channelType, config Map)` 描述目標，`WebhookNotifyAdapter` 從 config 讀 URL、POST `{"content": ...}`，`NotifyTools.notify(content, channel)` 依序「從 Profile 解析目標 → sandbox.enforce → adapter.send」，channel 非必填時預設第一個渠道——所以把 webhook 換成企業微信 SDK，NotifyTools 一行不用改。
