# Demo 三：目錄帶腳本的每日 GitHub 日報

<LearningGoal>
能說明為何把抓取 GitHub trending 的確定性工作寫成目錄裡的 Python 腳本、由 Agent 用 shell 執行，並解釋子行程自行連網如何繞過 http_get 網域白名單、把信任轉移到 Agent 作者身上。
</LearningGoal>

## Lesson

把抓 GitHub trending 的確定性工作寫成 `scripts/github_trending.py`、由 Agent 用 `shell` 執行、LLM 只負責組稿；子行程自行連網會繞過 `http_get` 的網域白名單，因此安裝這個 Agent 等於信任作者，Sandbox 只用命令與檔案路徑兩道白名單守住「能跑什麼、能碰哪些檔」。
