# 底座與 Agent 的分界

<LearningGoal>
能用「底座 vs Agent」分界圖說明 Provider／ReAct／CLI／Notify／Tool／Memory／Sandbox／排程／Web 全都屬於底座，而真正的業務 Agent 只是插上去的一個目錄，並解釋為何底座越厚、定義一個 Agent 就越便宜。
</LearningGoal>

## Lesson

Provider／ReAct／CLI／Notify／Tool／Memory／Sandbox／排程／Web 全都是底座，真正的業務 Agent 只是插上去的一個目錄；三個 Demo 加起來不到一百行、零 Java 的不成比例，正是「底座越厚、定義一個 Agent 越便宜」這把量尺的刻度。
