# 發布 v0.1.0：打包、產物與可操作性驗收

<LearningGoal>
能複述 v0.1.0 的打包指令（mvn clean verify／package、git tag）、兩個發布產物（fat JAR 與 .oryxos 工作區），並用「乾淨機器 30 分鐘從零跑起兩個 Agent」的可操作性驗收標準判斷一個版本能不能發。
</LearningGoal>

## Lesson

發布 v0.1.0 用 `mvn clean verify`／`package` 與 `git tag`，產出單一 fat JAR（`oryxos.jar`）與可備份、可進 git 的 `.oryxos` 工作區兩個產物；真正的門檻是可操作性驗收——新人在乾淨機器 30 分鐘內從零把兩個 Agent 跑起來，卡住代表文件缺說明而非程式缺功能。
