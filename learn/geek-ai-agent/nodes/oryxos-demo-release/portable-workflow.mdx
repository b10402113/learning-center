# 帶得走的工作流、設計母題與後續路徑

<LearningGoal>
能複述每個模組重複四次的工作節奏（原理→動手前想清楚→與 AI 實作→驗證並講解程式碼）與四條設計母題，並用「新增一個實作、不改介面」的訊號觸發方式說明後續擴展路徑。
</LearningGoal>

## Lesson

真正帶得走的是每個模組重複的四步節奏（原理→動手前想清楚→與 AI 實作→驗證並講解）與四條設計母題（介面先行、訊號驅動升級、階段克制、同一入口），後續每一項擴展都是「新增實作、不改介面」並由具體訊號觸發。
