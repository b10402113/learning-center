# Demo 二：目錄帶子指令的每日科技日報

<LearningGoal>
能說明把長篇排版規範放進目錄子指令、用 read_file 按需載入的做法，並解釋為何一份 seed 進長期記憶的偏好能讓之後每天的日報都把 AI／晶片排前面。
</LearningGoal>

## Lesson

把長篇排版規範放進 `skills/digest-format.md`、用 `read_file` 在組稿那一步按需載入，就是漸進式揭露；新聞來源走 `http_get`（穩）或自寫 MCP（險），而一句 `save_memory` 種下的偏好讓之後每天的日報都把 AI／晶片排前面。
