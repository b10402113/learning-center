# Demo 一：光桿 AGENT.md 的每日天氣 Agent

<LearningGoal>
能用一個光桿 AGENT.md 定義出每日 08:00 自動推送天氣與穿搭建議的 Agent，說清它的最小設定、三道環境閘門，以及「先推再看時鐘」的除錯順序。
</LearningGoal>

## Lesson

一個光桿 AGENT.md（frontmatter 的誰／何時／用什麼＋一句 body）就能定義每日 08:00 自跑的天氣 Agent；最小權限的 tools、三道環境閘門（金鑰／白名單／webhook），以及「先手動推、再看時鐘」的除錯順序，決定了它能否穩定留下可對賬的審計痕跡。
