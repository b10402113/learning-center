# 資料定位與複製一致性：分片路由與同步／非同步

<LearningGoal>
能說明訊息如何先分片、再靠路由元數據表查到 Master，並比較同步與非同步複製的得失，講清 When 為何在外有可信來源（Redis）的情況下選擇非同步。
</LearningGoal>

## Lesson

定位 Master 是查「分片→副本」路由元數據表而非對節點算雜湊，一致性雜湊降低分片變動時的搬遷量；同步複製不丟但慢且受 Slave 拖累、非同步快但可能丟尾端，When 因 Redis 為可信外部來源而選非同步。
