# 為何要叢集化：單機的兩道天花板與六問題全景

<LearningGoal>
能說出單機的兩道天花板（容量、單點故障）為何逼出叢集化，並用成員、唯一決策、資料定位、故障接管、複製一致性、協調選型六個問題，以及它們對應的六個機制，拼出一個叢集系統的全景。
</LearningGoal>

## Lesson

叢集化以水平擴充與消除單點故障突破單機的容量與當機兩道天花板，代價是成員感知、唯一決策、資料定位、故障接管、複製一致性、公共協調六個多機新問題，六機制各自對應其中一格。
