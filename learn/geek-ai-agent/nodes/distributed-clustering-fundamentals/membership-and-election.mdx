# 成員感知與唯一決策：心跳、租約與選舉

<LearningGoal>
能解釋心跳加租約如何把「節點還活著嗎」變成可判定的「租約過期了嗎」，並說出 CAS 與多數派（quorum）為何能保證唯一決策、避免腦裂。
</LearningGoal>

## Lesson

租約把「節點還活著嗎」換成可判定的「租約過期了嗎」，偵測延遲下限即 TTL；CAS 保證同一時間只有一個節點搶到領導權，多數派共識則確保網路分區時只有多數側能選出 leader，因此共識不應自造。
