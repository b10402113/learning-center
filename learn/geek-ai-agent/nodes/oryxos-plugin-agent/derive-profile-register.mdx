# 掃描→deriveProfile→註冊→自跑：底座零改動的插件機制

<LearningGoal>
能說出「掃描→deriveProfile→註冊→自跑」四個步驟各自做什麼，並解釋為什麼這條路徑讓底座一行都不用改。
</LearningGoal>

## Lesson

插件化的核心是不改底座、只加一個 Profile 來源：掃描 `.oryxos/agents/` → `AgentLoader` 解析 frontmatter 與 body → `deriveProfile(agentDir)` 映射成底座只認的 `Profile`（含 schedules）→ 註冊進可變的 `ProfileRegistry` 並交給 `AgentScheduler.registerProfile`；觸發時走同一條 `AgentService.process`，因此 ReAct／Tool／Provider 與排程器全部零改動。
