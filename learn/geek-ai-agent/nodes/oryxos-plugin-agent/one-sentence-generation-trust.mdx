# 一句話生成與腳本信任邊界

<LearningGoal>
能說出「一句話生成」為何必須人審、最終落地為何改成模板骨架，以及安裝帶腳本的 Agent 等於信任作者的信任邊界。
</LearningGoal>

## Lesson

一句話生成本質是一次 LLM 呼叫且必須人審（草稿只回傳不落地，最終落地改為模板 scaffold、LLM 生成下沉為對既有 Agent 的重生成）；而 L3 腳本是任意程式碼，白名單只管「直譯器＋本目錄 scripts/」，子程序網路能繞過 http_get 域名白名單，所以安裝帶腳本的 Agent 等於信任其作者——這是必須明說的信任邊界。
