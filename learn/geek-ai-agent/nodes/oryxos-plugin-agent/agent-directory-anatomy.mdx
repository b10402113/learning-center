# 一個 Agent 目錄長什麼樣：AGENT.md、scripts、skills、REFERENCE.md

<LearningGoal>
能畫出一個 Agent 目錄的完整結構，並說出哪個檔案在什麼時機才進入上下文（progressive disclosure）。
</LearningGoal>

## Lesson

一個 Agent 目錄固定放在 `.oryxos/agents/<name>/`，由四個檔案組成：AGENT.md（frontmatter 即 Profile、body 是任務編排）、scripts/（執行時只把輸出帶進上下文、程式碼不進）、skills/ 子指令與 REFERENCE.md（各自被 read_file 用到才讀）——靠既有的 read_file／shell 達成漸進式揭露，不必新增底層能力。
