# 一目錄一 Agent：為什麼這叫 Agent OS

<LearningGoal>
能說清「一目錄一 Agent」為什麼是 Agent OS 的分界線，以及它借了 Skill 目錄形態、卻定義 Agent 的關鍵差別。
</LearningGoal>

## Lesson

Agent OS 的分界不在核心多強，而在是否提供「定義、安裝、執行任意多個 Agent」的標準機制；底座是可共用的系統能力，Agent 是一個自足目錄，借 Anthropic Skills 的目錄形態與漸進式揭露，但把單位釘死為一目錄一 Agent（skill 降為內部元件，無跨 Agent 能力庫）。
