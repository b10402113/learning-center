# 準備階段：constitution、spec、plan 三份 artifact

<LearningGoal>
能說出需求文件、技術方案、設計目標分別餵給哪個 Spec-Kit 命令，並列出三份 artifact 各自該長什麼樣。
</LearningGoal>

## Lesson

Spec-Kit 準備階段不重寫既有文件，而是把需求文件餵給 `/speckit.specify` 產出五個 user story、把技術方案餵給 `/speckit.plan` 產出九模組實施計畫、把設計目標與關鍵決策餵給 `/speckit.constitution` 產出不可協商的憲法，並靠人工複審與鎖定 plan.md 守住關鍵決策。
