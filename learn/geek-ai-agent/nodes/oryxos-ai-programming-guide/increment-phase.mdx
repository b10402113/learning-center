# 增量階段：手動提示詞工作流與 artifact 對接

<LearningGoal>
能跑一遍 issue → fork → Claude Code → PR 的增量工作流，並說清增量產物怎麼跟主體階段的 artifact 對齊。
</LearningGoal>

## Lesson

主體完成後增量階段切回手動提示詞加 Claude Code，走 issue → fork → 修改測試 → PR 的社群貢獻流程，Spec-Kit 非強制；但 constitution 仍不可協商、spec 是能力契約、plan 大致凍結，小改動走 PR、大 feature 才可選擇性重跑重流程。
