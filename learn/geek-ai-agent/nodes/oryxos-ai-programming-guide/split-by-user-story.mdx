# 按 user story 拆解：US-1 → US-2 → (US-3 ∥ US-4) → US-5

<LearningGoal>
能按 user story 把 OryxOS 專案拆成有依賴順序的可執行任務，並說出五個 US 各自的核心任務類別。
</LearningGoal>

## Lesson

OryxOS 按 user story 而非時間拆解——US-1（Provider）→ US-2（ReAct）→（US-3 Memory ∥ US-4 Plugin Tool）→ US-5（Web Service），每個 US 有明確模組、任務類別與 demo，任務粒度控制在一到兩個檔案且各自產出可執行的程式碼。
