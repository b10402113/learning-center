# 兩階段混合模式：主體 Spec-Kit、增量手動提示詞

<LearningGoal>
能判斷什麼工作用 Spec-Kit、什麼工作用手動提示詞，並說出兩階段混合模式為什麼是 OryxOS 的正解。
</LearningGoal>

## Lesson

OryxOS 採兩階段混合模式——主體開發用 Spec-Kit 跑完整 SDD 流程，增量開發改用手動提示詞加 Claude Code；判斷依據是工作性質，中大型 greenfield、需求清楚、agent 主導的專案用重武器，一到三個檔案的小改動用輕工具，並以 analyze 與版本紀律處理 Spec-Kit 的已知局限。
