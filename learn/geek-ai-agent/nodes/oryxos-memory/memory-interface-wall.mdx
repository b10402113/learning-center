# 介面牆與三層設計：MemoryService、四契約、信號驅動升級

<LearningGoal>
能設計 MemoryService 門面與 LongTermMemoryStore 後端介面這道「介面牆」，背出三後端共守的四條行為契約，定位 core／session／archival 三層，並說出觸發向量檢索升級的三個真實信號。
</LearningGoal>

## Lesson

用 MemoryService 門面與 LongTermMemoryStore 後端介面立起一道「介面牆」，三後端共守「不快取、核心永不截斷、scope 由呼叫方顯式指定、檢索只在歸檔區」四條契約；core／session／archival 三層各司其職，Agent 主動 save_memory 寫入，等三個真實信號出現再於牆後換上向量檢索。
