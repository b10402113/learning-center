# 可插拔三後端：Markdown／SQLite／Mem0

<LearningGoal>
能實作 Markdown、SQLite、Mem0 三檔 LongTermMemoryStore，說清各自定位與四契約如何落地，並證明只改 memory.backend 設定就能換後端而門面以上零改動。
</LearningGoal>

## Lesson

Markdown（預設、零依賴、人可讀）、SQLite（結構化升級、LIMIT 截斷、SQL LIKE）、Mem0（外部集成、DELEGATED、把提煉與衝突消解下放）三檔實作同一組契約；換後端只改 memory.backend，門面以上一行不動。
