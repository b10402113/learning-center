# 壓縮 vs 提煉：上下文壓縮、記憶壓縮與完整循環

<LearningGoal>
能用一句話分辨上下文壓縮（把眼前的對話變短）與記憶壓縮（把長期倉庫整理精簡），並解釋記憶提煉為何決定長期記憶品質，最後能畫出記憶的完整閉環。
</LearningGoal>

## Lesson

上下文壓縮縮短的是眼前的對話、記憶壓縮整理的是長期的倉庫，而記憶提煉（把冗長對話抽成結構化條目）的品質直接決定長期記憶的好壞；三者串成「累積 → 壓縮提煉 → 寫入 → 定期整合 → 檢索重注入」的完整閉環。
