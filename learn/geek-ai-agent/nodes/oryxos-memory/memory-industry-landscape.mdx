# 業界記憶方案盤點與 MemGPT／Mem0 解剖

<LearningGoal>
能盤點 Mem0／Zep／Letta(MemGPT)／Cognee／LangMem／ReMe 的定位差異，說清 MemGPT「記憶即作業系統」與 Mem0「add 即消解」兩個核心思想，並用「記憶是否為核心差異化能力」這個錨判斷自造或集成。
</LearningGoal>

## Lesson

2026 開源記憶生態由 Mem0（add 即消解的 library）、Zep／Graphiti（時序知識圖譜）、Letta／MemGPT（記憶即 OS 的執行時）與 Cognee／LangMem／ReMe 各據一方；選型錨是「記憶是否為核心差異化能力」——同層的 Letta 只學思想絕不集成，零件式的 Mem0 可在記憶非差異化時集成。
