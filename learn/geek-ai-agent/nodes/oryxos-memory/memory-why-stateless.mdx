# 為什麼 Agent 需要記憶：無狀態 LLM 與短期／長期記憶

<LearningGoal>
能說清 LLM 每次呼叫都無狀態、context window 有限且昂貴，因此 Agent 必須在視窗之外管理記憶；並能區分短期（工作）記憶與長期記憶（情節／語意／程序）。
</LearningGoal>

## Lesson

LLM 每次呼叫都是無狀態、context window 有限且昂貴，所以 Agent 必須在視窗之外管理記憶：短期（工作）記憶留在視窗內、會話結束即失，長期記憶（情節／語意／程序）跨會話持久並在需要時被檢索回上下文。
