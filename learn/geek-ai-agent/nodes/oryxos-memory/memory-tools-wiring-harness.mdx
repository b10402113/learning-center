# 記憶工具、Prompt 注入與契約測試

<LearningGoal>
能把 save_memory／recall_memory 兩個內建工具接上 MemoryService，讓 PromptBuilder 每輪注入長期記憶，並用一份參數化契約測試證明三後端行為一致、切換後端上層不變。
</LearningGoal>

## Lesson

save_memory／recall_memory 兩個內建工具只認門面、把記憶暴露給 Agent，PromptBuilder 每輪注入長期記憶（不快取，故本輪寫入下一輪就在場）；再用一份跑在三檔後端上的參數化契約測試，把「介面不變、實作自由替換」變成自動化保證。
