# Session 持久化與驗收 harness

<LearningGoal>
能說明 session 歷史以 JSON 存進 SQLite 的 sessions 表、重啟後如何恢復，並能複述 SessionManagerTest 與 SessionRepositoryTest 各驗證了什麼。
</LearningGoal>

## Lesson

session 歷史以 JSON 塞進 SQLite 的 sessions 表一格 messages_json（手維護 schema，別信 ddl-auto=update），SessionManagerTest 釘住冪等性契約、SessionRepositoryTest 釘住跨重啟的持久性契約，再用 chat／serve／gateway 共用 Profile 與 Session 存儲的手動檢查收尾。
