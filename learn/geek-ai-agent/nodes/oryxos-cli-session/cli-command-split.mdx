# 動手前的四個決定：輕/重命令切分與 JPA 掃描坑

<LearningGoal>
能複述動手前的四個決定（不碰 Agent 邏輯、輕重切分、Picocli、顯式 JPA 掃描），並能解釋「Found 0 JPA repository interfaces」陷阱的成因與修法。
</LearningGoal>

## Lesson

動手前四個決定——CLI 永不碰 Agent 邏輯、輕/重命令切分（init／profile list 不開 Spring，chat／serve／gateway 才開）、用 Picocli 統一子命令、重命令要顯式宣告 JPA 掃描範圍，因為 scanBasePackages 不自動攜帶 repository／entity 掃描，否則啟動會報「Found 0 JPA repository interfaces」。
