# Session：冪等 session id 的單一真相

<LearningGoal>
能說出 session id 是 channel+user+profile 三元組、為什麼必須只在 SessionManager 內部拼裝，以及冪等的定義（同樣三元組→同一 session）。
</LearningGoal>

## Lesson

session id 是 channel＋user＋profile 三元組，拼裝只准在 SessionManager 內部一處發生，所有入口只傳三個值、由 getOrCreate 統一拼，才能保證冪等（同樣三元組永遠得到同一個 session），否則任一入口自己拼 id，同一個使用者就會裂成兩段互相不認識的歷史。
