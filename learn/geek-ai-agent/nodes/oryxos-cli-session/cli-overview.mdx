# CLI 是什麼：薄入口與十二個子命令

<LearningGoal>
能說出 CLI 的定位是「門不是工人」、核心階段 12 個子命令的分組，以及三種運行模式如何共用同一個引擎與同一份 Session 存儲。
</LearningGoal>

## Lesson

CLI 是「門不是工人」的薄入口：核心階段 12 個子命令分成啟動 Agent（chat／serve／gateway）、查看狀態、初始化三組，其中三種運行模式共用同一份 Profile、同一個 Session 存儲與同一個引擎，差別只在訊息從哪裡來（stdin／HTTP／渠道），所以 CLI 一層不碰任何 Agent 邏輯。
