<LearningGoal>
能說出 When 的六大技術決策，並解釋每個決策為什麼勝過它的替代方案，以及為何三週內做 HA 是合理的。
</LearningGoal>

## Lesson

When 用六個技術決策把難題外推給成熟元件——ETCD 管協調、Redis 存訊息、多層時間輪做 O(1) 排程、Master/Slave 求快速切換、對外 HTTP 對內 gRPC、整體用 Java——自己只專心做好記憶體中的時間輪，並因此敢在三週內交付含 HA 的 MVP。
