<LearningGoal>
能解釋多層時間輪如何用環加指針做到 O(1) 插入與觸發，說清跨層降級、多輪分片與排程迴圈的精度設計。
</LearningGoal>

## Lesson

多層時間輪用「環加指針」把排程變成 O(1)：延遲超出細層就以更粗的層承接，到期時逐層降級到細層精準觸發；每節點開 2–4 個輪並以訊息 ID 的一致雜湊選輪，排程迴圈只讀取與觸發、其餘非同步，並用 sleep_until_next_slot() 對齊格子邊界以避免漂移。
