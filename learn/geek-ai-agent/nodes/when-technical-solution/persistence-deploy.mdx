<LearningGoal>
能畫出 When 的 Redis key 結構並解釋如何避開 big-key，說清重啟恢復順序與三種部署形態的取捨。
</LearningGoal>

## Lesson

Redis 只用三類 key（message 本體、按輪拆分的到期索引、僅供恢復的槽位 SET），以拆成大量小 key 與 TTL 安全網避開 big-key；寫入先寫 Redis 成功才回傳，節點重啟必須先從 Redis 載完時間輪才向 ETCD 註冊，部署則提供 docker-compose、單機生產與 K8s 三種形態。
