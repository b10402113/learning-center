<LearningGoal>
能列出九個 Maven 模組與依賴方向，並說明 Profile、ContextLoader、Channel、三種運行模式、CLI 與 ConfigLoader 在支撐層的角色。
</LearningGoal>

## Lesson

九個 Maven 模組是五個能力（provider／core／memory／tool／web）加四個支撐（boot／cli／storage／channel-cli），全部依賴 oryxos-core、由 boot 組裝成單一 JAR；支撐層則由 Profile 設定多 Agent、ContextLoader 統一注入 Bootstrap 與 Skill、Channel 管訊息入口、chat／serve／gateway 三種運行模式共用 Profile 與 Session、CLI 拆分輕命令加速、ConfigLoader 統一載入憑證。
