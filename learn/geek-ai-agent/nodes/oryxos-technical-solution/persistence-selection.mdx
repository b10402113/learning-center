<LearningGoal>
能解釋為什麼核心用 SQLite + MEMORY.md 而不用向量庫，以及三條升級路徑與各自的代價。
</LearningGoal>

## Lesson

核心以 SQLite（sessions／tool_invocations／llm_calls，靠手寫腳本或 Flyway 遷移）加 Spring Data JPA 管關係型資料、MEMORY.md 管長期記憶、檔案系統管使用者要編輯與版控的設定；不用向量庫是因為選項都需外部行程或尚未就緒，但介面已預留 LanceDB／pgvector／JVector 三條升級路徑。
