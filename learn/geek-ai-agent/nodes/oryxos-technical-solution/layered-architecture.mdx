<LearningGoal>
能畫出 access／engine／capability／foundation 四層，並說明五大能力如何各自供養 ReAct 引擎、又如何在兩端被暴露出去。
</LearningGoal>

## Lesson

OryxOS 是切成四層的單體：access（CLI Channel、Web REST API）、engine（ReActLoop、PromptBuilder、ToolExecutor）、capability（Provider、Memory、Tool）、foundation（Profile／Bootstrap／Skill、Session、SQLite、config）；ReAct 是引擎，Provider／Memory／Tool 供養它，Web 與 CLI 把它的能力暴露出去。
