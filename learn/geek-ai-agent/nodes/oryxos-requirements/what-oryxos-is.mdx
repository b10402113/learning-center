# OryxOS 是什麼：定義與交付兩階段

<LearningGoal>
能用一句話說清 OryxOS 是一個裝在企業自己基礎設施上的 Agent OS，並解釋它的兩階段交付（先做 runtime kernel、後做治理層）為什麼是這樣切的。
</LearningGoal>

## Lesson

OryxOS 是裝在企業自有基礎設施上、向上統一運行一群業務 Agent、向下接住模型／渠道／工具／記憶／身份／審計的 Java Agent OS，採「先核心 runtime kernel、後治理層」的兩階段交付，核心階段只用 12 小時蓋出最短可跑的五能力鏈，治理層留待擴展階段。
