# 術語表與九個 Maven 模組

<LearningGoal>
能用自己的話定義 Agent、Profile、Provider、Session、Channel、Tool Policy、Skill、Bootstrap、Workspace 等核心術語，並把五大能力對應到九個 Maven 模組中的哪幾個。
</LearningGoal>

## Lesson

用一套對齊開源 Agent OS 事實標準的術語（Agent／Profile／Provider／Session／Channel／Tool Policy／Skill／Bootstrap／Workspace）統一全專案語言，並把五大能力落成九個 Maven 模組：provider、core、memory、tool、web 加 boot、cli、storage、channel-cli，模組依賴方向就是能力供養方向。
