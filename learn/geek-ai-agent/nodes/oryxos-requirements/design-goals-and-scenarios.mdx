# 四個設計目標與三個典型場景

<LearningGoal>
能背出「統一、私有、易接入、可觀測」四個設計目標並解釋各自對應的工程要求，再用三個典型場景說明這些能力組合起來長什麼樣。
</LearningGoal>

## Lesson

「統一、私有、易接入、可觀測」四個設計目標是每個取捨的評分尺；運維、知識管理、銷售三個典型場景看似各異，拆開都是同一條骨架（渠道進 → ReAct 規劃 → 工具存取系統 → Memory 保上下文 → 渠道出），業務側只需設定 Profile、寫 Plugin Tool、呼叫 Web Service。
