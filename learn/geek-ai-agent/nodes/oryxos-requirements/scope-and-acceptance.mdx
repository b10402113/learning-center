# 核心／擴展／社區範圍與驗收標準

<LearningGoal>
能分清核心、擴展、社區三層各放什麼，複述四層驗收標準與五個必過 Demo，並說出核心階段的性能、可靠性與安全硬指標。
</LearningGoal>

## Lesson

核心／擴展／社區三層界定做與不做的邊界（核心 12 小時做 runtime kernel，治理層屬擴展），四層驗收標準（功能、性能、可運維、場景）與五個必過 Demo、以及性能／可靠性／安全硬指標，一起構成核心階段的完成定義。
