# Digest — 03-11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南

## Overview (L1)

- 1. 为什么单独写这篇 — Skills exploded after Anthropic's Oct 2025 launch (1000+ skills in a year); the doc resolves three confusions: what Skills are, what the industry actually uses, and how to distill your own.
- 2. Skills 是什么 — A Skill is "process consolidation + tool invocation" (SOP + toolbox): a directory whose core is SKILL.md (YAML frontmatter name/description + markdown instructions). Clarifies the relationship to MCP, Subagents, Plugins, Commands, and explains progressive disclosure (3 layers) and cross-tool compatibility (8+ tools).
- 3. Skills 的两类核心价值 — Capability Uplift (让 AI 学会做没做过的事) vs Encoded Preference (让 AI 按你的方式做事); shows how to mix both in daily development.
- 4. 业界 Skills 全景 — Survey: Anthropic official `anthropics/skills` (121k star), community libraries (obra/superpowers, alirezarezvani/claude-skills, ComposioHQ, travisvn, Garry Tan GStack), and star skills (frontend-design, Superpowers, agent-browser, Composio, skill-creator).
- 5. 实用 Skills 清单 — Industry skills organized by 12 development scenarios (code gen/refactor, testing, code review, docs, git, debugging, deploy/CI, database/migration, frontend, API/MCP, project management, security), each with 2–3 examples plus practical advice.
- 6. 怎么选 Skills — Five selection criteria (match scenario, solve a real pain, clear value type, official/high-star first, trial before deciding) and three anti-patterns (following the hype, installing several similar skills, not reading SKILL.md).
- 7. 自己沉淀 Skills 的方法论 — When to distill a Skill; the standard SKILL.md structure; how to write descriptions; progressive layering; a full worked example (spring-rest-controller); personal/project/team skill layers.
- 8. Skills 和团队协作 — Team skill repo organization, versioning, review, a 4-phase adoption path, and five common failure modes.
- 9. Skills 生态的演进趋势 — Standardization deepening, the emergence of a Skills marketplace, and impacts on engineering organization roles.
- 10. 结语 — Skills are a portable, cross-tool, reusable personal engineering asset that compounds long-term.

### 7. 自己沉淀 Skills 的方法论

- Locator: `[[sources/geek-ai-agent/20260922/03-11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#7. 自己沉淀 Skills 的方法论]]`
- Summary: The distillation playbook: when to make a Skill, the SKILL.md standard structure, description-writing techniques, progressive layering, a full spring-rest-controller example, and personal/project/team layers.
