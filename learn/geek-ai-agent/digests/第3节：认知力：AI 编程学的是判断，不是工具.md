# Digest — 第3节：认知力：AI 编程学的是判断，不是工具

## Overview (L1)

- Framing — AI programming is not about learning tools; it is about judgement (判断), experience, and assets. Tools are an entry ticket (入场券) everyone has, not a moat.
- Core five stages — Design, think, decompose, execute, verify (设计/思考/拆解/执行/验证); only execute goes to AI, value lives at both ends.
- What you actually learn — Cognition (认知) over tools, large-project experience and muscle memory (肌肉记忆), long-term competitiveness, and open source as a compounding asset.
- Mindset shift — Move the center of gravity from "doing" (做) to "thinking" (想); clarity (清晰度) replaces diligence as the key variable.
- One-line close — AI programming is not learning a tool, it is learning how to get something done (怎么把一件事做成).

### 学的是什么·01–02：经验与熟练度

- Summary: Learn workflows and fluency, not isolated points; the same workflow is run four times across four projects.
- Key claims: single-point tool skill vs end-to-end workflow from fuzzy requirement to production; point→flow, one→four, watch→do; running the same workflow across OryxOS/When/DifyPro/mq9 builds muscle memory; if not run on the keyboard, it is not learned.
- Learner-relevant: Justifies deliberate repeated practice and the four-project structure.
