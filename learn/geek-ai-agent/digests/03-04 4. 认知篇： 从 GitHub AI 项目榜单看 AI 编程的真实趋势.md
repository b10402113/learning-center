# Digest — 03-04 4. 认知篇： 从 GitHub AI 项目榜单看 AI 编程的真实趋势

## Overview (L1)

- Core thesis — As of 2026 the AI industry is still in stage one (building infrastructure/tools for the AI theme); real-user applications have not reached the top of the leaderboards. Core AI-coding capabilities are converging toward abstractions (MCP, Subagents, SDD); the real engineer gap has moved from "can you use it" to "are you fluent and is your judgement accurate."
- Real data vs hype — IBM+AWS production data shows at most ~30% reduction in development time, far below the 10x marketing talk; "human + AI collaboration" is the current production form. Tools are converging, so engineers' judgement differentiates them.
- Method — Public data (GitHub leaderboards, reports, papers, official data, real production feedback) is presented raw, classified across five dimensions, then turned into labelled judgements; failure data is recorded alongside successes.
- Reader takeaway — Study abstractions (MCP/SDD/Subagents/Skills/Hooks/Permission), practice driving (人+AI 协作) not full autonomy, build infrastructure-layer projects, and calibrate expectations to ~30%.
