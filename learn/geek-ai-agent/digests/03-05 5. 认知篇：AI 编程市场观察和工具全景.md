# Digest — 03-05 5. 认知篇：AI 编程市场观察和工具全景

## Overview (L1)

- Diagnosis — The fatigue of AI-programming learners comes from having no clear cognitive map (认知地图) of the market stage or the tool layers; learning more without anchors produces a vicious cycle of anxiety.
- Market stages — Three stages of understanding: AI as a code tool (1.5x ceiling), learning AI tricks (largest, most anxious group), realizing it is about workflow (the emerging consensus). Most are stuck in the 2→3 transition: consensus exists, method is missing.
- Root cause — "Using AI well" ≠ "knowing more AI tricks"; means-oriented learning has no end, result-oriented problem-solving does; ask which problem a tool solves and whether you currently have it.
- Tool map — The seven-layer architecture from model to methodology, plus three scenarios showing how layers collaborate, and a three-question filter for new tools.
- Takeaway — Deliver not more tools but a method for seeing tools clearly; filter 95% of noise and watch only for real structural changes (MCP, SDD).

### 二、「越学越焦虑」的根源
- Locator: `[[sources/geek-ai-agent/20260922/03-05 5. 认知篇：AI 编程市场观察和工具全景.html#越学越焦虑的根源]]`
- Summary: The root is confusing "knowing more tools" with "using tools well."
- Key claims: means-oriented is endless and gives attention; result-oriented yields capability and assets; novelty has no value unless it creates a capability difference; the trained skill is a judgement — what problem does this tool solve, do I have it, is it better than what I use.
- Learner-relevant: Provides the anti-anxiety judgement habit the learner should internalize.

### 三、市场的真实状态：有共识，缺方法
- Locator: `[[sources/geek-ai-agent/20260922/03-05 5. 认知篇：AI 编程市场观察和工具全景.html#市场真实状态]]`
- Summary: An honest read of the market: most learners want copy-paste usage, a minority evolves fast.
- Key claims: ~80% of AI-programming courses teach tool operations, ~5% teach thinking but users can't apply it; the productive minority are not the most aggressive new-tool chasers but those who run and polish a basic workflow; the gap between "playing with AI" and "getting things done with AI" has widened sharply.
- Learner-relevant: Sets realistic expectations and points to the productive side of the divide.
