# Digest — 03-12 12. 扩展篇：Superpowers 深度介绍

## Overview (L1)

- 先回答你心里的疑问 / 一句话定义 — Superpowers is an agentic skills framework AND a software development methodology that packs "what a serious software engineer should do" into Skills and forcibly embeds them into an AI coding agent's workflow. Key judgment: it is not an SDD tool but an engineering-discipline framework for agents.
- 它要解决什么真实问题 — AI writes code fast but "scattered": no tests, unclear responsibilities, fixing symptoms, silent breakage. This is a workflow problem, not a model problem; discipline is either trained into the model or installed into the workflow, and Superpowers takes the latter path. 200k+ stars and inclusion in Anthropic's plugin marketplace signal a real pain point.
- 核心设计：Skills 框架 — Same SKILL.md mechanism as Claude Code's Skills, but a curated library around engineering discipline. Covers what a Skill looks like, the ~20 built-in core skills (brainstorming, writing-specs, writing-implementation-plans, subagent-driven-development, tdd, debugging-systematically, root-cause-analysis, writing-skills), and automatic activation via description matching.
- 完整工作流：一次跑通 — End-to-end flow: one-sentence request → brainstorming → writing-specs (signed off block by block) → writing-implementation-plans (minutes-sized tasks with exact paths) → subagent execution in isolated worktrees + two-stage review → wrap-up (merge / PR / keep / discard) and worktree cleanup; contrasts with "just let AI write".
- 用 5 组件抽象拆解 — Decomposes along LLM + Tools + Memory + Loop + Environment: it reuses LLM/Tools/Environment and only changes Memory (a large Skills library) and Loop (a forced structured workflow). Portability and decoupling explain its success.
- 跟 Spec-Kit、OpenSpec 的边界 — Spec-Kit and OpenSpec are "tools that do SDD" (0-to-1 and brownfield respectively); Superpowers is "a framework that governs agent discipline" and contains SDD as one Skill among TDD, review, debugging, etc.
- 跨 agent 支持 — Deliberately agent-agnostic (Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Copilot CLI, Factory Droid); best on Claude Code, with reduced effect elsewhere.
- 工程哲学 — Agent as contractor, two-stage review (spec compliance + code quality), true red-green TDD, YAGNI/DRY encoded in Skills, worktree isolation; "slow is fast".
- 怎么开始用 — Install on Claude Code via plugin marketplace; run a first demo; write your own Skill with writing-skills; interface with existing Spec-Kit/OpenSpec workflows.
- 它的局限 — Slow for trivial tasks, over-engineered for small projects, hard to add new Skills to the main repo, and a real learning curve.
- 我的判断 / 总结 — Useful but needs filtering; likely a transitional product, yet it marks AI coding's turn from "fast but scattered" to "slow but steady"; tools pass, engineering methodology does not.
