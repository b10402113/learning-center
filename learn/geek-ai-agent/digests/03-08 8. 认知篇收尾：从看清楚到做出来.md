# Digest — 03-08 8. 认知篇收尾：从看清楚到做出来

## Overview (L1)

- Why preview — The 7 cognition materials (~80k+ characters) are placed in preview, not the bootcamp itself, because the bootcamp body is projects/practice; cognition is the precondition, not the warm-up.
- The 7-part structure — Opening (course design) → essence (01) → personal position (02) → data calibration (03) → external world (04) → capability boundary (05) → methodology landing (06) → cognition closure (07).
- Bootcamp's place — The path splits into tools / driving / value; tools are self-learnable free online, value is personal, and the bootcamp owns the middle "driving" (驾驭) which is muscle memory only obtainable by running real projects.
- Real experience → product — Four projects each deposit a distinct kind of experience (complex system, 0→1, legacy retrofit, external open-source collaboration); product creation is the natural application of that experience.
- Seven closing judgements — A checklist the learner should have grown after the cognition materials.
