# Digest — 08 8. 认知篇收尾：从看清楚到做出来

## Overview (L1)
- 一、7 份材料一起讲了什么 — 认知篇 7 份材料有内部结构：训练营本身→本质→个人→数据校准→外部世界→能力边界→方法论落地→认知收束，是一条完整认知路径，读者读后认知地图完整。
- 二、训练营在这套认知里的位置 — 整条路径分三步：工具（网上免费可自学）、价值（个人化无人能替）、驾驭（中间一步，训练营专注，只能真实项目里练出肌肉记忆）。
- 三、希望：获得 AI 编程的真实经验，最终做出产品 — 训练营希望学员获得真实经验（四个项目各给一段：OryxOS 复杂系统/When 从零到一/DifyPro 老项目改造/mq9 外部协作），再用经验做出产品。
- 四、写在认知篇结束之前 — 七个应长出的判断（AI 编程是旧角色升级版、工具会过时判断会留下、自动化有清晰边界、工作流变但方式是协作、开源是被低估的复利资产、SDD+Harness 是成熟方法论、真实经验最终做出产品）；读完即可放下认知进项目。

### 一、7 份材料一起讲了什么

- Summary: 逐份回顾 7 份材料的定位与内部结构：开篇（训练营设计）、01 本质、02 个人价值、03 数据校准、04 市场与工具全景、05 自动化边界、06 方法论落地、本篇收束。
- Key claims: 认知篇放预习而非训练营，因为训练营本体是项目/训练/经验（练、做、反复跑），预习吃认知、训练营吃实战；7 份材料约 8 万多字是训练营能饱满进行的前提。

### 二、训练营在这套认知里的位置
- Locator: `[[sources/geek-ai-agent/08 8. 认知篇收尾：从看清楚到做出来.html#二、训练营在这套认知里的位置]]`
- Summary: 把 AI 编程能力路径分三步：工具（门槛被互联网拉平，B 站/YouTube/官方文档自学即可）、价值（永远个人化，没人能替）、驾驭（训练营专注的位置）。
- Key claims: 驾驭=用工具把事情做成（让 AI 理解需求/在边界内工作/跑完整工作流/什么时候交棒/跑偏救回/沉淀资产），单纯看教程学不会，是肌肉记忆，只能在真实项目里反复跑；训练营不教工具基础操作、不替价值判断，扎扎实实带练 10 周。
- Learner-relevant: 训练营在能力路径中的清晰定位，支撑"为什么是项目制训练"。

### 三、希望：获得 AI 编程的真实经验，最终做出产品
- Locator: `[[sources/geek-ai-agent/08 8. 认知篇收尾：从看清楚到做出来.html#三、希望：获得 AI 编程的真实经验，最终做出产品]]`
- Summary: 训练营希望学员先获得真实经验再做出产品；四个项目各给一段经验：OryxOS 复杂系统（跨语言/跨自研开源 fork/强安全架构决策）、When 从零到一（模糊需求→spec→SDD 起手→Harness 配置→部署上线）、DifyPro 老项目改造（读十万行陌生代码/delta spec 增量/Permission+Hooks 保不破坏原系统）、mq9 外部协作（提 PR/过 maintainer review/留公开印记）。
- Key claims: 讲得出来和用得出来之间差的就是真实经验，只能靠踩出来；做产品是真实经验自然导向的结果（有经验=把已会的东西用一遍，试错成本被前期消化）；四个项目是经验训练，自己的产品是经验应用。
- Learner-relevant: 四个项目各训练什么经验的权威说明，支撑 ROADMAP 各节点目标。

### 四、写在认知篇结束之前
- Locator: `[[sources/geek-ai-agent/08 8. 认知篇收尾：从看清楚到做出来.html#四、写在认知篇结束之前]]`
- Summary: 真正收尾：读到这里应长出七个判断，不是背而是自己想清楚的，读完后可放下认知进项目。
- Key claims: 七判断——①AI 编程是程序员旧角色的升级版（旧积累仍是核心资产）②工具会过时判断会留下（学工具=短期生产力，学方法论=长期判断力，练驾驭=终身能力）③AI 自动化真实但有清晰边界（不被 10x 忽悠、不miss 30% 真实生产力）④工作流变了但方式是协作非全自动（真正能力是设计协作工作流反复跑）⑤开源是被低估的复利资产（门槛降/含金量升/复利快）⑥SDD+Harness 是当下真正成熟可教的两个方法论（学方法论不在多在精）⑦获得真实经验最终做出产品；认知和实操互相滋养，想不通的可带问题去项目里跑。
- Learner-relevant: 认知篇结业判断清单，作为该主题所有节点的总收束。
