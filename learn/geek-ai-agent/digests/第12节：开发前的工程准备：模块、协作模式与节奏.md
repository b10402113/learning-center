# Digest — 第12节：开发前的工程准备：模块、协作模式与节奏

## Overview (L1)

- From tech doc to code — With OryxOS's research + requirements + technical plan ready, this session defines how to turn the docs into a buildable construction plan: which mode, how to feed docs, how to split tasks, how to collaborate with AI, and at what cadence.
- 9 Maven modules — Five core capabilities (provider, core, memory, tool, web) plus four supporting modules (boot, cli, storage, channel-cli); the ReAct engine (core) is fed by Provider/Memory/Tool and exposed via CLI/Web.
- SDD's three modes — Spec-Kit (AI splits + executes, you write spec and review; greenfield medium-large), OpenSpec (you split, AI executes single tasks, delta-spec; brownfield), lightweight manual (CLAUDE.md + Skill; familiar stacks, small changes).
- OryxOS chooses Spec-Kit — Hits all five fit criteria; increment phases switch to manual prompting, OpenSpec as contrast.
- Collaboration discipline — analyze after each US, re-read constitution on violation, re-read spec/plan on context loss, git commit per user story.
- 4-week cadence — Week 1 LLM + ReAct, Week 2 Memory + Tool, Week 3 Web Service, Week 4 multi-Agent + wrap-up; each week ~3 hours with a demo.
