# Digest — 13 13. 扩展篇：Hermes Agent 深度介绍

## Overview (L1)
- 引言：为什么要了解 Hermes Agent — 个人持久化 Agent 流派的代表（与 IDE 内嵌 coding agent、chatbot 包装层并列），设计哲学独特、工程实现完整（v0.14.0、134k+ star）、覆盖场景全。
- Hermes Agent 是什么 — Nous Research 的开源、自我改进个人 AI Agent，"The agent that grows with you"；关键属性与"它不是什么"的边界；项目背景。
- Hermes Agent 解决什么问题 — 五大痛点（无记忆、不学习、与真实生活脱节、不能持续做事、绑设备）及针对性设计。
- 技术原理 — 三层架构、核心 AIAgent 引擎、prompt_builder、MEMORY.md + USER.md 记忆系统、autonomous skill creation、closed learning loop、Subagent 委托、安全机制。
- 能用 Hermes Agent 做什么 — 个人助手类、自动化工作流（GitHub PR review 等）、跨平台协作、开发者工作流、Nous Research 自己的用法。
- 怎么开始用 Hermes Agent — 安装、首次配置、三种运行模式、第一个 demo（PR review）、接入消息平台、写 skill、进阶 subagent 和 MCP、持续使用建议。
- 总结 — 核心定位、适合谁、我的判断（个人持久化 Agent 路上做得最深，Python 生态部署门槛高）。

### problems-it-solves
- Locator: `[[sources/geek-ai-agent/13 13. 扩展篇：Hermes Agent 深度介绍.html#Hermes Agent 解决什么问题]]`
- Summary: 列五大痛点（无记忆、不学习、脱节、不能持续做事、绑设备）并逐个对应设计：agent-curated memory（MEMORY.md + USER.md）、autonomous skill creation、multi-platform messaging gateway（20+ 平台）、cron scheduler、server-resident（5 美元 VPS / serverless hibernate）。
- Key claims: 记忆问题不是 context window 大小能解决的；与 ChatGPT 网页版、Claude Desktop、Cursor 的差异是定位差异——独立于任何设备和平台的长期伙伴。
- Learner-relevant: 理解"个人持久化 Agent"解决的真实痛点与设计思路。

### technical-principles
- Locator: `[[sources/geek-ai-agent/13 13. 扩展篇：Hermes Agent 深度介绍.html#技术原理]]`
- Summary: 拆解技术原理：三层架构（用户接入层/核心引擎层/执行后端层）；核心 AIAgent 类（run_agent.py）支持三种 API 模式（Anthropic 风格、OpenAI Chat Completions、OpenAI Responses），ProviderTransport ABC 抽象；prompt_builder.py 动态拼接 system prompt（SOUL.md 人格、MEMORY.md + USER.md、skills、AGENTS.md + .hermes.md、tool-use guidance、model-specific instructions）；记忆系统（MEMORY.md 存事实、USER.md 存画像经 Honcho dialectic 建模、FTS5 跨会话搜索）；技能系统（autonomous skill creation、self-improvement during use、hermes curator 于 v0.13.0 引入、兼容 agentskills.io 标准）；closed learning loop；Subagent 委托（isolated subagents、zero-context-cost pipelines、Python RPC）；安全机制（多 execution backend、Dangerous command approval、MCP OAuth 2.1 PKCE、OSV malware scanning、Webhook HMAC）。
- Key claims: 每个 Hermes 实例的 system prompt 都不一样，因为每个人的 MEMORY/USER/SKILLS 不同；普通 LLM-wrapper 能力是 LLM 给的，Hermes 能力是 LLM 加自己积累的 skill 库；5+ tool calls 的复杂任务自动写 skill。
- Learner-relevant: 提供个人持久化 Agent 的完整技术实现参考，支撑记忆/技能/学习循环类元素。

### what-you-can-do
- Locator: `[[sources/geek-ai-agent/13 13. 扩展篇：Hermes Agent 深度介绍.html#能用 Hermes Agent 做什么]]`
- Summary: 四类典型应用：个人助手类（消息聚合、日程、学习助手、写作助手）；自动化工作流（GitHub PR Review Agent、定时 dashboard、自动化测试 agent、新闻聚合）；跨平台协作（跨平台对话延续、voice memo transcription、家庭群组助手）；开发者工作流（pre-commit review、调试助手、多 Agent 编排、IDE 集成）。
- Key claims: Nous Research 自己用 Hermes 做 PR review 自动化、测试 agent、跨平台沟通，且 Hermes 可导出训练轨迹用于 SFT 数据生成和 RL 微调来训练 Hermes 系列模型——产生数据反过来训练 LLM 形成相互增强闭环。
- Learner-relevant: 具象化 Hermes 能力范围，支撑"个人 Agent 应用场景"认知。

### getting-started
- Locator: `[[sources/geek-ai-agent/13 13. 扩展篇：Hermes Agent 深度介绍.html#怎么开始用 Hermes Agent]]`
- Summary: 实操指引：安装（Linux/macOS curl 脚本、Windows WSL2、Android Termux、PyPI pip install hermes-agent、源码 setup-hermes.sh；依赖 uv、Python 3.11、Node.js、ripgrep、ffmpeg；Hermes Home 默认 ~/.hermes/）；首次配置（hermes setup wizard 选 Provider、fallback、平台、OpenClaw 迁移）；三种运行模式（CLI/TUI、Messaging Gateway、OpenAI 兼容 API Server，可同时跑）；第一个 demo（GitHub PR review agent：gh CLI + Remember 写 MEMORY + 手动 review + 定义 skill + cron 定时 + webhook）；接入消息平台（Telegram @BotFather 示例）；写 skill（自动创建或按标准格式手写：# Skill、## When to Use、## Prerequisites、## How to Run、## Quick Reference、## Procedure、## Pitfalls、## Verification）；进阶（delegate_task subagent、MCP 集成）；持续使用建议（VPS 24 小时、接最常用平台、常聊重要决策、复杂任务多交给它、定期跑 curator、定 cron）。
- Key claims: 三种运行模式共享同一份记忆/技能/配置；cron 命令示例 hermes cron create "0 */2 * * *" "Check for new open PRs..."; 接入新平台不用改 Hermes 代码；Hermes 价值是复利型，越用越能干。
- Learner-relevant: 提供从零上手的完整路径与关键命令形态。
