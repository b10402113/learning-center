# Digest — 03-03 3. 认知篇： AI 编程时代程序员的个人价值

## Overview (L1)

- The shift — A programmer's "personal value" is being redefined from "what I can do inside a company" to "what I can accumulate as an individual"; those who see it capture the biggest dividend.
- What no longer holds — Tool proficiency, tech-stack depth, years of experience, big-company background are no longer individually a foundation; they move from deciding your price to deciding your floor.
- Three criteria — A true foundation must be AI-hard-to-replicate, unique to you, and continuously growing (复利).
- Three foundations — Workflow-design ability, deep engineering judgement, compounding-asset accumulation ability.
- Open source — The purest compounding asset and most underrated lever; AI lowers the barrier, raises its value, and speeds compounding.

### 二、判断立身之本的三条标准
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#判断立身之本的三条标准]]`
- Summary: Filter: AI-hard-to-replicate, unique to you, continuously growing.
- Key claims: judgement/decision/trade-off/sign-off are hard for AI because their inputs are real business context and tacit history; uniqueness means your specific path and judgement style; growth means assets that compound rather than depreciate; only all three together is a true foundation (examples of partial failures: past-tense assets, entry tickets, narrow moats).
- Learner-relevant: Gives a reusable self-assessment rubric for any claimed skill.

### 三、工作流设计能力
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#工作流设计能力]]`
- Summary: Designing a human+AI workflow that carries an idea from fuzzy requirement to production.
- Key claims: passes all three criteria; the stronger the tool, the greater the value of workflow design; transfers across stacks (understand/constrain/verify/deposit); why SDD tools and Skills repos underdeliver — individuals differ, so tools must return to the person.
- Learner-relevant: Defines foundation #1 and its transferability.

### 四、深度工程判断力
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#深度工程判断力]]`
- Summary: Making correct technical calls at key nodes (etcd vs Consul, ship or not, AI-write or hand-write).
- Key claims: judgement ≠ knowledge; depends on specific context and scars, so AI can't sign off for you; AI amplifies judgement's value because faster execution makes "doing the right thing" the bottleneck and wrong direction has larger sunk cost; judgement carries personal style and grows with projects.
- Learner-relevant: Defines foundation #2 and why it appreciates in AI era.

### 五、复利资产积累能力
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#复利资产积累能力]]`
- Summary: Deliberately distilling reusable, accumulating assets after each project.
- Key claims: assets include personal CLAUDE.md templates, Skills libraries, Slash Commands/Hooks, scaffolds, articles, notes, decision records, open-source contributions; they do not appear automatically — doing projects ≠ accumulating assets; AI can accelerate deposition several-fold; four asset classes: local, semi-public, public, identity — the best is public+identity = open source.
- Learner-relevant: Defines foundation #3 and its hidden AI-era accelerator.

### 六、复利资产的最佳载体：开源
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#复利资产的最佳载体开源]]`
- Summary: Open source reframed as "doing your existing work in public," with four escalating returns.
- Key claims: open source's essence is public work, not extra work; it needs serious people, not geniuses; four return layers — capability (free high-quality code review), identity (public verifiable resume), network (cross-company circle), compounding (value grows over time); the last three cannot be obtained inside a company.
- Learner-relevant: Gives the concrete mechanism and payoff model for open source.

### 七、AI 时代，开源红利在放大
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#AI时代开源红利在放大]]`
- Summary: Three amplifying dividends plus faster elite recognition.
- Key claims: barrier drops (AI reads large projects, crosses languages, drafts PRs); value rises because verified contributions are scarce when "writing code" is devalued; compounding speeds up (PR cycle weeks→days); maintainers quickly identify real contributors amid AI noise.
- Learner-relevant: Motivates a concrete AI-era open-source strategy.

### 八、落到日常怎么做
- Locator: `[[sources/geek-ai-agent/20260922/03-03 3. 认知篇： AI 编程时代程序员的个人价值.html#落到日常怎么做]]`
- Summary: Three foundations are built simultaneously in one project; four concrete daily actions plus counterexamples.
- Key claims: run the full workflow every project without shortcuts; record the "why" of every key decision and retrospect; ask "what did I sediment?" at project end (criterion: next start is higher); pick one open-source project and start with docs/tests. Counterexamples: "I can use Spec-Kit" is tool skill, "learned framework source" is knowledge, "did ten projects" without deposition is labor.
- Learner-relevant: Converts the value theory into daily practice and clear anti-patterns.
