# Digest — 03-13 13. 扩展篇：Hermes Agent 深度介绍

## Overview (L1)

- 引言：为什么要了解 Hermes Agent — Positions Hermes in the 2026 AI-agent landscape (IDE-embedded coding agents, chatbot wrappers, persistent personal agents). Hermes is the "persistent personal agent" representative: closed learning loop (闭合学习循环), agent-curated memory (Agent 自己管理记忆), autonomous skill creation (自主创建技能); mature at v0.14.0 with 134k+ star.
- Hermes Agent 是什么 — Nous Research's open-source, self-improving personal AI agent ("The agent that grows with you"): MIT-licensed, persistent, multi-platform (CLI + 20+ messaging platforms + IDE via ACP), multi-model, six execution backends, subagent parallelism. Explicitly not a coding copilot, chatbot wrapper, IDE plugin, cloud service, or enterprise Agent OS.
- Hermes Agent 解决什么问题 — Five real pain points (no memory, no learning, disconnected from real life, cannot run continuously, tied to a laptop) and Hermes's targeted designs: agent-curated MEMORY.md/USER.md, autonomous skill creation, multi-platform gateway, built-in cron scheduler, and server-resident design.
- 技术原理 — Three-layer architecture (access layer, core engine, execution backend); the AIAgent orchestration engine with three API modes and a ProviderTransport abstraction; dynamic prompt assembly; the MEMORY.md/USER.md + FTS5 memory system; the skill system; the closed learning loop; subagents; and security mechanisms.
- 能用 Hermes Agent 做什么 — Concrete use cases: personal assistant (message digest, schedule, learning, writing), automated workflows (GitHub PR review, scheduled dashboards, testing, news aggregation), cross-platform collaboration, developer workflows, and how Nous Research itself uses it.
- 怎么开始用 Hermes Agent — Installation options, first-time setup, three run modes (CLI/TUI, messaging gateway, API server), a PR-review demo, connecting messaging platforms, writing skills, subagents/MCP, and habits for sustained use.
- 总结 — Recaps the positioning, core innovation (closed learning loop), who it suits, and honest limitations (Python ecosystem, personal-first philosophy, learning curve).

### 技术原理

- Locator: `[[sources/geek-ai-agent/20260922/03-13 13. 扩展篇：Hermes Agent 深度介绍.html#技术原理]]`
- Summary: Explains the architecture, AIAgent engine, prompt construction, memory, skills, learning loop, subagents, and security.
- Key claims: Three layers are access (CLI/TUI, gateway, ACP IDE, cron, OpenAI-compatible API), core engine (memory, skills, learning loop, scheduling, safety, MCP, model router, subagent orchestration), and execution backend; AIAgent in run_agent.py supports Anthropic, OpenAI Chat Completions, and OpenAI Responses modes via ProviderTransport ABC; prompts are dynamically assembled from SOUL.md, MEMORY.md/USER.md, skills, context files, tool guidance, and model instructions; memory uses agent-curated MEMORY.md + USER.md with FTS5 cross-session search and Honcho dialectic user modeling; skills have autonomous creation, self-improvement during use, and an autonomous curator; the closed learning loop is what distinguishes it from a plain LLM wrapper; subagents run isolated with zero-context-cost pipelines; security includes backend isolation, native approve buttons, MCP OAuth 2.1 PKCE, OSV malware scanning, and webhook HMAC signing.
- Learner-relevant: The core technical reference for "how an agent keeps learning" and how a personal agent OS is engineered.

### 怎么开始用 Hermes Agent

- Summary: Practical onboarding: install, setup, run modes, PR-review demo, messaging platforms, skills, subagents/MCP, and sustained-use habits.
