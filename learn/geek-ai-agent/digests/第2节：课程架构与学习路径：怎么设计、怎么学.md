# Digest — 第2节：课程架构与学习路径：怎么设计、怎么学

## Overview (L1)

- Three-word design — 认知 (cognition), 驾驭 (mastery), 进阶 (advancement): a progression, not parallel layers; without cognition, mastery is copycatting; without mastery, advancement is empty talk.
- Cognition layer — See clearly what AI programming is: essence, industry status, tool system, evolution direction, and your position; the biggest risk is lacking judgment, not tools.
- Mastery layer — 80% of content: four real projects (OryxOS, When, DifyPro, mq9) run the same workflow four times across four scenario types.
- Advancement layer — Open-source contribution + long-term co-building on top of mastery; a compounding asset.
- Teaching approach — A general-then-specific structure: cognition in the opening/14 PDFs, mastery in the projects, advancement at the end; two principles (projects lead methodology; every project follows the same rhythm).
- Learning guide — cognition requires previewing; mastery requires doing; three study intensities all work; closing "少年依旧" mindset.

### cognition-layer
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#cognition-layer]]`
- Summary: Cognition covers five questions — the essence of AI programming, industry status + evolution, the tool system, where it's heading, and your position as an engineer.
- Key claims: the typical anxiety swings (AI wrote silly code → "AI is useless"; AI made an impressive demo → "it will replace us"; too many tools → don't know what to learn) all stem from an unbuilt cognition layer.
- Learner-relevant: Diagnoses the root of tool anxiety and frames the first layer.

### mastery-layer
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#mastery-layer]]`
- Summary: Four real projects across four scenarios: OryxOS (AI Agent OS, 4 weeks, from 0→1 or secondary development), When (distributed delay component, 3 weeks, gRPC/etcd/time wheel), DifyPro (Dify secondary development, 2 weeks, AI collaboration in a large unfamiliar codebase), mq9 (Rust open-source project, 1 week, contribute a PR).
- Key claims: the four projects live in the oryx-labs GitHub space for long-term maintenance; two scarce experiences from When (AI writing distributed systems + large distributed-system project experience).
- Learner-relevant: Shows the concrete project mix and what each trains.

### advancement-layer
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#advancement-layer]]`
- Summary: Advancement is mastery's natural extension: (1) compound review notes, (2) organize a personal tool library, (3) submit an open-source PR.
- Key claims: open source is still a programmer's best calling card for jobs and promotions; the first PR is scary but opens a door.
- Learner-relevant: Turns project work into durable personal assets.

### teaching-approach
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#teaching-approach]]`
- Summary: A general-then-specific structure: the general part is cognition (opening + 14 PDFs); the specific part is mastery across four projects; the advancement part is open source + long-term co-building.
- Key claims: two principles — projects string methodology together (not the reverse), and every project runs the same rhythm; SDD, Skills, Subagents, Hooks, Spec Coding are scattered naturally across the projects.
- Learner-relevant: Explains the pedagogical logic so content that looks "random" makes sense.

### learning-guide
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#learning-guide]]`
- Summary: Cognition-layer preview materials come in three types (cognition, extension, project); mastery-layer requires 100% hands-on; the project-end self-check is "can you explain what you did and why."
- Key claims: read preview materials and live-stream density rises greatly; if not, you stay passive and learn nothing; operations get cheaper while judgment gets more valuable.
- Learner-relevant: The self-check standard and study method.

### three-intensities
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#three-intensities]]`
- Summary: Three study intensities: basic (read 14 PDFs + run the core tasks of the four projects → run AI coding smoothly in enterprise projects); advanced (deepen one project, compound notes and a personal tool library); complete (finish mq9, submit a PR, join long-term co-building).
- Key claims: all three paths are valid; less investment is not shameful, more isn't pressured.
- Learner-relevant: Lets the learner choose a realistic commitment level.

### closing
- Locator: `[[sources/geek-ai-agent/20260922/第2节：课程架构与学习路径：怎么设计、怎么学.pdf#closing]]`
- Summary: Tools keep changing; those who survive are curious, willing to act, and willing to push themselves forward; AI amplifies who you already are.
- Key claims: the mindset to cultivate is reading the 14 pre-materials carefully, immediately trying new concepts, diving into unfamiliar code, and asking "if I redid it, what would I change"; the author's word for this state is 少年依旧 ("still youthful").
- Learner-relevant: Motivates the mental posture that makes the course work.
