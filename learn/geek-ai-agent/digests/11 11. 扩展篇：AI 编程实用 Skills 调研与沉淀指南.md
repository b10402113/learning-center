# Digest — 11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南

## Overview (L1)
- 1. 为什么单独写这篇 — 针对 Skills 的三个困惑（是什么、业界用什么、怎么沉淀），前半讲业界全景与实用清单、后半讲沉淀方法论。
- 2. Skills 是什么：从程序员视角理解 — Skill = 流程固化 + 工具调用（SOP + 工具箱），与 MCP/Subagents/Plugins/Commands 的关系，渐进式加载与跨工具兼容。
- 3. Skills 的两类核心价值 — Capability Uplift（让 AI 学会做没做过的事）与 Encoded Preference（让 AI 按你的方式做事），以及两者混搭。
- 4. 业界 Skills 全景：调研结果 — Anthropic 官方 Skills、社区高 star 库（obra/superpowers、claude-skills、awesome 清单、GStack）、单个明星 Skill 赏析。
- 5. 实用 Skills 清单：按开发场景分类 — 12 个场景（代码生成与重构、测试、code review、文档、git、调试、部署、数据库、前端设计、API 集成与 MCP、项目管理、安全审查）各配代表 Skill。
- 6. 怎么选 Skills：判断装不装的心法 — 五个判断标准加三种反模式。
- 7. 自己沉淀 Skills 的方法论 — 何时沉淀、SKILL.md 标准结构、写 description 技巧、渐进式分层、真实例子全流程、个人/项目/团队三种 Skill。
- 8. Skills 和团队协作 — 团队仓库组织、版本化、评审迭代、起步路径、失败模式。
- 9. Skills 生态的演进趋势 — 标准化深化、Skills 市场、工程组织变化。
- 10. 结语：Skills 作为程序员个人资产 — Skills 是可文本化、可移植、跨工具、可复用的工程资产。

### skills-vs-adjacent-concepts
- Locator: `[[sources/geek-ai-agent/11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#2.2 Skills 和 MCP、Subagents、Plugins、Commands 的关系]]`
- Summary: 理清五个相邻概念：MCP 是工具调用协议（工具供给侧）、Skill 是指令包（行为标准）、Subagent 是独立 AI 实例（任务分发）、Plugin 是组合包（打包分发）、Command 是显式入口。
- Key claims: 想固化流程用 Skill，接入外部系统用 MCP，并行处理用 Subagent，打包分发用 Plugin；Commands 是 Skills 的一种特殊触发方式。

### progressive-disclosure

### two-core-values
- Locator: `[[sources/geek-ai-agent/11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#3. Skills 的两类核心价值]]`
- Summary: Capability Uplift（能力提升：让 AI 学会做没做过的事，配套外部工具或专门知识，如 PDF 处理、gws Workspace、Firecrawl）与 Encoded Preference（偏好编码：让 AI 按你的方式做事，纯文字指令，如 frontend-design、DHH 风格、React Best Practices）。
- Key claims: Capability Uplift 判断标准是"装上后能做之前做不了的事"；Encoded Preference 判断标准是"做事方式变了但能做的事没变"；两类可混搭叠加。
- Learner-relevant: 提供 Skill 分类判断的两轴框架，支撑选 Skill 与写 Skill 的准心。

### practical-skill-catalog
- Locator: `[[sources/geek-ai-agent/11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#5. 实用 Skills 清单：按开发场景分类]]`
- Summary: 按 12 个开发场景整理代表 Skill：代码生成与重构（software-architecture、DHH 风格 Ruby、subagent-driven-development）；测试（Build (TDD)、webapp-testing、JUnit Test Generator）；code review（code-review、GStack code review、security-audit）；文档（Document Collaboration、API Docs Generator、Javadoc Generator、Changelog Generator）；git（commit-message-generator、branch-manager、git-workflow）；调试（Debug、stack-trace-analyzer、log-analyzer）；部署（Dockerfile、Kubernetes yaml、GitHub Actions、aws-skills）；数据库（db-migrator、schema-design、database-designer）；前端设计（frontend-design、React Best Practices、Tailwind Component、brand-guidelines）；API 集成与 MCP（mcp-builder、API Builder、GraphQL Schema Designer、Composio）；项目管理（hierarchical-planner、brainstorm、spec-driven-development）；安全审查（security-audit、OWASP、Secret Scanner、Penetration Testing）。

### how-to-choose-skills
- Locator: `[[sources/geek-ai-agent/11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#6. 怎么选 Skills：判断装不装的心法]]`
- Summary: 五个判断标准（匹配当前工作场景、解决真实痛点、价值类型清楚、官方或高 star 优先、试用再决定）加三种反模式（跟风装明星 Skill、装一堆类似 Skill 对比、不读 SKILL.md 就用）。
- Key claims: Skill 不是装得越多越好，是"当下用得上"；同类 Skill 选一个最匹配的，AI 不会自动择优；SKILL.md 是文本文件，装后花 5 分钟读一遍。
- Learner-relevant: 提供避免被清单牵着走的决策框架与避坑清单。

### how-to-accumulate-skills
- Locator: `[[sources/geek-ai-agent/11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#7. 自己沉淀 Skills 的方法论]]`
- Summary: 沉淀方法论核心：何时沉淀（同一操作做到第三次、流程可重复、AI 反复做错、跨项目复用、团队多人受益）；SKILL.md 标准结构（frontmatter name+description、目的/触发场景/步骤/约束/示例）；description 关键技巧（讲触发条件、列关键词、写明用/不用、50-200 字）；内容渐进式分层（SKILL.md 主体/references/scripts 与 examples）；一个 Spring Boot REST controller Skill 从需求到 SKILL.md 的真实全流程；个人（~/.claude/skills/）、项目（.claude/skills/）、团队三种 Skill 差别。
- Key claims: "第三次"是沉淀 Skill 的合适判断点；description 决定 AI 能否准确触发，是最重要的字段；渐进式分层让 SKILL.md 主体保持简洁；个人/项目/团队三层级按优先级合并，新发现模式先思考放哪个层级。
- Learner-relevant: 提供从日常问题到工程资产的完整转化路径，支撑自建 Skill 实操。

### skills-and-team-collaboration
- Locator: `[[sources/geek-ai-agent/11 11. 扩展篇：AI 编程实用 Skills 调研与沉淀指南.html#8. Skills 和团队协作]]`
- Summary: 团队 Skills 实践：仓库组织（单仓库/按职能拆/项目自带）、版本化（SKILL.md 改走 PR、依赖工具版本同步、DEPRECATED 标记、changelog）、评审迭代（四看点、每月 review）、起步路径（1-2 人尝鲜→单项目全员→团队仓库→社区贡献）、失败模式（库膨胀、写成操作手册、与 CLAUDE.md 重复、不维护、取代思考）。
- Key claims: SKILL.md 修改走 PR，因为影响所有使用者的 AI 行为；理想 SKILL.md 长度在几千字符；Skill 与 CLAUDE.md 职责要清晰（通用约束 vs 特定场景流程）；每个 Skill 指定 owner。
- Learner-relevant: 提供团队级 Skills 落地的组织实践与避坑经验。
