# Digest — 07-09 第 2 周作业

## Overview (L1)

- 必做作业（Week 2） — Six mandatory tasks: run OryxOS locally and configure the first agent with a notification; open the first PR to oryx-labs/oryxos; study Hermes Agent docs, run it, and compare OryxOS vs Hermes (function/architecture/enterprise value); use Spec-Kit to decompose the first task from the four technical docs; write four documents (industry research, requirements, technical plan, programming guide) with AI; and star the two course open-source projects (oryxos, robustmq).
- 挑战题 — Find and fix a bug in the OryxOS core code and open an issue plus fix; or become a long-term maintainer of OryxOS.
- 作业说明 — Tasks 3–5 can be submitted as an online document to the TA; grading notification via the "极客时间训练营" WeChat account; learners are encouraged to share their thinking in the group chat.
