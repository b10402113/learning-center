# Digest — 03 3. 认知篇： AI 编程时代程序员的个人价值

## Overview (L1)
- 一、什么不再是立身之本 — 工具熟练度（2026 年已是入场券/智力平权）、技术栈深度（AI 压缩学习周期）、工作年限、大厂背景都从"决定上限"变"决定下限"。
- 二、判断立身之本的三条标准 — AI 难以复制、你独有、能持续生长；三条同时满足才是立身之本，缺一条都会贬值。
- 三、工作流设计能力 — 能设计"人和 AI 协作把一件事从模糊需求跑到生产上线"的系统；工具越强其价值越大，跨场景迁移性强。
- 四、深度工程判断力 — 关键节点做对的技术判断；AI 让"做事"变快而"做对的事"成瓶颈；判断带个人风格且能持续生长。
- 五、复利资产积累能力 — 每项目沉淀可复用、可累积、能持续受益的资产；AI 极大加速沉淀，但资产不会自动产生，分本地/半公开/公开/身份四类。
- 六、复利资产的最佳载体：开源 — 开源是"在公开环境下做事"；能力、身份、网络、复利四层收益，后三层公司给不了。
- 七、AI 时代，开源红利在放大 — 门槛大幅降低、含金量提升（被 review 认证的真）、复利速度加快、精英被更快识别。
- 八、落到日常怎么做 — 跑完整工作流、记录关键决策、主动问"沉淀了什么"、主动挑一个开源项目；三条立身之本在同一个项目里同时建立。

### 一、什么不再是立身之本
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#一、什么不再是立身之本]]`
- Summary: 先破除旧认知地图：工具熟练度、技术栈深度、工作年限、大厂背景四样东西的溢价都在缩水。
- Key claims: 这些能力没消失，但从"决定你值多少钱"变成"决定你的下限"；决定上限的是另一种能力。
- Learner-relevant: 重构"程序员价值"的衡量坐标。

### 1. 工具熟练度不再是立身之本
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#1. 工具熟练度不再是立身之本]]`
- Summary: 熟练工具在 2024 年还成立、2026 年已不成立，业界称"智力平权"。
- Key claims: 工具迭代快于人学习；真正的壁垒是"无论工具怎么换都能跑出好结果"的能力，依附在人身上。
- Learner-relevant: 区分"工具熟练度"与"跨工具能力"。

### 2. 技术栈深度也不再是立身之本
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#2. 技术栈深度也不再是立身之本]]`
- Summary: "精通 Java/Rust/Kubernetes"的溢价缩水，AI 几小时可跨进新技术栈。
- Key claims: 值钱的是"在这门技术上踩过坑、做过判断、形成的工程直觉"；深度不再稀缺，沉淀在深度里的判断才稀缺。
- Learner-relevant: 把投资从"学技术栈"转向"攒判断"。

### 3. 工作年限也不再是立身之本
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#3. 工作年限也不再是立身之本]]`
- Summary: "做了十年开发"的溢价变小，AI 让经验获取变快。
- Key claims: 用 AI 用熟的三年工程师可输出过去八年工程师的产出；重要的不是做多少年，是这些年沉淀了什么。
- Learner-relevant: 用"沉淀质量"替代"年限"衡量经验。

### 4. 大厂背景也变得不一样了
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#4. 大厂背景也变得不一样了]]`
- Summary: 大厂背景的真实价值是"见过什么、做过什么、积累了什么判断"，而这类判断在 AI 时代传递加快。
- Key claims: 不在大厂也可通过开源、技术分享、和 AI 高质量对话获得类似视野；大厂背景是基础不是终点。
- Learner-relevant: 把"公司光环"重新拆解为可积累的判断与视野。

### 二、判断立身之本的三条标准
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#二、判断立身之本的三条标准]]`
- Summary: 给出筛选立身之本的三个标准：AI 难以复制、你独有、能持续生长，并说明缺一条的贬值情形。
- Key claims: 三条都满足的工程师能力是：工作流设计能力、深度工程判断力、复利资产积累能力。
- Learner-relevant: 作为评价"该练什么"的过滤器。

### 三、工作流设计能力
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#三、工作流设计能力]]`
- Summary: 第一个立身之本：设计人和 AI 协作的工作流系统（产出物、人做/AI 做、反馈循环、救场、沉淀）。
- Key claims: 三条标准全过（AI 不能给自己设计工作流/带个人风格/越做越精炼）；工具越强工作流设计价值越大；底层模式"理解、约束、验证、沉淀"跨场景稳定。
- Learner-relevant: 支撑"工作流设计是核心训练目标"的认知。

### 四、深度工程判断力
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#四、深度工程判断力]]`
- Summary: 第二个立身之本：在关键节点做对的技术判断（选型、能不能上生产、bug 是表象还是底层、该不该让 AI 写）。
- Key claims: 判断来自踩坑与底层理解；本质是"不完美信息下做最优决策"；AI 让做事变快而"做对的事"成瓶颈，判断价值被放大；判断风格是个人指纹且持续生长。
- Learner-relevant: 强调拍板与取舍是人的核心职责。

### 五、复利资产积累能力
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#五、复利资产积累能力]]`
- Summary: 第三个立身之本：每项目后沉淀可复用资产（CLAUDE.md、Skills、Slash Commands、Hooks 配置、脚手架、文章/笔记/开源贡献）。
- Key claims: 资产不会自动产生，是最大的认知盲区；AI 能加速沉淀（提炼模式/整理笔记/生成 Skill 草稿）；四类资产=本地/半公开/公开/身份，最有价值的是"公开+身份"合体的开源贡献。
- Learner-relevant: 支撑"复利资产"概念，为开源主张做铺垫。

### 六、复利资产的最佳载体：开源
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#六、复利资产的最佳载体：开源]]`
- Summary: 开源是"在公开环境下做事"，破除"义务劳动/必须大牛/没回报"三个误解。
- Key claims: 开源最缺认真做事的人不是大牛；收益分四层——能力（高质量 review 训练）、身份（公开可验证简历）、网络（跨公司/行业/时间的圈子）、复利（随时间增值）；后三层公司给不了。
- Learner-relevant: 开源作为个人价值载体的完整论证，支撑 mq9 与进阶层。

### 七、AI 时代，开源红利在放大
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#七、AI 时代，开源红利在放大]]`
- Summary: AI 编程没有让开源贬值反而放大红利：门槛降低、含金量提升、复利加快、精英更快被识别。
- Key claims: 门槛降低（AI 帮读架构/跨语言/提 PR）；含金量提升（被 maintainer review 认证的"真"在 AI 时代稀缺）；复利加快（两三年达以前五年的积累）；在噪音时代真做事的工程师更易被识别。
- Learner-relevant: 强化"AI 时代做开源"的决策依据。

### 八、落到日常怎么做
- Locator: `[[sources/geek-ai-agent/03 3. 认知篇： AI 编程时代程序员的个人价值.html#八、落到日常怎么做]]`
- Summary: 三条立身之本在同一项目里同时建立，落到四个具体动作与反例，并诚实说明这条路不适合所有人。
- Key claims: 动作=每个项目跑完整工作流、每个关键决策问"为什么"并记录、每个项目结束问"沉淀了什么"、主动挑一个开源项目；反例（"会用 Spec-Kit"是工具熟练度不是工作流设计等）；开源适合特定性格，不做也是好工程师，但少一份跨公司/行业/时间的资产。
- Learner-relevant: 把立身之本转化为可执行日常动作与取舍。
