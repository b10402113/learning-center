# MEMORY — pro-python

## Goal
Get hired as a Python developer — master modern Python idioms (type hints, dataclasses, async, FastAPI) so I can pass interviews and contribute on day one.

## Why
I'm already in a Python role but feel underqualified. I want to level up to stay competitive — this is about career stability and growth, not just learning for fun.

## Prior experience
- Intermediate Python (1-3 years) — I've built and maintained Python services at work
- Mostly older patterns: no type hints, no async, no modern tooling
- I read code from an existing Django/Flask app to learn — I'm not the primary author

## Anchors
- I read a Django/Flask app codebase daily — type hints, FastAPI, and modern patterns will help me understand what I'm reading
- I have a Python role already — these lessons connect to my real job, not a hypothetical future job
- I learn by example — show me the code first, then explain why it works

## Habits & constraints
- Weekday evenings — focused but bounded time blocks
- Need material that respects limited time — no filler, get to the point

## Knowledge type
Mostly declarative — I need mental models and vocabulary to read code and make architectural decisions, not just muscle memory for writing code.

## How to teach me
Example-first: show the code, then explain why it works. I learn by reading code to understand patterns, so worked examples with clear explanations of the "why" stick best. Concept-heavy or theory-first approaches bore me.
