Truthiness — falsy values and truthiness shortcuts

學習目標：說出 Python 的 falsy 值清單、用 bool() 驗證真值，並寫出 if due_date: 這類比 is None 更簡潔的判斷。

Why this step matters

Python 的 if 不只接受 True/False——任何值放進條件裡都會被評估成真或假。這叫 truthiness（真值判斷）。Pythonic 的程式碼大量依賴它：if not items:、if user:……讀不懂 truthiness，就讀不懂別人寫的 Python。

Truthy 與 falsy：一個值不一定是布林，也能被當布林用

「Truthy」不是一個型別，是一種評估結果：任何值放進布林語境（if、while、not……）時，Python 會把它當成真或假。好消息是 falsy 清單很短，把它背下來，其餘全部都是 truthy：

Falsy 值例子
False布林假值本身
None「沒有值」的哨兵值
0整數零（0.0 同理）
""空字串
[]空 list
{}空 dict
set()空集合

反向記法更好記：「零、空、沒有」都是假，其他一切都是真。任何非零數字、任何有內容的字串、任何有元素的容器，放進 if 都是 True。

bool()：真值檢測器

想知道某個值會被評估成真還是假，不用背——直接問 Python。內建函式 bool() 接受任何值，回傳它的布林評估結果：

bool(None)       # False
bool(0)          # False
bool("")         # False
bool([])         # False
bool({})         # False

bool(1)          # True
bool(-3)         # True（非零就是真，負數也算）
bool("false")    # True（非空字串，內容是什麼不重要）
bool([0])        # True（list 有元素，哪怕元素本身是 falsy）

特別注意最後兩個："false" 是非空字串所以是 truthy；[0] 是有元素的 list 所以也是 truthy。Truthiness 看的是容器本身空不空，不看內容。

回到 is_overdue：truthiness 捷徑

上一課 is_overdue 的第一個判斷是：

if due_date is None:
    return False

因為 None 是 falsy，這段可以改寫成：

if not due_date:
    return False

due_date 是 None 時，not due_date 就是 not None 的評估，結果為 True，進入分支。兩種寫法在這個情境下等價，但第二種更簡潔，也是你在真實 Python codebase 裡最常看到的格式。反過來，if due_date: 等價於「有到期日」。

冷知識：布林其實是整數

Python 的 bool 在底層繼承自 int：True 就是 1、False 就是 0。所以你可以做出這種邪術：

True + True        # 2
isinstance(True, int)   # True

知道這件事有用——它解釋了為什麼 sum() 可以直接數 list 裡有多少個 True。但千萬不要在程式碼裡拿它做算術或邏輯trick：同事會恨你，code review 也過不了。知道、理解、不使用。

什麼時候該用 is None，什麼時候該用捷徑？

最後一個判斷題。None、空字串 ""、空 list []、False 是不同的值，只是剛好都 falsy。什麼時候差別會要命？

def set_nickname(nickname=None):
    if not nickname:            # 這裡 "" 和 None 被當成同一種情況
        return "anonymous"

如果產品語意上「使用者清空了暱稱」("") 和「使用者沒填過暱稱」(None) 是兩回事，if not nickname 就把它們合併了——這可能是你要的，也可能正是 bug。這時要明確寫 if nickname is None。

經驗法則：在意「值不存在」和「值是空的」的差別時，用 is None 明確表達；不在意、只想判斷「有沒有東西」時，用 truthiness 捷徑。有時需要明確，有時不重要——但你要知道自己在選哪一個。
