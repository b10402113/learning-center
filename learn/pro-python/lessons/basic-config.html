最快速的上門：logging.basicConfig 一行設定

一行 code 讓 logging 動起來

最簡啟動

只要兩行，你就能把 print 換成 logging：

import logging

logging.basicConfig(level=logging.INFO)
logging.info("服務啟動了")

執行後輸出：

INFO:root:服務啟動了

basicConfig 做了什麼？

basicConfig() 設定「根 logger（root logger）」的行為。它告訴 Python：

  • 輸出哪些等級以上的訊息（這裡是 INFO 以上）
  • 輸出格式長什麼樣
  • 輸出到哪裡（預設是 stderr）

自訂格式

加上 format 參數，讓 log 更好讀：

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s: %(message)s",
)

輸出變成：

2026-09-04 10:30:00 INFO root: 服務啟動了

basicConfig 的限制

這行設定雖然方便，但有幾個問題：

  • 沒有名字——所有訊息都標記為 root，複雜專案裡分不出來源
  • 只能設定一次——在大型專案裡，處始化順序會打架
  • 無法同時輸出到檔案和終端——要自己寫 handler

這就是爲什麼我們下一步要學「命名 logger」。
