Annotated 語法與型別組合

學習目標

掌握 Annotated[T, Depends(...)] 語法：把依賴注入資訊附加到型別上，讓 FastAPI 在靜態檢查與執行期都能正確解析。

傳統寫法的缺點

FastAPI 早期依賴注入的寫法很直白：session: Session = Depends(get_session)。但這種寫法有一個缺點：型別提示和注入機制混在一起，IDE 和靜態檢查工具只能看到 Session，看不到 Depends(get_session) 這層資訊。

Annotated 的解決方案

Python 3.9 引入的 Annotated 解決了這個問題。Annotated 讓你在型別後面附加額外的詮釋資料，這些資料不會影響執行期的行為，但 FastAPI 會讀取它來決定怎麼注入。

from typing import Annotated
from fastapi import Depends

SessionDep = Annotated[Session, Depends(get_session)]

這行宣告的意思是：「這個東西的型別是 Session，但請用 Depends(get_session) 來取得它」。SessionDep 是一個型別別名，你可以在端點裡面這樣用：

@app.get("/projects/{project_id}")
def get_project(session: SessionDep):
    ...

IDE 會把 session 當成 Session 看待，自動補全和型別檢查都正常運作。FastAPI 在執行期看到 Annotated[Session, Depends(get_session)]，就知道要呼叫 get_session 來注入值。

型別組合能力

Annotated 的第二個好處是型別可以組合。你可以把 Annotated 和 Optional、List 或其他泛型一起用，FastAPI 一樣能正確解析。比如 Annotated[Project, Depends(get_project_or_404)] 表示「注入一個 Project 物件，但取得方式是透過 get_project_or_404」。

這種寫法讓依賴注入變成型別系統的一部分，而不是函式簽章裡的特殊語法。當你的依賴鏈變長，Annotated 的組合能力會讓程式碼保持清晰，不會被一層又一層的 Depends() 淹沒。
