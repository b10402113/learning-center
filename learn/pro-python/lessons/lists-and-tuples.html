Lists 與 tuples：可變與不可變的有序容器

學習目標：能依「資料該不該被改動」選擇 list 或 tuple，並避開 in-place 方法不回傳新值這個經典陷阱。

Why this step matters

打開任何一支 Python 服務，最常看到的就是一對方括號和一對小括號。專案 API 回傳的是一排專案（list），版本號、座標、RGB 色值是固定綁在一起的一組值（tuple）。讀 code 的第一個判斷永遠是：這坨資料會不會被改？這一步把 list 和 tuple 分清楚，順便拆掉一個幾乎每個 Python 學習者都踩過的炸彈——以為方法會回傳新值，結果它回傳 None。

先看一眼四種容器

容器字面語法一句話定位
list[]有序、可變——最常用的序列
tuple()有序、不可變——固定綁在一起的一組值
set{}無序、自動去重
dict{key: value}鍵值對應——JSON 的形狀

用 type(...) 可以隨時確認手上的東西是哪一種。另外一個立刻要記的規矩：不要把變數取名成 list、dict、set——這會遮蔽（shadow）內建名稱，之後到處出現難查的怪事。set 和 dict 下一步細講，這一步先攻 list 和 tuple。

List：會長大的序列

food = ["payments-api", "ops-console"]
food.append("portal")        # 加一個元素
food.extend(["analytics"])   # 一次接上多個元素
food.pop()                   # 移除並回傳最後一個

append 有個關鍵行為：它不回傳任何東西（回傳 None），而是就地（in place）修改 food 本身。用 + 也可以把兩個 list 串起來，但這個寫法不明確、難除錯，正規作法是 extend。list 裡技術上可以混不同型別，但消費這個 list 的人會很痛苦——理論上可以，實務上別做。

最大的坑：就地修改 vs 回傳新值

names = ["carol", "alice", "bob"]
result = names.sort()
print(result)   # None！
print(names)    # ['alice', 'bob', 'carol'] ← 原本的被改掉了

names.sort() 和 names.reverse() 都是就地修改、回傳 None。想要「拿到排好序的新 list、原本的不動」，改用內建函式：

letters = ["d", "a", "c"]
sorted_letters = sorted(letters)   # 回傳新的排好序 list
# letters 本身保持不變

判斷的經驗法則：方法呼叫在實例上（names.sort()）→ 傾向就地修改；內建函式把資料當參數傳入（sorted(names)）→ 傾向回傳新值、不動原本。result = names.sort() 這一行是經典 bug：看起來很合理，result 卻是 None，而且原本的資料還被偷偷改了。

字串與 list 互相轉換

len(names)               # list 的長度
len("hello")             # 字串的長度——同一個內建函式

"A,B,C,D,E".split(",")        # → ["A", "B", "C", "D", "E"]
" ".join(["alice", "bob"])    # → "alice bob"
",".join(["alice", "bob"])    # → "alice,bob"（結尾不會多一個逗號）

split 建議永遠明確指定分隔符——預設會吃空白、換行等多種字元，容易出現非預期結果。CSV 之類的資料進出 Python 就靠這一對方法。注意 join 是呼叫在「連接字串」身上、list 放參數——語法有點 funky，但到處都看得到。

Tuple：生下來就不改

version = ("alpha", 0, 0, 2)
version.append(3)
# AttributeError: 'tuple' object has no attribute 'append'

tuple 是不可變（immutable）的有序容器。不可變不代表變數不能重新指派——version = ("beta", 1, 0, 0) 是建立一個新的 tuple 再把名字指過去，原本那個 tuple 一個位元都沒變。你沒有任何方法就地改掉 tuple 裡的某個值。

  • 適用場景：座標 (x, y)、配對 (key, value)、RGB 色值——三個 0–255 的數字綁死一組
  • 單元素 tuple 一定要有尾逗號：(1,) 才是 tuple，(1) 只是一個整數
  • 解包（unpacking）：a, b = (1, 2) 一次把兩個值拆給兩個變數

何時選誰

問題答案
這串資料會新增、刪除、排序？list
這組值生下來就固定、要綁在一起？tuple
需要唯一值？set（下一步）
需要 key → value 查找？dict（下一步）

還有一個伏筆：tuple 因為不可變，可以當 dict 的 key——list 不行。這個限制下一步會再看到它發威。
