字串、f-string 與比較運算

學習目標

會用字串內建方法與 f-string 組字串，並知道比較運算子永遠回傳布林值（True/False）。

字串自帶一箱工具

字串在 Python 裡很受寵——一堆好用的方法直接內建。把專案名稱整理成 URL 用的 slug（網址片段）就是典型流程：

name = "  Payments API  "

name.strip()            # "Payments API" —— 去除頭尾空白
name.strip().lower()    # "payments api" —— 轉小寫
name.upper()            # 全大寫
name.strip().lower().replace(" ", "-")
# "payments-api" —— 取代字元，slug 完成

方法可以像這樣串起來：前一個的輸出直接餵給下一個。在 VS Code 裡打 name. 再按 Tab，會列出所有可用方法並附上一行說明——這是探索字串能力最快的方式。

f-string：把值放進字串

把變數的值放進字串，標準答案是 f-string——字串前加 f，大括號裡放變數名：

name = "Nina"
f"The name is {name}"     # "The name is Nina"

大括號裡不只能放變數——整個運算式都可以，還能加格式（format specifier）：

price, quantity = 19.5, 3
f"Total: {price * quantity:.2f}"   # "Total: 58.50" —— 算式 + 保留兩位小數
f"Name: {name!r}"                  # "Name: 'Nina'" —— !r 顯示 repr 形式

實務原則：組字串一律用 f-string。用 + 把字串串起來不但難讀，還有效能瑕疵——能用 f-string 的地方就用 f-string。

比較運算子永遠回傳布林值

標準比較六兄弟：==（等於）、!=（不等於）、<、>、<=、>=：

priority = 13

priority == 13    # True
priority != 13    # False
priority >= 10    # True

關鍵事實：比較的結果永遠是布林值——只有 True 或 False 兩種。注意大小寫：Python 的布林值是大寫開頭的 True/False，跟 JavaScript 的小寫 true/false 不同——兩邊都寫的人很容易手滑，這是值得記住的 gotcha。

字串也是一種 collection（集合）——你可以用 for 迴圈逐字走過一個字串。這個主題在後面的集合單元正式展開。
