Node 03 — Step 2/4 · First FastAPI app

寫出第一個路由，跑起 dev server

學習目標

用 FastAPI 寫一個 GET 路由，啟動 dev server，在瀏覽器看到 JSON 回應。

三分鐘跑起一個 API

先別管理論。打開你的編輯器，建一個 main.py，貼上這三行：

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello World"}

然後在終端機執行：

uv run uvicorn main:app --reload

打開瀏覽器，訪問 http://localhost:8000。你會看到：

{"message": "Hello World"}

就這樣。一個能跑的 API 已經在你電腦上運行了。

逐行拆解

from fastapi import FastAPI

從 fastapi 套件匯入 FastAPI 類別。這是你的應用程式的起點。

app = FastAPI()

建立一個 FastAPI 應用程式的實例（instance）。這個 app 物件會處理所有路由、請求、回應。你可以把它想成一個「路由註冊表」——你告訴它哪個 URL 對應哪個函式，它就幫你處理 HTTP 的一切。

@app.get("/")

這是一個 Python 裝飾器（decorator）。它告訴 FastAPI：「當有人用 GET 方法訪問 / 這個路徑時，執行下面的函式。」

FastAPI 支援所有標準 HTTP 方法：@app.get()、@app.post()、@app.put()、@app.delete()、@app.patch()。

def root():

路由處理函式。名字隨便取，重要的是裝飾器綁定的路徑和方法。這個函式回傳一個 Python dictionary，FastAPI 會自動把它轉成 JSON。

return {"message": "Hello World"}

回傳一個 dictionary。FastAPI 自動做兩件事：

  1. 把 dictionary 序列化成 JSON
  2. 設定 Content-Type: application/json 回應標頭

你不需要手動 jsonify() 或 HttpResponse——回傳 Python 物件就好。

Dev Server 與 --reload

uvicorn 是一個 ASGI（Asynchronous Server Gateway Interface）伺服器，負責接收 HTTP 請求並轉給 FastAPI 處理。

--reload 旗標讓伺服器監聽檔案變化——你改了 main.py，伺服器自動重啟。開發時一定要加，省下手動重啟的時間。

注意：--reload 只用於開發環境。正式環境用 uvicorn main:app 不加 --reload，因為監聽檔案變化有效能開銷。

用 Mock 資料模擬資料庫

在引入真正的資料庫之前，我們先用 Python dictionary 模擬一筆資料：

from fastapi import FastAPI

app = FastAPI()

PROJECTS = {
    1: {"id": 1, "name": "Project Alpha", "slug": "project-alpha"},
    2: {"id": 2, "name": "Project Beta", "slug": "project-beta"},
    3: {"id": 3, "name": "Project Gamma", "slug": "project-gamma"},
}

@app.get("/projects")
def list_projects():
    return list(PROJECTS.values())

訪問 http://localhost:8000/projects，你會看到一個 JSON 陣列：

[
  {"id": 1, "name": "Project Alpha", "slug": "project-alpha"},
  {"id": 2, "name": "Project Beta", "slug": "project-beta"},
  {"id": 3, "name": "Project Gamma", "slug": "project-gamma"}
]

這個 dictionary 就是我們的「假資料庫」。之後會用 PostgreSQL 替換它，但現在先專注在路由機制上。

自動文件，馬上試試

啟動伺服器後，打開 http://localhost:8000/docs。你會看到 Swagger UI 頁面，列出你剛寫的兩個路由：

  • GET /
  • GET /projects

點一下 GET /projects，再點 「Try it out」→「Execute」，就能直接在瀏覽器裡測試 API。不需要 curl、不需要 Postman。

小結

一個 FastAPI 應用程式只需要：一個 FastAPI() 實例、一個或多個 @app.get() 裝飾的路由函式、用 uvicorn 跑起來。回傳 dictionary 就自動變 JSON。下一步，我們加入路徑參數，讓 API 能根據 URL 回傳不同資料。
