Union operator and Optional

Node 05 · Step 3 of 4 · pro-python

Learning goal

Express "this value can be one of several types" using the | union operator and Optional.

When one type isn't enough

Sometimes a variable legitimately holds more than one type. A function might return a result on success or None on failure. A configuration value might be an int or a string. Union types describe exactly that.

The | operator

Python 3.10 introduced the | operator for unions:

def find(user_id: int) -> User | None:
    if user_id in cache:
        return cache[user_id]
    return None

User | None means "either a User or None." Read the pipe as "or." You can chain more than two: int | float | str.

Optional is sugar

Optional[X] is exactly the same as X | None. It existed before | and is still widely used:

from typing import Optional

def find(user_id: int) -> Optional[User]:
    ...

Both forms mean the same thing. Prefer X | None in new code — it's shorter and doesn't need an import.

Working with unions

When you have a union value, narrow it before using type-specific operations:

result: int | None = compute()

if result is not None:
    print(result + 1)   # mypy knows result is int here

The is not None check tells the type checker which branch you're in.
