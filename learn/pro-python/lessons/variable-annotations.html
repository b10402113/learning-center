變數型別註解

Node 05 · 步驟 1/4 · pro-python

學習目標

使用 name: type = value 語法來註解變數，並理解提示在執行時實際的作用。

為什麼要註解變數？

你已經知道怎麼註解函式參數和回傳型別。一樣的冒號語法也可以用在函式內部的普通變數上。它能讓讀者——以及像 mypy 這樣的工具——知道該變數預期裝載什麼形狀的資料。

語法

count: int = 0
name: str = "Untitled"
rates: list[float] = []

模式是 name: type = value。冒號放在變數名稱和型別之間；賦值方式跟之前完全相同。

提示不是強制

型別提示在執行時期不會被檢查。Python 很樂意讓你把已註解的變數重新賦值為完全不同的型別：

count: int = 0
count = "urgent"   # 不會報錯 —— Python 在執行時忽略提示

提示是對讀者和靜態分析器的承諾，而不是執行時的約束。如果你需要強制檢查，就得靠 mypy 或 Pydantic 這類工具。

何時該註解

當型別無法從右側明顯看出時才註解：

  • 空集合：items: list[str] = []
  • 複雜容器：cache: dict[str, int] = {}
  • 一開始是 None、之後才被賦值的值

像 name = "Alice" 這樣的簡單案例通常不需要註解——型別已經很清楚了。
