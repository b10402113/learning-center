泛型集合型別

Node 05 · 步驟 2/4 · pro-python

學習目標

使用 list[int]、dict[str, int] 與 tuple[str, ...] 來描述集合的內容物。

不只是「一個 list」

寫 items: list 幾乎沒告訴讀者任何資訊。泛型讓你能宣告容器裡裝的是什麼：list[str] 代表「一個字串的 list」。這就像「一個箱子」跟「一箱螺絲」的差別。

最常使用的三種

# 一個整數的 list
scores: list[int] = [1, 2, 3]

# 鍵為字串、值為整數的 dict
ages: dict[str, int] = {"alice": 30, "bob": 25}

# 固定長度的 tuple —— 第一個是 str，第二個是 int
pair: tuple[str, int] = ("alice", 30)

# 可變長度的 tuple —— 所有項目都是 str
names: tuple[str, ...] = ("alice", "bob", "carol")

list、dict、tuple 是內建的泛型型別。方括號裡放的是型別參數——list 放一個、dict 放兩個，tuple 則放固定位置或 ...。

巢狀泛型

泛型可以自然巢狀。一個把字串映射到整數 list 的 dict，從左到右讀即可：

groups: dict[str, list[int]] = {
    "odd": [1, 3, 5],
    "even": [2, 4, 6],
}

看到巢狀深度別慌——讀作「dict of str to list of int」。
