用 session.exec() 列出所有資料

學習目標

用 session.exec(select(Model)) 抓回全部 Project，組成 JSON 陣列回傳。

從單筆到全部

session.get() 只能查主鍵。要拿全部記錄，需要用 select() 建構查詢，再用 session.exec() 執行：

from sqlmodel import select

@app.get("/projects")
def list_projects(session: Session = Depends(get_session)):
    statement = select(Project)
    projects = session.exec(statement).all()
    return projects

select(Project) 產生 SELECT * FROM project。session.exec(statement) 回傳一個 Result 物件，呼叫 .all() 把所有記錄放進一個 list。

加上過濾條件

select() 後面可以串 .where() 加條件：

statement = select(Project).where(Project.slug == "project-alpha")
project = session.exec(statement).first()

.first() 回傳第一筆或 None，.one() 強制要求只能有一筆（否則拋例外）。

分頁：不要一次吐全部

如果表格有十萬筆記錄，.all() 會全部載進記憶體。實務上用 .offset() 和 .limit() 做分頁：

statement = select(Project).offset(0).limit(10)
projects = session.exec(statement).all()

前端傳 ?skip=0&limit=10，路由參數接起來：

@app.get("/projects")
def list_projects(
    skip: int = 0,
    limit: int = 10,
    session: Session = Depends(get_session),
):
    statement = select(Project).offset(skip).limit(limit)
    return session.exec(statement).all()

排序

用 .order_by() 指定順序：

from sqlmodel import col

statement = select(Project).order_by(col(Project.name).asc())

沒有加 order_by 時，資料庫不保證回傳順序——每次查詢可能不同。

小結

session.exec(select(Model)) 是列出全部記錄的標準模式。加上 .where() 過濾、.offset()/.limit() 分頁、.order_by() 排序，就能應付大多數列表需求。
