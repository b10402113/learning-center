Sets 與 dicts：唯一值與鍵值對應

學習目標：能用 set 自動保持唯一值、用 dict 做鍵值對應並對應 JSON 結構，並用 .get() 帶預設值安全存取缺失的鍵。

Why this step matters

上一步分清了「可變與不可變」，這一步處理另外兩個需求：值不能重複（優先權清單、標籤清單），和用名字查值（request body、JSON）。set 和 dict 用同一對大括號，一個冒號之差就是兩種不同的東西——這也是新手語法混淆的重災區。讀 FastAPI 端點時你會天天看到 dict：進來的 JSON request body、回傳的 response，形狀都是 dict。

Set：自動去重的容器

unique_priorities = {"high", "medium", "low", "high"}
# → {"high", "medium", "low"}——重複的 high 直接消失

set 只收唯一值：重複的元素丟進去不會報錯，Python 只是靜靜地不存第二次。兩件事要記住：

  • 無序——不要期待 set 印出來的順序和你定義時一樣。list 和 tuple 會保留你給的形狀，set 不會，順序完全沒有保證。
  • 快——判斷「這個值在不在裡面」這類操作，set 非常快，實務上到處都在用。

另外，set 還支援聯集（union）、交集（intersection）、差集（difference）這類集合運算。兩個 set 之間「哪些元素都有？哪些只有一邊有？」一行就能算——超出這堂課範圍，但知道它們存在，讀別人的 code 才不會卡住。還有一個語法細節：{} 什麼都沒放時建立的是 dict；要建空 set 得用建構子 set()。

Dict：用 key 查 value

project = {
    "name": "Payments API",
    "slug": "payments-api",
}   # key: value，冒號隔開；多行定義完全合法

dict 把鍵（key）對應到值（value）。多行定義時，開括號後換行、下面縮排就有效；行尾逗號可加可不加——很多團隊一律加上，是為了讓 git diff 乾淨，照你專案的 styleguide 走。dict 之所以重要，是因為它和 JSON 的結構直接對上：API 收到的 request body、回傳的 response，在 Python 這邊的形狀就是 dict。這是你在 FastAPI 專案裡最常看到的資料結構。

存取：中括號 vs .get()

task = {"title": "Write docs", "done": False}

task["title"]                  # → "Write docs"
task["priority"]               # → KeyError！這個 key 不存在

task.get("priority")           # → None，不會炸
task.get("priority", "low")    # → "low"，自訂預設值

先用現象記住差別：中括號存取遇到不存在的 key 直接拋 KeyError；.get() 遇到缺失的 key 回傳 None，還可以帶第二個參數當預設值。處理「key 可能不存在」的資料（例如使用者上傳的 JSON），.get(key, default) 是安全的那把刀。

keys()、values()、items()

project.keys()     # 只要所有的 key
project.values()   # 只要所有的 value
project.items()    # (key, value) 配對——下一步 for 迴圈的主角

三個方法各自拿到 dict 的一部分。`.items()` 回傳的是一對對的 key-value 配對，下一步會用它把 dict 走一遍。

key 的限制：必須不可變

coords = {(0, 0): "origin", (1, 1): "corner"}   # tuple 當 key：可以
bad = {[0, 0]: "origin"}
# TypeError: unhashable type: 'list'           # list 當 key：不行

dict 的 value 可以混任何型別，但 key 必須是不可變的。原因：key 是用來查找的「地址」，list 這種可變物件會在記憶體裡被改動，一改地址就對不上了，所以 Python 直接拒絕。tuple 不可變，可以當 key——上一步留下的伏筆在這裡回收。value 要不要同型別？不需要，但同樣建議保持一致，消費資料的人才不會痛苦。

一句話總結

需求用什麼
值不可以重複set（自動去重、無序、快）
用名字查值（JSON 的形狀）dict
key 可能缺失、要有預設值dict.get(key, default)
key 要用一組固定值tuple（不可變才能當 key）
