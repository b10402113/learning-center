建立 routers 套件與移動端點

建立 routers 套件、實作 projects 路由器

建立 routers 套件

第一步是在專案根目錄建立一個 routers/ 資料夾，並加上 __init__.py 讓它變成 Python 套件。這一步看起來沒什麼作用，但它是後續所有匯入的基礎：

routers/
  __init__.py
  projects.py

在 projects.py 定義路由器

建立 routers/projects.py，並在檔案開頭建立 APIRouter 實例。這裡的 prefix="/projects" 表示底下所有端點都會掛在 /projects 路徑下；tags=["projects"] 則讓 Swagger UI 把它們歸在同一區：

from fastapi import APIRouter

router = APIRouter(prefix="/projects", tags=["projects"])

從 main.py 搬移端點

把原本寫在 main.py 的專案相關端點全部移到 routers/projects.py。移動時只需要把 @app.get、@router.post 等裝飾器從 app 改成 router，函式本體完全不用改：

# 原本在 main.py
@app.get("/projects")
def list_projects(session: Session = Depends(get_session)):
    ...

# 搬到 routers/projects.py 之後
@router.get("")
def list_projects(session: Session = Depends(get_session)):
    ...

注意路徑從 "/projects" 變成 ""，因為 prefix 已經幫我們加上了。

相對匯入

因為路由器現在位於 routers/ 子資料夾，匯入上層模組時要使用相對匯入（relative import）。例如要匯入 models.py 或 dependencies.py：

from ..models import Project
from ..dependencies import get_session, get_project_or_404

兩個點 .. 代表「往上一層目錄」。如果專案結構更深，就繼續加點。

注意：相對匯入必須在套件內部使用。如果直接執行 routers/projects.py 會報錯，但透過 uv run 或 app.include_router() 匯入就沒問題。

完整路由器範例

把列表、讀取、更新、刪除全部移過來之後，routers/projects.py 會長這樣：

from sqlalchemy.orm import Session

from ..models import Project
from ..dependencies import get_session, get_project_or_404
