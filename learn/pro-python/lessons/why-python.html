為什麼選 Python？

學習目標

理解 Python 的生態優勢、適用場景與限制，以及在 AI 輔助編程時代如何負責任地使用它。

Python 無所不在

Python 出現在幾乎每個軟體領域：

領域代表工具
Web 後端Django、Flask、FastAPI
資料科學pandas、NumPy、SciPy、Jupyter
AI / 機器學習PyTorch、TensorFlow、Hugging Face
基礎設施 / 腳本Ansible、SaltStack、CLI 工具

這種跨領域的普及度意味著：你學一次 Python，就能在多個領域讀寫程式碼。對職涯來說，這是一個高報酬的投資。

PyPI：Python 的真正殺手鐲

Python 有一個巨大的套件生態系——PyPI（Python Package Index）上有數十萬個套件，而且多數經過長期維護和實戰驗證。這代表：

  • 你需要的功能，很可能已經有人寫好了
  • 社群龐大，遇到問題容易找到解答
  • 整合不同服務的成本低——wrapper 套件通常現成可用

PyPI 的廣度和成熟度，是 Python 和其他語言競爭時最大的差異化優勢。

Python 的取捨：速度

Python 不是最快的語言。在 CPU 密集型（CPU-bound）的工作負載下——像是大量數值計算、影像處理——Rust 或 C 會快得多。

但 Python 的優勢在於快速開發。從想法到可運行的程式碼，Python 的迭代速度極快。對於 API 服務、自動化腳本、資料分析這類「開發時間比執行時間更貴」的場景，Python 是合理的選擇。

情境Python 適合嗎？
REST API / Web 後端✓ 非常適合
自動化腳本 / 工具鏈✓ 非常適合
資料分析 / 探索✓ 非常適合
高頻交易 / 遊戲引擎✗ 考慮 Rust / C
嵌入式系統✗ 考慮 C / Rust

AI 輔助編程時代的 Python

現在是 LLM（Large Language Model）時代。AI 編程助手可以幫你快速產出程式碼，但這帶來一個陷阱：

AI 產出的程式碼不一定正確。

課程明確警告：不要盲目信任 AI 的建議。你仍然需要：

  • 理解你寫的程式碼 — 能解釋它為什麼這樣運作
  • 驗證 AI 的輸出 — 跑測試、檢查邊界條件
  • 保持判斷力 — 知道什麼時候 AI 的建議是好的，什麼時候不是

打字的肌肉記憶在 AI 時代可能沒那麼重要了，但理解程式碼的能力反而更重要。這正是這門課在教的東西。
