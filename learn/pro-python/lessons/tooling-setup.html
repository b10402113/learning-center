工具驗證與環境設定

學習目標

驗證 Docker、Git、VS Code、UV 已正確安裝，並完成 VS Code 擴充功能與專案環境的設定。

驗證你的工具

開始寫程式碼之前，先確認所有工具都就位。打開終端機，逐一執行以下命令：

# Docker
docker --version

# Git
git --version

# VS Code（CLI）
code --version

# UV
uv --version

# Python（由 UV 管理）
uv python list

每個命令都應該印出版本號。如果 code --version 找不到命令，打開 VS Code → Command Palette（Cmd+Shift+P）→ 搜尋「Install code command in PATH」並執行。

UV 同時管理 Python 版本和虛擬環境。你不需要手動安裝 Python——UV 會幫你下載正確的版本。

複製課程專案

用 Git 複製課程的 companion repo：

# SSH（推薦，如果你設定了 SSH key）
git clone git@github.com:nnja/python-4-pros.git

# HTTPS
git clone https://github.com/nnja/python-4-pros.git

建立虛擬環境

進入專案目錄後，執行：

cd python-4-pros
uv sync

uv sync 會做兩件事：

  1. 根據 .python-version 檔案下載正確的 Python 版本（3.14）
  2. 根據 pyproject.toml 建立虛擬環境（.venv/）並安裝所有依賴

VS Code 設定

從終端機開啟 VS Code（確保它偵測到正確的 .venv）：

code .

安裝以下擴充功能（Extensions）：

擴充功能用途
PythonPython 語言支援、偵錯
Pylance靜態型別檢查、自動補全
Ruff程式碼格式化 + linting（取代 black + flake8）
DockerDockerfile 語法提示、容器管理
GitLensGit blame、歷史記錄、比較

Ruff 格式化

課程使用 ruff.toml 設定 Ruff 的格式化規則。Ruff 同時扮演 formatter 和 linter 的角色——一個工具取代了傳統的黑（black）+ flake8 組合。

在 VS Code 中，建議設定「儲存時自動格式化」：

  1. 開啟 VS Code 設定（Cmd+,）
  2. 搜尋「format on save」
  3. 勾選 Editor: Format On Save
  4. 搜尋「default formatter」，將 Python 的預設格式化器設為 Ruff

驗證清單

在進入下一堂課之前，確認：

  • ☐ docker --version 印出版本號
  • ☐ git --version 印出版本號
  • ☐ code --version 印出版本號
  • ☐ uv --version 印出版本號
  • ☐ 專案已複製，uv sync 成功執行
  • ☐ VS Code 從終端機 code . 開啟
  • ☐ 五個擴充功能已安裝
  • ☐ Ruff 設為預設格式化器
