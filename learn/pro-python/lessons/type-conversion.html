內建型別轉換：int()、bool() 與 built-ins

學習目標

會用 int()、float()、bool() 等內建建構子明確轉換型別，並知道這些內建型別不需要 import。

型別之間可以轉換

動態型別讓一個變數可以隨時換型別；但很多時候你不是要「換標籤」，而是要把值本身從一種型別換成另一種。Python 兩種都支援：有時候隱轉換自己發生（整數乘浮點數會得到浮點數：5 * 2.0 → 10.0），但更常見、也更可靠的做法是明確轉換（explicit conversion）——你自己呼叫轉換函式，讓意圖一目了然。

內建建構子：轉換就用它們

每個基礎型別都有一個同名的建構子（constructor），直接呼叫就能轉換：

int("42")      # 42 —— 字串轉整數
float("3.14")  # 3.14 —— 字串轉浮點數
str(42)        # "42" —— 數字轉字串
bool(0)        # False
bool(1)        # True

集合型別也一樣是建構子：list()、dict()、set()——後面的單元會大量使用它們。

最常見的實戰場景：外部資料進來時幾乎都是字串。使用者輸入、URL query parameter、JSON 欄位——拿到 "42" 想當數字用，就得 int("42") 轉過去，不然 "42" + 1 會直接 TypeError。

bool() 的轉換規則

bool(0) 是 False、bool(1) 是 True——數字 0 是假的，非 0 是真的。其實每個值丟進 bool() 都會得到真或假（字串的空字串是假的、空 list 是假的……），這個主題叫 truthiness（真值判斷），後面的單元會正式展開。現在先記住：bool() 是把任何值轉成真假的工具。

為什麼不用 import？

你可能注意到：用 int()、bool() 從來不需要 import。因為它們是內建（built-in）型別——Python 啟動時就已經在命名空間裡，開箱即用。

對照組是標準庫（standard library）：datetime、pathlib、logging、re 這些模組也是 Python 自帶、不用安裝，但要明確 import 才能用。一句話區分：內建型別是「本來就在」，標準庫模組是「免費但要自己拿」。

轉換要明確寫出來。依賴隱轉換的程式碼，讀的人（包括三個月後的你）看不出型別在哪裡變了。
