課程概覽：你將打造什麼？

學習目標

了解整門課的目標、要打造的 Release Tracker API 專案，以及課程中會用到的工具鏈。

這門課在做什麼？

這門課由 Nina Zakharenko 授課，目標是教你寫出道地（idiomatic）、經過測試、可上生產環境的 Python 程式。不是從零學 Python——課程假設你已經會寫程式、能用 Unix shell、電腦裝了 Docker。

整門課的核心專案是一個 Release Tracker API。從頭到尾，你會打造一個完整的後端服務：

元件用途
FastAPI建立 REST API 路由，自動產生 Swagger UI 文件
Postgres關係型資料庫，儲存 release 資料
SQLModel結合 Pydantic 驗證與 SQLAlchemy ORM 的模型層
Docker打包應用與資料庫，確保環境一致
UV新一代 Python 套件管理器，取代 pip + venv

這個專案不是玩具——它會走到部署、認證、CI/CD，是一個你放進 portfolio 能說的東西。

課程涵蓋的主題

課程按「先跑起來，再層層加複雜度」的順序推進：

  1. 環境設定 — 安裝工具、建專案骨架
  2. 型別提示（Type Hints） — 讓 Python 程式可被靜態檢查
  3. Pydantic 模型 — 請求/回應的驗證層
  4. 測試 — pytest 與 TestClient
  5. 資料庫 — Docker Postgres、SQLModel、Alembic 遷移
  6. CRUD 重構 — 分離關注點
  7. 依賴注入 — FastAPI 的 Annotated + Depends
  8. 日誌 — 結構化 logging 與請求計時中介軟體
  9. 認證 — 密碼雜湊、JWT、保護端點
  10. 部署 — Dockerfile、secrets、GitHub Actions CI

使用的 Python 版本

課程使用 Python 3.14。不用 3.15 的原因是資料庫驅動（database drivers）尚未相容。這是一個實際的工程取捨——新版本不一定能立刻用，要等生態系跟上。

工具鏈一覽

你會用到的工具：

  • VS Code — 程式碼編輯器，搭配 Python、Pylance、Ruff、Docker、GitLens 擴充功能
  • UV — 套件管理 + 虛擬環境，一個工具搞定
  • Docker Desktop — 跑 Postgres 容器、最終打包應用
  • Git — 版本控制
