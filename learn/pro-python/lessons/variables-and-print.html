變數與 print：給值一個名字

學習目標

會建立變數、分辨「檔案」與「REPL」兩種執行方式，並知道要用 print() 才看得到輸出。

變數：給值一個名字

建立變數只要一行——名字、等號、值，就這樣：

payments_api = "payments-api"
priority = 13

沒有型別宣告、沒有關鍵字（沒有 let 或 var）。變數只是一個綁在值上的名字：你把 "payments-api" 這個字串取名為 payments_api，之後用這個名字就能拿到它。型別屬於值本身，不屬於名字——這件事的後果（一個名字可以先放整數再放字串）是下一步的主角。

兩種執行方式：檔案與 REPL

跑 Python 程式有兩條路：

方式指令適合什麼
執行檔案uv run main.py正式程式碼、要重複跑的東西
互動直譯器（REPL）uv run python快速試一個想法、檢查一個值

REPL（Read-Eval-Print Loop，互動式直譯器）是你打一行、它馬上算一行給你看的環境。現代 REPL 離開時直接打 exit 就行，不用加括號——這是新手最常卡住的地方之一。

檔案裡什麼都不會顯示——除非你 print()

REPL 會自動回顯（echo）每個運算式的結果；檔案不會。這是第一個常見的「為什麼我看不到輸出」陷阱：

"payments-api"          # 在 main.py 裡：安靜無聲，什麼都不印
print("payments-api")   # 這樣才看得到

同一段程式貼進 REPL，第一行會直接給你 'payments-api'；放進檔案執行，什麼都沒有。在檔案裡想看到結果，必須 print()。

順帶一提：專案裡的進入檔案慣例上叫 main.py，它代表「這個模組是要被執行的，不是要被 import 的」。學習階段直接在裡面寫 print 完全可以，不用堅持正式的入口寫法。

print() 的快速除錯招數

print() 可以一次接多個參數，用逗號分開，輸出會用空格隔開——快速除錯時非常好用：

name = "  Nina  "
print(name, name.strip(), len(name))
# 輸出：  Nina   Nina  8

數字與算術

整數（int）與浮點數（float）直接寫字面值：5、2.0。標準算術都有：+ - * /。兩個容易錯過的細節：

  • 整數乘浮點數會得到浮點數：5 * 2.0 是 10.0。Python 沒有 double——浮點數就一種。
  • // 是整數除法（捨去小數），% 是餘數（modulo）：
total_tasks = 13
total_tasks / 2    # 6.5
total_tasks // 2   # 6
total_tasks % 2    # 1
