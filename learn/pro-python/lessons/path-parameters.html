路徑參數與自動型別驗證

學習目標

在路由裡用 {param} 語法定義路徑參數，並觀察 FastAPI 如何自動驗證型別。

從靜態路由到動態路由

上一步的路由 /projects 回傳所有專案。但如果我只想查一筆呢？RESTful API 的做法是把 ID 放進 URL：

/projects/1    → 回傳 id=1 的專案
/projects/2    → 回傳 id=2 的專案

在 FastAPI 裡，你用花括號 {} 在路由字串中宣告一個「路徑參數（path parameter）」：

@app.get("/projects/{project_id}")
def get_project(project_id: int):
    project = PROJECTS.get(project_id)
    if project is None:
        return {"error": "Project not found"}, 404
    return project

兩件重要的事：

  1. 路由字串裡的 {project_id} 宣告了一個參數佔位符
  2. 函式參數 project_id: int 用型別提示告訴 FastAPI 這個參數必須是整數

自動型別驗證

FastAPI 最強大的地方在於：它會根據型別提示自動驗證路徑參數。

正常請求：

GET /projects/1
→ {"id": 1, "name": "Project Alpha", "slug": "project-alpha"}

傳了字串而不是整數：

GET /projects/hello
→ {
    "detail": [{
        "loc": ["path", "project_id"],
        "msg": "value is not a valid integer",
        "type": "type_error.integer"
    }]
}
→ HTTP 422 Unprocessable Entity

你沒有寫任何驗證邏輯。FastAPI 看到 project_id: int，就知道要把 URL 裡的值轉成整數。轉不了？直接回 422 錯誤，告訴呼叫者哪裡出了問題。

關鍵洞察：在 Flask 裡，你需要手動寫 int(project_id) 和 try/except。在 FastAPI 裡，型別提示就是驗證規則——寫一次，到处生效。

用 .get() 安全地查詢

注意程式碼裡用的是 PROJECTS.get(project_id)，不是 PROJECTS[project_id]。

寫法找不到時
PROJECTS[project_id] 拋出 KeyError，伺服器回 500 內部錯誤
PROJECTS.get(project_id) 回傳 None，你可以優雅地處理

用 .get() 讓你檢查回傳值是不是 None，然後回傳一個有意義的 404 回應，而不是讓伺服器崩潰。

完整範例

把前面的程式碼組合起來：

from fastapi import FastAPI

app = FastAPI()

PROJECTS = {
    1: {"id": 1, "name": "Project Alpha", "slug": "project-alpha"},
    2: {"id": 2, "name": "Project Beta", "slug": "project-beta"},
    3: {"id": 3, "name": "Project Gamma", "slug": "project-gamma"},
}

@app.get("/projects")
def list_projects():
    return list(PROJECTS.values())

@app.get("/projects/{project_id}")
def get_project(project_id: int):
    project = PROJECTS.get(project_id)
    if project is None:
        return {"error": "Project not found"}, 404
    return project

現在你有兩個路由：

  • GET /projects — 列出所有專案
  • GET /projects/{project_id} — 根據 ID 取得單一專案

打開 /docs，你會看到 Swagger UI 自動更新了——新的路由帶了一個 project_id 參數欄位，你可以輸入數字測試。

路徑參數的順序

路由字串裡的參數名稱必須跟函式參數名稱一致：

# ✅ 正確：名稱一致
@app.get("/projects/{project_id}")
def get_project(project_id: int): ...

# ❌ 錯誤：名稱不一致，會報錯
@app.get("/projects/{project_id}")
def get_project(pid: int): ...

FastAPI 用名稱來匹配路由參數和函式參數。名字不同，它不知道哪個對應哪個。

小結

路徑參數用 {name} 語法宣告在路由字串裡，用型別提示在函式參數上驗證。FastAPI 自動處理型別轉換和錯誤回應——你只需要寫 project_id: int。用 .get() 安全查詢，避免 KeyError。下一步，我們用 Pydantic 模型來規範回應的結構。
