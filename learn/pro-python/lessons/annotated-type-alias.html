用 Annotated 建立可複用的型別別名

DRY dependencies with ProjectDep · Step 3/4

Learning Goal

能用 `Annotated[Project, Depends(get_project_or_404)]` 建立一個可複用的型別別名 `ProjectDep`。

Lesson

上一課我們寫了 `get_project_or_404` 函式。現在要把它包裝成一個型別別名，讓路由簽章自我描述。

# dependencies.py
from typing import Annotated
from fastapi import Depends

ProjectDep = Annotated[Project, Depends(get_project_or_404)]

這行宣告做了兩件事：

  • 型別：告訴靜態檢查工具（MyPy、Pyright）和 FastAPI，這個註解的型別是 Project。
  • 依賴：告訴 FastAPI，在呼叫路由之前，先執行 get_project_or_404，把回傳的 Project 物件注入進來。

有了 ProjectDep，路由簽章從這樣：

async def get_project(project_id: int, session: SessionDep):

變成這樣：

async def get_project(project: ProjectDep):

路由不再需要自己處理 project_id 查詢和 404 判斷。FastAPI 看到 ProjectDep，會自動從路徑裡抓 project_id，呼叫 get_project_or_404，把回傳的 Project 物件直接塞進 project 參數。

這就是 Annotated 的威力：把「型別」和「依賴解析」綁成一個單位。路由簽章越短，可讀性越高，也越不容易寫錯。
