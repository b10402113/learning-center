# Digest — 57.md

## Overview (L1)

- `.env` is NOT a secret store — it makes dev easier but must never be used in production.
- What counts as a secret: anything whose leak would force credential rotation (JWT secret, database URL with password, managed Postgres password).
- Debug mode is NOT a secret but should default to False in production to avoid verbose tracebacks and sensitive log leakage.
- Production secrets should use platform-native environment variables (Cloud providers, Kubernetes Secrets, Vault), not `.env` files.

## Sections (L2)

### What .env Is and Isn't
- Locator: [[sources/pro-python/completed/20260903_57.md#env-purpose]]
- Summary: Explains that `.env` is a convenience for local development, not a secret store, and must be in `.gitignore`.
- Key claims: `.env` avoids polluting the shell with project-specific exports; it is NOT for production, NOT in version control, and NOT a documentation file; provide `.env.example` for new contributors.
- Learner-relevant: Treating `.env` as a dev convenience (not a production tool) prevents accidental secret leakage.

### What Counts as a Secret
- Locator: [[sources/pro-python/completed/20260903_57.md#what-is-a-secret]]
- Summary: Defines a secret as anything whose leak would force credential rotation; distinguishes secrets from configuration.
- Key claims: JWT secret and database URL are secrets; debug mode is not a secret but should default to False in production; production debug=True leaks tracebacks and sensitive data.
- Learner-relevant: Correctly classifying configuration vs. secrets determines how each should be stored and managed.

### Production Secret Storage
- Locator: [[sources/pro-python/completed/20260903_57.md#production-secrets]]
- Summary: Recommends platform-native environment variables, Kubernetes Secrets, or Vault for production secret storage.
- Key claims: Cloud providers offer managed secret storage; Kubernetes Secrets encrypt at rest; Vault provides fine-grained access control; never use `.env` in production.
- Learner-relevant: Knowing the production secret storage options helps you make secure deployment decisions.
