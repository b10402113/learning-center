## Sections (L2)

### SQLModel table inheritance
- Locator: [[sources/pro-python/completed/20260903_28.md#sqlmodel-table-inheritance]]
- Summary: To make a Pydantic-like class work with the database, inherit from `SQLModel` and set `table=True`. The `ProjectBase` class defines shared fields, and `Project` inherits from it with `table=True` to create the actual database table.
- Key claims: `table=True` is the flag that tells SQLModel to generate a database table; `ProjectBase` holds reusable field definitions; `Project` inherits and adds the table flag — separation of read/write schemas from the table model.
- Learner-relevant: The base/table split pattern is the standard SQLModel approach — it lets you have separate schemas for reads, writes, and database storage.

### Field definitions and constraints
- Locator: [[sources/pro-python/completed/20260903_28.md#field-definitions-and-constraints]]
- Summary: Uses `Annotated` types with `StringConstraints` for reusable validated field types; database-level constraints like `unique=True` enforce at the DB level, not just validation.
- Key claims: `Annotated[str, StringConstraints(min_length=1)]` creates a reusable constrained string type; `Field(unique=True)` adds a database constraint; SQLModel `Field` is different from Pydantic `Field`.
- Learner-relevant: Understanding the difference between Pydantic validation (app level) and database constraints (DB level) is critical for data integrity.

### Auto-generated fields
- Locator: [[sources/pro-python/completed/20260903_28.md#auto-generated-fields]]
- Summary: Project table includes `id` (auto-generated primary key), `created_at` and `updated_at` timestamps with `DateTime` and `UTC` timezone awareness, plus a `slug` field for URL-safe identifiers.
- Key claims: `id` is auto-generated by the database; `created_at` and `updated_at` use `datetime.now(UTC)` for timezone-aware timestamps; `slug` provides a URL-safe version of the project name.
- Learner-relevant: Auto-generated IDs and timestamps are database conventions that reduce boilerplate and ensure consistency.
