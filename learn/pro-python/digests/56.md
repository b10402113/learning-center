# Digest — 56.md

## Overview (L1)

- Detailed Dockerfile walkthrough for the FastAPI app: using Python 3.14-slim as the base image, UV for dependency management, pinning UV version.
- Key Dockerfile flags: `--compile-bytecode` for faster startup, `PYTHONDONTWRITEBYTECODE=1` and `PYTHONUNBUFFERED=1` for production, explicit file copying to avoid accidentally copying .env.
- `uv sync --no-dev` installs only production dependencies; `EXPOSE 8000` tells the container what port to listen on.
- Docker Compose orchestrates the app and Postgres containers together.
