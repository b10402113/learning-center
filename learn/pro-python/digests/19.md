# Digest — 19.md

## Overview (L1)

- Pydantic: runtime data validation using Python type hints
- Install with `uv add pydantic`; check PyPI for version, maintenance status, GitHub stars
- Use cases: API request bodies, configuration files, uploaded file validation
- `BaseModel` subclass with typed fields: `class ProjectCreate(BaseModel): name: str; description: str`
- Pydantic validates at instantiation time; raises `ValidationError` for bad data
- Field constraints: `min_length`, `max_length`, `ge` (>=), `le` (<=), `pattern` for regex
