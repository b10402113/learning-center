# Digest — 50.md

## Overview (L1)

- Never store plaintext passwords; always store password hashes.
- Hashing is a one-way cryptographic function that returns a fixed-size string; salts make identical passwords produce different hashes.
- The `pwdlib` library with Argon2id is used for password hashing in the project.
- Password verification works by hashing the submitted password and comparing it to the stored hash.

## Sections (L2)

### Why Never Store Plaintext Passwords
- Locator: [[sources/pro-python/completed/20260903_50.md#plaintext-warning]]
- Summary: Repeatedly emphasizes that plaintext passwords must never be stored, listing risks: database compromise, SQL injection, leaked backups, cloud misconfigurations.
- Key claims: Users reuse passwords across sites; a leak can cascade into account takeovers; a leak can turn into widespread damage.
- Learner-relevant: This is a non-negotiable security practice; storing plaintext passwords is a critical vulnerability.

### How Hashing Works
- Locator: [[sources/pro-python/completed/20260903_50.md#hashing-basics]]
- Summary: Explains hashing as a one-way cryptographic function: takes any input, returns a fixed-size string; deterministic with salt; cheap to compute.
- Key claims: Salts ensure identical passwords produce different hashes; modern algorithms (Argon2id) are currently infeasible to crack; older algorithms may become insecure over time.
- Learner-relevant: Understanding how hashing and salting work helps you reason about password security and choose the right library.

### Using pwdlib with Argon2id
- Locator: [[sources/pro-python/completed/20260903_50.md#pwdlib-argon2id]]
- Summary: Shows how to install `pwdlib` with Argon2id (`uv add "pwdlib[argon2]"`) and use it for hashing and verifying passwords.
- Key claims: `pwdlib` is a modern Python password hashing library; Argon2id is the recommended algorithm; verification hashes the input and compares to the stored hash.
- Learner-relevant: Using a well-maintained library with a modern algorithm is the standard approach for password hashing in Python.
