# Digest — 02-why-python.md

## Overview (L1)

- Python appears in web frameworks (Django, Flask, FastAPI), data science (pandas, NumPy, SciPy, Jupyter), AI, and infrastructure/scripting
- PyPI is a major strength: hundreds of thousands of well-maintained, battle-tested packages
- Python is not the fastest language; for CPU-bound work, consider Rust or C — but Python's strength is rapid development and ecosystem breadth
- LLM/vibe coding discussion: AI tools are useful but need careful use; understanding code still matters
- Warning about trusting LLM outputs without verification
