## Sections (L2)

### Introduction to Pytest
- Locator: [[sources/pro-python/completed/20260903_21.md#introduction-to-pytest]]
- Summary: Nina introduces pytest as the most widely used Python test framework, contrasting it with the standard library's built-in testing which is boilerplate-heavy and challenging.
- Key claims: pytest is the most widely used test framework for Python; it abstracts away the unpleasantness of stdlib testing; installed as dev dependency with `uv add dev pytest`.
- Learner-relevant: pytest is a critical tool for professional Python development; knowing how to set it up is foundational.

### Test Discovery and Structure
- Locator: [[sources/pro-python/completed/20260903_21.md#test-discovery-and-structure]]
- Summary: Pytest automatically discovers tests by naming convention — test files must be in a `tests/` directory at project root, file names must start with `test_`, and test functions must be defined with the `test_` prefix.
- Key claims: Test files go in `tests/` at project root; filenames must start with `test_`; test functions use the `test_` prefix; running `uv run pytest` from the project root executes all discovered tests.
- Learner-relevant: Understanding pytest's discovery convention eliminates manual test registration boilerplate.

### Writing the First Test
- Locator: [[sources/pro-python/completed/20260903_21.md#writing-the-first-test]]
- Summary: Demonstrates writing a test for a `slugify` function that lowercases and replaces spaces with dashes, using simple assertions and importing the function under test.
- Key claims: A `slugify` function strips, lowercases, and replaces spaces with dashes; tests import the function and use `assert` to verify expected output; `assert slugify("Release Tracker") == "release-tracker"`.
- Learner-relevant: Writing simple assertion-based tests is the foundation of test-driven development in Python.
