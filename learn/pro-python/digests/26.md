### Raising HTTP 404 Exceptions
- Locator: [[sources/pro-python/completed/20260903_26.md#raising-http-404-exceptions]]
- Summary: When a project lookup returns None (not found), raise `HTTPException` with a 404 status code instead of letting the endpoint return a 500 error from the mock database returning None.
- Key claims: `raise HTTPException(status_code=404, detail="Project not found")` provides a clean error response; `status.HTTP_404_NOT_FOUND` is more readable than the raw integer 404; importing `status` from FastAPI gives named constants for all HTTP codes.
- Learner-relevant: Proper error handling with meaningful status codes is essential for API usability — clients need to distinguish "not found" from "server error."

### Slug-Based Search Endpoint
- Locator: [[sources/pro-python/completed/20260903_26.md#slug-based-search-endpoint]]

- Learner-relevant: Slugs are a standard pattern for user-friendly, URL-safe identifiers in web APIs.
