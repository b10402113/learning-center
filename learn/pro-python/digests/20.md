# Digest — 20.md

## Overview (L1)

- Pydantic field types: `SecretStr` for sensitive data (hides from logs/stack traces)
- `StringConstraints` for string validation: `min_length`, `max_length`, `strip_whitespace`
- `Annotated` type from `typing` creates reusable constrained types: `Annotated[str, StringConstraints(...)]`
- Custom type aliases: `StrippedName = Annotated[str, StringConstraints(strip_whitespace=True, min_length=2)]`
- Reusable annotated types reduce boilerplate across models
- All-whitespace strings become empty strings after stripping; empty strings fail min_length validation
