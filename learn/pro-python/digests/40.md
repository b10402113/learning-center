## Sections (L2)

### Programmatic logging configuration
- Locator: [[sources/pro-python/completed/20260903_40.md#programmatic-logging-configuration]]
- Summary: Replaces the minimal `basicConfig` with a programmatic logging setup that reads the log level from environment variables, uses a structured format with timestamps and module names, and defaults to INFO in production.
- Key claims: `configure_logging(debug: bool)` sets level to DEBUG or INFO based on the parameter; the log format includes timestamp, level, module name, and message; environment variables control the log level without code changes.
- Learner-relevant: Environment-controlled logging lets you get verbose DEBUG output locally while keeping production logs clean and structured.

### Environment variables and .env files
- Locator: [[sources/pro-python/completed/20260903_40.md#environment-variables-and-env-files]]
- Summary: A `.env` file sets `debug=true` for local development; VS Code can be configured to load `.env` files into Python terminals automatically via workspace settings.
- Key claims: `.env` files store local development configuration; `debug=true` enables DEBUG-level logging; VS Code's "Python > Terminal: Activate Environment" setting loads `.env` automatically; never commit `.env` files with secrets to version control.
- Learner-relevant: The `.env` pattern separates configuration from code — different environments (local, staging, production) can have different settings without changing any code.

### config.py helper
- Locator: [[sources/pro-python/completed/20260903_40.md#configpy-helper]]
- Summary: A small `config.py` module provides a helper function to read environment variables with defaults, pulling database URLs and debug flags from the environment.
- Key claims: `config.py` centralizes configuration reading; defaults ensure the app works without explicit environment setup; `os.environ.get("KEY", default)` is the standard pattern; the config module is imported where settings are needed.
- Learner-relevant: Centralizing configuration in one module makes it easy to find and change settings — it's the single source of truth for app configuration.
