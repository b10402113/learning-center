### Testing duplicate project creation
- Locator: [[sources/pro-python/completed/20260903_36.md#testing-duplicate-project-creation]]
- Summary: Writes a test that POSTs a project with a duplicate name and asserts that the response is 409 Conflict with a meaningful detail message, not a 500 Internal Server Error.
- Key claims: Creating a duplicate project should return 409 (not 500); the test asserts `response.status_code == 409` and checks the JSON detail; SQLAlchemy raises `IntegrityError` when unique constraints are violated.
- Learner-relevant: Proper HTTP status codes are essential for API clients — 409 tells the client "this conflicts with existing data" so they can handle it appropriately.

### FastAPI exception_handler
- Locator: [[sources/pro-python/completed/20260903_36.md#fastapi-exception-handler]]
- Summary: FastAPI's `@app.exception_handler(IntegrityError)` decorator catches specific exceptions globally and returns custom responses, avoiding try/except blocks in every route.
- Key claims: The handler catches `IntegrityError` anywhere in the app; it returns a JSON response with status 409 and a detail message; this is applied once globally, not per-route; alternative: `app.add_exception_handler()` for class-based handlers.
- Learner-relevant: Global exception handlers ensure consistent error responses — every IntegrityError across all routes gets the same 409 treatment.

### Why 409 Conflict
- Locator: [[sources/pro-python/completed/20260903_36.md#why-409-conflict]]
- Summary: HTTP 409 Conflict is the semantically correct status code when a request conflicts with the current state of the resource — a duplicate name violates the unique constraint.
- Key claims: 409 means "this request conflicts with something else in the database"; it's distinct from 400 (bad request) and 404 (not found); the detail message says "data conflict occurred" for clarity.
- Learner-relevant: Choosing the right status code communicates intent — clients can programmatically distinguish between "you sent bad data" (400), "it doesn't exist" (404), and "it already exists" (409).
