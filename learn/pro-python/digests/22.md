### Type Hints Review
- Locator: [[sources/pro-python/completed/20260903_22.md#type-hints-review]]
- Summary: Reviews adding type hints to `is_overdue` and `next_status` functions, using `due_date: Date | None` and `status: TaskStatus` parameters with `TaskStatus` return type.
- Key claims: `is_overdue` takes a `due_date` typed as `Date | None`; `next_status` takes and returns `TaskStatus`; type hints improve code clarity and editor support.
- Learner-relevant: Type hints are now standard practice in Python and critical for FastAPI/Pydantic integration.

### Pydantic Model for Computer
- Locator: [[sources/pro-python/completed/20260903_22.md#pydantic-model-for-computer]]
- Summary: Demonstrates defining a Pydantic `Computer` model with `brand: str`, `ram_gigabytes: int`, `hard_drive_gigabytes: int`, and catching `ValidationError` when invalid data is provided.
- Key claims: Pydantic validates types automatically at instantiation; passing a string where int is expected raises `ValidationError`; the model enforces required fields — missing `brand` also raises an error.
- Learner-relevant: Pydantic's runtime validation is the backbone of FastAPI's request/response validation.

### Testing with pytest.raises
- Locator: [[sources/pro-python/completed/20260903_22.md#testing-with-pytest-raises]]
- Summary: Shows how to use `pytest.raises` context manager to assert that specific exceptions are raised — used for both Pydantic `ValidationError` and missing required field tests.
- Key claims: `pytest.raises(ExceptionType)` context manager wraps code expected to raise; assertions inside verify the exception type; test suite runs with `uv run pytest`.
- Learner-relevant: `pytest.raises` is essential for testing error paths and validation logic.
