# Digest — 53.md

## Overview (L1)

- Protecting endpoints with FastAPI's `OAuth2PasswordBearer` and a `get_current_user` dependency that verifies the JWT and retrieves the user.
- `OAuth2PasswordBearer` tells FastAPI to expect a token in the Authorization header; missing tokens get a 401 rejection.
- The interactive Swagger docs UI gains an "Authorize" button that prompts for email/password and posts to `/auth/token`.
- Token verification involves three steps: decode with the signing key, check the signature, and look up the user in the database.

## Sections (L2)

### OAuth2PasswordBearer Setup
- Locator: [[sources/pro-python/completed/20260903_53.md#oauth2-setup]]
- Summary: Configures `OAuth2PasswordBearer` with a token URL of `/auth/token`, telling FastAPI where clients obtain tokens.
- Key claims: `OAuth2PasswordBearer` extracts the token from the Authorization header; missing tokens are rejected with 401; the Swagger UI gains an "Authorize" button automatically.
- Learner-relevant: This is the standard FastAPI pattern for adding token-based auth to protected routes.

### get_current_user Dependency
- Locator: [[sources/pro-python/completed/20260903_53.md#get-current-user]]
- Summary: Implements a dependency function that decodes the JWT, verifies the signature, and fetches the user from the database.
- Key claims: Three verification steps: decode with the key, check signature integrity, and look up the user; the dependency is aliased as `current_user_dep` for route handlers.
- Learner-relevant: The dependency pattern keeps auth logic centralized; routes just declare the dependency to become protected.

### Protected Routes
- Locator: [[sources/pro-python/completed/20260903_53.md#protected-routes]]
- Summary: Shows how adding the `current_user_dep` dependency to a route handler makes it require authentication.
- Key claims: Adding the dependency parameter to a route handler is all that's needed to protect it; the framework handles token extraction and validation.
- Learner-relevant: Protecting routes is as simple as adding one dependency parameter — the framework does the heavy lifting.
