## Sections (L2)

### APIRouter concept
- Locator: [[sources/pro-python/completed/20260903_37.md#apirouter-concept]]
- Summary: `APIRouter` splits a monolithic app into focused route modules. Each router defines routes with a prefix and tags, then gets included into the main app — keeping the codebase organized as it grows.
- Key claims: `APIRouter(prefix="/projects", tags=["projects"])` creates a grouped router; `router.get(...)` replaces `app.get(...)`; `app.include_router(router)` registers the router in the main app; tags group endpoints in Swagger UI.
- Learner-relevant: APIRouter is the standard pattern for organizing FastAPI apps beyond a single file — it scales to dozens or hundreds of endpoints.

### Router setup and imports
- Locator: [[sources/pro-python/completed/20260903_37.md#router-setup-and-imports]]
- Summary: Creates a `routers/` package with `__init__.py` and `projects.py`, moving project endpoints from main.py. Uses relative imports (`from ..models import ...`) since the router is now in a subdirectory.
- Key claims: `routers/__init__.py` makes it a Python package; `projects.py` defines the router with all project endpoints; relative imports (`..`) go up directory levels; `router.get`, `router.post`, etc. replace `app.*` decorators.
- Learner-relevant: The routers/ package pattern is the standard FastAPI project structure — it separates concerns by feature.

### Registering routers in main.py
- Locator: [[sources/pro-python/completed/20260903_37.md#registering-routers-in-mainpy]]
- Summary: `app.include_router(projects_router)` in main.py brings all project routes back into the app, maintaining the same URL paths and behavior as before the refactor.
- Key claims: `app.include_router(router)` merges routes from the router into the app; the prefix ensures routes are at the correct path; main.py becomes a lightweight entry point that only wires up routers and middleware; no API behavior changes during this refactor.
- Learner-relevant: main.py becomes the composition root — it's where you see the full API structure at a glance without wading through endpoint implementations.
