# Digest — 16.md

## Overview (L1)

- Context managers ensure resources are cleaned up even if exceptions occur
- Without context managers: manual `try`/`finally` with `f.close()` — verbose and error-prone
- `with` keyword is the context manager syntax: `with open("file") as f:`
- Context managers used for: file I/O, database connections, locks, any resource needing cleanup
- Custom context managers via `__enter__` and `__exit__` methods, or `contextlib` for simpler cases
- `contextlib.contextmanager` decorator makes writing context managers easier

- Locator: [[sources/pro-python/completed/20260903_16.md#writing-context-managers]]
