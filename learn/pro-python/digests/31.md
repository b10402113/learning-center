## Sections (L2)

### Dependency Injection with Depends
- Locator: [[sources/pro-python/completed/20260903_31.md#dependency-injection-with-depends]]
- Summary: FastAPI's `Depends` mechanism calls a function before the endpoint runs and passes its result as a parameter. `get_session` is a dependency that provides a database session, injected via `session: Session = Depends(session_dep)`.
- Key claims: `Depends(session_dep)` tells FastAPI to call `get_session` and pass the result; the session is automatically managed (opened, committed, closed); this replaces manual session management in every endpoint.
- Learner-relevant: Dependency injection is FastAPI's core pattern — it eliminates boilerplate and ensures consistent resource management across all endpoints.

### CRUD operations
- Locator: [[sources/pro-python/completed/20260903_31.md#crud-operations]]
- Summary: Implements the four CRUD operations — Create (POST), Read (GET), Update (PATCH), Delete (DELETE) — replacing dictionary lookups with SQLModel/SQLAlchemy database queries.
- Key claims: POST creates a new record; GET reads by ID or lists all; PATCH partially updates; DELETE removes; each operation uses `session.add()`, `session.commit()`, `session.refresh()` for transaction management.
- Learner-relevant: CRUD is the universal pattern for data-driven APIs — mastering it means you can build any REST API.

### session.refresh() usage
- Locator: [[sources/pro-python/completed/20260903_31.md#session-refresh-usage]]
- Summary: After creating or updating a record, `session.refresh(obj)` reloads the object from the database to get auto-generated fields (like `id`, `created_at`, `updated_at`) that weren't known before the commit.
- Key claims: `session.refresh(obj)` queries the database for the latest state of the object; it's needed after `session.commit()` to populate server-generated values; it ensures the response contains the complete, up-to-date record.
- Learner-relevant: Forgetting `session.refresh()` after a write is a common bug — the response will be missing auto-generated fields.
