<LearningGoal>
能用 Python 套件產生 JWT、設定過期時間，並用伺服器端的密鑰驗證 token 是否合法。
</LearningGoal>

## Lesson

在 Python 上，最常見的 JWT 套件是 <strong>PyJWT</strong>。安裝用 <code>uv add pyjwt</code>。

產生一個 token 只需要三件事：payload（要放的 claims）、secret key（伺服器密鑰）、演算法。<code>jwt.encode(payload, SECRET_KEY, algorithm="HS256")</code> 會回傳一串 JWT 字串。<code>exp</code> 是 JWT 標準 claim，PyJWT 會自動把它轉成 Unix timestamp；一旦 token 過期，驗證就會失敗——你不需要自己寫過期檢查。

收到 token 後，用同一個 secret key 解碼：<code>jwt.decode(token, SECRET_KEY, algorithms=["HS256"])</code>。它會自動驗證 Signature 和 <code>exp</code>。如果 token 被竄改、過期、或簽章不對，就會拋出 <code>ExpiredSignatureError</code> 或 <code>InvalidTokenError</code>。

JWT 的安全性完全取決於 secret key。如果攻擊者拿到你的 key，他就能簽發任何 token、冒充任何人。所以不要把 key 寫死在程式碼裡——用環境變數或 .env 管理；用足夠長的隨機字串（至少 256 位元）；如果 key 外洩，立刻輪換——但輪換會讓所有已發出的 token 失效。

JWT 的「難以偽造」不是魔法，是數學：沒有 key 就無法產生對的雜湊。保護 key 就是保護整個認證系統。
