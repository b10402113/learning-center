<LearningGoal>
Control the log level through environment variables and a `.env` file so local development emits DEBUG output while production stays at INFO, without changing any code.
</LearningGoal>

## Lesson

環境控制 log 等級的核心訴求是：本機開發時看到詳細的 DEBUG 訊息，正式環境只顯示 INFO 以上，而且程式碼不用改。這需要把 log 等級的決定權從程式碼轉移到環境變數。

第一步是建立 `config.py` 助手。這個小模組把「讀環境變數」集中成一個地方，用 `os.environ.get("DEBUG", "false")` 讀取環境變數，有就用環境變數的值，沒有就用預設值 `"false"`。再包成 `get_debug()` 函式，把字串轉成 boolean，其他地方只要呼叫 `get_debug()` 就能知道現在是不是開發模式。

第二步是建立 `.env` 檔案。`.env` 放在專案根目錄，記錄本機開發設定，例如 `DEBUG=true` 和 `DATABASE_URL=postgresql://dev:dev@localhost:5432/app`。VS Code 可以設定在開啟 Python terminal 時自動載入 `.env`（透過 `python.envFile` 設定），這樣你不用手動 `export DEBUG=true`。

第三步是把 `get_debug()` 傳進 `configure_logging`：`configure_logging(debug=get_debug())`。本機開發時 `DEBUG=true`，`get_debug()` 回傳 `True`，log 等級就是 `DEBUG`；正式環境沒設 `DEBUG` 或設為 `false`，`get_debug()` 回傳 `False`，log 等級就是 `INFO`。

一個重要警告：`.env` 通常包含資料庫密碼、API key 等敏感資訊，一定要在 `.gitignore` 加上一行 `.env`，避免密碼被 push 到 GitHub。
