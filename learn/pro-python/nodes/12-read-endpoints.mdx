# Database-backed read endpoints

## Learning goal

Query the database with session.get(), return data from Postgres

## Steps

1. [[learn/pro-python/nodes/12-read-endpoints/dependency-injection|用 Depends 注入資料庫 session]] — 理解 FastAPI 如何用 Depends 把資料庫 session 自動注入路由
2. [[learn/pro-python/nodes/12-read-endpoints/get-by-id|用 session.get() 查詢單筆資料]] — 用 session.get(Model, id) 從 Postgres 抓回一筆 Project（after step 1）
3. [[learn/pro-python/nodes/12-read-endpoints/list-all|用 session.exec() 列出所有資料]] — 用 session.exec(select(Model)) 抓回全部 Project（after step 1）
4. [[learn/pro-python/nodes/12-read-endpoints/handle-not-found|查詢不到資料時回傳 404]] — 當 session.get() 回傳 None 時拋出 HTTPException（after step 2）

## Lesson

之前的課程裡，API 資料存在 Python dictionary 裡——關掉伺服器資料就沒了，而且無法多人共享。這節課把資料搬到 PostgreSQL，用 SQLModel 的 session 真正跟資料庫對話。

核心機制是 FastAPI 的依賴注入（dependency injection）：你宣告「我需要一個資料庫 session」，FastAPI 就自動幫你打開、在路由結束後關閉，不需要自己管理生命週期。有了 session 之後，`session.get(Model, id)` 可以抓單筆、`session.exec(select(Model))` 可以抓全部。如果 `session.get()` 找不到東西，就拋 `HTTPException(status_code=404)`。

走完這四步，你的 API 就能從真正的資料庫讀資料——PostgreSQL 裡的資料重啟伺服器依然存在，多個客戶端也能共享同一份資料。
