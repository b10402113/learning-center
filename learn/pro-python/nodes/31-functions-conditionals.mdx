# Functions and conditionals

## Learning goal

Define functions with default parameters and keyword-only args, use if/elif/else

## Steps

1. [[learn/pro-python/nodes/31-functions-conditionals/function-basics|Function basics — def, return vs print]] — 用 `def` 定義函式、回傳值而不是印出
2. [[learn/pro-python/nodes/31-functions-conditionals/default-parameters|Default parameters, keyword-only args, and the mutable default trap]] — 預設參數、`*` 關鍵字傳參、可變預設值陷阱 (after step 1)
3. [[learn/pro-python/nodes/31-functions-conditionals/if-elif-else|Conditionals — if / elif / else]] — 多分支邏輯與縮排區塊，用 `is_overdue()` 綜合練習 (after step 1)
4. [[learn/pro-python/nodes/31-functions-conditionals/truthiness|Truthiness — falsy values and truthiness shortcuts]] — falsy 值清單、`bool()`、`if due_date:` 捷徑寫法 (after step 3)

## Lesson

這個節點補上兩塊最基礎的拼圖：函式和條件判斷。函式這條線從 `def` 語法與「回傳而非印出」開始，走到預設參數、keyword-only 參數，最後停在可變預設值這個難查的經典 bug。條件這條線用 `if`/`elif`/`else` 加上縮排規則搭起分支邏輯，再透過 truthiness（真值判斷）學會 `if due_date:` 這類 Pythonic 寫法。兩條線在 `is_overdue()` 這種真實例子裡會合——一個函式，根據參數走不同分支，回傳布林值。走完之後，你讀到的每一個 FastAPI dependency、每一個 CRUD 函式，骨架都是這四步的組合。
