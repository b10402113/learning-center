# Variables, types, and naming

## Learning goal

Understand Python's dynamic typing, variable naming, and None

## Steps

1. [[learn/pro-python/nodes/29-variables-types/variables-and-print|變數與 print：給值一個名字]] — 建立變數、分辨檔案與 REPL 執行、用 print() 看輸出
2. [[learn/pro-python/nodes/29-variables-types/dynamic-typing|動態型別：變數沒有固定型別]] — 型別跟著值走、可重新指派成不同型別、type hint 執行時不強制（完成步驟 1 後）
3. [[learn/pro-python/nodes/29-variables-types/type-conversion|內建型別轉換：int()、bool() 與 built-ins]] — 用內建建構子明確轉型，認識不需 import 的內建型別（完成步驟 2 後）
4. [[learn/pro-python/nodes/29-variables-types/strings-fstrings-comparisons|字串、f-string 與比較運算]] — 字串方法、f-string 插值與格式、回傳布林值的比較運算子（完成步驟 1、3 後）
5. [[learn/pro-python/nodes/29-variables-types/naming-and-none|命名慣例與 None]] — snake_case、避開內建名稱、用 is None 表達「刻意缺失」（完成步驟 1、3 後）

## Lesson

Python 的變數不是一個「有型別的盒子」，而是一個綁在值上的名字——型別屬於值，不屬於名字。這一個事實解釋了本節點的全部內容：為什麼同一個變數可以先放整數再放字串（動態型別）、為什麼 type hint 只是提示而不是執行時的強制、為什麼 `int()`、`bool()` 這些轉換工具是內建、不需要 import，以及為什麼「沒有值」要用 `None` 這個關鍵字刻意表達、用 `is None` 檢查。五個步驟從建立變數與看見輸出開始，走過動態型別的陷阱與內建轉換，再進到字串、f-string 與比較運算的日常寫法，最後落在命名慣例與 `None` 的正確語意。
