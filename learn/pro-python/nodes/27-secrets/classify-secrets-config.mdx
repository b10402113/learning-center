<LearningGoal>
能用「洩漏後是否必須輪換憑證」分辨秘密與一般設定，並避免讓 production debug 模式洩漏資料。
</LearningGoal>

## Lesson

以洩漏後是否必須輪換憑證為判準，把 JWT secret 與含密碼的資料庫 URL 視為秘密，同時在 production 關閉可能洩漏 traceback 的 DEBUG。
