# Type hints for variables and generics

## Learning goal

Annotate variables, use list/dict/tuple generics, union operator

## Steps

1. [[learn/pro-python/nodes/05-type-hints-variables/variable-annotations|變數型別註解]] — 學習 `name: type` 的變數註解語法及其重要性
2. [[learn/pro-python/nodes/05-type-hints-variables/generic-collections|泛型集合型別]] — 使用 `list[int]`、`dict[str, int]`、`tuple[str, ...]`（完成步驟 1 後）
3. [[learn/pro-python/nodes/05-type-hints-variables/union-operator|Union 運算子與 Optional]] — 用 `|` 與 `Optional` 表達「二或多選一」（完成步驟 1 後）
4. [[learn/pro-python/nodes/05-type-hints-variables/annotated-example|綜合運用]] — 建構一個完整註解的資料模型（完成步驟 2–3 後）

## Lesson

函式簽章只是全貌的一半。當你能夠註解參數與回傳型別之後，下一步就是把同樣的清晰度帶進函式內部的變數，以及你搭建的資料結構上。

變數註解使用跟函式參數相同的冒號語法：`name: type = value`。它們讓讀者和工具知道該變數預期裝載什麼形狀的資料，儘管 Python 在執行時仍然不會強制檢查。真正值得投入的地方是泛型集合 —— `list[int]`、`dict[str, int]`、`tuple[str, ...]` —— 它們不只告訴你「這是一個 list」，還能宣告「這是一個整數的 list」。當某值可能是多種型別之一時，union 運算子（`int | None`）或 `Optional[int]` 就能直接表達。

這些工具加起來能把模糊的容器變成自述型的資料模型。本節點中的步驟會從單一變數註解開始，逐步進展到結合泛型與 union 的完整範例。
