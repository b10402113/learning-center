4. [[learn/pro-python/nodes/13-write-endpoints/delete-endpoints|Delete endpoints (soft vs hard)]] — Implement DELETE with soft vs hard delete (after step 2)

## Lesson

Read endpoints let your API serve data. Write endpoints let your API change it. Once you can create, update, and delete records through HTTP, you have a complete CRUD application — the backbone of almost every production service.

This node covers the three write operations: POST to create, PATCH to update, and DELETE to remove. Each one follows the same pattern — receive a validated payload, apply the change inside a database transaction, commit, then refresh the object so the response includes server-generated fields like `id` and `created_at`. Along the way you'll build a `slugify` helper that turns arbitrary project names into URL-friendly identifiers, and you'll learn why most production systems prefer soft deletion (hiding records behind a flag) over hard deletion (permanently erasing them).
