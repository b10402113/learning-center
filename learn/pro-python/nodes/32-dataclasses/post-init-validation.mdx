<LearningGoal>
能使用 __post_init__ 在建構後執行驗證，並用 field(default_factory=...) 避開可變預設值的共享陷阱。
</LearningGoal>

## Lesson

`__post_init__` 是 dataclass 在建構子執行完之後自動呼叫的掛鉤，適合做欄位驗證或衍生計算；而 `field(default_factory=...)` 則解決了 Python 函式預設值只會求值一次的可變物件共享陷阱——每次建立實體時，工廠函式都會被呼叫，產生全新的預設值。
