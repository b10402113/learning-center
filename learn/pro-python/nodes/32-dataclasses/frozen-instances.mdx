<LearningGoal>
能解釋 frozen=True 如何讓 dataclass 實體變成不可變物件，以及這種不可變性在設計值物件時為什麼有用。
</LearningGoal>

## Lesson

`frozen=True` 讓 dataclass 實體在建構之後變成不可變，任何修改屬性的動作都會拋出 `FrozenInstanceError`；這種不可變性讓它適合作為值物件使用，並且會自動產生 `__hash__`，因此可以安全地放進 `set` 或當作 `dict` 的 key。
