<LearningGoal>
能根據「資料容器 vs 行為載體」的判斷準則，決定一個型別該用 @dataclass 還是手寫完整類別。
</LearningGoal>

## Lesson

選擇 `@dataclass` 還是手寫完整類別，核心判斷在於「資料容器 vs 行為載體」：如果物件主要責任是裝資料、需要自動樣板、或具備值語意，就用 `@dataclass`；如果需要複雜初始化邏輯、大量自訂特殊方法、或身處複雜繼承階層，手寫完整類別比較不會被語法限制綁手綁腳。
