<LearningGoal>
能說出散落在程式碼裡的「魔術字串」造成哪些問題，並解釋 Enum 如何用一組固定值解決它們。
</LearningGoal>

## Lesson

假設你的程式裡有個任務狀態，整個 codebase 都會用到。第一次寫的人用了 `"in_progress"`，三個月後另一個檔案裡出現 `"IN_PROGRESS"`，還有人寫成 `"in progress"`。每次要用這個狀態，你都得更早以前的答案是什麼——底線還是空格？一個字還是兩個字？大小寫怎麼配？答案不在手邊，只能翻遍程式碼去挖。

直接寫死在程式碼裡、沒有單一定義處的字面字串，叫做**魔術字串（magic string）**。它帶來三個具體問題：

| 問題 | 實際發生什麼事 |
| --- | --- |
| 沒有自動補全 | 編輯器幫不了你，只能靠記憶重打精確的值 |
| 拼錯不會報錯 | `"in_progres"` 完全合法，比較永遠失敗，bug 靜靜藏著 |
| 無效狀態難拒絕 | 任何字串都能塞進欄位，出事才發現 |

標準庫 `enum` 模組的**列舉（Enum）**就是解法：把所有合法狀態收進一個具名類別，每個狀態是一個成員（member）。

```python
from enum import StrEnum

class TaskStatus(StrEnum):
    PLANNED = "planned"
    IN_PROGRESS = "in_progress"
    DONE = "done"
```

之後整個程式碼庫只用 `TaskStatus.IN_PROGRESS`。打 `TaskStatus.`，編輯器列出全部成員——用選的，不用背的；成員名拼錯會當場現形，而不是三個月後才在 production 爆炸；合法值只有定義裡那幾個，無效狀態更容易在驗證時擋下。字串類的列舉（string enum）是實務上最常見的一種，需要一組固定不變的值時就該用它。
