<LearningGoal>
能用 `StrEnum` 定義一組固定狀態值、在 REPL 檢查成員，並解釋為什麼必須繼承 `StrEnum` 而不是寫普通類別。
</LearningGoal>

## Lesson

`StrEnum` 是 Python 3.11 加入的字串列舉；更舊的 codebase 裡會看到等價的前身寫法 `class TaskStatus(str, Enum)`。定義就是把每個合法值寫成類別成員：

```python
from enum import StrEnum

class TaskStatus(StrEnum):
    PLANNED = "planned"
    IN_PROGRESS = "in_progress"
    DONE = "done"
```

貼進 REPL 檢查，每個成員都有兩個面向：`.name` 是類別裡寫的成員名（`"PLANNED"`），`.value` 是指派給它的值（`"planned"`）。成員本身顯示為 `TaskStatus.PLANNED`，印出來清楚可讀，比裸字串好除錯。`StrEnum` 還有一個實點性質：成員本身就是字串——`TaskStatus.IN_PROGRESS == "in_progress"` 是 `True`——所以值可以直接與字串比較、直接存進資料庫欄位。需要數字狀態時換用 `IntEnum`，成員本身就是整數，機制完全相同。

一個常見的質疑：這些不就是普通類別欄位嗎，為什麼要繼承？因為少了那個繼承，拿到的就只是一個普通類別加上幾個字串屬性——Enum 的全部機制都不會生效：自動補全與編輯器檢查幫不上忙、`auto()` 沒有作用、`.name`/`.value` 與按值查找一概不存在。繼承就是在宣告「這是一個 string enum 型別」；語法看起來笨重，是因為 enum 是後來才加進 Python 的。

列舉也與 `match`/`case`（結構化模式匹配）天然搭配——每個 `case` 直接對成員匹配，意圖一目瞭然，比一串 `if status == ...` 好讀也好維護。
