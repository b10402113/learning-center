<LearningGoal>
能用 `auto()` 消除重複的值指派，並解釋 Enum 免費提供的型別檢查，以及它作為資料庫欄位驗證的用途。
</LearningGoal>

## Lesson

`PLANNED = "planned"` 把同一個字打兩遍，成員一多就成了大寫與小寫之間的複製貼上。`enum` 模組的 `auto()` 就是為了消掉這份重複：

```python
from enum import StrEnum, auto

class TaskStatus(StrEnum):
    PLANNED = auto()        # 值是 "planned"
    IN_PROGRESS = auto()    # 值是 "in_progress"
    DONE = auto()           # 值是 "done"
```

在 `StrEnum` 裡，`auto()` 產生的值就是成員名的小寫形式，跟手打 `"planned"` 結果完全相同（普通 `Enum` 裡則是 1、2、3 遞增整數）。記得把 `auto` 加進 import，否則會拿到 `NameError: name 'auto' is not defined`。

`StrEnum` 還送你一份不用 type hinting 的型別檢查：成員必須是字串，寫 `DONE = 1` 會直接報 `TypeError`。Python 平時愛做隱性的型別轉換（coercion），但這裡它不會把 `1` 偷偷轉成 `"1"`——你免費拿到一道成員型別的護欄。

真正發威的場景是**資料庫欄位只接受一組固定值**：任務狀態、優先權這類欄位。`TaskStatus(value)` 按值查找成員，合法就回傳成員、不合法就拋 `ValueError`——「這個值是不是欄位接受的其中之一」一行就有答案；自己寫類別重造這套清單與檢查邏輯，只是徒增負擔。這也是後續所有驗證工作的基礎。
