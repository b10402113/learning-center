# Collections, loops, and comprehensions

## Learning goal

Work with tuples, dicts, sets, for loops, list/dict/set comprehensions

## Steps

1. [[learn/pro-python/nodes/33-collections-loops/lists-and-tuples|Lists 與 tuples：可變與不可變的有序容器]] — 依可變性選擇 list 或 tuple，避開 in-place 方法不回傳新值的陷阱
2. [[learn/pro-python/nodes/33-collections-loops/sets-and-dicts|Sets 與 dicts：唯一值與鍵值對應]] — set 自動去重、dict 對應 JSON 結構，用 `.get()` 安全存取（完成步驟 1 後）
3. [[learn/pro-python/nodes/33-collections-loops/for-loops|for 迴圈與 dict 迭代]] — 同一套語法走訪四種 collection，用 `.items()` 解包 key 與 value（完成步驟 1–2 後）
4. [[learn/pro-python/nodes/33-collections-loops/comprehensions|Comprehensions：一行完成轉換與過濾]] — 把簡單 for 迴圈改寫成 comprehension，認識 generator 與 zip（完成步驟 3 後）

## Lesson

這個節點把 Python 資料結構的基本盤補齊：四種 collection（list、tuple、set、dict）各自的語法與適用場景、for 迴圈怎麼走訪它們，以及 comprehension 這個 Python 最招牌的語法糖。四步是一條主線：先分清「可變與不可變」（list vs tuple），再學「唯一值與鍵值對應」（set vs dict），接著用 for 迴圈把四種容器走一遍——dict 用 `.items()` 搭配 tuple unpacking 同時拿 key 和 value——最後把簡單的迴圈收進一行 comprehension，連同 generator、`sum()`/`any()`/`all()` 和 `zip()` 一次學齊。走完之後，你在 FastAPI 端點裡讀到的 request body（dict、JSON 的形狀）、回傳的專案清單（list of dicts）、crud 層裡一行的 `[t["title"] for t in tasks if not t["done"]]`，全都是這四步的組合。
