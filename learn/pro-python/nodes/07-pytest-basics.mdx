# pytest — discovery and first test

## Learning goal

Set up pytest, write a test for slugify, run with `uv run pytest`

## Steps

1. [[learn/pro-python/nodes/07-pytest-basics/install-pytest|安裝 pytest 作為開發依賴]] — 用 `uv add dev pytest` 把測試框架加進專案
2. [[learn/pro-python/nodes/07-pytest-basics/test-discovery|pytest 的自動發現機制]] — 理解 `tests/` 目錄與 `test_` 前綴如何讓 pytest 自動找到測試（after step 1）
3. [[learn/pro-python/nodes/07-pytest-basics/write-first-test|為 slugify 寫第一個測試]] — 匯入待測函數並用 `assert` 驗證輸出（after step 2）
4. [[learn/pro-python/nodes/07-pytest-basics/run-pytest|執行 pytest 並解讀結果]] — 從專案根目錄跑 `uv run pytest` 並判斷測試是否通過（after step 3）

## Lesson

這節課帶你走過 pytest 最基本的四步：安裝、發現、寫測試、執行。pytest 是 Python 生態裡最主流的測試框架，它把標準庫那些繁瑣的樣板程式碼全部藏起來，讓你只要遵守命名慣例就能開始寫測試。

你會先理解為什麼測試框架要放在開發依賴（dev dependency）而不是正式依賴；接著認識 pytest 的自動發現機制——只要檔案放在 `tests/` 目錄、檔名以 `test_` 開頭、函式以 `test_` 開頭，pytest 就會自動執行；然後為一個 `slugify` 函式寫出第一個測試，用 `assert` 驗證輸入與輸出；最後從專案根目錄執行 `uv run pytest`，看懂輸出結果代表的意義。
