## Learning goal
能用 basicConfig 快速啟動 logging，理解它的層級設定與格式限制。
## Lesson

要讓 logging 最快動起來，只要兩行程式碼。`logging.basicConfig(level=logging.INFO)` 會設定「根 logger（root logger）」的行為：輸出 INFO 以上的訊息，格式預設是 `LEVEL:logger_name:message`，目的地是 stderr。

你可以用 `format` 參數讓輸出更好讀。常見的格式字串包含 `%(asctime)s`（時間戳記）、`%(levelname)s`（等級）、`%(name)s`（logger 名字）、`%(message)s`（訊息本身）。加上時間和模組名之後，log 就不再只是一串文字，而是有脈絡的事件紀錄。

但 basicConfig 有三個限制：第一，所有訊息都標記為 `root`，在複雜專案裡分不出來源；第二，它只能設定一次，大型專案裡初始化順序會打架；第三，它無法同時輸出到檔案和終端。這些限制會在下一步用「命名 logger」解決。
