## Learning goal
能說出 DEBUG / INFO / WARNING / ERROR / CRITICAL 的用途，以及「門檻」如何過濾訊息。
## Lesson

Python logging 定義了五個嚴重等級，由低到高是 DEBUG（10）、INFO（20）、WARNING（30）、ERROR（40）、CRITICAL（50）。設定等級就像設定「門檻」：只有這個等級以上的訊息才會被輸出。設定 INFO 時，DEBUG 被擋下，INFO 以上通過。

DEBUG 是開發時的詳細診斷資訊，例如 route 收到的參數、SQL 查詢內容。INFO 是一般操作事件，例如服務啟動、請求完成。WARNING 是預期外的狀況但程式還能跑，例如重試連線。ERROR 是嚴重問題，例如資料庫斷線。CRITICAL 是程式可能無法繼續執行，例如記憶體耗盡。

常見做法是讀環境變數，在開發時用 DEBUG，上線後用 INFO。這樣你可以在本機看到所有細節，production 不會被 DEBUG 訊息癱瘓。
