## Learning goal
能建立模組層級的命名 logger，並理解層級繼承如何讓設定向下流動。
## Lesson

在每個模組最上方寫 `logger = logging.getLogger(__name__)`，是 Python 社群的慣例。`__name__` 會自動被設成模組路徑，例如 `routers.projects`，log 輸出就能清楚顯示訊息來自哪個模組，不再全是 `root`。

Logger 名字用點號分隔，形成一層一層的結構。當你設定 `routers` 這個 logger 的等級，`routers.projects` 和 `routers.tasks` 都會跟著改。這讓「整個 routers 套件用 DEBUG」這種批量設定變成可能，而不是一個一個模組調整。

規則是：應用程式碼用命名 logger，第三方套件用 root。套件作者通常會用 `logging.getLogger(__name__)`，所以你只要設定 root，就能控制所有套件的 log 等級。這讓你的設定檔保持簡潔，同時保留對每個套件微調的彈性。
