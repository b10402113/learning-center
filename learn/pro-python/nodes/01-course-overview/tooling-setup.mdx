# 工具驗證與環境設定

## Learning goal

驗證 Docker、Git、VS Code、UV 已正確安裝，並完成 VS Code 擴充功能與專案環境的設定。

## Lesson

開始寫程式碼之前，先確認所有工具都就位。打開終端機，逐一執行以下命令：

```bash
docker --version
git --version
code --version
uv --version
uv python list
```

每個命令都應該印出版本號。如果 `code --version` 找不到命令，打開 VS Code → Command Palette（`Cmd+Shift+P`）→ 搜尋「Install code command in PATH」並執行。UV 同時管理 Python 版本和虛擬環境——你不需要手動安裝 Python，UV 會幫你下載正確的版本。

用 Git 複製課程的 companion repo（`nnja/python-4-pros`），進入專案目錄後執行 `uv sync`。這個命令會做兩件事：根據 `.python-version` 檔案下載正確的 Python 版本（3.14），以及根據 `pyproject.toml` 建立虛擬環境（`.venv/`）並安裝所有依賴。

從終端機開啟 VS Code（`code .`），確保它偵測到正確的 .venv。安裝五個擴充功能：**Python**（語言支援、偵錯）、**Pylance**（靜態型別檢查、自動補全）、**Ruff**（格式化 + linting，取代 black + flake8）、**Docker**（Dockerfile 語法提示、容器管理）、**GitLens**（Git blame、歷史記錄）。

課程使用 `ruff.toml` 設定 Ruff 的格式化規則。Ruff 同時扮演 formatter 和 linter 的角色——一個工具取代了傳統的黑（black）+ flake8 組合。建議在 VS Code 中設定「儲存時自動格式化」，並將 Python 的預設格式化器設為 Ruff。

在進入下一堂課之前，確認所有命令都能印出版本號、專案已複製且 `uv sync` 成功、VS Code 從終端機開啟、五個擴充功能已安裝、Ruff 設為預設格式化器。
