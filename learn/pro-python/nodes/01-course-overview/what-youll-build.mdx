# 課程概覽：你將打造什麼？

## Learning goal

了解整門課的目標、要打造的 Release Tracker API 專案，以及課程中會用到的工具鏈。

## Lesson

這門課由 Nina Zakharenko 授課，目標是教你寫出**道地（idiomatic）、經過測試、可上生產環境**的 Python 程式。不是從零學 Python——課程假設你已經會寫程式、能用 Unix shell、電腦裝了 Docker。

整門課的核心專案是一個 **Release Tracker API**。從頭到尾，你會打造一個完整的後端服務，包含以下元件：

| 元件 | 用途 |
| --- | --- |
| FastAPI | 建立 REST API 路由，自動產生 Swagger UI 文件 |
| Postgres | 關係型資料庫，儲存 release 資料 |
| SQLModel | 結合 Pydantic 驗證與 SQLAlchemy ORM 的模型層 |
| Docker | 打包應用與資料庫，確保環境一致 |
| UV | 新一代 Python 套件管理器，取代 pip + venv |

課程按「先跑起來，再層層加複雜度」的順序推進：環境設定 → 型別提示（Type Hints）→ Pydantic 模型 → 測試（pytest + TestClient）→ 資料庫（Docker Postgres、SQLModel、Alembic 遷移）→ CRUD 重構 → 依賴注入（Annotated + Depends）→ 日誌（結構化 logging）→ 認證（密碼雜湊、JWT）→ 部署（Dockerfile、secrets、GitHub Actions CI）。

課程使用 **Python 3.14**。不用 3.15 的原因是資料庫驅動（database drivers）尚未相容——這是一個實際的工程取捨：新版本不一定能立刻用，要等生態系跟上。

你會用到的工具鏈：**VS Code**（搭配 Python、Pylance、Ruff、Docker、GitLens 擴充功能）、**UV**（套件管理 + 虛擬環境，一個工具搞定）、**Docker Desktop**（跑 Postgres 容器、最終打包應用）、**Git**（版本控制）。

下一步會解釋為什麼選 Python，以及它的生態系優勢。再下一步動手驗證你的工具是否就位。
