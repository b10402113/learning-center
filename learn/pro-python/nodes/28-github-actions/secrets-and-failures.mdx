<LearningGoal>
Keep secrets out of workflow files and diagnose CI failures by separating environment, quality, test, and service-health problems.
</LearningGoal>

## Lesson

CI 應以 GitHub secrets 在執行時注入最小權限的敏感值，並透過 health endpoint 與分層失敗訊號區分環境、品質、測試和服務問題。
