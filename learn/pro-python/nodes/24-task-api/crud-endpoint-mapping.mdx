# CRUD methods and endpoint mapping

## Learning goal

Map CRUD operations to FastAPI endpoints following the project router pattern

## Lesson

Task router 的 endpoint 形狀和 project router 幾乎一樣。學好這一步，等於把整個 CRUD + router 的 pattern 複用一遍。之後要加新的實體（entity），照著這套 pattern 走就行。

Task CRUD 需要五個方法，每個對應一個 endpoint：create 對應 POST，read 對應 GET /{task_id}，list 對應 GET（帶 filter），update 對應 PATCH /{task_id}，delete 對應 DELETE /{task_id}。每個方法都接受 <code>session</code> 作為第一個參數。

FastAPI 的 decorator 把 HTTP verb 和路徑綁定到 function。endpoint function 本身幾乎不做邏輯，只是把參數傳進 <code>crud</code> module。這讓 route layer 保持精簡，真正的工作都在 crud.py 裡。

Task endpoint 需要同時拿到 <code>session</code> 和 <code>project</code>，所以在 function signature 裡一起宣告。FastAPI 會自動呼叫這兩個 dependency 的函式，把回傳值注入進來。<code>task_dep</code> 則用在 read / update / delete 這三個需要拿到既有 task 的 endpoint。

把 HTTP 處理（status code、response model）和資料庫操作分開，有兩大好處：測試時可以直接測 crud.py 不必跑 API；換框架時 crud.py 幾乎不用改。
