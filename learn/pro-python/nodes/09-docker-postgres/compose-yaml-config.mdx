## Lesson

compose.yaml 是 Docker Compose 的設定檔，用 YAML 格式描述你要跑哪些服務、它們怎麼設定、資料怎麼保存。把它放在專案根目錄，VS Code 會自動認出這個檔案並給它專屬圖示。

一個最簡單的 compose.yaml 包含兩個頂層區塊：<code>services</code> 和 <code>volumes</code>。<code>services</code> 定義要跑哪些容器，<code>volumes</code> 定義 named volume 來保存資料。

以 Postgres 為例，<code>image: postgres:17-alpine</code> 指定映像檔版本，alpine 是精簡版，體積小。<code>ports: "5432:5432"</code> 把主機的 5432 對應到容器的 5432，讓本機應用能透過 localhost 連到資料庫。<code>environment</code> 區塊設定資料庫名稱、使用者、密碼，容器啟動時會自動建立這些帳密。<code>volumes</code> 把 named volume <code>postgres_data</code> 掛載到容器內的 <code>/var/lib/postgresql/data</code>，這是 Postgres 存放資料的標準路徑，確保容器刪除後資料還在。

健康檢查不只是確認容器在跑，而是確認資料庫真的能接受連線。<code>pg_isready</code> 是 Postgres 內建的工具，它會實際嘗試連線。設定裡 <code>interval: 10s</code> 表示每 10 秒檢查一次，<code>timeout: 5s</code> 表示每次最多等 5 秒，<code>retries: 5</code> 表示連續失敗 5 次才標記為不健康，避免短暫的網路抖動誤判。

範例中的密碼只適合本地開發。正式環境的密碼絕對不能寫在 compose.yaml 裡，要用 .env 檔案或 secrets 管理。
