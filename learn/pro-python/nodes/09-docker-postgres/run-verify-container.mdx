<LearningGoal>
能用 docker compose 啟動 Postgres，並用健康檢查與連線測試確認它真的在跑。
</LearningGoal>

## Lesson

在專案根目錄下執行 <code>docker compose up -d</code>，就能背景啟動 Postgres 容器。<code>-d</code> 表示 detached 模式，容器會在背景跑，不會佔用終端機。

用 <code>docker compose ps</code> 查看服務狀態。如果健康檢查通過，狀態會顯示 <code>(healthy)</code>。這代表不只是容器在跑，而是資料庫真的能接受連線。

如果容器沒有顯示 healthy，用 <code>docker compose logs db</code> 查看日誌排查問題。常見的錯誤包括連接埠被佔用、volume 權限問題、或環境變數拼錯。

容器健康不代表應用連得上。最保險的方式是實際連進去查資料。用 <code>docker compose exec db psql -U release_tracker -d release_tracker -c "\dt"</code> 可以連進容器裡的 psql，列出目前資料庫中的所有表格。剛開始應該是空的，因為我們還沒建表。

想重來？用 <code>docker compose down -v</code> 停止並移除容器，同時刪除 named volume。這等於砍掉重練，下次 <code>up</code> 就是一個全新的資料庫。
