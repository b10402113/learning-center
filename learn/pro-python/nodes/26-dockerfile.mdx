# Dockerizing the app

## Learning goal
Write a Dockerfile with python:3.14-slim, build and run the container

## Steps

1. [[learn/pro-python/nodes/26-dockerfile/build-image-basics|用 Dockerfile 固定 Python 執行環境]] — 以 `python:3.14-slim` 建立可移植的應用映像檔
2. [[learn/pro-python/nodes/26-dockerfile/reproducible-dependencies|用 UV 安裝可重現的生產依賴]] — 固定 UV 與鎖定檔，只安裝 production 依賴（after step 1）
3. [[learn/pro-python/nodes/26-dockerfile/runtime-and-security|設定容器執行時行為與檔案邊界]] — 控制輸出、bytecode、複製檔案與容器埠號（after step 2）
4. [[learn/pro-python/nodes/26-dockerfile/compose-and-verify|用 Compose 啟動並驗證完整服務]] — 協調 FastAPI 與 Postgres 並實際驗證服務（after step 3）

## Lesson

Dockerizing 一個 FastAPI 應用，是把 Python 版本、依賴、原始碼與啟動方式封裝成可重建的 image，再用 Compose 協調 API 與 Postgres。可靠的容器不只要能 build，還要避免帶入不必要檔案、排除開發依賴，並透過健康檢查與實際請求確認服務真的可用。
