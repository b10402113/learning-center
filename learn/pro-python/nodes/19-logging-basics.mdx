# Python logging basics

## Learning goal

Replace print() with logging, configure log levels

## Steps

1. [[learn/pro-python/nodes/19-logging-basics/logging-vs-print|為什麼生產環境用 logging 而不是 print？]] — 認識 print 在正式環境的風險與 logging 的優勢
2. [[learn/pro-python/nodes/19-logging-basics/basic-config|最快速的上門：logging.basicConfig 一行設定]] — 一行啟動 logging，了解格式限制（after step 1）
3. [[learn/pro-python/nodes/19-logging-basics/logger-hierarchy|命名 logger 與層級：getLogger(__name__) 的慣例]] — 建立模組層級 logger，理解繼承機制（after step 2）
4. [[learn/pro-python/nodes/19-logging-basics/log-levels|五種嚴重等級與過濾行為]] — 五個 log 級別與門檻過濾（after step 2）
5. [[learn/pro-python/nodes/19-logging-basics/lazy-formatting|懶加載格式化：用 %s 而不是 f-string]] — 為什麼 %s 省效能（after step 4）

## Lesson

print() 是原型階段的快速通道，但進到 CI/CD 環境它就變成隱患：可能外洩敏感資料、沒有結構化格式、無法在執行時過濾等級。Python 標準庫 logging 針對這些問題設計了模組化 API：每個模組建立自己的 logger、用層級繼承做統一管控、用百分號語法延遲字串插值，最終讓你的服務在 production 裡具備可觀察性。這五步從「為什麼要換」走到「怎麼正確用」，完成後你就能把 fastapi 專案的任何 print 乾淨地轉成 logging。
