<LearningGoal>
能使用 `uv add dev pytest` 將 pytest 安裝為開發依賴，並理解為什麼測試框架不該出現在正式環境。
</LearningGoal>

## Lesson

Python 標準庫裡內建了 `unittest`，但用起來非常繁瑣——你要寫很多樣板程式碼（boilerplate），測試類別的命名、斷言方法的選擇都有嚴格規定。這導致很多人寫測試的意願低落。

pytest 的出現解決了這個問題。它把那些繁瑣的細節全部藏起來，讓你用最直覺的方式寫測試：只要一個 `assert` 就夠了。現在，pytest 已經成為 Python 生態裡最主流的測試框架。

測試框架只會在開發和 CI 環境使用，正式部署的伺服器上不需要它。如果把它放在正式依賴（main dependencies），會增加部署時間、映像檔大小，甚至引入不必要的安全風險。UV 用 `--dev` 標記來區分這兩種依賴：

```bash
uv add --dev pytest
```

這條指令會把 `pytest` 加到 `pyproject.toml` 的 `[dependency-groups]` 或 `[tool.uv.dev-dependencies]` 區段，而不是主依賴列表。

執行 `uv add --dev pytest` 後，UV 會自動完成三件事：下載 pytest 及其依賴、更新 `pyproject.toml`、更新 `uv.lock` 鎖定版本。你可以用以下指令確認安裝成功：

```bash
uv run pytest --version
```

這會輸出 pytest 的版本號碼，表示一切就緒。
