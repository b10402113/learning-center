<LearningGoal>
能從專案根目錄執行 `uv run pytest`，並根據輸出判斷測試是否通過。
</LearningGoal>

## Lesson

你已經寫好了測試檔案，放在 `tests/test_slug.py`。現在要實際執行它，看看 `slugify` 函式是不是真的如你預期般運作。pytest 會自動發現所有符合命名慣例的測試，執行它們，然後用清晰的格式報告結果。

從專案根目錄（`pyproject.toml` 所在的位置）執行：

```bash
uv run pytest
```

`uv run` 會確保使用專案的虛擬環境和依賴來執行 pytest，不需要手動啟用環境。

通過時的輸出長這樣：

```
$ uv run pytest
========================= test session starts =========================
platform linux -- Python 3.14.0, pytest-8.3.0, pluggy-1.5.0
rootdir: /home/user/my-project
collected 1 item

tests/test_slug.py .                                         [100%]

========================== 1 passed in 0.01s ==========================
```

重點在第三行：`collected 1 item` 表示找到一個測試，後面的 `.` 表示通過。最後一行 `1 passed` 確認測試成功。

失敗時的輸出會顯示詳細的錯誤訊息：

```
$ uv run pytest
========================= test session starts =========================
collected 1 item

tests/test_slug.py F                                         [100%]

=============================== FAILURES =========================______
_________________ test_slugify_lowercases_and_dashes_spaces _________________

    def test_slugify_lowercases_and_dashes_spaces():
>       assert slugify("Release Tracker") == "release_tracker"
E       AssertionError: assert 'release-tracker' == 'release_tracker'
E
E         - release_tracker
E         + release-tracker

tests/test_slug.py:4: AssertionError
======================= 1 failed in 0.01s ========================
```

pytest 會顯示哪個測試失敗、斷言比較的實際值與預期值、以及差異在哪裡。這讓你快速定位問題。

輸出符號對照：

| 符號 | 意義 |
| --- | --- |
| `.` | 測試通過 |
| `F` | 測試失敗（Failure） |
| `E` | 測試出錯（Error，非斷言失敗） |
| `s` | 測試被跳過（Skipped） |

常見執行選項：

| 選項 | 作用 |
| --- | --- |
| `-v` | 詳細模式，列出每個測試名稱 |
| `-q` | 安靜模式，只顯示摘要 |
| `tests/test_slug.py` | 只執行特定檔案 |
| `-k "slugify"` | 只執行名稱包含 "slugify" 的測試 |
