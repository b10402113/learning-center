# Error handling and context managers

## Learning goal

Raise and catch exceptions properly, use custom exceptions, understand with statements

## Steps

1. [[learn/pro-python/nodes/34-error-handling/raising-exceptions|Raising Exceptions]] — use `raise` to throw `ValueError` and other exceptions when code cannot complete safely
2. [[learn/pro-python/nodes/34-error-handling/catching-exceptions|Catching Exceptions]] — use `try`/`except` to catch specific exceptions and handle errors gracefully (after step 1)
3. [[learn/pro-python/nodes/34-error-handling/custom-exceptions|Custom Exceptions]] — create domain-specific exception classes by subclassing `Exception` (after steps 1–2)
4. [[learn/pro-python/nodes/34-error-handling/context-managers|Context Managers]] — use `with` statements to manage resources that need guaranteed cleanup (after step 2)

## Lesson

Python's error handling model is built on exceptions: when something goes wrong, Python raises an exception that can be caught and handled. Instead of returning error codes and checking them everywhere, you let exceptions propagate until you reach a handler that knows what to do. This keeps the happy path clean and pushes error handling to the edges. In this node, you learn to raise exceptions when validation fails, catch them with specificity, define your own exception types for domain errors, and use context managers to guarantee resource cleanup even when things go wrong.
