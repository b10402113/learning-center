# Project setup with UV

## Learning goal

Initialize a UV project, understand pyproject.toml and .python-version

## Steps

1. [[learn/pro-python/nodes/02-project-setup/uv-init-scaffold|用 UV 初始化專案]] — 能用 `uv init` 建立一個新的 Python 專案，並理解每個產生檔案的用途
2. [[learn/pro-python/nodes/02-project-setup/pyproject-toml|解讀 pyproject.toml]] — 能讀懂 pyproject.toml 的每個欄位，理解它如何定義專案的中繼資料與依賴 (after step 1)
3. [[learn/pro-python/nodes/02-project-setup/python-version-and-sync|Python 版本管理與 uv sync]] — 理解 .python-version 檔案的作用，並能用 `uv sync` 建立虛擬環境 (after steps 1–2)

## Lesson

每個 Python 專案都從一個空白資料夾開始，但「空白」不等於「什麼都沒有」。UV 幫你在一秒內產生完整的專案骨架：一個 `pyproject.toml` 記錄專案身份與依賴、一個 `.python-version` 釘選 Python 版本、一個 `main.py` 作為起點、一份 `.gitignore` 排除不需要追蹤的檔案。這三步帶你從 `uv init` 開始，逐步拆開每個檔案的用途，最後用 `uv sync` 建好虛擬環境。走完之後，你就有一個乾淨、可重複建置的專案，可以開始寫程式碼。
