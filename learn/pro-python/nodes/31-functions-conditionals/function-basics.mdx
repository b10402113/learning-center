# Function basics — def, return vs print

## Learning goal

用 `def` 定義帶參數的函式並回傳值，說得出「回傳」和「印出」的差別，以及為什麼函式應該回傳而不是印出。

## Lesson

Python 用 <code>def</code> 定義函式：關鍵字、名稱、小括號、參數列表、冒號，然後縮排的區塊就是函式本體——沒有大括號，縮排本身就是語法，編輯器在冒號後會自動縮排。

<code>slugify</code> 是個最小的完整例子：<code>strip()</code> 去頭尾空白、<code>lower()</code> 轉小寫、<code>replace(" ", "-")</code> 把空白換成連字號，三個字串方法串起來回傳 <code>"payments-api"</code> 這種 URL slug。

一個會影響可測性的關鍵決定：函式應該<strong>回傳值</strong>而不是印出。印出版本「能動」，但值變成 terminal 上的一行文字，呼叫方拿不到、沒辦法繼續轉換（例如 <code>.upper()</code>）、也沒辦法寫進 pytest 斷言；回傳版本把資料的控制權留給呼叫方。函式應該小而專注，在函式裡 print 會讓除錯變得困難。

<code>return</code> 是可選的：沒有 return 的函式照樣執行，但 Python 會讓它隱式回傳 <code>None</code>——看到呼叫結果是 <code>None</code>，先檢查是不是忘了 return。
