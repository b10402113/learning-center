# Truthiness — falsy values and truthiness shortcuts

## Learning goal

說出 Python 的 falsy 值清單、用 `bool()` 驗證真值，並寫出 `if due_date:` 這類比 `is None` 更簡潔的判斷。

## Lesson

Python 的 <code>if</code> 不只接受布林——任何值放進條件裡都會被評估成真或假，這叫 truthiness（真值判斷）。Falsy 清單很短，記口訣「零、空、沒有」：<code>False</code>、<code>None</code>、<code>0</code>、<code>""</code>、<code>[]</code>、<code>{}</code>、<code>set()</code>，其餘一切都是 truthy——包括 <code>-3</code>、<code>"false"</code>（非空字串）、<code>[0]</code>（容器有元素，不看內容）。內建 <code>bool()</code> 可以驗證任何值的評估結果。

實用捷徑：<code>if not due_date:</code> 等價於 <code>if due_date is None:</code>，更簡潔，也是真實 codebase 裡最常見的寫法。

冷知識：<code>bool</code> 底層繼承自 <code>int</code>，<code>True + True == 2</code>——知道就好，別在程式碼裡用。最後的判斷題：<code>None</code>、空字串、<code>False</code> 是不同的值，只是剛好都 falsy；當「不存在」（None）和「空值」（""、[]）在語意上是兩回事時，要明確寫 <code>is None</code> 區分，其餘情境用捷徑即可——重點是知道自己在選哪一個。
