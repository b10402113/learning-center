# Default parameters, keyword-only args, and the mutable default trap

## Learning goal

為函式加上預設參數值、用 `*` 強制關鍵字傳參，並避開「可變預設值」這個經典難查 bug。

## Lesson

預設參數讓一個簽名服務兩種情境：<code>def slugify(name, separator="-")</code> 不傳就用連字號，要客製就 <code>slugify("Payments API", separator="_")</code> 覆蓋。

關鍵機制：<strong>預設值在函式定義時評估一次，之後所有呼叫共用同一份</strong>。對字串、數字這種不可變值沒問題；對 list、dict 這種可變物件就是陷阱——<code>def add_tag(name, tags=[])</code> 的那個空 list 是所有呼叫共用的，第二次呼叫會看到第一次 append 的東西，結果跨呼叫累積，而且不報錯，極難查。標準解法是 None 慣用語：預設值設 <code>tags=None</code>，函式內 <code>if tags is None: tags = []</code>，每次呼叫都新建 list。這個 pattern 在 Python codebase 裡到處都是。

參數列表裡單獨的 <code>*</code> 是分隔符：之前的參數可照位置傳，之後的<strong>必須</strong>用關鍵字傳。多個同型別參數靠位置傳很容易搞錯順序，強制寫出參數名讓呼叫端意圖一目瞭然——現代 Python API（包括 FastAPI）大量使用。type hint、<code>*</code>、預設值可以組合成一個現代風格簽名：<code>def slugify(name: str, *, separator: str = "-") -> str</code>。
