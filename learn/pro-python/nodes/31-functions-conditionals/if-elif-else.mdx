# Conditionals — if / elif / else

## Learning goal

用 `if`/`elif`/`else` 寫出多分支邏輯，靠縮排（而非大括號）定義程式碼區塊，並在函式裡組合條件判斷。

## Lesson

條件判斷從 <code>if</code> 開始：<code>elif</code> 可以接任意多個或完全不接，<code>else</code> 最多一個且可省略。條件從上往下依序檢查，第一個成立的分支執行完就離開整串。每個關鍵字結尾是冒號，本體靠縮排定義，跟 <code>def</code> 同一套規則——<code>else</code> 沒對齊它的 <code>if</code>，Python 直接報「找不到匹配的 if 區塊」，看起來像邏輯錯，其實是排版錯。

<code>is_overdue(due_date, status)</code> 是「函式 + 條件」的基本形：沒有到期日回傳 False；已完成也回傳 False；其他情況回傳 <code>due_date &lt; date.today()</code>。三個分支互斥——哪個條件先成立就走哪條、回傳、離開函式。最後一行直接回傳比較結果，因為比較運算式本身就是布林值，不需要再包一層 if/else。

參數決定路徑：隨著傳進來的參數不同，函式內部走不同的路、回傳不同的結果。你讀到的每一個 service 函式、每一個 FastAPI endpoint，放大來看都是這個結構的變形。
