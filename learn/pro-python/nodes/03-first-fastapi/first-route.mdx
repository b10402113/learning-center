# 寫出第一個路由，跑起 dev server

## Learning goal

用 FastAPI 寫一個 GET 路由，啟動 dev server，在瀏覽器看到 JSON 回應。

## Lesson

一個 FastAPI 應用程式最小只需要三行程式碼：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello World"}
```

用 `uv run uvicorn main:app --reload` 啟動，打開 `http://localhost:8000`，就會看到 `{"message": "Hello World"}`。

逐行拆解：`FastAPI()` 建立應用程式實例——一個路由註冊表，你告訴它哪個 URL 對應哪個函式，它處理 HTTP 的一切。`@app.get("/")` 是裝飾器（decorator），表示「用 GET 方法訪問 `/` 時，執行下面的函式」。FastAPI 支援所有標準 HTTP 方法：`@app.get()`、`@app.post()`、`@app.put()`、`@app.delete()`、`@app.patch()`。

路由函式回傳一個 Python dictionary 時，FastAPI 自動做兩件事：把 dictionary 序列化成 JSON，以及設定 `Content-Type: application/json` 回應標頭。不需要手動 `jsonify()` 或包 `HttpResponse`——回傳 Python 物件就好。

`uvicorn` 是 ASGI（Asynchronous Server Gateway Interface）伺服器，負責接收 HTTP 請求並轉給 FastAPI 處理。`--reload` 旗標讓伺服器監聽檔案變化——改了程式碼，伺服器自動重啟。開發時一定要加，但正式環境不要加，因為監聽檔案變化有效能開銷。

在引入真正的資料庫之前，先用 dictionary 模擬資料：

```python
PROJECTS = {
    1: {"id": 1, "name": "Project Alpha", "slug": "project-alpha"},
    2: {"id": 2, "name": "Project Beta", "slug": "project-beta"},
    3: {"id": 3, "name": "Project Gamma", "slug": "project-gamma"},
}

@app.get("/projects")
def list_projects():
    return list(PROJECTS.values())
```

訪問 `/projects` 會回傳一個 JSON 陣列。啟動伺服器後打開 `/docs`，Swagger UI 會列出所有路由，點一下就能直接在瀏覽器裡測試 API——不需要 curl 或 Postman。
