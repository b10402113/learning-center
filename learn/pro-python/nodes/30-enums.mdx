# Enums and the standard library

## Learning goal

Use StrEnum for fixed sets of values, auto() for avoiding duplication

## Steps

1. [[learn/pro-python/nodes/30-enums/magic-string-problem|魔術字串問題：為什麼需要 Enum]] — 認識魔術字串造成的拼字與維護問題，以及 Enum 固定值集合的定位
2. [[learn/pro-python/nodes/30-enums/strenum-basics|定義與檢查 StrEnum：繼承為什麼重要]] — 用 `StrEnum` 定義狀態值並在 REPL 檢查（完成步驟 1 後）
3. [[learn/pro-python/nodes/30-enums/auto-and-type-safety|auto() 與免費的型別安全]] — 用 `auto()` 去重、靠 Enum 取得免費的型別檢查與欄位驗證（完成步驟 2 後）

## Lesson

當同一個狀態字串散落在整個程式碼庫，你很快就會開始猜：是 `in_progress`、`In Progress` 還是全大寫？Enum（列舉）就是標準庫對這個問題的回答——把一組固定不變的值收進一個具名的類別裡，讓編輯器幫你自動補全、讓拼字錯誤在寫下的那一刻就現形、讓不合法的狀態更容易被擋下來。三個步驟依序走過問題本身、`StrEnum` 的定義與檢查方式，以及 `auto()` 與型別安全帶來的免費防護。
