## Learning goal

Use `list[int]`, `dict[str, int]`, and `tuple[str, ...]` to describe the contents of collections.

## Lesson

Saying `items: list` tells the reader almost nothing. Generic types let you say what is inside the container — `list[str]` means "a list of strings." This is the difference between "a box" and "a box of screws."

The three built-in generics you will use most are `list`, `dict`, and `tuple`. The square brackets hold the type arguments: one for `list`, two for `dict`, and either fixed positions or `...` for `tuple`.

```python
# A list of integers
scores: list[int] = [1, 2, 3]

# A dict with string keys and int values
ages: dict[str, int] = {"alice": 30, "bob": 25}

# A tuple of fixed length — first item str, second item int
pair: tuple[str, int] = ("alice", 30)

# A tuple of variable length — all items are str
names: tuple[str, ...] = ("alice", "bob", "carol")
```

For `tuple`, the `...` means "any number of items, all of this type." Without it, the tuple has a fixed length and each position has its own type.

Generics nest naturally. A dict mapping strings to lists of ints reads left to right:

```python
groups: dict[str, list[int]] = {
    "odd": [1, 3, 5],
    "even": [2, 4, 6],
}
```

Read it as "dict of str to list of int." Do not panic at the depth — the structure mirrors the data.
