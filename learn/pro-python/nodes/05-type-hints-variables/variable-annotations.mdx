## Learning goal

使用 `name: type = value` 語法來註解變數，並理解提示在執行時實際的作用。

## Lesson

函式簽章只是全貌的一半。當你能夠註解參數與回傳型別之後，下一步就是把同樣的清晰度帶進函式內部的變數上。

變數註解使用跟函式參數相同的冒號語法。模式是 `name: type = value` —— 冒號放在變數名稱與型別之間，賦值方式跟之前完全相同。

```python
count: int = 0
name: str = "Untitled"
rates: list[float] = []
```

提示讓讀者和像 mypy 這樣的工具知道該變數預期裝載什麼形狀的資料。但這裡有一點很關鍵：Python 在執行時不會強制檢查。你可以把一個已註解的變數重新賦值為完全不同的型別，Python 也不會抱怨。

```python
count: int = 0
count = "urgent"   # 不會報錯 —— Python 在執行時忽略提示
```

提示是對讀者和靜態分析器的承諾，而不是執行時的約束。如果你需要強制檢查，就得靠 mypy 或 Pydantic 這類外部工具。

那麼什麼時候該註解？規則很簡單：當型別無法從右側明顯看出時才註解。空集合是最典型的例子 —— `items: list[str] = []` 告訴讀者這個 list 裡面應該放什麼。像 `cache: dict[str, int] = {}` 這樣的複雜容器同樣受益。一開始是 `None`、之後才會被賦值的變數也值得加上提示，讓讀者知道它最終會裝載什麼型別。

像 `name = "Alice"` 這種簡單案例通常不需要註解。型別已經從字面值看得一清二楚。加上 `: str` 只是重複讀者已經知道的資訊。
