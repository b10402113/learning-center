## Learning goal

Express "this value can be one of several types" using the `|` union operator and `Optional`.

## Lesson

Sometimes a variable legitimately holds more than one type. A function might return a result on success or `None` on failure. A configuration value might be an int or a string. Union types describe exactly that.

Python 3.10 introduced the `|` operator for unions. Read the pipe as "or":

```python
def find(user_id: int) -> User | None:
    if user_id in cache:
        return cache[user_id]
    return None
```

`User | None` means "either a User or None." You can chain more than two: `int | float | str`.

Before `|`, the same idea was written with `Optional[X]` from the `typing` module. `Optional[X]` is exactly the same as `X | None`. It still appears in a lot of older code, so you need to recognize it:

```python
from typing import Optional

def find(user_id: int) -> Optional[User]:
    ...
```

Both forms mean the same thing. In new code, prefer `X | None` — it is shorter and does not need an import.

When you have a union value, narrow it before using type-specific operations. The type checker uses that narrowing to know which branch you are in:

```python
result: int | None = compute()

if result is not None:
    print(result + 1)   # mypy knows result is int here
```

The `is not None` check tells the tool which type you are working with. Without it, mypy would complain that `result` might be `None`.
