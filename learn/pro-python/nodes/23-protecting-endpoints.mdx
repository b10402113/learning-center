# Protecting endpoints

## Learning goal

Use OAuth2PasswordBearer and get_current_user dependency

## Steps

1. [[learn/pro-python/nodes/23-protecting-endpoints/oauth2-setup|OAuth2PasswordBearer 設定與權杖提取]] — 設定 OAuth2PasswordBearer，讓 FastAPI 從 Authorization header 提取權杖
2. [[learn/pro-python/nodes/23-protecting-endpoints/get-current-user|get_current_user 依賴注入]] — 實作驗證 JWT 並取得使用者的依賴函式（after step 1）
3. [[learn/pro-python/nodes/23-protecting-endpoints/protect-routes|用依賴注入保護路由]] — 在路由處理器加入依賴參數即可要求認證（after step 2）
4. [[learn/pro-python/nodes/23-protecting-endpoints/auth-flow-integration|完整認證流程與常見錯誤]] — 串聯註冊、登入、授權請求三步流程，排除常見錯誤（after step 3）

## Lesson

這節課把前面兩課（密碼雜湊、JWT 權杖）的成果串成一個可以實際運作的認證系統。核心只有兩個元件：`OAuth2PasswordBearer` 負責從 HTTP 請求中把權杖挖出來，`get_current_user` 依賴負責驗證權杖並查出使用者。FastAPI 的依賴注入機制讓保護路由變得很宣告式——你只要在處理器函式簽名裡多加一個參數，整個權杖提取與驗證流程就會自動跑完，驗證失敗的回傳 401 也幫你準備好了。
