# Pydantic models for validation

## Learning goal

Define BaseModel subclasses for request/response validation

## Steps

1. [[learn/pro-python/nodes/06-pydantic-models/define-basemodel|定義 Pydantic 模型與型別欄位]] — 繼承 BaseModel 並宣告帶有型別的欄位
2. [[learn/pro-python/nodes/06-pydantic-models/runtime-validation|執行期驗證與 ValidationError]] — 理解 Pydantic 如何在物件建立時自動驗證資料（after step 1）
3. [[learn/pro-python/nodes/06-pydantic-models/response-models|在 FastAPI 使用 response_model]] — 用 response_model 確保 API 輸出結構（after step 1）
4. [[learn/pro-python/nodes/06-pydantic-models/testing-validation|測試 Pydantic 驗證邏輯]] — 用 pytest.raises 驗證錯誤路徑（after step 2）

## Lesson

這節課把「資料驗證」從型別提示的靜態檢查，升級到 Pydantic 的執行期強制執行。你會先學會定義一個 `BaseModel` 子類別，理解欄位型別如何宣告；接著看到 Pydantic 在物件建立時如何自動驗證資料，並在型別不符或缺少必填欄位時拋出 `ValidationError`；然後把這個能力接到 FastAPI 的 `response_model`，讓 API 的輸出結構被自動過濾與驗證；最後用 `pytest.raises` 把驗證邏輯寫成測試，確保錯誤路徑也被覆蓋。
