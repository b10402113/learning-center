<LearningGoal>
會建立變數、分辨「檔案」與「REPL」兩種執行方式，並知道要用 print() 才看得到輸出。
</LearningGoal>

## Lesson

建立變數只要一行——名字、等號、值：<code>payments_api = "payments-api"</code>。沒有型別宣告、沒有 <code>let</code>/<code>var</code> 關鍵字。變數只是一個<strong>綁在值上的名字</strong>：型別屬於值本身，不屬於名字。

跑 Python 有兩條路：<code>uv run main.py</code> 執行檔案，<code>uv run python</code> 打開 REPL（Read-Eval-Print Loop，互動式直譯器）——你打一行、它馬上算一行給你看，離開時直接打 <code>exit</code> 不用加括號。兩者最大的行為差異是<strong>回顯</strong>：REPL 會自動顯示每個運算式的結果，檔案不會。所以一行光禿禿的 <code>"payments-api"</code> 貼進 REPL 會顯示 <code>'payments-api'</code>，放進 main.py 執行則安靜無聲——在檔案裡想看到結果，必須 <code>print()</code>。

```python
"payments-api"          # 在 main.py 裡：什麼都不印
print("payments-api")   # 這樣才看得到
```

<code>print()</code> 可以用逗號一次接多個參數，輸出以空格分隔：<code>print(name, name.strip(), len(name))</code>——快速除錯時最好用的招數。順帶一提：<code>main.py</code> 是「這個模組要被執行、不是要被 import」的慣例名稱，學習階段直接在裡面寫 print 完全可以。

數字直接寫字面值：整數 <code>5</code>、浮點數 <code>2.0</code>，標準算術 <code>+ - * /</code> 都在。兩個細節：整數乘浮點數會得到浮點數（<code>5 * 2.0</code> 是 <code>10.0</code>），而且 Python 沒有 <code>double</code>——浮點數就一種；另外 <code>//</code> 是整數除法（捨去小數）、<code>%</code> 是餘數：<code>13 // 2</code> 是 <code>6</code>，<code>13 % 2</code> 是 <code>1</code>。
