<LearningGoal>
會用 int()、float()、bool() 等內建建構子明確轉換型別，並知道這些內建型別不需要 import。
</LearningGoal>

## Lesson

要把<strong>值本身</strong>從一種型別換成另一種，最可靠的做法是明確轉換（explicit conversion）：每個基礎型別都有一個同名建構子（constructor）——<code>int("42")</code> 得到整數 <code>42</code>、<code>float("3.14")</code> 得到 <code>3.14</code>、<code>str(42)</code> 得到 <code>"42"</code>；集合型別 <code>list()</code>、<code>dict()</code>、<code>set()</code> 同理。<code>bool()</code> 把任何值轉成真假：<code>bool(0)</code> 是 <code>False</code>、<code>bool(1)</code> 是 <code>True</code>——每個值都有真值（truthiness），後面的單元會正式展開。

最常見的實戰場景：<strong>外部資料進來時幾乎都是字串</strong>。使用者輸入、URL query parameter、JSON 欄位——拿到 <code>"42"</code> 想當數字用，就得 <code>int("42")</code> 轉過去，不然 <code>"42" + 1</code> 直接 <code>TypeError</code>。

這些建構子全部<strong>不需要 import</strong>：<code>int</code>、<code>float</code>、<code>bool</code>、<code>list</code>、<code>dict</code>、<code>set</code> 是內建（built-in）型別，Python 啟動時就在命名空間裡。對照組是標準庫模組（<code>datetime</code>、<code>pathlib</code>、<code>logging</code>、<code>re</code>）：同樣是 Python 自帶、不用安裝，但要明確 import 才能用。隱轉換也存在（整數乘浮點數會得到浮點數），但依賴隱轉換的程式碼看不出型別在哪裡變了——轉換要明確寫出來。
