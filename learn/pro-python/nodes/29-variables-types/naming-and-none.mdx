<LearningGoal>
會用 snake_case 命名變數、避開 list/dict 等內建名稱，並用 is None 正確檢查「值刻意缺失」。
</LearningGoal>

## Lesson

Python 變數的慣例命名是 <strong>snake_case（蛇形命名）</strong>：全小寫、單字間用底線——<code>total_tasks</code>、<code>payments_api</code>，不是 camelCase 也不是 PascalCase。

鐵律：<strong>內建名稱永遠不拿來當變數名</strong>。<code>list = [1, 2, 3]</code> 完全合法，但這一行會讓內建的 <code>list()</code> 建構子被<strong>遮蔽（shadow）</strong>——模組裡後續所有 <code>list(...)</code> 呼叫都會壞掉（<code>TypeError: 'list' object is not callable</code>），而且錯誤訊息完全不會提示是你自己蓋掉的。<code>dict</code>、<code>set</code>、<code>int</code>、<code>str</code>、<code>print</code> 同理。

<code>None</code> 是 Python 的 null——特殊關鍵字，意思是「<strong>刻意地</strong>沒有值」，常當旗標用：一開始設 <code>current_user = None</code>，之後用 <code>if current_user is None:</code> 分流。語意上要分清楚：<code>""</code> 和 <code>0</code> 是真實存在的值（空的名字、數量為零），<code>None</code> 是「這個位置還沒有值」——「還沒填」用 <code>None</code>、「填了但留空」用 <code>""</code>，混用會讓讀的人猜不出你的意圖。

檢查 None 的慣用寫法是<strong>身分比較</strong>：<code>if x is None:</code>，不是 <code>== None</code>。<code>is</code> 問「是同一個物件嗎」，<code>==</code> 問「相等嗎」；<code>None</code> 全 Python 只有一個實例，<code>is</code> 既精確又快，而且不怕自訂 <code>__eq__</code> 讓 <code>== None</code> 回傳怪結果。Python 社群的鐵律：一律 <code>is None</code>。
