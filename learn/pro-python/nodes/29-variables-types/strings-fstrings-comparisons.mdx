<LearningGoal>
會用字串內建方法與 f-string 組字串，並知道比較運算子永遠回傳布林值（True/False）。
</LearningGoal>

## Lesson

字串在 Python 裡自帶一箱工具，方法還能<strong>串接</strong>——前一個的輸出直接餵給下一個。把專案名稱整理成 URL 用的 slug（網址片段）是典型流程：<code>"  Payments API  ".strip().lower().replace(" ", "-")</code> 得到 <code>"payments-api"</code>。在 VS Code 打 <code>name.</code> 再按 Tab，會列出所有字串方法與一行說明——探索字串能力最快的方式。

把值放進字串，標準答案是 <strong>f-string</strong>：字串前加 <code>f</code>，大括號放變數——<code>f"The name is {name}"</code>。大括號裡可以放<strong>整個運算式</strong>並加格式：<code>f"Total: {price * quantity:.2f}"</code> 先算乘法再固定兩位小數；<code>{name!r}</code> 顯示 repr 形式。實務原則：<strong>組字串一律用 f-string</strong>——用 <code>+</code> 串字串難讀且有效能瑕疵。

比較運算子六兄弟：<code>==</code>（等於）、<code>!=</code>（不等於）、<code>&lt;</code>、<code>&gt;</code>、<code>&lt;=</code>、<code>&gt;=</code>。關鍵事實：<strong>比較的結果永遠是布林值</strong>，只有 <code>True</code>/<code>False</code> 兩種，而且是大寫開頭——跟 JavaScript 的小寫 <code>true</code>/<code>false</code> 不同，兩邊都寫的人容易手滑。字串本身也是一種 collection（集合），可以用 for 迴圈逐字走過——後面的集合單元會正式展開。
