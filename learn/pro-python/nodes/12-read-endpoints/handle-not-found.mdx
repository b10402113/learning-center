# 查詢不到資料時回傳 404

## Learning goal

當 `session.get()` 回傳 `None` 時，拋出 `HTTPException(status_code=404)` 回傳標準 REST 錯誤。

## Lesson

如果 `session.get()` 找不到記錄，直接回傳 None，API 會回應 200 OK 加上 body null。客戶端不知道是「找到了但值是空」還是「根本不存在」——這違反 REST 語義。

FastAPI 提供 `HTTPException`，直接對應 HTTP 狀態碼。`raise HTTPException(...)` 會立即停止路由執行，FastAPI 把它轉成對應的 HTTP 回應：

```python
from fastapi import HTTPException

@app.get("/projects/{project_id}")
def get_project(project_id: int, session: Session = Depends(get_session)):
    project = session.get(Project, project_id)
    if project is None:
        raise HTTPException(status_code=404, detail="Project not found")
    return project
```

Python 慣例用 `is None` 判斷空值，因為 `is` 比較物件身份（identity），比 `==` 更精確。

`detail` 不只能是字串，任何 JSON 可序列化的資料都可以——可以放字典、列表、數字。

常見狀態碼：200 成功讀取、201 成功建立、204 成功但無 body、400 請求格式錯誤、404 資源不存在、409 資料衝突、422 驗證錯誤（FastAPI 自動處理）、500 伺服器內部錯誤。
