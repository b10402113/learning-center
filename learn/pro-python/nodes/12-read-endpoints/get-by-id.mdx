# 用 session.get() 查詢單筆資料

## Learning goal

用 `session.get(Model, id)` 從 Postgres 抓回一筆 Project，並在 API 路由中回傳。

## Lesson

之前的課程用 Python dictionary 模擬資料。dictionary 不是執行緒安全的、關掉伺服器資料就沒了、找不到會噴 KeyError 而不是 404。真正解決問題的方法是讓 SQLModel 和 SQLAlchemy 跟 PostgreSQL 對話。

`session.get(Model, primary_key)` 是 SQLModel 和 SQLAlchemy 最基本的查詢方法。給它模型和主鍵，它回傳那筆記錄，找不到就回傳 None：

```python
@app.get("/projects/{project_id}")
def get_project(project_id: int, session: Session = Depends(get_session)):
    project = session.get(Project, project_id)
    return project
```

`session.get()` 會根據主鍵產生 `SELECT * FROM project WHERE id = ?`。因為用主鍵查，SQLAlchemy 內部會先檢查快取（identity map）——如果這筆記錄已經在 session 裡，就不會真的去資料庫查。

`session.get()` 回傳的是一個 Project 實例。FastAPI 搭配 response model 宣告，會自動把它序列化成 JSON。`response_model=Project` 做兩件事：驗證回傳資料符合 Project 結構、在 API 文件裡顯示回應格式。

找不到時 `session.get()` 回傳 None，不是拋例外。如果直接回傳 None，FastAPI 會回 null 而不是 404——這通常不是你要的。下一步課會教你怎麼處理。
