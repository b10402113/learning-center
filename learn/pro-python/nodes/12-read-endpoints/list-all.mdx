# 用 session.exec() 列出所有資料

## Learning goal

用 `session.exec(select(Model))` 抓回全部 Project，組成 JSON 陣列回傳。

## Lesson

`session.get()` 只能查主鍵。要拿全部記錄，需要用 `select()` 建構查詢，再用 `session.exec()` 執行。`select(Project)` 產生 `SELECT * FROM project`。`session.exec(statement)` 回傳一個 Result 物件，呼叫 `.all()` 把所有記錄放進一個 list。

```python
from sqlmodel import select

@app.get("/projects")
def list_projects(session: Session = Depends(get_session)):
    statement = select(Project)
    projects = session.exec(statement).all()
    return projects
```

`select()` 後面可以串 `.where()` 加條件。`.first()` 回傳第一筆或 None，`.one()` 強制要求只能有一筆（否則拋例外）。

如果表格有十萬筆記錄，`.all()` 會全部載進記憶體。實務上用 `.offset()` 和 `.limit()` 做分頁——前端傳 `?skip=0&limit=10`，路由參數接起來。沒有加 `order_by` 時，資料庫不保證回傳順序，每次查詢可能不同。
