<LearningGoal>
能用 set 自動保持唯一值、用 dict 做鍵值對應並對應 JSON 結構，並用 .get() 帶預設值安全存取缺失的鍵。
</LearningGoal>

## Lesson

`set`（`{}`）和 `dict`（`{key: value}`）用同一對大括號，一個冒號之差就是兩種東西。`set` 只收**唯一值**：重複的元素丟進去不會報錯，Python 只是靜靜地不存第二次（`{"high", "medium", "high"}` → 剩三選二）。它是**無序**容器——不要期待印出來的順序和定義時一樣；但判斷「值在不在裡面」非常快。空的大括號 `{}` 建的是 dict，要建空 set 得用 `set()`。set 還支援聯集、交集、差集這類集合運算——超出這堂課範圍，但讀別人的 code 要認得。

`dict` 把**鍵（key）**對應到**值（value）**，並且和 JSON 的結構直接對上——API 收到的 request body、回傳的 response，在 Python 這邊的形狀就是 dict。存取有兩把刀：中括號遇到缺失的 key 直接拋 `KeyError`；`.get(key)` 回傳 `None`，`.get(key, default)` 帶自訂預設值——處理不完整 JSON 的安全寫法。`.keys()`、`.values()`、`.items()` 分別拿到所有鍵、所有值、一對對的 key-value 配對。

一個重要限制：**dict 的 key 必須是不可變的**。key 是查找用的「地址」，list 這種可變物件會在記憶體裡被改動、地址就對不上，所以 Python 直接拒絕（`TypeError: unhashable type: 'list'`）；tuple 不可變，可以當 key。value 沒有這個限制，但同樣建議保持型別一致。
