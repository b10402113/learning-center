<LearningGoal>
能用同一套 for 語法走訪 list、tuple、set、dict，並用 .items() 搭配 tuple unpacking 在迴圈裡同時拿到 key 與 value。
</LearningGoal>

## Lesson

Python 的 `for` 迴圈只有一種寫法：`for item in collection:`，對 list、tuple、set 完全通用。迴圈變數是你取的方便名字，每一輪自動更新；要留心的是它**迴圈結束後不會消失**——會殘留在原地、停在最後一輪的值，拿它判斷「迴圈有沒有跑過」是常見 bug 來源。

dict 的走訪有三種：`.keys()` 只要鍵、`.values()` 只要值、`.items()` 兩個都要。第三種是重點——`for key, value in person.items():` 每一輪拿到一個 `(key, value)` 配對，loop header 用 tuple 解包（unpacking）一次拆成兩個變數，兩者同時更新。這是 Python 裡最常見的 dict 走訪寫法。

真實資料不會只有一層：接上真資料庫之前，mock database 最常見的形狀就是 **list of dicts**——外層 list 提供順序，每個 dict 裝一筆記錄。四種容器的選擇總結：會變的序列用 list（保序、可變）、固定的一組用 tuple（保序、不可變）、要唯一用 set（去重、附贈集合運算）、要查找用 dict（名字對應值，JSON 資料最常見的形狀）。
