<LearningGoal>
能依「資料該不該被改動」選擇 list 或 tuple，並避開 in-place 方法（append、sort）不回傳新值這個經典陷阱。
</LearningGoal>

## Lesson

Python 最常見的四種容器：`list`（`[]`，有序可變）、`tuple`（`()`，有序不可變）、`set`（`{}`，無序去重）、`dict`（`{key: value}`，鍵值對應）。這一步先攻前兩種。第一個規矩：不要把變數取名成 `list`、`dict`、`set`——會遮蔽內建名稱，之後到處出現難查的怪事。

`list` 是會長大的序列：`append()` 加一個元素、`extend()` 接上多個、`pop()` 移除並回傳最後一個。關鍵行為是 `append()` **不回傳任何東西**（回傳 `None`），而是就地（in place）修改 list 本身。這個行為配上 `sort()` 就是經典 bug：

```python
names = ["carol", "alice", "bob"]
result = names.sort()   # result 是 None，names 被就地排好了
```

判斷的經驗法則：**方法呼叫在實例上**（`names.sort()`）→ 傾向就地修改、回傳 `None`；**內建函式把資料當參數**（`sorted(names)`）→ 傾向回傳新值、不動原本。字串和 list 之間靠 `split()`（拆開，記得明確指定分隔符）和 `join()`（接回，結尾不多逗號）互轉，CSV 資料進出就靠這一對。

`tuple` 是生下來就不改的有序容器：沒有 `append`，呼叫直接 `AttributeError`；重新指派變數只是把名字指向一個**新的** tuple，原本的一個位元都沒變。適用場景是固定綁在一起的值——座標、配對、RGB 色值。兩個語法細節：單元素 tuple 一定要尾逗號 `(1,)`；解包（unpacking）`a, b = (1, 2)` 一次把值拆給多個變數。tuple 因為不可變可以當 dict 的 key——list 不行，這個限制下一步會看到它發威。
