<LearningGoal>
能把簡單的 for 迴圈改寫成帶過濾條件的 list comprehension，認識 dict/set comprehension、generator 與 zip，並判斷何時該退回普通迴圈。

## Lesson

Comprehension（推導式）是 Python 最招牌的功能之一：把「簡單、重複」的迴圈收進一行，從既有的集合建成新的集合。你在 crud 層會天天看到 `[t["title"] for t in tasks if not t["done"]]` 這種一行——讀不懂它，讀 codebase 就會處處卡住；會寫它，很多函式瞬間變短。

從 for 迴圈到一行：任務是把一排專案名稱轉成 URL slug。用 for 迴圈是這樣：

```python
project_names = ["Payments API", "Ops Console", "Portal"]
slugs = []
for name in project_names:
    slugs.append(name.lower().replace(" ", "-"))
```

Comprehension 把整個「建 list → 迴圈 → append」收成一行：

```python
slugs = [name.lower().replace(" ", "-") for name in project_names]
# → ['payments-api', 'ops-console', 'portal']
```

讀法是固定的：**左邊是輸出元素的長相**（每個元素經過什麼轉換），**右邊是來源迴圈**（從哪個集合、用什麼變數名拿出來）。

過濾：把 `if` 放到最後：

```python
tasks = [
    {"title": "Write docs", "done": True},
    {"title": "Fix login bug", "done": False},
    {"title": "Deploy API", "done": False},
]

[t["title"] for t in tasks]              # 沒有過濾：三個標題全進來
[t["title"] for t in tasks if not t["done"]]
# → ['Fix login bug', 'Deploy API']      # 過濾：只要未完成的
```

條件放在**整個推導式的最後**：`[轉換 for 變數 in 集合 if 條件]`。條件不成立的元素直接被跳過。

拿 comprehension 算數：「未完成的任務有幾個？」——每個未完成任務貢獻一個 1，通通加起來：

```python
sum(1 for t in tasks if not t["done"])
# → 2
```

注意這裡連方括號都省了：comprehension 直接當參數傳進 `sum()`。同一家族還有兩個常用的內建：`any()` 檢查「是不是至少一個符合」、`all()` 檢查「是不是全部符合」：

```python
any(not t["done"] for t in tasks)   # 還有未完成的嗎？→ True
all(t["done"] for t in tasks)       # 全部都完成了嗎？→ False
```

Generator comprehension：方括號版會**一次把整個 list 建在記憶體裡**。資料小的時候無所謂；資料大的時候，把方括號換成括號，就得到 generator comprehension：

```python
gen = (1 for t in tasks if not t["done"])
print(gen)        # <generator object ...>——看不到內容！

sum(1 for t in tasks if not t["done"])   # 餵給 sum() 照常工作
```

generator 不預先建表，而是**被要求的當下才產生下一個值**，值用完就結束——所以你沒辦法像 list 那樣把它印出來、索引它。它適合「值只需要走一遍」的場景：`sum()`、`any()`、`all()`、只跑一次的 for 迴圈。要走多遍、要保留結果，就用回 list comprehension。原則很簡單：**一次性消費用 generator（省記憶體），要留下來用就 list**。

dict comprehension、set comprehension 與 zip：Comprehension 不是 list 的專利——換括號就換容器：

```python
{name.lower() for name in project_names}          # set comprehension：去重的轉換結果
{t["title"]: t["done"] for t in tasks}            # dict comprehension：key: value 的轉換結果
```

最後一個好用的配角是 `zip`：把兩個 list **依位置配對**（第 0 個對第 0 個、第 1 個對第 1 個……），配好的東西餵給 `dict()` 就快速變出一個字典：

```python
keys = ["name", "slug"]
values = ["Payments API", "payments-api"]
dict(zip(keys, values))   # → {"name": "Payments API", "slug": "payments-api"}
```

何時不要用：Comprehension 的適用條件——你在**轉換**資料（每個元素經過同樣的處理）、邏輯**短**——可能加一個 `if` 過濾、一行讀起來**清楚**。經驗法則：**超過兩行就退回普通 for 迴圈**。Comprehension 是讓短邏輯變清晰的工具，不是把長邏輯硬塞成一行的方法——可讀性輸了，它就失去了存在意義。
