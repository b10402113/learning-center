# Type hint syntax for parameters and return types

## Learning goal

看懂並寫出函式參數與回傳值的 type hint 語法：`name: str` 和 `-> str`。

## Lesson

從一個沒有 type hint 的函式說起。你應該寫過這種函式：

```python
def slugify(name, separator):
    return name.strip().lower().replace(" ", separator)
```

這個函式能用，但外人看不出 `name` 和 `separator` 該傳什麼型別，也不知道它會回傳什麼。Type hint 就是為了解決這個問題——在參數和回傳值旁邊加上型別註解。

**參數的 type hint：`參數名: 型別`**。在參數名稱後面加上冒號和型別，就完成了參數的 type hint：

```python
def slugify(name: str, separator: str):
    return name.strip().lower().replace(" ", separator)
```

`name: str` 的意思是「`name` 預期是一個字串」。`separator: str` 同理。這不會強制你一定要傳字串——Python 在執行時不會檢查。它只是給讀程式碼的人和靜態分析工具看的。

**回傳值的 type hint：`-> 型別`**。在函式參數列表的右括號後面，加上箭頭和回傳型別：

```python
def slugify(name: str, separator: str) -> str:
    return name.strip().lower().replace(" ", separator)
```

`-> str` 表示「這個函式預期回傳一個字串」。注意箭頭是減號加大於號，中間沒有空格。

把參數 hint 和回傳 hint 放在一起，就是完整的函式 type hint 寫法：

```python
def 函式名(參數1: 型別1, 參數2: 型別2) -> 回傳型別:
    ...
```

幾個重點：每個參數的 hint 是獨立的——可以有些參數有 hint，有些沒有，但通常會全部加。回傳 hint 只有一個——寫在函式定義的最後一行。如果函式不回傳任何值（也就是回傳 `None`），hint 寫 `-> None`。

實際例子：沒有回傳值的函式，回傳型別寫 `None`：

```python
def greet(name: str) -> None:
    print(f"Hello, {name}")
```

回傳布林值：

```python
def is_valid_email(email: str) -> bool:
    return "@" in email
```

回傳整數：

```python
def count_words(text: str) -> int:
    return len(text.split())
```

這是新手最常混淆的地方：**type hint 只是提示，不是限制**。就算你寫了 `name: str`，你還是可以傳一個整數進去，Python 不會報錯。Type hint 的真正價值在於：讓 IDE 能提供更好的自動完成和錯誤提示；讓 `mypy` 這類靜態檢查工具在執行前就抓到型別錯誤；讓讀程式碼的人一眼看懂函式的輸入輸出。
