# Course overview and tooling setup

## Learning goal

Understand what we're building and install UV, VS Code, Docker

## Steps

1. [[learn/pro-python/nodes/01-course-overview/what-youll-build|課程概覽：你將打造什麼？]] — 了解 Release Tracker API 專案與課程工具鏈
2. [[learn/pro-python/nodes/01-course-overview/why-python|為什麼選 Python？]] — 理解 Python 的生態優勢與限制（after step 1）
3. [[learn/pro-python/nodes/01-course-overview/tooling-setup|工具驗證與環境設定]] — 驗證並設定 Docker、VS Code、UV 環境（after step 1）

## Lesson

這節課是整門課程的起點。你會先看到我們要打造的完整專案——一個帶 Swagger UI、Postgres 資料庫和 Docker 部署的 Release Tracker API——對課程的全貌建立心理地圖。接著了解為什麼 Python 是這門課的選擇：它的生態系、快速開發的能力，以及它在效能上的取捨。最後動手驗證和設定開發工具，確保你的環境可以順利跑起後續的每一堂課。三步走完，你應該清楚知道「這門課在做什麼」、「為什麼用 Python」以及「我的工具都準備好了」。
