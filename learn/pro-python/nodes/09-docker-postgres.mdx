# Docker Postgres setup

## Learning goal

Run Postgres in Docker, configure compose.yaml with volumes and healthchecks

## Steps

1. [[learn/pro-python/nodes/09-docker-postgres/why-docker-postgres|為什麼用 Docker 跑 Postgres？]] — 理解為什麼本地開發該用 Docker 跑 Postgres，而不是直接裝在主機上
2. [[learn/pro-python/nodes/09-docker-postgres/compose-yaml-config|compose.yaml 的結構與設定]] — 能讀懂並寫出一個 Postgres 服務的 compose.yaml（after step 1）
3. [[learn/pro-python/nodes/09-docker-postgres/run-verify-container|啟動容器並驗證 Postgres 是否正常]] — 能用 docker compose 啟動 Postgres，並用健康檢查與連線測試確認它真的在跑（after step 2）
4. [[learn/pro-python/nodes/09-docker-postgres/sqlmodel-orm|SQLModel：FastAPI 的 ORM 首選]] — 理解 SQLModel 如何同時擔任 Pydantic 驗證與 SQLAlchemy ORM 的角色（after step 3）

## Lesson

這節課把 FastAPI 應用連上真正的資料庫。我們會用 Docker 跑 PostgreSQL，寫一個 compose.yaml 定義服務、volume 與健康檢查，啟動容器並驗證它活著，最後用 SQLModel 這個 ORM 把 Python 物件對應到資料庫表格。走完這四步，你的應用就不再有失憶症——重啟伺服器，資料還在。
