# First FastAPI app

## Learning goal

Write a route, run the dev server, see JSON in the browser

## Steps

1. [[learn/pro-python/nodes/03-first-fastapi/what-is-fastapi|什麼是 FastAPI？為什麼選它？]] — 認識 FastAPI 的核心定位與 Flask/Django 的差異
2. [[learn/pro-python/nodes/03-first-fastapi/first-route|寫出第一個路由，跑起 dev server]] — 用 FastAPI 寫一個 GET 路由，啟動 dev server，在瀏覽器看到 JSON 回應（after step 1）
3. [[learn/pro-python/nodes/03-first-fastapi/path-parameters|路徑參數與自動型別驗證]] — 在路由裡用 `{param}` 語法定義路徑參數，觀察 FastAPI 自動驗證型別（after step 2）
4. [[learn/pro-python/nodes/03-first-fastapi/pydantic-response|用 Pydantic 模型塑形回應]] — 定義 Pydantic BaseModel 規範 API 回應結構（after step 3）

## Lesson

FastAPI 是現代 Python web 框架，建立在 Starlette（非同步）和 Pydantic（驗證）之上。它的核心賣點是用 Python 型別提示（type hints）驅動一切——路由參數、請求驗證、API 文件全部自動生成，不需要額外 DSL 或設定檔。

這節課從零開始：先理解 FastAPI 在框架光譜中的位置（介於 Flask 的精簡和 Django 的全功能之間），然後動手寫出第一個路由、啟動 dev server、看到 JSON 回應。接著加入路徑參數，體驗 FastAPI 的自動型別驗證——傳錯型別直接回 422 錯誤。最後用 Pydantic 模型定義回應結構，把內部資料和 API 輸出分離。

走完這四步，你就有一個能跑的 API，雖然資料還存在 dictionary 裡，但路由、參數驗證、回應塑形這些核心機制都到位了。
