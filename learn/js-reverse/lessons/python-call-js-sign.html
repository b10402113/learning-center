execjs 编译与调用：Python 调 JS 拿 sign

实战：sign 逆向（JS 执行） · 步骤 3/5

学习目标

能用 execjs.compile 加载 JS 文件并调用 get_sign 函数，完成有道翻译 sign 请求。

execjs 的三步调用链

execjs 的固定套路只有三步，记住就不会乱：

  1. compile：把 JS 代码（字符串或文件内容）编译成可调用的上下文对象
  2. call：按函数名调用 JS 函数，参数直接往后传
  3. 拿返回值：JS 函数的返回值自动转成 Python 类型（数字、字符串、列表、字典）

第一步：compile 编译 JS

execjs 支持两种编译方式。第一种是直接传 JS 代码字符串：

import execjs

js_code = """
const crypto = require("crypto");
function get_sign(t) {
    const signStr = `client=fanyideskweb&mysticTime=${t}&product=webfanyi&key=fsdsogkndfokasodnaso`;
    return crypto.createHash("md5").update(signStr).digest("hex");
}
"""
js_compile = execjs.compile(js_code)

第二种是读取 JS 文件后编译，这在实际逆向中更常见——你抠出来的 JS 代码通常保存在文件里：

import execjs

with open("03 有道翻译.js", encoding="utf-8") as f:
    js_compile = execjs.compile(f.read())

两种方式得到的 js_compile 是同一个东西：一个可调用的上下文对象。

第二步：call 调用 JS 函数

call() 的第一个参数是 JS 函数的名称（字符串），后面的参数会原样传给 JS 函数：

import time

# 获取当前毫秒时间戳
t = int(time.time() * 1000)

# 调用 JS 函数，返回 sign
sign = js_compile.call("get_sign", t)
print("sign:", sign)

如果 JS 函数返回的是数组（比如 return [sign, e]），execjs 会自动把它转成 Python 列表：

result = js_compile.call("get_sign")
sign = result[0]   # 签名字符串
timestamp = result[1]  # 时间戳
print(f"sign={sign}, time={timestamp}")

第三步：发请求

拿到 sign 后，剩下的就是标准的 requests 流程：把 sign 和时间戳塞进 POST 请求体，发给有道翻译接口：

import requests

url = "https://dict.youdao.com/webtranslate"
data = {
    "i": "dog",
    "from": "AUTO",
    "to": "AUTO",
    "domain": "0",
    "dictResult": "true",
    "keyid": "webfanyi",
    "sign": sign,
    "client": "fanyideskweb",
    "product": "webfanyi",
    "appVersion": "1.0.0",
    "vendor": "web",
    "pointParam": "client,mysticTime,product",
    "mysticTime": t,
    "keyfrom": "fanyi.web"
}

resp = requests.post(url, data=data)
print(resp.text[:200])  # 打印前 200 字符

完整脚本

把上面三步拼起来，就是一个完整的有道翻译请求脚本：

import execjs
import requests
import time

# 1. 编译 JS
with open("03 有道翻译.js", encoding="utf-8") as f:
    js_compile = execjs.compile(f.read())

# 2. 调用 JS 获取 sign
t = int(time.time() * 1000)
sign = js_compile.call("get_sign", t)

# 3. 发请求
url = "https://dict.youdao.com/webtranslate"
data = {
    "i": "dog",
    "from": "AUTO",
    "to": "AUTO",
    "client": "fanyideskweb",
    "product": "webfanyi",
    "sign": sign,
    "mysticTime": t,
    "keyfrom": "fanyi.web",
    # ... 其他参数省略
}
resp = requests.post(url, data=data)
print(resp.text[:200])

常见踩坑

  • JS 文件编码问题：Windows 上抠出来的 JS 文件可能是 GBK 编码，用 encoding="utf-8" 打开会报错。遇到乱码时试试 encoding="gbk" 或用 errors="ignore"。
  • node 未安装：execjs 找不到 JS 运行时会抛出 RuntimeError: Could not find a runtime。Mac 上装 node 最简单的方式是 brew install node。
  • JS 代码依赖浏览器对象：如果 JS 里用了 window、document，在 node 里跑会报错。这时需要补环境（后面节点会讲），先把这些对象声明为空对象即可：const window = {};

小结

execjs 的调用链就三步：compile 编译 → call 传参调用 → 拿返回值。sign 生成逻辑原封不动留在 JS 里，Python 只负责拿结果发请求。下一步，我们把 AES 解密逻辑也搬到 JS 里。
