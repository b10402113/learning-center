asyncio 四个核心概念与 wait/await

js-reverse · 06-asyncio · Step 3/4

学习 goal

能独立写出「特殊函数 + 任务列表 + wait + 回调解析」的 asyncio 多任务协程代码，并解释每个核心概念的角色。

从协程到 asyncio

协程是一种思想，asyncio 是 Python 3.6+ 内置的协程框架。它提供了一套完整的机制来定义、调度、执行协程。理解 asyncio 的关键是掌握四个层层递进的概念。

概念一：特殊函数

用 async def 定义的函数叫特殊函数（async function）。调用它时，不会立即执行函数体，而是返回一个协程对象。

async def fetch(url):
    response = await aiohttp.ClientSession().get(url)
    return await response.text()

# 调用特殊函数不会执行，而是返回协程对象
coro = fetch('http://example.com')
print(coro)  # <coroutine object fetch at 0x...>

注意：特殊函数内部不能出现不支持异步的代码（比如 time.sleep 或 requests），否则会中断整个异步效果。要用 asyncio.sleep 代替 time.sleep。

概念二：协程对象

协程对象是调用特殊函数后返回的对象。它只是一组「待执行的操作」的封装，本身不会运行。必须把它交给事件循环才能执行。

概念三：任务对象

任务对象（Task）是高级协程。它和普通协程对象的区别在于：可以绑定回调函数。

import asyncio

async def fetch(url):
    return "html content"

# 把协程对象包装成任务对象
task = asyncio.ensure_future(fetch('http://example.com'))

# 绑定回调函数——任务完成后自动调用
task.add_done_callback(lambda t: print(t.result()))

回调函数有且仅有一个参数 t（就是任务对象本身），用 t.result() 可以拿到特殊函数的返回值。

概念四：事件循环

事件循环（Event Loop）是装载任务对象并启动执行的容器。它是 asyncio 的发动机——所有协程都要放进事件循环里才能跑。

loop = asyncio.get_event_loop()
loop.run_until_complete(task)

多任务：wait 和 await

单个任务没意义。多任务协程的关键是 asyncio.wait(tasks)：它接收一个任务列表，给每个任务赋予「可被挂起」的权限。

await 必须加在每一个阻塞操作前面。它的作用是人为检测阻塞并挂起任务——遇到 await 就交出控制权，让事件循环去跑别的任务。

async def main():
    tasks = [
        asyncio.ensure_future(fetch(url1)),
        asyncio.ensure_future(fetch(url2)),
        asyncio.ensure_future(fetch(url3)),
    ]
    # wait 给每个任务赋予可挂起的权限
    done, pending = await asyncio.wait(tasks)
    for t in done:
        print(t.result())

完整链路

四个概念的协作关系：

  1. async def 定义特殊函数
  2. 调用特殊函数 → 得到协程对象
  3. asyncio.ensure_future → 包装成任务对象（可绑定回调）
  4. 任务对象放进事件循环 → loop.run_until_complete 启动
  5. 内部用 await 挂起阻塞操作，asyncio.wait 调度多任务
