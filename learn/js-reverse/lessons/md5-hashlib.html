MD5 摘要算法与 hashlib.md5

js-reverse · 步骤 2/5 · Python 标准库里的单向散列工具

MD5（Message-Digest Algorithm 5）是一种单向散列函数。单向意味着你只能从明文算出密文，不能从密文倒推回明文。散列意味着无论输入多长，输出永远固定在一百二十八位——也就是三十二个十六进制字符。这两个特性让 MD5 成了签名场景里的常客：服务器不需要知道你的明文是什么，只需要用同样的规则算一遍，看结果跟你发过来的 sign 是否一致。

Python 里的 MD5 调用链

在 Python 里用 MD5 只需要一行导入：import hashlib。实际计算分两步走。第一步，创建一个 md5 对象：m = hashlib.md5()。第二步，往对象里喂数据并取出结果。喂数据用 m.update(s.encode())，其中 s.encode() 把字符串转成 UTF-8 字节——MD5 只接受字节，不接受字符串。取结果用 m.hexdigest()，返回的就是三十二位小写十六进制字符串。

整个调用链可以写成四行：

import hashlib
m = hashlib.md5()
m.update(s.encode())
sign = m.hexdigest()

也可以压成一行：sign = hashlib.md5(s.encode()).hexdigest()。两种写法完全等价，选哪个取决于你个人偏好。

必须踩过的两个坑

第一个坑：update 可以接受字节，但不能接受字符串。如果你写了 m.update(s) 而 s 是字符串，Python 会抛出 TypeError: Unicode-objects must be encoded before hashing。这个报错在逆向初期很常见，只要记得先 .encode() 就不会卡住。

第二个坑：MD5 对大小写敏感。"abc" 和 "ABC" 算出来的 MD5 完全不同。在逆向 sign 时，拼接字符串里的每个字符都必须和 JS 端或服务器端的完全一致——包括大小写、空格、& 和 = 的位置。任何一个字符的差异都会导致摘要面目全非。

逆向不是破解

MD5 的不可逆性也意味着：当你拿到一个 sign 值时，你不需要尝试去「解密」它。你只需要按照同样的规则，把参与拼接的参数重新拼一遍、重新算一遍，看结果是否匹配。这就是逆向工程和密码学攻击的本质区别——你不是在破解算法，而是在复现算法。
