摘要演算法家族

學習目標：理解 md5、sha1、sha256 都是單向雜湊函數：不可逆、同輸入同輸出、輸出定長；能從十六進位長度識別演算法，並在 Python 裡用 hashlib 復現「鹽 + 資料」的加鹽摘要。

現象：你看到一串固定長度的十六進位字串

前端請求參數裡常出現這種固定長度的字串：

md5:    65a8e27d8879283831b664bd8b7f0ad4          (32 字元)
sha1:   2ef7bde608ce5404e97d5f042f95f89f1c232871  (40 字元)
sha256: 5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8  (64 字元)

它們看起來隨機，但同一个輸入永遠得到同一個輸出。這就是摘要演算法（message digest / hash function）。

核心特徵

  • 單向性：不可逆。從雜湊值推不回原始資料。
  • 確定性：同輸入必得同輸出。
  • 定長輸出：無論輸入多大，輸出長度固定（md5 = 128 位元 = 32 十六進位字元）。
  • 雪崩效應：輸入差一個位元，輸出看起來完全不同。

從長度識別演算法

這在逆向裡非常實用：

十六進位長度位元數演算法
32128md5
40160sha1
64256sha256
128512sha512

Python 實作：加鹽摘要

網站儲存密碼或產生 sign 參數時，很少直接對明文做 md5，而是加鹽（salt）：

import hashlib

salt = "abc123"
password = "my_password"

# 第一次：直接 md5
m = hashlib.md5()
m.update(password.encode())
print(m.hexdigest())

# 第二次：加鹽 md5
m2 = hashlib.md5()
m2.update(salt.encode())
m2.update(password.encode())
print(m2.hexdigest())

呼叫多次 update 等同於把字串拼接後再 hash：hashlib.md5((salt + password).encode())。這在復現前端 sign 參數時非常常見。

實戰用途

  • 口令儲存：資料庫存 md5(鹽 + 密碼)，而非明文。
  • 一致性校驗：下載檔案後算 md5，比對官方提供的 md5 確認檔案未損毀。
  • sign 參數：把請求參數按特定順序拼接後加鹽 md5，伺服器端用同樣的鹽複算驗證請求未被竄改。

安全提醒

md5 和 sha1 在密碼學上已被碰撞攻擊破解，不應繼續用於安全場景。但逆向的需求是「復現」而非「破解」：你不需要找碰撞，只需要用同樣的輸入和同樣的鹽，得到同樣的輸出。

重點整理

  • md5 = 32 十六進位字元、sha1 = 40、sha256 = 64、sha512 = 128。
  • 摘要演算法不可逆，但可以復現：同樣的輸入 + 同樣的鹽 = 同樣的輸出。
  • Python 用 hashlib.md5() / sha1() / sha256()，記得多段 update() 等於拼接。
  • 逆向 sign 時，第一直覺就是試 md5(鹽 + 參數拼接)。
