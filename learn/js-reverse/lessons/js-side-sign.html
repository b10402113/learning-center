JS 侧 sign 生成：crypto 模块与 createHash

实战：sign 逆向（JS 执行） · 步骤 2/5

学习目标

能写出 JS 版 get_sign 函数，理解 crypto.createHash("md5") 的调用链与返回值。

从 Python 到 JS：同一个算法的两种写法

上一节的 Python 版 sign 生成逻辑是这样的：把固定字符串和动态时间戳拼起来，取 MD5。

现在我们要把同样的逻辑搬到 JS 里。JS 没有内置的 hashlib，但 node 提供了 crypto 模块，功能和 Python 的 hashlib 对应。

node 的 crypto 模块

crypto 是 node 的内置模块，不需要额外安装。它的 createHash 方法创建一个哈希对象，用法和 Python 的 hashlib.md5() 几乎一一对应：

操作Python hashlibnode crypto
创建哈希对象hashlib.md5()crypto.createHash("md5")
喂数据.update(b"data").update("data")
拿十六进制结果.hexdigest().digest("hex")

模板字符串：JS 里的字符串插值

JS 的模板字符串（用反引号 ` 包裹）可以在字符串里直接嵌入变量，语法是 ${变量名}。这比 Python 的 f-string 更早出现，是 ES6 的标准特性：

const client = "fanyideskweb";
const mysticTime = 1725600000000;
const product = "webfanyi";
const key = "fsdsogkndfokasodnaso";

// 模板字符串拼接
const signStr = `client=${client}&mysticTime=${mysticTime}&product=${product}&key=${key}`;
console.log(signStr);
// 输出：client=fanyideskweb&mysticTime=1725600000000&product=webfanyi&key=fsdsogkndfokasodnaso

JS 版 get_sign 函数

把上面的逻辑封装成一个函数，接收一个时间戳参数 t，返回 sign 值：

const crypto = require("crypto");

function get_sign(t) {
    const client = "fanyideskweb";
    const mysticTime = t;
    const product = "webfanyi";
    const key = "fsdsogkndfokasodnaso";
    const signStr = `client=${client}&mysticTime=${mysticTime}&product=${product}&key=${key}`;
    const sign = crypto.createHash("md5").update(signStr).digest("hex");
    return sign;
}

注意 require("crypto")：这是 node 引入内置模块的方式，相当于 Python 的 import hashlib。

一个更灵活的 get_sign 版本

上面的版本每次调用都要从外部传入时间戳。我们也可以把时间戳的生成逻辑封装进去，让 get_sign() 同时返回 [sign, 时间戳] 两个值：

const crypto = require("crypto");

function get_sign() {
    const client = "fanyideskweb";
    const mysticTime = Date.now();  // 毫秒级时间戳
    const product = "webfanyi";
    const key = "fsdsogkndfokasodnaso";
    const signStr = `client=${client}&mysticTime=${mysticTime}&product=${product}&key=${key}`;
    const sign = crypto.createHash("md5").update(signStr).digest("hex");
    return [sign, mysticTime];
}

const result = get_sign();
console.log("sign:", result[0]);
console.log("时间戳:", result[1]);

Date.now() 是 JS 获取毫秒级时间戳的标准写法，等同于 Python 的 int(time.time() * 1000)。

在 node 中验证

把上面的代码保存为 03 有道翻译.js，然后在终端运行：

node "03 有道翻译.js"

如果输出一个 32 位的十六进制字符串和一个时间戳，说明 JS 侧 sign 生成逻辑跑通了。

小结

JS 版 get_sign 的核心是 crypto.createHash("md5").update(字符串).digest("hex")，对应 Python 的 hashlib.md5(字符串).hexdigest()。时间戳用 Date.now()，字符串拼接用模板字符串。下一步，我们用 Python execjs 来调用这个 JS 函数。
