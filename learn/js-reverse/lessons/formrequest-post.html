FormRequest 发送 POST 请求

深度爬取与 POST 请求 · 步骤 4/4

学习目标

能解释 scrapy 起始请求的内部机制，并为任何 POST 接口写出 FormRequest 版爬虫。

scrapy 的起始请求是怎么发出去的？

你写过 scrapy 爬虫，但可能没想过一个问题：start_urls 里的 URL 是怎么被请求的？

答案是：Spider 父类（scrapy.Spider）内部有一个 start_requests(self) 方法，它遍历 start_urls，对每个 URL 调用 scrapy.Request(url) 发 GET 请求。

换句话说，scrapy 默认只发 GET 请求。如果你要发 POST 请求，就必须重写 start_requests 方法，改用 scrapy.FormRequest。

FormRequest 的用法

FormRequest 是 Request 的子类，专门用于发 POST 请求。它的关键参数是 formdata——一个字典，里面放 POST 请求的表单参数：

import scrapy

class BaiduTranslateSpider(scrapy.Spider):
    name = 'baidu'

    def start_requests(self):
        url = 'https://fanyi.baidu.com/sug'
        formdata = {'kw': 'dog'}
        yield scrapy.FormRequest(url=url, formdata=formdata, callback=self.parse)

    def parse(self, response):
        data = response.json()
        print(data)

运行后，scrapy 会向 https://fanyi.baidu.com/sug 发一个 POST 请求，请求体里带着 kw=dog。百度翻译的 sug 接口会返回一个 JSON 响应，用 response.json() 解析即可。

FormRequest vs Request

两者都是 scrapy 的 Request 类，区别在于：

特性RequestFormRequest
默认方法GETPOST
传参方式URL 查询字符串（?key=value）请求体（formdata字典）
典型用途翻页、进详情页、普通列表页搜索接口、登录接口、API 调用

什么时候需要发 POST？

以下场景几乎都必须用 POST：

  • 搜索接口：百度翻译 sug、京东商品搜索、微博搜索——这些接口的关键词放在 POST 请求体里。
  • 登录接口：用户名和密码不能放在 URL 里（GET 请求的 URL 会被记录在服务器日志、浏览器历史中），必须用 POST。
  • AJAX 接口：很多现代网站用 AJAX 加载数据，这些接口通常是 POST，参数是 JSON 或表单格式。

进阶：POST JSON 数据

有些接口要求请求体是 JSON 格式（Content-Type: application/json），而不是表单格式。这时候不能用 formdata，要改用 body 参数：

import json
import scrapy

class JsonPostSpider(scrapy.Spider):
    name = 'json_post'

    def start_requests(self):
        url = 'https://api.example.com/search'
        payload = {'keyword': 'python', 'page': 1}
        yield scrapy.Request(
            url=url,
            method='POST',
            body=json.dumps(payload),
            headers={'Content-Type': 'application/json'},
            callback=self.parse
        )

    def parse(self, response):
        data = response.json()
        print(data)

注意：FormRequest 默认的 Content-Type 是 application/x-www-form-urlencoded（表单格式）。如果你要发 JSON，必须用 scrapy.Request 并手动设置 body 和 headers。

常见踩坑

  • 忘记重写 start_requests：直接往 start_urls 里放 POST 接口的 URL，scrapy 会发 GET 请求，接口返回 405 Method Not Allowed。
  • formdata 的 value 不是字符串：formdata 字典的 value 必须是字符串或数字，不能是列表或字典。
  • 忘记设置 Content-Type：发 JSON 时如果不手动设置 Content-Type: application/json，服务器会按表单格式解析，导致 400 Bad Request。
