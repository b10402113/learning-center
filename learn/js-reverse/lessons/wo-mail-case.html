沃邮箱案例：数字模块 ID 与 RSA 登录加密

学习目标：理解数字模块 ID 调度与哈希 key 调度的差异，按数字 ID 437 在 2 万行里定位 RSA 加密函数，确认老站 jQuery + 数字模块 ID 的旧版 webpack 形态。

沃邮箱登录页的加密场景

中国联通沃邮箱的登录页在提交密码前，会先用前端 JS 把明文密码加密，再发请求。抓包可见请求体里的 password 字段是 256 字节级的 hex 字符串，典型的 RSA 加密结果。

这个加密函数的入口写在 loader 文件末尾：

window.loader(437).encrypt(t, o, n)

注意这里用的是数字下标 437，不是 "W2Yj" 这种哈希 key。这是旧版 webpack（以及老站）的典型形态。

数字下标 vs 哈希 key：两种调度方式的对比

特征数字下标哈希 key
模块 ID 形状437"W2Yj"
调用方式window.loader(437)window.loader("W2Yj")
webpack 版本webpack 3 及更早webpack 4+ 主流
站点技术栈jQuery 时代React / Vue 现代栈
识别方法loader 尾部测试调用是数字loader 尾部测试调用是字符串

两种只是 key 形状不同，调度函数本身的缓存-执行-返回逻辑完全一致。看到数字下标就意识到"这可能是 jQuery 老站"，可以预判 mod 文件里大概率内嵌了 jQuery 源码。

沃邮箱 loader 的结构特点

沃邮箱 loader（login.54f91.js）比财联社 loader 更"老派"：

// chunk 名映射为字符串
{'0': 'loginCommon', '6': 'login'}

// 入口模块 329 在 document.onreadystatechange 里异步加载
Promise.all([t.e(0), t.e(6)]).then(...)

// 资源根路径动态取
c.p = window.__webpack_public_path__
  • chunk 名用字符串：loginCommon、login，不是数字或哈希。
  • 入口模块延迟执行：等 document.onreadystatechange 触发后再加载。
  • 资源根路径动态取：window.__webpack_public_path__ 由服务端下发，不是硬编码。

mod1：2 万行里的 jQuery + RSA

沃邮箱只 require 一个 mod 文件——loginCommon chunk（chunk 0），但它有 21508 行、914 KB，是整包打包的产物。文件头部写着：

window = global;
document = {};

除了 window = global，还多补了一个 document = {}，因为 jQuery 在初始化时会检测 document。

用编辑器搜索 "jquery" 或 jQuery，你会看到完整的 jQuery 1.11.3 源码以 UMD 形式内嵌：

!function(a, b) {
  "object" == typeof module && "object" == typeof module.exports ?
    module.exports = a.document ? b(a, !0) : function(a) {...} :
    b(a)
}("undefined" != typeof window ? window : this, function(a, b) {
  // jQuery 1.11.3 完整源码...
});

看到这种 UMD 包装，就能确认：老站 = jQuery + 数字模块 ID。

按数字 ID 437 定位 RSA 加密

在 mod1 文件里搜索 437: 或 "437":，跳到 437 号模块的源代码：

437: function(e, n, t) {
  // RSA 加密入口
  e.exports = {
    encrypt: function(t, o, n) {
      // t: 明文
      // o: 256 字节级超长 hex 模数
      // n: '10001'（hex 65537，RSA 公钥指数）
      // ...RSA 加密实现...
    }
  };
}

encrypt(t, o, n) 的参数含义：

  • t：明文密码。
  • o：RSA 模数（modulus），256 字节的 hex 字符串。
  • n：RSA 公钥指数，固定为 '10001'（即十进制 65537）。

这是标准的 RSA 公钥加密入参结构。只要找到这个函数，就能在 Python 里用 rsa 库或 pycryptodome 复现。

本地复现的完整代码

// 1. 补环境
global.window = global;
global.document = {};

// 2. 加载 loader 和 mod
require("./09_loader.js");   // 沃邮箱 loader
require("./10_mod1.js");     // loginCommon chunk

// 3. 调目标加密函数
var plain = "mypassword";
var modulus = "a1b2c3d4e5f6...";  // 256 字节 hex，从真实请求抓
var exponent = "10001";

var encrypted = window.loader(437).encrypt(plain, modulus, exponent);
console.log(encrypted);

注意这里只 require 一个 mod，因为沃邮箱是整包打包，所有模块都在 loginCommon 一个 chunk 里。跟财联社"三个 mod 依赖闭环"形成对比。
