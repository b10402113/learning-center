詳細用法：launch 參數、視口、反檢測與節點互動

js-reverse · 08-pyppeteer · Step 3/4

學習目標

能配置 Pyppeteer 的各類運行細節：launch 參數、視口尺寸、webdriver 反檢測注入、type/click 節點互動。

launch 的常用參數

launch() 是整個爬蟲的起點，它有幾個最常用的參數：

browser = await launch(
    ignoreHTTPSErrors=True,   # 預設 False，略過 HTTPS 憑證錯誤
    headless=True,            # 預設 True 無頭模式，False 會顯示視窗
    executablePath=None,      # 指定本機 Chrome/Chromium 路徑
    devtools=False,           # True 會強制 headless=False 並打開 DevTools
    args=['--disable-infobars']  # 額外命令列參數
)
  • headless=True：背景執行，不顯示瀏覽器視窗，適合爬蟲。
  • headless=False：顯示視窗，方便除錯。
  • devtools=True：強制開視窗並打開 DevTools，通常用於觀察頁面行為。
  • args：可以傳入任何 Chromium 的命令列參數。

關閉自動化提示條

你有沒有看過瀏覽器上方出現「Chrome 正受到自動測試軟體控制」的提示條？這是最基本的爬蟲特徵。關閉方法是在 args 裡加上 --disable-infobars：

browser = await launch(
    headless=True,
    args=['--disable-infobars']
)

視口設定

有些網站會根據螢幕寬度調整版面，如果 Pyppeteer 用預設的 800x600 視口去訪問，可能會拿到異常的排版或元素位置。手動設定視口可以解決這個問題：

await page.setViewport({'width': 1366, 'height': 768})

這行通常放在 goto() 之前，確保頁面在正確的尺寸下渲染。

注入 JS 反檢測

這是 Pyppeteer 爬蟲的重點。正常瀏覽器裡，window.navigator.webdriver 是 undefined 或 false；但自動化工具驅動的瀏覽器，這個值會是 true。許多網站會據此擋爬蟲。

Pyppeteer 的解法是用 page.evaluate() 在頁面載入前注入一段 JS，把 webdriver 改回 false：

await page.evaluate(
    '''() => {
        Object.defineProperties(navigator, {
            webdriver: { get: () => false }
        })
    }'''
)

這一行通常放在 goto() 之前，效果等同於 Selenium 的 stealth.min.js。

節點互動：type 與 click

Pyppeteer 的節點互動和 Selenium 很像，但多了「擬人」的彈性。

type：在指定選擇器輸入文字，可以設定 delay 模擬逐字輸入：

await page.type('#kw', '周杰倫', {'delay': 100})  # 每字間隔 100ms

click：點擊指定選擇器：

await page.click('#su')

querySelectorAll：取得多個元素，再逐一點擊：

links = await page.querySelectorAll('.s_tab_inner > a')
for link in links:
    await link.click()

頁面等待

動態頁面元素出現的時間不一定，Pyppeteer 提供幾種等待方式：

  • await page.waitFor(2000)：強制等待 2000 毫秒（2 秒）。
  • await page.waitForSelector('#btn')：等待特定選擇器出現。
  • await page.waitForXPath('//h2')：等待特定 XPath 出現。

元素定位的三種簡寫

Pyppeteer 提供三種元素定位方法，還有對應的簡寫：

方法簡寫說明
Page.querySelector()Page.J()取第一個符合的元素
Page.querySelectorAll()Page.JJ()取所有符合的元素
Page.xpath()Page.Jx()用 XPath 定位

取得元素屬性

用 Jeval() 可以在定位元素後，用 JS 箭號函式取出屬性：

src = await page.Jeval('#img', 'el => el.src')

如果要取得元素的位置和大小，用 boundingBox()：

box = await el.boundingBox()  # 回傳 {x, y, width, height}
