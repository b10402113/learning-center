模組導入與 __name__ 入口判斷

學習目標

能辨認模組來源、讀懂常見導入寫法，並判斷檔案是入口還是被導入的工具。

模組從哪裡來

來源例子取得方式
內建time、json隨 Python 安裝
第三方requests、lxml另外安裝
自訂sign.py、utils.py自己撰寫

導入與執行

import time
time.sleep(1)

import requests as req

from time import sleep
sleep(1)

import 保留模組命名空間，from ... import ... 直接取出成員；避免使用萬用字元導入，以免來源不清或名稱衝突。導入模組時，Python 會執行它的頂層程式碼，同一程序通常只首次執行一次。

__name__ 與入口

def add(a, b):
    return a + b

if __name__ == "__main__":
    print(add(1, 2))

直接執行檔案時，__name__ 是 "__main__"；被導入時則是模組名稱，因此啟動流程或自測程式應放在判斷式內。
