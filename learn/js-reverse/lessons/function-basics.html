函数基础：声明、arguments 与返回值

JS 逆向 · 节点 15 · 步骤 1/5

学习目标

能看懂 JS 函数声明提升、arguments 对象和返回值规则，判断函数调用的实际行为。

函数声明可以晚于调用

JS 会把整个函数声明"提升"（hoist）到当前作用域的顶部。所以下面这段代码不会报错，打印出 3：

console.log(add(1, 2)); // 3

function add(a, b) {
  return a + b;
}

这只在函数声明（function name(){}）成立。如果是函数表达式 var add = function(){}，变量 add 只会提升声明、不会提升赋值，提前调用会得到 undefined is not a function。逆向时看到调用在前、声明在后，能立刻认出这是函数声明，不会被"它怎么还没定义就能跑"搞糊涂。

形参与实参个数不必匹配

JS 调用函数时，传多传少都不会报错。多出来的实参被忽略，缺的形参值是 undefined：

function demo(a, b) {
  console.log(a, b);
}
demo(1);        // 1 undefined
demo(1, 2, 3);  // 1 2

这让"函数到底接收几个参数"没法光看声明确定——必须看函数体内部怎么消费参数。逆向时这是常态，别被声明里的形参个数骗了。

arguments：类数组的不定长参数仓库

每个函数内部都有一个自动生成的 arguments 对象，它按顺序装着所有实参，还能用 arguments.length 拿到实参个数。下面这个 sum 函数不需要声明任何形参，也能把任意个数加起来：

function sum() {
  var total = 0;
  for (var i = 0; i < arguments.length; i++) {
    total += arguments[i];
  }
  return total;
}
console.log(sum(1, 2, 3));    // 6
console.log(sum(5, 5, 5, 5)); // 20

arguments 看起来像数组，能下标访问、有 .length，但没有 push/map 这些数组方法，所以叫类数组（array-like）。逆向老代码时 arguments 非常常见，ES6 的 ...rest 参数是它的现代替代品，但老项目和混淆代码里还是到处是 arguments。

没有 return 默认返回 undefined

JS 函数如果没有显式 return，返回值一律是 undefined。这意味着一个"什么都不返回"的函数，和一个"返回 undefined"的函数，行为完全一样。逆向时可以用这一点判断一个函数的用途：

  • 函数体做了一些操作（改 DOM、发请求），但没有 return → 它靠副作用工作，不需要返回值。
  • 有 return 但返回值永远不被使用 → 可能是被混淆器或打包工具插入了无用代码。

逗号表达式与返回值求值

逗号表达式 (expr1, expr2, expr3) 会从左到右依次求值，整个括号表达式的值是最后一个。这个特性偶尔被用来在一行里塞多个操作：

function test() {
  var x = 10;
  return (x = x + 5, x * 2);
}
console.log(test()); // 30

等价于先把 x 改写成 15，再返回 15 * 2。逆向时遇到 return (a = ..., b = ..., c)，把它拆成"若干赋值 + 返回最后一个值"就能读懂。
