JavaScript 模組導出與依賴

學習目標

沿著 exports 與 require 追蹤模組提供的介面，定位網頁程式真正呼叫的函式。

模組是一個介面邊界

在常見的 CommonJS 形式中，一個檔案是模組；模組內部可以有私有變數，只有放進 exports 或指定給 module.exports 的值，才能被其他檔案取得。

// math.js
function add(a, b) { return a + b; }
exports.add = add;

// main.js
const math = require('./math');
console.log(math.add(2, 3));

兩種導出形狀

exports.parse = parse;

module.exports = {
  parse,
  version: '1.0'
};

exports 最適合逐項掛上成員；重新指定整個模組時要使用 module.exports。讀逆向程式時，先找到 require 的路徑，再回到對應檔案檢查它真正導出的名稱與資料。

和瀏覽器分析的連接

打包後的前端程式常把多個模組包成載入器與模組表；看到模組 ID、依賴陣列或導出物件時，可用「誰導入誰、誰導出什麼」建立追蹤圖。
