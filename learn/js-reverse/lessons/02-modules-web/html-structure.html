HTML 文檔結構與常用標籤

學習目標

看懂 HTML 骨架，依標籤與屬性定位登入表單、連結、圖片及其他頁面資料。

文檔骨架

<!DOCTYPE html>
<html>
  <head>
    <title>頁面標題</title>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>內容</h1>
  </body>
</html>

DOCTYPE 宣告解析方式；head 放標題與編碼等頁面資訊；body 放可見內容。HTML 是描述性標記語言，不是程式語言。

定位頁面資料

標籤逆向時重點
ahref 是跳轉目標，target 控制開啟方式
imgsrc 是圖片 URL，alt 是替代文字
formaction 是提交 URL，method 是 GET 或 POST
inputname/value 對應提交參數

區塊元素如 div、p 通常獨佔一行；行內元素如 a、span 依內容佔位。檔案上傳需使用 enctype="multipart/form-data"，單選框要共享相同 name。
