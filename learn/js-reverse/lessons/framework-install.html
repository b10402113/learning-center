框架概念与环境安装

Scrapy 框架入门 · Step 1/4

Learning goal

理解框架是「项目半成品」的学习定位，并完成 Scrapy 安装与环境验证。

Lesson

在写爬虫的路上，你已经用 requests + xpath 跑通了不少页面。但当你同时面对十几个网址、需要排队请求、还要把数据存到数据库时，重复造轮子的疲惫感会越来越重。这时候就需要一个框架（framework）。

框架是什么

框架就是一个「半成品项目」。它把爬虫工程里重复出现的高性能异步下载、请求队列、分布式调度、数据解析、持久化存储这些通用功能都做好了，你只需要在它留出的业务口子上填写自己的逻辑。

打个比方：框架像一间已经铺好水电、装好橱柜的厨房，你不用从砌墙开始，只要带食材进去炒菜就行。

Scrapy 的定位

Scrapy 是为爬取网站数据、提取结构性数据而生的应用框架。它集成了高性能异步下载、队列、分布式、解析、持久化等能力，是 Python 爬虫生态里最出名、最强悍的框架之一。

学习心态：先会用，再谈源码

框架的源码动辄几万行，一上来就钻进去只会打击信心。正确的姿势是：先学会每个功能怎么用，跑通完整流程，遇到瓶颈再回头翻源码。前期把用法练熟，源码里的设计思路自然会在实践中浮现。

安装

Scrapy 在各平台的安装方式统一，打开终端执行：

pip install scrapy

验证安装

安装完成后，在终端输入 scrapy 回车。如果能看到一串帮助信息（列出 startproject、genspider、crawl 等子命令），而不是「找不到指令」的报错，就说明安装成功。

安装常见坑

  • macOS 上如果提示权限错误，检查是否用了系统 Python，建议走 Homebrew 或 pyenv 管理的环境。
  • Windows 上若报 Microsoft Visual C++ 缺失，需安装相应的 Build Tools。
  • 安装后终端仍找不到指令，确认 pip 对应的 Python 版本和当前终端使用的是同一个。
