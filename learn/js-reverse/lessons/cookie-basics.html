Cookie 原理與規範

學習目標

追蹤 Cookie 從伺服器下發到瀏覽器回傳的完整流程，並掌握基本限制。

為什麼需要 Cookie

HTTP 是無狀態協議，伺服器不會自動記得上一個請求的使用者；Cookie 是伺服器建立、瀏覽器保存的鍵值對，讓後續請求帶上可辨識登入態的資料。

四步生命週期

  1. 瀏覽器第一次訪問，尚未帶有此站 Cookie。
  2. 伺服器在響應頭以 Set-Cookie 下發鍵值對。
  3. 瀏覽器依規則保存 Cookie。
  4. 再次訪問符合條件的 URL 時，瀏覽器自動放進 Cookie 請求頭。
響應：Set-Cookie: session_id=abc123
後續：Cookie: session_id=abc123

在逆向或爬蟲中，帶著有效 Cookie 重放請求之所以可能成功，是因為伺服器依它辨識使用者；不同瀏覽器通常各自保存 Cookie，不會互相共享。

常見規範數字

範圍課件中的限制
單一 Cookie約 4KB
單一伺服器約 20 個
單一瀏覽器約 300 個
