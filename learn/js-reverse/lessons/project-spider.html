项目创建与 Spider 编写

Scrapy 框架入门 · Step 2/4

Learning goal

能独立用 startproject 和 genspider 搭建 Scrapy 工程，并写出一个包含 name、start_urls、parse 三要素的 Spider。

Lesson

搭一个 Scrapy 工程只需要五步：建项目、建爬虫、改配置、写解析、跑起来。我们先走完前两步，把项目骨架和 Spider 文件立起来。

第一步：创建项目

在终端里进入你想放项目的目录，执行：

scrapy startproject myproject

Scrapy 会自动生成一个名为 myproject 的文件夹，里面是项目的标准目录结构。

项目目录结构

文件/文件夹职责
scrapy.cfg项目配置文件，不要删改
items.py定义数据字段，封装抓取结果
middlewares.py所有中间件（请求/响应的加工层）
pipelines.py所有管道（数据持久化的加工层）
settings.py爬虫的全局配置
spiders/存放所有爬虫文件的文件夹

记住这个结构：scrapy.cfg 是入口，settings.py 是总控，spiders/ 是写业务逻辑的地方，items.py 和 pipelines.py 是数据流的后半段。

第二步：创建爬虫文件

进入项目目录，用 genspider 命令生成一个爬虫模板：

cd myproject
scrapy genspider baidu www.baidu.com

这条命令会在 spiders/ 文件夹下生成一个 baidu.py 文件，里面已经帮你写好了 Spider 类的骨架。

Spider 三要素

打开 baidu.py，你会看到三个关键字段：

  • name = 'baidu' — 爬虫的唯一标识，运行的时候靠它找人。
  • start_urls = ['http://www.baidu.com/'] — 起始 URL 列表，框架会自动对列表里每个 URL 发起 GET 请求。
  • def parse(self, response): — 专门用来解析响应、提取数据的方法。

一个最小可运行的 Spider

import scrapy

class BaiduSpider(scrapy.Spider):
    name = 'baidu'
    start_urls = ['http://www.baidu.com/']

    def parse(self, response):
        print(response.text[:200])

这个爬虫什么也没做，只是把百度首页 HTML 的前 200 个字符打印出来。但它已经跑通了 Scrapy 的完整链路：调度器取 URL → 下载器请求 → 把响应交给 parse。

allowed_domains 的作用

genspider 还会自动生成一个 allowed_domains 列表。它是爬虫的「活动范围」：只有在这个域名下的 URL 才会被跟踪。写爬时如果不小心跳到别的域名，Scrapy 会自动忽略，避免爬虫跑飞。
