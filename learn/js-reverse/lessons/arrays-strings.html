字串與陣列：slice、split、splice 與遍歷

js-reverse · 14-js-variables-control · Step 4/4

學習目標

能操作陣列的 push/pop/splice、字串的 slice/split/indexOf，並分辨 for、for-in、for-of 三種遍歷各自拿到的是索引還是元素。

為什麼字串和陣列是簽名演算法的原物料

JS 籤名（sign）演算法的本質，就是把一組參數重新排列、切片、拼接，最後丟進雜湊函式。所有這些操作，背後都是字串和陣列的方法。只要認出 split、splice、slice 這「三個 slice」在幹什麼，你就能還原出參數字串經歷了哪些轉換。

字串的三個常用方法

slice：切一段子字串

slice(start, end) 從 start 切到 end（不含 end）。省略 end 就切到最後。

var s = "hello world"
s.slice(0, 5)   // "hello"
s.slice(6)      // "world"

split：按分隔符切開成陣列

split(" ") 用空格切開，回傳一個字串陣列。

var s = "北京 天津 重慶 上海"
var arr = s.split(" ")
console.log(arr)       // ["北京", "天津", "重慶", "上海"]
console.log(arr.length) // 4

indexOf 與 startsWith

indexOf 回傳子字串的位置，找不到回傳 -1。startsWith 判斷是否以某個前綴開頭。

"hello".indexOf("ll")     // 2
"hello".indexOf("xx")     // -1
"http://example.com".startsWith("http")  // true

陣列的增刪全家餐

push / pop：操作尾巴

push 在陣列末尾加一個元素，pop 移除最後一個元素。

var arr = [11, 22, 33]
arr.push(100)   // [11, 22, 33, 100]
arr.pop()       // [11, 22, 33]

unshift / shift：操作頭部

unshift 在陣列開頭加一個元素，shift 移除第一個元素。

var arr = [11, 22, 33]
arr.unshift(100)  // [100, 11, 22, 33]
arr.shift()       // [11, 22, 33]

splice：一方法三用途

splice 是逆向中出現頻率最高的陣列方法，因為它同時能做刪除、插入、_replace_。

var arr = ["a", "b", "c", "d"]

// 刪除：從索引 1 開始刪 2 個
arr.splice(1, 2)          // arr 變為 ["a", "d"]

// 插入：從索引 1 刪除 0 個，插入 100, 200, 300
arr.splice(1, 0, 100, 200, 300)  // ["a", 100, 200, 300, "b", "c", "d"]

// 替換：從索引 1 刪除 2 個，插入 "B", "C"
arr.splice(1, 2, "B", "C")       // ["a", "B", "C", "d"]

記憶口訣：第一個參數是起始索引，第二個是刪除數量，後面的參數是要插入的元素。

陣列遍歷的三種方式

語法拿到的是常見用途
for (var i=0; i<n; i++)索引（透過 arr[i] 取值）需要索引或修改原陣列
for (var x in arr)索引（key）需要索引但不需要值
for (var x of arr)元素（value）只需要值，語法最簡潔
var arr = [10, 11, 12, 13]

// for：拿到索引，用 arr[i] 取值
for (var i = 0; i < arr.length; i++) {
    console.log(arr[i])   // 10, 11, 12, 13
}

// for-in：拿到索引
for (var x in arr) {
    console.log(x)        // "0", "1", "2", "3"
}

// for-of：直接拿到元素
for (var x of arr) {
    console.log(x)        // 10, 11, 12, 13
}

逆向時看到 for-in 要警覺：它拿的是索引，不是值。混淆經常用這種寫法讓你搞混。

reverse、join 與其他實用方法

var arr = [11, 22, 33]
arr.reverse()          // [33, 22, 11]

var cities = ["北京", "天津", "重慶", "上海"]
cities.join(",")       // "北京,天津,重慶,上海"

reverse 直接反轉陣列，經常用在籤名裡改變參數順序。join 把陣列用指定分隔符拼回字串，是 split 的逆向操作。
