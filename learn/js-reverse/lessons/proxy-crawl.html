代理伺服器、匿名度與代理池

js-reverse · Step 3/4 · 約 15 分鐘

這節課你會學到什麼

理解代理伺服器在爬蟲中的定位（隱藏真實 IP、對抗 IP 黑名單），區分透明/匿名/高匿三種匿名度，並能用 requests 的 proxies 參數寫出帶代理池、隨機選擇代理、間隔睡眠的批量爬蟲。

情境：為什麼爬蟲需要代理？

你在雪球網一次抓 500 篇熱帖，每篇都從同一個 IP 發出。網站後台發現這 500 個請求都來自同一個地方，幾分鐘內就觸發了反爬機制——把你這個 IP 加入黑名單。之後你再發請求，伺服器直接拒絕，爬蟲就停了。

解決方案很直覺：如果每次請求來自不同的 IP，伺服器就沒辦法用「同一個 IP 短時間內請求太多」來封鎖你。代理伺服器（Proxy Server）就是做這件事的中間人。

代理的運作原理

你 ──→ 代理伺服器 ──→ 目標網站
  ←── 代理伺服器 ←── 目標網站

真實流程：
你發出請求（帶你的 IP）
    ↓
代理伺服器收到，改寫請求的來源 IP 為代理的 IP，轉發給目標
    ↓
目標看到的來源是代理的 IP（不是你的 IP），回傳資料給代理
    ↓
代理把資料轉傳給你

關鍵點：伺服器收到的請求裡，來源 IP 是代理的 IP，不是你的。這就是代理能隱藏你真實位置的原理。

匿名度三等級

不同代理提供的隱蔽程度不同，按匿名度分三等級：

匿名度伺服器知道什麼適用場景
透明代理 知道你用代理，也知道你的真實 IP 不適合爬蟲（毫無隱蔽性）
匿名代理 知道你用代理，但不知道你的真實 IP 基本夠用，但有些網站會專門過濾「用了代理」的請求
高匿代理（推薦） 都不知道，伺服器完全看不出有人在用代理 爬蟲首選
買代理要點：認準「高匿」兩個字。透明和匿名代理在爬蟲場景裡形同虛設。

協議類型：HTTP vs HTTPS

代理也分協議類型：

  • HTTP 代理：只能轉發 HTTP 請求（明文傳輸）
  • HTTPS 代理：能轉發 HTTPS 請求（加密傳輸）

大多數網站都用 HTTPS，所以你需要的是支援 HTTPS 的代理。有些免費代理只支援 HTTP，遇到 HTTPS 目標網站就沒用了。

實戰：單代理測試

拿到一個代理 IP:port 之後，先測試它能不能用：

import requests

# 你的代理伺服器
proxies = {
    "http": "http://123.45.67.89:8080",
    "https": "http://123.45.67.89:8080"   # 注意：值也是 http:// 開頭
}

# 先用 cip.cc 確認你的代理 IP
resp = requests.get("http://cip.cc", proxies=proxies)
print(resp.text)
# 如果輸出的是代理的 IP 而不是你的真實 IP，說明代理生效
常見錯誤：proxies 字典的值要以 http:// 開頭，即使 key 是 "https"。不要寫成 https://123.45.67.89:8080。

實戰：代理池批量爬取

單代理有壽命（很快就會被封），所以大規模爬取要用代理池：把多個代理 IP:port 存在一個列表裡，每次隨機選一個，配合延遲避免被封。

import requests
import random
import time

# 代理池：至少準備 3-5 個不同的代理
proxy_pool = [
    "http://123.45.67.89:8080",
    "http://98.76.54.32:3128",
    "http://55.66.77.88:8888",
    "http://11.22.33.44:9090",
]

for page in range(1, 11):
    # 每次隨機選一個代理
    proxy = random.choice(proxy_pool)
    proxies = {"http": proxy, "https": proxy}

    try:
        resp = requests.get(
            f"https://target.com/api/data?page={page}",
            proxies=proxies,
            timeout=5
        )
        print(f"Page {page}: {resp.status_code}")
    except Exception as e:
        print(f"Page {page}: 代理 {proxy} 失敗 - {e}")
        continue

    # 每次請求後休息一下，避免被封
    time.sleep(random.uniform(1, 3))

這段程式碼做了三件關鍵的事：

  1. 隨機選擇代理：random.choice(proxy_pool)，讓每次請求來自不同的 IP
  2. 間隔睡眠：time.sleep(random.uniform(1, 3))，在 1-3 秒之間隨機等待，不讓請求太規律
  3. 錯誤處理：try/except 包住，單個代理失敗不影響整個爬蟲

代理從哪裡來？

代理 IP 的來源分兩大類：

來源優點缺點
免費代理網站 免費 品質差、速度慢、很多根本不能用、很快就會被封
付費代理服務（芝麻代理等） 品質穩定、速度快、支援高匿 有成本，按量計費
建議：學習階段用免費代理練手，正式爬取用付費代理。免費代理勝在能理解代理池的邏輯，但真要穩定爬取得靠付費服務。

小結

代理伺服器是爬蟲對抗 IP 黑名單的核心武器。代理按匿名度分三等級（推薦高匿），按協議分 HTTP/HTTPS 兩種。在 requests 裡用 proxies 字典設定代理，大規模爬取時建立代理池隨機選擇、配合延遲避免被封。
