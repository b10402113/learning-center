Selenium 浏览器自动化

Step 3 — execute_script 与 page_source 获取动态数据

Learning Goal

理解 page_source 拿到的是渲染后的动态源码，掌握用 execute_script 滚动触发懒加载、再用解析库提取数据的完整范式。

page_source：Selenium 的核心产出

Selenium 爬虫和 requests 爬虫最大的区别，就在于获取数据的方式。requests 用 .text 拿到的是服务器返回的原始 HTML；Selenium 用 page_source 拿到的，是浏览器渲染之后的 DOM 源码。

这意味着什么？如果一个页面的数据是 JavaScript 动态加载的——比如滚动到底部才加载更多商品、或者点击按钮后才渲染列表——requests 拿到的 HTML 里根本没有这些数据，但 page_source 里有。因为浏览器已经执行了 JS，DOM 里已经填充了这些内容。

一句话：page_source = 浏览器当前看到的页面源码 = 可见即可得。

# 获取当前页面的渲染后源码
html = browser.page_source

# 拿到之后，就可以用任何解析库提取数据
from lxml import etree
tree = etree.HTML(html)
titles = tree.xpath('//h2[@class="title"]/text()')

常用的解析库有正则、BeautifulSoup、pyquery、lxml，选一个顺手的就行。lxml 的 XPath 支持最完整，和 Selenium 配合最顺畅。

execute_script：注入 JavaScript 的万能后门

Selenium 的 API 覆盖了绝大多数浏览器操作，但总有些事情是 API 没提供的——比如滚动页面、修改隐藏字段的值、触发某个自定义事件。这时候就需要 execute_script()，它允许你直接在页面上下文里执行任意 JavaScript 代码。

最典型的用法是滚动页面。很多网站使用「懒加载（Lazy Load）」技术：页面一开始只渲染顶部内容，等用户滚动到附近时才加载更多数据。如果不滚动，page_source 里就只有顶部那几条。

# 向下滚动 2000 像素
browser.execute_script('document.documentElement.scrollTo(0, 2000)')

# 滚动到页面底部
browser.execute_script('window.scrollTo(0, document.body.scrollHeight)')

# 执行 JS 并返回值
title = browser.execute_script('return document.title')

execute_script() 可以带返回值，只要 JS 代码里有 return 语句。这让你能直接从页面 DOM 里读取信息，而不需要先拿整个 page_source 再解析。

「可见即可得」完整范式

把滚动 + page_source + 解析串起来，就是 Selenium 爬虫抓取动态加载数据的标准流程：

from selenium import webdriver
from selenium.webdriver.common.by import By
from lxml import etree
import time

browser = webdriver.Chrome()
browser.get('https://movie.douban.com/explore')

# 1. 滚动触发懒加载
browser.execute_script('document.documentElement.scrollTo(0, 2000)')
time.sleep(1)  # 等数据加载

# 2. 再次滚动，加载更多
browser.execute_script('document.documentElement.scrollTo(0, 4000)')
time.sleep(1)

# 3. 拿到渲染后的源码
html = browser.page_source

# 4. 解析提取数据
tree = etree.HTML(html)
titles = tree.xpath('//div[@class="title"]/a/text()')
for title in titles:
    print(title)

browser.quit()

这个范式可以应对绝大多数「没有接口可抓、数据靠 JS 渲染」的页面。核心就是：滚动让数据出现 → page_source 拿到完整 DOM → 解析库提取。

获取动态加载数据：豆瓣电影案例

以豆瓣电影分类页为例，页面初始只显示几部电影，向下滚动时才会加载更多。完整流程：

  1. 打开页面，确认初始只有少量电影条目。
  2. 用 execute_script 滚动到页面底部，触发懒加载。
  3. 等待 1-2 秒，让新数据渲染完成。
  4. 再次滚动，重复几次，直到加载出所有数据。
  5. 用 page_source 拿到包含所有电影的完整源码。
  6. 用 lxml 的 XPath 解析出电影名、评分等信息。

注意：滚动后必须 time.sleep() 等待数据加载，否则 page_source 里还是滚动前的内容。后面学「显式等待」后可以用更优雅的方式替代 sleep。

execute_script 的其他妙用

  • 修改元素属性：browser.execute_script("document.getElementById('x').type='text'")，把隐藏字段改成可见。
  • 移除元素：browser.execute_script("document.querySelector('.ad').remove()")，去掉遮挡的弹窗或广告。
  • 触发事件：browser.execute_script("document.querySelector('button').click()")，直接调用 JS 点击。
  • 获取页面信息：browser.execute_script("return document.cookie")，读取当前页面的 Cookie。

关键概念总结

  • page_source：浏览器渲染后的动态源码，包含 JS 执行后的内容，是 Selenium 爬虫的核心产出。
  • execute_script()：在页面上下文执行 JavaScript，用于滚动、修改 DOM、触发事件等 API 未覆盖的操作。
  • 懒加载（Lazy Load）：页面初始只渲染部分内容，滚动到附近时才加载更多，需要 execute_script 滚动触发。
  • 可见即可得：Selenium 爬虫的核心理念——浏览器能看到的数据，page_source 里都有。
