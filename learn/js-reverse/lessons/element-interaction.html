Selenium 浏览器自动化

Step 2 — 元素定位与节点交互

Learning Goal

掌握七种元素定位方式与 By 统一写法，能组合定位 + 交互完成搜索框输入、按钮点击等绝大多数页面操作。

元素定位是自动化的基石

Selenium 自动化的每一步都从「找到元素」开始。你告诉浏览器「点击搜索按钮」，浏览器得先知道搜索按钮在页面上的哪个位置。HTML 页面是一个树状结构（DOM），每个元素都有自己的标签名、属性、文本内容——定位就是根据这些特征把目标元素挑出来。

Selenium 提供了七种定位方式，覆盖了你可能遇到的所有场景。实际爬虫中最常用的是 XPath 和 CSS Selector，因为它们能处理最复杂的定位需求。

七种定位方式

定位方式方法适用场景
IDBy.ID元素有唯一 id 属性
NameBy.NAME表单元素常有 name 属性
Class NameBy.CLASS_NAME通过 CSS 类名定位
Tag NameBy.TAG_NAME按标签类型定位，如 div、a
Link TextBy.LINK_TEXT按链接的完整文本定位
Partial Link TextBy.PARTIAL_LINK_TEXT按链接的部分文本定位
XPathBy.XPATH最灵活，支持路径和条件
CSS SelectorBy.CSS_SELECTOR语法简洁，前端最熟悉

By 统一写法（推荐）

Selenium 早期版本提供了一系列 find_element_by_xxx 方法，比如 find_element_by_id()、find_element_by_xpath()。现在推荐统一使用 By 对象，代码风格更一致，也更容易切换定位方式：

from selenium.webdriver.common.by import By

# 通过 ID 定位
element = browser.find_element(By.ID, 'kw')

# 通过 XPath 定位
element = browser.find_element(By.XPATH, '//input[@id="kw"]')

# 通过 CSS Selector 定位
element = browser.find_element(By.CSS_SELECTOR, '#kw')

# 通过 Class Name 定位
element = browser.find_element(By.CLASS_NAME, 's_ipt')

注意 find_element（单数）返回第一个匹配的元素，如果找不到会抛异常。find_elements（复数）返回所有匹配元素的列表，找不到时返回空列表。

XPath 快速入门

XPath 是爬虫中最常用的定位方式，因为它能处理「没有 id、没有 class」的复杂元素。核心思路是把 DOM 当成文件路径来导航：

# 绝对路径（从根节点开始，不推荐，页面一改就失效）
/html/body/div[1]/div[2]/input

# 相对路径（推荐）
//input[@id='kw']                    # 找 id 为 kw 的 input
//div[@class='container']//a        # 找 class 为 container 下的所有 a 标签
//a[contains(text(),'登录')]        # 找文本包含「登录」的 a 标签
//input[@type='text' and @name='q'] # 多条件组合

几个最常用的 XPath 技巧：

  • //：从任意位置开始查找，不用管层级。
  • @属性名：按属性筛选，比如 @id、@class、@type。
  • contains(@attr, '值')：属性值包含某段文字，适合 class 有多个值的情况。
  • text()：按元素的文本内容定位。
  • [n]：取第 n 个匹配元素（从 1 开始计数）。

节点交互：输入、清空、点击

定位到元素之后，就可以模拟人的操作了。最常用的三个方法：

方法作用典型场景
send_keys('文字')在输入框输入文字搜索框、登录表单
clear()清空输入框内容重新填写表单前
click()点击元素按钮、链接、复选框

一个完整的登录流程示例：

# 定位用户名输入框并输入
username = browser.find_element(By.ID, 'username')
username.clear()
username.send_keys('my_username')

# 定位密码输入框并输入
password = browser.find_element(By.ID, 'password')
password.clear()
password.send_keys('my_password')

# 定位登录按钮并点击
login_btn = browser.find_element(By.ID, 'login-btn')
login_btn.click()

获取元素信息

除了操作元素，还经常需要从元素身上「读取」信息：

element = browser.find_element(By.ID, 'price')

element.text          # 元素的可见文本，比如「¥199」
element.tag_name      # 标签名，比如「span」
element.get_attribute('href')   # 获取 href 属性值
element.get_attribute('class')  # 获取 class 属性值
element.is_displayed()          # 元素是否可见
element.is_enabled()            # 元素是否可交互

get_attribute() 特别有用，很多数据不是显示在页面文本里，而是藏在 HTML 属性里——比如图片的 src、链接的 href、自定义的 data-* 属性。

定位失败的常见原因

  • 页面还没加载完：元素还没渲染就去定位，会报 NoSuchElementException。解决方法是加等待（后面会学）。
  • 元素在 iframe 里：iframe 是页面中嵌入的子页面，里面的元素默认定位不到。必须先 browser.switch_to.frame('iframe_id') 切入，定位完再 browser.switch_to.default_content() 切回主页面。
  • XPath 写错了：在浏览器 DevTools 里用 $x("你的xpath") 先测试，能选中再写进代码。
  • 多个匹配元素：find_element 只返回第一个，如果要点的是第二个，用 find_elements()[1]。
