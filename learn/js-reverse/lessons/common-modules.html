常用內建模組

學習目標

用 time、random、os、json、re 完成爬蟲中的計時、取樣、檔案、資料與文字處理。

五個高頻工具

模組用途常見 API
time時間戳、延遲、計時time.time()、sleep()
random隨機延遲或取樣choice()、sample()
os檔案系統與路徑exists()、join()
json介面資料交換dumps()、loads()
re模式匹配與提取findall()

可直接套用的流程

import time, json, re
start = time.time()
text = '{"title": "課程"}'
data = json.loads(text)
title = re.findall(r'"title":\s*"(.*?)"', text)[0]
print(data, title, time.time() - start)

json.loads 把 JSON 字串變成 Python 物件；json.dumps 做反向轉換，dump/load 則直接搭配檔案。正則的 .*? 是非貪婪匹配，分組會讓 findall 回傳括號內內容。
