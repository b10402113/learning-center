HTML 文档结构与常用标签

js-reverse · 模组与网页基础 · 步骤 5/5

学习目标

看懂 HTML 文档骨架（DOCTYPE/html/head/body），分辨块级与内联标签，认识表单、超链接、图片等常见标签的属性，能定位页面元素在文档结构中的位置。

什么是 HTML？

HTML（HyperText Markup Language）是制作网页的标准标记语言，扩展名 .html 或 .htm。它是描述性语言，不是编程语言——写给浏览器看，告诉浏览器"这里是一段文字"、"那里是一张图"。

用户访问网页，本质是把服务器的 HTML 文档下载到本地，由浏览器按顺序解释渲染成网页效果。

HTML 文档骨架

<!DOCTYPE html>          ← 告诉浏览器用什么解析器
<html>                    ← 文档起止标记
  <head>                  ← 头部（不在窗口显示）
    <title>标题</title>    ← 标题栏标题
    <meta charset="UTF-8"> ← 声明编码
  </head>
  <body>                  ← 可见的网页主体
    <h1>Hello</h1>
    <p>段落</p>
  </body>
</html>
  • <!DOCTYPE html>：告诉浏览器用什么解析器解析文档。
  • <head>：内容不在浏览器窗口显示。<title> 定义标题栏标题，<meta charset="UTF-8"> 声明编码。
  • <body>：可见的网页主体。

标签的语法规则

  • 标签分闭合（<p>...</p>）和自闭合（<br>、<img>）两种。
  • HTML 不区分大小写。
  • 属性可带可不带。网页可见数据只能写在标签之间或属性中。

块级 vs 内联标签

类型特点常见标签
块级（block）独占一行<h1>-<h6>、<p>、<div>、<ul>、<table>
内联（inline）按内容占位<a>、<img>、<span>、<strong>、<em>

<div> 是无实际意义的块级元素、<span> 是无实际意义的行内元素，专为 CSS 样式服务。

常用标签

标题与段落

<h1>一级标题</h1>
<h2>二级标题</h2>
<p>段落</p>
<br>          ← 换行

文本格式化

<strong>粗体</strong>    ← 语义：重要
<b>粗体</b>            ← 单纯视觉
<em>斜体</em>            ← 语义：强调
<i>斜体</i>
<del>删除</del>
&nbsp;              ← 空格（HTML 里连续空格会被合并）

超链接 <a>

<a href="https://example.com" target="_blank">点击跳转</a>
  • href：跳转目标（网络链接或本地路径），留空则默认刷新当前页。
  • title：悬浮提示信息。
  • target="_blank"：新建窗口打开；_self 为默认覆盖自身。

图片 <img>

<img src="https://example.com/a.jpg" alt="描述" width="200">
  • src：图像 URL（本地或网络地址），不正确则显示裂图。
  • alt：图像无法显示时的替换文本。
  • width/height：控制显示尺寸。

列表

<ul>                  ← 无序列表
  <li>项目一</li>
  <li>项目二</li>
</ul>

<ol start="100">        ← 有序列表，从 100 开始
  <li>第一项</li>
</ol>

表格

<table border="1">
  <tr>                ← 行
    <td>单元格</td>   ← 列
    <td>单元格</td>
  </tr>
</table>
  • <tr> 定义行、<td> 定义列。
  • rowspan 合并行、colspan 合并列。

表单 <form>（逆向重点）

<form action="/login" method="post">
  <input type="text" name="username">
  <input type="password" name="password">
  <input type="submit" value="登录">
</form>
  • action：指向服务器处理程序 URL。
  • method：get 或 post（默认 get）。
  • input type：text、password、checkbox、radio、date、file、submit、reset 等。
  • 单选框的 name 必须一样，否则无法单选。
  • 文件上传必须设置 enctype="multipart/form-data"。

登录/搜索表单是逆向最常见的请求来源，须认识每个控件与提交参数的对应关系。
