對象屬性的 hook：Object.defineProperty

函數能被包裹，屬性的讀寫也能——把「取個值」「賦個值」都變成帶日誌的監控入口。

學習目標

掌握用 Object.defineProperty 的 get/set 重新定義對象屬性的寫法，把屬性的讀與寫都變成可監控的入口——包括對象上原本不存在的屬性。

為什麼屬性也需要 hook

函數 hook 監控的是「調用」這個動作。但網站的關鍵資料常常不走函數，而是藏在對象屬性裡：一個 token 被寫進 user.token，一個配置從 config.key 讀走。屬性的讀和寫發生時沒有任何函數被調用，函數 hook 對此無能為力。你需要的是把「讀屬性」和「寫屬性」本身變成可以攔截的操作。

Object.defineProperty（重新定義對象屬性的 API）就是為此而生。它接收三個參數：參數 1 是對象，參數 2 是屬性名，參數 3 是屬性描述符。描述符裡可以定義 get() 和 set(value) 兩個函數：讀取屬性值時執行 get，設置屬性值時執行 set。把這兩個函數換成帶日誌的版本，屬性就被 hook 了。

已有屬性的 hook：三步

// 1、創建一個對象
let user = {
    "name": "波波",
};

// 2、保存原屬性
_name = user.name;

// 3、對象屬性的 hook
Object.defineProperty(user, "name", {
    get(){ // 獲取屬性值的時候執行
        console.log("正在獲取屬性值");
        return _name;
    },
    set(value){ // 設置屬性值的時候執行
        console.log("正在設置屬性值:", value);
        _name = value;
    }
});

// 4、獲取屬性和設置屬性操作
console.log(user.name)   // 觸發 get：打印"正在獲取屬性值"，輸出 波波
user.name = 'Jay'        // 觸發 set：打印"正在設置屬性值: Jay"
console.log(user.name)   // 觸發 get：輸出 Jay

結構和函數 hook 完全同構：保存原值（_name = user.name）對應保存原函數；重新定義（defineProperty）對應同名覆蓋。讀寫方照常寫 user.name，毫無察覺。

關鍵細節：為什麼要把原值存到外部變數

注意 get 裡返回的是 _name，set 裡寫的也是 _name——兩者都不碰 user.name 本身。這不是風格問題，而是生死問題：如果在 get 裡寫 return user.name，讀取 user.name 又會觸發 get，無限遞歸直到棧溢出；set 同理。把真正的值保存在描述符之外的普通變數 _name 裡，get/set 只做「日誌 + 轉手」，就不會自引用。

不存在的屬性也能 hook

一個自然的疑問：對象上沒有的屬性（比如 user 只有 name，沒有 age），能 hook 嗎？能。Object.defineProperty 本來就是「定義」屬性的 API——屬性不存在時，它會把屬性創造出來。寫法一模一樣，只是「保存原值」這步變成給外部變數一個初始值：

let user = {
    "name": "波波",
};

// 保存原值（age 原本不存在，先給外部變數一個初始值）
_age = 18;

// 對象屬性 age 的 hook
Object.defineProperty(user, "age", {
    get(){
        console.log("正在獲取屬性值");
        return _age;
    },
    set(value){
        console.log("正在設置屬性值:", value);
        _age = value;
    }
});

console.log(user.age)   // 觸發 get：輸出 18
user.age = 20           // 觸發 set
console.log(user.age)   // 觸發 get：輸出 20

這個能力在實戰中很關鍵：網站常常在多個 JS 文件間傳值——xxx.js 裡創建對象，ooo.js 裡才 user.age = 18 動態加上屬性。你不必等屬性出現，提前把監控埋好，屬性第一次被寫入時就能看到。

本節小結

屬性 hook = 用 Object.defineProperty(obj, prop, { get, set }) 把屬性的讀寫重新定義成帶日誌的函數。三個要點：get 在讀取時執行、set(value) 在設置時執行；真正的值必須存到外部變數避免遞歸自引用；不存在的屬性可以先定義再監控。下一節把這兩套寫法搬進真實瀏覽器，去 hook 瀏覽器自帶的函數和 cookie。
