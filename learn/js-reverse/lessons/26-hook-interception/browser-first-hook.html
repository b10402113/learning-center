26-hook-interception / browser-first-hook

瀏覽器先手 hook：atob 與 cookie

網頁腳本跑完你才注入 hook 就太晚了——用 DevTools 搶在頁面加載之前埋下監控。

學習目標

能在真實瀏覽器裡用 DevTools 的 Script 事件監聽 + Sources Snippets，在頁面加載之前完成 atob 與 document.cookie 的先手 hook，監控每一次調用。

問題：hook 寫好了，但來不及注入

前面兩節的寫法在本地 demo 裡完美可用。可真到了瀏覽器裡，時機成了頭號難題：目標網站的加密代碼在頁面加載過程中就跑掉了——比如把登入憑證加密成 base64 再發出去。等你打開控制台手動粘貼 hook 代碼，關鍵的那次調用早已結束。hook 必須在瀏覽器頁面加載出來之前完成，才能攔到第一批調用。

本節的目標是 hook 瀏覽器環境自帶的 atob——它是瀏覽器內置的 base64 解碼函數。網站只要做 base64 編解碼就繞不開它，hook 住它就等於在所有 base64 數據的必經之路上設了崗哨，這是逆向 base64 數據最常用的起手式。

先手 hook 的五步操作鏈

核心思路：用 DevTools 的「Script 事件監聽」讓頁面在執行第一段腳本之前自動斷住，趁機注入 hook。

步驟操作目的
1在空白頁面打開瀏覽器開發者工具（F12）在乾淨的環境準備好工具，不觸發目標站腳本
2開啟 JS 的事件監聽器斷點：Sources → Event Listener Breakpoints → 勾選 Script讓 DevTools 在任何腳本執行的瞬間自動斷住
3訪問目標頁（如百度），頁面會立刻斷點停留在腳本執行前搶在網站自己的代碼動起來之前獲得控制權
4在 Sources 的 Snippets（程式碼片段）中新建 hook 代碼片段，打上斷點，然後運行在頁面腳本執行之前注入 hook
5取消事件監聽器中的 Script 勾選，之後即可監控每次調用hook 已生效，不再需要每段腳本都斷住

第 5 步有一個致命細節：不可刷新頁面。hook 是對當前頁面裡的函數對象做的替換，一旦刷新，整個 JS 環境重建，hook 隨之消失，必須從第 1 步重來。

atob 的 hook 代碼

寫法就是函數 hook 的四步套路，一個字都不用改：

_atob = atob; // 保存原函數

atob = function (str) {
    console.log("正在執行atob方法, 參數:", str);
    let result = _atob(str);
    console.log("正在執行atob方法, 返回值:", result);
    return result;
};

注入成功後，網站每做一次 base64 解碼，控制台就自動打印出原始密文字符串和解出的明文。配合 console.trace() 還能順藤摸瓜找到調用它的加密邏輯位置。

cookie 的 hook：屬性 hook 的實戰版

document.cookie 是屬性不是函數，所以換用上一節的 defineProperty 寫法。操作步驟與 atob hook 完全相同（同一條五步操作鏈），只是注入的 Snippet 換成：

_cookie = document.cookie; // 先保存原值

Object.defineProperty(document, 'cookie', {
    get(){
        console.log("正在獲取cookie:", _cookie);
        return _cookie;
    },
    set(value){
        console.log("正在設置cookie:", value);
        _cookie = value;
    }
});

cookie 是登入憑證的大本營（session id、token 常寫在這裡）。hook 住它，網站什麼時候讀出、什麼時候寫入 cookie、每次寫入的值是什麼，全部一覽無餘——這正是定位重要憑證生成位置的手段。

本節小結

瀏覽器先手 hook 的關鍵不是新寫法，而是時機：在頁面加載之前完成注入。操作鏈是：空白頁開 DevTools → 勾選 Script 事件監聽斷點 → 訪問目標頁讓它斷住 → Snippets 注入 hook 代碼 → 取消 Script 監聽（之後不可刷新）。hook 內容本身只是複用前面的套路：atob 用函數 hook，cookie 用 defineProperty 屬性 hook。有了先手能力，下一節要看攻防的另一面——網站如何檢測你的 hook，你又如何隱藏它。
