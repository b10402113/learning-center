滑動驗證：cv2 模板匹配與擬人化軌跡

js-reverse · 08-pyppeteer · Step 4/4

學習目標

能用 cv2 模板匹配算出滑塊缺口距離，並用 Pyppeteer 的 hover/down/move/up 序列模擬人的滑動軌跡。

滑動驗證的通用解法

你在 day09 用 Selenium 做過滑動驗證，Pyppeteer 的思路完全一樣，只是 API 不同。整個流程分兩步：

  1. 算距離：用 OpenCV 的模板匹配算出缺口位置。
  2. 模擬滑動：用滑鼠事件序列拖曳滑塊到缺口。

用 cv2 模板匹配算缺口距離

這一步和 Selenium 完全相同。先下載背景圖和缺口圖，再用 cv2.matchTemplate() 比對：

import cv2
import numpy as np

background = cv2.imread('background.png', 0)
gap = cv2.imread('gap.png', 0)

result = cv2.matchTemplate(background, gap, cv2.TM_CCOEFF_NORMED)
min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(result)
x = max_loc[0]  # 缺口的 x 座標

注意：圖片在網頁上顯示的尺寸可能和原圖不同，必須做像素單位換算。例如網頁上顯示 360px，原圖是 278px，就要乘以 278 / 360，再減去滑塊起始位置的偏移量：

distance = x * 278 / 360 - 13

Pyppeteer 的擬人化輸入

在模擬滑動之前，通常要先輸入帳號密碼。Pyppeteer 的 type() 可以設定 delay 參數，讓每個字元的輸入間隔隨機化，模擬人的打字節奏：

import random

await page.type('#loginname', 'my_account', {'delay': random.randint(30, 60)})
await page.type('#nloginpwd', 'my_password', {'delay': random.randint(30, 60)})

這種「隨機 delay」是通過率的关键——固定間隔太像機器人。

擬人化滑動軌跡

Pyppeteer 的滑鼠操作是分步驟的，這讓我們能精確控制軌跡。滑動序列如下：

# 1. 懸停在滑塊上
await page.hover('#slider')

# 2. 按下滑鼠左鍵
await page.mouse.down()

# 3. 分 100 步緩慢移動到目標位置
await page.mouse.move(x + distance, y, {'steps': 100})

# 4. 釋放滑鼠左鍵
await page.mouse.up()

其中 steps: 100 是關鍵——steps 越大，移動越慢、越像人。如果一步到位，會被判定為機器人。

加入隨機偏移

為了讓軌跡更自然，可以在橫向距離上加一個隨機偏移量：

import random

actual_distance = distance + random.uniform(20, 40)
await page.mouse.move(x + actual_distance, y, {'steps': 100})

這個偏移模擬的是人眼判斷的微小誤差。

取得元素位置

在懸停之前，需要知道滑塊的位置。用 boundingBox() 取得元素的邊界框：

slider = await page.J('#slider')
box = await slider.boundingBox()
x = box['x']
y = box['y']

完整滑動流程

slider = await page.J('#slider')
box = await slider.boundingBox()
x, y = box['x'], box['y']

await page.hover('#slider')
await page.mouse.down()
await page.mouse.move(x + distance, y, {'steps': 100})
await page.mouse.up()

await page.waitFor(2000)  # 等待驗證結果
