快速上手：核心 API 走通渲染頁面抓取

js-reverse · 08-pyppeteer · Step 2/4

學習目標

能獨立寫出 Pyppeteer 非同步爬蟲的完整骨架：launch → newPage → goto → content，並把它嵌進 asyncio 任務回呼體系。

從一個 JS 渲染頁開始

假設我們要爬 quotes.toscrape.com/js/，這個頁面的內容是 JavaScript 動態產生的，用 requests 直接拿只會得到空殼 HTML。Pyppeteer 的解法很簡單：讓瀏覽器跑完 JS，再取渲染後的原始碼。

五行核心 API

Pyppeteer 的爬蟲骨架只有五個步驟，全部寫在一個 async def 函式裡：

import asyncio
from pyppeteer import launch

async def main():
    browser = await launch(headless=True)   # 1. 啟動瀏覽器
    page = await browser.newPage()          # 2. 開新分頁
    await page.goto('http://quotes.toscrape.com/js/')  # 3. 跳轉並等待載入
    content = await page.content()          # 4. 取得渲染後的原始碼
    await browser.close()                   # 5. 關閉瀏覽器
    return content

html = asyncio.get_event_loop().run_until_complete(main())

這五行程式碼就能達到 Selenium 同等的效果，而且全程非同步。

把 Pyppeteer 嵌進 asyncio 任務回呼

你在 day08 學過「特殊函式 → 協程物件 → 任務物件 → 事件循環」的架構。Pyppeteer 可以無縫嵌進去，寫法一樣：用 asyncio.ensure_future() 包成任務物件，再用 add_done_callback() 綁定解析回呼。

import asyncio
from pyppeteer import launch
from lxml import etree

async def crawl(url):
    browser = await launch(headless=True)
    page = await browser.newPage()
    await page.goto(url)
    content = await page.content()
    await browser.close()
    return content

def parse(task):
    html = task.result()
    tree = etree.HTML(html)
    titles = tree.xpath('//h2/text()')
    print(titles)

url = 'https://news.163.com/'
loop = asyncio.get_event_loop()
task = asyncio.ensure_future(crawl(url))
task.add_done_callback(parse)
loop.run_until_complete(task)

這種「渲染 + 非同步 + 解析」的模板，就是 Pyppeteer 爬蟲的標準結構。

用本機 Chrome 取代內建 Chromium

如果不想用 Pyppeteer 內建的 Chromium，可以把 executablePath 指向本機已裝的 Google Chrome。路徑可以在瀏覽器網址列輸入 chrome://version/，找到「應用程式路徑」或「個人資料路徑」：

browser = await launch(
    headless=True,
    executablePath='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
)
