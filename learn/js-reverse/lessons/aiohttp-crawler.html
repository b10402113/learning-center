aiohttp 与多任务异步爬虫实战

js-reverse · 06-asyncio · Step 4/4

学习 goal

能独立写出基于 aiohttp + asyncio 的多任务异步爬虫，理解为什么 requests/time 必须换成 aiohttp/asyncio.sleep。

为什么 requests 不行

requests 是同步库。它的 get() 方法会阻塞当前线程，直到服务器返回响应。如果在 asyncio 的特殊函数里用 requests，整个事件循环都会被卡住——其他任务全部暂停，异步就变成了同步。

解决办法：用 aiohttp——一个支持异步的网络请求库，API 设计和 requests 很像，但所有方法都是 async 的，可以被 await 挂起。

aiohttp 快速上手

aiohttp 的核心是 ClientSession，用法和 requests 相似：

import aiohttp
import asyncio

async def fetch(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

# response.text() → 字符串
# response.read() → 二进制
# response.json() → JSON 自动反序列化

代理参数：和 requests 不同

aiohttp 的代理参数写法与 requests 不同。requests 用 proxies={'http': 'http://ip:port'}，aiohttp 直接用 proxy='http://ip:port'：

async with session.get(url, proxy='http://127.0.0.1:7890') as response:
    return await response.text()

多任务异步爬虫完整实战

来看一个完整的例子：用 Flask 搭建带 2 秒延迟的本地服务器模拟慢速网站，然后用 aiohttp 并发请求。三个 2 秒的请求，异步后总耗时约 2 秒。

服务端（模拟慢速网站）

from flask import Flask
import time

app = Flask(__name__)

@app.route('/page/')
def page(n):
    time.sleep(2)  # 模拟慢速响应
    return f'<h1>Page {n}</h1>'

app.run()

爬虫端（aiohttp + asyncio）

import aiohttp
import asyncio
from lxml import etree

async def fetch(session, url):
    async with session.get(url) as response:
        return await response.text()

def parse(html):
    # 回调函数：解析数据
    tree = etree.HTML(html)
    title = tree.xpath('//h1/text()')[0]
    print(title)

async def main():
    urls = [f'http://127.0.0.1:5000/page/{i}' for i in range(1, 4)]
    async with aiohttp.ClientSession() as session:
        tasks = [asyncio.ensure_future(fetch(session, url)) for url in urls]
        # 绑定回调：数据解析放在回调里完成
        for task in tasks:
            task.add_done_callback(lambda t: parse(t.result()))
        await asyncio.wait(tasks)

loop = asyncio.get_event_loop()
loop.run_until_complete(main())

关键替换清单

同步写法（会卡住）异步写法（正确）
requests.get(url)session.get(url)（aiohttp）
time.sleep(2)await asyncio.sleep(2)
response.textawait response.text()
proxies={'http': '...'}proxy='http://...'

为什么总耗时约 2 秒

三个请求是同时发出的——asyncio.wait(tasks) 让它们并发执行。每个请求等 2 秒，但它们是同时等的，所以总耗时约 2 秒，而不是 6 秒。这就是异步的收益。

数据解析放在回调里

实战中，数据解析（lxml + xpath）通常放在任务回调里完成。这样任务一旦完成，立刻触发解析，不需要等所有任务都完成再统一处理。
