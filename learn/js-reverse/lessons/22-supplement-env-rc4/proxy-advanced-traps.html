Proxy 进阶捕获器：属性描述符与调用/构造拦截

网站绕过 get/set 的三种姿势，Proxy 都有对应的捕获器

为什么 get/set 还不够？

上一课用 get/set 拦住了「点号读写」——obj.name、obj.age = 25 这类操作。但 JS 对象身上的底层操作远不止这两种。有些网站偏偏不走点号，而是用属性描述符 API 读写属性；你还可能想监控「某个加密函数什么时候被调用、参数是什么」「网站什么时候 new 了一个对象」。这三种操作，get/set 全都抓不到。

Proxy 的设计是一对一的：JS 里每种底层操作，都有对应的捕获器（trap）。这节课补齐逆向中最常用的四个进阶 trap：getOwnPropertyDescriptor、defineProperty、apply、construct。补完之后，网站换什么姿势操作对象，都躲不过你的监控。

先补一课：属性描述符是什么

JS 对象的每个属性，除了值之外还带着一份「说明书」，叫属性描述符。用 Object.getOwnPropertyDescriptor 能看到它：

var Stu = { "name": "小明" };

console.log(Object.getOwnPropertyDescriptor(Stu, "name"));
// { value: '小明', writable: true, enumerable: true, configurable: true }

四个字段：value 是属性值；writable 控制能不能改值；enumerable 控制能不能被 for...in 枚举出来；configurable 控制能不能删除属性或修改描述符本身。

关键点在这里：网站可以用 Object.getOwnPropertyDescriptor(Stu, "name").value 读到 name 的值——整个过程不触发你的 get trap。同理，用 Object.defineProperty 定义属性也不会触发 set。这就是网站绕过基础监控的标准手法。

getOwnPropertyDescriptor：拦截描述符读取

在 handler 里加上同名 trap，描述符读取这一操作也被纳入监控：

var User = {
    username: "bobo",
    age: 20,
    address: "Bj"
};

User = new Proxy(User, {
    get(target, p, receiver) {
        console.log(`获取属性${p}操作`);
        return Reflect.get(target, p);
    },
    getOwnPropertyDescriptor(target, p) {
        let result;
        result = Reflect.getOwnPropertyDescriptor(target, p);
        console.log(`通过属性描述符获取属性${p}操作`);
        return result;
    }
});

console.log(User.username);  // 触发 get
console.log(Object.getOwnPropertyDescriptor(User, "address").value);
// 触发 getOwnPropertyDescriptor，日志打出「通过属性描述符获取属性address操作」

写法和 get 完全同构：先用 Reflect.getOwnPropertyDescriptor(target, p) 拿到真实结果，再打日志，最后把结果原样返回。注意返回值必须是一个合法的描述符对象（或 undefined），不能随便返回别的，否则 JS 引擎会报错。

defineProperty：拦截描述符定义

写入方向同理。网站用 Object.defineProperty 给对象定义属性时——比如偷偷挂一个检测字段——defineProperty trap 就会触发：

var Person = {};

Person = new Proxy(Person, {
    getOwnPropertyDescriptor(target, p) {
        let result;
        result = Reflect.getOwnPropertyDescriptor(target, p);
        console.log(`通过属性描述符获取属性${p}操作`);
        return result;
    },
    defineProperty: function (target, p, descriptor) {
        console.log(`通过属性描述符设置属性${p}操作`);
        let result;
        result = Reflect.defineProperty(target, p, descriptor);
        return result;
    }
});

// 通过属性描述符给 Person 定义一个 name 属性
Object.defineProperty(Person, 'name', {
    value: 'Bobo',
    writable: true,      // 允许修改属性值
    enumerable: true,    // 允许枚举属性
    configurable: true   // 允许删除或修改属性描述符
});

descriptor 参数就是网站传进来的那个描述符对象——它想写什么值、设了哪些开关，你在 trap 里看得一清二楚。这对分析「网站在对象上藏了什么字段」特别有用。

apply：拦截函数调用

Proxy 不只包对象，也能包函数。函数被调用时，apply trap 触发：

add = function (a, b) {
    console.log("add函数正在被调用");
    return a + b;
};

add = new Proxy(add, {
    apply: function (target, thisArg, argList) {
        // target: 函数对象。thisArg: 调用时的 this 指针。argList: 参数数组
        let result;
        result = Reflect.apply(target, thisArg, argList);
        console.log(`${target.name}函数被调用，参数为:${argList}`);
        return result;
    }
});

add(1, 2);

三个参数各管一件事：target 是被代理的函数对象（target.name 能拿到函数名）；thisArg 是这次调用的 this 指向；argList 是参数数组——add(1, 2) 传进来就是 [1, 2]。Reflect.apply 用原参数执行原函数，拿到返回值后打日志再返回。

逆向用法很直接：定位到加密函数后，给它套上带 apply 的 Proxy，它每次被调用、传了什么参数全部落在控制台里。这和 hook 的「保存原函数 + 同名覆盖」殊途同归，但 Proxy 的写法更系统，不用手动管原函数的保存与调用。

construct：拦截 new 构造

new Fn() 调的就是构造函数。要监控「网站什么时候 new 了一个对象」，用 construct trap：

function Animal() {
    // 构造方法，类似 Python 里的 __init__
}

Animal = new Proxy(Animal, {
    construct: function (target, argArray, newTarget) {
        // target: 函数对象。argArray: 构造参数列表。newTarget: 代理后的对象
        let result = Reflect.construct(target, argArray, newTarget);
        console.log(`${target.name}对象被创建`);
        return result;
    }
});

obj = new Animal();  // 日志打出「Animal对象被创建」

argArray 是传给构造函数的参数列表，newTarget 是代理后的构造函数本身。Reflect.construct 负责真正执行构造、产出实例，trap 里把这个实例返回即可。网站的加密器如果是个类（new Encryptor(key) 这种写法），construct 一拦，密钥什么时候传进来的就暴露了。

六类 trap 速查表

到这里，逆向中最常用的 Proxy 捕获器就齐了。记住这个对应表：每种操作一个 trap，trap 里用同名 Reflect 方法转发原操作。

网站的操作触发的 trap转发用的 Reflect
obj.p 读属性getReflect.get
obj.p = v 写属性setReflect.set
Object.getOwnPropertyDescriptor(obj, p)getOwnPropertyDescriptorReflect.getOwnPropertyDescriptor
Object.defineProperty(obj, p, desc)definePropertyReflect.defineProperty
fn(...args) 调用函数applyReflect.apply
new Fn(...args) 构造对象constructReflect.construct

把这套带全部 trap 的 Proxy 套在 window 上做环境探测，监控面就从「点号读写」扩展到了「描述符 API、函数调用、对象构造」。网站无论换哪种姿势读环境、藏字段、调函数，都会在日志里留下痕迹。
