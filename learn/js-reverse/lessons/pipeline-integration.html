完整管道项目整合

Scrapy 管道与持久化 · 步骤 4/4

学习目标

把多管道与内置管道组合成一个真实可跑的项目：列表页进详情页、解析字段交管道、图片走 ImagesPipeline、元数据走多管道分别落盘数据库与文件。

项目目标：爬取图片站

这一节我们做一个完整的 Scrapy 项目：爬取一个图片列表页，进入每张图片的详情页，提取标题、图片链接、标签，然后：

  • 图片二进制数据 → ImagesPipeline 下载并保存到本地
  • 标题、标签等元数据 → MySQL 管道 存入数据库
  • 标题、标签等元数据 → Redis 管道 推入待处理队列
  • 标题、标签等元数据 → 文件管道 写入 CSV 做备份

这是一个典型的"一进四出"管道架构：Spider 只负责解析，存储全部交给管道链。

items.py：定义 Item

import scrapy

class ImageItem(scrapy.Item):
    title = scrapy.Field()        # 图片标题
    tags = scrapy.Field()         # 标签列表
    image_url = scrapy.Field()    # 图片链接（ImagesPipeline 用）
    image_path = scrapy.Field()   # 下载后的本地路径（管道自动填）
    source_url = scrapy.Field()   # 来源页面 URL

spiders/image_spider.py：爬虫解析

爬虫分两步：先解析列表页，提取详情页链接；再进详情页，提取标题、标签、图片链接，封装成 Item。

import scrapy
from myspider.items import ImageItem

class ImageSpider(scrapy.Spider):
    name = 'image'
    allowed_domains = ['example.com']
    start_urls = ['https://example.com/list']

    def parse(self, response):
        """解析列表页，提取详情页链接"""
        detail_urls = response.xpath('//a[@class="detail"]/@href').extract()
        for url in detail_urls:
            full_url = response.urljoin(url)
            yield scrapy.Request(full_url, callback=self.parse_detail)

    def parse_detail(self, response):
        """解析详情页，提取字段并封装 Item"""
        item = ImageItem()
        item['title'] = response.xpath('//h1/text()').extract_first()
        item['tags'] = response.xpath('//div[@class="tags"]/a/text()').extract()
        item['image_url'] = response.xpath('//img[@class="main"]/@src').extract_first()
        item['source_url'] = response.url
        yield item

注意：parse 里用 response.urljoin(url) 把相对链接补成绝对链接，否则 ImagesPipeline 会下载失败。

pipelines.py：四个管道类

四个管道各司其职，按优先级串联：

# pipelines.py
import json
import pymysql
from redis import Redis
from scrapy.pipelines.images import ImagesPipeline
from scrapy.http import Request

# 1. ImagesPipeline 子类（优先级 100，最先执行）
class ImageDownloadPipeline(ImagesPipeline):

    def get_media_requests(self, item, info):
        url = item['image_url']
        if url:
            yield Request(url)

    def file_path(self, request, response=None, info=None, *, item=None):
        title = item['title'].replace('/', '-')  # 避免文件名含斜杠
        return f'full/{title}.jpg'

    def item_completed(self, results, item, info):
        for ok, value in results:
            if ok:
                item['image_path'] = value['path']
        return item


# 2. 文件管道（优先级 200）
class CsvBackupPipeline:
    def open_spider(self, spider):
        self.f = open('images_backup.csv', 'w', encoding='utf-8')
        self.f.write('title,tags,image_path,source_url\n')

    def process_item(self, item, spider):
        line = f"{item['title']},{'|'.join(item['tags'])},{item.get('image_path','')},{item['source_url']}\n"
        self.f.write(line)
        return item

    def close_spider(self, spider):
        self.f.close()


# 3. MySQL 管道（优先级 300）
class MySQLPipeline:
    def open_spider(self, spider):
        self.conn = pymysql.Connect(
            host='localhost', port=3306,
            user='root', password='123456',
            db='image_db', charset='utf8mb4'
        )
        self.cursor = self.conn.cursor()

    def process_item(self, item, spider):
        sql = "INSERT INTO image (title, tags, image_path, source_url) VALUES (%s, %s, %s, %s)"
        self.cursor.execute(sql, (
            item['title'],
            json.dumps(item['tags'], ensure_ascii=False),
            item.get('image_path', ''),
            item['source_url']
        ))
        self.conn.commit()
        return item

    def close_spider(self, spider):
        self.cursor.close()
        self.conn.close()


# 4. Redis 管道（优先级 400，最后执行）
class RedisPipeline:
    def open_spider(self, spider):
        self.r = Redis(host='localhost', port=6379, db=0)

    def process_item(self, item, spider):
        self.r.lpush('image_queue', json.dumps(dict(item), ensure_ascii=False))
        return item

    def close_spider(self, spider):
        pass

settings.py：开启管道并配置存储

# settings.py
BOT_NAME = 'myspider'
SPIDER_MODULES = ['myspider.spiders']
NEWSPIDER_MODULE = 'myspider.spiders'

ROBOTSTXT_OBEY = False
LOG_LEVEL = 'ERROR'

# 图片存储路径
IMAGES_STORE = 'images'
IMAGES_THUMBS = {
    'small': (50, 50),
    'big': (270, 270)
}

# 管道优先级：数字越小越先执行
ITEM_PIPELINES = {
    'myspider.pipelines.ImageDownloadPipeline': 100,
    'myspider.pipelines.CsvBackupPipeline': 200,
    'myspider.pipelines.MySQLPipeline': 300,
    'myspider.pipelines.RedisPipeline': 400,
}

执行顺序：ImagesPipeline 先下载图片 → CSV 管道写备份 → MySQL 管道存数据库 → Redis 管道推队列。每个管道都必须 return item，否则链就断了。

运行项目

scrapy crawl image

运行后你会看到：

  • images/ 目录下多了原图和缩略图
  • images_backup.csv 里有一行行元数据
  • MySQL 的 image 表里有新记录
  • Redis 的 image_queue 列表里推入了 JSON 字符串

管道链断了怎么排查？

如果某个管道忘了 return item，后面的管道就收不到数据。排查方法：

  1. 看日志：Scrapy 不会报错，但后面的管道不会执行。
  2. 在每个管道的 process_item 开头加 print(f"Processing in {self.__class__.__name__}")，看输出到哪个管道就停了。
  3. 检查 settings.py 里的优先级数字，确认顺序是否符合预期。

常见踩坑

  • ImagesPipeline 的优先级设得太大：如果 MySQL 管道优先级是 100，ImagesPipeline 是 400，那 MySQL 会先执行，此时图片还没下载，image_path 就是空的。
  • Redis 存了 Item 对象：必须 json.dumps(dict(item)) 转成字符串，否则 Redis 会报错。
  • MySQL 的 tags 字段是列表：数据库里不能直接存列表，要 json.dumps(item['tags']) 序列化成 JSON 字符串。
  • 图片链接为空：如果详情页没有图片，get_media_requests 里要判断 if url，否则会 yield 一个 None 导致报错。
