极简壁纸请求-解密-下载闭环

POST → execjs 解密 → JSON 解析 → 拼 URL → 二进制落盘

这个案例的完整链路

极简壁纸（bz.zzzmh.cn）是一个响应体加密的典型案例。请求本身没有加密参数，服务器返回的 JSON 里只有一个加密字符串。解密、解析、下载，全靠客户端完成。

完整流程分五步：

  1. POST 请求 /bz/v3/getData，拿到加密响应。
  2. 用 execjs 调 JS 解密函数，把加密字符串还原成明文 JSON。
  3. json.loads 解析明文，取出图片列表。
  4. 遍历列表，拼接每张图片的高清下载地址。
  5. GET 请求下载地址，把图片二进制写入本地。

第一步：POST 请求拿加密响应

接口地址是 https://api.zzzmh.cn/bz/v3/getData，POST 请求，请求体是 JSON：

import requests

headers = {
    'authority': 'api.zzzmh.cn',
    'accept': 'application/json, text/plain, */*',
    'accept-language': 'zh-CN,zh;q=0.9',
    'cache-control': 'no-cache',
    'content-type': 'application/json;charset=UTF-8',
    'origin': 'https://bz.zzzmh.cn',
    'referer': 'https://bz.zzzmh.cn/',
    'user-agent': 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15.7) AppleWebKit/537.36 ...',
}

json_data = {
    'size': 24,
    'current': 1,
    'sort': 0,
    'category': 0,
    'resolution': 4,
    'color': 0,
    'categoryId': 0,
    'ratio': 0,
}

response = requests.post('https://api.zzzmh.cn/bz/v3/getData', headers=headers, json=json_data)
result = response.json().get("result")
print(result)  # 输出: ak+9VCsq4dEdB+UdU/Go8kh5JDEbMHGTCmF/AyXJQ0IgHU+lUAiv ...

响应体里 result 字段就是加密的 base64 字符串。这一步没有任何加密参数，headers 里的 authority、origin、referer 都是从浏览器复制过来的，照搬即可。

第二步：execjs 调 JS 解密

把上一课讲的扣下代码准备好（08 极简壁纸.js），用 execjs 加载并调用入口函数 _0x58b5da：

import execjs

data = execjs.compile(open("08 极简壁纸.js").read()).call("_0x58b5da", result)
print("data:", data)
print("data:", type(data))

关键点：

  • execjs.compile(...) 把 JS 代码编译成可执行的上下文。
  • .call("_0x58b5da", result) 调用入口函数，传入加密字符串。
  • 扣下的 JS 文件里已经有 window = global;，所以能直接跑。

第三步：JSON 解析取图片列表

解密后的 data 是一个 JSON 字符串，需要用 json.loads 解析成 Python 字典，再取出 list 字段：

import json

data = json.loads(data).get("list")
# data 是一个列表，每个元素是一张壁纸的信息字典

列表里的每个元素至少包含两个字段：

  • i：图片的基础 ID。
  • t：图片的类型编号。

第四步：拼接高清下载地址

每张图片的高清下载地址规则是：

高清地址 = "https://api.zzzmh.cn/bz/v3/getUrl/" + i + str(t) + "9"

比如 i=12345, t=6，拼出来的就是 https://api.zzzmh.cn/bz/v3/getUrl/1234569。这里的 "9" 是固定后缀，可能代表最高分辨率。

for img in data:
    i = img.get("i")
    t = img.get("t")
    id_num = i + str(t) + "9"
    url = "https://api.zzzmh.cn/bz/v3/getUrl/" + id_num
    print(url)

第五步：下载图片并落盘

拿到高清地址后，GET 请求就能拿到图片二进制内容。写入本地时一定要用 wb 模式（二进制写入），否则图片会损坏：

for img in data:
    i = img.get("i")
    t = img.get("t")
    id_num = i + str(t) + "9"
    url = "https://api.zzzmh.cn/bz/v3/getUrl/" + id_num

    res = requests.get(url, headers=headers)

    with open(f"img/{id_num}.jpg", "wb") as f:
        f.write(res.content)
    print(f"{id_num} 下载成功!")

注意几点：

  • headers 和 POST 请求保持一致，否则可能被拒绝。
  • 文件路径 img/{id_num}.jpg 里的 img/ 目录必须提前创建。
  • res.content 是 bytes 对象，对应二进制内容；res.text 是字符串，不能用来写图片。

响应体加密 vs 参数加密

极简壁纸属于响应体加密：请求本身没加密，密文藏在响应里。这和前面学过的参数加密（sign、AES 加密请求字段）形成对比：

类型密文位置逆向目标典型算法
参数加密请求 URL / 表单复现加密算法，生成密文MD5、SHA1、AES
响应体加密响应 JSON / 字符串复现解密算法，还原明文RC4、AES、Base64

响应体加密的破解链路更长：不仅要会解密，还要处理 base64 编码、字符编码、JSON 解析、文件下载。但加密强度往往更低，因为 RC4 这类算法本身不难。
