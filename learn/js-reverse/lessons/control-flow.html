分支與迴圈：if、switch、while、for

js-reverse · 14-js-variables-control · Step 3/4

學習目標

能讀懂 if-else / if-else-if / switch-case 三種分支結構，理解 switch 的 break 穿透行為，以及 while 與 for 共用的迴圈三要素。

為什麼分支和迴圈是流程還原的關鍵

加密代碼本質就是「根據不同條件走不同路線」再加上「重複執行某些步驟」。只要你會看分支和迴圈，就能把一段加密流程畫成流程圖——sign 演算法裡哪個步驟先跑、哪個步驟重複跑幾次，全部寫在分支和迴圈裡。

if-else 雙分支

最基本的條件判斷，條件為真時走 if 區塊，否則走 else 區塊。if 裡面還可以再包 if，形成任意深度的巢狀。

var age = 9
if (age >= 18) {
    console.log("成年電影")
} else {
    console.log("未成年電影")
}

if-else-if 多分支

當條件超過兩個，用 else if 接龍。JS 從上往下檢查，遇到第一個成立的條件就進去，後面的全部跳過。

var score = 88
if (score > 90) {
    console.log("成績優秀")
} else if (score > 80) {
    console.log("成績良好")   // 這行被執行
} else if (score > 60) {
    console.log("成績及格")
} else {
    console.log("不及格")
}

因為 88 > 80 成立，JS 就進去印出「成績良好」，後面的 else if 和 else 通通跳過。

switch-case：另一條多分支路線

當判斷條件是「等於某個值」的時候，switch-case 比 if-else-if 整齊。

var week = 6
switch (week) {
    case 0: console.log("星期日"); break
    case 1: console.log("星期一"); break
    case 2: console.log("星期二"); break
    case 3: console.log("星期三"); break
    case 4: console.log("星期四"); break
    case 5: console.log("星期五"); break
    case 6: console.log("星期六"); break
    default: console.log("輸入不符合條件")
}

break 穿透：switch 最大的坑

case 結尾必須寫 break，否則 JS 會「穿透」繼續執行下一個 case 的程式碼，不管條件符不符合。

switch (week) {
    case 6: console.log("星期六")   // 沒有 break
    case 5: console.log("星期五")   // 沒有 break
    default: console.log("其他")
}
// 當 week = 6 時，輸出：星期六、星期五、其他

逆向時如果發現某個 case 沒寫 break，不代表是程式碼寫壞了——有時是故意穿透把多個條件串在一起執行。

default 是「以上皆非」的兜底選項，放在最後，有沒有 break 都可以。

while 迴圈：條件成立就繼續跑

while 每次執行前先檢查條件，條件為真才進入迴圈體。設計迴圈時要掌握「迴圈三要素」：初始變數、條件判斷、步進更新。少了任何一個，迴圈不是跑不出來，就是永遠停不下來。

var count = 0           // 初始變數
while (count < 10) {    // 條件判斷
    console.log(count)
    count++             // 步進更新
}

for 迴圈：三要素寫在同一行

for 的本質和 while 完全相同，只是把三要素壓縮到一行，可讀性更好。

for (var count = 0; count < 10; count++) {
    console.log(count)
}

三個位置的對應關係：初始變數、條件判斷、步進更新。只要認出這三個，就能立刻知道迴圈跑幾次。

迴圈在逆向中的角色

還原加密演算法時，迴圈是辨識「重複執行」的關鍵結構。MD5 的 64 輪雜湊、AES 的多輪加密、字元的逐位異或——全部用迴圈實作。看到一個 for 迴圈，先問自己：初始值是多少？條件會讓它跑幾圈？每次圈做些什麼？這三個問完，演算法的論廓就出來了。
