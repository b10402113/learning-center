HTML 多媒體標籤

學習目標

讀懂 video 與 audio 的播放屬性，從 HTML 找到可供後續請求分析的媒體 URL。

影音標籤

<video src="lesson.mp4" controls width="640"></video>
<audio src="intro.mp3" controls loop></audio>
屬性作用
src媒體檔案的路徑或 URL
controls顯示播放控制項，預設不顯示
autoplay頁面載入後嘗試自動播放
loop循環播放，可用正整數指定次數或以 -1 表示無限循環
width/height設定播放窗口尺寸

從 HTML 找資源

逆向時先檢查 video、audio 的 src，也要注意巢狀的 source 標籤與瀏覽器格式支援差異；真正下載前仍需確認授權與存取條件。

import re
html = '<video src="https://cdn.test/a.mp4">'
url = re.search(r'<video[^>]+src="([^"]+)"', html).group(1)
