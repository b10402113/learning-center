HTML 多媒体标签

js-reverse · 模组与网页基础 · 步骤 6/6

学习目标

认识 video 与 audio 标签的属性与用法，理解如何从 HTML 中提取多媒体资源的真实 URL。

为什么多媒体标签重要？

爬取视频或音频网站时，你看到的页面只是外壳——真正的媒体文件藏在 <video> 或 <audio> 标签的 src 属性里。理解这些标签，才能从 HTML 中定位到真实的资源 URL。

<video> 视频标签

<video src="video.mp4" controls autoplay width="600px"></video>
属性作用说明
src视频文件的路径或 URL本地路径或网络地址均可
controls是否显示播放控件默认不显示，加上即显示
autoplay页面加载后自动播放多数浏览器限制自动播放音频
loop循环播放loop 或 loop="-1" 无限循环；正整数指定次数
width播放窗口宽度如 width="600px"
height播放窗口高度如 height="400px"

完整示例：

<video
  src="https://example.com/video.mp4"
  controls
  autoplay
  width="600px"
></video>

<audio> 音频标签

<audio src="music.mp3" controls autoplay loop></audio>
属性作用说明
src音频文件的路径或 URL本地路径或网络地址均可
controls是否显示播放控件默认不显示
autoplay页面加载后自动播放浏览器通常限制自动播放
loop循环播放loop 或 loop="-1" 无限循环

从 HTML 提取多媒体 URL

爬取音视频站点时，核心思路就是从页面 HTML 中找到 <video> 或 <audio> 标签的 src 属性：

import re

html = '<video src="https://example.com/video.mp4" controls></video>'
urls = re.findall(r'<video src="(.*?)"', html)
print(urls)  # ['https://example.com/video.mp4']

实际网站中，src 可能是相对路径，需要拼接基 URL；也可能被 JavaScript 动态渲染，需要用 Selenium 等工具获取完整 DOM。

浏览器兼容性

由于版权等原因，不同浏览器支持的播放格式不同。常见格式：

类型常见格式
视频.mp4（最通用）、.webm、.ogg
音频.mp3（最通用）、.wav、.ogg
