鏈式 Promise 與 AJAX 封裝

用鏈式 Promise 拉平串行異步流程，並學會將回調風格的異步 API（如 $.ajax）封裝成 Promise 供鏈式消費。

鏈式then：在回調裡回傳新 Promise

Promise 真正的威力在於：.then() 的回調裡可以 return 一個新的 Promise，下一個 .then() 會等它落定再執行。於是，回呼地獄的三角形被拉平成一條向右延伸的鏈。

function get_A() {
    return new Promise(function (resolve, reject) {
        console.log("發送A請求")
        setTimeout(function () {
            let data_A = "AAA"
            resolve(data_A)
        }, 1000)
    })
}

function get_B() {
    return new Promise(function (resolve, reject) {
        console.log("發送B請求")
        setTimeout(function () {
            resolve()
        }, 2000)
    })
}

function get_C() {
    return new Promise(function (resolve, reject) {
        console.log("發送C請求")
        setTimeout(function () {
            resolve()
        }, 3000)
    })
}

let p = get_A()
p.then(function (res) {
    console.log("A請求結束")
    console.log("A請求響應數據為：", res)
    return get_B()
}).then(function (res) {
    console.log("B請求結束")
    return get_C()
}).then(function (res) {
    console.log("C請求結束")
})

注意三個關鍵：每個 get_X() 都 return new Promise；上一個 .then() 裡 return get_B()，下一個 .then() 就等 get_B() 的 Promise 落定；上一個 then 拿到的 res 是上一個 Promise resolve 出來的數據。

把回調風格 API 封裝成 Promise

老代碼常用 $.ajax 這種回調風格：成功走 success，失敗走 error。要把它們接入鏈式世界，只要用 new Promise 包一層就行。

function fetchData(url) {
    return new Promise(function (resolve, reject) {
        console.log("發送請求！");
        $.ajax({
            url: url,
            success: function (res) {
                resolve(res)
            }
        })
    });
}

封裝的規則是：成功時調用 resolve(res)，失敗時調用 reject(error)。封裝完的 fetchData(url) 就是一個返回 Promise 的函數，可以直接 .then()。

實戰：連續請求同一個 API

把 fetchData 用鏈式調用串起來，可以對同一個 API 連續發兩次請求，第一次取 res.now，第二次取 res.refer：

let url = "https://devapi.qweather.com/v7/weather/now?location=101070101&key=0718ad154da14f0a98ca49778f9bfd53"

fetchData(url).then(function (res) {
    console.log("響應數據:", res.now)
    return fetchData(url)
}).then(function (res){
    console.log("響應數據:", res.refer)
})

這就是現代加密網站裡最常見的代碼形態：接口 A 的返回值是接口 B 的輸入， Promise 鏈讓這種串行依賴變得清晰可追蹤。

小結

三步走完，你現在應該能：

  • 認出回呼地獄的嵌套結構，理解爲什麼它難以維護。
  • 用 Promise 的三狀態（pending / fulfilled / rejected）和 then 雙回調讀懂異步代碼。
  • 用鏈式 .then() 拉平串行流程，並把任意回調風格的 API 封裝成 Promise。

下一步的學習會進入 async / await 語法——它讓鏈式 Promise 看起來更像同步代碼，是逆向调试加密網站異步請求的終極武器。
