定时器与 window 全局变量

JS 逆向 · 节点 15 · 步骤 5/5

学习目标

能认出顶层 var/function 挂在 window 上、理解 setInterval/setTimeout 的行为与取消方式，定位网页中定时驱动的回调函数。

顶层 var/function 挂在 window 上

浏览器里有一个全局对象 window。在 <script> 顶层用 var 声明的变量和用 function 声明的函数，会自动成为 window 对象的属性：

var username = "alice";
function greet() { return "hi"; }

console.log(window.username); // alice
console.log(window.greet());  // hi

所以在浏览器控制台里直接打 window 就能看到所有全局状态——这是逆向时探测入口函数和全局配置的首选方式。注意：ES6 的 let/const 声明的变量不会挂到 window 上，只有 var 和函数声明会。

setTimeout：延迟执行一次

setTimeout(fn, ms) 让函数 fn 在 ms 毫秒后执行一次。它返回一个定时器 ID，供 clearTimeout 取消：

var id = setTimeout(function() {
  console.log("3 秒后打印");
}, 3000);

// 如果中途想取消：
clearTimeout(id);

逆向时如果发现某个操作"过一会儿才触发"，很可能就是 setTimeout 在驱动。找到定时器 ID 就能找到回调函数，找到回调函数就能找到核心逻辑。

setInterval：周期重复执行

setInterval(fn, ms) 每隔 ms 毫秒重复执行 fn。同样返回定时器 ID，用 clearInterval 取消：

var tick = 0;
var id = setInterval(function() {
  tick++;
  console.log("第 " + tick + " 秒");
}, 1000);

// 5 秒后停止
setTimeout(function() { clearInterval(id); }, 5000);

网页里周期性刷新 token、指纹更新、心跳包几乎都是 setInterval 驱动的。逆向时打开控制台，在 Sources 面板搜索 setInterval/setTimeout，往往能直接定位到关键的周期性任务。

定时器 + DOM：时钟显示案例

一个典型的综合案例：点击按钮后，用 setInterval 每秒刷新一次时间，并通过 DOM 操作写入输入框：

function show() {
  var now = new Date().toLocaleString();
  document.getElementsByTagName("input")[0].value = now;
}
// 点击开始按钮：
// <button onclick="start()">开始</button>
function start() {
  setInterval(show, 1000);
}

这段代码把定时器、Date 对象、DOM 查询、DOM 赋值串在一起，是网页动态行为的典型形态。读逆向目标时，看到 setInterval 配 document.get...value = ...，要意识到"这段代码正在周期性地往页面写数据"——它可能就是你要找的渲染逻辑或加密参数生成点。
