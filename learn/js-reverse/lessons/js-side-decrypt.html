JS 侧 AES 解密：crypto-js 与 createDecipheriv

实战：sign 逆向（JS 执行） · 步骤 4/5

学习目标

能写出 JS 版 AES-128-CBC 解密函数 decrypt_data，理解 crypto-js 的密钥/IV 派生与解密流程。

为什么 AES 解密也要搬到 JS？

上一节我们把 sign 生成搬到了 JS。但 sign 只是请求的一半——有道翻译的响应是 AES 加密的，我们同样需要解密。

PyCryptodome 虽然能实现 AES 解密，但响应里还涉及 base64 变体处理（- 替换成 +、_ 替换成 /）、去填充、密钥和 IV 的 MD5 派生。如果加密逻辑已经用 crypto-js 实现了解密，直接复用是最省力的做法。

crypto-js 简介

crypto-js 是一个纯 JS 加密库，浏览器和 node 都能用。它封装了常见的哈希和加密算法，API 比 node 的 crypto 更「高层」，直接提供 AES.encrypt/AES.decrypt 这样的方法。

在有道翻译的例子里，密钥和 IV 是通过两个 ydsecret://... 字符串派生的——这两个字符串的 MD5 值分别作为 AES 的 key 和 IV。

base64 变体处理

有道翻译的响应文本用的是 URL-safe base64：把标准 base64 里的 + 替换成 -、/ 替换成 _，并且省略了末尾的 = 填充。解密前必须替换回来：

function to_base64_urlsafe(s) {
    // 标准 base64 → URL-safe base64
    return s.replace(/\+/g, "-").replace(/\//g, "_");
}

function from_base64_urlsafe(s) {
    // URL-safe base64 → 标准 base64
    return s.replace(/-/g, "+").replace(/_/g, "/");
}

密钥和 IV 的派生

有道翻译的密钥和 IV 分别由两个固定字符串的 MD5 值决定：

  • key = MD5(ydsecret://query/key/B*RGygVywfNBwpmBaZg*WT7SIOUP2T0C9WHMZN39j^DAdaZhAnxvGcCY6VYFwnHl)
  • iv = MD5(ydsecret://query/iv/C@lZe2YzHtZ2CYgaXKSVfsb7Y4QWHjITPPZ0nQp87fBeJ!Iv6v^6fvi2WN@bYpJ4)

在 crypto-js 中，可以直接把 MD5 的结果转成 WordArray（二进制数据），直接当密钥和 IV 用：

const CryptoJS = require("crypto-js");

const key = CryptoJS.MD5("ydsecret://query/key/B*RGygVywfNBwpmBaZg*WT7SIOUP2T0C9WHMZN39j^DAdaZhAnxvGcCY6VYFwnHl");
const iv = CryptoJS.MD5("ydsecret://query/iv/C@lZe2YzHtZ2CYgaXKSVfsb7Y4QWHjITPPZ0nQp87fBeJ!Iv6v^6fvi2WN@bYpJ4");

JS 版 decrypt_data 函数

把上面的逻辑封装成一个解密函数，接收加密的响应文本，返回解密后的明文字符串：

const CryptoJS = require("crypto-js");

function decrypt_data(encryptedText) {
    // 1. 密钥和 IV 派生
    const key = CryptoJS.MD5("ydsecret://query/key/B*RGygVywfNBwpmBaZg*WT7SIOUP2T0C9WHMZN39j^DAdaZhAnxvGcCY6VYFwnHl");
    const iv = CryptoJS.MD5("ydsecret://query/iv/C@lZe2YzHtZ2CYgaXKSVfsb7Y4QWHjITPPZ0nQp87fBeJ!Iv6v^6fvi2WN@bYpJ4");

    // 2. URL-safe base64 转标准 base64
    const base64 = encryptedText.replace(/-/g, "+").replace(/_/g, "/");

    // 3. AES-128-CBC 解密
    const decrypted = CryptoJS.AES.decrypt(
        base64,
        key,
        {
            iv: iv,
            mode: CryptoJS.mode.CBC,
            padding: CryptoJS.pad.Pkcs7
        }
    );

    // 4. 转成 UTF-8 字符串
    return decrypted.toString(CryptoJS.enc.Utf8);
}

// 测试
console.log(decrypt_data("加密的响应文本"));

逐行解读

在 node 中验证

把上面的代码保存为 JS 文件，运行前需要先安装 crypto-js：

npm install crypto-js

然后调用：

node decrypt.js

如果输出解密后的明文（比如 {"translateResult":...}），说明 JS 侧解密逻辑跑通了。

小结

JS 版 AES 解密的核心是 CryptoJS.AES.decrypt(密文, key, {iv, mode, padding})。密钥和 IV 由两个固定字符串的 MD5 值派生，密文需要先做 URL-safe base64 替换。下一步，我们用 Python execjs 调用这个解密函数。
