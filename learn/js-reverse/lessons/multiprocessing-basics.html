multiprocessing 进程实战

js-reverse · 节点 05 · 步骤 3/5

学习目标

掌握 multiprocessing.Process 的完整用法：创建、启动、传参、join 等待、进程数据隔离与守护进程，能写出异步爬虫骨架。

Process 的基本用法

运行的 Python 文件是主进程，基于 Process 创建的是子进程。两进程即可实现异步。

from multiprocessing import Process

def worker(name):
    print(f"子进程 {name} 执行中")

if __name__ == '__main__':
    p = Process(target=worker, args=('A',))
    p.start()      # 启动子进程
    p.join()       # 等待子进程结束
    print("主进程结束")

用进程实现异步

假设三个任务各耗时 2 秒，同步串行总耗时约 6 秒。改成每任务一个子进程，三个进程并行执行，总耗时约 2 秒。

import time
from multiprocessing import Process

def task(name):
    print(f"{name} 开始")
    time.sleep(2)
    print(f"{name} 结束")

if __name__ == '__main__':
    processes = []
    for i in range(3):
        p = Process(target=task, args=(f"任务{i}",))
        processes.append(p)
        p.start()

    # 正确写法：先 start 所有子进程，再逐个 join
    for p in processes:
        p.join()

    print("全部完成")
错误写法：在循环内边 start() 边 join() —— 这样会变成串行，每个进程必须等前一个完成才启动下一个，失去了异步的意义。

进程数据隔离

进程间数据完全隔离，不共享。子进程中的全局变量是主进程变量的拷贝，修改不影响主进程。

from multiprocessing import Process

n = 100

def modify():
    global n
    n = 0

if __name__ == '__main__':
    p = Process(target=modify)
    p.start()
    p.join()
    print(n)  # 输出 100，不是 0

如果需要跨进程传值，需使用进程通信机制（管道、信号量等），但爬虫场景很少用到，了解即可。

守护进程

守护进程（daemon）随主进程代码结束而终止，且不能再开子进程。

p = Process(target=task)
p.daemon = True   # 必须在 start() 之前设置
p.start()
# 主进程代码结束，p 也随之终止
注意：守护进程内如果尝试再开启子进程，会抛出 AssertionError。
