Flask 演示伺服器

Node 13 · Step 2 / 4 · 預估 12–15 分鐘

Learning goal

用 Flask 在本機架設一個只有三個路由的最小伺服器，理解模板渲染、表單頁與 JSON 介面的差別，為後續 Ajax 練習提供可控的靶站。

Lesson

學 Ajax 需要一個可以反覆戳、又不會弄壞真實網站的靶站。我們在本機用 Flask 架一個最小伺服器，只有三個頁面：首頁、登入頁、一個回傳 JSON 的 /books 介面。所有後續的 Ajax 請求都會對準這台自己機器上的伺服器。

Flask 的最小骨架

Flask 是一個 Python 的輕量網頁框架。一個最小可動的 Flask 應用程式長這樣：

from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Hello"

if __name__ == "__main__":
    app.run(debug=True)

@app.route("/") 是裝飾器（decorator），它把後面的 index 函式和 URL 路徑 / 綁在一起。當瀏覽器對 http://127.0.0.1:5000/ 發請求，Flask 就會呼叫 index()，把回傳值放進回應裡。

我們的三個路由

靶站需要三個路由，分別對應三種常見的後端行為：

路由方法它做什麼回應類型
/indexGET渲染 index.html，注入目前時間HTML
/loginGET渲染 login.html（空表單頁）HTML
/booksGET隨機抽 4 本書，用 jsonify 回傳JSON

模板渲染：把變數塞進 HTML

/index 用 render_template("index.html", now=datetime.now()) 把目前時間注入模板。Flask 預設會去專案資料夾下的 templates/ 目錄找模板檔。模板裡可以寫 {{ now }}，Flask 在渲染時會把變數替換進去。

from flask import render_template
from datetime import datetime

@app.route("/index")
def index():
    return render_template("index.html", now=datetime.now())

這代表 /index 的回應是完整 HTML，瀏覽器收到後直接顯示。這是典型的「伺服器端渲染」—— 資料在伺服器端就放進 HTML 裡了。

JSON 介面：回傳資料而非畫面

/books 是 Ajax 要打的目標。它不回傳 HTML，而是回傳 JSON：

import random
from flask import jsonify

BOOKS = ["三體", "銀河帝國", "沙丘", "基地", "1984", "美麗新世界"]

@app.route("/books")
def books():
    selected = random.sample(BOOKS, 4)
    return jsonify(selected)

random.sample(BOOKS, 4) 從書單裡隨機抽 4 本不重複的書。jsonify(selected) 把 Python 列表轉成 JSON 陣列，並設定正確的 Content-Type: application/json 回應頭。

這個介面是純資料端點（data endpoint）。它不關心畫面，只負責回傳一個 JSON 陣列。瀏覽器直接打開 http://127.0.0.1:5000/books 會看到 ["三體","銀河帝國","沙丘","基地"]，但這不是給人類看的 —— 它是給 JavaScript 或 Python 爬蟲吃的。

表單頁：同步請求的對照組

/login 

@app.route("/login")
def login():
    return render_template("login.html")

login.html 裡有一個 <form action="/login" method="post">。如果使用者填了表單按提交，瀏覽器會發一個 POST 請求，整個頁面跳轉。這就是前面說過的「同步全覆盖」行為。

目錄結構

Flask 預設的目錄約定如下：

01 server/
├── myServer.py          # Flask 應用程式
├── templates/           # HTML 模板放這裡
│   ├── index.html
│   └── login.html
└── static/              # JS / CSS / 圖片放這裡
    └── index.js

templates/ 和 static/ 是 Flask 預設的資料夾名稱，不用在程式碼裡額外指定路徑。

為什麼要自己架靶站？

用自己架的伺服器有三個好處：

  • 完全可控：每次打 /books 都會拿到不同的書單，你可以反覆測試而不會把別人的網站打掛。
  • 延遲為零：請求在本地跑，DevTools 裡的 timing 乾乾淨淨，容易觀察。
  • 可以看後端原始碼：你知道 /books 怎麼實作的，所以你能完全理解請求和回應的對應關係。
