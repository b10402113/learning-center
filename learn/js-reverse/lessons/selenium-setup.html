Selenium 浏览器自动化

Step 1 — 环境搭建与浏览器创建

Learning Goal

能够独立搭建 Selenium 环境并创建 Chrome 浏览器实例，完成打开页面、定位元素、点击输入等基础自动化操作。

为什么需要 Selenium？

之前学的 requests 很强大，但它有个致命短板：它只拿到服务器返回的原始 HTML，不会执行页面上的 JavaScript。现代网站大量使用 Ajax 动态渲染——你看到的內容是浏览器执行 JS 之后才出现的，requests 拿到的 HTML 里根本没有这些数据。

Selenium 的思路完全不同：它不直接发 HTTP 请求，而是驱动一个真实的浏览器（Chrome、Firefox 等），让浏览器像人一样打开页面、执行 JS、渲染 DOM。你通过代码告诉浏览器「点这个按钮」「在那个输入框打字」，浏览器就照做。渲染完之后，你再让浏览器把当前页面的源代码交给你——这就是 page_source，里面包含了所有动态加载后的数据。

一句话：Selenium = 用代码遥控浏览器。凡是 requests 搞不定的动态页面、登录验证、点击翻页，都可以交给 Selenium。

环境安装

Selenium 的安装分两步，缺一不可：

  1. 安装 Python 包：pip install selenium
  2. 下载浏览器驱动：Chrome 需要 chromedriver，Firefox 需要 geckodriver

驱动是一个独立的可执行文件，Selenium 通过它来控制浏览器。驱动版本必须和你本机安装的浏览器版本严格匹配，否则会报错。下载地址：chromedriver.storage.googleapis.com。Windows 用户注意：系统是 64 位的，下载 win32 版本即可（没有 win64 版本）。

下载后把驱动放到一个固定路径，比如项目目录下的 ./chromedriver，或者把它加入系统 PATH，这样代码里就不用写路径了。

创建浏览器实例

环境就绪后，三行代码就能让浏览器弹起来：

from selenium import webdriver

# 创建 Chrome 浏览器实例
browser = webdriver.Chrome(executable_path='./chromedriver')

# 打开一个网页
browser.get('https://www.baidu.com')

Selenium 支持多种浏览器，创建方式类似：

浏览器创建方式
Chromewebdriver.Chrome()
Firefoxwebdriver.Firefox()
Edgewebdriver.Edge()
Safariwebdriver.Safari()
PhantomJS（无界面）webdriver.PhantomJS()

实际爬虫中几乎只用 Chrome，因为它市场份额最大、兼容性最好、DevTools 支持最完善。

第一个自动化脚本：百度搜索

让我们用一个完整的例子串起「打开页面 → 定位元素 → 交互 → 关闭浏览器」的闭环。目标：让浏览器自动打开百度，搜索「Python Selenium」，然后关闭。

from selenium import webdriver
from selenium.webdriver.common.by import By
import time

# 1. 创建浏览器
browser = webdriver.Chrome(executable_path='./chromedriver')

# 2. 打开百度
browser.get('https://www.baidu.com')

# 3. 定位搜索框（通过 ID）
search_box = browser.find_element(By.ID, 'kw')

# 4. 在搜索框输入文字
search_box.send_keys('Python Selenium')

# 5. 定位搜索按钮并点击
search_btn = browser.find_element(By.ID, 'su')
search_btn.click()

# 6. 等 3 秒让结果加载
time.sleep(3)

# 7. 关闭浏览器
browser.quit()

注意每步之间用 time.sleep() 留出页面加载时间，否则元素还没渲染完就去定位会报错。后面会学更智能的等待方式。

处理弹窗

有些页面会弹出 alert 警告框（比如「确定要离开吗？」），Selenium 的 API 无法直接点击弹窗上的按钮，必须切换到 alert 对象：

# 切换到 alert 弹窗
alert = browser.switch_to.alert

# 点击「确定」
alert.accept()

# 或者点击「取消」
alert.dismiss()

关键概念总结

  • Selenium：浏览器自动化工具，用代码驱动真实浏览器执行动作。
  • WebDriver：浏览器驱动，Selenium 通过它来控制浏览器。
  • page_source：浏览器当前渲染后的网页源码，是 Selenium 爬虫的核心产出。
  • find_element：定位页面元素的方法，是后续所有交互的前提。
  • browser.quit()：关闭浏览器，释放资源，脚本结束前必须调用。
