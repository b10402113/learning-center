RC4 算法：KSA 密钥编排与 PRGA 输出

从混淆代码中识别 RC4 的两段式结构

RC4 是什么？

RC4 是一种流密码（stream cipher），核心思想是：用密钥生成一个伪随机字节序列，再把明文的每个字节和序列里的对应字节做异或（XOR），得到密文。解密时做同样的异或操作就能还原明文。

RC4 的特点是加密和解密是同一个函数——因为异或运算的逆运算就是异或本身。这个特性让它非常适合在浏览器里做轻量级的响应体加密，也是逆向工程里最常见的算法之一。

RC4 的两段式结构

RC4 分两步：

  1. KSA（Key Scheduling Algorithm，密钥编排）：用密钥打乱一个 256 字节的置换盒（S-box）。
  2. PRGA（Pseudo-Random Generation Algorithm，伪随机生成）：用打乱后的 S-box 逐字节产生密钥流，和明文异或。

在混淆代码里，这两步通常写在一个循环里交替执行，但逻辑上是分开的。识别 RC4，就是认出这两段。

极简壁纸的 RC4 实现

扣下的代码里，RC4 被封装在 _0x476691 函数里。先看它的结构：

function _0x476691(_0x4eff8a) {
    let _0x5f0aa7 = [-0x6f, 0x34, 0x5b, ...];  // 256 字节密钥数组
    let _0x48065b = 0, _0x5274e8 = 0, _0x86b937 = 0;
    let _0x114065 = [];

    for (let _0x4aff5a = 0; _0x4aff5a < _0x4eff8a.length; _0x4aff5a++) {
        // KSA + PRGA 混合在这里
    }
    return _0x114065;
}

关键点：

  • _0x5f0aa7 是 256 字节的密钥数组，直接硬编码在代码里，逆向时可以直接复用。
  • 函数输入是字节数组（_0x4eff8a），输出也是字节数组。

拆解 KSA + PRGA 循环

循环内部的三行代码，把 KSA 和 PRGA 混在一起：

_0x48065b = (_0x48065b + 1) & 0xff;           // i 递增，取低 8 位
_0x5274e8 = (_0x5f0aa7[_0x48065b] + _0x5274e8) & 0xff;  // j 递增

// 交换 S[i] 和 S[j]
const _0x3c8821 = _0x5f0aa7[_0x48065b];
_0x5f0aa7[_0x48065b] = _0x5f0aa7[_0x5274e8];
_0x5f0aa7[_0x5274e8] = _0x3c8821;

// 计算密钥流字节并异或
_0x86b937 = (_0x5f0aa7[_0x48065b] + _0x5f0aa7[_0x5274e8]) & 0xff;
_0x114065.push(_0x4eff8a[_0x4aff5a] ^ _0x5f0aa7[_0x86b937]);

逐行解读：

  • i = (i + 1) & 0xff：KSA 的索引 i 每次加 1，& 0xff 保证在 0-255 范围内。
  • j = (S[i] + j) & 0xff：KSA 的索引 j 加上 S[i]，取低 8 位。
  • 交换 S[i] 和 S[j]：打乱置换盒。
  • k = S[(S[i] + S[j]) & 0xff]：PRGA 用当前 S-box 计算密钥流字节。
  • 明文[i] ^ k：异或得到密文字节，推进结果数组。

这就是 RC4 的核心循环。把它从混淆代码里抠出来，就能在 Python 里复现。

怎么认出 RC4？

在混淆代码里认 RC4，看三个特征：

  1. 256 字节数组：代码里有一行超长的整数数组，长度正好是 256。
  2. & 0xff：循环里反复出现 & 0xff 或 % 256，保证索引在 0-255 范围内。
  3. 交换 + 异或：循环里有两次数组元素交换，接着用一个索引计算出的值做异或。

只要同时看到这三样，基本就是 RC4。极简壁纸的代码把变量名混淆成了 _0x5f0aa7、_0x48065b，但结构没变。

密钥数组的复用

RC4 的密钥数组是硬编码在代码里的，意味着加密和解密用同一套密钥。逆向时直接把这 256 个数字抄下来，在 Python 里定义成同样的数组，就能复现算法。

注意负数：代码里出现了 -0x6f、-0x41 这样的负数。在 JavaScript 里这是 32 位有符号整数，但实际参与 & 0xff 运算后会转成无符号字节。抄写时要保留原样，Python 里会自动处理。
