# 百度翻译 POST 表单请求闭环

## Learning goal

能独立拼出百度翻译 v2transapi 的 POST 表单（query/sign/token/ts），让 sign 随 query 动态变化，跑通从输入单词到拿到翻译结果的闭环。

## Lesson

能独立拼出百度翻译 `v2transapi` 的 POST 表单（from/to/query/transtype/simple_means_flag/sign/token/domain/ts），让 sign 随 query 动态变化、ts 用实时毫秒时间戳、token 短期固定，跑通「输入单词 → `execjs.call('get_sign', wd)` → `requests.post`」的翻译闭环，并知道 `Acs-Token` 请求头过期是 sign 算对仍被拦截的常见原因。
