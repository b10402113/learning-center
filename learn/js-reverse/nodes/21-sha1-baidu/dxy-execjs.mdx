# execjs 调用 SHA1 与 GET 请求闭环

## Learning goal

能把扣下的 SHA1 JS 模块通过 execjs 挂到 Python 调用链上，拼出完整的丁香网 GET 请求，跑通从参数构造到拿到 JSON 响应的闭环。

## Lesson

能把扣下的 SHA1 JS 模块通过 `execjs.compile(...).call("u", data)` 挂到 Python 调用链上，串起「构造参数 → 字典序拼接 → execjs 算 sign → 拼进 params → `requests.get`」的丁香网 GET 请求闭环，并理解为什么 JS 对输入做了 `unescape(encodeURIComponent(e))` 预处理时，直接调 Python `hashlib` 会因为编码差异算出不同结果。
