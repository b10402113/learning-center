# 丁香网参数构造与字典序拼接

## Learning goal

能独立构造丁香网病例搜索接口的 noncestr、timestamp、serverTimestamp 和明文串，理解参数按字典序排列后再喂给 SHA1 的拼接规则。

## Lesson

能独立构造丁香网病例搜索接口的 noncestr（8 位左补零随机数字）、timestamp（毫秒时间戳）与 serverTimestamp（timestamp − 2），并按字典序把所有参数（appSignKey、keyword、noncestr、pageNum、pageSize、sectionCode、serverTimestamp、timestamp）拼成 SHA1 的输入明文串，理解 `appSignKey` 是硬编码的盐、顺序搞错或 noncestr 没补零都会导致 sign 算不对。
