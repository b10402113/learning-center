# 百度翻译 get_sign 算法与 gtk 补环境

## Learning goal

能看懂百度翻译 get_sign 里 gtk 拆段、字符转码、魔数字符串驱动位运算的逻辑，并说出为什么 Node 里要先写 `window = global; window.gtk = ...` 才能跑通。

## Lesson

能看懂百度翻译 `get_sign` 里 gtk 拆段（`f = 320305`、`m = 131321201`）、字符转码、魔数字符串（`+-a^+6` 和 `+-3^+b+-f`）驱动 `n()` 函数做移位/异或/加法的混淆逻辑，并说出为什么 Node 里要先写 `window = global; window.gtk = '320305.131321201'` 补环境——因为 gtk 挂在 `window.gtk` 上，浏览器里天然存在，Node 里不补就会报 `ReferenceError`。
