# SHA1 算法特征识别

## Learning goal

能从一个手写的加密函数里识别出 SHA1 的五个魔数、80 轮循环和 hex 输出特征，知道它为什么不是"自定义加密"而是标准摘要算法。

## Lesson

能从手写的加密函数里识别出 SHA1 的五个魔数（1732584193、-271733879、-1732584194、271733878、-1009589776）、80 轮循环和 40 位 hex 输出特征，认出它是标准 SHA1 而非自定义加密，并知道扣下的 Webpack 模块加载器（`n(e,t)`）包裹的代码可以整体搬运到 Node.js 里直接跑。
