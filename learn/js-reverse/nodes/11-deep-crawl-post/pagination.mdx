<LearningGoal>
能用 URL 模板 + 页码递增的方式，让 scrapy 自动翻页爬取全站列表数据。
</LearningGoal>

## Lesson

翻页爬取的核心是解析完当前页后构造下一页 URL 并 `yield scrapy.Request` 自我回调；可用 URL 模板 + 页码递增，也可解析页面上的"下一页"链接，三者配合固定页数、空页检测等终止条件即可覆盖绝大多数列表翻页场景。
