<LearningGoal>
能用 meta 字典把列表页的 item 传给详情页回调，实现"翻页 + 进详情页"的深度爬取。
</LearningGoal>

## Lesson

当数据不在同一张页面时，用 `meta={'item': item}` 把列表页的 item 传给详情页回调，在详情页通过 `response.meta['item']` 取出并补全字段后再 yield，实现"翻页 + 进详情页"的深度爬取。
