<LearningGoal>
理解 scrapy 五大核心组件的职责分工与请求/响应的数据流，并掌握两条最低成本的性能调优配置。
</LearningGoal>

## Lesson

scrapy 由引擎、调度器、下载器、爬虫、管道五大组件协作驱动请求与响应的流转，默认并发 32 个请求；面对爬取慢的问题，可优先调大 `CONCURRENT_REQUESTS` 与降低 `LOG_LEVEL` 两条最低成本的配置。
