# 编码与加密特征

## Learning goal

认识网络传输与前端代码里最常见的四种编码/加密形态：base64、摘要算法（md5/sha1/sha256）、AES 对称加密、RSA 非对称加密；能在抓到一段陌生密文时，从字符集、长度、填充符等外观特征快速判断它属于哪一类，并知道在 Python 里用哪个库、按什么顺序把它解开。

## Steps

1. [[learn/js-reverse/nodes/16-encoding-crypto/base64-basics|base64 编码与解码]] — 从 3 字节到 4 字符的重编码原理，掌握标准编解码与末尾 `=` 填充的坑
2. [[learn/js-reverse/nodes/16-encoding-crypto/base64-variants|base64 变种与图片]] — URL 安全变种的字符替换规则，以及 `data:image/png;base64` 内嵌图片的拆解（after step 1）
3. [[learn/js-reverse/nodes/16-encoding-crypto/digest-algorithms|摘要算法家族]] — md5/sha1/sha256 的单向散列、定长输出、加盐拼接在口令与一致性校验中的用法
4. [[learn/js-reverse/nodes/16-encoding-crypto/aes-symmetric|AES 对称加密实战]] — CBC 模式、16 字节 key/iv、PKCS7 填充，以及 base64 加解密的完整闭环
5. [[learn/js-reverse/nodes/16-encoding-crypto/rsa-asymmetric|RSA 非对称加密]] — 公私钥分工、PEM 存储、PKCS1_v1_5 填充，以及 CryptoJS/Python 互解（after step 3）

## Lesson

爬虫进入 JavaScript 阶段后，迎面遇到的第一道坎往往不是语法，而是请求参数里那一串看不懂的字符：它可能是一眼能看出规律的 base64，也可能是加了盐的 md5，或者是被 AES、RSA 层层包裹的密文。这一节不是密码学导论，而是一张"特征识别地图"——帮助你在抓包里快速判断一段密文属于哪种算法，并按正确顺序把它解开。

前两个步骤围绕 base64 展开：它是"编码"而非"加密"，只是把字节重排成可见字符，但逆向时最常见的坑就是变种字符替换和末尾填充符的丢失。第三个步骤进入摘要算法（hash）：md5、sha1、sha256 都是单向散列，不可逆，但可以通过"盐 + 数据"的拼接复现，是登录口令与 sign 参数的常客。第四个步骤是 AES 对称加密：key 和 iv 必须都是 16 字节，明文要填充到 16 的倍数，密文通常再做 base64 编码传输——这是前端 CryptoJS 最典型的套路。第五个步骤是 RSA 非对称加密：公钥加密私钥解密，密钥以 PEM 文件形态出现，与 AES 的"同一把钥匙"形成对比。每个步骤都按"现象 → 特征识别 → Python 复现"的节奏走，确保你在遇到真实案例时能直接动手。
