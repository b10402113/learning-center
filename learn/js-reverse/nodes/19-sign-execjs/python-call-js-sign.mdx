# execjs 编译与调用：Python 调 JS 拿 sign

## Learning goal

能用 execjs.compile 加载 JS 文件并调用 get_sign 函数，完成有道翻译 sign 请求。

## Lesson

execjs 的调用链是 compile 编译 JS → call 按函数名传参调用 → 拿返回值（JS 数组自动转 Python 列表），sign 逻辑留在 JS 里，Python 只负责拿结果发 requests 请求。
