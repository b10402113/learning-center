# execjs 混合路线：什么时候该用 Python 调 JS？

## Learning goal

能说明 Python 原生复现与 execjs 混合路线各自的适用边界，以及在什么条件下应该选 execjs。

## Lesson

execjs 混合路线把加密/解密逻辑留在 JS 里，由 Python 负责发请求和处理响应；当加密依赖浏览器对象、已用 crypto-js 实现、或被严重混淆时，execjs 比纯 Python 复现更省力。
