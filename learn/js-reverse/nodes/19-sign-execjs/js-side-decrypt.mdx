# JS 侧 AES 解密：crypto-js 与 createDecipheriv

## Learning goal

能写出 JS 版 AES-128-CBC 解密函数 decrypt_data，理解 crypto-js 的密钥/IV 派生与解密流程。

## Lesson

JS 版 AES-128-CBC 解密用 `CryptoJS.AES.decrypt(密文, key, {iv, mode: CBC, padding: Pkcs7})`，密钥和 IV 由两个固定字符串的 MD5 值派生，密文需先做 URL-safe base64 替换（`-` → `+`、`_` → `/`）。
