# JS 侧 sign 生成：crypto 模块与 createHash

## Learning goal

能写出 JS 版 get_sign 函数，理解 crypto.createHash("md5") 的调用链与返回值。

## Lesson

JS 版 get_sign 用 `crypto.createHash("md5").update(字符串).digest("hex")` 生成 sign，时间戳用 `Date.now()`，字符串拼接用模板字符串 `` `${变量}` ``，对应 Python 的 hashlib.md5().hexdigest() 和 f-string。
