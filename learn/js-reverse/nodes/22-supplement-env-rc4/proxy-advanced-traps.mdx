# Proxy 进阶捕获器：属性描述符与调用/构造拦截

## Learning goal

掌握 Proxy 的 getOwnPropertyDescriptor / defineProperty / apply / construct 四个进阶捕获器，能监控走属性描述符 API 的属性读写，以及函数调用与 new 构造。

## Lesson

网站可以绕开 get/set 读写属性（属性描述符 API）、直接调用函数或 new 构造对象，Proxy 用 getOwnPropertyDescriptor / defineProperty / apply / construct 四个进阶捕获器把这三类操作也纳入监控，trap 内一律用同名 Reflect 方法转发原操作。
