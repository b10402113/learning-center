能根据场景在「终端指令式」与「管道式」之间做选型判断，并写出把爬取结果落盘到 .csv 的完整流程。
</LearningGoal>

## Lesson

持久化存储有终端指令式（`scrapy crawl 爬虫名 -o 文件.csv`，简单但只能存文本文件）与管道式（items.py 定义字段 → Spider yield item → pipelines.py 的 process_item 接收并存储 → settings.py 开启 ITEM_PIPELINES，可存文件也可存数据库）两条路线；管道式 process_item 必须 return item 才能把数据传给下一个管道。
