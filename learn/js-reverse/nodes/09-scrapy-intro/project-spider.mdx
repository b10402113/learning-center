<LearningGoal>
能独立用 startproject 和 genspider 搭建 Scrapy 工程，并写出一个包含 name、start_urls、parse 三要素的 Spider。
</LearningGoal>

## Lesson

用 `scrapy startproject` 建项目、`scrapy genspider` 建爬虫文件；Spider 三要素是 name（唯一标识）、start_urls（起始 URL 列表，默认都被 GET 请求）、parse（专门解析响应的方法）；settings.py 需改 ROBOTSTXT_OBEY=False、LOG_LEVEL='ERROR'、USER_AGENT 三项配置。
