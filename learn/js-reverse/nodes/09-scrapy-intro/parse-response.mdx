<LearningGoal>
掌握 response.xpath 返回 Selector 对象的机制，区分 extract 与 extract_first 的取舍，并能用 scrapy crawl 运行爬虫、读懂终端日志。
</LearningGoal>

## Lesson

response.xpath 返回的是 Selector 对象列表，需 extract() 取全部匹配结果或 extract_first() 取第一个；Element 选项卡是渲染后效果，Network 才是请求对应的原始响应，写 xpath 应以原始响应为准；运行命令是 `scrapy crawl 爬虫名`，终端日志可观察请求状态码与统计摘要。
