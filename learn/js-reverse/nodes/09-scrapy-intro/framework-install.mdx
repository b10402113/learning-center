## Lesson

框架是集成各种通用功能的项目半成品；Scrapy 是为爬取网站数据、提取结构性数据而生的应用框架，学习重点是各功能用法而非源码，安装只需 `pip install scrapy`，终端能识别 scrapy 指令即成功。
