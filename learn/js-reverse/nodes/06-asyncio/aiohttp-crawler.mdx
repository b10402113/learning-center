# aiohttp 与多任务异步爬虫实战

## Learning goal

能独立写出基于 aiohttp + asyncio 的多任务异步爬虫，理解为什么 requests/time 必须换成 aiohttp/asyncio.sleep。

## Lesson

aiohttp 是支持异步的网络请求库，用法与 requests 相似但所有方法都是 async 的。多任务异步爬虫的标准写法是：ClientSession + session.get + asyncio.wait(tasks) + 回调解析。三个 2 秒的请求并发后总耗时约 2 秒，requests/time 必须换成 aiohttp/asyncio.sleep 才能保持异步效果。
