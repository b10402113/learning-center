# 同步、异步与并行、并发

## Learning goal

能分辨同步/异步、并行/并发两组概念，并说出为什么 IO 密集型爬虫任务适合用异步来加速。

## Lesson

同步是等完再做，异步是不等先做别的；并行是真的同时跑，并发是看起来同时跑。爬虫是 IO 密集型任务，异步能让 CPU 在等待网络响应时不空转，从而提升执行效率。
