# 协程原理：用户空间调度

## Learning goal

能说出协程与线程/进程的本质区别（用户空间调度 vs 操作系统调度），并解释协程为什么轻量、为什么可控。

## Lesson

协程把调度权从操作系统交回程序员：遇到阻塞时主动挂起，让 CPU 去做别的事，数据回来了再恢复。这让协程既轻量（创建销毁开销小）又可控（调度逻辑可自定义），是 IO 密集型任务里最高效的异步手段。
