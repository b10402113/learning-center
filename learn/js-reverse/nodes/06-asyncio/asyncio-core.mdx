# asyncio 四个核心概念与 wait/await

## Learning goal

能独立写出「特殊函数 + 任务列表 + wait + 回调解析」的 asyncio 多任务协程代码，并解释每个核心概念的角色。

## Lesson

asyncio 用四个层层递进的概念把协程用起来：async def 定义特殊函数 → 调用得到协程对象 → ensure_future 包装成任务对象（可绑定回调）→ 放进事件循环启动。多任务用 asyncio.wait(tasks) 赋予可挂起权限，await 加在每个阻塞操作前主动检测并挂起。
