# JS 变数、型别与控制流

## Learning goal

var/let/const、资料型别、分支、回圈、字串、阵列

## Steps

1. [[learn/js-reverse/nodes/14-js-variables-control/variables|變數宣告：var、let、const]] — 能辨識 var/let/const 三種宣告方式與 undefined 預設值
2. [[learn/js-reverse/nodes/14-js-variables-control/operators|運算符：==、===、短路與三目]] — 能分辨 == 與 === 的隱式轉換差異，並手工求值綜合表達式（after step 1）
3. [[learn/js-reverse/nodes/14-js-variables-control/control-flow|分支與迴圈：if、switch、while、for]] — 能讀懂三種分支結構與迴圈三要素（after step 2）
4. [[learn/js-reverse/nodes/14-js-variables-control/arrays-strings|字串與陣列：slice、split、splice 與遍歷]] — 能操作陣列與字串的常用方法，並分辨三種遍歷的差異（after step 3）

## Lesson

這一節把 JS 最基礎的積木補齊：變數宣告、運算符、分支、迴圈、字串與陣列。對逆向爬蟲來說，這些是讀懂任何 JS 加密邏輯的入場券——sign 演算法再怎麼混淆，最終還是會落回這些基本結構。

四步走下來，你會先掌握 var/let/const 的差異與 undefined 陷阱；接著搞懂 == 與 === 的隱式轉換、短路運算與三目運算子的優先順序，這些是混淆代碼裡最愛埋雷的地方；然後用分支和迴圈看懂程式流程；最後用字串與陣列的操作還原資料處理邏輯。這些基礎打穩了，後面碰到的閉包、原型鏈、Promise 才有地方落脚。
