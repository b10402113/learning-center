# 分布式与增量式爬虫

## Learning goal

理解原生 Scrapy 无法分布式的根因，掌握用 scrapy-redis 改造 CrawlSpider 为分布式版本的完整流程，并能用 redis set 实现只爬新增数据的增量式爬虫。

## Lesson

原生 Scrapy 無法分散式，因為多台電腦無法共享調度器和管道，scrapy-redis 提供可共享的調度器和管道，改造流程包括父類改 RedisCrawlSpider、start_urls 換成 redis_key、settings 指定共享管道/調度器/去重/Redis 連線、修改 Redis 設定解除本機綁定、lpush 起始 URL 啟動爬取；增量式爬蟲用 Redis set 做去重記錄表，sadd 回傳 1 表示有更新才發請求，實現只爬新增資料。
