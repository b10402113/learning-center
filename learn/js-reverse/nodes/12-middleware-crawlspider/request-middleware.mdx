# 代理、UA 与 Cookie 中间件

## Learning goal

掌握代理中间件、UA 中间件和 Cookie 中间件的实现方式，理解全局代理的效率弊端，并能用 spider 参数打通爬虫文件与中间件的数据交互。

## Lesson

三類請求中介物都在 process_request 裡改寫請求：代理中介物用 request.meta['proxy'] 掛代理、UA 中介物用 request.headers['User-Agent'] 隨機換 UA、Cookie 中介物用 request.cookies 或 request.headers['cookie'] 帶登入狀態，spider 參數讓爬蟲檔案定義資料源、中介物取用，實現配置與行為的解耦。
