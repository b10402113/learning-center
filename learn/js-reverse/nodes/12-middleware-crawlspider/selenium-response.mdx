# 中间件结合 Selenium 篡改响应

## Learning goal

掌握在 process_response 中用 Selenium 渲染动态页面并替换原响应的完整方案，理解"Scrapy 调度 + Selenium 渲染"混合架构的适用场景。

## Lesson

當 Scrapy 拿到的回應是動態載入的空殼時，可以在 process_response 中用 Selenium 渲染頁面、用新的 HtmlResponse 替換原回應；瀏覽器物件作為爬蟲類屬性只啟動一次，中介件透過 spider.bro 取用，這種「Scrapy 調度 + Selenium 渲染」的混合架構是應對動態載入站點的主力方案。
