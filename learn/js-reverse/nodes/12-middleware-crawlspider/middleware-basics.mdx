# 下载中间件核心概念

## Learning goal

理解 Scrapy 下载中间件在框架中的位置、三个核心方法的作用，以及 spider 参数如何实现爬虫类与中间件的数据交互。

## Lesson

下載中間件位於引擎與下載器之間，是 Scrapy 的全局請求／回應攔截點；三個核心方法各司其職：process_request 改寫請求、process_response 替換回應、process_exception 處理例外，spider 參數則讓爬蟲檔案與中間件共享資料。
