# CrawlSpider 全站爬取

## Learning goal

掌握 CrawlSpider 的 rules、LinkExtractor 与 Rule 配合方式，能自动翻页爬取全站数据，并掌握"列表页 meta 传 item + 详情页补全"的深度爬取通用套路。

## Lesson

CrawlSpider 用 LinkExtractor 按正則或 XPath 提取連結，用 Rule 對每個連結發請求並解析，從而自動翻頁爬全站；配合 meta={'item':item} 手動發請求，可以完成「列表頁提取摘要 → 詳情頁補全內容」的深度爬取。
