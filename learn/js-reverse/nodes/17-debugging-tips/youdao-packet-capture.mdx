<LearningGoal>
能用 requests 复刻有道翻译的完整 POST 请求，并识别出请求体中不可复用的动态参数 sign 与 mysticTime。
</LearningGoal>

## Lesson

用 Python requests 复刻有道翻译的完整 POST 请求，验证硬编码抓包值在第二次请求时失效，从而识别出 sign 和 mysticTime 这两个不可复用的动态参数。这是从「能抓包」到「发现需要逆向」的临界点，为后续 sign 逆向埋下伏笔。
