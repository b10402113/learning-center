<LearningGoal>
能列出加密值在 HTTP 请求中最可能出现的三种位置，并在抓到请求后优先检查这三个地方。
</LearningGoal>

## Lesson

加密值在 HTTP 请求中只有三种可能的位置——查询参数与 form 数据、请求头、Cookie——抓到请求后按这个顺序逐一检查即可快速锁定目标字段。
