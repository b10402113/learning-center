<LearningGoal>
能列出加密值在 HTTP 请求中最可能出现的三种位置，并在抓到请求后优先检查这三个地方。
</LearningGoal>

## Lesson

加密值在 HTTP 请求中的位置只有三种可能：查询参数与 form 数据里、请求头里、或者 Cookie 里。抓到请求后，按这个顺序逐一检查，能快速锁定目标字段。判断一个字段是否加密，可以看长度是否固定、字符集是否局限于十六进制或 Base64，以及每次请求的值是否变化。
