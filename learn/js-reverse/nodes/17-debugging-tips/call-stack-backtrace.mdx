<LearningGoal>
能从请求发送入口逐层向上回溯呼叫堆栈，定位加密函数在代码中的真实位置。
</LearningGoal>

## Lesson

从请求发送入口（如 XMLHttpRequest.send 或 fetch）的断点出发，利用 Chrome DevTools 的 Call Stack 面板逐层向上回溯函数调用链，直到找到真正执行加密的那一段代码。
