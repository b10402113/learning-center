能在呼叫堆栈过深或代码被混淆时，用关键字搜索作为备选入口定位加密参数。
</LearningGoal>

## Lesson

当调用栈过深或代码被混淆时，关键字搜索是 Call Stack 之外的第二把钥匙。通过参数名、URL 路径、或者 md5/sha1/encrypt/JSON.stringify 等敏感词，可以在压缩混淆的代码里直接定位加密逻辑的位置。Global Search 返回的结果优先关注 .js 文件中的赋值语句。
