# 深度爬取与 POST 请求

## Learning goal

翻页、meta 跨页传参、FormRequest 发送 POST

## Steps

1. [[learn/js-reverse/nodes/11-deep-crawl-post/core-components|scrapy 五大核心组件与数据流]] — 理解 scrapy 五大核心组件的职责分工与请求/响应的数据流，并掌握两条最低成本的性能调优配置
2. [[learn/js-reverse/nodes/11-deep-crawl-post/pagination|多页翻页爬取]] — 能用 URL 模板 + 页码递增的方式，让 scrapy 自动翻页爬取全站列表数据（after step 1）
3. [[learn/js-reverse/nodes/11-deep-crawl-post/meta-passing|meta 跨页传参]] — 能用 meta 字典把列表页的 item 传给详情页回调，实现"翻页 + 进详情页"的深度爬取（after step 2）
4. [[learn/js-reverse/nodes/11-deep-crawl-post/formrequest-post|FormRequest 发送 POST 请求]] — 能解释 scrapy 起始请求的内部机制，并为任何 POST 接口写出 FormRequest 版爬虫（after step 1）

## Lesson

这节课把 scrapy 从"单页爬虫"升级到"全站深度爬虫"。先搞清楚 scrapy 五大核心组件怎么协作、请求和响应在引擎、调度器、下载器、爬虫、管道之间怎么流动——这是后面所有进阶操作的地基。然后学会两套最常用的进阶手法：用 URL 模板 + 页码递增实现多页翻页，用 meta 字典把列表页的 item 传给详情页回调，把分散在多页的数据拼进同一个 item。最后学会 scrapy 里发 POST 请求的正确姿势——重写 `start_requests` 换用 `FormRequest`，这是对接后续逆向出的 POST 参数的关键。
