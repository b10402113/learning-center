<LearningGoal>
理解 md5、sha1、sha256 都是单向散列函数：不可逆、同输入同输出、输出定长；能从十六进制长度识别算法，并在 Python 里用 hashlib 复现"盐 + 数据"的加盐摘要。
</LearningGoal>

## Lesson

md5、sha1、sha256 都是單向雜湊函數，輸出長度固定（分別為 32、40、64 個十六進位字元），可從長度反推演算法；Python 的 <code>hashlib</code> 用多次 <code>update()</code> 實現「鹽 + 資料」的拼接摘要，是復現前端 sign 參數與登入口令雜湊的關鍵。
