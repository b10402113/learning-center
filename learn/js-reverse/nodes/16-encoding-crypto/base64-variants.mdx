<LearningGoal>
识别 URL 安全型 base64 的字符替换规则（`-` 替 `+`、`_` 替 `/`），能把网页里 `data:image/png;base64` 内嵌图片还原成可查看的图片文件，并处理密文里混入空格或缺失填充符的脏数据。
</LearningGoal>

## Lesson

URL 安全型 base64 把標準字元 <code>+</code> 和 <code>/</code> 替換成 <code>-</code> 和 <code>_</code> 以避開 URL 保留字元，解碼前必須先還原；網頁內嵌圖片使用 <code>data:image/...;base64,&lt;資料&gt;</code> 格式，用逗號切開取後半段做 base64 解碼後以 <code>"wb"</code> 二進位模式寫檔；逆向抓到的髒資料處理順序為去空白、還原變種、補 <code>=</code> 填充、最後解碼。
