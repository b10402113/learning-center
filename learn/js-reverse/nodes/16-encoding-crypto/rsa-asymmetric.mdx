<LearningGoal>
理解 RSA 公私钥分工——公钥加密私钥解密用于数据传输，反向用于数字签名；能从 PEM 文件识别密钥，在 Python 里用 PKCS1_v1_5 完成加解密，并认识前端 CryptoJS 的 RSA 调用形态。
</LearningGoal>

## Lesson

RSA 非對稱加密使用公鑰加密、私鑰解密，金鑰以 PEM 格式（<code>-----BEGIN PUBLIC KEY-----</code>）儲存；Python 用 pycryptodome 的 <code>PKCS1_v1_5</code> 完成加解密，前端用 JSEncrypt 或 CryptoJS 呼叫，兩者可互通；RSA 有長度限制，長訊息通常採用「AES 加密資料 + RSA 加密 AES 金鑰」的混合加密架構。
