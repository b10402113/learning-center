## Lesson

这一节把「爬虫工具箱」里最基础的两把扳手交给你：requests 负责把网页搬回来，xpath 负责从网页里把想要的东西抠出来。

requests 是 Python 里最主流的 HTTP 库，它的 API 设计得像在浏览器地址栏输入网址一样直觉——`requests.get(url)` 就是发一个 GET 请求，`requests.post(url, data=...)` 就是提交表单。学会它，你就掌握了「让程序代替浏览器上网」的能力。

xpath 则是一种在 HTML/XML 文档里定位节点的查询语言。你可以把它想像成档案柜的路径指示：`/html/head/title` 是绝对路径，`//div[@class="song"]` 是「不管在哪裡，只要 class 是 song 的 div」。学会它，你就能从一整页密密麻麻的 HTML 源码里，精准地抽出标题、链接、图片地址，而不需要在一堆字符串里盲目搜索。

这两样工具组合起来，就是最经典的聚焦爬虫链路：用 requests 拿到页面源码 → 用 etree 加载成可查询的文档对象 → 用 xpath 表达式定位目标节点 → 提取文本或属性值 → 持久化存储。后面所有更复杂的爬虫技巧——登入、加密、异步、分布式——都是在这个链条上叠加而成的。
