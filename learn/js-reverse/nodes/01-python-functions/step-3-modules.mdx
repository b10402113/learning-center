</LearningGoal>

## Lesson

代码越写越多，全塞一个文件里就难以维护。把相关功能拆到不同的 `.py` 文件里，每个文件就是一个模组。模组能避免函数名/变量名冲突——同名函数可以分别存在不同模组里，用模组名前缀区分。

模组分三种来源：内建模组是 Python 自带的（`time`、`json`、`re`）；第三方模组是别人写的、用 pip 安装的（`requests`、`execjs`）；自定义模组是你自己写的 `.py` 文件。

### 导入即执行

用 `import` 导入一个模组时，Python 会执行该模组里的顶层代码（不在函数里的代码）。多次导入同一个模组，顶层代码只执行一次。

```python
# logger.py
print("logger 模组被加载了")

def log(msg):
    print(f"[LOG] {msg}")
```

```python
# main.py
import logger      # 输出：logger 模组被加载了
import logger      # 第二次导入，不会再次输出
logger.log("hello") # [LOG] hello
```

所以导入一个模组时看到「打印东西」，不是 bug，是顶层代码被执行了。

### 各种 import 写法

读别人项目时，你会看到三种常见 import 写法。`import 模组名` 导入整个模组，用 `模组名.函数名` 调用；`import 模组名 as 别名` 给长名缩写；`from 模组名 import 成员` 只导入指定函数，直接用函数名调用。不推荐 `from 模组名 import *`，会污染命名空间。

```python
import json
data = json.loads('{"a": 1}')

import requests as req
resp = req.get("https://example.com")

from os.path import exists, join
print(exists("/tmp"))
```

### __name__ 与入口惯例

每个模组内部都有一个内置变量 `__name__`。当模组被直接执行（作为入口文件）时，`__name__` 的值是 `"__main__"`；当模组被导入时，`__name__` 的值是模组文件名。

```python
# tool.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    print("测试 add:", add(1, 2))
```

这个 `if __name__ == "__main__"` 是 Python 脚本的标准入口惯例。它让同一个文件既能被别的模组导入（不跑测试代码），也能直接执行（跑测试或主逻辑）。

### 包：带 __init__ 的文件夹

当模组越来越多，用文件夹把相关模组组织起来，就形成了包。确切地说，包是一个包含 `__init__.py` 文件的文件夹。`__init__.py` 本身可以为空，也可以放包级别的初始化代码。

```python
m_log/
    __init__.py
    logger.py
    formatter.py
```

导入包里的模组有三种写法：`import m_log.logger`、`from m_log import logger`、`from m_log.logger import log`。读第三方库时，看到 `from xxx.yyy import zzz`，要知道 `xxx` 是包，`yyy` 是里面的模组，`zzz` 是具体函数或类。
