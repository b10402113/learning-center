<LearningGoal>
能正确定义函数、调用函数，并理解返回值与参数传递的规则。
</LearningGoal>

## Lesson

把一段会重复使用的代码打包成一个带名字的「工具」，以后只要喊名字就能用，这就是函数。Python 里用 `def` 关键字定义函数，定义之后不会立刻执行，只有被「调用」时才会跑。

```python
def greet(name):
    return f"你好，{name}！"

msg = greet("Andy")
print(msg)   # 你好，Andy！
```

定义函数只是把工具做好放在桌上；调用函数才是真正把工具拿起来用。调用时必须写函数名后面跟圆括号，括号里按定义时的要求把参数塞进去。

### 返回值：return 做了什么

函数执行完后，可以用 `return` 把结果「扔」回给调用的人。几个容易踩的点：

- 不写 `return`，函数默认返回 `None`——不是空字符串，不是 0，就是代表「没有」的 `None`。
- 写 `return a, b`，Python 会把多个值打包成一个元组（tuple）。用单个变量接收时，拿到的是整个元组。
- 函数执行到 `return` 就结束了，后面的代码不会跑。

```python
def calc(a, b):
    return a + b, a - b

result = calc(10, 3)
print(result)       # (13, 7)
```

还有一种容易看走眼的写法：`return inner` 和 `return inner()` 完全不同。前者把函数本身扔回去（你可以接着调用），后者是把 `inner` 执行后的结果扔回去。

```python
def outer():
    def inner():
        return "我是内部函数"
    return inner   # 注意：没有括号

fn = outer()
print(fn())        # 我是内部函数
```

### 参数：形参与实参

定义函数时括号里写的是形参（formal parameter），相当于占位符；调用时塞进去的是实参（argument），是真正的值。Python 调用函数时不检查参数类型——传错类型不会在调用时报错，要等到函数内部真正用到这个值时才会抛异常。这是动态语言的便利，也是坑。

```python
def power(base, exp):   # base 和 exp 是形参
    return base ** exp

print(power(2, 10))     # 2 和 10 是实参
```

### 位置参数与默认参数

位置参数必须按定义时的顺序、个数不多不少地传。多传、少传、顺序错了都会报错。默认参数在定义时就给了默认值，调用时可以省略。但有一条铁律：默认参数必须放在位置参数后面。

```python
def request(url, method="GET", timeout=10):
    print(f"{method} {url} (timeout={timeout}s)")

request("https://example.com")
request("https://example.com", method="POST")
request("https://example.com", timeout=30)   # 用关键字跳过中间默认参数
```

调用时写 `参数名=值` 可以不按顺序传，也能跳过中间的默认参数。这个写法在 requests 等第三方库里非常常见，看懂它是读别人项目代码的基本功。
