## Lesson

这一节快速过五个爬虫脚本里最常用的内建模组。不需要背接口，只要记住「这个模组能做什么」，用的时候再查具体写法。

### time 模块：时间戳与格式化

计算机认识的时间是时间戳（从 1970-01-01 00:00:00 UTC 到现在的秒数），人看的是格式化字符串。`time` 模块在两种形式之间转换，还能让程序暂停。

```python
import time

ts = time.time()                          # 1725580800.123
s = time.strftime("%Y-%m-%d %X")          # '2024-09-06 08:00:00'
time.sleep(1.5)                           # 暂停 1.5 秒
```

逆向签名里常见一个 `ts=1725580800` 参数，就是这个时间戳。爬虫里计算请求耗时、在两个请求之间加随机延迟，都离不开 `time`。

### random 模块：随机数

爬虫常用随机数来反反爬：随机延迟、随机 UA、随机打乱请求顺序。

```python
import random

random.random()               # 0.0 ~ 1.0 之间的随机小数
random.randint(1, 10)         # 含 1 和 10 的随机整数
random.randrange(10)          # 0 ~ 9，不含 10
random.choice(["a", "b"])     # 从序列里随机取一个
random.sample(range(100), 5)  # 取 5 个不重复的
random.shuffle(lst)           # 原地打乱列表，返回 None
```

注意 `shuffle` 是原地修改列表，不返回新列表。

### os 模块：与操作系统打交道

脚本中拼接路径、检查文件是否存在、列出目录内容，都靠 `os` 和 `os.path`。

```python
import os

os.getcwd()                   # 当前工作目录
os.path.exists("data.txt")    # 文件是否存在
os.path.isfile("data.txt")    # 是不是文件
os.path.isdir("data")         # 是不是目录
os.path.abspath("data.txt")   # 绝对路径
os.path.join("/tmp", "a.txt") # 跨平台拼接路径：/tmp/a.txt
os.path.getsize("data.txt")   # 文件大小（字节）
os.listdir(".")               # 列出目录内容（含隐藏文件）
```

路径拼接永远用 `os.path.join`，别手拼字符串，否则 Windows 和 macOS/Linux 会不一致。

### json 模块：序列化与反序列化

把 Python 字典/列表转成 JSON 字符串叫序列化，反过来叫反序列化。这是爬虫解析接口返回数据的核心技能。

```python
import json

# 对象 → 字符串
d = {"name": "Andy", "age": 25}
s = json.dumps(d, ensure_ascii=False)   # '{"name": "Andy", "age": 25}'

# 字符串 → 对象
d2 = json.loads(s)                       # {'name': 'Andy', 'age': 25}

# 直接读写文件
with open("data.json", "w", encoding="utf-8") as fp:
    json.dump(d, fp, ensure_ascii=False)

with open("data.json", "r", encoding="utf-8") as fp:
    d3 = json.load(fp)
```

### re 模块：正则表达式

正则用来从 HTML 或文本里提取目标数据。几个最常用的语法：`.` 匹配除换行外任意字符，`\d` 匹配数字，`[abc]` 匹配集合内任一字符；`*` 任意多次，`+` 至少一次，`?` 0 或 1 次，`{m,n}` m 到 n 次；`.*` 是贪婪模式（尽量多匹配），`.*?` 是非贪婪（惰性）模式（尽量少匹配）。

```python
import re

# 提取所有数字
re.findall(r"\d+", "age 25 height 175")     # ['25', '175']

# 提取手机号（中国大陆）
re.findall(r"1[3-9]\d{9}", "call 13800138000")  # ['13800138000']

# 非贪婪截取：从 http 到最近的 .
re.findall(r"http.*?\.", "http://a.com http://b.net")  # ['http://a.', 'http://b.']
```

`re.findall` 返回所有匹配结果的列表，配合 `.*?` 非贪婪模式，能在 HTML 里精准抠出标签之间的内容。
