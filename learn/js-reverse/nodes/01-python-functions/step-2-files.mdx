掌握文件的打开模式、读写方法，并养成使用 with 上下文管理器的安全习惯。
</LearningGoal>

## Lesson

把数据写进文件实现持久化，就像「大象塞冰箱」——分三步：打开、操作、关闭。Python 里用 `open()` 打开文件，拿到一个文件对象（file handle），读或写完之后再 `close()` 关闭。

问题是：如果中间出了异常，`close()` 可能被跳过，数据只写了一部分到磁盘。这就是 `with` 出场的原因。`with` 是上下文管理器，保证无论正常结束还是抛异常，文件都会被自动关闭。以后写文件操作，默认就用 `with`，别手写 `close()`。

```python
with open("data.txt", "r", encoding="utf-8") as fp:
    content = fp.read()
# 离开缩进块后，fp 自动关闭
```

### 打开模式

处理文本文件常用 `r` / `w` / `a` 三种模式：`r` 只读（文件必须存在），`w` 只写（存在则清空），`a` 追加写。加上 `+` 号变成读写模式（`r+` / `w+` / `a+`），其中 `w+` 会先清空，`a+` 写入只能在末尾。

处理图片、视频等非文本文件，用 `rb` 读、`wb` 写。处理非 UTF-8 编码的文件（例如 GBK 网页源码），打开时要传 `encoding` 参数，编码不规范可加 `errors='ignore'` 跳过非法字符。

### 读写方法

文件对象有几个常用方法：`read(size)` 读 size 个字符（不传参则一次性读完，大文件别这么做）；`readline()` 一次读一行，不能回头，返回空字符串说明已到末尾；`readlines()` 一次性读入内存返回按行分割的列表，方便但占内存；`write(text)` 写入内容，注意是写入内存缓冲区，`close()` 后才真正写回硬盘。

安全读大文件的姿势是逐行读，不一次性塞进内存：

```python
with open("big.log", "r", encoding="utf-8") as fp:
    for line in fp:
        if "error" in line:
            print(line.strip())
```

### 二进制文件：图片拷贝

处理图片、视频等非文本文件，用 `rb` 读、`wb` 写，整个流程就是「读二进制 → 写二进制」。逆向脚本里经常要把抓到的图片或视频片段保存到本地，这套 rb/wb 流程直接能用。

```python
with open("cat.png", "rb") as src:
    data = src.read()

with open("cat_copy.png", "wb") as dst:
    dst.write(data)
```
