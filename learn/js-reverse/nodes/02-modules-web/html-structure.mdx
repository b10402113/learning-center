## Lesson

HTML（HyperText Markup Language）是制作网页的标准标记语言，扩展名 `.html` 或 `.htm`。它是描述性语言，不是编程语言——写给浏览器看，告诉浏览器"这里是一段文字"、"那里是一张图"。用户访问网页，本质是把服务器的 HTML 文档下载到本地，由浏览器按顺序解释渲染成网页效果。

一份标准 HTML 文档的骨架如下：

```html
<!DOCTYPE html>          ← 告诉浏览器用什么解析器
<html>                    ← 文档起止标记
  <head>                  ← 头部（不在窗口显示）
    <title>标题</title>    ← 标题栏标题
    <meta charset="UTF-8"> ← 声明编码
  </head>
  <body>                  ← 可见的网页主体
    <h1>Hello</h1>
    <p>段落</p>
  </body>
</html>
```

- `<!DOCTYPE html>`：告诉浏览器用什么解析器解析文档。
- `<head>`：内容不在浏览器窗口显示。`<title>` 定义标题栏标题，`<meta charset="UTF-8">` 声明编码。
- `<body>`：可见的网页主体。

标签的语法规则：标签分闭合（`<p>...</p>`）和自闭合（`<br>`、`<img>`）两种；HTML 不区分大小写；属性可带可不带；网页可见数据只能写在标签之间或属性中。

块级与内联标签的区别：

| 类型 | 特点 | 常见标签 |
| --- | --- | --- |
| 块级（block） | 独占一行 | `<h1>`-`<h6>`、`<p>`、`<div>`、`<ul>`、`<table>` |
| 内联（inline） | 按内容占位 | `<a>`、`<img>`、`<span>`、`<strong>`、`<em>` |

`<div>` 是无实际意义的块级元素、`<span>` 是无实际意义的行内元素，专为 CSS 样式服务。

常用标签：

**标题与段落**：`<h1>` 到 `<h6>` 表示六级标题，`<p>` 表示段落，`<br>` 换行。

**文本格式化**：`<strong>` 粗体（语义：重要）、`<b>` 粗体（单纯视觉）、`<em>` 斜体（语义：强调）、`<i>` 斜体、`<del>` 删除、`&nbsp;` 空格（HTML 里连续空格会被合并）。

**超链接 `<a>`**：`href` 规定跳转目标（网络链接或本地路径），留空则默认刷新当前页；`title` 是悬浮提示；`target="_blank"` 新建窗口打开，`_self` 为默认覆盖自身。

**图片 `<img>`**：`src` 指定图像 URL（本地或网络地址），不正确则显示裂图；`alt` 是替换文本；`width/height` 控制显示尺寸。

**列表**：`<ul>` 无序列表，`<ol>` 有序列表（可带 `start` 属性指定起始编号），`<li>` 为列表项。

**表格**：`<table>`、`<tr>`（行）、`<td>`（列），`rowspan` 合并行、`colspan` 合并列。

**表单 `<form>`**（逆向重点）：`action` 指向服务器处理程序 URL，`method` 取 get 或 post（默认 get）。`input type` 有 text、password、checkbox、radio、date、file、submit、reset 等。单选框的 `name` 必须一样，否则无法单选。文件上传必须设置 `enctype="multipart/form-data"`。登录/搜索表单是逆向最常见的请求来源，须认识每个控件与提交参数的对应关系。
