# HTML 多媒体标签

## Learning goal

认识 video 与 audio 标签的属性与用法，理解如何从 HTML 中提取多媒体资源的真实 URL。

## Lesson

video 和 audio 标签的 src 属性藏着真实的媒体文件 URL，controls 默认隐藏播放控件，loop 支持正整数指定次数或 -1 无限循环，不同浏览器因版权限制支持的播放格式不同。
