## Learning goal

認識 video 與 audio 標籤的屬性與用法，理解如何從 HTML 中提取多媒體資源的真實 URL。

## Lesson

本課讀懂 video、audio 的播放屬性，並從 src 或 source 定位媒體資源 URL。
