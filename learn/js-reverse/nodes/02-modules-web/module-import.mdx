<LearningGoal>
理解 Python 模块的三种来源、import 与 from-import 的写法，以及 __name__ 如何决定入口文件与被导入模块的行为差异。
</LearningGoal>

## Lesson

当你写一个爬虫脚本，代码会越来越长：发请求的、解析 HTML 的、存档案的、加密签名的……全塞在一个档案里，改一行就要读懂全部。模块（module）就是把这些函数按功能分组，放到不同档案里，让代码可读、可维护、可复用。

Python 的模块分三类：

| 来源 | 例子 | 怎么来 |
| --- | --- | --- |
| 内建模块 | `time`、`os`、`json` | 安装 Python 就有 |
| 第三方模块 | `requests`、`lxml` | 用 `pip install` 安装 |
| 自定义模块 | 你自己写的 `utils.py`、`sign.py` | 项目里的 `.py` 档案 |

导入模块有三种常见写法，各自有不同的使用场景。

第一种是 `import 模块名`：

```python
import time
time.sleep(1)  # 调用时必须带上模块名前缀
```

优点是不会和当前档案的变量冲突，缺点是每次调用都要写模块名。

第二种是 `import 模块名 as 别名`：

```python
import numpy as np
np.array([1, 2, 3])
```

爬虫圈子里常见别名：`import requests as req`、`import pandas as pd`。

第三种是 `from 模块名 import 成员`：

```python
from time import sleep
sleep(1)  # 直接用，不带前缀
```

适合频繁调用某个函数；但注意不要 `from module import *`，会让代码看不出函数来自哪里。

一个关键行为：**导入模块时，Python 会执行该模块的顶层代码**。如果 `utils.py` 里写了 `print("载入中")`，导入时就会打印。而且多次导入只执行一次——Python 会缓存已导入的模块。

每个档案都有一个内建变量 `__name__`：如果档案是直接执行的（入口文件），`__name__` 的值是 `"__main__"`；如果档案是被导入的，`__name__` 的值是模块名（档案名去掉 `.py`）。

这让我们可以写一段"只有直接执行时才跑"的代码：

```python
# utils.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    # 只有直接执行 utils.py 才会跑这里
    print("测试 add:", add(1, 2))
```

爬虫脚本里很常见：主程序用 `if __name__ == "__main__":` 包起来，方便被其他脚本复用。

当模块越来越多，就用文件夹来组织——这种包含 `__init__.py` 的文件夹就叫包（Package）。导入包的语法：

```python
import m_log.logger          # 导入包里的模块
from m_log import logger      # 简写
from m_log.logger import log  # 直接导入函数
```
