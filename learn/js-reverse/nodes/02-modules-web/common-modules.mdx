## Lesson

爬虫脚本里，有几个内置模块几乎天天用到：time 管时间、random 管随机、os 管档案、json 管数据交换、re 管文本提取。这一节快速过一遍它们最常用的接口。

**time 模块**最常见的两个用途：测量请求耗时、生成时间戳参数。

```python
import time

# 1. 时间戳（1970-01-01 到现在的秒数）
ts = time.time()          # 1716290000.123456
ts_ms = int(ts * 1000)    # 毫秒时间戳，接口常用

# 2. 格式化人可读时间
now = time.strftime('%Y-%m-%d %H:%M:%S')  # '2024-05-21 14:30:00'

# 3. 暂停（限速、等待页面）
time.sleep(2)  # 暂停 2 秒

# 4. 测量程序耗时
start = time.time()
do_something()
print(f"耗时 {time.time() - start:.2f} 秒")
```

**random 模块**用来模拟人类行为（随机延迟）、随机取样数据。

```python
import random

random.random()          # 0.0 ~ 1.0 之间的小数
random.randint(1, 10)    # 1 ~ 10 之间的整数
random.choice(['a', 'b', 'c'])  # 随机选一个
random.sample(range(100), 5)    # 随机选 5 个不重复的
random.shuffle(lst)      # 原地打乱列表顺序
```

**os 模块**管文件系统操作：存档案、建目录、判断路径是否存在。

```python
import os

os.path.exists('data.json')      # 档案是否存在
os.path.isdir('output')          # 是不是目录
os.path.isfile('config.py')      # 是不是档案
os.path.join('folder', 'a.txt')  # 拼接路径（跨平台）
os.listdir('.')                  # 列出目录内容
os.makedirs('output/sub', exist_ok=True)  # 递归建目录
```

**json 模块**是爬虫取数的核心技能——接口数据几乎都是 JSON。

```python
import json

# Python 字典 → JSON 字符串（发给服务器）
data = {'name': 'Alice', 'age': 25}
s = json.dumps(data, ensure_ascii=False)  # '{"name": "Alice", "age": 25}'

# JSON 字符串 → Python 字典（解析响应）
obj = json.loads(s)  # {'name': 'Alice', 'age': 25}

# 直接读写档案（持久化）
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False)

with open('data.json', 'r', encoding='utf-8') as f:
    obj = json.load(f)
```

**re 模块**（正则表达式）用来精确提取目标片段。当 HTML 结构复杂、XPath 不好写时，正则特别有用。重点是分组：`findall` 加分组后，返回的是括号内捕获的内容，而不是整个匹配。

```python
import re

# 单字符
r'\d'      # 一个数字
r'.'       # 任意字符
r'[a-z]'   # 小写字母

# 数量
r'\d+'     # 一个或多个数字
r'\d{1,3}' # 1 到 3 个数字

# 分组：findall 加分组后，返回分组内捕获的内容
html = '<hTml>Hello</HtMl>'
re.findall(r'<hTml>(.*)</HtMl>', html)
# ['Hello']  ← 只返回括号里的内容

# 贪婪 vs 非贪婪
r'<div>.*</div>'    # 贪婪：匹配尽可能多
r'<div>.*?</div>'   # 非贪婪：匹配尽可能少
```
