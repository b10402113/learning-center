# Python 客戶端對照

## Learning goal

用 Python requests 重現瀏覽器對 /books 的 Ajax 請求，建立「瀏覽器 Ajax = Python requests」的映射。

## Lesson

`requests.get("http://127.0.0.1:5000/books")` 加 `res.json()` 和 jQuery `$.ajax` 做的事情完全一樣 —— 對同一個 URL 發 GET 請求、拿回 JSON、解析成原生資料結構；逆向爬蟲的核心工作流就是先在 DevTools 抓到請求，再把 URL、方法、參數、請求頭原封不動翻譯成 Python，只有當參數是 JavaScript 動態產生（如 sign、token）時才需要回去讀 JS 代碼。
