# Ajax 前端演示頁

## Learning goal

看懂 jQuery $.ajax 的事件驅動流程：點擊觸發 → 非同步請求 → 回調函式 → DOM 更新。

## Lesson

JavaScript 是事件驅動的：`onclick` 把函式綁到 DOM 元素上，點擊才觸發；`$.ajax({url, type, success})` 對準伺服器路徑送出 GET 請求，伺服器回應後 jQuery 自動把 JSON 解析成 JavaScript 陣列傳給 `success` 回調，回調再用 `.html()` 把資料塞回畫面；整個過程頁面不跳轉，DevTools Network 面板裡會多出一筆 XHR 類型的請求。
