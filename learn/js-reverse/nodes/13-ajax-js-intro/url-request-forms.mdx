# URL 結構與四種請求形式

## Learning goal

拆解 URL 的四個組成部分，並區分瀏覽器同步請求與 JavaScript 非同步請求的差異。

## Lesson

每個 URL 由協議、域名與埠號、路徑、查詢參數四塊組成；瀏覽器發請求有四種形式 —— 地址列回車、a 標籤、form 表單、Ajax —— 前三種是瀏覽器內建的同步行為（整個頁面被覆蓋），Ajax 則是 JavaScript 發起的非同步請求（頁面不動、資料在背景交換），判斷一個請求是同步還是 Ajax 決定了爬蟲要對最終 HTML 發請求，還是去找背後的 JSON 介面。
