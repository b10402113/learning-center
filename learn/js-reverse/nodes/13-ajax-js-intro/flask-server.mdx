# Flask 演示伺服器

## Learning goal

用 Flask 在本機架設一個只有三個路由的最小伺服器，理解模板渲染、表單頁與 JSON 介面的差別。

## Lesson

Flask 用 `@app.route()` 裝飾器把 URL 路徑和函式綁在一起，`render_template()` 回傳完整 HTML（伺服器端渲染），`jsonify()` 回傳 JSON（純資料端點）；我們架了一個只有 /index、/login、/books 三個路由的本地靶站，提供完全可控、零延遲、可對照後端原始碼的練習環境。
