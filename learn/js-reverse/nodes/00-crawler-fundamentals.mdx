# 爬虫基础：定义、分类与合法性

## Learning goal

理解爬虫的本质、三种分类（通用/聚焦/增量式）以及使用爬虫的法律边界。

## Steps

1. [[learn/js-reverse/nodes/00-crawler-fundamentals/what-is-crawler|爬虫的本质：客户端模拟与请求—响应模型]] — 理解爬虫是模拟客户端发送网络请求的程序
2. [[learn/js-reverse/nodes/00-crawler-fundamentals/three-crawler-types|三种爬虫分类：通用、聚焦与增量式]] — 区分三种爬虫的适用场景与技术差异（after step 1）
3. [[learn/js-reverse/nodes/00-crawler-fundamentals/crawler-legality|爬虫的法律边界：善意、恶意与三大风险]] — 辨别善意与恶意爬虫的行为边界，列举三大风险（after step 2）

## Lesson

这一节建立对爬虫的宏观认知：它是什么、有哪些类型、在法律上意味着什么。爬虫的核心动作就是模拟浏览器向网站发请求、拿数据——这和你手动打开网页做的事情一模一样，只不过用代码自动化了。理解了这个本质，才能在后面的实战中知道什么时候该用什么策略，什么时候该踩刹车。
