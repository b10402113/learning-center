# Python 基础：函式与档案操作

## Learning goal

定义/呼叫函式、读写档案、with 上下文管理器

## Steps

1. [[learn/js-reverse/nodes/01-python-functions/step-1-functions|函数定义与调用]] — 能正确定义函数、调用函数，并理解返回值与参数传递的规则。
2. [[learn/js-reverse/nodes/01-python-functions/step-2-files|档案读写与上下文管理器]] — 掌握文件的打开模式、读写方法，并养成使用 with 上下文管理器的安全习惯。（在 step 1 之后）
3. [[learn/js-reverse/nodes/01-python-functions/step-3-modules|模组与包]] — 理解模组与包的组织方式，能读懂并写出各种 import 写法，并理解 __name__ 的用途。（在 step 1 之后）
4. [[learn/js-reverse/nodes/01-python-functions/step-4-toolbox|常用工具箱速览]] — 认识 time、random、os、json、re 这五个常用内建模组的核心接口，能在脚本中直接使用。（在 step 3 之后）

## Lesson

这一章把 Python 最基础的工具箱过一遍：函数、档案、模组、常用内建库。对已经有 Python 日常使用经验的人来说，这些内容并不陌生，但爬虫和逆向脚本对这几块各有侧重——函数用来封装请求逻辑，档案用来持久化 cookie 和抓包结果，模组决定了你能不能读懂别人的项目，time/json/re 几乎每个脚本都会用到。

学习顺序上，先把函数打扎实。后面写档案操作和模组导入时，本质上都是在调用函数，只是这些函数来自 Python 内建或第三方档案。掌握 `__name__ == '__main__'` 的惯例后，再进入工具箱速览，就能把 json 解析、正则提取、时间戳生成这些碎片能力串成完整的脚本。
