<LearningGoal>
掌握 threading.Thread 的创建与启动，理解线程共享全局变量与进程数据隔离的差异，并学会用线程池 pool.map 批量派发爬虫任务。
</LearningGoal>

## Lesson

threading.Thread 的 API 与 Process 一致，但同一进程内的线程共享全局变量（子线程修改主线程可见），线程池（multiprocessing.dummy.Pool）通过 pool.map(func, urls) 批量派发任务，复用线程避免反复创建销毁的开销。
