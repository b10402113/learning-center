<LearningGoal>
掌握 multiprocessing.Process 的完整用法：创建、启动、传参、join 等待、进程数据隔离与守护进程，能写出异步爬虫骨架。
</LearningGoal>

## Lesson

multiprocessing.Process 通过 target=func 指定子进程任务，start() 启动后多个进程可并行执行，join() 让主进程等待子进程结束，进程间数据完全隔离（子进程修改全局变量不影响主进程），守护进程（daemon=True）随主进程结束而终止。
