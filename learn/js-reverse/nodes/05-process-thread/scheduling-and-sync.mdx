<LearningGoal>
理解进程调度如何制造"同时"的假象，辨析并发与并行、同步与异步的核心差异，并掌握进程四态及其转换条件。
</LearningGoal>

## Lesson

并发是时间片轮转制造的"同时"假象（伪并行），并行是多核 CPU 真正的同时执行；同步必须等前一步完成才做下一步，异步则发起后不等待直接继续，进程的四态（就绪、运行、阻塞、终止）由调度算法控制。
