理解协程如何在单进程/单线程下通过自主切换阻塞环节来提升效率，为后续 asyncio 异步爬虫铺好理论基础。
</LearningGoal>

## Lesson

协程在单进程/单线程内主动监测阻塞环节并在其间切换执行，让就绪态增多以"迷惑"操作系统多分配 CPU，本质是想尽办法把 CPU 留在自己的程序里，从而在单线程下大幅提升效率。
