<LearningGoal>
用工厂类比建立进程与线程的直觉模型，理解 CPU、进程、线程三者的关系，并掌握进程与线程的定义差异。
</LearningGoal>

## Lesson

进程是操作系统分配资源的基本单元（车间），线程是 CPU 调度的最小单位（车间里的工人），同一进程的线程共享内存空间，不同进程的线程资源隔离。
