# 财联社案例：get_sign() 与 W2Yj 签名模块定位

## Learning goal

跑通「扣 loader + 三 mod → Node 里出 sign」的最小工作流，掌握先读文件头判定结构、再按模块 ID 精确定位的省力读法。

## Lesson

财联社案例要求按「读文件头 100–300 行判定结构，再按模块 ID 精确定位」的省力读法，把 loader + 三个 mod（chunk 4 含目标签名模块 `W2Yj`、chunk 0/3 的 core-js polyfill）require 进 Node 后调用 `window.loader("W2Yj")(data)` 复现 `get_sign()` 签名。
