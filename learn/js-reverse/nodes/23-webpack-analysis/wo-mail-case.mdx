# 沃邮箱案例：数字模块 ID 与 RSA 登录加密

## Learning goal

理解数字模块 ID 调度与哈希 key 调度的差异，按数字 ID 437 在 2 万行里定位 RSA 加密函数，确认老站 jQuery + 数字模块 ID 的旧版 webpack 形态。

## Lesson

沃邮箱案例展示数字模块 ID 调度的旧版 webpack 形态：按数字 ID 437 在 2 万行 mod1 里定位 RSA 加密函数，配合 loader 的 `window.loader(437).encrypt(t, o, n)`（`n='10001'` 为 RSA 公钥指数）复现登录密码加密。
