# loader + mod 分离：webpackJsonp.push 劫持与模块注册

## Learning goal

理解真实站点的 webpack 产物如何被拆成 loader + 若干 mod，loader 如何劫持 webpackJsonp.push 完成模块注册，以及如何在本地 Node 里 require 后复现加密函数。

## Lesson

真实站点的 webpack 产物被拆成「loader.js + 若干 mod 文件」：mod 通过 `window.webpackJsonp.push([[chunk名], {模块字典}, [依赖chunk]])` 注册模块，loader 劫持 `webpackJsonp.push` 完成注册并暴露调度器；逆向时把 loader 和 mod 一起 require 进 Node（补 `window = global` 等环境），再 `window.loader("模块ID")` 就能在本地拿到目标函数。
