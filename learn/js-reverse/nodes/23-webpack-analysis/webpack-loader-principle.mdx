# webpack 加载器原理：自执行结构与调度函数

## Learning goal

亲手跑通 80 行教学 demo，理解 webpack 加载器的自执行结构、缓存对象、调度函数，以及数组下标与哈希 key 两种调度方式。

## Lesson

webpack 加载器的本质是一个自执行函数 `!function(e){...}(模块容器)`，内部用缓存对象 `t` 避免重复执行，调度函数 `n(r)` 先查缓存再以 `e[r].call(o.exports, o, o.exports, n)` 执行模块，把调度器挂到 `window.loader` 后即可按数组下标或哈希 key 两种 ID 任意调度模块。
