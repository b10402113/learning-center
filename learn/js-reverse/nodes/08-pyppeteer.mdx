# Pyppeteer 异步浏览器

## Learning goal

Pyppeteer 异步控制、滑动验证、拟人操作

## Steps

1. [[learn/js-reverse/nodes/08-pyppeteer/intro-install|Pyppeteer 简介与环境安装]] — 认识 Pyppeteer 的定位与异步优势，完成本地安装
2. [[learn/js-reverse/nodes/08-pyppeteer/core-api|快速上手：核心 API 走通渲染页面抓取]] — 五行 API 走通 launch → goto → content 的完整异步爬虫（after step 1）
3. [[learn/js-reverse/nodes/08-pyppeteer/detailed-usage|详细用法：launch 参数、视口、反检测与节点交互]] — launch 参数、视口设置、webdriver 反检测、type/click 交互（after step 2）
4. [[learn/js-reverse/nodes/08-pyppeteer/slide-verify|滑动验证：cv2 模板匹配与拟人化轨迹]] — cv2 算缺口距离 + hover/mouse.move 分步滑动（after step 3）

## Lesson

Pyppeteer 是 Selenium 的异步替代品：背后同为 Chromium 浏览器，但基于 Python async 体系，无需手动配置 ChromeDriver，且天然支持异步并发。它解决的是 Selenium 的两个痛点——环境配置繁琐和同步阻塞效率低。四步走完，你会掌握从「异步启动浏览器拿渲染源码」到「模拟人的轨迹过滑动验证」的完整链路，这也是爬取需要 JS 渲染的动态页面和有反爬检测的登录场景的核心能力。
