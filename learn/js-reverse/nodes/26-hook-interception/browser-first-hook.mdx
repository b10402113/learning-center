# 瀏覽器先手 hook：atob 與 cookie

## Learning goal

在真實瀏覽器裡用「Script 事件監聽 + Snippets」搶在頁面腳本之前完成內置函數（atob）與 cookie 屬性的 hook，並理解為什麼時機必須早於頁面加載。

## Lesson

瀏覽器裡 hook 的難點是時機——先用 Script 事件監聽讓頁面在腳本執行前斷住、再用 Snippets 趁停頓注入 hook（atob 用同名覆蓋、cookie 用 defineProperty），就能在頁面加載前完成先手監控，且全程不可刷新頁面。
