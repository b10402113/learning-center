<LearningGoal>
能在真实浏览器里用 DevTools 的 Script 事件监听 + Sources Snippets，在页面加载之前完成 atob 与 document.cookie 的先手 hook，监控每一次调用。
</LearningGoal>

## Lesson

內置函數必須在頁面加載之前完成 hook，否則網站的加密調用早已結束。操作鏈：空白頁開 DevTools → 勾選 Sources 事件監聽器的 Script 斷點 → 訪問目標頁觸發斷點 → 在 Sources Snippets 新建 hook 片段、打斷點並運行 → 取消 Script 監聽（不可刷新頁面）。hook 內容複用前面的套路：`atob`（瀏覽器自帶 base64 解碼函數）用函數 hook 觀察輸入密文與解出明文；`document.cookie` 用 `Object.defineProperty` 的 get/set 監控讀寫，定位憑證生成點。
