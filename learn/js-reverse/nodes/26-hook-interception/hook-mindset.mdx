<LearningGoal>
理解 hook（拦截和修改函数或方法行为的技术）的概念、三大作用，以及「保存原函数 + 同名覆盖」这个所有 hook 共用的最小可用模式。
</LearningGoal>

## Lesson

hook 是能夠攔截和修改函數或方法行為的技術，可在原函數執行前/後插入邏輯或替換實現，目的是找到函數入口並觀察參數變化。所有 hook 共用的最小可用模式是「保存原函數 + 同名覆蓋」：`_add = add` 保存原實現不改內部邏輯，`add = function(...)` 同名覆蓋不改變調用方式，包裹函數打印參數與返回值後原樣 return。hook 的位置必須在原函數加載完成之後。
