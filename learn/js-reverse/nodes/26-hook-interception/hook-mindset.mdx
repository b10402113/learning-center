# Hook 的概念與最小可用模式

## Learning goal

理解 hook 是「攔截和修改函數行為的技術」，說出它在逆向中的用途，並記住「保存原函數 + 同名覆蓋」這個貫穿全程的最小可用模式。

## Lesson

Hook 是攔截和修改函數行為的技術——用「保存原函數 + 同名覆蓋」的最小模式，在不改原代碼、不變調用方式的前提下，觀察每一次調用的參數與返回值，這正是逆向中定位加密函數調用點的第一手段。
