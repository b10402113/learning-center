# 函數的 hook：包裹原函數

## Learning goal

獨立寫出一個函數 hook：保存原函數、同名覆蓋、打印入參與返回值、原樣返回結果，並理解 hook 代碼必須在原函數加載之後執行。

## Lesson

函數 hook 固定四步——拿到原函數、`_add = add` 保存、同名包裹（打印入參 → 調原函數 → 打印返回值 → 原樣返回）、照常調用觀察輸出——且 hook 代碼必須在原函數加載完成之後執行，包裹函數必須 `return result` 保持對外行為等價。
