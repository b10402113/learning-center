<LearningGoal>
能独立写出函数 hook 的四步流程——定义/取得原函数、保存原函数、同名包裹、调用观察，并理解 hook 必须在原函数加载完成之后的时机要求。
</LearningGoal>

## Lesson

函數 hook 的四步流程：定義/取得原函數 → `_add = add` 保存原函數（不改內部實現）→ `add = function(a,b){...}` 同名包裹（打印參數、調用 `_add`、打印返回值、原樣 return）→ 調用 `add(1,2)` 觀察輸出。時機硬性要求：hook 代碼必須在原函數加載完成之後執行，否則 `_add` 保存到的是 undefined。逆向用途是讓加密函數在複雜調用鏈中自報調用點與參數。
