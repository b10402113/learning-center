<LearningGoal>
掌握用 Object.defineProperty 的 get/set 重新定义对象属性的写法，把属性的读与写都变成可监控的入口——包括对象上原本不存在的属性。
</LearningGoal>

## Lesson

用 `Object.defineProperty(obj, prop, { get(){...}, set(value){...} })` 把對象屬性的讀與寫重新定義成可監控的入口：`get()` 在取值時執行、`set(value)` 在設值時執行。原值必須保存到外部變數（如 `_name`）並在其中讀寫，避免在 get/set 中自引用造成無限遞歸。對象上原本不存在的屬性（如 `age`）同樣可以 hook——先定義屬性再監控，這對跨 JS 文件動態加屬性的場景很關鍵。
