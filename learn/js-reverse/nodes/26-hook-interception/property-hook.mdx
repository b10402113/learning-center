# 對象屬性的 hook：Object.defineProperty

## Learning goal

用 Object.defineProperty 把屬性的讀寫重新定義成帶日誌的 get/set，監控已有屬性與不存在的屬性，並理解為什麼要把原值存到外部變量。

## Lesson

用 `Object.defineProperty(對象, 屬性名, { get, set })` 重新定義屬性的讀寫行為、把原值存進外部變量避免 `get` 自引用遞歸，就能把任何屬性（包括本來不存在的）變成帶日誌的監控入口。
