# Hook 檢測與反檢測

## Learning goal

理解網站如何用 toString() 與原型鏈上的 Function.prototype.toString.call 檢測函數是否被 hook，並掌握對應的兩級破解寫法與各自代價。

## Lesson

網站用 `toString()` 比對 `[native code]` 來檢測 hook，第一級破解是重寫實例的 `toString` 返回偽造字串；對方改用原型鏈上的 `Function.prototype.toString.call` 繞過實例，就再重寫原型鏈上的 `toString` 並用 `this.name` 動態適配調用者——hook 會增加被檢測風險，攻防需權衡。
