<LearningGoal>
理解网站用 toString() 与 Function.prototype.toString.call 两级检测识别 hook 的原理，掌握重写实例 toString 与重写原型链 toString 两种破解及各自代价。
</LearningGoal>

## Lesson

網站用 `toString()` 檢測函數是否被 hook：原生內置函數返回 `function atob() { [native code] }`，被 hook 後返回包裹函數源碼。第一級破解是在 hook 時重寫實例上的 `atob.toString` 返回偽造的 `[native code]`；對方升級為原型鏈檢測 `Function.prototype.toString.call(atob)` 繞開實例重寫後，第二級破解是重寫 `Function.prototype.toString`，用 `this.name` 動態適配調用者名字（寫死會讓所有函數都返回 atob），代價是污染所有函數的 toString 行為。
