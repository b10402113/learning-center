# 代理服务器、匿名度与代理池

## Learning goal

理解代理服务器在爬虫中的定位（隐藏客户端真实 IP、对抗 IP 黑名单），区分透明/匿名/高匿三种匿名度与 HTTP/HTTPS 两种协议，并能用 requests 的 proxies 参数写出带代理池、随机选择代理、间隔睡眠的批量爬虫。

## Lesson

高頻爬取會讓網站把你的 IP 加入黑名單，之後每次請求都被拒絕。代理伺服器就是中間人，它改寫請求的來源 IP 為自己的 IP，轉發給目標，再把回傳資料轉傳給你。目標看到的來源是代理的 IP，不是你的真實 IP，黑名單就封不到你頭上。

代理的隱蔽程度分三等級。透明代理會告訴目標「有人在用代理」以及你的真實 IP，爬蟲場景毫無用處。匿名代理知道有人在用代理，但不知道你的真實 IP，基本夠用但有些網站會專門過濾用了代理的請求。高匿代理最推薦，目標完全看不出有人在用代理，伺服器收到的請求和一般訪客沒有兩樣。買代理的時候認準「高匿」兩個字。

代理也分協議類型，HTTP 代理只能轉發 HTTP 請求，HTTPS 代理能轉發 HTTPS 請求。大多數網站都用 HTTPS，所以你要買支援 HTTPS 的代理。拿到一個代理 IP:port 之後，用 <code>requests.get(url, proxies={"http": "http://ip:port", "https": "http://ip:port"})</code> 來設定——注意 proxies 字典的值永遠以 <code>http://</code> 開頭，即使是 https key 也不要寫成 <code>https://</code>。測試時先用 <code>cip.cc</code> 確認回傳的是代理的 IP 而不是你的本機 IP，這樣才知道代理有生效。

單代理很快就不能用，大規模爬取要上代理池。把多個代理 IP:port 存在一個列表裡，每次請求前用 <code>random.choice()</code> 隨機選一個，配合 <code>time.sleep(random.uniform(1, 3))</code> 錯開請求間隔，避免同一個代理瞬間刷太多被封。再用 <code>try/except</code> 包住，單個代理失敗不影響整個爬蟲，直接略過換下一個。

免費代理網站能練手，但品質差、速度慢、很多根本不能用；正式爬取靠付費代理服務（如芝麻代理），勝在品質穩定、速度快、支援高匿。
