# 实战：DES/AES 案例

## Learning goal

招标网 DES-ECB、毛毛租 AES-CBC 加解密

## Steps

1. [[learn/js-reverse/nodes/20-des-aes-cases/des-ecb-case|招标网 DES-ECB 解密实战]] — 用 requests 抓取密文并通过 execjs 调用 decryptByDES 完成解密
2. [[learn/js-reverse/nodes/20-des-aes-cases/cryptojs-des-api|CryptoJS DES 解密 API 链]] — 逐行拆解 CryptoJS DES 解密的完整调用链（after step 1）
3. [[learn/js-reverse/nodes/20-des-aes-cases/aes-cbc-case|毛毛租 AES-CBC 加密与解密实战]] — PyCryptodome 加密请求体 + execjs 解密响应（after step 1）
4. [[learn/js-reverse/nodes/20-des-aes-cases/cryptojs-aes-api|crypto-js AES 解密与 iv=key 模式]] — 拆解 crypto-js AES 解密 API 链并理解 iv=key 特征（after step 3）

## Lesson

这一节把前两节学到的 execjs 调用和 PyCryptodome 加密，落到两个真实案例上。第一个案例是招标网：接口响应是 DES-ECB 加密后的密文，你只需用 requests 把密文拉下来，再交给 CryptoJS 的 decryptByDES 函数就能解出明文。第二个案例是毛毛租：这次轮到我们加密——用 PyCryptodome 把请求体用 AES-128-CBC 加密后 POST，响应则交给 crypto-js 的 decrypt_data 函数解密。两个案例合在一起，覆盖了"Python 请求 + JS 解密"和"Python 加密 + JS 解密"两条最常见的混合逆向路线。
