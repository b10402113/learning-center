<LearningGoal>
掌握在 Node 环境中补齐浏览器全局对象的最小可用 shim，并抹除暴露宿主身份的指纹。
</LearningGoal>

## Lesson

在 Node 环境中用手造的最小浏览器全局对象（window/document/navigator/screen/history/location）填补 JS 依赖，并 delete global/Buffer 抹除 Node 指纹，再用 Proxy 代理拦截 get/set 逐一补齐缺失属性。
