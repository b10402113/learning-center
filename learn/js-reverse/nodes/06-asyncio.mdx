# asyncio 与异步爬虫

## Learning goal

协程、asyncio 事件循环、aiohttp 多任务异步请求

## Steps

1. [[learn/js-reverse/nodes/06-asyncio/sync-async-concepts|同步、异步与并行、并发]] — 分辨同步/异步、并行/并发两组概念，理解 IO 密集型任务为何适合异步
2. [[learn/js-reverse/nodes/06-asyncio/coroutine-principle|协程原理：用户空间调度]] — 协程与线程/进程的本质区别（after step 1）
3. [[learn/js-reverse/nodes/06-asyncio/asyncio-core|asyncio 四个核心概念与 wait/await]] — 特殊函数、协程对象、任务对象、事件循环，以及 wait/await 的多任务调度（after step 2）
4. [[learn/js-reverse/nodes/06-asyncio/aiohttp-crawler|aiohttp 与多任务异步爬虫实战]] — 用 aiohttp 替换 requests，写出完整的多任务异步爬虫（after step 3）

## Lesson

爬虫的核心瓶颈是网络 IO——每次发请求、等响应，CPU 都在空转。上一章讲了进程和线程，它们靠操作系统调度来切换任务，但你无法控制切换时机。协程把调度权交回程序员：遇到阻塞时主动挂起，让 CPU 去做别的事。asyncio 是 Python 的协程框架，它用四个层层递进的概念（特殊函数 → 协程对象 → 任务对象 → 事件循环）把协程用起来。配合 aiohttp 这个异步网络请求库，三个 2 秒的请求可以压到 2 秒完成。
