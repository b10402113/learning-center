# 爬虫的本质：客户端模拟与请求—响应模型

## Learning goal

理解爬虫的本质是模拟客户端发送网络请求并获取数据的程序，区分 B/S 与 C/S 两种架构下的爬虫形态。

## Lesson

爬蟲的本質是用程式碼扮演客戶端，向網站伺服器發送 HTTP 請求並拿回數據——和你用瀏覽器做的事情一模一樣，只是自動化了。B/S 架構下直接模擬瀏覽器發請求，C/S 架構下則需先抓包再復現。所有爬蟲都遵循四步骨架：指定 URL → 發送請求 → 獲取響應 → 持久化存儲。網站會用反爬機制（UA 檢測、IP 限制、驗證碼等）阻擋爬蟲，爬蟲工程師則用反反爬策略繞過，這是一場持續的矛與盾對抗。
