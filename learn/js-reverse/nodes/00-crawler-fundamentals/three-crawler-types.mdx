# 三种爬虫分类：通用、聚焦与增量式

## Learning goal

能区分通用爬虫、聚焦爬虫、增量式爬虫三种类型的适用场景与技术差异。

## Lesson

爬蟲根據「爬什麼範圍」分為三種：通用爬蟲爬整個網站（如搜索引擎索引），聚焦爬蟲只抓特定數據（如商品價格、課程字幕），增量式爬蟲只抓新增或更新的內容（如新聞追蹤）。課程以聚焦爬蟲為主，但分頁爬取本質上就是增量思維——只拿尚未拿到的頁面。面對需求時先想清楚「爬什麼範圍」，再決定技術方案。
