# 爬虫的法律边界：善意、恶意与三大风险

## Learning goal

能说出爬虫技术的中立性原则，辨别善意爬虫与恶意爬虫的行为边界，并列举三大法律风险与规避建议。

## Lesson

爬蟲技術本身中立合法，關鍵在使用方式。善意爬蟲（如搜索引擎）合理控制頻率、抓取公開數據、提供有價值的服務；惡意爬蟲（如搶票軟體）高頻請求、侵犯隱私、癱瘓網站。三大法律紅線：違反網站意願突破反爬、干擾網站正常運營、抓取受法律保護的數據。守住控制頻率、遵守 robots.txt、審查數據內容三條底線。
