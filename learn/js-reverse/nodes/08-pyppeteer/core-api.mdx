## Lesson
Pyppeteer 的爬蟲骨架只有五個步驟——launch → newPage → goto → content → close，全部寫在 async def 函式裡，並可無縫嵌進 asyncio 任務回呼體系，形成「渲染 + 非同步 + 解析」的可複用模板。
