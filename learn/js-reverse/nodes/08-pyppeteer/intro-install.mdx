## Lesson
Pyppeteer 是 Selenium 的非同步替代品：背後同為 Chromium 瀏覽器，但走 Python async 體系，無需手動配置 ChromeDriver，且天然支援非同步並發，適合需要 JS 渲染的動態頁面爬取。
