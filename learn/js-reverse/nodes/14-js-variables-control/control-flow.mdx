<LearningGoal>
能讀懂 if-else / if-else-if / switch-case 三種分支結構，理解 switch 的 break 穿透行為，以及 while 與 for 共用的迴圈三要素。
</LearningGoal>

## Lesson

分支和迴圈是還原加密流程的地圖：if-else 雙分支、if-else-if 多分支按順序匹配第一個成立的條件；switch-case 需寫 break 否則會穿透，default 是兜底選項；while 和 for 本質相同，都是「初始變數 + 條件判斷 + 步進更新」三要素的條件循環。逆向時用這套結構就能畫出加密演算法的流程圖。
