能分辨 == 與 === 的隱式轉換差異、理解短路運算與零值，並手工求值三目與逗號運算子的綜合表達式。
</LearningGoal>

## Lesson

JS 運算子是逆向中最常踩雷的地方：`==` 會做隱式類型轉換，`===` 嚴格比較型別與值；短路運算 `&&` `||` 靠零值（0、""、false）決定回傳對象，常用於守衛模式；三目 `? :` 是 if-else 的單行縮寫；逗號運算子從左到右求值但只回傳最後一個。混淆代碼經常把這些塞進同一行，按照運算子優先順序逐步拆解就能還原。
