<LearningGoal>
能辨識 JS 中 var/let/const 三種宣告方式、理解只宣告未賦值的 undefined 預設值，以及一行多變數宣告的常見陷阱。
</LearningGoal>

## Lesson

JS 變數宣告是逆向的基本入場券：var/let/const 的差異在於能否重新指派，const 綁定不可改但物件屬性可變；只宣告不賦值的變數自動為 `undefined`，這是判斷賦值時機的關鍵線索；一行多變數宣告時，沒賦值的仍是 undefined。這些基礎能幫助你快速讀懂加密代碼中的變數初始化邏輯。
