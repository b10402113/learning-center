<LearningGoal>
能操作陣列的 push/pop/splice、字串的 slice/split/indexOf，並分辨 for、for-in、for-of 三種遍歷各自拿到的是索引還是元素。
</LearningGoal>

## Lesson

字串和陣列是 JS 籤名演算法的原物料：字串的 `slice`、`split`、`indexOf` 負責切割、查找與前綴判斷；陣列的 `push`/`pop`、`unshift`/`shift` 操作頭尾元素；`splice` 一方法三用途（刪除、插入、替換）是逆向高頻方法；`for-in` 拿索引、`for-of` 拿元素，而傳統 `for` 搭配索引最靈活。這些操作組合起來就是籤名參數的拼接與重排。
