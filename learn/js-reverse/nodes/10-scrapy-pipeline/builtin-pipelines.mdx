# 内置管道 FilesPipeline 与 ImagesPipeline

## Learning goal

理解 scrapy 自带的 FilesPipeline 和 ImagesPipeline 的差异，掌握"约定字段驱动"与"重写方法驱动"两种模式，并能独立写出图片下载项目。

## Lesson

Scrapy 为二进制资源下载提供了两个现成的管道类。ImagesPipeline 面向图片/音频/视频，需要重写 get_media_requests、file_path、item_completed 三个方法，由你告诉它每一步怎么做；FilesPipeline 面向普通文件，靠约定字段驱动，你只要在 Item 里填好 file_urls 和 files 两个字段，管道就会自动下载并填充结果。两者都依赖 Pillow 做图片处理，都通过 IMAGES_STORE 或 FILES_STORE 配置存储路径。
