# 完整管道项目整合

## Learning goal

把多管道与内置管道组合成一个真实可跑的项目：列表页进详情页、解析字段交管道、图片走 ImagesPipeline、元数据走多管道分别落盘数据库与文件。

## Lesson

这一节把前三节的知识点整合成一个完整的 Scrapy 项目。Spider 分两步解析：parse 解析列表页提取详情页链接，parse_detail 解析详情页提取标题、标签、图片链接并封装成 Item。管道链按优先级串联：ImagesPipeline（优先级 100）最先下载图片，CsvBackupPipeline（200）写 CSV 备份，MySQLPipeline（300）存数据库，RedisPipeline（400）推队列。每个管道都必须 return item，否则链就会断开。
