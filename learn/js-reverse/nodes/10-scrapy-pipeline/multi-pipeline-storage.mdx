# 多管道优先级与数据库存储

## Learning goal

用多个管道类把同一份数据分别存到文件、MySQL、Redis，并理解优先级数字如何控制 Item 在管道链中的流转顺序。

## Lesson

Scrapy 支持在 ITEM_PIPELINES 里注册多个管道类，Spider 只管 yield 一次 Item，引擎会自动把 Item 送入管道链。每个管道类对应一个存储载体：文件管道用 open_spider 打开文件、process_item 写 CSV、close_spider 关闭文件；MySQL 管道用 pymysql.Connect 建连接、cursor 执行 SQL 并 commit；Redis 管道用 Redis 客户端 lpush 把 Item 塞进列表。优先级数字越小，管道越先收到 Item；每个管道的 process_item 都必须 return item，否则 Item 会在这个管道断掉，后续管道全部失效。
