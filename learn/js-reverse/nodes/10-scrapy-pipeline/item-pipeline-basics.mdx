# Item 封装与 Pipeline 三方法

## Learning goal

掌握 items.py 定义字段、yield 提交、以及 pipelines.py 中 process_item / open_spider / close_spider 三方法的调用时机与职责。

## Lesson

Item 是 Scrapy 对"一条数据"的标准化封装，字段用 scrapy.Field() 定义；Spider 解析完数据后 yield 一个 Item 交给引擎，引擎再把它送进管道链。管道类通常实现三个方法：open_spider 在爬虫启动时调用一次，负责打开文件或建立数据库连接；process_item 在每次 Item 到达时调用，负责写入数据，且必须 return item 才能让 Item 继续流向下一个管道；close_spider 在爬虫结束时调用一次，负责关闭资源。这套机制把"抓"和"存"拆开，让 Spider 只管解析，存储逻辑集中在管道里。
