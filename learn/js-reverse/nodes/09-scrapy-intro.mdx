# Scrapy 框架入门

## Learning goal

专案结构、Spider 编写、Response 解析、终端运行

## Steps

1. [[learn/js-reverse/nodes/09-scrapy-intro/framework-install|框架概念与环境安装]] — 理解框架是「项目半成品」的学习定位，并完成 Scrapy 安装与环境验证
2. [[learn/js-reverse/nodes/09-scrapy-intro/project-spider|项目创建与 Spider 编写]] — 能独立用 startproject 和 genspider 搭建 Scrapy 工程，并写出一个包含 name、start_urls、parse 三要素的 Spider（after step 1）
3. [[learn/js-reverse/nodes/09-scrapy-intro/parse-response|Response 解析与终端运行]] — 掌握 response.xpath 返回 Selector 对象的机制，区分 extract 与 extract_first 的取舍，并能用 scrapy crawl 运行爬虫、读懂终端日志（after step 2）
4. [[learn/js-reverse/nodes/09-scrapy-intro/persist-data|持久化存储的两条路线]] — 能根据场景在「终端指令式」与「管道式」之间做选型判断，并写出把爬取结果落盘到 .csv 的完整流程（after step 3）

## Lesson

这一节把前面零散的 requests + xpath 经验，收拢到一个真正的爬虫框架里。Scrapy 不是重新发明爬取逻辑，而是把请求调度、并发下载、数据解析、持久化这些重复劳动做成「半成品」，让你只写业务相关的部分。

四步走下来，你会先建立「框架 = 半成品」的正确心态，避免一上来就钻源码；然后亲手搭出项目骨架，理解 Spider 三要素和目录结构；接着在 parse 里用 response.xpath 拿到数据，搞懂 Selector 对象和 extract 的取舍；最后在终端指令式和管道式两条落盘路线里做选型，完成从请求到存储的完整闭环。
