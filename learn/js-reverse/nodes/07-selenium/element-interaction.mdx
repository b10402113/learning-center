<LearningGoal>
掌握七种元素定位方式与 By 统一写法，能组合定位 + 交互完成搜索框输入、按钮点击等绝大多数页面操作。
</LearningGoal>

## Lesson

Selenium 提供七种元素定位方式，推荐使用 By 统一写法（find_element(By.ID, 'xxx')），最常用的是 XPath 和 CSS Selector。定位到节点后可用 send_keys 输入、clear 清空、click 点击完成交互，用 get_attribute 获取元素属性值。定位失败常因页面未加载、元素在 iframe 里或 XPath 写错。
