<LearningGoal>
能够独立搭建 Selenium 环境并创建 Chrome 浏览器实例，完成打开页面、定位元素、点击输入等基础自动化操作。
</LearningGoal>

## Lesson

Selenium 是浏览器自动化工具，通过驱动真实浏览器执行点击、输入等操作，解决 requests 无法获取动态渲染页面的问题。环境搭建需要 pip install selenium 并下载与浏览器版本匹配的 chromedriver，创建浏览器实例后即可用 find_element 定位元素、send_keys 输入、click 点击，完成自动化闭环。
