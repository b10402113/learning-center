<LearningGoal>
理解 page_source 拿到的是渲染后的动态源码，掌握用 execute_script 滚动触发懒加载、再用解析库提取数据的完整范式。
</LearningGoal>

## Lesson

page_source 拿到的是浏览器渲染后的动态源码，实现「可见即可得」。execute_script 用于注入 JavaScript 执行滚动等 API 未覆盖的操作，触发懒加载后再用 page_source 配合解析库（如 lxml）提取数据，这是 Selenium 爬虫抓取动态加载内容的完整范式。
