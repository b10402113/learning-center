# 进程、线程与并行

## Learning goal

掌握进程/线程的核心模型，能用 multiprocessing 与 threading 写出异步爬虫，并理解协程的动机与原理。

## Steps

1. [[learn/js-reverse/nodes/05-process-thread/process-thread-model|进程与线程的核心模型]] — 用工厂类比建立进程与线程的直觉模型
2. [[learn/js-reverse/nodes/05-process-thread/scheduling-and-sync|进程调度、状态与同步异步]] — 辨析并发/并行、同步/异步，掌握进程四态（after step 1）
3. [[learn/js-reverse/nodes/05-process-thread/multiprocessing-basics|multiprocessing 进程实战]] — Process 创建、join、数据隔离与守护进程（after step 2）
4. [[learn/js-reverse/nodes/05-process-thread/threading-and-pool|threading 线程与线程池]] — Thread 共享内存、线程池 pool.map 批量派发（after step 3）
5. [[learn/js-reverse/nodes/05-process-thread/coroutine-concept|协程原理与动机]] — 单线程内自主切换阻塞环节，把 CPU 留在自己程序里（after step 2）

## Lesson

爬虫提速的核心问题是：网络请求是阻塞操作——CPU 在等服务器响应，这段时间什么都干不了。解决办法是让多个请求"同时"进行。

但"同时"有两种含义：并行是多核 CPU 真的同时跑多个任务，并发是单核靠时间片快速切换制造同时的假象。无论哪种，Python 都提供了对应工具——multiprocessing 用进程隔离数据、threading 用线程共享内存、协程则在单线程内自主切换。

本课从工厂类比出发，先建立进程/线程的心智模型，再逐一拆解调度原理、同步异步、Process/Thread 实战、线程池，最后引出协程的动机。这些工具是后面 asyncio 异步爬虫的直接前置。
