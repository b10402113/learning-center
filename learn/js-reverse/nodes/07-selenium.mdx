# Selenium 浏览器自动化

## Learning goal

驱动浏览器、元素定位、动作链、隐蔽 selenium 侦测

## Steps

1. [[learn/js-reverse/nodes/07-selenium/selenium-setup|环境搭建与浏览器创建]] — 能够独立搭建 Selenium 环境并创建 Chrome 浏览器实例，完成打开页面、定位元素、点击输入等基础自动化操作。
2. [[learn/js-reverse/nodes/07-selenium/element-interaction|元素定位与节点交互]] — 掌握七种元素定位方式与 By 统一写法，能组合定位 + 交互完成搜索框输入、按钮点击等绝大多数页面操作。（after step 1）
3. [[learn/js-reverse/nodes/07-selenium/dynamic-data|execute_script 与 page_source 获取动态数据]] — 理解 page_source 拿到的是渲染后的动态源码，掌握用 execute_script 滚动触发懒加载、再用解析库提取数据的完整范式。（after step 2）
4. [[learn/js-reverse/nodes/07-selenium/action-chains-waiting|动作链与页面等待]] — 掌握 ActionChains 处理鼠标拖曳等无特定对象的动作，能按场景选择强制、显式、隐式三种等待策略。（after step 2）
5. [[learn/js-reverse/nodes/07-selenium/captcha-anti-detect|验证码实战与规避检测]] — 掌握 OpenCV 缺口识别 + 动作链拖动的滑动验证解法，学会用打码平台处理点选验证码，并能用 stealth.min.js 规避 Selenium 侦测。（after steps 3–4）

## Lesson

Selenium 是浏览器自动化的核心工具。当 requests 拿不到动态渲染的页面内容、或者网站需要登录才能访问时，Selenium 用代码驱动真实浏览器去执行点击、输入、滚动等操作，再通过 `page_source` 拿到渲染后的网页源码，实现“可见即可得”。

本节点从环境搭建开始，先让你能独立创建浏览器实例并完成基础操作；然后深入元素定位与节点交互，这是所有自动化脚本的基石；接着用 `execute_script` 执行 JavaScript 滚动页面、用 `page_source` 获取动态加载数据，这是 Selenium 爬虫的核心产出点；再进阶到动作链和页面等待，处理滑动验证码等复杂交互以及动态页面的加载时序；最后实战滑动验证码、打码平台登录，并掌握用 stealth.min.js 规避 Selenium 侦测的关键反反爬手段。
