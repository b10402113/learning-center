# 鏈式 Promise 與 AJAX 封裝

## Learning goal
用鏈式 Promise 拉平串行異步流程，並學會將回調風格的異步 API（如 $.ajax）封裝成 Promise 供鏈式消費。

## Lesson
Promise 的鏈式 then 透過在回調中回傳新 Promise 將串行異步流程拉平，並可將 $.ajax 等回調風格 API 封裝成 Promise 供鏈式消費，是閱讀現代加密網站異步請求鏈的關鍵。
