# Promise 語法與三狀態機制

## Learning goal
掌握 Promise 的三狀態（pending / fulfilled / rejected）與 `then` 雙回調的觸發條件，能閱讀並理解任何包含 Promise 的 JS 代碼。

## Lesson
Promise 是封裝異步操作的對象，擁有 pending、fulfilled、rejected 三種不可逆狀態，透過 then 的雙回調分別訂閱成功與失敗結果；掌握三狀態機制是閱讀現代加密網站異步請求代碼的基礎。
