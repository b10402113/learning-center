# 回呼地獄：串行異步的嵌套困境

## Learning goal
理解「回呼地獄（callback hell）」的成因——串行異步任務的嵌套寫法為何導致代碼右移、難以閱讀和維護，並體會 Promise 要解決的核心痛點。

## Lesson
串行異步任務若以回調函數逐層嵌套，代碼會向右偏移形成三角形結構，閱讀、維護與錯誤處理成本隨深度指數上升，這就是回呼地獄；Promise 的核心動機正是把這種嵌套拉平成鏈式結構。
