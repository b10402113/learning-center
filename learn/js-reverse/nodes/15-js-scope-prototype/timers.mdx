<LearningGoal>
能认出顶层 var/function 挂在 window 上、理解 setInterval/setTimeout 的行为与取消方式，定位网页中定时驱动的回调函数。
</LearningGoal>

## Lesson

顶层 var/function 挂在 window 上是探测全局状态的入口，setTimeout 延迟一次、setInterval 周期重复、clearTimeout/clearInterval 取消——网页中 token 刷新、心跳包等动态行为几乎都靠定时器驱动。
