# eval 与动态执行

## Learning goal

能识别 eval 将字符串转为可执行代码的运行机制，并在阅读混淆脚本时判断其调试与追踪影响。

## Lesson

eval 把字符串当作 JS 代码执行，eval 混淆里不论多复杂最终一定是一个字符串，逆向做法是把 eval() 里的内容单独执行还原出真实代码——动态生成的代码静态分析读不到，调试时只能对 eval 本身或还原后的代码下断点。
