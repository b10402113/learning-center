<LearningGoal>
能描述原型链查找、用 call/apply 改变 this、把箭头函数还原为传统函数阅读混淆代码。
</LearningGoal>

## Lesson

方法挂在 prototype 上让所有实例共享，实例沿 __proto__ 上行查找方法构成原型链，call/apply 改变 this 指向，箭头函数是普通函数的语法糖且 this 由外层决定——三者合起来是读混淆代码的三把钥匙。
