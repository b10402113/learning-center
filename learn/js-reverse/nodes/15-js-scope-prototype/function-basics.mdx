<LearningGoal>
能看懂 JS 函数声明提升、arguments 对象和返回值规则，判断函数调用的实际行为。
</LearningGoal>

## Lesson

JS 函数声明可提升、形参与实参个数不必匹配、arguments 接收任意实参、无 return 默认返回 undefined、逗号表达式返回最后一个值——掌握这些规则才能准确判断函数调用的真实行为。
