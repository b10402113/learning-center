<LearningGoal>
能区分全局变量与局部变量、理解 var 无块级作用域、识别全局变量污染并判断变量修改的影响范围。
</LearningGoal>

## Lesson

函数内 var 声明是局部变量、不写 var 赋值会改到全局、var 无块级作用域、同名局部变量会遮蔽全局——判断变量属于哪层作用域是读 JS 代码的基本功，全局污染则是闭包要解决的核心问题。
