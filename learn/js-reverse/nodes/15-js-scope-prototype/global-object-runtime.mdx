# window、globalThis 与运行时全局对象

## Learning goal

能区分浏览器的 window、Node 的全局对象与 globalThis，并据此判断抽取 JS 在不同运行环境中的依赖。

## Lesson

window 是浏览器专属的全局对象、globalThis 跨环境通用且浏览器里 globalThis === window、混淆代码常以 (function(w){...})(window) 把全局对象递进闭包——判断一段 JS 依赖哪个全局对象，是抽取后换到 Node/execjs 运行时补环境（window shim）的第一步。
