# 模组与网页基础

## Learning goal

理解模块导入与常用内置模块、HTTP 协议与 Cookie 机制、HTML 文档结构与常见标签，为后续爬虫与逆向分析打下基础。

## Steps

1. [[learn/js-reverse/nodes/02-modules-web/module-import|模块导入与 \_\_name\_\_ 入口判断]] — 理解模块的三种来源、import 与 from-import 写法，以及 `__name__` 如何决定入口文件与被导入模块的行为差异
2. [[learn/js-reverse/nodes/02-modules-web/common-modules|常用内置模块]] — 会用 time、random、os、json、re 完成爬虫脚本中的常见操作（after step 1）
3. [[learn/js-reverse/nodes/02-modules-web/http-protocol|HTTP 协议]] — 拆解请求报文与响应报文的字段，理解"无状态"的含义（after step 1）
4. [[learn/js-reverse/nodes/02-modules-web/cookie-basics|Cookie 原理与规范]] — 理解 Cookie 的工作流程与规范限制（after step 3）
5. [[learn/js-reverse/nodes/02-modules-web/html-structure|HTML 文档结构与常用标签]] — 认识文档骨架与表单、超链接、图片等常见标签（after step 3）
6. [[learn/js-reverse/nodes/02-modules-web/html-multimedia|HTML 多媒体标签]] — 认识 video 与 audio 标签的属性，理解如何从 HTML 提取多媒体资源的真实 URL（after step 5）

## Lesson

这一节把爬虫与逆向工具箱里的"基础零件"补齐：先复习 Python 模块的导入机制，再快速过一遍爬虫脚本里最常用的内置模块（time、random、os、json、re）；接着把视角从本地脚本转向浏览器与服务器之间的通信，理解 HTTP 的请求-响应模式、无状态特性，以及 Cookie 是怎么让服务器"记住"你的；最后落到网页本身，看一份 HTML 文档从 `<!DOCTYPE html>` 到表单、超链接、图片是怎么组装起来的。

走完这五步，你就能读懂一个爬虫脚本为什么这么写，也能在 DevTools 里看懂一次请求的来龙去脉——后面的 requests、xpath、session 节点都会反复调用这些基础。
