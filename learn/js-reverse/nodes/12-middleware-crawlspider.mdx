# 中间件、CrawlSpider 与分散式

## Learning goal

下载中间件、UA/代理中间件、CrawlSpider 全站爬取

## Steps

1. [[learn/js-reverse/nodes/12-middleware-crawlspider/middleware-basics|下载中间件核心概念]] — 理解下载中间件在框架中的位置、三个核心方法的作用，以及 spider 参数的数据交互机制
2. [[learn/js-reverse/nodes/12-middleware-crawlspider/request-middleware|代理、UA 与 Cookie 中间件]] — 掌握三类请求中间件的实现方式与全局代理的效率弊端（after step 1）
3. [[learn/js-reverse/nodes/12-middleware-crawlspider/selenium-response|中间件结合 Selenium 篡改响应]] — 掌握"Scrapy 调度 + Selenium 渲染"混合架构应对动态加载站点（after steps 1–2）
4. [[learn/js-reverse/nodes/12-middleware-crawlspider/crawlspider|CrawlSpider 全站爬取]] — 掌握 rules、LinkExtractor 与 Rule 配合方式，自动翻页爬全站
5. [[learn/js-reverse/nodes/12-middleware-crawlspider/distributed-incremental|分布式与增量式爬虫]] — 掌握 scrapy-redis 分布式改造流程与 redis set 增量式去重（after step 4）

## Lesson

本节点把 Scrapy 的"全局拦截"和"全站调度"两件事串起来。前半段聚焦下载中间件：它是引擎和下载器之间的拦截点，所有请求和响应都从这里经过。三个核心方法分别管请求、管响应、管异常，而 spider 参数让爬虫类和中间件能共享数据。基于这个机制，可以写出代理、UA、Cookie 中间件，也能在 process_response 里把动态页面交给 Selenium 渲染后再塞回给 Scrapy 解析。

后半段进入全站爬取：CrawlSpider 用 LinkExtractor 按正则或 xpath 提取链接，再用 Rule 对每个链接发请求并解析，从而自动翻页爬全站。配合 meta 传 item 的套路，可以完成"列表页提取 → 详情页补全"的深度爬取。最后，当单机爬取不够用时，scrapy-redis 提供可共享的调度器和管道，把 CrawlSpider 改造成多机协作的分布式版本；而 redis set 的去重能力，天然适合做只爬新增数据的增量式爬虫。
