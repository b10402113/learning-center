# JS 函式、作用域与原型

## Learning goal

闭包、作用域链、原型物件、箭号函式、定时器

## Steps

1. [[learn/js-reverse/nodes/15-js-scope-prototype/function-basics|函数基础：声明、arguments 与返回值]] — 函数声明提升、arguments 与返回值规则
2. [[learn/js-reverse/nodes/15-js-scope-prototype/scope-chain|作用域链与全局污染]] — 全局/局部变量、var 无块级作用域、全局污染（after 1）
3. [[learn/js-reverse/nodes/15-js-scope-prototype/closure|IIFE 与闭包]] — 匿名函数、IIFE、闭包私有状态（after 2）
4. [[learn/js-reverse/nodes/15-js-scope-prototype/prototype|原型物件与箭头函数]] — 原型链、call/apply、箭头函数（after 1）
5. [[learn/js-reverse/nodes/15-js-scope-prototype/timers|定时器与 window 全局变量]] — window 挂载、setInterval/setTimeout（after 1）

## Lesson

JS 函数是逆向工程里的“骨架节点”。你看一段 JS 代码，最先碰到的一定是函数声明、变量赋值和函数调用；但如果看不懂函数怎么声明、变量藏在哪一层作用域、方法挂在实例还是原型上，读混淆代码就会像走进迷宫。

这一节把函数基础、作用域、闭包、原型和定时器拆开讲一遍。前三个步骤沿着“函数声明 → 作用域 → 闭包”这条线往下走，让你理解为什么生产代码要把变量包进函数、为什么混淆器总爱用 `(function(){...})()` 把整段逻辑藏起来。第四步换到原型和箭头函数，前者告诉你“方法不在对象身上，而是在 `__proto__` 上”，后者教你把 `()=>` 还原成 `function(){}`。第五步落在定时器和 window 全局变量上，网页里周期性刷新的 token、指纹更新，几乎都靠 `setInterval` 驱动，而顶层声明的变量全挂在 `window` 上——控制台里一查便知。

五步走完，你应该具备三项基本功：读 JS 时能立刻判断“这个变量是哪一层的”、遇见闭包能指出“变量被哪个函数持有”、看见箭头函数能脑内还原成传统形式。后面 DevTools 断点和 sign 逆向都会反复用到这些能力。
