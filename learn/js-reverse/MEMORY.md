# MEMORY — js-reverse

## Goal
能夠獨立爬取需要登入驗證的網站內容，特別是已購買課程的字幕，並延伸作為自己模型的訓練資料來源。

## Why
已付費購買的課程內容應該能留一份本地副本，方便反覆觀看與筆記，不依賴平台在線；平台一旦下架或帳號出問題就沒了。後續想將各種網站內容作為自己模型的訓練資料。

## Prior experience
- Python 日常使用，但幾乎沒寫過爬蟲
- 用過 ChatGPT / Claude API
- 幾乎沒用過 requests / execjs
- 沒有 JS 逆向經驗

## Anchors
- 日常寫 Python
- 會開瀏覽器 DevTools（F12）看網路請求
- 重度 Claude 用戶
- 目標明確：爬登入後的網站內容

## Habits & constraints
- 每週 5–8 小時
- 晚上或週末學習
- Mac + Python 3 + Chrome
- 沒有硬性 deadline

## Knowledge type
程序性為主（procedural）—— JS 逆向不是靠背概念學會的，是靠動手：開 DevTools、設斷點、摳 JS、復現加密、跑通請求。

## How to teach me
動手優先：先講一個真實案例的完整流程（例如摳一個登入接口），再回頭解釋每一步背後的概念。不喜歡純概念灌輸，喜歡「先跑通再理解」。
