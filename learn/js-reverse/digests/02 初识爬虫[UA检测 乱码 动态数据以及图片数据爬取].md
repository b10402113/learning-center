## L2 — Section Detail

### 爬虫相关介绍
- [[sources/js-reverse/20260908/02 初识爬虫/课堂笔记/02 初识爬虫[UA检测 乱码 动态数据以及图片数据爬取].md#爬虫相关介绍]]
- 定义：爬虫模拟 B/S 或 C/S 架构中的客户端（浏览器）进行请求和数据获取
- 分类：通用爬虫（全页抓取）、聚焦爬虫（指定数据抓取）、增量式爬虫（监测更新并抓取最新数据）
- 矛与盾：反爬机制（网站侧阻止爬虫）与反反爬策略（爬虫侧破解反爬）

### 爬虫合法性探究
- [[sources/js-reverse/20260908/02 初识爬虫/课堂笔记/02 初识爬虫[UA检测 乱码 动态数据以及图片数据爬取].md#爬虫合法性探究]]
- 爬虫技术本身中立合法，但利用爬虫获取数据的行为存在违法风险
- 善意爬虫（如搜索引擎）vs 恶意爬虫（如抢票软件高频请求）
- 三大风险：违反网站意愿突破反爬、干扰网站运营、抓取受法律保护的数据
- 规避建议：优化代码避免干扰、审查抓取内容中是否含隐私/商业秘密

### 中国人事考试网（UA检测与UA伪装）
- [[sources/js-reverse/20260908/02 初识爬虫/课堂笔记/02 初识爬虫[UA检测 乱码 动态数据以及图片数据爬取].md#中国人事考试网（UA检测）]]
- User-Agent 是请求载体（浏览器/爬虫）的身份标识
- 反爬机制：UA检测 — 网站后台检测请求是否来自浏览器
- 反反爬策略：UA伪装 — 将爬虫的 User-Agent 伪装成浏览器身份
- headers = {'User-Agent': '...'} 传入 requests.get(headers=...)

### 中国人事考试网站内搜索（POST请求）

- 使用 requests.post() 发送 POST 请求，data 参数携带表单数据
- 需通过抓包工具定位数据包：提取 url、请求方式、请求参数、请求头

### 智慧职教动态加载数据爬取（重点）
- [[sources/js-reverse/20260908/02 初识爬虫/课堂笔记/02 初识爬虫[UA检测 乱码 动态数据以及图片数据爬取].md#智慧职教（动态加载数据爬取）**(重点)**]]
- 动态加载数据：不是直接通过浏览器地址栏 URL 请求到的数据
- 两种情况：请求数据包中无匹配 URL 的包，或有匹配包但不含目标数据
- 获取方法：用抓包工具全局搜索（Ctrl+F）定位数据包 → 提取 URL 和请求参数 → 模拟请求
- 请求头需携带 Referer（体现模拟浏览器力度）
- response.json() 获取 JSON 格式的字典/列表响应数据
- 分页爬取：循环 pageNum 参数实现多页数据抓取

### 图片数据爬取（二进制响应）
- [[sources/js-reverse/20260908/02 初识爬虫/课堂笔记/02 初识爬虫[UA检测 乱码 动态数据以及图片数据爬取].md#图片数据爬取]]
- 二进制数据（图片/视频/音频/压缩包）使用 response.content 获取
- 方式1：requests.get() + response.content + 二进制写入（'wb'）
- 方式2：urllib.request.urlretrieve() 直接下载保存
- 爬取图片需做 UA 伪装时使用方式1
