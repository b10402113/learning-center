# L1 overview

- Purpose — once a design system exists, keep growing it with new components instead of rebuilding visuals per project.
- Starting state — System X previously held only font guidance, color palettes, and line-art animations; one prompt added a split-view drag animation, a grid that reacts to the mouse pointer, and five typography hover interactions.
- Model choice — Fable is described as the most effective model for front-end design work at the time of recording.
- Timing tactic — when the weekly usage limit is about to reset and a lot of usage remains, spend it improving the design system rather than letting it expire.
- Prompt ingredients — direct the model at System X, invoke the `surprise me` skill to force a different approach, and invoke `/align` so the plan and placement are agreed before building.
- Output — answers to the alignment questions produce a single HTML page of the new components, which then becomes part of the design system for later builds.
