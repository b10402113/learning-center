# L1 overview

- Module framing — memory matters because using Claude Code, especially with skills, builds up context over time.
- Context defined — context is all the files added or created in your workspace folder.
- Cost of neglect — the growing pile of files eats tokens and usage limits unless memory is managed well.
- File cabinet analogy — memory is a file cabinet the AI agent can access; correct setup lets Claude Code retrieve the right folder when relevant.
- Two levels of memory — there are just two important files and two memory levels to be aware of.
- CLAUDE.md — the employee handbook that sits at the top of the cabinet.
- MEMORY.md — the bigger drawer holding the agent's longer-term memory, i.e. the rest of the cabinet.

# L2 detail

- `#L1-L46` — Module introduction: heavy Claude Code and skill use builds context, context means every file added or created in the workspace folder, and an unmanaged pile will consume tokens and usage limits.
- `#L47-L76` — The file cabinet mental model: the agent has access to a cabinet; everything built and all worked-with context gets filed there, and proper memory lets Claude Code retrieve the right folder at the right moment.
