# L1 overview

- Design systems — the concept that controls look and feel; turns a generic "vibe coded" site (blue gradients, default font) into something custom.
- `/robo` — the author's internal design system skill, shared below; one prompt redesigned the skeleton with the Dodo font, a dot matrix visual on the side, and no generic AI look.
- Taste — to make your own design system you must develop taste, which comes from seeing many examples and picking the elements that inspire you.
- Design systems toolkit — 35 complete, fundamentally different websites to pick from and iterate on: a security-posture site with background animation, a voice AI agency template with animated cards, a minimalist style, an e-commerce system, and personal favorites.
- Color palette toolkit — references for well-known brands including Apple, Airbnb, Uber, Starbucks, and PlayStation, plus dozens more, with palettes and design-system building blocks.
- Make your own — clone the toolkit, open a design (e.g. "data poem"), click copy reference, optionally combine with another palette (e.g. Airbnb), then create a skill named design system X holding both references.
- Skill as hub — the design system skill systematizes the aesthetic and later becomes the store for reusable components, pricing blocks, and animations; `/robo`, for example, holds the agency pricing components used across the author's materials.
- Apply it — point Claude at the HTML page path, invoke design system X, and ask it to improve the look; result is a more professional, brand-consistent page.
