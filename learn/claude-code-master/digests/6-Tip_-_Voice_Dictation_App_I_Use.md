# L1 overview

- Voice prompting is unreasonably effective: speaking to AI agents is roughly three times faster than typing prompts.
- Many AI apps already include a record button that transcribes speech directly into the prompt.
- On Windows, pressing Windows key + H opens the free Microsoft speech service, which transcribes across any app.
- The author personally uses Aqua Voice (aquavoice.com), a paid tool that is cheaper than the more popular Wispr Flow: about $8/month for Pro, with a free tier.
- Dedicated dictation tools add a custom dictionary for correcting recurring mispronunciations (e.g. AI terms), a keyboard shortcut, and an on-screen text box for continuous transcription.
- Tool choice is a preference; alternatives are linked below.
