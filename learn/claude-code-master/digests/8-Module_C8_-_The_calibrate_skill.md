# L1 overview

- The skill — `calibrate` is a personal skill run at the end of almost every session.
- What it does — it reviews the session, spots where the user corrected or gave feedback, folds those lessons into memory, and suggests skill updates.
- Rationale — talking to Claude Code like a teammate should end with the teammate calibrating from the conversation to improve its practice.
- Worked example — a `recording` skill fetched a YouTube transcript and auto-generated timestamps for an hour-long community session.
- Immediate application — calibrate updated both the recording skill and memory so the next session on that topic starts smarter.
- Compounding effect — initial skills plus growing memory plus a calibrate run per session build an agentic operating system tuned to the user's setup.
- Framing — the result behaves more like a teammate than a chatbot such as ChatGPT; the speaker offers the skill in the resources and suggests personalizing it.
