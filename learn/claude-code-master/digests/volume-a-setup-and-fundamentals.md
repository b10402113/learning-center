# L1 overview

**Volume A — Setup and Fundamentals** (8 modules, slide text only, no transcripts). Gets a beginner from nothing to a working, understood Claude Code setup. Covers: the three surfaces it runs on; the VS Code setup; how pricing/tokens/usage limits work; the context window and compaction; the four model tiers; permission modes; effort levels; and GitHub as the source of agent tools.

- **A1 Three Surfaces** — Claude Code runs in the desktop app, the VS Code extension, and the terminal; same model + harness underneath, so pick by comfort. Desktop = least intimidating but most limited; VS Code extension = the presenter's pick (run several agents side by side).
- **A2 VS Code x Claude Code Setup** — install the extension, open an empty folder as workspace, run setup to build starter files, edit CLAUDE.md so the agent remembers your context (name, location) every session. The folder becomes your "operating system / second brain."
- **A3 Pricing and Usage** — free / pro / max plans; what a token is; read remaining usage (session, weekly, Sonnet limits) with the usage command. Start on pro, move up only when work demands.
- **A4 The Context Window** — the window is the agent's "desk"; context rot when it fills; compaction summarizes long chats to free room; how to check usage to know when to compact or start fresh.
- **A5 Models** — four tiers: Haiku, Sonnet, Opus, and the newer "Fable" tier; cost rises with capability; a sensible default per plan; the catch of API pricing once you hit limits (subscription beats API).
- **A6 Permission Modes** — five modes from ask-before-edits to bypass; two hidden by default (unlock in settings); auto mode is the sweet spot (checks in before risky actions, moves fast otherwise).
- **A7 Effort Levels** — effort = the thinking budget per prompt; low-vs-max demo; mid/high is plenty for most knowledge work; "ultra code mode" spawns a fleet of agents for broad tasks.
- **A8 GitHub for Agents** — GitHub is becoming the "Google Drive for agents"; install a tool by pasting its GitHub link; the personalize skill vets fit; use Star History to find trending tools. You don't need to be a developer.
