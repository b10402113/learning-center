# L1 overview

- Automatic filling — on recent Claude Code versions MEMORY.md fills itself automatically when Claude deems a conversation worth keeping.
- No prompting needed — it may write to memory.md on its own without a user request.
- Steering — you can still ask Claude Code in natural language to remember a specific nugget or fact about you, and it writes it to memory.
- Manual edits discouraged — the speaker advises against editing these memory files by hand, since having the agent review and edit its own markdown is more efficient.
- Auto memory logging — enabled by default on the latest Claude Code; in VS Code, `/memory` directs you to the terminal, which opens Claude Code there.
- Toggle — the memory settings let you turn auto memory off or on, and on is the default.
