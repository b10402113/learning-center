# L1 overview

- Phase four of the Craft framework — "firing it up": deploy the local HTML build with Vercel, a free tool that ends every deployment on a `.vercel.app` URL; custom `.com`/`.io`/`.ai` domains need a separate guide, and login-gated builds go through the other classroom lessons.
- Deployment workflow — ask Claude to deploy to Vercel with a chosen slug (`robonuggetsagencyxdemo.vercel.app`); Claude installs the Vercel CLI, returns a browser link to log in, and after that can deploy whenever asked.
- Small Vercel file — a short reference file teaching Claude the deployment steps, plus a linked guide for custom TLDs.
- Result — the Agency X site goes live in seconds with both the front end and the working contact form, ready to hand to prospective clients.
- Phase five (final) — have Claude document the whole build as a skill: prompt for a `website creation` skill capturing clear steps, corrections, and feedback; invoke `/align` and ask for about three questions on a simple skill, more on important ones.
- Rubric Flows — a visual layer inside the author's agentic operating system that renders a skill's steps as an interactive workflow, useful for showing clients the process; Claude can also connect to it and simulate the steps.
- Key principle — for any large build, write a skill and a repeatable process so the next run starts strong; skills are just Markdown files, so visualizing them is how you present the process to clients and colleagues.
