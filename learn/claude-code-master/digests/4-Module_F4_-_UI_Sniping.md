# L1 overview

- UI sniping — a technique for making a site more visually stunning beyond what the design system alone provides.
- 21st.dev — a bookmarkable library of well-built pre-built components (3D robot view, globe animation, buttons for apps) shared by the world.
- Sniping from a library — search a component type (e.g. testimonials), copy the prompt, paste it into the Claude session, and ask it to include the component, choose an appropriate place, and adopt the existing design system.
- Robo Capture — a custom Chrome extension that lets you click and capture specific UI elements (e.g. an SVG block) from any website into a clipboard-ready script.
- Reference sites — recent.design is recommended as a constantly updated source of well-designed websites; other inspiration links are provided below the lesson.
- Capture workflow — open the extension, click target elements, remove unwanted picks, copy, then tell Claude to treat the capture as design inspiration and rebuild it according to the design system for the client.
- Installing the extension — go to `chrome://extensions`, enable developer mode, click load unpacked, and point it at the downloaded RoboCapture folder.
- Outcome — the captured animation became a new "every agent drawn to spec" section on Agency X that walks through the steps the agency follows.
