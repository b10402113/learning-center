# L1 overview

- Create phase — the "C" in the Craft framework, meaning build the front end: the visible design without underlying functionality.
- Three steps — plan the sections, improve the look with a design system, then make it visually stunning; the same steps apply to non-website software.
- Research first — ask Claude to research best practices for the kind of site being built before deciding what sections to include.
- Planning prompt — Agency X, an AI solutions agency that builds automations and agents for clients; research the best agency and service sites to include in 2026 and return a final section list.
- Visual plan — the `/HTML` skill renders the section plan as an HTML page for easier review; removing that line makes Claude return the plan as chat text instead.
- Section choices — the plan returned 12 sections (hero, trust bar, problem framing, solution); for a first agency site, drop sections you cannot fill, such as hard-number case studies or interactive proof like an ROI calculator or live demo agent.
- Skeleton build — one-page Agency X site with hero, trust bar, services, what we build, pricing, FAQs, and final CTA.
- Review gate — the default output is generic on purpose; check the copy, that buttons work, and that the chosen sections are actually present before moving to the design system.
