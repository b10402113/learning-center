# L1 overview

- Three elements of every agent platform — model (engine/brain), harness (Claude Code's system prompts and files that let the model use tools and edit files), and context (your workspace); the model and harness are shared by everyone, so context is the only differentiator.
- Agent as digital employee — the model and harness are the engine and body the employee arrives with; everything you set up is their workspace, a folder such as `Robo` holding business code, automations, images, and videos.
- Context as operating system — a properly engineered workspace becomes the base layer all business and personal work runs on; Claude Code is the first thing opened on the device and the all-in-one teammate used hourly.
- ARMS framework — Applications, Routines, Memory, Skills; named for the acronym and for giving agents "arms" to reach into your workspace and contacts.
- Workspace analogy, pillar by pillar — Applications are device/app access, Routines are the calendar of recurring tasks, Memory is the filing cabinet of past conversations and projects, Skills are the notebook of recipe cards for specific tasks.
- Bottoms-up build order — skills first (foundational quality), then memory (knowledge base), then routines (automation at an expected quality level), then applications (tools connected so agents work 24/7), and finally your own applications.
