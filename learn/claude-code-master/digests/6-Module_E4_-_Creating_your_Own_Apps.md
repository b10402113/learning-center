# L1 overview

- Shift in scope — earlier modules connected pre-existing applications to Claude Code for automation; agents can also create applications for you.
- What you can build — a Chrome extension or custom business software can be requested from the agent directly.
- What the optional lessons cover — the build process in detail, plus a view of "rubric," an internal tool used to give a more visual layer for working with these agents.
- Advantage of building your own app — you control the connection between Claude Code and the app, which is usually much easier than relying on third-party tools.
