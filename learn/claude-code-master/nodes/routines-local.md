# 怎麼讓工作在你不在時自己完成

## Lesson

routine 就是 Claude Code 在你不在時自己跑——而它排在 ARMS 第三，是因為要先有 skills 和 memory，自動化才不會產出「差一點」的東西。這一課帶你建第一條 local routine：用聊天描述你要什麼、把 skill 折進去、檢查第一次跑、再排時間，之後用白話打開最近一次 session 就能優化。限制也很清楚：只有在你電腦醒著時才會跑。
