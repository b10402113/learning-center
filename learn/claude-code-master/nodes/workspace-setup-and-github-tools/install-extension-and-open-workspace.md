# 我的 VS Code x Claude Code 設定

這門課預設你是在 IDE 裡用 Claude Code，不是在 terminal 裡。講者說得很直接：他最習慣的方式是透過 IDE（integrated development environment，整合開發環境）來用 Claude Code，而他挑的是 VS Code。VS Code 是開源的，也就是免費，下載就能裝。

所以起步只有兩件事：把 extension 裝起來，然後開一個資料夾給它。下面照順序走一遍。

## 裝 extension，圖示沒出現就按右鍵

VS Code 裝好之後，點左邊的 extensions 分頁，找到 Claude Code —— 認明 Anthropic 出的那個 —— 按 install。

裝完，左側側欄會多一個 Claude Code 圖示。如果你沒看到它，不用重裝，也不用去翻設定。在左側側欄按右鍵，清單裡找 Claude Code，點一下就會切換那個圖示的顯示與否。

<!--image:1-->

點開圖示，畫面應該會讓你覺得眼熟：可以開一個新 session，直接開始對話。用過 Claude 桌面版，或任何 ChatGPT 那類聊天介面的人，這裡的操作邏輯是一樣的。

## 先開資料夾，再開始聊

在跟 Claude Code 講第一句話之前，講者建議先去 explorer 分頁，實際開一個資料夾。

任何資料夾都可以。但如果你是完全第一次用，他建議挑一個空資料夾。

他自己示範的那個資料夾叫 `my workspace`，選下去之後，左邊的 explorer 就會列出那個資料夾裡的所有檔案。因為是空的，所以什麼都沒有。

這個「什麼都沒有」不是這一步的副作用，是這一步的重點。

## 空資料夾是一個邊界，不是一個佔位

現在它是空的，但課程往下走，這個資料夾會被填滿：你自己的 context，還有 Claude Code 產出的工具與輸出，都會存在這裡。

走完整套課，它基本上就是你自己的 operating system，或者說第二個大腦。當你把 Claude Code 當成一個隊友、甚至當成一整隊 AI agent 在用，這個你選的資料夾會慢慢長成你目前事業的所有文件——帳單、產出、各種連線、這門課會走過的每一個工具。

所以 workspace 不是 Claude Code 幫你挑的暫存區，是你指定的邊界。它看得到什麼、產出的東西放哪裡，都以這個資料夾為準。這也是為什麼第一次用要挑空的：邊界乾淨，你才知道後來長出來的東西是從哪來的。

## 左邊那欄是真的資料夾

空資料夾選好之後，左邊 explorer 會顯示這個資料夾裡的東西，空的就顯示空的。這裡有個容易誤會的地方值得先確認一次。

在 explorer 上按右鍵、選 reveal in File Explorer，它會直接打開你電腦上的檔案總管。你在那裡看到的，就是硬碟上實際存在的那些檔案——不是 VS Code 自己另外複製的一份，也不是雲端上的鏡像。

<!--image:3-->

現在檔案很少。但你用得越多，這裡就會被你的 context 填滿，而 Claude Code 正是拿這些 context 去幫你做出結果。知道左邊那欄對應的是硬碟上哪個資料夾，之後要備份、要搬移、要確認東西有沒有真的存下來，你才有地方看。

## 順手把 VS Code 用成多視窗

最後一件不是安裝動作，但一樣屬於「把 workspace 準備好」：VS Code 可以同時開多個分頁，而且這些視窗可以拖放，讓它們並排在你想要的位置，同時執行、同時預覽檔案。

現在看起來只是方便。等你開始同時操作多個 agent，這會變成一個很有力的功能。

資料夾開好、邊界確定之後，下一個動作就是讓這個空資料夾長出第一批檔案，也就是跑一次 `/init`。
