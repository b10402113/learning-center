# 模型、思考力度、放行程度怎麼調

## Lesson

session 裡有三個即時旋鈕：用哪一層模型（Haiku／Sonnet／Opus／Fable）、花多少思考力度（effort）、以及放行到什麼程度（permission mode）。這一課讓你能依任務選對這三個值，並延伸到排程情境——把簡單工作的模型往下換，直接省 token。
