# MEMORY.md、自動記憶與 calibrate

## Lesson

MEMORY.md 不是把所有記憶塞進一個檔，而是一個索引，指向一個一個 artifact。自動記憶會自己寫，`/calibrate` 則負責把 session 裡的修正變成下一次的預設。
