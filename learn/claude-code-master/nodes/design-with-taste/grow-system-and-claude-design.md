# 讓系統長大：加互動元件，順便看 Claude Design

到這裡，一頁網站已經有骨架、有自己的視覺語言、有好元件，也補上了素材。但過了兩、三個星期，你可能開始覺得有點單調：每個新頁面都用同一批按鈕、同一種卡片，整個網站像同一個模板，只是換了顏色。

Module F7 處理的就是這種情況。它沒有要你重做整套系統，只教你一次加入一個有特色的新元件，讓設計系統慢慢長大。

## 一個 prompt，三種互動元件

課程示範的是在 Design System X 裡加入新的互動元件：可拖曳、調整左右畫面的分割版面（split-view drag）、可操作的網格（interactive grid），以及五種文字排版動畫（typography animations）。

這些不是換個顏色、改個圓角就算了的改動。它們有互動感，會讓人想停下來試玩。

重點在這裡：它們沒有一個是手刻的，全部由同一個 prompt 產生。

<!--image:1-->

這個 prompt 沒有停在「幫我做一個拖曳元件」這種單一要求，它從比較高的層次描述需求：依照現有系統的規格，產出一批新的互動元件。你需要準備的內容大致包括：已經對齊的設計方向、要新增的互動類型與數量，以及哪些風格要避開，免得新元件長得跟現有的一模一樣。

系統愈完整，這一步就愈有效：agent 有現成的規格可以參照，不必從空白開始猜。

## 讓它不要每次都給你同一種答案

同一句 prompt 打三次，通常會得到三個很相似的結果。這是 agent 的預設行為，不代表它偷懶。

課程提供兩個 skill，幫你調整產出的方向。

`/align` 會在開始動手前先問幾個問題，確認彼此對方向的理解一致。這對新增互動元件特別有幫助，因為「好看的互動」沒有標準答案。先把方向談清楚，比做完才整個重畫省事得多。

`/surprise-me` 則反過來，會要求 agent 換一種做法，試著產出更新鮮的結果。如果你發現成果開始有固定的樣子，就可以試試它。

兩個不用同時開。要收斂用 `/align`，要擴散用 `/surprise-me`。如果你只是希望這次的結果跟上次不一樣，先確認自己要收斂還是擴散，再挑一個 skill。

## 用剩下的額度做這件事

課程特別建議，可以在每週用量重置前，用 Fable 5 來做這件事。

原因很直接：新增互動元件屬於加分項目，不是上線前一定要完成的工作。它需要模型多花心力發想，也可能一次產出好幾個版本供你挑選。這種工作就適合排在額度快用完、又不想浪費的時候。

重置前跑，等於把原本會歸零的容量，換成能留在系統裡的成果。

<!--image:3-->

反過來說，如果你正趕著出貨，額度也不寬裕，就先別做這件事。那時候該收斂，不是再加新東西。

## Claude Design 在哪裡

第二段素材是 Bonus：Claude Design。這是 Anthropic 為前端工作打造的視覺工具，目前仍在 beta 階段。

它換掉的是工作的方式。原本的流程是「你輸入 prompt，agent 寫程式，你再看結果」；Claude Design 把中間那一段變成視覺操作：先在畫面上看、調到想要的樣子，再交給 coding agent。

<!--image:4-->

大致可以這樣分工：

- 需要判斷、調整結構或撰寫邏輯時，留在 chat 裡處理。
- 需要直接查看、比較顏色和版面，或快速嘗試幾種視覺方向時，使用視覺工具。

課程認為，Claude Design 之後很可能會和 coding agent 接在一起。那才是值得期待的地方：你在視覺工具裡調整好的內容，可以直接成為 agent 的前端工作介面，不必再用文字說明「左邊再往下一點」。

所以就算它現在還在 beta，也值得先試用看看。等工具真的整合起來，你就不會是第一次打開它。

## 你現在可以做的

在 Design System X 裡開一個新 branch，照以下順序試一次：

1. 先用 `/align` 確認方向：這次要加入拖曳版面、互動網格，還是文字動畫？
2. 寫一個 prompt，說明要做的類型和數量，並清楚註明「不要長得像現有元件」。
3. 產出後只留下其中一到兩個，其他先捨棄。練習挑選，也是這一步的重要部分。
4. 找個空檔試用 Claude Design 的 beta，先熟悉視覺工具的樣子。

設計系統會變好，靠的是隔一段時間就多一個真的用得上的元件，而不是一次灌進十個。課程把這件事叫「長」，不叫「補齊」。
