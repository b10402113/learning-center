# 為什麼同一個模型，別人做得到你做不到

## Lesson

這一課先立起整門課的心智模型：每個 agent 平台都只是 model、harness 加上你自己的 context，前兩者人人相同，真正的差距只在 context。接著用 ARMS（Applications、Routines、Memory、Skills）這張地圖，指出後面每一冊在補哪一層，讓你之後做的每件事都能掛回這張圖。
