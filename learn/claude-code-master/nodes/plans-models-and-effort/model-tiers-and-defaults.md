# 這個選擇沒有標準答案

你打開 Claude Code 的模型選單，看到四個名字：Haiku、Sonnet、Opus、Fable。真正的問題不是「哪個最強」，而是「今天一整天，我預設要用哪一個」。

這個選擇的代價不是速度，而是額度。選得太重，你的 5 小時 session 額度可能下午就見底。

## 原本三個，現在四個

Anthropic 的模型原本總共只有三個：Haiku、Sonnet、Opus。現在多了第四層，叫 Fable。

切換不用改設定檔，在指令列就能自由換，四個模型直接來回選。

## 一條線分四層

區分這四個模型的方法很簡單。Haiku 是四個裡面最不吃 token、也最便宜的，但它同時最不強。

往右移，能力上升，成本也上升。

<!--image:1-->

所以這不是四個各自獨立的好選項，而是同一條光譜上的取捨。你付的每一分錢，買的都是往右邊挪一格的能力。

## 成本要分輸入和輸出看

先看一個具體數字：Fable 每一百萬 token 的 input 要 $10。

input token 指的是你送給 agent 的 prompt。output token 是回覆的訊息、思考、tool call，也就是 agent 為了回答你、在背後做的所有事。輸入通常比輸出便宜很多，所以看價格時不能只看一個數字。

把四個模型的相對關係排開更清楚：Fable 剛好是 Opus 的兩倍貴；Opus 比 Sonnet 貴將近 60%；Sonnet 又是 Haiku 的三倍。

價差是倍數在跳，不是加一點點。

## 每天的預設怎麼挑

只訂 Pro 方案的話，先把 Sonnet 設成預設。原因很實際：如果你用 Opus 或 Fable 當每天的主力，很快會撞到 rate limit，也就是 5 小時 session 或每週 session 的 token 用量上限。

<!--image:3-->

Max 方案則可以直接把 Opus 設成預設。

講師自己的做法是預設 Opus。Fable 因為是新出的，他也正在試，想看它跟上一層的 Opus 差多少。

Haiku 他幾乎不當預設。但如果你一直撞 rate limit，很值得考慮降級到 Haiku，至少用在很簡單的任務上，看看工作流程會不會順一點。

## 什麼時候真的會付到這些錢

有個大前提：如果你訂的是月費方案，你其實不會直接付這些 token 費用。訂閱方案相對這些價格，補貼得多很多。

這些每百萬 token 的價格，一是你把模型用在 Claude Code 之外時的實付價，例如自己開發應用；二是你撞到 rate limit、還想繼續用時要付的價。

做法是到帳號的 settings → usage，往下拉，可以開啟 usage credits，額度用完後繼續使用。

但這裡有個大雷：開啟之後，你付的是 API 價格，也就是上面那組數字，比訂閱方案貴得多。

<!--image:4-->

## 先選一個，再調整

這件事沒有正確答案，取決於你做的是哪種工作。

但如果要一個起點：Pro 就 Sonnet，Max 就 Opus。真的撞牆了，再把簡單任務丟給 Haiku。

明天打開 Claude Code 之前，先想一下今天的活值得用哪一層。

還有一種情況會讓你直接碰到這張價目表：額度用完、打開 usage credits。那個開關後面的算法值得單獨看一次。
