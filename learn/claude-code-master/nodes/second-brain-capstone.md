# 把整個 workspace 變成你的第二大腦

## Lesson

這一課把前面所有層收束成一個成品：一個讓整個 workspace 可搜尋、視覺化、又更便宜的第二大腦。你會走一遍 applications／routines／memory／skills 四層怎麼互相扣合，看一場實測示範它回答起來比預設便宜約四成，最後拿到一份可匯入的模板，把它套到你自己那堆檔案上。
