# 把 workspace 當作業系統（ARMS）

## Lesson

Model 與 harness 是每個人共用的，只有 context（你的 workspace）是差異化來源。ARMS 把 workspace 拆成 Apps、Routines、Memory、Skills 四層，並給出由下往上的建置順序。
