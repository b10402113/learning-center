# 怎麼做出「不像 AI 生成」的網站

## Lesson

在 AI 時代，前端品味才是真正的差異點，別再交那種一眼就看出是「vibe-coded」的網站。這一課走 CRAFT 的前半段：先研究該有哪些區塊並用 `/html` 把計畫視覺化預覽，再用設計系統把 AI 味洗掉，用 UI Sniping 拆別人做好的元件、用 `/tweak` 拉滑桿即時改，最後接 AI 生圖補素材。
