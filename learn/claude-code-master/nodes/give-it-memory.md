# 怎麼給它一個跨 session 的記憶

## Lesson

沒有記憶，每個 session 都從零開始，你得一再自我介紹。這一課把 memory 當成一個檔案櫃：CLAUDE.md 是每次開場都讀的員工手冊（身分、目標、規則、workspace 地圖），有專案與全域兩份；MEMORY.md 則是一份短索引，指向你實際建出來的記憶檔。你會用 `/init` 讓它自己起草 CLAUDE.md，並認識會自己長大的自動記憶。
