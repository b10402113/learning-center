# Context Window：一張會越堆越滿的桌子

你有過這種感覺嗎：同一個 session 從早上聊到下午，前面幾輪它答得又快又準，後來開始抓錯重點、重問你已經講過的事，甚至翻回早就放棄的方向。你以為模型變笨了，其實是它桌上沒位子了。

課程把 AI agent 想成你的數位員工：你替它準備一張自己的桌子。**Context window 就是那張桌子。** 你每跟它講一次話，桌上就多堆一疊紙；聊得越久，桌面越滿。

<!--image:1-->

## 一張桌子，一個數位員工

這個比喻好用，是因為它同時講了兩件事。第一，桌子是「這個員工當下看得到的全部」——沒放在桌上的東西，它不知道。第二，桌子有面積，不是無底洞。

## 桌子有硬上限

桌面的極限是用 token 算的。Token 是模型讀文字的最小單位，你可以先把它想成「字數的粗略單位」。一張桌子能放多少 token 是固定的；一旦放到那個上限，這個 session 的對話就滿了。

在 Claude Code 裡切換模型就看得到這件事。Opus 的 context window 是 100 萬 token。100 萬聽起來很抽象，課程給了一個換算：大約等於七本《哈利波特》並排放在一起的長度。

但再大也是數字。100 萬 token 就是 100 萬 token，不是無限。

<!--image:2-->

## 對話本身就在吃掉桌面

真正會讓人意外的是，桌面消耗得比想像中快，而且不是只有你打的字在吃。

課程示範了一輪很普通的來回：你送出的 prompt 大概五個 token，它回你一段大概兩百 token。你打的那五個字很小，回你的那兩百 token 是它的四十倍。而這只是一輪。整段對話裡每一輪的輸入和輸出，都留在桌上。

所以，「這段對話還很新鮮」跟「桌上還有空間」是兩件不同的事。

## 在你開口之前，桌子已經被佔掉一角

打開 `/context`，你會看到一個比例圖。課程的畫面裡，紫色區塊只佔了 7,000 token 左右，那是你實際打的字和它給你的回覆。但其餘那一大塊，在你還沒講第一句話之前就已經用掉了。

原因是每個 Claude Code session 一開始就帶著東西進來：Anthropic 寫在 harness 裡的 system prompt，加上一組 system tools，兩者你都不能改；除此之外還有你的 memory 檔案和 skills。

把這些加起來，在你還沒開口之前，桌子就已經被佔掉兩萬到兩萬五千 token 左右；workspace 越大，這個數字還會更高。

<!--image:3-->

換句話說，你以為的「一百萬」，實際能用的從來不是一百萬。

## 滿了怎麼辦：compaction

桌子滿了，總得有東西讓位。Claude Code 的做法是把比較舊的內容 summarize 掉，這個過程叫 compaction。它把前面那一大段對話壓成摘要，空出桌面給後面的事。

你也可以自己按 `/compact`。它做的事，是讓 AI 把整個 session 的文字看一遍，自己給自己一個 prompt 去摘要。課程示範了兩種情況：一個 session 訊息太少，`/compact` 直接拒絕，因為沒什麼好壓；另一個 session 建過 landing page、累積了不少內容，按下去之後整段對話被壓縮，模型就能再塞進更多東西。

也有不用你動手的版本：session 一路跑到接近上限，它會自己 compact。

## 比「滿」更早出現的問題：context rot

如果問題只是「滿了再壓」，那還算好處理。麻煩的是桌子還沒滿，品質就先掉了。課程把這個現象叫 context rot：同一個 session 跑得越久，它會明顯地變笨。

<!--image:4-->

原因不難懂。桌上堆的東西裡，有一部分已經沒用了：走過但沒走通的路、過期的細節、早就修掉的錯誤。它們不會自動消失，還會跟真正有用的資訊搶位置。模型要從一堆雜訊裡撈出你要的那一句，就越來越吃力。

課程用了找書的比喻：你要找的是第 10 章的那個主題，它卻翻到第 2 章給你。不是它不聰明，是這一整段對話已經太長了。

## 什麼時候該看、該壓、該重開

實際做法可以簡化成三個動作。

不確定還剩多少空間，打 `/context` 看比例。開始覺得它抓錯重點、重問已經答過的問題，打 `/compact` 把舊內容壓掉。如果壓完還是覺得它不在狀況內，那通常不是空間問題，而是這段對話的累贅太多——開一個新的 session，把真正需要的前情提要帶過去，會比繼續搶救快。

課程也提醒不要過度緊張。現在的模型本身夠好，而且還在變強，多數時候可以讓 session 自然跑，等到你明顯感覺到 context rot 再處理就好；真的跑到上限，它自己會 compact。

還有一個讓人放鬆的事實：context window 一直在變大。就目前的產業狀況來說，它已經不是大多數人最大的阻礙。但那是之後的事，今天你手上這張桌子，還是會滿。

而真正更常咬你的，不是桌子滿，是桌子還沒滿它就先亂了。下一篇專門講這件事。
