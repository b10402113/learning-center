# 把環境架起來：介面、花費、工具去哪拿

## Lesson

從「什麼都還沒設定」開始，這一課把日常操作的底盤架好：在三種介面之間選一個、開一個資料夾當 workspace、看懂方案與 token 用量，並知道去 GitHub 把工具裝進來。也順手學一個立即可用的加速器——語音輸入，讓你之後每一步都能真的在自己機器上跑起來。
