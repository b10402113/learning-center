# L1 overview

- `README.md` + `CHANGELOG.md` — kit 是課程買家的 ZIP，不是公開 repo；README 用一張表把 M0–M8 對到檔案，並列出課程依賴的四個公開 repo（`ticket-bay`、`skills`、`quicke2e`、`brain-template`）。CHANGELOG 逐日記錄修正與「Last verified」版本。學習者在意的是：每個模組的材料在哪、怎麼更新，以及哪些坑已經被前一批學生踩過。
- `m0/setup-guide.md` — 從空機到「TicketBay unit tests 綠 + 課程技能裝好」的 agent 可執行指南：費用路徑（Minimum / Full / Free）、作業系統、git / python3 / jq、Node 22、Docker、GitHub CLI、Claude Code、fork + clone、unit / integration tests、十個課程 skills、Discord。每一步都有 **Done when**，🙋 步驟交給人類。學習者得到一個可重現的 baseline，也看到「技能要裝進專案 `.claude/skills/`，不是 global，否則 box 看不到」這類環境邊界。
- `m1/map.md` + `map.png` — 七層地圖：model、prompt、context、harness、memory、loop、boundary；每個模組都落在其中一層。核心句是「agent = model + harness」，失敗時先找壞掉的那一層。學習者用它建立診斷框架：更好的 prompt 不會修好缺測試或爆掉的 context window。
- `m1/reset-rules.md` — 四個 context 習慣，對應 select / compress / isolate / offload：一個 session 一個任務、點名檔案、研究交給 subagent、同一個問題修正兩次就寫 handoff 再 `/clear`。附 reset 徵兆與 `/compact`。學習者把「context 是有限資源」變成可操作的四個動作。
- `m1/box-setup.md` — `./box` dev container 的啟動與驗證：只掛載這個 repo 加短網路 allowlist，課程在 box 內用完整權限跑 agent；`./box` 會背景保留、有自己的 node_modules 與 Claude 登入。Verify 表檢查「沒有 SSH 私鑰、`example.com` 被防火牆擋、`npm ping` 通過、`git ls-remote` 可用」。學習者看到 boundary 層的具體實作。
- `m2/five-hooks/` — 五個 hook 加兩個 bonus：`block-dangerous`、`protect-secrets`、`test-gate`、`fast-feedback`、`session-context`，加上預設關閉的 `protect-test-config` 與通知用的 `notify`；同時給 Claude Code `settings.json` 與 Hermes `config-hooks.yaml`。學習者理解：寫在檔案裡的規則只是建議，hook 才是每次都會執行的 gate，而 pattern guard 有誠實的極限。
- `m6/add-mcp-server/` — 一個 skill，讓 agent 對「你自己的 app」加 MCP server：先跑 `assess-app.sh` 盤點，提出工具清單並**停下來等人批准**，再做 stdio、Streamable HTTP、每人一把 API key、docs-search、key 上的 toolset，最後四項安全測試。附五份 reference 與 TicketBay 端到端範例。學習者看到 MCP 是「產品動作的窄介面」，不是把 API endpoint 包一層。
- `m7/routine-guide.md` — Claude Code 雲端 routine：每小時把專用 bug inbox 的最舊未處理信件變成 PR。內容包含 claim label、AGENTS.md 事實、`guard-network.sh`、deny WebFetch/WebSearch、Discord webhook、cloud environment allowlist、完整 routine prompt、五個驗證測試與 hardening 理由。學習者得到一個可審核的無人值守 loop，也看到「green run 只代表 session 跑過」。
- `m8/hermes-guide.md` + `m8/config-pack/` — 24/7 coding employee：Hermes gateway 跑在 host，指令進 rootless Docker sandbox；含 model 登入與 fallback chain、approvals、SOUL、memory、skills、hooks、MCP、Discord、bug inbox、cron bug loop、晨間 PR triage、每日 pull、brain 同步與大量 traps。`config-pack` 是可合併的 config 片段、Dockerfile、cron、工具、prompt、hook 與 systemd unit。學習者看到 host / sandbox 分層、秘密存放位置與營運細節。

- `#L1-L65` — `m1/box-setup.md` — 目的：啟動 TicketBay 的 `./box` 並通過 lesson 1.9 檢查。命令：`./box node --version`、`./box npm ci`、`./box npm run test:unit`、`./box claude auth status`、`./box ls .claude/skills`。概念：box 只看到 repo 與 allowlist，第一次建 image 需 1–10 分鐘且之後會重用；Verify 表證明「沒有 `id_*` 私鑰、外網被擋、npm 與 git 仍可用」。學習點：boundary 不是口號，是一組可重跑的檢查。
- `#L1-L22` — `m1/map.md` — 七層表格：每層的目標、決定什麼、在哪個模組教；圖上六層加第七層 boundary。結尾的診斷規則「找到壞掉的那層，修那層」是整門課的除錯語言。學習點：把 agent 失敗分類，而不是一律加 prompt。
- `#L1-L33` — `m1/reset-rules.md` — 四個習慣與 select / compress / isolate / offload 的對照；handoff 三步（寫 goal / done / next / files / failed、`/clear`、從 handoff 繼續）；reset 的三個徵兆；`/compact` 與自動壓縮的差異。學習點：context engineering 是四個可練習的動作，不是抽象原則。
- `#L1-L100` — `m2/five-hooks/README.md` — 目的：把五個 hook 裝進任何 repo。表格列出事件與理由：`block-dangerous`（PreToolUse·Bash）、`protect-secrets`（PreToolUse·Read/Edit/Write/Bash）、`test-gate`（Stop）、`fast-feedback`（PostToolUse）、`session-context`（SessionStart），再加 bonus A `protect-test-config` 與 bonus B `notify`。安裝步驟、env var 選擇、驗證指令、bonus A 開啟方式、Hermes 差異（`terminal` / `read_file` / `patch`、`pre_verify`、`pre_llm_call`、需 `--accept-hooks`）與 honest limits。學習點：三個 gate、兩個 observe，以及「pattern guard 只縮窄路，不是牆」。
- `#L1-L72` — `m2/five-hooks/.claude/settings.json` — 把腳本接到 Claude Code 生命週期：`PreToolUse` 的 Bash 與 Read/Edit/Write/MultiEdit/Bash matcher、`PostToolUse` 的編輯後回饋（timeout 120）、`Stop` 的 test gate（600）與 notify、`Notification`、`SessionStart` 的 `startup|resume|clear`。學習點：hook 的威力來自事件與 matcher 的組合，不是腳本本身。
- `#L1-L26` — `m2/five-hooks/.claude/hooks/block-dangerous.sh` — 第一個 gate：`jq` 缺失就 fail closed；用 regex 擋 `rm -rf`（任意旗標順序）、force push（含 `--force-with-lease`）、drop / truncate database；exit 2 並在 stderr 給替代做法。學習點：好的 gate 不只拒絕，還告訴 agent 下一步怎麼做。
- `#L1-L28` — `m2/five-hooks/.claude/hooks/protect-secrets.sh` — 第二個 gate：檢查 `file_path` 與 shell 指令中的每個 word，命中 `.env` / `.env.*` 就擋，但放行 `.env.example` / `.sample` / `.template`。學習點：agent 讀進 window 的東西等於送到 model provider，所以 secret 必須在讀取層擋。
- `#L1-L43` — `m2/five-hooks/.claude/hooks/test-gate.sh` — 第三個 gate：Stop 時跑 `TEST_CMD`（預設 `npm run test:unit`），repo 沒變就跳過；用 `stop_hook_active` 與 `/tmp/test-gate-<session>` 計數避免無限迴圈，超過 `MAX_ROUNDS=3` 就放行並提醒人類；紅燈回傳 `decision: block` 加測試 tail。學習點：「done」必須外部驗證，且 gate 要有逃脫閥。
- `#L1-L38` — `m2/five-hooks/.claude/hooks/fast-feedback.sh` — 第四個 hook：PostToolUse 後只檢查 `ts|tsx|mts|cts`；shell 指令若含 `sed -i`、`>`、`tee`、`mv/cp/patch` 就用 `git diff` 找變更；typecheck 錯誤只回編輯過的檔，lint 可選；用 `decision: block` 把錯誤直接交回 agent。學習點：把回饋迴路縮到秒級，避免錯誤累積。
- `#L1-L25` — `m2/five-hooks/.claude/hooks/session-context.sh` — 第五個 hook：SessionStart 輸出 branch、`git status --short` 前 30 行、最近 8 個 commit，以及 `DECISIONS_FILE`（預設 `docs/decisions.md`）最後 40 行；Hermes 只在 `pre_llm_call` 首輪作用。學習點：每個 session 從現況開始，省掉人類重述。
- `#L1-L24` — `m2/five-hooks/.claude/hooks/protect-test-config.sh` — bonus A：保護 `vitest|jest|playwright|stryker` config、`stryker*.json`、`.github/workflows/`、`.claude/`、`.hermes/`，也擋 shell 寫入；先去掉 `/dev/null` 與 fd redirect 再判斷，避免誤擋唯讀命令。預設不註冊。學習點：agent 可能「修測試設定」讓 suite 假綠，這是 test harness 的攻擊面。
- `#L1-L17` — `m2/five-hooks/.claude/hooks/notify.sh` — bonus B：Notification 與 Stop 時播放 macOS 音效，或推到 ntfy topic；沒有 `jq` 只警告、不阻擋。學習點：人類注意力也是 harness 資源，通知要與 gate 分開。
- `#L1-L29` — `m2/five-hooks/hermes/config-hooks.yaml` — 同一批腳本在 Hermes 的註冊：`pre_tool_call`（terminal / read_file / write_file / patch）、`pre_verify`（test-gate 與 fast-feedback）、`pre_llm_call`（session-context）；`fail_closed: true`；bonus A 註解掉；註明 hook 在 host 跑、需 `--accept-hooks` 寫 allowlist。學習點：policy 可以跨 harness 移植，但事件名稱與工具名稱不同。
- `#L1-L38` — `m6/add-mcp-server/SKILL.md` — 目的：把「替自己的 app 加 MCP server」變成可執行 skill。八步：`assess-app.sh` 盤點 → 提工具清單並等人 OK → 本地 stdio 公開工具 → Streamable HTTP 每請求建 server → 每人一把 key → docs-search 工具 → key 上的 toolset → 四項測試。Gotchas 包含 description 決定工具可見度、stdout 屬於 protocol、危險動作要 confirm link。學習點：先盤點、先提案、先等人批准，再寫 code。
- `#L1-L20` — `m6/add-mcp-server/references/auth.md` — 「誰在呼叫」：Bearer key、可辨識前綴（`tb_`）、每請求解析 caller（user id / role / scopes）、無 header 只給 public、錯 key 一律 401 不降級匿名、private 查詢以 caller id 過濾、scope 在工具內檢查；沒有 auth 的 app 兩個選項；OAuth 是最後一步。學習點：授權問題要在工具執行前回答完。
