# PR tour + triage

## Lesson

Git diff 依字母排序，不是理解順序；PR Tour 先講意圖，再排該讀的檔案與行。PR Triage 把整個 queue 依「真正需要多少注意力」排序，而不是依年齡或大小。兩者都只指路、不下安全判決。
