# Agent loop

model、prompt、context 管的是單次呼叫；再往外一層，是決定這通呼叫怎麼被執行、結果怎麼回來的 harness。

你請 AI 讀一個檔案時，模型不會直接打開檔案。它會先輸出「讀取檔案」的工具呼叫，再由外圍程式執行，並把結果交回模型。

<!--image:1-->

這套外圍程式稱為 **harness**。它會把目前的對話內容，也就是模型這一輪能讀取的 window，送給模型。

它也會判斷模型是否提出工具呼叫，以及是否執行。

流程會一輪一輪重複。harness 把 window 送給模型，模型提出工具呼叫；harness 執行後，將結果放回 window，再把更新後的內容送回模型。

直到模型只回覆文字、不再提出工具呼叫，循環才會停止。這個循環稱為 **agent loop**。

模型負責產生回應與工具呼叫，harness 則把工具呼叫轉成實際動作，並將執行結果送回模型。

<!--image:2-->

搞懂這個循環之後，下一個問題就很具體：預設的 harness 拿到你的專案，會在哪裡出錯？
