# Instruction file 與 skills

## Lesson

Instruction file 放 agent 查不到、且全 repo 都成立的規則；其餘內容分流到 skill、文件或 hook。Skill 平時只有 name 與 description 佔 context，真正需要時才載入全文。兩者都是把專案知識交給 agent 的檔案，而不是更長的提示詞。
