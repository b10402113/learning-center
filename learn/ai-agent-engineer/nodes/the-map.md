# The map：七層地圖

## Lesson

同一個模型換掉 harness，Terminal Bench 名次就從三十名外進到前五，這是整門課的起點。七層不是功能清單，而是除錯順序：先定位壞在哪一層，再修那一層。之後每個模組都會回到這張地圖。
