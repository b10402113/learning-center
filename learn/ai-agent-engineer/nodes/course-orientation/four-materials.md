# 你的工具箱

開始一門使用 AI agent 的課程時，你可能會遇到幾種不同的資源：練習專案、設定指南、可重複使用的技能，以及整理知識的模板。先了解它們各自的用途，就能依照需求找到合適的資源。

<!--image:1-->

- **TicketBay**：練習用的應用程式，包含 Next.js 與 Postgres 專案、`box`、CI 檢查、MCP 伺服器，以及各課程的起始與解答分支。
- **course kit（課程套件）**：ZIP 檔，內含供 agent 使用的設定指南與模組資料，可協助你準備工具、設定 TicketBay，並完成各課程步驟。
- **skills（技能）**：一組讓 agent 執行特定工作的技能，例如建立技能資料夾、檢查測試或整理 pull request，可以在不同課程中重複使用。
- **brain-template（第二大腦模板）**：用來建立個人知識整理系統的模板，包含資料夾、索引、安裝與同步工具，以及擷取、分類、檢查和查詢知識的技能。

<!--image:2-->

分清楚這四種材料之後，下一個問題很實際：course kit 裡到底有哪些模組檔案，手上的版本又是不是最新的。
