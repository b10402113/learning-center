# The centralized brain

## Lesson

沒有共享記憶時，只能在每次重講、複製規則到每個專案、或只用本機 global 檔之間三選一。第二大腦是一個跨專案的 markdown git repo，所有 agent 讀寫同一份。Index 讓 agent 先讀一行摘要，而不是先掃全庫。
