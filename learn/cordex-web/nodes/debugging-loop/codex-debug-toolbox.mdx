# Codex 的除錯工具箱：browser use、CDP、截圖與 computer use

<LearningGoal>
能分辨 browser use、CDP、截圖與 computer use 各自讓 Codex 看到什麼，並說出 browser use 與 computer use 的差別。
</LearningGoal>

## Lesson

Codex 靠四種工具自行診斷——browser use 讓它像人一樣操作頁面重現問題、CDP 讓它看到 DevTools 的 logs／network／layout、截圖讓它比對畫面、computer use 把操作延伸到瀏覽器以外的任何 app；browser use 只管瀏覽器內的東西，computer use 則能碰電腦上任何 app，而桌面 app 與 CLI 底層跑的是同一顆引擎。
