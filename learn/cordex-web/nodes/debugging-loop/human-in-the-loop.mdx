# 什麼時候該放手、什麼時候得自己當 judge

<LearningGoal>
能判斷一個前端問題該放手讓 Codex 自走，還是得由人類說出「這才是我要的」。
</LearningGoal>

## Lesson

除錯迴圈的人機分工約五五波：客觀壞掉的問題（東西壞了、build 不過、請求失敗）放手讓 Codex 自走，取決於你意圖的問題（好不好看、該不該在前）則由你當 judge；真正的判準不是「主觀或客觀」，而是「這次這個 bug，模型抓不抓得到你的意圖」，而這條線會隨模型能力移動。
