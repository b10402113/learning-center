# 跑一次除錯迴圈：從 bug 報告到根因修復

<LearningGoal>
能寫出一則「症狀＋期望行為」的除錯 prompt，並讓 Codex 跑完重現→診斷→修根因→多斷點驗證。
</LearningGoal>

## Lesson

把 bug 寫成一則含四要素的報告——症狀、期望行為、要求重現與修根因、邊界與多斷點驗證——前置是專案能跑且 bug 能穩定重現；送出後讓 Codex 用 browser use、CDP 與截圖自己跑完一輪診斷，別急著中途打斷。
