# 開一個附視覺證據的 PR

<LearningGoal>
能在 AGENTS.md 定義 PR 證據規則，讓 Codex 自動截下多斷點的 before／after 截圖並開出一個附視覺證據的 PR。
</LearningGoal>

## Lesson

在 AGENTS.md 的 PR 區塊定義視覺證據規則——before 在改動前截、after 在同一路由同一寬度同一篩選狀態截、涵蓋 390／721／768／1440（動到手機斷點加 720）、檔名位置固定、嵌入用 GitHub 上傳後的穩定網址——規則寫好後 Codex 會自己截圖並開出附多斷點 before／after 的 PR。
