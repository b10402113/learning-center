# 要給多少指引：只說要什麼，還是指定設計系統

<LearningGoal>
能用「repo 有沒有把這件事編碼」這個判準，決定 prompt 該停在只說要什麼，還是要明講設計系統、套件與慣例。
</LearningGoal>

## Lesson

用「這件事 repo 有沒有編碼」決定 prompt 的顆粒度：AGENTS.md 有路由、skill 有檔案清單、references 有契約、設計系統清楚、驗證與 PR 規則齊備，就只說要什麼；缺任何一項便短期明講、長期補進 repo——「只說要什麼」是 repo 先做足功夫換來的特權，不是預設值。
