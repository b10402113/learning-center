# 動手探索既有專案並送功能 prompt

<LearningGoal>
能照著步驟把既有專案跑起來、用 Codex 探索它的結構，並送出一段只描述結果、不含設計系統細節的功能 prompt。
</LearningGoal>

## Lesson

在既有專案加功能的程序是：先把專案跑起來、再讓 Codex 依 repo 規則探索結構，最後送出一段只描述結果、並要求重用既有 state、helpers、components、styles 的功能 prompt——prompt 不需完美，關鍵是它講的是「要什麼」而非自己指定設計系統與套件。
