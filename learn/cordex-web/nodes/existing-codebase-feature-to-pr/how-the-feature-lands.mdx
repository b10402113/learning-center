# 功能為何能長得跟既有 dashboard 一樣

<LearningGoal>
能說出功能自動貼合既有 dashboard 的傳導鏈——AGENTS.md 路由到 skill、skill 指向範例元件與資料契約，於是 Codex 重用既有 primitives 並保留 region filter。
</LearningGoal>

## Lesson

功能能自動貼合既有 dashboard，靠的是一條 repo 內的傳導鏈：AGENTS.md 把工作路由到 skill，SKILL.md 導覽 Codex 先讀哪些既有檔案，references 定義資料與元件契約（含「只吃被篩選過的 cities」），assets 提供可改寫的起點，於是新卡片在視覺與行為上都跟其他卡片一致。
