# 既有 codebase 的貢獻契約：只說要什麼

<LearningGoal>
能說出在既有（共享）codebase 裡下 prompt 的契約——你只描述想要的結果、不指定怎麼做，因為 repo 本身該提供設計系統與慣例。
</LearningGoal>

## Lesson

在既有（共享）codebase 裡，貢獻契約是「你只說要什麼，repo 提供怎麼做」；Codex 只看得到 repo，沒被寫進 repo 的規則對它等於不存在，它就會自己發明一套、把工程師卡成 review 瓶頸，所以知識必須先被編碼進 AGENTS.md 與 skill。
