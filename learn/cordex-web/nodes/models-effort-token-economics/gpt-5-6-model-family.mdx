# GPT-5.6 三兄弟：Sol、Terra、Luna

<LearningGoal>
能說出 GPT-5.6 家族中 Sol、Terra、Luna 三顆模型的定位差異，並在拿到一個任務時先判斷該派哪一顆上場。
</LearningGoal>

## Lesson

GPT-5.6 家族的 Sol、Terra、Luna 代表的是「智慧、速度、成本」的不同配法，不是能力有無的差別：Sol 是旗艦、留給最難的任務，Terra 居中，Luna 最小最便宜、適合不難但量大的工作；選模型的第一步，就是判斷這個任務值不值得動用最貴的算力。
