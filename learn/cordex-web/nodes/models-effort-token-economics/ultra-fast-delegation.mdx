# Ultra、fast mode 與委派：把額度花在刀口上

<LearningGoal>
能操作並判斷三種加速／省額度手法——Ultra 子代理、fast mode、以及把粗活委派給便宜模型——各自怎麼開、何時開、會多花或少花什麼。
</LearningGoal>

## Lesson

Ultra 讓 Codex 自動派出多個子代理處理平行的獨立子工作或複雜任務，但非常吃 token、還得先進設定打開；fast mode 讓 token 輸出更快但額度燒得更快；委派則把粗活交給最便宜的 GPT-5 Luna 加最高 effort，再用測試當 back pressure 守住品質——三者改變的都是資源效率，做完一律要驗證。
