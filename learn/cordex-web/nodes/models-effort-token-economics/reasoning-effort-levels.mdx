# Reasoning effort：叫模型多想一點，代價是什麼

<LearningGoal>
能解釋 reasoning effort 是什麼、五個等級與預設值，並說出調高 effort 的兩個代價以及「想太久反而更差」的過度思考現象。
</LearningGoal>

## Lesson

Reasoning effort 是模型在回答前願意花多少思考量，預設值是 medium；往上調通常更聰明，代價是更多 token 與更慢，而且在簡單問題上開太高會出現過度思考、結果反而變差，所以實務上從 medium 出發、依任務難度上下調整，max 只留給真正困難的問題。
