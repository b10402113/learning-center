# 任務到手時，我該選哪個模型與 effort

<LearningGoal>
能面對一個具體任務，用判別問句選出模型與 reasoning effort，並依訂閱等級決定要不要動用 Ultra／fast／委派，把額度花得划算。
</LearningGoal>

## Lesson

選模型與 effort 的核心是判斷任務值不值得用貴的算力：難題給 Sol、瑣事給 Luna、折衷用 Terra，effort 從 medium 起跳依難度調整；Ultra、fast mode 與委派是三個資源槓桿，分別換取平行處理、更快輸出與更省額度，而能放心用多少取決於訂閱等級與是否備好測試當 back pressure。
