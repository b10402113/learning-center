# Exec plan 是什麼：寫在 repo 裡的活文件

<LearningGoal>
能定義 exec plan 是一份放在 repo、會隨工作持續更新、由 Codex 自動建立的活文件，並說出它跟一次性計畫的差別。
</LearningGoal>

## Lesson

exec plan 是 Codex 團隊自創的稱呼（非業界標準），指一份存在 repo、隨工作持續更新、由 Codex 自動建立的活文件；它跟對話裡的計畫差在放在 repo（跨 session、跨同事）、是活的（隨工作長大）、且設定好 AGENTS.md 之後由 Codex 自動產生，內容涵蓋目的、進度與任務、意外與發現、決策紀錄四類。
