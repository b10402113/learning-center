# 為什麼 Codex 會忘記你當初為什麼這樣做

<LearningGoal>
能說出 context 退化與 compaction 為什麼會弄丟重要決策，以及「隔了一段時間後，另一個 Codex 把你當初的決定改回去」這個真實風險。
</LearningGoal>

## Lesson

Codex 的記憶綁在單次對話上：context 超過約四成後輸出品質會漸進退化，compaction 挑重點留下來又不受你控制，於是重要決策會被弄丟；換 session、換同事的 Codex 更是從頭來過，導致下一個 instance 可能善意地把你深思過的決定改回去（例如把安全團隊指定的舊套件升級而弄壞系統）——所以決策必須寫進 repo。
