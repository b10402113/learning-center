# 讓 Codex 自己寫 exec plan：AGENTS.md 指引與專屬資料夾

<LearningGoal>
能在 AGENTS.md 寫入 exec plan 的定義與建立時機，並設好專屬資料夾，讓 Codex 在新功能或重大決策時自己產生計畫。
</LearningGoal>

## Lesson

要讓 exec plan 自動化，需要一個集中收文件的專屬資料夾，以及 AGENTS.md 裡一段回答「它是什麼、何時建立、放在哪」的指引；指引寫得越明確，Codex 越會主動在新功能或重要架構決定時建立、並在每完成一步後更新，驗證方式就是請它做一件全新的事、看資料夾裡是否自己長出一份計畫。
