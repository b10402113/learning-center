# 寫一份撐得過 compaction 的決策日誌

<LearningGoal>
能寫出最小可用的 exec plan／決策日誌，涵蓋目的、進度與任務、意外與發現、決策紀錄四塊，並持續更新它。
</LearningGoal>

## Lesson

一份最小可用的 exec plan 有四塊：目的（為什麼做）、進度與任務（做到哪、還剩什麼）、意外與發現（過程中冒出的插曲）、決策紀錄（做了什麼選擇、為什麼）；其中決策紀錄最關鍵，因為理由才是下一個人判斷能不能改動的依據，而文件寫好後要每完成一件事就回來補一筆，compaction 才帶不走你的理由。
