# 什麼時候值得開 exec plan

<LearningGoal>
能判斷哪些工作值得開 exec plan（長時間 goal、複雜演算法反覆迭代、後端／大型專案、跨 session 或跨同事），以及在什麼情況下它划不來。
</LearningGoal>

## Lesson

exec plan 不是每件事都要開，選項有三檔（不寫、簡易決策日誌、完整 exec plan）；動手前問三題——有沒有不寫就難以理解的決策、會不會長時間反覆迭代、未來會不會有人接手，任一為「是」就留下紀錄，全為「否」就略過，因為小改動硬開只會讓人習慣忽略它，而長 goal 與後端／大型專案則是最該使用它的地方。
