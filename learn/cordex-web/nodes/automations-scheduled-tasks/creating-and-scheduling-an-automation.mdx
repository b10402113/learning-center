# 建立一個 scheduled automation：定時 prompt、排程與編輯

<LearningGoal>
能從對話裡或排程頁建立一個 automation，設定每日／每週／自訂時段的排程，並知道事後怎麼查看與編輯它。
</LearningGoal>

## Lesson

建立 automation 有兩個入口：在對話裡請 Codex 建，或自己到排程頁手動建。用一段話交代「在哪裡跑、多久跑、每次做什麼」，把排程的節奏（每天／上班日／每週／自訂）與時間設好，它就會時間到自動執行；建好後可以點開查看、直接編輯，也能從排程頁一次看到所有會跑的 automation。
