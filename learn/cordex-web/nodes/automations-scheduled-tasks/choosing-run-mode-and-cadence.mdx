# 跑在同一個對話還是每次開新對話：run mode 與排程節奏的抉擇

<LearningGoal>
能依任務性質選對 run mode（沿用原對話 vs 每次開新對話）與排程節奏（每日／每週／自訂）。
</LearningGoal>

## Lesson

Run mode 的判準是「今天的產出需不需要記得前幾次」：需要就沿用原本的對話（例如每天刷新同一份資料），不需要、甚至不該記得就每次開新對話（例如 daily brief）。排程節奏則對齊你消費這份產出的頻率——每天看就每天跑，每週回顧就每週跑，並把時段排在你真正會用到它之前。
