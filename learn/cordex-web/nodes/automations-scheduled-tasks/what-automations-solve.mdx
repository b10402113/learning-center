# Automations 解掉什麼問題：讓 app 不用接 live 資料源也能保持最新

<LearningGoal>
能說出 automation 是什麼、它為什麼存在，以及它和「請使用者連上 live 資料源」的差別。
</LearningGoal>

## Lesson

Automation 是 Codex 裡「照排程重複跑同一段 prompt」的功能，住在排程頁。它解掉的是內容過期的問題——當 app 建立在天天變動的 Gmail、Slack 資料上，又不想讓 app 或使用者去背外部連線時，就用 plugin 加上 automation 定期把資料抓回來、更新頁面，用「排程刷新」換掉「永久即時」。
