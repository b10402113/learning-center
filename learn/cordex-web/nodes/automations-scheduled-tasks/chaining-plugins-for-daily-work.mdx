# 串接 plugin 做每日工作：Gmail、Slack、GitHub 的常駐檢查

<LearningGoal>
能安裝 plugin 並用它寫出「每天定時檢查某件事」的 automation，例如待審 PR 或 daily brief。
</LearningGoal>

## Lesson

要做出真正有用的 automation，得先加上對應的 plugin（Gmail、Slack、GitHub 這些每天在用的工具），再用一段 prompt 描述「要檢查什麼、多久一次」，做出 daily brief、待審 PR 清單這類常駐檢查。而且 automation 不只是一個 prompt，它後面可以掛 plugin、skill 或具體 action，等於一個定時觸發的工作流程入口。
