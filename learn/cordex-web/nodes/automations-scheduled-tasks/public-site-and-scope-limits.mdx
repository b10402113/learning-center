# 自動化做不到的事：公開站限制與 Sites 的邊界

<LearningGoal>
能說出公開站為何不能靠 automation 自動重新部署，以及 Sites 只出版 web 對 companion app 的影響。
</LearningGoal>

## Lesson

Automation 有明確的邊界：公開網站不能靠它自動重新部署，因為資料必須先確認可以再次公開分享，才能推上線，這一步需要人來把關——判斷方法是問一句「這個排程會把資料推到公開的地方嗎？」。另外，Sites 只出版 web、不出版 mobile app；Codex 做得到行動應用，但上架得走另一條路，只是你擁有網站程式碼，可以據此衍生 companion app。
