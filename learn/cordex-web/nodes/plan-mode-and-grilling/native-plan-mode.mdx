# 原生 plan mode：先定義、還不要動手

<LearningGoal>
能說出原生 plan mode 在做什麼、它和直接開工的差別，以及它為什麼不夠。
</LearningGoal>

## Lesson

原生 plan mode 是 Codex 內建的「定義模式」：用 `/plan` 先讓模型把功能講清楚、先別動手，避免它在需求模糊時邊想邊改、把假設固化進程式碼；但它問的問題不夠多，會給你一份看似完整、其實漏掉關鍵決策的計畫。
