# 該用 plan mode 還是 grilling？

<LearningGoal>
能在一個新功能面前，判斷該用原生 plan mode 還是 grill-me／grill-with-docs，並知道何時停手。
</LearningGoal>

## Lesson

用「決策分叉的密度」與「錯誤假設的代價」來選：功能小、方向明、決策瑣碎就用原生 plan mode 甚至直接開工；有真正的產品或領域分叉、改錯代價高、決策需要被留下，就用 grill-me／grill-with-docs。用了 grilling 最多跑兩輪，絕不用「全部採用建議」代替判斷。
