# grill-me：用決策樹把設計逼到共享理解

<LearningGoal>
能說出 grill-me／grilling 怎麼用一棵決策樹把設計逼到共享理解，以及「每個問題附建議」的問答機制。
</LearningGoal>

## Lesson

grill-me 是社群自製的 skill，做法是持續訪談使用者直到雙方達成共享理解；它把設計看成一棵決策樹，沿分支一題題追問，每題附上通常八成到九成正確的建議，讓你用 `take recommend` 或 `A` 快速回答，但實務上只跑兩輪，而且不能無腦採用全部建議。
