# grill-with-docs：把決策寫成 context.md 與垂直切片

<LearningGoal>
能說出 grill-with-docs 如何串起 grilling 與 domain modeling，把答案落成 context.md、Mermaid 與垂直切片。
</LearningGoal>

## Lesson

grill-with-docs 是複合 skill：用 domain modeling 跑一場 grilling，把商業術語與需求記進 `context.md`，補上「談完就忘」的缺口，並順帶產出 Mermaid 流程圖與可端到端驗收的垂直切片；目的是把決策前移、寫成文件，讓你對要蓋的東西有確定性並形成 back pressure。
