# 動手裝好並跑一輪 grilling

<LearningGoal>
能照著安裝 grill-me／grilling／grill-with-docs／domain-modeling，並對一個功能實跑一輪 grilling（限兩輪）拿到 up-front 決策。
</LearningGoal>

## Lesson

安裝指令是 `npx skills@latest add schneidenbach/skills`，勾選 grill-me、grilling、grill-with-docs、domain-modeling，選全域與 symlink，裝進 `~/.agents/skills`；使用時描述功能並叫「grill me with docs」，用 `take recommend` 或 `A` 快速回答、看不懂就請它解釋，最多跑兩輪，最後檢查 `context.md`、Mermaid 流程圖與垂直切片才進實作。
