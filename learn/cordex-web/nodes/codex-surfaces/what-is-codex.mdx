# Codex 是什麼？一個 harness，兩種面貌

<LearningGoal>
能說明 Codex 是同一個 harness 的兩種面貌，並講出從 chat 到 delegation 的演進為什麼改變了工作方式。
</LearningGoal>

## Lesson

Codex 是 OpenAI 的 agent，核心是一套 harness；ChatGPT Work 與 Codex 其實是同一套 harness 的兩種面貌——前者藏起 git 與程式碼給非開發者用，後者保留開發者功能。
