# Codex 的入口地圖：Chat、Work、桌面 app、瀏覽器擴充與手機遠端

<LearningGoal>
能分辨 Chat、Work、桌面 app、瀏覽器擴充與手機遠端各自連到哪裡、能不能碰到本地檔案。
</LearningGoal>

## Lesson

Codex 的各個入口共用同一套 harness，差別在跑在雲端還是本機、碰不碰得到本地檔案：桌面 app 能存取本機檔案與 automations，網頁 Work 在雲端，瀏覽器擴充與手機 remote 都連回你的機器。
