# 這個任務該從哪個入口進？判準與反例

<LearningGoal>
能針對一個任務，用判準選出正確入口，並說出什麼時候這個選擇會翻轉。
</LearningGoal>

## Lesson

選入口的分水嶺是任務需不需要碰本機資源：要碰檔案、操作本機 app 或排程就用桌面 app（或擴充／remote／CLI），純問答用 Chat，要交辦任務又想在雲端用 Work。
