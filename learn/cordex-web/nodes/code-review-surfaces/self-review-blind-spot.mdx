# 為什麼模型審自己的 code 有根本盲點

<LearningGoal>
能解釋為什麼讓同一個模型審自己寫的 code 有根本限制，以及為什麼要為此保留第二個模型。
</LearningGoal>

## Lesson

Codex review 換掉的是對話脈絡，不是模型本身；同一個模型審自己寫的程式會有同一套盲點，所以需要保留第二個模型，用不重疊的視角來補。
