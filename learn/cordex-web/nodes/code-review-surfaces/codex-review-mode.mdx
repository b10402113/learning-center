# Codex review：不帶對話脈絡的獨立審查者

<LearningGoal>
能說出 Codex review 是什麼、它和一般對話的差別（不帶 session 脈絡的獨立 instance），以及它審查的兩種對象與自訂 review 規則。
</LearningGoal>

## Lesson

Codex review 是一個不帶當前對話脈絡的獨立 instance，專門審 uncommitted changes 或對 base branch 的差異；它還能套用自訂 review 規則，把團隊的審查標準固定下來。
