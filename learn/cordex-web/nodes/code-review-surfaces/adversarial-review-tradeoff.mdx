# Adversarial 互審：多輪吵架，還是單次審查就夠？

<LearningGoal>
能判斷什麼時候用 adversarial 多輪互審、什麼時候單次第二模型審查就夠，並說出多輪互審的 token 代價。
</LearningGoal>

## Lesson

Adversarial 多輪互審讓兩個模型互相爭辯、逼近共識，靠的是視角不重疊；但它 token 代價極高，小方案跑一輪就見底，所以預設用單次第二模型審查，只有高風險、複雜且額度充足時才升級。
