# 跑一次第二模型審查：Claude 審 Codex

<LearningGoal>
能在 Codex 裡跑一次第二模型（Claude）的 code review，知道怎麼觸發、選哪個模型、審什麼，以及外部服務授權與 worktree 帶來的實務細節。
</LearningGoal>

## Lesson

跑第二模型審查的順序是：決定審 uncommitted changes 或對 base branch、在對的地方用內建 review 工具並明確禁止誤觸個人 skill、選對模型（Codex 用最強、Claude 用 Opus 最低 Sonnet）、明確允許外送授權，最後把結果當輸入自己判斷。
