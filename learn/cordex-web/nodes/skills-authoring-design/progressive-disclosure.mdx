# 分層設計：SKILL.md 當導航，references 與 assets 放細節

<LearningGoal>
能說出 SKILL.md、references、assets 三層各自該放什麼，並解釋這樣分層為什麼能避免 skill 一被載入就把 context 灌爆。
</LearningGoal>

## Lesson

SKILL.md 當導覽、references 放深度細節、assets 放可直接引用的範例程式與腳本；因為 Codex 常在「還不確定要不要用」的階段就載入 SKILL.md，這種分層讓它平常只讀薄薄一層、需要時才逐層往下取，避免 context 一開場就被灌爆。
