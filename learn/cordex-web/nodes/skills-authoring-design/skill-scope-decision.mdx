# 專案 skill 還是個人 skill：工作流該放在哪

<LearningGoal>
能依「這個工作流是否需要 repo 裡真實的元件與設計系統」判斷該把 skill 寫進專案還是裝在個人層級，並認出哪些重複工作值得變成 skill。
</LearningGoal>

## Lesson

判斷一個重複工作流該不該變成 skill，關鍵是它會不會反覆出現；決定位置時，看它需不需要 repo 裡真實的元件與設計系統——要，就是專案 skill；不需要且跨專案通用，就是個人 skill。至於整個 repo 都該遵守的一般慣例，屬於 AGENTS.md，不屬於 skill。
