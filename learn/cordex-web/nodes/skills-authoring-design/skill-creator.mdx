# Skill creator：用一個 skill 生出 skill

<LearningGoal>
能說出 skill creator 是什麼、它跑起來實際做了哪些事，以及為什麼每次要建立 skill 都應該用它。
</LearningGoal>

## Lesson

Skill creator 是一個用來建立 skill 的 skill，也是每次寫 skill 的預設入口：它會讀取專案、抓出可重用的元件與慣例，替你組好名字、描述與結構，並安裝到正確的位置；裝在 repo 就是專案 skill，裝在 Codex home 就是跨 session 的個人 skill。
