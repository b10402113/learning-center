# SKILL.md 的骨架：觸發描述與指引段落

<LearningGoal>
能認出一份好 SKILL.md 的骨架——name 與 description 負責讓 Codex 判斷該不該載入，指引段落負責告訴它怎麼做——並讀懂一份真實的專案 skill 範例。
</LearningGoal>

## Lesson

SKILL.md 的骨架分兩塊：name 與 description 是讓 Codex 判斷該不該載入這個 skill 的觸發資訊，正文則把工作流拆成可執行的段落，判準是「寫得像作者本來就熟悉這個 codebase」——放真實的檔名、元件與驗證步驟，而不是泛泛通則。
