# Codex 是什麼，以及它的各種入口

## Learning goal

能說出 Codex 與 ChatGPT Work 的差別，並針對一個任務選對入口（桌面 app／Work／瀏覽器擴充／遠端）。

## Steps

1. [[learn/cordex-web/nodes/codex-surfaces/what-is-codex|Codex 是什麼？一個 harness，兩種面貌]] — 認得 harness 這個共用引擎，以及從 chat 到 delegation 的演進
2. [[learn/cordex-web/nodes/codex-surfaces/codex-entry-points|Codex 的入口地圖：Chat、Work、桌面 app、瀏覽器擴充與手機遠端]] — 分清楚每個入口連到雲端還是本地（after step 1）
3. [[learn/cordex-web/nodes/codex-surfaces/choosing-an-entry-point|這個任務該從哪個入口進？判準與反例]] — 用判準替一個任務挑入口（after steps 1–2）

## Lesson

很多人第一次打開 Codex，第一個困惑不是「它會不會寫程式」，而是「我現在到底該點哪一個」。ChatGPT 網站上有 Chat，也有 Work；電腦上有桌面 app；瀏覽器裡還有擴充；手機上又能遠端連回自己的筆電。這些入口看起來都像同一個東西，差別卻決定了 Codex 能不能碰到你專案裡的檔案。

這個節點要把這件事講清楚。它不教你怎麼下 prompt，而是先建立一張入口地圖：Codex 的引擎（harness）只有一套，卻長出好幾個面貌，每個面貌能碰到的資源不同。三個步驟走完，你應該能看著一個任務，指著其中一個入口說「這個交給它」，並且講得出為什麼不是另一個。
