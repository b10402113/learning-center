# 拆解 Mission Control 的 prompt：把 moodboard 與 fixtures 收斂成一份 spec

<LearningGoal>
能照著「新資料夾與建置目標、視覺方向、素材來源、功能清單、資料行為、品質要求與發佈」的結構，寫出一份貼合方向的 dashboard prompt。
</LearningGoal>

## Lesson

一份可用的 dashboard prompt 有五段：開新資料夾並指定用 Sites 建置；用一句話定義要蓋什麼、指向 fixtures 並把 moodboard 當視覺方向（要求翻譯、不要照抄）；列出 day-at-a-glance 與看板功能及資料操作（把 refresh 不覆蓋手動任務寫進去）；用克制條款鎖住介面並指定 durable data 與「完全靠 fixtures」的範圍；最後給 responsive／accessible／polished 並發佈——把素材換成真實 plugin、框架寫明，就能套用到自己的專案。
