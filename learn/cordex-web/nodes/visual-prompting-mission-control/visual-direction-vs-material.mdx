# 為什麼只用文字描述會做出通用介面：視覺方向與素材

<LearningGoal>
能說出為什麼「用文字描述預設值」不如直接給視覺範例，並分辨 moodboard（視覺方向）、fixtures（素材）與真實 plugin 三者在 prompt 裡各自扮演的角色。
</LearningGoal>

## Lesson

只用「現代、乾淨、有質感」這類抽象形容詞描述介面，等於把方向交回模型的平均預設樣板，產出就會是通用介面；解法是給兩種具體輸入——moodboard 提供視覺方向（要翻譯色彩與構成，不要照抄版面），fixtures 或真實 plugin 提供資料素材（可示範用前者、真有用用後者，接真實資料要守住隱私）。
