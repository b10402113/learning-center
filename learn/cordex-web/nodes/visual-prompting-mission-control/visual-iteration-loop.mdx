# 用 annotation、appshot 與 browser use 把產出調到你要的方向

<LearningGoal>
能用內建瀏覽器的 picture-in-picture、annotation、screenshot 與 appshot 迭代 dashboard，並知道哪些 QA 會自動發生、哪些時候要自己開口要求。
</LearningGoal>

## Lesson

迭代 dashboard 靠把視覺意見精準餵回去：用 picture-in-picture 看 Codex 透過 browser use 自己點、自己測各斷點；用 annotation 把評論釘在你點選的元件上（用詞可以口語）；範圍較大時用 screenshot，需要更多上下文就用 appshot（Mac 預設 Command 連按兩下）；重新載入確認手動任務有被持久化；用 plugin 時 QA 通常自動發生，沒做就補一句「做完前先除錯確認」，最後以私人方式發佈並守住隱私。
