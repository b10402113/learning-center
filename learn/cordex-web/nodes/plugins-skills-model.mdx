# Plugin、App、MCP 與 Skill 的分野

## Learning goal

能分清 plugin／app（connector）／MCP server／skill 各自是什麼，並知道 skill 的組成與放置位置。

## Steps

1. [[learn/cordex-web/nodes/plugins-skills-model/plugin-bundle-anatomy|Plugin 是什麼：一個打包了 skill、app、MCP 的包裹]] — 認識 plugin 是「skills + apps + MCP servers 的打包」，以及打包存在的理由
2. [[learn/cordex-web/nodes/plugins-skills-model/apps-and-mcp-connectors|App 與 MCP server：授權存取與暴露工具]] — 分清 app（connector）與 MCP server 各自在做什麼（after step 1）
3. [[learn/cordex-web/nodes/plugins-skills-model/skills-as-instructions|Skill 是什麼：給 agent 的工作流程指示]] — 說出 skill 的定義與組成，以及它解決的重複問題（after step 1）
4. [[learn/cordex-web/nodes/plugins-skills-model/plugin-catalog-and-selection|該裝哪些 plugin：分類與選擇]] — 認得 plugin 的分類，並依任務判斷該裝哪一類（after steps 2–3）

## Lesson

Codex 把「擴充能力」這件事收斂成一個字：**plugin**。但一個 plugin 裡面其實混了三種不同的東西——**skills、apps、MCP servers**。這三種東西解決的問題完全不一樣：app 負責讓你登入授權、讓 Codex 代你存取外部服務；MCP server 負責把你的工具包成 agent 叫得動的形式；skill 則是一份工作流程說明，告訴 agent 這件事該怎麼做。把它們分開看，你才不會把「裝了一個 plugin」誤當成「教會 Codex 一個做法」，也才知道遇到某類需求時該去找哪一種東西。這條路線先拆包裹，再逐一解釋三個零件，最後回到分類：面對一堆 plugin，你該依手上的任務挑哪幾個。
