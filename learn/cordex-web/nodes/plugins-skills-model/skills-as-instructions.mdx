# Skill 是什麼：給 agent 的工作流程指示

<LearningGoal>
能說出 skill 是「給 agent 照著做的工作流程指示」，講出它的組成（一份文字說明，外加可選的 assets 與 scripts），並說明為什麼它讓你不必一再重複同一套指示。
</LearningGoal>

## Lesson

Skill 是給 agent 照著做的工作流程指示，核心是一份文字說明，可選擇性帶上 assets 與 scripts；放在 repo 內只對該專案生效，裝在個人層級則跨專案生效。它給的是「做法」而非「能力」，用來省下每次重複交代的力氣。
