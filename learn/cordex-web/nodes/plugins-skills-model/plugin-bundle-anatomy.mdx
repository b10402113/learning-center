# Plugin 是什麼：一個打包了 skill、app、MCP 的包裹

<LearningGoal>
能說出 plugin 是「skills + apps + MCP servers 的打包」，並解釋為什麼 Codex 用打包而不是要你逐項安裝。
</LearningGoal>

## Lesson

Plugin 是 skills、apps 與 MCP servers 的打包容器：它把常一起出現的三種零件綁成一包，讓你一次安裝就整組到位；但 plugin 本身不是 skill，也不是任何單一零件，看懂它等於看懂它帶進來的是哪幾樣東西。
