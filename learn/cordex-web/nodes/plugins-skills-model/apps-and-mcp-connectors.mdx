# App 與 MCP server：授權存取與暴露工具

<LearningGoal>
能分辨 app（connector）與 MCP server 的角色：一個是你登入授權後讓 Codex 代你存取的外部服務，一個是把工具暴露給 agent 的介面。
</LearningGoal>

## Lesson

App（connector）與 MCP server 都在讓 Codex 碰得到外部東西，但分工不同：app 解決授權與身分，讓 Codex 代你存取 GitHub、Slack 這類服務；MCP server 解決介面，把你的工具暴露成一張 agent 叫得動的選單。兩者常成對出現，卻不能互換。
