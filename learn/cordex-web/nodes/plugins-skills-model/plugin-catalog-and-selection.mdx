# 該裝哪些 plugin：分類與選擇

<LearningGoal>
能認得 plugin 的幾大分類（工作情境、原始碼審查、專案追蹤、託管、服務、builder workflows），並依手上的任務判斷該裝哪一類、不該裝哪一類。
</LearningGoal>

## Lesson

選 plugin 先分辨自己是「連上既有服務」還是「做某一類成品」：前者對應工作情境、原始碼、專案追蹤、託管、服務供應商等分類，後者對應 builder workflows；若只是要統一做法則該寫 skill。最後用「這個任務現在真的需要它嗎」當安裝閘門。
