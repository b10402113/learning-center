<LearningGoal>
能分辨 write-practical-copy 與 design-ui-with-restraint 各防哪一種「AI 味」，並說明把品味編碼成 repo skill 對產出的影響。
</LearningGoal>

## Lesson

write-practical-copy 擋的是文字腔（宏大、誇張、短句加句號、空泛 CTA），design-ui-with-restraint 擋的是多餘的介面資訊（重複標題、裝飾編號、示範資料警語），把品味編碼成 repo skill 讓 Codex 每次動工都自動套用。
