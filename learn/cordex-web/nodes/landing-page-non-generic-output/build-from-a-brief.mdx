<LearningGoal>
能照著步驟從一個 brief 生出 landing page：建立 project、指名 skill、給視覺方向、要三個概念、指定圖片風格，最後發布。
</LearningGoal>

## Lesson

完整程序：建立綁定 repo 資料夾的 project、開乾淨對話並選 medium effort、貼上六區塊 brief、確認 skill 生效、（需要時）要三個概念並挑一個建出來、指定圖片風格，最後響應式無障礙發布到 Sites。
