<LearningGoal>
能說出為什麼少了視覺方向，模型就會退回自己的預設、產出人人相同的「AI 味」網站，並指出視覺方向在一個 brief 裡的角色。
</LearningGoal>

## Lesson

「AI 味」來自模型在沒有視覺方向時退回唯一一套預設，於是每個人都拿到相同的樣品屋；視覺方向是 brief 裡獨立於內容與品質標準的一層。
