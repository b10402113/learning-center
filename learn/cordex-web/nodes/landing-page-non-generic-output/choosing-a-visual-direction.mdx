<LearningGoal>
能判斷什麼時候該自己把視覺方向寫進 brief、什麼時候該用 voice mode 與「三個概念」跟 Codex 一起決定方向。
</LearningGoal>

## Lesson

用「你現在能不能想像成品長什麼樣」來判斷：腦中有畫面就把方向寫進 brief，講不出來就用 voice mode 或要三個視覺概念，挑定後再叫 Codex 把那個概念建成新資料夾。
