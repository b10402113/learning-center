<LearningGoal>
能認出 landing-page prompt 的六個區塊（安排與 skill、brief、視覺方向、內容、圖片生成、收尾），並查閱每一塊包含什麼。
</LearningGoal>

## Lesson

一份 landing-page prompt 可拆成六個區塊：安排與 skill、對象 brief、視覺方向、內容、圖片生成、收尾；其中視覺方向篇幅最長也最關鍵，直接決定成品離不離開模型的預設。
