# PR 分頁與把專案知識寫進 repo

<LearningGoal>
能認得 PR 分頁與整合終端機這兩個留在 app 內的功能，知道 agents.md 與 repo skills 是把重複指示放進 repo 的兩個位置。
</LearningGoal>

## Lesson

PR 分頁與整合終端機把協作留在 app 內（後者特別適合 git worktree）；要把重複交代的事沉澱下來，agents.md 放這個 repo 的規則與背景、Codex 每個新任務都會讀，repo skills 則放專案專屬、可重複的工作流。
