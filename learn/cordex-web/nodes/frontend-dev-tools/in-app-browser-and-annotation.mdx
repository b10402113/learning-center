# 內建瀏覽器與標註：把視覺回饋釘在螢幕上的那個元素

<LearningGoal>
能說出內建瀏覽器比外部瀏覽器多了什麼，並用標註工具把視覺問題釘在具體元素上、直接改 CSS 或字體。
</LearningGoal>

## Lesson

內建瀏覽器是專屬 Codex、能讓它直接操作的瀏覽器，給的是共同視角；標註工具則把視覺回饋釘在具體元素上、甚至直接改字體與 CSS，兩者一起把視覺迭代從猜謎變成指哪改哪。
