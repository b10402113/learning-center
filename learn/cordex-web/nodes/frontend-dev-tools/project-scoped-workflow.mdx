# 把 Codex 綁進專案資料夾，並在 app 內把東西跑起來

<LearningGoal>
能在 Codex 桌面 app 建立一個綁定本地資料夾的 project，發一個 prompt、把產物跑起來，並用內建瀏覽器看到它。
</LearningGoal>

## Lesson

把 Codex 綁進本地資料夾的 project，在 app 內發 prompt、用整合終端機（Command+J）或一句「run it」把 dev server 跑起來，再用內建瀏覽器看到畫面；直接雙擊 HTML 檔會是空的，因為它需要 dev server。
