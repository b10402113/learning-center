# CDP：讓 Codex 看得懂 log 與 network

<LearningGoal>
能解釋 CDP 給 Codex 的除錯能力（log、network），以及它為什麼讓修 bug 少一個猜的步驟。
</LearningGoal>

## Lesson

CDP（Chrome DevTools Protocol）是工具與瀏覽器之間的溝通協定，Codex 接上它之後能直接取得 logs 與 network，把除錯從「猜哪裡壞」變成「查證據再修」，且與管外觀的標註互補。
