# 內建生圖：先用訂閱生一張視覺方向，再開始蓋

<LearningGoal>
能說出內建生圖用哪一份額度、在「生視覺資產」與「驗證視覺方向」兩種情境怎麼用。
</LearningGoal>

## Lesson

內建生圖跟 ChatGPT 的生圖能力一樣，但用訂閱額度、不走 API；它一方面替網站生視覺資產，一方面在動工前先產一張視覺方向讓你確認，落實「先對方向，再動手」。
