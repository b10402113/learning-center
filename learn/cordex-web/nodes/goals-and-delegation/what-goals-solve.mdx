# /goal 解掉什麼問題：為什麼 Codex 只跑一輪就停

<LearningGoal>
能說出 goal 與一般 prompt 的差別、為什麼長工需要驗收條件，以及什麼時候根本不該動用 goal。
</LearningGoal>

## Lesson

一般 prompt 是一問一答，Codex 常常做一版就停；goal 把「停」的條件明講出來——不要停，直到驗收條件成立——於是它會反覆循環，值得用在大而久的任務，一次就對的小事則不必動用。
