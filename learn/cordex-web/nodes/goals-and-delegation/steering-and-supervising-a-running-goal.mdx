# 跑到一半該不該插手：監督、修正與收尾的判準

<LearningGoal>
能判斷一個正在跑的 goal 何時該放手讓它自走、何時該送新 prompt 修正方向，並知道它靠什麼機制自我驗證、哪一類問題一定需要人來當裁判。
</LearningGoal>

## Lesson

監督 goal 的判準：若「對不對」能用清楚條件驗證就放手讓它自走，若需要品味判斷「好不好、像不像我要的」就在跑偏時送新 prompt 修正；它靠 SQLite 任務清單與 browser use／CDP／computer use 自我驗證，收尾時要核對它宣稱的驗證是否真的發生過。
