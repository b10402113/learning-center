# 寫一個 goal：寬的目標，加上可驗收的停止條件

<LearningGoal>
能寫出一個「寬目標＋驗收條件」的 goal，並分清楚前端視覺檢查與 eval／golden set 這兩種停止條件的形式。
</LearningGoal>

## Lesson

寫 goal 的五步：用 `/goal` 起頭、把目標寫得寬而講結果、把驗收條件寫得具體（前端用視覺清單、問答用 eval／golden set）、長內容放心讓它自拆成 spec 檔、送出後確認它真的進入 goal 模式。
