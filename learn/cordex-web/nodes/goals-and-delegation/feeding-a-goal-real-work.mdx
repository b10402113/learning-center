# 把真實工作餵進 goal：ticket、spec 與獨立 worktree

<LearningGoal>
能接上 ticketing system（GitHub CLI 或 Jira MCP），用「grill-me → spec 檔 → /goal 引用 spec」的順序把一張票變成可長時間自走的 goal，並在獨立 worktree 上開跑。
</LearningGoal>

## Lesson

把真實工作餵給 goal：接上 tracker（GitHub 用 `gh`、Jira 用 MCP server）、用 grill-me 逼出決策並寫成 repo 裡的 spec 檔、在獨立 worktree／分支用 `/goal` 引用那份 spec 開跑，且要記得接上 GitHub 等於帳號層級權限，必須在指令裡限定只碰某一個 repo。
