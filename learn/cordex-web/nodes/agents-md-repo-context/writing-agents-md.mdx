# 動手寫一份 AGENTS.md

<LearningGoal>
能照著一份可操作的程序，為自己的 repo 寫出 AGENTS.md：從真實指令、repo map、skill 路由、慣例到驗證與 PR 證據。
</LearningGoal>

## Lesson

寫 AGENTS.md 的程序是：先讀 package.json 抄下真實指令，再依序寫入 Start here、repository map、skill 路由、慣例與設計系統、UI 驗證與 PR 證據，並補上規則背後的理由——只寫真的存在的東西。
