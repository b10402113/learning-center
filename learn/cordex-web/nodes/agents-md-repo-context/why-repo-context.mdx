# 為什麼 repo 要自己說故事：把上下文寫進版本庫

<LearningGoal>
能說出共享 repo 為什麼要把上下文寫進版本庫，以及上下文沒被編碼時會付出什麼代價——特別是 Codex 各做各的、工程師被卡成 review 瓶頸。
</LearningGoal>

## Lesson

在共享 repo 裡，Codex 只看得到 repo，所以知識不被編碼進 repo 就會各自發明一套、把工程師卡成 review 瓶頸；解法是把專案政策寫進 AGENTS.md、把可重複流程寫進專案 skill，並提供可重用的 helper 與清楚的設計系統。
