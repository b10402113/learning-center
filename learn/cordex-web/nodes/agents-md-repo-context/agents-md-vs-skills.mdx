# 什麼進 AGENTS.md、什麼進 skill

<LearningGoal>
能判斷一段內容該放 AGENTS.md 還是 skill，並用 skill 的 SKILL.md ＋ references／assets 分層避免把 context 撐爆。
</LearningGoal>

## Lesson

政策與地圖放 AGENTS.md、可重複流程放 skill；skill 內再以 SKILL.md 當導覽、references 放深度契約、assets 放範例與腳本，讓 context 只在需要時才展開，避免一載入就爆掉。
