# 模型、reasoning effort 與額度經濟學

## Learning goal

能依任務挑模型（Sol／Terra／Luna）與 reasoning effort，並用 Ultra／fast 與委派把訂閱額度用得更有效率。

## Steps

1. [[learn/cordex-web/nodes/models-effort-token-economics/gpt-5-6-model-family|GPT-5.6 三兄弟：Sol、Terra、Luna]] — 三顆模型的定位差異，先學會「哪個任務派哪顆」
2. [[learn/cordex-web/nodes/models-effort-token-economics/reasoning-effort-levels|Reasoning effort：叫模型多想一點，代價是什麼]] — 五檔思考深度、預設值、過度思考與 token 成本（after step 1）
3. [[learn/cordex-web/nodes/models-effort-token-economics/ultra-fast-delegation|Ultra、fast mode 與委派：把額度花在刀口上]] — 三種加速與省額度手法怎麼開、何時開（after step 2）
4. [[learn/cordex-web/nodes/models-effort-token-economics/choosing-model-effort-and-quota|任務到手時，我該選哪個模型與 effort]] — 用判別問句與訂閱等級做最終選擇（after step 3）

## Lesson

Codex 的品質與成本，一半取決於你怎麼調「模型」與「reasoning effort」這兩個旋鈕。模型決定上限：Sol 是旗艦，用來啃最難的任務；Terra 居中；Luna 最小、最便宜，適合不難但量大的工作。Effort 決定模型願意花多少思考時間：調高通常更聰明，但會吃更多 token，而且對簡單問題可能「想太多」反而變差。搞懂這兩個旋鈕之後，再看 Ultra、fast mode 與委派——它們不是讓答案變好，而是讓你在額度有限時，把貴的算力留給真正需要的地方。這四個步驟走完，你應該能在任務上手的當下，反射性地選好模型、effort 與加速策略。
