# 打磨 goal 的驗證迴圈

<LearningGoal>
能寫出一則打磨用的 goal，把「做完」定義成一份可重複執行的多 viewport 驗證清單，而不是一次成功的 build。
</LearningGoal>

## Lesson

打磨 goal 先用 GOAL 段落定出終點，再用八步軌道與「不要在球中央淡出」的禁令修好運動、用 CITY OWNERSHIP 堵住城市串場，最後以 VALIDATION LOOP 收尾——列出四個 viewport 尺寸與逐項檢查，並寫明「build 過了不算完成」，把「完成」定義成一份可重複執行的檢查清單。
