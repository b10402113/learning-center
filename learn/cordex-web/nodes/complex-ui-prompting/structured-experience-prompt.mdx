# 寫第一階段的大型結構化 prompt

<LearningGoal>
能照著段落骨架寫出一則描述高複雜度前端體驗的大型結構化 prompt，並在裡面塞進精確規格與品質要求。
</LearningGoal>

## Lesson

第一階段的大型結構化 prompt 有固定段落骨架——定位與技術棧、CORE CONCEPT（把故事拆成可計數的狀態）、VISUAL COMPOSITION（主角與不能壞的邊界）、CHOREOGRAPHY、精確規格、響應式與品質要求——並用「把感覺翻譯成數字與否定句」的手法收尾，要求 Codex 親眼看過而不是只看編譯。
