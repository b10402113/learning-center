# 第二階段：在既有 build 上疊生成資產

<LearningGoal>
能在不重新設計既有 3D 體驗的前提下，用一則針對性 prompt 把生成資產疊上去，並寫清楚資產的格式與品質規則。
</LearningGoal>

## Lesson

第二階段用一則只加一件事的針對性 prompt，先點名要保留的既有結構，再指名各城市要的具體地標、寫死資產的格式與瑕疵規則，並用資料驅動設定每個資產的進場、焦點、退場、縮放與繞行半徑；做完會得到「資產對了、動畫還很粗糙」的版本，交給第三階段的 goal 打磨。
