# 為什麼高複雜度 UI 要拆階段

<LearningGoal>
能說出為什麼高複雜度的 3D／動畫體驗要拆成階段來做，並講出三個階段各自的目標。
</LearningGoal>

## Lesson

高複雜度的 3D／動畫體驗不該用一個 prompt 一次做完，而要拆成三個先後有序的階段——先用 3D 骨架確認方向、再疊生成資產、最後用 goal 打磨；因為要跑長工，動工前先把 permission 設成 approve for me，並用 pets 追蹤多個並行對話。
