# 動手做 screenshot-to-component：把截圖重建成可編輯的元件

<LearningGoal>
能寫出一段 prompt 讓 Codex 用 skill creator 產出 screenshot-to-component skill，並說出驗收它做對了沒有的檢查點。
</LearningGoal>

## Lesson

寫一段 prompt 讓 skill creator 在專案裡產出 screenshot-to-component：要求它先讀專案、重用真正的元件與樣式，把截圖重建成真的 UI（響應式、可存取、好編輯），指定落點並用真實截圖與 typecheck／build 驗收。
