# 什麼是 living frontends：Codex 當場發明的新互動

<LearningGoal>
能說出 living frontend 是什麼、它和「用 Codex 更快寫一般前端」差在哪裡，以及為什麼要把這種能力寫成 repo 裡的 skill。
</LearningGoal>

## Lesson

Living frontend 指的是 Codex 當場創造全新的互動型態與元件，而不是把一般前端做得更快；它真正解掉的是「只有原作者做得出來」的瓶頸，因為做法可以寫成住在 repo 裡的 skill，讓之後任何人都能重複呼叫。
