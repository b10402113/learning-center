# 什麼時候該做 living frontend：靜態插圖 vs 活元件

<LearningGoal>
能判斷某塊前端該維持靜態、還是改造成可由 skill 重生成的活元件，並說出維護與曝露給 browser agent 的取捨。
</LearningGoal>

## Lesson

面對一塊前端，先問它會不會隨 UI 改、會不會有人重複做、使用者會不會想看到它活起來——中一個就做成活元件，三個都不成立就維持靜態；並記得留下重生成的方法，別讓它又變回靜態。
