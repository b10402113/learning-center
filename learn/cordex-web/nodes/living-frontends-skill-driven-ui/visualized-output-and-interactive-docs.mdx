# 視覺化輸出與互動文件：把答案畫出來，把程式碼重建成體驗

<LearningGoal>
能解釋 visualized skill 為什麼是「輸出一個介面而不是一段文字」，以及「指著既有程式碼、叫 Codex 在新環境重建同樣體驗」這個模式怎麼運作。
</LearningGoal>

## Lesson

visualized skill 把答案的載體從文字換成畫面，而互動文件是「把程式碼指給 Codex、請它在新環境重建體驗」的成果——輸入給程式碼能重建出活的版本，給截圖只能模仿外觀。
