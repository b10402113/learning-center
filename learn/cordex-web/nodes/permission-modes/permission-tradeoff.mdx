# Permission mode 在解什麼問題：自動化與安全的那條線

<LearningGoal>
能說出 permission mode 在解什麼問題，並指出「全部要你按」與「全開」這兩種極端各自壞在哪。
</LearningGoal>

## Lesson

Permission mode 是 Codex 工作迴圈上的判斷關卡：它決定每個動作要自動放行還是先停下來問你，而「全部要你按」會把你綁在螢幕前、「全開」則可能讓它在你不知情時做出不可逆的事，答案落在中間。
