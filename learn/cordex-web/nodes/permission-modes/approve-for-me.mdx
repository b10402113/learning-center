# Approve for me：為什麼它是預設的最佳中位數

<LearningGoal>
能解釋 approve-for-me 的機制（另一個安全檢查執行緒），並說出它和「全部要你核准」的差別。
</LearningGoal>

## Lesson

Approve for me 讓 Codex 在動手前先開另一條執行緒判斷動作安不安全：安全就自動放行、不安全才回頭問你，因此被當成安全與自動化之間的預設中位數。
