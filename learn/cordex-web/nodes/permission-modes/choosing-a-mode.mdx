# 怎麼選 permission mode：一份可操作的決策規則

<LearningGoal>
面對自己的情境能選對 permission mode，並知道要留意哪些操作習慣。
</LearningGoal>

## Lesson

選 permission mode 的可操作規則：預設 approve for me，只有隔離可拋棄的機器才用 full access，工作機永遠不用 full access，要可預期的規則改用 custom，並用 pet 盯著同時並行的多個 agent。
