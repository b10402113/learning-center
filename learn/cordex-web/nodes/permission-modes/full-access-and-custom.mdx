# Full access 與自訂權限：什麼時候可以全開，什麼時候不行

<LearningGoal>
能列出四種 permission mode 的機制與適用邊界，並說出 full access 只有在隔離機器上才可接受。
</LearningGoal>

## Lesson

四種 permission mode 的機制與邊界：ask for approval 每個都問、approve for me 由另一條執行緒判斷、full access 完全不問且只適合隔離可拋棄的機器、custom 用你自訂的明確規則換取可預期性。
