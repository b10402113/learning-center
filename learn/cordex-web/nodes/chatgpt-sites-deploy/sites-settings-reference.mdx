# Sites 設定面：存取、網域、環境變數、儲存與分析

<LearningGoal>
能查出一份 Sites 的設定面清單：存取控制、自訂網域、環境變數、內建儲存與分析各有哪些選項與限制。
</LearningGoal>

## Lesson

Sites 設定面五項：存取與分享（公開／SSO／workspace 群組／ChatGPT identity／自帶驗證）、網域（自動 URL／自選 URL／自訂網域）、環境變數（API 金鑰與第三方服務）、內建儲存（結構化與 blob，自動挑選）、分析（流量、訪客、熱門頁面）。
