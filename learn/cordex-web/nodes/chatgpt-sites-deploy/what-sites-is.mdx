# Sites 是什麼：把託管、驗證與儲存都收進 Codex

<LearningGoal>
能說出 ChatGPT Sites 是什麼、它替 Codex 接手了哪些託管與驗證工作，以及使用它的帳號前提與個人／企業帳號的差異。
</LearningGoal>

## Lesson

ChatGPT Sites 讓你直接從 Codex 託管應用程式，把部署、分享、儲存與驗證一併接手，起點可以是 prompt 或既有專案，發佈至少需要 Plus；個人帳號可公開分享，企業帳號多了內建 SSO 與 workspace 群組存取。
