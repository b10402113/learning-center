# 從 prompt 或既有專案部署上線

<LearningGoal>
能從一個 prompt 或既有專案把網站部署並發佈上線，並知道編輯與重新部署各自會發生什麼。
</LearningGoal>

## Lesson

部署五步：決定起點（prompt 或匯入既有專案）、用 Sites plugin 把既有專案轉成 site、發佈取得 URL、在 Sites 介面管理與編輯（編輯會開新對話請 Sites plugin 改）、先存新版本再重新部署。
