# 什麼時候用 Sites、什麼時候自架：網域與版本的取捨

<LearningGoal>
能判斷什麼時候該用 Sites、什麼時候自架更合適，並在自動產生的 URL、自訂網域、公開與私有之間做出選擇。
</LearningGoal>

## Lesson

判別規則：需要登入（尤其公司 SSO）或需要儲存時優先用 Sites；純靜態且不需要 SSO 則兩者皆可。網域先用自動 URL、長期經營再考慮自訂網域；版本先存新版本、確認無誤再部署。
