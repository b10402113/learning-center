# L1 overview

- **Ch8 §8.11 (end) — both domains give the same minimum bulk capacitance** — Frequency domain sets Cbulk = 1/(2π·fVRM-max·Ztarget) = L_VRM/Ztarget² at the frequency where the VRM impedance crosses Ztarget; time domain sets the same value from ΔV = I·Δt/C with the response interval Δt = L_VRM/Ztarget. Because both reduce to the same expression, the estimate is robust. Typical bulk values land in 100–1000 µF; very low target impedances plus a low-frequency VRM feedback loop push them higher. Note this is only the *floor* — the peak from VRM-L ∥ Cbulk is a separate problem (next section).

- **Ch8 §8.12 — optimizing bulk capacitor with the VRM: parallel peak at ~90 kHz** — An inductive VRM output meeting a capacitive bulk cap creates a new parallel peak, "often the biggest problem in the PDN," and can destabilize the VRM. SMPS are non-linear and time-varying, so frequency-domain analysis is approximate and the impedance peak differs for rising vs falling current; the book's tip is to start from the VRM supplier's bulk recommendation because they ran the SPICE transient/stability model. Worked case: VRM R = 2 mΩ, L = 20 nH, Ztarget = 10 mΩ → target exceeded above f = Ztarget/(2πL) ≈ 80–90 kHz, Cbulk ≈ 180 µF; with 100 µF the resulting peak (Figure 8.26) is 3× the target. Q of that parallel resonance is set by VRM L, bulk C, and cap ESR (VRM R ≪ ESR); with a ceramic MLCC the ESR is too low and the peak is underdamped. Critical damping (Q = 1) using only the VRM's DC output resistance would need C = L/R² = 20 nH/(2 mΩ)² ≈ 5000 µF — "absurdly high," so MLCCs cannot self-damp this node. Instead use tantalum/electrolytic bulk (ESR 0.02–0.1 Ω, range 5 mΩ–1 Ω across body sizes) and pick the count so the *parallel* ESR equals Ztarget: that is the minimum condition (characteristic impedance = Ztarget at Q = 1), which nearly eliminates the peak (Figure 8.27). Algorithm: (1) take vendor recommendation, (2) find VRM output L, (3) find Ztarget, (4) meet the minimum C of eq. 8.51, (5) choose type/count for ESR = Ztarget, (6) more C only helps if Q stays low. Figure 8.28 sweeps 100→400 µF at ESR = Ztarget: under-sized C gives too-high a peak and too-high Q; at or above the estimate the profile is good and extra C only lowers Z and Q.

- **Ch8 §8.13 — building the ecology: VRM + bulk + cavity + package + ODC** — VRM/bulk interactions live below 1 MHz; above that both look inductive and their parallel combination is ~10 nH, which appears in series with the package lead inductance and the cavity spreading inductance (spreading is usually negligible against the VRM/bulk term). From the die, the cavity is just more series inductance, and the total VRM+bulk inductance is typically >10× the package lead inductance. Compared with a shorted board, this larger loop raises the Bandini peak and moves it down: reference case (ODC 50 nF, ESR 5 mΩ, package 250 pH → Z0 = 71 mΩ, peak 1 Ω at 45 MHz shorted) becomes 9.6 Ω near 10 MHz once the VRM (10 nH, 1 mΩ), one 100 µF bulk (5 nH mount, 5 mΩ ESR), and a 10 mil/Dk 4.3/5 in × 5 in/2.4 nF cavity are attached (Figure 8.29); the estimate from the parallel-L formula matches the simulated 9.6 Ω. Board-level knobs are only the bulk cap's *mounting inductance* (lower it) or its *series resistance* (raise it) — more bulk capacitance does nothing, because the peak is set by inductance, not capacitance. Adding MLCCs is how both are accomplished: their low mounting inductance shorts the VRM/bulk inductance and their ESR adds damping; values must still be chosen so other parallel peaks stay low. Two selection strategies follow from the intrinsic Q of the Bandini Mountain: low Q (already damped on-die) → board damping is ineffective; high Q (Q = 14 here) → board damping is very effective.

- **Ch8 §8.14 — fundamental limits to the peak impedance** — Cost/robustness balance: keep the Bandini peak below ~3× Ztarget and every other peak below Ztarget. The packaged die sets the absolute floor because ODC and package lead inductance are not under board control. Counterintuitively a dead-short board is *not* optimal: with cavity L = 0 the die pads still see ODC ∥ package L, so the peak remains. Above Q ≈ 3 (and whenever package L cannot be reduced) the effective fix is a series resistive element at board level. The optimum board profile looks like a *resistor* of value Ztarget, flat over roughly 1–200 MHz (the Bandini band); practical for Ztarget ≈ 100 mΩ, not for ≤10 mΩ, where on-package capacitors are needed to extend the flat region and damp the peak. Approximation: peak impedance falls as the series resistance rises (valid while Q ≳ 2, ~40% error at Q = 1), because that resistance is damping; but when series R exceeds Ztarget the PDN impedance is above target below the peak frequency, so overshooting is counterproductive. Hence optimum R_board = Ztarget, and the condition for the peak to be below target reduces to Z0(Bandini) < Ztarget — if the characteristic impedance is above target, no board resistance can meet it; the only levers are lower package L or more ODC. With 0.25 nH and 50 nF, Z0 = 71 mΩ, so no board-level R gets below 71 mΩ across a wide band; a 71 mΩ board R gives a simulated peak of ~100 mΩ (Figure 8.30 compares 20/50/71/100 mΩ). Three observations: (1) Z0 of ODC+package L is the hard floor — if it exceeds half of Ztarget, meeting target at the Bandini frequency is nearly impossible; (2) optimum board R = Ztarget; (3) higher board R needs fewer components and costs less, making "board resistance = Ztarget" the most robust *and* cost-effective guideline. Two count estimates (eqs. 8.77–8.78): enough capacitors that their inductive impedance at fmax is below Ztarget, and that their parallel mounted inductance is below the package lead inductance (diminishing returns beyond that). Final values should still come from circuit simulation.

- **Ch8 §8.15 — one MLCC value on the board: general features** — Case-study baseline: Ztarget = 100 mΩ, fmax = 0.2 GHz, ODC 50 nF/5 mΩ, package 250 pH, cavity 10 mil/Dk 4.3/5 in × 5 in/2.4 nF center-probed, VRM 10 nH/1 mΩ, one 100 µF bulk with 5 mΩ ESR and 5 nH mount. Three profiles (Figure 8.31): (1) ODC + package with shorted board, (2) cavity + VRM + bulk, (3) the full ecology at the die pads. Replacing the short with the VRM/bulk shifts the Bandini peak lower and makes it larger. A single MLCC (1 nH mount assumed, ESR derived from C via the Ch5 model) produces *two* peaks regardless of value (Figures 8.32–8.33): the low-frequency peak is the parallel resonance of bulk inductance ∥ MLCC inductance against the series combination of bulk and MLCC capacitance; the high-frequency peak is MLCC inductance ∥ package inductance against ODC. Adding *any* value reduces the Bandini peak, because the MLCC's ESL parallels the VRM/bulk inductance and lowers the effective inductance the die sees (hence lower characteristic impedance) — but some values reduce it much more than others.

- **Ch8 §8.16 — optimizing the single MLCC value: SRF ≈ Bandini frequency, inductance first** — Without ODC, package L, and bulk properties, no single value can be chosen — so "add 10 µF" application notes are arbitrary. Larger is not better: a single 10 µF and a single 0.16 µF give different profiles (Figure 8.34), and the optimum is when the MLCC self-resonant frequency sits near the existing Bandini peak. The actual dip is slightly *below* the MLCC's own SRF because it is the series resonance of CMLCC with LMLCC + Lmount + Lspreading + Lpackage; the smaller the package lead inductance relative to the MLCC inductance, the closer dip and SRF coincide (Figure 8.35). Matching condition Ltotal·CMLCC = 1/ω²_Bandini, solved for CMLCC ≈ (Lbulk-mount + Lpkg)/((2πf)²·... ) — in the case study it estimates ~160 nF, and the SPICE optimum is 160 nF. Caveat: MLCC tolerances and mounting geometry make sitting exactly on the peak unreliable, and on-die power gating moves the Bandini frequency between use conditions, so use several values with low-Q series resonances to get a broad remedy rather than one high-Q capacitor on a high-Q peak. ESR damping is real (Q = 14 here) but second order in capacitance, whereas peak reduction is roughly first order in mounting inductance: with the same SRF, 1 nH/160 nF gives a 0.84 Ω peak vs 4 nH/45 nF giving 1.65 Ω (Figure 8.36), so "lower mounting inductance is always better" is the golden rule. More identical capacitors are also not better: they add capacitance (good, lowers the low-frequency peak) and parallel the mounting inductances (good, until the total is comparable to package L, here 50 × 1 nH = 20 pH vs 250 pH), but they also parallel the ESRs, removing damping and *raising* the high-frequency peak (Figures 8.37–8.38). A single optimized capacitor can beat 50 identical optimized ones.

- **Ch8 §8.17 — three different MLCC values (10 µF/1 µF/0.1 µF) is folklore** — The common app-note rule is compared with three identical 10 µF at the same 2 nH ESL (Figure 8.39). At low frequency the three 10 µF win (more total C); at high frequency all three have identical ESL so the profiles converge; only the mid-band differs. The pro-mixed argument (each value has a low-impedance point at its own SRF) weakens once realistic ESR is used; the pro-identical argument (at HF they are just three inductors, so a single value gives the lowest impedance) is also incomplete. The correct figure of merit is the *peak* impedance, especially the Bandini peak, which requires simulating the whole ecology (ODC + package + VRM + bulk). Adding MLCCs almost always helps to first order because their mounting inductance parallels the bulk/VRM inductance — capacitor *values* are nearly irrelevant at that order. With the full ecology (Figure 8.40) three mixed values give a slightly *lower* peak than three identical ones only because the small-value capacitors have higher ESR and damp the high-Q Bandini peak; three 2 nH capacitors in parallel give 300 pH, comparable to the 250 pH package lead, so both sets approach the shorted-board limit and are equally risky. Scaling to 100 capacitors (all 10 µF, or 33/33/34 of 10/1/0.1 µF) makes both profiles indistinguishable from a dead short (Figure 8.41): "whether 3 capacitors or 300, if selected arbitrarily the PDN is never better than a dead short," i.e. a large Bandini peak, high cost, and no robustness. Both fixed-value choices "work" only if transient currents are small or their spectral content misses the peak (e.g. ~2 MHz); a 30 MHz component makes both equally bad, and no capacitors might be better.

- **Ch8 §8.18 — optimizing three values: 10 Ω → 0.25 Ω, a factor of 40** — Manual SPICE search over three values finds 1000 nF, 60 nF, and 20 nF giving a peak below 0.3 Ω (Figure 8.42), versus 0.8 Ω for three *identical* optimized capacitors and 10 Ω with no MLCCs. Three different optimized values beat even a dead-short board (0.25 Ω vs the 1 Ω shorted Bandini peak) because the small capacitors' ESR damps the high-Q peak: Z0 = 0.07 Ω with intrinsic Q = 14 becomes a 0.25 Ω peak at Q ≈ 3.5. This is the power of optimization, but the optimum depends on ODC, package L, and each capacitor's ESL — change any one and the values are no longer optimal (Figures 8.43). Hence: optimizing one or three values is only possible with full knowledge of the Bandini Mountain and capacitor models, which is usually unavailable — and if you are going to optimize anyway, why restrict yourself to three values? To first order, a high-Q Bandini needs the board to look resistive at Ztarget near the peak; to second order, values and counts are tuned in simulation to lower the peak further. That is exactly the Frequency Domain Target Impedance Method.

- **Ch8 §8.19 — FDTIM: flat board impedance, minimum capacitor count** — Three guidelines: (1) choose a minimum total count so the board's equivalent inductance is below the package lead inductance — then the Bandini Mountain is the intrinsic ODC ∥ package-L peak; (2) when the Bandini Q is high (peak frequency generally <200 MHz), choose values and counts so the board presents a *flat* impedance near Ztarget, which damps the peak — too low a flat value gives too little damping resistance and the capacitors do nothing, too high a value means the peak never gets below it; (3) when Q is low (peak generally >200 MHz) the peak is insensitive to board losses, so values barely matter and the only job is enough capacitors to keep board inductance well below package L. Procedure: first compute Z0 = √(Lpkg/CODC) and the intrinsic Q, because Z0 sets the achievable floor — if Z0 is not significantly below Ztarget no combination works, and the only remedies are more ODC, less package L, or on-package capacitors (50 nF + 0.25 nH → 0.071 Ω; ~2× Z0 = 0.15 Ω is the practical target). Second, minimize every mounting inductance, because the parallel combination of all MLCC mounting inductances plus cavity spreading inductance is in series with the package lead inductance. Third, count from N such that 2π·fmax·(ESL/N) ≤ Ztarget (and N·... so the parallel inductance ≤ Lpkg): the extreme case fmax = 200 MHz, Ztarget = 1 mΩ, ESL = 2 nH needs ~2500 capacitors — every pH of mounting inductance costs real money.

- **Ch8 §8.20 — selecting values with the FDTIM: 3 values per decade, ESR sets the count** — Vendors stock three values per decade (1, 22, 47), with ~22 µF the practical maximum in small bodies. The *smallest* value usable must have its SRF above the highest Bandini peak: C < 1/((2πfmax)²·ESL); at 200 MHz with 1 nH that is <~630 pF, and with a 0.3 nH mobile-grade mount it drops to ~2 nF. The pool from 22 µF down to 1 nF at three per decade is 14 values. Goal: flat, below Ztarget, over the widest band with the fewest values and fewest parts. Simple automation: pick N per value so that the minimum impedance at that value's SRF — ESR/N — equals Ztarget; then the maxima between the dips are only slightly above target. Caveat: that rule is efficient at low Ztarget and wasteful at high Ztarget, where the large values contribute no damping and one per decade is enough. With ESL = 1 nH, fmax = 200 MHz, Ztarget = 0.1 Ω, the minimum total is ~13 capacitors.

- **Ch8 §8.20 (cont.) — 16 capacitors give a 0.2 Ω peak; five times better than 16 × 10 µF** — A SPICE-optimized 16-capacitor distribution holds a flat impedance near but under 0.1 Ω from 1 MHz to 200 MHz (Figure 8.44); below 1 MHz bulk capacitors must take over, above 200 MHz ODC does. Because the values are discrete, you cannot raise the ripple up to the target without crossing it. Attached to the full ecology (with augmented bulk) the peak drops from 3 Ω to 0.2 Ω (Figure 8.45), close to the 0.15 Ω practical limit. The advantage is that FDTIM needs no knowledge of the Bandini Mountain: 16 × 10 µF would at best make the board a short and leave the 1 Ω intrinsic peak — FDTIM buys a 5× reduction (Figure 8.46). When the Bandini Q is low (peak near 200 MHz) the selection matters much less.

- **Ch8 §8.21 — high-power case: ODC 400 nF, package 2.5 pH, target 5 mΩ** — On-die ESR = 0.25/400 = 0.6 mΩ; Z0 = √(2.5 pH/400 nF) = 2.5 mΩ; intrinsic Q is high (Q ≈ 10 mΩ/2.5 mΩ scale), shorted-board peak 10 mΩ at ~160 MHz (Figure 8.47 matches estimate). For Ztarget = 5 mΩ the VRM must be ≤ ~1 mΩ; with a 3 nH feedback-loop inductance the minimum bulk is L/Ztarget² ≈ 120 µF, and one 200 µF/5 mΩ/5 nH part is used. Board MLCCs must pull a 3 Ω peak toward ~5 mΩ. Counts from the usual two conditions are large and require 0.5 nH mounting. 200 identical capacitors (1 µF or 10 µF — identical profiles) drop the peak from 3 Ω to 20 mΩ, a 100× improvement, but provide no damping: 20 mΩ is 8× Z0, i.e. still high Q, so FDTIM can do better (Figure 8.48). Applying FDTIM yields 135 capacitors across 22 µF–1 nF whose own minima sit just under 5 mΩ (Figure 8.49); in the full ecology the added damping brings the peak below 5 mΩ everywhere except the low-frequency end (Figure 8.50) — fewer parts *and* a lower peak than 200 identical capacitors. The residual ~1 MHz rise is the VRM/bulk parallel resonance, fixed by dropping bulk mounting inductance from 5 to 4 nH and going from 1 to 6 × 200 µF (Figure 8.51).

- **Ch8 §8.22 — controlled-ESR capacitors: buy the damping instead of engineering it** — Controlled-ESR (CES) parts give a broad, flat impedance centered on their SRF, nearly independent of capacitance in the Bandini band (Figure 8.52, 1 µF and 10 µF both 2 nH/1 Ω). Trade-offs: maximum capacitance per body is ~1/10 of a standard MLCC, inductance may be higher, only a few suppliers, current catalog 1 µF and 10 µF at 0.1–1 Ω. They add a third sizing condition to the two earlier ones: in mid-band, enough parts in parallel that the parallel resistance is near and below Ztarget (eqs. for all three conditions). Case 1 (Ztarget 0.1 Ω, ODC 50 nF, package 250 pH, 13 parts): 13 conventional 10 µF merely reproduce the 10 Ω-ish intrinsic Bandini peak, while 13 CES 10 µF/1 Ω drop it to ~130 mΩ ≈ 2× Z0, close to the practical best (Figure 8.53). Case 2 (Ztarget 5 mΩ, ODC 400 nF, package 2.5 pH): 100 CES 0.5 Ω parts give an acceptable profile (Figure 8.54). Design is far simpler than FDTIM but CES costs ~5× conventional; total cost of ownership is less than that premium because assembly cost (identical for both) often dominates. Still no guarantee if Z0 > Ztarget.

- **Ch8 §8.23 — on-package decoupling (OPD): split the peak before it reaches the board** — OPD targets the lowest-impedance, highest-end chips; package real estate is expensive but its finer design rules allow interdigitated or reverse-aspect-ratio parts with mounting inductance ~0.2 nH or less (Figure 8.55), and CES in that configuration is a small cost increment. Only the semiconductor vendor can implement it, so customers should always request it — it lowers board requirements and enables lower Ztarget, though at higher component cost (a purchasing-incentive conflict the book calls out). Example: ODC 400 nF, total chip-to-board 50 pH split 10% chip-attach / 90% package-to-board (0.045 nH); Z0 = 11 mΩ, practical floor ~20 mΩ, high Q so external damping matters, and the board-MLCC minimum at 0.5 nH mount is ~32 (Figure 8.56 equivalent circuit). Criterion 1: the parallel mounted inductance of all OPD must be comparable to or below the package-to-board inductance, otherwise the package-to-board path shorts them out. When met, the Bandini splits into two peaks: the *high*-frequency one from ODC ∥ (L_OPD ∥ L_pkg-board), whose parallel inductance is lower than L_pkg-board alone so the frequency rises and its characteristic impedance falls (lower peak, ref. [10]); the *low*-frequency one from C_OPD with L_pkg-board + L_OPD, always lower in frequency and lower in Z0 than the original Bandini provided C_OPD ≫ CODC (Figure 8.57, 10 × 10 µF at 0.2 nH → 20 pH, half the package-to-board loop). Optimize the OPD value so its SRF matches the no-OPD Bandini peak; 10 × 0.1 µF beats 10 × 10 µF by 60 → 20 mΩ (Figure 8.58) — a few optimized parts beat many large ones. CES OPD is often cost-effective: parallel resistance near Ztarget; here Z0 = 2.5 mΩ, practical floor ~5 mΩ, ideal CES 0.05 Ω but only 0.1 Ω is available, giving ~15 mΩ (Figure 8.59). With 10 CES OPD the profile is stable whether the board is shorted or fully populated (Figure 8.60), and no board MLCCs are needed — versus 43 FDTIM-selected board capacitors (vs a 32-part minimum) for the same result (Figure 8.61). Fewer parts, flatter profile, lower risk of a mis-optimized board distribution; the price is expensive parts on expensive package area.

- **Ch8 §8.24 — multiple chips sharing a rail act as extra decoupling capacitors** — From one die's pads, the other chips on the same rail look like board-level decoupling capacitors with different values: ESL generally *lower* than an MLCC (many power/ground balls in parallel — good, it lowers the parallel inductance), ESR generally *lower* than an MLCC (50 nF on-die ≈ 5 mΩ vs an MLCC's higher ESR — bad, because it adds no damping and can short out damping that exists), capacitance ~50–500 nF, i.e. comparable to MLCCs. Metric: the SRF of the on-die C with package L as seen from the board, f = 1/(2π√(Lpkg·CODC)); for identical dies this equals the Bandini frequency (0.25 nH, 50 nF → ~45 MHz), so the chips present capacitors resonating right around each other's Bandini peak. With many *unoptimized* MLCCs the board is already near a short, so extra low-loss capacitors only slightly reduce the peak — more chips can slightly *help* (Figures 8.62 identical chips split each other's peak; 8.63 non-identical chips give a very slight reduction plus small resonances elsewhere). With *optimized* (FDTIM, damping) capacitors the opposite happens: the extra chips' low ESR/ESL short out the damping resistance and the Bandini peak *grows* (Figure 8.64). Summary rule: added chips may make a poor PDN slightly less poor but a robust PDN slightly less robust.

- **Ch8 §8.25 — the bottom line** — (1) The ecology is every interconnect from die pads to VRM pads; each element dominates some frequency range. (2) ODC provides the low impedance at the highest frequency. (3) The important features are the *peaks* from capacitor–inductor parallel combinations. (4) The most important is ODC ∥ package lead inductance, named the Bandini Mountain. (5) Its two figures of merit are Z0 (sets the floor) and peak frequency (usually 10–100 MHz). (6) Planes only supply low spreading inductance from MLCCs to BGA pads; cavity capacitance/resonance and cavity size barely matter at the die. (7) The main design principle is to bring the Bandini peak reasonably close to Ztarget. (8) Identical values vs three decade values make little difference; without ODC and package-L data, optimizing is hard. (9) Making the board look resistive at Ztarget over roughly 1–50 MHz damps the peak. (10) FDTIM selects values for a flat profile: with Bandini details it reduces the peak, without them it still gives the most robust PDN.
