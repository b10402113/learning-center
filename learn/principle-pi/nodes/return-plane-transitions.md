# 訊號換 return plane 時，如何馴服 SI 問題

## Lesson

訊號換層時，return current 必須在兩個平面之間找路，這條路就是 cavity。這篇解釋 noise 怎麼被激發、為什麼是長距離耦合，以及 thin dielectric 為何同時降阻抗又提高阻尼。
