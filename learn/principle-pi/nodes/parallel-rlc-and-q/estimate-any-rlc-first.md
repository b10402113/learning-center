# 分析 RLC 電路的四項品質指標：從鉭質到 MLCC 電容的實務估算

在設計高速數位電路的電源分配網路（PDN）時，電容絕不是理想元件，而是常被等效成串聯或並聯的 RLC 電路。面對任何實際電容的等效電路，分析的第一步不是立刻套入複雜的模擬，而是先算出描述其核心特性的四項品質指標（figures of merit）。

這四項指標能快速勾勒出電路的阻抗輪廓：

<!--image:1-->

- **共振頻率（SRF）**：串聯共振頻率，常用單位為 MHz。
- **特性阻抗（$Z_0$）**：電路的特徵阻抗，單位為 $\Omega$。
- **品質因子（q-factor）**：電路的品質指標，決定了共振點附近阻抗變化的銳利程度。
- **極值阻抗**：若是串聯 RLC 電路，指的就是共振時的最低阻抗（$Z_{\min}$）；若是並聯電路，則是對應最高阻抗（$Z_{\max}$）。

在計算這四項指標時，通常以電容值 $C$（單位 nF）、電感值 $L$（單位 nH），以及串聯電阻 $R_{\text{series}}$（單位 $\Omega$）為基礎。

以下透過三顆實際電容的參數，觀察這四項指標如何反映出截然不同的阻抗行為。

## 範例一：大型鉭質電容

一顆典型的大型鉭質電容，其串聯 RLC 模型參數如下：

- $C = 1000\ \mu\text{F} = 10^6\ \text{nF}$
- $L = 8\ \text{nH}$
- $R = 0.05\ \Omega$

這類超大電容量的鉭質電容，算出來的 q-factor 非常低。q-factor 低意味著阻抗不會在共振頻率處急遽下墜，因此可以預期它的阻抗曲線會呈現相當平坦的走勢。從被動元件廠商 AVX 針對類似規格（電感較低、SRF 較高）鉭質電容所提供的阻抗曲線來看，整個阻抗輪廓確實非常寬且平緩。

## 範例二：1206 封裝的大型陶瓷電容（MLCC）

接著看一顆採用 1206 封裝、X5R 介電材質的典型大型積層陶瓷晶片電容（MLCC）：

- $C = 10\ \mu\text{F} = 10{,}000\ \text{nF}$
- $L = 3\ \text{nH}$
- $R_{\text{series}} = 0.003\ \Omega$

這顆 MLCC 的串聯等效電阻極低，只有幾個毫歐姆，因此計算出的 q-factor 相對相當大，共振點會呈現非常陡峭的尖銳下陷。

<!--image:2-->

在廠商提供的阻抗資料中（例如 AVX 的曲線），其標示的等效電感常壓在 $1\ \text{nH}$。這種設定比電容實際焊在電路板上、透過過孔（via）連接時能達到的電感值要激進得多。正是因為廠商假設的電感較小，其阻抗曲線所呈現的 SRF 才會略高於最初以 $3\ \text{nH}$ 估算的數值。

## 範例三：0402 封裝的小型陶瓷電容（MLCC）

最後一顆是 0402 封裝、X7R 介電材質的小型 MLCC：

- $C = 1\ \text{nF}$
- $L = 1\ \text{nH}$
- $R_{\text{series}} = 0.16\ \Omega$

與前一個 1206 封裝的大電容相比，這顆小電容的串聯電阻高了約 50 倍。電阻大幅增加的主要原因，在於其內部結構中並聯的導體極板層數遠少於大容值電容。然而，由於它的電容值大幅降低，電路本身的特性阻抗也隨之顯著提高；在電阻與特性阻抗雙雙增加的情況下，兩者相互抵消，最終算出的 q-factor 依然與大型 MLCC 維持在旗鼓相當的範圍內。
