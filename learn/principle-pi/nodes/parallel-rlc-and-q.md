# 並聯 RLC、共振與 q 值

## Lesson

PDN 阻抗曲線上的每一個峰幾乎都是並聯共振，而峰高可以寫成特性阻抗乘上 q。這一節把四個品質指標——共振頻率、Z0、q、峰值——變成拿到任何 RLC 都先估一輪的反射動作。
