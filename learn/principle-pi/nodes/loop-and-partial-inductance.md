# 準靜態近似、內外部電感與局部電感

## Lesson

集總模型只在結構小於二十分之一波長時成立，超過就得改用全波工具。這一節說明內外部電感與集膚深度的分工，並用局部自感與互感把一整條迴路的電感拆到各段上。
