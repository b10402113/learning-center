# Transient current 與阻抗峰方程式

## Lesson

沒有 transient current 就沒有 target impedance。這篇從 CMOS 的 clock-edge 充放電推出電流波形，再用三種刺激把 Z(f) 的 f、Z0、q 換成 droop 與 p-p noise。
