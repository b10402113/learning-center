# 平面的電容、片電感與擴散電感

## Lesson

一對電源與接地平面是一個腔體，低頻看是平行板電容，中頻看是片電感，高頻看是模態共振。這一節先建立平面最常用的兩個量——每平方片電感與徑向擴散電感——並說明為什麼電流從哪裡灌進去會改變結果。
