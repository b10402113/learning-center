# 什麼是電感：磁場、能量與 Maxwell 方程

## Lesson

高頻阻抗幾乎由迴路電感決定，而它同時抬升每一個並聯峰。這一節從磁力線環、磁通密度與儲能建立直覺：電感衡量的是「每安培能圈住多少場線」，不是場線的總數。
