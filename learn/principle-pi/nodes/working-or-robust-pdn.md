# 「能動」的 PDN 與「穩健」的 PDN

## Lesson

把雜訊預算換成可計算的 target impedance，再用 PDN ratio 把「實際峰值」與「目標」放在同一個尺度上比較。這條線把測試台上能跑與真正穩健之間的差距，變成一組可以取捨的成本與風險。
