# 用 shorting via 抑制 cavity 共振

一個 6 吋見方、填 FR4 的 cavity，第一個共振峰落在 500 MHz。這個頻率剛好是半個波長塞進 cavity 長度的頻率。現在在中間加一顆 shorting via，量到的 Z11 幾乎沒動，只把低頻阻抗從電容性拉成電感性。繼續加，加到整個面均勻鋪滿，第一個峰才開始往高頻跑。

要回答的問題是「到底要幾顆、間距多少」：用 `fres = 1/(2π√(Lvia/n · Ccavity))` 把 via 數換成共振頻率，再用 `s ≤ 3·RT[ns]` 把頻率換成間距。

## 一顆沒用，鋪滿才有用

短接同電壓兩平面的 via，和 cavity 阻抗之間的互動很複雜。via 的低電感會和 cavity 的電容形成並聯共振。via 的位置又改掉 cavity 的邊界條件，決定困在裡面的波怎麼反射、來回彈、干涉。要算準得靠 3D field solver，但規則可以推。

先看一個例子，趨勢很清楚：6 吋見方、FR4 的 cavity，從邊緣的接觸點看 Z11，第一個峰在 500 MHz。加 1 顆在正中央，模態共振幾乎不動，只改掉低頻段的阻抗性質。改加 1、4、9、16、25、36、49 顆均勻鋪在整個面上，第一個峰和所有更高階的共振一起往高頻移。顆數越多、間距越密，等效 shorting 電感越低，並聯共振頻率就越高。

「均勻分佈」是關鍵。均勻鋪最能把 via 到 via 之間的 spreading inductance 壓到最低，也最直接影響 cavity 的模態共振。擠成一團，或只在角落補幾顆，分佈不均，效果就對不上這個模型。

## 把 via 陣列讀成一個 LC

第一個峰的頻率，可以近似成「n 顆 via 並聯的 shorting 電感」與「cavity 電容」的並聯共振。離開 via 的 spreading inductance 可以看成一個集中電感，電流穿過它，流到集中在離 via 最遠處半徑上的集中電容。via 的電感和 power plane 的 spreading inductance 是同一個東西，它們產生同樣的磁場。

於是

<!-- derived -->
```
fres = 1 / (2π · √( (Lvia / n) · Ccavity ))
```

其中 Ccavity 用平行板近似，Lvia 近似成和 cavity 間距（也就是 via 長度）成正比，係數與 via 直徑有關：

<!-- derived -->
```
Ccavity = ε0 · Dk · Len² / h
Lvia    = k · h
```

兩個看法會得到同一個結論。一個是「n 個並聯電感，一起餵整個 cavity 電容」；另一個是「一顆 via，只餵它附近那一小塊 cavity 電容」。兩邊的 LC 都隨 via 數上升，所以顆數越多、共振頻率越高。寫成比例關係就是

<!-- derived -->
```
fres ∝ √n
```

這一行是後面所有換算的根：頻率對顆數只有平方根關係，顆數要漲四倍，頻率才翻一倍。

## 從顆數換成間距：波長是間距的六倍

實務上沒有人用「顆數」思考，大家用「間距」。若 via 均勻鋪在方型 cavity 上，間距和顆數的關係是

<!-- derived -->
```
svia-via ≈ Len / √n
```

把長度換成 via-to-via 間距之後，第一個共振頻率的估計式跟著改寫。再加上波長：v 是介質中的波速，`v = c / √Dk`，而 `λres = v / fres`。

接下來是這套方法最漂亮的一步。用 3D field solver 掃過前面的例子（6 吋見方、FR4、10 mil 厚、via 直徑 10 mil），把第一個峰的波長對 via 間距作圖，得到的是一條幾乎筆直的線，經驗擬合是

<!-- derived -->
```
λres = 6 · svia-via
```

波長是間距的六倍；反過來說，一個波長上至少要放六顆 shorting via。這個「6」不是物理常數，它是這批 via 特徵（直徑、孔徑、cavity 厚度）下的擬合結果。換一種 via，這個比例會變，得自己用模擬重新定。

## FR4 上的速算：先 1/f，再 3·RT

FR4 裡訊號速度大約 6 吋/nsec。把 λ = 6·s 代進去，間距（吋）就等於 1 除以頻率（GHz）：

<!-- derived -->
```
s[n] ≤ 1 / f[GHz]        (FR4)
```

想要 suppress 1 GHz 以下的共振，間距就不要超過 1 吋。3D solver 也驗過這件事的另一面：同樣是 1 吋間距，擺在 3 mil 厚和 10 mil 厚的 cavity 上，最低共振頻率都落在約 1 GHz。間距決定的是「允許留在 cavity 裡的最長波長」，所以這個數字和 cavity 大小、介質厚度都無關。

接著把目標頻率換成訊號邊緣。robust 的設計要把第一個共振推到訊號頻寬之外，而頻寬大約是 `0.35 / RT`：

<!-- derived -->
```
f ≥ 0.35 / RT[ns]
s ≤ 1 / f = RT[ns] / 0.35 ≈ 3 · RT[ns]     (單位：吋)
```

`s ≤ 3·RT[ns]` 這個式子其實在講幾何：邊緣在空間上有長度，等於 `v · RT = 6·RT[ns]` 吋；間距是它的一半，就是在邊緣的空間長度上至少放兩顆 via。常見 rule of thumb 是：要 suppress 訊號頻寬以下的 cavity 共振，就在 rising edge 的空間範圍內至少擺兩顆 shorting via，並均勻鋪在 cavity 上。

## 算一個例子：0.5 ns 邊緣要幾顆

拿一條 0.5 ns 邊緣的單端訊號，cavity 是那個 6 吋見方的板子。

<!-- derived -->
```text
RT = 0.5 ns
s  = 3 × RT              = 1.5 in
n  ≈ (Len / s)²          = (6 / 1.5)² = 16 顆
f1 ≈ v / (6 · s)         = 6 / (6 × 1.5) = 0.67 GHz
BW ≈ 0.35 / RT           = 0.7 GHz     → f1 已經在邊緣頻寬之上
```

兩個方向算出來的答案互相對得上：用 `s ≤ 3·RT` 得到 1.5 吋，用 `λ = 6·s` 回頭算第一個峰是 0.67 GHz，剛好壓在 0.7 GHz 的頻寬線上。如果邊緣換成 0.2 ns，間距就得收成 0.6 吋，第一個峰推到約 1.7 GHz，仍然剛好等於 0.35/0.2 ns 的頻寬。這兩個式子是同一件事的兩種寫法。

真實板子上的數字大概長這個樣子：一塊示範板在一般區域用 0.25 吋間距（suppress 到 4 GHz），部分結構收緊到 0.1 吋（10 GHz），最緊做到製程極限的 0.04 吋（25 GHz）。把 `s ≤ 1/f` 倒過來讀就是這張表。

## 這個數字的有效邊界

- **k 是擬合出來的**：波長等於六倍間距這件事，是特定 via 特徵下的結果。via 直徑、cavity 厚度、孔徑一改，六倍這個數字就要重新用 field solver 標定。
- **密集陣列才成立**：這條直線是在 via 密度夠高的區間擬合出來的。「加一顆在正中央」不會把 500 MHz 的模態峰推走，只改低頻阻抗性質。顆數和間距要一起看，不能只看有沒有 via。
- **前提是兩個平面同電壓**：shorting via 只能短接同電壓的平面。這也是「所有 return plane 都用同一種電壓」這條設計規則的來源。
- **要更準還是得靠 3D**：spreading inductance 的分佈和 cavity 損耗讓解析式只能給方向和量級。建議是：均勻鋪、間距照 rule of thumb 抓，然後用 field solver 驗一次。

## 給自己的 checkpoint

- 為什麼中間加一顆 shorting via 幾乎沒效？（模態共振看的是整個面的邊界條件；單點短接只改低頻阻抗性質）
- `fres = 1/(2π√(Lvia/n·Ccavity))` 裡，顆數 n 出現在哪裡、對頻率是什麼關係？（分母的 Lvia/n，fres ∝ √n）
- 6 吋見方 cavity，間距 1.5 吋大約要幾顆？第一個峰在哪？（約 16 顆；約 0.67 GHz）
- 0.3 ns 邊緣要的間距是多少？（s ≤ 3 × 0.3 = 0.9 吋，對應 suppress 到約 1.1 GHz）
