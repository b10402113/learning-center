# Human-in-the-loop：inbox 與 approval

## Lesson

背景 agent 沒有聊天窗，它的介面是 inbox。危險動作先持久化 proposal，等 correlated 的決定，喚醒後重讀再重驗版本。approval 是 harness 的確定性邏輯，agent 不該知道自己被擋。
