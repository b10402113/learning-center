# L1 overview

- **課程入口與站台設定（`index.md`、`.vitepress/*`）** — 入口說明 checkout 事故 agent 的產品形狀、三角色權限（model/harness/service/person/Inngest）、三個頁面（Inbox、Activity、Events）、Neon 與三個 terminal 的啟動方式、branch 對照表。VitePress 提供深色主題、側邊欄、本地搜尋，主題層改寫 diff 區塊的複製行為。
- **六課主線（`01`–`06`）** — 每課固定節奏：Engineering idea → See it in the lab → Live coding（精確 diff）→ Verify → Break it on purpose → Engineering challenge → Catch up。教學弧線是「先把 loop 寫出來，再讓它 durable，再讓它會等，再加人工閘門，再做安全重試，最後讓它會求助」。
- **可執行 demo 的設計** — 每課都绑一組 checkout 啟動旗標（`--fault feature`、`--fault release`、`--fault dependency --recover-after-ms`、`--lose-next-action-response`），並用 `lesson-N` 為起始、`lesson-N+1` 為解答的相鄰 branch。學員切 branch 就能重現，不需重建 DB 或 Inngest 歷史。
- **Capstone（`advanced-lab/index.md`）** — 用四個 trial 把 approval、retry、help、recovery 當成一個系統驗證，並用 world outcome / action trajectory / human boundary 三個維度評分。
