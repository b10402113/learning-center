跑環境檢查，匯出第一個無聲可播檔

Step 3/5 · 開好工作區、匯出第一個可播檔

這一步要完成什麼

資料夾能開，不代表影片工具都已經準備好。這一節要帶你完成一次完整的基本檢查：先請 AI 確認電腦實際裝了哪些工具，等你看懂檢查結果後，再用預附的無聲範例測試 preview 和 export。

完成後，你會得到兩個看得見的結果：一份顯示環境狀態的檢查結果，以及一個可以在電腦上播放的影片檔。這就像先確認廚房的爐子、鍋子和食材都在，再開始煮第一道菜。

動手前需要先具備什麼

  • 工作區已經開好，AI 也讀過說明或計畫。
  • AI 助手能執行你電腦上的指令，包括 Route A 的準備好環境，或 Route B 自己建立的環境。
  • 你會先閱讀檢查結果，不會跳過檢查就直接開始做影片。

第一步：請 AI 檢查裝了什麼

你要做的事：先請 AI 盤點這台電腦目前有哪些工具，並要求它在執行任何設定之前，先說明還缺少什麼。

不要一開始就說「幫我做影片」。先把環境檢查清楚，才能避免做到一半才發現工具沒裝好。這一步是把「我以為裝好了」換成「工具自己回報已經裝好了」。

Route A 的 Windows 準備版工作區需要 Python、瀏覽器和 FFmpeg 才能運作，START-HERE.md 裡也放了這個環境會用到的指令。你可以請 AI 逐一執行這些指令，再用白話說明每個結果。

檢查結果通常會像下面這樣。實際版本可能會依你的電腦而不同：

{
  "python": "3.10.11",
  "python_supported": true,
  "ffmpeg": true,
  "ffprobe": true,
  "playwright": "1.54.0",
  "Pillow": "12.1.1",
  "numpy": "2.2.6"
}

你要檢查的不是版本號，而是每一項是否存在且可用。

  • Python 是否存在，而且版本受到支援。
  • FFmpeg 和 FFprobe 是否存在。
  • Playwright 是否安裝。它負責開啟瀏覽器並擷取畫面。
  • Pillow 和 NumPy 是否存在。

如果任何項目顯示為 false，或結果中完全沒有這個項目，先停下來補齊環境。不要帶著半套工具繼續跑，否則後面的錯誤會像骨牌一樣一個接一個出現。

如果你需要本機安裝或補齊工具的操作說明，請參考 Foundation 4.1 與 4.2。

第二步：用無聲範例測試 preview 與 export

環境檢查通過後，才進行這一步。現在要確認的不是正式影片內容，而是「渲染」這條路能不能走通：畫面能不能預覽，以及影片檔能不能匯出。

準備好的下載內容裡附了一個很小的無聲場景。它包含一個 idea.md，會依序經過 PLAN、BUILD、REVIEW 三個步驟，最後產出大約八秒的無聲畫面。

這個範例沒有旁白是正常的。這次請先把注意力放在兩件事：

  1. preview 能不能正常顯示畫面。
  2. export 能不能產生影片檔。

你要做的事：在 Windows 準備版工作區中，使用專案自己的 Python 執行 demo.py：

# 在 Windows 準備版工作區裡，用專案的 Python 執行
.venv\Scripts\python.exe demo.py my-first-lesson

# 也可以指定直式畫面或線條風格
.venv\Scripts\python.exe demo.py my-first-lesson --format tall
.venv\Scripts\python.exe demo.py my-first-lesson --style line

這個指令會建立一個合成練習。執行完成後，請檢查渲染結果是否出現在 videos/silent-first-scene/05_render/ 這類輸出資料夾中。

這個工作區有一個適合初學者的保護設計：已經存在的 slug 不會被覆蓋。因此，即使你需要重跑測試，也不用擔心把先前的結果蓋掉。

如果你的電腦不是 Windows：.venv\Scripts\python.exe 是 Windows 的路徑寫法。請改用你的作業系統呼叫 Python 的方式。若不確定怎麼改，請要求 AI 依你的系統給出對應指令，並說明它和 Windows 寫法的差別。

第三步：打開檔案，確認它真的會播

你要做的事：找到剛才產生的影片檔，直接點開播放。

這一步看似簡單，卻不能省略。命令列沒有報錯，只代表程式順利結束；真正打開檔案並看到畫面動起來，才代表輸出的影片確實可用。

如果影片沒有聲音，請不用擔心。這個範例本來就是無聲測試。只要畫面能播放，就代表環境已經通過目前最基本的考驗。

做完長什麼樣

完成後，你應該能確認兩件事：

  1. 環境檢查結果顯示需要的工具都在，而且版本可用。
  2. 輸出資料夾裡有一個可以在電腦上播放的影片檔。

如果兩項都成立，就表示這台電腦已經能跑起工作區，也能把畫面渲染成影片。你已經拿到整個模組第一個「看得到」的成果。

這一節先只確認流程能不能跑通。至於為什麼需要這些工具、每個工具在背後負責什麼，屬於原理內容，會在對應階段再說明。

小結

先請 AI 實際檢查環境，並在動手設定前說明需求；確認工具齊全後，再用預附的無聲範例測試 preview 和 export。最後打開輸出檔案，看到畫面能播放，就代表環境已經通了。

現在你已經檢查過環境，也匯出過第一個測試檔。下一節要使用 workspace 的新專案指令，建立課程專案 meeting-note-explainer，而且不會動到這次的範例。
