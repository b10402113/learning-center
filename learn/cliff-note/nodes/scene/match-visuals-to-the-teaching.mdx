# 用畫的，還是用真的？

<LearningGoal>
依觀眾下一步要做什麼，判斷該用乾淨手繪介面還是真實截圖，並說明選錯會發生什麼事。
</LearningGoal>

## Lesson

先問觀眾下一步是要懂概念還是實際操作——懂概念用乾淨的手繪介面，要操作就用真實截圖，並讓觀眾知道示意圖只是示意。
