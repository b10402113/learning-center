# 把畫面逐格驗證一遍

<LearningGoal>
在最忙的一格讀關鍵字是否準確、強調是否單一、有沒有跟旁白同步，再用靜格與縮小視窗做最後確認。
</LearningGoal>

## Lesson

停在最忙的一格讀關鍵字、確認一次只強調一個且與旁白同步、用靜格抓重疊並預留字幕與角色的空間、配旁白播放抓節奏，最後縮小視窗確認小尺寸仍讀得到。
