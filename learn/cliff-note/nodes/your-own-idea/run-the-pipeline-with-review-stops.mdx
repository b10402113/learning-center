# 用同一條管線跑，每個交接點都停下來看

<LearningGoal>
請 AI 照著同一條管線做，並在每個交接點停下來交付成果，同時說出每個階段的產出，選一個想在往下走之前先做的決定並存成規則。
</LearningGoal>

## Lesson

因為你已知道每段產出什麼（腳本、旁白、時間碼、視覺計畫、預覽、匯出），可以主動請 AI 照管線走、並在每個交接點停下交付成果；每次停下來挑一個想先做的決定，若是每次都想要的決定就存成規則，如此便把一個成功的成品升級成一條你能控制的流程。
