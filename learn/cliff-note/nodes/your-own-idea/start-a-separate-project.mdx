# 保留範例，另開一個新專案

<LearningGoal>
在不動到已完成範例專案的前提下，開一個自己的新專案資料夾，沿用共用的階段指令與繪圖工具，並寫出一份講清楚觀眾、來源、目標的新 brief。
</LearningGoal>

## Lesson

先保留完成的範例專案當作對照，再請 AI 用工作區的開新專案程序另開一個資料夾；階段資料夾（01_voice 到 05_render）與繪圖 runtime 跨專案共用、直接沿用，最後替新專案寫一份講清觀眾、來源、一個目標的 brief，並要求 AI 在寫腳本前先給你看。
