# 先小量測試，再匯出真正的 MP4

<LearningGoal>
先跑一次小量測試匯出，再打開真正的 MP4 檢查畫面、聲音與修正是否都在；若它和瀏覽器預覽不一致，知道要回報第一個分歧的時刻。
</LearningGoal>

## Lesson

匯出會把瀏覽器場景在每個時間點畫成一張張畫面再與音訊合成，所以同一個時間點每次都要畫出同樣的圖；標準順序是先請 AI 說明這個 workspace 的匯出方式，先跑一次小量測試，再打開真正的 MP4 檢查畫面、聲音與修正是否都在，若與預覽不一致就回報第一個分歧的時刻，修好短測試後才做完整匯出。
