# 存下可重現的指令，收攏整條流程

<LearningGoal>
把能重現匯出的指令與資源設定保存下來，把審過的影片檔和一行修改註記留在專案裡，並說出五階段各自「誰動手、你檢查什麼」。
</LearningGoal>

## Lesson

把能重現匯出的指令（`python anim.py render meeting-note-explainer --phone --workers 1`）、資源設定、輸出檔名與一行修改註記一起留在專案的 render 資料夾，因為值錢的是能重複產出的方法而不只是成品；收尾時回頭看五階段（Voice → Words → Storyboard → Scene → Export），AI 動手做檔案，你負責導一個修正並驗收結果。
