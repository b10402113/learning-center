# 用觀眾的眼睛把預覽看一遍

<LearningGoal>
把配著旁白的預覽從頭到尾播完一次，記下第一個讓你聽不懂、或讀不到旁白要你注意什麼的時刻。
</LearningGoal>

## Lesson

先把自己當成第一次看影片的觀眾，把配好旁白的預覽不暫停播完一次，記下第一個讓理解中斷的時刻（聽不懂或讀不到），再用一句話描述「大約在哪個節拍、發生了什麼」；一次只留一個卡點，因為第一個卡點最明顯也最值得修。
