# 靜格與播放：修好了沒有？

<LearningGoal>
分辨靜格與播放各自能抓到什麼問題，並用真正的預覽（從上一個節拍播進來）判斷這次修正到底有沒有用。
</LearningGoal>

## Lesson

靜格抓的是空間問題（文字讀不讀得到、元素有沒有重疊），播放抓的是時間問題（畫面有沒有跟旁白一起到、停留夠不夠久），兩者互補；驗收修正的預設動作是讀改過的靜格、再從上一個節拍播進修改處，並用真正的預覽而非 AI 的文字說明下判斷。
