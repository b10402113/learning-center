# 對照旁白審分鏡：畫面有沒有回答聽到的話

<LearningGoal>
邊聽旁白邊讀計畫，用「這個畫面有沒有回答我正聽到的那句話」判斷一個 beat 該留還是該改，並知道重要文字要留多少時間才讀得完。
</LearningGoal>

## Lesson

審分鏡時要用「光看這個畫面，能回答我正在聽到的那個問題嗎」這個判準，在工作與裝飾搶同一刻時讓工作優先；典型反例是旁白說 Friday、畫面卻在動裝飾資料夾，應改成顯示截止日並留足夠時間讓觀眾讀完。
