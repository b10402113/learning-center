# 這個階段產出什麼：逐字稿與分鏡計畫

<LearningGoal>
說出這個階段在整條流程裡的位置、它會產生的兩個檔案，並解釋為什麼「每句話配什麼畫面」的計畫是一個可以逐句檢查的文字檔，而不是黑箱。
</LearningGoal>

## Lesson

這個階段把選定的旁白變成兩份東西——一份逐字稿＋時間檔（事實），一份 cues 分鏡計畫（決定，每句話配一個畫面工作）；計畫是可讀、可改的文字檔，所以你能逐句檢查，而不是把它當黑箱。
