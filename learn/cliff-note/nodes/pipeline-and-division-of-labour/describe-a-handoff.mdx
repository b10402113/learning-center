# 每段交接都問三件事：輸入、產出檔、檢查點

<LearningGoal>
能用「輸入 / 產出檔 / 檢查點」三行描述任何一段交接，並以 voice 階段示範寫出一份可檢查的交接筆記。
</LearningGoal>

## Lesson

任何一段交接都能用三行講清楚——輸入（它讀到什麼）、產出檔（它寫出哪個檔案）、檢查點（你看什麼才放行）。以 voice 階段為例，輸入是一份審過的腳本，產出是一段錄好的 take，檢查點是完整聽一遍確認意思與語氣；完成的標準是能講出一個把工作往前推的檔案，並說出自己會檢查什麼。
