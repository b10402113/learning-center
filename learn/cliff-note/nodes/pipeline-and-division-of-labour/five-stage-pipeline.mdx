# 五個階段：Voice → Words → Storyboard → Scene → Export

<LearningGoal>
能依序說出 Voice → Words → Storyboard → Scene → Export 五個階段，並說明為什麼要把做影片的工作切成這幾段。
</LearningGoal>

## Lesson

一支旁白動畫由五個依序接力的階段完成：Voice（先有旁白）、Words（把旁白變成帶時間碼的文字）、Storyboard（排每句話配什麼畫面）、Scene（把分鏡做成動畫）、Export（合成並匯出影片檔）。切成階段是為了讓每一段都有明確產出、都能單獨檢查與修正，這正是早期攝影棚就在用的分工，只是把當年的人換成了 AI；整條管線裝在一個專案資料夾裡。
