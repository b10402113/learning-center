# 看懂五階段與「AI 動手、你檢查」的分工

## Learning goal

說出 Voice→Words→Storyboard→Scene→Export 五階段，並能用「輸入 / 產出檔 / 檢查點」描述任何一段交接。

## Steps

1. [[learn/cliff-note/nodes/pipeline-and-division-of-labour/ai-does-you-direct|AI 做檔案，你導演結果]] — 認清誰做檔案、誰負責導演與檢查
2. [[learn/cliff-note/nodes/pipeline-and-division-of-labour/five-stage-pipeline|五個階段：Voice → Words → Storyboard → Scene → Export]] — 記住五階段順序與「為什麼要分階段」（after step 1）
3. [[learn/cliff-note/nodes/pipeline-and-division-of-labour/describe-a-handoff|每段交接都問三件事：輸入、產出檔、檢查點]] — 用三行描述任一段交接（after step 2）
4. [[learn/cliff-note/nodes/pipeline-and-division-of-labour/capture-your-idea|先寫下你自己的題目]] — 產出一句可重用的題目備忘（after step 3）

## Lesson

這節課要你先把整條流程的樣子看清楚，再回頭動手。做一支旁白動畫不是一個大動作，而是五個小階段接力：先有聲音（Voice），再把聲音變成帶時間碼的文字（Words），接著排「哪句話配什麼畫面」的分鏡（Storyboard），然後讓 AI 把分鏡做成一幕一幕的場景（Scene），最後把所有東西匯出成一個影片檔（Export）。

在這條輸送帶上，每一次把工作交出去都是一次「交接」：上一段留下一個檔案，下一段讀它、再產出下一個檔案，而你要在中間停下來檢查，確認這一段的產出真的對。這節課不只要你能背出五階段的名字，更要你能對任何一段交接講出三件事——它吃什麼（輸入）、它吐出哪個檔（產出檔）、你要看什麼才知道可以往下走（檢查點）。學會這三件事，後面每一節的實際操作都會變得好判斷：你知道現在在哪裡、成品長什麼樣、要檢查什麼。
