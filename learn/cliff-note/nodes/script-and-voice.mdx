# 腳本與旁白

## Learning goal

對照來源寫出並審過一份腳本，再做或選一段聽完整的 voice take。

## Steps

1. [[learn/cliff-note/nodes/script-and-voice/draft-the-script|先拿到腳本：把 brief 與 note 交給 AI]] — 用明確的指令讓 AI 從 brief 與原始 note 起草口語腳本初稿
2. [[learn/cliff-note/nodes/script-and-voice/review-the-script|審腳本：對照來源，留下你能用的版本]] — 刪掉來源沒給的細節、改順拗口句，存成要用的腳本（after step 1）
3. [[learn/cliff-note/nodes/script-and-voice/choose-the-voice-route|選旁白路線：自己錄，還是用語音服務]] — 在兩條路線間取捨，並先確認授權、成本與設定（after step 2）
4. [[learn/cliff-note/nodes/script-and-voice/listen-and-fix|聽整段、修一句：選定要用的 voice take]] — 開著腳本整段聽、針對一句修正、記錄選定版本（after step 3）

## Lesson

這個節點處理整條管線的源頭：影片要講什麼。1.3 已經把 brief 和原始 note 準備好了，這裡要把它們變成一串可以照著念、也可以照著算時間的句子，並且做出一段聽得過的旁白。

分工是這樣：AI 負責讀資料、起草、寫檔、跑語音；你負責決定「這句話對不對、這段聽不聽得懂」。順序不能顛倒——先看過腳本再讓它做音訊，因為一旦有了錄音，之後每一張畫面的時間都會綁在這段錄音上，改句子就等於全部重來。所以先把文字定下來，是這一節反覆強調的省事原則。

四個步驟沿著這個順序走：先拿到腳本、再對照來源審一遍、接著決定旁白要用哪條路線做、最後整段聽完並修掉有問題的那一句。做完之後你手上會有一份審過的腳本和一段聽過的錄音，下一節（時間碼與分鏡）就從這段真實的錄音去推算每句話落在哪裡。
