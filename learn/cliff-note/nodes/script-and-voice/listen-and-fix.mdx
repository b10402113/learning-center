# 聽整段、修一句：選定要用的 voice take

<LearningGoal>
能開著腳本整段聽完旁白，抓出漏字、專有名詞與節奏問題，針對一句修正後在上下文裡重聽，並記錄選定的版本交給下一個階段。
</LearningGoal>

## Lesson

旁白產生後要開著腳本整段聽完，核對名字、關鍵字與節奏；有問題只針對那一句修，改完放回上下文重聽，最後保留選定的腳本與 take 並記錄版本，因為之後每張畫面都會綁在這段真實錄音上。
