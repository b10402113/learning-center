# 先拿到腳本：把 brief 與 note 交給 AI

<LearningGoal>
能下一個包含「觀眾、要懂什麼、先看腳本再做音訊」的指令，讓 AI 從 brief 與原始 note 起草一份口語腳本初稿，並知道這份初稿存到哪裡。
</LearningGoal>

## Lesson

請 AI 寫腳本時，指令要包含三塊：材料（brief 與 note）、方向（觀眾是誰、要懂什麼）、以及檢查點（先看腳本再做音訊）；腳本會被寫成 `01_voice/script.md`，先有文字、後有聲音，改句子才發生在最便宜的時候。
