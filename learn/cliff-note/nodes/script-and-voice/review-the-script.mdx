# 審腳本：對照來源，留下你能用的版本

<LearningGoal>
能判斷腳本裡哪些細節是來源沒給的、該刪掉，並把拗口的句子改簡單，最後存成要交給旁白錄製的版本。
</LearningGoal>

## Lesson

審腳本要分開「正確」與「好念」：先逐句對照來源刪掉 AI 自己補的細節，再把念不順的句子改成更簡單的說法，只改說法不改細節，最後存成 `01_voice/script.md`。
