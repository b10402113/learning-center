# 選旁白路線：自己錄，還是用語音服務

<LearningGoal>
能在「自己錄音」與「用語音服務」之間做出選擇，並在送出語音請求前確認授權、成本與工作區設定。
</LearningGoal>

## Lesson

旁白有兩條路線——自己錄（免費、留正本）與語音服務（可能付費、必須用有權使用的聲音）；走服務前先請助理說明設定與費用，用 `--dry-run`／`--check` 看過再送出，全程都在同一個專案裡完成。
