# 跑環境檢查，匯出第一個無聲可播檔

<LearningGoal>
能照「先檢查、再說明、才動手」的順序跑通環境，並用預附的無聲範例匯出一個真的播得出來的片段。
</LearningGoal>

## Lesson

先請 AI 檢查實際裝了什麼並說明需求，再跑設定指令；用預附的無聲範例測 preview 與 export，把輸出檔打開來播，看到畫面會動就代表環境通過。
