# Digest — 1.3 Get the Workspace Ready with Your AI

## Overview (L1)

- Lesson 1.3 of Module 1 ("Your First Animation"); it moves from watching the whole process (1.2) to getting a workspace ready for the learner's first animation, using one small example throughout: a short animation that teaches how a meeting note ("Sam will send the draft on Friday") becomes a clear action card.
- Two starting routes: Route A opens the prepared "Animation & Voice Workspace" in the Premium Vault and downloads `animation-voice-workspace-2026-09-29.zip`; Route B builds an equivalent workspace in an empty folder with the AI, from the five-stage overview.
- Whichever route, the AI must inspect what is actually installed and explain what it needs before running setup; the prepared Windows workspace uses Python, a browser and FFmpeg, with its own commands in `START-HERE.md`.
- The prepared package includes a tiny silent scene used only to check that preview and export work (a setup test, so having no voice is fine); the real lesson project follows the voice-first order seen in 1.2.
- Once setup is ready, the learner creates a separate project named `meeting-note-explainer`, gives the AI the note and asks for a brief covering who is watching, what they should understand, and what the finished animation should help them do — then reads the saved source and brief before moving on.
- Stopping point: the folder opens, the assistant can explain how it works, and source + reviewed brief are saved in the project; the script and voice come next in 1.4.

### route-b-build-your-own

- Locator: `[[sources/cliff-note/20261006/3-1.3 Get the Workspace Ready with Your AI/video.en.vtt#route-b-build-your-own]]`
