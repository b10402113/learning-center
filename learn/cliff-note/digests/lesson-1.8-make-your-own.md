# Digest — 1.8 Make the Next Video with Your Own Idea

## Overview (L1)

- Closing lesson of Module 1 ("Your First Animation"): the learner takes the completed meeting-note example and runs their own small idea through the same workspace pipeline.
- Core move: keep the finished (`meeting-note-explainer`) project intact and create a separate project folder with its own source and brief, reusing the stage instructions and drawing tools.
- The value of walking the pipeline once is that the learner now recognizes each output (script, voice, word timings, cues, scene, export) and can direct the assistant at each review point.
- Preferences that helped (shorter sentences, larger source text, keeping the source visible during comparison) are saved as reusable instructions and read at the start of the next project; Foundation 4.4 covers project instructions.
- Change scope determines the re-run point: new narration refreshes voice/timings; a style-only change can keep the reviewed voice but must still teach the same idea.
- Finish by showing the export to someone unfamiliar, asking what they understood, applying one concrete correction, and sharing the result (export, tools, one change). Bonus lessons cover custom assets and other animation techniques.

## Sections (L2)

### choose-your-idea

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#choose-your-idea]]`
- Summary: After completing one full example, the learner picks a small idea from their own work and uses the same workspace to explain it.
- Key claims: candidate ideas are a step clients keep asking about, a short lesson for your team, or one part of a process that is clearer when seen; the example "Sam note" was fictional practice material, so the new topic needs its own real facts.
- Learner-relevant: anchors the whole lesson on a concrete self-chosen subject rather than the demo content.

### keep-project-create-new-folder

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#keep-project-create-new-folder]]`
- Summary: Preserve the finished meeting-note project and ask the AI to create a separate project folder for the next video.
- Key claims: the first project is kept intact (its voice, scene and export are retained); the new project gets its own source and brief.
- Learner-relevant: establishes the safe-reuse pattern — don't overwrite the working example.

### reuse-instructions-and-fresh-brief

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#reuse-instructions-and-fresh-brief]]`
- Summary: Reuse the shared stage instructions and drawing tools, then write a fresh brief capturing audience, source material, and the one outcome the viewer should understand.
- Key claims: the AI can draft the brief with you just as in the example; the shared stage folders (`01_voice` … `05_render`) and drawing runtime are reused across projects.
- Learner-relevant: gives the repeatable "new project" opening procedure and the brief fields to fill.

### review-each-handoff

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#review-each-handoff]]`
- Summary: Because the learner now knows what each stage produces, they can ask the assistant to follow the pipeline and stop for review at each handoff, choosing which decision they want to make before it continues.
- Key claims: the handoff outputs are script, voice, word timings, visual/storyboard, narrated preview, and final export; a preferred decision can be saved as a rule so the next run starts with the same expectation; the brief can explicitly require reading `PREFERENCES.md` and stopping for script review before creating the voice.
- Learner-relevant: turns one successful run into a controllable, repeatable workflow.

### carry-preferences-forward

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#carry-preferences-forward]]`
- Summary: Keep the preferences that helped and have the AI write them as reusable instructions that it reads when starting the next project.
- Key claims: example preferences are shorter spoken sentences, larger source text, and keeping the original information visible during a comparison; service accounts and voice permissions still need their own valid setup for each new project; Foundation 4.4 (Project Instructions) goes deeper.
- Learner-relevant: a concrete list of reusable preferences and the external dependency (accounts/permissions) to re-check.

### start-small-and-scope-changes

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#start-small-and-scope-changes]]`
- Summary: Start with roughly 30 seconds and one idea, check the output at each stage, and match the re-run scope to the kind of change.
- Key claims: changing the narration requires updating the dependent voice and timings; changing only the visual style can keep the reviewed voice but must be checked so the new look still explains the same thing; telling the assistant which stage changed tells it where to start the revision.
- Learner-relevant: decision rule for what to regenerate when you revise.

### review-export-and-share

- Locator: `[[sources/cliff-note/20261006/8-1.8 Make the Next Video with Your Own Idea/video.en.vtt#review-export-and-share]]`
- Summary: Watch the finished export, show it to someone unfamiliar to learn what they understood, apply one concrete correction, and share the result with the tools used and one thing changed.
- Key claims: viewer response picks the next correction; the share prompt is the export + tools + one review change; the workspace is now something the learner can keep improving, and bonus lessons cover adding own assets or trying another animation technique.
- Learner-relevant: closes the loop with an external check and seeds the next module (bonus techniques).
