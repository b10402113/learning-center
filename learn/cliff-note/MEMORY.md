# MEMORY — cliff-note

## Goal
用 AI 從頭到尾做出一支簡短的旁白動畫，整個流程自己走一遍：寫腳本 → 做旁白 → 排分鏡/時間碼 → 讓 AI 生成場景 → 匯出成影片檔。學會「自己出主意、讓 AI 動手、自己檢查結果」這個分工，而不是親手寫動畫程式。

## Why
這是「AI Animations & Workflows」課程的入門模組（Module 1: Your First Animation）。想學會用 AI 把一個小想法變成看得懂的動畫，先照課程的範例完整走一次，之後能換成自己的題目重複使用。

## Prior experience
- 初學者：沒有 code-based 動畫或 motion graphics 經驗
- 沒有寫過程式；動畫由 AI 產出，自己不寫 code
- 腳本、旁白、分鏡都交給 AI 起草，自己負責選題與檢查
- 未說明其他背景

## Anchors
- 課程的共同範例：便利貼「Sam will send the draft on Friday.」→ 一張動作卡片（Action / Owner / Due day）
- 工作目錄會放在自己電腦上的專案資料夾（課程用 `meeting-note-explainer`）
- 自己的一個小題目（1.8 要用：想解釋給誰聽、他們要懂什麼）
- 一般聊天式 AI 助手（課程提到也可以用一般 chat，自己存檔、自己執行）

## Habits & constraints
- 未說明。預設：以課程節奏逐課進行，每課收在一個「跑得起來、看得到」的結果
- 環境：Mac（darwin）；課程示範的準備版 workspace 是 Windows（Python + 瀏覽器 + FFmpeg），需注意平台差異
- 成本敏感：優先走免費/本地路徑，必要時才用付費語音與生圖

## Knowledge type
Procedural（偏重「做」）。核心是動手走完五個階段——寫腳本、做旁白、排時間碼、生成場景、匯出。概念只為支撐當下的操作而即時補上。

## How to teach me
初學者導向：先講清楚「這一步在整條流程的哪裡、要吃什麼、產出什麼檔案、我要檢查什麼」，再示範操作。每一步都對應課程的分工（AI 動手、我檢查）。不要一次倒太多程式或術語；用共同範例「Sam / Friday」說明，收在一個看得到的畫面或影片檔。
