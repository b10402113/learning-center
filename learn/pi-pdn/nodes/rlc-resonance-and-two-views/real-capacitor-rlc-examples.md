# RLC 電路與真實電容的例子

上一步留下三個元件需要測試：一顆鉭電容、一顆 1206 封裝的 10 µF 電容，以及一顆 0402 封裝的 1 nF 電容。問題是，四個性能指標能不能預測每個元件會如何影響阻抗曲線？

這裡的每顆電容都用串聯 RLC 電路來建模。電容量是 C，元件內部與安裝時產生的電感是 L，而串聯電阻則是 R。在資料表上，這個電阻會標示為 ESR。

## 看曲線前先算出四個數值

任何 RLC 電路都有四個性能指標：諧振頻率、特性阻抗、Q 值，以及最大或最小阻抗。書上的建議是，分析任何電路時，第一步都先計算這四個數值。

公式中的單位如下：SRF 使用 MHz、Z0 使用 Ω、C 使用 nF、L 使用 nH。

Zmin 是串聯電路的最低阻抗，Zmax 則是並聯電路的最高阻抗。電容是串聯 RLC 電路，因此以下三個元件的性能指標是 Zmin。

## 三個元件，一張表

| | 鉭電容 | 1206 10 µF | 0402 1 nF |
| --- | --- | --- | --- |
| C | 1000 µF = 10^6 nF | 10 µF = 10,000 nF | 1 nF |
| L | 8 nH | 3 nH | 1 nH |
| Rseries | 0.05 Ω | 0.003 Ω | 0.16 Ω |
| Z0 | 2.8 mΩ | 17 mΩ | 1 Ω |
| SRF | 56 kHz | 0.92 MHz | 159 MHz |
| q | 0.057 | 5.8 | 6.3 |
| Zmin | 0.05 Ω | 0.003 Ω | 0.16 Ω |

這張表是依公式計算出的結果，不是實測數據。每個數值都是把書中提供的各元件參數代入上一步的公式算出來的。

## 範例 1：大型鉭電容

把這顆鉭電容建模為串聯 RLC 電路，其中 C = 1000 µF，也就是 10^6 nF；L = 8 nH；R = 0.05 Ω。

Z0 = √(8 / 10^6) = 2.8 mΩ。這比上一步的 1 Ω 電路低了三個數量級。

q = Z0 / Rseries = 0.0566。阻抗曲線最低點為 Z0 / q，也就是 0.05 Ω 電阻的阻值。

q = 0.057，遠低於代表臨界阻尼的 1/2。預期不會出現尖銳的特徵，只會有一道平緩而寬廣的凹谷。

AVX 公布了一款類似電容的阻抗曲線；那款電容的 L 更低、SRF 更高，曲線非常寬廣平坦。這就是低 q 在圖上的樣子。

## 範例 2：1206 封裝的 10 µF MLCC

取 C = 10 µF，也就是 10,000 nF；L = 3 nH；Rseries = 0.003 Ω。

Z0 = √(3 / 10,000) = 17 mΩ。SRF 約為 0.92 MHz。q = 17 mΩ / 0.003 Ω ≈ 5.8，而 Zmin 為 0.003 Ω。

書上稱這個 q 值相對較高，也直接指出原因：串聯電阻非常低。預期會出現尖銳的諧振。

AVX 自己為這個元件繪製的曲線採用 L = 1 nH。對於安裝在電路板上並透過導通孔連接的 1206 元件來說，這個數值遠低於一般能達到的程度，因此 AVX 算出的 SRF 比上面的估算值略高。

## 範例 3：0402 封裝的 1 nF MLCC

這裡 C = 1 nF、L = 1 nH、Rseries = 0.16 Ω。

Z0 = √(1 / 1) = 1 Ω。SRF 約為 159 MHz，而 q = 1 Ω / 0.16 Ω = 6.3。Zmin 為 0.16 Ω。

它的電阻約是 1206 元件的 50 倍。原因是並聯的導體層數較少。

較高的特性阻抗讓 q 值回升，因此即使這兩個元件並不相同，最後的 q 值仍然相近。

## 為什麼 ESR 低不代表一定比較好

q 等於 Z0 除以 Rseries。若 Z0 不變而 R 降低，q 就會升高。對串聯 RLC 電路而言，畫在曲線上會形成更深、更窄的凹谷；對並聯電路而言，則會形成更高、更窄的峰值。

這三個元件並不是只讓 R 逐步變化，因為 Z0 也會跟著變。從 0402 換成 1206 時，Z0 約下降 60 倍，R 則約下降 50 倍，因此 q 幾乎沒有變化。

所以，單看 ESR 低並不能說明太多。它會讓元件原本就有的諧振變得更尖銳，也會延長時域中的電流振鈴。鉭電容則呈現另一種取捨：0.05 Ω 的電阻相較於 2.8 mΩ 的 Z0，讓 q 降到 0.057，形成平坦的曲線，並抑制振鈴。

## 凹谷不會降到零

真實電容並不是教科書裡的理想 RLC 電路。它的最低阻抗就是串聯電阻，因此 1206 元件的凹谷最低到 0.003 Ω，0402 元件則最低到 0.16 Ω。

<!--image:3-->

當要求元件在自己的 SRF 下讓電源軌維持穩定時，這個最低阻抗就是重要的數值。

這些公式並非只適用於電容。下一步會把封裝的一段引線電感和晶片上的電容量放在一起，並從兩個角度觀察同一組元件：從晶片端看是並聯峰值，從電路板端看則是串聯凹谷。
