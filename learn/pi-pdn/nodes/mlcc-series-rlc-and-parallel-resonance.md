# 實用 MLCC：series RLC、並聯與兩顆電容之間的 PRF

## Lesson

一顆真實 MLCC 在實用頻段內就是 series RLC：低頻由 C 決定、高頻由 ESL 決定、SRF 處最低是 ESR。這個 node 的轉折點是「兩顆不同容值的電容並聯會生出 parallel peak」，這也是之後所有 MLCC 選值爭論的根源。
