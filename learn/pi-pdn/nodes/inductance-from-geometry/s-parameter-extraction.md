# 用 3D solver 的 S-parameter 反抽迴路電感

上一節的三條法則都只適用於準靜態情況，本質上也都是近似。它們能快速估算，但無法回答「這個結構的實際電感是多少？」要得到答案，得交給 3D solver 計算電磁場。

## 先把 port 2 短路

對於任意形狀的幾何結構、特殊形狀 plane 的耦合，以及 via clearance hole 這類由邊緣場主導的結構，只有 3D field solver 才有機會給出合理答案。它會直接求解 Maxwell 方程式，並套用導體與介質的邊界條件。

先記住書上的一句警告：答案你一定拿得到。難的是確認答案是否真的對應你的問題，以及你是否敢相信它。

書上的範例是一對 power-ground via，連接 BGA 底下的焊球與板子底部的去耦電容。電路板是 8 層板，總厚度 62 mil；via 直徑為 10 mil，間距為 40 mil。

這個問題設成 two-port。板頂的 port 1 接在 power ball 與 ground ball 的 pad 之間；板底的 port 2 則接在兩根 via 之間，也就是電容預定的焊接位置。

直接查看 S2P 檔案沒有太大用處。要抽取電感，得先把 port 2 的 port impedance 設為 0 Ω，再重新模擬一次。

這麼一來，遠端就形成短路。電流從一根 via 流下去，再從另一根 via 流回來，構成完整的迴路。

<!--image:1-->

solver 回報的 S11，是從 port 1 的 50 Ω 源看進這個迴路時的反射。書上的預期是看到 180 度相位差，並且在 Smith chart 上從最左側開始。這表示阻抗很低、接近短路，符合預期。

## S11 不是答案，Zin 才是

S11 是反射係數，不是阻抗。訊號從 Z1 看向 Z2 時，反射係數為 Γ = (Z2 − Z1)/(Z2 + Z1)。

<!--image:2-->

當 Z1 為 50 Ω 時，這個 Γ 就能直接換算出看進迴路的輸入阻抗：

`Zin = 50 × (1 + S11) / (1 − S11)`

由於 S11 是複數，Zin 也是複數。實部代表損耗，虛部則代表電感性成分。

將虛部除以角頻率，就能得到 L：

`L = Im(Zin) / ω`

只要每個頻率點都有複數形式的 S11，這段轉換用幾行 Python 就能完成：

<!-- derived -->
```python
import numpy as np

z0 = 50.0
zin = z0 * (1 + s11) / (1 - s11)     # s11: 每個頻率的複數反射係數
L = zin.imag / (2 * np.pi * f)       # f: 對應的頻率陣列
```

有一點很容易弄錯：L 應該在整個頻段內計算成一條曲線，而不是挑一個頻率點來取值。

原因會在下一節說明。理想電感模型只適用於結構長度小於波長的 1/20。超過這個範圍後，Zin 的虛部便不再單純隨 ω 線性增加，從單一頻率點抽取的 L 也會失真。

## 1.5 vs 1.3，以及 5 GHz 的天花板

對同一組 via pair，twin rod 公式給出的結果是 21 pH/mil × 62 mil = 1.30 nH；從 3D 模型反抽出的結果則是 1.5 nH。

兩者相差 15%，該相信哪一個？

兩個都對，只是回答的問題不同。公式只計算均勻圓桿；solver 則額外考慮了兩件事：電流進出 via 時並非均勻分布，而 via 頂部與底部的磁場也不均勻。這兩項因素讓 solver 算出的電感略高。

因此，1.3 nH 適合用來做 sizing，1.5 nH 則適合納入阻抗預算。兩者差距不大，但要記住差異的方向：公式通常會低估，因為它沒有考慮接頭。

頻率上限也可以先估算。當結構長度超過波長的 1/20，理想電感模型就會失效；此時結構開始呈現分布式傳輸線的特性。

1 吋長的結構在空氣中對應的頻率約為 0.6 GHz；介質會降低光速，使頻率降至約 0.3 GHz。這個 via 長度只有 0.06 吋，約為 1/16 吋，因此上限可以乘以 16：0.3 GHz × 16 = 4.8 GHz。

書上的 3D 模擬指出，模型在約 6 GHz 以前都相當準確；以 1/20 波長回推，頻率上限則是 4.8 GHz。反抽出的曲線在 5 GHz 以前保持平坦。這三個數字落在相近的範圍內，實務上記住約 5 GHz 就足夠了。

<!--image:3-->

此外，S-parameter 還有一項使用限制：把它當成黑盒放進電路模擬很方便，但它無法隨設計縮放。只要 via 設計改變，就得重新模擬。若要快速掃描參數，仍需要可縮放的電路拓撲模型。

這個 1.5 nH 就是阻抗預算中的 via 項。下一節會把 plane pair 視為 cavity，看看它在頻域中如何共振。
