# Cavity 的 modal resonance 與衰減

## Lesson

把 cavity 看成一條很寬、很低阻抗的 transmission line，開路邊界會反射，於是出現 f = n/(2·TD) 的 modal 峰。這個 node 給出二維的 f_mn、probe 位置如何決定激不激得起來，並說明為什麼薄介質是壓 modal peak 最有效的一招。
