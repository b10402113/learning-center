# 阻抗峰的方程式與三種電流波形

## Lesson

同一個 fres 在 die 端是 parallel RLC 的峰、在 board／VNA 端是 series RLC 的谷，描述它的還是 Z0、Q、peak 三個數。這個 node 把 impulse、step、resonance 三種電流波形各跑一次，示範「RLC → 波形」與「波形 → RLC」這兩個方向都能走。
