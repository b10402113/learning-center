<LearningGoal>
能跑完閘門後的 Step 1–3：用訊號字判斷 UI、Logical 或 Both 軌，載入規格與 AGENTS.md 並做完整性檢查，用唯讀 subagent 隔離探索，從 build plan 續做且只在主線寫碼。
</LearningGoal>

## Lesson

閘門過後照三件事走。Step 1 用訊號字把工作分類成 UI、Logical 或 Both。Step 2 載入治理規格（只讀建置段落：Requirements 的 AC、Decision、設計段落、Build plan、Consequences）、最近的 `AGENTS.md`、`design.md`、build approach 與工具 skills，並跑段落完整性與 input coverage 兩趟檢查；monorepo 在目標 workspace 裡工作，規格與慣例衝突時規格贏並立旗給 `/sync`。Step 2.5 用便宜唯讀的探索 subagent 回傳精簡地圖，把讀取隔離在主線之外；Step 2.6 只在需要時查當前 API，永遠不用來換工具。Step 3 從 build plan 第一個未勾的任務續做，碼在主線寫，大型 rollout 走「原語先、逐站套用、最後一次 gate、絕不只做一半」，規格錯就先回頭改規格，資料層要 migration 套用且 schema 確認上線才算完成。
