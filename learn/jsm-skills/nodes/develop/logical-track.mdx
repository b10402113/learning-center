<LearningGoal>
能照 logical-guide 的七個階段實作後端：把不變量放進資料庫、對金流與訊息做冪等、在介面層做授權而不只驗證，並在整合層處理密鑰、webhook 與日誌。
</LearningGoal>

## Lesson

Logical 軌的定位是資深後端工程師：實作 `/architect` 的決策，不重辯，跟著規格、`AGENTS.md` 與既有程式碼的風格走。七個階段依序是：Phase 1 先把決策吃進去並列出整合點與被取代的舊碼；Phase 2 資料層，migration 要套用且 schema 確認上線，能在資料庫強制的不變量就放那裡；Phase 3 核心邏輯，狀態機要明確，金流與訊息要冪等，輸入在邊界往安全方向失敗；Phase 4 介面層，照 API 表實作並強制授權、每個列表都分頁、一致錯誤形狀、公開端點限流；Phase 5 整合與設定，密鑰從環境讀、webhook 驗簽章並冪等、加結構化與稽核日誌；Phase 6 刪掉被取代的碼並證明無人引用，舊碼在則遷移未完成；Phase 7 正確性與安全檢查，涵蓋安全、失敗模式、並行下的不變量與設定完整。
