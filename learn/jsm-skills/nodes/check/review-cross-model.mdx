<LearningGoal>
能說清楚 review 的跨模型不變量，並跑完一輪：偵測與確認作者模型、對照到不同的審查模型、界定 diff 範圍、用唯讀子代理產出嚴重度排序的發現。
</LearningGoal>

## Lesson

`review` 唯一不能彎的規則是審查要跑在跟作者不同的模型上；流程是偵測並確認作者模型、對照到不同的審查者、界定 diff 範圍，再由一個沒有編輯權的唯讀子代理寫出發現。
