# 四條核心慣例：誰握方向盤

<LearningGoal>
能說出四條核心慣例（engineer decides、suggestions never gates、one recommended option、keep skills lean）各在防哪一種失敗，並解釋它們為什麼是同一套「人類握方向盤」的設計觀。
</LearningGoal>

## Lesson

四條核心慣例（工程師決定而 AI 只推薦、建議不是關卡、每個問題帶一個推薦選項、skill 每一行都是成本）其實共用同一個前提：方向盤在工程師手上，AI 只負責把選項與後果講清楚。
