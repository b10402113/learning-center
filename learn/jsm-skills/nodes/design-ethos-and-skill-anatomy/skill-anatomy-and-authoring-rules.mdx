# Skill 解剖與撰寫規則：一個 skill 該長什麼樣

<LearningGoal>
能講出一個 skill 的資料夾解剖（SKILL.md、modes、approaches、templates、agents/openai.yaml）與六條撰寫規則，並依「少用且長」的判準決定哪些內容要拆檔、哪些留在 SKILL.md。
</LearningGoal>

## Lesson

skill 的骨架是 SKILL.md 當入口、modes 與 approaches 依情境各讀一個、templates 產出時才讀、agents/openai.yaml 只是薄轉接；六條撰寫規則要求每一行改變行為、給指令不給理由、叫概念不解釋、步驟可檢查、規則只說一次、語氣只定義一次。
