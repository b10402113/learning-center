# Token 預算與 progressive disclosure：為什麼每一行都是成本

<LearningGoal>
能用「每次載入都是成本」解釋 progressive disclosure 與 token 預算，並用 cost-unit 權重判斷該先砍輸出、砍 fresh input，還是砍 resident 檔。
</LearningGoal>

## Lesson

成本來自三條載入路徑（SKILL.md 本文、description、支援檔案），progressive disclosure 只在「罕見又長」時拆檔；而 token 不等價，cache-read 只算約十分之一、output 最貴，所以省錢要先砍 output 與 fresh input。
