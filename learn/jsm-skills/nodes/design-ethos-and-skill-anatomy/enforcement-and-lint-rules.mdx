# 把慣例變成守門員：11 條可執行檢查

<LearningGoal>
能列出 check-portability 的 11 條規則與 byte budget，並解釋 prompt 的 lint 如何用 warn-before-fail 頻帶與 prose masking 讓風格和 token 預算不再靠人記得。
</LearningGoal>

## Lesson

把 prompt 當產品、把慣例當測試：零依賴的檢查腳本就是測試套件，用 11 條規則（跨工具可攜性、byte 與熱路徑預算、風格一致性）掃過所有 markdown，並靠九成的警告頻帶與先遮罩程式碼的手法，讓風格與預算不再靠人記得。
