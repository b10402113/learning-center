<LearningGoal>
能依樣板寫出可貼上的 PR 標題與內文，以及符合既有格式、不重複的 changelog 條目。
</LearningGoal>

## Lesson

PR 用一行祈使句標題（≤72 字元、跟隨專案 commit 慣例）與 What／Why／Changes／How to test / verify／Risk & rollout／Notes for reviewers 六段內文，改動照意圖分組；changelog 附加到 `CHANGELOG.md` 的 unreleased 區段、沿用既有格式、從讀者視角寫且不重複；`gh` 只在 GH_ACTION 指示下才動。
