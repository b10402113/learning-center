<LearningGoal>
能用 git 蒐集分支變更集與規格依據、跑完 PR 的三項環境檢查，並處理 NO_TAGS、PR_EXISTS、postmortem 缺料這幾個邊角。
</LearningGoal>

## Lesson

動筆前先用 git 從 `main`（否則 `master`）取變更集與 diff、從最近修改的規格取動機，PR 另作 GH_INSTALLED／HAS_REMOTE／PR_EXISTS 三項環境檢查，並在 NO_TAGS、PR_EXISTS、postmortem 缺料三個邊角停下來問；commit 只是提示，diff 才是真相。
