<LearningGoal>
能把技術變更翻成使用者看得懂、不埋 breaking changes 的 release note，並寫出時間軸與根因分離的 blameless postmortem。
</LearningGoal>

## Lesson

release note 把技術變更翻成使用者價值、依重要性排序（Highlights／Improvements／Fixes）、breaking changes 絕不埋；postmortem 全程 blameless，時間軸只放有時間戳的事實，Root cause 分開導火線與底層弱點，action item 具體可指派並標 Prevent／Detect／Mitigate。
