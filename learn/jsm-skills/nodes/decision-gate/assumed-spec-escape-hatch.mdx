# Assumed spec：先蓋再記的逃生口

<LearningGoal>
能說出 `Assumed` spec 記錄哪三件事（owed decision、assumption built on、code area）、它為何讓決策留在 repo 而非對話，以及它為何不阻擋 feature 標成 done。
</LearningGoal>

## Lesson

`Assumed` spec 如何在動手前把未決的載重選擇記下來（owed decision、assumption built on、code area），讓假設留在 repo 而非對話，且不阻擋功能標成 done。
