# 一條需求一路追：acceptance-criteria 主線

<LearningGoal>
能說出一條需求如何從 spec 的編號規則，被 build plan 指名、被 check verify 跑、被 test 鎖住，並解釋這條主線為何讓「沒被證明的東西不算完成」。
</LearningGoal>

## Lesson

一條需求如何從 spec 裡編號的「完成定義」，被 build plan 指名、被 check verify 跑、被 test 鎖住，成為整套流程裡可一路追蹤的誠實主線。
