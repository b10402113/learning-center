# Ratification：把暫定決策補成正式決策

<LearningGoal>
能跑一次 ratification——先讀 assumed spec 的三個欄位，再讓 `/architect` 對著已蓋的程式碼重跑設計對話，並依「假設成立／假設錯誤」走對應的收尾。
</LearningGoal>

## Lesson

`/architect` 如何對著已蓋的程式碼重跑設計對話來 ratification 一份 `Assumed` spec：假設成立就補齊內容並清掉標記，假設錯誤就寫修正版並把舊的標成 `Superseded`。
