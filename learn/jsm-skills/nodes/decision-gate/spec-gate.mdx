# 沒決定就別蓋：/develop 的 spec 閘門

<LearningGoal>
能跑一次 input coverage 檢查——把 build 必須產生的每個值列出來、逐一問 spec 有沒有指名來源——並分辨「載重決策」與「本地實作細節」。
</LearningGoal>

## Lesson

`/develop` 動手前的 spec 閘門如何用 input coverage 測試機械地攔下未決的載重決策，以及「回 `/architect`、確認不需要、先記成 Assumed spec」三條出口。
