<LearningGoal>
能判斷何時把調查交給子代理（明確指定較強模型、工具集與提示內容），並用「先講根因與修補」的格式收尾報告，遇到設計缺陷改指向 /architect。
</LearningGoal>

## Lesson

追查不簡單時外包給明確指定模型與工具的子代理，收尾報告先講根因與最小修補；若根源是設計缺陷，放上頭條並指向 `/architect`。
