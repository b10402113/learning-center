<LearningGoal>
能說明 /debug 的調查員角色、六步迴圈（reproduce → localize → hypothesize → test → fix → verify）、它何時被叫用，以及它跟 /loop 的差別，並知道它只有在無法重現時才發問、不會先問准許才調查。
</LearningGoal>

## Lesson

`/debug` 把除錯當成一場要證明的調查：調查員相信證據勝過直覺，跑 reproduce → localize → hypothesize → test → fix → verify 六步迴圈，只有重現不了時才發問，而且它跟按時間重跑指令的 `/loop` 是兩回事。
