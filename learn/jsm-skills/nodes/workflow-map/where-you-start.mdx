# 從哪裡起跑：greenfield、brownfield、monorepo 與 debug

<LearningGoal>
能說出 greenfield、brownfield、monorepo 三種入口各自的起跑順序與背後理由，並說明 debug 迴圈為什麼不需要 scope 或 spec 就能走。
</LearningGoal>

## Lesson

起跑順序取決於起點：greenfield 是 `/scope`、`/architect` 定 stack、自己 scaffold、`/audit`（關鍵是讓 audit 讀到真專案）；brownfield 是 `/audit` 先讀懂專案、`/scope` 再收編既有並規劃下一片；monorepo 則把每件事 scope 到目標 workspace，各自有自己的 scope、spec、`AGENTS.md` 與指令。`/debug` 是不需要 scope 或 spec 的獨立迴圈：重現、定位、假設、測試、修補、驗證，一次只驗一個假設，最後把回歸測試交給 `/test`。
