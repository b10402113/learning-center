# 九階段地圖：每個階段回答什麼、吃什麼、留下什麼

<LearningGoal>
能畫出九階段的 DAG，說出每一階段的輸入、輸出與它寫進 repo 的檔案，並指出 debug 與裸 /scope 這兩條隨時可走的旁路。
</LearningGoal>

## Lesson

九個階段各回答一個問題：`scope` 定要做什麼、`audit` 記專案怎麼運作、`architect` 做決策、`develop` 照著蓋、`check` 用 `verify` 與 `review` 兩種模式確認、`test` 防回歸、`document` 寫給人看、`sync` 把文件對回程式碼；`scope` 與 `audit` 屬專案層，中間七站是會反覆跑的功能迴圈。每一階段的產出都是檔案，所以階段之間靠檔案交接，流程能跨 session、跨人；`/debug` 與裸 `/scope` 則是兩條隨時可走的旁路。
