# 把決策一路串到測試

<LearningGoal>
能沿著一條 acceptance criterion 從決策一路追到程式、驗證與測試，並說出這條線為什麼讓「完成」變成可被證明的事。
</LearningGoal>

## Lesson

acceptance criteria 把 architect 的決策、develop 的程式、check 的驗證與 test 的測試用同一組編號串起來，讓「完成」變成可被證明的事。
