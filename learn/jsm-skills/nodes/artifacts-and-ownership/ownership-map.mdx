# 誰能動哪個檔案

<LearningGoal>
能說出每個知識載體由誰建立、誰讀、誰能改，並解釋單一擁有者與外科手術式修改為什麼讓這些檔案不會隨時間崩壞。
</LearningGoal>

## Lesson

每個知識載體都有固定的建立者、讀者與唯一修改者，靠單一擁有者與外科手術式修改兩條紀律，讓這些檔案不會隨時間崩壞。
