# 檔案才是記憶：四種知識載體

<LearningGoal>
能說出為什麼這套流程把工作狀態放進檔案而不是聊天，並分辨四種工作載體（AGENTS.md、scope、specs、design.md）各自裝什麼、放在哪裡。
</LearningGoal>

## Lesson

這套流程把工作狀態放進 repo 的檔案而不是對話，並用 AGENTS.md、scope、specs、design.md 四種載體分別承載專案運作、建置順序、真實決定與介面方向。
