# 驗證深度：Prototype 到 GA

<LearningGoal>
能比較 Prototype / Alpha / Beta / GA 四種深度各跑哪些驗證，並說出為什麼它們是建議而非關卡、done 為什麼永遠由工程師宣告。
</LearningGoal>

## Lesson

驗證深度只決定 /develop 之後的檢查尾巴長度（Prototype → Alpha → Beta → GA），永遠是建議而非關卡，done 由工程師宣告，且任何深度都要求把關鍵決定寫下來。
