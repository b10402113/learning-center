# 誰建立、誰讀、誰改：固定擁有權

<LearningGoal>
能對照擁有權表說出每個檔案由誰建立、誰讀、誰改，並認得 spec 狀態線與 Assumed、Superseded 兩個狀態。
</LearningGoal>

## Lesson

每個狀態檔的建立、讀取、修改權都固定：只有 architect 寫 spec 內容與清 Assumed 標記，只有 develop 能移動 spec 狀態行（唯一能建的是 Assumed 存根），這就是檔案不糊掉的原因。
