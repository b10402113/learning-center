# 狀態如何跨 session、跨團隊存活

<LearningGoal>
能解釋 audit 從真實專案寫入、sync 對帳、以及「不覆寫手寫內容」如何讓檔案在換 session、換人之後仍然可信。
</LearningGoal>

## Lesson

audit 從真實專案寫入且不覆寫手寫內容、巢狀 context 讓每個 workspace 有自己的事實、sync 只做外科手術式對帳，這三件事讓狀態檔在換 session、換人之後仍然可信。
