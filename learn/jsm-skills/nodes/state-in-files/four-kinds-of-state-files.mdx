# 四種狀態檔：AGENTS.md、scope、specs、design.md

<LearningGoal>
能說出四種狀態檔各放什麼內容、住在哪個路徑，並解釋 AGENTS.md 為什麼要巢狀擺放。
</LearningGoal>

## Lesson

四種狀態檔各據一個家：AGENTS.md（可巢狀）講專案怎麼運作、scope 記要蓋什麼與順序、spec 記真實決定與驗收標準、design.md 記介面風格方向，每個事實只有一個來源。
