# 為什麼狀態要放檔案，而不是留在對話裡

<LearningGoal>
能用自己的話解釋「狀態放檔案」解決了什麼問題，並說出為什麼把知識留在對話裡會讓專案愈蓋愈難改。
</LearningGoal>

## Lesson

對話是一條會蒸發的線；把重要狀態寫進專案裡的檔案，知識才會留下來，工作也才能跨 session、跨團隊接得下去。
