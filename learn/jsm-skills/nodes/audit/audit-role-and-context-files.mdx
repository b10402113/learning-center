# /audit 在做什麼：AGENTS.md 是唯一正本

<LearningGoal>
能說出 `/audit` 在整條工作流裡負責哪一件事、`AGENTS.md` 與 `CLAUDE.md` 各自扮演什麼角色，以及它刻意不碰哪些別人的地盤。
</LearningGoal>

## Lesson

`/audit` 是工作流的情境啟動器，唯一產出是工具中立的 `AGENTS.md`（root 與 nested 兩層），`CLAUDE.md` 只是指向它的薄指標；它不建 spec、不維護變更後文件、不寫 scope，也絕不覆寫既有內容。
