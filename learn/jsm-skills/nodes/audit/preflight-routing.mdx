# pre-flight：這五個訊號決定你跑哪個 phase

<LearningGoal>
能依 pre-flight 的五個訊號與有順序的決策表，判斷這次該跑 Phase 0 / 1 / 2 / 3 / 4 哪一個，並說出為什麼 `WORKFLOW_SETUP` 會壓過程式碼行數。
</LearningGoal>

## Lesson

pre-flight 用五個訊號與一張有順序的決策表選出 Phase 0 / 1 / 2 / 3 / 4，其中 workflow setup 訊號會壓過原始碼行數。
