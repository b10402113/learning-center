# AGENTS.md 的形狀：root 精簡、巢狀、兩個鏡像欄位

<LearningGoal>
能查出 root 與巢狀 `AGENTS.md` 各有那些段落、root 為何要壓在約 60 行內，以及 `## Stack` 與 `## Build approach` 兩個鏡像欄位的來源與衝突處理規則。
</LearningGoal>

## Lesson

`AGENTS.md` 的形狀固定：root 只放全域事實並壓在約 60 行內，area 細節放巢狀文件，`## Stack` 與 `## Build approach` 只能從架構 spec 與 scope 鏡像而來。
