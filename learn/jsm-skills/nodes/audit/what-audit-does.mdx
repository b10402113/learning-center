# /audit 是什麼：把 durable context 寫進 AGENTS.md

<LearningGoal>
能說出 `/audit` 為什麼存在、為什麼 durable context 只寫進 `AGENTS.md` 而 `CLAUDE.md` 只是指標，以及它明確不碰哪三種檔。
</LearningGoal>

## Lesson

`/audit` 把專案的背景知識寫進工具中立的 `AGENTS.md`，`CLAUDE.md` 只是匯入指標；它永不覆寫既有內容，也不碰 spec、計畫與 scope。
