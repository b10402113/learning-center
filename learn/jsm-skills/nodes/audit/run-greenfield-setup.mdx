# 跑 greenfield setup：問清標準與工具，寫出 root AGENTS.md

<LearningGoal>
能在剛 scaffold 完的 greenfield 專案上跑完 Phase 1：用 decision panel 問定編碼標準與工具、種好兩個鏡像欄位、寫出 root `AGENTS.md` 與 `CLAUDE.md` 指標，必要時 `git init`。
</LearningGoal>

## Lesson

Phase 1 依序做最小探索、用 decision panel 問定編碼標準與工具、跑工具探勘的同意閘門，再寫出 root `AGENTS.md` 與 `CLAUDE.md` 指標；工具只記錄，安裝交給 `/develop tooling`。
