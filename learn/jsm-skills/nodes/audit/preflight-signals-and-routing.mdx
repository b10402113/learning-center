# pre-flight 訊號與 phase 路由

<LearningGoal>
能從一個 repo 的線上訊號判斷它該走哪個 phase，並解釋為什麼「工作流設定中」這個訊號會蓋過原始碼數量。
</LearningGoal>

## Lesson

`/audit` 用 pre-flight 收集情境檔狀態、原始碼數量、成熟度、monorepo 與 `WORKFLOW_SETUP` 五類訊號，再照路由表選 phase；`WORKFLOW_SETUP` 蓋過原始碼數量，因為剛 scaffold 的專案仍算 greenfield，分不清時退回 Phase 0 問一次。
