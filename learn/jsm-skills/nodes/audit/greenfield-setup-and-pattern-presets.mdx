# Greenfield：決策面板與四種風格 preset

<LearningGoal>
能跑完 Phase 1 的決策面板、選定一套 coding-style preset 並把它落成 root `AGENTS.md` 的 `## Rules`，同時處理 `## Git` 與 mirrored fields。
</LearningGoal>

## Lesson

Phase 1 用決策面板問滿架構風格、型別、資料夾結構、程式標準與工具鏈（只記錄不安裝），從四套 coding-style preset 選一套落成 `## Rules`，並處理 `## Stack`、`## Build approach` 兩個 mirrored fields、`## Git` 區塊與 monorepo stub。
