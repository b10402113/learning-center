# 掃描既有 repo：whole-repo 與 area 模式

<LearningGoal>
能跑 Phase 2 的 whole-repo 掃描與 Phase 3 的 area 掃描，判斷一個區域值不值得寫 nested `AGENTS.md`，並用 scout 子代理分攤大量閱讀。
</LearningGoal>

## Lesson

Phase 2 掃描整個沒有說明的 repo、萃取耐久知識後寫 root 與少數 warranted 的 nested 文件（大型 repo 的閱讀外包給唯讀 scout），Phase 3 只處理指定區域、檢查路徑與 root 後補該區域文件，並用 `ROOT_GAPS` 收集區域看見的 root 缺口。
