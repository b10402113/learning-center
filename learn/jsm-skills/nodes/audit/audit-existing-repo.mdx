# 稽核既有 repo：whole-repo / area / gap-fill 的掃描與補洞

<LearningGoal>
能在既有 repo 上跑 Phase 2 / 3 / 4：掃描足夠範圍、判斷那些 area 值得巢狀文件，並分清楚 root gap、proposed additions 與 contradiction 三種發現各該怎麼處理。
</LearningGoal>

## Lesson

Phase 2 / 3 / 4 都是先掃描再謹慎寫入：整庫寫精簡 root 並判斷巢狀文件，area 掃描處理 `ROOT_GAPS`，gap-fill 補洞並把矛盾交回人決定。
