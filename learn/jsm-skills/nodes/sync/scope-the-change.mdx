<LearningGoal>
能用 git 取出這次的變更集（先驗 freshness、判斷 base 與 mode、用 --name-status 取得 A/M/D），濾掉文件與測試只留 source 檔，並定位出該看的 AGENTS.md、specs 與這次相關的 scope 路徑。
</LearningGoal>

## Lesson

能驗 freshness、判斷 base 與 uncommitted／branch 模式、用 --name-status 取 A／M／D、濾出 source 檔並留下 D 與 manifest 兩份清單，再定位 root／nested AGENTS.md、docs/specs 與相關 workspace 的 scope（此刻只記路徑不讀）。
