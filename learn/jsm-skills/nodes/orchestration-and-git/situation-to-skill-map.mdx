# 卡住時的地圖：從處境判斷該跑哪個 skill

<LearningGoal>
卡住時，能從「現在的處境」判斷下一步該跑哪個 skill，並說出這個判斷的理由。
</LearningGoal>

## Lesson

卡住時用「我現在缺的是決定、實作、證明還是對齊」來判斷下一步該跑哪個 skill，並依 greenfield、brownfield、monorepo 調整入口，而 workflow depth 只是選單、不是軌道。
