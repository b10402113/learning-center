# 九個 skill 與 canonical pipeline：一個階段一個 skill

<LearningGoal>
說出九個 skill 各自的職責與整條 canonical pipeline，並解釋「一個階段一個 skill、只跑這次改動需要的」這個設計。
</LearningGoal>

## Lesson

這套系統以九個 skill 對應九個階段、把狀態放在檔案而非對話，主線是一條 canonical pipeline，其中後七站會反覆形成 feature loop，而 `debug` 則是隨時可用的旁支。
