# commit 節奏：天然提交點、訊息格式與 push 的歸屬

<LearningGoal>
認出哪些階段是天然 commit 點，依 commit 模式決定何時提交，寫出合規的訊息，並知道 push 與 PR 不歸 develop。
</LearningGoal>

## Lesson

commit 的天然提交點是里程碑落地且 typecheck 通過，依 `per-milestone`、`end-of-build`、`manual` 模式決定提交單位，訊息用一行 Conventional Commit 加必需的 `Co-Authored-By` trailer，而 push 與 PR 留給 `/document`。
