# skill 何時碰 git：integration 開關、分支與動手前檢查

<LearningGoal>
判斷一個專案裡 skill 該不該碰 git，並在動工前完成分支決策與新鮮度、協作檢查。
</LearningGoal>

## Lesson

先讀 AGENTS.md 的 `## Git` 設定決定 skill 碰不碰 git，再於動手前完成遠端、落後、未提交與協作的唯讀檢查，並永遠從功能分支起步、不在預設分支上蓋東西。
