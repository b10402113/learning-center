# 九階段排成一條線：一次完整跑的順序與起手式

<LearningGoal>
能在自己的練習專案上排出一次完整跑的順序（idea → /scope → /audit → /architect → /develop → /check verify → /test → /check review → /document → /sync，/debug 待命），並依 greenfield、brownfield、monorepo 三種 repo 形狀選對第一鏟挖在哪。
</LearningGoal>

## Lesson

一次完整跑的順序是 `idea → /scope → /audit → /architect → /develop → /check verify → /test → /check review → /document → /sync`，`/debug` 待命；起手式依 repo 形狀而定（全新從 `/scope` 起、先選 stack 再建專案才 `/audit`，既有程式庫從 `/audit` 起，monorepo 以 workspace 為單位，bug 直接 `/debug`、小改動可只跑 `/develop` 加 `/check verify`），而狀態全寫在檔案裡，所以斷在任何交接點都能清掉 session 再接回來。
