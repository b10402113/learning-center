# 這次要跑多深：Prototype 到 GA，以及何時跳過

<LearningGoal>
能用 Prototype、Alpha、Beta、GA 四級深度判斷這次改動要跑哪些階段，並說出「suggestions, never gates」的界線、這個流程不會做什麼，以及最常見的幾種失敗模式。
</LearningGoal>

## Lesson

四級深度（`Prototype` 只跑 develop、`Alpha` 加 verify、`Beta` 加 test、`GA` 再加跨模型 review 與 document）只決定 `/develop` 之後建議的檢查尾巴與 done 時機，不會關掉前面「決定要寫下來」的閘；develop 之後每一步都可自由跳過、done 永遠由你宣告且跳過會被誠實記成跳過，而流程也明確承諾不偷偷標 done、不藏起沒做的決定、不擅自連網、review 不改碼、任何 skill 都不重寫你的文章。
