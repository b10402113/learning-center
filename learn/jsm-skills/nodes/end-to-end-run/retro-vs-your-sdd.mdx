# 覆盤：把 jsm-skills 對回你自己的 SDD

<LearningGoal>
能拿自己 SDD 的每個環節逐項對照 jsm-skills 的九階段，指出它多了什麼、少了什麼，並講清楚你打算把哪些做法搬進自己的流程。
</LearningGoal>

## Lesson

把 jsm-skills 與自己的 SDD 並排對照：原有的 grill、spec、issues、implement、review 幾乎都有對應，它多出的是 audit、verify、test、document、sync 與 debug；值得搬走的是專案慣例的顯式檔案、活的 scope、spec 生命週期與固定擁有權、驗收條件直線、跨模型 review 與收尾的 document／sync，而它不強制、不管團隊與交付、維護成本自付，自己流程的追問深度與細粒度追蹤則值得保留。
