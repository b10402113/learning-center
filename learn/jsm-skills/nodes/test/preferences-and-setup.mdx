<LearningGoal>
能說出 test-preferences.json 的 framework 與 gate 兩種形狀各自什麼時候用，並跑對第一次執行時的 setup 問答與安裝檢查。
</LearningGoal>

## Lesson

`test-preferences.json` 讀的是「有沒有指名 tool」而不是檔案在不在：tool 有值就走寫入路徑，tool 是 null 且 gate 有值代表專案刻意不用 runner（只跑 typecheck 並指向 `/check verify`），沒有檔就進 setup 問答，格式壞掉就重跑 setup；設定分 framework 與 gate 兩種形狀且兩個鍵都要寫，缺工具時先問再裝，選延後（deferred）仍要寫出完整正確的測試。
