<LearningGoal>
能在跑測試後誠實分辨「測試寫錯」與「程式真的錯」，把後者留在 BUGS_FOUND 而不弱化斷言，並依 RUN_AFTER 產出正確的回報與 scope 收尾。
</LearningGoal>

## Lesson

`/test` 每輪都重新問「跑或不跑」且不存成偏好；跑時用精簡 reporter、只重跑失敗檔案。失敗分兩種：測試自己寫錯就修測試，程式真的錯就讓它紅著、記到 `BUGS_FOUND`，絕不改原碼或弱化斷言。回報格式隨 `RUN_AFTER` 不同、`BUGS_FOUND` 不空時放最前面；最後勾 scope 的 `Test it`、鏡射 spec 為 `Accepted`，但 `done` 由工程師宣布，通過才建議清上下文，可提議提交但永不 push。
