<LearningGoal>
能說出 /test 測什麼、不測什麼，為什麼「過了卻抓不到 bug 的測試比沒有更糟」，以及它和 /develop、/check verify、/check review 的分工。
</LearningGoal>

## Lesson

`/test` 為這條分支已改動但未提交的檔案寫回歸測試，範圍由 git 決定；它只擁有測試檔與 `test-preferences.json`，不寫應用碼、不碰 context 檔，信條是「會過卻抓不到 bug 的測試比沒有更糟」，因此測呼叫者依賴的行為而非覆蓋率，也不把切片刻意假裝的 scaffolding 鎖進測試。
