<LearningGoal>
能說出 `/architect` 的角色與它擁有的產物，並指認一份 spec 的落點（$SPEC_DIR）、形狀（單檔或目錄）與 create / update / supersede 三個操作各自何時使用。
</LearningGoal>

## Lesson

`/architect` 是設計決定的 skill，產物是一紙放在 `$SPEC_DIR` 的規格，規格由主執行緒親手寫、subagent 只讀；create / update / supersede 分別對應開新、就地演化與取代，而規格落點由 repo 形狀決定、形狀由決定大小決定（預設單檔，基礎或保護傘決定才升成 `index.md` 加 `rationale.md` 的目錄）。
