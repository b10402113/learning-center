# 問什麼、推什麼、自己查什麼

<LearningGoal>
把任何一個設計問題歸類成 INFER、ASK 或 RECOMMEND，並在 RECOMMEND 時給出「首選＋一句理由＋備選」而不是中立選單。
</LearningGoal>

## Lesson

每個設計問題都先丟進三個抽屜：prompt 或程式碼看得到的是 `INFER`（自己查、別問）、只有工程師知道的是 `ASK`（直接問）、專業能定案的是 `RECOMMEND`（給首選＋一句理由＋備選）；`RECOMMEND` 永遠不是中立選單也不是無聲決定，任何一整份成品都不該被包成單一的接受或修改面板。
