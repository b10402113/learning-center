# spec 生命週期與擁有權

<LearningGoal>
說出五種 spec 狀態各自的意義與誰負責推進，並分辨 feature-linked 與 standalone decision spec 的差別。
</LearningGoal>

## Lesson

spec 的狀態鏡射功能生命週期（`Proposed` → `In Progress` → `Accepted`），外加被取代的 `Superseded` 與先建後決的 `Assumed`；擁有權刻意拆開：只有 `/architect` 寫內容、只有 `/develop` 推進狀態、只有 `/architect` 能清 `Assumed`，有 scope 功能連動的 spec 走鏡射，純決策 spec 確認即 `Accepted`，記錄既成事實的 spec 則出生即 `Accepted`。
