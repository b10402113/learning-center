<LearningGoal>
能依情境選對 `FEATURE` / `ARCHITECTURE` / `ENHANCEMENT` / `CROSS-CUTTING`，並說出每個模式多產出的設計段與它套用的專家預設。
</LearningGoal>

## Lesson

依題目與程式碼現況選對 FEATURE、ARCHITECTURE、ENHANCEMENT、CROSS-CUTTING 四種模式，各自套用第一原理設計、架構模式先行、strangler 遷移與標準強制機制等專家預設，並產出對應的 `## Feature design`、`## Proposed stack`、`## Migration plan` 或 `## Standard definition`。
