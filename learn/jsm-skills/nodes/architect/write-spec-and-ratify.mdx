# 寫 spec、交叉檢查、ratify

<LearningGoal>
把訪談結果落成正確位置與形狀的 spec，跑完交叉檢查與確認，並依 spec 種類 ratify 狀態；遇到 Assumed spec 時知道怎麼清理它。
</LearningGoal>

## Lesson

收尾依序是讀三個寫作檔、依 repo 形狀定 location、依決策大小定 shape、組裝建置規格與決策紀錄、自己檢查、交叉檢查（永遠先問，主抓決策完整度）、確認直到接受、依種類 ratify 狀態、連結 scope；撿到 `Assumed` spec 則走 ratify：假設成立就補內容並清狀態，不成立就 supersede 並請工程師重做。
