# /scope 是什麼：把點子變成粗的、活著的 WHAT

<LearningGoal>
能說出 `/scope` 的職責與三種行為（plan / replan / add）如何由情境推斷，並指出它明確不碰的四樣東西。
</LearningGoal>

## Lesson

`/scope` 只回答要蓋什麼、什麼順序、多講究、哪些要先決定；它用一個指令推斷 plan / replan / add 三種行為，產出一份粗的、會長大的清單，並永遠給你可覆寫的推薦。
