# 選 delivery style：四種 build approach 與 foundations-first

<LearningGoal>
能用判準在 Tracer Bullet、Skateboard、Facade、Journey 之間做選擇，並說明為什麼每個 approach 都先蓋 foundations。
</LearningGoal>

## Lesson

選 approach 就是選先對付哪種風險：層接不起來用 Tracer Bullet、做出沒人要的東西用 Skateboard、做錯體驗用 Facade、體驗不夠完整用 Journey；正式產品預設 Tracer Bullet，而 foundations 永遠排在功能切片之前。
