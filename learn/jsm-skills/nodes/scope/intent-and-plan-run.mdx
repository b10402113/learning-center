<LearningGoal>
能說明 `/scope` 如何從上下文推斷 plan / replan / add 三種意圖，並照著 plan 的七個步驟把一句點子拆成有序的 feature 清單。
</LearningGoal>

## Lesson

`/scope` 沒有子指令，靠三條規則推斷 plan（沒有 scope 加產品點子）、replan（有 scope 不給參數）、add（有 scope 又指名單一功能）；整輪規劃遵守「能推論就推論、推不出來才一批批問、該判斷的給一張恰有一個推薦的面板」，並以發明測試決定每個功能是否需要規格。
