<LearningGoal>
能判斷手上的 repo 屬於 greenfield、brownfield 還是 monorepo，說出各自的第一步，並解釋為什麼所有路線都得先鋪基礎再做功能。
</LearningGoal>

## Lesson

plan 的第一步是掃描 repo 分類（有原始碼為 brownfield、無為 greenfield、多個工作區設定為 monorepo）並只讀一個路線檔案；greenfield 從零基礎先行（標準偏好、技術棧與架構、編碼標準與工具鏈、資料模型、設計系統、會動的骨架），brownfield 登記 existing 與 in-progress 而非重鋪基礎，monorepo 每個工作區各自一份 scope、全 repo 共用的放 _root。
