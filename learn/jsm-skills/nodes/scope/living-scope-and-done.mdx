# 活著的文件：replan、add，以及為什麼有些框沒打勾

<LearningGoal>
能解釋 `done` 不等於 `existing`、為何 `docs/scope/index.md` 上的框不會被 `/develop` 一次勾完，以及 replan 如何對帳並處理 Assumed 決策債。
</LearningGoal>

## Lesson

scope 是活著的文件，勾選的推進權分散在各階段所以框不會一次勾完，`done` 不等於 `existing`，Assumed 是可以暫時欠著的決策債，由 replan 就地對帳、add 輕輕補上新功能。
