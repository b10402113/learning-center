# 跑一次 plan：三條路線、問題走訪與 workflow tier

<LearningGoal>
能照著 plan 模式的順序跑一次完整規劃，分類 greenfield / brownfield / monorepo，切出粗 feature，並選定 workflow tier。
</LearningGoal>

## Lesson

plan 依序做定位（只讀一條路線）、生成面板問清楚、選 approach 並採用其人格、套 foundations first、切粗 feature、選 workflow tier、寫檔與報告，最後交出一份 `docs/scope/scope.md`。
