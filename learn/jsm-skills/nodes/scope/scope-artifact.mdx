<LearningGoal>
能說出 scope 檔案的兩段式形狀（At a glance 表 + 依 phase 分組的 feature 段），並解釋 feature lifecycle、status、workflow tier 這三套標記各自在文件裡扮演什麼角色。
</LearningGoal>

## Lesson

scope 是一份兩段式的活計畫：At a glance 表掃全局，依 phase 分組的功能段寫細節，段落順序即建置順序；功能段有 intent、一行 Done when 與 checkbox 步驟，並用 feature lifecycle（流程走到哪）、status（功能身分）與 workflow tier（develop 後跑幾關）三套標記記錄狀態。
