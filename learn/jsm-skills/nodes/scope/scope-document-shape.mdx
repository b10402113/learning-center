# scope 文件的形狀與狀態生命週期

<LearningGoal>
能畫出 scope 文件的兩部分（At a glance 表加上 phase 分組 sections），列舉五種狀態，並說出「下一個未打勾的框就是下一步」這條規則。
</LearningGoal>

## Lesson

scope 文件固定由 At a glance 表與 phase 分組段落組成，功能會從一個入口框長成 built ready 的多框形狀，狀態除了 planned / in-progress / done 還有 existing 與 dropped，而下一步永遠是第一個未打勾的框。
