<LearningGoal>
能用自己的話分辨四種 build approach 各自怎麼切、先做什麼、把什麼延後，並依產品目標選出正確的一種。
</LearningGoal>

## Lesson

四種 build approach 的差別看第一片交付：Tracer Bullet 先打通一條最薄但全程真實的垂直線（保留真結構、只砍寬度），Skateboard 先出最薄但真正可用的整體（願意砍結構），Facade 先把關鍵畫面在假資料上做齊（後端後接、原型等級），Journey 一次把一條使用者旅程做完整（含所有狀態與拋光）；正式生產專案預設 Tracer Bullet，選定後讀 persona 檔並在後續所有切片照它走，把選擇記在 scope 開頭。
