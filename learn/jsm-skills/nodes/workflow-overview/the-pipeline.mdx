# 整條 pipeline 與依專案型態選入口

<LearningGoal>
能背出 canonical pipeline 的順序，並依 greenfield、brownfield、單一改動、monorepo 四種情境決定從哪一站進、跑哪幾段。
</LearningGoal>

## Lesson

主線是 `idea → /scope → /audit → /architect → /develop → /check verify → /test → /check review → /document → /sync`，真正反覆跑的是從 `/architect` 到 `/sync` 的 feature loop，而入口依 greenfield、brownfield、單一改動、monorepo 四種情境而不同。
