# 九個 skill 與各自的職責

<LearningGoal>
能用一句話說出九個 skill 各自的職責，並分辨哪些是「做決定與產出」的階段、哪些是「確認與收尾」的階段。
</LearningGoal>

## Lesson

九個 skill 是一條組裝線上的九個工作站：前段 `scope`、`audit`、`architect` 把想法與決策寫成檔案，中段 `develop` 把 spec 蓋成程式，後段 `check`、`test`、`document`、`sync` 讓成品可驗證、可交接，`debug` 則隨時處理壞掉的東西；把它們串起來的是磁碟上的檔案，不是對話的記憶。
