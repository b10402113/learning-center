# 讓 /latest 愈來愈懂你的口味

跑完一次 `/latest`，回來的點子可能多到挑不完，也可能少到你懷疑它壞了。少的時候，其中幾個還完全不像你會講的東西。

這兩件事都有解法。點子量看兩個設定：視窗（window，看過去幾天內的新東西）和主題。口味靠一條回饋迴路：你每次在 cart 裡挑的東西，會寫回 skill 的品味檔，下一次的排序就照它調整。

## 先看量：七天和十個都只是預設值

`/latest` 預設看過去七天，整理成最多 10 個已排名的點子。兩個數字都是預設值，可以自己改。

結果頁最上面會寫這次跑了什麼：主題、視窗、執行時間，還有搜了哪些來源、沒搜哪些。手機上來源收在「Show the sources」後面。該搜的來源沒搜，就是先要處理的地方。

## 點子太少，先動這兩個旋鈕

<!--image:1-->

回來的點子太少，有兩個成本很低的調整：

- 把主題放寬一點。
- 把視窗改成過去 28 天。

先試哪個都可以。七天內抓不到東西，常常只是這週剛好安靜，不是這主題沒人談。

主題要往另一邊走：更有創意，也更具體。「AI」太寬，你真正想講的可能是本地端和開源 AI。「Claude」太寬，你真正想講的可能是用 Claude 做 3D 建模。

放寬是讓搜尋抓得到材料，具體是讓你講得像自己。做法是先放寬去搜，再用具體角度去挑。結果頁少於 5 筆，Tips 面板會自己打開。

## 在結果頁把 cart 挑成一串

<!--image:2-->

每次跑完都產出同一個 HTML 頁面：深色底、可切亮色，跟 `/outliers` 用同一套設計。cart 也是共用的，兩個 skill 挑的東西會落在同一份清單。

頁面上能做的挑選動作：

- 按 `/` 搜尋，範圍包含標題、angle、來源和作者。
- 用篩選 chips 收窄：平台、來源，還有「Fits your taste」。
- 排序：rank、最新，或互動量。
- 點開卡片看細節：angle、為什麼幫得上觀眾、為什麼符合你的口味、每個數字，還有原始連結（另開新頁）。

按卡片上的 Add 就進 cart。cart 抽屜裡可以拖曳排序（鍵盤用方向鍵抓握把），每則能寫備註，還有兩個按鈕：Copy for my agent 和 Download .md。cart 存在瀏覽器裡，每個結果頁共用，重新載入還在。瀏覽器擋掉儲存時，至少這次瀏覽還能用。

有一個容易漏掉的欄位：卡片上的 fit。它只出現在符合品味檔的點子上，用一行字說明為什麼符合。看到 fit 出現，就是品味檔在做事。

## 挑完丟回去，它會改兩件事

cart 挑好之後，按 Copy for my agent，把那段文字（開頭是「Idea cart:」）貼回 Claude。它會做兩件事：

1. 把這些點子寫成你能直接講的腳本，用你的語氣，給 TikTok 或 Instagram 用。看起來還不夠好先別管，現在就是先開始錄。
2. 照你這次挑的點子調整 `/latest`，讓它下次給的點子更貼近你想講的東西。

第二件事才是這篇的重點。第一件事把你挑的東西變成能拍的素材，第二件事會改變下一次清單的長相。

## 品味檔：它憑什麼排得更準

<!--image:3-->

skill 資料夾裡有一個 `taste.md`。agent 每次跑 `/latest` 之前都會先讀它，把符合的點子排前面，也照它塑造 angle。

這個檔案由腳本維護，因為 agent 通常會保護自己的 skills 資料夾，不讓別的流程隨便寫入。在終端機跑這幾行：

<!-- derived -->
```bash
python scripts/taste.py add -
python scripts/taste.py like -
python scripts/taste.py show
```

- `add -` 吃你貼回來的那段 cart，把每一則寫進 Picks，並更新 Counts（存了幾則、最後一次是哪天、平台與格式分布、來源分布）。
- `like -` 換掉「What you like」清單。清單最多 8 行，寫的是主題、格式、來源和 angle。這幾行就是 agent 判斷「像不像你」的依據。
- `show` 直接印出整個檔案。

Picks 每一行長這樣：日期 | 在哪裡 | 誰 | 標題 | 連結 | 備註。連結是主鍵，同一則點子只會存一次，重貼同一份 cart 不會長出重複項。

還有兩個容易出錯的地方：

- `add` 預設只收 `/latest` 的點子。cart 裡如果有 `/outliers` 的東西，會留在那裡給 `/outliers` 自己收。
- 這個檔案可以自己改。想手動加一條「我不要講工具評測」，直接編輯就好，agent 下次跑之前讀到的就是新的。

檔案裡有 picks 的時候，結果頁會多一行「Shaped by N picks you saved」。看到這行，代表這次的排序已經吃到你的口味。

## 收尾

下一次跑 `/latest`，先動兩個設定：視窗開到 28 天，主題寫得更具體。回來之後挑一輪，把 cart 貼回 Claude，讓 `taste.md` 記住你這次的選擇。

再下一次，同一份主題的回饋會更貼近你想講的東西。
