# 通用來源：知識之井

前一個節點要你把量拉起來，100 格打勾。但打勾的前提是：你每天都有話可講。小池塘定了、content identity 也寫了，然後你打開空白稿子，發現卡住的不是主題，而是「今天到底要講哪一件新的東西」。這個問題不會靠靈感解決，它靠一個固定的來源。你要把那個來源找出來，而且只找最新的那一段。

## 井的意思是「最新資訊落下的地方」

判斷標準是這樣：做教育型內容，觀眾追蹤你，是因為你在那個產業裡像個內行人。內行人的一個具體表現，就是你永遠跟上最新的東西。如果你今天還在講 2023 年的 OpenAI GPT 應用商店，那不是懷舊，那是掉分。人們願意聽你講話，很大一部分原因就是你手上有最新的工具與消息。

問題可以縮成一句：全世界關於你這個產業的最新資訊，都落在哪裡？那個地方就是你的知識之井（well of knowledge）。不管你談的是 AI、系統工程，還是鉤針編織，這一題都成立。井的位置每個產業差很多，但你必須先講得出它在哪。

## 三個井，以 AI 為例

以 AI 來說，我固定看三個地方。

第一個是 X。原因很單純：有新東西出來的時候，發一則推文或 X 貼文比寫一篇文章容易太多，因為它全部是文字。你只要用個一天，它大概就摸清你的偏好。Anthropic、OpenAI 這些公司的即時公告都在那裡，Claude 開發者帳號也很活躍，Anthropic 團隊的人（例如 Claude Code 的創辦人 Boris Cherney）我追得很緊。任何吸引我注意的東西我就書籤起來。需要點子的時候直接翻書籤，或讓 Claude 去讀我的書籤，幫我提議內容點子。等於把你原本就在滑手機的時間，順手變成點子研究階段。

第二個是 GitHub，加上 starhistory.com。GitHub 有點像開發者界的 Google Drive，大量程式碼、外掛、軟體都以開源形式發布在那裡。我至少每兩週去一次 starhistory.com，它會給一份熱門清單：最多人討論、最多 star 的 repository。看到有趣的東西，以前我會自己打開研究，現在直接丟給 Claude，問它是不是真的可行、值不值得談。

但有個陷阱：一個專案有很多 star，只代表它有社會認證（social proof），不代表它適合你。我看過一個 voice studio，主打「開源、完全本地端的 11 Labs 替代方案」，社會認證很夠，但我不覺得對我有用，因為我的內容不是專門聚焦在開源本地替代方案上。判斷還是回到你作為創作者喜歡什麼。

第三個是官方文件，這是最被低估的一個。Opus 5.5 剛發布的時候，Claude 平台發布了一份「prompting Claude Opus 5.5」的文件，講怎麼對新模型下 prompt。我把它餵給 Claude，跟它一起工作，用來草擬影片的段落節奏（beats）和重點條列（bullets），最後做出一支「Anthropic 剛公布了 12 條 prompt Opus 5.5 的新規則」，現在大約有 40 萬次觀看。它會中，是因為它非常切中時事、非常新，站在產業知識的最前緣；而官方出的東西，對很多人來說一定有用，所以品質也站得住。

如果你的利基不是 AI，井的樣子會換。可能是某個很多人活躍的論壇；如果你是醫生，可能是某個在討論 AI 領域最新最好東西的群組；如果你玩數學，數學圈也有自己的論壇在談最新的發展。重點是把這些來源列出來，並且確認你之後用來摘要點子的 skill 有把它們包含進去。

## 讓 agent 幫你盯，但別把自己淹掉

井找好之後，你不需要每天手動去撈。現在很多 agent 已經可以在你沒下 prompt 的情況下主動通知你，Grokbot、ChatGPT 都有這類能力。你用持續的通知流，只要利基裡有新東西，它就丟給你。

我自己有一個 Grokbot 帳號，一開始只讓它給 Claude 的通知，後來擴充到 GPT-6、OpenAI、Google 的消息，一天大概兩到三次。但你不必一天收三次。我這樣做只有一個原因：AI 這個領域動得實在太快。

## 為什麼影音平台只能算第二手

假設你對某個產業很有熱情，但你的資訊都是從 TikTok、Instagram 或 YouTube 看到的。那些是第二手的知識來源。

原因不是內容不好，是時間差。拍影片、真的在鏡頭前錄自己、剪好、再發到 YouTube，難度比發一則文字高太多。所以知識一旦上了那些平台，傳遞本來就有延遲。你直接從源頭拿，例如 X、Claude、官方文件，或依你的產業而定像 GitHub 這樣的地方，會比等一支影片出來快得多。做教育型內容，慢一步就是講別人講過的東西。

## 你的利基跟我不一樣

你的利基跟我的利基不一樣。你當然可以談 AI，但要有心理準備，起步會比較辛苦，因為 AI 是紅海。

反過來，如果你熱愛健身器材，而且真的想做健身器材的內容，那健身器材的點子來源和最新消息大概會在別的地方。這要由你判斷，或者請 Claude 幫你研究那些資訊從哪裡來。

## 先把七天掃一遍

還有一個可以直接用的東西是 `/latest`。它做的事是去掃過去七天的知識，來源涵蓋社群媒體、Reddit，當然也包含網路。

建議是：這類 skill 要能調。我現在設七天，是因為我的產業動得太快；如果你的產業不是這樣，就改成過去 14 天或 28 天，特別是當你發現拿到的點子不夠水準、對你不夠有用的時候。

井有了、`/latest` 也裝上了，下一個要處理的是：怎麼讓它產出的清單真的排得上用場。那是下一步的事。今天有時間的話，就做兩件事：寫下你利基的三個井，然後針對其中一個井跑一次 `/latest`，把第一個點子發出去。次數是這樣累積的。
