# 別再滑一整天，讓 /latest 幫你找新題目

你想發一支影片，所以打開手機找題目。四十分鐘後你還在滑，書籤多了十幾則，一支都沒錄。問題不是沒有資訊，是沒有人幫你把那些資訊收成「今天可以講的那幾件事」。

`/latest` 就是為這件事寫的。它去看你的領域在過去七天有什麼新東西，整理成最多 10 個、已經排好名次的內容點子。「七天」和「10 個」都只是預設值，你可以自己改。

## 它去哪裡找資料

底層它會讀 Reddit、X、YouTube、GitHub 和網路上的內容，再加上你自己平常會看的來源。後面這一項其實最重要，因為最懂這個領域的人是你，你知道哪幾個帳號一開口就值得聽。

它只留下附得上真實連結的點子。清單上每一個你都能點進去看，確認那則貼文、那個 repo、那篇官方公告真的存在，而不是模型把印象拼出來的一段話。這一條聽起來像廢話，但它決定了你打開清單之後，是花五分鐘挑點子，還是花半小時查證。

## 安裝大概五分鐘

1. 到教室頁面下載 zip 檔。
2. 把安裝用的 prompt 貼進 Claude 或你正在用的 agent。
3. 回答幾個關於你領域的問題。

真正花時間的是第三步。你答得越具體，撈回來的東西越像你會講的話；你答「AI」，它就給你一整片紅海。

如果你還沒有領域，可以先問 Claude：「根據你對我的了解，建議一些我可以在內容裡講的主題。」先有一個講得出口的方向，再回來裝。

## 怎麼用

設定好之後，輸入 `/latest`，或在後面直接接上你的領域。這支 skill 有附模板，結果會開成一個可以搜尋、可以篩選的頁面。看到不錯的就加進購物車，把有感的那幾個收集起來。

拿「AI agents」跑一次，馬上就回來幾個點子。每一個都夠你今天拿起手機，對著螢幕講一講，就開始發。

但記得：量才是關鍵。點子挑得再準，沒發出去就等於零。你要真的去發、真的去講這些點子。

## 為什麼預設是七天

七天這個預設值，是為了動得快的產業。AI 現在就是這樣，兩週前的東西可能已經沒人討論了。

所以這個數字該由你判斷。如果你的產業沒那麼快，或者你發現撈回來的點子不夠水準、對你沒什麼用，就把它調成 14 天或 28 天。天數不是規則，是一個你可以轉的旋鈕。

如果你連 skill 都還沒跑起來過，也不用先讀完什麼。把 Claude Code 或其他 agentic 平台設定好，大概 15 分鐘以內就能搞定，然後直接試 `/latest`。

## 跑完之後，今天就發

對你自己的產業、你自己的興趣領域跑一次，不要只跑「AI agents」那個題目。

挑一個你現在就有話想說的點子，今天就把它發出去。第一則的價值不在完美，在於你把次數從 0 變成 1，之後每一次都只是再加一。
