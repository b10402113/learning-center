# hook 不一定要用「說」的

你已經寫得出幾種 hook 了。但那些都是台詞：開場第一句話講什麼、怎麼把觀眾釘在畫面上。

問題來了。你不打算露臉。第一格畫面裡沒有你的表情、沒有你的手勢、沒有你那句自信的開場白。那前三秒要靠什麼把人留下來？

答案是：畫面本身就可以是 hook。而且對不露臉的內容來說，它可能是你最好用的一種。

## 台詞之外，還有一種 hook 是畫出來的

常見的 hook 幾乎都長在台詞上：contrarian 是一句反話、curiosity gap 是一句吊胃口的話、list 是一句承諾。但 hook 也可以不靠講，靠你放進畫面的第一個東西。

一個很省力的做法是：刻意把製作質感壓低。用手上那支手機拍自己的螢幕，然後拿一顆橘子插在筷子上，當作指字棒。就這樣。沒有燈、沒有腳架、沒有第二顆鏡頭。

效果是：第一格畫面會讓看的人心裡冒出「我到底在看什麼」。就因為這個疑問，手指會多停一下。而「多停一下」，正是 hook 唯一要換到的東西。

這種做法還有一個好處：它不需要你多買任何設備。你本來就要錄螢幕，本來就有手機，缺的只是一個奇怪但合理的畫面元素。

## 讓視覺 hook 跟品牌有關聯

視覺 hook 唯一該守的規則很簡單：盡量讓它跟你的品牌有點關係。

回到那顆橘子。它看起來像隨手撿的，其實扣得很緊。品牌的色系在開始用這個 hook 之前就已經是橘色；而在一些國家，包括澳洲，有些品種的橘子就叫 nuggets。所以「nuggets 連到橘色」這件事很容易成立，觀眾的潛意識會自己接上線。

連結建立起來之後，會發生另一件事：下次他在動態裡滑到「筷子上的橘子」，不用看名字就知道這是誰。同一個畫面同時做了兩份工，一份是停住手指，一份是累積辨識度。

但這不用硬湊。視覺 hook 可以隨時換掉，換一個跟你品牌扣得上的就好。

## 模式只是模式，你要長出自己的

那九個模式只是起點。你之後大概會撞見新的模式，或是只屬於你那個產業的模式。

方法說出來很普通，卻是最有效的一個：當你在看內容的時候，把喜歡的、覺得有趣的、覺得「這我以後可能用得上」的，直接存起來。不是存進腦袋，是存成一份你看得到、翻得到的清單。

這件事沒有終點。做了兩年，你還是會在看到好 hook 的那一刻按下書籤。因為那份清單不是筆記，是你之後挑 hook 時的資料庫。

## 換一個身分滑手機

這裡有一個視角要翻過來。

你現在不只是內容的消費者，你是內容的生產者。所以下次你滑動態的時候——尤其是用你發內容的那個商業帳號在滑的時候——你看到的東西應該要不一樣。

那個帳號該是為你的 niche 優化過的。它餵給你的，會是同一個領域最新的趨勢、最新的 hook，而不是隨機的娛樂。同一個動作，以前是消磨時間，現在是補貨。

再往後，演算法會自己幫你找到這類帳號：專門整理好 hook、好內容模式的人。The Post Protocol 就是其中一個。他們做的事情很直接——給你一個可以照著試、照著抄的內容模式。例如，開頭直接說「這支拿到大約一千萬次觀看」，下一則就照抄同一個格式再發一次。

這透露了一個現實：很多內容模式不管在哪個地區、哪個 niche、哪個產業，都一樣有效。所以這類帳號值得你存起來。如果你現在還沒有這份追蹤清單，今天就是開始的那天。

## 讀完你要發出的東西

一次做完兩件事。

第一件，挑一支你手上已經有的短片，或下一支要錄的。用螢幕錄影當第一格，加一個跟品牌扣得上、又有點奇怪的小道具，讓它撐起前三秒。不用好看，只要讓人想問「這是什麼」。

第二件，開一份清單。今天滑十分鐘，存下三個讓你停下來的 hook，順手記一句你為什麼停。這份清單以後會接上 hook 的 skill：等你叫它產建議時，你手上已經有自己的品味可以拿來篩，而不是照單全收。
