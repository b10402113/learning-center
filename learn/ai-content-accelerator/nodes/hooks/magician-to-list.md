# 九個 hook 模式

你已經知道要講什麼，卻卡在第一句話。更常發生的情況是：你寫得出開場，但每一次都長得一樣。

hook 只有一個工作：讓對的人知道，他為什麼現在就該在意。九個模式都在做這件事，只是做法不同。這裡補齊後面四個：magician、curiosity gap、versus、list。看完你會有九種可以挑，也會知道什麼時候該用哪一種。

## Magician：用一個值得看的畫面停住手指

magician 的做法，是用一個值得看的東西讓對方的拇指停下來。

在科技與 AI 內容裡，最直接的版本就是螢幕錄影。有人示範 OpenClaw 怎麼自己操作 Blender，開場就這幾句：「我的天，OpenClaw 現在跑在這台 Mac Mini 上，它可以控制 Blender 了。這是我自己客製的 Mac Mini。」光看畫面本身就夠了：電腦在自己動。

科技之外也一樣。Zack King 是視覺型 hook 的代表之一。他那支影片的第一格畫面是兩支手機，上面擺著一把刀。台詞接著說：「這是蛋糕還是假的？我們來看看。喔，切不下去，因為那是紙做的。而這隻手也是假的。哈囉？」

什麼時候用？當你的成果在畫面上就看得出來。畫面會動，東西會變，結果不必先解釋。觀眾第一眼看到變化，就會想知道發生什麼事。

## Curiosity Gap：開一個洞，然後先不補

curiosity gap 是在對方已知的東西上開一個缺口，然後刻意讓它開著。

這大概是最萬用的模式，尤其在教育型內容。只要影片裡有東西要講，你就能弔胃口地暗示：我接下來要講的，會幫到你。講 Claude for Excel 的那支就是這樣開場：「這件事別跟你老闆說。看好了——把這份資料清乾淨，完成。修公式，簡單。做好了。」

也有一種可以套進任何領域的版本。一開口就說：「這是我知道最扯的事實。」然後講一條繩子繞了地球一整圈，結果才發現它本來應該離地一英尺。你可以把這句話換成任何主題：「這是我知道最扯的 AI 事實」，或「這是我知道最有用的一招資料工程技巧」。

所以如果手上一個 hook 都沒想出來，curiosity gap 就是通用備案。它不挑主題，只要求你手上真的有一件事要講。

## Versus：把兩個東西並排，逼觀眾選

versus 是把兩個東西並排放，讓對方去選。

經典用法是直接比模型。有人幾乎每天都用 ChatGPT、Gemini 跟 Claude，每一個都有特定的超能力。ChatGPT 的超能力是「服從」：你丟給它一張十幾項的複雜檢查清單，它就照做。

也可以玩得很活。把五歲小孩拉進情境，讓他選自己喜歡哪一種比較貴的義大利麵：「五歲小孩比較喜歡哪一個？1 美元的義大利麵，還是 5 美元的義大利麵？」結果小孩選了 1 美元的那個 Kraft Mac and Cheese。

什麼時候用？當觀眾正在兩個選項之間猶豫，而你有明確的 A 和 B。並排之後，選擇本身就帶著情緒：貴或便宜、舊或新、快或慢。你不必先說服他，他會自己開始比。

## List：給一個數得出來的回報

list 就是清單型內容。你承諾一個他數得出來的回報。

假設你說：「這三個 Claude Code plugin 可以讓 Claude 不再浪費 token。」觀眾馬上知道三件事：這是 short、大概一分鐘、他會多拿到三個 nuggets。他心裡有一筆帳：花這些時間，換回來的更多。這就是更高的 ROI。

講法很直接：「這三個 Claude Code plugin 可以讓 Claude 不再浪費 token。第一個是 caveman，它會強迫 Claude 用精簡、講重點的方式回答。」談被動收入的那支也一樣：「如果你想做被動收入，這是我在開始之前希望有人告訴我的三件事。第一件，被動收入是一個目的地，不是起點，你不該從那裡開始。」

做 short 時有一個要注意的地方。你承諾「一支影片給你 50 個技巧」，觀眾的判斷是這支一定很長，然後直接滑掉。想讓人看到最後，一般不要超過 10 個，這樣他才會覺得這支還是短的、幾秒就看完。

## 什麼時候用哪一個

四個模式不難記，難的是當下要挑哪一個。照這個順序問自己。

第一，這件事在畫面上看得出來嗎？看得出來就用 magician。拍螢幕、拍成品、拍東西自己動。

第二，手上有沒有一份具體、數得出來的清單？有就用 list。三個外掛、五個錯誤、兩個步驟，數字本身就是承諾。

第三，觀眾是不是正在兩個選項之間選？是就用 versus。把兩邊並排，讓選擇發生在畫面上。

第四，以上都沒有，但你有一件想講的事？用 curiosity gap。它是備案，不是次級品。

模式也可以混著用。一個開場同時做兩件事，沒有問題。這些模式是拿來打開思路的，不是拿來遵守的規則。

拿起你下週要發的那支短片：同一個主題，用這四個模式各寫一句開場。四句並排，選一句最像你會說的，放進第一格。
