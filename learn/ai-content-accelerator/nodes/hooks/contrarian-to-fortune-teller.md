# 前三秒決定他要不要留下來

你發了一支四十幾秒的短片，講的是你真心覺得有用的東西。發出去，觀看數停在兩位數，平均觀看時間不到三秒。

問題通常不在內容。觀眾在最前面幾秒就會決定要不要把這則內容看完，因為他真正付給你的其實是注意力。所以那邊要放一個東西，讓他決定「留下來看」而不是「繼續往下滑」。那個東西叫 hook。

Hook 只有一個工作：讓對的人知道，他為什麼現在就該在意。

五個可以馬上套用的模式。

## 原理上一步講完了

前一步已經拆過：前 3 秒是包裝，後面的 body 才是肉；短影音的 hook 就是那 3 秒，長影音則是標題、縮圖加前 15 到 30 秒。這裡不再重講一遍，直接進模式。

先把這一步當成同一件事的延伸：不管用哪一種形狀，你都在回答「我要不要留下來」，只是換一個方式問。

## 五個 hook 模式

Hook 模式一共有九個；contrarian、investigator、teacher、experimenter、fortune teller 是其中五個。

有效的學法是看例子，再想它怎麼套到自己的 niche、自己的工作。套到你的 niche，可以寫成一句直接用的開場。

<!--image:2-->

## 一、Contrarian：說跟觀眾被教的不一樣的話

本質上就是說出跟觀眾過去被灌輸的觀念相反的話。

講 Claude 的開頭直接說「不要再對 Claude 下 prompt 了」。因為 Andrej Karpathy 認為有更好的方式跟 agent 合作。這個 hook 抓得住人，是因為觀眾是一群 AI 新手，他們對 AI 的認知就是「chatbot，你要去 prompt 它」。在這種背景下丟一句反話，注意力就來了。

內容的講法是：停止對 Claude 下 prompt，Karpathy 認為有更好的方式，而他的方法有三層。第一層是 spec——不要只是丟一個任務給它、然後祈禱它懂你，而是先跟它一起把 spec 寫詳細。

跟科技無關也照樣能用。飲食領域的例子是「五個該淘汰的飲食趨勢」。你的領域裡如果有大家都熟知、其實已經過時的建議，這個模式就直接成立。

套到你的 niche，可以寫：找出你 niche 裡大家都在講的一句話，把它反過來。例如「別再幫你的 agent 加工具了，問題從來不在工具不夠」。

## 二、Investigator：掀開大多數人漏掉的東西

本質上是揭露一個大多數人都漏掉的隱藏事物。你的領域裡有新聞的時候，這個模式特別有效，可以跟任何跟主題相關的最新消息混在一起用。

開頭直接說「有人把 Claude Fable 5.1 的完整 system prompt 洩出來了」，接著補一句：那不是什麼基本的 prompt，它超過 275,000 個字元。數字一出來，你很難不留下。

非 AI 的例子是超市。「這就是為什麼我絕對不會在 Aldi 買絞肉，而且原因不是你想的那個。」先講幾個原因，一路說「這不是真正的原因」，接近結尾才揭曉。hook 就是「有一個你漏掉、但你其實該知道的東西」。

套到你的 niche，可以寫：找一件你每天在用、但大多數人不知道的事。例如「你的 coding agent 每次都在同一個步驟偷偷改掉你的檔案，原因不是模型笨」。

## 三、Teacher：承諾解決一個他早就知道的問題

本質上是承諾幫他解決一個他已經知道自己有的問題。

開頭是「我要教你在三分鐘內做出你自己的 AI Jarvis」。AI Jarvis 那陣子在 Instagram 上紅到不行，已經有一群人看過那些炫的示範，心裡本來就在好奇「這要怎麼做」。這個 hook 有效，是因為問題早就存在，你只是接手回答。

要注意的是兌現。做 shorts，尤其你承諾三分鐘內學到東西，內容結束前一定要真的讓他學到。不然你身為創作者跟教育者的名聲會被侵蝕。這個模式不適合你，也完全沒關係。

另一個例子是硬舉。開頭就對準真的想練背、想變強的人：「硬舉是鍛鍊整個身體背側非常好的動作，但前提是你做對。第一步，雙腳站開與髖同寬，槓鈴落在腳掌中段上方。」直接進第一步，等於宣告後面還有一整套。

套到你的 niche，可以寫：把你的實作寫成一句承諾。例如「我教你在三分鐘內把一個 repo 接上會自己跑測試的 agent」。

## 四、Experimenter：自己試一次，然後回報結果

本質上是試一件事，然後回報你發現了什麼。

這個模式準備起來比較花時間，但它會付你股息。特別是當你本來就在東試西試、也想把過程記錄下來的時候，這是一石二鳥：事情本來就要做，順手拍成內容，還能從對同一件事有興趣的人那裡拿到曝光跟互動。

例子是一個叫 Slash Bragg 的 Claude skill，可以把任何 side project 在幾秒內變成一支 22 秒的 launch video。整個過程就是「好，找到 repo 了，裝起來，可以用了，我來跑一次」。訣竅是實測——實際去試，然後老實說這東西到底有沒有用。

套到你的 niche，可以寫：把你這週本來就要玩的東西拍成一次測試。例如「我裝了那個說能把 side project 變成 launch video 的 skill，這是實際跑完的結果，還有它哪裡不靈」。

## 五、Fortune Teller：畫一個他看得見的未來

地球上每一個人都對自己產業的未來有興趣。所以如果你心裡有一個預測，而且你覺得它能幫到人，這個模式就適合你。它做的事是：指向一個他們能想像、而你也相信會成真的未來，然後幫他們做好準備。

SaaS 未來預測的開頭是「SaaS 已經死了。這大概是大多數人心裡想的，但我想挑戰你去想『服務』。根據 Sequoia 的一份報告，下一家市值一兆美元的公司會是⋯⋯」。

這裡同時用了 contrarian。一開頭就說「SaaS 已經死了，這大概是大多數人想的」，等於不只告訴你未來會怎樣，還同時承諾「事情不是你現在相信的那樣」。

另一個例子談理財：25 歲前投入 100,000 美元，從此不必再為退休存錢，還是會以百萬富翁的身分退休。後面補了數字跟不同年齡區間的推算。

套到你的 niche，可以寫：寫一句你真心相信、而且能幫到人的預測。例如「接下來寫程式的主場會從編輯器移到 agent 的排程表，先學會排程的人會先受益」。

## 同一個題目，換五種開場

同一個題目——例如「我用 agent 做了一個會自己跑的小工具」——套五個模式，會長出五句方向完全不同的話。

Contrarian 說：不要再用聊天視窗做這件事了。

Investigator 說：這個工具背後有一個沒人講的設定，改了之後差很多。

Teacher 說：我教你用十分鐘，把一個 repo 變成會自己動的東西。

Experimenter 說：我把這個 skill 真的裝起來跑了一次，結果跟我預期的不一樣。

Fortune Teller 說：明年做這種小工具的方式，會跟今年完全不同。

五句都是同一個題目。差別只在你要先戳破哪一個既有想法，或先給他哪一種確定感。

<!--image:3-->

這些都只是模式。真正的價值是幫你打開思路，你可以混搭，也可以之後長出你自己的形狀。

## 把五句寫下來，挑一句發出去

只看不寫，等於沒學。把這五個模式對到你手上的一個題目，各寫一句，寫在筆記裡。

這件事有一個很實際的用途：之後你叫 agent 幫你產 hook 的時候，你才有辦法指揮它往你覺得最適合的形狀走，而不是拿到一堆你不會用的句子。

挑一個你本來就要發的題目，把五句寫完，選一句最像你、也最像你觀眾的，今天拍出去。
