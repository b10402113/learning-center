# 拿一支影片，發到九個社群平台

上一則算的是手動上稿那筆被乘出來的成本。成本既然會隨平台數放大，下一步就是找工具把它抵掉。

其中一個選項是 Blotato：你給它一支影片，時間由你挑，它替你送到多個地方。內容一模一樣的部分，就交給它去重複。

<!--image:1-->

## 一支影片，時間你挑，九個平台

用法很單純：一支影片、你挑的時間、九個平台。

同一個內容不用重做九次。你決定什麼時候發出去，它負責把內容送到那些平台。

Blotato 由 Sabrina 開發，很早就有一批使用者開始用。

## 它的設計就是讓 agent 去操作

Blotato 的關鍵不是功能多寡，而是設計方向：你的 agent 可以直接操作它。

如果你用的是 Codex 或 Claude Code，不必自己在介面裡一則一則點。

只要跟 agent 講清楚兩件事：這些內容今天幾點要出去，要送哪幾支影片、配哪些 captions。

它會把內容全部排好。排好的結果，在行事曆上看得到。

所以它適合放進自動化產線。排程不是由你操作工具，而是 agent 替你操作工具。你只要在行事曆上確認結果。

## 它可以連到哪九個平台

Blotato 能連結的平台有這九個：

- Instagram
- Facebook
- TikTok
- YouTube
- LinkedIn
- Twitter
- Threads
- Pinterest
- Bluesky

九個平台一次設定好。之後每一支影片都走同一條路出去。
