# 為什麼你需要排程工具

一支影片剪好了，躺在資料夾裡。你要發到 Instagram、TikTok、YouTube Shorts。上傳三次，聽起來很簡單。真正花時間的不是上傳。

把手動上稿的成本算清楚，才能回答一個很實際的問題：這一週，我該花錢買排程工具、自己架一套開源的，還是先繼續手動發？

## 手動上稿的成本，是被乘出來的

手動發到每個平台，慢的不是任何一個動作。是這些動作全部要重複一遍。

每一份內容都要上傳一次。caption 要複製、貼上。然後一個平台、一個平台手動做。就算發的是完全一模一樣的內容，整套流程還是照樣再走一次。

成本不是「發一篇要多久」。是「發一篇要多久 × 平台數 × 你這週發幾天」。平台從一個變成三個，這筆帳就乘以三。每天發，再乘以七。

還有一種成本更難看見：出錯的時候，你得回到每一個平台分別處理。同一支影片在三個地方有同一個錯字，就是三次修正。

排程工具做的事很單純。它把這件差事從你身上拿走。你要判斷的，只是用哪一種方式拿走。

## 三個選項，三種成本結構

**第一個選項：先手動發。**

這完全還在你的選項裡。你不需要今天就決定投資工具。可以先手動發，發到你自己覺得「投資一個排程工具是划算的」那個時間點為止。用上面的乘法算一下，那個時間點什麼時候到，你會很有感。

**第二個選項：Blotato。**

它讓你拿一支影片，發到九個社群平台，時間由你挑。九個平台是 Instagram、Facebook、TikTok、YouTube、LinkedIn、Twitter、Threads、Pinterest、Bluesky。

它還有一個對工程背景的人特別有用的地方：可以讓 agent 去操作。你用 Codex 或 Claude Code，直接跟 agent 說「這些東西今天幾點出去、要送哪些影片或 captions」。它就會把內容排好，你在行事曆上看得見。排程這件事變成一句指令，而不是一輪點擊。

**第三個選項：Postiz。**

它也有名。有名的原因是它開源。開源代表免費，代價在別的地方。

## Postiz 免費，但代價在兩件事上

第一，你要懂一點技術。你得知道怎麼架自己的 Docker server。還得知道怎麼架自己的資料庫，例如 Postgres。如果這在你能力範圍內，或者你本來就想學，那 Postiz 值得去看看。

第二個代價更重要。當你把 Postiz 的開源碼複製下來，等於你在做一個自己的應用程式——你自己的 Blotato。這個你自己做的排程 App，要能真的自動發到 TikTok、Instagram 或其他平台，你得走過這些平台的審核流程（audit process）。審核有它自己的要求。有時候要好幾週才會通過。

Postiz 省下的是授權費。付出的是設定時間，加上一段你無法控制的等待期。

<!--image:3-->

## 怎麼判斷

如果你現在的狀況是沒有預算投資像 Blotato 這樣的排程工具，Postiz 是一條路。但要先把上面那兩個前提跟代價算進去，再決定要不要走。

如果你有預算，而且你在意「agent 能不能直接操作」，Blotato 省下的是每天那輪重複動作。它把「發到九個平台」壓成一句話。

如果你還不確定值不值得，先手動發。這不是拖延。是把判斷建立在真實數字上——你真的手動發過一週，才知道那筆乘法乘出來是多少。

## 現在就能算

打開你手上的待發清單。挑出這週要發的三支影片。把三個數字寫下來：每支要發幾個平台、你每天要發幾支、這週要發幾天。乘起來。那個數字就是你這一週付給手動上稿的成本。再拿它跟工具費用擺在一起看。你會知道這週該選哪一個。
