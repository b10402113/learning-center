# 發文時間到底重不重要？

影片剪好了，`/post` 也接上排程工具了。剩下最後兩個決定：這批東西幾點出去？還有，如果帳號是全新的，可以直接開始排程嗎？

這兩個問題很容易反過來想。多數人先問「什麼時候發最好」，再問「新帳號要不要暖機」。實際順序剛好相反：時段沒那麼關鍵，新帳號的節奏才是真正會卡住你的地方。

## 時段沒有你想得那麼重要

一天裡的哪個時段、一週裡的哪一天，其實沒有很多人以為的那麼重要。

真正決定結果的是內容本身的品質，也就是它有沒有用。再來是你發的量：能發多少就發多少，你才有足夠的樣本快點迭代。

所以排程時間真正的用途，不是搶到流量最好的那一格，而是出錯時你救得回來。

<!--image:1-->

預設值是早上 9 點、下午 1 點、傍晚 5 點。選這三個時間唯一的理由，是那些時間你醒著。如果 agent 發錯了，或你自己貼錯了，你可以很快手動刪掉那則貼文，把它收回來。

你可以一天發五次，也可以一天只發一次，兩者都完全可行。改 skill 裡的時間，或直接叫 agent 照你的需求改，都行。焦慮時段通常只是把注意力從「內容夠不夠好」移開。

## TikTok 會先推給你所在的國家

至少在 TikTok 上，它會先把你的內容推給你所在的國家，地區性非常強。以 TikTok 來說，帳號剛開始時，最早看到內容的人——尤其是新帳號——大多來自澳洲。

<!--image:2-->

所以你排的時間更該落在你醒著的時候。不是為了演算法，而是為了你處理得動：留言、私訊、發錯要刪、臨時要補一則。你睡著的那八小時，帳號發生什麼事你都只能隔天再看。

但也不要為這件事焦慮。你要追的北極星是有品質的內容，而品質是靠大量出貨換來的：試不同的 hooks、試不同的講法、在鏡頭前隨著次數變多越來越有自信。走到某個點，人們追蹤你是因為信任你，而且你講的東西對他們的產業真的有用。

## 新帳號先正常用幾週，再連排程

如果某個帳號是全新的，尤其是在 TikTok 上，先像一般人一樣正常使用幾週，再把它連進排程工具。

這不是偏方。新帳號直接接上自動發佈，等於跳過平台判斷「這個帳號是不是真人在用」的階段。先讓它累積一點正常的活動，再交給 agent 排程，後面的節奏會穩得多。

<!--image:3-->

暖機不只是「等」。這幾週你可以手動發、可以回留言、可以看哪一種 hook 有人停下來。等你把帳號連進排程時，你手上已經有一點自己的觀察，而不是照抄別人的時間表。

## 排程不等於已發佈

送出排程之後，行事曆上看到一排貼文，很容易以為事情結束了。

但要等到連結打開，那則貼文才算真的上線。行事曆是計畫，連結才是證據。這也是為什麼發佈這件事要留下可點開的清單，而不是只看截圖。

## 把連結丟回去，讓 /post 越用越像你

連結回來之後，把那些連結送給你的 agent，可以做兩件事。

第一，請它幫你排一整週。比如一天三篇，你的影片就會自己持續出去，你不用每天重新開一次對話。

第二，請它把 `/post` 這個 skill 依你改過的地方優化。這一步才是整個迴圈的重點：每次你調整 caption、換封面、改平台組合，這些偏好都該被寫回 skill，而不是留在那一次的對話裡。久了之後，它會學會你喜歡怎麼發。

<!--image:4-->

所以這一整套的順序是：帳號先正常用幾週，再連排程；時段挑你醒著的時間，讓自己救得回來；發出去之後等連結、看結果，再把偏好寫回 skill。時段只是一個參數，會跟著回饋一直改的，是 skill 本身。

下一則貼文就可以照這個順序走一遍：挑一個你醒著的時段，把影片交給 `/post`，等連結回來，然後告訴 agent 哪裡要改。
