# 什麼是「內容作業系統」

## Lesson

當點子、腳本、評論散在各個聊天視窗裡，創作就會漏掉。這個 node 用 Content OS 的全圖與 RUBRIC Scripts，把腳本集中成一個可批次修改、批次錄製的工作流。
