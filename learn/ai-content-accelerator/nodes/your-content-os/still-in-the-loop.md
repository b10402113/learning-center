# 訓練 agents 更貼近你的品味

發想、寫腳本、剪輯、發文，現在都有人幫你跑了。你的 agent 幾乎把每一步都接走。你可能會因此覺得，下一步就是完全放手。

但真的跑一段時間，你會發現有幾件事一直回到你手上。而且一開始特別明顯。

## 還在你手上的三件事

第一，選點子。工具可以把點子挖出來，但真正在挑的人是你。

第二，做內容。腳本長什麼樣子、哪一段要留、哪一段要剪掉，是你在決定。

第三，看過那個剪輯。成品的節奏對不對、有沒有你要的味道，要你自己看完才知道。

<!--image:1-->

這三件事不是「agent 快做好了，再等一下就好」。它們是你要留下來的部分。

## 這不是自動化沒做完

很多人把「我還在迴圈裡」當成過渡狀態。好像工具再強一點，人就可以退場。

不是這樣。用 agents 用得好，關鍵是你可以訓練這些 agents 更貼近你的品味、更符合你的喜好。品味不是自動化要消掉的東西。品味是自動化要瞄準的目標。你沒有給出品味，agent 只能給你平均值。

所以這些決策留著，是設計，不是欠債。

## 品味是怎麼被訓練進去的

態度對了，方法很樸素：看到不對，就改。

agent 挑了一個不像你的點子，你換掉它。然後把「為什麼這個不行」寫回那個 skill。agent 剪掉一段你其實想留的話，你改回來。然後把判斷寫回流程。你改的不是那一次成品而已。你改的是往後每一次的預設。

這就是把品味訓練進 agents 的方式。每一次修正，都讓那個判斷變成流程的一部分，而不是只存在你的腦子裡。

<!--image:2-->

久了會出現一個變化：你需要盯的地方越來越少。你修得越細，越多事情就自己跑起來。同樣的錯誤不會再回來問你第二遍，因為答案已經寫在 skill 裡了。

到了那個階段，創作這一段的大部分粗活已經交給 agent。剪輯、動畫大約八成到九成都在 agent 手上。你花的時間集中在少數幾個真正需要你判斷的地方。

## 該你下決策的地方，別讓出去

放手放到最後，還是有一件事不能外包：你的品味要套上去，你還是要下決策。

理由很簡單。你下決策，內容才會是你獨有的。你完全不下決策，最後拿到的就是一堆看起來很順、但誰來做都一樣的東西：vibe coded 的成品，或者 AI slop。

所以「還在迴圈裡」不是要修掉的問題。它是要守住的東西。你守住的不是每一個步驟，而是那幾個只有你能做的判斷。其他的，訓練給 agent。

## 從下一次修正開始

下一次你看到不喜歡的成品，先別急著自己動手改完就結束。

問一句：這個判斷，我有沒有寫回流程？

有寫回去，你就在把品味訓練進 agent。沒寫回去，你下一次還要再判斷一次同樣的事。
