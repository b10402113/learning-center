# 但有一件事：你仍然在迴圈裡

你把 skill 一個一個接起來了：找點子、寫腳本、錄、剪、排程發文。跑過一輪之後，很容易冒出一個錯覺——這條線上好像已經沒有你的位置了。

事實不是這樣。至少剛開始的時候，你還在整個迴圈裡面。

## 那些還是你親手在做的事

挑點子的時候，是你真的在挑。工具可以丟給你一批選項、幫你排序、標出哪個比較安全，但最後說「就這個」的人是你。

做內容也一樣。腳本是你決定的，哪一段要留、哪一段要砍也是你決定的。剪完之後，你還是會把它看過一遍。

不是工具不夠好，而是這幾件事本來就不在工具能替你做的範圍裡。它們要的是判斷：這個點子對你的品牌來說好不好？這一段留下來，影片還會不會像你？

<!--image:1-->

所以先接受一件事：這幾個位置，短時間內不會空出來。你不是在等一個全自動的版本出現，你是在決定自己要在哪幾個點上出力。

## 自動化比例

把數字攤開來看會比較清楚。同一套流程裡，很多環節其實已經自動化，時間分佈長得不一樣。

大部分時間花在哪裡？花在依自己的偏好、自己的品味去判斷，本質上就是那個 trifecta——決定哪些點子對這個品牌是好的。

創作的過程大概 80% 到 90% 已經自動化，剪輯、動畫很多是 agent 在做。

發文大概 95% 自動化。連檢查 caption 這種事都已經不像以前那麼重要，因為你已經相當信任 agents 能把這件事做好。

被自動化掉的是粗活，留在你手上的那一段是判斷。判斷那一段，恰好是你最不該急著交出去的。

## 自動化是一道光譜

所以不要用「自動化」跟「沒自動化」這種二分法來看這件事。它其實是一道光譜。

一端是：每一個步驟你都親自檢查，agents 只是在旁邊幫你。另一端是：所有事情都自己跑起來。

你在這道光譜上的位置，不是靠「更大膽地放手」往前推，而是靠把 skills 修得更細。skill 修得越細，agent 越知道你要什麼，你能放手的地方就越多。這些細節本來就該內建在流程裡，不是每次憑感覺重講一遍。

但不管你走到哪一段，品味還是要套上去，決策還是要你來下。差別只在於：一開始你是在每一個環節下決策，後來你是在少數幾個關鍵點下決策。

這條線如果少了這一層，得到的不是效率，是 vibe coded 的東西，和一堆 AI slop。內容會變成誰都能發的東西，那也就沒有理由被記得。

## 把品味訓練進 agents

最基本的一點是：用 agents、而且用得好，最棒的地方在於你可以訓練這些 agents 更貼近你的品味、更符合你的喜好。

這不是抽象的說法。每一次你覺得「這不是我要的」然後去改 skill，你就是在把一次判斷寫進去。下一次它就更接近你一點，你需要在旁邊盯著的時間就少一點。

所以「還在迴圈裡」不是失敗，是起點。真正的動作有兩個：一是承認選點子、定腳本、看剪輯這幾件事現在還是你的工作，不要因為流程看起來很順就跳過；二是每次你做出判斷之後，把那個判斷沉澱到 skill 裡，而不是留在腦子裡下次重講。

品味不會自己長到 agent 身上，它只會透過你一次一次的修正，慢慢變成流程的一部分。你越願意花時間在「判斷」而不是「操作」，這條產線就越像你。
