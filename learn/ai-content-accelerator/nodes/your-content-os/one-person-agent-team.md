# 一個人加一隊 agents，就經營一間內容事業

做內容的人多半都遇過同一件事：真正拖住你的，不是想法不夠，而是想法到你手上之後，還有一大段路要走。

一段內容要從「這次要講什麼」變成「已經發出去了」，中間有四份工作。以前這四份工作各是一個人，現在各是一個 agent。

## 以前，這四件事各要一個人

第一份是研究點子：決定這次要講什麼、憑什麼講。第二份是寫腳本：把想法排成可以拍、可以讀的順序。第三份是剪輯：把素材收成一支能看的成品。第四份是發文：處理發佈的動作和細節。

這四份工作分開看都不難。但它們不是一次性的。點子不會自己冒出來，腳本不會自己排好，素材不會自己變乾淨，貼文也不會自己送出去。你如果不想一直卡在這裡，就得湊出一個團隊：有人專門研究點子、有人專門寫腳本、一個剪輯師、一個負責發文的人。

這也是為什麼做內容長期是一門需要人力的生意。你要付的不是四個任務的時間，是四個位置一直有人的時間。

## 現在，四份工作各有 agent 接手

這四份工作，現在各自有東西可以接手。

找點子的那一端，有工具自動幫你挖。製作的那一端，用 Rubric Scripts 和 Rubric Editor 把腳本與剪輯做出來。發佈的那一端，有 `/post` 這類 skill 把發文自動化。

這條路徑上已經沒有哪一段是「非有另一個人在場」才能動。每一段都有自己的負責人，只是這個負責人現在是 agent。

## 為什麼是現在

這種安排放在幾年前是空話。

不是因為那時候的人不夠拚，而是因為這四份工作裡，沒有一份能在沒有人的情況下做到可以直接發佈的水準。研究點子要判斷，寫腳本要手感，剪輯要取捨，發文要拿捏。這些過去只能靠經驗累積在一個人身上。

AI 工具發展到現在這個樣子，這四段才第一次變成可以交給 agent 執行、而你只在關鍵處插手的事。所以「一個人加一隊 agents」不是一種偷懶的說法，是一個幾年前根本不存在的選項。

## 它成立的前提

不過這件事有前提，而且前提不在工具上。

第一個前提是你要會用它。Agent 不是裝好就會自己變好。你越了解 AI agents 怎麼運作，越能把這套作業系統調成符合你需求的樣子，調起來也越有效率。同一套工具，懂的人調出來是一條產線，不懂的人調出來是一堆要你回頭補救的半成品。

第二個前提是決策要留在你手上：要講哪個點子、腳本長什麼樣、剪輯過不過，最後還是你說了算。

少了任何一個，你只是把產量放大，方向卻不是你選的。
