# 一人加一隊 agent，就能跑內容事業

你的問題不是不會做內容。是沒有人幫你做。

點子要想、腳本要寫、影片要剪、貼文要發。這四件事分開看都不難。全綁在同一個人身上，一天就沒了。以前遇到這個問題，答案很直接：請人。現在多了一個選項——一個人，加一隊 agent。

<!--image:1-->

## 傳統團隊的四份工

要做內容事業，以前得湊出一個團隊。有人專門挖點子，有人寫腳本，一個剪輯師，還有一個負責發文的人。

這四個不是頭銜，是四段真的有人坐下來做的流程。研究、撰寫、剪輯、發佈，每一段都吃時間，每一段都要有人在。你可以養一整個團隊來做這件事，前提是你養得起。在那之前，這四段工就是你下班後剩下的力氣。

## 每一步都有一個 agent 接手

現在這四段流程，各自都有對應的 skill 幫你自動化。

挖點子那一端，有工具自動幫你掃。製作那一端，用 Rubric Scripts 與 Rubric Editor 把內容做出來。發佈那一端，用 `/post` 這類 skill 把貼文送出去。你在 content identity 上先把方向定好，選題時做判斷。剩下的動作，一段一段被 agent 接走。

這件事之所以可能，是因為 AI 工具到了現在這個樣子。再往前推幾年，同樣的流程只能靠人力堆。

<!--image:2-->

## 前提一：你還在迴圈裡

有一件事不能跳過：尤其在剛開始，你其實還在整個循環裡面。

挑點子的時候，是你在挑。做內容的時候，是你在決定腳本、決定要剪什麼，而且你會看過那個剪輯。agent 不是替你做決定，是替你把決定執行掉。這個差別很小，但它決定了你做出來的東西像不像你。

而用 agent 用得好的地方在於：你可以訓練它們越來越貼近你的品味、你的偏好。它們不是固定不動的工具，是會被調教的執行者。你丟進去的判斷越多，它們越知道你要什麼。

## 自動化到什麼程度

在一條已經跑順的產線裡，創作端大約 80% 到 90% 自動化——很多剪輯、動畫都是 agent 在做。發佈端大約 95% 自動化，連檢查 caption 這種事都不再那麼關鍵，因為你已經相當信任 agent 把這一段做好。

剩下那些時間花在哪？花在用自己的品味判斷哪些點子對這個品牌是好的，本質上就是那個 trifecta 的判斷。判斷沒有被自動化，被自動化的是判斷之後的手。

## 前提二：品味是最後一道防線

自動化是一道光譜，不是一個開關。

一開始，你在這一端：每個步驟你都親自檢查，agent 只是從旁協助你。當你做得越多、把那些 skills 修得越細，你會慢慢走到另一端——所有事情都自己跑起來。

<!--image:3-->

但即使在那一端，品味還是要套上去，決策還是你下。少了這一層，你最後只會做出一些 vibe coded 的東西，或一堆 AI slop。守住這些原則、守住這套作業系統，大部分的粗活才會真的交到 agent 手上。

所以「一人加一隊 agent」成立的前提，說到底只有兩條：你留在挑選與決策的位置上，而且你願意把 skills 一直修細。少了任一條，你只是換了一個更貴的貼文排程器。

## 你現在要發出的東西

這套作業系統的價值不在於全自動，而在於它把粗活交出去、把判斷留給你。所以第一個動作不是去買工具。

把你這週本來就要發的那一則，從頭到尾走一次四段流程。每走完一段，在旁邊標記：這一步是我做了決定，還是 agent 執行了我的決定。跑完一則，你會拿到一張自己的分工表——上面標著你真正該花時間的地方，也標著下一個該修細的 skill。
