# 自動化是一道光譜

你已經把發想、寫稿、剪輯、發文一段一段接上 agent。
可是每次發佈前，你還是會從頭到尾再看一遍。
心裡想：這樣到底算不算自動化？

算。
只是你現在站在光譜上比較靠左的位置。

自動化不是一個開關。
沒有「打開」和「關掉」兩種狀態。
它是一道光譜，你在上面挑一個位置站。

<!--image:1-->

## 光譜的兩端

左端是這樣：每個步驟你都親自檢查，agent 只在旁邊幫你。
點子你自己挑，腳本你自己定，剪出來的東西你自己看過。

右端是另一種樣子：所有事情都自己跑起來，你只在少數幾個地方出現。

很多人把這兩端當成兩種人。
一種是「還沒自動化」，一種是「已經自動化」。
這個分類沒有用。
同一條流程裡，不同階段的進度本來就不一樣。

發佈通常跑在創作前面。
你檢查 caption（貼文的說明文字）檢查久了，會發現這件事沒那麼關鍵。
也會慢慢信任 agent 做得夠好。
創作比較慢，因為腳本跟剪輯裡有太多判斷要做。

問題不是「我自動化了沒」。
問題是「我這條流程的每一段，各自站在哪裡」。

## 往右移動，靠的是修 skill

想往右走，很多人的第一個反應是再買一個工具。
這個方向是錯的。

真正會讓你往右移的，是把流程裡用的那些 skill 修得更細。
規則寫得更清楚。
判斷標準講得更明白。
遇到什麼情況該怎麼處理，都補上去。

你做得越多，就越知道哪一段會出錯。
然後回頭把那一段的 skill 補起來。
位置就是這樣一點一點往右移。

換工具不會讓你往右移。
工具只決定你在哪裡工作。
skill 才決定這一段能不能自己跑完。

## 品味要套在選定的點上

往右移有一個前提：你的品味還是要套上去，你還是要下決策。

如果整條流程都自己跑，你完全放手，結果不會是「高效率的內容」。
你會做出一些 vibe coded 的東西，或一堆 AI slop。
表面上都對，讀起來都空。

品味可以訓練進 agent，但前提是你先有品味可以教。
品味不是憑空長出來的。
是你一次次在特定的點上做判斷，才有東西可以交出去。

「放手」不是把判斷全部刪掉。
是把判斷集中在少數幾個你選定的位置。

## 畫出你的流程，標三個點

拿一張紙，把你現在從點子到發佈的流程畫成一條線。
寫下每個階段現在是誰在做：你、agent，還是兩個一起。

然後在這條線上標出三個「一定要經過你」的點。
每一個都寫下它為什麼要留在你這裡。

說得出理由的點，就留著。
說不出理由的點，通常代表它已經可以往右移了。

<!--image:3-->

這三個點就是你現在的品味介入點。
守住它們，也守住整套作業系統。
大部分的粗活最後都會交到 agent 手上。
你會走到那個點：流程自己跑，你只在你選好的位置上出現。
