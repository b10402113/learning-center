# 自動化是一道光譜

agent 現在會挖點子、寫腳本、剪片、排程發文。問題已經不是「能不能自動化」，而是「哪幾段要留下來自己判斷」。

這沒有標準答案，只有位置——你在光譜上的位置。

## 光譜的兩端

一端是：每個步驟你都親自看過，agents 只在旁邊幫你。另一端是：所有事情都自己跑起來。

從一端走到另一端，靠的不是換一套工具，而是把 skills 修細。做得越多，你越清楚哪裡該卡規則、哪裡可以放手。這些調整最後會沉澱進你的 workflow。規則夠細，多數環節就不再需要你每次點頭。

## 把數字攤開

創作這一端——剪輯、動畫這些——大約 80% 到 90% 已經交給 agent。發文那一端大概 95%：排程、格式、caption 檢查，都不必每天盯。

真正吃掉時間的不是這些，是判斷：哪些點子對這個品牌是好的。那是品味的工作，也是 trifecta 的工作。生成量再大，內容最後長的還是你的樣子，靠的就是這一段。

<!--image:2-->

## 品味要套在哪裡

尤其在前期，你其實還在回圈裡。點子是你挑的；腳本是你定的，要剪什麼也是你定的，剪完你還要看過。

這不是自動化沒做完，是刻意留著的。agents 用得好的地方，就在於你能把這些判斷餵回去，讓它越來越貼近你的品味。留白不是效率損失，你是在訓練它。

拿掉這一段的後果很具體：一堆 vibe coded 的東西，跟一堆 AI slop。速度變快了，但沒有人會記得那是誰做的。

<!--image:3-->

## 一個人，加一隊 agents

這套流程跑順之後，規模的問題就不再是「要請幾個人」。研究點子、寫腳本、剪輯、發文，以前是一個團隊的分工；現在一個人加一隊 agents，就能跑一間內容事業。從發想用的工具，到 Rubric Scripts 和 Rubric Editor 做內容，再到用 `/post` 把發文自動化，每個環節都有對應的 skill 接手。

## 收尾：守住原則，粗活交出去

「選一個位置」的意思是：先決定哪幾個判斷點一定要經過你，其餘的交出去。品位守住了，走到光譜右端就不是失控，是規模。

下一步很具體：把現在的流程攤開，標出三個一定要經過你的點——挑點子、定腳本、看剪輯——寫下每一個點為什麼要留。剩下的，交給 agent 去跑。
