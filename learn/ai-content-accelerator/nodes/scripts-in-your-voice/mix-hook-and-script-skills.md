# 兩個 skill 就搞定：hook 跟 script

打開腳本，唸第一句就覺得不對。文法沒錯、結構也對，但那個節奏、那個用詞，一眼就被認出是 AI 寫的。AI 越普及，觀眾越會抓文案和腳本裡的「ChatGPT 味」。你花時間做的內容，可能在前三秒就被歸類。

要解決這件事，不必重寫一套流程。把寫腳本拆成兩個 skill：一個專門產 hooks，一個專門產影片其餘的 script。兩個都吃你自己的語氣。跑完一輪，你手上會有一份聽起來像你、而且是為那則內容寫的腳本。

## 第一步先假設你已經做過

上一步用 humanizer 和「Signs of AI writing」把贅字清掉了。這一層這裡先當成已完成：你的 skill 裡有一道濾網，後面產出的東西不必再逐句手改。

還沒做也沒關係，先往下看。這一步的重點在分工。

## 兩個 skill 的分工

分工很單純：一個 skill 產 hooks，一個 skill 產影片其餘的 script。

為什麼要拆成兩個？因為 hook 跟 script 的判斷標準不同。hook 只有幾秒鐘可以決定要不要留住人，它要短、要刺、要對得上那則內容。script 要承接 hook 之後的節奏，把話講完。混在一起寫，通常兩邊都不到位。

<!--image:1-->

兩個 skill 都讀同一份 tone of voice 設定。你的常用詞、你講話的方式、你的規則，都寫在那裡。不管你換哪個模型——GPT、Codex、Claude，或之後冒出來的新模型——它拿到的是同一套語氣規則，不會每次重講一遍。

## 一次跑完的流程

要讓這週的腳本比上週更精緻，路徑只有三步：

1. 把你抓到的想法丟進去。
2. 叫你的 agent 呼叫這兩個 skill。
3. 讓它給你一份 script——在你的語氣上更到位，也會依照那則內容給你幾個可用的 hook 範例。

<!--image:2-->

第三步是重點。它給你的不是通用範本，是掛在這則內容上的 hook 選項。你從裡面挑一個順眼的，不用從零開始想第一句。

如果你今天還有時間，就手動跑一次：挑一個上週的想法，讓它走過這兩個 skill，看看輸出長什麼樣。看過一次，你才知道要修哪裡。

## 這些 skill 只是基準版

不管來源是自己寫的還是抓來的，這些 skill 都只是基準版。還是要套你自己的品味，依照你的產業去調整——別人講起來順的句子，你用起來可能卡。

修的方法也很簡單，就是跑完之後直接跟 Claude 說：

> 根據我這次對話給你的回饋，更新你的 skills。

<!--image:3-->

這句話是把回饋變成資產的關鍵。每次你覺得「這句不像我」、「這個 hook 太軟」，講出來，它就寫回 skill 裡。下一支影片再跑，起點已經比上一次高。時間拉長，這個 skill 會越來越懂你怎麼講話、常講哪些詞，而不是停在剛建好那天的樣子。

所以今天就挑一個上週的想法：丟進 hook skill 和 script skill，讓它給你一份腳本跟幾個 hook 選項。不滿意的地方不要改稿了事，直接講成回饋，叫它更新 skill。
