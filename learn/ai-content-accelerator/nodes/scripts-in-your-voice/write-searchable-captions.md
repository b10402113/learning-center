# 實作：把 caption 寫成能被搜到的樣子

錄完、剪完，hook 也定了。發佈畫面上還剩一個欄位空著：caption。多數人的第一個反應，是把 hook 原封不動再貼一次。反正下面那塊字沒人看。這個想法一半對。另一半，會讓你漏掉一件正在發生的事。

上一步已經說明 caption 的角色變了：它不是拉流量的主力，但在照片、carousel，還有主題很特定的內容上，它是加分項。這一步只做一件事——把那幾行字寫出來。

<!--image:1-->

## 先問一句：這則內容要給誰搜到

平台自己會轉錄影片，所以短影片、主題又寬的時候，caption 交給 agent 寫就好。值得你花時間的是另外三種情況：照片或 carousel、主題是很特定的工具或問題、你希望有人主動搜到它。

這個判斷只有十秒。判斷完，再決定要不要往下做。

<!--image:2-->

## 寫法一：把工具名寫進 caption

第一個做法很簡單：caption 裡永遠把你在講的那個工具名字寫出來。

不要只是把 hook 重複貼進 caption。hook 的寫法通常是為了把好奇心拉到最大，所以會故意不寫工具名。caption 相反。它要直接點名。

道理其實是常識。有人在找 Claude Code，那麼直接寫出「Claude Code」的內容，會比文字描述含糊的內容，更容易被 AI agents 抓去用。

<!--image:3-->

## 寫法二：加一段「我們回答了這些問題」

在 caption 裡加一個簡單的段落，標題就叫「我們回答了這些問題」。把這則內容回答到的問題列出來。

這段通常落在 below the fold。要按「閱讀更多」才會出現。大多數人根本不會點到那裡。所以放進去完全沒問題。本質上，就是替貼文補一點 metadata，說明你回答了哪些問題。

<!--image:4-->

## 寫法三：hashtag 當補位，不當主力

Hashtags 還是可以寫。但重點是：它們現在真的沒那麼重要了。

它們基本上只是一種好用、簡單的補關鍵字方式。前提是 caption 裡還沒提到那個關鍵字。「把關鍵字塞進 hashtag 就會有額外流量加成」這件事，已經不是現在的情況了。

## 一份可以直接套的模板

把上面三件事排成一個順序，下次開空白欄位時照這個順序寫：

1. 第一行放工具名或主題關鍵字，不要只放 hook。
2. 第二行一句話說這則內容回答了什麼。
3. 需要時補上「我們回答了這些問題」的清單。
4. hashtag 只放 caption 還沒出現的關鍵字，三個以內就夠。

## 收尾：這幾行字寫完就可以發

caption 還是相關的，因為每一則內容都會帶著一個 caption 出去。但每一則內容的肉，是 hook，也就是你的包裝，加上你影片裡真正在講的內容。

所以，把 caption 交給 agent 寫，是可行的一條路。你當然可以自己改。但讓 agent 寫是可以的。因為無論如何，真正更關鍵的還是內容本身，是你影片裡到底讓人看到什麼。
