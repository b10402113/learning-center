# 把 agent 訓練成你的講話方式

對著 teleprompter 唸 14 分鐘，跑一個指令，回來就拿到一整批切好的 reels。畫面看起來像剪輯已經結束，但真正的工作從這裡開始。你要坐下來把每一段播過去，告訴 agent 哪裡留、哪裡剪、哪裡太長。審片的動作，同時也在訓練它認識你的講話方式。

## 打開 editor，先看懂畫面

Editor 上一步已經裝好，第一版 clips 也切出來了。這一步從「坐下來審」開始：打開畫面，先看懂每個鍵在幹什麼。

進到 editor，用過 Premiere 的話，很多快捷鍵會很熟。按住 Ctrl 在時間軸上放大，按住 Shift 左右平移，按 R 或點原始素材就只播原始素材。播放速度用 S 和 D 調整，覺得太慢可以調快。常設在 2.1 倍速，先快速掃過一遍。按 C 可以把 clip 切開，拖曳就跟其他剪輯軟體一樣。快捷鍵是照自己的工作方式做的，想改就改；想加面板也可以加。

<!--image:2-->

## 為什麼它剪得對，也為什麼會剪錯

上一步拆過：agent 把影片轉錄成帶時間戳的字，再靠「字」和「字被說出來的時間」判斷哪一段留、哪一段剪。

所以它剪錯的時候，通常不是轉錄壞了，而是判斷規則還沒學會你的講話方式。這正是這一步要處理的事。

## 預設規則與審片動作

預設規則是：開頭有假開場時，最後那一次 take 會被保留。slash cut 內建這條規則，因為很多人講話就是這樣。

問題是每個人講話都不一樣。有人停頓很多，有人一句話一直重來，有人講得飛快。所以你要把 agent 訓練成你的講話方式。目標是每次呼叫 slash cut，它都直接給你你要的結果。

審片時，一次把所有 clips 播完，通常用 2 倍速聽，專門看它有沒有把假開場留下來。如果某段被剪掉了，但正片其實需要它，就把那個 clip 拉長。它會自動在那一小段上留一則評論，說明你想延長哪裡。如果中間有一段明顯的停頓，只想留下某個片段，就按 C 把 clip 切開，再拖過去。某個 clip 太長，就拖短，把不要的部分刪掉。

## 這就是強化學習

目前它還比較偏手動剪、手動審。真正的加速在畫面上方那兩個開關：teach your slash cut skill 和 teach your slash animate skill。把開關打開，按 copy comments for all clips，它會把所有 clips 上所有未結案的項目複製起來。直接貼給 Claude，裡面就帶著所有有用的資訊，它馬上知道下一步要做什麼。

這比打字描述精準得多，也比自己動手剪快得多。一開始，你大概會對 Claude 的剪法有點失望，這很正常。但一旦把它訓練好，訓練到它懂你怎麼講、你想怎麼剪，它會走到一個境界：幾乎每一次剪出來的 clips 都是對的。

本質上這就是強化學習，只是規模很小。你每一次在 editor 裡留的評論，都是在告訴它哪個選擇被獎勵、哪個被扣分。你不需要懂訓練模型，只要把不滿意的地方標出來就好。

## 想要動畫就開 /animate

如果要在影片裡加動畫，那是另一個獨立的主題，用 /animate 這個 skill。它讓 agent 幫你加動畫，素材來自一個現成元素庫。這是選配、也比較進階，不需要從這裡開始；等你的剪點覺得順了，再回來看。

安裝方式跟其他 skill 一樣，附帶 install prompt。裝好之後，到 RUBRIC Editor 把 Teach my /animate 打開。你對一支有動畫的 clip 留的評論，就會教 /animate 你喜歡什麼。

## 輸出

等 clips 都剪好、Claude 也把你在 editor 裡留的評論處理完，直接叫它 render 就好。想手動一點，editor 也有 export 按鈕，可以選不同解析度。

如果你本來就有慣用的剪輯軟體，例如 Adobe Premiere 或 Final Cut Pro，可以讓 Claude Code 透過 MCP connector 去操作那些工具。MCP connector 就是加在 Claude Code 上的外掛，讓它能驅動 Premiere Pro 這類軟體。短影音直接 render，長格式影片則有時會在 Premiere Pro 裡再審一遍。用 DaVinci Resolve 或 Final Cut Pro 的人，可以用 search connectors 這個 skill 去找目前最新的 connector。

<!--image:4-->

到這裡，你手上應該有一批可以直接拿去分發、排程的 reels。下一次錄完，先別急著手動剪；跑一次 slash cut，坐下來把 clips 播完，把不滿意的段落標出來，按下 copy comments，貼給 Claude。這是你這週要發出去的東西，也是你正在餵給 agent 的那一份品味。
