# 使用 RUBRIC Editor

錄完一段素材，影片就躺在資料夾裡。要把它變成能發的短片，中間還隔著剪輯：找剪點、判斷哪一句重來、把停頓拉掉。這段最花時間，也最容易被跳過。

自動剪輯要解決的就是這一段。把原始錄影交給 agent，讓它先剪一版，你只負責審。需要的只有兩件事：裝好 RUBRIC Editor，以及用 slash cut 讓 agent 依帶時間戳的轉錄，剪出可以直接審的 clips。

## 手剪過，才有辦法審

上一步已經要你先手剪一兩支。那件事的價值在這裡才兌現：你知道一段話被切掉之後聽起來是什麼樣子，才有辦法判斷 agent 剪得對不對。

接下來就是把這件事交出去，但先交第一版，不交出判斷權。

## 安裝 RUBRIC Editor

RUBRIC Editor 是一個跑在自己電腦上的本機應用。

取得方式跟 Rubric Scripts 一樣：下載壓縮檔，照附帶的 install prompt 安裝。

裝好之後，它會跑在另一個 local host 網址。

因為服務就在本機，Claude 可以直接在 Chrome 裡把它打開，替你操作。

## 用 slash cut 剪出第一版

RUBRIC Editor 附了一個 skill 叫 slash cut。

用法很直接：把錄好的素材檔路徑給它，呼叫這個 skill。MKV 或 MP4 都可以。

呼叫時可以多給一點上下文，說明這段影片在講什麼。

不給也常常能切對，現在很多模型已經能自己把每一支 reel 分開。

但多給上下文，第一次就切對的機率明顯高很多。

實際錄一次：對著 teleprompter 念，全長大約 14 分鐘，總共八支 reels。

跑一個指令之後，拿到一份可以直接開始審的 Rubric Editor，畫面上有七支 reels。

## 介面長得像剪輯軟體

如果你用過 Premiere 這類工具，很多快捷鍵會很熟：

- 按住 **Ctrl**，在時間軸上放大。
- 按住 **Shift**，左右平移瀏覽。
- 按 **R**，或直接點原始素材，只播原始素材。
- 按 **S** 或 **D** 調播放速度，例如設在 2.1 倍速。

播一次就會聽到它把某一段切掉，例如「我說 number one」那句，因為那不是正片。

這些功能是照實際工作習慣內建的。要改功能、改快捷鍵、多加幾個面板，都可以照自己的喜好來。

## 它怎麼知道要剪哪裡

你呼叫 slash cut、把影片交給 Claude 之後，背後發生兩件事。

第一，你透過檔案路徑，把原始錄影（MKV 或 MP4）交給 Claude。第二，agent 會把影片內容轉錄成文字。

第二步是關鍵。轉錄不只抓到腳本裡的字，還會替每一個字加上時間戳記。

所以你同時有「字」和「這個字在第幾秒被說出來」兩組資料。Claude 就是靠這個判斷哪些字要留、哪些要剪、在影片的哪個位置。

有了字級時間戳（word-level timestamps），剩下的就是判斷：哪些段落留、哪些不留。

## 轉錄工具怎麼選

轉錄工具不只一種，做法都一樣：到 ElevenLabs 或 AssemblyAI 的網站拿一組 API key，然後問 Claude 怎麼把 key 給它，讓它連到你的帳號。

- **AssemblyAI**：一小時的影片只要 33 秒。14 分鐘的素材，轉錄不到 10 秒就完成。
- **Whisper**（OpenAI）：免費，但慢很多。它跑在你的電腦上，速度取決於 CPU 效能。一小時的影片大約要 15 分鐘。可以在 slash cut 裡設定，把預設從 AssemblyAI 換成 Whisper。
- **ElevenLabs Scribe**：速度跟 AssemblyAI 差不多，但貴一點。本來就有 ElevenLabs 訂閱的話，直接用它最省事。

## 預設規則是保留最後一次 take

預設情況下，如果開頭有假開場（false start），最後那一次 take 才是被保留的。

這是 slash cut 內建的規則。

問題是每個人講話的方式都不一樣：有人停頓很多，有人一句話一直重來，有人講得飛快。所以規則要能調，讓它慢慢學會哪些 take 該剪、哪些停頓該留。

整個流程的最後一步，是 agent 讀它剛剪好的成品，上傳到 Rubric Editor 給你審。

## 接下來就是審

第一版 clips 出來之後，真正的價值不在剪得多快，而在你怎麼審、怎麼把每一次修正回寫成它的判斷。那個流程是下一步的事。

到這裡，你要發出的東西很具體：挑一支已經錄好、還躺在資料夾裡的素材，裝好 RUBRIC Editor，跑一次 slash cut，拿到一份可以直接開始審的 clips。
