# 螢幕分享就用 OBS

上一支影片確認了：聲音比畫面重要，你手上那支手機已經夠用。這一步處理的是另一半——螢幕分享。

你決定要錄螢幕上的操作，滑鼠已經移到錄影鍵上。該用的工具是 OBS。它開源、免費。你要做的不是把每個設定都研究一遍，而是把它調到「按一下就能錄」的狀態。

## 熱鍵：錄影時不必真的停下來

OBS 裡可以調的設定很多，但最常用的是熱鍵。常用的三組熱鍵是：

| 熱鍵 | 切到什麼畫面 |
| --- | --- |
| shift + control + 4 | 讓觀眾看到完整畫面 |
| shift + control + 1 | 切回自己比較大的視角 |
| shift + control + 2 | 把影片暫停，只顯示白畫面或黑畫面，同時靜音 |

第三組是關鍵。你講到一半需要停頓、想改一句話、喝口水，按一下就切成空白而且靜音。你還在講話也沒關係，畫面上沒有人。這樣錄影時就不必真的停下來重來。如果你要做長格式內容，這個功能很值得花五分鐘設好。

## 直式畫面

很多人以為 OBS 只能錄橫的，其實它也能設成直式比例。做短影音不用另外找一套工具。同一個場景調一下畫布就好。很多設定直接叫 Claude 幫你設。

不過如果你才剛起步、正在衝量、衝 reps，先從短影音開始。一支一支錄，比一次規劃一支長片容易維持。

## 讓 agent 驅動它

OBS 還有一個別的工具沒有的地方：Claude 和其他 agent 真的可以驅動它，因為已經有人做好 connector 了。

這個 connector 不是官方版。你可以拿 search connectors 這類 skill 跑一下，看看 OBS 目前有哪些 connector、哪一個還能用。很可能再過一陣子就會出現官方版本，讓 agent 直接驅動它。

<!--image:3-->

這裡的習慣比這個工具本身重要：用任何應用程式之前，先找找有沒有 connector，能自動化就自動化。OBS 只是第一個練習對象。

## 回到重點

相機和設備真的沒有你想的那麼重要。真正決定成果的，是你練習的次數，還有每一次有沒有比上一次好一點。

所以今天就做這三件事：把三組熱鍵設好、把直式畫布開起來、錄下第一段螢幕操作。設備的事，等你錄完十次再說。
