# 選好之後，丟回 Claude 做兩件事

購物車裡躺著一排縮圖和倍數。那個數字不是絕對觀看數，是這支比帳號平常紅幾倍。平常 4,000 的頻道，一支 33,000，就是 8 倍。

真正卡住的是下一步：這些卡片裡，哪一張你這個禮拜真的能坐下來錄？

<!--image:1-->

## 用兩個條件篩，不要用「哪支最紅」篩

挑的時候看兩件事。第一，**你有感**。看到題目，腦中馬上冒出自己的想法、經驗或反例。第二，**這週就能講**。手上已經有素材，不用先學新東西、不用等 demo 做完。

這兩條篩下去，購物車通常只剩兩三張。剩下的才是候選題，其餘先留著，下週或下個月再回來看。

## 丟回 Claude，請它寫成你講得出口的腳本

選定之後，把清單丟回 Claude，請它把題目寫成可以直接講的腳本，用在 TikTok 或 Instagram 貼文上。關鍵字是「用你自己的語氣」。

腳本不是文章。文章可以靠結構撐住，腳本要能從嘴巴裡說出來。寫完先讀一遍，出聲讀。哪裡舌頭打結、哪裡要在心裡補半句話才接得下去，那裡就是該改成白話的地方。講不出來的句子，觀眾也聽不進去。

<!--image:2-->

## 現在不夠好，很正常

第一版腳本大概不會太好。可能 hook 太長、鋪陳太多、結尾虛掉。這不用現在解決，後面會專門講怎麼把它變好。

現在唯一要守住的動作是：**量才是關鍵，先開始錄**。一支講得普通的影片發出去，會換來一次真實的回饋；一份改到完美的腳本躺在資料夾裡，什麼都不會發生。

## 順手讓 skill 更懂你的口味

同時還有第二件事：請 agent 依這次挑選的結果，調整 `/outliers` 這支 skill。你挑了哪幾張、跳過了哪幾張、為什麼，這些都是訊號。調整過幾次之後，它推給你的題目會愈來愈接近你會真的拍的東西。

一次只花幾分鐘，但累積起來差很多。工具不會自己懂你，是你每次的選擇在教它。

## 挑不到東西時，先動搜尋條件

有時候結果頁很空，或一整排都無感。先別急著怪工具，改條件比較快。

**放寬主題**：搜一個比原本更寬的領域。**往更早看**：把時間範圍拉得比預設更長。主題要盡量具體——不要只講 AI，講本地 AI、醫療裡的 AI、給系統工程師用的 AI，這種題目才有畫面。

也完全可以不是 AI。你的嗜好、工作、生意，都算在裡面。

<!--image:3-->

這週的題目不用等到「準備好」。從購物車挑一張你有感、這週講得出來的卡，請 Claude 寫成一段你講得出口的話，然後打開鏡頭。
