# Outlier 不需要幾百萬觀看

你打開一個只有幾千訂閱的頻道。某一支影片的觀看數是其他影片的好幾倍。它沒有爆紅，但在這個帳號裡明顯突出。這就是 outlier。

判斷 outlier 不看絕對數字。一個頻道平常 4,000 觀看，有一支拿到 33,000，就是平常的 8 倍。這代表那個主題在它的觀眾裡奏效了。你要找的就是這種主題。

<!--image:1-->

## 它算的是倍數，不是熱門排行

前面那條式子，就是這支 skill 做的事：把每一則貼文的觀看數，除以那個帳號平常的觀看數，再排出名次。範圍橫跨 YouTube、TikTok、X 和其他平台。

它給你的不是熱門影片清單，而是「對這個帳號來說異常好」的影片清單。倍數就是訊號。

<!--image:2-->

## 安裝

安裝只有三步。下載 zip。把安裝 prompt 貼進 Claude 或你的 agent。它會回給你設定需要的連結。

設定只有第一次要做，之後不用再管。你不用記住任何指令，連結它會給你。

<!--image:3-->

## 要抓 YouTube 資料，得先開 API

要抓 YouTube 的資料，得開啟 YouTube Data API。這件事免費，只要建立一把 key。

設定的過程會把連結都給你。拿到 key 之後，傳給 Claude，或請它開一個安全檔案，讓你自己貼進去。

## 跑起來

請 Claude 執行 `/outliers`。附模板，結果會開成一個頁面，裡面有縮圖和倍數。

一邊看縮圖，一邊看倍數，把喜歡的加進購物車。挑的重點有兩個：你有感，而且這週就能講。

<!--image:4-->

## 跑完之後

頁面會給你一份有縮圖、有倍數的清單。看到這裡先別急著全部收下——下一步要處理的是，怎麼從裡面挑出這週真的能講的那一張，以及挑完之後怎麼把它變成腳本。

## 幾個小技巧

結果太少，就把主題放寬，搜一個比你原本更寬的領域。或者往更早看，要一個比預設更長的時間範圍。

主題要有創意，盡量具體。不要只講 AI，可以講本地 AI、醫療裡的 AI、給系統工程師用的 AI。

也可以完全不是 AI。你的嗜好、你的工作、你的生意，都算。

到這裡，你手上要有的東西很具體：一個裝好的 `/outliers`、一把免費的 key，一份已經放進購物車的清單。清單裡至少要有一支影片，是你這週就能開口講的。
