# 獨輪車上的熊

你已經有一項真的會的技能，也想開始做內容講 AI。第一個念頭很自然：那就講「Claude 基礎用法」吧。你錄了一支教學，標題寫得像外面那些爆紅內容一樣，內容也紮實。發出去，觀看數停在兩位數。

這跟你的能力無關，跟你懂不懂 AI 也無關。問題出在你選的那個題目有多大。

## 題目抓太大，是新手最自然的錯

如果你只是講 AI、講 Claude、講 ChatGPT，你面對的是一片大海，而且海裡已經有大咖。

想像你做了一支「Claude 基礎用法」。這支教學很可能飛不起來，不是因為它沒用，而是因為外面已經有一大堆教學在講同樣的事。Dan Martell 就是一個例子：他本來就在商業界，出過好幾本書，頻道內容品質很好，而且明確針對 Claude 和 AI 的初學者。他在 YouTube 上有三百萬訂閱。

他做這種大眾題目行得通，有兩個原因。第一，AI 初學者的數量非常可觀，那就是那片大海。第二，他已經在商業和科技領域站穩位置、為人所知，粉絲量也夠。

換成你，也許只有一百或兩百個追蹤者，做一支一樣在教 Claude 的教學，標題也照抄「16 分鐘學會 97% 的 Claude」，內容一樣，結果大概率是沒什麼觀看。因為你是在大海裡當一條很小的魚。

把自己放進觀眾的鞋子裡想一次就好：當這個領域已經有 Dan 這種人站穩了位置、成功出場過好幾家新創，觀眾會聽誰的？

## 先當小池塘裡的大魚

對大多數剛起步的人，真正該記住的策略只有一句：試著當小池塘裡的大魚。

做法很簡單。與其跟所有人一起擠在「AI」這個題目上競爭，你只要在剛開始的時候把範圍縮小。之後你隨時可以往外擴張——等你更成功、累積出追蹤者之後再說。

把焦點縮窄，不只是競爭變少。還有一個現象會站在你這邊。

## 一隻熊，加一台獨輪車

那個現象叫「獨輪車上的熊」。

一隻熊，算是有點意思。一台獨輪車，也算是有點意思。但你把這兩個放在一起，畫面就非常突出。人就是這樣：當你把兩個以上的東西組成一個完整的整體，大家會更有興趣。

<!--image:2-->

這個比喻真正的用處，是幫你決定題目怎麼切。單獨講 AI，你是那隻普通的熊。加上一個只有你有的東西，你才變成獨輪車上的熊。

## 把 AI 接上你已經有的專業

所以如果你還是要講 AI——會想學這些的人，本來就對 AI 有興趣——一個很好的起點是：把 AI 跟你已經有專業的某個 niche 結合起來。niche 就是一個夠小、有人在乎、而且你講得比多數人清楚的題目範圍。

看幾個實際的樣子：

- Mike Gerard 是房地產仲介，他做的內容是 Claude 加房地產。
- Mark Coles 做健身教練事業，他講的是 AI 怎麼幫他做健身教練。
- Mukesh 是醫生，他用 AI 講的是自己工作現場會遇到的事。

這些人的訂閱數或觀看數不一定最高。但這正是重點：你不需要那麼大的粉絲量，就能讓內容替你帶動生意。

<!--image:3-->

把 AI 當成一層放大器，套在你本來就懂的場景上，你講的每一句都有細節撐著。別人講「AI 可以幫你寫信」，你講「AI 怎麼幫房仲回覆一則帶看後的追蹤訊息」——後者聽起來就是不同等級的東西。

## 小池塘不是終點

從小小的池塘開始，不代表你要一直待在那裡。

有一個人早期的內容，很明顯偏品牌和廣告，因為他職涯裡很大一塊是在 Unilever、HelloFresh、Virgin 這些公司管品牌。他現在的內容比較一般性了，雖然還是針對 Claude Code 和重度 agentic AI 使用者——但那是做了幾年內容之後才那樣的。一開始，他做的範圍比現在窄得多。

Alex 的路徑也一樣。他現在的內容全都在談商業，但一開始，他是在「商業」這片大海裡把範圍縮到健身房管理，讓自己先被看見。你去他頻道按最舊的排序，會看到好幾年前那些講健身房管理的內容。後來他才從那個小子集合，擴張到商業這片更大的海。他做了大概八年，這才是為什麼很多人願意信任他，讓他在那麼大的海裡玩。

<!--image:4-->

所以順序是這樣：先聚焦在一個更小的池塘，在那裡當大魚，站穩了再往外擴。

## 寫下你的第一個小池塘題目

現在把這件事變成一個句子。格式是「我原本就懂的場景」加「AI」，而且場景要小到你能講出只有你做過的事。

先寫三個候選，每個都不超過一行。例如你每天在寫 TypeScript、在替 solo builder 把 agent 接進真的會賺錢的流程，那候選可能是「用 agent 處理客戶退款流程的實作」、「一個人維護 repo 時怎麼讓 agent 接手重複工作」、「把 side project 從 demo 推到收費的那幾步」。

再從三個裡挑一個。判斷標準不是哪個聽起來最大，而是哪個你現在就能講出五個具體案例、而且講得出別人不知道的細節。

選好之後，寫下你的第一個題目。它應該長得像「我用 agent 做 X 的時候，遇到 Y」，而不是「AI 入門教學」。

最後補一行：三年後你想講到多大的範圍。那行現在不用做任何事，它只是提醒你，小池塘是起點，不是天花板。
