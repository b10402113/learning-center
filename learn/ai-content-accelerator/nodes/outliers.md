# 第二種穩定選題來源：Outlier

## Lesson

Outlier 不是看絕對觀看數，而是看「這支影片是這個帳號平常的幾倍」。這個 node 教你用相對倍數找已被市場驗證的題目，並用 `/outliers` 建自己的研究資料庫。
