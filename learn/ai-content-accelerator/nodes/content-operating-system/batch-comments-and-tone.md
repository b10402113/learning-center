# 一次改完所有腳本

「這句太長。」你在心裡講了一次，然後繼續往下讀。讀到第三份腳本，你已經忘了第一份要改哪裡，最後乾脆整份重貼給 agent，從頭再 prompt 一次。

問題不是腳本不夠好，是回饋散掉了。每一份都改一點，改到後面已經記不得自己嫌過什麼。要批次修，就得先把意見留在看得到的地方。

## 把回饋留在句子旁邊

打開一份腳本，左邊是點子清單，可以直接切換。覺得哪句話不像你，就把那段文字反白，會跳出一個小視窗。在裡面寫下意見，就像在 Google Doc 留 comment。不想打字就用語音工具講，快很多。這些評論會進到一個會滾動的清單裡，你隨時可以打開來看，不會漏掉。

一份看完就換下一份。三個點子就是三次同樣的動作：快速讀過去、確認 caption、留幾則評論。比如你想把第一點跟第二點對調，就把這個意見寫下來。每則評論會自動存進那份腳本自己的 comments card。

## 評論要具體

最沒用的評論是「這段好一點」。agent 拿到這句話，只能猜。

有用的版本長這樣：「這個 hook 太長，砍成一行。」你指出位置、指出問題、指出要改成什麼樣子。另一種更直接的寫法：寫下你真正會怎麼講，用你自己的話。那句話本身就是答案，agent 不用再揣摩你的語氣。

## 按一顆鍵，全部一起改

全部看完之後，不要自己重寫，也不要一份一份 prompt agent 去修。按 copy comments for all scripts，它會把整段指令複製到剪貼簿。貼上、送出，agent 就會一次把所有腳本修好。

<!--image:2-->

這一步是整條流程的關鍵。你花時間的地方是「讀」跟「判斷」，不是「重複下指令」。這也是專屬介面存在的理由。caption、SEO 的注意事項、這支影片整體在講什麼，都擺在同一個畫面上。你才有辦法在一輪裡把三份都審完。

## Teach My Tone：把回饋寫回 tone skill

複製評論之前，把 Teach My Tone 這個開關打開。它會讓 agent 用同一批評論去改你的 slash tone skill。

你剛剛嫌棄的那些句子，不只會被改掉，還會變成規則。下一批腳本產生的時候，就已經避開你這次糾正的寫法。tone skill 愈改愈好，之後的腳本也跟著變強。

<!--image:3-->

這件事值得做超過一次。每審一輪，你的 tone 就多吸收一輪你的判斷。累積幾輪之後，你會發現需要留的評論變少了。

## 什麼時候可以不用逐一審

如果你的 tone of voice 跟 hooks 這兩個 skill 已經調準了，很多時候你不需要每一份腳本、每一個 hook 都逐一審。挑一個 hook、確認 caption、往下走就好。

留評論是例外處理，不是固定流程。真正需要你出手的地方，通常就是你會卡住的地方。

## 收尾

腳本修好之後，把它送到你錄影時真的會看的地方，例如 Telegram，或你自己的 teleprompter。

但在那之前，每一份腳本都要出聲念過一遍。如果你在哪一句卡住，那一句就是該改的地方。念順了再錄，也不要等完美：量才是重點。
