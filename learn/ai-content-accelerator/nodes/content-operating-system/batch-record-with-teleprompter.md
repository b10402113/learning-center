# 一次錄完，之後再切

你的腳本已經寫好了，可能就躺在同一個頁面裡，一份一份排著。但真正要開錄的時候，還是得先打開一份、捲到第一行、把視窗擺到眼睛高度，錄完再換下一份。錄到第五支，注意力已經不在講內容，而是在找檔案、對位置、想剛剛那句是不是漏了。

問題不在腳本，在順序。一支一支錄，等於把整批工作切成一堆小啟動成本。換個做法：把整批腳本當成同一件事，一次錄完，切段留給後面的自動剪輯。

## 先決定腳本要送到哪裡讀

腳本寫好，不等於你讀得到。要照著念，它得先被送到一個你眼睛真的能盯著看的地方。

常見的三種去處：**Telegram**，把 agent 接上你的帳號，整份腳本會傳到手機上，站著、走著都能讀；**artifact 或網頁**，坐在電腦前讀的時候，請 agent 把腳本放進一個頁面；再來就是**自己的 teleprompter**。

teleprompter 聽起來很專業，其實只是一套很個人的小軟體，唯一用途就是：當你有腳本要照著讀，叫 agent 把它送進去。它不需要漂亮，也不需要功能齊全，只要字夠大、會自己往下跑就好。

## teleprompter 長什麼樣

打開之後就是一份腳本攤在畫面上。點 desktop view 進到讀稿模式，按 play，文字就開始往下捲；捲動速度可以調，字級也可以調。念快了就調快，眼睛跟不上就放大字。

手機版是另一個頁面，在 Chrome 裡打開，長得跟桌機版很像。按播放、按暫停，就這樣。它的存在只是為了讓你不需要坐在電腦前也能錄。

重點是：這類工具你都可以照自己的習慣改。速度、字級、版面，甚至要不要多一個計時器，跟 agent 說一聲就好。

## 把整批腳本變成一份長文件

真正省時間的一步在這裡：不要一支一支錄，把所有要錄的腳本**依序載進 teleprompter，變成一整頁長長的文件**。

比如說這次要發八支 reels，那就是八份腳本接在一起。你照著這份長文件，從第一支、第二支、第三支，一路不間斷地念下去，一次錄完。中間不停、不換檔、不重新對位置。

錄完的成果是一份沒有切過的原始素材。接著把它整份丟給 agent，讓它照你要的段落切開、把每一支 clip 分好，最後換回八支獨立的影片。你在錄的時候只想著講話，切割這種機械工作交給它。

## 把錄影壓進一個時段

這個做法最大的改變，是你終於可以把創作批次化。

假設你把星期六訂為內容創作日，那就撥一個小時，對著一份長文件念，一次錄十五支 reels。一個小時的專注，換來整週要發的素材。平日不需要再擠時間開錄影軟體、調燈光、重念同一句話，正職工作的時間也不會被切碎。

能不能穩定出片，靠的通常不是靈感，而是這種「一次做完一批」的節奏。

## 錄之前，先出聲念一遍

進 teleprompter 之前，每一份腳本都要出聲念過一次。原因很實際：默讀順的句子，念出來會卡。如果你在某一句停了、繞了、要重看一次才懂，那一句就是該改的地方，不是該硬念過去的地方。

還有一個更重要的提醒：**不要等完美**。腳本永遠可以再修一句，但修到滿意才開錄，你一支都發不出去。量才是重點，先讓一批內容真的錄完、真的上線，再從回饋裡修下一批。

這一週要做的不是錄一支影片，是排一份長文件：把這週要發的腳本照順序接好，載進 teleprompter，按下 play，然後一路念到底。
