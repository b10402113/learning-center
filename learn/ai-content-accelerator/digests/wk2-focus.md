# L1 overview

- 第二週（Wk2）主題是**內容選題（content ideation）**：拆解哪些環節可以自動化，哪些其實不必自己來。
- 本週會提供數個 **skill** 與**自動化模板**，讓學習者能直接做出本週里程碑。
- 學習目標一：理解為什麼**品質在起步階段被過度恐懼**，以及品質真正的定義。
- 學習目標二：理解為什麼**數量是優先該專注的事**，以及如何邊做邊迭代。
- 學習目標三：找出自己利基的**知識之井**，並用 **Claude** 從中產生點子。
- 學習目標四：用 **outlier（異常爆量內容）** 找出已被市場驗證有效的點子。
- 學習目標五：保留**自己的點子**，因為那部分無法自動化。
- 本週成果：**實際發布一篇自己的點子**，並至少 brainstorm 出 **3 個內容點子**。
