# L1 overview

- 很多人卡在相機與拍攝設備，但現在做內容畫質不是品質最大指標，聲音比畫面更重要。
- 對 AI 有興趣的學習者，手上現有手機就已夠用，不需要買新相機；作者早期只用舊的 Google Pixel 做 TikTok。
- 教育型內容與替企業建立信任的內容，唯一真正要求是聲音清楚。
- 若只能升級一樣且有預算，先投資聲音，再考慮買炫的新相機。
- 螢幕分享內容最常用的是開源免費工具 OBS；已有 connector 可讓 Claude 等 agent 驅動它。
- 作者常用 OBS 熱鍵：shift + control + 4 切成完整畫面、shift + control + 1 切回自己的大視角、shift + control + 2 暫停成白／黑畫面（畫面無人且靜音），方便錄影時不必真的停下來。
- 初學者建議先從短影音開始衝量與 reps；OBS 也能設成直式比例，很多設定可叫 Claude 幫忙。
- 作者連結的 OBS connector 不是官方版；可用 search connectors skill 查目前最新 connector，並養成先找 connector、能自動化就自動化的習慣。
- 設備真的沒有想像中重要；更重要的是 Content Pyramid 裡的練習次數（reps）與每次是否比上次更好。
- 有了這套作業系統與資源，就能把許多事自動化，規模化產出內容又不犧牲事業時間。
