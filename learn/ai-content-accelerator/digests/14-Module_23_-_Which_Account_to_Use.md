# L1 overview

- 本課談戰術：該用哪個帳號發內容，以及養帳號（warming up）的概念；下一週才會把發佈自動化（distribution）。
- 多數人在個人帳號（與朋友家人聯繫用）與事業／主題帳號（只講你的主題）之間選一個。
- 作者建議為事業內容開獨立帳號：把私人生活、朋友與工作隔開。
- 獨立事業帳號的另一好處：feed 會是與 niche 相關的內容，方便用內容生產者的視角研究趨勢與收集 hook 點子。
- 不一定要新開帳號：可把沒在用的舊帳號改名、封存舊貼文，因為它已經養過（warmed up），第一天就能發。
- 養帳號不複雜：平台要的是真實、正常的人操作；像正常人一樣看內容、追蹤 niche 裡的人、按讚互動留言。
- 平台真正要擋的是大量自動化、買來的帳號；Instagram 與 TikTok 都不要這類帳號。
- 警訊：如果每次發文觀看數都不到 10，代表已被標記成 bot，較好的做法是換帳號，或開新帳號重新養。
- 養帳號時間：網路多數指南約一週；謹慎一點可養兩週（作者一般建議）；新帳號最好等四週再開始自動化發文。
- 這些只是二手經驗整理，平台沒有鐵打的明文規則；只要像真人一樣使用帳號，大致安全。
- 能手動發就先手動發：手動發有更好的觸及與體驗，也能在自動化前觀察每支內容表現；經營事業帳號時還會看到產業實際流傳的 hook、腳本與趨勢。
