# L1 overview

- 第三週是把前幾週的內容身份定位、內容 firmware 更新、靈感流程自動化全部拿來實作的一週。
- 本週里程碑：設定 5 篇內容，目標是在週末前全部發佈，並用後續模組的工具讓每一篇逐步優化。
- 第一步先學「怎麼說得好」：hooks 的原則、正確的 script 寫法、以及 captions 的思考方式。
- 第二步才動手做：談相機與拍攝環境，說明什麼樣的 setup 已經「夠用」。
- 同時提供自動化剪片方法，讓影片剪完就處於可直接發佈的狀態。
- 最後補成長基礎：該用哪個帳號發內容、從建立名聲到建立信任、以及養帳號（warming up accounts）的概念。
- 全課以 AI agents 協助並自動化內容製作步驟為主軸，先從 hook 開始。
