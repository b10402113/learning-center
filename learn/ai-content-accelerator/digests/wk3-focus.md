# L1 overview

- 第三週主題是「Content Creation」：把前兩週累積的點子真正做成內容，並讓 AI agent 承擔大量製作工作。
- 本週產出目標：發佈 5 篇內容，而且每一篇都要比前一篇更好。
- 要學的核心表達技巧：寫出讓人停下來的 hooks、寫出像自己語氣的 scripts、寫出幫人找到你的 captions。
- 要把點子轉成腳本，使用 RUBRIC Scripts；要設定相機；要把無聊的剪輯交給 agent，使用 RUBRIC Editor。
- 本週也會談 trust and truth（信任與真實），以及 agent 與你一起運作的整套 content OS（內容作業系統）。
- 最後要決定從哪個帳號發文，並在第一次發文前先把帳號養好（warm it up）。
- 頁面只是課程導覽，列出本週四類學習目標與最終里程碑，沒有額外技術細節。
