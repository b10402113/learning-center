# L1 overview

- **`/latest`** 用來找新鮮內容點子，免去整天滑手機：看你的**領域（niche）過去七天**有什麼新東西。
- 輸出是**最多 10 個、已排好名次**的內容點子；「七天」與「10 個」都只是預設值，可自行調整。
- 資料來源：**Reddit、X、YouTube、GitHub、網路**，再加上**你自己平常會看的來源**；自己的來源最重要，因為最懂領域的人是你。
- 只保留**附得上真實連結**的點子，每一個都能點進去看。
- 安裝約**五分鐘**：下載 zip、把安裝 prompt 貼進 Claude 或 agent、回答幾個領域問題。
- 若還沒有領域，可直接問 Claude：「根據你對我的了解，建議一些我可以在內容裡講的主題。」
- 使用方式：輸入 **`/latest`** 或後面接領域；結果會開成**可搜尋、可篩選**的頁面，可把喜歡的**加進購物車**。
- 提醒：**量才是關鍵**，必須真的去發、真的去講這些點子。
- 選好後丟回 Claude 做兩件事：把點子寫成**可直接講的腳本**（TikTok／Instagram、用**自己的語氣**）；請 agent **調整 `/latest` skill** 以更懂你的口味。
- 小技巧：點子太少就把主題**放寬**或改成看**過去 28 天**；主題要**有創意且更具體**，例如從 AI 縮小到**本地端與開源 AI**，或從 Claude 縮小到**用 Claude 做 3D 建模**。
