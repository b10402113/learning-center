# L1 overview

- 這是 Rubric Scripts 的快速導覽：腳本被寫出、審過、準備進錄影的地方。
- 核心價值是一頁管好所有腳本，不必再翻舊對話找當初想錄的那支。
- 開始兩步：把 install prompt 貼進 agent，輸入 slash rubric scripts 開啟頁面。
- 把上週用 slash latest 與 slash outliers 收集的 shortlist 載入，或直接重跑那兩個 skill。
- Agent 會用 slash script skill 為每個點子寫腳本，附三個 hook 選項（來自 slash hooks），整份腳本使用你的語氣（來自 slash tone）。
- 每份腳本進頁面時 hook 會被標亮，一眼看出第一句話是否抓人。
- 留評論方式：反白文字、像 Google Doc 一樣加評論；頁面另有影片區與頻道區，會在內容分發模組再談。
- 評論複製給 agent 後可做兩件事：一是照評論重寫腳本，讀順後送到 Telegram 或 teleprompter，且不要等完美、量才是重點；二是開啟 Teach My Tone，用同一批評論修 slash tone skill。
- 小技巧：評論要具體（例如「這個 hook 太長，砍成一行」）、直接寫下你真正會怎麼講、錄前每份腳本都要出聲念過，卡住的那句就是該改的地方。
