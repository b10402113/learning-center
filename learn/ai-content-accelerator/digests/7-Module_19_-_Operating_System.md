# L1 overview

- 這一課拉遠視角，先讓學習者看見正在逐步建起的整套內容作業系統（content operating system）。
- 作業系統的定義：一組 skills、軟體、原則，這次針對內容，目的是替事業帶進營收或利潤。
- 這就是 RoboNuggets 內容作業系統，也是作者每天實際用來推動事業與品牌的那一套。
- 第一週做內容身份定位，介紹兩個框架：Content Trifecta（該創作什麼）與 Content Pyramid（該怎麼創作），並談自動化的產業靈感搜尋。
- 第二週應已累積想法：來自產業 outliers、niche 的知識井（well of knowledge）最新內容，以及自己的想法。
- 這一週把內容真的做出來，下週開始就有最終成品可直接發佈。
- Agent 貫穿所有步驟、位於正中央；以前需要一整個內容團隊才能完成與自動化的工作，現在由一個 agent 在旁協助完成。
- 後面會介紹兩套固定使用的客製軟體：Rubric Scripts 與 Rubric Editor，用來自動化並檢視大量內容。
- 停下來看全圖的目的：讓你知道正在建的是一个可隨創作與學習持續改進的作業系統，接近課程最後會再回到這張圖。
