# L1 overview

- 第二種「已被驗證」的選題來源是 **outlier（異常爆量貼文）**：表現超出該帳號平常水準的貼文。
- Outlier **不是看絕對觀看數**，而是看**相對倍數**。
- 例證：**Morin** 一支 **33,000** 觀看的影片，當時約 **6,000** 訂閱、平常觀看約 **4,000**，等於平常的**約 8 倍**，是明確訊號。
- 大創作者同理：**Chris Williamson** 平常約 **50 萬**，一支 **100 萬**就是平常的 **2 倍**，才算 outlier。
- 工具 **VidIQ** 會在瀏覽 YouTube／Instagram 時直接顯示 **outlier score**（如「我平常的 2 倍」）；作者提到 **Claude 和 Jeff** 影片 **80 萬**觀看、約平常 **7.5 倍**。
- 作者把「看內容」變成「做研究」：看到好影片按 **`/INSPO`** skill，存進自己的 **outlier 影片小資料庫**（放在 **rubric console** 分頁）。
- 因為資料庫用 Claude 建立，Claude 也能讀取，依當天上下文與調性找素材。
- **沒有 VidIQ 也能開始**：**`/outliers`** skill 會自動算 outlier 分數，可給一組參考影片或讓 agent 在產業中搜尋並排名。
- 底層就是數學：**這支影片的觀看數 ÷ 這個帳號平常的觀看數**；**長影片與 Shorts 都適用**。
- Outlier 能判斷**哪些主題正在帶動大量觀看**，可**照著做**或**加上自己獨特觀點**，也能看出**趨勢**。
- 例證：**馬尼拉**一家在地烘焙店的 TikTok 拿到 **1,200 萬**觀看，剪輯簡單、只是在講產品，示範用 outlier 概念挖出跟趨勢的商業內容。
