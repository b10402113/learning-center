# L1 overview

- 走到這裡手上應該已有一份**簡短的點子清單**；最好的下一步就是**直接挑一個發出去**，那就是本週里程碑。
- 核心提醒：**你自己的點子真的重要**，甚至比研究結果更重要。
- AI agent 可以幫忙、可以做 outlier 研究、可以掌握最新資訊，但很多趨勢與爆紅內容是**沒做這些研究的人**開始的，靠的是**對自己點子的創意**。
- 例證：**Vasilius** 已有 **10 萬**訂閱，那支影片只是坐著講**系統工程（systems engineering）40 分鐘**。
- 他大概沒做 outlier 研究、也沒追最新資訊，但做了兩件事：**真的做出來並發出去**；因為專業夠深，內容**對他在意的那群人是真的有用**。
- 不要因為點子不符合 outlier 研究或任何研究就把它丟掉。
- **量才是關鍵**：發出去才會拿到回饋，才知道如何迭代與做得更好。
- 心態轉換：從**消費者**變成**生產者**，有目的地看內容。
- 看動態牆時問自己：**這個創作者是怎麼想到這個點子的？這個趨勢從哪裡來？** 這會帶來下一支內容的靈感。
- 作者常用**書籤工具**，隨手存起來，之後點子打中時回去翻；養成**當內容的學生**的習慣，是這個時代生意成長的重要部分。
- 第二週到此結束；這門課**重點是行動**，若這週沒真的發出東西，成功與累積追蹤者的機會會大幅下降。

- `#L5-L8` — 自己的點子比研究結果更重要；許多爆紅內容由沒做研究、只靠創意的人開始。

- `#L17-L21` — 量才是關鍵：發布後取得回饋，才能迭代與改進。
- `#L22-L27` — 從消費者轉為生產者：有目的地看內容、追問點子與趨勢來源、用書籤工具累積靈感。
- `#L28-L30` — 第二週收束：課程重點是行動，鼓勵完成下一頁的里程碑。
