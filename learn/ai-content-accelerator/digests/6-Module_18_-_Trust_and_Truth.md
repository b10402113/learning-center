# L1 overview

- 為什麼重要：用內容替事業帶曝光時，最怕累積了追蹤者卻不信任你，這會直接傷害綁在一起的事業名聲。
- 基本原則：under promise and over deliver（少承諾、多交付），適用於內容創作者、事業主與任何交易。
- 內容承諾的本質就是 hook；常見陷阱是承諾太多、吹得太滿，真正交付時卻不足。
- 包裝就是承諾：前三秒、標題、縮圖都是承諾，觀眾期待至少拿到同等品質；這裡的品質指內容有用、能對上開頭承諾，而非製作質感。
- Clickbait 本身不一定壞，問題是它把期待吹大，交付時產生巨大落差，犧牲的是名聲；建議新手避免全大寫的 clickbait 標題。
- 平台與創作者利益一致：YouTube 目標是拉高觀看時間，clickbait 雖帶來點擊卻讓人提早離開，因此平台會避開、甚至壓低 clickbait。
- 第一步是先有自覺：你在影片裡說的話會影響名聲；高產量時可能沒確認 script 是否過時，但有自覺下次就能改進。
- 小創作者（10,000、20,000 追蹤者，尤其只發 shorts）通常可以多試 clickbait，但要知道長期賽局最終要調整。
- 真實案例：一則「Claude 或 Anthropic 每月付 7,000 美元讓人學 AI」的貼文爆紅、約 900,000 次觀看，但梯次已截止數週，追蹤者後來發現 program 已關閉，會把這個經驗算進對創作者的評價。
- 任何包裝都一樣：作者只在工具真的超猛時才用 insane，因為各產業都有被過度使用、讓人聯想到過度承諾的字；clickbait 標題長期弊大於利。
- Faceless content 起步沒問題，但長期賽局中露臉更能建立信任，因為觀眾看到鏡頭後面的真人更容易產生連結；對鏡頭講話是可練的技能。
