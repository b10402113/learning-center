# L1 overview

- /animate 用來在影片中加入動畫，效果類似作者近期影片中的動態元素。
- 使用時機：剪輯與排序完成後，讓 agent 從現成元素庫（library of ready-made elements）替你加上動畫。
- 這是選用且較進階的主題，不需要從這裡開始；等剪輯手感對了再回來。
- 取得 skill：到 Jay's Resources 的 j9 - /animate Skill 取得，附 install prompt。
- 安裝後在 RUBRIC Editor 開啟 Teach my /animate，你對動畫 clip 的評論會教 /animate 你喜歡什麼。
- 延伸課程：R67「The /animate Skill」談 /animate 是什麼、作者怎麼用、如何建自己的版本。
- 延伸課程 n77「Opus 5.5 Motion Graphics in 3 Levels」談 AI 動態圖像三層次：one-shot、storyboard、逐鏡頭導演。
- 延伸課程 n78「Sonnet 5.5 is a BEAST for Video Editing」談用 transcript 剪輯、用 design system 做動畫，再把整個工作流存成自己的 /animate。
