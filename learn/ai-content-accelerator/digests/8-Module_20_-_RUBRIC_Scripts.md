# L1 overview

- Rubric 是 RoboNuggets 社群自製自維護的一整套客製化軟體與系統，每個工具都設計成 agent-ready、可與 AI agent 一起用。
- 為什麼需要作業系統：已經有 slash hooks 與自己的 tone of voice skill，但大量創意工作若只在 Claude 或 Codex 聊天視窗裡做，效率與檢視體驗不佳。
- 典型流程原本是：把點子丟給 Claude、呼叫 hook 與 tone skill、產出為 Instagram 或 TikTok 最佳化的腳本；Rubric Scripts 讓這個流程集中化。
- 若腳本只躺在聊天視窗，大部分會消失，之後也難整理與優化；Rubric Scripts 把內容集中一處，並形成回頭更新 skill 的遞迴迴圈。
- 安裝：從說明欄下載 Rubric Scripts、複製 install prompt，丟給 Claude、Codex 或任何 agent；它是瀏覽器端軟體，跑在 Google Chrome。
- 附帶 skill 指令 slash rubric scripts：把點子餵給 agent，依你的語氣與最適合的 hook 轉成腳本，給幾個版本，再載入 Rubric Scripts 檢視。
- 預設會尋找 hooks 與 tone 兩個 skill；若尚未建立會教你建立。UI 幾乎全部可改，可叫 agent 加功能、改 caption 長度、把 hook 從三個改成四個。
- 介面功能：搜尋、篩選、多種排序（自訂順序、最後編輯、最新加入、閱讀時間最短、字母）、卡片式／清單式檢視、淺色／深色模式。
- 打開腳本：左側是點子可切換，預設給三個 hook 可選、可編輯；可反白文字留評論，也可用 Aqua 或 Whisper Flow 等語音工具輸入，評論集中成滾動清單。
- 專屬介面同時顯示 caption 與 SEO 最佳實踐，以及影片整體說明；之後還會成為發佈前預覽（第四週主題）。
- 批次修改：按 copy comments for all scripts 複製所有評論，貼給 agent 一次修好；開啟 teach my slash tone 會把評論寫進 tone skill。
- 讀腳本的位置：Telegram（接上 Claude Code）、artifact 或網頁、作者自製 teleprompter（附 zip，含桌機與手機版）。
- 批次錄製：把多支 reels 腳本載進 teleprompter 成一份長文件，一次不間斷錄完；例：8 支 reels 約 14 分鐘，或週末一小時錄 15 支，之後交給自動剪輯切段。
