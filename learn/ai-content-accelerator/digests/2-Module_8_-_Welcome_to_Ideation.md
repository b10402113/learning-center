# L1 overview

- 第二週主題是**內容選題（ideation）**：為內容 brainstorm 點子時，正確做法是什麼。
- 核心問題：選題流程中**哪些環節可以自動化**，哪些環節其實**根本不必自己來**。
- 課程會提供數個 **skill** 與**自動化模板**，讓學習者本週就能動手實作。
- 本週具體要求：想出一篇內容貼文，而且不是空想，要**真的做出來、真的發出去**，在第二週結束前完成。
- 內容創作有兩個關鍵**槓桿**：**品質**與**數量**，後續所有判斷都繞著這兩個概念轉。
- 教學順序是先談**品質**，再談**數量**。

# L2 detail

- `#L1-L6` — 歡迎來到第二週，定義本週主題為內容選題，並提出核心問題：哪些環節可自動化、哪些不必自己做。
- `#L7-L14` — 本週目標：提供 skill 與自動化模板，要求學習者在週末前真的做出並發布一篇內容貼文。
- `#L15-L19` — 內容創作的兩個槓桿（品質與數量），說明兩者是最關鍵概念，並預告先談品質、再談數量。
