# L1 overview

- 第二週里程碑要求：**挑一個自己的點子，本週發佈到你選擇的平台**。
- 接著在社群發一篇貼文，內容需包含：**至少 3 個內容點子**、**每個點子如何對你的受眾有用**、**已發佈那篇的連結**。
- 貼文還要提到本週你察覺到的**內容身份（content identity）改變**。
- 提供一段可直接丟給 agent 的 prompt，協助一步步完成里程碑貼文。
- Prompt 第一步：先蒐集所有關於你的資訊（記憶、profile、**CLAUDE.md**、專案檔案、過去對話、先前貼文），用 **2–3 行**回報，之後全程運用，能答的問題就跳過，選擇題把最可能的答案放第一個。
- Prompt 第二步：訪談你，使用內建問題工具（如 Claude Code 的 **AskUserQuestion**）或聊天式多選；問已發佈貼文的內容／平台／連結／成效、上週投票贏家、受眾與其困難、點子來源（最新消息、outlier、自身經驗），以及內容身份是否改變。
- Prompt 第三步：給出下一批貼文的點子選項，每個附一行「為何對受眾有幫助」，來回調整到 **3 個**合適點子。
- Prompt 第四步：從四種貼文格式選一種並推薦最適合的：**A Check-in**、**B You voted, I listened**、**C I posted it**、**D Wildcard**。
- 語氣規則：像對同課程的同儕說話、已發佈連結放前幾行、不編造、配合你的語氣、少量合適 emoji、**不要粗體、破折號、炒作詞**、不要「here's the thing」「不是 X 而是 Y」、不要總結式結尾。
- 結尾要像諮詢一群同領域同儕，問一個真實決策（下一個做哪個點子、會加什麼、看過什麼有效），不要只問「thoughts?」；唯一 hashtag 是 **`#week2`**，放最後一行。
- 標題要平實說明發了什麼、談什麼，**80 字元以內**；不可用「Week 2」，也不可含糊（如「My update」「Some ideas」）。
- 里程碑貼文發在 Skool 社群的 **Builds** 分頁。
