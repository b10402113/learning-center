# L1 overview

- 核心提醒：把發文交給排程工具前，先確認帳號已經 **warmed up（暖機完成）**。
- 原因：一個只用軟體發文的新帳號，看起來不像真人在使用 App。
- 暖機做法：像真人一樣使用新帳號——登入、發文、觀看、按讚、在你所屬的利基留言互動。
- 時間建議：**全新帳號**先用手動發文一週，之後再接排程；**已養一段時間的帳號**則可現在就接。
- 官方（Blotato）建議：新帳號先正常使用**數週**再連接排程工具。
- 連接帳號後的安全做法：**先排一篇**，確認真的上線後再排其餘貼文。
- 頁面附資源：Blotato 的指南「how to post to TikTok with Claude」連結。
