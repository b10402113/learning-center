# L1 overview

- 全月收束：把鏡頭拉遠，回顧正在建立的 **content operating system（Content OS）**；目前已具備 **content identity（內容身分）**、自動挖掘內容點子的方法、把內容做出來的流程，本週補上發佈與「去哪裡發、什麼時候發」的原則。
- 課程附上一整套框架圖，可複製、印出、隨時參考，用來記住所有 skills 與框架。
- 關鍵觀察：**每個步驟都已被 agent 自動化**——從發想工具、用 **Rubric Scripts** 與 **Rubric Editor** 創作，到第四週用 **/post** 自動發文。
- 這件事只有現在這些 AI 工具才可能：過去需要一整個團隊（研究點子、寫腳本、剪輯、發文），現在**一個人加一隊 agents** 就能經營內容事業。
- 但**你仍然在迴圈裡**：選點子是你真的在挑、做內容是你決定腳本與剪什麼、也會看過剪輯；用好 agents 的價值在於能訓練它們更貼近你的品味。
- 作者目前的自動化比例：創作約 **80%–90% 自動化**（剪輯、動畫多由 agent 做），發文約 **95% 自動化**；大部分時間花在依個人偏好／品味（本質是 **trifecta**）判斷哪些點子適合 RoboNuggets 品牌。
- **自動化是一道光譜**：一端是每個步驟都親自檢查、agents 僅從旁協助；另一端是全部自己跑起來。
- 品味與決策仍必須套上去，內容才會是你獨有的，避免做出 **vibe coded** 的東西或一堆 **AI slop**。
- 守住原則與這套作業系統，就能把大部分粗活交給 agents；接下來前往本月最後的里程碑。
