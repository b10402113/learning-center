# L1 overview

- 第三週里程碑：在你選定的平台上發佈五份不同的內容。
- 跟前幾週一樣有 starter prompt，可丟給 Claude 或你的 agent，它會幫你把貼文生出來、帶你起步。
- 實際發文仍必須自己動手做。
- 唯一要求：試著讓每一次發佈都比上一次好一點點。
- 「好一點點」可以是換不同的 hook、換不同的腳本或語氣、或換一種突然想到的呈現方式。
- 這樣才能收到回饋、知道哪種有效，並更靠近北極星：找到真正能在你這個 niche 打動人的內容類型。
- 兩件事別忘：把這週的工具用起來；完成比完美重要（done beats perfect）。
- 剛起步時影片或貼文沒有每支破百萬觀看完全沒關係，只要發的東西對人有幫助就已足夠。
