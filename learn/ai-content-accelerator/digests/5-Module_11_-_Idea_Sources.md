# L1 overview

- 好點子也可能**來自你自己**：作者許多最佳點子都是臨時想到、沒靠 AI agent；依**內容三要素**要找出你**享受**且**獨特**的部分，因此很多好點子來自**經驗與專業**。
- 但既然當前最佳化目標是**量**，**Claude**、**Codex** 等 AI agent 可以幫忙**找**點子。
- 通用來源是找出你產業的**知識之井（well of knowledge）**：全世界關於該領域的最新資訊落在哪裡；做**教育型內容**要展現專業，方法之一是永遠跟上產業最新知識，例如別再講 **2023 年**的 OpenAI GPT 應用商店。
- 以 AI 為例，**X** 是極佳來源，因為純文字、發布容易；一天就能摸清偏好；可書籤有興趣的內容再讓 **Claude** 讀書籤提點子，並追蹤 **Anthropic**、**OpenAI**、**Claude 開發者帳號**與 **Claude Code 創辦人 Boris Cherney** 等即時公告。
- **GitHub** 是開發者界的 Google Drive；作者至少每兩週看 **starhistory.com** 的熱門清單（最多 star／討論的 repo），再丟給 Claude 判斷可行性。
- **官方文件**是被低估的來源：作者曾把「prompting Claude Opus 5.5」文件餵給 Claude，草擬影片的 **beats** 與 **bullets**，該片約 **40 萬**觀看，因切中時事而有效。
- 知識之井因產業而異：可能是論壇、醫生社群、數學圈等，並要確保摘要用的 skill 涵蓋這些來源。
- 可讓 agent **主動通知**：用 **Grokbot**、**Hermes**、**OpenClaw** 或 ChatGPT 設定持續通知流；作者用 Grokbot 追 Claude、GPT-6、OpenAI、Google，一天約 **2–3 次**通知。
- **TikTok、Instagram、YouTube** 屬**第二手**知識來源，因製作與上架有延遲；應盡量選**越即時**的源頭。
- 你的利基與作者不同：談 AI 會較辛苦（**紅海**），健身器材等領域的來源在別處，可用 Claude 研究。
- 最後資源是 **`/latest` skill**：掃描**過去七天**的社群、**Reddit**、網路等來源；可調整為 **14 天或 28 天**；設定約 **15 分鐘**。
