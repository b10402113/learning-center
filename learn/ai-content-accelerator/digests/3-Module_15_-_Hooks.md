# L1 overview

- Hook 的定義：觀眾在最前面幾秒決定要不要看完，因為他們付給你的是注意力；hook 的唯一工作是讓對的人知道他為什麼現在該在意。
- 重要性論證：一支 60 秒影片前 3 秒是 hook、後 57 秒是 body；內容表現一半靠 body，一半靠包裝（packaging），hook 屬於包裝且在「能否被送到對的人面前」上被過度加權。
- 核心學習法：觀察自己在看內容時，是哪個部分最先抓住注意力，那個東西本質上就是 hook。
- 短影音（TikTok、Instagram Reels、YouTube Shorts）hook 是前 3 秒，因為平台自動播放；長影音（YouTube）hook 是標題、縮圖與點進去後的前 15–30 秒。
- 建議先從 shorts 開始以拉高產量、穩定發佈；課程先給短影音 hook 模式，之後可轉用到長影音。
- 前輩資源：Callaway（YouTube 談內容）、Tadi Galloway（YouTube 策略顧問）、Alex（用內容替企業帶 leads）。
- 九個 hook 模式：Contrarian、Investigator、Teacher、Experimenter、Fortune Teller、Magician、Curiosity Gap、Versus、List。
- Contrarian：說出與觀眾被灌輸觀念相反的話；例 Nate「不要再對 Claude 下 prompt」，引用 Andrej Karpathy 的三層方法、第一層是 spec；The Fitness Chef「五個該淘汰的飲食趨勢」。
- Investigator：揭露大多數人漏掉的隱藏事物；例 Nick「Claude Fable 5.1 完整 system prompt 洩漏、超過 275,000 字元」；Bobby「絕對不在 Aldi 買絞肉，原因不是你想的那個」。
- Teacher：承諾解決觀眾已知的問題；例 Kevin「3 分鐘做出自己的 AI Jarvis」、Jeremy 硬舉教學；警告是必須真的兌現承諾，否則名聲受損。
- Experimenter：親自試一件事並回報結果；例用 Claude skill「Slash Bragg」把 side project 在幾秒內變成 22 秒 launch video。
- Fortune Teller：描繪觀眾看得見的未來並幫他準備；例 She 談「SaaS 已死」引用 Sequoia 報告、Humphrey「25 歲前投入 100,000 美元就能以百萬富翁退休」；可與 contrarian 混搭。
- Magician：用一個值得看的畫面停住手指；例 Riley 示範 OpenClaw 在 Mac Mini 上操作 Blender、Zack King 的視覺鉤子。
- Curiosity Gap：在已知事物上開缺口並刻意不補；例 Kevin「這件事別跟你老闆說」的 Claude for Excel、Mark「這是我知道最扯的事實」；是最萬用的教育型內容備案。
- Versus：把兩個東西並排逼觀眾選；例 Jeff 比較 ChatGPT、Gemini、Claude 的超能力、Max 讓五歲小孩選 1 美元 vs 5 美元義大利麵。
- List：承諾可數的回報（listicle）；例「三個 Claude Code plugin 讓 Claude 不再浪費 token」、Ali Abdaal「被動收入前希望有人告訴我的三件事」；shorts 清單一般不要超過 10 個。
- 加碼：hook 不一定要用說的，視覺 hook 也能建立品牌辨識；作者早期用手機拍螢幕、把橘子插在筷子上當指字棒，呼應 content trifecta，特別適合 faceless content。
- 模式會演化：看內容時 bookmark 喜歡的 hook，追蹤整理 hook 的帳號如 The Post Protocol，同一格式跨地區、跨 niche 都有效。
- 課程附 hooks skill，內含所有模式，之後用來產 script，再由自己的品味篩選。
