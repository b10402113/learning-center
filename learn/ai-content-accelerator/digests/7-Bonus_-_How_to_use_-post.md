# L1 overview

- **/post** 的用途：影片做好後，想讓它立刻出現在所有地方；會把一支影片或多則貼文排程到 **Instagram、TikTok、YouTube Shorts、Threads**，並回傳一份內容行事曆。
- 底層運作：agent 把影片送給 **Blotato**（已連接你帳號的排程工具），由 Blotato 執行發佈；Blotato 也能發到其他更多平台。
- 設定四步：從課程頁面下載 zip → 把 **install prompt** 貼進 agent → 需要 **Blotato 帳號**（沒有就註冊）→ 在 Blotato 連接社群帳號並複製 **API key**。
- 安全細節：請 agent 開一個**安全檔案**，由使用者**自己**貼入 API key。
- 發文前需人工核准兩件事：每個平台的 **caption 文字** 與它挑的 **封面（cover）**；說 **go** 之後才排進行事曆，**核准前什麼都不會出去**。
- 重要區別：**排程不等於已發佈**，要等連結打開、貼文真正上線才算。
- 連結回來後可做兩件事：請 agent 幫你排一整週（例如一天三篇），以及請 agent 依你改過的地方**優化 /post skill**，讓它學會你喜歡怎麼發。
- 新帳號注意事項：全新帳號（尤其 TikTok）先正常使用數週再接進來，這也是 **Blotato 官方建議**。
