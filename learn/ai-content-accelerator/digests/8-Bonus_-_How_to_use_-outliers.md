# L1 overview

- **`/outliers`** 的重點：outlier **不需要幾百萬觀看**。
- 例證：頻道平常 **4,000** 觀看，一支影片拿到 **33,000**，就是平常的 **8 倍**，代表該主題奏效。
- 底層是一道數學題：**每則貼文的觀看數 ÷ 該帳號平常的觀看數**，橫跨 **YouTube、TikTok、X 和其他平台**。
- 安裝三步：下載 zip、把安裝 prompt 貼進 Claude 或 agent、依它提供的連結完成設定；**只有第一次要設定**。
- 抓 YouTube 資料需開啟 **YouTube Data API**（**免費**）並建立一把 **key**；把 key 傳給 Claude，或請它開安全檔案自行貼入。
- 執行 **`/outliers`** 後會開成一個頁面，內含**縮圖**與**倍數**；把喜歡的加進購物車，特別是**你有感**且**這週就能講**的。
- 選好後丟回 Claude 做兩件事：寫成**可直接講的腳本**（TikTok／Instagram、用**自己的語氣**）；請 agent **調整 `/outliers` skill** 以更懂你的口味。
- 提醒：**量才是關鍵，先開始錄**，腳本不夠好後面的模組會處理。
- 小技巧：結果太少就**放寬主題**或**往更早看**（更長時間範圍）；主題要有創意且**盡量具體**。
- 具體化例子：不要只講 AI，可講**本地 AI**、**醫療裡的 AI**、**給系統工程師用的 AI**；也可以完全不是 AI，而是**嗜好、工作、生意**。
