# ROADMAP — ai-content-accelerator

## Goal

把內容從「知道重要」變成每天真的在跑的產線：定出一個說得清楚的 content identity，用自己寫的 skills 把「找點子 → 寫腳本 → 錄 → 剪 → 排程發佈」串起來，並在 TikTok／Instagram／YouTube Shorts 上真的發出至少 15 則內容。

## Learning path

照課程順序（concept-first）：先建立內容的心智模型與身分（Wk1），再學選題的品質、數量與來源（Wk2），接著把點子做成可發佈的內容（Wk3），最後學發佈與自動化（Wk4）。

這條路徑優化的是「判斷力」：每一個動作背後都先有一個原則，遇到平台改版或工具換掉時，你還能從原則推出做法。它適合願意先花一週換掉舊假設、再開始大量出貨的學習者。

## How to use

Read the nodes in order. Each node is a Markdown container whose `steps` array sets the teaching order. Run `/nodes <subject>/<node-id>` to confirm a node and write its steps.

## Nodes

### Tier 1 — 內容身分：先換掉你對內容的假設

1. **[歡迎來到內容加速器](nodes/welcome-to-accelerator.md)**
   - Goal: 說出這門課要建的 AI 內容產線與四週路線，並接受「一定要真的發出去」。
2. **[第一個原則：一千個真粉絲](nodes/thousand-true-fans.md)**
   - Goal: 用 1,000 × $100 的數學說明內容事業不必靠 10 萬追蹤。
3. **[下一個原則：interest media](nodes/interest-media.md)**
   - Goal: 用興趣媒體解釋零粉絲也能被配送，並判斷自己的內容是 A 型還是 B 型事業。
4. **[內容只有兩種：娛樂或教育](nodes/educate-over-entertain.md)**
   - Goal: 選教育型內容，並把題目縮到一個你已經有優勢的小池塘。
5. **[自私的內容 vs 無私的內容](nodes/selfless-content-and-trifecta.md)**
   - Goal: 用 Content Trifecta 寫下 content identity，並用 selfless 檢驗第一則內容。

### Tier 2 — 選題：品質、數量與來源

6. **[兩個槓桿：品質與數量](nodes/quality-and-volume.md)**
   - Goal: 用「品質被過度恐懼」與「量先於品質」定出每週出貨節奏，並用 content pyramid 迭代。
7. **[通用來源：知識之井](nodes/well-of-knowledge.md)**
   - Goal: 找到自己利基的知識之井，用 `/latest` 產出點子；需要時拆解它的選題管線。
8. **[第二種穩定選題來源：Outlier](nodes/outliers.md)**
   - Goal: 用相對倍數找 outlier，並用 `/outliers` 建自己的研究清單。
9. **[你自己的點子才算數](nodes/your-own-ideas.md)**
   - Goal: 在 research 之外保留自己的點子，並在本週真的發出第一篇。

### Tier 3 — 創作：把點子做成可發佈的內容

10. **[Hook 到底是什麼：前三秒決定他要不要留下來](nodes/hooks.md)**
    - Goal: 用九個 hook 模式為一支短片寫出前 3 秒，並選出最適合的包裝。
11. **[為什麼腳本最怕被認出「這是 AI 寫的」](nodes/scripts-in-your-voice.md)**
    - Goal: 用 tone of voice skill 寫出不像 AI 的腳本，並用 caption 讓內容被搜到。
12. **[最基本的原則：少承諾，多交付](nodes/trust-and-truth.md)**
    - Goal: 用 under-promise/over-deliver 檢查 hook 與標題，避免 clickbait 反噬信任。
13. **[什麼是「內容作業系統」](nodes/content-operating-system.md)**
    - Goal: 把點子集中到 RUBRIC Scripts，建立可批次修改、批次錄製的腳本工作流。
14. **[先講一件很多人卡住的事](nodes/camera-and-editing.md)**
    - Goal: 用現有設備錄清楚，並用 RUBRIC Editor 把剪輯與動畫交給 agent。
15. **[我的建議：開一個專門的帳號](nodes/account-and-warmup.md)**
    - Goal: 選定發文帳號、完成暖機，並在接排程前手動發幾篇。

### Tier 4 — 發佈：讓每一分力氣發揮到最大

16. **[先搞清楚：內容其實只有三大類](nodes/three-kinds-of-content.md)**
    - Goal: 用 shorts／longs／text 選出起點（TikTok 優先），並把同一支內容鋪到多個平台。
17. **[為什麼你需要排程工具](nodes/automated-scheduling.md)**
    - Goal: 用 Blotato + `/post` 把一週內容排到多個平台，並在發佈前核准 caption 與封面。
18. **[把鏡頭拉遠：你的 Content OS 全貌](nodes/your-content-os.md)**
    - Goal: 用 Content OS 全圖檢查每個環節，決定自己的自動化比例與品味介入點。
