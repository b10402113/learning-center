# 單次 LLM 呼叫 vs. Agentic Loop

<LearningGoal>
能用「最小可靠機制」的原則決定一個任務該用單次 LLM 呼叫還是 agentic loop，並說出各自的判別條件與過度工程的代價。
</LearningGoal>

## Lesson

用「最小可靠機制」決定執行模式：單次 LLM 呼叫適合小而自足、不需要外部結果、使用者能輕鬆檢查答案的任務；agentic loop 只在工作無法一次完成、每一圈的觀察會改變下一步時才值得啟動，否則只是多背延遲、成本與失敗模式。
