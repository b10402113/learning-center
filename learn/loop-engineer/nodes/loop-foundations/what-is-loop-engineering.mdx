# 什麼是 Loop Engineering？

<LearningGoal>
能用「受控執行器」的觀點說出 loop engineering 在設計什麼，並列出圍繞模型的六個控制層各自解決什麼問題。
</LearningGoal>

## Lesson

Loop engineering 設計的是讓系統「像 agent」的那個重複決策循環（plan → act → observe → improve）；agent 不是魔法，而是受控執行器，可靠度來自圍繞模型的六個控制層與行動前、行動後、低信心時的三道可靠性閘門。
