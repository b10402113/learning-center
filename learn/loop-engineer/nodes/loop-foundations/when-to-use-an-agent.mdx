# 什麼時候該用 Agent、什麼時候不該

<LearningGoal>
能用一個判別問句判斷問題適不適合 agent，說出四類適合的場景、四類該改用更簡單機制的場景，並描述企業內先窄後廣的安全導入順序。
</LearningGoal>

## Lesson

判斷 agent 適不適合，要問「這個問題需不需要在看到結果後再決定下一步」：路徑不明、需要外部工具、需要看中間結果、判斷會改變下一步時才成立；否則改用單次呼叫、決定性工作流、規則與人工複核或批次服務，且導入時從窄用例開始、量測真實行為、有證據才擴張。
