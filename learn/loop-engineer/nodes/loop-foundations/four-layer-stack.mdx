# Model、Harness、Tools 與 Execution Environment

<LearningGoal>
能分清 model、harness、tools、execution environment 四層各自的職責與契約，並說明為什麼可靠性來自邊界而不是模型的聰明。
</LearningGoal>

## Lesson

可靠的 agent 由 model（推理）、harness（loop 控制與 state）、tools（對外能力）、execution environment（隔離與資源）四層合作而成，每層都有「能做什麼、必須回傳什麼、失敗怎麼處理」的契約；可靠性來自把邊界畫清楚，而不是假設模型永遠選對。
