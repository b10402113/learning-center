# 判斷一次 Tool Call 能不能跑、能不能重試

<LearningGoal>
能用 read-only／side-effecting 的差別、schema 邊界與 idempotency 三個判準，決定一次 tool call 該執行、該拒絕、還是該安全重試，並說出結果未知時為什麼不能盲目重送。
</LearningGoal>

## Lesson

用「會不會改變外部狀態」「參數是否落在 schema 範圍」「失敗是暫時還是規則性」「上一次結果是否已知」四個問題，依序決定一次 tool call 該執行、拒絕還是安全重試；結果未知時永遠先用冪等鍵查狀態，不要盲目重送。
