# 實作 Python Tool Dispatcher：把請求驗證、路由、執行轉成 Observation

<LearningGoal>
能寫出 dispatch_tool()，確認請求結構、只路由到註冊表內的工 具、用關鍵字引數執行，並把成功與失敗都轉成固定的結構化 observation。
</LearningGoal>

## Lesson

寫出 dispatch_tool()：先驗證請求結構與引數型別，只從 TOOL_REGISTRY 取出已註冊的工具，用 tool(**arguments) 以關鍵字引數執行，並把所有成敗都收斂成 {ok, tool, result|error} 的固定 observation。
