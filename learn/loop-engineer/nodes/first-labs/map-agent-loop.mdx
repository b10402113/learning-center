# 端到端追蹤一個 Agent Loop：從 Goal 到四種終止狀態

<LearningGoal>
能組出一個有 state、tools、action selection、evaluation 與執行上限的 expense-claim agent loop，並用 trace 說明它為何停在 APPROVED、ESCALATED、FAILED 或 LIMIT_REACHED。
</LearningGoal>

## Lesson

用 AgentState、三個工具、select_action()、execute_action()、evaluate_observation() 與有界的 run_agent() 組出 expense-claim agent loop，並用 trace 證明它停在 APPROVED、ESCALATED、FAILED 或 LIMIT_REACHED 的正確理由。
