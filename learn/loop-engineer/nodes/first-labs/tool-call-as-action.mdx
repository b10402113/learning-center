# Tool Call 是 Loop 的 Action：模型出請求，Harness 才是執行邊界

<LearningGoal>
能用「模型出結構化請求、harness 才執行」的觀點說出 tool call 的可控邊界，並列出一個安全工具必須具備的四個部分與 governed execution pipeline 的四道關卡。
</LearningGoal>

## Lesson

模型只送出結構化的工具請求，真正決定能不能執行的是 harness；一個安全工具需要 schema、runtime boundary、input validation、observation contract 四個部分，而每一次呼叫都該走過 policy、schema 驗證、sandbox、audit log 四道治理關卡。
