把一句模糊需求翻譯成可驗收的 goal 契約（outcome / scope / inputs / constraints / success evidence），並寫出作為終止條件的 completion criteria。

## Lesson

Goal 是可執行契約（outcome / scope / inputs / constraints / success evidence），completion criteria 是坐在 observe 與 decision 之間的停止條件——先定義 done，再開始跑。
