# 建造者模式

## Learning goal

講清建造者「複雜對象分步構建、與表示分離」的意圖，用裝修套餐場景

## Steps

1. [[learn/design-pattern/nodes/builder/builder-concept|建造者模式的意圖與場景]] — 理解「將構建與表示分離」的意圖，用裝修套餐場景建立動機
2. [[learn/design-pattern/nodes/builder/builder-bad-smell|ifelse 實現的維護災難]] — 識別 ifelse 套餐選擇的代碼壞味道（after step 1）
3. [[learn/design-pattern/nodes/builder/builder-structure|建造者模式的三層結構]] — IMenu 接口 + 裝修包實現 + Builder 建造者（after step 2）
4. [[learn/design-pattern/nodes/builder/builder-summary|選用時機與權衡]] — 何時用、何時不用、優缺點（after step 3）

## Lesson

建造者模式解決的核心問題是：當一個對象的構建過程很複雜（多個部件、多種組合方式），如何把「怎麼組裝」和「組裝出什麼」分開。裝修套餐是天然的類比——同一套物料（吊頂、塗料、地板、地磚），按不同品牌檔位組合出豪華、田園、簡約三種套餐，每個套餐的構建材質和價格計算方式都不同。四步走完之後，你應該能用這個場景講清楚建造者模式的意圖、結構，以及「基本物料不變、組合頻繁變化」時的選型判斷。
