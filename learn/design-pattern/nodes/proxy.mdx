# 代理模式

## Learning goal

講清代理「不寫實現類也能調用、攔截增強」的意圖，用 MyBatis mapper 中間件場景

## Steps

1. [[learn/design-pattern/nodes/proxy/proxy-concept|什麼是代理模式？]] — 認識代理的意圖與三種典型場景
2. [[learn/design-pattern/nodes/proxy/proxy-jdk-dynamic|JDK 動態代理：無實現類也能調用]] — 理解 InvocationHandler + Proxy.newProxyInstance（after step 1）
3. [[learn/design-pattern/nodes/proxy/proxy-spring-middleware|Spring 中間件：代理對象進容器]] — 掌握 BeanDefinitionRegistryPostProcessor + FactoryBean 的註冊套路（after step 2）

## Lesson

代理模式的核心思想是「老大和小弟」——你找小弟辦事，小弟去對接老大的複雜服務。這個「小弟」就是代理（Proxy），它讓調用者用最簡單的方式接入原本需要大量代碼才能使用的服務。本節通過模擬 MyBatis 中間件的實現過程，從「只定義接口不寫實現類就能跑」的魔法入手，拆解 JDK 動態代理與 Spring bean 註冊兩個核心機制。
