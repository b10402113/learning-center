# 双维度组合 vs 部分-整体树：桥接与组合的结构问题

## Learning goal

识别"双维度笛卡尔积爆炸"和"层级递归的树结构"这两种嵌套 ifelse 的形态，说出桥接和组合各解决哪一种。

## Lesson

开发中一个高频出现的结构问题是：ifelse 嵌套到不可维护。但"嵌套"本身有两种完全不同的形态，搞混了就会选错模式。

**第一种：笛卡尔积爆炸。** 两个独立维度交叉——支付渠道（微信、支付宝）× 支付方式（密码、人脸、指纹）。维度 A 有 M 个值，维度 B 有 N 个值，组合就是 M×N 个分支。每新增一个维度值，分支数线性增长；每新增一个维度，分支数指数爆炸。ifelse 变成一个矩阵，改一个地方要在 N 个分支里找。这类问题的解法是**桥接模式**：把两个维度拆开，用"抽象持有实现引用"的组合方式连接，避免子类化的笛卡尔积。

**第二种：层级递归嵌套。** 条件判断本身形成树形结构——优惠券决策引擎按性别→年龄→消费金额多级过滤，每一级过滤是树的一个节点，节点可以有多个子条件。新增一级过滤，嵌套加深一层；新增一个并列条件，同级多一个分支。ifelse 越嵌越深，改一个条件要在整棵树里找。这类问题的解法是**组合模式**：用叶子节点和组合节点统一接口的递归树替代嵌套 ifelse。

两者的共同点是都用组合替代继承来降低复杂度，都属于结构型模式。核心区别：桥接拆的是两个独立维度的交叉（矩阵变组合），组合拆的是同一接口的层级嵌套（树替代 ifelse）。识别信号很简单——看到 channelType × modeType 这种双维度嵌套就想到桥接，看到条件判断形成 if-else 树就想到组合。
