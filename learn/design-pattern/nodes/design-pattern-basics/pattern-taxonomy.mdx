# 三大分類：23 個模式的全局地圖

<LearningGoal>
能用目錄建立創建型/結構型/行為型三分類與每個模式綁定的真實場景的地圖，說出模式解決什麼問題。
</LearningGoal>

## Lesson

23 個模式孤零零地背一定混，但掛著場景就忘不掉。書的目錄就是這張地圖：六大原則在前，之後按**創建型 / 結構型 / 行為型**排好，每種綁定一個真實業務場景。三分類一句話：**創建型管「生」**（對象怎麼來，5 個：工廠方法、抽象工廠、建造者、原型、單例），**結構型管「拼」**（類和對象怎麼組合，7 個：適配器、橋接、組合、裝飾器、外觀、享元、代理），**行為型管「配」**（對象之間怎麼協作，10+ 個：責任鏈、命令、迭代器、中介者、備忘錄、觀察者、狀態、策略、模板方法、訪問者）。

每個模式都綁一個你熟悉的場景當掛鉤：創建型——統一發獎服務（工廠方法）、Redis 雙集群升級（抽象工廠）、裝修套餐（建造者）、試卷混排（原型）、全局一份（單例）；結構型——多種 MQ 統一接入（適配器）、支付渠道×支付模式（橋接）、規則決策樹（組合）、SSO 疊加校驗（裝飾器）、白名單門面（外觀）、秒殺共享（享元）、MyBatis mapper 沒實現類也能調用（代理）；行為型——618 審批鏈（責任鏈）、點單→烹飪（命令）、組織樹遍歷（迭代器）、手寫 ORM SqlSession（中介者）、配置回滾（備忘錄）、搖號通知（觀察者）、審核流轉（狀態）、優惠券計算（策略）、爬蟲→海報骨架（模板方法）、校長/家長視角（訪問者）。

這張 GoF 地圖是「全局索引」，和 ROADMAP 的問題線（ifelse 怎麼拆、對象怎麼來、接口對不上怎麼辦）是兩張配合的地圖：講選型用問題線，報分類用 GoF 線。面試被問到任何一個模式，先報分類、再說場景、再講結構——地圖就是提詞器。
