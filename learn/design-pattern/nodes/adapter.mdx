# 適配器模式

## Learning goal

講清適配器「異構接口統一輸出」的意圖，用多 MQ 消息體場景

## Steps

1. [[learn/design-pattern/nodes/adapter/adapter-concept|適配器的直覺]] — 建立「不兼容接口統一輸出」的直覺與動機
2. [[learn/design-pattern/nodes/adapter/adapter-mq|MQ 消息體適配]] — 同值異名的多 MQ 消息如何通過字段映射 + 反射統一輸出 (after step 1)
3. [[learn/design-pattern/nodes/adapter/adapter-interface|接口適配]] — 同義不同出參的兩個查詢接口如何包裝成統一調用 (after step 1)
4. [[learn/design-pattern/nodes/adapter/adapter-tradeoffs|適用邊界與選型]] — 適配器何時用、何時不該用、與策略/橋接/外觀怎麼選 (after steps 2–3)

## Lesson

適配器模式解決的是「接口對不上」的問題——你的系統想統一調用，但外來的接口（不管是消息體還是 API 方法）各有各的命名、各有各的返回值。適配器在中間做一層翻譯，讓調用方只面對一個統一的口。本節走兩條線：MQ 消息體適配和接口適配，最後收束到適用邊界。
