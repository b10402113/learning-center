# 相似模式選型對比

## Learning goal

就面試常見的相似模式對照題（策略/狀態/命令/模板、代理/裝飾/適配、工廠/建造者、觀察者/中介者）講出適用邊界與選型理由。

## Steps

1. [[learn/design-pattern/nodes/pattern-selection/behavioral-quartet|策略/狀態/命令/模板——四種行為模式怎麼分]] — 說出四種行為模式的核心區別與各自適用場景
2. [[learn/design-pattern/nodes/pattern-selection/proxy-decorator-adapter|代理/裝飾器/適配器——三種結構模式怎麼分]] — 說出三種結構模式的核心區別與各自適用場景
3. [[learn/design-pattern/nodes/pattern-selection/factory-vs-builder|工廠/建造者——創建模式怎麼分]] — 說出三種創建模式的核心區別與各自適用場景（after step 1）
4. [[learn/design-pattern/nodes/pattern-selection/observer-vs-mediator|觀察者/中介者——協作解耦怎麼分]] — 說出觀察者與中介者的核心區別與各自適用場景（after step 1）
5. [[learn/design-pattern/nodes/pattern-selection/selection-cheatsheet|選型速查——一句話判斷該用哪個模式]] — 能用一句話速判常見相似模式對的選型方向（after steps 2–4）

## Lesson

面試問「策略和狀態有什麼區別」或「代理和裝飾器怎麼分」，考的不是背誦——是能不能用一句話說清「什麼時候用哪一個」。這個節點把前面學過的模式按相似度分組，逐組拆解邊界，最後給你一套速判口訣。它依賴前面所有模式節點的基礎，是衝刺階段的收網之作。
