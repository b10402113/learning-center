# 狀態模式

## Learning goal

講清狀態模式「狀態驅動行為」的意圖，用審核狀態流轉場景拆掉 ifelse

## Lesson

狀態模式解決的核心問題是：一個對象的行為會隨著內部狀態的改變而改變，但你不想用一堆 ifelse 去判斷「現在是什麼狀態、能做什麼」。通過把每個狀態封裝成獨立的類，讓狀態自己決定「我能不能執行這個操作」以及「執行完之後切換到哪個狀態」——對象的行為就由當前狀態來驅動，而不是由外部的分支判斷來驅動。

這組步驟從狀態模式的概念出發，先用營銷活動審核的真實場景建立直覺，再看一把梭 ifelse 的痛點，然後用狀態模式三件套重構，最後學會判斷何時值得引入。
