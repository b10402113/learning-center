# 單例模式

## Learning goal

講清 7 種單例寫法的線程安全與懶載入取捨，能說出何時不該用單例

## Steps

1. [[learn/design-pattern/nodes/singleton/what-is-singleton|什麼是單例模式？]] — 說清單例的本質與解決的問題
2. [[learn/design-pattern/nodes/singleton/seven-implementations|7 種單例實現逐一拆解]] — 逐一拆解每種寫法的線程安全與懶載入取捨（after step 1）
3. [[learn/design-pattern/nodes/singleton/singleton-boundaries|單例的適用邊界與決策清單]] — 歸納何時該用、何時不該用（after step 2）

## Lesson

單例模式是創建型模式中最直覺的一個：保證一個類只有一個實例，並提供一個全局訪問點。聽起來簡單，但「只有一個實例」在多線程環境下怎麼保證、「全局訪問點」怎麼設計，就引出了七種截然不同的寫法——從最樸素的靜態類，到 Effective Java 推薦的枚舉單例，每一種都在「懶不懶加載」「線不線程安全」兩個維度上做取捨。三步走完之後，你應該能對著面試官講清楚每種寫法的機制，也能說出什麼場景下不該用單例。
