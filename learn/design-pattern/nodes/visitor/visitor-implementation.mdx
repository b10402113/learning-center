# 校園場景完整實現：五類走通

<LearningGoal>
走通訪問者模式在校園場景中的完整實現：User 抽象類 + Student/Teacher 數據結構 + Visitor 接口 + Principal/Parent 訪問者 + DataView 數據看板，理解每一層的職責。
</LearningGoal>

## Lesson

校園場景有學生和老師兩種固定身份，家長關心排名和教學水平，校長關心班級分佈和升學率。完整實現分三層。

數據結構層：User 抽象類持有 name、identity、clazz 三個基礎屬性，聲明 `accept(Visitor visitor)` 抽象方法。Student 繼承 User，額外持有 ranking（隨機排名），accept 內執行 `visitor.visit(this)`。Teacher 同理，額外持有 entranceRatio（隨機升學率）。業務數據掛在數據結構類上，訪問邏輯留在訪問者裡。

訪問者層：Visitor 接口定義兩個同名重載 `visit(Student)` 和 `visit(Teacher)`。Principal（校長）實現時打印學生姓名+班級、老師姓名+班級+升學率；Parent（家長）實現時打印學生姓名+班級+排名、老師姓名+班級+級別。同一批數據，兩個訪問者輸出完全不同的字段組合。

調度層：DataView 構造器初始化 4 名學生（謝飛機、windy、大毛、Shing）和 4 名老師（BK、娜娜、dangdang、澤東）。`show(Visitor)` 遍歷 userList，對每個用戶調用 `user.accept(visitor)` 觸發雙分派。測試時 `dataView.show(new Parent())` 輸出家長視角（排名+級別），`dataView.show(new Principal())` 輸出校長視角（升學率）——同一份數據，雙分派生效。

五類的職責分工：User/Student/Teacher 管數據和 accept 入口；Visitor/Principal/Parent 管訪問邏輯；DataView 管初始化和遍歷調度。每一層只做一件事，加新視角只需要實現一個新的 Visitor 類，不動任何數據類。
