Lesson 3/4 · 訪問者模式

校園場景完整實現：五類走通

Node: visitor · Step 3/4 · 行為模式

學習目標

走通訪問者模式在校園場景中的完整實現：User 抽象類 + Student/Teacher 數據結構 + Visitor 接口 + Principal/Parent 訪問者 + DataView 數據看板，理解每一層的職責。

場景回顧：校園裡的兩種視角

學校裡有學生和老師兩種身份，信息是固定的：

  • 學生：姓名、班級、身份（重點班/普通班）
  • 老師：姓名、班級、身份（特級/普通/實習）

兩個角色想從中看到不同的東西：

  • 家長：學生的成績排名 + 老師的教學水平
  • 校長：班級的學生分佈 + 老師的升學率

接下來我們用五個類（加一個數據看板）把整個模式走通。

第一層：數據結構（User → Student / Teacher）

先定義數據結構的骨架。User 是抽象類，持有基礎屬性，並聲明一個讓訪問者進來的方法：

public abstract class User {
    protected String name;      // 姓名
    protected String identity;  // 身份
    protected String clazz;     // 班級

    public User(String name, String identity, String clazz) {
        this.name = name;
        this.identity = identity;
        this.clazz = clazz;
    }

    // 關鍵：讓訪問者進來的入口
    public abstract void accept(Visitor visitor);
}

學生和老師各自繼承 User，實現 accept，並提供自己的業務特性方法：

public class Student extends User {
    private int ranking; // 排名（隨機生成）

    public Student(String name, String identity, String clazz) {
        super(name, identity, clazz);
        this.ranking = new Random().nextInt(100);
    }

    @Override
    public void accept(Visitor visitor) {
        visitor.visit(this);  // ← 雙分派的起點
    }

    public int getRanking() { return ranking; }
}

public class Teacher extends User {
    private BigDecimal entranceRatio; // 升學率（隨機計算）

    public Teacher(String name, String identity, String clazz) {
        super(name, identity, clazz);
        this.entranceRatio = BigDecimal.valueOf(
            new Random().nextDouble() * 100
        ).setScale(2, RoundingMode.HALF_UP);
    }

    @Override
    public void accept(Visitor visitor) {
        visitor.visit(this);  // ← 雙分派的起點
    }

    public BigDecimal getEntranceRatio() { return entranceRatio; }
}

關鍵設計：業務數據（排名、升學率）掛在數據結構類上，訪問邏輯留在訪問者裡。數據類只負責「接受訪問者」。

第二層：訪問者（Visitor → Principal / Parent）

訪問者接口定義兩個同名方法，靠參數類型區分：

public interface Visitor {
    void visit(Student student);
    void visit(Teacher teacher);
}

兩個具體訪問者各自實現自己關心的字段組合：

public class Principal implements Visitor {
    @Override
    public void visit(Student student) {
        System.out.println("校長視角 - 學生姓名：" + student.name
            + "，班級：" + student.clazz);
    }

    @Override
    public void visit(Teacher teacher) {
        System.out.println("校長視角 - 老師姓名：" + teacher.name
            + "，班級：" + teacher.clazz
            + "，升學率：" + teacher.getEntranceRatio());
    }
}

public class Parent implements Visitor {
    @Override
    public void visit(Student student) {
        System.out.println("家長視角 - 學生姓名：" + student.name
            + "，班級：" + student.clazz
            + "，排名：" + student.getRanking());
    }

    @Override
    public void visit(Teacher teacher) {
        System.out.println("家長視角 - 老師姓名：" + teacher.name
            + "，班級：" + teacher.clazz
            + "，級別：" + teacher.identity);
    }
}

校長關注升學率，家長關注排名——同一批數據，不同訪問者輸出完全不同。

第三層：數據看板（DataView）

DataView 負責初始化數據並提供展示方法：

public class DataView {
    private List<User> userList = new ArrayList<>();

    public DataView() {
        // 學生
        userList.add(new Student("謝飛機", "重點班", "C1班"));
        userList.add(new Student("windy", "普通班", "C2班"));
        userList.add(new Student("大毛", "重點班", "C1班"));
        userList.add(new Student("Shing", "普通班", "C2班"));
        // 老師
        userList.add(new Teacher("BK", "特級教師", "C1班"));
        userList.add(new Teacher("娜娜", "特級教師", "C1班"));
        userList.add(new Teacher("dangdang", "普通教師", "C2班"));
        userList.add(new Teacher("澤東", "實習教師", "C2班"));
    }

    // 核心：傳入不同訪問者，輸出不同視角
    public void show(Visitor visitor) {
        for (User user : userList) {
            user.accept(visitor);  // 雙分派觸發點
        }
    }
}

DataView 是「數據結構不動、接入不同訪問者即換輸出」的調度層——最直觀理解解耦的入口。

測試：同一份數據，兩種輸出

public class ApiTest {
    @Test
    public void test() {
        DataView dataView = new DataView();
        System.out.println("\n--- 家長視角 ---");
        dataView.show(new Parent());
        System.out.println("\n--- 校長視角 ---");
        dataView.show(new Principal());
    }
}

家長視角：看到學生排名（如 62、51、16、98）和老師級別（特級/普通/實習）。

校長視角：看到老師升學率（如 70.62、23.15、70.98、90.14）。

同一份數據，雙分派生效——這就是訪問者模式的完整運作。

五類的職責一覽

類體系職責
User數據結構抽象類，持有基礎屬性 + accept(Visitor)
Student / Teacher數據結構實現 accept，提供業務特性方法（排名/升學率）
Visitor訪問者接口，定義 visit(Student) 和 visit(Teacher)
Principal / Parent訪問者實現各自視角的訪問邏輯
DataView調度層初始化數據 + show(Visitor) 遍歷觸發雙分派

自我檢測

Q1. 在訪問者模式中，accept 方法定義在哪裡？

  • 訪問者接口裡
  • 數據結構的抽象類裡
  • 數據看板裡
  • 具體訪問者裡

Q2. Student 類的 accept 方法內部做了什麼？

  • 直接打印學生信息
  • 調用 super.accept()
  • 調用 visitor.visit(this)
  • 返回學生的排名

Q3. DataView 的 show(Visitor) 方法的作用是？

  • 遍歷用戶列表，對每個用戶調用 accept(visitor) 觸發雙分派
  • 直接打印所有用戶信息
  • 過濾出特定角色的用戶
  • 創建新的訪問者實例

Q4. 家長和校長在同一個 Student 上看到的字段有什麼不同？

  • 完全相同
  • 家長看到升學率，校長看到排名
  • 家長看到姓名，校長看不到
  • 家長看到排名，校長看到班級信息

Q5. 數據結構類（Student/Teacher）的職責是什麼？

  • 實現所有視角的訪問邏輯
  • 持有數據 + 提供 accept 入口，不承擔業務邏輯
  • 初始化所有用戶數據
  • 決定打印哪些字段
