# 快取昂貴的探索

## Learning goal

在 loop 前用 HITL research 把外部文件/決策快取成 research.md，省 token、保 smart zone。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/research-cache/explore-phase-cost|為什麼探索很貴：重複的 explore phase 吃掉 token]] — 認出會讓每次 context window 探索成本爆表的兩種工作，理解「先快取再跑 loop」的原理
2. [[learn/ai-coding-for-real-engineer/nodes/research-cache/hitl-research-prompt|跑一輪 HITL research：從 prompt 到 research.md]] — 用「多方案＋迭代＋網路驗證＋指定輸出位置」的 prompt 把探索快取下來（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/research-cache/reading-and-steering-research|讀 research 結果、用 taste 定案]] — 讀懂 research 文件結構，用自己的判斷拍板並核對宣稱（after step 2）
4. [[learn/ai-coding-for-real-engineer/nodes/research-cache/research-lifecycle|research.md 的生命週期：防腐與刪除]] — 存 repo、被 PRD/issues 引用、做完就刪，避免 doc rot（after step 3）

## Lesson

AFK loop 每跑一圈都從空白 context 開始，凡是「外部服務沒有本地文件、或者 codebase 裡很刁鑽」的探索，每一圈都要重付一次代價。這個 node 教的不是省掉探索，而是把探索提前、快取起來：進 loop 之前先做一輪人機合作（HITL）的 research，把外部文件、選型與決策濃縮成一份 local 的 research.md，之後每一圈 agent 都在幾秒內讀完它，把省下來的 token 留給實作，人停在 smart zone。node 走完你手上就有這份資產的完整生命週期：為什麼值得快取、怎麼跑 research、怎麼定案，以及做完為什麼要狠心刪掉。
