# 計畫搬進 backlog：PRD 與 plan 都變成 issue

<LearningGoal>
說明為什麼要把 PRD 與 plan 從本機檔案搬進任務佇列，並講出這個做法如何讓規劃與實作平行進行。
</LearningGoal>

## Lesson

把 PRD 與 plan 從本機檔案搬成 GitHub issue，讓 AFK agent 看得到規劃、工作區保持乾淨，並使規劃與實作可以平行進行。
