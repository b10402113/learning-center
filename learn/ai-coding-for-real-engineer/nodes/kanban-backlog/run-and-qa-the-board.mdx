# 跑 AFK 迴圈與人工 QA

<LearningGoal>
檢查 PRD-to-issues 產出的第一張 issue 是不是合格的 tracer bullet、合併過薄的切片、放行 agent 建立 issue，跑完 AFK 迴圈後照 QA checklist 人工驗收並把回饋變成新 issue。
</LearningGoal>

## Lesson

放行前先檢查第一張票是不是 tracer bullet、合併過薄的切片，允許 gh issue create 後跑 AFK 迴圈，最後人工照 QA 清單驗收並把品味回饋變成新 issue。
