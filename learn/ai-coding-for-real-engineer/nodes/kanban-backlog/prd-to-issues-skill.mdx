# 跑 PRD-to-issues：把 PRD 切成垂直切片

<LearningGoal>
照著步驟跑 PRD-to-issues，產出一組帶 blocked-by 依賴、標好 HITL/AFK、並以 QA checklist issue 收尾的垂直切片。

## Lesson
