# 用 Kanban 取代多階段計畫

<LearningGoal>
解釋為什麼把 PRD 拆成一張有依賴關係的 issue 圖，比一份多階段計畫更好擴充、更好 QA，也更接近真人的協作方式。
</LearningGoal>

## Lesson

用一張有依賴關係的 issue 圖取代線性的多階段計畫，讓工作更好擴充、更好並行、更好驗收，而 PRD 仍負責定義目的地。
