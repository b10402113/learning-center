# 哪些留給人、哪些放手：HITL 與 AFK 的界線

<LearningGoal>
用「哪裡需要品味」這把尺，判斷一件工作該留在 HITL 還是可以 AFK，並說出規劃與 QA 為什麼非人不可。
</LearningGoal>

## Lesson

用「哪裡需要品味」判斷工作該留給人還是放手：有明確規格、可靠測試驗證的走 AFK，需要人的判斷與感覺的（規劃、QA、架構取捨）留在 HITL。
