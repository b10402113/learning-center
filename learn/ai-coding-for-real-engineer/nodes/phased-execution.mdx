# 逐階段執行不翻車

## Learning goal

用「do phase N + PRD + 整個 plan」逐階段放手實作，每階段 clear context、commit，保持 smart zone。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/phased-execution/phase-prompt-pattern|「do phase N + PRD + 整個 plan」：把實作交給全新 session]] — 用全新 session 承接 PRD + plan，一句「do phase one」開場
2. [[learn/ai-coding-for-real-engineer/nodes/phased-execution/phase-loop|一個 phase 的內迴圈：探索、最小實作、測試、QA、commit]] — 每個 phase 內部跑一圈：探索 → 最小實作 → 測試 → QA → commit（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/phased-execution/context-reset|每階段清 context，守住 smart zone]] — 每階段 clear context 再開下一圈，接近 dumb zone 就 clear + commit（after step 2）
4. [[learn/ai-coding-for-real-engineer/nodes/phased-execution/commit-as-signal|每階段 commit：安全點與跨 session 的持久訊號]] — commit 是回退點，詳細 commit message 是未來 session 的 context（after step 3）

## Lesson

目的地和路線都畫好了，剩下的就是放手讓 agent 跑。這個 node 教你把「PRD（目的地）+ 垂直切片 plan（路線圖）」變成一段段可以放心交付的實作：不開 plan mode，一句「do phase N」把整個 context 交給全新 session，然後每跑完一圈就清一次 context、commit 一次。這樣每一圈都活在 smart zone 裡，翻車了也有安全點可以回去。
