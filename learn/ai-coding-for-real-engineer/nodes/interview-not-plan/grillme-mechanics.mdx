# GrillMe 的運作原理：一次一題、先探索、給推薦

## Learning goal

能說出 GrillMe 這份 skill 檔案的設計原則（一次一題、可探索的就不問、每個問題附推薦答案），並解釋每一條如何把模糊需求釘成 shared design concept。

## Lesson

GrillMe 就只是一份單一 markdown 檔，內容是給 agent 的指令——Agent Skills 格式讓它平常只露出名稱＋描述，但本質仍是指令文件。它的五條設計原則，每一條都直接執行 shared design concept：①訪談直到共享理解成立，不設題數上限；②一次只問一題，逼你逐個做決定，防止重要決策被「都行都行」略過；③可探索的就不問——讀 codebase 就查得到的事 agent 自己 explore，skill 裡有「Explore」這個字，它真的會連動 Explore sub-agent 去深度探索；④沿設計樹逐條分支、逐一解決依賴；⑤每個問題附推薦答案，把使用者從「憑空設計」變成「判斷」——判斷比設計省力，所以每個決策你都願意認真做完。

lesson 24 的練習設定是開全新 session、用 default mode（不進 plan mode、不開 auto-accept edits），把模糊需求丟給 GrillMe 當沙盒跑，邊跑邊記改進想法。重點是它的設計原則完全可複用：任何「把訪談當技能」的寫法都長這樣，你不一定要用 GrillMe 這份檔案。
