# 選好你的 agent 與訂閱

<LearningGoal>
用 tiering 原則幫自己的訂閱選出課程要用的 model：用訂閱的預設模型、選 medium effort、避開 Haiku，並理解頂/中/入門三級在各 provider 都成立。
</LearningGoal>

## Lesson

選 model 的核心不是記名字，而是記 **tiering 原則**：模型名稱會一直換（課程錄完後教練就發過補充），但每個 provider 都有三級——Opus 級（頂）、中階級、很便宜的 Haiku 級（入門）——分層永遠成立。所以做法是：**用你訂閱方案的預設模型**，在 Claude Code 用 `/model` 確認即可——Max 5x 的預設是 Opus 級，Pro 的預設是 Sonnet 級。不要手動去換名字，預設就是你的方案能給的最好平衡。課程三令五申**避開 Haiku**：它快但不夠力，扛不住課程要丟給它的一些工作流；effort 選 **medium**，跟著 harness 的預設走（教練觀察到 harness 把 Opus 的預設從 high 調回 medium，因為內部評估發現 medium 對大部分工作就夠了）。

訂閱上教練給兩個錨點：課程是**用 Max 5x 打造**的，想要 Opus 級最佳模型，建議至少買一個月 Max 5x；預算有限的話 **Pro + Sonnet 也能走完課程**——不能保證深度挖每一課都不撞 usage limit，但「Pro 應該過得去」。最後，整套流程是 **harness-agnostic** 的：課程 demo 用 Claude Code 只是因為它流行，任何跑在 CLI 裡的 coding agent 都能套用同一套七階段流程；沒用過 coding agent 的初學者先從 Claude Code 開始。決策清單：看你的訂閱 → 用它的預設 → 確認 effort 是 medium。
