# 七階段流程總覽

<LearningGoal>
按順序說出七階段流程——grill（訪談）→ research → prototype → PRD/plan → issues → implement → review——並說出每個階段各自產出什麼。
</LearningGoal>

## Lesson

這門課的立場是不賣框架：市面上有一堆包裝 AI coding agent 的大型框架（GSD、spec kits 等），但教練主張你應該**擁有自己的流程**，把它建立在三十年的工程直覺與實務經驗上。七階段流水線就是這套流程：grill（訪談）→ research → prototype → PRD/plan → issues → implement → review。每一站都在把「模糊」往「可執行」推一格——grill 一題一題把模糊需求問清楚，產出需求輪廓；research 補齊未知，產出研究筆記；prototype 用小代碼沖掉設計上的未知數，產出可丟的實驗；PRD/plan 把方向寫成兩份文件；issues 把文件切成可執行的任務清單；implement 整段放手讓 agent 跑，產出能跑、有測試、已 commit 的代碼；review 在最後守住品質。

整套系統最關鍵的支柱是讓 implement **徹底 away from keyboard（AFK）**——人不在鍵盤前，agent 自己跑完，人用同一段時間做別的事，這就是「plan while the AI ships」（趁 AI 交貨時規劃下一批工作）。正因為前面五個階段已把該決定的都決定好了，implement 才不需要人逐行指揮。課程用一個約 20,000 行的 TypeScript/React playground 做 interactive exercises，你也可以把練習套在自己的 repo 上（跟練課程 repo 支援較多）。最後記住一個正循環：**agent 在好的 codebase 裡才會表現好**，而這條流程本身就在把你推向更健康的 codebase。
