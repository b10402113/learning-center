# 什麼時候該 prototype、什麼時候不用

<LearningGoal>
用「這件事有沒有先例、未知多不多」判斷該不該先做 prototype，並說出 bug 修復與既有功能擴充為什麼通常不必。
</LearningGoal>

## Lesson

依「有沒有先例、未知多不多、猜錯代價大不大」判斷：有明確行為的 bug 與純組裝的既有功能擴充不必原型，無先例、要挑方向、要接新服務、要動系統結構的才值得。
