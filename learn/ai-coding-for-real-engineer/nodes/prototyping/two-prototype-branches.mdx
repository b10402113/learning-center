# prototype 的兩條分支：邏輯與 UI

<LearningGoal>
認得 prototype skill 的兩條分支——用終端機小程式推演資料模型邏輯的 logic branch，與同路由多變體切換的 UI branch——並知道各自查什麼、何時用。
</LearningGoal>

## Lesson

prototype skill 提供 logic branch（用終端機按鍵推演隨時間變化的資料模型，最常用）與 UI branch（同路由多個差異大的版本，用 URL 參數切換）兩條分支，產出用完即丟。
