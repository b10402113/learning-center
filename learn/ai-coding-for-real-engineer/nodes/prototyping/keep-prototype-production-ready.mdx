# prototype 也要能直接上線：TDD、可重用元件與實測

<LearningGoal>
在 prototype 裡維持 TDD 與程式碼標準、把零件寫成可 export 的元件，並實際接上服務跑一次（API key 放 .env、開兩個分頁驗證即時反應），讓 unknown unknowns 在 AFK 之前全部落地。
</LearningGoal>

## Lesson

原型也要走 TDD 與程式碼標準、把零件寫成可 export 的元件，接上服務後把 API key 放進 .env，並開兩個分頁實測即時反應，才算把 unknown unknowns 清空。
