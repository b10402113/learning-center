# 為什麼要先做 prototype：把規劃變成可以玩的東西

<LearningGoal>
說出 prototype 為什麼是 HITL 技巧、它補上文字規劃的哪個缺口，以及 unknown unknowns 是什麼、為什麼要在 AFK 之前先沖掉。
</LearningGoal>

## Lesson

文字規劃會漏掉 unknown unknowns；prototype 是一個粗糙、之後丟掉的可玩版本，用來在 AFK 實作前把未知逼出來、先把 taste 灌進去。
