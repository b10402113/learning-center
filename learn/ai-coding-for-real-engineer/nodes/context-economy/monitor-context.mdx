# 把 context 用量放在眼前

<LearningGoal>
安裝 status-line，讓 context 用量（token 數）隨時可見，並用「80k–100k token 的 smart zone」取代「40% 就該緊張」的舊規則。
</LearningGoal>

## Lesson

Claude Code 預設 UI 把 context 用量藏起來了——想看數字得退出 plan mode、跳出工作流程、自己敲 `/context`。講師的解法是裝一套社群 status-line：把安裝文章貼進 Claude Code，它會改你的**全域**設定（`~/.claude` 的 settings JSON，不是專案設定），存檔後重開 session，token 用量就常駐在 prompt 下方，隨時可見。這是四招的第一招，也是前提：看不見就管不住。

裝好之後要換一把新的尺。Anthropic 公布了 Opus 4.6 / Sonnet 4.6 的 1M token window，百分比就不再可靠——200k 的 40% 是 80k，1M 的 40% 是 400k，同一個百分比代表完全不同的狀態。所以 status-line 改顯示 **raw token 數**為主、暗淡的百分比為輔，而新的 smart zone 緊張線是 **80k–100k tokens**。講師錄影時用 200k limit，他說 40% 正是 80k——心算時記得影片百分比 × 200k 才是 raw token 數。
