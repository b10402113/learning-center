# 七階段流程是什麼、為什麼有效

## Learning goal

說出七階段流程（grill→research→prototype→PRD/plan→issues→implement→review）各階段做什麼、為何這樣排，並選好自己用的 model/subscription。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/process-overview/seven-phase-pipeline|七階段流程總覽]] — 按順序說出七階段，並說出每個階段產出什麼
2. [[learn/ai-coding-for-real-engineer/nodes/process-overview/why-this-order|為什麼這樣排]] — 解釋前面的階段如何把模糊需求釘成可執行的規格，讓實作階段能整段放手（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/process-overview/choose-your-agent|選好你的 agent 與訂閱]] — 用 tiering 原則幫自己的訂閱選出課程要用的 model（after step 1）

## Lesson

這門課把「讓 AI coding agent 放手寫程式」拆成一條七階段流水線：grill（訪談）把模糊需求一題一題釘清楚，research 把未知補齊，prototype 沖出設計上的未知數，PRD/plan 把方向寫成兩份文件，issues 把工作切成可執行的任務，implement 整段放手讓 agent 跑（可以全程 AFK，人走開去規劃下一批工作），最後 review 守住品質。前面越用力，後面越能放手——順序本身就是在降低風險。看懂這條流水線後，你得先決定自己要用哪個 model 跑完課程，再開始動手。
