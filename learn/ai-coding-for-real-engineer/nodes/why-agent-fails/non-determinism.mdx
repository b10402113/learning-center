# 非決定性：同一個 prompt 每次不同

<LearningGoal>
說出 agent 是從機率分布抽樣選下一個 token 的非決定性機器，因此同樣的指令每次可能給出不同結果，並據此調整期待。
</LearningGoal>

## Lesson

前兩課的約束都跟「記住什麼」有關，這一課換一個軸：即使完全不管記憶，agent 本身也不是確定的機器。LLM 產生文字是逐 token 生成——每個時間點算出整個詞表裡每個 token 的機率分布，再從這個分布抽樣選出下一個 token。抽樣帶隨機性：機率 30% 的 token，十次裡約被抽中三次。所以 agent 不是「算答案」，是「抽答案」，同樣指令跑兩次可以走完全不同軌跡、給出不同結果。

課程第一次開跑時，約 2,500 位學生跑完全相同的練習，有人 agent 行為與教練示範天差地遠——一次到位、繞大圈、不同實作取捨都有。這不是操作錯誤，是非決定性內建在每個 agent，規模越大越明顯。照著課程做卻複製不出示範時先別慌：差很多是常態，重點是結果有沒有對。

非決定性不代表無序。AFK 階段的 feedback loop 正是把它拉向一致的手段：讓 agent 跑測試、過 typecheck，對的留下、錯的再修——驗證結果而非逐字輸出，不同軌跡會收斂到同一個正確終點。所以把期待改成「結果正確」，不要期待「每次一樣」：agent 第一次給的答案不是唯一答案也不是標準答案，結果不如預期時先驗證，不要直接質疑它壞了。
