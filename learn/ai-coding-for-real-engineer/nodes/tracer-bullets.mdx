# 垂直切片的力量

## Learning goal

用 PRD-to-plan skill 產出引用 user story、只含 durable decisions 的垂直切片計畫。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/tracer-bullets/tracer-bullet-concept|「曳光彈」tracer bullets：把水平計畫翻成垂直切片]] — 懂 tracer bullets 的運作機制，以及它為何能翻轉 agent 的水平切法
2. [[learn/ai-coding-for-real-engineer/nodes/tracer-bullets/prd-to-plan-skill|用 PRD-to-plan skill 公平地重跑計畫]] — 乾淨 session 呼叫 skill、刪掉舊 plan，與 naive plan 比較（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/tracer-bullets/skill-workflow-propose-ask|skill 的流程：先探索、再提議、問過才寫]] — 看懂三段流程，以及它比直接生 plan 可靠的原因（after step 2）
4. [[learn/ai-coding-for-real-engineer/nodes/tracer-bullets/durable-decisions-only|只規劃 durable decisions、引用 user story]] — 分辨 durable decisions 與會過期的細節，看懂垂直切片計畫的輸出（after step 3）

## Lesson

這個 node 把上一節「為什麼需要另一種切法」的診斷變成藥方：垂直切片不是抽象理想，而是靠兩樣東西落地——一句話（tracer bullets）和一隻 skill（PRD to plan）。四步走完，你會擁有「怎麼把 PRD 切成可執行的垂直切片計畫」的完整掌控：先懂 tracer bullets 為什麼能翻轉 agent 的預設水平切法，每個 phase 貫穿所有 layer、早回饋、可驗證（step 1）；再學會在公平的實驗條件下呼叫 PRD-to-plan skill——乾淨 session、先刪舊 plan、再比較輸出（step 2）；接著看懂 skill 內部的三段流程：先探索、再提議、問過才寫（step 3）；最後認出計畫裡該留下的只有 durable decisions，以及它為什麼必須引用 PRD 的 user stories（step 4）。等這份計畫到手，下一節 phased-execution 就接手把它一階段一階段跑完。
