# 開車基本功：終端、slash commands、中斷與恢復

<LearningGoal>
在 VS Code 整合終端啟動 Claude Code，用 /usage、/context、/clear 掌控 session 與 context window，並用 escape 中斷執行、輸入 go 恢復。
</LearningGoal>

## Lesson

開車的地點是 VS Code 整合終端。打開 VS Code，開一個新的 terminal panel，輸入 `claude` 就啟動了。但不是任何終端都適合——VS Code 整合終端讓你在同一個介面裡跑 agent、看 diff、讀檔案，不用切來切去。之後 review diff 時你會感謝這個選擇。

啟動後的第一件事：跑 `/terminal-setup`。這個指令幫你裝好鍵盤綁定，其中最重要的是 **shift+enter 在輸入框換行**。沒有這個綁定，你寫多行 prompt 時按 enter 就會直接送出，整個 prompt 斷在半路。裝好之後，shift+enter 換行、enter 送出，就像在任何聊天軟體裡一樣自然。

掌控 session 靠三個 slash command，全部指向同一個主題：**context 意識**。context window（上下文窗口）是 LLM 的工作記憶——你每次輸入的東西、agent 讀過的檔案、跑過的指令，全部塞在這個窗口裡。窗口有大小上限（例如 200k tokens），裝太滿 agent 就會變笨（之後的課會深入講 smart zone / dumb zone）。三個命令分別是：

`/usage` 顯示 plan 的用量上限，包含 session 和本週的額度。這讓你知道自己有沒有足夠的額度跑完一個大任務，避免跑到一半被斷。`/context` 視覺化 context window 目前裝了多少 token——例如 200k 中已用 21k。這是最直接的 context 意識工具，你不需要每五分鐘跑一次，但每次開始新任務前、或感覺 agent 開始「怪怪的」時，跑一下看看。`/clear` 把 context window 歸零，等於開新聊天。所有累積的「部落知識」——之前讀過的檔案、跑過的指令、討論過的決策——全部清掉，從乾淨狀態重新開始。

執行中你想插手就按 **escape** 中斷 Claude——它會停下來等你。這時候你可以打新的 prompt 改方向，或者輸入 **go** 讓它從中斷點繼續。這是暫停不是結束。很多人不知道 escape + go 這個組合，看到 agent 走偏只能乾瞪眼，等它跑完整個錯誤的結果才重新來。會 escape 就等於拿到方向盤——你隨時可以踩煞車，決定要轉彎還是繼續直走。

開新 session 的慣例是先 `/clear` 從乾淨狀態開始，跑久一點就 `/context` 看一眼。把這兩個動作養成習慣，你就不會讓 agent 在「裝太滿」的狀態下亂跑。context window 像是一個背包：`/context` 就是拉開拉鍊看裡面裝了什麼、還剩多少空間；`/clear` 就是把背包倒空、重新開始裝。你不會背著一個塞滿的背包去爬山——agent 也不會在 context 裝太滿時表現好。context 意識是整門課反覆回來的主題，現在把它養成習慣。
