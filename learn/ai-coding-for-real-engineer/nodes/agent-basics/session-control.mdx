# 開車基本功：終端、slash commands、中斷與恢復

<LearningGoal>
在 VS Code 整合終端啟動 Claude Code，用 /usage、/context、/clear 掌控 session 與 context window，並用 escape 中斷執行、輸入 go 恢復。
</LearningGoal>

## Lesson

開車的地點是 VS Code 整合終端。啟動後先跑 `/terminal-setup` 裝好鍵盤綁定，其中最重要的綁定是 shift+enter 在輸入框換行——讓你能寫多行 prompt 而不是打到一半就送出去。掌控 session 靠三個 slash command，全部指向同一個主題：context 意識。`/usage` 看 plan 的用量上限（session 與週）、`/context` 視覺化 context window 目前裝了多少 token（例如 200k 中已用 21k）、`/clear` 把 context window 歸零，等於開新聊天。

執行中你想插手就按 escape 中斷 Claude，輸入 go 讓它繼續——這是暫停不是結束。很多人不知道這個組合，看到 agent 走偏只能乾瞪眼；會 escape 就等於拿到方向盤。開新 session 的慣例是先 `/clear` 從乾淨狀態開始，跑久一點就 `/context` 看一眼——把這兩個動作養成習慣，你就不會讓 agent 在「裝太滿」的狀態下亂跑，而這正是整門課反覆回來的主題。
