# 暫存 prompt 與貼圖

<LearningGoal>
用 Ctrl-S 暫存目前寫到一半的 prompt、Ctrl-C 丟棄它，並把圖片直接貼進 prompt（WSL 不支援），讓 prompt 可以中途抽離再恢復。
</LearningGoal>

## Lesson

開車基本功的最後兩個工具，讓 prompt 可以中途抽離再恢復。寫到一半想先做別的事，用 <strong>Ctrl-S 暫存</strong>目前的 prompt，做完事再把它叫回來；寫歪了用 <strong>Ctrl-C 丟棄</strong>。這不是手動複製貼上，而是 Claude Code 內建的機制——把「打 prompt」從一次性動作變成可暫停、可反悔的流程。

除此之外，你還能直接把<strong>圖片貼進 prompt</strong>：UI 長歪、報錯畫面、設計稿，一張圖勝過描述半天，是給 agent 視覺資訊最直接的方式。唯一例外是 WSL 不支援貼圖，原生 Windows 或 macOS 都可以。回頭看這個 node 的整套動作——`/clear`、`@` 參照、Ctrl-S/Ctrl-C、貼圖——其實都是在管理「你要給 agent 的輸入」：清掉舊的、指到對的、暫存沒打完的、貼上說不清的。把它們練熟，之後學大流程就不必分心想怎麼打字。
