# 用 @ 精準參照檔案

<LearningGoal>
用 @ 加上下鍵與 tab 參照特定檔案，並理解被參照的檔案會自動被讀進 context window，用小成本換取 agent 需要的精確資訊。
</LearningGoal>

## Lesson

讓 agent 的 prompt 精準，第一招是 `@` 檔參照。在輸入框打 `@` 跳出檔名補全，上下鍵移動、tab 接受；被參照的檔案會被自動讀進 context window——你不是給它一個檔名提示，而是把整份檔案內容直接放進它眼前。這點重要，因為 LLM 是不可靠的記憶體：你省略「這個檔是哪個」，它就靠探索去補，而探索燒的是你最珍貴的資源。

為什麼「小成本換精確」划算：參照會花一點前置時間（agent 讀檔、燒一點 token），但換來的是它手上握著剛好正確的那份內容；不參照的版本是它自己翻目錄、猜檔名、讀錯檔再回頭，冤枉路燒的往往更多、結果更不可靠。注意 `@` 參照和「Explore」探索的邊界：前者是你告訴它讀哪個檔（精準、省，用在你知道答案時），後者是讓它自己找出相關檔（深、貴，用在你不確定時）。先養成「知道就 @ 給它」的習慣，下一課再學怎麼暫存 prompt。
