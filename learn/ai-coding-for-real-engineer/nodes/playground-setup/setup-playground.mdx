# 把 playground 跑起來

<LearningGoal>
在本機跑起課程的 20k 行 TS/React playground：clone、Node LTS + corepack/pnpm、install、db:seed、dev（localhost:5175）、裝好 agent，並遵守「先別探索 codebase」的紀律。
</LearningGoal>

## Lesson

整個 setup 是一張機械的檢查清單：clone `aihero/coho-004-project`、裝 Node LTS、`corepack enable` 取得 pnpm、`pnpm install`、`pnpm db:seed`、`pnpm dev`（跑在 localhost:5175）、最後裝好並登入你的 agent（Claude Code 或任何 CLI harness）。選 pnpm 不是口味問題——它比 npm 快、省磁碟空間，被當成業界標準；`pnpm db:seed` 也不是空殼，它把整個課程平台的假資料（users、categories、quizzes、enrollments、lesson progress、quiz attempts、video watch events）灌進本地資料庫，後面每一課的練習都建立在這批資料上。

setup 裡唯一需要「反直覺自律」的地方，是課程要求你**刻意先別探索 codebase**。這不是不能看，而是探索是另一課專門教的技能（用「Explore」動詞觸發子代理做深度探索）——現在亂翻只會養成淺層亂看的習慣，污染你對 repo 的印象。完成清單後就收手，等探索課再上。
