# 用「Explore」叫出深層 sub-agent

<LearningGoal>
說明「Explore」這個動詞如何連結到 Explore sub-agent，並說出深層探索的成本（token、tool calls）與換來的覆蓋深度。
</LearningGoal>

## Lesson

換一個字眼就換一條路。對天真 prompt 的基準線（6 檔、無 sub-agent）加一個追問：「Explore how PPP works in this repo」——把「Tell me」換成「**Explore**」這個動詞，orchestrator 就 spawn 了一個帶客製化 system prompt 的 Explore sub-agent，它激進地搜尋、讀遠多於 6 份的檔案，再把一份濃縮的 summary 回報給 parent orchestrator。這就是 lesson 16 的 context-saving 機制：探索的髒活由一個獨立 context window 的子代理去燒 token，主 context 保持乾淨，留給真正要動腦的實作。

深層探索不是免費的——課程給了具體統計：約 60 秒、64k tokens（佔它的 context 約 32%）、25 次 tool calls，但回傳的是「幾乎像我們自己寫的」深度探索。為什麼「Explore」一個字就有效？課程的解釋是這個動詞在模型的 **latent space** 裡連到了 Explore sub-agent——模型看到 Explore 就知道該叫出這個 sub-agent；而「Tell me what the tech stack is」連不到任何 sub-agent。這是把「深層探索」變成可重現動作的具體手法。
