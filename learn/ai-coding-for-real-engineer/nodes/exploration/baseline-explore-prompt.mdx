# 天真 prompt：先看看它給多少

<LearningGoal>
用「告訴我這 repo 的 tech stack 和用途」當開場 prompt，並用 Ctrl-O 觀察它只讀幾份檔案、不會 spawn sub-agent 的淺層覆蓋。
</LearningGoal>

## Lesson

練習從最天真、最直覺的 prompt 開始：「告訴我這個 repo 的 tech stack 和它的用途」（Tell me what the tech stack of this repo is and what its intended purpose is）。關鍵不是馬上改措辭，而是先建立基準線——用 `Ctrl-O` 展開 verbose 模式，看 agent 到底做了什麼：搜尋 2 個 pattern、讀 6 個檔案、給出一份含 tech stack 的簡短 summary，而且**沒有 spawn 任何 sub-agent**。課程原文說得直接：只讀六個檔案，不會給你「這個 repo 在發生什麼事的完整 breakdown」。

這個結果的意義是：天真 prompt 觸發的是淺層探索（shallow coverage）——agent 用自己的 context 淺淺掃過幾份檔案就交差。你要養成的習慣，是把探索當成**可觀察的過程，而不是一個答案**：先記住「讀了幾個檔案、有沒有 spawn sub-agent」這條基準線，下一課用一個字眼徹底翻轉它。答得漂不漂亮看不出探索深度，動作軌跡才反映 agent 真正讀進了多少。
