# 把發現長成自己的 mental model

<LearningGoal>
用準備好的 follow-up 問題追問 agent，把探索回傳的片段發現轉成自己對 repo 完整且可操作的 mental model。
</LearningGoal>

## Lesson

Explore sub-agent 回傳的 summary 不是你的 mental model——它是子代理的理解壓縮，你對 repo 的理解還是一張白紙。課程的練習指令是：agent 回傳後，**query it and ask it some more questions**——探索不是問一次就結束的單次動作，而是一段追問的對話。用預先準備好的 follow-up 問題（核心流程怎麼串、資料模型與 source of truth、程式碼怎麼分層、慣例有哪些、加一個 feature 會動到哪些檔案）把片段發現焊進腦海，從「知道 repo 有這些東西」升級成「我理解它怎麼拼在一起、下一步改哪裡」——那才是可操作的認知。

課程的收尾提醒是：繼續跑任何想跑的 exploration commands 來加深理解，因為接下來要開始建 feature。探索不是為了炫耀知道 tech stack，而是讓接下來的實作有可靠落點。整個節奏可重複使用：天真 prompt 看基準線 → 用「Explore + 具體主題」叫出 deep sub-agent → 用 follow-up 問題展開成自己的 mental model → 確認「我理解它怎麼拼在一起、feature 會動到哪」。到這一步，你才真正「擁有」這個 repo，而不是收到一份摘要。
