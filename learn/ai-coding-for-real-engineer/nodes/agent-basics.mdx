# 怎麼開車

## Learning goal

在 VS Code 終端驅動 Claude Code：slash commands（`/usage` `/context` `/clear`）、`@` 檔參照、prompt stash、貼圖，建立 context 意識。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/agent-basics/harness-vs-process|先分清楚：工具與流程]] — 把「agent 工具」和「七階段流程」分開，理解 Claude Code 只是示範用的 CLI agent、任何 CLI harness 都適用
2. [[learn/ai-coding-for-real-engineer/nodes/agent-basics/session-control|開車基本功：終端、slash commands、中斷與恢復]] — 在 VS Code 整合終端啟動，用 `/usage` `/context` `/clear` 掌控 session 與 context，escape 中斷、輸入 go 恢復（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/agent-basics/file-references|用 @ 精準參照檔案]] — 用 `@` + 上下鍵 + tab 參照檔案，被參照的檔案會自動讀進 context window（after step 1）
4. [[learn/ai-coding-for-real-engineer/nodes/agent-basics/prompt-stash|暫存 prompt 與貼圖]] — 用 Ctrl-S 暫存、Ctrl-C 丟棄，並把圖片貼進 prompt（after step 3）

## Lesson

這個 node 是「怎麼開車」：上一課把環境跑起來，這一課教你握住方向盤——在 VS Code 終端裡實際操作 Claude Code 的日常指令。動作很瑣碎：slash commands、`@` 參照、暫存 prompt、貼圖，但全部指向同一件事：**context 意識**。你每一次輸入都在往 context window 裡加東西或清掉它，開車的第一步就是隨時知道現在裝了多少。

步驟的安排先立一個心智框架（工具 vs 流程），再學 session 控制（啟動、中斷、恢復、清空），最後是讓 prompt 更精準的兩個技巧（`@` 檔參照、暫存與貼圖）。學會這些基本功，下一課 review diff、bash、permissions 才有得立足——context 意識是整個課程反覆回來的主題，現在把它養成習慣。
