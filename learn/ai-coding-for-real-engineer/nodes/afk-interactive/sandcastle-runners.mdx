# Sandcastle：先從 interactive 模式開始

<LearningGoal>
說明 Sandcastle 如何用同一份 prompt 跑任何 agent／沙箱，並分辨 interactive.ts 與 main.ts 的差別，以及為什麼第一次要先跑 interactive、先不掛沙箱。
</LearningGoal>

## Lesson

Sandcastle 是不綁定特定 agent 與沙箱的執行器，它把 agent、sandbox、prompt 三個變數拆開；第一次先用只跑單一回合的 interactive.ts、且不掛沙箱，是為了在看不清錯誤之前先觀察並修好 prompt。
