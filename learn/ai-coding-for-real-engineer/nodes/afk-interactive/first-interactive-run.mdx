# 跑第一次：prompt.md 與單一任務

<LearningGoal>
設定並執行 interactive.ts，讀懂 prompt.md 的 prompt expansion 與「只做一個任務」的指示，並判讀第一次執行結果。
</LearningGoal>

## Lesson

interactive.ts 用 agent、sandbox、prompt 三個獨立設定跑單一回合；prompt.md 以 prompt expansion 把 PRD 與計畫全文內嵌進 prompt，並限制一次只做一個任務，執行後留下一條可用的 tracer bullet。
