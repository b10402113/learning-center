# 「do phase N」是一個 for 迴圈

<LearningGoal>
能說明多階段計畫為什麼需要人下「do phase N」，以及為什麼這個動作本質上是一個可以自動化的 for 迴圈。
</LearningGoal>

## Lesson

「do phase N」看似需要人的判斷，實際上只是重複觸發同一段早已自動化的流程，本質上就是一個 for 迴圈；模型在 2025 年底好到能承接定義明確的任務，才讓這個迴圈真的可行。
