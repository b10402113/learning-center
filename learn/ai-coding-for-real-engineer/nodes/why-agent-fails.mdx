# agent 為什麼變笨

## Learning goal

解釋 context window 二次方擴張、smart/dumb zone、statelessness、非決定性，並用這些約束預測 agent 什麼時候會出錯。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/why-agent-fails/context-window|Context Window 與二次方擴張]] — 說出 context window 是什麼、注意力為什麼二次方成長、塞越多越吃力
2. [[learn/ai-coding-for-real-engineer/nodes/why-agent-fails/smart-dumb-zone|Smart Zone 與 Dumb Zone]] — 說出 context 填滿後推理變差、幻覺、召回失敗，並用 token 門檻判斷何時進入 dumb zone（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/why-agent-fails/unreliable-memory|參數記憶不可靠與無狀態]] — 說出為什麼不能靠模型記憶、無狀態意味什麼，推導出靠 context 與文件（after step 1）
4. [[learn/ai-coding-for-real-engineer/nodes/why-agent-fails/non-determinism|非決定性：同一個 prompt 每次不同]] — 說出 agent 是 next-token 抽樣機、同樣指令每次結果不同，並調整期待（after step 1）
5. [[learn/ai-coding-for-real-engineer/nodes/why-agent-fails/predicting-failures|用這些約束預測 agent 何時會出錯]] — 綜合四項約束預測 agent 何時容易出錯並說出防範方式（after steps 2–4）

## Lesson

agent 之所以「變笨」，不是它故意偷懶，而是四條硬性約束在背後決定它的表現。這節課把四條約束逐條講清楚：context window 裡注意力二次方擴張，讓塞太多內容的模型愈來愈吃力；一旦把它塞進 dumb zone，推理變差、幻覺跑出來；它內建的參數記憶是壓縮過、不可靠的，而且完全無狀態，離開 context 就什麼都不記得；最後它本來就是從機率分布抽樣的非決定性機器，同一個 prompt 每次都可能給不同結果。看懂這四條約束後，你就能反過來預測 agent 什麼時候會出錯，也知道「保持 context 精簡、靠 context 與文件而不是靠模型記憶」這些動作背後的原因。
