# 跑一次完整多階段實作（並讀懂日誌）

<LearningGoal>
實際啟動一次 AFK 迴圈跑完整份多階段計畫，並從日誌讀出 agent 如何跳過已完成的 phase、逐階段 typecheck／test／commit，以及每輪消耗多少 context window。
</LearningGoal>

## Lesson

每輪 agent 先辨識已完成的工作、只往下一個 phase 走，依序 explore、實作、typecheck／test、commit，沒有完成信號就進下一輪；日誌要讀收集到的 commits、信號出現在第幾輪、以及每輪的 context window 用量。
