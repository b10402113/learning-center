# 迴圈怎麼停：maxIterations 與 completion signal

<LearningGoal>
說出 AFK 迴圈的兩個終止條件（maxIterations 與 completion signal "no more tasks"），並解釋「信號為主、上限為保險」的成本取捨。
</LearningGoal>

## Lesson

AFK 迴圈有兩個終止條件——達到 `maxIterations` 或看到 prompt 約定的 completion signal `no more tasks`；上限是不看情況的保險，信號是做完就收工的出口。
