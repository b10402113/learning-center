# 放手之後：規劃前提與平行化自己

<LearningGoal>
判斷放手跑 AFK 迴圈時人該做什麼，並說明為什麼前面的規劃工作是多階段自走能順利收尾的前提。
</LearningGoal>

## Lesson

放手與否看四個前提——沙箱與 prompt 已驗證、plan 切成單輪切片、煞車設好、commit 可回溯；四題都過才放手，並把時間拿去平行化自己（規劃下一批工作）。
