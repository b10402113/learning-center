# 從 interactive 到 main.ts：無人值守的 runner

<LearningGoal>
說出 `sandcastle/main.ts` 這個 AFK runner 和 `interactive.ts` 的三個差異，並用位置引數（PRD、plan）呼叫它。
</LearningGoal>

## Lesson

`main.ts` 是 interactive 的單圈再加上一個 while 迴圈：它沿用同一支 Claude Code、Docker 沙箱與 prompt，只把 `interactive` 換成 `run`，並加上 `maxIterations` 與 completion signal，用 PRD 與 plan 兩個位置引數啟動。
