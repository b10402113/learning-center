# 互動式 AFK

## Learning goal

說明「do phase N 是 for loop」，並用 Sandcastle interactive 模式 + prompt.md，在可觀察環境下跑第一次單一任務。

## Steps

1. [[learn/ai-coding-for-real-engineer/nodes/afk-interactive/afk-pattern|「do phase N」是 for loop：把實作循環自動化]] — 認知轉向：人從迴圈執行者變成佇列管理者，AFK agent 自動跑「do phase N」
2. [[learn/ai-coding-for-real-engineer/nodes/afk-interactive/sandcastle-interactive|Sandcastle interactive 模式：先能看見，再談放手]] — 先跑 `interactive.ts`（無 sandbox、用 prompt.md 模仿最終 agent），再談 `main.ts`（after step 1）
3. [[learn/ai-coding-for-real-engineer/nodes/afk-interactive/prompt-md-expansion|prompt.md 的機制：`!` 展開、PRD/plan 注入、單任務守則]] — 寫 prompt.md：反引號 `!` 指令內嵌、PRD/plan 注入、一次只做一個任務（after step 2）
4. [[learn/ai-coding-for-real-engineer/nodes/afk-interactive/first-interactive-run|跑第一次：`npx tsx sandcastle/interactive.ts`]] — 跑第一次單一任務，看到 permission 請求是擋在完全 AFK 前的最後一關（after step 3）

## Lesson

「do phase N」本來是一個人坐在鍵盤前，對多階段 plan 一圈一圈手動下指令；這個 node 教你把它看成一個可以自動化的 for loop，然後用 Sandcastle 的 interactive 模式，在還看得見每一步的環境下跑第一次。核心是「先能觀察、再談放手」：interactive 模式不用 sandbox，靠一份模仿最終 agent 的 prompt.md 先讓你把設定優化到位，等你確認 agent 的行為正確，下一步才進 sandbox、才進 `main.ts`。跑完這個 node，你會有一份可重用的 prompt.md，和一場完整看完的「探索 → 實作 → 測試 → commit」單任務示範。
