# 用 gh CLI 把 agent 接上 GitHub

<LearningGoal>
用 gh CLI 加 prompt expansion 讓 agent 抓開放 issue、挑任務、做完 commit 後 close 或留言，並把 personal access token 注入沙箱。
</LearningGoal>

## Lesson

用 prompt expansion 的 `!` 區塊跑 `gh issue list` 把開放 issue 抓成 JSON，配任務選擇 prompt 挑一件、實作並 commit；完成就 `gh issue close`、未完成就 `gh issue comment`，token 透過 `.env` 注入沙箱。
