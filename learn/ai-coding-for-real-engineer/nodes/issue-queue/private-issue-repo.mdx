# 準備一個只有你能動的 issue repo

<LearningGoal>
一步步把專案複製成自己擁有的 GitHub repo（複製目錄、清掉 git 歷史、建新 repo），得到一個只有你能發 issue、agent 能安全取用的私有任務佇列。
</LearningGoal>

## Lesson

把本機專案複製一份、清掉 git 歷史、在自己的帳號建立新 repo，才能得到一個只有你能發 issue 的私有任務佇列；直接 fork 會讓所有人共用同一個 issue 池。
