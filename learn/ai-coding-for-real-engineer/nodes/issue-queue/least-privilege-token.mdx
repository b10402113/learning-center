# 只給 agent 剛好夠用的 token

<LearningGoal>
用最小權限原則決定 agent 的 GitHub token 該有哪些權限，並說出一次成功修復的完整流程與可觀測性從何而來。
</LearningGoal>

## Lesson

用 fine-grained token 限定單一 repo，只開放讀取、留言、關票（不含建立 issue），讓 agent 剛好夠用；關票時附上的留言同時提供了修復的可觀測性。
