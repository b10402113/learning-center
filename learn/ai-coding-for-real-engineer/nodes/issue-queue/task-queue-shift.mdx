# 為什麼讓 agent 自己挑任務

<LearningGoal>
說明為什麼要把「指定 PRD 與 plan」換成讓 agent 自己從佇列挑任務，並背出五級任務優先序、判斷這個模式適用的規模。
</LearningGoal>

## Lesson

把 AFK 迴圈的輸入從固定計畫換成任務佇列，agent 就會自己挑下一個任務，挑選依據是五級優先序：重大 bug 修正 → 開發基礎設施 → 新功能的 tracer bullets → 打磨與快速見效 → 重構。
