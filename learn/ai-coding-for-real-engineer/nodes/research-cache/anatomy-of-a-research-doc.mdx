# 好的 research 文件長什麼樣

<LearningGoal>
說出一份好的 research 文件應包含哪些區塊，並解釋它為什麼放在 repo 的 plans/ 目錄而不是開成 GitHub issue。
</LearningGoal>

## Lesson

一份好的 research 文件像一份 ADR，包含需求、推薦做法、實作設計、整合點與被比較掉的替代方案；它放在 repo 的 plans/ 而非 GitHub issue，因為它是會被很多張票反覆讀取的參考資料，不是一張做完就關的票。
