# 為什麼要把探索快取下來

<LearningGoal>
說明為什麼要先把昂貴的外部探索做一次並寫成 research.md，講出它如何省下重複的 token 與探索時間、又為什麼這件事得由人來主導。
</LearningGoal>

## Lesson

把迴圈裡最貴的探索搬到外面只做一次，寫成 repo 裡的 research.md，讓後續每一輪直接讀答案，省下重複的 token 並把 agent 留在 smart zone；這件事是 HITL 工作，因為選哪條路要靠人的品味，而且只有沒有先例、又會被重複用到的決策才值得研究。
