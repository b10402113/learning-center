# 跑一次研究：把未知問成一份文件

<LearningGoal>
照著一個可重複的研究 prompt 做一次 HITL 研究：要求多個方案、用問題反覆收斂、上網驗證假設，最後把結果寫成 plans/ 目錄底下的一份文件。
</LearningGoal>

## Lesson

用五要件 prompt（講清情境、要求多方案、請它反問收斂、要求上網驗證、輸出到 plans/）跑一次研究：agent 會先探 stack，再把規格問題丟回來，接著並行比較服務，最後產出一份完整的研究文件。
