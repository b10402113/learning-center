# 別在主機上開 YOLO

<LearningGoal>
說出為什麼在沒有隔離的主機上打開 `--dangerously-skip-permissions`（YOLO）風險過高，並指出 Claude Code 內建 sandbox 為什麼不足以信任。
</LearningGoal>

## Lesson

YOLO（`--dangerously-skip-permissions`）把權限詢問整個拿掉，讓不受監督的 agent 可能執行破壞性指令，或在被 prompt injection 之後把敏感程式碼外洩；Claude Code 內建的 sandbox 可以被跳出，擋不住這種風險。所以要放手，先要有真正的隔離。
