# 建起沙盒：Dockerfile、.env 與 build image

<LearningGoal>
安裝 Docker Desktop 或 Podman、備好 `.env` 的 Anthropic API key、執行 `pnpm sandcastle docker build image`，把 Sandcastle 的 Docker 沙盒映像建起來。
</LearningGoal>

## Lesson

安裝 Docker Desktop 或 Podman、把 `sandcastle/.env.example` 複製成 `.env` 並填入 Anthropic API key、執行 `pnpm sandcastle docker build image`，把內含 Node 22 與 Claude Code、工作目錄為 `/home/agent` 的沙盒映像建起來。
