# 隔離到底隔離了什麼

<LearningGoal>
說明 Docker 沙盒用 bind mount 只把 repo 交給 agent、所有 bash 都在容器內執行、憑證用環境變數注入這三個機制，如何把 agent 的可及範圍縮到最小。
</LearningGoal>

## Lesson

容器隔離不是砍掉 agent 的能力，而是用 bind mount 只把 repo 掛進容器、讓所有 bash 都在容器內執行、並以環境變數注入憑證，把 agent 的可及範圍縮到最小；Docker 與 Podman 提供的是同一套隔離模型。
