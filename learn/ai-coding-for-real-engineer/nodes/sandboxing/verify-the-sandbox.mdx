# 驗證沙盒：用 test.ts 跑一次 Hello

<LearningGoal>
執行 `npx tsx sandcastle/test.ts`，從 logs 看出 agent 已在容器內回話、沙盒設定耗時、沒有留下 commit、以及用掉約 19k context，確認沙盒真的能跑。
</LearningGoal>

## Lesson

用 `npx tsx sandcastle/test.ts` 跑一次 hello 測試，從 logs 的四個訊號——agent 回話、沙盒設定耗時、沒有產生 commit、約 19k context——確認沙盒真的能在容器內啟動、認證與執行。
