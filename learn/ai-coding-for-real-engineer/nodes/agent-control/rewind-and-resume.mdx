# 用 rewind / resume 回放 session

## Learning goal

用 escape 兩次進入 rewind 模式還原程式碼或對話，並用 `/resume` 或 `claude --continue` 續開本機持久化的 session，把 LLM 的無狀態性用 harness 端的 session 持久化補回來。

## Lesson

先建立最重要的心智模型：**LLM 本身完全不記得上一次對話**，每次開新 session 都是空 context。所有「記憶」其實存在 harness（Claude Code）這一端。所以你真正需要的不只是「agent 記得」，而是**一個能倒帶、能重播的工具**。

進入 rewind 模式只要按 escape 兩次，Claude Code 會列出這個 session 的歷史時間點（最下面是目前狀態，越往上越早）。還原有三種選擇：還原程式碼 + 對話（最常用）、只還原對話、只還原程式碼。選好後用方向鍵 + Enter 確認，就能把時間撥回那一點——最常用的就是把 session 直接倒回編輯發生之前，一鍵回到「沒出事」的狀態。除此之外，跟 Claude 說 `revert that please` 也可以還原它剛才的改動。

Claude Code 會把 session **持久化在本機**，退出（Ctrl-C 兩次）後有多種方式續開：`claude resume <uuid>`（直接續開指定 session）、新 session 裡用 `/resume` 挑選甚至搜尋歷史 session、或 `claude --continue` 直接回最後一個 session。三者都回到離開時的狀態。

對 AFK 工作來說這兩個能力缺一不可：**Rewind 讓你在 agent 改壞時倒帶到出事前，Resume 讓你隔天接著做**。你之所以敢走開，除了上一課的 review 閘門，還因為你知道回來時出什麼事都能倒帶、任何進度都能續開。
