Sandbox 與 AFK Loop

Node afk-loop-sandbox · Quick Reference · Print-friendly

YOLO 模式三危險

危險機制防禦
刪除主機檔案rm -rf ~ 等破壞性指令Docker 隔離：指令只影響容器內部
外洩機敏程式碼curl POST codebase 到外部容器網路隔離：禁止出站流量
Prompt injection檔案中埋入惡意指令被 agent 執行容器限制影響範圍 + 最小權限 token

Docker 沙盒設定步驟

  1. 安裝 Docker Desktop 或 Podman
  2. 從 .env.example 複製並填入 ANTHROPIC_API_KEY
  3. pnpm sandcastle docker build image
  4. 冒煙測試：npx tsx sandcastle/test.ts（prompt: "hello"）

AFK 迴圈結構

// 核心邏輯
while (iterations < maxIterations) {
  run_sandcastle(prd_path, plan_path);
  iterations++;
  if (agent_emitted("no more tasks")) break;
}

maxIterations

  • 安全上限（10–50）
  • 信任完成訊號，但保留防線

完成訊號

  • Agent 輸出 "no more tasks"
  • 比 maxIterations 更精準

適合 AFK 的條件

✅ 適合 AFK

  • 測試能自動驗證
  • typecheck 能抓到錯誤
  • 完成標準可程式化判斷
  • 垂直切片任務（tracer bullet）

❌ 需要 HITL

  • UI 「好看不好看」
  • 需求只有人看得出對錯
  • 一次性決策（不可逆）
  • 架構設計
