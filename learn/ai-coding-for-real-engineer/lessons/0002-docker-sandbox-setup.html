Lesson 002 · Sandbox 與 AFK Loop

Docker 沙盒設定與冒煙測試

四步把 agent 關進容器，確認它能呼吸。

前置條件

你已經懂了為什麼需要沙盒（上一課）。現在動手。這堂課只需要你機器上有一個東西：Docker。如果你還沒裝，下面是最快的路徑。

步驟一：安裝 Docker

1

選擇你的容器引擎

選項 A：Docker Desktop（推薦，課程預設）

  • 去 docker.com/products/docker-desktop 下載 Mac 版
  • 安裝後開啟，確認選單列出現 Docker 图示
  • 免費方案足夠個人使用

選項 B：Podman（免費、無 daemon）

  • brew install podman
  • podman machine init && podman machine start
  • 命令列與 Docker 幾乎相同，課程 repo 有支援

安裝完畢後，打開終端機驗證：

docker --version
# 或
podman --version

看到版本號就表示就緒。

macOS 常見問題

  • Docker Desktop 要求 Apple Silicon (M1/M2/M3) 或 Intel — 選對下載頁面
  • 第一次啟動可能要 30–60 秒，看選單列图标從灰色變成綠色
  • 如果 docker 指令找不到，重開終端機或執行 sudo ln -sf /Applications/Docker.app/Contents/Resources/bin/docker /usr/local/bin/docker

步驟二：設定環境變數

2

填入 API Key

進入課程 repo 的 sandcastle 目錄：

cd aihero/coho-004-project/sandcastle

複製環境變數模板：

cp .env.example .env

編輯 .env，填入你的 Anthropic API key：

ANTHROPIC_API_KEY=sk-ant-api03-你的金鑰貼這裡
關於 API Key 的來源 課程要求使用 Anthropic API key（直接從 console.anthropic.com 取得）。不建議用 Claude 訂閱帳號——課程提到有一個未解決的法律問題阻斷了訂閱帳號在沙盒中的使用。API key 是付費的，但冒煙測試只花幾分錢。

步驟三：Build Docker Image

3

建立容器映像

回到 repo 根目錄，執行 build：

cd ..
pnpm sandcastle docker build image

這個指令會：

  1. 讀取 sandcastle/Dockerfile（Node 22 + Claude Code 已安裝）
  2. 安裝所有依賴
  3. 產生一個可用的 Docker image

第一次 build 大約 2–5 分鐘（下載 base image + 安裝依賴）。後續 rebuild 只有增量變更，快很多。

你會看到什麼 終端機會輸出 build steps（Step 1/8 : FROM node:22……），最後一行會是 Successfully tagged ...。看到這個就表示 image 就緒。

步驟四：冒煙測試

4

確認容器內 agent 能跑

npx tsx sandcastle/test.ts

這個腳本做兩件事：

  1. 在 Docker 容器裡啟動 Claude Code
  2. 給它一個簡單 prompt（"hello how are you"）
  3. 觀察 agent 是否正常回應

你會在終端機看到 agent 的即時 log——它在容器內探索、回覆、完成任務。

成功的樣子 Log 顯示 agent 收到 prompt、執行了 bash 指令（在容器內）、輸出了回應。沒有錯誤、沒有 timeout。整個過程大約 30 秒到 1 分鐘。

你在隔離什麼

跑完冒煙測試後，你可以打開 Docker Desktop 的「Containers」頁面，看到正在運行的容器。點進去看檔案系統——你會發現：

  • 容器內有一個 /home/agent 目錄，裡面是你 bind mount 進來的 repo
  • 容器外的主機檔案系統完全看不到
  • 容器內執行的所有 bash 指令都在容器環境中
安全驗證 在容器內的 agent 執行 ls ~ 看到的是 /home/agent，不是你主機的 home 目錄。這就是隔離。

自學檢查

快速回顧

  1. .env.example 裡唯一需要填的變數是什麼？
  2. 冒煙測試的腳本是什麼？它用什麼 prompt？
  3. Build 完成後，你在 Docker Desktop 看到容器代表什麼？
