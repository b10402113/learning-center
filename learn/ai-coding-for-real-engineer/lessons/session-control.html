學習目標：在 VS Code 整合終端啟動 Claude Code，用 /usage、/context、/clear 掌控 session 與 context window，並用 escape 中斷執行、輸入 go 恢復。

在哪裡開車：VS Code 整合終端

Claude Code 跑在 VS Code 的整合終端（integrated terminal）裡。這不是選擇題——整個課程你會頻繁需要看 diff、改檔案，留在 VS Code 裡讓 agent 和 IDE 在同一個畫面，是後面幾課（IDE diff review）的地基。

啟動後第一件事：跑 /terminal-setup，它會裝好鍵盤綁定。其中最重要的綁定是 shift+enter 在輸入框裡換行——讓你能寫多行 prompt，而不是打到一半就送出去。

三個 slash commands：掌控 session 與 context

課程把這三個指令視為一套組合，全部指向同一個主題：context 意識。

指令看什麼用途
/usageplan 的用量上限看這個 session 和這週把訂閱額度用掉多少
/contextcontext window 的消耗視覺化目前裝了多少 token（例如 200k 中已用 21k），是偵測 context 用法的唯一內建視窗
/clear歸零把 context window 重置為 0，等於開一個全新的聊天
為什麼這三個是一組？LLM 是無狀態的——所有「臨場知識」都存在 context window 裡。`/context` 讓你知道裝了多少，`/usage` 讓你知道額度還剩多少，`/clear` 讓你在該歸零時乾脆地歸零。這是整門課會反覆回來的主題。

中斷與恢復：escape 與 go

agent 跑起來之後，你隨時可以打斷它：

  • escape——中斷正在執行的 Claude
  • 中斷後輸入 go——讓它繼續接著做

這不是結束 session，只是暫停。很多新手不知道這個組合，看到 agent 走錯方向只能乾瞪眼等它跑完；學會 escape 就等於拿到方向盤——發現偏了就停下來，改講清楚，再 go 讓它續跑。

把「開車」變成肌肉記憶

這三個 slash command + escape/go，是每一節課都會用到的組合。開一個新 session 的慣例建議是：先 /clear 確保從乾淨狀態開始（課程之後教 AFK 前還會再強調「每階段 clear context」）。跑久一點就 /context 看一眼——養成這個習慣，你就永遠不會讓 agent 在「裝太滿」的狀態下亂跑。
