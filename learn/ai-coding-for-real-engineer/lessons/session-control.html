開車基本功：終端、slash commands、中斷與恢復

Step 2/4 · 怎麼開車

學習目標：在 VS Code 整合終端啟動 Claude Code，用 /usage、/context、/clear 掌控 session 與 context window，並用 escape 中斷執行、輸入 go 恢復。

開車的地點：VS Code 整合終端

Claude Code 跑在終端裡。但不是任何終端——課程推薦用 VS Code 整合終端，因為你之後 review diff、看檔案變更都需要 IDE 的輔助。打開 VS Code，開一個新的 terminal panel，輸入 claude 就啟動了。

啟動後的第一件事：跑 /terminal-setup。這個指令會幫你裝好鍵盤綁定，其中最重要的是 shift+enter 在輸入框換行——沒有這個綁定，你寫多行 prompt 時按 enter 就會直接送出，整個 prompt 斷在半路。

三個 slash command：掌控 context 意識

掌控 session 靠三個 slash command，全部指向同一個主題：context 意識。context window（上下文窗口）是 LLM 的工作記憶——你每次輸入的東西、agent 讀過的檔案、跑過的指令，全部塞在這個窗口裡。窗口有大小上限（例如 200k tokens），裝太滿 agent 就會變笨（之後的課會深入講 smart zone / dumb zone）。

指令 做什麼 為什麼重要
/usage 顯示 plan 用量上限（session 和週） 知道自己有沒有額度，避免跑到一半被斷
/context 視覺化 context window 目前裝了多少 token 最直接的 context 意識工具——例如 200k 中已用 21k
/clear 把 context window 歸零 等於開新聊天，清除所有累積的「部落知識」

/context 是這三個裡面最值得養成習慣的。你不需要每五分鐘跑一次，但每次開始新任務前、或感覺 agent 開始「怪怪的」時，跑一下看看——它會告訴你 context 已經裝了多少。等到之後學 context economy 時，你會發現這個習慣值多少 token。

類比：context window 像是一個背包。`/context` 就是拉開拉鍊看裡面裝了什麼、還剩多少空間。`/clear` 就是把背包倒空、重新開始裝。你不會背著一個塞滿的背包去爬山——agent 也不會在 context 裝太滿時表現好。

escape + go：暫停與恢復

執行中你想插手就按 escape 中斷 Claude，它會停下來等你。這時候你可以：

  • 直接打新的 prompt 改方向
  • 輸入 go 讓它從中斷點繼續

很多人不知道 escape + go 這個組合。看到 agent 走偏只能乾瞪眼，等它跑完整個錯誤的結果才重新來。會 escape 就等於拿到方向盤——你隨時可以踩煞車，決定要轉彎還是繼續直走。

養成兩個習慣

  1. 新 session 先 /clear——從乾淨狀態開始，不要帶著上一次 session 的殘留
  2. 跑久一點就 /context 看一眼——確認 context 還在 smart zone 裡

這兩個動作看起來瑣碎，但它們是整門課反覆回來的主題——context 意識的具體實踐。現在把它們養成習慣，之後學大流程時就不必分心想「context 怎麼管」。

小結

Session 控制：`/terminal-setup` 裝綁定、`/usage` 看額度、`/context` 看容量、`/clear` 歸零、escape 中斷、go 恢復。這些是方向盤和儀表板——先學會開車，再上路。
