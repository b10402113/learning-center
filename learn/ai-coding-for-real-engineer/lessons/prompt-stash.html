暫存 prompt 與貼圖

Step 4/4 · 怎麼開車

學習目標：用 Ctrl-S 暫存目前寫到一半的 prompt、Ctrl-C 丟棄它，並把圖片直接貼進 prompt（WSL 不支援），讓 prompt 可以中途抽離再恢復。

寫到一半想先做別的事

你正在打一個很長的 prompt，解釋你要 agent 做什麼——忽然你想起要先查一個東西。傳統做法是把 prompt 複製到某個地方、做完事再貼回來。但 Claude Code 有內建機制：Ctrl-S 暫存。

按下 Ctrl-S，你目前打到一半的 prompt 會被暫存起來，輸入框清空。你可以跑別的指令、做別的事。想恢復的時候，暫存的 prompt 會自動回來。

不想恢復了？按 Ctrl-C 丟棄暫存的 prompt，輸入框保持乾淨。

這不是手動複製貼上——是 Claude Code 內建的 prompt 管理機制。它把「打 prompt」從一次性動作變成可暫停、可反悔的流程。

貼圖：一張圖勝過描述半天

有時候文字描述不了你想讓 agent 看的東西：

  • UI 長歪了——截圖比寫「按鈕跑到右邊去了」精確一百倍
  • 報錯畫面——直接貼截圖，agent 看得懂
  • 設計稿——一張圖就是完整的需求規格

做法很簡單：把圖片直接貼進 prompt 輸入框。Claude Code 會把圖片一併送進 context window。這是給 agent 視覺資訊最直接的方式。

例外：WSL（Windows Subsystem for Linux）不支援貼圖功能。原生 Windows 和 macOS 都可以。如果你在 WSL 裡跑，需要用其他方式把圖片路徑傳給 agent。

整套「怎麼開車」的動作總覽

回頭看這個 node 的四個步驟，其實全部在管理同一件事——你要給 agent 的輸入：

動作 管理什麼
/clear 清掉舊的 context
@ 參照 指到對的檔案
Ctrl-S / Ctrl-C 暫存沒打完的 prompt
貼圖 貼上說不清的視覺資訊

把它們練熟，之後學大流程時就不必分心想「怎麼打字」——打字變成反射，判斷才是主軸。

小結

暫存與貼圖：Ctrl-S 暫存、Ctrl-C 丟棄、圖片直接貼進 prompt。加上上一課的 @ 參照，你現在有四招管理 agent 的輸入：清掉舊的、指到對的、暫存沒打完的、貼上說不清的。
