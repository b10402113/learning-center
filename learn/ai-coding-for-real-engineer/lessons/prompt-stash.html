暫存 prompt 與貼圖

ai-coding-for-real-engineer › agent-basics › prompt-stash

學習目標：用 Ctrl-S 暫存目前寫到一半的 prompt、Ctrl-C 丟棄它，並把圖片直接貼進 prompt（WSL 不支援），讓 prompt 可以中途抽離再恢復。

場景：寫到一半，但你想先做別的事

你正在打一段很長的 prompt，突然想到應該先確認某個設定、或先跑一個指令看看輸出。傳統做法是：把整段話複製起來、開新行、做事、再貼回來。煩，而且容易漏。

Claude Code 給你一個更乾淨的機制：暫存（stash）。

快捷鍵動作何時用
Ctrl-S暫存目前寫到一半的 prompt想先去跑另一個指令，之後再回來
Ctrl-C丟棄目前的 prompt寫歪了、決定不要了

暫存不是「複製貼上」——是 Claude Code 幫你把這段 prompt 收好，你做完別的事，隨時可以把它叫回來繼續。這讓寫 prompt 這件事可以中途抽離再恢復，不用重打。

貼圖：把畫面直接交給 agent

除了文字，你還能直接把圖片貼進 prompt。這是處理「視覺資訊」最直接的方式——例如 UI 長歪了、報錯畫面、設計稿，一張圖勝過你描述半天。

唯一的例外：WSL 不支援貼圖。如果你在 Windows Subsystem for Linux 裡跑 Claude Code，這個功能不可用；換到原生 Windows 或 macOS 環境就有。

把這三招連起來看

回顧這個 node 學的整套「開車」動作，其實是同一件事的三面：/clear、@ 參照、Ctrl-S/Ctrl-C、貼圖——都是在管理你要給 agent 的輸入。暫存讓你不用重打，丟棄讓你可以反悔，貼圖讓你能給它剛好需要的視覺資訊。這些都是讓 prompt 更精準、更可恢復的小工具；把它們練熟，之後學大流程時就不用分心在想「怎麼打字」。
