把 context 用量放在眼前

Node 6 · context-economy · Step 1/4 · 用 status-line 盯住 smart zone

Learning goal

安裝 status-line，讓 context 用量（token 數）隨時可見，並用「80k–100k token 的 smart zone」取代「40% 就該緊張」的舊規則。

問題：看不見就管不住

上一節講了 context 是二次方擴張的，裝越多越靠近 dumb zone。但「理論上知道」和「隨時看得到」是兩回事——Claude Code 預設 UI 把 context 用量藏起來了，你得跳出工作流程、退出 plan mode、敲 /context 才看得到數字。講師的原話是「It was just gross」（太噁心了）。

對比之下，Cursor 或 OpenCode 都把 context 百分比常駐顯示，所以用戶能簡單地保持在 smart zone。Claude Code 不是做不到，而是預設不顯示——它其實有可自訂的 status line。

解法：裝一個 status-line 套件

解法是把一套社群開發的 status-line 文章貼進 Claude Code，讓它自動幫你設定。整個安裝過程：

  1. 先 clear 清空 context，再用 shift-tab 切回 default mode。
  2. 複製課程提供的整篇文章（copy as markdown）貼進 Claude Code。
  3. 讓 Claude Code 照著文章逐步設定——它會改你的全域設定（~/.claude 的 settings JSON），不是專案設定。
  4. 存檔後重開 session，status line 就常駐了。

關鍵點：這裝在全域，意思是對你所有專案都生效，跟 repo 無關。安裝後連未重啟的 session 都能看到 context 用量出現在 prompt 下方。

新度量衡：token 數，不是百分比

講師錄影後 Anthropic 公布了 Opus 4.6 / Sonnet 4.6 的 1M token context window，這讓「百分比」不再是可靠的度量衡——200k 的 40% 是 80k，1M 的 40% 可是 400k，天差地遠。所以新的 status-line 設定改為顯示：raw token 數（主顯示）+ 暗淡括號內的百分比（參考用）。

Smart zone 的新規則：看到 token 數到達 80k–100k 就開始緊張。別再用百分比算——講師錄影時用的是 200k limit，所以對影片裡的他來說 40% ≈ 80k tokens；但你的數字要看 raw token。

之後課程影片裡講師繼續講百分比，你只要做一次心算：200k × 百分比 ≈ raw token 數。status line 會隨 session 進行即時更新，讓你在任何時刻都清楚 context 裡發生什麼。

為這個節點定調

monitor-context 是這節四招的第一招，也是後面三招的前提：sub-agent（外包探索）、compact/clear（重置）、handoff（換手）都是在「你知道 context 在哪裡」之後才有意義的動作。看不見就管不住，先讓用量隨時在眼前。
