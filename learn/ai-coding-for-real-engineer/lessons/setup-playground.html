把 playground 跑起來

Node 1 · setup-playground · 20k 行 TS/React 課程 repo 落地

Learning goal

在本機跑起課程的 20k 行 TS/React playground：clone、Node LTS + corepack/pnpm、install、db:seed、dev（localhost:5175）、裝好 agent，並遵守「先別探索 codebase」的紀律。

整個 setup 的檢查清單

這是最機械但最關鍵的一段——之後每一課都是「在 playground 上跟 agent 一起改 code」，環境沒跑起來就沒有著陸點。清單是：

  1. clone 課程 repo：aihero/coho-004-project
  2. 安裝 Node LTS（用 LTS，不要最新版）
  3. 啟用 corepack 拿到 pnpm（corepack enable）
  4. pnpm install 裝依賴
  5. pnpm db:seed 種本地資料庫
  6. pnpm dev 起 dev server，跑在 localhost:5175
  7. 裝好 agent（Claude Code 或任何 CLI harness）並登入

為什麼用 pnpm

課程選 pnpm 不只是口味問題：它比 npm 快、省磁碟空間，而且被當成業界標準。啟用方式是 corepack enable——corepack 是 Node 內建的包管理器版本管理器，一行指令就能取得與 repo 約定的 pnpm。

db:seed 到底種了什麼

pnpm db:seed 不是一個空殼——它把整個課程平台的假資料灌進本地資料庫：使用者（users）、分類（categories）、測驗（quizzes）、註冊（enrollments）、課程進度（lesson progress）、測驗嘗試（quiz attempts）、影片觀看事件（video watch events）。後面的練習（星等評分、留言、書籤）全都建立在這些假資料上。

先別探索 codebase——這是紀律，不是偷懶

課程明確要求你「刻意不要」現在就翻 codebase。不是不能看，而是探索是另一課專門教的技能（用「Explore」動詞觸發子代理做深度探索）。現在就亂翻，只會養成淺層亂看、污染自己對 repo 的印象。setup 完成後就把手放下，等探索課再上。

一個常見摩擦點：agent 的安裝

課程 demo 用 Claude Code，但整套流程幾乎任何 CLI-based agent 都適用。安裝後記得登入並確認模型——選你訂閱方案的預設模型（Max 5x 用 Opus 等級、Pro 用 Sonnet 等級），別選最便宜的等級。這一步卡關時，多數問題出在 Node 版本或 corepack 沒啟用，先用 node -v 和 pnpm -v 確認環境。
