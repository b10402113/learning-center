把 playground 跑起來

Step 1/3 · 把環境跑起來

學習目標：在本機跑起課程的 20k 行 TS/React playground：clone、Node LTS + corepack/pnpm、install、db:seed、dev（localhost:5175）、裝好 agent，並遵守「先別探索 codebase」的紀律。

為什麼需要這個 playground

整門課的所有練習都發生在一個約 20,000 行的 TypeScript / React 專案上。你不會只是讀過去——你會在上面真實地操作 agent、改 code、跑測試、commit。如果你的環境還沒跑起來，後面每一課都沒有着陸點。

這個 playground 是一個課程平台：有 users、categories、quizzes、enrollments、lesson progress 等假資料。你不需要理解它的全部，但你需要它能跑。

完整設定清單

以下是一張機械式的檢查清單。一步一步走，每一步都只是跑一行指令。

1. Clone repo

git clone https://github.com/aihero/coho-004-project.git
cd coho-004-project

把課程專案整個複製到你的本機。這是你的工作目錄。

2. 安裝 Node LTS + 啟用 corepack

# 確認 Node 版本（需要 LTS）
node --version

# 啟用 corepack，取得 pnpm
corepack enable

pnpm（Package Hardened Node.js）是這門課使用的套件管理器。它比 npm 快、省磁碟空間，而且被視為業界標準。corepack 是 Node 內建的工具管理器，啟用後你就能直接用 pnpm 指令，不需要額外安裝。

3. 安裝依賴

pnpm install

把所有依賴抓下來。這一步可能要幾分鐘，取決於你的網路速度。

4. Seed 資料庫

pnpm db:seed

這不是空殼指令。它會把整個課程平台的假資料灌進本地資料庫：users、categories、quizzes、enrollments、lesson progress、quiz attempts、video watch events。後面每一課的練習都建立在這批資料上。

5. 啟動 dev server

pnpm dev

跑起來後，打開瀏覽器到 localhost:5175，你應該會看到課程平台的 UI。看到畫面代表環境 OK。

6. 裝好 agent

安裝並登入你的 coding agent（Claude Code 或任何 CLI harness）。課程用 Claude Code 做示範，但任何 CLI-based 的 agent 都能用。

類比：想像你在準備一個工作坊。Clone 是租場地、install 是搬桌椅、seed 是準備教材、dev 是開燈確認一切就緒、裝 agent 是請來講師。全部完成後，工作坊才能開始。

反直覺的紀律：先別探索 codebase

設定完成後，你可能會衝動地想打開幾個檔案看看這個 repo 長什麼樣子。課程要求你刻意不要這麼做。

這不是不能看——而是探索 codebase 是另一課專門教的技能。它需要特定的 prompting 技巧（用「Explore」動詞觸發子代理做深度探索），而現在亂翻只會養成淺層亂看的習慣，污染你對 repo 的印象。

完成清單後就收手。等探索課再上。

反模式：「我先隨便打開幾個檔案看看」→ 你會看到表面的 import 和型別，但抓不到真正的架構脈絡，養成「看過等於理解」的錯覺。

小結

設定流程：clone → corepack enable → pnpm install → pnpm db:seed → pnpm dev（localhost:5175）→ 裝 agent。完成後收手，不要探索 codebase。
