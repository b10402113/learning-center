用 rewind / resume 回放 session

學習目標：用 escape 兩次進入 rewind 模式還原程式碼或對話，並用 /resume 或 claude --continue 續開本機持久化的 session，把 LLM 的無狀態性用 harness 端的 session 持久化補回來。

LLM 是無狀態的

這是整個課程最重要的心智模型之一：LLM 本身完全不記得上一次對話。每次開新的 session，它的 context 都是空的——上次聊了什麼、改到哪裡，它一概不知道。所有「記憶」其實都存在 harness（Claude Code）這一端。

所以當你把權力交給 agent、讓它放手改一堆檔案時，你真正需要的不是「agent 記得」，而是一個能倒帶、能重播的工具。Claude Code 的 rewind 和 resume 就是這個工具。

Rewind：倒帶回去

最簡單的還原方式其實是直接開口：跟 Claude 說 revert that please（把剛才的改動還原）。但更精確、更可控的方式是進入 rewind 模式：

按下 escape 兩次

進入 rewind 模式後，Claude Code 會列出這個 session 的歷史時間點，你可以選擇把狀態還原到其中某一個點。還原時有三種選擇：

選項作用
1. 還原程式碼 + 對話整個 session 回退到該時間點（最常用）
2. 只還原對話對話回退，程式碼保持現狀
3. 只還原程式碼程式碼回退，對話保持現狀

課程示範中，老師最常用的是還原完整的程式碼與對話——直接把 session 倒回編輯發生之前，一鍵回到「沒出事」的狀態。

關鍵 列表最下面一項是「目前狀態」，越往上是越早的狀態。用方向鍵選取、Enter 確認，就能把時間撥回那一點。

Resume：續開 session

Claude Code 會把 session 持久化在本機。也就是說，你可以隨時離開（按 Ctrl-C 兩次退出），之後再用好幾種方式回到同一個 session：

  1. claude resume <uuid>：直接從上次退出時輸出的 UUID 續開
  2. /resume：在新 session 裡用斜線命令挑選歷史 session（甚至可以搜尋）
  3. claude --continue：直接續開最後一個 session

三種方式都會把你帶回離開時的狀態——程式碼、對話、所有進度都在。對比「重新開一個全新的 session 從頭解釋一遍」，這省掉的可不只是打字的時間。

為什麼這對 AFK 很重要

「離線交付」的整個前提是：你走開、agent 放手做、你回來收尾。但萬一你走開期間 agent 改壞了什麼，或你回來想換個方向？你不可能靠「重新講一遍」來恢復——因為上下文早就超過一個 session 能承載的量。

Rewind 讓你能在出錯時倒帶到出事前的點，Resume 讓你能隔天接著做。兩者合起來，就是你對「agent 在你不盯的時候亂搞」的最強保險。

小結

  • LLM 無狀態，記憶全在 harness 端——session 持久化是唯一能倒帶的工具
  • escape 兩次進入 rewind，可選擇還原「程式碼 + 對話 / 只對話 / 只程式碼」
  • Ctrl-C 兩次退出後，用 claude resume、/resume 或 claude --continue 續開
  • Rewind = 出錯時倒帶；Resume = 隔天接著做；合起來 = AFK 的保險
