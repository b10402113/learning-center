用 rewind / resume 回放 session

Step 2/4 · review diff、bash、風險控管

學習目標：用 escape 兩次進入 rewind 模式還原程式碼或對話，並用 /resume 或 claude --continue 續開本機持久化的 session，把 LLM 的無狀態性用 harness 端的 session 持久化補回來。

先建立心智模型：LLM 完全不記得你

這是整個 agent 工作流中最重要的一個心智模型：LLM 本身完全不記得上一次對話。每次你開新 session，context 是空的。你昨天花了三小時教它你專案的架構——今天新開一個 session，它什麼都不記得。

所有「記憶」其實存在 harness（Claude Code）這一端。Session 被持久化在本機的檔案系統裡。所以你真正需要的不是「agent 記得」，而是一個能倒帶、能重播的工具。

Rewind：倒帶到出事前

按 escape 兩次，Claude Code 會進入 rewind 模式。它會列出這個 session 的歷史時間點——最下面是目前狀態，越往上越早。

還原有三種選擇：

選項 還原什麼 最常用場景
還原程式碼 + 對話 兩者都回到該時間點 最常用——改壞了，整體倒回
只還原對話 對話回到該時間點，程式碼保留 想重跑某個 prompt 但保留改動
只還原程式碼 程式碼回到該時間點，對話保留 想保留對話記錄但撤銷改動

選好後用方向鍵 + Enter 確認，就能把時間撥回那一點。最常用的操作就是：把 session 直接倒回編輯發生之前，一鍵回到「沒出事」的狀態。

除了 rewind 模式，你也可以直接跟 Claude 說 revert that please，它會還原剛才的改動。但 rewind 是更徹底的——它可以回到任何歷史時間點，不只是「剛才」。

Resume：隔天接著做

Claude Code 會把 session 持久化在本機。退出（Ctrl-C 兩次）後，你有三種方式續開：

方式 用法 適合場景
claude resume <uuid> 直接續開指定 session 你知道要回到哪個 session
/resume 從歷史清單中挑選，支援搜尋 不記得 session ID，想搜尋
claude --continue 直接回最後一個 session 昨天的工作今天要接著做

三者都回到離開時的狀態：同一個 context、同一個檔案狀態、同一個對話記錄。

對 AFK 的意義

這兩個能力對「離線交付」（AFK）缺一不可：

  • Rewind 讓你在 agent 改壞時倒帶到出事前——你不怕它出錯，因為出錯了可以復原
  • Resume 讓你隔天接著做——你不怕退出，因為退出了可以續開

你之所以敢走開（AFK），除了上一課的 review 閘門，還因為你知道：回來時出什麼事都能倒帶、任何進度都能續開。這就是 LLM 無狀態性的解法——不是讓 LLM 記住你，而是讓 harness 幫你記住。

類比：LLM 是一個完全失憶的天才。每次你見到他，他都不記得你。但你的錄影機（harness）把每次對話都錄下來了。你可以倒帶（rewind）到任何時間點重播，也可以明天把錄影機接上繼續錄（resume）。天才本人失憶，但錄影機幫你記住了一切。
口訣：escape 兩次倒帶，--continue 續開。Rewind 解決「改壞了怎麼辦」，Resume 解決「退出了怎麼辦」。兩者合起來，讓你敢放手 AFK。
