選好你的 agent 與訂閱

Node 1 · process-overview · 用 tiering 原則挑出課程要用的 model

學習目標：用 tiering 原則幫自己的訂閱選出課程要用的 model：用訂閱的預設模型、選 medium effort、避開 Haiku，並理解頂/中/入門三級在各 provider 都成立。

先講大事：重要的不是模型名字，是分級

模型名稱會一直換——課程錄完之後，教練自己也發了一則補充說明：模型變了，但訂閱分層和背後的想法完全沒變。任何 provider 都有三級：一個 Opus 級（頂）、一個中階級（mid tier）、一個很便宜的 Haiku 級（入門）。所以你要記的不是「現在叫什麼名字」，而是「我的訂閱落在哪一級、預設給哪一級」。

用你訂閱的預設模型

在 Claude Code 裡用 /model 可以切換模型。課程的建議很簡單：跟著你訂閱的預設走——因為每個方案的預設模型不同：

  • Max 5x：預設是 Opus 4.6（課程錄製時）
  • Pro：預設是 Sonnet 4.6

不要自己手動去換名字，預設就是你的方案能給的最好平衡。

避開 Haiku，選 medium effort

課程三令五申：不要用 Haiku。它很快，但「就是不夠力」——有些課程工作流它扛不住。速度快不是省錢，是你在花時間跟一個扛不動的模型搏鬥。

Effort 建議選 medium。教練的觀察：harness 一度把 Opus 4.6 的預設調到 high，後來又降回 medium——因為內部評估發現 medium 對大部分工作就夠了。跟著 harness 的預設走即可。

訂閱怎麼選：Max 5x vs Pro

教練無法替你決定價格，但給了你兩個錨點：

  • 課程是用 Max 5x 打造的——如果你想要 Claude 最好的模型（Opus 級），建議至少買一個月 Max 5x。
  • 預算有限的話，Pro + Sonnet 4.6 也能走完課程。不能保證深度挖每一課不會撞到 usage limit，但「Pro 應該過得去」。

口訣：用你訂閱的預設模型，選 medium effort，避開 Haiku；預算夠上 Max 5x，不夠就 Pro + Sonnet。

課程不綁 agent：任何 CLI coding agent 都行

整套流程是 harness-agnostic 的——課程 demo 用 Claude Code，只是因為它流行、又是教練的日常主力。任何跑在 CLI 裡的 coding agent 都能套用同一套七階段流程。沒用過 coding agent 的初學者，教練建議先從 Claude Code 開始。

小結

選型的核心不是記模型名字，而是記 tiering 原則：每個 provider 都有頂/中/入門三級，名字會換、分層不變。用訂閱的預設模型、medium effort、避開入門級。你的決策清單就是：看你的訂閱 → 用它的預設 → 確認 effort 是 medium。
