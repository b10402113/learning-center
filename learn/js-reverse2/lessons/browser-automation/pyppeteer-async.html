Pyppeteer：不必自己管 driver 的非同步瀏覽器操作

Step 5/6 · 瀏覽器自動化與動態渲染

學習目標

用 Pyppeteer 啟動 Chromium、開新分頁、渲染頁面、取得內容，並在頁面內執行 JS 隱藏 webdriver。

前言：有沒有不必管 driver 的辦法？

Selenium 最大的日常麻煩，是那個「驅動程式」：你要自己下載對應版本的 chromedriver，版本對不上就啟動失敗；換一台電腦、換一次 Chrome 更新，就得再處理一遍。而且它的呼叫是同步的，跟你在 asyncio 那節學到的非同步爬蟲接不太起來。

這一節要看的是另一條路：Pyppeteer。它直接用一支 Python 套件驅動 Chromium 瀏覽器，第一次執行如果瀏覽器沒裝，它會自動幫你下載設定好，省掉 driver 的對齊問題；而且它的 API 是基於 async 的，能自然融入非同步流程。把它想成「另一種開瀏覽器的方式」就好，操作邏輯跟 Selenium 很像，但幾個關鍵字不同。

前置條件：Python 3.5 以上（因為用到 async），並且已安裝套件：

pip install pyppeteer

最小迴圈：啟動、開頁、取內容

先看一支能跑的最小程式，目標是把一個用 JavaScript 渲染的頁面抓下來。它做的事跟 Selenium 一樣，只是每一步都掛在 async 上、前面要加 await：

import asyncio
from pyppeteer import launch
from lxml import etree

#创建一个特殊的函数
async def main():
    #对应的pyppeteer相关的操作要写在特殊函数内部
    #1.创建一个浏览器对象
    bro = await launch(headless=True)
    #2.创建一个新的page
    page = await bro.newPage()
    #3.发起请求
    await page.goto('http://quotes.toscrape.com/js/')
    #4.获取页面源码数据
    page_text = await page.content()
    #5.数据解析
    tree = etree.HTML(page_text)
    div_list = tree.xpath('//div[@class="quote"]')
    print(len(div_list))
    await asyncio.sleep(3)
    await bro.close()
#创建一个协程对象
c = main()
#创建且启动事件循环对象
loop = asyncio.get_event_loop()
loop.run_until_complete(c)

逐段對照：launch() 建立瀏覽器物件；newPage() 開一個新分頁（等於在瀏覽器裡新開一個標籤）；goto(url) 叫它跳到目標網址；content() 回傳當前頁面的原始碼，這就是 Selenium page_source 的對應物。前面每一行都加了 await，因為這些動作都是非同步的。最後三行是把協程丟進事件迴圈執行，這正是你在 asyncio 那節學過的啟動方式，這裡原封不動搬過來用。

注意幾件事：過程中你完全沒有設定 driver，也沒有指定瀏覽器路徑，卻達到了跟 Selenium 一樣的渲染效果。content() 拿到的是渲染後的頁面，接著的 XPath 解析也跟以前一模一樣。

啟動參數：把惱人的提示條關掉

launch() 可以吃幾個常用參數：headless 決定要不要開無頭模式（預設是開的，設 False 才會顯示視窗）、executablePath 可以指定一個已有的 Chrome 執行檔、args 則用來傳額外的啟動參數。其中一個很實用的用途，是關掉那個「Chrome 正受到自動測試軟體的控制」提示條：

browser = await launch(headless=False, args=['--disable-infobars'])

這個提示條不影響功能，但它就是一個明顯的破綻，在某些網站上甚至會直接被拿來判斷你是不是自動化。順帶一提，把 headless=False 打開有無頭模式，不是為了好看，而是有些頁面在無頭環境下的行為不同，開著有頭模式比較容易對照排查。

修版面：設定 viewport

有時候打開頁面會發現版面怪怪的：元素擠成一團、跑出預期外的排版。這通常是因為視窗尺寸不對。用 setViewport() 明確指定寬高，就能讓頁面以固定的像素尺寸渲染：

import asyncio
from pyppeteer import launch

width, height = 1366, 768
async def main():
    browser = await launch(headless=False)
    page = await browser.newPage()

    await page.setViewport({'width': width, 'height': height})

    await page.goto('https://www.taobao.com')
    await asyncio.sleep(3)
    await browser.close()
asyncio.get_event_loop().run_until_complete(main())

對照前面的最小範例，這裡只多了一行 setViewport，而且它是放在 newPage() 之後、goto() 之前。順序有差：先設定好視窗，頁面才會用正確的尺寸去排版與判斷（例如某些響應式設計會依寬度決定顯示哪種版型）。

隱藏 webdriver：在頁面內改寫屬性

跟上一節同樣的道理：Pyppeteer 驅動的瀏覽器，window.navigator.webdriver 一樣會是 true，需要處理。Pyppeteer 的作法很直覺，頁面開好之後，用 page.evaluate() 在瀏覽器裡執行一段 JS，把這個屬性的取值改成永遠回傳 false：

import asyncio
from pyppeteer import launch

width, height = 1366, 768

async def main():
    #规避检测
    browser = await launch(headless=False, args=['--disable-infobars'])
    page = await browser.newPage()
    await page.setViewport({'width': width, 'height': height})
    await page.goto('https://login.taobao.com/member/login.jhtml?redirectURL=https://www.taobao.com/')

    #规避检测
    await page.evaluate(
        '''() =>{ Object.defineProperties(navigator,{ webdriver:{ get: () => false } }) }''')
    await asyncio.sleep(20)
    await browser.close()

asyncio.get_event_loop().run_until_complete(main())

Object.defineProperties(navigator, {webdriver: {get: () => false}}) 的意思是：把 navigator.webdriver 這個屬性重新定義成一個 getter，任何人去讀它，拿到的都是 false。這就是上一節那行 JS 的完整寫法。要留意的是，這裡的注入發生在 goto() 之後，跟 Selenium 用 CDP 搶在頁面載入前註冊不同；如果目標網站在頁面最早期就檢查，這種寫法可能來不及，那就要改用更早注入的手段。

節點互動與 selector

互動方式也跟 Selenium 對得上，只是名字不同：輸入用 page.type()、點擊用 page.click()、選取多個元素用 querySelectorAll()。以在百度搜尋為例：

import asyncio
from pyppeteer import launch


async def main():
    # headless参数设为False，则变成有头模式
    browser = await launch(
        headless=False
    )
    page = await browser.newPage()
    # 设置页面视图大小
    await page.setViewport(viewport={'width': 1280, 'height': 800})

    await page.goto('https://www.baidu.com/')
    # 节点交互
    await page.type('#kw', '周杰伦', {'delay': 1000})
    await asyncio.sleep(3)
    #点击搜索按钮
    await page.click('#su')
    await asyncio.sleep(3)
    # 使用选择器选中标签进行点击
    alist = await page.querySelectorAll('.s_tab_inner > a')
    a = alist[3]
    await a.click()
    await asyncio.sleep(3)
    await browser.close()
asyncio.get_event_loop().run_until_complete(main())

page.type(selector, text, {'delay': 1000}) 的第三個參數 delay 是每打一個字的間隔毫秒數；設了它，輸入會像真人一樣一個字一個字打，而不是瞬間填滿，這對某些會檢查輸入節奏的網站有幫助。querySelectorAll() 則回傳符合選擇器的元素列表，可以用索引取出其中一個再操作。它也有對應 XPath 的 page.xpath()，以及簡寫的 J、JJ、Jx。

完整練習：非同步抓網易新聞標題

把上面的零件組起來，就是一支實際的爬蟲。下面這段用 ensure_future 建立任務、用 add_done_callback 掛上解析函式，抓完之後在回呼裡用 XPath 取出標題：

import asyncio
from pyppeteer import launch
from lxml import etree


async def main():
    # headless参数设为False，则变成有头模式
    browser = await launch(
        headless=False,
        #可在浏览器中输入chrome://version/，在页面的"个人资料路径"查看浏览器的执行程序
        executablePath='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
    )
    page = await browser.newPage()

    await page.goto('https://news.163.com/domestic/')

    await asyncio.sleep(3)
    # 打印页面文本
    page_text = await page.content()

    return page_text


def parse(task):
    page_text = task.result()
    tree = etree.HTML(page_text)
    div_list = tree.xpath('//div[@class="data_row news_article clearfix "]')
    for div in div_list:
        title = div.xpath('.//div[@class="news_title"]/h3/a/text()')[0]
        print('wangyi:', title)


tasks = []
task1 = asyncio.ensure_future(main())
task1.add_done_callback(parse)
tasks.append(task1)
asyncio.get_event_loop().run_until_complete(asyncio.wait(tasks))

這裡的流程是：main() 只負責把頁面渲染好並回傳 HTML 字串，parse(task) 從 task.result() 取出這份字串，再用 XPath 解析出每則新聞標題。這種「渲染」與「解析」分工的寫法，讓你之後要同時渲染多個頁面時，可以直接建立多個任務並行處理。

做完會看到什麼

成功的判準跟上一節一樣：程式跑完後，主控台印出一批你要的資料（例如網易新聞的標題），而且跟畫面上看到的一致。差別是你這次完全沒有碰 driver，也沒有手動安裝瀏覽器，還順便讓整段流程相容於非同步。

小結

Pyppeteer 用一支套件直接驅動 Chromium，第一次執行會自動下載瀏覽器，省去管理 chromedriver 的麻煩；它的 API 基於 async，每個操作前要加 await，啟動協程的方式跟 asyncio 一模一樣。核心呼叫是 launch()、newPage()、goto()、content()；用 setViewport() 修版面、args=['--disable-infobars'] 關提示條、page.evaluate() 隱藏 webdriver，互動則用 type／click／querySelectorAll。

到這裡，你手上有 Selenium 和 Pyppeteer 兩把「開真瀏覽器」的刀。但有沒有可能，只在真正需要瀏覽器的環節用它，其餘時間切回輕量的封包請求？下一步要介紹的 DrissionPage 就是把這兩種模式合成一個工具的選擇。
