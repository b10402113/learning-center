前言：伺服器回給你的那一坨，就是 HTML

前面把通道和狀態都講完了，現在回到最實際的問題：伺服器回給你的回應正文，到底是一份什麼東西？答案多半是 HTML 文件。而你之後要抓的標題、連結、圖片、商品價格，全都包在這些標籤裡面。所以認得標籤，等於知道資料可能放在哪裡。

這一節的性質跟前面不同，它偏向「查閱」：把 HTML 的文件骨架、標籤語法和常用標籤整理成表。你不需要現在背下來，之後寫 XPath 或讀原始碼時再回來查即可。

HTML 是什麼

HTML，全名 HyperText Markup Language（超文本標記語言），檔案副檔名是 .html 或 .htm。它是一種用來製作網頁的標準標記語言，寫給瀏覽器看、帶有描述性。注意，它不是程式語言。

它的運作方式很單純：使用者訪問網頁時，其實是把伺服器上的 HTML 文件下載到本機，再由本機瀏覽器依序解釋、渲染成畫面上看到的樣子。而你在網頁上看到的所有資料，都只會寫在標籤之間，或寫在標籤的屬性裡。這句話，就是爬蟲之後定位資料的唯一依據。

文件骨架

任何一個 HTML 頁面都有固定的骨架：

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>123</title>
</head>
<body>
	
</body>
</html>

骨架裡每一段的角色如下：

標籤作用
<!DOCTYPE html>告訴瀏覽器用哪種解析器來解析這份 HTML 文件。
<html>文件的開始與結束標記，宣告這是一份 HTML 文件。
<head>文件開頭的部分。head 裡的內容不會顯示在視窗中，但有特殊意義。
<title>定義網頁標題，顯示在瀏覽器標題列。
<meta charset="UTF-8">宣告文件使用的編碼方式。
<body>之間的文字是網頁真正可見的主體內容。

標籤語法

標籤有兩種寫法：成對的閉合標籤，以及自閉合標籤。

<标签名 属性1=“属性值1” 属性2=“属性值2”……>内容部分</标签名>
<标签名 属性1=“属性值1” 属性2=“属性值2”…… />
規則說明
尖括號包關鍵詞HTML 標籤是由尖括號包住的特定關鍵詞。
閉合 vs 自閉合標籤分成閉合標籤與自閉合標籤兩種。
不分大小寫HTML 不區分大小寫，<DIV> 與 <div> 視為相同。
屬性可有可無標籤可以有若干屬性，也可以完全不帶屬性，例如 <head>。

區塊級與行內標籤

標籤大致可分兩類，這對判斷版面上的資料怎麼排很有幫助：

類型排版行為
區塊級標籤（block）獨占一行，以另起一行開始渲染。
行內標籤（inline）按文本內容占位，不需另起一行。

常用標籤

標籤用途常用屬性
<h1>～<h6>標題，數字越小字越大—
<p>段落—
<br/>強制換行—
<b>、<strong>粗體文本—
<em>、<i>斜體文本—
<del>刪除線文本—
<div>區塊級容器，本身沒有實際意義，靠 CSS 給樣式style、class、id
<span>行內容器，本身沒有實際意義，靠 CSS 給樣式style、class、id
<a>超連結，指向另一個網頁、位置、檔案或郵件地址href、title、target
<img>圖片src、alt、width、height、border、title
<ul>、<ol>無序／有序清單ul 用 type、ol 用 start
<li>清單中的一項—

超連結與圖片：爬蟲最常取的兩個標籤

<a> 的 href 是最重要的屬性，規定點擊後要跳到的目標；title 提供滑過去的提示文字；target 決定在新分頁開啟（_blank）還是覆蓋目前視窗（_self，預設值）。

<img> 的 src 指定圖片的 URL，alt 是圖片載入失敗時顯示的替代文字，另外 width、height、border、title 分別控制寬、高、邊框與提示文字。圖片也可以搭配 <a> 做成可點擊的連結。

表格標籤

網頁的表格和試算表一樣有行有列：用 <table> 定義整張表，<tr> 定義一行，<td> 定義一格。數一個 table 裡有幾對 tr，就知道有幾行；數一個 tr 裡有幾對 td，就知道有幾欄。

標籤作用常用屬性
<table>整張表格border、width、height、align、bgcolor、cellpadding、cellspacing
<tr>一行height、align、bgcolor
<td>一個儲存格（th 也是儲存格）rowspan（合併列）、colspan（合併欄）、align、valign

表單標籤

表單用來收集使用者輸入並送到伺服器，是瀏覽器與伺服器傳遞資料的橋樑。整份表單被 <form> 包住，內部再放各種表單元素。

屬性值說明
action伺服器端處理程式的 URL表單資料要送到哪裡
methodpost、get（預設值）表單資料的送出方法
target同超連結的 target 屬性送出時 URL 的開啟方式
enctypeapplication/x-www-form-urlencoded（預設）、multipart/form-data、text/plain送出資料的編碼方式，檔案上傳必須用 multipart/form-data

常見的表單元素包括文字框、密碼框、多行文字框、核取方塊、選項按鈕、下拉選單、檔案上傳框，以及送出／重設按鈕。課程提供一份 test.html 當練習場，內容是一張登入表單，之後解析練習會用到它：

<form action="#" method="post">
        <label>用户名：</label>
        <input type="text" name="username"/><br/>
        <label>密码：</label>
        <input type="password" name="password"/><br/>
        …
        <input type="submit" value="提交">
        <input type="reset" value="重置">
    </form>

檔案上傳的寫法略有不同，必須把表單編碼指定成 multipart/form-data，因為檔案的二進位資料要用這種方式送出：

<form action="#" method="post" enctype="multipart/form-data">
    <input type="file">
    <input type="submit" value="上传文件">
</form>

多媒體標籤

標籤用途常用屬性
<video>嵌入影片src、controls（顯示播放控制項）、autoplay（自動播放）、loop（循環次數）、width、height
<audio>嵌入音訊同上

想要抓的資料去找哪個標籤／屬性

小結

HTML 是一份描述性的標記語言，瀏覽器把它渲染成你看見的網頁，而所有資料都只存在於標籤之間或屬性之中。文件有固定的骨架，標籤有閉合與自閉合兩種寫法，也分區塊級與行內。爬蟲要抓的連結、圖片、表格欄位與表單參數，分別對應到 href、src、tr/td 與 action/method 這些位置。

到這裡，這個節點的四步就走完了：你知道爬蟲是用 HTTP 模擬瀏覽器的客戶端、讀得懂請求與回應訊息、說得出 Cookie 怎麼維持狀態，也認得 HTML 裡資料藏在哪。下一步會把鏡頭拉遠，畫出「抓取 → 反爬 → 逆向」的整張地圖，看看這些基礎位在整條路線的哪個起點。
