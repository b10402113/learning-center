Proxy 處理器全覽：六個 trap 各攔什麼

Step 5/5 · Hook 與 Proxy 攔截

學習目標

查得到六個 handler trap（get／set／getOwnPropertyDescriptor／defineProperty／apply／construct）各自攔什麼、參數是什麼、最小範例長什麼樣。

前言

Proxy 的處理器（handler）是一組 trap 的集合，每個 trap 對應一種操作。這一頁不是要教你原理，而是一份查閱用的目錄：當你在逆向時遇到某種寫法，回來查它對應哪個 trap。

上一節你只用了 get 與 set。但網站讀寫屬性的方式不只一種：有些用屬性描述符（Object.getOwnPropertyDescriptor、Object.defineProperty），有些則是把「函式本身」當物件來代理，攔它的呼叫或 new。這些都各有一個 trap 等著你。

Trap 一覽表

trap攔截的操作參數對應的 Reflect
get讀取屬性 obj.p(target, p, receiver)Reflect.get(target, p)
set設定屬性 obj.p = value(target, p, value, receiver)Reflect.set(target, p, value)
getOwnPropertyDescriptorObject.getOwnPropertyDescriptor(obj, p)(target, p)Reflect.getOwnPropertyDescriptor(target, p)
definePropertyObject.defineProperty(obj, p, descriptor)(target, p, descriptor)Reflect.defineProperty(target, p, descriptor)
apply呼叫函式 f(...)(target, thisArg, argList)Reflect.apply(target, thisArg, argList)
construct用 new 建立物件 new F(...)(target, argArray, newTarget)Reflect.construct(target, argArray, newTarget)

get 與 set

攔截屬性的讀取與設定。用在補環境時，是所有 trap 裡最常派上用場的兩個。

var User = {
    username: "bobo",
    age: 20
}
User = new Proxy(User, {
    get(target, p, receiver) {
        console.log(`获取属性${p}操作`)
        return Reflect.get(target, p);
    },
    set(target, p, value, receiver) {
        console.log(`设置属性${p}操作`)
        Reflect.set(target, p, value);
    }
});

參數：target 是被代理的物件、p 是屬性名、receiver 是代理後的物件，value 是要寫入的值。

getOwnPropertyDescriptor

攔截透過屬性描述符取得屬性值的操作。有些網站的 JS 不是用 obj.p 讀屬性，而是走 Object.getOwnPropertyDescriptor，就要靠這個 trap 才看得到。

var User = {
    username: "bobo",
    age: 20,
    address:"Bj"
}

User = new Proxy(User, {
    get(target, p, receiver) {
        console.log(`获取属性${p}操作`)
        return Reflect.get(target, p);
    },
    set(target, p, value, receiver) {
        console.log(`设置属性${p}操作`)
        Reflect.set(target, p, value);
    },
    getOwnPropertyDescriptor(target, p){
        let result;
        result = Reflect.getOwnPropertyDescriptor(target, p);
        console.log(`通过属性描述符获取属性${p}操作`)
        return result;
    }
});

//测试
console.log(User.username);
User.age = 30;
console.log(Object.getOwnPropertyDescriptor(User, "address").value);

參數：target 是被代理的物件、p 是屬性名。回傳值是一個屬性描述符物件。

defineProperty

攔截透過屬性描述符定義屬性的操作，對應 Object.defineProperty。

var Person = {};

Person = new Proxy(Person, {
    get(target, p, receiver) {
        console.log(`获取属性${p}操作`)
        return Reflect.get(target, p);
    },
    set(target, p, value, receiver) {
        console.log(`设置属性${p}操作`)
        Reflect.set(target, p, value);
    },
    getOwnPropertyDescriptor(target, p){
        let result;
        result = Reflect.getOwnPropertyDescriptor(target, p);
        console.log(`通过属性描述符获取属性${p}操作`)
        return result;
    },
    defineProperty: function (target, p, descriptor){
        console.log(`通过属性描述符设置属性${p}操作`)
        let result;
        result = Reflect.defineProperty(target, p, descriptor); 
        return result;
    }
    
});

// 通过属性描述符给Person对象定义一个name属性
Object.defineProperty(Person, 'name', {
      value: 'Bobo',
      writable: true, // 允许修改属性值
      enumerable: true, // 允许枚举属性
      configurable: true // 允许删除或修改属性描述符
    }
);
console.log(Person)

參數：target 是被代理的物件、p 是屬性名、descriptor 是屬性描述符物件（可含 value、writable、enumerable、configurable 等欄位）。回傳布林值，代表是否設定成功。

apply

攔截函式被呼叫。這裡的目標物件是一個函式，apply 會在它被呼叫時執行。

add = function(a,b){
    console.log("add函数正在被调用");
    return a+b;
}
add = new Proxy(add, {
    apply:function (target, thisArg, argList){
        // target: 函数对象。thisArg: 调用函数的this指针。argList:函数参数数组
        let result;
        result = Reflect.apply(target, thisArg, argList);
        console.log(`${target.name}函数被调用，参数为:${argList}`);
        return result;
	}
});
add(1,2);

參數：target 是函式物件、thisArg 是呼叫時的 this、argList 是參數陣列。

construct

攔截 new 關鍵字。用 new 建立物件，就是在呼叫該物件的建構方法，這個 trap 專門攔這件事。

function Animal(){
    
}
Animal = new Proxy(Animal, {
	construct:function (target, argArray, newTarget) {
    //target: 函数对象。argArray: 参数列表。newTarget: 代理后的对象
    let result = Reflect.construct(target, argArray, newTarget);
        
    console.log(`${target.name}对象被创建`);
    return result;
	}
});
animal = new Animal();

參數：target 是函式物件、argArray 是參數列表、newTarget 是代理後的物件。

小結

處理器裡每個 trap 對應一種操作：get／set 攔一般屬性的讀寫；getOwnPropertyDescriptor／defineProperty 攔走屬性描述符的存取與定義；apply 攔函式呼叫、construct 攔 new。每個 trap 都要用對應的 Reflect.* 把操作交還給目標物件，參數依序是目標物件、屬性（或參數）與代理物件。

到這裡，這個節點的工具就備齊了：hook 用來攔單一函式或屬性，Proxy 用來盯整個物件的讀寫並找出補環境的缺口，還有對付 toString 檢測的那一層偽裝。實際面對目標站時，這幾招經常會一起用：先用 Proxy 找出它讀了哪些屬性，再用 hook 針對關鍵的原生 API 抓出輸入輸出。
