第一支 requests：GET、響應物件與存檔

Step 1/5 · requests 入門與動態資料定位

學習目標

用 requests.get 完成第一次抓取並存檔，讀懂回傳的響應物件（status_code、text）與四步流程在程式碼裡的對應位置。

前言：先讓程式抓到第一個檔案

你已經知道爬蟲的骨架是「指定 URL、發送請求、取得響應、持久化」四步，但那時候我們的重點是那張地圖，還沒真的把工具拿起來。這一節要做的，就是讓你把第一支程式跑起來，親眼看到一個網頁被寫進你電腦裡的檔案。

先動手寫第一支，好處是接下來所有進階技巧都有地方可以掛。不論是編碼、偽裝身分還是抓動態資料，講到底都只是在同一個骨架上補東西；你只要認得每一步是做什麼的，後面就都是往對應的格子裡加料。

前置條件：本機已安裝 Python。若還沒安裝過 requests，先在終端機裝起來，它是一個第三方模組，不會跟 Python 一起附帶。

安裝 requests

pip install requests

# 可以使用清华源安装
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple

第一行是標準安裝；第二行是當你連官方來源很慢時，改走清華大學的鏡像來源。裝好之後，import requests 就能用了。

第一步到第四步：一個能跑的最小範例

以東方財富首頁為例。下面這段程式把四步依序做了一次，註解標了每一步的位置：

import requests
# 1. 指定服务器的URL
url = 'https://www.eastmoney.com/'

# 2. 发送请求:根据指定的url发送get请求，得到响应对象
response = requests.get(url)

# 查看响应状态码
# print(f'响应状态码：{response.status_code}')

# 3. 获取响应数据
data_str = response.text  # text 字符串形式的响应数据【html响应文件】
# print(type(data_str))
# print(data_str)

# 4. 持久化存储
with open('caifu.html',mode='w',encoding='utf-8') as f:
    f.write(data_str)
print('数据爬取结束！')

逐段看。url = '...' 是第一步，決定要打哪個網址。requests.get(url) 是第二步，它會送出一發 GET 請求，並回傳一個「響應物件」，這裡存進變數 response。第三步是 data_str = response.text，把 HTML 以字串形式從響應物件裡取出來。最後的 with open(...) 是第四步，把這個字串寫進專案目錄下的 caifu.html。跑完之後，你應該會在資料夾裡看到它。

響應物件裡有什麼：status_code 與 text

requests.get 交回來的不是一個字串，而是一個「響應物件」。你可以把它想成一張收據，上面記著這次請求的各種結果，而我們每次都是從這張收據裡挑需要的欄位。

最該先檢查的是 response.status_code。它是伺服器回應的狀態碼，200 代表這次請求成功、內容拿到了；4 開頭通常是你這邊的問題（例如 404 找不到頁面），5 開頭則是對方的伺服器出錯。先把這行印出來，你才知道自己拿到的到底是不是正常內容，而不是一頁錯誤訊息。

確認狀態碼沒問題後，才輪到內容。HTML 網頁用 response.text 取，拿到的是字串。這裡先建立一個觀念：.text 不是唯一取法，回應是什麼型別，就用對應的方法取；取錯方法就會拿到一團看不懂的東西。這個對照表會在這個節點的最後一步完整展開，現在先記住 HTML 用 .text 就好。

第四步的小細節：為什麼存檔要指定編碼

你可能注意到 open 裡多寫了 mode='w',encoding='utf-8'。mode='w' 是「寫入」模式，會建立檔案並覆蓋舊內容；encoding='utf-8' 則是告訴 Python 用 UTF-8 把字串寫進檔案。如果不指定，不同系統的預設編碼不一致，存出來的檔案就可能在別台電腦上變成亂碼。

要注意的是，這裡指定的編碼管的是「寫檔」這一步。如果亂碼是在第三步 response.text 就已經產生，那問題不在存檔，而在回應解碼，得換另一個地方修，那是下一步要處理的事。

小結

四步流程在程式碼裡各有位置：第一步行 url = ...、第二步行 requests.get(url)、第三步行 response.text、第四步行 with open(...)。requests.get 回傳的響應物件先看 status_code 確認成功，再用對應方法取出內容；HTML 用 .text，寫檔時記得指定 encoding='utf-8'。
