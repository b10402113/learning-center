摘要演算法：MD5 與 SHA 家族

Step 4/5 · 編碼與摘要：URL、Base64、MD5/SHA

學習目標

說明摘要演算法不可逆、定長、決定性的三個特徵，並用 Python 的 hashlib 重現 MD5 與 SHA，以及加鹽的寫法。

前言：那 32 個字元，為什麼解不回來

你抓包看到登入請求裡有個 pwd 欄位，值是 e10adc3949ba59abbe56e057f20f883e，剛好 32 個字元，全是十六進位。你想著「這大概是密碼被藏起來了」，於是拿各種解碼器輪番上陣：Base64 解出來是亂碼，URL 解碼沒反應。因為這段東西從一開始就不是「編碼」，而是「摘要」，它天生就設計成解不回去。

前面兩節的 URL 編碼和 Base64 都是可逆的，目的是「換一種安全的形式搬運」。摘要演算法（hash，雜湊）的目的完全不同：它把任意長度的輸入，壓成一小段固定長度的指紋，而且刻意讓這個過程單向不可逆。這正是它能拿來當簽名、存密碼的原因。這一節要建立的，就是「看到一段摘要時，該去想什麼」的直覺。

摘要什麼時候會出現

在爬蟲與逆向的世界裡，摘要幾乎無所不在。最常見的是 sign 參數：網站把一串規則拼好的參數（例如按字母排序、加上一個固定密鑰）餵進 MD5 或 SHA，吐出一段十六進位，伺服器收到後用同樣規則重算一次來比對，就知道這個請求有沒有被竄改。另一種是拿來存密碼，資料庫只存摘要，不存明文。還有一種是校驗檔案有沒有被改過。

這些用途都建立在摘要的三個性質上：不可逆、定長、決定性。以下逐一拆開。

性質一：不可逆

摘要演算法是單向的。你可以把明文算成摘要，卻沒辦法從摘要還原出明文，就算你知道對方用的是 MD5，也算不回去。原因是這個過程把大量資訊壓縮掉了：不管輸入是 6 個字元還是 6 GB，輸出都是固定幾十個字元，資訊只進不出。

不過，「不可逆」不等於「打不破」。如果原始輸入是一個弱密碼（例如 123456），攻擊者可以拿常見密碼一個一個算摘要、做成對照表來比對，這叫撞庫或彩虹表。所以網站通常會加鹽（salt），在密碼前面或後面再接一段額外的字串，讓同一組密碼在每個網站算出來都不一樣，提高破解成本。

性質二：定長

不同長度的輸入，輸出長度永遠固定。同一個演算法不會因為輸入變長，輸出也跟著變長。不同演算法的固定長度如下：

演算法輸出位元十六進位字元數
MD512832
SHA-116040
SHA-25625664
SHA-512512128

這張表是實戰最有用的線索。當你在封包裡看到一段十六進位是 32 個字元時，第一個該懷疑的就是 MD5；看到 40 個字元，先想 SHA-1。長度本身就是密碼學留下的指紋。

性質三：決定性

同一個輸入，永遠算出同一個摘要。今天算、明天算、換一台電腦算，結果都一模一樣。反過來說，只要輸入有一點點不同，輸出就會差非常多，哪怕只差一個空格，整段摘要也會面目全非。這條性質讓摘要成為「一致性檢查」的好工具：只要比對摘要，就知道兩份資料是不是完全相同。

在 Python 裡重現 MD5

Python 的 hashlib 提供了這些演算法。用法有兩種：一種是一次把整段資料丟進去算完；另一種是先建立物件、再一段一段 update() 餵資料，適合資料很大、要分次讀取的情況。下面這段程式碼示範加鹽的寫法，先在建構時餵入一段固定的鹽，再把真正的密碼 123456 交給 update()：

from hashlib import md5, sha1, sha256, sha512

data = "123456"
m = md5("yuanLaoShiDaShuaiGe".encode())
m.update(data.encode())  # data字节
…
print(m.hexdigest())  # b7a4250495541312d48fc1553e40b0a0

這裡的鹽 yuanLaoShiDaShuaiGe 讓 123456 算出的結果不再是常見的 e10adc3949ba59abbe56e057f20f883e，而是 b7a4250495541312d48fc1553e40b0a0。也就是說，同樣的密碼在不同網站（不同鹽）會得到完全不同的摘要。

update() 是可以累加的：先餵一段、再餵一段，等於一次餵進它們串接起來的內容。下面的程式碼先 update("123 ")（注意結尾有一個空格）再 update("456")，結果等同於直接算 "123 456"：

data = "123 "
data2 = "456"
m = md5("yuanLaoShiDaShuaiGe".encode())
m.update(data.encode())  # data字节
m.update(data2.encode())  # data字节

print(m.hexdigest())
print(m.digest())

這段程式碼同時示範了兩種輸出：hexdigest() 回傳十六進位字串，就是你在封包裡看到的那種；digest() 回傳原始位元組，用在需要把摘要當二進位資料繼續處理的時候（例如接進下一層加密）。

換成 SHA 也是同一套

把上面的 md5 換成 sha1、sha256 或 sha512，用法完全一樣，只是輸出長度不同。也就是說，你在 JS 原始碼裡看到 CryptoJS.MD5(...) 就對應到 hashlib.md5，看到 CryptoJS.SHA1(...) 就對應到 hashlib.sha1。逆向時的重點通常不是演算法本身，而是「輸入字串是怎麼拼出來的」。

小結

摘要演算法把任意長度的輸入壓成固定長度的指紋，具備三個性質：不可逆（算不回明文）、定長（MD5 是 32 個十六進位、SHA-1 是 40 個）、決定性（同輸入永遠同輸出）。Python 用 hashlib 操作，hexdigest() 取十六進位字串、digest() 取原始位元組，update() 可以分段累加。實戰中它是 sign 參數與密碼儲存的主力，辨識它的第一條線索就是長度。
