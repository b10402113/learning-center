用 lxml 建立解析物件並定位標籤

Step 2/5 · XPath 與資料解析

學習目標

能把頁面原始碼載入 lxml 的 etree 物件，並用 XPath 的絕對／相對、屬性、索引、階層四種表達式精準定位標籤。

前言：知道要定位，但工具還沒裝

上一節確定了方向：解析要做兩件事，先定位標籤，再從標籤取值。可是「定位」聽起來像是一個動作，實際上你得先有一個能聽懂 XPath 的物件。你手上只有 requests 抓回來的一串字，它對程式來說就只是一段文字，不是一棵可以被搜尋的樹。

這一節先把這個落差補上。做完之後你會得到一個可執行的流程：把原始碼載入 etree 物件，然後對它下 XPath 表達式，拿回你指定的標籤清單。這是之後每一種爬取案例都會重複的起點，所以值得先在一個乾淨的小頁面上練熟。

前置條件：安裝 lxml

Python 標準庫沒有現成的 XPath 工具，要先用 pip 裝 lxml：

pip install lxml -i https://pypi.tuna.tsinghua.edu.cn/simple

lxml 是 Python 對 libxml2 的封裝，速度快，也是之後 Scrapy 底層在用的解析引擎。裝好之後，所有操作都從 from lxml import etree 開始。

兩個準備動作：載入，然後下表達式

XPath 解析的編碼流程只有兩步。第一步，建立一個 etree 物件，把即將被解析的頁面原始碼載入進去。第二步，呼叫這個物件的 xpath() 方法，配上不同形式的表達式，去定位標籤、提取資料。下面是原始碼裡的最小示範：

from lxml import etree
#1.创建一个etree类型的工具/对象,把被解析的页面源码数据加载到该对象中
tree = etree.parse('./test.html')
#2.调用etree对象的xpath函数，结合不同xpath表达式进行标签定位和数据提取
#标签定位的xpath表达式：
#定位meta标签
# ret = tree.xpath('/html/head/meta')[0]
# ret = tree.xpath('//meta')[0] #从相对位置定位meta标签
#定位所有的div标签
# ret = tree.xpath('//div')
#索引定位:想要定位到第一个div标签(下标是从1开始)
# ret = tree.xpath('//div[1]')
#属性定位：定位到class属性值为song的div标签://tagName[@attrName="attrValue"]
# ret = tree.xpath('//div[@class="song"]')
#层级定位：定位所有li标签下的a标签
# ret = tree.xpath('//div[@class="tang"]/ul/li/a')
# ret = tree.xpath('//div[@class="tang"]//a')
# print(ret)

注意一件事：原始碼裡把每一條定位都「註解起來」當範例。你實際使用時，就是把某一行的 # 拿掉，只留你要的那條。每一次 tree.xpath(...) 都回傳一個列表，裡面裝著所有符合條件的標籤。

載入的兩種方式：讀檔案，還是讀字串

載入物件有兩種常見寫法，差別在資料從哪來：

寫法資料來源時機
etree.parse('./test.html')本機的 HTML 檔案練習、離線分析一份存下來的頁面
etree.HTML(page_text)記憶體裡的 HTML 字串爬蟲即時抓回來、還沒存檔的頁面

爬蟲實戰幾乎都用第二種，因為你要解析的是 response.text。以下是碧血劍案例裡把它接起來的片段：

response.encoding = 'utf-8'
page_text = response.text
tree = etree.HTML(page_text)
li_list = tree.xpath('/html/body/div[2]/div[1]/main/ul/li')

etree.HTML() 會把一段可能殘缺的 HTML 字串補成完整的樹。之後你在爬蟲裡看到 etree.HTML(page_text)，就知道它正準備把抓回來的頁面交給 XPath。

定位標籤的四種表達式

拿下面這個網頁當靶場。它是一份刻意設計過的練習頁，裡面有兩個 div，其中一個 class 是 song、一個是 tang：

<div class="song">
	<p>李清照</p>
	<p>王安石</p>
	<p>苏轼</p>
	<p>柳宗元</p>
	<a href="http://www.song.com/" title="赵匡胤" target="_self">
		<span>this is span</span>
		宋朝是最强大的王朝，不是军队的强大，而是经济很强大，国民都很有钱</a>
	<a href="" class="du">总为浮云能蔽日,长安不见使人愁</a>
	<img src="http://www.baidu.com/meinv.jpg" alt="" />
</div>

有了這棵樹，定位的方式可以分成四類：

1. 絕對路徑與相對路徑：`/` 對 `//`

絕對路徑從根節點 html 開始，一層一層往下寫，例如 /html/head/title 表示「html 下面的 head 下面的 title」。相對路徑則用 // 開頭，代表不管它在哪一層，只要名字對就找出來，例如 //title 會抓出頁面裡所有的 title。原始碼的說明是：/ 表示一個層級，// 表示多個層級。

兩者的差別在於「精確」與「容錯」的拉扯。絕對路徑很精確，但只要網站改一個 wrapper，它就整條失效；相對路徑比較耐改，但範圍太寬時會撈到你不要的標籤，所以要靠屬性把它收緊。

2. 屬性定位：用 `[@attr="值"]` 挑出特定標籤

當頁面上有很多同名標籤時，屬性是最好用的篩子。語法是 //tagName[@attrName="attrValue"]，例如 //div[@class="song"] 就只挑 class 為 song 的那個 div。

3. 索引定位：用 `[n]` 挑第幾個

想要一堆同名標籤裡的特定一個，就用索引，例如 //div[1] 取第一個 div。這裡有一個常踩的坑：XPath 的索引從 1 開始，不是 0。寫 //div[0] 不會拿到第一個，只會空手而回。

4. 階層定位：把上面幾種串起來

實戰很少只用一種，通常是把屬性與階層串成一條路徑。以下兩條的目標都是 div.tang 底下的 a 標籤，但寫法不同：

a_list = tree.xpath('//div[@class="tang"]/ul/li/a')
a_list = tree.xpath('//div[@class="tang"]//a')

第一條用 / 逐層指定「tang 的 ul、ul 的 li、li 的 a」，路徑必須完全吻合；第二條用 // 表示「tang 底下不管幾層的 a 都算」，範圍比較大。選哪一條，取決於你要精準框住結構，還是要容忍中間多一層少一層。

動手之後你會看到什麼

如果你把上面的片段跑起來，每一個 xpath() 回傳的都是列表。定位標籤時，列表裡裝的是 Element 物件；如果只想看第一個，就在後面接 [0]。這一節的驗收標準很具體：你能對一份陌生的 HTML，挑出正確的屬性、階層與索引，讓 xpath() 回傳你想要的那一串標籤。至於怎麼把標籤裡的文字和屬性拿出來，是下一節的事。原理只要知道「回傳的是標籤不是資料」就夠了。

小結

XPath 解析先後做兩件事：用 etree.parse() 讀本機檔、或 etree.HTML() 讀頁面字串，把 HTML 載入成 etree 物件；再呼叫 xpath() 下表達式。定位有四種基本功：/ 與 // 控制跨幾層，[@attr="值"] 用屬性篩選，[n] 取第 n 個（從 1 起算），三者可以串成階層路徑。

定位完成，你手上拿到的還是一堆標籤物件，不是可用的資料。下一節要處理的就是這個落差：把標籤裡的文字與屬性實際取出來，並學會在一堆標籤裡用 ./ 做局部解析。
