<LearningGoal>
拿到一份打包檔時，能判斷它屬於陣列、物件（hash key）或多檔 JSONP 哪一型，並說出各型的模組 id 長什麼樣、該從哪裡接上 require 函式。
</LearningGoal>

## Lesson

判斷型態先看 IIFE 尾端傳入的容器：`[` 是陣列版（數字索引）、`{` 是物件版（字串 hash key）、`[]` 加上檔案內有 `webpackJsonp` 是多檔版（模組由別的檔案 push 進來）；再用模組 id 是數字還是字串，決定呼叫時要報什麼 key。
