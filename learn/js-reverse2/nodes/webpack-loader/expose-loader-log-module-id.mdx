<LearningGoal>
把 bundle 內的 require 函式接到 `window.loader`、在模組執行處插一行 `console.log` 印出模組 id，再用 `window.loader(id)` 逐一呼叫模組，直到鎖定產生簽名參數的那一個。
</LearningGoal>

## Lesson

先確認或補上 `window.loader = n` 把 require 函式露出，再在「模組即將被執行」的前一行插 `console.log("moduleID:::", r)` 記錄模組 id，最後用 `window.loader(id)` 逐一呼叫，靠「報哪個 id 就印哪個 id」的對應關係鎖定簽名模組。
