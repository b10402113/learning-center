<LearningGoal>
面對一段陌生字串，依長度與字母表判斷它是 URL 編碼、Base64（標準或 URL-safe）還是十六進位摘要，並選對還原方式。
</LearningGoal>

## Lesson

判型看字母表與長度兩件事：有 %XX 是 URL 編碼、字元落在 A-Z a-z 0-9 + / 且長度是 4 的倍數是標準 Base64、出現 - 或 _ 是 URL-safe、只有 0-9 a-f 且長度是 32／40／64／128 就偏向十六進位摘要（不可逆、該重算而非還原）；但要記得長度是 4 的倍數不代表就是 Base64，解出一層也不代表結束。
