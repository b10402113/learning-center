<LearningGoal>
辨識並還原 URL-safe Base64（- 與 _）與 data:image/...;base64, 圖片，並補上長度不足 4 的 = 之後正確解碼。
</LearningGoal>

## Lesson

URL-safe Base64 只是把標準字母表的 + 換成 -、/ 換成 _，解碼前先 replace 回標準字母表、需要時補 = 再 b64decode；Data URI 圖片則先切掉 data:image/...;base64, 前綴、取逗號後的內容，解碼成位元組後用 "wb" 寫檔。
