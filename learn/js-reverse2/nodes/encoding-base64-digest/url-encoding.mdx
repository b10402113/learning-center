<LearningGoal>
看得懂查詢字串裡的 %XX 形式，並用 Python 的 quote / unquote / urlencode 還原與重建 URL 參數。
</LearningGoal>

## Lesson

查詢字串用 &、=、? 這些保留字切分參數，所以值裡的保留字、空格與中文都要先做百分比編碼（% 加上該字元 UTF-8 位元組的十六進位，例如 & 是 %26、苑 是 %E8%8B%91）；Python 用 quote／unquote 處理單一值、urlencode 處理整個字典，只有在要跟 JS 簽名輸入逐字對齊時才需要手動編碼。
