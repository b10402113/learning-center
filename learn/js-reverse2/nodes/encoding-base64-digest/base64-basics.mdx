<LearningGoal>
說出 Base64 的字母表與 3 位元組轉 4 字元的分組規則，並用 Python 的 b64encode / b64decode 完成編碼與解碼。
</LearningGoal>

## Lesson

Base64 用 A-Z a-z 0-9 + / 這 64 個安全字元，把任意位元組每 6 個 bit 一組重新表示，每 3 個位元組換 4 個字元、尾端用 = 補到 4 的倍數（you 是 eW91）；它是可逆的編碼、不是壓縮也不是加密，Python 用 b64encode／b64decode 處理，輸出長度一定是 4 的倍數。
