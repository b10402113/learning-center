<LearningGoal>
說出瀏覽器加密 JS 在 Node 執行失敗的兩個根因（頂級物件不同、Node 專屬識別字外洩），並認出「補環境」要解決的正是這件事。
</LearningGoal>

## Lesson

瀏覽器 JS 搬進 Node 會壞，根因有二：頂級物件不同（瀏覽器是 `window`、Node 是 `global`，所以 `window`、`document` 在 Node 不存在），以及 Node 專屬識別字（`process`、`global`、`Buffer` 等）會讓「你是不是 Node」的檢測抓到證據；補環境就是補前者、清後者，把環境餵得像瀏覽器，而非重寫演算法。
