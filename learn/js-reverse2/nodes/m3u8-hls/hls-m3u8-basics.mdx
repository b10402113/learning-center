<LearningGoal>
能說明 HLS 為什麼把影片切成 TS 分片，並從一份 M3U8 播放清單讀出每個欄位代表什麼。
</LearningGoal>

## Lesson

HLS 把影片切成幾秒一段的 TS 分片，再用一份純文字的 M3U8 清單列出播放順序，讓播放器邊下載邊播放；清單中以 `#` 開頭的都是標籤，只有不以 `#` 開頭的行才是真正的 TS 分片位址。
