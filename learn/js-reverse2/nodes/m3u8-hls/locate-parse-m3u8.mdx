<LearningGoal>
能在播放頁的封包裡找到 M3U8 檔案，並把清單中所有 TS 分片位址解析成一份可直接下載的 URL 清單。
</LearningGoal>

## Lesson

在播放頁的封包裡搜尋 `m3u8` 定位清單，抓回文字後逐行跳過 `#` 標籤、只取非 `#` 開頭的分片位址，再把相對路徑接成完整網址，得到可直接下載的 `ts_url_list`。
