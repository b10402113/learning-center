<LearningGoal>
帶著 cookie 與查詢資料重放第二次請求，跑分頁迴圈取回資料，並在每頁結束清 cookie、整套重跑。
</LearningGoal>

## Lesson

重放就是「同一個端點＋查詢資料＋cookie2」——criteriaJson 整串照抄、session 自動帶上兩組 cookie、resultList 雙重編碼解兩次——分頁迴圈每頁把五段整套重跑，結束清 cookie、頁間停一秒，因為 cookie2 是一次性消耗品。
