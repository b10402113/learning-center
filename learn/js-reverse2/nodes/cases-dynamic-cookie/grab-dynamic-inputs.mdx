<LearningGoal>
用 XPath 從第一發回應抓出 meta content、ts 腳本內文與 auto 腳本三件套，並理解三者每次請求都會變、不能寫死。
</LearningGoal>

## Lesson

三件套藏在第一發回應的三個位置——第二個 meta 的 content 屬性、第一段 script 的內文（ts 腳本）、帶 src 的外部 script（補網域再下載原文）——三條 XPath 就能挖齊，但它們每次請求都變、不能寫死，位置式 XPath 也會隨改版失效。
