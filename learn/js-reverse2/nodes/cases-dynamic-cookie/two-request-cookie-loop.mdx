<LearningGoal>
說出「抓動態輸入→注入→執行 JS→取得 cookie→帶資料重放」的五段迴圈，並解釋為什麼第一發請求拿不到資料。
</LearningGoal>

## Lesson

動態 cookie 站台把資料鎖在第二次請求後面：第一發只拿得到 cookie1 與三件套（meta content、ts 腳本、auto 腳本），三件套每次請求都不同，注入補好環境的 JS 才算出 cookie2，帶著它與查詢資料重放才回資料——整條流程就是「抓動態輸入→注入→執行 JS→取 cookie→帶資料重放」的五段迴圈。
