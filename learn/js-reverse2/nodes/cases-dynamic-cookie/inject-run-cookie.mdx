<LearningGoal>
把三件套字串替換進補好環境的 JS 模板佔位符，用 execjs 呼叫 get_cookies，並解析出要帶走的 cookie 鍵值。
</LearningGoal>

## Lesson

注入是純字串替換——佔位符在模板裡長什麼樣，replace 的第一個引數就要長什麼樣（meta_content 裸名、'ts_js' 連引號）——替換後整份腳本交給 execjs 編譯、呼叫入口 get_cookies（Python call 的函式名就是 VM/TS 腳本的入口），再從 document.cookie 字串取第一對鍵值寫進 session。
