# 編碼與摘要：URL、Base64、MD5/SHA

## Learning goal

依長度／字母表辨識 Base64（含 URL-safe 與圖片 Data URI）與雜湊（MD5/SHA），並用 Python 重現驗證。

## Steps

1. [[learn/js-reverse2/nodes/encoding-base64-digest/url-encoding|URL 編碼：查詢參數為什麼要跳脫]] — 看懂 %XX 並用 quote/unquote/urlencode 還原與重建
2. [[learn/js-reverse2/nodes/encoding-base64-digest/base64-basics|Base64：把任意位元組塞進文字]] — 掌握字母表與 3→4 分組，用 b64encode/b64decode 編解碼
3. [[learn/js-reverse2/nodes/encoding-base64-digest/base64-variants-data-uri|Base64 變體：URL-safe 與 Data URI 圖片]] — 還原 -/_ 變體、補 = 並拆出 Data URI 圖片（after step 2）
4. [[learn/js-reverse2/nodes/encoding-base64-digest/digest-md5-sha|摘要演算法：MD5 與 SHA 家族]] — 說明不可逆／定長／決定性，用 hashlib 重現與加鹽
5. [[learn/js-reverse2/nodes/encoding-base64-digest/identify-encoding-by-shape|一眼判型：從長度與字母表認出編碼]] — 依長度與字母表判斷該用哪種還原法（after steps 1–4）

## Lesson

編碼與摘要，是 JS 逆向每一次動手前都要先過的「認字」關卡。你在封包裡看到的加密參數，十之八九不是憑空生出來的亂碼，而是一層層編碼疊上來的結果：查詢字串裡的 `%XX`、`sign` 裡那串長度剛好的英數、響應裡一段 `data:image/png;base64,` 開頭的圖片，還有登入密碼欄位那個固定 32 個字元的十六進位字串。這一節要給你的，就是辨識這些字串、並在 Python 裡把它們還原或重算出來的基本功。

這一步之所以重要，是因為它決定了你後面的力氣花在哪裡。如果一段字串其實只是 Base64 編碼過的明文，你解開就結束了，不必去找什麼金鑰；如果它是一段摘要（雜湊），那你就要意識到「反向解不回來」，重點得放在找出輸入與鹽（salt）。同樣一雙眼睛，能不能一眼看出是編碼還是摘要，會直接影響你判斷這個參數該「解」還是該「重算」。

這條路分成五步。前三步是編碼這一側：先講最基礎的 URL 編碼，再進到 Base64 的分組與字母表，然後補上實戰常見的兩個變體——URL-safe 字母表和 Data URI 圖片。第四步換到摘要這一側，講 MD5／SHA 為什麼不可逆、長度為什麼固定，以及為什麼同一個輸入每次算出來都一樣。第五步把這些線索收攏成一張判型表：面對陌生字串，依長度與字母表決定它屬於哪一類、該用哪種方式還原。
