<LearningGoal>
在「請求堆疊追蹤」與「關鍵字搜尋」兩條定位入口的方法之間，依手上握有的線索選出正確的一條。
</LearningGoal>

## Lesson

定位加密入口只有兩條路——請求堆疊追蹤（從「誰送出這個請求」往回追）與關鍵字搜尋（用參數名、URL 路徑、敏感詞直接找）；看得到請求就走請求堆疊，有線索字就先搜關鍵字，混淆會讓關鍵字搜尋失效，非 XHR 送出的值會讓請求堆疊不好用。
