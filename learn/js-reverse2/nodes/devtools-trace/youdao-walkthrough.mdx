<LearningGoal>
對一個真實請求，標出哪些欄位是動態而必須重現的，並說明如何用請求堆疊／關鍵字搜尋把它們定位到產生它們的 JS。
</LearningGoal>

## Lesson

面對真實的被保護請求，先做紙上兵推：把欄位分成固定與動態（有道翻譯的目標是 `sign` 與 `mysticTime`），先關鍵字搜 `sign`／`pointParam`／`md5` 縮小範圍、必要時再用請求堆疊沿 `webtranslate` 追發送鏈，選 XHR 或行斷點暫停，最後用 Python 重算並比對來驗證。
