依「值在什麼時機、什麼位置產生」選對斷點種類，讓執行停在能觀察到加密值的地方。
</LearningGoal>

## Lesson

斷點要對應你的線索：知道哪一行就用行斷點，值在頁面載入瞬間產生、要搶在頁面程式前停住就用事件監聽斷點，值由某個 XHR／Fetch 送出就用請求斷點；混淆的長行會讓行斷點失準，重新整理會讓事件監聽的前置動作失效。
