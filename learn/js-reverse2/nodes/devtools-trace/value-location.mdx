<LearningGoal>
說出加密值可能出現的三個位置（請求資料、請求頭、Cookie），並從 Network 面板認出哪個請求、哪個參數是被保護而需要重現的。
</LearningGoal>

## Lesson

要還原一個被保護的值，第一步不是問「誰算的」，而是問「它在哪」：加密值可能出現在請求資料、請求頭或 Cookie，位置不同追法就不同；先在 Network 鎖定可疑請求，再把欄位分成固定與動態，動態的那幾個才是要重現的目標。
