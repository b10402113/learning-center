# 加密請求 body、解密響應：一次跑通完整對

<LearningGoal>
能打通「加密請求 body、解密響應」的完整對，用兩把不同的 key 各自完成加解密並驗收結果。
</LearningGoal>

## Lesson

完整的加解密對是「pad → AES.new → encrypt → b64encode」送出請求、再用另一把 key 解密響應——補齊規則照抄前端（先補 \b 再 PKCS7）、請求與響應各用一把 key（都是 key==iv），驗收分請求被接受、響應解得開、內容合理三層。
