# 不是 AES 的對稱加密：DES／ECB 與 RC4 串流

<LearningGoal>
能認出不是 AES 的對稱加密：DES 的 8 位元組 key 與 ECB 模式，以及 RC4 串流加自定 UTF-8 解碼的混合管線。
</LearningGoal>

## Lesson

對稱加密不等於 AES：DES 的 key 是 8 位元組、ECB 沒有 iv 且相同明文塊加密出相同密文塊，RC4 則是 256 牌堆洗牌後逐一 XOR 的串流密碼、沒有填充，分流要看 JS 呼叫名稱與參數特徵，不能靠習慣。
