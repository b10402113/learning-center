# 認出密文在哪裡：整段 base64、欄位 base64 與傳輸變體

<LearningGoal>
看到響應或請求裡的字串，能判斷密文藏在哪個位置，並把整段 base64、欄位 base64、加引號、URL-safe 等傳輸變體還原成乾淨的密文位元組。
</LearningGoal>

## Lesson

解密的第一步是認出密文藏在哪（整段 body、JSON 欄位或連請求都要加密），再把加引號、URL-safe 等運輸變體洗乾淨，最後 base64 解碼成密文位元組——base64 只是編碼不是加密，判斷是不是密文要看解碼後的位元組像不像亂數。
