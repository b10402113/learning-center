# key 與 iv 的三種藏法：words 陣列、MD5 派生、key==iv

<LearningGoal>
能從 JS 裡三種常見的藏法還原 key 與 iv：CryptoJS 的 words 整數陣列、MD5 派生的摘要位元組，以及 key 直接當 iv 用的捷徑。
</LearningGoal>

## Lesson

key 與 iv 有三種常見藏法——CryptoJS 的 words 整數陣列（每個整數拆 4 位元組還原）、MD5 派生（秘密字串過 MD5 取 digest 而非 hexdigest）與 key==iv 的偷懶寫法——辨認靠看解密呼叫的參數型別，還原動作都是固定的。
