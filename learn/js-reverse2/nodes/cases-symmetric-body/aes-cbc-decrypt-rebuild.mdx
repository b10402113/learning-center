# 用 Python 重現 AES-CBC 解密：Pkcs7 與 ZeroPadding

<LearningGoal>
拿到 key、iv、mode、padding 之後，能用 Python 的 pycryptodome 重現 AES-CBC 解密，並分別處理 Pkcs7 與 ZeroPadding 兩種填充。
</LearningGoal>

## Lesson

AES-CBC 解密的骨架是「準備 key／iv → AES.new → b64decode → decrypt → 處理填充」，其中填充要照抄 JS 的設定：Pkcs7 用 unpad、ZeroPadding 用 rstrip 剝零，解出亂碼時依序檢查填充、key／iv、資料預處理與 mode。
