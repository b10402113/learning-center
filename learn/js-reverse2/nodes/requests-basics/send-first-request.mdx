<LearningGoal>
用 `requests.get` 完成第一次抓取並存檔，讀懂回傳的響應物件（`status_code`、`text`）與四步流程在程式碼裡的對應位置。
</LearningGoal>

## Lesson

用 `requests.get(url)` 送出請求後會拿到響應物件，先看 `status_code` 確認成功，HTML 內容用 `response.text` 取出並以 `encoding='utf-8'` 寫檔──這就是四步流程在程式碼裡的位置。
