<LearningGoal>
用 `response.content` 搭配 `'wb'` 存下圖片／影片等二進位資料，或用 `urlretrieve` 一行下載，並依回應型別選對取值方法。
</LearningGoal>

## Lesson

圖片、影片等二進位資料要用 `response.content` 取位元組並以 `'wb'` 寫檔，或用 `urlretrieve(img_url, 路徑)` 一行下載；需要 UA 偽裝時改用 `requests`，而 `.text`／`.json()`／`.content` 分別對應 HTML、JSON、二進位三種回應型別。
