<LearningGoal>
分辨請求參數該交給 `params` 還是 `data`，並在已知端點時用 GET 查詢字串或 POST 表單正確送出，取回 HTML 或 JSON。
</LearningGoal>

## Lesson

已知端點帶參數時，GET 查詢字串交給 `params`（會接成 `?key=value`）、POST 表單交給 `data`，判準以抓包工具顯示的請求方法與參數位置為準，參數名照抄不臆測，JSON 回應則用 `response.json()`。
