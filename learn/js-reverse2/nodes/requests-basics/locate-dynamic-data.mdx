<LearningGoal>
用抓包工具的全域搜尋定位動態資料所屬的請求，抄下它的 URL 與參數，補上 `Referer` 重放，並用 `response.json()` 取出 JSON 資料。
</LearningGoal>

## Lesson

頁面看得到、程式抓不到時，資料多半是動態載入的；用抓包工具 `Control+F` 全域搜尋找出帶回資料的請求，抄下它的 URL、參數與 `Referer` 等標頭重放，再用 `response.json()` 解出資料。
