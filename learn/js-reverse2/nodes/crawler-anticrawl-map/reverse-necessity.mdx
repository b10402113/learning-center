<LearningGoal>
用「模擬瀏覽器的力度不足」解釋為什麼抓不到資料，並畫出抓取→反爬→逆向的整體地圖，說明何時必須從一般抓取升級到逆向。
</LearningGoal>

## Lesson

抓不到資料的唯一原因是模擬瀏覽器的力度不夠；整條路線分抓取（四步骨架）、反爬（矛與盾）與逆向三段，能用模仿解決的就留在抓取，當保護升級為前端 JS 計算的簽名或加密內容時，才需要逆向前端並用 Python 重現。
