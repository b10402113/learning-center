<LearningGoal>
依「指定 URL → 發送請求 → 取得響應 → 持久化」四步寫出最小爬蟲，並在抓不到資料時用封包全域搜尋定位動態資料。
</LearningGoal>

## Lesson

任何爬蟲的骨架都是「指定 URL、發送請求、取得響應、持久化」四步；響應是 HTML 用 `response.text`、JSON 用 `response.json()`、二進位用 `response.content`，抓不到資料時則用抓包工具的全域搜尋定位真正帶回資料的動態請求。
