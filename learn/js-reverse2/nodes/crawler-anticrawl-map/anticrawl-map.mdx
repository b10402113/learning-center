認得常見的反爬手段（UA 檢測、Referer 防盜鏈、Cookie、頻率限制與代理、驗證碼、動態渲染、參數加密），並說出每一招卡在四步流程的哪一步。

## Lesson

常見反爬手段可依卡點整理成一張地圖：請求頭類（UA 檢測、Referer 防盜鏈、Cookie）、網路與人機類（頻率限制與代理、驗證碼）、內容類（動態渲染、參數加密），每一招都卡在四步流程的某一步，也各有對應的破解方向。
