# 從 crypto-js 還原 AES/DES，並用 pycryptodome 重現

<LearningGoal>
看到 crypto-js 的 AES/DES 程式碼，能依序抓出 key、iv、mode、padding，並在 Python 用 pycryptodome 寫出可驗證、可對接的加解密。
</LearningGoal>

## Lesson

從 crypto-js 的 AES／DES 呼叫抄出 key、iv、mode、padding，在 Python 用 pycryptodome 以 pad→AES.new→encrypt→b64encode 重現加密、以 b64decode→decrypt→unpad 重現解密，並以兩邊密文一字不差作為驗收。
