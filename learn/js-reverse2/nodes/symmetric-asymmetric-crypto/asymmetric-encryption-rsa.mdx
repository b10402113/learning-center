# 非對稱加密：公鑰加密、私鑰解密的 RSA 模型

<LearningGoal>
能說明非對稱加密為何需要公鑰與私鑰兩把 key，講清楚「公鑰加密、私鑰解密」的方向，並認出 jsencrypt 的 setPublicKey／setPrivateKey 特徵。
</LearningGoal>

## Lesson

非對稱加密用一對金鑰：公鑰可公開、負責加密，私鑰留在伺服器、負責解密；它解決了對稱加密在前端必須洩漏 key 的矛盾，代價是速度較慢，前端最常見的實作是 jsencrypt，可用 setPublicKey／setPrivateKey 與 window／self 補丁辨識。
