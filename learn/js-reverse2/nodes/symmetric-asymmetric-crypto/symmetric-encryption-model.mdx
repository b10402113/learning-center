# 對稱加密的運作模型：Key、Mode、Padding、IV

<LearningGoal>
能講清楚對稱加密為何只需要一把 key，並說出 Key／Data／Mode／padding／iv 這五個參數各自決定什麼，以及 ECB 與 CBC 的差別。
</LearningGoal>

## Lesson

對稱加密以同一把 key 完成加解密，結果由 Key／Data／Mode／padding／iv 五個參數決定；ECB 讓相同明文得到相同密文，CBC 用前一塊密文與 iv 讓每次密文不同，而 AES 已取代 DES 成為主流。
