# 用 Python 生成金鑰、重現 RSA 加解密，對照 jsencrypt

<LearningGoal>
能用 pycryptodome 生成公私鑰、以 PKCS1_v1_5 加密成 base64 傳輸、再用私鑰解密，並對照 jsencrypt 在 Node 下的寫法與環境 shim。
</LearningGoal>

## Lesson

用 pycryptodome 生成金鑰並匯出 PEM，公鑰端 importKey→PKCS1_v1_5→encrypt→base64、私鑰端 decrypt 還原，並對照 jsencrypt 的 setPrivateKey／decrypt；驗收看能否解回原文，因為 PKCS#1 v1.5 有隨機填充、同段明文每次密文都不同。
