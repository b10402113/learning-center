# 國密 SM3/SM4：從 sm-crypto 讀懂一條簽名管線

<LearningGoal>
認出 sm-crypto 的 sm3／sm4 特徵，並讀懂四川補貼案例「排序拼接 → SM3 雜湊 → 轉大寫 → SM4 加密」的簽名管線，說出每個 helper 在做什麼。
</LearningGoal>

## Lesson

認出 sm-crypto 的 sm3（雜湊）與 sm4（對稱加密、預設 ECB 無 IV）後，讀懂四川補貼案例的簽名管線：JSON 參數排序拼接成正規化字串、接上固定密語，先 SM3 雜湊轉大寫再 SM4 加密得到 sign，timestamp 同樣 SM4 加密，source 為固定常量。
