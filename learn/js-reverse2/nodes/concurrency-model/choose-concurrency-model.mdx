<LearningGoal>
面對一批 IO 密集的爬取任務，依「隔離需求、切換可控性、建立開銷」判斷該用行程、執行緒、執行緒池還是協程。
</LearningGoal>

## Lesson

依「IO 密集還是計算密集、是否需要共享記憶體、任務量大小、切換是否要可控」在行程／執行緒／執行緒池／協程之間做選擇；爬蟲多為 IO 密集，協程靠單執行緒內主動在阻塞點讓出，把 CPU 盡量留在自己的程式裡。
