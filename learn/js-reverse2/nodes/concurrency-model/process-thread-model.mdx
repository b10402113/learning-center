<LearningGoal>
用「工廠—車間—工人」的譬喻說出行程與執行緒的關係，並分清執行緒共享記憶體、行程之間彼此隔離。
</LearningGoal>

## Lesson

行程是 CPU 能處理的單個任務（車間），執行緒是行程內實際運作的單位（工人）；同一行程的執行緒共享記憶體，行程之間彼此隔離，且建立執行緒比建立行程便宜。
