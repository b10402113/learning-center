<LearningGoal>
用 multiprocessing.Process 建立子行程、傳參、start 出非同步效果，用 join 控制結束，並說出資料隔離與 daemon 的後果。
</LearningGoal>

## Lesson

用 `Process(target=函式, args=(...))` 建立子行程、`start()` 啟動即可做出非同步；用清單收好全部 start 後再逐一 `join`，並記得行程資料彼此隔離、子行程改動不會傳回主行程、`daemon = True` 要放在 `start()` 前。
