# XPath 與資料解析

## Learning goal

用 lxml/XPath 精準取出想要的欄位，並破解防盜鏈（Referer）與圖片懶載入（`data-original`）。

## Steps

1. [[learn/js-reverse2/nodes/xpath-parsing/data-parsing-basics|資料解析與聚焦爬蟲：從「抓下來」到「取出想要的」]] — 說出解析在爬蟲流程的位置、通用原理與四種技術的取捨
2. [[learn/js-reverse2/nodes/xpath-parsing/xpath-locate|用 lxml 建立解析物件並定位標籤]] — 把原始碼載入 etree，用四種表達式定位標籤（after step 1）
3. [[learn/js-reverse2/nodes/xpath-parsing/xpath-extract|提取文字與屬性：/text()、//text() 與 @attr]] — 取出文字與屬性，並用 `./` 局部解析（after step 2）
4. [[learn/js-reverse2/nodes/xpath-parsing/multipage-and-binary-download|多頁爬取與二進位檔案下載]] — 套用頁碼規律與兩層結構，用 `content` + `wb` 下載檔案（after step 3）
5. [[learn/js-reverse2/nodes/xpath-parsing/anti-hotlink-and-lazy-load|防盜鏈與圖片懶載入的機制與對策]] — 解釋 `Referer` 與 `data-original` 卡在哪、該改抓哪個屬性（after step 3）

## Lesson

抓下一個頁面只是半成品。伺服器回給你的是一大包 HTML，裡面混著導覽列、廣告、版權宣告，真正要的資料可能只佔幾行。資料解析要處理的就是這段落差：把頁面原始碼當成一份有結構的文件，先定位到資料所在的標籤，再從標籤裡把文字或屬性取出來。做完這一步，你的爬蟲才從「什麼都抓」變成「只抓要的」，也就是聚焦爬蟲。

這個節點的主線是 XPath。它用一條字串描述「我要哪個標籤」，再交給 lxml 去執行。學會的關鍵不是背語法，而是看得懂一條表達式在講什麼：`/` 和 `//` 的差別是跨幾層、`[@attr="值"]` 是挑屬性、`[n]` 是挑第幾個、`/text()` 和 `//text()` 則決定要標籤自己的文字還是底下全部文字。把這幾個元素組起來，你就能對準任何欄位。

學會定位與提取之後，還有兩種常見的攔路手法要拆。一種是防盜鏈：圖片或檔案的網址在原始碼裡的名字和你以為的不一樣，伺服器還要求你帶著正確的 `Referer` 才肯給。另一種是圖片懶載入：真正的圖片網址藏在 `data-original` 這種自訂屬性裡，`src` 反而是空的。這兩者其實是同一件事的兩面——**你在瀏覽器裡看到的，不一定是原始碼裡真正的那個**。這節課會把這個原則講清楚，讓你知道什麼時候該換一個屬性來抓。
