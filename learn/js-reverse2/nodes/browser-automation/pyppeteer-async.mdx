<LearningGoal>
用 Pyppeteer 啟動 Chromium、開新分頁、渲染頁面、取得內容，並在頁面內執行 JS 隱藏 `webdriver`。
</LearningGoal>

## Lesson

Pyppeteer 用一支套件直接驅動 Chromium、第一次執行自動下載瀏覽器，省去管理 chromedriver；API 基於 `async`、操作前加 `await`，核心是 `launch()`、`newPage()`、`goto()`、`content()`，並用 `setViewport()` 修版面、`args=['--disable-infobars']` 關提示條、`page.evaluate()` 隱藏 `webdriver`。
