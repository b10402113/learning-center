<LearningGoal>
用 Selenium 建立 driver、用 `By` 定位元素、與節點互動、執行 JS，並以 `page_source` 取得渲染後的 DOM 交給解析器。
</LearningGoal>

## Lesson

Selenium 的基本迴圈是建立 driver、用 `get()` 開頁、用 `By` 搭配 `find_element`／`find_elements` 定位、以 `send_keys`／`clear`／`click` 互動，需要時用 `execute_script()` 執行 JS、用 `switch_to.frame()` 切進 iframe，最後取 `page_source` 拿到渲染後的 DOM 接回 XPath 解析。
