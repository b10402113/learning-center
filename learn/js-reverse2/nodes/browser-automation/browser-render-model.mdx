<LearningGoal>
說出為什麼 `requests` 抓不到 JavaScript 渲染出來的資料、瀏覽器自動化的心智模型，以及 `page_source` 為什麼能拿到渲染後的 DOM。
</LearningGoal>

## Lesson

`requests` 拿到的是伺服器原始 HTML、不會執行 JavaScript；資料若由 JS 在瀏覽器裡渲染，就只能靠瀏覽器自動化開一個真瀏覽器把頁面跑完，再用 `page_source` 取回渲染後的 DOM，這就是「可見即可得」。
