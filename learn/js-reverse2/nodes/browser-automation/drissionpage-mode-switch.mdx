<LearningGoal>
在 `ChromiumPage`、`SessionPage`、`WebPage` 之間選對工具，並用模式切換處理「登入嚴格、資料好抓」的網站。
</LearningGoal>

## Lesson

DrissionPage 把「控制瀏覽器」與「收發封包」合成同一個工具：`ChromiumPage` 只開瀏覽器、`SessionPage` 只打封包、`WebPage` 兩者兼具且能用 `change_mode()` 切換；面對「登入嚴格、資料好打」的網站，先用瀏覽器登入再切回封包採集，但若登入本身要逆向密碼加密或資料靠 JS 渲染，切模式救不了。
