<LearningGoal>
用 new Proxy 的 get／set 攔截對物件的讀寫，並從「讀到不存在的屬性」判斷補環境時該補哪些東西。
</LearningGoal>

## Lesson

`Proxy` 用 `new Proxy(target, handler)` 把一個物件包起來，handler 裡的 trap（最常用 `get` 讀、`set` 寫）負責攔截操作，並用對應的 `Reflect.*` 以原本語意交還給目標物件，避免改變行為或無限遞迴；它最有價值的用法是對 `window`、`document` 這類大物件做代理，記錄所有「讀到不存在的屬性」，藉此找出補環境該補哪些東西。
