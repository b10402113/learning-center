<LearningGoal>
照著瀏覽器操作順序，在頁面程式碼執行前把原生的 atob 與 document.cookie hook 起來，並確認攔得到每一次讀寫。
</LearningGoal>

## Lesson

攔截瀏覽器原生 API（例如 `atob`、`document.cookie`）靠的不是新語法而是時機：先用 Sources 的 Script 事件監聽器斷點讓頁面在執行腳本前暫停，趁空檔把「存原函式、換包裝」（函式）或 `defineProperty` 的 `get`／`set`（屬性）寫進 Snippets 並執行，再取消斷點放行，全程不能重新整理，否則新文件會讓 hook 失效。
