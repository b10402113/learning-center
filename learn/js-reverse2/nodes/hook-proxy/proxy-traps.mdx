<LearningGoal>
查得到六個 handler trap（get／set／getOwnPropertyDescriptor／defineProperty／apply／construct）各自攔什麼、參數是什麼、最小範例長什麼樣。
</LearningGoal>

## Lesson

Proxy 處理器裡每個 trap 對應一種操作：`get`／`set` 攔一般屬性的讀寫，`getOwnPropertyDescriptor`／`defineProperty` 攔走屬性描述符的存取與定義，`apply` 攔函式呼叫、`construct` 攔 `new`；每個 trap 都要用對應的 `Reflect.*` 把操作交還給目標物件，參數依序是目標物件、屬性（或參數）與代理物件。
