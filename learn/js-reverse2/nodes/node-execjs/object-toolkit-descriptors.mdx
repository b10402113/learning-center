<LearningGoal>
用 Object 的幾個工具辨識型別、判斷自有屬性與原型物件，並用屬性描述符讀懂、甚至改寫一個屬性的可寫、可列舉與 get/set 行為。
</LearningGoal>

## Lesson

用 `Object.prototype.toString.call` 精確辨識型別、用 `hasOwnProperty` 分辨自有與繼承屬性，並用屬性描述符讀懂與改寫一個屬性的 `writable`／`enumerable` 與 `get`／`set` 行為——這正是寫 hook 的底層原語。
