## Lesson

從一個 32 位密文出發，先猜它是 MD5，再用全域搜尋與請求堆疊定位加密入口、設斷點找回產生它的函式；重現有兩條路——用 execjs 呼叫原碼，或認出演算法後用 Python `hashlib.md5` 重寫。
