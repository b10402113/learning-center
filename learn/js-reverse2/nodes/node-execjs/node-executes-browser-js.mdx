<LearningGoal>
說明瀏覽器 JS 在 Node 執行會壞在哪（window 對 global、Node 專屬符號外洩），並用假物件與 toString 標籤把環境補起來的起手式。
</LearningGoal>

## Lesson

瀏覽器 JS 在 Node 會壞，是因為頂層物件不同（`window` 對 `global`）與 Node 專屬符號（`global`、`process` 等）外洩；把手刻的 `window` 假物件接上 `self`／`top`、覆寫 `toString` 讓類別標籤回傳 `'[object Window]'`，再刪掉 Node 符號，是補環境的起手式。
