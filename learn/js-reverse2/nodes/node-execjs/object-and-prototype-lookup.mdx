<LearningGoal>
從暫停頁面上的一個屬性反問「它掛在哪」，沿原型鏈判斷成員是定義在物件本身，還是某一層的原型物件上。
</LearningGoal>

## Lesson

物件有字面量與 `new` 建構子兩種建立方式；實例透過 `__proto__` 連到建構子的 `prototype`，成員查找沿原型鏈由內往外逐層進行，直到找到或走到鏈的末端。
