## Lesson

用 PyExecJS 的 `get → compile → eval` 三步，把一段 JS 檔放進 Python 執行並取回結果；能用 Python 重寫的標準演算法（如 MD5 用 `hashlib`）就直接重寫，讀不懂或高度客製的邏輯才用 execjs 兜底。
