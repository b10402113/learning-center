<LearningGoal>
對理財網重現 RSA-SHA256 簽章，對齊 JSON 序列化細節，並把簽章放進 signature header 送出請求。
</LearningGoal>

## Lesson

理財網用寫死在 bundle 的私鑰對 `JSON.stringify(data)` 做 RSA-SHA256（SHA256withRSA）簽章並放進 `signature` 標頭，重現的成敗在序列化逐字元對齊（緊湊 JSON、鍵序、null），而 PKCS#1 v1.5 簽章具確定性，可用比對簽章字串來驗證。
