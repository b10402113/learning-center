<LearningGoal>
從外貿電商平台的 bundle 抽出 2048-bit 公鑰 PEM，在 Python 重現 RSA-OAEP（SHA-256、MGF1-SHA1）加密與 base64 包裝。
</LearningGoal>

## Lesson

外貿電商平台把 2048-bit 公鑰 PEM 與 RSA-OAEP（SHA-256 雜湊、MGF1-SHA1）寫死在模組 `MuMZ`，加密後再以 `window.btoa` 包一層 Base64，Python 用 `cryptography` 照抄參數即可重現，但 OAEP 自帶隨機填充，驗證只能看伺服器收不收、不能比對密文字串。
