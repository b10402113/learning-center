<LearningGoal>
從沃郵箱的 bundle 抽出 modulus 與 exponent，在 Python 重現 PKCS#1 v1.5 密碼加密與 `#!` 前綴包裝。
</LearningGoal>

## Lesson

沃郵箱的公鑰是「模數＋指數（`'10001'` 即 65537）」而非 PEM，模組 `437` 的 `hashPassword` 以 PKCS#1 v1.5 加密密碼後輸出 hex 並加 `#!` 前綴，Python 用 `RSAPublicNumbers` 組回公鑰即可重現，注意模數字串裡的換行與十六進位指數兩個陷阱。
