判斷一個 RSA 保護真正擋住了什麼——特別是「私鑰在前端」的失效模式——並在重用 bundle、execjs、Python 重寫三條重現路線中做選擇。
</LearningGoal>

## Lesson

「私鑰在前端」讓簽章淪為橡皮圖章（理財網是流程性洩漏、沃郵箱的 `loadPassword` 是殘留洩漏），公鑰在前端則是擋偷看不擋偽造的正確設計，重現路線按「演算法是否標準、是否長期維護」在重用 bundle、execjs、Python 重寫之間選擇。
