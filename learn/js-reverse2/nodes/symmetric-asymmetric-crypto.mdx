# 對稱與非對稱加密：AES/DES、RSA、國密

## Learning goal

從 JS 還原 key/IV/mode/padding，在 Python 重現 AES/DES 與 RSA，並認得國密 SM3/SM4 與 crypto-js/jsencrypt 的特徵。

## Steps

1. [[learn/js-reverse2/nodes/symmetric-asymmetric-crypto/symmetric-encryption-model|對稱加密的運作模型：Key、Mode、Padding、IV]] — 一把 key 如何同時加密與解密，五個參數各決定什麼
2. [[learn/js-reverse2/nodes/symmetric-asymmetric-crypto/aes-des-in-js-and-python|從 crypto-js 還原 AES/DES，並用 pycryptodome 重現]] — 抓出 key／iv／mode／padding，在 Python 跑出可驗證的密文（after step 1）
3. [[learn/js-reverse2/nodes/symmetric-asymmetric-crypto/asymmetric-encryption-rsa|非對稱加密：公鑰加密、私鑰解密的 RSA 模型]] — 為什麼要兩把 key，以及 jsencrypt 的特徵（after step 1）
4. [[learn/js-reverse2/nodes/symmetric-asymmetric-crypto/rsa-in-python-and-js|用 Python 生成金鑰、重現 RSA 加解密，對照 jsencrypt]] — 生成、匯入、加密、base64 傳輸、解密的完整程序（after step 3）
5. [[learn/js-reverse2/nodes/symmetric-asymmetric-crypto/national-crypto-sm3-sm4|國密 SM3/SM4：從 sm-crypto 讀懂一條簽名管線]] — 認出國密特徵並拆解四川案例的簽名流程（after step 2）

## Lesson

前面處理的是「編碼」與「摘要」——Base64 只是換個表示法，MD5/SHA 只能往前、不能回頭。這個節點要處理的是第三類：可以真正加密、也能解回原文的演算法，而它們分成兩大家族。

第一家族是**對稱加密**，AES 與 DES 都屬於它。加解密共用同一把 key，所以只要在 JS 裡挖出那把 key，加上 iv、mode、padding，就能用 Python 原封不動地重現。這是最常見的加密型別，也是站台保護請求 body 或回應內容的主力。第二家族是**非對稱加密**，代表是 RSA，它用公鑰加密、私鑰解密，公鑰可以大方地寫在前端程式碼裡，因此逆向時你找的是公鑰而不是「洩漏的密鑰」。最後再補上一條同樣常見但常被誤認的管線：中國國密 SM3／SM4，它的外觀與 AES 相似，卻藏在 `sm-crypto` 這個套件裡，四川補貼案例會把它整條簽名流程攤開。

五步走完，你會有一套固定動作：先看密文的長度與字母表判斷是哪一族，再回 JS 找參數或金鑰，最後在 Python 重現並比對結果。
