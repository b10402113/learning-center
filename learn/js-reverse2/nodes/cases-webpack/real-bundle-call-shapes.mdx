<LearningGoal>
用一張對照表認清四個真實站點的 loader 變形與模組匯出形狀，接到新的 webpack 站時能對號入座決定探針插哪、入口怎麼呼叫。
</LearningGoal>

## Lesson

四站 loader 的變形集中在分發器寫法、探針訊息、快取清理與懶載入機制四欄，`window.loader` 洩漏點則完全一致；模組匯出共四種形狀（物件方法、可呼叫函式、具名方法物件、default 互操作），判定順序是先看 id 是字串還是數字、再看回傳值是物件還是函式、最後看要不要點 `.default`。
