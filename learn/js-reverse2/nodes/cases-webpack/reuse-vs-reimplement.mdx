<LearningGoal>
以 aerfa 的 get_s 與打包版呼叫為例，建立「直接呼叫原 bundle 還是用 Python 重寫」的判準，並知道各選項什麼時候失效。
</LearningGoal>

## Lesson

呼叫原 bundle 換來與瀏覽器一致的保真度、付出補環境與改版後重新定位的成本，Python 重寫換來乾淨快速、卻賭逐位元精確與規格漂移的無聲風險，用「讀得懂嗎、驗得了嗎、跟得上改版嗎」三句判別問句就能下決定，aerfa 的十行 `get_s` 與一行 `window.loader(141).default(e)` 正是兩條路的縮影。
