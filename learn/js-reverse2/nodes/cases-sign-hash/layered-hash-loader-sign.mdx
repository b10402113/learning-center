# 打包檔裡的雙層雜湊：財联社的排序→SHA1→MD5 簽名

<LearningGoal>
在 webpack 打包檔裡定位簽名模組，拆出「排序序列化 → SHA1 → MD5」的管線並用 window.loader 呼叫它。
</LearningGoal>

## Lesson

財联社的簽名埋在 webpack 模組裡、管線是「排序序列化 → SHA1 → MD5」，手法是用 loader 探針與 window.loader 分發器定位模組 W2Yj、讀匯出函式拆管線、再用標準常數（"sha-1"、1732584193、_ff/_gg/_hh/_ii）認出兩層雜湊的身分，最後照決策規則用 execjs 呼叫原 JS 重現。
