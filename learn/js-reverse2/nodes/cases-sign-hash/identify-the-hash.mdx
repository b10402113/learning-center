# 不一定是 MD5：辨識雜湊與選擇重現路線

<LearningGoal>
從雜湊實作判斷它是標準演算法還是自家配方，並決定翻成 Python 還是直接用 execjs 呼叫。
</LearningGoal>

## Lesson

sign 不一定是 MD5——丁香網是手寫 SHA-1、百度翻譯是以 gtk 為種子的自家 hash，抉擇翻 Python 還是 execjs 的判準是四個問句（輸出形狀、標準常數、輸入可見度、環境糾纏深度），標準雜湊且好拼就自己寫、自家配方或糾纏深就呼叫原 JS，且記住輸出形狀只反映最後一層。
