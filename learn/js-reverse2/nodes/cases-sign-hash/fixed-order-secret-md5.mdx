# 配方二：固定順序＋固定密鑰的 MD5 簽名（xdf 與有道翻譯）

<LearningGoal>
照著做能重現「固定順序拼接＋固定密鑰 → MD5」的簽名，並處理簽名用原始字串、送出要編碼的落差。
</LearningGoal>

## Lesson

「固定順序＋固定金鑰 → MD5」的欄位順序寫死在 JS 程式碼裡（xdf 把 UUID 黏在參數字串尾巴、有道把金鑰當最後一個 key 欄位），重現的關鍵是照抄插入順序、並讓進簽名的欄位值與送出時的編碼形式完全一致，最後用純 Python 與 execjs 各跑一次驗證輸出相同。
