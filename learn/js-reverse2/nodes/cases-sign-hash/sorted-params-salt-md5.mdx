# 配方一：排序拼接＋salt 的 MD5 簽名（福建電子交易平台）

<LearningGoal>
照著做能在 Python 重現「排序拼接＋salt → MD5」的簽名，並讓字串化細節與 JS 完全一致。
</LearningGoal>

## Lesson

「排序拼接＋salt → MD5」配方的 Python 重現要把 JS 的字串化細節照抄齊全——鍵名不區分大小寫排序要用 cmp_to_key、巢狀值的 json.dumps 要指定 separators 與 ensure_ascii=False、空字串與 None 要先過濾，最後 salt 黏在拼接結果前面取小寫 MD5 掛上 portal-sign。
