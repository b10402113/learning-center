# Node 執行、execjs 與 JS 前置知識

## Learning goal

把瀏覽器 JS 搬到 Node 執行、用 execjs 從 Python 呼叫，並掌握 descriptor／原型等讀暫停頁面所需的語言知識。

## Steps

1. [[learn/js-reverse2/nodes/node-execjs/execjs-python-calls-js|用 PyExecJS 讓 Python 呼叫 JS]] — 用 get → compile → eval 把一段 JS 跑進 Python，並判斷何時改用 Python 重寫
2. [[learn/js-reverse2/nodes/node-execjs/object-and-prototype-lookup|物件、原型與原型鏈查找]] — 從暫停頁面的一個屬性反問它掛在哪一層原型
3. [[learn/js-reverse2/nodes/node-execjs/object-toolkit-descriptors|Object 工具與屬性描述符]] — 用 Object 工具辨識型別、判斷自有屬性，並讀懂 writable／enumerable／get／set（after step 2）
4. [[learn/js-reverse2/nodes/node-execjs/node-executes-browser-js|把瀏覽器 JS 搬到 Node 執行]] — window 對 global、刪掉 Node 專屬符號，以及用假物件補環境（after step 1）
5. [[learn/js-reverse2/nodes/node-execjs/wechat-pwd-reverse-case|案例：微信公眾平台密碼加密]] — 從 32 位密碼參數回推加密函式，用 hashlib.md5 或 execjs 重現（after steps 1、3、4）

## Lesson

逆向講到要「把網站的加密 JS 拿回來自己跑」，會撞到兩件很實際的事：這門語言在瀏覽器裡跑得好好的，搬到 Node 就壞掉；而用 Python 寫爬蟲的你，又不可能時時手動去執行一段 JS。這個節點就是在補這兩塊——一邊是 `execjs` 這座 Python 對 Node 的橋，另一邊是讀暫停頁面時真正需要的 JS 語言底子：物件怎麼建立、成員掛在原型鏈的哪一層、屬性的描述符如何決定它能不能被改。

先學會用 `execjs` 把一段 JS 塞進 Python 執行並取回結果，你就有一個「把演算法原封不動搬過來」的兜底手段；再往下一層，看懂物件與原型鏈的查找順序、以及 `Object.defineProperty` 這類描述符工具，你才有能力在 DevTools 暫停的那一刻，判斷畫面上這個屬性或方法是誰提供的、能不能被攔截。最後一步把兩條線接起來，跟著微信公眾平台的真實案例，從一個 32 位密碼參數回推到加密函式，選擇純 Python 或 execjs 兩種重現路線之一。

這一步之後，你就具備了往後每個真實案例都要用到的兩個動作：定位加密入口，以及把入口那坨 JS 變成自己能控制的程式。
