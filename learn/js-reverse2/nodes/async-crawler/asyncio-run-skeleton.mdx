<LearningGoal>
用 `async def`、`asyncio.ensure_future`、`asyncio.get_event_loop` 與 `run_until_complete` 把一個協程跑起來，並用回調函式取出它的回傳值。
</LearningGoal>

## Lesson

一支最小協程程式由四個零件組成：`async def` 產生協程物件、`ensure_future` 包成任務、`get_event_loop` 建立事件循環、`run_until_complete` 啟動，並用 `add_done_callback` 搭配 `t.result()` 取回傳值。
