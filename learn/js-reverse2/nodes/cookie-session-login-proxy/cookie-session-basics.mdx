<LearningGoal>
能說出 Cookie 為何存在、它以什麼形式在客戶端與伺服器之間流動，並解釋 `requests.Session` 如何自動承接這條狀態線。
</LearningGoal>

## Lesson

Cookie 是伺服器建立、存在客戶端、並在後續請求自動帶上的鍵值對，用來在無狀態的 HTTP 上維持登入狀態；`requests.Session`（工作階段物件）會自動幫你收下與送出這些 Cookie。
