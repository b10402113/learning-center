<LearningGoal>
能依「Cookie 是否會變動、是否要跨多次請求延續」判斷該手動把 Cookie 放進標頭，還是改用 `requests.Session` 自動處理。
</LearningGoal>

## Lesson

Cookie 量少、不會變、只需用一次時，手動塞進標頭最省事；Cookie 會過期、含即時變動片段或需跨多次請求延續時，改用 `requests.Session` 自動承接。
