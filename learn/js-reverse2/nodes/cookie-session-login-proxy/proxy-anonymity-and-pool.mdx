能用 `proxies` 參數讓請求走代理，說出透明／匿名／高匿的差別與代理類型必須對上協定，並用代理池輪換 IP 做高頻批次爬取。

## Lesson

高頻請求會被網站用 IP 黑名單擋下，因此用 `proxies` 參數讓請求改由代理伺服器轉發；挑高匿代理、讓類型對上協定，並用代理池輪換 IP。
