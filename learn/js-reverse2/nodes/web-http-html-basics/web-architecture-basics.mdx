<LearningGoal>
能說出 B/S 架構與爬蟲的關係，並用「請求-響應」與「無狀態」兩個特性說明 HTTP 的基本運作。
</LearningGoal>

## Lesson

HTTP 是瀏覽器與伺服器之間的溝通協定：客戶端先送請求、伺服器才回應，而且它天生無狀態、不記得前後請求的關聯；爬蟲就是一個自己寫的客戶端，用 HTTP 模擬瀏覽器去要伺服器端的資料，需要「記住」的狀態則靠 Cookie 補上。
