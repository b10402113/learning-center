<LearningGoal>
解釋 Cookie 為何能讓登入狀態延續，並說出它由誰建立、存在哪裡與大小數量限制。
</LearningGoal>

## Lesson

Cookie 是伺服器建立、存在客戶端瀏覽器裡的一組組鍵值對：第一次拜訪時瀏覽器帶著空 Cookie，伺服器產生 Cookie 後由瀏覽器保存，之後每次請求都自動帶上，伺服器便能認出你是誰，登入狀態因此得以延續；它的大小與數量有上限，且不同瀏覽器之間不共享。
