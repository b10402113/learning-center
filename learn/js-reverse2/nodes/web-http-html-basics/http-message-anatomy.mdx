<LearningGoal>
讀懂一個原始 HTTP 請求和回應，指出方法、標頭與狀態碼各自的角色，並分辨 GET 與 POST 的差異。
</LearningGoal>

## Lesson

一個 HTTP 請求由請求行（方法、URL、版本）、請求頭、空行與請求體四段組成，回應同樣四段但開頭換成帶狀態碼的狀態行；GET 把參數放在 URL 上，POST 放在請求體裡，而 `User-Agent`、`Referer`、`Content-Type` 與狀態碼是爬蟲最常回頭檢查的欄位。
