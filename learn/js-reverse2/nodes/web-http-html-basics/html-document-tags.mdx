<LearningGoal>
認得 HTML 文件骨架與常用標籤，並指出爬蟲之後該從哪個標籤或屬性取值。
</LearningGoal>

## Lesson

HTML 是描述性的標記語言，資料只存在於標籤之間或屬性之中；文件有固定骨架、標籤分閉合與自閉合兩種寫法，爬蟲要抓的連結、圖片、表格欄位與表單參數分別對應到 `href`、`src`、`tr/td` 與 `action/method` 這些位置。
