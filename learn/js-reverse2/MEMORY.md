# MEMORY — js-reverse2

## Goal
建立完整爬蟲＋反爬的知識體系，最終能獨立面對工作上的目標網站：從抓取、反爬對抗到逆向加密參數（sign / token / 加密 body），理解保護手法後用 Python 穩定重現並爬取資料。廣度優先，但每一塊都要能真的用出來。具體目標網站之後提供。

## Why
工作需要，要爬特定網站的資料。要的是一套能對付真實反爬的完整能力，能直接套用在工作的目標網站上，而不是零散的技巧。

## Prior experience
- **Python 熟練，日常會寫** — 課程絕大多數案例的 Python 重現門檻低，可直接把 JS 演算法翻譯成 Python。
- **全端／後端背景**，日常寫 TypeScript / Node；**會寫 JS 但底層不熟**（原型鏈、作用域、閉包、打包機制需要補，而這正是 JS 逆向的核心）。
- 有 React／前端經驗，用過 DevTools，但非系統化（沒在用斷點與 call stack 追加密入口）。
- **爬蟲與逆向完全新手**：沒有 requests / Scrapy 實戰，沒解過 sign。
- macOS 開發環境，具備終端機與容器能力。

## Anchors
- **工作上的目標網站（之後提供）** — 最終實戰錨點，節點深度應朝這個方向收斂。
- **課程內的真實案例**（有道翻譯、招標網、丁香網、福建電子交易平台、pdd 等）— 每個手法跟著一個真站跑一次。
- **自建 Flask demo（Day21「自己爬蟲自己」）** — 在可完全理解的靶場上練完整迴圈（客戶端簽名 → 伺服器驗簽 → 回資料），再進攻真站。
- 後端 API 經驗：懂 request / response / cookie / token，可對接 HTTP 與簽名邏輯。
- 前端打包經驗：可對接 webpack loader / 模組拆解。
- Python 能力：可直接把 JS 算法重寫成 Python。

## Habits & constraints
- 每週約 5–8 小時（平日晚上＋週末碎片時間）。
- macOS 上開發，獨自學習。
- 沒有明確死線；工作驅動、動機真實（要爬特定網站）。
- 需要能在短時段內完成、看得到進度的節點。

## Knowledge type
混合，但 **procedural 主導**。概念（HTTP、對稱／非對稱／摘要演算法、JS 執行環境、反爬機制）是必要基礎，但瓶頸在「拿到一個有保護的真站，能不能一步步定位入口、還原算法、用 Python 重現並穩定爬取」。每個節點都應對著真站或 demo 操作驗證。

## How to teach me
- **以真實案例拆解為主，邊操作 DevTools 邊講**：每個手法都跟著一個真站／demo 跑一次，不純讀。
- **先建立大圖再往下鑽**：先講清楚「抓取 → 反爬 → 逆向」的整體流程與各階段如何相扣，再進細節。
- 每個手法都要能回答「**什麼時候用、什麼時候不適用**」，強調取捨。
- 動手實作優先；觀念只講到足以支撐決策的深度。
- 避免長篇定義，用實際案例與對比來教學。
