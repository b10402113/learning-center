# RAG generation eval: faithfulness & relevance

## Lesson

The other half of RAG is generation, judged on two axes: faithfulness to the retrieved context (not parametric knowledge) and relevance to the actual question. Context swapping becomes the debugging test that reveals whether the model is even using retrieval at all.
