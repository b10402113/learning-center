# From traces to a failure taxonomy

## Lesson

This is the Analyze step: reading traces as the user and writing short open codes about the first failure observed, then clustering those notes into higher-order failure categories through axial coding. The output — a failure taxonomy with prevalence rates — is the shared vocabulary that tells every later evaluator what to measure and how often it happens.
