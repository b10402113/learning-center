# Multi-turn eval: anchoring, coherence, memory

## Lesson

Moving from single calls to conversations, this node takes multi-turn evaluation deep: session-level pass/fail, turn-level diagnosis, and coherence/memory failures that only emerge across turns. You learn to distinguish anchoring from context truncation and instruction drift, since each has a different fix.
