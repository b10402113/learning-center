# Collaborative evaluation: rubrics, Cohen's κ, alignment

## Lesson

Because criteria are subjective and drift, this node aligns human judgment before it ever feeds the judge: the nine-step workflow from rubric drafting through independent labeling to alignment sessions, measured with Cohen's κ rather than percent agreement. The outcome is a refined rubric and a consensus gold-standard dataset that later validates the judge honestly.
