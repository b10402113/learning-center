# Ship it: CI/CD gate & improvement strategies

## Lesson

The final thread closes the loop: continuous evaluation as CI unit tests for known unknowns plus CD monitoring for unknown unknowns, joined through a deploy gate. With the measurement trustworthy, you learn to order improvement work by effort — prompt refinement first, then architecture, then model-level changes — always choosing the cheapest change that actually moves the number.
