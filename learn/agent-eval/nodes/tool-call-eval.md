# Tool-call eval: the four stages

## Lesson

When an agent calls tools, end-to-end success can't tell you where it broke, so this node decomposes every call into four stages — selection, argument generation, execution, and output handling — because the fix differs per stage. You practice attributing a failure to the right stage and choosing the matching remedy, from rewriting tool descriptions to adding schema validation.
