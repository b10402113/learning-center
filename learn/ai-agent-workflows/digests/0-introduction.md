# L1 overview

- Sabrina Goldfarb (GitHub Copilot team) frames this as a practical course on AI agent workflows, built and demonstrated in VS Code with Copilot.
- Unlike agent-hype material, it asks when an agent is unnecessary and a cheap, deterministic, LLM-powered code workflow is enough.
- The course moves through four levels: LLMs, workflows, single-agent systems, and multi-agent systems, with progressively less developer control.
- It rejects "token maxing" and argues for efficient AI use to protect budgets, the environment, and engineering skills.
- A three-part scorecard — context, reliability, cost — is used like a CAP-theorem trade-off analysis after every system type.
- A running career-advisor product turns vague goals into a career choice, then schools/courses, then scholarships and loans.
- The product is deliberately open-ended so the same examples can illustrate both user-facing systems and everyday engineering work.
- The lesson closes by resetting vocabulary (agent, LLM, workflow, multi-agent) before any code is shown.
