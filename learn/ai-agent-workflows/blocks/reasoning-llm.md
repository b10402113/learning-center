# Reasoning LLM（推理模型）

## 定義

Reasoning LLM 是一種被訓練成「先推理、再回答」的 LLM。它仍然遵守文字進、文字出的規則，差別在於輸出最終答案之前，會先產生一段用來思考的文字。

## 為什麼重要

推理模型讓模型自己完成原本需要使用者手動催促的步驟。理解它的定位，才不會把「有思考過程」誤認為「有行動能力」，也能判斷什麼時候值得為推理付出額外的成本與延遲。

## 如何運作

它來自一個簡單的觀察：要求模型一步一步思考，能降低幻覺、提高答對的機率。實驗室把這個流程直接訓練進模型，於是模型在回答前會先產生推理內容，再根據推理給出最後答案。使用者不需要每次都在提示詞裡寫「請一步一步思考」。

## 例子

問一個需要多步比較的問題時，推理模型會先輸出中間的分析，最後才給結論。這些中間文字是它思考過程的一部分，而不是最終答案。

## 邊界與常見誤解

- **仍然是文字模型**：推理模型不會因為會思考就能行動，它依然只能輸出文字。
- **思考不等於答案**：中間推理是過程，最後的結論才是要交給使用者的結果。
- **推理不是保證正確**：它降低出錯機率，但不代表每一步都對。
- **不是所有任務都需要**：簡單查詢或格式轉換，額外推理只會增加成本。

## 進階

推理模型與 Chain-of-Thought Prompting 的關係是「把提示技巧變成模型能力」。畫面上看到的思考文字，通常是模型思考的摘要，而不是內部運算的完整重現，詳見 Thinking Summary。
