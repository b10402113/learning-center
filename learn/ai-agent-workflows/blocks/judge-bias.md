# Judge Bias（裁判偏誤）

## 定義

Judge bias 是指 LLM 裁判在評分時出現的可預測偏差：分數不只看內容好壞，也受到模型來源、語氣或呈現順序影響。偏誤是系統性的，不會因為多跑幾次就自動消失。

## 為什麼重要

如果不知道裁判有偏誤，就會把偏誤當成模型實力。例如某個模型總是贏，可能只是因為裁判與它同家族，或因為它的答案排在前面。這會直接誤導選型。

## 如何運作

常見的三種偏誤：

- **同家族偏好**：裁判傾向給自己公司或同一模型家族的回答較高分。評測 Anthropic 的 agent 時，最好避免只用 Anthropic 的模型當裁判。
- **自信偏誤**：裁判容易被語氣自信的答案說服。即使內容完全錯誤，只要寫得篤定，仍可能拿到高分。
- **順序偏誤**：兩兩比較時，裁判對答案出現的先後順序敏感。同一個答案放在 A 或 B，結果可能不同。

## 例子

把兩份答案送給裁判比較時，A 先出現就選 A；把順序對調後，裁判又選了新的 A。這代表排序不是來自內容，而是來自位置。解法是每次測試都對調順序，並重跑多次。

## 邊界與常見誤解

換一個不同家族的裁判、對調順序、盲測，都能降低偏誤，但很難完全消除。偏誤不是「裁判壞掉」，而是 LLM 評分的固有特性；把它當成需要校正的雜訊，而不是一次就能修好的 bug。

## 進階

建立裁判時，先用一批人工已標註的答案校準，觀察裁判在哪些類別特別容易失準。對高風險決策，保留人工複核；對大規模初篩，則用多個裁判與順序對調來平均掉偏誤。
