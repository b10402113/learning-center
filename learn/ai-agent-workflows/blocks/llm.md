# LLM（大型語言模型）

## 定義

LLM 是一個把文字輸入轉成文字輸出的模型。它的輸出讀起來像人類寫的語言，但模型內部其實是在處理數字與機率，而不是在理解世界。

## 為什麼重要

LLM 是整個 agent 系統的基礎零件。分清楚它只能「文字進、文字出」，才不會把模型產生的流暢文字誤當成它已經理解或採取了行動，也才能看懂 agent 的外殼為什麼必須存在。

## 如何運作

輸入一段文字脈絡，模型根據訓練學到的統計規律，逐段產生最可能接續的文字。整個過程沒有對外部的操作：它不會查資料庫、不會執行程式，也不會改變環境。輸出完成後，控制權交回呼叫它的程式。

## 例子

你問模型「這段程式碼有什麼問題」，它回一段分析文字。這段文字可能很有幫助，但它仍然只是文字；真正去讀檔、執行測試或修改檔案的，是外面的程式，不是模型本身。

## 邊界與常見誤解

- **LLM 不能行動**：它只能輸出文字，無法直接對環境做任何事。
- **流暢不等於正確**：像人寫的語氣不代表內容沒有錯。
- **LLM 不是 agent**：聊天產品背後通常包了一層 agent 外殼；模型只是其中一個零件。
- **文字進文字出不會變**：即使換成推理模型，這個基本介面仍然成立。

## 進階

因為 LLM 的介面固定，它可以被替換。同一個 agent 外殼可以換上不同版本的模型，而整體流程不變；這也意味著除錯時要分清問題來自模型，還是來自包住它的程式。
