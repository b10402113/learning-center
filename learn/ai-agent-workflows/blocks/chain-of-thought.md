# Chain-of-Thought（思維鏈）

## 定義

Chain-of-thought 是一種提示策略：要求模型在給出最終答案前，先寫出中間的推理步驟。它的典型指令就是「一步一步思考」，讓模型把多步問題拆成可追蹤的推理片段，而不是直接跳到結論。

## 為什麼重要

對需要組合多個條件、比較選項或做算術的任務，直接輸出答案容易在中間某一步出錯。把推理攤開後，模型較有機會發現前一步的結論不合理，也讓開發者能看見它是在哪個環節偏離。這是 2022 年之後提升 LLM 表現的關鍵技巧之一。

## 如何運作

模型仍是一次輸出，只是輸出的內容包含推理與答案兩部分。提示詞通常會指定格式，例如先寫「Thought」再寫結論，或要求列出步驟。推理文字本身不是外部動作，不會改變環境；它只是讓模型把內部計算顯性化。

## 例子

問「一位喜歡動物與科學、不喜歡久坐的人適合什麼職業」時，模型可能先比較野生動物生物學家與公園巡邏員的工作型態，再說明為何前者更符合條件。這段比較就是思維鏈，最後才給出推薦。

## 邊界與常見誤解

- **思維鏈不是行動**：它只產生文字，不會查資料或改變世界。
- **推理文字不保證正確**：模型可能寫出一段看似合理、實際卻錯的推理。
- **不是所有任務都需要**：簡單查詢或格式轉換，硬加推理只會增加成本。
- **它不是 agent**：思維鏈沒有工具、沒有觀察回饋，也沒有迴圈。

## 進階

ReAct 把思維鏈從「一次輸出」推進到「多輪迴圈」：模型先推理，再採取行動，收到環境結果後重新推理。這個組合讓推理不再只靠模型內部知識，而是能被外部觀察修正，見 [[react]]。
