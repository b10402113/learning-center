# L1 overview

- A flag is a phrase that suggests no production experience; on a borderline rubric decision one flag can flip the outcome, so words matter as much as knowledge — but the flags are not banned words and the fixes are not a script, because an interviewer can change one number and a memorized line stops fitting (learn the reason behind each fix).
- The 12 flags sit on the 45-minute clock with each fix belonging to a framework step; the serving path (the longest phase, 12 minutes) holds five of them, and flags 4–5 fall between minutes 30–43, exactly the fixes a candidate who runs out of time loses.
- Flag 1 "I'd use GPT to rank the feed" — an LLM knows the world, not your users, and one call per post across ~2,000 candidates is far too slow and costly; train a model on your logs of likes and hides. Flag 2 "first we'd train our own model" — pre-training is only for a company whose product is the model; call a hosted API, add retrieval for missing facts, and fine-tune only when better prompts stop helping.
- Flag 3 "fast and accurate" is a wish, not a requirement: define success with three values — resolution rate (at least half of routine contacts), first words within ~1 second (streamed), and at most ~13 cents per conversation — plus a guardrail metric (customer satisfaction no worse than human agents, or a customer who gives up counts as resolved).
- Flag 4 is a diagram that ends at the response arrow: nothing returns from the user, so the system can never improve and cannot notice drift; log each prediction with its features, turn later outcomes into labels, and retrain on a measured cadence (~every two weeks by measuring error growth) — say it before anyone asks. Flag 5 is every step calling the biggest model: no token budget and no volume, so nobody can show what's affordable (~$40,000/day realized as ~$5,000); cut it on three shelves — avoid the call (semantic cache), tune the serving software so each GPU stays busy, then change the model.
- Flag 6 "we'll fine-tune the hallucination away" — tuning shapes behavior, not truth; stack four layers instead: prompt answers only from the retrieved context, every claim cites a chunk that code confirms was in the context, a verifier checks each claim, and the system refuses with a next step when evidence is missing (count wrong refusals as well as wrong answers).
- Flag 7 "the prompt tells the model never to reveal restricted documents" — a prompt instruction is a suggestion, not a control, since instructions and outside text arrive together; filter retrieval by each document's ACL, use per-user-scoped tool credentials, and check actions in code.
- Flag 8 "the model will just know" leaves users to find broken answers first — run every change on a golden set. Flag 9 (the most dangerous) gives an agent an endless loop and admin access, which sets the blast radius; every loop needs budgets (~12 steps, 50 cents, 90 seconds) and irreversible actions wait for a person, climbing the autonomy ladder from suggest to audited auto on measured evidence — sub-$10 refunds reach bounded auto first.
- Flag 10 "a team of agents" multiplies the bill; only context isolation, parallelism, or specialization justify a second agent. Flag 11 names tools instead of shape ("Pinecone, LangChain, GPT") — say what you need (a vector index, test pgVector in existing Postgres first, Pinecone only if outgrown) because the trade-off outlives the product name. Flag 12 "error alerts will catch bad answers" — a wrong answer returns 200 OK and no alarm fires: this silent failure is the default failure of an AI system (drift, stale index), so monitor the answers themselves for groundedness and track outcomes like repeat contacts.
- Three meta-flags cover the whole interview: depth only on demand (no trade-off until asked, sounds rehearsed — pair every choice with its cost), fighting the follow-up (answer the stress test calmly from the fallback ladder, best to worst), and the invisible user (one sentence per main part about what the user experiences, e.g. the customer starts reading within about a second).
- Self-audit: record a full 45-minute practice run, count flags 3, 4, and 5 first (common and cheap to fix), count the rest, rewrite each onto the miss list, and rerun on a later day to compare counts; because these fixes fill the data/metrics, production-maturity, and communication/clock rubric rows, they often move a score more than one more deep dive.
