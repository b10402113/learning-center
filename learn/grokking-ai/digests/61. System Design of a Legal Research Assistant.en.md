# L1 overview

- Recognition move: Enterprise RAG with the stake style (cost of a wrong answer) turned to maximum — attorneys ask questions and get answers with citations to case law, and courts have sanctioned lawyers for filing invented citations, so errors must not happen at all.
- Four things change at maximum stake: deciding metrics are errors that must not happen, latency is traded for verification (~30 s per answer is fine when manual research takes an hour), a case can match and still be overturned (no longer "good law"), and permissions get two layers (tenant ID per firm plus live ethical-wall checks so a lateral hire cannot see the rival firm's matter).
- Metrics: North Star is attorney-verified usefulness; three binding metrics that veto any change — fabricated citation rate (target zero, measured in audits), unsupported claim rate, and refusal correctness in both directions (refuse with no source, answer when one exists).
- Data: license case law and statutes plus each firm's memos in one index with passage metadata and pinpoint locations; a citation graph stores each case's treatment status (followed vs overturned) with every passage, and SLOs commit a new decision searchable in 4 hours and a treatment change indexed within 2 hours.
- Retrieval is hybrid — semantic plus lexical (BM25) merged by reciprocal rank fusion, then a heavy re-rank reads the question against 200 candidates keeping 20; the writer is a frontier model at low temperature, not fine-tuned for knowledge (weights go stale when a higher court overturns a case and have no ID code can check), with a small fine-tune allowed only for citation format.
- Structural prevention is the core rule: the model writes claims (not free text), each with a pinpoint citation and quoted passage; three synchronous checks run (per-claim entailment, citation existence verified word-for-word in code, treatment-status recheck), and a citation that does not resolve to a real document cannot render at all — a guarantee that does not depend on the model obeying a prompt.
- Failure policy: a failed claim is stripped with a note if the answer still makes sense, retried once if central, otherwise refuse and list sources with quotes; if the verifier or wall service is down the system fails closed (licensed law only).
- Evaluation and cost: a golden set of fixed questions grows from every attorney-flagged wrong claim, includes overturned-case traps and wall probes; one fabricated citation or failed wall probe blocks release, new versions run in shadow mode, and no firm's documents train a shared model; a query costs $1–$3, of which licensed data (~$20M/year ≈ $2/query) rather than model compute (~$0.15–$0.50) is the real cost line.
