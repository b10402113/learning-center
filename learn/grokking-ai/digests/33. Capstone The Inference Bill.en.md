# L1 overview

- **Setup and framing**: a $20/user/month project management app with ~5M DAU adds an assistant that summarizes threads, drafts status updates, answers project questions, and helps plan work. The **deciding variable is cost**, because a fixed subscription price means every request eats margin. Targets: keep the most capable model's quality, TTFT within ~2 seconds, and AI cost a small share of the $20 seat. Open the interview with "Cost is the design constraint here, not a footnote."
- **Naive bill first** (cost with no savings): 5M DAU × 20% × 4 interactions = 4M requests/day, peak ~150/s, each 2,500 input + 300 output tokens; at $3/$12 per M that is 10B input tokens ($30,000) + 1.2B output ($14,400) = **~$44,400/day ≈ $45k/day ≈ $16M/year**. Per user that is ~4.5¢/day, ~$1.35/month or 7% of the $20 price; a heavy 40-interaction user costs ~$13/month. Against a 20% cost target leaving $4/seat, this feature alone uses a third of it.
- **Savings priced in order**: **routing** (summaries have a fixed format → small model; multi-project planning → frontier; rule-based for button clicks, classifier for freeform chat) sends 75% of traffic cheap and lands ~$15k/day, removing about two-thirds of the bill — and the router's uncertain-case choice matters (fail open → frontier, safe but near-naive cost; fail closed → small model, cheap but silent quality loss, so the small path needs its own checks). Then **prefix caching** (1,500 of 2,500 input tokens are a static prefix; ~90% cache discount with 80% hit rate → ~$10,220/day) and a **semantic cache** (15% hit rate → ~$9,000/day, scoped per organization, only how-to questions, threshold trades savings against wrong answers).
- **Self-hosting the small path** gets ~34,000 output tokens/s at peak; at 2,500 tokens/s per node for $3/hour, 16 nodes with headroom cost ~$1,150/day versus ~$3,330/day at the provider, saving ~$700k–$1M/year — but only if an infra team already exists, and with both caches the provider price falls to ~$2,000/day so the saving shrinks to $300k–$400k.
- **Operational discipline**: request flow is gateway (rate limits, token budget) → semantic cache → router → prompt builder (static prefix first, identical every time) → cost log. Alert on cost like on errors; a prefix-cache hit rate halving overnight (+~20% bill) usually means a deploy put today's date above the static prefix. Backpressure via per-organization rate limits, a **degradation ladder** on the monthly token budget (80% shorter answers → 90% more small-model routing → 100% cached answers only), a kill switch, and a daily LLM judge on sampled small-model answers plus the golden set on every change.
- **Scale rule**: at 50k DAU, calling the provider for everything is enough; at 50M DAU the router is required. The daily bill traces $45k → $15k (routing) → $10k (prefix cache) → $9k (semantic cache). Every cheap path can lose quality with no error, which is why each needs its own quality check.
