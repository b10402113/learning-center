# L1 overview

- Lesson 41, Introduction: GenAI Product Designs — a GenAI product is the six-stage request path (gateway → input gate → context assembly → router and model → output gate → delivery), the state stores that remember for a stateless model, and the feedback loop. Traces one returning customer's "Did my credit arrive?" message to a first sentence at ~0.9 s, then contrasts four products by their extreme: chat (state and scale), code assistant (latency, 200–400 ms), AI-powered search (integration, ~300 ms at 10,000 QPS untouched), and text-to-image (compute, ~10 s of GPU per image). Safety is shared: direct versus indirect prompt injection, layered guardrails, and the rule that a safe prompt can still produce an unsafe result.
- Lesson 42, Design a ChatGPT-Style Assistant — "the model is bought, not built." At 100M weekly users, 10M conversations/day and ~2,000 sends/second at peak, state and cost drive the design. Three stores at three time scales: append-only conversation store partitioned by conversation ID, a ~3,000-token context window packed from fixed instructions, retrieved memory facts, a running summary, pinned facts, last six turns and the new message, and user memory as a small RAG system over one person. Resending history grows cost quadratically (~57K tokens over 20 turns, ~234K over 40), so summaries and prefix caching matter. Covers gateway budgets and device fingerprinting, incremental output moderation, router tiers (~70–80% cheap), the four cost levers taking ~$1.0M/day naive to ~$328K, and the failure ledger.
- Lesson 43, Design a Code Assistant — one question, two products: inline completion at 200–400 ms versus chat at 1–2 s, so one model cannot serve both. Completion uses a small owned FIM model on own GPUs with local context rules and no retrieval, speculative decoding, and one line by default; the client debounces 50 ms, cancels in flight, caches the last suggestion, never blocks. Chat is RAG over a repository reindexed on every push with structure-aware chunks, plus code-native context (dependency graph, type signatures, recent diffs, test output). Telemetry gives free labels (shown/dismissed/accepted/kept) for retraining; execution checks gate releases. Two opposed filters: secrets outbound, attribution inbound. Costs split into a per-call floor (~$90K/day for 300M completions) and chat routing (~$110K/day for 10M questions).
