# L1 overview

- Defines a model as a function whose behavior is learned from data, and argues the hard part of an AI system design interview is the system around it, not the model; you design out loud for about 45 minutes.
- Introduces the three question families via one food delivery company: predictive systems produce scores (32-minute ETA, ~100 ms latency), generative systems produce content (LLM support assistant, seconds), agentic systems take actions (auto-issuing a $6.40 credit on a $32 order).
- Names four facts that change the design: quality is a range not right/wrong; quality can drift while code stays the same; each request can cost real money (an LLM answer about one cent); the model can be wrong or tricked by prompt injection.
- Key rule: input checks cannot stop prompt injection, so important limits (the $10 credit cap) must live in regular code outside the model.
- Presents the fixed 7-step framework: frame the problem, define success with numbers, map the data, pick a model (baseline first), design the serving path with timeout and fallback, close the feedback loop, count the costs.
- Lists three common mistakes: starting with the model, reusing one family's tools for another, and trusting the model's output; the course runs nine modules, predictive first, with a 30-second spoken answer ending most lessons.
