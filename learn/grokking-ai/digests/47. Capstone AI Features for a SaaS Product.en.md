# L1 overview

- For a CRM serving ~40,000 tenants, name the trap first: three requested features (email drafting, call summaries, ask-my-pipeline) are three copies of the hard parts unless built as one shared platform with three features on top; classify each by shape (chat vs pipeline) and stakes.
- Email drafting is chat-shaped with free human review (moderate stakes); call summaries are pipeline-shaped background jobs; ask-my-pipeline looks like chat but is text-to-query, not RAG — RAG returns vaguely similar deals and lets the model guess numbers, so the system writes a structured query, runs it read-only under the user's own permissions, and narrates the result.
- Two invariants are never traded: tenant isolation (no tenant sees another's data) and every number in a pipeline answer comes from the database; every isolation check fails closed, the tenant ID comes from the session not the model, and semantic cache keys include tenant plus access scope.
- The platform has five parts — gateway (per-tenant request and budget limits), router (features ask for a tier, never a provider, so failover is one setting), safety sandwich (input gate, hardened assembly, output gate with per-tenant policy dials), eval service (golden sets block quality regressions), telemetry — plus four data-governance tiers (opt out of training, zero retention, regional inference, own fleet).
- Model choice follows the bar: summaries use the small model (high volume), drafting routes ~70% to small and delicate replies to frontier, pipeline questions use frontier to write the query; ship lowest-risk first (summaries → drafting → pipeline).
- Pipeline runs in four stages: intent classification, text-to-query against a semantic layer (which defines "slipping" as a pushed close date), read-only SQL execution, then small-model narration whose numbers are checked against rows; low confidence asks the user to confirm, a failure gets one repair attempt, and it never shows a guess. Golden pairs run per schema version on a small fake dataset; cost is ~$16,000/day over ~1M seats (~48 cents/seat/month), with drafting the largest bill at ~$7,000/day despite pipeline questions costing 1.5 cents (~7× a summary).
