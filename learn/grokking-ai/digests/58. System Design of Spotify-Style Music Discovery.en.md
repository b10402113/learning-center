# L1 overview

- One system used twice: the recommendation funnel (retrieve → rank → rules) runs in batch for Discover Weekly (30 new tracks every Monday) and online for Radio (next track depends on the last play/skip); that one split decides the latency budget — Radio must fit 100–200 ms.
- Music changes three things: audio is itself a signal (audio embeddings make a track uploaded this morning findable the same day, before any plays), order matters (Radio plays one track after another), and both modes share one embedding space so a Discover Weekly change can break Radio.
- Success is not clicks: four engagement events (30-second listen, save, artist follow, playlist add), skip is the fast no; North Star = tracks saved from Discover Weekly per user per week, guardrails = artist/genre diversity and fairness to new or less-known artists; each logged impression becomes a label.
- Three feature sources — collaborative signals, audio content embeddings, text/metadata embeddings — plus session context (recent tracks, skips, time of day, device) arriving via an event stream within seconds; baseline is popularity-by-cohort (country + age band + top genres), upgraded only when offline recall and an A/B test agree.
- Production shape: ANN index over ~1,000 candidates (~20 ms encoder-scale work), gradient-boosted-tree ranker, sequence model later; Discover Weekly is a Saturday batch over the ~250M of 400M users active in the last week, writing versioned playlists (Monday open ≈ 1 ms lookup); Radio keeps ~500 candidates, re-ranks on skip, pre-fetches 2–3 tracks, and falls back to the cue then a genre station.
- Three training-loop protections: position-bias correction (position as a training feature, fixed at serving), an exploration slice of 1–5% of slots for the long tail (exploration tax = higher skip rate), and atomic promotion of index plus user-embedding model in the model registry to prevent silent version skew.
- Cost math: 250M users × 1,000 candidates = 250B scores/week ≈ 2.9M scores/s; at 10,000 scores/s/server ≈ 290 servers; at $2/server-hour ≈ $13,900/week, while scoring all 400M would be 60% more (~$430,000/year); Radio does ~8× the scoring, so its ranker must stay light.
