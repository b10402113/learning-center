# 系統開始學習後改變了什麼

## Lesson

AI 系統仍然是分散式系統，快取、資料庫、佇列、負載平衡器一個都沒少。真正改變的是四個平常不用說出口的假設：輸出不是對或錯、行為不會自己變、請求很便宜、失敗會響。每個假設破掉，就對應一個必須補上的元件。
