# 怎麼跑一場案例研究與評析設計

## Lesson

面試官只能評分你說出來的部分，而最常見的失敗是把二十五分鐘花在需求上，於是在風險與成本之前時間就沒了。所以這三個 node 練的是三件事：辨識（兩分鐘內說出這題像哪個已知系統）、配速（每一階段都有說出口的結束條件），以及評析（接手別人的設計，依嚴重度排序問題）。
