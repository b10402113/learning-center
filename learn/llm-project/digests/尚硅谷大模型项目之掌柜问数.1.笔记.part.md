# Digest — 尚硅谷大模型项目之掌柜问数 (part 1.笔记)

## Overview (L1)

- **1. 项目概述** — 掌柜问数是面向数据仓库的智能 NL2SQL 系统，通过自然语言对话让用户无需写 SQL 即可查询业务数据，自动生成 SQL 并返回可视化结果。
- **2. 项目架构** — 基于星型模型的事实表+维度表组织数据，用 MySQL 存储元数据，Qdrant 构建语义向量索引，Elasticsearch 构建全文索引，LangGraph 编排智能体工作流。
- **3. 项目开发环境** — Python 3.12 + conda 虚拟环境，依赖 FastAPI/SQLAlchemy/Qdrant/ES/LangChain 等；Docker Compose 一键启动 MySQL/Qdrant/Elasticsearch/Kibana/Embedding 服务。
- **4. 基础设施搭建** — 配置管理（OmegaConf+YAML），异步 MySQL 客户端（SQLAlchemy+asyncmy），Embedding/Qdrant/ES 客户端封装，loguru 日志与 request_id 上下文注入。
- **5. 元数据知识库** — 从 YAML 配置同步表/字段/指标到 MySQL，构建字段与指标的 Qdrant 向量索引（BGE-large-zh），维度取值同步到 ES 全文索引。
- **6. 问数智能体** — LangGraph 状态机：抽取关键词 → 并行召回字段/指标/取值 → 合并 → 过滤表/指标 → 添加额外上下文 → 生成 SQL → 校验 → 校正 → 执行，流式输出进度与结果。
- **7. API 接口** — FastAPI 提供 `/api/query` SSE 流式接口，依赖注入连接各仓库，lifespan 管理客户端生命周期，中间件注入 request_id。
- **8. 前后端联调** — 前端 Vite 项目启动，后端 Apifox 测试 SSE 流式响应，最终完成问答可视化联调。
