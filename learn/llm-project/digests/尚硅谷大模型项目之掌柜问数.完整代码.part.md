# Digest — 尚硅谷大模型项目之掌柜问数 (part 完整代码)

## Overview (L1)

- `data-agent/` — Python FastAPI 后端，实现"掌柜问数"核心能力：接收自然语言查询，通过 LangGraph Agent 图完成关键词抽取、多路召回（字段/值/指标）、LLM 过滤、SQL 生成与校验，最终流式返回查询结果。
- `data-agent-fronted/` — Vue 3 + Vite 前端，单文件聊天界面，通过 SSE 消费后端 `/api/query` 流，实时渲染进度步骤与结果表格。
- `data-agent/conf/` — YAML 配置（`app_config.yaml` 管基础设施连接，`meta_config.yaml` 管业务元数据：表/字段/指标定义）。
- `data-agent/prompts/` — 各 Agent 节点的 Prompt 模板（关键词扩展、表/指标过滤、SQL 生成与校正）。
