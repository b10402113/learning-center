# 元數據協同：四張表如何驅動 NL2SQL

## Learning goal

能完整說清一個用戶問題從「自然語言」到「SQL 查詢」的過程中，四張元數據表各自扮演什麼角色。

## Lesson

一個用戶問題的 NL2SQL 流程：先從 metric_info 和 column_info 的 alias 做語義匹配，再從 table_info 和 column_info 的 role 確定 JOIN 和聚合邏輯，最後從 metric_info 的 description 確認指標計算方式——四張表各司其職，共同驅動 SQL 生成。
