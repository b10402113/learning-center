# table_info 與 column_info：結構化元數據

## Learning goal

能說清 table_info 和 column_info 兩張表的字段含義，理解 role 字段如何把表和列分類為 primary_key / foreign_key / measure / dimension / fact / dim。

## Lesson

table_info 用 role 字段把表分為 fact 和 dim，column_info 用 role 字段把列分為 primary_key / foreign_key / measure / dimension——這兩個 role 字段直接決定 LLM 該用 JOIN、聚合還是分組。
