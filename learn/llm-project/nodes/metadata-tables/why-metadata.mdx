# 為什麼 NL2SQL 需要元數據知識庫

## Learning goal

能解釋「自然語言問數」場景下，為什麼不能把用戶的問題直接丟給 LLM 生成 SQL，而需要一個元數據知識庫做語義中間層。

## Lesson

元數據知識庫是 NL2SQL 系統的語義中間層——它把數據庫的表、列、指標的業務含義登記在四張表裡，讓 LLM 從「猜」變成「查」，精準匹配用戶的自然語言到數據庫的列和指標。
