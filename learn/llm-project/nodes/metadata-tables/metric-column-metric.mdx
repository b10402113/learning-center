# metric_info 與 column_metric：指標定義與多對多關聯

## Learning goal

能說清 metric_info 和 column_metric 的字段含義，理解指標如何通過關聯表與數據列建立多對多關係，以及 relevant_columns 字段的作用。

## Lesson

metric_info 通過 description 登記指標的計算邏輯、通過 alias 支持自然語言匹配；column_metric 用關係表實現列與指標的多對多關聯，讓 LLM 知道每個指標需要聚合哪些列。
