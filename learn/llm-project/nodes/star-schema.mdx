# 數倉星型模型

## Learning goal

能讀懂 fact_order + 4 張 dim 表的結構，理解事實表/維度表/度量/外鍵的分工

## Steps

1. [[learn/llm-project/nodes/star-schema/star-schema-concepts|星型模型：事實表與維度表的分工]] — 理解星型模型的核心概念與數據倉庫建模思維
2. [[learn/llm-project/nodes/star-schema/fact-order-structure|fact_order：訂單事實表的字段與度量]] — 走讀事實表每個字段，理解外鍵與度量的分工（after step 1）
3. [[learn/llm-project/nodes/star-schema/dim-tables-structure|四張維度表：從描述到分析維度]] — 走讀四張維度表的字段結構，理解維度如何提供分析上下文（after step 1）

## Lesson

數據倉庫的星型模型（Star Schema）是掌柜問數整個 NL2SQL 系統的數據基礎。它把數據分成兩類：事實表記錄交易事件（訂單金額、數量），維度表描述分析切面（誰買的、買什麼、什麼時候、在哪裡）。三步走完之後，你應該能拿到任何一張 SQL 建表腳本，直接讀懂它的角色分工——哪欄是外鍵、哪欄是度量、它連接哪張維度表——這也是後續 LLM 生成 SQL 時需要理解的核心 schema。
