# 流式響應與全棧串接

<LearningGoal>
能解釋 LangGraph 的 astream 如何橋接為 HTTP SSE 流，說清 progress/result/error 三種事件的用途與前端消費方式。
</LearningGoal>

## Lesson

LangGraph 的 graph.astream(stream_mode="custom") 異步生成進度和結果 chunks，QueryService 以 async generator 逐塊 yield 為 SSE 格式（data: {JSON}\n\n），FastAPI 的 StreamingResponse 以 text/event-stream 響應頭推送給前端。三種事件類型覆蓋進度（progress）、結果（result）和錯誤（error），前端通過 EventSource 消費並實時渲染。lifespan 管理應用級客戶端資源，ContextVar 實現 request_id 的日誌追蹤。
