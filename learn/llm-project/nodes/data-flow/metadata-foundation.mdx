# 元數據基礎：支撐 RAG 的知識庫

<LearningGoal>
能說清元數據知識庫的三層結構——MySQL 結構化存儲、Qdrant 向量索引、ES 全文索引——以及它們各自解決什麼問題。
</LearningGoal>

## Lesson

元數據知識庫是 RAG 的語義基礎，分三層：MySQL 存結構化定義（表/字段/指標的名稱、類型、描述、別名），Qdrant 存向量索引（字段名/描述/別名轉向量做語義匹配），ES 存全文索引（維度字段的實際取值做關鍵詞匹配）。三層協作，確保自然語言能被準確映射到數據倉庫的表、字段和取值。
