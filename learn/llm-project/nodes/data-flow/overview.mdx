# 系統全貌：從提問到結果的完整旅程

<LearningGoal>
能畫出從用戶提問到結果返回的完整數據流，說清每個階段的輸入與輸出。
</LearningGoal>

## Lesson

一個查詢從用戶提問到結果返回，要經過關鍵詞抽取、三路並行召回、合併過濾、SQL 生成與校驗、執行、流式返回六個階段。數據倉庫為分析設計，業務庫為交易設計；系統用 RAG 檢索增強生成，先從元數據知識庫找相關信息再餵給 LLM 生成 SQL，用 SSE 實時推送進度到前端。
