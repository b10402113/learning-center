# 多路召回到 SQL 生成

<LearningGoal>
能畫出「關鍵詞抽取 → 三路並行召回 → 合併過濾 → SQL 生成 → 校驗校正」的完整管線，說清每個節點的輸入與輸出。
</LearningGoal>

## Lesson

12 個 LangGraph 節點分五大階段：jieba 分詞抽取關鍵詞，三路並行召回（Qdrant 向量語義匹配字段/指標、ES 全文匹配維度值），合併時補充主外鍵和取值示例並按表分組，LLM 精篩過濾候選清單，最後生成 SQL 經 EXPLAIN 校驗、LLM 校正回路，通過後執行並以 SSE 流式推送結果。
