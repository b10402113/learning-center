# 一個查詢的完整旅程

## Learning goal

能畫出從用戶提問到結果返回的完整數據流，說清每個階段的輸入/輸出

## Steps

1. [[learn/llm-project/nodes/data-flow/overview|系統全貌：從提問到結果的完整旅程]] — 畫出從用戶提問到結果返回的完整數據流，說清每個階段的輸入/輸出
2. [[learn/llm-project/nodes/data-flow/metadata-foundation|元數據基礎：支撐 RAG 的知識庫]] — 說清 MySQL + Qdrant + ES 三層元數據結構的分工（after step 1）
3. [[learn/llm-project/nodes/data-flow/retrieval-to-sql|多路召回到 SQL 生成]] — 畫出關鍵詞抽取 → 三路並行召回 → 合併過濾 → SQL 生成的完整管線（after step 2）
4. [[learn/llm-project/nodes/data-flow/streaming-stack|流式響應與全棧串接]] — 解釋 LangGraph astream → SSE → 前端消費的橋接機制（after step 3）

## Lesson

掌柜問數是一個面向數據倉庫的 NL2SQL 智能分析系統——用戶用自然語言提問，系統自動生成 SQL 查詢數據倉庫，再把結果以可視化表格返回。整個過程不需要用戶寫一行 SQL。

這條數據流可以分成四個階段：先是全局鳥瞰，搞清楚系統長什麼樣；再看元數據知識庫，它是 RAG 檢索的語義基礎；然後是多路召回加 SQL 生成的核心管線；最後是流式響應如何從後端一路跑到前端。四步走完，你就有了搭建類似系統的完整心智模型。
