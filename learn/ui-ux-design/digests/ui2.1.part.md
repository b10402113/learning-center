### 1.3 Create accounts

- Locator: `[[sources/ui-ux-design/20261007/ui2/1.3 Create accounts Lesson Summary (Li).en.srt#accounts]]`, `[[sources/ui-ux-design/20261007/ui2/1.3 Create accounts Lesson Summary I Designership (Li).pdf#accounts]]`

### 1.5 Course walkthrough

- Locator: `[[sources/ui-ux-design/20261007/ui2/1.5 Course walkthrough Lesson Summary (Li).en.srt#walkthrough]]`, `[[sources/ui-ux-design/20261007/ui2/1.5 Course walkthrough Lesson Summary I Designership (Li).pdf#walkthrough]]`
- Summary: A quick end-to-end overview of the course's 10 modules. Mizko explains what each stage accomplishes and how the stages build on one another, from onboarding to testing.
- Key claims: Module 1 Welcome (onboarding, logins, announcement); Module 2 Overview (understand the project/research/brief, not just pixels); Module 3 Creating a Site Map; Module 4 User Flows (interactions between pages); Module 5 Wireframes (layout, IA, flow); Module 6 Lean Branding Workshop (build a brand direction in hours without brand/graphic design background); Module 7 Foundational Styles (primary colors + visual direction in Figma); Module 8 Technical Concepts (essential technical awareness before designing); Module 9 UI Designs (flesh out the UI); Module 10 Test case Creation (test with real users, get feedback, iterate). By the end, learners understand the entire process from brief → design → usability testing.
- Learner-relevant: Mental model of the whole course; anchors every later module's purpose. Note: the TOC labels modules by section headings (11 headings incl. "Project Setup" and "Wrap up!"), while the walkthrough groups them as 10 numbered modules.
