# Digest — UX/UI Design Mastery Course (part 3: User Interface Design)

## Overview (L1)

- Typography 101: Understanding the Essentials of Typefaces, Fonts, and Layout — Introduces typography's power to set brand tone (FedEx, NYT, Apple, Amazon examples) and the core vocabulary: typography vs typeface vs font, font anatomy, weights, headings/subheadings, scale, paragraphs, line height, line length, alignment, and lists.
- Color & Branding: Learn How to Influence Users' Initial Impression of Your Product — Argues color drives up to 90% of an initial impression and 80% of brand awareness, then walks the branding decision factors: consumer perception, emotional response, memorability, competition, authenticity, personality, and uniqueness.
- Color & Behavior: Learn How to Influence People's Choices — Shows how color shapes behavior and decisions: prompting action (Big Orange Button, red CTA), blue's calming/time effect, the placebo effect, color meanings by hue and culture, temperature effects, and clothing-color perception, plus color-tool resources.
- Input Controls and Navigational Components in UI Design — Defines the four UI-element categories, then details input controls (buttons, text fields, checkboxes, radio buttons, dropdowns, toggles, forms) and navigational components (top nav, sidebars, tabs, breadcrumbs, pagination).
- Informational Components and Containers — Covers informational components (tooltips, progress bars, notifications, loaders, modals) that communicate state/context, and containers (cards, tables) that group related content into organized, scannable layouts.
- UI Analysis — A screen-by-screen visual critique of a grocery-shopping app, diagnosing low contrast, weak hierarchy, floating elements, non-interactive-looking controls, and pricing emphasis, and recommending fixes.

## Sections (L2)

### Typography 101: Understanding the Essentials of Typefaces, Fonts, and Layout

- Locator: `[[sources/ui-ux-design/20261007/ui1/3. User Interface Design/1. Typography 101_ Understanding the Essentials of Typefaces, Fonts, and Layout.mhtml#typography-101]]`
- Summary: Fonts shape both readability and perceived brand message, illustrated by FedEx, The New York Times, Apple, and Amazon's failed font change. The lesson separates the terms typography, typeface, and font, then covers font anatomy, weights, headings, scale, paragraphs, line height, line length, alignment, and lists.
- Key claims: Typography should be legible and convey the right brand tone (Amazon reverted a font users found stressful and scam-like); typography = arranging letters, typeface = a family like Times/Garamond/Helvetica, font = a specific form (weight/size); font anatomy includes baseline, cap line, mean line, ascender, descender; use body size as the baseline for a type scale (e.g., 16px body, H2 24px); line height ≈ 1.5× font size and line length 45–75 characters for body; left alignment is most readable for large text, right for RTL scripts, center only for short text.
- Learner-relevant: Gives the exact typographic vocabulary and rules of thumb needed to read and critique any screen's text hierarchy and readability.

### Color & Branding: Learn How to Influence Users' Initial Impression of Your Product

- Locator: `[[sources/ui-ux-design/20261007/ui1/3. User Interface Design/2. Color & Branding_ Learn How to Influence Users' Initial Impression of Your Product.mhtml#color-branding]]`
- Summary: Explains why color is central to branding and first impressions, then frames the design decisions a palette must satisfy: consumer perception, emotional response, memorability, competition, authenticity, personality, and uniqueness. Uses examples like McDonald's red-and-gold and industry-standard color conventions.
- Key claims: Colors can influence up to 90% of an initial impression and increase brand awareness by 80%; colors evoke specific emotions (blue → trust/loyalty, red → alertness/passion, bright hues → youth); color meanings must fit the industry to feel authentic (a bank using bright blue/pink feels inauthentic); consistency across all materials builds memorability; either match industry color conventions (banking) or deliberately differentiate (social media's ubiquitous blue).
- Learner-relevant: Supplies a checklist for choosing a brand palette that resonates emotionally and authentically rather than arbitrarily.

### Color & Behavior: Learn How to Influence People's Choices

- Locator: `[[sources/ui-ux-design/20261007/ui1/3. User Interface Design/3. Color & Behavior_ Learn How to Influence People's Choices.mhtml#color-behavior]]`
- Summary: Moves from branding into behavioral influence, covering how color prompts action (BOB = Big Orange Button), how blue calms and shrinks perceived wait time, the placebo effect, hue-by-hue meanings and cultural variation, temperature perception, and what clothing color signals. Ends with a list of free color tools.
- Key claims: Warm colors (orange/red/yellow/pink) are linked to action and cold colors (blue/green/purple) to passivity; HubSpot found a red CTA button performed 21% better than green; a 2004 study found blue made pages feel faster to load via relaxation; warm-colored placebos produce a stronger effect than cool ones; color meanings shift by culture (e.g., blue = calm/trust, red = passion/urgency/danger, white = purity, black = power/mystery); designers use cool colors for calm, warm for energy.
- Learner-relevant: Turns color theory into a practical lever for CTA design, perceived performance, and culturally appropriate color choices.

### Input Controls and Navigational Components in UI Design

- Locator: `[[sources/ui-ux-design/20261007/ui1/3. User Interface Design/4. Input Controls and Navigational Components in UI Design.mhtml#input-controls]]`
- Summary: Establishes the four UI-element categories (input controls, navigational components, informational components, containers) then drills into how users enter data and move through an interface. Gives design guidance for buttons, text fields, checkboxes, radio buttons, dropdowns, toggle switches, and forms, then for top nav, sidebars, tabs, breadcrumbs, and pagination.
- Key claims: Buttons must be sized, shaped, colored, and labeled for clarity and conversion; text fields should match the data type, be large enough, carry clear labels, sparing placeholder text, and instructions; checkboxes = multi-select, radio buttons = single-select; dropdowns suit many or related options and pair with search/optgroup when needed; toggles should animate to confirm state; forms should ask less, be easy, optimize conversion, show clear errors, and be tested; breadcrumbs show hierarchy (Home > Category > Product); pagination vs lazy loading trade performance against user confusion and load times.
- Learner-relevant: Provides concrete, per-component rules for designing the interaction layer users actually click and type into.

### Informational Components and Containers

- Locator: `[[sources/ui-ux-design/20261007/ui1/3. User Interface Design/5. Informational Components and Containers.mhtml#informational-containers]]`
- Summary: Covers components that communicate state and context rather than collect input — tooltips, progress bars, notifications, loaders, and modals — and containers that group related content, namely cards and tables.
- Key claims: Informational components convey instructions, warnings, feedback, and status to keep users informed; tooltips give timely guidance but become distracting if overused; progress bars/loaders make waiting and progress visible; notifications should be timely and relevant but not overused; modals should be rare, relevant, short, and easily dismissed; cards group related elements into a uniform, visually pleasing pattern; tables present large datasets compactly and are responsive to screen size.
- Learner-relevant: Completes the component vocabulary so a designer can choose the right feedback or grouping pattern for a given screen state.

### UI Analysis

- Locator: `[[sources/ui-ux-design/20261007/ui1/3. User Interface Design/6. UI Analysis.en.srt#ui-analysis]]`
- Summary: A worked visual critique of a grocery-shopping app screen, identifying each problem and the fix. Only the visual side is examined, with the stated goal of finding improvement areas and recommending changes.
- Key claims: Icons over images need a low-opacity background layer for contrast; text needs a good text/background contrast ratio (checkable via Figma plugins), and labels with low contrast hurt legibility and accessibility; a title must differ in size/weight/spacing to stand out; pure black on white strains eyes, so use deep charcoal/dark gray and make body text lighter than the title to build hierarchy; floating product highlights should move near their related description; distinguish equal-importance elements with spacing or dividers; make the current price most prominent among price data; give controls (steppers, coupon) a button-like, clearly interactive appearance; improve the Add-to-Cart CTA's contrast and add a cart icon for universal, prominent recognition.
- Learner-relevant: Demonstrates applying every prior lesson (contrast, hierarchy, spacing, affordance, color) in a single end-to-end UI audit.
