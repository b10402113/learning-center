# Digest — UX/UI Design Mastery Course (part 1)

## Overview (L1)

- ui1.1 Intro to UX/UI Design — eight-lesson opener that defines UX vs UI, maps design career paths and company types, explains how to grow designer value, and lays out core UX principles, Nielsen's usability heuristics, responsive design, and quick UI-improvement strategies.

## Sections (L2)

### 1. Understanding UX and UI Design

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/1. Understanding UX and UI Design.en.srt#understanding-ux-and-ui]]`
- Summary: Defines UI design as the visual layer (buttons, color, typography, icons, layout) and UX design as the overall experience (how a product feels, how easy it is, how well it meets needs). Uses a car analogy (UI = appearance and dashboard, UX = how it drives) and a food-delivery/grocery-app example to show each role's daily work. Closes with why good UX/UI drives satisfaction, conversion, retention, brand trust, and accessibility.
- Key claims: UI makes a product visually appealing and easy to interact with, UX makes it efficient and enjoyable; UX and UI are interdependent and must work together; good UX/UI increases satisfaction, conversion rates, retention, and trust, and improves accessibility.
- Learner-relevant: Foundation for the whole course — anchors the UX/UI distinction and the business value of design.

### 2. Career Opportunities in Design Across Various Types of Companies

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/2. Career Opportunities in Design Across Various Types of Companies.en.srt#career-opportunities-companies]]`
- Summary: Explains how a designer's job differs by company type: startups/small businesses (generalist, fast pace), freelancing (designer plus business owner), design agencies (generalist across many clients, long hours), and in-house at large companies (fewer projects, deeper specialization, expert peers). Contrasts scope, pace, and specialization across each setting.
- Key claims: Startup designers juggle interaction, visual design, research, and marketing; freelancers must also self-promote and manage finances; agency designers may not see a project end to end; in-house designers specialize more but get fewer chances to broaden skills.
- Learner-relevant: Helps the learner choose a work environment and set expectations for role scope.

### 3. Common Design Career Paths

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/3. Common Design Career Paths.en.srt#common-design-career-paths]]`
- Summary: Surveys common design roles — UI designer, UX designer, combined UX/UI designer, product designer, UX researcher, graphic designer, visual designer, and motion designer — with each one's focus, responsibilities, and typical US salary ranges. Distinguishes UX (research and experience) from UI (visual execution) and notes product design's product-roadmap ownership.
- Key claims: UI/US avg ~$82.6k, UX ~$81.1k, UX/UI ~$80.1k, product designer ~$108k, UX researcher ~$96.8k, graphic ~$48.9k, visual ~$77.1k, motion ~$69.1k; UX and UI are intertwined, hence the blended "UX/UI Designer" title; role choice should come down to personal strengths, interests, and goals.
- Learner-relevant: Career-orientation anchor; lets the learner map the course skills to a target role.

### 4. How to Increase Your Value as a UX/UI Designer

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/4. How to Increase Your Value as a UX_UI Designer.mhtml#increase-value-as-designer]]`
- Summary: Saved lesson page listing professional skills that make a UX/UI designer more valuable: communication, avoiding confirmation bias, time management, user research before designing, handling feedback and criticism, software management tools (Jira, GitLab, Trello), structured problem-solving, and stakeholder management. Each skill gets concrete, actionable techniques.
- Key claims: Argue from user needs and research, not personal preference; confirmation bias (Kahneman's term) leads designers to defend an interpretation instead of meeting real user needs; understand users deeply before designing; brainstorm without feasibility limits, then narrow via research and testing; learn ticketing tools to track issues and collaborate.
- Learner-relevant: Professional-skills anchor connecting design craft to real workplace behavior.

### 5. Key Principles of UX Design

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/5. Key Principles of UX Design.en.srt#key-principles-of-ux-design]]`
- Summary: Walks through core UX principles: consistency (visual and functional), familiar navigation and Jakob's Law, page speed, progress bars/steppers, streamlined sign-up and magic links, simplicity, and auto-saving progress. Uses stats and UI patterns to show how each principle reduces friction and builds trust.
- Key claims: Consistent elements reduce cognitive load; users expect your product to work like ones they already use (Jakob's Law); 53% of mobile visitors abandon pages taking over 3s, and Telefonica's 70% faster load lifted click-throughs 31%; ask only for essential sign-up info; steppers should show completed steps, current location, and remaining steps; auto-save preserves progress.
- Learner-relevant: Core principles anchor; repeated across later nodes on navigation, forms, and usability.

### 6. 10 Usability Heuristics by Jakob Nielsen

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/6. 10 Usability Heuristics by Jakob Nielsen.en.srt#nielsen-usability-heuristics]]`
- Summary: Enumerates Jakob Nielsen's ten usability heuristics with a concrete example for each: visibility of system status; match between system and real world; user control and freedom; consistency and standards; error prevention; recognition rather than recall; flexibility and efficiency of use; aesthetic and minimalist design; help users recover from errors; and help and documentation.
- Key claims: Provide timely feedback for system status (e.g., button hover/click states); use familiar language and icons (login not authenticate, trash for delete); allow undo/redo/revise; keep back buttons in a consistent place; validate input and confirm irreversible actions; surface recent items to aid recognition; allow personalization; use clean minimal layouts; make error messages clear and solution-oriented; provide searchable help/docs; heuristics are guidelines, not strict rules.
- Learner-relevant: The canonical evaluation checklist — anchors usability review and design critique across the course.

### 7. Responsive Design

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/7. Responsive Design.en.srt#responsive-design]]`
- Summary: Defines responsive design as adapting a layout to a device's dimensions, covering breakpoints, website-first vs mobile-first approaches, and min/max sizing with relative font sizes. Notes that as screens shrink, content takes more vertical space, so amount of content, text size, and navigation must be rebalanced.
- Key claims: Responsive design changes element position, image and text size, and overall layout; common breakpoints are 320px (small mobile), 768px (tablet), 1280px (large desktop); mobile-first forces focus on essentials and yields faster loading and better mobile usability; min/max values bound element size; font sizes must change per screen for legibility.
- Learner-relevant: Foundation for the responsive-design and constraints work later in the Figma section.

### 8. Simple Strategies for a Better User Interface

- Locator: `[[sources/ui-ux-design/20261007/ui1/1. Intro to UX.UI Design/8. Simple Strategies for a Better User Interface.en.srt#better-user-interface-strategies]]`
- Summary: Practical UI-improvement techniques: skeleton screens to make loading feel shorter, the thumb zone for one-handed reach, minimum tap-target sizing, collecting user feedback, reducing clicks, and using whitespace and color thoughtfully. Supports each with data and cross-cultural color caveats.
- Key claims: Skeleton screens make perceived load time shorter than spinners; thumb zone is the lower half of the screen, so place key controls there; minimum recommended tap target is ~48px (a 24px icon can reach it with spacing); 70% of best-in-class CX companies collect feedback, ESPN.com revenue rose 35% after community-driven redesign; fewer clicks reduce frustration; whitespace creates hierarchy and legibility; color meanings vary by culture (white = purity in the West, mourning in the East); mobile was ~59% of web traffic in Q2 2022 and non-mobile-optimized sites see 5x more abandonment; mobile-friendliness affects SEO.
- Learner-relevant: Concrete UI tactics anchor for the later UI-design and Figma nodes.
