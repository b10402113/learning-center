# Digest — UX/UI Design Mastery Course (part 6: Conducting UX Research)

## Overview (L1)

- `ui1.6` — Conducting UX Research for Better User Experiences — Defines UX research, splits it into qualitative/quantitative and attitudinal/behavioral, surveys research methods (interviews, focus groups, surveys, five-second testing, card sorting), walks three portfolio class projects (project brief, user interviews, competitive analysis), and supplies a 50-prompt ChatGPT prompt bank for UX/UI design work.

## Sections (L2)

### 1. Understanding User Needs: An Introduction to UX Research

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/1. Understanding User Needs An Introduction to UX Research.en.srt#understanding-user-needs-an-introduction-to-ux-research]]`
- Summary: UX research is the process of collecting data about users and their interaction with digital products, aiming to make products easier to use and more enjoyable. It is divided into two subsets (qualitative vs quantitative) and two approaches (attitudinal vs behavioral). Mixing all four gives the clearest view of a design problem.
- Key claims: Qualitative research is descriptive and answers *why* behind behavior, done via in-depth interviews and observation; quantitative research turns data into numbers and answers *what* users do, usually via surveys, usability testing, or analytics; attitudinal research captures what people think/feel and may not match behavior, while behavioral research observes actual interaction and is ideal for evaluating design changes and ROI; common methods include surveys, interviews, focus groups, and usability testing.
- Learner-relevant: Provides the vocabulary and 2×2 frame for choosing research methods; a learner can classify any study by qualitative/quantitative and attitudinal/behavioral.

### 2. Class Project 01 - Generate Project Brief

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/2. Class Project 01 - Generate Project Brief.mhtml#class-project-01-generate-project-brief]]`
- Summary: First portfolio activity: generate a project brief using the FakeClients brief generator, then build on it across later modules. Students pick one brief that sparks interest (or use their own project idea) and must take later lessons in order.
- Key claims: Use `https://fakeclients.com/ux`, select "UX Design" from the dropdown, click "Generate Brief", and regenerate until one fits; each brief presents a user pain point and the designer chooses a mobile app or website (only one) to solve it; everything created can go into the portfolio.
- Learner-relevant: Produces the project brief that anchors the rest of the portfolio project; establishes the course's build-a-project workflow.

### 3. Exploring UX Research Methods

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/3. Exploring UX Research Methods.mhtml#exploring-ux-research-methods]]`
- Summary: Catalogues the core research methods — user interviews, focus groups, surveys, five-second testing, and card sorting — with guidance for running each. Ends with how to choose a method based on the research question.
- Key claims: User interviews are qualitative; recruit representative participants, interview a minimum of 10–15 users, stay neutral, avoid leading questions, and prepare but flex a question list; focus groups are qualitative with a small-but-diverse group, minding body language and non-verbal cues; surveys are quantitative, fast, and screenable but weak for depth and cannot observe actual behavior; five-second testing captures first impressions fast; card sorting reveals how users mentally group information; method choice should follow the research question.
- Learner-relevant: Gives an actionable method-selection toolkit plus concrete survey example questions; supports planning the class-project interviews.

### 4. Class Project 02 - Conduct User Interviews

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/4. Class Project 02 - Conduct User Interviews.mhtml#class-project-02-conduct-user-interviews]]`
- Summary: Hands-on activity to interview potential users of the portfolio product, following a four-step process: recruit, prepare, conduct, analyze. Goal is to learn users' opinions, thoughts, experiences, and feelings about the product.
- Key claims: Recruit 1–3 participants (friends/colleagues, optionally incentivized) and interview in person, Zoom, or Google Meet; prepare a question list, note-taking tools, and recording equipment, and get recording permission; create an open environment so users give honest feedback, listen carefully, avoid leading, and encourage elaboration; afterward, review notes for patterns, consensus, and disagreement to inform later design.
- Learner-relevant: Directly generates qualitative user data for the portfolio project; models the recruit-prepare-conduct-analyze loop.

### 5. Guide to Competitive Analysis

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/5. Guide to Competitive Analysis.en.srt#guide-to-competitive-analysis]]`
- Summary: Explains competitor analysis — identifying competitors and researching their marketing strategies to make informed product decisions and find unmet market needs. Covers when to run it, direct vs indirect competitors, the steps, standard contents, and how to share findings.
- Key claims: Best time to run it is when launching a new product/service or entering a new market; direct competitors offer the same products/services in the same market while indirect competitors offer different products but target the same audience; identify 2–5 main competitors, then assess strengths/weaknesses, marketing/positioning, and the overall competitive landscape; a typical analysis includes name + link, product description, pricing, target audience, strengths/weaknesses, key differentiators, and a rating; document and share findings via a report/presentation or a meeting/webinar (free Figma template provided).
- Learner-relevant: Supplies a repeatable competitive-analysis procedure with the standard artifact fields; sets up Class Project 03.

### 6. Class Project 03 - Competitive Analysis

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/6. Class Project 03 - Competitive Analysis.mhtml#class-project-03-competitive-analysis]]`
- Summary: Step-by-step activity to conduct a competitive analysis for the portfolio project: define competitors, evaluate them, analyze pricing, and compare against your own company. Uses a free Figma template.
- Key claims: Define competitors and their objectives via websites, financial reports, press releases, and customer reviews; evaluate each on pricing, features, customer service, and UX and note unique advantages and marketing messages; analyze pricing and promotions (discounts, free shipping) to adjust your own; compare your own pricing, features, and service to spot gaps and improvements; free Figma template is linked for the exercise.
- Learner-relevant: Produces a competitive-analysis artifact for the portfolio and operationalizes the Guide's procedure.

### 7. ChatGPT for UX/UI Design (e-book: 50 ChatGPT Prompts)

- Locator: `[[sources/ui-ux-design/20261007/ui1/6. Conducting UX Research for Better User Experiences/7. ChatGPT for UX UI Design.pdf#chatgpt-for-ux-ui-design]]`
- Summary: An e-book (`www.uxpeak.com`) on using ChatGPT for UX/UI design: best practices for prompting, a table of 50 prompts, and 50 prompts with examples. Framed as a game-changer designers should adopt to brainstorm, execute, and analyze faster.
- Key claims: Best practices include the "act as" role hack, respecting token limits (GPT-3 4096 / GPT-4 8K / GPT-4 32K as of April 2023), avoiding over-complicated or under-specified commands, asking for tabular answers, setting character limits, regenerating/refining rather than accepting the first result, defining audience/channel/tone, providing examples, chaining prompts in one window (new chats lose memory), and using adjectives; the 50 prompts cover app ideas, feature brainstorming, interview emails/questions/scripts, product descriptions, checkout flows, UX copy, user personas, user flows, research synthesis, success/error messages, micro-interactions, success metrics, arguments, honest feedback, audience research, tone rewrites, business metrics, competitor research, user stories, problem statements, gamification, review summaries, colour palettes, client comms, onboarding, design systems, design options, UX mistakes, stakeholder questions, 404 messages, salary negotiation, growth ideas, best practices, fonts, and a login-form UX checklist.
- Learner-relevant: A reusable prompt library directly usable for research tasks (interview questions, synthesis, competitor research, personas); includes an e-book promo code.
