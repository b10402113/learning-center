# UX 與 UI 的分野

## Learning goal

分清 UX 與 UI 的職責、兩者如何互補，並能說出好設計如何驅動轉換、留存與信任。

## Steps

1. [[learn/ui-ux-design/nodes/ux-ui-foundations/ux-and-ui-defined|UX 與 UI 到底在解什麼問題？]] — 用生活譬喻分辨兩者各在處理「使用起來的感覺」還是「看起來的樣子與操作介面」
2. [[learn/ui-ux-design/nodes/ux-ui-foundations/the-ux-umbrella|UX 是一把大傘，UI 就在傘底下]] — 把 UX 拆成一張技能地圖，看清 UI 在哪一層（after step 1）
3. [[learn/ui-ux-design/nodes/ux-ui-foundations/why-good-design-matters|好設計為什麼是門好生意？]] — 用五個面向與實際數據說明設計如何影響產品成效（after steps 1–2）
4. [[learn/ui-ux-design/nodes/ux-ui-foundations/ui-improvement-checklist|七個能立刻動手的介面改善手段]] — 一份可查的手法清單，把前幾步的觀念落成看得見的手段（after steps 1–3）

## Lesson

設計這門學問最容易被混淆的地方，是 UX 與 UI 常常被當成同一件事，又被當成二選一的兩條路。這個節點先把兩者分開講清楚：UI 處理的是產品的外觀與操作介面——按鈕、色彩、字體、圖示、版面；UX 處理的是整體使用體驗——用起來順不順、能不能解決使用者的問題。分開之後再看它們的關係：UX 其實是一把大傘，UI Design 是傘下的一個技能，和 User Research、Product Strategy、Information Architecture、Site Maps、User Flows、Usability Testing 並列。最後把話題從「設計是什麼」拉回「設計值多少」：好設計會直接影響滿意度、轉換率、留存、品牌信任與可及性，不是做完功能後的美化收尾。走完這幾步，你手上會有一組判斷工具：一張技能地圖、一組商業價值論述，以及一份具體的介面改善手法清單。
