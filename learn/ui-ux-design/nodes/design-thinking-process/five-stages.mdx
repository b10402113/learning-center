# 五階段流程：empathize、define、ideate、prototype、test

<LearningGoal>
能依序說出設計思維五個階段各自在做什麼、產出什麼，並解釋為什麼測試發現問題時可以回頭重走前幾個階段。
</LearningGoal>

## Lesson

設計思維的五個階段依序是同理、定義、發想、原型、測試：先蒐集使用者洞察，收斂出人物誌與問題陳述，在不急著評判的前提下大量發想，做出可測試的原型，再用真使用者驗證；測試若指出問題，就退回定義或發想重走一次。
