# 設計思維：先解決對的問題，再做對的畫面

<LearningGoal>
能說出設計思維為什麼是以人為本的心態而非固定流程，並解釋迭代、跨領域協作與「失敗是踏腳石」在實務上的意思。
</LearningGoal>

## Lesson

設計思維不是一套要照抄的固定流程，而是一種以人為本、允許迭代、鼓勵跨領域協作、並把失敗當成養分的**心態**；五個階段只是把它拆成可操作的步驟。
