# 從迴圈到交付：brief、sitemap、userflow、wireframe、UI、測試

<LearningGoal>
能把抽象的設計思維迴圈對照到真實交付流程，說出每個階段產出什麼、為什麼順序是這樣，以及後面的階段為什麼建立在前面的成果上。
</LearningGoal>

## Lesson

設計思維是「怎麼想」、交付流程是「做出什麼」；真實專案的順序是先理解（brief、研究），再決定結構（sitemap、user flow、wireframe），然後定視覺（branding、styles、UI），最後測試與迭代——每一步的產出都是下一步的輸入。
