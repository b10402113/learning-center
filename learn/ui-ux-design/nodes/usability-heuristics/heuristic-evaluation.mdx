# 用啟示做設計評審：跑一輪 Heuristic Evaluation

<LearningGoal>
能拿 Nielsen 十項啟示當檢查表，對一個畫面跑一輪啟示評估，寫出每一項發現、所對應的啟示與嚴重度，形成可動手的修改清單。
</LearningGoal>

## Lesson

Heuristic evaluation 的流程是：定範圍與情境、逐項走查十項啟示、用固定格式記錄發現、標嚴重度並排序、收斂成修改清單，最後修完重跑一輪驗證，產出一份有依據且可直接動手的清單。
