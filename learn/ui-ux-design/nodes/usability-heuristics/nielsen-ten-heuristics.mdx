# Nielsen 十項可用性啟示：一份設計檢查表

<LearningGoal>
認得 Nielsen 的十項可用性啟示，能說出每一項的意思，並各舉出一個具體的介面例子。
</LearningGoal>

## Lesson

Nielsen 的十項可用性啟示是一份可逐項核對的設計檢查表，涵蓋回饋、貼近使用者、掌控感、一致、防錯、省記憶、可調、專注與協助；它是幫你做判斷的指引，而非硬性規則。
