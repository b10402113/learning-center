# 可用性的核心原則：先降低摩擦，再談漂亮

<LearningGoal>
能說出六個核心可用性原則——一致性、遵循熟悉慣例、載入速度、進度回饋、簡潔、自動儲存——並解釋每一個在降低什麼摩擦、建立什麼信任。
</LearningGoal>

## Lesson

可用性的六個核心原則——一致性、遵循熟悉慣例、速度、進度回饋、簡潔、自動儲存——本質上都在做同一件事：降低使用者的認知負擔，並用可預期性換取信任。
