<LearningGoal>
能畫出 UX 傘下的技能地圖，並解釋為什麼 UI 是 UX 的一部分、為什麼現在的設計師要兩邊都碰。
</LearningGoal>

## Lesson

UX 是一把大傘，傘下包含 User Research、Product Strategy、Information Architecture、Site Maps、User Flows、UI Design 與 Usability Testing；UI Design 是傘下的一格而非與 UX 平行的另一條路，市場上專職的 UX／UI 角色通常由資深且深耕特定領域的人擔任，而現在普遍期待設計師兩邊都能做。
