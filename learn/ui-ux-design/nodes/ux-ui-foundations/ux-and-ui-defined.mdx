<LearningGoal>
能分辨 UX 與 UI 各在處理「使用起來的感覺」還是「看起來的樣子與操作介面」，並用生活譬喻說出兩者的分工。
</LearningGoal>

## Lesson

UI 處理產品的視覺元素與操作介面（按鈕、色彩、字體、圖示、版面），UX 處理使用者與產品互動的整體體驗；用車子外觀／操駕感與室內設計／居住動線兩個譬喻可以分辨兩者，而它們互相依賴，必須一起做才能兼顧實用與好看。
