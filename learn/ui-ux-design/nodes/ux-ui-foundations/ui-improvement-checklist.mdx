<LearningGoal>
認得七個具體的 UI 改善手法、它們各自處理什麼狀況與關鍵數值，遇到介面問題時知道該查哪一條。
</LearningGoal>

## Lesson

七個可查閱的介面改善手段是骨架屏、拇指區、點擊目標（最小約 48px）、收集使用者回饋、減少點擊數、留白與色彩運用，每一條各對應一種具體症狀與它的關鍵數值或做法。
