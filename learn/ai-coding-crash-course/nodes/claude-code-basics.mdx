# 在 CLI 外殼裡熟練操作

## Learning goal

能日常順手使用一套 CLI harness——指令、進階提示技巧、IDE diff 管理、rewind/resume、bash 模式。

## Steps

1. [[learn/ai-coding-crash-course/nodes/claude-code-basics/cli-core-commands|Claude Code 5 大核心指令：/usage /context /clear /terminal-setup / escape]] — 啟動 Claude Code、完成終端設定、掌握核心指令
2. [[learn/ai-coding-crash-course/nodes/claude-code-basics/advanced-prompting|Claude Code 進階提示：@ 引用、暫存與圖片貼入技巧]] — 用 @ 引用檔案、Ctrl+S 暫存草稿、貼上圖片（after step 1）
3. [[learn/ai-coding-crash-course/nodes/claude-code-basics/diff-ide-management|Claude Code IDE 整合：diff 審查安裝與實戰指南]] — 安裝 IDE 整合、在 IDE 中審查代理修改（after step 1）
4. [[learn/ai-coding-crash-course/nodes/claude-code-basics/rewind-resume-fork|Claude Code Rewind Resume Fork：會話回退、恢復與分岔]] — 回退代碼與對話、恢復或分叉過去的 session（after step 1）
5. [[learn/ai-coding-crash-course/nodes/claude-code-basics/bash-execution|Bash 執行指令：讓 Claude Code 跑命令、讀輸出、自動除錯]] — 用 `!` 執行 bash、把輸出推進上下文、背景化長命令（after step 1）

## Lesson

掌握了代理的構成與思考方式之後，下一步是學會真正「開車」。本節以 Claude Code 為示範外殼（harness），帶你熟悉日常操作的核心指令——啟動、設定、查看用量、管理上下文、中斷代理——以及四個進階技巧：用 @ 引用檔案、用 IDE 審查 diff、用 rewind 回退修改、用 bash 模式跑命令。這些操作是你跟代理協作的基礎動作，熟練之後才能把注意力放在設計與交付上，而不是跟工具搏鬥。
