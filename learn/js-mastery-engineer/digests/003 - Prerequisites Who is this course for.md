# L1 overview

- The course targets developers who can already code but are not necessarily senior.
- It avoids beginners: participants need basic coding skills and familiarity with the terminal.
- It is aimed at developers who have used AI for coding and hit trouble on larger projects.
- It addresses common pitfalls such as relying on a single instructions file for complex projects.
- It asks for an adaptable mindset and openness to changing work processes.
- Technical prerequisites are minimal: no specific framework or tool experience is required.
- Participants need a paid plan for the coding agent, upgradeable as needed.
- The foundational modules matter for every developer regardless of experience level.
