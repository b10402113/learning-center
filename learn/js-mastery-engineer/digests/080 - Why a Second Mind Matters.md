# L1 overview

- GA means the public release of an application after thorough verification, the highest tier of functionality assurance.
- /check review has a separate model review the code to find mistakes the author may have missed.
- That model does not share the original assumptions, so its assessment is unbiased.
- Effective review at different stages raises reliability.
- Each tier demands more distance from the original writer.
