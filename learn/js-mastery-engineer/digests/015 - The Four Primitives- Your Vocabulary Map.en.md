# L1 overview

- A short transition lesson: the previous module covered how agents think by reading, deciding, acting, and observing; this module covers what the agent can reach for.
- Claims there are only four primitives and states that number up front so the learner does not restart from zero with each new tool.
- Warns that new tools launch constantly and each invents its own names for the same four things.
- Advises learning the four once and treating every new tool as merely learning somebody's accent.
