# L1 overview

- The lesson argues that context matters more than prompt engineering for AI agent performance.
- Prompt engineering is often treated as the main solution, but a prompt's effectiveness depends on the quality of the context already established for the agent.
- Context engineering means designing what the agent knows before it processes a prompt.
- Systems architecture matters because it sets known parameters before AI tasks.
- The next module covers context types, their appropriate use, and the pitfalls of poor context management.
- Structuring code efficiently is itself part of the context for AI operations.
