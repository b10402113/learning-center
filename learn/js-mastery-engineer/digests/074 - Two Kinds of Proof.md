# L1 overview

- There are two kinds of proof for a feature: real-time functionality and future protection.
- The first checks whether the feature works today, using CheckVerify.
- Alpha tier means the feature is built and proven in real time.
- Beta tier protects the feature against future changes so it keeps working.
- Order matters: verify first, then test, for long-term stability.
- Both verification and testing depend on the acceptance criteria the architect established.
