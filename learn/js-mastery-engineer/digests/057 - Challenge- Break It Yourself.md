# L1 overview

- The challenge asks learners to run the example applications locally using the setup instructions in their READMEs, which requires a free Supabase account and TMDB API keys.
- Part 1 is hands-on setup: get the apps running yourself instead of watching them run.
- Part 2 asks you to find at least one architectural issue that the course examples did not already cover, using the module's insights.
- Part 3 asks you to post the finding in the community with the problem, the specific file and line, and the decision that was left unresolved.
- The target is undecided architecture, not ordinary bug hunting.
- The exercise is meant to build understanding through direct engagement, and it sets up the later agentic engineering workflow.
