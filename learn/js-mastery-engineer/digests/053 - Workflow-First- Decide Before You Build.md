# L1 overview

- The lesson outlines the agentic engineering build as a structured flow from planning to execution with human oversight.
- The scope skill defines core requirements through an interactive interview.
- Features are ordered with foundational decisions (data models, design systems) prioritized.
- The architect skill poses specific choices about the data system, and the choices become acceptance criteria documented in a spec.
- The develop skill follows the architect's plan with user oversight; check-verify runs functional tests against the spec; review cross-verifies the spec with another agent.
- The test skill generates a test suite from the changes made, and sync records shipped features for future sessions.
- The full flow is scope, architect, develop, check, test, sync, in contrast with simpler build methods.
