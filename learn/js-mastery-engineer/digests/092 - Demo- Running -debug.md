# L1 overview

- Providing accurate observations and expectations is crucial for effective debugging.
- Clear reproduction steps streamline the investigation, while vague statements slow the debugging tool's response.
- The Debug Skill enhances investigation by using previous verification data.
- Precise descriptions help formulate hypotheses, and changes should be minimised to one at a time for clarity.
- The goal is the root cause with minimal fixes and subsequent testing, and fixes should always be explainable.
- Debugging requires understanding the author's intent, especially with AI-generated code.

# L2 detail

- `#L1-L9` — why details, accurate observations and reproduction steps matter.
- `#L10-L14` — using the Debug Skill and keeping to one change at a time.
- `#L15-L20` — the root-cause goal, explainable fixes, and recovering the author's intent.
