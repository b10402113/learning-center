# L1 overview

- The lesson is about instilling discipline into engineering procedures so tasks are repeatable under pressure instead of relying on guesswork or memory.
- Engineer the context: make deliberate decisions upfront instead of letting the agent assume.
- Consistency is key: follow the established procedures for every task regardless of fatigue or time pressure.
- Documentation matters: write down crucial decisions and steps so nothing important is lost.
- Size matters: keep changes small enough for thorough review.
- The skill executes the procedure while your judgment stays for critical decisions; only load the procedures you need to reduce context load.
- No magic: writing procedures is straightforward and improves understanding rather than complicating it.
