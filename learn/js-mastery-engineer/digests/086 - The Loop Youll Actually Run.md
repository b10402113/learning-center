# L1 overview

- Lecture summary on workflow and judgment in product development: skills carry the state and the process, while judgment is what makes the decisions.
- Evaluate whether a recommendation aligns with your product's goals.
- Clear the discussion when it becomes unclear or unproductive.
- Value honest results over misleadingly favorable ones.
- Request evidence and choose reviewers whose perspective differs from the author's.
- An agent can work quickly and without fatigue but carries no responsibility for product success or sustainability.

# L2 detail

- `#L1-L9` — framing: skills carry the state and process, judgment handles decision-making.
- `#L10-L17` — practical rules: check recommendations against goals, clear unproductive discussion, prefer honest results, seek evidence and differing reviewers, and note the agent's lack of responsibility.
