# L1 overview

- Assigns a three-part, roughly 30-minute challenge using the attached uncut repos; setup needs only a free Supabase account and TMDB keys per each readme.
- Part one: run both apps locally and feel the vibe app's 40-second feed yourself, because actually waiting differs from watching someone wait.
- Part two: find one killer not already shown. Four were given (uncached AI call, silent rate-limit drops, the 400 title cap, delete-then-insert import); a senior reviewer would find at least three more.
- Hints for part two: inspect how the vibe app validates request bodies, what a user could put in the profile endpoint, and what the vibe search does with the raw query.
- Part three: post one community message naming the problem, the file and line, and one sentence on which decision was never made.
- States the real skill being practiced is hunting undecided architecture, not bugs, which is what senior reviewers are paid for and what to do whenever an agent hands over code.
- Transitions: every decision watched in build 2 — the interview, written specs, the gate that refused to build, the checks — is encoded in the open-sourced agentic engineering workflow skills.
- Next lessons install the system and run it on the learner's own projects.
