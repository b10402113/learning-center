# L1 overview

- /develop runs after the stack is architected and, on a greenfield project, sets up the architectural foundation rather than building features.
- It analyzes existing specifications and dependencies before scaffolding the new project setup.
- It installs dependencies just in time, adding them only when needed to keep the project lightweight.
- The user keeps control and can deviate from the plan for immediate needs, such as building an unspecified UI component.
- The workflow can adapt to visual designs and real-time changes.
- Scope is managed through continual updates so the plan reflects actual progress.
