# L1 overview

- Debugging should follow a scientific method rather than trial and error, to identify and resolve issues effectively.
- The first type of bug is a straightforward code bug addressable with a structured method.
- Debugging means observing failures, forming specific explanations, testing them, and learning from the results.
- Change one thing at a time to understand each change's impact.
- A six-step method is outlined for thorough understanding rather than memorisation.
- Tools can assist, but understanding the underlying method is what separates root cause from symptom.
