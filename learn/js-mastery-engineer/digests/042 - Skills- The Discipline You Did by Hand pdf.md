# L1 overview

- A skill is a procedure you kept doing by hand, written down so the agent runs it instead of you remembering to.
- It does not cost much context because each skill has a short name and description plus a long body; the agent reads only the name and description and loads the body only when it picks that skill.
- This solves the always-on rent problem by structure rather than willpower: many procedures are available, you pay for the one in use and two lines each for the rest.
- The thesis: the skill runs the procedure, you make the calls; it is not a smarter agent and does not improve the model.
- It removes procedural overhead so your attention goes to the decisions that were always yours.
