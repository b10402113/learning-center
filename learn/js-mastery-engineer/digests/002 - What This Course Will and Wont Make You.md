# L1 overview

- Coding has become a commodity because AI can generate code almost instantaneously.
- The durable developer skill is judgment: knowing what to build and how to manage AI tools.
- AI is not replacing roles so much as changing how they function and which skills matter.
- The course teaches judgment rather than better prompting tricks.
- Developers should use AI as a supportive tool, not lean on it for every coding task.
