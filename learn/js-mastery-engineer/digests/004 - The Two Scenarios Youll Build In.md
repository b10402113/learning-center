# L1 overview

- The course focuses on practical workflows that survive real job scenarios rather than theory.
- It opens with hands-on coding guidance showing the pitfalls of hand coding and vibe coding.
- It names two project-start scenarios: client work and personal projects.
- Scenario 1 is new work where vague requirements must be turned into specifications, with early idea validation.
- Scenario 2 is existing work: adding features to pre-existing or legacy codebases.
- Both Greenfield and Brownfield projects are taught with the same workflow and the skills chosen as needed.
