# L1 overview

- The workflow can be fast as well as thorough: you can batch architect several features up front, either answering the questions yourself or letting it choose the recommended answers.
- Once those specs exist, you can develop the features together in a single session; you still own the architecture and can check the specs, but the agent runs on established plans.
- Architecting ahead when you have time gives you both speed and precision because the agent follows explicit specs instead of inventing decisions mid-build.
