# L1 overview

- The lesson explains subagents as a way to keep context clean by moving heavy work into separate spaces while the main agent stays focused on concise results.
- Subagents perform extensive reading and searching without affecting the main agent's context.
- They allow parallel execution by breaking jobs into parts that do not depend on each other.
- Use one when the task is heavy and only the result is needed, or when the job can be divided into independent parts.
- For small, quick tasks a subagent may be unnecessary and can complicate the process.
- The course workflow uses these principles to keep speed and context hygiene.
