# L1 overview

- Opens the agentic engineering workflow module, where prior theory becomes practice.
- The skills are open source and install in one command: `npx skills at latest, add jsmastery pro skills`, optionally with a Claude Code flag.
- The installer asks whether to install the skills installer, then which skills to include; without the flag it asks which agent (Claude Code, Cursor, Codex, etc.) to install for.
- No account or API key is needed because skills are markdown files containing instructions.
- At recording time there are nine skills: architect, audit, check, debug, develop, scope, sync, and test.
- The narrator notes the skills are low risk at recording, may be flagged medium/high later depending on rule changes, and asks viewers to report it.
- Installing globally puts nine folders in the global Claude skills folder, each with a SKILL.md the agent reads; some skills are detailed and include extra modes or patterns.
- For a new project the order is always: scope the idea, architect the stack, set up the project, audit what was created, then enter the develop loop.
