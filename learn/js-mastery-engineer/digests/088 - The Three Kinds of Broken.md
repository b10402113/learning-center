# L1 overview

- There are three primary kinds of break: a normal code bug with observable and reproducible errors, an AI-generated-code failure producing unexpected behaviour, and the agent losing track and repeating actions without solving the core issue.
- Classifying the bug avoids unnecessary cost and wasted time and prevents using the wrong debugging technique.
- A fix you can't explain indicates the underlying problem may still persist.
- Identify the type before attempting a fix, and prefer evidence-based troubleshooting over intuition.
- The next lesson covers methods for the first type.
