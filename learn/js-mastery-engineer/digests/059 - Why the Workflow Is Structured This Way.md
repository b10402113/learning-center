# L1 overview

- The lesson counters the idea that structured workflows are unnecessary when agents write code.
- Software projects have always followed a lifecycle: requirements → design → implementation → verification.
- Architecture decision records matter because they keep the reasoning behind choices from being lost.
- Agents tend to rush straight to implementation, so the process must guide them step by step.
- Teams such as GitHub and Amazon similarly document requirements before engaging agents.
- The point is not writing code faster but making sure essential development steps are not skipped.
