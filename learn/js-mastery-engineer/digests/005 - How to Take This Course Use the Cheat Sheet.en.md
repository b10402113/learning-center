# L1 overview

- Advises building along with the instructor: a workflow only becomes yours when your own hands run it, and watching is worth perhaps a tenth of doing.
- Lays out the course shape: agent fundamentals and context thinking, then a deliberately painful build made without skills, then the JSM workflow as the fix, then real scenarios.
- Emphasizes not skipping the module comparing a manually prompted or vibe-coded codebase against a workflow-built one, because it makes later material click.
- Introduces a cheat sheet that starts empty on purpose; the learner fills in each skill, what it does, and when to reach for it in their own words.
- Explains that self-written notes stick better than downloaded ones, and that an official one-pager is unlocked at the end for comparison.
- Insists on going in order because every module leans on the previous one, especially the legacy workflow, and on attempting challenges before watching solutions.
