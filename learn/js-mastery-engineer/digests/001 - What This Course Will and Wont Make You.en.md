# L1 overview

- Frames AI as having commoditized code writing: a feature described in plain English returns working code, so the skill itself no longer differentiates developers.
- Poses the hiring question — if anyone can generate code, what makes a developer worth hiring — and introduces the author as Adrian of the JS Mastery channel.
- Recounts a viral post and the backlash from junior developers who felt he had no concrete answer for them, which motivated the course.
- Argues the answer is not better prompts, because an AI capable of writing code can also write prompts; the real differentiator is judgment.
- Defines judgment as knowing what to build, pointing the agent at it, reviewing what comes back like a senior reviewing a junior's PR, and shipping work that holds up.
- Claims the agent does not supply judgment but raises the price of lacking it, while judgment itself can be taught.
- Says AI is changing the shape of roles rather than eliminating them, and states the course will not create developers who prompt their way to code they do not understand.
- Concludes that the learner stays the engineer while the AI becomes the fastest junior or mid-level developer they have worked with.
