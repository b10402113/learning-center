# L1 overview

- Opens with a gut check to confirm fit: the course targets developers who already write code, not absolute beginners.
- Describes the primary learner as someone who has used AI only in a chat window, pasting questions and answers until the project grows too large and stops working.
- Describes a second profile: a developer who added a CLAUDE.md file, saw short-term gains, then watched the agent forget, burn tokens, and contradict the file.
- Explains that such failures are not the learner's fault but the result of asking a single instructions file to carry a real project; the missing piece is a workflow.
- Lists minimal technical prerequisites: ability to write code, basic terminal use, and editor navigation, with no specific framework, AI tool, or agent knowledge required.
- Notes that a paid plan for the coding agent is required, starting with the smallest tier and upgrading only at its limits, with details in the next lesson.
- Makes mindset the most important prerequisite: willingness to change how you work, since openness matters more than seniority.
- Advises seniors already running agents daily to move quickly through early modules but slow down for legacy codebases and recovery.
