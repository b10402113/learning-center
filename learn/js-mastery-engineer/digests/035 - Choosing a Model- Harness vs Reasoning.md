# L1 overview

- The model is roughly 20% of the result; the other 80% is the harness: the spec, context management, skills and session discipline.
- A top-tier model with no harness still vibe-codes; a modest model inside a good harness produces solid, reviewable work.
- Cost, speed and reasoning are a spectrum, not a ranking; pick the point the task needs rather than always reaching for the most powerful model.
- Decide vs execute: the deep tier decides (specs, module boundaries, hard debugging) and the fast tier executes (implementation against a written plan).
- Effort or thinking level is the same trade-off one level down; raise it for judgment work and lower it for routine execution.
- In this course's Claude setup the deep tier is Opus and the fast tier is Sonnet; the workflow holds down to roughly Sonnet at high effort or Opus at medium effort.
- Because the model is only a fifth of the result, swapping in a better model later requires no workflow changes.
