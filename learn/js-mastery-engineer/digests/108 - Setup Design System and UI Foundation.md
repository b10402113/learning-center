# L1 overview

- The lesson builds the design system and UI foundation for a mobile-first movie recommendation app, covering visual language and base components.
- The design system includes type, color, spacing, and base components.
- It can be architected from a Cloud Code window, deciding whether a design already exists or must be created from scratch.
- The design uses Tailwind V4 and Schatzian, removing initial setup questions.
- Visual designs may originate from Figma designs or screenshots.
- Research on Dribbble and Behance is encouraged for movie-app-specific UI inspiration.
- Mobile-first prioritisation ensures a native feel on phones, including haptic feedback.
- Active testing and refinement plus accessibility and user-friendliness for all components and navigation are emphasised.
