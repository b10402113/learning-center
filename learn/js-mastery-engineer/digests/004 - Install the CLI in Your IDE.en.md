# L1 overview

- A short setup lesson that assumes most learners already have an environment.
- The course is demonstrated in Claude Code running inside the editor; all ideas are tool-agnostic and port to Cursor, Codex, and other tools.
- The author chose Claude Code because a poll showed the majority wanted it, and he maps each concept to other tools so learners are not locked in.
- Real agentic work needs a paid plan; free tiers are fine for poking around but not for building.
- Recommends starting on the smallest paid tier and upgrading when limits are consistently hit, or going straight to the max plan if budget allows.
- Final steps are installing the CLI and, on VS Code, the Claude Code extension.

# L2 detail

- `#L1-L2` — Framing: the one boring setup lesson, kept fast.
- `#L3-L11` — Tool choice, tool-agnostic principles, the poll, and mapping ideas to other editors.
- `#L12-L19` — Paid plan requirement, tier guidance, and the author's personal recommendation.
- `#L20-L23` — Installing the CLI and VS Code extension; end of setup.
