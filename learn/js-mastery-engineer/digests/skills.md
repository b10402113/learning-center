# L1 overview

- **Repo meta and docs** (`README.md`, `CLAUDE.md`, `docs/`) — the JSM engineering workflow as nine Agent Skills (`scope`, `audit`, `architect`, `develop`, `check`, `test`, `document`, `sync`, `debug`), the install path (`npx skills add JavaScript-Mastery-Pro/skills`), the artifact map (`docs/scope/`, `docs/specs/`, `AGENTS.md`, `design.md`, `docs/reviews/`), and the authoring rules (every line must change behavior, completion summaries lead with the outcome).
- **Helper scripts and CI** (`scripts/`, `.github/workflows/check.yml`, `package.json`) — `check-portability.mjs` enforces 11 cross-tool conventions plus byte budgets, `analyze-token-usage.mjs` attributes a Claude Code transcript's tokens to main thread vs subagents, and `npm run check` runs in CI with zero dependencies.
- **`architect`** — turns one load-bearing decision into a build spec in `docs/specs/`, with four modes (`architecture`, `feature`, `enhancement`, `cross-cutting`), a gated staged conversation that separates INFER / ASK / RECOMMEND decisions, mandatory acceptance criteria and data model, a value-sourcing table, and an `Assumed` status for build-now decisions. This is the concrete template for spec-driven agent work.
- **`audit`** — writes the layered `AGENTS.md` context files (plus a thin `CLAUDE.md` pointer) every other skill reads, routing between greenfield, whole-repo, area, and gap-fill phases, and offering four architecture presets (Clean Architecture, DDD, Functional, SOLID) plus an Agent Skill / MCP discovery sweep.
- **`develop`** — builds from a spec after a gate that stops when a decision is owed, resumes from the first unchecked build-plan task, keeps UI and logical tracks separate, requires a migration to be applied and verified, deletes superseded code, and emits per-AC `verify.md` steps. Shows how to keep an agent from silently inventing design decisions.
- **`check`** — two modes: `verify` drives the real app and proves each acceptance criterion with a cited evidence ledger (never a fabricated PASS), while `review` runs a fresh-model senior review that writes severity-ranked findings to `docs/reviews/`. Demonstrates independent, model-separated verification.
- **`scope`** — turns an idea into a living coarse plan with modes `plan`, `replan`, and `add`, greenfield/brownfield/monorepo routes, four delivery approaches (Tracer Bullet, Skateboard, Facade, Journey), and four workflow tiers (Prototype, Alpha, Beta, GA). The best example of phase planning, deduplication, and "needs spec" routing.
- **`debug`, `test`, `document`, `sync`** — `debug` runs a reproduce → localize → hypothesize → test → fix loop; `test` classifies changed files and writes a git-scoped suite traced to `AC-N`; `document` writes PR/changelog/release-note/postmortem prose from the real diff; `sync` makes surgical, evidence-based reconciliation edits to `AGENTS.md`, the scope, and spec status lines. Together they show the closing half of an agentic engineering loop.
