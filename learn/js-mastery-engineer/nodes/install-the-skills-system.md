# 安裝 JSM Skills 與九個入口

## Lesson

九個 skill 不是新發明的方法論，而是把一個好團隊本來就該跑的流程寫成 agent 讀得懂的檔案。先安裝，再搞清楚每個 skill 對應哪一個階段，以及新專案、既有專案、小修改各自該從哪裡進場。
