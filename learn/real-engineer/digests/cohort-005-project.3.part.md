# L1 overview

- `app/db/schema.ts` — 整個 Cadence 的資料模型：20 張表加 6 個 enum，課程結構、購買與退款、優惠券與團隊、評分、留言、觀看事件全部在這裡定型。`$type<Enum>()` 讓 TypeScript 認得欄位值域，但資料庫層只是 `text`，驗證發生在寫入路徑。
- `app/db/index.ts` — Drizzle + better-sqlite3 的連線層，刻意做成零副作用：`getSqlite()` lazy 開連線，`db` 是 `Proxy` 轉發。理由是避免 route 只 import 一個 service 時把原生 sqlite 綁定拖進瀏覽器 bundle。
- `app/lib/access.server.ts` — 存取權的單一住處：`getAccess()` 回傳一個 `Access` 物件，`requireContentAccess` / `requireStaff` / `requireInstructorOrAdmin` 建在它上面。這是本 repo 少數真正的 deep module。
- `app/lib/ppp.ts` — 購買力平價（PPP）規則：4 個 tier、寫死的國家對 tier 表、`calculatePppPrice`、以及純函式 `checkPppAccess` 決定「折扣購買者換國家是否被封鎖」。
- `app/lib/session.ts` — cookie session 封裝（`cadence_session`），存 `userId` 與 dev 用的 `devCountry`；所有 `*.server` 的授權最終都靠 `getCurrentUserId` 取得身分。
- `app/lib/country.server.ts` — 三層國別解析：dev session override → `CF-IPCountry` header → ip-api.com 查 `X-Forwarded-For`，全部失敗回 `null`（等同 Tier 1）。
- `app/lib/analytics.ts` — 分析頁的純設定與計算：`PLATFORM_FEE_RATE = 0.2`、四個時間範圍、`rangeStart`、`splitRevenue`。明確不碰 DB 或 request，讓 service 與 route 共用同一組數字。
- `app/lib/markdown.server.ts` — 給「信任輸入」（課程內文、sales copy）用的 markdown 渲染器：marked + shiki 高亮，允許原始 HTML。
- `app/lib/comment-markdown.server.ts` — 給「不信任輸入」（學生留言）用的另一個渲染器 `renderComment`：轉義原始 HTML、連結只允許 http/https/mailto 並加 `rel="nofollow"`、丟棄圖片。兩支渲染器分開是刻意的安全邊界。
- `app/lib/validation.ts` — 三個 Zod 橋接器：`parseFormData`、`parseParams`、`parseJsonBody`，把錯誤壓成「每欄位第一個訊息」的 map。
- `app/lib/comments.ts` / `app/lib/ratings.ts` — 各兩行的常數檔：留言長度 1–5000、評分 1–5。前端與 server 共用同一組界線。
- `app/lib/utils.ts` — 通用格式化：`cn`（clsx + tailwind-merge）、`formatPrice`（0 顯示 "Free"）、`daysSince`、`formatRelativeTime`、`formatDuration`。
- `app/root.tsx` / `app/app.css` — 框架外殼與設計 token：dark mode 由 inline script 在 hydration 前套上，`app.css` 用 Tailwind v4 `@theme` 定義整套 oklch 色票與 sidebar 變數。
- `app/components/sidebar.tsx` — 以角色過濾的導覽：`navItems` 每項自帶 `roles`，`isVisible` 決定顯示；另有近期課程進度條與主題切換。
- `app/components/comment-thread.tsx` — 課程討論區：`RenderedComment` 樹（伺服器已渲染 `bodyHtml`）、用 `useFetcher` 送 create/edit/delete intent，刪除是軟刪除。
- `app/components/youtube-player.tsx` — YouTube IFrame API 封裝：`extractVideoId` 吃三種網址格式，播放中每 10 秒打 `/api/video-tracking`，並回報 play/pause/ended。
- `app/components/dev-ui.tsx` — 開發用的浮動面板：切換目前使用者與 PPP 國別，對應 401 錯誤訊息裡那句話。
- `app/components/monaco-markdown-editor.tsx` — 講師寫課程內文用的編輯器：Monaco 動態載入、自訂 `cadence-dark` 主題、把 Prettier 註冊成 markdown formatter、Cmd+S 先排版再存。
- `app/components/star-rating.tsx` — `StarRating`（唯讀平均，用裁切做出半星）與 `StarRatingInput`（每顆星是 submit button，無 JS 也能評分）。
- `app/components/user-avatar.tsx` / `app/components/course-image.tsx` — 兩個防破圖的顯示小件：頭像取姓名首字母，課程封面失敗時退回書本圖示。
- `app/components/ui/*.tsx` — 9 個 shadcn/Radix 風格的基礎元件（button、card、chart、input、label、select、skeleton、tabs、textarea），幾乎沒有業務邏輯，只有 `chart.tsx` 的 `ChartConfig` 與主題注入稍微複雜。
- `app/lib/*.test.ts` / `app/test/setup.ts` — 四支 vitest 測試（PPP、analytics、留言渲染安全、國別解析）加上測試工具：`createTestDb()` 用同一份 drizzle migration 開 in-memory SQLite，`seedBaseData()` 鋪一組 user/instructor/category/course。
