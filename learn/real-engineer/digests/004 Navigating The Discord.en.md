# L1 overview

- 這門課雖然主要自學，但 cohort 的價值在社群：每個人都會卡住，卡住就去 Discord 問。
- 公開區頻道涵蓋 General、各產品線（AI Hero、Everlight、Soundcastle、Skills）、strategic programming、Showcase、Jobs、Random。
- AI Coding Crash Course 與 Cohort 005 的頻道在下方，要看到 Cohort 005 需要 `Cohort 005` role，購買時應該已指派。
- 最重要的頻道是 Questions：先搜尋是否已有答案，再自己發問；其他閒聊走 General。
- 拿不到權限先仔細找隱藏頻道，再不行寄信到 `team@AIHero.dev`。
- 多回答問題可能被授予 hero role，作者在 cohort 期間會請兩週假待在 Discord 回答問題。

# L2 detail

- `#L1-L5` — cohort 形式帶來社群與提問機會；卡住是必然的，Discord 就是提問的地方。
- `#L6-L12` — 公開頂部區塊對所有人開放：General、AI Hero、Everlight、Soundcastle、Skills，還有 strategic programming（軟體基本功社群）、Showcase、Jobs、Random；AI Coding Crash Course 與 Cohort 005 專屬頻道在其下方。
- `#L13-L22` — Random 有 mod Raphael 貼的狗照片；最關鍵的是 Questions 頻道——可搜尋既有問題是否已解答，也可自己發問；其他切題的閒聊放 General；Crash Course General 熱絡，Cohort 005 General 剛建立還很安靜。
- `#L23-L31` — 進入 Cohort 005 需要 `Cohort 005` role，購買時應有連結可點，另有一個 role 連結會把 AI Hero 帳號接上 Discord；若連結失效看不到頻道，務必再三確認（頻道常藏在眼前），仍不行就寄 `team@AIHero.dev`；其他 role 包含 moderators（Matt、Raphael、Chinstrap）與紅色的 heroes。
- `#L32-L37` — hero role 頒給特別熱心的人，像 Camille、Jasper 這種大量回答問題者可能被作者親自授予。
- `#L38-L49` — Discord 的價值在於和處境相同的人交換想法；這個 cohort 會很大，成員包含進階學習者、轉職資深工程師、完全沒有程式經驗的人；cohort 期間作者會請兩週假，在 Discord 回答問題與討論教材。
