# L1 overview

- 課程收尾，作者逐一說明每個章節如何餵養整座 software factory，這是他自己對全課論證的總結。
- Crash course：理解 agent、human in the loop、實際與 agent 保持互動，是建立信任、榨出效能的基礎，後面越深入越能感受到它的回報。
- Domain language：對齊語言與建 glossary 的投資貫穿全程——在 review、在設計符合領域語言的 codebase、在 Wayfinder 的規劃、也在工廠裡的人機溝通都回本。
- Wayfinder 雖然被排在「煞車」區，實際上更是加速器：它是把更多工作推過工廠的規劃解，也是作者尋覓半年的高效規劃方案。
- Review 可能是全課最關鍵的一段：所有人都在問 human review 怎麼辦，而 review 章節就是答案。
- Codebase design 與 feedback loop 難以拆開教學，因為設計得越好、越可能建立好的自動檢查；feedback loop 同時也是 verification，再往上一層建立信任。
- Software factory 章節的目的，是讓「自己的工廠可以放著跑、需要時才叫你」變得具體，並把基礎設施的選擇做實。
- 全課主線始終是：先裝煞車建立信任，再踩油門擴大產能，而每一段都在為此服務。
