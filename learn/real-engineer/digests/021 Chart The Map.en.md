# L1 overview

- 練習題：Cadence 要做真正的 in-app notifications，需要第三方服務、通知鈴位置、設計與事件清單都還不明。
- 判斷時機的法則：當你感覺到面前的 fog of war、對「怎麼走到 destination」感到緊張，就是該開 Wayfinder 的時候。
- 開場 prompt 要講清楚 destination 是 spec，不是做完的功能。
- 第一個 session 只做 charting：找出 fog of war、定出 destination，不是把功能做完。
- 回答「我不知道」完全可以，這階段本來就很多未知。
- 觀察重點：注意有沒有 research ticket 落下、落下後發生什麼事，結束後去讀 map 與 ticket。

# L2 detail

- `#L1-L17` — 前提回顧，並以 Cadence 的 in-app notifications 為題：要留住學習者、通知講師有留言、手機要會震；清楚點出霧在哪（UI 長相、鈴鐺位置、要通知哪些事件），並把「感覺到霧」當成啟動 Wayfinder 的訊號。
- `#L18-L27` — 開 Wayfinder session 描述功能；destination 要設成 spec 而非完成的功能，且要在初始 prompt 講明；第一場 grilling 允許說「我不知道」，目的只是 charting 與定位霧。
- `#L28-L33` — 交代觀察任務：留意是否有 research ticket 落地及其後續，並在塵埃落定後去讀 map 與各張 ticket。
