# 選自己的基礎設施，白板你的 task

## Lesson

GitHub 是最好的教學工具，不是唯一的生產選擇：一個能運作的 software factory 由五個可替換的部件組成，而且決定的順序就是優先順序。選定之後，離開 terminal 回到白板，把每一個 task 同時標上「做什麼」與「在哪個部件上做」，工廠的形狀才會從抽象變成可施工。
