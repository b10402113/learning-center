# 三道煞車與 PR 的呈現方式

## Lesson

品質是分層堆上來的：automated checks 花 CPU、automated review 花 token、human review 花你最貴的注意力。人審之前，PR 自己就要說得清楚——Summary 先講 why、Evidence 給 before/after、Merge Danger 用 one-way/two-way door 與 blast radius 決定該審多深。
