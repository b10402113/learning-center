# Harness 裡面有什麼：記憶、工具、持久化

<LearningGoal>
能列出 harness 必須解決的三類問題——記憶（短期／長期／暫存／事實）、工具（自有實作或 MCP）、長程任務（持久化執行）——並各舉一個實例。
</LearningGoal>

## Lesson

harness 必須解決三類問題：記憶（短期／長期／暫存／事實）、工具（自有實作或 MCP，外加 tool server 的管理）、長程任務（以持久化執行撐過關窗與重啟）。
