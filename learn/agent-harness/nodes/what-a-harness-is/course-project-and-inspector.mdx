# 課程專案與 Inspector 的驗證面

<LearningGoal>
能說出課程專案的結構（harness／runtime／server／shared／web）、`npm run dev` 起動的 inspector 兩欄各顯示什麼，以及 event stream 為何成為每個能力的驗證面。
</LearningGoal>

## Lesson

課程專案以 harness/ 為核心、runtime.ts 是 agent 迴圈；npm run dev 起動的 inspector 用同一條 event stream 同時顯示 chat 與原始事件，event log 即系統真相，成了每個能力的驗證面。
