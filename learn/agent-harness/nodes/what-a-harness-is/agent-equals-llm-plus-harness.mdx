# Agent = LLM + Harness

<LearningGoal>
能說出「agent = LLM + harness」這個等式，並解釋為什麼 harness 是讓 agent 可靠、可依賴的那一層基礎設施，而不是可有可無的包裝。
</LearningGoal>

## Lesson

Agent 是由「會想的 LLM」加上「讓它在真實世界可靠運作的 harness」組成的：沒有 harness 就只剩一次性交易推論；harness 是 agent-agnostic 的基礎設施，它決定了 agent 能不能被信賴、能不能把成果落地。
