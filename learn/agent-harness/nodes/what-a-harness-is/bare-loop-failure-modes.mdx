# 裸迴圈的失敗模式

<LearningGoal>
能描述一個沒有 harness 的裸 LLM 迴圈會在哪幾種情境下失敗——只有一次性交易推論、無記憶、無持久化、無法自癒——並指出每種失敗對應缺失的哪一層。
</LearningGoal>

## Lesson

裸 LLM 迴圈會以四種方式壞掉——只有一問一答的交易推論、金魚般的失憶、一關窗就死、壞了不會自癒——每一種都對應回 harness 缺的那一層。
