# 何時用 Claude Code、何時自己建

<LearningGoal>
能在「用現成的 coding harness（Claude Code / Codex）還是自己寫 programmatic agent」之間做判斷，並說出「最好的 harness 勝過最好的模型」這條理由。
</LearningGoal>

## Lesson

寫程式、分析、做原型可以直接用 Claude Code 這類現成 coding harness；但要多用戶、生產環境、非 coding、需要確定性工作流時就要自建 programmatic agent。決定成敗的是 harness 而非模型。
