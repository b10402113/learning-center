# Code Mode：一段程式取代多次往返

<LearningGoal>
能說出 code mode 是什麼、為什麼 agent 產生的程式碼不能在開發機或生產伺服器上直接執行，以及沙箱必須「逃不出去」的理由。
</LearningGoal>

## Lesson

code mode 讓模型在一支程式裡把多次工具呼叫串成「一次往返」，但這份由模型生成的程式只能在一個「逃不出去」的沙箱裡執行——它不能用模型生成的程式碼，直接去碰開發機或生產伺服器。
