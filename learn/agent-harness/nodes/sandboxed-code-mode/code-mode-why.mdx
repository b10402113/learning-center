# Code Mode：一段程式取代多次往返

<LearningGoal>
說出 code mode 的價值（把十幾次工具往返壓成一次「寫程式、跑、拿結果」），以及為什麼 agent 產生的程式碼不能直接跑在你自己的機器或伺服器上。
</LearningGoal>

## Lesson

Code mode 讓模型一次寫出串接工具的程式，把十幾次「呼叫、等待、推理、回傳」壓成一次「寫程式、跑、拿結果」；它可靠是因為模型擅長寫程式卻不擅長心算，而它生成的程式必須關進一個逃不出去的沙箱，課堂用的 `node:vm` 只是方便練習的中介點、不是能上線的安全邊界，這項能力也是工具箱裡的選項、不是每個 agent 的標配。
