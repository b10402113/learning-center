# 實作 runInSandbox：node:vm 的沙箱邊界

<LearningGoal>
能用 `node:vm` 寫出 `runInSandbox` 的完整流程：建立 context、只注入 `tools` 與 `console.log`、用 async IIFE 包住程式碼、再以 `Promise.race` 對上 timeout，返回 `{ ok }` 結果。
</LearningGoal>

## Lesson

`runInSandbox` 用 `node:vm` 造最小 context、只注入白名單 `tools` 與攔截式 `console.log`、把程式包成 async IIFE 以支援頂層 `await`，再用 `Promise.race` 讓程式與 timeout 對決，最後用 `{ ok }` 標記成敗。
