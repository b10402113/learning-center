# 實作 runInSandbox：node:vm 的沙箱邊界

<LearningGoal>
用 `node:vm` 寫出 `runInSandbox(code, api, options)`：用 `createContext` 注入白名單 `tools` 與擷取式 `console`、用 async IIFE 讓模型能寫 top-level `await`、用 `Promise.race` 綁 timeout，最後回傳 `{ ok, result, logs }` 或 `{ ok, error }`。
</LearningGoal>

## Lesson

用 `node:vm` 寫出 `runInSandbox(code, api, options)`：`createContext` 只注入白名單 `tools` 與擷取用的假 `console`、async IIFE 讓模型能寫 top-level `await`、`Promise.race` 綁兩秒 timeout，最後回傳明確的 `{ ok, result, logs }` 或 `{ ok, error }`；`ok` 旗標是為了讓讀結果的模型一眼判別成敗。
