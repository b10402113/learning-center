# run_code 工具：把沙箱接進 harness

<LearningGoal>
能定義 `runCode` 工具（description + code schema）、建出只開放 `getCharges` 與 `searchKnowledgeBase` 的 sandbox API，並在 `runTool` switch 裡接上它，體會「定義工具、處理工具」的固定節奏。
</LearningGoal>

## Lesson

把沙箱接成一支工具就是「定義工具、處理工具」：定義 `runCode`（description 告訴模型能 `await` 哪支白名單函式、schema 只要一個 `code` 字串），再在 `runTool` switch 裡把 code 送進 `runInSandbox`，sandbox API 只開放唯讀的 `getCharges` 與 `searchKnowledgeBase`。
