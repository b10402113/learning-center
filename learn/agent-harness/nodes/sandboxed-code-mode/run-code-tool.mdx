# run_code 工具：把沙箱接進 harness

<LearningGoal>
定義沙箱 API（`getCharges`、`searchKnowledgeBase`）與 `run_code` 工具，並在 `runTool` switch 接上 `runInSandbox`，讓 agent 用一段程式取代一串工具呼叫。
</LearningGoal>

## Lesson

定義沙箱 API（`getCharges`、`searchKnowledgeBase`，並把搜尋抽成共用的 `searchKB`）與 `runCode` 工具，再於 `runTool` 的 switch 把模型的 `code` 導向 `runInSandbox`；關鍵是工具 `description` 要講清楚用途、程式形式與可呼叫的 `tools.*`，而新增工具的節奏永遠是「定義工具、處理工具」。
