# 為何 code 勝 inference，與 vm 不是真正的邊界

<LearningGoal>
能解釋為什麼讓模型「寫程式再執行」比「用推論做算術」可靠（算術跟日期會幻覺），並說得出 `node:vm` 只是中介點、不是真正的安全邊界，生產環境該用託管沙箱。
</LearningGoal>

## Lesson

讓模型「寫程式再執行」比「用推論算術」可靠得多——推論做算術、認日期會幻覺，程式卻是確定性的（demo 真的算出 $49 退款）；但 `node:vm` 只是中介點、不是真正的安全邊界，生產環境要換託管沙箱或獨立 process。
