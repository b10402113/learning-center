# 為何 code 勝 inference，與 vm 不是真正的邊界

<LearningGoal>
用 $49 退款 demo 說明為何算術交給程式碼比交給推論可靠，指出 timeout 由誰在哪裡設定，並說清楚 `node:vm` 只是中介點、不是真正的安全邊界。
</LearningGoal>

## Lesson

面對一個任務，先問結果是否牽涉精確算術、日期或可重現性：是就用 code 模式讓模型寫程式在沙箱執行，否就用推論直接回答；但 `node:vm` 只是中介點、殺不掉漏出的 async 工作，要上線服務就該換成託管隔離沙箱。
