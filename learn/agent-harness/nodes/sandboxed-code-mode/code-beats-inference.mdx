# 為何 code 勝 inference，與 vm 不是真正的邊界

<LearningGoal>
用 $49 退款 demo 說明為何算術交給程式碼比交給推論可靠，指出 timeout 由誰在哪裡設定，並說清楚 `node:vm` 只是中介點、不是真正的安全邊界。
</LearningGoal>

## Lesson

用 $49 退款 demo 證明模型寫程式比用推論算數可靠（推論是機率的、數字與日期會幻覺，程式則可重現），timeout 在 `runTool` 呼叫 `runInSandbox` 時以 `options.timeoutMs` 設定；最後收在最重要的警告：`node:vm` 殺不掉漏出的 async 工作，只是中介點，正式部署要用 e2b 這類託管隔離沙箱。
