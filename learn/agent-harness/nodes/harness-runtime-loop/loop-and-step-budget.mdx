# Agent Loop 與 Step 上限

<LearningGoal>
能寫出 while 迴圈的 step 記數與 maxSteps 上限，並解釋為什麼 harness 要自己擁有這個迴圈、而不是用 SDK 內建的 loop。
</LearningGoal>

## Lesson

harness 自己擁有 agent loop——用 `while` 迴圈與 `maxSteps` 上限管制失控，並只把「呼叫模型」這一件事交給 AI SDK，以保住換 SDK、換語言都不動核心的可攜性。
