# Stream Part 轉成 Harness 事件

<LearningGoal>
能把 stream part 的類型對應到 harness 事件（modelDelta / toolRequest / toolCompleted / workflowFailed），並說出為什麼要一併送出工具參數。
</LearningGoal>

## Lesson

依 `part.type` 把 provider 的 chunk 翻譯成 harness 事件（`text-delta`→`modelDelta`、`tool-call`→`toolRequest`、`tool-result`→`toolCompleted`、`error`→`workflowFailed`），並送出工具參數讓審批者看得見將發生的動作。
