# streamText 與串流迴圈

<LearningGoal>
能解釋 streamText 為何不 await、for-await 如何逐段迭代 fullStream，以及為什麼串流是不可讓步的體驗底線。
</LearningGoal>

## Lesson

`streamText` 回傳的是一條不 await 的流，用 `for await` 逐段迭代 `fullStream` 裡的各種 chunk；串流是把「等待」變成「正在發生」的不可讓步底線。
