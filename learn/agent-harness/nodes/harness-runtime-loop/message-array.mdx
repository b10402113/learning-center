# 訊息陣列：模型的對話契約

<LearningGoal>
能說出 ModelMessage 的結構與四種 role，並解釋為什麼每一輪都得把整段對話重新送給模型。
</LearningGoal>

## Lesson

模型不保留任何伺服器端記憶，所以每一輪呼叫都得把整段對話（`ModelMessage` 陣列，含 `system` / `user` / `assistant` / `tool` 四種 role）重新送給它——harness 就是替模型記住對話的那個人。
