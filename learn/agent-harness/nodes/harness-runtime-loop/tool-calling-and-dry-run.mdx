# 工具呼叫語意與 Dry Run

<LearningGoal>
能說出「LLM 不執行工具、只請求工具」的語意，把完成的回應 append 回 messages，並用 dry run 辨識裸迴圈還缺什麼。
</LearningGoal>

## Lesson

模型只請求工具、不執行工具，harness 依 `toolCallId` 跑函式再把結果餵回、並把完成回覆 append 回 `messages`；dry run 則暴露出重複副作用與缺審批這兩個裸迴圈缺口。
