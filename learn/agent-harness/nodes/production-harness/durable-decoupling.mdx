# Durable 解耦：讓 run 不再依附 client

<LearningGoal>
能解釋 durable execution 如何把 agent run 與 client 解耦（SSE 重整、關頁面都不丟失），並判斷何時該把它從「可延後的下一步」升級成非有不可的一層。
</LearningGoal>

## Lesson

durable execution 把 run 的身分與狀態（workflow id、event log）從 client 連線切開，讓 SSE 重整、關頁面、server 重啟都不丟失工作；對短命的 chat agent 可以延後，但工作壽命超過一次連線、或需要背景完成與審批等待時，它就變成地基。
