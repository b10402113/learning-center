# 最小可上線的 Harness 清單

<LearningGoal>
能排出 chat agent 上線的最小 harness 清單與建置順序——tool calling、自己掌握的記憶、記憶壓縮——並說明 durable 解耦為何可以延後、turn limit 如何防止迴圈跑飛。
</LearningGoal>

## Lesson

chat agent 的最小可上線清單是 tool calling（SDK 免費附帶）、把記憶持久化到自己控制的儲存、以及記憶壓縮，再加一個約十步的 turn limit；durable execution 解耦 client，是最該延後的一項。
