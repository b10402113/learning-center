# 無限／背景 agent 與 inbox

<LearningGoal>
能描述無限／背景 agent 的運作模型——給一個任務或等一個事件、無限地跑、用 inbox 對外交互——並說明為何它不需要 messages API，以及真正難的是 eval 與約束。
</LearningGoal>

## Lesson

無限／背景 agent 不是拿來聊天的：它被給一個任務或待命等事件，然後持續地跑；durable execution 是入場券，messages API 因沒有對話而多餘，互動改由 agent 主動投遞的 inbox 承擔——真正難的是 eval 與約束。
