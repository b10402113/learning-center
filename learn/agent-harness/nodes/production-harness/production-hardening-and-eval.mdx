# 生產硬化：託管沙箱與 eval

<LearningGoal>
能判斷何時該把工具執行從本機 `node:vm` 移到託管沙箱、用 eval 驗證每一次改進，並用「多用戶、非寫程式的產品」這條線決定該自建 programmatic agent 還是用現成 harness。
</LearningGoal>

## Lesson

生產硬化的兩條主線是：把本機 `node:vm` 換成託管沙箱（保留自訂介面、只換實作），以及用 eval 驗證每一次改動；而「多用戶、非寫程式的產品」這條線決定你該自建 programmatic agent，因為現成 harness 無法強制決定性流程。
