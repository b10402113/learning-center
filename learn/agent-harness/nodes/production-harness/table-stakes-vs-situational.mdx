# Table stakes 與 situational：從目標體驗反推

<LearningGoal>
能從要交付的體驗反推 harness 需求，分辨 table stakes（tool calling、記憶）與 situational（durable、guardrail、approval、PII、自評迴圈），並用 trading agent 的例子說明同一份清單為何不能套用到所有 agent。
</LearningGoal>

## Lesson

harness 的優先序要從目標體驗反推：tool calling 與記憶是 table stakes，durable、sandbox、approval、PII、自評迴圈則是 situational——同一個 trading agent 的例子就會逼出自癒、護欄、審批與自評一整串需求。
