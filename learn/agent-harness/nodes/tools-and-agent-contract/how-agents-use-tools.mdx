# 一個 agent 是怎麼呼叫工具的

<LearningGoal>
能說出一個沒有 harness 的 agent 是怎麼用工具完成一件事的（工具呼叫 → 拿到結果 → 迴圈直到有信心回答），並列出三種讓這個裸迴圈在生產環境失敗的原因。
</LearningGoal>

## Lesson

沒有 harness 的 agent 靠「工具呼叫 → 拿結果 → 再判斷」的裸迴圈做事，但它無限、無審批、可靠性靠機率，會在生產環境以三種方式失敗——evals 補機率那一半，基礎設施（infrastructure）補結構那一半。
