# system prompt：agent 的底層契約

<LearningGoal>
能區分 system prompt 與使用者訊息，說明它承載什麼（背景、人設、背景脈絡）與它的代價（吃 context window），並說出為什麼把其他產品的 system prompt 挖出來其實不是大事。
</LearningGoal>

## Lesson

system prompt 是 agent 的底層契約——承載背景、人設與脈絡、貫穿整段對話，代價是每回合吃掉 context window 的空間；它只是軟建議而非安全邊界，所以被公開也不是大事。
