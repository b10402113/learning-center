# 送出的工具：護欄不能只寫在 prompt

<LearningGoal>
用 `send_reply` 這個真的會寄出草稿的工具，說出為什麼「未經使用者同意前不要使用」這類護欄寫在 description 或 prompt 文字裡必然失效，以及真正的強制必須落在 harness 層。
</LearningGoal>

## Lesson

像 `send_reply` 這種真的有副作用（寄出／退款）的工具，其護欄寫在 description 或 prompt 文字裡必然失效，因為文字對模型只是軟性建議；真正的強制必須寫進 harness 層的執行程式——模型只負責「提議」，harness 才是「執行」的那隻手。
