# 什麼是 Agent Harness

## Learning goal

建立「agent = LLM + harness」的心智模型，說得出裸迴圈的失敗模式，判斷何時該用 Claude Code、何時自建，並看懂課程專案與 inspector 的驗證面。

## Steps

1. [[learn/agent-harness/nodes/what-a-harness-is/agent-equals-llm-plus-harness|Agent = LLM + Harness]] — 認識「agent = LLM + harness」這個等式，理解 harness 是讓 agent 可靠的那層基礎設施
2. [[learn/agent-harness/nodes/what-a-harness-is/harness-components|Harness 裡面有什麼：記憶、工具、持久化]] — 拆解 harness 要解決的三類問題（after step 1）
3. [[learn/agent-harness/nodes/what-a-harness-is/bare-loop-failure-modes|裸迴圈的失敗模式]] — 一個沒包 harness 的裸 LLM 迴圈會在哪裡壞掉（after steps 1–2）
4. [[learn/agent-harness/nodes/what-a-harness-is/when-to-build-vs-buy|何時用 Claude Code、何時自己建]] — 在現成 coding harness 與自建 programmatic agent 之間做判斷（after steps 1–2）
5. [[learn/agent-harness/nodes/what-a-harness-is/course-project-and-inspector|課程專案與 Inspector 的驗證面]] — 看懂課程 repo 與 inspector 的 event stream 驗證面（after step 1）

## Lesson

這節課要在動手寫任何程式碼之前，先把你腦中「agent」這個詞拆成兩半：模型（LLM）負責「想」，harness 負責「讓它在現實世界裡可靠地運作」。裸的 LLM 呼叫只是一次性交易推論；加上 harness 之後，它才長出記憶、工具、持久化與自癒能力，才談得上是一個能交付工作的 agent。

拆完定義之後，我們會分別看看拆掉 harness 會發生什麼（裸迴圈的失敗模式），以及什麼時候該伸手拿現成的 Claude Code、什麼時候得自己寫。最後落到課程專案上：你會在 inspector 的 event stream 裡，用同一條事件串流去驗證後面每一層能力。走完這五步，你應該能對任何一個 agent 產品說出「它缺了哪一層 harness、值不值得自己補」。
