# 選擇 DBOS + Postgres 與取得資料庫

<LearningGoal>
能說出 DBOS 如何用 workflow ID 記錄/重播 step 的輸入輸出、讓失敗的工作流跳過已完成的工作、且 step 必須冪等；比較 DBOS 與 Temporal／Cloudflare／Inngest／Upstash／Vercel Workflows，並用 Neon 取得一個 Postgres 資料庫。
</LearningGoal>

## Lesson

DBOS 用 workflow ID 記錄／重播每個 step 的輸入輸出，讓失敗的工作流跳過已做過的工作，而你要負責把 step 寫成冪等；相較 Temporal／Cloudflare／Inngest／Upstash／Vercel Workflows 這些 service-based 方案，DBOS 幾乎不用改 code 且是 database-backed；再用 Neon 取得 Postgres（記得拔 -pooler）。
