# CI/CD：一套早已熟悉的分散式系統

<LearningGoal>
能用 CI/CD（Jenkins、GitHub Actions）當心智模型，把 durable execution 的 retry、replay、cache、非同步回報、斷線恢復對應到具體的分散式系統行為。
</LearningGoal>

## Lesson

CI/CD 本身就是分散式運算，它的 retry／replay／cache／非同步回報／斷線恢復，正好是 durable execution 機制的具體對照；agent 的執行要像 CI/CD 一樣分散、獨立、能從斷點接續。
