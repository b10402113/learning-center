# 執行要活得比任何觀察者久

<LearningGoal>
能說出 durable execution 的定義——執行要能抗故障、獨立於任何觀察者而存活——並用「ChatGPT 回覆到一半斷線」的場景拆出 checkpointing、fault tolerance、resilience 三個要件。
</LearningGoal>

## Lesson

durable execution（持久化執行）的核心在於「執行要活得比任何觀察者都久」：不管 client 或 server 誰先掛掉，都該能接續，靠 checkpointing（檢查點）、fault tolerance（故障容忍）、resilience（韌性）三個要件把 agent 推進分散式運算的領域。
