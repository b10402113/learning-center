# 不可逆的動作為何不能重跑

<LearningGoal>
能解釋兩個具體危害——訊息全放在記憶體會在重啟時消失、send_reply／轉帳這類不可逆動作不能 undo——並用冪等（idempotency）與 exactly-once 語意說出不可逆動作為何必須「只做一次」。
</LearningGoal>

## Lesson

訊息全放在記憶體會在重啟時消失，而 send_reply／轉帳這類 destructive action（不可逆動作）無法 undo、重跑會重複發生；解法是讓動作冪等（idempotency），再由冪等的 step 堆出 exactly-once。
