# 唯讀 investigators：註冊表與最小權限

<LearningGoal>
能用 Record<string, investigator> 註冊 billing / technical / sales，各自只拿職責內的 getCharges 或 searchKB，並用 generateText 讓 runInvestigator 以有界步數單次執行。
</LearningGoal>

## Lesson

investigator 是唯讀的 sub-agent，用 `Record<string, investigator>`（systemPrompt + tools）註冊，各自只拿職責內的工具以落實最小權限；因為重跑安全，`runInvestigator` 能用 `generateText` 以 `stopWhen: stepCountIs(5)` 有界地 inline 單次執行。
