# 平行 dispatch、fan-in 容錯與 supervised 路由

<LearningGoal>
能用 plan.steps.map 對每個子 agent 起一個平行 DBOS step、以 allSettled 收集 fulfilled 的 findings、對失敗的發 SubagentFailed 事件並繼續，將 synthesize 包成 step，最後註冊 workflow 並用 mode === 'supervised' 路由。
</LearningGoal>

## Lesson

dispatch 用 `Promise.allSettled` 對 `plan.steps.map` 起平行子 agent step（各自獨立 context、整批一起重試），fan-in 只收 fulfilled 的 findings、對 rejected 發 `SubagentFailed` 後繼續走，`synthesize` 包成 step 並以 `DBOS.registerWorkflow` 註冊，最後由 `message.mode === 'supervised'` 路由進入。
