# 持久化的 supervisor workflow 與 synthesize

<LearningGoal>
能建立第二條 DBOS workflow（supervisorWorkflow），把 makePlan 包進 runStep 讓 plan 只計算一次並成為可持久化的一級產物，用 event 當 checkpoint，並實作 synthesize 把多份 findings 收斂成單一回覆。
</LearningGoal>

## Lesson

第二條 `supervisorWorkflow` 把非決定性又昂貴的 `makePlan` 包進 `DBOS.runStep`，讓 plan 只計算一次並被永久保存，事件則當作 checkpoint；`synthesize` 用 `generateText`、以 support lead 的角色把 findings 收斂成單一回覆，並對缺失的調查簡短承認。
