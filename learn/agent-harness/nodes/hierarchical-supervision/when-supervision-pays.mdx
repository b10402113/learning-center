# 階層式監督何時划算：隔離與 fan-out

<LearningGoal>
能判斷何時該用 supervisor 與 sub-agents（隔離邊界如 git worktree、研究型 fan-out 與 context 切分），並說明 plan mode 為何由使用者明示開啟而非自動判斷。
</LearningGoal>

## Lesson

階層式監督與 handoff 的差別是「主管是否保留控制權」；扇出只在有清楚隔離邊界（如 git worktree）或題目塞不進單一 context 時才划算，plan mode 因自動判斷需要 evals 而改由使用者明示開啟，且 plan 是一份被建立、儲存、可驗證的一級產物。
