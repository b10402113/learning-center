# 把 plan 做成一級結構化產物

<LearningGoal>
能說明 generateObject 相對 generateText 的差異，用 zod 定義 plan schema（steps 內含 id / agent / objective）並以 z.infer 取型別，實作 makePlan；同時知道 generateObject 已被標記 deprecated 的替代寫法。
</LearningGoal>

## Lesson

`generateObject` 回傳保證符合 zod schema 的 JSON，讓 plan 成為可驗證的一級產物；`PlanSchema` 以 `steps[{id, agent, objective}]` 描述，`z.infer` 推導出 `Plan` 型別，`makePlan` 以此產生計畫——同時要知道 `generateObject` 已 deprecated，新寫法應改用 `generateText` 搭配 output 設定。
