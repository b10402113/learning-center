# 判斷：何時拆 agent，handoff 到底是什麼

<LearningGoal>
能判斷何時才該把功能拆成多個 agent（權限邊界而非工具數量），區分 handoff 是「完全交出控制權」而 subagent 是「委派並回報」，並識破 swarm 陷阱。
</LearningGoal>

## Lesson

拆 agent 的唯一正當理由是權限邊界、不同護欄、團隊歸屬或職責劃分等約束，而不是工具數量；handoff 是完整且永久的控制權轉移（原 agent 退場、不監督、不收回），與保留單一窗口的 subagent 是拓撲上的差別，而非能力高低；在還沒真的遇到問題前就架 swarm，多半只是燒錢的敘事。
