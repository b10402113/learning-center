# 把 agent 變成資料：三個欄位

<LearningGoal>
能把 agent 收斂成 name + systemPrompt + toolSet 三個欄位，做出 triage 與 billing 兩個 agent，並解釋最小權限（退款只給 billing、triage 只靠 handoff）為何勝過把每個工具發給每個 agent。
</LearningGoal>

## Lesson

一個 agent 收斂成 name + systemPrompt + tools 三個欄位，其餘 runtime、記憶、持久化全部共用；triage 是入口、工具集刻意不含 issueRefund，billing 才持有退款特權，而 draftReply／sendReply 因收尾需要而人人都有——最小權限靠工具集讓它「做不到」，prompt 只是第二道鎖。
