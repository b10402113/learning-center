# runtime 攔截 handoff：橫向控制權轉移

<LearningGoal>
能定義 handoff 與 issueRefund 工具，說明為何 handoff 必須由 runtime 攔截（agent 無法把自己換掉），並追蹤 currentAgent 的攔截、event 與交換流程。
</LearningGoal>

## Lesson

handoff 與 issueRefund 都是以 zod 定義、沒有 execute 的工具；handoff 故意不在工具層處理，因為那樣的結果只會回到同一顆 agent 的 context，唯有 runtime 能在 currentAgent 上攔截、以 DBOS.runStep 發出 durable 的 agent_handoff 事件（from／to／reason），再以 agents[to] 查表換人——控制流原語住在 harness，不住在 LLM。
