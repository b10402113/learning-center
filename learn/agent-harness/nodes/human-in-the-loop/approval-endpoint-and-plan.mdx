# 送審端：/api/approve、UI 按鈕與 plan 審批練習

<LearningGoal>
能用 server 的 /api/approve/:workflowId 透過 DBOS.send 把決定送進被暫停的 workflow、配合 UI 的 approve 按鈕閉合雙向流程，並把「plan 先批準再執行、可來回調整」當成串起整段的結尾練習。
</LearningGoal>

## Lesson

用 `POST /api/approve/:workflowId` 把決定經由 `DBOS.send` 送進被暫停的 workflow，inspector 的批准卡片靠 `approval.requested`／`approval.resolved` 事件驅動；而把同一套 primitive 套在 plan 上，就是「先批準、可來回調整、再執行」的結尾練習。
