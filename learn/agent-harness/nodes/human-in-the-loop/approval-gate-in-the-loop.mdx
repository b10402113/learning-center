# 把 approval gate 接進 durable loop

<LearningGoal>
能在 runtime loop 的 tool call 分派處加上 NEEDS_APPROVAL 檢查：發 ApprovalRequested 事件、用 DBOS.recv 等待決定、發 ApprovalResolved，approve 就執行、拒絕就塞進「不重試」的 tool 結果。
</LearningGoal>

## Lesson

在 tool call 分派處加第三個分支：發 `ApprovalRequested`、用 `DBOS.recv` 等待（預設 fail closed）、發 `ApprovalResolved`，批准就跑 `toolStep`，拒絕就回一則「不要重試」的 tool 結果以維持訊息序列合法。
