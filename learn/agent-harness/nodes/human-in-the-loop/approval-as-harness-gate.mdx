# 審批是 harness 的責任，不是 LLM 的請求

<LearningGoal>
能解釋為什麼 human-in-the-loop 審批必須是決定性的 harness 層行為——用工具選項或 map 標記「哪些工具要審批」、在 harness 內按名稱查配置並暫停——而不是在 prompt 裡求 LLM 照做。
</LearningGoal>

## Lesson

審批必須像 handoff 一樣由 harness 決定性判定——用 `NEEDS_APPROVAL` 這類清單在工具分派處按工具名稱查配置——而不是在 prompt 裡求 LLM 照做，因為模型只負責提議、harness 才是執行的那隻手。
