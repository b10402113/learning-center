# DBOS recv/send：無限期暫停與恢復

<LearningGoal>
能用 DBOS.receive 無限暫停一個 workflow、用 DBOS.send 攜帶 payload 與 tag 喚醒它，並解釋 durable 為什麼讓「等一個人類、甚至等很多天」不必燒任何 compute。
</LearningGoal>

## Lesson

`DBOS.recv` 把 workflow 連同等待的訊息 checkpoint 進 Postgres、不佔用任何 compute，`DBOS.send` 再從外界以相同 topic 帶 payload 喚醒它，因此等一個人類可以從幾秒延伸到數年、甚至跨過一次 crash。
