# 把事件寫進 Postgres：event_log 與 durable bus

<LearningGoal>
用 Drizzle 建出 event_log 表（seq 主鍵 + jsonb data），把 bus 改成「先寫資料庫、再廣播給訂閱者」，並用 history() 依 seq 重播整條事件時間線。
</LearningGoal>

## Lesson

用 Drizzle 建出只靠 seq（bigserial 主鍵）與 data（jsonb）兩欄的 event_log，把 bus 改成「先寫資料庫、再通知訂閱者」，subscribe 回傳 cleanup 防洩漏、history() 依 seq 重播整條時間線——事件從此脫離 process 記憶體，隨 server 崩潰而蒸發的問題消失。
