# 把迴圈包成 DBOS workflow

<LearningGoal>
用 DBOS.runStep 把 model turn、tool step、多種 emit 與失敗 emit 包成 step，用「是否非確定 / 昂貴」判別哪些能留在 step 外，再用 registerWorkflow 啟動持久化語意。
</LearningGoal>

## Lesson

用 DBOS.runStep(callback, { name }) 把 model turn、emit、tool call 與失敗 emit 包成 step，以「是否非確定／昂貴」決定哪些初始化可留在外面，而讓一切生效的關鍵是 registerWorkflow——註冊之前這些 step 沒有 durable 語意。
