# 決定哪些要持久化，並把工具執行收回來

<LearningGoal>
用「重跑會不會造成傷害」判定該包進 durable step 的邊界（tool call、emit、streamText），移除工具的 execute、集中成單一 runTool switch，並定義 ToolCall 與 Turn 兩個型別。
</LearningGoal>

## Lesson

用「重跑會不會造成傷害」劃出該包進 durable step 的三個候選（tool call、emit、streamText），刪掉工具的 execute、集中成單一 runTool switch 以奪回執行控制權，並定義 ToolCall 與 Turn 兩型別，把包裝邊界留在 workflow 呼叫端而非 tools 檔。
