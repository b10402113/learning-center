# 把 model turn 與 tool call 抽成函式

<LearningGoal>
把舊 runtime 裡的串流與工具執行抽成 modelTurn（emit modelDelta → 回傳 Turn）與 toolStep（toolRequested → runTool → toolCompleted）兩個獨立函式，讓每段副作用都能被單獨包進 durable step。
</LearningGoal>

## Lesson

把 runtime 的串流與工具執行抽成 modelTurn（emit modelDelta → 回傳 Turn）與 toolStep（toolRequested → runTool → toolCompleted，靠同一 toolCallId 對應）兩個獨立函式——純 refactor、行為不變，只為讓每段副作用能被單獨包進 durable step。
