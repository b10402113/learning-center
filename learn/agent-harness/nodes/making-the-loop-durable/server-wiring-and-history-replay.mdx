# 接上 server：重啟續跑與 history replay

<LearningGoal>
用 env loader、main bootstrap、DBOS.launch 把 server 接上 durable bus，讓 submit_task 經 startWorkflow 啟動 workflow、連線時重播 history，並看懂「殺掉 server 重啟後續跑」的示範與其背後的訊息陣列機制。
</LearningGoal>

## Lesson

用 env.ts 搶先載入變數、main() 依序 ensureSchema → setConfig → DBOS.launch 再 listen，把 durable bus 接上 WebSocket，讓 submit_task 經 DBOS.startWorkflow 啟動、重連時 history() 逐條重播；重啟後模型因最後一則訊息 role 為 user/tool 而自然續跑。
