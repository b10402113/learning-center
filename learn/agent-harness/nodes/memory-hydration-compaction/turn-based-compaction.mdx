# 以 turn 為單位的壓縮：接進 runtime 的 durable step

<LearningGoal>
在每個迴圈開頭、model turn 之前檢查 token 預算，用 while 迴圈把最舊的整個 turn 移出（不拆 message），把摘要包成 DBOS step 並發出 `memory_compacted`，再用 `buildContext` 跑這一輪。
</LearningGoal>

## Lesson

壓縮必須在每輪 model turn 之前、以整個 turn 為單位滑動（逐則拆 message 會留下懸空 tool call 而弄壞 API），摘要包成具名 DBOS step 讓重放不重跑，完成後發出 `memory_compacted`，再用 `buildContext` 把摘要注入這一輪的 context。
