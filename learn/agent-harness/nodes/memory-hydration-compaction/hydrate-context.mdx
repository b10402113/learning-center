# Hydrator：估算 token 並組出這一輪的 context

<LearningGoal>
實作 `estimateTokens` 與 `buildContext`：量整段 context 的大小，再把 system prompt（可夾帶 running summary）、當前任務、保留的 turns 組成模型實際看到的 messages。
</LearningGoal>

## Lesson

`estimateTokens` 量整包 messages 的大小，`buildContext` 依 system（可夾帶 running summary）→ user 任務 → 保留 turns 的順序組出模型這一輪真正看到的內容，並守住「只有一則 system、結尾落在 user 或 tool」兩條訊息陣列規則。
