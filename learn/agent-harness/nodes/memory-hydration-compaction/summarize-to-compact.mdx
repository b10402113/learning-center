# Summarizer：用一次 LLM 呼叫把舊 turns 壓成摘要

<LearningGoal>
用 `generateText` 寫出 `summarize`：把舊 turns 攤平成文字、折入既有摘要（summaries of summaries）、保留 ID／類別／金額／已送事項，並用 `maxOutputTokens` 設上限。
</LearningGoal>

## Lesson

`summarize` 就是一次獨立的 `generateText` 呼叫（不串流、有自己的 system prompt），把舊 turns 折入既有摘要形成 summaries of summaries，保留 ID／類別／金額／已送事項等具體事實，並用 `maxOutputTokens` 硬性封住摘要長度。
