# 脈絡為何膨脹：History、State、Context

<LearningGoal>
說出脈絡無限成長為何讓模型變笨、變慢、變貴，並分辨 History（持久事件日誌）、State（壓縮摘要）、Context（這一輪送進模型的內容）三者的角色。
</LearningGoal>

## Lesson

無限成長的脈絡會讓模型同時變笨（中間內容等於被遺忘）、變慢、變貴，而更大的 context window 只是把懸崖往後移、並非解方；harness 因此必須區分持久的事件日誌（History）、壓縮後的摘要（State）、以及每輪即時組出的模型輸入（Context）。
