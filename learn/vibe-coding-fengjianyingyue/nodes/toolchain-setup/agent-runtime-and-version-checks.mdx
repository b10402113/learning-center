<LearningGoal>
能說出為什麼 Claude Code 是架在 Node.js 與 git 上的 npm 套件，並用 node／npm／git／claude 四個版本命令逐項驗證安裝，遇到 PATH 或權限問題時知道從哪裡查。
</LearningGoal>

## Lesson

Claude Code 是發佈在 npm 上的全域套件，底座是 Node.js 與 git；安裝後要用 `node --version`、`npm --version`、`git --version`、`claude --version` 逐項驗證，而 command not found、EACCES 權限、nvm 換版後套件消失、Node 版本過舊，是四個最常見的坑。
