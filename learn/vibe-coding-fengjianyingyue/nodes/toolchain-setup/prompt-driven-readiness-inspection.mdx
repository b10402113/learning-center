<LearningGoal>
能寫出「只檢查、不動手」的環境就緒提示詞，以及「路徑由我給、OS 設定交給 agent」的環境變數設定提示詞，並知道 agent 動完手後要怎麼複驗。
</LearningGoal>

## Lesson

環境檢查與設定要分成兩次下指令：先用「只檢查，不做其他操作」的只讀提示詞拿到現況，再用「我已經下載、目錄在……，請依我的作業系統設定」把路徑交給 agent 處理 OS boilerplate，最後開新終端機用 `java -version` 與 `mvn -version` 親自複驗。
