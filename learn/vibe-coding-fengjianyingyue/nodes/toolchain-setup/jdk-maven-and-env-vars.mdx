<LearningGoal>
能設定 JAVA_HOME／MAVEN_HOME／PATH，讓 java -version 與 mvn -version 指向同一個 JDK，並認得 JAVA_HOME 指到 JRE、PATH 順序、多版本 JDK 這幾個常見坑。
</LearningGoal>

## Lesson

JDK 與 Maven 解壓只算前置，真正決定能不能用的是環境變數：`JAVA_HOME` 要指向 JDK 根目錄、PATH 要含兩者的 `bin`，而 `mvn -version` 印出的 Java version 才是驗證 Maven 用了哪套 JDK 的關鍵；JAVA_HOME 指到 JRE、PATH 順序被系統版搶先、多版本互指、設定檔寫錯或未重載，是四個常見坑。
