# 接上 GitHub MCP：讓 agent 能操作遠端 repo

<LearningGoal>
能安裝 GitHub MCP server、重啟後驗證連線，並用白話把本地專案推送到指定的遠端 repo，同時知道 token 不能進版控。
</LearningGoal>

## Lesson

用「安裝、重啟、測試」三步接上 GitHub MCP，先用唯讀的列出倉庫驗證連線，再用白話把本地專案推送到遠端，同時記得 token 不能進版控。
