# 把 commit 當存檔點：初始化 repo 與第一次存檔

<LearningGoal>
能用白話讓 agent 建立本地 git repo、完成第一次存檔，並解釋為什麼要把 commit message 交給 agent 自動總結。
</LearningGoal>

## Lesson

把 commit 當成遊戲存檔點：用「建立 git 倉庫、完成第一次存檔初始化」與「使用 git 存檔，備註請你自動總結」兩句白話，讓 agent 建立 repo 並自動寫好存檔訊息。
