# 查歷史與回退：AI 改壞了怎麼還原

<LearningGoal>
能請 agent 列出所有存檔紀錄、從中挑一個 hash，用白話把專案回退到那個版本，並判斷什麼時候該回退、什麼時候該往前修。
</LearningGoal>

## Lesson

先用「查看所有 git 存檔記錄」拿到各版本的 hash，再把它原封不動貼進「回退 git 版本到 edd05fc」，就能在 agent 改壞時退回上一個乾淨的存檔點，並判斷何時回退、何時往前修。
