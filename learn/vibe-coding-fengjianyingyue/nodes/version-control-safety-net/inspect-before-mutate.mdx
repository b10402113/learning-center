# 先檢查、不動手：用「只檢查」提示詞摸清環境

<LearningGoal>
能用一句「只檢查、不做其他操作」的提示詞，讓 agent 回報機器上有沒有 git、這個專案能不能版控，並說出為什麼要把「診斷」和「變更」分開。
</LearningGoal>

## Lesson

把診斷和變更分開：先用「只幫我檢查，不做其他操作」的提示詞，讓 agent 回報機器上有沒有 git、專案能不能版控，把風險擋在動手之前。
