# 角色化資料夾骨架：把整條產線排成一個專案

<LearningGoal>
能為新產品列出以角色命名的資料夾骨架，說出每個資料夾該放什麼，並解釋為什麼這種排法能同時讓你自己和 coding agent 都找得到東西。
</LearningGoal>

## Lesson

用角色與編號命名資料夾，讓每個交付階段都有專屬容器，也讓 agent 靠目錄名稱就知道東西該放哪。
