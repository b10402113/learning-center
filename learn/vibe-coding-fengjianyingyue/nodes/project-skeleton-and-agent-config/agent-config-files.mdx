# AGENTS.md 與 CLAUDE.md：一份給 agent 的專案說明書

<LearningGoal>
能寫出一份包含專案概述、專案結構、開發指令、技術棧、設計系統與資料模型的 agent 說明書，並用 AGENTS.md 與 CLAUDE.md 兩份同名內容的檔案對應不同 coding agent。
</LearningGoal>

## Lesson

把專案概述、結構、指令、技術棧、設計系統與資料模型寫成 AGENTS.md，並鏡像成 CLAUDE.md，agent 才不必每次開工重新猜。
