# Digest — 前端页面调整自然语言文字内容 (vibe-coding prompt playbook: UI refinement)

## Overview (L1)

- `前端页面调整自然语言文字内容.txt` — 18 numbered natural-language UI fix requests for the 财务管家 app: align styles to login/register, remove stray Material icon ligature text (`home`, `bar_chart`, `arrow_back`), fix disappearing charts, replace a floating button's text with an SVG icon, add floating buttons to three pages, and wire avatar/category/account management.

## Sections (L2)

### styling-consistency

- Locator: `[[sources/vibe-coding-fengjianyingyue/20260926/前端页面调整自然语言文字内容.txt#styling-consistency]]`
- Summary: items 1, 8–13, 17–18 — unify every page with the login/register style; delete redundant labels/links; increase icon-to-text spacing.
- Key claims: visual consistency is requested page-by-page in plain language; "参考" (reference) another screen as the standard.
- Learner-relevant: the iterate-by-screenshot-review loop; small, enumerable UI changes are the sweet spot for agent edits.

### icon-ligature-bug

- Locator: `[[sources/vibe-coding-fengjianyingyue/20260926/前端页面调整自然语言文字内容.txt#icon-ligature-bug]]`
- Summary: items 3, 8, 10, 11, 17 — remove visible English words like `arrow_back`/`home` that are actually unrendered icon-font ligatures.
- Key claims: classic AI-generated-UI bug — icon font fails to load, so the ligature name shows as text; fix by swapping to inline SVG.
- Learner-relevant: recognizing and diagnosing a recurring AI-code failure mode.

### feature-requests

- Locator: `[[sources/vibe-coding-fengjianyingyue/20260926/前端页面调整自然语言文字内容.txt#feature-requests]]`
- Summary: items 14–16 — avatar upload (front-end only, backend noted as out of scope), account management with emoji picker, category management CRUD with emoji picker.
- Key claims: the learner scopes work ("你只需要实现前端即可") and specifies emoji-per-account/category as a product requirement.
- Learner-relevant: scoping a prompt to a layer; letting the learner's domain desire drive the spec.

### chart-regression

- Locator: `[[sources/vibe-coding-fengjianyingyue/20260926/前端页面调整自然语言文字内容.txt#chart-regression]]`
- Summary: item 4 — "图表突然消失，重新修复" (the chart suddenly disappeared, fix it again).
- Key claims: AI edits cause regressions; a fix may need to be re-requested.
- Learner-relevant: regression as a normal cost of agent edits; motivates tests and checkpoints.
