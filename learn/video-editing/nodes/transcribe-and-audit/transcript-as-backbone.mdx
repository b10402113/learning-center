<LearningGoal>
能說明為什麼 agent 剪片的第一步一定是轉錄，並說出逐字稿的時間碼在整條產線裡扮演什麼角色。
</LearningGoal>

## Lesson

對有說話的素材來說，逐字稿是 agent 的耳朵、也是整條產線的時間軸：字級時間碼指出每一句話落在影片的哪一秒，讓 agent 能判斷哪些段落該剪，也讓後續的動態圖像能對準台詞出現。
