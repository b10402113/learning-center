# 為什麼影片是程式碼

## Learning goal

能解釋為什麼 agentic 剪片是「寫程式」（HTML/CSS/JS、three.js、ffmpeg），而不是生成式影片模型，並說出 agent 實際產出哪些檔案與素材。

## Steps

1. [[learn/video-editing/nodes/code-based-video-model/code-not-video-model|影片不是生成出來的：agent 做的是寫程式]] — 認出 agent 做影片時真正在寫 HTML/CSS/JavaScript，並用程式碼決定每個元素出現的時間與位置
2. [[learn/video-editing/nodes/code-based-video-model/the-render-stack|agent 的算圖工具鏈]] — 查回每一層工具（HTML/CSS/JS、Canvas/WebGL、Web Audio、ffmpeg）各負責畫面上的什麼（after step 1）
3. [[learn/video-editing/nodes/code-based-video-model/what-the-agent-produces|agent 到底產出哪些檔案與素材]] — 列出工作區圖片、SVG、網頁與 1080p MP4 的關係，並解釋為什麼圖像要用 SVG（after step 2）
4. [[learn/video-editing/nodes/code-based-video-model/code-you-own|為什麼是程式碼很重要]] — 說明程式碼影片能拆層、能重用成設計系統與 skill，而生成式模型是黑箱（after step 3）

## Lesson

先建立一個正確的心智模型：這種「AI 剪片」不是餵一句話給生成式影片模型、等它吐出一段影片；它是 agent 在寫網頁程式。所有你看得到的動作、文字與圖形，都是 HTML、CSS、JavaScript，加上 three.js 這類繪圖函式庫與 ffmpeg 算出來的，畫面裡的圖片只是工作區裡的檔案，被程式碼放到「第幾秒、哪個位置」。正因為產出的是程式碼而不是黑箱，你才能拆開每一層、改它、把喜歡的風格存成設計系統與 skill。這個節點先用四個步驟把這件事從「聽起來很玄」變成「我能說出它到底怎麼運作、產出什麼」：先確立「影片是程式碼」的核心命題，再拆解 agent 實際動用的算圖工具鏈，接著盤點會出現在工作區裡的檔案與素材，最後說明為什麼「是程式碼」在長期上比生成式模型更值得投資。
