# 打造並校準 /animate skill

## Learning goal

能把每次修正沉澱成可複用的 `/animate` skill（pattern 化、calibrate、吸收而非堆疊），並維護已登記的元素庫。

## Steps

1. [[learn/video-editing/nodes/build-and-refine-animate-skill/skill-shapes-output|skill 就是一份 markdown 檔]] — 看懂同一段素材為什麼會因為 skill 校準程度不同，產出「meh」與「wow」兩種結果
2. [[learn/video-editing/nodes/build-and-refine-animate-skill/three-step-refinement-loop|三步循環：知道工具、給回饋、更新 skill]] — 記住 refine skill 的三步迴圈，以及它為什麼是持續的過程而非一次性修正（after step 1）
3. [[learn/video-editing/nodes/build-and-refine-animate-skill/feedback-as-reusable-patterns|把回饋寫成可複用的 pattern]] — 把「這裡怪怪的」改寫成帶 what／when／always-never 的規則，並用 reference design、新規則、元素庫三種方式餵回去（after step 2）
4. [[learn/video-editing/nodes/build-and-refine-animate-skill/element-library-and-catalog|元素庫與 catalog：讓喜歡的元件找得回來]] — 把重複用到的元件登記進 catalog，讓 skill 下一支影片直接取用（after step 3）
5. [[learn/video-editing/nodes/build-and-refine-animate-skill/calibrate-absorb-and-loop|calibrate：把回饋吸收進 skill，然後再跑一輪]] — 用 calibrate 指令讓 agent 吸收回饋而非堆疊區塊，並跑到輸出不再讓你驚訝為止（after steps 3–4）

## Lesson

前面幾個節點走的是「做出一支影片」：轉錄、剪片、設計系統、分鏡、算圖、執導。但每做一支就重講一次規則、重調一次轉場、重新找一次上次那個好用的數字動畫，等於每支影片都從零開始。這個節點要處理的是把那些重複的修正「沉澱」下來，變成一顆越用越準的 `/animate` skill。

核心的心智模型很單純：**skill 就是一份 agent 動手前會讀的 markdown 檔**。同一段素材、同一個模型，餵進未校準的 skill 會得到「meh」，餵進帶著你的規則與參考的 skill 會得到「wow」；差別不在模型，而在那份檔案裡裝了多少你的品味。而檔案變聰明的方式，是一個三步循環：先知道工具、做出第一版，再把觀察寫成可複用的 pattern 餵回去，最後請 agent 把回饋「吸收」進檔案，而不是在底下堆一段新規則。

五個步驟會依序把這條循環拆開：先建立「skill 是一份檔」的觀念與前後對比；再看懂三步循環的全貌；接著學會把「這裡怪怪的」翻譯成帶 what／when／always-never 的 pattern；然後把重複使用的元件登記進元素庫與 catalog，讓下一支影片直接取用；最後用 calibrate 指令更新 skill，跑 render→compare→calibrate 的迴圈，直到輸出不再讓你驚訝，並把它收斂成一行指令的成品流程。
