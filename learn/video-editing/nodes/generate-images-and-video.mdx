# 用 /generate 生圖生影

## Learning goal

能用 `/generate` skill 便宜又安全地生圖生影（聚合商路由、per-model recipe、成本護欄、sidecar log、gallery），作為自架的 Higgsfield 替代方案。

## Steps

1. [[learn/video-editing/nodes/generate-images-and-video/why-replace-higgsfield|為什麼用一支 skill 取代 Higgsfield 訂閱？]] — 看懂 Higgsfield 其實是模型聚合器，以及 pay-as-you-go 聚合商在成本、可靠性與範圍上的取捨
2. [[learn/video-editing/nodes/generate-images-and-video/generate-pipeline-and-layout|/generate 的四步管線與資料夾佈局]] — 建立 Route → Prep refs → Generate → Log 的心智模型與工作區結構（after step 1）
3. [[learn/video-editing/nodes/generate-images-and-video/set-up-keys-and-skill-file|取得金鑰並寫出 SKILL.md]] — 把三個聚合商的 key 放進 `.env`，寫出帶路由規則與護欄的 skill 檔（after step 2）
4. [[learn/video-editing/nodes/generate-images-and-video/write-model-recipes|一模型一 recipe：五個模型與三種認證]] — 用 recipe 範本接上五個推薦模型，認得 sync／async 與三種認證形狀（after step 3）
5. [[learn/video-editing/nodes/generate-images-and-video/guardrails-log-and-gallery|成本護欄、sidecar log 與 gallery]] — 用五條護欄與 sidecar log 安全地花錢，讓成果自動進 gallery（after step 4）

## Lesson

`/generate` 這支 skill 真正解決的問題，不是「怎麼生出好看的圖」，而是「怎麼在可預算內、用最便宜的模型、安全地把圖和影片生出來，而且每一筆都留得下來」。它把 Higgsfield 這類訂閱服務背後的東西拆開：Higgsfield 本質上是一層包在第三方模型外面的聚合器，而 fal.ai、WaveSpeed AI、Kie AI 這類 pay-as-you-go 聚合商做的是同一件事，卻不用付月費。於是，一支寫在 Markdown 裡的 skill，加上三個 API key，就能取代那個每月 $49 到 $79 的訂閱。

這個節點把「自架生圖生影」拆成五步。先弄清為什麼要換掉訂閱、換上聚合商，接著建立 `/generate` 的四步管線心智模型——Route（挑最便宜的可用模型）→ Prep refs（載入真實參考圖，絕不用文字描述 logo）→ Generate（照 recipe 呼叫 API，async 就輪詢）→ Log（在檔案旁寫 JSON 紀錄）。再來是動手的部分：把金鑰寫進 `.env`、寫出 `SKILL.md`，並為每個模型寫一份 recipe。最後一步處理「花錢」這件事——影片每分鐘都是真金白銀，所以要有成本護欄、草稿先用便宜模型、成果用一個扁平資料夾收好並自動進 gallery。

走完之後，你不會只是「用了一個工具」，而是擁有整套系統：路由、護欄、模型庫、prompt 紀錄。這正是別人願意付錢買的部分，也是你可以繼續擴充、加新模型的一份個人資產。
