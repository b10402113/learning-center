# 五個最常重複使用的 recipe

<LearningGoal>
能認出五個最常重複使用的 recipe（液態玻璃、去背、地球儀、像素圖示、數字 count-up）各自的用途、關鍵參數與限制，並知道要從哪裡取用。
</LearningGoal>

## Lesson

五個常備 recipe 可以直接貼進 composition：液態玻璃用 `backdrop-filter: blur(24px) saturate(160%)`、chroma key 用 `feColorMatrix` 做軟邊去背、D3 線框地球儀靠 `clearRect` 保持透明、像素 agent 圖示把 4 欄鏡射成 8 欄、數字 count-up 在 0.5 秒跑到目標值再停住並只用真實數字；CSS 無限動畫要改寫成有限次重複才進得了確定性算圖。
