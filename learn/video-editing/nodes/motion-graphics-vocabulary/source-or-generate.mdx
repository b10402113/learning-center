# 借現成元件，還是自己生一個

<LearningGoal>
面對一個要做進影片的元素，能判斷該去 21st.dev 借現成的 HTML 元件，還是用生成提示自己做一個，並說出兩種做法的取捨。
</LearningGoal>

## Lesson

遇到新元素先問外面有沒有接近的成品，再問它是否必須精準貼合品牌：通用、常見、只是試風格的就借 21st.dev 元件、複製提示並指定套用段落；獨有、要長期留下的就自己用結構化提示生成，而且一次只做一個類別、先做三到四個再決定；動手前先確認授權。
