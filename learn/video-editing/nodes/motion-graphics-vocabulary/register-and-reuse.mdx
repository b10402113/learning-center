# 把元素登記起來，下次直接取用

<LearningGoal>
能把喜歡的元素挑出來、登記進 element catalog，下一次做影片時用一行指令把選好的元素加回來重複使用。
</LearningGoal>

## Lesson

走過「挑元素頁面（暫停懸停描邊、存清單、一鍵複製）→ `add to element library:` 加入 library → 登記 element catalog（名字、類別、路徑、用途）並做索引頁 → 下次用元素路徑取用」這四步，語彙庫就會隨每支影片累積。
