# 語彙庫和資料夾差在哪裡

<LearningGoal>
能說明為什麼要建立個人動態圖像語彙庫、什麼算是一個可重用的「元素」，以及一個有登記的語彙庫和單純堆檔案的資料夾差在哪裡。
</LearningGoal>

## Lesson

語彙庫不是堆檔案的資料夾，而是「檔案加上一份可被讀取的 element catalog（名字、類別、路徑、用途）」；agent 只能重用它找得到的元素，而每一次登記都會讓往後的影片更快。
