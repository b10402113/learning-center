# /generate 的四步管線與資料夾佈局

<LearningGoal>
能說出 `/generate` 的四步管線（Route → Prep refs → Generate → Log）與整個工作區的資料夾佈局，並解釋「一個扁平資料夾」、「一模型一 recipe」等設計選擇背後的理由。
</LearningGoal>

## Lesson

`/generate` 是一份 agent 每次動手前會讀的 Markdown 作戰手冊，跑 Route → Prep refs → Generate → Log 四步，成果扁平收進 generations 資料夾並自動進 gallery。
