# 一模型一 recipe：五個模型與三種認證

<LearningGoal>
能為一個模型寫出 recipe 檔（model id、provider、method、endpoint、auth、request／response），並認得五個推薦模型、三種認證形狀，以及 sync 與 async 的差別。
</LearningGoal>

## Lesson

每個模型一份 recipe，記下 model id、provider、method、endpoint 與 response 處理；先接 Nano Banana 2 Lite 與 Kling 3.0，並分清三種認證形狀與 sync／async。
