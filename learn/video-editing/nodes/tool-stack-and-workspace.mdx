# 工具鏈與工作區設定

## Learning goal

能把工作區架起來：agent 與模型／effort、HyperFrames、hyperframes-helper skill、轉錄工具、ffmpeg、金鑰與 `.env`，以及護欄（lint 0 error、付費前先確認）。

## Steps

1. [[learn/video-editing/nodes/tool-stack-and-workspace/toolchain-roles|產線上的四個角色：agent、HyperFrames、轉錄、ffmpeg]] — 認出四個角色各做什麼，以及 HTML 進、MP4 出的資料流
2. [[learn/video-editing/nodes/tool-stack-and-workspace/choose-agent-and-model|選 agent 與模型：Claude Code、Codex 與 effort 怎麼搭]] — 依任務有沒有明確終點挑模型，並設對 effort（after step 1）
3. [[learn/video-editing/nodes/tool-stack-and-workspace/install-hyperframes-and-helper|安裝 HyperFrames 與 hyperframes-helper skill]] — 用 npx 裝 CLI 與 skill，逐項驗證（after step 1）
4. [[learn/video-editing/nodes/tool-stack-and-workspace/transcription-tools-and-keys|轉錄工具與 API key：AssemblyAI、Whisper、Scribe 怎麼選]] — 用速度、成本、隱私三個判準選工具，並管好 key（after step 1）
5. [[learn/video-editing/nodes/tool-stack-and-workspace/workspace-guardrails|工作區護欄：先讀 skill、lint 0 error、付費前先確認]] — 三條讓 agent 產線安全又誠實的規則（after step 3）

## Lesson

把前面「為什麼影片是程式碼」的心智模型，換成一台真的可以開機的機器。這個節點不談創作，只把工作區架起來：哪四個角色會一起工作、你用哪個 agent 和哪個模型拉它們、HyperFrames 與 helper skill 怎麼裝、轉錄要選哪家、金鑰放哪裡，以及三條能讓整條產線不亂花錢、不假裝完成的護欄。走完之後，你手上會有一個在任何 Mac 上都能重跑的工作區檢查表，後面 Tier 2 的剪片、設計系統、算圖都從它出發。
