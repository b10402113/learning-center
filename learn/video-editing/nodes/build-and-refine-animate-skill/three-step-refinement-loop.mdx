<LearningGoal>
能說出把粗略 skill 養成可交付 skill 的三步循環——知道工具、給結構化回饋、更新 skill，並理解它是一個持續的迴圈，而不是一次性的修正。
</LearningGoal>

## Lesson

把粗略 skill 養成可交付 skill 的是三步循環：知道工具、做出第一版；把觀察寫成 pattern 餵回去（最關鍵的一步）；再用一句 calibrate 更新 skill——而且它是一個每次都要跑、不是一次就結束的迴圈。
