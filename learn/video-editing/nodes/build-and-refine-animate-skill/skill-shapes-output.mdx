## Lesson

skill 就是一份 agent 動手前會讀的 markdown 檔；同一段素材、同一個模型，校準程度不同的 skill 會給出「勉強能看」與「眼睛一亮」兩種結果，差別在檔案裡裝了多少你的品味。
