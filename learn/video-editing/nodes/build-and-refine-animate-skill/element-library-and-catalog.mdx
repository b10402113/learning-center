<LearningGoal>
能說明為什麼喜歡的元件要「登記一次」進元素庫，以及 catalog 如何讓 skill 在下一支影片直接找到並重用，而不是重新發明一次。
</LearningGoal>

## Lesson

元素庫收的是一再用到的元件（數字 count-up、瀏覽器外框、圖示），關鍵在「登記一次」讓 skill 下次找得到、敢重用；少了登記，它就只是一個沒人翻得懂的資料夾。
