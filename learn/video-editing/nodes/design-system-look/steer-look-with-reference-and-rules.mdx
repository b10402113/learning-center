# 用參考設計與規則鎖住外觀

<LearningGoal>
能把「你想要的樣子」用參考設計與可複用的規則 pattern 餵給 agent，讓動畫的顏色、字體與節奏對上品牌。
</LearningGoal>

## Lesson

用參考設計（放進設計系統或截圖並說「match this」）、寫成可複用 pattern 的規則（做什麼、什麼時候、一律或絕不）與元素庫，把設計系統的顏色、字體與節奏牢牢鎖住。
