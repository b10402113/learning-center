# 取得並存下你的 DESIGN.md

<LearningGoal>
能從 styles.refero.design 挑一套設計系統並把它的 DESIGN.md 原文存進專案，或在沒有現成檔案時用參考影片反推出一套。
</LearningGoal>

## Lesson

從 Refero Styles 挑一套設計系統、請 agent 原文存成 `DESIGN.md` 並列出主色與字體確認；沒有現成檔案時，則餵參考影片讓 agent 用 FFmpeg 截圖反推出一套。
