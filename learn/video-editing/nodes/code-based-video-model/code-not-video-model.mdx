<LearningGoal>
能說明 agentic 影片不是用生成式影片模型產生的，而是 agent 用 HTML/CSS/JavaScript 把工作區裡的圖片放到精確的時間與位置，並指出這條產線的輸出是「先網頁、後 MP4」。
</LearningGoal>

## Lesson

agent 做影片時其實是在寫 HTML／CSS／JavaScript，把工作區裡的圖片放到精確的時間與位置；產出先是可播放的網頁，再錄成 1080p MP4，而不是生成式影片模型的輸出。
