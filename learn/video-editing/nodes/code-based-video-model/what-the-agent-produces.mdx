<LearningGoal>
能列出 agent 產出的成品與素材（工作區圖片、SVG 圖形、可播放的網頁、1080p MP4），並解釋為什麼圖像要用 SVG，以及「先有網頁、才有影片」的關係。
</LearningGoal>

## Lesson

agent 交出的是一組工作區資產——原始素材、SVG、必要時生成的圖片、可改的母帶網頁，以及錄好的 1080p MP4；圖像指定 SVG 是為了可縮放、可改色、可動畫。
