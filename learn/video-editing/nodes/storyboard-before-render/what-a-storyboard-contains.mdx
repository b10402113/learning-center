<LearningGoal>
能列出一頁 HTML 分鏡該包含的欄位——影片描述、場景數、總時長、逐場景秒數拆解、每幕的靜態畫面與文案預覽——並認出這些欄位在審查頁上的位置。
</LearningGoal>

## Lesson

一頁 HTML 分鏡把整支影片的計畫攤成可審查的欄位：影片描述、場景數、總時長、逐場景秒數拆解、每幕靜態畫面、文案預覽、開始時間與動態描述；選 HTML 是為了快、能點、能改，工具附的樣板可當起點但不是內容。
