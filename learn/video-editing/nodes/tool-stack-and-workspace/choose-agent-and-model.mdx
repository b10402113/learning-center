<LearningGoal>
能依「這個任務有沒有明確終點」在 Sonnet 5.5、Opus 5.5、Fable 5.1 之間選模型，設對 effort，並知道剪片該挑哪個 agent 平台。
</LearningGoal>

## Lesson

模型選擇的判準是「這個任務有沒有明確終點」：有終點（如剪片）用便宜快的 Sonnet 5.5，需要品味時才上 Opus 5.5；務必記得每 token 成本不等於每任務成本，Sonnet 在 max effort 下反而比 Opus 貴，effort 開大是為了讓任務一次做完，而 agent 平台（Claude Code／Codex／Fable）可挑你順手的，skill 不綁廠商。
