<LearningGoal>
能把三條工作區護欄落成習慣：動手前先讀 skill、宣稱完成前跑 lint 到 0 error、任何付費生成前先報價並等明確同意。
</LearningGoal>

## Lesson

三條護欄——動手前先讀 helper skill、永遠不改 HyperFrames 核心、宣稱完成前 `npx hyperframes@latest lint` 必須 0 error——再加上「付費生成前先報價、等明確同意才呼叫 API」，並把 ffmpeg 裝好（選配但建議）、先決定多片段 `data-media-start` 或單片段；護欄的作用是讓你放心把長任務交給 agent。
