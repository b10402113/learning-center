<LearningGoal>
能依速度、成本與隱私在 AssemblyAI、Whisper、ElevenLabs Scribe 之間選轉錄工具，並把 API key 放進對的地方、不讓它出現在對話裡。
</LearningGoal>

## Lesson

轉錄工具的取捨是「免費與隱私」對上「速度」：Whisper 免費、本機但要 15–50 分鐘，AssemblyAI 約 $0.21／小時、只要約 42 秒、需要 API key，ElevenLabs Scribe 適合已有訂閱者但慢約 40%；用「素材多長、能不能上傳、有沒有現成訂閱」三個問題收斂選擇，並把金鑰放進 `.env`、排除在版控之外，永遠不要貼進對話。
