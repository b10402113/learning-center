<LearningGoal>
能說出這條 agentic 影片產線上四個角色各負責什麼、為什麼缺一不可，並把 HyperFrames 的「HTML 進、MP4 出」放進正確的位置。
</LearningGoal>

## Lesson

這條產線有四個角色——agent 是介面兼導演、HyperFrames 把 agent 寫的 HTML 網頁渲染成 MP4、轉錄工具把聲音變成帶時間碼的文字、ffmpeg 負責剪切與轉檔；順序固定為先轉錄、再剪、再算圖、最後執導，而 HyperFrames 不是生成式影片模型，只是 HTML-to-MP4 的渲染器。
