<LearningGoal>
能從零把 HyperFrames CLI 與 hyperframes-helper skill 裝進專案，並用版本與 help 指令確認每一步真的裝上了。
</LearningGoal>

## Lesson

HyperFrames 用 `npx hyperframes@latest` 呼叫、不必全域安裝，官方 skills 用 `npx skills add heygen-com/hyperframes` 加入，helper skill 則是把 repo 裡的 `.claude/skills/hyperframes-helper/` 複製進專案；最後把 agent 開在放素材的資料夾，並用 `node --version`、`--help` 與「請 agent 做一支影片」逐項驗證「裝得上、叫得到」。
