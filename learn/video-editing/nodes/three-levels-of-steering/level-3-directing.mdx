# Level 3：對成品影片執導

<LearningGoal>
能用 review page 對成品影片的畫面、聲音與剪點釘選時間碼回饋，貼回後檢查更新，確認滿意才 render 1080p MP4。
</LearningGoal>

## Lesson

對成品影片執導，就是做一個能播放、釘選留言、拖曳修剪與記錄聲音回饋的 review page，走完一輪複製所有留言一次貼回，等頁面更新後再看一次，確定滿意才 render 成 1080p MP4；它處理的是分鏡照不到的畫面、聲音與剪點。
