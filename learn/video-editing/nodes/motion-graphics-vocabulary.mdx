# 動態圖像語彙庫

## Learning goal

能建立個人動態圖像語彙庫：可複用的 recipe（液態玻璃、去背、地球儀、像素圖示、數字 count-up）與 21st.dev 版型。

## Steps

1. [[learn/video-editing/nodes/motion-graphics-vocabulary/library-vs-folder|語彙庫和資料夾差在哪裡]] — 認出什麼算一個可重用的元素，理解「有登記的語彙庫」和「堆檔案的資料夾」的差別
2. [[learn/video-editing/nodes/motion-graphics-vocabulary/core-recipes|五個最常重複使用的 recipe]] — 看懂液態玻璃、去背、地球儀、像素圖示、數字 count-up 的用途與關鍵參數（after step 1）
3. [[learn/video-editing/nodes/motion-graphics-vocabulary/source-or-generate|借現成元件，還是自己生一個]] — 判斷何時去 21st.dev 借元件、何時用生成提示自己造（after step 1）
4. [[learn/video-editing/nodes/motion-graphics-vocabulary/register-and-reuse|把元素登記起來，下次直接取用]] — 走過「挑元素 → 登記 catalog → 一行指令取用」的流程（after steps 1–3）

## Lesson

到這裡，你已經能跑完整條產線：剪片、設計系統、分鏡、HyperFrames 算圖，還會用時間碼執導。但每支影片都從零開始長動畫，速度就卡住了。真正讓第十支影片比第一支快的方法，是把每一支影片裡做過、而且想再用的東西留下來。

這個節點談的是「語彙庫」。它不是一個放素材的資料夾，而是一份有登記、能被 agent 讀取、下次直接召喚的清單。裡面的元素分成幾類：寫在 composition 裡的 recipe（像液態玻璃卡片、chroma key 去背、D3 地球儀、像素圖示、數字 count-up），用提示生成出來的素材（3D 物件、圖示、背景），版面（browser mockup、分割畫面），還有動態、音效與音樂。

元素的來源有兩條線：一條是去 21st.dev 這類元件庫，複製現成 HTML 元件的提示，請 agent 改寫進影片；另一條是用一段結構化的提示，請模型從頭做一個你要的素材。兩條線各有適用時機。

最後，也是最能拉開差距的一步：把喜歡的元素登記進 element catalog。有登記，agent 下一次才找得到、才用得上；沒有登記，那只是一堆幾週後連自己都忘了存在的檔案。
