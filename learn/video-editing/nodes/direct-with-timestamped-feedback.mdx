# 用時間碼回饋執導

## Learning goal

能用時間碼釘選回饋「執導」已渲染的影片，限定範圍重渲染，補完最後 10–20% 且不回歸。

## Steps

1. [[learn/video-editing/nodes/direct-with-timestamped-feedback/why-direct-the-final-video|為什麼分鏡做完還要「執導」]] — 看懂分鏡加重建只到 80–90%，執導補的是畫面、聲音、剪點這最後一段
2. [[learn/video-editing/nodes/direct-with-timestamped-feedback/anatomy-of-a-timestamped-note|好的執導留言長什麼樣]] — 寫出帶時間、位置、單一指令的留言，並把聲音問題也寫成同一種形式（after step 1）
3. [[learn/video-editing/nodes/direct-with-timestamped-feedback/review-page-feedback-loop|做出 review page，把回饋蒐集成一批]] — 用一頁可播放、可釘留言、可拖曳修剪的介面看完整支影片，一次複製全部留言（after step 2）
4. [[learn/video-editing/nodes/direct-with-timestamped-feedback/scoped-rerender-without-regression|限定範圍重渲染，補完也不回歸]] — 用「只改我列的、其他別動」的指令重算，確認後再算最終 1080p，並知道何時收工（after step 3）

## Lesson

分鏡節點把影片調到「大致對了」，但一支影片真正的最後一哩，幾乎都不是在靜態畫面上解決的。這一節要處理的就是那 10–20%：畫面裡某個字擋到臉、某個圖示該在講到某個詞時出現、一段動畫拖得太長、某個剪點切早了半秒、音樂在某處太大聲。這些問題要邊播邊看才看得出來，而且必須能精準指出「第幾秒、畫面哪個位置、要怎麼改」。

這個節點把「執導」拆成一條可重複的迴圈。先建立正確的期待：分鏡加第一次 build 通常只到 80–90%，剩下的靠看完成品回饋；接著學會把口語的「怪怪的」寫成帶時間與位置的留言，連聲音問題都用同一種格式講清楚；然後用一頁 review page 把整支影片看完、把回饋蒐集起來一次送出；最後用「只改我列出的、其他原封不動」的指令限定範圍重渲染，確認這一輪真的修好、又沒有弄壞別的地方，再輸出最終的 1080p。

四個步驟走完，你手上會有一套從「已渲染影片」到「定稿」的收尾流程：不是再從頭做一次，而是用最小的改動把影片推到可交付。這套迴圈也是後面把經驗沉澱成 `/animate` skill 的素材。
