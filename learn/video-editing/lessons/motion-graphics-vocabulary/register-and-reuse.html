把元素登記起來，下次直接取用

Step 4/4 · 動態圖像語彙庫

前言：讓這支影片用過的零件，下一支還找得到

前三節談了為什麼要建立語彙庫、五個常備 recipe、以及新元素要借還是要生。但這些都還是「知道有這件事」。如果你今天把一支影片做完，喜歡裡面的logo 動畫和吉祥物，隔兩週卻只記得「好像有做過」，那前面的努力就白費了。

這一節是一條可以照著做的程序，把「做完影片」和「累積語彙庫」接起來。動手前你需要的，只是一支已經完成的影片或 reel、一個可以跟 agent 對話的 session，以及一個放元素的資料夾（還沒有的話，下面第二段會教你順手建一個）。照著走完，你手上會有一個可以重複取用的 elements 資料夾、一份 element catalog，以及一個能預覽所有元素的索引頁。

步驟一：先請 agent 做一個「挑元素」的頁面

第一個動作不是直接去翻檔案，而是請 agent 生一個專門用來挑元素的網頁。它會播放你完成的那支影片（或 reel），讓你邊看邊把喜歡的部分挑出來。把下面這串指令貼給 agent，並把 [your-reel].html 換成你的檔名：

Make me a page that plays [your-reel].html and lets me pick out
its parts. When I pause and hover, outline the element under my
mouse and tell me what it is. Let me save any element to a list,
with a short note on why I want to keep it. Add a button that
copies the whole list, so I can paste it back to you.

預期看到什麼：頁面開始播放影片；當你按下暫停、把滑鼠移到某個元素上，它會被描邊，並顯示這個元素是什麼；你可以把它存進清單，順手寫一句「為什麼想留」；頁面上還有一個按鈕，能一次複製整份清單。實際操作的感覺很像逛網拍把商品丟進購物車：你看到喜歡的就加一件，最後一次結帳。

步驟二：把清單貼回去，成立或加入 library

挑完之後，按那個複製按鈕，把整份清單貼回同一個 session，前面加上一句固定指令：

add to element library: [paste the list from the picker]

如果你還沒有 library，就在這裡請 agent 幫你開一個。慣例是開一個 elements 資料夾，並請它在每個元素旁寫一句「這個可以怎麼重複用」。這一句很重要，因為它是幾個月後你唯一會看的線索。預期看到什麼：agent 把清單裡的元素整理成一包，存進 elements 資料夾，每個元素都帶著它的用途說明。

步驟三：請 agent 正式登記進 element catalog

元素存進資料夾還只是檔案。要讓它以後找得到，得請 agent 建立 element catalog，並在裡面為每個元素寫一筆記錄。把下面這段貼給它：

Add what you just made to my element catalog. One entry: name,
category, file path, and one line on when to use it. Create the
catalog if it does not exist yet, and add to it every time you
make something new from now on. Then build me an index page that
reads the catalog and previews every element in it.

這段指令一次交代了三件事。第一，每筆記錄只寫四欄：名字、類別、檔案路徑、一句「什麼時候用」。第二，catalog 不存在就建立，而且從現在起每次做新東西都要加一筆。第三，請 agent 做一個索引頁，讀取 catalog 並把每個元素預覽出來。預期看到什麼：多了一個 catalog 檔，以及一個打開就能看到所有元素縮圖的索引頁。這個索引頁就是你未來挑元素的入口。

提醒一件事：不要只在「這次很滿意」的時候才登記。真正讓語彙庫有用的，是每次都登記的習慣。你可以把上面那段指令存成一個常用指令，每支影片收尾時就貼一次。

步驟四：下次做影片，把選好的元素加回 prompt

到了下一支影片，流程就反過來了：先打開索引頁，像逛型錄一樣挑這次要用的元素。每選一個，系統就把該元素的檔案路徑記下來；選完之後複製這份路徑清單，放進你要給 HyperFrames 的提示。它的感覺就像把選好的零件放進購物車，結帳時一次帶走。

預期看到什麼：agent 收到的不再是「幫我做一張玻璃卡片」這種從零開始的描述，而是「用 elements/glass-card.html 這張卡片，套在第二段」。因為路徑明確、元素已經驗證過，這一段幾乎不需要來回修改。這也是整個節點真正的回報：下一支影片不再是重做，而是組合。

做完長什麼樣

走完這四步，你應該有一個 elements 資料夾、一份 element catalog（每筆四欄：名字、類別、路徑、用途）、以及一個讀取 catalog 的索引頁。從下一支影片開始，你可以用路徑把既有元素叫回來，只花力氣在新的部分。至於「為什麼登記比堆檔案重要」的原理，前面第一節已經談過，這裡只負責把它變成一個你會重複執行的動作。

小結：挑選、登記、取用，三個動作變成習慣

用一段提示讓 agent 做一個「暫停並懸停就能描邊、可存清單、可一鍵複製」的挑元素頁面；把清單貼回去並加上 add to element library: 成立或加入 library，沒有就在 elements 資料夾開一個；再用一段指令請 agent 登記進 element catalog，每筆寫名字、類別、路徑與一句用途，並做一個索引頁；下次做影片時打開索引頁挑元素、複製路徑，放進 HyperFrames 提示。關鍵不是一次做得多完美，而是每次都登記，讓語彙庫複利。

這一步把整條產線收尾了：你不再只是完成一支影片，而是在累積一套會愈用愈快的系統。接下來可以回到 動態圖像語彙庫 的節點說明，或直接進入下一個節點，把這套語彙庫沉澱成可重複使用的 skill。
