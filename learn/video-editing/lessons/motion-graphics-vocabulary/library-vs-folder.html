語彙庫和資料夾差在哪裡

Step 1/4 · 動態圖像語彙庫

前言：為什麼第十支影片沒有比第一支快？

你可能已經有這種經驗。第一支影片，你和 agent 一起做了一張漂亮的液態玻璃卡片，卡片滑進畫面、停留、再淡出，效果很好。第二支影片又要用到類似的卡片，你只好再描述一次「半透明、有模糊、邊緣有一圈亮光」。到了第三支影片，你隱約記得之前做過，卻找不到那個檔案，於是又從零講一遍。

問題通常不在 agent 不夠聰明，而在每一支影片都是從一張白紙開始。你做過的東西沒有留下能被重複取用的形式，agent 自然每次都得重學一次。做十支影片，等於把同一張卡片重新發明了十次。

這個節點要處理的，就是把「做過而且想再用的東西」變成一份 agent 讀得到、下次叫得出來的清單。有了這份清單，第十支影片才會真的比第一支快。

一支影片裡，有哪些東西值得留下來？

先把「值得留下來的元素」講清楚。在一支用 HyperFrames 做的影片裡，可以被重複使用的東西不只一種，它們的存在形式也不一樣。有些是模型生成出來的檔案，有些是一段 HTML 或 CSS，有些是版面配置，有些甚至只是聲音。

類別例子存在形式
3D 圖像（3D graphics）可旋轉的產品或吉祥物模型生成的圖或 3D 資產
版面（layouts）browser mockup、分割畫面、直式影片格一段可套用的 HTML 結構
動效（motion elements）物件從左側滑入、放大進場時間軸上的動畫設定
資訊圖表（infographics）邊講邊長出來的流程圖可重計時的 HTML／SVG
圖片（images）生成好的插圖或場景圖圖片檔
圖示與 logo（icons／logos）依產業分類的小圖示SVG 或透明 PNG
背景（backgrounds）標題後方緩慢變化的點陣可調參數的 HTML
音效與音樂（SFX／music）短促的 whoosh、背景音樂床音訊檔

把這些分開看，有個好處：你之後在 catalog 裡登記時，會知道每個元素該附上什麼資訊。一個 3D 檔要附素材路徑，一段版面要說明它適用直式還是橫式，一首音樂則要標長度與授權。

recipe 也是元素，只是它住在程式碼裡

除了上面那些檔案型元素，還有一類很容易被忽略：寫在 composition 裡的 recipe（可複製的樣式片段）。液態玻璃卡片是一組 CSS；去背是一段 SVG 濾鏡；地球儀是一串 D3 加上 Canvas 的程式；數字 count-up 是一個會從 0 跑到目標值再停住的動畫。它們不是獨立的檔案，而是一段可以直接貼進下一個 composition 的程式碼。

這類 recipe 之所以值得留下來，是因為它們最花時間。重新設計一次玻璃卡片的透明度、模糊量與內陰影，可能要來回好幾輪；但把上次調好的那組 CSS 直接拿來用，只需要幾秒鐘。把 recipe 當成元素一起管理，就不會每次重做。

資料夾和語彙庫的差別：有沒有「登記」

這裡是整個節點最關鍵的一句話：一個你再也找不到的元件，不是語彙庫，只是一個資料夾。

把做好的檔案丟進一個資料夾，並不叫建立語彙庫。真正讓它變成語彙庫的，是另一份「登記表」，這裡稱為 element catalog（元素目錄）。catalog 裡每一筆記錄只寫四件事：這個元素叫什麼名字、屬於哪個類別、檔案放在哪個路徑，以及一句話說明「什麼時候該用它」。

為什麼一定要登記？因為 agent 只能重複使用它找得到的東西。當你下一次說「幫我加一張玻璃卡片」，agent 會去 catalog 裡找；如果 catalog 裡沒有這一筆，它就算記得你之前做過，也找不到檔案，只能重做一次。這也是資料夾和語彙庫真正的分界：資料夾只有檔案，語彙庫有檔案加上一份可被讀取的索引。

為什麼語彙庫會一次比一次好用

語彙庫最好用的地方，是它會累積。每用一次同一套 skill、多做一支影片，你就會多留下幾個可以重複使用的元素。第一次做一支影片，你要生出所有素材；第二次做主題相近的影片，你可以從 catalog 裡挑出七八成的元素，只補上新的部分；到第十次，你幾乎是在組合既有零件。

換句話說，語彙庫把「每次重做」換成「每次疊加」。它不是讓你今天這支影片變快，而是讓往後每一支影片都站在前面累積的基礎上。接下來幾個步驟，會依序把這份清單補齊：先看幾個最常用的 recipe，再決定新元素該借現成的還是自己做，最後把挑好的元素正式登記進 catalog。

小結：語彙庫是「檔案加上一份登記表」

一支影片裡可重複使用的元素分成幾類：3D 圖像、版面、動效、資訊圖表、圖片、圖示與 logo、背景、音效與音樂；recipe 則是住在程式碼裡的樣式片段。把檔案丟進資料夾還不算語彙庫，關鍵是 element catalog 這份登記表，記下名字、類別、路徑和一句「什麼時候用」。agent 只能取用登記過的元素，而語彙庫會隨著每一次使用累積，讓下一支影片更快。
