# ROADMAP — agent-as-service

## Goal

把已有的 agent 工程能力變成收入：照這門課的 8 週路徑走完「定位 → 上線 → warm/cold outreach → 成交 → 交付 → 增長」，實際成交第一個付費客戶。

## Learning path

**Historical（照課走 8 週）**：保留課程原生的 8 週時間軸，一個 tier 對應一週，節點就是課程的模組本身。順序不做重排——課程的設計（先定位、再上線、再開發、再成交、再交付、最後增長）就是路徑。每週的 milestone 貼文當強制交付物：tier 走完要有對應的真實產出，不是筆記。適合想完全照已驗證的課程節奏執行、用課程時程逼出真實痕跡的人。

## How to use

Read the nodes in order. Each node is a Markdown container whose `steps` array sets the teaching order. Run `/nodes <subject>/<node-id>` to confirm a node and write its steps.

## Nodes

### Tier 1 — 立場與定位（Wk1 · The Opportunity）

1. **[你每天都在用 AI，卻從沒賣過它](nodes/what-to-expect.md)**
   - Goal: 建立心態預期——Transition Curve、reps over perfection，並把 milestone 貼文當交付物。
2. **[AaaS 機會與新 MSP 模型](nodes/aaas-opportunity.md)**
   - Goal: 說出為什麼是 agent 而非 chat、MSP 平行、四個不會被商品化的東西，並寫出一句話定位。
3. **[Your Identity：Naming & Branding](nodes/identity-naming-branding.md)**
   - Goal: 選 lane、取名、驗網域、生 logo，並發出 #week1 介紹貼。

### Tier 2 — 上線（Wk2 · Going Live）

4. **[Website + Business Email 上線](nodes/website-business-email.md)**
   - Goal: 有一個能分享的 URL——三元件網站加 Google Workspace 兩個信箱。
5. **[Building Credentials：沒有客戶也能建立憑證](nodes/building-credentials.md)**
   - Goal: 把既有經驗改寫成「helped who, achieve what, by how」的案例。
6. **[Your First Announcement：第一次公開公告](nodes/first-announcement.md)**
   - Goal: 發出 LinkedIn 公告、在對話裡種下轉介紹種子，並發 #week2 貼。

### Tier 3 — 找到第一個客戶（Wk3 · Finding Your First Client）

7. **[The Mindset Shift：一切都是數學](nodes/mindset-shift.md)**
   - Goal: 追 input KPI 而非 output KPI，把拒絕除個人化。
8. **[Warm Outreach：最快的第一個客戶](nodes/warm-outreach.md)**
   - Goal: 建 50+ 名單、寫 50 字內訊息、最多兩次 follow-up，導向 discovery call。
9. **[Cold Outreach：規模化的陌生開發](nodes/cold-outreach.md)**
   - Goal: 掌握 3–5 句、免費價值先行、1–5% 回覆率的數學。
10. **[Cold Outreach Automation Kit：Apollo → Instantly](nodes/cold-outreach-automation-kit.md)**
    - Goal: 把冷信機器真的架起來——credit 經濟學、域名 warmup、campaign 三段結構，發 #week3 數字貼。

### Tier 4 — 成交（Wk4 · Closing the Deal）

11. **[The DOTS Framework 與 Discovery Call](nodes/dots-framework.md)**
    - Goal: 跑一場只問不推銷的 5WH 通話，用 Intro Pack 實例結構提案。
12. **[Pricing & Closing Techniques](nodes/pricing-closing.md)**
    - Goal: 對價值定價而非時數，用 anchoring、guarantees、scarcity 與縮範圍 pilot 收尾。
13. **[Making It Official：Contracts & Invoicing](nodes/contracts-invoicing.md)**
    - Goal: 寫出六要素合約、50/50 請款，防 scope creep。

### Tier 5 — 交付（Wk5 · Delivering Results）

14. **[The Build Phase：先交出 MVP](nodes/build-phase.md)**
    - Goal: 把提案餵給 agentic platform、先建核心功能、用 demo 換回饋。
15. **[The Integrate Phase：進入客戶的真實環境](nodes/integrate-phase.md)**
    - Goal: 選對三種整合模式，安全取得權限，完成 handover 訓練。
16. **[The Tune Phase：Results Reporting 不是選配](nodes/tune-phase-results-reporting.md)**
    - Goal: 寫出有數字、有美元值的月報，養出 retainer。

### Tier 6 — 溫暖增長（Wk6 · Warm Leads）

17. **[Expanding with Existing Clients](nodes/expanding-existing-clients.md)**
    - Goal: 用 adjacent problems 找 upsell，分清三種 retainer。
18. **[Getting Referrals](nodes/getting-referrals.md)**
    - Goal: 在贏的當下直接開口、給腳本、讓轉介紹容易發生。
19. **[Proof & Presence](nodes/proof-presence.md)**
    - Goal: 把 testimonial 建進交付流程，並在實體場合被記住。

### Tier 7 — 冷流量與 Inbound（Wk7 · Cold Leads）

20. **[Content for Inbound](nodes/content-for-inbound.md)**
    - Goal: 理解內容是複利資產，從 short-form 發出第一支。
21. **[Content Strategy：什麼真的有用](nodes/content-strategy.md)**
    - Goal: 掌握 hook、批量產量、email 名單與 selfless content 四槓桿。
22. **[Productizing Your Offer](nodes/productizing-your-offer.md)**
    - Goal: 從過去專案挖模式，做成命名、定價、可範本的 package。

### Tier 8 — 展望（Wk8 · Expanding Beyond）

23. **[Your Freedom Number](nodes/freedom-number.md)**
    - Goal: 算出自己的數字，反推成客戶數 × 客單價 × 每週動作。
24. **[Learning How to Learn](nodes/learning-how-to-learn.md)**
    - Goal: 分清 evergreen 與工具、架 AI 晨報、build > consume。
25. **[What's Next：槓桿的三 C](nodes/whats-next.md)**
    - Goal: 分辨 Capital、Code、Content 三槓桿，規劃 services → content → products 的路徑。
