# L1 overview

- RoboLabs' real client pricing deck (client anonymized as "Poppies Studios"), the worked example behind the anchoring lesson: a Build Plan slide describing four agents (Clipper, Publisher, Analytics, plus a bonus Remix agent) with feasibility checks, followed by the B.I.T. framework slide and an Engagement Summary table with per-phase pricing.
- The pricing table quotes $1,000 per phase per agent with the anchored $3,000 crossed out and marked "Special rate" — the actual example of showing a higher price first, then the rate you really want.
- Payment structure: 50% down for Phase 1, review together at Milestone 1, then move to Phase 2; if the work proves technically infeasible, a full refund — framed as "low-risk, high-value, especially while AI is still new and expectations are evolving"; Tune is scoped separately in a footer because its difficulty (legacy systems, complexity) only becomes clear after the build.
