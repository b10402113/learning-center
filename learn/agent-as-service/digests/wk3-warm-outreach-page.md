# L1 overview

- Course-page text for lesson "2️⃣ Warm Outreach" (robonuggets / 🔶 Agents-as-a-Service / Wk3): Jay covers reaching people who already know you — the fastest path to a first client.
- Learning outcomes: build a 50+ contact list from phone/LinkedIn/email, write a sub-50-word message with a clear ask, follow up with intent (two max).
- Contains the agent prompt for generating a personalized warm outreach message, the message template, the contact-export tool list, and a pointer to the Warm Outreach Skill Kit file for AI agents.

# L2 detail

- `#L1-L29` — Title, breadcrumb, and "What You'll Learn": build a list of 50+ contacts from phone, LinkedIn, and email; write a short outreach message under 50 words with a clear ask; follow up with intent (two follow-ups max).
- `#L30-L64` — "Warm Outreach Message" resource: warm outreach is free, fast, highest conversion, needs only contacts and 30 minutes a day; verbatim agent prompt ("Ask me numbered questions about my AI practice... write me a short outreach message (under 50 words) and a follow-up message for 3-5 days later") and the template — "Hey [Name], Quick one, I've started helping businesses automate their work with AI. Do you know anyone who might benefit from something like this? Happy to chat if you want to know more. Either way, hope you're well! P.S. Also have our website (website.com) if you need more info."
- `#L65-L85` — Tools for building the contact list: Google Contacts CSV export (contacts.google.com), LinkedIn Export via Settings → Data Privacy → Get a copy of your data, iPhone and Android contacts export links; the Warm Outreach Skill Kit MD is a knowledge file to feed your AI agent (Claude Code etc.) so it can export contacts, write personalized messages, and manage outreach across LinkedIn, phone/SMS, and Gmail; attachment listed as "Warm Outreach Skill MD".
