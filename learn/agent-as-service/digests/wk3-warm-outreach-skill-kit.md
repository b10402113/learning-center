# L1 overview

- RoboLabs knowledge file to feed an AI agent (Claude Code etc.) so it becomes a warm outreach expert across three channels: LinkedIn, phone/SMS, and email via Gmail.
- Defines the 5-step workflow (export → clean & tier → write personalized messages → send in controlled batches → follow up 2x max), then gives per-channel export steps, message best practices with numbers, timing/cadence tables, safety limits, and compliance notes.
- Ends with AI-assisted writing prompts, a cross-platform safe-limits quick reference, and 10 universal rules ("never pitch in the first message", "plain text beats HTML", "the goal is a conversation, not a conversion").
