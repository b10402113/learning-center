# 歷史也許不會完全重複，但它會押韻

上一篇幫你找到可以開價的方向。但要把這門本事變成收費的服務時，腦裡總會浮出一個很實際的問題：這門生意能長多大？它是熱潮一過就蒸發的生意，還是能撐幾十年的行業？

這問題不用靠直覺回答。歷史上有一段幾乎一模一樣的劇本可以對照，也有具體的數字可以算。

## 上個世代已經發生過一次

把時間往回撥二三十年。電腦剛進辦公室的那個年代，大多數公司根本沒有能力自己管理這些機器。於是一類新生意出現了：MSP（Managed Service Provider，管理服務供應商），替企業管理 IT 系統的公司，幫你架設系統、讓系統持續運轉、壞了幫你修。

技術難只是表面。公司真正要的是一個可以負責的窗口：確保這些系統真的整合進業務裡，而不是買了一堆機器擱在那裡。

這個市場現在值 3,800 億美元。Accenture、TCS、Capgemini 這些大公司，都是這個領域的玩家。

## 機器變簡單了，生意卻沒有消失

現在買電腦、設定電腦已經這麼容易，MSP 怎麼還活得好好的？

因為歷史證明的是，新技術會一直冒出來。Accenture、Capgemini 這些公司早已不幫企業裝電腦了，但它們幫你做雲端儲存、資料目錄、資料治理，企業需要的新技術換了名字，付費找人處理的結構完全沒變。

今天的 AI agent 就是這一輪的「新技術」。企業需要的是：有人幫他把 agent 架起來；有人在一段期間內持續維護；模型更新時（現在幾乎每個月都出新模型）有人幫他跟著升級；最重要的，壞掉的時候有人可以打電話。

這四件事，跟三十年前請 MSP 裝電腦、修電腦，是同一張訂單。

## 為什麼每個產業都會需要

這不只是科技公司的事。只要一家公司的工作內容是知識工作、是智力勞動，它現在就開始變成一門 AI 生意，就像前幾年每家公司都被「大數據」燒過一輪。

這股轉變橫跨所有產業：

- 律師事務所：用 agent 做文件審閱、客戶接待（client intake）。
- 房地產公司：用 agent 篩選潛在買家（qualify leads）、自動安排看屋行程。
- 創意產業：整條製作管線正在被翻轉，因為 agent 已經能端到端地把影片做出來。

從中小型企業到大型企業，每一家都會因為 AI agent 的引入而轉型。所以不管你最後選哪個利基、哪個產業，「看懂 AI agent 怎麼運作」都換得出錢。

## 數字說話

還有幾個訊號可以確認這波機會有多大：

- Y Combinator 最新的創投批次裡，將近一半是 AI agent 公司。
- Andrew Wilkinson（Tiny 的創辦人、億萬富翁）公開聘僱專家替他打造 AI agent，而不是自己學。有錢有時間的人選擇買別人的專業，這件事本身就是訊號。
- AI-as-a-Service 市場將從 200 億美元成長到 2030 年的 910 億美元；換一種算法，企業 AI 市場將從 970 億美元成長到 2030 年的 2,290 億美元。

<!--image:3-->

3,800 億美元的 MSP 市場，是上一輪技術轉型留下的結果。這一輪才剛從 200 億美元開始往上跑。你現在進場的時間點，跟三十年前那些幫辦公室裝電腦的人一樣。

## 下次被問到，就這樣答

下次有人問你「做 AI agent 服務到底是不是一門生意」，別講熱潮。用一句話講給對方聽，也講給自己聽：上個世代，不會管電腦的公司養出了 3,800 億美元的 MSP 市場；這一個世代，不會用 AI agent 的公司會重複同一件事，而你就是那個被找去的人。不過，這個答案要站得住，先得回答一個更根本的擔心：AI 一直變強，這門手藝會不會終究被商品化？下一篇正面處理。
