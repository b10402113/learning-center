# Chat 是 table stakes，agent 完全不同

你每天用 AI 查文件、改程式、整理重點，這沒什麼特別。但如果有人問「你能幫我什麼？我願意付錢」，回答「我很會用 ChatGPT」是收不到錢的。

這跟你的技術好不好無關，重點是你打算賣的東西值不值錢。先講清楚一件事：chat 為什麼已經賣不起來，「會做事的 agent」為什麼才收得到錢。

## Chat 為什麼收不到錢

最基礎的 AI 應用就是 ChatGPT：你問，它答。現在任何人都能用它生成一張圖、寫一篇文章。當一項服務普及到人人自己就能輕鬆做到，它就商品化了：你因為「會用」而有的優勢，跟著消失。

這種現象有個說法叫 table stakes：上桌的最低賭注。每個玩家都有，所以有等於沒有。會用 chat 工具就是今天的 table stakes，它讓你上牌桌，不能讓你收費。

## 差別在 agent 會做事

Agent 不一樣。它真的會做事：除了回你訊息，還會自己往下做，接進真正的商業工作流。

Chat 的產出是一段文字，接下來做不做、怎麼做，還是你的事；agent 直接接手工作流裡的一段，把它跑完。

如果你是每天把 agent 跑起來的工程師，「會做事」在技術上不是瓶頸。機會在另一邊：企業自己卡住了。

## 公司缺的不是模型，是把它接進來的人

公司想在自家營運裡導入 AI agent，但多半自己做不起來。找人把 agent 裝起來只是第一件事，後面還有三件：有人替他們維護一段時間、模型更新時跟著更新（現在幾乎每個月都有新模型），以及出事的時候，有一個人可以打給他。

最後一件是責任。系統要真的整合進公司營運，就必須有人對結果負責，這件事目前不會由一個 chatbot 來扛。

整合進工作流是什麼樣子？看幾個行業就知道：律師事務所讓 agent 做文件審查和客戶接待；房地產公司讓它篩選潛在客戶、排看屋行程；創意產業的整條製作管線也在變，因為 agent 已經能從頭到尾把影片做出來。每個例子裡，agent 都不是聊天視窗，而是工作流裡的一段。

<!--image:2-->

市場上也看得到同樣的事。Y Combinator 最新的幾批新創，接近一半是 AI agent 公司；Tiny 的創辦人 Andrew Wilkinson 公開聘請專家來建 AI agent，沒有自己學。連最有資源的人都選擇找外面的人做。AI-as-a-Service 的市場規模，預計從 200 億美元成長到 2030 年的 910 億美元。

## 你要賣的是哪一種

回到收不到錢的問題。分界線很清楚：凡是「會用 chat 就能做到」的，客戶自己十分鐘後也能做到，那不是生意；客戶買的是工作流裡有一段交給你的 agent 跑，跑壞了有你這個人可以找。

動手做一件事：從你身邊找一個具體的業務痛點，同事、前客戶或朋友手上那種每天重複的知識工作，然後問自己：chat 給一段文字能不能解決？如果不行，需要有人把一段流程接起來負責到底，那才是可以開價的方向。
