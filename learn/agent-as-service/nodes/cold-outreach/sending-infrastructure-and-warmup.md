# 打造一台每週帶進新對話的冷信機器

你手上有一份兩百人的名單，第一個念頭多半是：打開自己的 Gmail，開始寄。

這個念頭正是最容易出事的地方。冷信不是把信寫好就好，真正決定成敗的是「從哪個信箱寄、寄得夠不夠多」。這一層搞錯，信寫得再好，下場都一樣：垃圾信匣。

## 為什麼不要用主力信箱發

主力信箱是你每天跟朋友、客戶、合作對象往來的那一個。它承載的不只是收發信，還有你在網路上的身分。

拿它去寄冷信，最糟的結果是被標成垃圾郵件寄件者。影響的是 deliverability（寄達率）：你寄出的信有多少真的進到對方收信匣，而不是被攔下來或丟進垃圾桶。

Gmail 這類供應商會盯著你的寄送模式。今天突然一天寄五十封給一群從不回信的人，Google 就會壓低這個信箱的聲譽，接著封鎖你、把你丟進垃圾信匣。

麻煩的是這件事會外溢。信箱被壓下去之後，連平常寄給朋友和客戶的信都會受影響。為了開發新客戶，賠掉原本在用的聯絡管道，不值得。

解法不是「寄得更小心」，而是換一個專門寄冷信的信箱。

## warmup：讓寄信的信箱先被信任

市面上的冷信工具有 Lemlist、Smartly 這類。挑選時真正要看的不是功能列表，是「好用」加「可靠」。Instantly.ai 在這兩件事上平衡得不錯，有免費試用，可以先小規模跑一輪再決定。

它做得到 Gmail 做不到的事，第一個就是 warmup。

warmup 是用大約一週的時間，讓準備寄信的信箱先建立信任，確保它不會被 Google 或其他信箱供應商標記。先讓信箱「看起來像個正常人」，再讓它去寄陌生開發信。

不想等這一週，Instantly 也提供已經 warmup 完的信箱直接買。買下去會拿到同一組網域下的五到六個帳號，當天就能開始寄。那個網域還可以設轉址，有人點進去會被導到你真正的網站。

所以有三條路：已經有 Google Workspace 信箱的，直接接進來；完全沒有信箱的，可以讓它幫你開；想今天就開始寄的，買預熱好的帳號。

## campaign：把名單變成每週幾百封

信箱準備好，下一步是 campaign。

一個 campaign 只有兩個核心：leads 和 sequence。leads 是名單，上傳 CSV 就好；sequence 是那封信本身，包含主旨、內文和動態欄位。

這裡不建議自己一欄一欄手動填。Instantly 有 API，可以把操作說明丟給 Claude Code 或 Antigravity 這類 agent，讓它代替你在 Instantly 裡建 campaign、寫主旨、寫內文、填動態值。用 agent 建比自己做快得多，而且可以重複。

至於為什麼非用工具不可：手動寄兩百封會寄到天荒地老。設定對之後，每週幾百封信在自動駕駛上跑，你才有辦法把力氣放在回覆和通話上。

## 量是先算出來的，不是寄出來的

冷信的回覆率本來就低，一開始抓一到五趴是正常的。這不是失敗，是這個通路的常數。

把數字攤開：回覆率兩趴，五十封換一個對話；寄兩百封，就是四個對話。要更多對話，就寄更多信。

抱怨冷信沒用的人，多半寄了十五封就放棄。這個量級根本還沒進入數學。

另一個常被低估的是 follow-up。正面回覆裡有六到七成來自 follow-up，不是第一封陌生信。第一封只是把種子種下去，真正把人叫回來的是後面那一下。

節奏上，等三到五天再補一封短信。不要隔天就追，那樣看起來很急。最多跟兩到三次就收手，往下一個名單走。

心態也要先調整：這個階段不是在賣，只是在開啟對話。對方一感覺到「有人在推銷我」，防備心就上來。輕鬆、有幫助、像一般人在講話，成交是後面的事。

## 你要做的那個動作

挑至少二十個潛在客戶，把冷信寄出去，然後記錄結果。

不要追求完美的信，先追求寄出的信。文案可以等有數據再改，但得先有第一批寄出去的東西，才知道這條路對你而言長什麼樣子。
