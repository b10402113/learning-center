# 選一個 domain、找出哪些還可用，再用 Namecheap 把它拿下

名字有了，下一步是把它變成網址：買一個 domain、放上網站，讓任何人都打得開。這件事不用糾結，也別花太多時間——能上線的地址，比完美的地址重要。

## 先認識 TLD：網址最後那段結尾

TLD（Top Level Domain）就是網址的結尾，例如 .com、.ai、.io。同一個名字配不同結尾，可用性、價格和感覺都不一樣。

好名字的 .com 多半早就被註冊走了。這時有兩個做法：

- 在名字後面加 modifiers。例如 Bright AI 被拿走，就加字換個組合。
- 改用替代結尾。.ai、.io、.co 都常見，看起來也專業。

## Namecheap：先一般搜尋，再開 Beast Mode

註冊 domain 的服務很多，Namecheap 最簡單，先用它就對了。

在搜尋框輸入想要的名字，例如 neocore。.com 很可能已被註冊，但結果頁會直接列出還買得到的結尾——你可能會發現 neocore.to 還開著，價格也不貴。

想一次試多一點，就切到同一個網站裡的 Beast Mode 分頁。它專門處理關鍵字組合，流程三步：

1. 把所有感興趣的關鍵字一次輸入。
2. 設定願意付的價格範圍，用它過濾結果。
3. 勾選 domain hacks 調整名字形態，指定想要的結尾，按 generate。

## domain hacks 會怎麼改你的名字

domain hacks 是對名字動一點手腳，讓可用選項變多：

- 拿掉最後一個母音。Flickr 當初就是這樣來的。
- 把名詞變複數。tool.com 被註冊了，tools.com 可能還開著。

目的只有一個：把選擇空間撐大。

## 該選哪種結尾？兩個實例

Beast Mode 可以鎖定你想要的 TLD。.ai、.io、.app、.so 都很常見，信任度也夠。按 generate，它會列出這些結尾下能試的組合。

兩個實際的價格感覺：

- **neocore.so**：如果 .com、.ai、.io 都被拿走，清單裡最合理的下一個可能就是它。畫面顯示的是澳幣價，一年大約 60 美元，不貴。.so 也早就被大公司用開了——Notion 的主網域就是 notion.so。
- **kiva.solutions**：.solutions 是比較少人知道的好選擇。短名字在這裡還有機會：挑一個四、五個字母、之後能品牌化的詞，例如 kiva，註冊 kiva.solutions，一年 12 澳幣、約 8 美元，讀起來就像個正式事業。

## 不想花錢？Netlify／Vercel 的免費子網域

買 domain 的錢現在是門檻？沒關係，照樣可以有網站。

Netlify 和 Vercel 提供免費託管，附帶它們自己的子網域。Netlify 是把網站發布到網路上的平台；部署完成，你就有一個像 robalabsai.netlify.app 的網址，任何人都打得開。這不是過渡用的空殼頁——它可以是完整網站，有互動、有客戶推薦、有聯絡表單。

Vercel 只比 Netlify 複雜一點點，結果一樣：免費拿到 neocore.vercel.app 這種網址。

## 讀完就做這一步

挑一條路，今天做完：

- 願意花錢：在 Namecheap 查名字的可用結尾，或用 Beast Mode 批次產生關鍵字組合，選一個立刻註冊。
- 想免費：把網站推上 Netlify 或 Vercel，先拿免費子網域站住位置。

兩條路通向同一個結果：一個能傳給客戶、能放在社群檔案上的上線地址。地址有了，下一篇補上這個身分的臉——logo。
