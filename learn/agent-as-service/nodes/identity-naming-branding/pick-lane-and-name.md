# 半小時想一個名字，然後帶著它往前走

你已經能做出跑得動的 agent demo，但手上沒有名字、沒有網域、也沒有一個拿得出手的帳號。要把「我賣 agent 服務」變成說得出口的事，第一個卡住你的往往是最基本的問題：這門生意該叫什麼？上一篇寫下的那句 one-liner，就是這個身分要講的第一句話；現在給它一個名字。

好消息是，名字不需要第一次就完美，之後隨時可以 rebrand。這一步要的不是完美，是夠真實，真實到能讓你繼續往前走。

## 先選 lane：operational 還是 creative

命名有個順序：先對自己要走哪條 lane 有個粗略概念，才選得出對的名字。兩條 lane 分別是：

- **operational**：幫企業把業務流程自動化。
- **creative**：把內容產出自動化。

不用硬切一半，兩者兼做完全可以。先有個輪廓就好，不必急著做出完整定位。

真的選不動，有個安全解：直接自稱 **AI solutions practice**。這個稱號夠寬，之後不管做什麼都罩得住；等找到 niche，再 rebrand 也來得及。

## 名字為什麼不是隨口取

字是有重量的。你怎麼稱呼自己、怎麼稱呼生意，會反過來塑造客戶對你的觀感。介紹自己時，名字是對方聽到的第一個東西。名字取得隨便，對方對你的 practice 的第一印象也跟著隨便。

所以想到名字還不算數，還得看它在現實世界裡用不用得上。

## 先列清單，再用可用性過濾

想到的名字一律先寫下來，自己想或請 AI 幫你生一批，然後逐個查兩件事：

- **TLD（top-level domain，網域尾綴，例如 .com、.net、.io）**：這個名字的網域還在嗎？像 Neocor.com 這種一眼就讓人想用的，多半已被註冊。
- **社群 handle**：LinkedIn、Instagram 上的帳號被搶走了沒？常見名字的 handle 通常剩得不多。

如果能把這個名字的 .com、.net、.io 等尾綴都拿到手，專業感和可信度直接加分，這也是可用性這關不能跳過的原因。

namecheck.com 這類工具能快速過這一關：輸入名字按搜尋，出現一張哪些網域尾綴還可用的快照；點 check usernames，一眼看到這個帳號還能在哪些平台註冊。名字被佔了也不用推翻重來：加個 modifier，或改找 .ai、.io、.co 這類替代尾綴，路就寬了。

## 計時三十分鐘，時間到就定案

這件事值得花的時間大約是 30 分鐘：快速想出一個名字，然後帶著它往前走。這麼趕，是因為你隨時可以改；卡在這裡，後面每一步都動不了。

這一週結束前，你手上該有一個有名字、有品牌、ready to go 的實體。名字是這個實體的第一塊積木，網域和 logo 緊接著來。

現在就動作：設一個 30 分鐘計時器，先寫下你的 lane 是 operational、creative，還是兩者兼做；列出候選名字，逐個查 TLD 與社群 handle；計時器一響，選一個網域還買得到的，定下來。

名字定了，下一篇把它變成網址。
