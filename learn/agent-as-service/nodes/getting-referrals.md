# Getting Referrals

## Lesson

轉介紹是信任的轉移，而且會複利：一個滿意客戶帶來同產業的兩三個。原則只有三條——直接開口、在贏的當下問、讓它容易發生；Wk5 的結果報告就是可轉寄的證據。
