# Warm Outreach：最快的第一個客戶

## Lesson

已經認識你的人是最快的第一單：建 50+ 名單、發 50 字內有明確 ask 的訊息、最多兩次 follow-up，把轉介紹導向 10 分鐘 discovery call。skill kit 的分通道流程直接餵給自己的 agent 跑。

1. [認得你名字的人，都算 warm](warm-outreach/why-warm-first.md)

3. [50 字以內、有一個明確 ask 的短訊息](warm-outreach/write-the-message.md)
4. [跟進兩次，然後停](warm-outreach/follow-up-twice.md)
