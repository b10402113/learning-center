# 每週最重要的東西，是那個每週 milestone

線上課上多了，很容易養出一種讀法：影片全看完、筆記寫得整整齊齊，讀完很有收穫感，一個月後卻發現什麼都沒發生。這種讀法在這八週行不通。判斷一週有沒有「讀完」，看的是有沒有交出那週的 milestone，筆記多完整不算數。

## 一週的節奏：1 個 focus＋3 個 modules＋1 個 milestone

每週一章，全部在 60 天內完成。每一週固定是三件東西：

- 🔲 **Focus for the week**：該週的主題，從這裡開始，先看清這段時間要學什麼。
- 1️⃣ **3 個 hands-on modules**：圍繞該週主題的實作單元。
- ✅ **Weekly Milestone**：該週的出口，把進度分享給社群。

一週的節奏很清楚：1 個 focus 定方向，3 個 modules 教做法，1 個 milestone 要你做出來。看完 modules 只是輸入，milestone 才是這週必須產出的東西。

## 只看不做，是不會動的

每週最重要的就是 milestone。它給你一個明確、可執行的任務，難度會隨著你讀到哪一週而變。

只有把 milestone 做完，行動才會變成結果。整堂課看完、卻沒有任何行動，不會有用。你一定會得到一些新知識，也許之後某天用得上，但既然都在讀了，不如在完成 modules 的當下就直接做出來。

還有一個很實際的理由：完成 milestones 是拿到最終獎勵的條件。最後有一張完成表格，要求提交每週的 milestone——平時沒累積，到頭來連要交的東西都不存在。靠筆記唸完這門課的路線，在這裡走不通。

## milestone 是一則貼文，不是一份筆記

milestone 要你有動作，也要你跟人互動。很多 milestone 就是設計來讓你對社群分享進度、跟其他人開始交流。

這門課的玩法有點像讀大學：課程本身能學到很多，但跟身邊的人互動，會拿到更多。社群裡有一大群來自世界各地、真的在用 AI 做出東西的人，當你把服務一步步建起來，這些連結會替你開門。milestone 貼文就是最低的破冰成本——與其默默讀完然後消失，不如讓作品先被看見。

<!--image:3-->

## 讀完你要做的那個動作

打開課綱，把第一週的 milestone 先排進你的行事曆，當成必交的交付物：沒交，這週就不算完成。第一週結束前，讓社群裡出現你的第一則進度貼文，這週才算真的讀完。

只是，知道要交和真的每週交出來是兩回事。路上真正淘汰人的，往往不是難度，是情緒。下一篇先給你那張情緒地圖。
