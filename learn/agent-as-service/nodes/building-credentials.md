# Building Credentials：沒有客戶也能建立憑證

## Lesson

雞生蛋問題的解法是重框：你已經有的經驗——工作自動化、side project、任何成果——都能改寫成「helped who, achieve what, by how」。credibility 是被創造出來的，不是等來的。
