# MEMORY — AI Agents

## Goal
端到端地构建并真正跑起来一个可工作的 ReAct 式智能体系统：它能做计划、调用工具（如搜索引擎、计算器），跨多轮对话持有记忆，并能基于检索到的文档（RAG）生成有依据的回答。做完之后，手里有一个能指得出来的成品，而不只是"理解了智能体"。

## Why
想真正看清智能体系统在表面之下到底在做什么，从而能判断各种工具/框架的优劣，并具备自己动手搭建的能力。这是支撑我在遇到难点时继续坚持的深层动机。

## Prior experience
- Python 中等级：能写脚本、跑 notebook / Colab、会用 `pip install`，但不算熟练工程师
- 机器学习基础：了解基本概念，但不熟悉 PyTorch 等深度学习框架
- 没有 LLM 应用/智能体相关的使用经验：没用过 LangChain、AutoGen 等框架，也没做过 RAG 或嵌入应用

## Anchors
- 每天正在用 AI 编程智能体（opencode / Claude Code 类工具）——这个工具本身就是 ReAct 式系统：有工具、有计划循环、有记忆、会读文件。这是第 7 章最生动的活锚点
- 维护着这个学习仓库——已经会如何把原始资料转成结构化课程，天然对应"智能体如何拆解任务"（第 6 章链式提示）
- 作为普通用户用过 ChatGPT / DeepSeek 等聊天产品——可用于对照"模型本身做什么 vs. 智能体外壳额外加了什么"

## Habits & constraints
- 时间灵活，按本仓库格式安排：每个 10–15 分钟的 lesson 一次会话，跨周渐进
- 无 GPU 假设：用 Google Colab（本书默认 T4）＋本地 GGUF 小模型（Phi-3 级别）＋一个 LLM API 的组合，覆盖第 7 章本地路径和第 8 章 API 路径，无需额外购置

## Knowledge type
Mixed，以程序性（procedural）为主：既需要陈述性理解（为什么 ReAct 有效、注意力与 RL 如何支撑智能体），更需要动手技能（真正接线工具、记忆、检索）。按混合型处理：先轻量陈述性打底，然后大部分时间用于动手练习。

## How to teach me
- 靠"构建并弄坏"来学习：每节课以能运行的东西收尾，且开头先说清一个具体的"为什么"
- 图解与直觉先行，数学越少越好（本书全图解，正合适）
- 避免冗长的纯文字铺陈；宁可给可运行的示例 + 清晰的图示
