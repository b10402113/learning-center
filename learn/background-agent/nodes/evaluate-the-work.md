# 評估工作，不只是最後一句話

## Lesson

一份漂亮的總結可能藏著無關的 disable、太晚的批准，或從過期證據宣稱完成。這個節點把評估拆成世界狀態、行動序列與人類邊界三層，並討論失敗要歸因到證據、工具契約、harness 政策還是事件關聯。
