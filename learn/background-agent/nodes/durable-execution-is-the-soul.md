# 耐久執行是靈魂，不是全部

## Lesson

durable runtime 讓代理永遠醒著，但它不負責事件從哪來、權限怎麼給、瀏覽器或機器怎麼託管。這個節點比較 DBOS、Temporal、Vercel Workflows 等選擇，並把可轉移的 harness 延伸到 email 與 coding agent。
