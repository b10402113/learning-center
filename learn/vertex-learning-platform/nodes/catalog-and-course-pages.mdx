# 首頁、課程總覽與課程頁

## Learning goal

能用 server component + sanityFetch 讀 Sanity 內容，渲染首頁/總覽/詳情頁，並用 GROQ 算 aggregate。

## Steps

1. [[learn/vertex-learning-platform/nodes/catalog-and-course-pages/server-component-homepage|用 Server Component + sanityFetch 串接首頁真實資料]] — 從靜態 mockup 換成 Sanity 動態查詢，理解 server-only 安全邊界
2. [[learn/vertex-learning-platform/nodes/catalog-and-course-pages/course-details-page|課程詳情頁：動態路由、GROQ aggregate 與 reverse reference]] — 建出課程詳情路由，展開 modules/lessons，用 reverse reference 找父課程 (after step 1)
3. [[learn/vertex-learning-platform/nodes/catalog-and-course-pages/all-courses-page|All-courses 總覽頁：列表複用與 CodeRabbit 審查]] — 列出全部課程，複用組件，處理 null slug 與 CodeRabbit review (after step 2)

## Lesson

這節課把 Vertex 從「有 UI 但沒資料」推進到「首頁、總覽頁、詳情頁全部接上真實 Sanity 資料」。三步走完之後，你應該能用 Server Component + `sanityFetch` 讀取 Sanity 內容、用 GROQ aggregate 算出課程統計、處理 reverse reference 反查父課程，並理解 CodeRabbit 如何在 AI 生成的 code 裡抓到 edge case。核心模式是：Server Component 在 server 端查好資料，把結果作為 props 傳給 Client Component——token 永遠不出現在瀏覽器端。
