# 種子資料：把空 schema 變成真實資料

## Learning goal

能用 deterministic ids 與 idempotent import 把 141 份文件、120 支真實 YouTube 影片種進 Sanity，並懂為什麼內容品質決定搜尋品質。

## Steps

1. [[learn/vertex-learning-platform/nodes/seeding-content/deterministic-ids-and-idempotent-import|Deterministic IDs 與冪等匯入]] — 為什麼 Sanity 需要穩定 ID 與重跑不重複的匯入機制
2. [[learn/vertex-learning-platform/nodes/seeding-content/seed-data-structure|Seed 資料結構：141 份文件的內容地圖]] — categories → instructors → courses → lessons 的完整結構（after step 1）
3. [[learn/vertex-learning-platform/nodes/seeding-content/video-resolution-and-seed-pipeline|影片解析與 Seed 管線]] — videos.json 如何把 lessons 對應到真實 YouTube 影片（after step 2）
4. [[learn/vertex-learning-platform/nodes/seeding-content/content-quality-drives-search-quality|內容品質決定搜尋品質]] — 為什麼 seed 內容的連貫性直接決定搜尋能否用（after step 3）

## Lesson

空的 Sanity schema 只是一套規則，沒有東西可以搜尋、沒有東西可以渲染。種子資料（seed）把這套規則變成真實內容——141 份文件、120 支真實 YouTube 影片——讓學習平台從第一天就有東西可以展示。這四步從「為什麼需要穩定 ID」開始，走過資料結構與影片解析，最後停在一個關鍵洞察：搜尋品質完全取決於內容品質，所以第一次 AI 寫入資料庫必須審查，不能盲批。
