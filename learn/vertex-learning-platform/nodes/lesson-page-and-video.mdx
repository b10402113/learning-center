# 課程頁與影片播放

## Learning goal

能實作 lesson 頁——provider embed（poster→點擊換 iframe）、`?t=` 起播秒數、Portable Text notes、reverse reference 反查父課程與課程表。

## Steps

1. [[learn/vertex-learning-platform/nodes/lesson-page-and-video/sanity-lesson-query|用 reverse reference 建立 lesson 資料查詢]] — 用反向引用從 Sanity 查出 lesson 所屬的父課程與模組結構
2. [[learn/vertex-learning-platform/nodes/lesson-page-and-video/lesson-video-player|Lazy-loading 視頻 embed 與深連結起播]] — 實作 poster→iframe 的懶載入播放器與 `?t=` 深連結（after step 1）
3. [[learn/vertex-learning-platform/nodes/lesson-page-and-video/lesson-page-layout|完整 lesson 頁：側邊欄、筆記與導覽]] — 組裝麵包屑、側邊欄、Portable Text 筆記與下一課導航（after steps 1–2）

## Lesson

lesson 頁是學習平台的核心體驗——學習者在這裡看影片、讀筆記、決定下一步。本節課從資料層出發，先用 reverse reference 一次查出 lesson 和它的父課程，再用 lazy-loading 模式把影片播放器的第三方 JS 延遲到點擊才載入，最後把側邊欄、Portable Text 筆記和導覽元件組裝成完整的 lesson 頁面。三步走完，你會有一個能用的 lesson 頁，以及對「為什麼影片不能直接放 iframe」「為什麼反向引用比加欄位好」這類設計決策的判斷力。
