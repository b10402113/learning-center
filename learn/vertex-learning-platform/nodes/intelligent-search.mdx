# 智慧搜尋：MCP + grounding + 兩段式時間戳

## Learning goal

能架 Sanity Context MCP + server 端 search API，用「模型只選 ID、Sanity 供事實」的 grounding 讓結果不可能造假，並懂 chapters-first 時間戳解析與 search UI。

## Steps

1. [[learn/vertex-learning-platform/nodes/intelligent-search/search-architecture|智慧搜尋架構：瀏覽器到 Sanity MCP 的完整路徑]] — 畫出 browser → server route → MCP → LLM 的資料流，說明為什麼 browser 永不直接碰 LLM
2. [[learn/vertex-learning-platform/nodes/intelligent-search/grounding-and-config|搜尋接地與配置：讓 AI 只能挑選、不能編造]] — 說清「模型只選 ID、Sanity 供事實」的 grounding 與 config-as-content（after step 1）
3. [[learn/vertex-learning-platform/nodes/intelligent-search/search-api-implementation|實作 POST /api/search：五道檢查的搜尋閘門]] — 把查詢變成 MCP 工具迴圈、驗證輸出，解釋 CodeRabbit review 五要點（after step 2）
4. [[learn/vertex-learning-platform/nodes/intelligent-search/search-results-ui|搜尋結果頁面：四種狀態與 Cmd+K 互動]] — 實作結果卡片、排序、loading/empty/error、Cmd+K（after step 3）

## Lesson

智慧搜尋是這個平台的招牌功能，核心難題不是「讓 AI 理解查詢」，而是「讓 AI 幫你挑結果、卻不自己編結果」。這四步從全景架構講到具體實作：先看完整資料流（為什麼 browser 永不直接碰 LLM），再拆解 grounding 與 config-as-content 兩大機制，接著動手實作 `POST /api/search`（MCP 工具迴圈 + 五道檢查），最後把結果體驗做出來。走完之後，你能夠用「模型只選 ID、Sanity 供事實」的原則，架出一套結果不可能造假、行為又能隨時微調的搜尋系統。
