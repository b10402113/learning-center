# 第一個應用部署（POC）

## Learning goal

能用 `kubectl run` 和 `kubectl create deployment` 部署一個應用，理解 Pod 是最小單位

## Steps

1. [[learn/kubernetes/nodes/first-deployment/run-first-pod|用 kubectl run 部署第一個 Pod]] — 理解 Pod 是 Kubernetes 最小部署單位，以及裸 Pod 的侷限
2. [[learn/kubernetes/nodes/first-deployment/deployments-and-self-healing|Deployment 與自我修復]] — 理解 Deployment 如何管理 Pod 生命週期（after step 1）
3. [[learn/kubernetes/nodes/first-deployment/recreate-from-scratch|從零重建集群]] — 刪除並重建集群，建立 CLI 肌肉記憶（after step 2）

## Lesson

這是一個 POC（概念驗證）階段的起點。你會先用最命令式的方式把一個 Pod 跑起來，感受 Kubernetes 最小的部署單位長什麼樣；然後用 Deployment 包住 Pod，看到自我修復的魔力——刪掉一個 Pod，它瞬間被重建。最後你會把整個集群砍掉重練，證明 Kind 集群的建立和銷毀是低成本操作，也讓你對 CLI 工作流建立肌肉記憶。這三步走完，你對 Kubernetes 的第一印象會從「好複雜的工具」變成「其實沒那麼可怕」。
