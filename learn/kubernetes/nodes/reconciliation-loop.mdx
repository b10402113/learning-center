理解 desired state → actual state → reconcile 的核心循環，並能用日常類比解釋它

## Lesson

Kubernetes 的一切，歸根結底就是一個簡單的問題：我們**想要**什麼狀態，我們**現在**在什麼狀態，然後把兩者之間的差距關閉掉——而且永遠不停。這就是 reconciliation loop（協調循環）。不管你要管理的是容器、儲存空間、IP 位址還是負載均衡器，底層都在跑同一個循環。理解這個循環，就是理解整個 Kubernetes 的鑰匙。
