# 從零重建集群

## Learning goal

能刪除並重建整個集群與所有部署，建立 CLI 操作的肌肉記憶，理解 Kind 集群的建立與銷毀是低成本操作。

## Lesson

刪除並重建 Kind 集群只需幾秒鐘（本質是 Docker 容器），反覆練習「刪除→建立→部署」循環能建立 CLI 肌肉記憶，也讓你理解 POC 階段的命令式操作是為了快速驗證、不是為了穩定運行。
