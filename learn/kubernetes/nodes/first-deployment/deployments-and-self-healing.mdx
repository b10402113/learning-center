# Deployment 與自我修復

## Learning goal

理解 Deployment 如何管理 Pod 的生命週期，並能示範刪除 Pod 後 Deployment 自動重建的自我修復機制。

## Lesson

Deployment 是 Kubernetes 的控制器，透過 reconciliation loop 確保 Pod 數量永遠符合期望——刪除 Pod 後它會在幾毫秒內自動重建，你改變的是 Deployment 的期望狀態而非 Pod 本身。
