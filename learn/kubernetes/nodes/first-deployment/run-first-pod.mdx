# 用 kubectl run 部署第一個 Pod

## Learning goal

能用 `kubectl run` 部署一個 Pod，理解 Pod 是 Kubernetes 最小的部署單位，以及裸 Pod（bare pod）與受控 Pod 的差異。

## Lesson

Pod 是 Kubernetes 最小的部署單位，用 `kubectl run` 可以命令式地創建一個裸 Pod——適合除錯但不適合生產，因為裸 Pod 被刪除後不會自動重建；命令式操作背後永遠是宣告式 manifest，而 Namespace 只是邏輯組織單位、預設不提供安全隔離。
