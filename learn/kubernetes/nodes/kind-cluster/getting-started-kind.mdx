# 用 Kind 建立第一個集群

## Learning goal

<LearningGoal>
能用 Kind 建立一個預設的本地 Kubernetes 集群，並用 kubectl 驗證 kube-system 命名空間中的核心元件。
</LearningGoal>

## Lesson

Kind（Kubernetes in Docker）用 Docker 容器來跑完整的 K8s 集群，一行 `kind create cluster` 就能在筆電上擁有和雲端相同的操作環境。預設集群包含完整的控制平面（API server、etcd、scheduler、controller manager），所有系統 Pod 跑在 kube-system 命名空間。default 命名空間是空的——那是留給你的應用的。Kind 的集群可以隨建隨銷，讓你反覆練習而不留殘留資源。
