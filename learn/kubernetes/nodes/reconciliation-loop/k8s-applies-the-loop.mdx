# Kubernetes 如何套用 Reconciliation Loop

## Learning goal

說明 Kubernetes 將 loop 應用在容器、Volume、IP、Load Balancer 等資源上的方式，以及為什麼 loop 是整個平台唯一一致的組件。

## Lesson

Kubernetes 裡每一種資源（容器、Volume、IP、Load Balancer）都由各自的 Controller 透過 reconciliation loop 管理，loop 是整個平台唯一一致的機制，也是你除錯時的思維起點。
