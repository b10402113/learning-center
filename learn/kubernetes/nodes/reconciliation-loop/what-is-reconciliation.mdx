# 什麼是 Reconciliation Loop？

## Learning goal

用日常類比（定速巡航、烤箱恆溫）解釋 desired state → actual state → reconcile 的核心概念，能不看筆記向別人說明。

## Lesson

Reconciliation Loop 是「聲明期望 → 觀察實際 → 關閉差距」的永不停止的循環，定速巡航、烤箱恆溫和餐廳出餐都是它的日常原型。
