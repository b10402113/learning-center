# L1 overview

- `docs/workshop/STABLE.md` — Day-1 afternoon (segments 8-14): rewrites the deliberately-wrong POC stack as declarative manifests in git. Adds `kubectl apply`/`diff` as the operating verb, readiness/liveness/startup probes and requests/limits, ConfigMaps + an imperative Secret + the `app` namespace, a Gateway API front door (NGINX Gateway Fabric `Gateway` + `HTTPRoute` replacing the NodePort), the operator/CRD pattern, a durable CloudNativePG `Cluster` with a durability proof, and a Kustomize base.
- `docs/workshop/STABLE.md` — teaching spine: every segment is Goal / Talking points / Live build / Watch for / (Anticipated questions) / Transition, with representative output and deliberately fake secrets; closes with a recap naming the five remaining gaps and a LEGO "same bricks, three builds" matrix (edge / self-hosted / cloud) that previews EKS.
- `docs/workshop/PRODUCTION.md` — Day-2 capstone (segments 17-21 morning on `kind`, 23-31 afternoon on EKS): HPA autoscaling, safe rolling updates + `rollout undo`, PodDisruptionBudgets + node drain, RBAC least privilege with a dedicated ServiceAccount, Argo CD GitOps, then Sealed Secrets.
- `docs/workshop/PRODUCTION.md` — cloud half: `eksctl` cluster started in segment 23 as a background provision, EKS tour, EBS CSI + gp3 StorageClass, AWS Load Balancer Controller fulfilling the *same* `Gateway`/`HTTPRoute` as a real ALB, `kind`+`eks` Kustomize overlays over the untouched base, Argo CD and per-cluster Sealed Secrets on EKS, built-in/platform observability, and a mandatory verified teardown.
- `docs/workshop/PRODUCTION.md` — recurring thesis paying off end to end: the resource is a stable contract, the controller is environmental (local-path vs EBS CSI, NGINX Gateway Fabric vs AWS LBC, base vs overlay, one Argo CD per cluster, one sealed key per cluster).
