# L1 overview

- Console is the hub for micro apps, now community-sourced: a visual layer on top of an agent setup.
- The problem it solves: agent platforms live in a terminal or editor, which is a poor visual workspace and hard to show to clients or peers.
- It is modular: a scaffold plus a clean design, so new views are requested from the agent rather than hand-coded.
- It works with any file-based platform (Claude Code, OpenClaw, NemoClaw); the template guides the agent, but each setup may need adjustment.
