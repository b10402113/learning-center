- Lesson page for Agentic OS v2: the homepage and Second Brain merged into one page the agent builds for you.

- Deliverables: homepage widgets, 3D/2D/timeline Second Brain, Routines-Skills-Applications tabs, file search and viewer, all local.
- Migration note: the agent leaves the first Agentic OS running and asks before v2 replaces it.
