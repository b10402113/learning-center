# L1 overview

- Elements is a browsable library of reusable video elements: 3D objects, editable infographics, motion recipes, hero counters, backgrounds, icons and CC0 sound effects.
- Every element previews in 16:9 and 9:16, can be copied as an agent-ready selection, and new elements can be registered so the library grows.
- Elements ships as part of the /animate skill.
