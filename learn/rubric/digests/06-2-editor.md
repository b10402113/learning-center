# L1 overview

- Editor lets the agent do the first cut, then puts it in a local Chrome review UI.
- `/cut` transcribes word by word, keeps the last clean take of each line, removes false starts and long pauses, and loads the cut into the editor.
- Review uses Premiere-style shortcuts; every change becomes a comment, and "Copy comments for ALL clips" sends them back so the agent re-cuts and learns your style.
- Transcription options: AssemblyAI by default, local Whisper for free, ElevenLabs Scribe if already subscribed.
- Export is rendered straight from the raw footage at the size you choose.
