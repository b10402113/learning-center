# L1 overview

- Carousels shows every Instagram carousel card by card in one local page so edits are pinned to the exact spot.
- You can pin comments, approve cards, pick the cover, reorder cards, add cards or carousels to a cart, and copy all comments.
- The agent can create new carousels into the app from a simple template and apply comments; it never posts for you.
- Apply-all-comments needs Agentic OS v2; otherwise the button copies comments for manual pasting.
