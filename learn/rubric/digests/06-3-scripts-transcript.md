# L1 overview

- Walkthrough of the Scripts loop: install prompt, `/rubricscripts`, load the shortlist from /latest and /outliers, generate with /script, /hooks and /tone.
- Each script lands with its hook highlighted; comments work like Google Docs.
- Two post-review actions: rewrite the scripts from comments, and (with Teach My Tone on) refine the /tone skill from the same comments.
- Practical advice: be specific in comments, write what you would actually say, and read every script aloud before recording.
