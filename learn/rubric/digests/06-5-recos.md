# L1 overview

- Recos makes the agent audit its own setup and produce ranked improvement recommendations.
- A local page plus a `/recos` skill reads apps, routines, memory and skills, then writes recos with evidence from your setup.
- Each reco shows gain, effort, priority and token savings, sorted by ARMS; you can skip, mark done, or add to a cart for the agent.
- Apply-all-comments needs Agentic OS v2; otherwise the button copies comments for manual pasting.

- `#L1-L3` — two screenshots and the self-audit thesis.
- `#L4-L16` — capability list: run /recos, ARMS sorting, skip/done/cart, comments, weekly refresh.
- `#L17-L18` — Agentic OS dependency and download prompt.
