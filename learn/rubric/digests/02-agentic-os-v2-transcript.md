# L1 overview

- Jay frames the argument: models got stronger but most agent setups did not catch up, so the OS layer is the bottleneck.
- The dashboard is only 20-30 percent of the value; the remaining 70 percent is how the workspace is organised underneath.
- ARMS names the four parts of that organisation: Applications, Routines, Memory, Skills — taught bottom-up from Skills.
- Skills have three levels: use Anthropic or skill-creator skills, enrich skills into routers with references, then trigger them headlessly with `claude -p`.
- Memory has three levels: a pile of files, agent-optimised router files (CLAUDE.md plus department routers), then the visual Second Brain.
- Routines have three levels: local Claude desktop schedules, an always-on cloud agent kept in sync with Syncthing, then a VPS running Claude Code.
- Applications have three levels: browse the connector UI, let the agent search official and community connectors, then build your own connectors and micro apps.
- Recurring method: every level ships with a copyable prompt the learner can hand to their own agent.
