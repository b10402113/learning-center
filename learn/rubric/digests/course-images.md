# L1 overview

- The lesson screenshots show what the RUBRIC system looks like when it runs: a dark, orange-accented command centre with a hex-and-dot visual language.
- The core visual argument: agents do work in terminals, but the output needs a surface you can see, search, and comment on.
- Agentic OS v2 is the homepage: micro apps rail, calendar, email triage, YouTube stats, routines, skills deck, and a central 3D workspace orb ringed by artifacts.
- Second Brain is a concentric map — Claude.md at the centre, then skills/content/departments, then memory, routines, and applications as outer rings.
- Console is the shell that hosts tabs (Agents, Generations, Docs, Links, Sprint, Backlog, Icons, Skills, Flows, Crons, Team).
- Every micro app follows the same review pattern: pin a comment on the exact spot, copy all comments, hand them to the agent.
- The apps are local-first browser UIs; nothing here is a hosted SaaS.
