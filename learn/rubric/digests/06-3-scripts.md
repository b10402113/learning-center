# L1 overview

- Scripts moves script review out of chat into one local page.
- `/rubricscripts` writes each idea with your /hooks and /tone skills: three hooks, a caption, and a review card.
- Highlight any line to comment; comments collect in a cart; "Copy comments for ALL scripts" makes the agent fix them and sharpen /tone.
- The app supports search, sort, card/list views, light/dark mode, captions with AEO practices, and references.
