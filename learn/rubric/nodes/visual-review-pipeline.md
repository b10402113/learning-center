# Storyboards 與 Carousels：還在分鏡與卡片時就修好

## Lesson

Storyboards 讓你在影片還是一張張定格時就修改節奏，Carousels 則把 IG 輪播拆成一張張卡片來審。兩者共用同一套釘點留言與留言購物車的資料契約，差別只在最後 agent 要改的是分鏡腳本還是 carousel 的 deck。
