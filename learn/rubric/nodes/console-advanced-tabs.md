# Console 進階分頁：額外、選用的 tabs

## Lesson

進階分頁被拆出來，是因為不是每個人都需要它們，而且每一個都多一點與 agent 協調的安裝成本。這個節點依用途分成內容與知識、工作管理、跨裝置存取三組，逐一說明每個 tab 的資料模型與何時值得裝。
