# RUBRIC：一套幫你跟 AI agent 合作得更好的工具

## Lesson

RUBRIC 不是另一個 agent 框架，而是一層讓 agent 產出變得可尋找、可觀看的工作系統。這個節點先建立三個部分的分工：Agentic OS 是每天早上的首頁，Second Brain 是可視化的記憶，Console 是 micro app 的著陸點；三者可以分開採用。
