# Console：AI agent micro app 的指揮中心

## Lesson

Console 是疊在 agent 設定之上的視覺層，解決多數 agent 平台只存在於 terminal 或編輯器的問題。這個節點從「為什麼需要它」走到實際安裝、客製與排錯，並拆開一個 shell 加可插拔模板的 scaffold 結構，讓你能自己判斷該加什麼 tab。
