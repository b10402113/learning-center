能用粒度、互斥屬性、行鎖演算法三個維度講清 MySQL 的鎖分類，並說明 RR 的 Next-Key Lock 為何讓它比 RC 更容易塞車與死鎖。
</LearningGoal>

## Lesson

MySQL 的鎖可從粒度（全局／表／MDL／行）、互斥屬性（S／X／意向鎖）與行鎖演算法（Record／Gap／Next-Key）三個維度理解；RR 的 Next-Key Lock 多鎖了間隙，正是它比 RC 更容易衝突與死鎖的原因。
