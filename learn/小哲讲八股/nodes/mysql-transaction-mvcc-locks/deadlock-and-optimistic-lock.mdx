<LearningGoal>
能用轉帳場景復現 AB-BA 死鎖、說明 wait-for graph 如何檢測與回滾，並講清樂觀鎖的 version CAS 與悲觀鎖在鎖持有時間上的本質差別。
</LearningGoal>

## Lesson

AB-BA 死鎖來自兩個交易相反的加鎖順序，InnoDB 用 wait-for graph 檢測並回滾代價較小的一方；樂觀鎖則是應用層的 version CAS，把行鎖的持有時間縮到 UPDATE 的那一瞬間。
