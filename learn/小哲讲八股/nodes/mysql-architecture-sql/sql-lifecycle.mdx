# 一條 SQL 的生命週期：六道關卡走一遍

<LearningGoal>
能按順序講出一條 SQL 從客戶端發出到返回結果所經過的每一關（連接器、查詢快取、分析器、優化器、執行器、儲存引擎），並說出每一關各做什麼、哪裡最容易出問題。
</LearningGoal>

## Lesson

一條 SQL 依序經過連接器、查詢快取（8.0 已移除）、分析器、優化器、執行器，最後由儲存引擎實際讀寫資料；把「慢」的症狀對應到關卡，就能有條理地定位問題出在哪一層。
