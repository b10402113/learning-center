# 磁碟 I/O 決定論：把架構變成一套診斷語言

<LearningGoal>
能用「一切設計都在減少磁碟 I/O」這條主線串起 MySQL 的分層與引擎選型，並把一條慢 SQL 定位到架構中的某一層，講出為什麼這樣設計。
</LearningGoal>

## Lesson

MySQL 幾乎所有底層設計都在減少磁碟 I/O；把分層、SQL 生命週期與引擎選型串在這條主線上，就能把一條慢查詢定位到架構中的某一層來排查。
