# 邏輯架構：Server 層與儲存引擎層的腦手分工

<LearningGoal>
能畫出 MySQL 的兩層邏輯架構，說出 Server 層（連接器、分析器、優化器、執行器）與插件式儲存引擎層各自負責什麼，並解釋為什麼要這樣分層。
</LearningGoal>

## Lesson

MySQL 分成 Server 層與插件式儲存引擎層：Server 層負責連線、解析、優化與執行，引擎層只負責資料的實際存取，兩者透過標準介面溝通，因此引擎可以替換，而 SQL 語法與內建函數、檢視表等公共功能保持一致。
