# InnoDB 與 MyISAM：從五個維度講清本質差別

<LearningGoal>
能從事務、鎖粒度、索引結構、外鍵、COUNT(*) 五個維度講出 InnoDB 與 MyISAM 的差別，說明兩者最本質的差異在哪，以及什麼情況下才會考慮 MyISAM。
</LearningGoal>

## Lesson

InnoDB 用聚簇索引讓主鍵葉子直接存完整資料行、輔助索引存主鍵值並支援事務與行級鎖；MyISAM 索引與資料分離、只有表級鎖，唯一明顯優勢是 O(1) 的 COUNT(*)，整體已退居少數極端場景。
