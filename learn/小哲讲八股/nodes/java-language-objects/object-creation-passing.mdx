# 物件的建立、傳遞與複製

<LearningGoal>
能說清楚 Java 為什麼只有值傳遞、基本型別與包裝類各自存在的理由，以及裝箱快取與淺/深拷貝在實務上會踩到什麼坑。
</LearningGoal>

## Lesson

Java 的變數裡裝的不是物件，而是位址；方法呼叫時參數複製的是這個位址的副本，所以物件共享會互相影響，重新賦值卻不會。這就是 Java 只有值傳遞的意思。基本型別與包裝類之間靠編譯器插入的 `valueOf`、`xxxValue` 自動轉換，Integer 快取池只涵蓋 -128 到 127，超出範圍就各建一顆，於是包裝類用 `==` 比較會得到不可靠的結果。`Object.clone` 預設按位複製，引用欄位共用同一顆內部物件，這種淺拷貝在可變欄位上會互相污染；需要深拷貝時，得自行逐層複製或用序列化重建。
