# 物件從哪來、怎麼傳：new、參照、值傳遞與複製

<LearningGoal>
能講清楚一個 new 背後建立了什麼、變數裡放的是值還是參照、Java 為何只有值傳遞，以及淺拷貝與深拷貝的差別。
</LearningGoal>

## Lesson

Java 只有值傳遞：對基本型別複製的是數值、對物件複製的是位址值，所以方法能透過位址改到物件內容，卻換不掉呼叫者手上的變數；而 Object.clone() 預設是淺拷貝，參照欄位仍共用同一個物件，要讓新物件徹底獨立得靠序列化之類的深拷貝。
