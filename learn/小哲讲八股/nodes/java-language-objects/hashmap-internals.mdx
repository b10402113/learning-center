<LearningGoal>
能講清楚 HashMap 1.7 與 1.8 的結構差異、紅黑樹閾值與負載因子的由來，以及 1.7 併發擴容成環的過程。
</LearningGoal>

## Lesson

HashMap 用陣列加拉鏈法；1.7 是陣列＋鏈表，衝突嚴重會退化成 O(N)，1.8 加上紅黑樹兜底（鏈表超過 8 且陣列大於 64 才樹化，退化門檻 6 是為了緩衝）；插入從頭插改尾插，維持擴容後順序並根除 1.7 併發擴容成環的死循環；擴容翻倍並用 `hash & oldCap` 判斷元素留在原位或搬到原位加舊容量；負載因子 0.75 是衝突率與空間利用率的折中；1.8 修的是死循環，HashMap 仍非執行緒安全。
