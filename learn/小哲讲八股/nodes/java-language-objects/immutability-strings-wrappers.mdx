<LearningGoal>
能講清楚不可變物件的好處、String 常量池與 intern 的版本差異、StringBuilder 與 StringBuffer 的取捨、包裝類與自動裝箱的坑，以及深拷貝與淺拷貝的差別。
</LearningGoal>

## Lesson

不可變是 String 能共用、能執行緒安全的前提，`new String("abc")` 建立 1 或 2 個物件取決於常量池狀態，intern 從 1.6 的深拷貝進永久代演化為 1.7 起的堆中存引用；拼接用 StringBuilder、多執行緒共用才用 StringBuffer；包裝類讓基本型別能進集合、表達 null、提供工具方法，但自動裝箱有 GC 與 NPE 風險，且 Integer 的 -128~127 緩存讓 `==` 的結果取決於是否在範圍內；金額用 BigDecimal 並以字串建構，物件複製預設是淺拷貝、要獨立就用序列化做深拷貝。
