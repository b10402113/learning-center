能在 ArrayList、LinkedList 與 CopyOnWriteArrayList 之間做出有理由的選擇，並解釋擴容成本與 CPU 快取造成的實際效能差異。
</LearningGoal>

## Lesson

集合框架分成 Collection（List／Set／Queue）與獨立的 Map 兩派；List 的選擇要看使用情境：ArrayList 用連續陣列換來 O(1) 隨機訪問與高 CPU 快取命中率，中間增刪需搬移；LinkedList 的指標操作只在頭尾划算，按索引仍要先 O(N) 定位，且節點散落造成 Cache Miss 與記憶體開銷；CopyOnWriteArrayList 讀無鎖、寫複製，適合讀多寫少，代價是弱一致性與寫入的記憶體壓力；已知資料量時應指定初始容量以減少擴容。
