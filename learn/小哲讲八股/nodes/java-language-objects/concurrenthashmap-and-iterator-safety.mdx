<LearningGoal>
能在併發場景選對容器，並講清楚 ConcurrentHashMap 的鎖粒度演進、禁 null 與 size 機制，以及 fail-fast 與 fail-safe 的差別。
</LearningGoal>

## Lesson

併發容器選型是在一致性與吞吐量之間取捨：ConcurrentHashMap 從 1.7 的 Segment 分段鎖（並發度固定 16、無法擴容）演進到 1.8 的 CAS＋synchronized 鎖頭節點（並發度隨陣列長度成長），並用 transferIndex 分片與 ForwardingNode 讓多執行緒協助擴容、讀寫不停；禁 null 是為了消除 get 的二義性，size() 以 baseCount 加 CounterCell 陣列做熱點分散、回傳弱一致近似值；fail-fast 用 modCount 及早拋出例外但不保證抓全，fail-safe 靠快照或弱一致不拋例外但可能讀到舊資料。
