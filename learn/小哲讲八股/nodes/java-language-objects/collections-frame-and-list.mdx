# 集合框架地圖與 List 選型

<LearningGoal>
能畫出集合框架的兩大派系，並用底層結構、擴容成本與 CPU 快取說明 ArrayList、LinkedList、CopyOnWriteArrayList 該怎麼選。
</LearningGoal>

## Lesson

集合框架分成 Collection 與獨立於它的 Map 兩大派系，List 的選型要同時看底層結構、擴容成本與 CPU 快取——ArrayList 靠連續記憶體與均攤 O(1) 擴容勝出，CopyOnWriteArrayList 以寫時複製換取無鎖讀取但只保證弱一致，而 fail-fast 與 fail-safe 決定迭代途中修改集合會不會拋例外。
