# 執行時看穿型別：反射、動態代理與泛型擦除

<LearningGoal>
能說明反射的效能開銷從哪來、JDK 動態代理與 CGLIB 的差異，以及泛型擦除為何讓 Java 不支援泛型陣列。
</LearningGoal>

## Lesson

反射用執行期的動態解析與安全檢查換來彈性、代價是效能，可用快取、setAccessible 與 MethodHandle／位元組碼生成優化；動態代理中 JDK 靠介面、CGLIB 靠繼承，而泛型只活在編譯期，擦除之後因為陣列協變會破壞型別安全，Java 乾脆禁止泛型陣列。
