<LearningGoal>
能講清楚反射為什麼慢、動態代理如何在執行時生成，以及泛型擦除與泛型陣列限制的成因。
</LearningGoal>

## Lesson

反射讓程式在執行時才決定操作哪個類與方法，慢在動態解析、安全檢查、參數裝箱與 JIT 無法內聯，優化靠快取、`setAccessible(true)` 與 MethodHandle／位元組碼生成；代理是插入增強邏輯的手法，JDK 代理靠介面、CGLIB 靠繼承且不能代理 final；SPI 用設定檔在執行時把介面與實作配對，JDBC 與 Dubbo 都是代表；泛型只存在於編譯期、執行時被擦除成 Object 或上限型別，這是為了向後相容，而泛型陣列被禁止，是因為陣列具體化且協變、泛型擦除且不協變，兩者衝突會讓執行時型別檢查失效。
