# 反射、動態代理與泛型擦除

<LearningGoal>
能解釋框架如何靠反射與動態代理運作、JDK 代理與 CGLIB 代理的取捨，以及泛型擦除為何讓 Java 不支援泛型陣列。
</LearningGoal>

## Lesson

反射讓程式在運行時才取得類別資訊並動態呼叫，是 Spring 與 MyBatis 的地基，但方法解析、存取檢查與參數裝箱都讓它比直接呼叫慢，優化靠快取 `Method`、`setAccessible` 與字節碼生成。動態代理在運行時生成代理物件，JDK 代理要求目標有介面，CGLIB 代理靠繼承、不能代理 final 方法，Spring 依有無介面選擇，Boot 2.0 之後偏向 CGLIB。泛型只存在於編譯期，擦除後運行時資訊消失；陣列協變搭配擦除會繞過型別檢查，所以 Java 不允許泛型陣列。
