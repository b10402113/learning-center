# String 不可變、常量池與拼接選型

<LearningGoal>
能說明 String 為何不可變、常量池如何讓字面量共用，以及 new String 建立幾個物件、intern 在不同 JDK 的差異與拼接該選誰。
</LearningGoal>

## Lesson

String 底層是不可變的字元容器，任何看起來像修改的操作都回傳新字串。不可變讓常量池敢讓字面量共用同一顆物件，也讓 `hashCode` 可以被快取。字面量進池、`new String` 則一定在堆上多建一顆，因此 `new String("abc")` 會依池中是否已有該字串建立 1 或 2 個物件。`intern` 在 JDK 1.7 之後只把原物件的引用記進池裡，不再複製。大量拼接請用 StringBuilder，確定有多執行緒共用時才換 StringBuffer。
