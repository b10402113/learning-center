# 字串為什麼不可變：常量池、intern 與拼接選型

<LearningGoal>
能說明 String 為何不可變、new String 與 intern 各建立幾個物件，以及何時該用 StringBuilder、何時用 StringBuffer。
</LearningGoal>

## Lesson

String 底層是 final 陣列所以不可變，常量池讓相同內容只存一份，new String 會依池中是否已有該字面量建 1 或 2 個物件，而拼接選型是常數用 String、單執行緒用 StringBuilder、跨執行緒才用 StringBuffer。
