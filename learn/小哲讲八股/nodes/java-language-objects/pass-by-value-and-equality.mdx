<LearningGoal>
能講清楚 Java 為什麼只有值傳遞、== 與 equals 分別在比什麼，並說出 hashCode/equals 契約與 BigDecimal 比較的坑。
</LearningGoal>

## Lesson

Java 只有值傳遞，參考型別複製的是位址的副本，因此改屬性會影響外面、重新賦值不會；`==` 比數值或位址，`equals` 沒重寫時等同 `==`、重寫後比內容，當 Key 用時 `equals` 相等就必須 `hashCode` 相等，金額比較則一律用 `BigDecimal.compareTo() == 0`。
