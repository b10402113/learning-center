# HashMap 演進與併發 Map

<LearningGoal>
能講清 HashMap 從 1.7 到 1.8 的結構、插入與擴容差異，紅黑樹 8/6 閾值與 0.75 負載因子的取捨，以及 ConcurrentHashMap 兩代的鎖粒度演進。
</LearningGoal>

## Lesson

HashMap 1.7 是陣列加鏈表、頭插法、擴容時重算 hash；1.8 加入紅黑樹、改用尾插法，並用 `hash & oldCap` 決定節點留在原位或搬到原位加舊容量。鏈表長到 8 且陣列長度至少 64 才轉樹，退回到 6 是為了避免頻繁切換；8 這個數字來自泊松分布下桶內節點數的極低機率。容量乘 0.75 是擴容門檻，也是時間與空間的折衷。1.7 的頭插法在併發擴容時可能讓鏈表成環，`get` 無限迴圈打滿 CPU，1.8 用尾插法解決。ConcurrentHashMap 1.7 用分段鎖、1.8 改成 CAS 加鎖桶頭，並靠 ForwardingNode 讓多執行緒協助擴容。
