# HashMap 兩代結構與併發 Map

<LearningGoal>
能講清 HashMap 1.7 與 1.8 的結構差異、樹化與擴容閾值、1.7 死循環的成因，以及 ConcurrentHashMap 的鎖粒度演進與 size 統計。
</LearningGoal>

## Lesson

HashMap 從 1.7 的陣列加鏈表演進到 1.8 的陣列加鏈表加紅黑樹，樹化閾值 8、退化閾值 6 與負載因子 0.75 都是時間與空間的權衡，1.7 的死循環源於頭插法在併發擴容時把鏈表倒置成環，而 ConcurrentHashMap 則從 1.7 的分段鎖走到 1.8 的 CAS 加 synchronized 鎖頭節點，並用 LongAdder 式分段計數讓 size() 不必加鎖。
