# 集合框架地圖與 List 選型

<LearningGoal>
能畫出 Collection/Map 兩大派系的地圖，並用結構、擴容與 CPU 快取解釋 ArrayList、LinkedList、CopyOnWriteArrayList 的選型與 fail-fast/fail-safe 差異。
</LearningGoal>

## Lesson

集合框架有兩條主線：Collection（List、Set、Queue）與獨立的 Map，Map 不繼承 Collection。ArrayList 底層是連續陣列，隨機存取 O(1)，擴容採 1.5 倍並複製整個陣列，把多次擴容的成本攤成均攤 O(1)；LinkedList 靠前後指標走訪，插刪理論上快，但找位置仍要 O(N)，節點分散也容易快取未命中。CopyOnWriteArrayList 讀無鎖、寫時複製整個陣列，適合讀多寫少。迭代時 ArrayList 屬於 fail-fast，會檢查 `modCount` 並拋出例外；CopyOnWriteArrayList 與 ConcurrentHashMap 屬於 fail-safe，回傳弱一致快照。
