# 執行緒有幾種狀態？六個狀態與容易搞混的三組

<LearningGoal>
能說出 Java 六個執行緒狀態與各自觸發條件，並分辨 RUNNABLE 為何合併了 OS 的就緒與運行，以及 BLOCKED、WAITING、TIMED_WAITING 三者的差別。
</LearningGoal>

## Lesson

Java 執行緒有六個狀態：NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING、TERMINATED。其中 RUNNABLE 把作業系統的就緒與運行合併成一個；三種「沒在跑」的差別在於——BLOCKED 是被動等 synchronized 鎖，WAITING 是主動且無期限地等一個顯式喚醒，TIMED_WAITING 則是等、但有超時會自動醒來。
