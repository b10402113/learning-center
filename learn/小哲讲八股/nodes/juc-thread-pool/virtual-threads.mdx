# 虛擬執行緒：為什麼百萬併發不再需要複雜的執行緒池

<LearningGoal>
能講清楚虛擬執行緒的 M:N 調度與阻塞卸載機制，並說明它為何讓「一請求一執行緒」的同步阻塞寫法重新具有高併發能力。
</LearningGoal>

## Lesson

傳統執行緒與作業系統執行緒 1:1 綁定、約 2MB 棧、切換昂貴，虛擬執行緒改用 M:N 由 JVM 在使用者態調度，成本降到幾百位元組、單機可上百萬條。它靠阻塞卸載讓載體執行緒持續幹活，使「一請求一執行緒」的同步阻塞寫法重新具備高併發能力；但 CPU 密集任務不會因此變快，限流仍需其他工具。
