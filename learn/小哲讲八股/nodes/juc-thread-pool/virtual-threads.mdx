# 虛擬執行緒：把執行緒變便宜之後

<LearningGoal>
講出虛擬執行緒與平台執行緒在映射模型、阻塞處理上的差別，以及它為什麼讓「一個請求一個執行緒」重新可行。
</LearningGoal>

## Lesson

虛擬執行緒把平台執行緒的 1:1 內核綁定改成 JVM 的 M:N 調度，建立成本從約 2MB 降到幾百位元組，阻塞時自動卸載、讓載體執行緒去做別的任務，使「一個請求一個執行緒」的同步阻塞寫法重新可行。
