# 七個核心參數：把執行緒池想成一間銀行

<LearningGoal>
用銀行網點的比喻記住 ThreadPoolExecutor 的七個核心參數，並能把他們分成人員數量、等待區、兜底輔助三類。
</LearningGoal>

## Lesson

ThreadPoolExecutor 的七個核心參數可用銀行網點記憶：`corePoolSize` 是正式員工、`maximumPoolSize` 是所有窗口上限、`keepAliveTime` 與 `unit` 是臨時工待命時間、`workQueue` 是候客區、`threadFactory` 是人力資源部、`handler` 是滿載時的保全；回答時分成人員數量、等待區、兜底輔助三類。
