# 拒絕策略怎麼選？Executors 為什麼被禁用

<LearningGoal>
能依「任務能不能丟、要不要對上游回壓」在四種拒絕策略間做選擇，並說明 Executors 五類快捷池各自的 OOM 陷阱，以及為何要手動建立 ThreadPoolExecutor。
</LearningGoal>

## Lesson

四種拒絕策略的取捨在於任務能不能丟、上游能不能被減速：能丟用 DiscardPolicy，不能丟且可回壓用 CallerRunsPolicy，不能丟又不想拖慢上游就用 AbortPolicy 快速失敗再補償；Executors 的快捷池則因無界佇列或無限執行緒數而有 OOM 風險，因此應手動 new ThreadPoolExecutor 把資源上界與拒絕策略寫清楚。
