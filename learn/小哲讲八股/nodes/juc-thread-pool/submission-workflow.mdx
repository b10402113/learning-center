# 任務提交後的生死四關

<LearningGoal>
按「核心執行緒 → 任務佇列 → 最大執行緒 → 拒絕策略」四關，講出一個任務提交後的完整流程，並解釋為什麼先排隊、後擴容。
</LearningGoal>

## Lesson

任務提交後依序走四關：核心執行緒未滿就直接建立；否則先把任務放進 `workQueue` 排隊；佇列滿了才建立非核心執行緒處理新任務；連最大執行緒都滿了才執行拒絕策略；最關鍵的反直覺點是「先排隊、後擴容」。
