# 執行緒的六種狀態與生命週期

<LearningGoal>
能講出 Java 執行緒六種狀態的語義、觸發方法與流轉，並說清楚 BLOCKED 與 WAITING 差在哪裡。
</LearningGoal>

## Lesson

Java 執行緒有 NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING、TERMINATED 六種狀態，其中 RUNNABLE 合併了就緒與運行，而 BLOCKED（被動等 `synchronized` 鎖）與 WAITING（主動等喚醒）是最容易混淆的兩種等待。
