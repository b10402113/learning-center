# 任務提交後發生什麼？四步執行流程

<LearningGoal>
能逐步追蹤一個任務提交後的走向——核心執行緒、任務佇列、最大執行緒、拒絕策略，並解釋為何核心滿了先排隊而不是立刻擴容。
</LearningGoal>

## Lesson

任務提交後固定走四道關卡：核心執行緒未滿就直接建立核心執行緒，核心滿了先放進 workQueue 排隊，佇列也滿了才建立非核心執行緒接住剛提交的新任務，三者都滿才執行拒絕策略。核心與非核心分開設計是為了彈性伸縮；若佇列無界，第三關永遠到不了，最大執行緒數就形同虛設。
