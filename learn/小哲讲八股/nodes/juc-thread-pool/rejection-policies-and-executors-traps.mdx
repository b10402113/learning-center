# 拒絕策略與 Executors 的坑

<LearningGoal>
比較四種拒絕策略的適用場景，講出 Executors 五種快捷執行緒池各自的坑，以及阿里手冊禁用它們的 OOM 理由。
</LearningGoal>

## Lesson

拒絕策略有 AbortPolicy（預設拋異常）、CallerRunsPolicy（提交者自己執行兼削峰）、DiscardPolicy（靜默丟棄）、DiscardOldestPolicy（丟隊頭）四種；Executors 的 Fixed 與 Single 用無界佇列、Cached 的執行緒數上限是 `Integer.MAX_VALUE`，都有 OOM 風險，因此阿里手冊要求手動 new ThreadPoolExecutor。
