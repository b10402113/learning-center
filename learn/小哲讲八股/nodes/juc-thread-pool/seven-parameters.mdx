# 執行緒池的七個參數：用銀行網點一次記住

<LearningGoal>
能用銀行網點的比喻解釋 ThreadPoolExecutor 七個參數各自的含義，並把它們分成人員數量、等待區、兜底輔助三類。
</LearningGoal>

## Lesson

ThreadPoolExecutor 的七個參數可分成三類：人員數量類的 corePoolSize（常駐核心）、maximumPoolSize（執行緒總數上限）、keepAliveTime 與 unit（非核心保活時間），等待區類的 workQueue，以及兜底輔助類的 threadFactory 與 handler；用銀行網點的正式員工、所有窗口、臨時工保活、候客區、人力資源部與保安就能一次記住。
