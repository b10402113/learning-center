# synchronized 怎麼實現？Monitor、物件頭與鎖升級

<LearningGoal>
能從字節碼的 monitorenter／monitorexit 講到物件頭關聯的 Monitor、可重入計數，並說出無鎖、偏向、輕量級、重量級四種鎖狀態為什麼要依照競爭程度逐步升級。
</LearningGoal>

## Lesson

synchronized 鎖的是物件：物件頭的 Mark Word 關聯到 Monitor，`Owner` 記著持有者、計數器實現可重入，`monitorenter` 對計數加一、`monitorexit` 減一，減到零才釋放。JDK 1.6 引入鎖升級，讓鎖依競爭程度從無鎖、偏向鎖、輕量級鎖一路升到重量級鎖，目的是把「使用者態到核心態」的昂貴切換留到真正必要的時候。
