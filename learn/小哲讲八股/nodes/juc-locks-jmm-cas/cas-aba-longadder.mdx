# CAS、ABA 與 LongAdder：無鎖原子怎麼做到，又會在哪裡翻車

<LearningGoal>
能講清楚 CAS 的三個操作數 V／A／B 與底層的 CPU 原子指令、失敗自旋的代價、ABA 問題與版本號解法，並說明 AtomicInteger 在高競爭下為什麼變慢、LongAdder 如何用分段累加把熱點打散。
</LearningGoal>

## Lesson

CAS 是樂觀鎖，用 V／A／B 判斷記憶體現值是否等於預期舊值，相等才換成新值，失敗就自旋重試，底層靠 Unsafe 與 CPU 的 `cmpxchg`。它只看結果不看過程，因此有 ABA 問題，標準解法是加版本號。AtomicInteger 在高競爭下因所有執行緒搶同一個 value、大量自旋重試而變慢；LongAdder 改用 base 加 Cell 陣列分段累加把熱點打散，代價是 `sum()` 只能得到最終一致的值。
