<LearningGoal>
能講清 CAS 的 V/A/B 邏輯與硬體基礎，說明 ABA 問題與版本號解法，並解釋 AtomicInteger 在高競爭下變慢的原因與 LongAdder 的分治優化。
</LearningGoal>

## Lesson

CAS 用 V/A/B 與 CPU 原子指令實現無鎖更新，但只看結果不看過程會遭遇 ABA，需靠版本號解決；AtomicInteger 在高競爭下因單點自旋而變慢，LongAdder 用 base 加 Cell 陣列分治把熱點拆開。
