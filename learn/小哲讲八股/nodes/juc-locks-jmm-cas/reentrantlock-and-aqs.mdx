# ReentrantLock 與 AQS：一個 state 加一條等待佇列

<LearningGoal>
能講出 AQS 用 volatile state、CLH 變體佇列與 CAS 三件套怎麼運作，並說明 ReentrantLock 如何靠它長出可重入、公平鎖、可中斷與多個 Condition，最後分辨兩把鎖各自適合的場合。
</LearningGoal>

## Lesson

AQS 的核心是三件套：`volatile int state` 代表共享資源狀態、CAS 負責原子搶奪、CLH 變體佇列讓搶失敗的執行緒排隊等待，state 的語義由各工具自己定義。ReentrantLock 就長在這套骨架上，因此能可重入，還比 synchronized 多了公平鎖、可中斷等待與多個 Condition；代價是必須手動解鎖，忘記寫 `unlock` 就會讓鎖永遠不釋放。
