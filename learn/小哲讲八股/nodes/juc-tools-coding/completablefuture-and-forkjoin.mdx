<LearningGoal>
能講清楚 CompletableFuture 的 CAS 狀態機與 Treiber Stack 回調鏈如何運作、沒指定池時為何落在 commonPool，以及 ForkJoinPool 的每執行緒雙端佇列與工作竊取和 ThreadPoolExecutor 的本質差別。
</LearningGoal>

## Lesson

CompletableFuture 以 <code>volatile result</code> 兼存結果與狀態、靠 CAS 決定誰完成，回調封裝成 Completion 節點壓入 Treiber Stack，由 <code>postComplete()</code> 迴圈觸發；未指定池時預設 commonPool。ForkJoinPool 以每執行緒雙端隊列加工作竊取取代 ThreadPoolExecutor 的單一公共隊列爭搶。
