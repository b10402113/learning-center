<LearningGoal>
能講清楚 ThreadLocal 為什麼是空間換時間、資料為什麼存在 Thread 物件裡、弱 key／強 value 為何會泄漏，以及 InheritableThreadLocal 在執行緒池為何串號、TTL 怎麼用 Capture/Replay/Restore 解決。
</LearningGoal>

## Lesson

ThreadLocal 用空間換時間讓每條執行緒各持一份私有副本，資料存在 Thread 的 <code>threadLocals</code> 中並以弱引用的 ThreadLocal 當 key；執行緒池複用會殘留強引用的 value，務必 <code>remove()</code>；父子執行緒透傳用 InheritableThreadLocal 會因複用而上下文污染，正解是 TTL 的 Capture／Replay／Restore。
