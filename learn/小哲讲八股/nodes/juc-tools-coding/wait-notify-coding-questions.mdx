<LearningGoal>
能用 synchronized 配 wait/notifyAll 寫出生產者消費者與 N 執行緒順序打印，並用 ReentrantLock 配多個 Condition 寫出三執行緒交替打印 ABC，同時說出 while 防虛假喚醒、notifyAll 保活性與精確喚醒的理由。
</LearningGoal>

## Lesson

三題共用同一骨架：用鎖圈臨界區、以 <code>while</code> 檢查條件、不滿足就 wait／await 並讓鎖，滿足就幹活改狀態再喚醒。生產者消費者用 synchronized + wait/notifyAll，N 執行緒順序打印用取模決定誰動且必須 notifyAll，三執行緒交替打印用 ReentrantLock + 多個 Condition 精確喚醒並以 <code>state % 3</code> 交棒。
