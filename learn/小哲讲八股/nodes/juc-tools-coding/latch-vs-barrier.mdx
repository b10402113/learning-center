<LearningGoal>
能分辨 CountDownLatch 一次性「一個等多」與 CyclicBarrier 可循環「互相等」的語義差異，並從 AQS 共享模式與 ReentrantLock + Condition 說出兩者底層實作的不同。
</LearningGoal>

## Lesson

CountDownLatch 是「一個等多」的一次性工具，底層用 AQS 共享模式、<code>state</code> 即計數；CyclicBarrier 是「互相等」的可循環工具，底層用 ReentrantLock + Condition，到齊後自動重置；選型就看「誰等誰、要不要重複」。
