# 什麼時候該打破雙親委派

<LearningGoal>
能判斷兩種必須打破委派的場景（SPI 父層呼叫子層、Web 容器多版本隔離），並說出各自打破的方式。
</LearningGoal>

## Lesson

雙親委派的可見性單向，因此在兩種場景須刻意打破：SPI（如 JDBC）用執行緒上下文類別載入器讓父層反向載入子層實作，Web 容器（如 Tomcat）用自訂 WebAppClassLoader 優先本地載入以隔離多版本；打破會犧牲類別全域唯一並帶來轉型與回收複雜度，非必要不打破。
