# 位元組碼怎麼跑：半編譯半解釋與 JIT

<LearningGoal>
能說出 Java 從 .java 到執行的完整鏈路，解釋為什麼需要解釋器搭配 JIT，並講清楚逃逸分析如何讓物件有機會不進堆。
</LearningGoal>

## Lesson

Java 先用 `javac` 把原始碼編成平台無關的位元組碼，執行時由解釋器逐條執行、JIT 依熱點探針把常用程式碼編譯成機器碼放進 Code Cache，並靠逃逸分析讓未逃逸的物件有機會留在棧上、不必進堆。
