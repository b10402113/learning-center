# 類別載入七階段：從 .class 到 Class 物件

<LearningGoal>
能按順序講出載入、驗證、準備、解析、初始化，並解釋為什麼 `static int a = 666` 在準備階段是 0。
</LearningGoal>

## Lesson

類別載入把 `.class` 讀進記憶體並在堆中建立 `java.lang.Class` 物件，流程為載入、驗證、準備、解析、初始化，加上使用與卸載；準備階段只給靜態變數分配記憶體與零值（`static int a = 666` 此時為 0，`static final` 常量則已成 666），初始化階段執行 `<clinit>()` 才真正賦值與執行靜態區塊。
