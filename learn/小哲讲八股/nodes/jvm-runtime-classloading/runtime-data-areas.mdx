# 五個執行時資料區與堆棧之別

<LearningGoal>
能畫出 JVM 五個執行時資料區、分清哪些線程共享哪些私有，並用四個維度講出堆與棧的差別，以及方法區從永久代走向元空間的原因。
</LearningGoal>

## Lesson

JVM 執行時資料區分五塊：堆與方法區執行緒共享，虛擬機棧、本地方法棧、程式計數器執行緒私有；堆是儲存單位、記憶體不連續且依賴 GC，棧是執行單位、連續且隨方法結束自動釋放，而方法區已從固定上限的永久代改為放在本地記憶體的元空間。
