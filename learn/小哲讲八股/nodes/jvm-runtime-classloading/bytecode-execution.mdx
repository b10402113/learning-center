# 位元組碼怎麼跑起來：半編譯、半解釋與 JIT

<LearningGoal>
能講出 `.java → .class → 執行` 的兩階段、JIT 為何存在與熱點探測，並用逃逸分析解釋「為什麼推薦用區域變數」。
</LearningGoal>

## Lesson

Java 是「半編譯、半解釋」：`javac` 先把原始碼編成平台無關的位元組碼，執行時由解釋器逐行翻譯，再由 JIT 把熱點程式碼即時編成機器碼放進 Code Cache，並透過逃逸分析把未逃逸的物件拆到棧上，省下堆分配與 GC 成本。
