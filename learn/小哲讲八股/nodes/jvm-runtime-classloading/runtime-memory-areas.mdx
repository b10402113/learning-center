# 執行時資料區：五塊記憶體各裝什麼

<LearningGoal>
能畫出五個執行時資料區、說出誰共享誰私有，並從四個維度對比堆與棧，以及方法區從永久代到元空間的演進。
</LearningGoal>

## Lesson

JVM 執行時資料區有五塊：執行緒共享的堆（物件與陣列、GC 主戰場）與方法區（類別資訊、常量、靜態變數，JDK 8 起由固定上限的永久代改為本地記憶體的元空間），以及執行緒私有的虛擬機棧、本地方法棧與程式計數器；堆與棧的分工是「儲存」與「執行」，前者靠 GC、後者隨方法自動釋放。
