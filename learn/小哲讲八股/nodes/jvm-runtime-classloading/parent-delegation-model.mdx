# 雙親委派：向上委託、向下載入

<LearningGoal>
能講出三個核心類別載入器、委派流程，以及安全與避免重複載入兩個目的。
</LearningGoal>

## Lesson

雙親委派是「向上委託、向下載入」：請求先交給父載入器一路傳到 Bootstrap，父層找不到時子載入器才自己載入；三個核心載入器由下而上是 Application、Extension、Bootstrap，換來沙箱安全（防核心 API 被覆蓋）與避免重複載入（類相同取決於類全名加上載入器）兩個目的。
