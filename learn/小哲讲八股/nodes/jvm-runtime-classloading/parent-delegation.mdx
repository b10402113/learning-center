# 雙親委派與它被打破的時候

<LearningGoal>
能描述「向上委託、向下加載」的委派流程與三個核心類加載器，說出沙箱安全與避免重複加載兩個目的，並解釋 SPI 與 Tomcat 為什麼要打破雙親委派。
</LearningGoal>

## Lesson

雙親委派以「向上委託、向下加載」決定類別由哪個類加載器載入，換來沙箱安全與避免重複加載，判定兩個類相同看的是「類全名 + 類加載器」；當基礎類要呼叫使用者實作（SPI 靠執行緒上下文類加載器）或需要多版本類別隔離（Tomcat 的 WebAppClassLoader 優先載入本地）時，就得刻意打破它。
