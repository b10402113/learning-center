# 類別載入七階段：從 .class 到 Class 物件

<LearningGoal>
能按順序講出類載入的七個階段，並清楚解釋準備階段為 static 變數設零值、初始化階段才真正賦值，以及 static final 常量為何是例外。
</LearningGoal>

## Lesson

類別載入就是把 `.class` 讀進記憶體並生成 `Class` 物件，流程為加載、連接（驗證／準備／解析）、初始化七階段：加載負責 IO 與生成 Class，驗證確保位元組碼安全，準備只給靜態變數零值與開好空間，解析把符號引用換成直接引用，初始化執行 `<clinit>()` 才真正跑靜態程式碼塊與賦值，`static final` 的編譯期常量則是準備階段就設定好的例外。
