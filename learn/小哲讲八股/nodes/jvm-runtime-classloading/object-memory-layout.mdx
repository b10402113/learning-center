# 一個物件在記憶體裡長什麼樣

<LearningGoal>
能拆解 HotSpot 物件的三個區塊（對象頭、實例數據、對齊填充），說出 Mark Word 為什麼會隨鎖狀態變化，並解釋 8 字節對齊與字段重排序的用途。
</LearningGoal>

## Lesson

HotSpot 物件由對象頭、實例數據、對齊填充三塊組成：對象頭的 Mark Word 存雜湊碼、GC 分代年齡與鎖狀態且會隨鎖升級改變結構，Klass Pointer 指向方法區的類元資料，陣列另有長度欄位，實例數據會做欄位重排序省空間，最後補齊到 8 位元組整數倍以利 CPU 讀取。
