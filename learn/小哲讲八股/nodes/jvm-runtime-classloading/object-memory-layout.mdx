# 物件在記憶體裡長什麼樣：物件頭、實例資料與對齊填充

<LearningGoal>
能說出 HotSpot 物件的三塊佈局、Mark Word 隨鎖狀態變化、欄位重排序與 8 位元組對齊。
</LearningGoal>

## Lesson

HotSpot 物件由物件頭、實例資料與對齊填充三塊組成：物件頭的 Mark Word 存雜湊碼、GC 分代年齡與鎖狀態（且隨鎖升級改寫結構），Klass Pointer 指向方法區的類別元資料；實例資料做欄位重排序；對齊填充把大小補到 8 的倍數以配合 CPU 對齊讀取。
