# 垃圾怎麼收？三種演算法、分代收集與 STW

<LearningGoal>
能說出標記-清除、標記-複製、標記-整理三種演算法各自的取捨，解釋分代收集為什麼在新生代用複製、老年代用清除或整理，並講清楚 STW 為什麼躲不掉。
</LearningGoal>

## Lesson

標記-清除、標記-複製、標記-整理三種演算法的本質是空間與時間的取捨——清除會留碎片、複製會浪費一半空間、整理要移動物件；分代收集讓存活率低的新生代用複製、存活率高的老年代用清除或整理。而任何收集器在標記引用時都得 STW 凍結記憶體狀態，所以調優的目標從來不是消滅停頓，而是縮短它。
