# 線上 GC 頻繁怎麼查？從告警到根因的四步法

<LearningGoal>
面對頻繁 GC 的線上告警，能列出程式與配置兩層的常見成因，並照「觀測、隔離、分析、解決」四步法用 jstat、jmap、MAT 定位根因。
</LearningGoal>

## Lesson

頻繁 GC 的成因分程式與配置兩層：程式面是大對象直接進老年代、static Map 或 ThreadLocal 造成的洩漏、不必要的物件建立；配置面是堆太小、新生代太小導致對象過早晉升、元空間不足。排查照「觀測區分 Young 還是 Full GC、jstat 看記憶體分佈、摘流量後 jmap dump、MAT 用支配樹與 Path to GC Roots 定位」四步走。
