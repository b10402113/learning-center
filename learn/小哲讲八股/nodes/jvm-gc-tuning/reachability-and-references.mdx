# 物件是垃圾嗎？可達性分析與四種引用

<LearningGoal>
能講清楚 JVM 為什麼用可達性分析而不是引用計數來判斷物件死活，說出四類 GC Roots，並用四種引用強度解釋「這個物件什麼時候才會被回收」。
</LearningGoal>

## Lesson

JVM 判斷物件死活靠的是可達性分析而不是引用計數，因為計數器永遠解不掉循環引用；可達性分析從四類 GC Roots 出發，沿引用鏈走得到就是活得、走不到才可回收。至於「什麼時候才被回收」，則由強、軟、弱、虛四種引用強度決定。
