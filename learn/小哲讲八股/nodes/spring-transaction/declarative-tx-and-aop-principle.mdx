<LearningGoal>
能講清楚 Spring 為什麼要統一管理事務、編程式與宣告式兩種寫法的差別，以及 @Transactional 背後 AOP 代理「開啟、提交、回滾」的完整流程，並說出使用時要關注的三個設定維度。
</LearningGoal>

## Lesson

宣告式事務把開啟、提交、回滾的樣板邏輯交給 AOP 代理處理，使用 @Transactional 時要掌握傳播行為、隔離級別、回滾規則三個維度。
