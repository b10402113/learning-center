<LearningGoal>
能說出 Spring 預設只對 RuntimeException 與 Error 回滾的規則、RuntimeException 與 Checked Exception 的差別，並解釋為什麼 rollbackFor 是實務上幾乎必加的設定。
</LearningGoal>

## Lesson

Spring 預設只對 RuntimeException 與 Error 回滾，受檢異常必須靠 rollbackFor = Exception.class 才會被納入，而且異常一定要真的丟到代理面前。
