# 用 EXPLAIN 讀懂優化器的執行計畫

<LearningGoal>
能看懂 EXPLAIN 的 type、possible_keys/key、key_len、rows、Extra 五個核心指標，判斷一條 SQL 是不是全表掃描、聯合索引命中幾列，以及有沒有覆蓋索引或檔案排序。
</LearningGoal>

## Lesson

EXPLAIN 展示優化器打算如何執行查詢，重點看五個欄位：type（ALL 即全表掃描）、key（possible_keys 有值而 key 為 NULL 是警訊）、key_len（判斷聯合索引命中幾列）、rows（採樣估算、不會觸發全表掃描）與 Extra（Using index 是覆蓋索引的綠燈，filesort 與 temporary 是紅燈）。
