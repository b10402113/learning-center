# 聯合索引與最左前綴：多級排序在哪裡斷掉

<LearningGoal>
能用「多級排序」解釋最左前綴匹配原則，判斷 (a,b,c) 聯合索引在 WHERE b=1、WHERE a=1 AND c=1、WHERE a=1 AND b>2 AND c=3 下各命中幾列。
</LearningGoal>

## Lesson

聯合索引在 B+ 樹裡是多級排序（a 定 b、b 定 c），由此推出最左前綴匹配原則：查詢必須從最左欄位開始、中間不能斷層、遇到範圍條件後續欄位停止匹配，判斷的關鍵永遠是「在這個已確定的範圍內，下一個欄位到底有沒有序」。
