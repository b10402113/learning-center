# 深分頁與慢 SQL：走索引為什麼還是很慢

<LearningGoal>
能解釋 LIMIT offset 為何越翻越慢並給出延遲關聯、游標法、業務限制三種優化，說出「走了索引仍慢」的四類成因，並用慢 SQL 三步法排查。
</LearningGoal>

## Lesson

深分頁因為 LIMIT offset 會先取出 offset+size 筆再丟掉前段而越翻越慢，可用延遲關聯、游標法或業務限制優化；走了索引仍慢的成因有四類：回表太多、深分頁、鎖等待與刷髒頁，排查依序是慢查詢日誌、EXPLAIN、SHOW PROFILE。
