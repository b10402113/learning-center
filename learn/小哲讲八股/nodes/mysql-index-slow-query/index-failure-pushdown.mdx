# 索引失效的三大忌與兩個坑，加上索引下推

<LearningGoal>
能列出讓索引失效的三大忌（列加工、前置 %、隱式型別轉換）與兩個坑（違反最左前綴、OR），並解釋索引下推如何把過濾下沉到引擎層以減少回表。
</LearningGoal>

## Lesson

索引失效的核心是一個「變」字：對索引列加運算或函數、LIKE 前置 %、隱式型別轉換、違反最左前綴、OR 一側無索引，都會讓 B+ 樹失去二分能力而改走全表掃描；索引下推則在不改變排序規則的前提下，把過濾下沉到引擎層，讓不合格的資料不必回表。
