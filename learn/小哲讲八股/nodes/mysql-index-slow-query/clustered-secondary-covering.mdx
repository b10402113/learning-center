# 索引即資料：聚簇索引、輔助索引、回表與覆蓋索引

<LearningGoal>
能講清楚 InnoDB 的聚簇索引與輔助索引各存什麼、回表為什麼多一趟隨機 I/O，以及覆蓋索引如何用「查詢所需欄位都在索引裡」避免回表。
</LearningGoal>

## Lesson

InnoDB 的資料檔本身就是主鍵 B+ 樹，葉子存完整行（聚簇索引）；輔助索引葉子只存主鍵值，所以查完整資料時要先拿主鍵、再回主鍵樹查一次，這第二趟就是回表，而當查詢所需欄位全都在某個索引裡，就形成覆蓋索引、可以省掉這一趟。
