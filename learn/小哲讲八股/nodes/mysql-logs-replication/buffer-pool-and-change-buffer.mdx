<LearningGoal>
能講清楚 Buffer Pool 如何用記憶體加速讀寫、為什麼它的 LRU 要分成新舊兩區，以及 Change Buffer 為什麼只對普通二級索引有效、對唯一索引無效。
</LearningGoal>

## Lesson

Buffer Pool 用記憶體快取資料頁，讀命中就直接回、寫只改記憶體並標成髒頁再異步刷盤，並靠新生代/老年代的改良 LRU 抵擋全表掃描；Change Buffer 則快取「索引頁不在記憶體時」的二級索引變更以省下隨機讀，但只對普通二級索引有效，因為唯一索引插入時本來就必須讀頁做去重檢查。
