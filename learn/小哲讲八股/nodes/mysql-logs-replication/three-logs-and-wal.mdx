<LearningGoal>
能講清楚 Redo Log、Undo Log、Binlog 三種日誌各自負責什麼、記錄什麼內容、怎麼寫入，並說出 WAL「先寫日誌再寫磁碟」為什麼能同時換來效能與持久性。
</LearningGoal>

## Lesson

Redo Log 是引擎層的物理日誌、循環寫，負責持久性與崩潰重做；Undo Log 是引擎層的邏輯日誌、追加寫，負責原子性回滾並兼職供 MVCC 讀取舊版本；Binlog 是 Server 層的邏輯日誌、追加寫，負責主從複製與歸檔恢復；而 WAL「先寫日誌再寫磁碟」用順序寫換掉隨機寫，是三種日誌共同的地基。
