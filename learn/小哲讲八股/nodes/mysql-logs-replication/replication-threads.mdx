<LearningGoal>
能用「主庫寫日誌、從庫抄日誌、重放日誌」講清楚主從複製的三個線程（Binlog Dump、I/O Thread、SQL Thread）與中繼日誌的角色，並比較異步、半同步、全同步三種複製模式的一致性代價。
</LearningGoal>

## Lesson

主從複製靠三個線程接力：主庫的 Binlog Dump Thread 發送、從庫的 I/O Thread 接收並寫入中繼日誌以解耦、從庫的 SQL Thread 從中繼日誌重放；主庫等待從庫的程度則分成異步、半同步與全同步三種模式，分別對應效能與一致性之間的取捨。
