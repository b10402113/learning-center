# Canal 與 Binlog：把快取同步從業務程式碼裡拆出來

<LearningGoal>
講清楚 Canal 如何偽裝成 MySQL Slave 訂閱 Binlog、解析成結構化事件並投遞下游，以及它為什麼比業務雙寫更解耦可靠。
</LearningGoal>

## Lesson

Canal 偽裝成 MySQL 從庫、發送 COM_BINLOG_DUMP 訂閱 Binlog，把二進位流解析成含庫名、表名、操作類型與 Before／After Image 的結構化 Entry，再投遞到 Kafka／RocketMQ 或目標儲存，讓快取同步從業務程式碼解耦、只要資料庫寫成功就不會漏通知。
