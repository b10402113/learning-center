# 快取失效三兄弟：穿透、擊穿與雪崩

<LearningGoal>
能用「資料存不存在、是不是熱點、失效範圍多大」三個維度分辨穿透、擊穿與雪崩，並各說出一組對應的防禦方案。
</LearningGoal>

## Lesson

穿透（查根本不存在的資料）、擊穿（單一熱點 Key 在高併發下過期）、雪崩（大量 Key 同時失效或快取層宕機）是快取失守的三種形態，辨識維度是「資料存不存在、是不是熱點、失效範圍多大」，分別以布隆過濾器或快取空物件、互斥鎖或邏輯過期、隨機 TTL 加高可用與限流降級來應對。
