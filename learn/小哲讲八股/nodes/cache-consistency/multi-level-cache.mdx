# 多級快取：L1 本地加 L2 Redis 的分工與代價

<LearningGoal>
講清楚 L1 本地快取與 L2 Redis 各自的定位、逐級讀取與回填流程，以及它為什麼值得用一致性麻煩換熱點保護。
</LearningGoal>

## Lesson

多級快取由 L1 本地（Caffeine，微秒級、容量小、有狀態）與 L2 分散式（Redis，毫秒級、容量大、共享）組成，讀取時逐級往下、命中就往回填；它的價值是抗熱點、把 Redis 單節點的頻寬壓力轉移到應用層記憶體，代價是資料變更時要靠 MQ 廣播通知所有節點清本地快取，並以短 TTL 兜底。
