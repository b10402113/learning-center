# 布隆過濾器：用位陣列換一個「一定不存在」

<LearningGoal>
講清楚位陣列加多個雜湊函式的寫入與查詢流程，解釋為什麼它只會誤判「存在」、為什麼不能刪除，以及工程上如何處理誤判率升高。
</LearningGoal>

## Lesson

布隆過濾器用位陣列與 k 個雜湊函式儲存資料的指紋，查詢時任一位置為 0 就確定不存在、全為 1 僅代表可能存在，因此只會單向誤判且標準版不支援刪除，最適合防快取穿透；資料被刪導致誤判率升高時，用定時重建或改用空間大三到四倍的計數布隆處理。
