# MEMORY — claude-ecosystem-bootcamp

## Goal
從零開始，學會使用整個 Claude 生態系並把重複工作自動化：能在 Claude 的四大介面（Chat、Cowork、Code、Design）之間選對工具，會用 Projects / Artifacts / Skills / Connectors / Plugins，會接 MCP 與第三方工具（Canva、Airtable、Tally、Firecrawl、Slack 等），並能用 routines / 排程 / dispatch 把日常任務自動跑起來。終點是「能自己搭出一條可運作的 AI 工作流」，而不是只會聊天。

## Why
想讓 AI 真正接手日常工作——不是把 Claude 當成一個聊天機器人，而是當成能代辦檔案、產出設計與簡報、串接既有工具、按時自動執行的協作夥伴。把「沒用過」變成「每天在用、而且用對」。

## Prior experience
- 完全沒有用過 Claude（本主題從零教起，不預設任何 Claude 知識）。
- 沒有 AI 助理 / prompt / 模型選擇的既有經驗。
- 沒有 MCP、connector、skill 或自動化排程的經驗。
- 具備一般電腦操作能力：會用瀏覽器、資料夾與檔案、試算表、文書與簡報工具。

## Anchors
- 日常檔案整理（下載資料夾一團亂、發票或收據要整理成報表）——對應 Cowork 代辦本機檔案。
- 寫作與簡報需求（貼文、email、投影片、landing page）——對應 Chat 與 Claude Design。
- 試算表與表單（Google Sheet、Excel、線上問卷）——對應 Excel / connector / 自動化。
- 瀏覽器上的日常操作（填表、抓資料、看網頁）——對應 Chrome extension。
- 手機與電腦之間的工作交接（把待辦丟給電腦上的 AI 完成）——對應 dispatch 與排程。

## Habits & constraints
- 每週 1–3 小時，時間破碎、不固定；長段落在週末或晚間。
- Mac 環境；能自行安裝桌面應用與瀏覽器擴充。
- 無硬性 deadline、中等壓力。
- 每課要能一次讀完、可隨時中斷再繼續。

## Knowledge type
mixed，**procedural 為主**。核心是「會操作、能自己做出來」——開專案、接 connector、寫 skill、排程自動化；declarative 部分（何時該用哪個介面、模型差異、context 與 harness 的概念）是支撐判斷力的背景，要在操作的脈絡裡講，不空談理論。

## How to teach me
- 先給**完整實跑**：一個真實情境 → 在介面上怎麼操作 → 產出什麼，再讓我照著做一次小重現。
- **每課開頭先用貼近日常的情境講「為什麼要學、解決什麼問題」**，再進核心；不要一開頭就丟定義或結論。
- 用白話說明，**不要名詞轟炸**；新名詞出現時先用一句話講清楚它是什麼、拿來幹嘛。
- 步驟要具體（點哪裡、打什麼、結果長怎樣），遇到安裝或設定只在必要時給最小步驟。
- 每篇要能**碎片化讀完**，結尾落在「真的做得出一個東西或真的能決定一件事」上。
- 講「為什麼」的機制（為什麼要分 Chat 還是 Cowork、為什麼 context 會變笨、為什麼 connector 能幫 Claude 動手）幫我記住「怎麼做」。
- 輸出語言 **zh-Hant**；程式碼、識別字、API 名稱與產品名稱保持英文。
