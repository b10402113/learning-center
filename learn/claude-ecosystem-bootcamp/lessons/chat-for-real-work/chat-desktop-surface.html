Chat 的完整版在桌面 App：web 版少了什麼

Step 1/4 · 用 Chat 做真實工作

學習目標

能說明為什麼要從 Claude 桌面應用開始，並指出 web 版缺少的本機檔案、排程與背景自動化能力。

前言：你一直少開的那扇門

前面幾節，你已經在 claude.ai 上跟 Claude 聊過，也用過語音、網路搜尋和看圖。這些都很實在，沒有白學。但這裡有個很容易被忽略的岔路：如果你一直只在瀏覽器裡用它，你會錯過後面一整條自動化路線的起點。

原因是這樣。你現在熟悉的 claude.ai 網頁版，功能其實是「基本款」：打開瀏覽器、打一段話、拿一個回覆，然後關掉。真正能碰到你電腦裡的檔案、能照時間自動跑、能串接你本機其他工具的版本，住在另一個地方：Claude 的桌面應用程式（desktop app）。這一節要做的決定很單純：把桌面 App 裝起來，之後都在裡面操作。因為接下來要學的 Cowork、排程與本機檔案，只在桌面版才存在。

兩個版本的差別，用一張表看清楚

先別急著安裝，我們先弄懂 web 版和桌面版到底差在哪。兩個版本的差別是用途不同，跟新舊無關。你可以把 web 版想成一個方便的前台：在任何一台電腦、借來的電腦、公司電腦上，打開瀏覽器就能用，適合臨時問問題。桌面版則像你把整個工作室搬回自己的電腦，工具更齊全，能動到本機的東西。

能力web 版（claude.ai）桌面 App
開啟方式瀏覽器，不用安裝安裝在 Mac 或 Windows
每次對話從零開始，沒有延續Chat、Cowork、Code 都在同一個地方

背景自動化沒有有，可在背景跑流程

這張表只要記住一句話：web 版能陪你聊天，但不會碰你的電腦；桌面版才會。而「會碰你的電腦」正是後面自動化的前提。

桌面 App 把三個工具收進同一個地方

桌面版不只多了本機能力，它還把 Claude 的三個主要工具放在同一個介面裡：Claude Chat、Cowork 和 Code。你不用在不同網站之間切來切去，在同一個應用程式裡就能切換。此外，它解鎖了網頁版做不到的四件事：讓排程任務自動執行、直接存取你電腦上的檔案、在背景跑自動化、以及連接你本機的工具和應用。

換句話說，之後你在這門課裡看到、要跟著做的東西，幾乎都會在這個桌面 App 裡出現。這也是為什麼我們從這一節開始，一律改用桌面版操作。

怎麼裝：五分鐘的事

安裝本身很簡單：到 claude.ai 的下載頁，或直接從官方提供的下載連結，把桌面 App 下載下來。它是免費的，Mac 和 Windows 都有支援，整個安裝設定大概只要五分鐘。裝好、登入同一個帳號之後，你就會在左側看到 Chat 的介面，接下來幾個節點都會在這裡進行。

有一個小提醒：你不用把 web 版從此封殺。臨時在別人的電腦上想問一句話，網頁版還是很方便。只是當你要做「真的會動到檔案、需要自動跑」的工作時，記得回到桌面 App。

小結

claude.ai 的網頁版是基本款：打開、聊天、拿答案，每一段對話各自獨立，也碰不到你電腦裡的本機檔案、排程與背景自動化。桌面 App 才是完整版，它把 Chat、Cowork、Code 收在同一個地方，並解鎖存取本機檔案、設定排程、背景自動化與串接本機工具的能力。安裝免費、Mac 與 Windows 都支援，大約五分鐘完成。從這個節點開始，我們都在桌面 App 裡操作；但要記得分清楚：這一節講的是「在哪裡用 Chat」，下一節才要正式回答「Chat 到底是什麼、它特別強在哪」。
