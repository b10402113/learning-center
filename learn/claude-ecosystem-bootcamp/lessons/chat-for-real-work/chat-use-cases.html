六種最適合交給 Chat 的任務

Step 3/4 · 用 Chat 做真實工作

學習目標

能用寫作編輯、解釋、腦力激盪、快速分析、研究問答、一次性草稿這六類，判斷什麼任務交給 Chat。

前言：知道它強，然後呢？

上一節我們確認了 Chat 是一個對話式的思考夥伴，強在寫作、讀長文件與拆解問題。可是「它很強」不會自動變成「我會用」。真正卡住人的往往是下一個問題：那我手上這些事，到底哪一件該丟給它？

這一節就是要給你一份可以照著用的清單。我們把最適合 Chat 的工作分成六類，每一類都配上真實例子。讀完之後，你看到一項任務，就能很快判斷它是不是 Chat 的活。先說結論：只要你需要的是「有人陪你想一想、寫一寫、讀一讀」，那就是 Chat。

一、寫作與編輯

第一類是寫作與編輯，也是 Chat 最常被使用的地方。具體來說，是這些東西：草擬 email、寫報告、寫部落格文章、寫社群貼文（caption）、整理摘要，以及任何跟文字有關的事。

比方說，你明天要寄一封說明信給合作夥伴，開頭怎麼寫都不順。你可以把背景、對象和你想表達的重點告訴 Chat，請它起個草稿；不滿意就接著說「再正式一點」「縮短到三段」，它會順著你的意思改。Chat 的寫作品質很好，它跟得上你要求的語氣，也會調整風格，最後產出的內容讀起來是自然的，而不是硬梆梆的樣板。這也是為什麼很多人的第一件「AI 真的幫到我」的事，就是寫作。

二、解釋複雜的東西

第二類是解釋。當你手上有一份看不懂的東西，就把它貼給 Chat，請它拆解。適合的東西包括：合約、技術文件、策略簡報（strategy brief）這類又長又硬的內容。

這裡就用到上一節講的長上下文能力。合約動輒十幾頁、技術文件充滿專有名詞、策略簡報塞滿圖表，你自己讀可能讀到頭昏，還抓不到重點。你可以直接把整份內容交給 Chat，問它「這份合約裡對我最不利的條款是哪些」「這份技術文件在解決什麼問題」。因為它一次能讀進大量內容又不迷失脈絡，所以能針對你真正在意的點給出解釋。

三、腦力激盪

第三類是腦力激盪。當你需要靈感、需要一堆選項可以挑的時候，Chat 特別好用。常見的情境像是想行銷角度、想內容題目、想活動主題。

它的優勢在於快、有創意，而且一次能給你很多選項。你可以說「給我十個針對上班族的內容題目」，先拿到一批候選，再從裡面挑幾個請它深入發展。腦力激盪最怕的就是腦子一片空白，而 Chat 的角色就是那個不怕冷場、可以一直丟球給你的夥伴。你不用照單全收，重點是它幫你把「零」變成「很多」，你再去篩。

四、快速分析

第四類是快速分析。當你有一堆資料、但不確定它代表什麼意思的時候，可以把它交給 Chat 幫你看一眼。資料的形式很彈性：可以是一張截圖、一份試算表，或直接把數據貼進對話裡。

你可以上傳之後問它：「哪些地方做得好、哪些做得不好、我下一步該做什麼？」比方說你貼上一張上個月的業績表，請它找出成長和衰退的品項，它會給你一段有重點的分析。這不是要取代正式的數據分析，只是讓你在短短一分鐘內對一份資料有個方向感，知道接下來該往哪裡看。這裡的重點是「快速」：你可以用最輕的方式得到一個初步判斷。

五、研究與問答

第五類是研究與問答。你可以直接問 Claude 一個問題、請它探索一個你不熟的主題，或請它幫你查某件事。這種一問一答的探索，是 Chat 的拿手好戲。

要特別提醒的是「網路搜尋（web search）」這個開關。如果你的問題跟最新資訊、即時價格、最近發生的事有關，記得把網路搜尋打開。打開後，Chat 才能去抓當下真實的資訊，並且附上來源；如果沒開，它只能憑訓練時的記憶回答，遇到新一點的事情就可能給你過時、甚至空泛的答案。這是使用 Chat 時很常被忽略、但影響很大的一個習慣。

六、一次性草稿

第六類是一次性草稿。所謂一次性，就是你只需要做這麼一次、不必重複的東西。例如：寫一份職缺說明（job description）、回覆一則客訴、把一場會議整理成摘要。

這類任務通常有幾個特徵：發生得突然、需要馬上產出、做完就不會再有第二次。你不需要為它建立什麼長期系統，只要請 Chat 幫你生出一份草稿，你改一改就能用。這種「急、一次性、要文字」的任務，正是 Chat 最適合發揮的地方。

把六類收成一個判斷

六類看起來很多，其實可以收成一句話：只要你需要的是「想一想、寫一寫、讀一讀」，而且產出的是一段文字或一個判斷，而不是要電腦替你動手，那它大概率就是 Chat 的活。寫作、解釋、腦力激盪、快速分析、研究問答、一次性草稿，全都是這個大原則下的具體例子。

反過來說，如果你的任務開始出現「要動到電腦裡的檔案」「要照時間自己跑」「要幫我在電腦上操作」，那就滑出了 Chat 的守備範圍。這正是下一節要談的界線。

小結

最適合交給 Chat 的工作有六類：寫作與編輯（email、報告、部落格、社群文案、摘要）、解釋複雜的東西（合約、技術文件、策略簡報，靠長上下文讀完整份）、腦力激盪（快速給出一批選項讓你挑）、快速分析（上傳截圖、試算表或貼上資料，問它什麼有效、下一步做什麼）、研究與問答（記得打開網路搜尋才拿得到即時資訊）、一次性草稿（職缺說明、回覆客訴、會議摘要這種做一次就好的東西）。共同的判準是：你需要的是想一想、寫一寫、讀一讀，產出的是文字或判斷，而不是要電腦替你動手。下一節要畫出 Chat 的界線，看看什麼時候該換成 Cowork 或 Code。
