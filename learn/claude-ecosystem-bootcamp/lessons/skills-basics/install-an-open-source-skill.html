安裝社群 skill：用 Humanizer 把文字改得更像真人

Step 3/3 · 取得、安裝並使用一個社群 skill

先完成一次完整操作

如果你已經寫好一封開發信，卻覺得句子太制式、熱情太用力，通常不用整封重寫。安裝 Humanizer 之後，你可以把原稿交給 Claude，請它依照一套現成規則，移除文字裡明顯的「AI 味」。

這一課會帶你完成一個完整流程：從 GitHub 取得 skill.md，在 Claude 的 Customize → Skills → Create skill 上傳並啟用，最後用 slash command 或自然語言叫出 Humanizer。

完成後，你的 Claude Skills 清單裡會多一個 Humanizer。開始前只需要兩樣東西：一個能登入 Claude 的帳號，以及能下載、開啟檔案的電腦操作能力。整個流程大約兩分鐘。

Step 1：從 GitHub 取得 skill 檔案

這次要安裝的 Humanizer，原始碼放在 GitHub 的 blader/humanizer 專案中，星星數超過兩萬五千。你不需要下載整個專案，真正需要的是裡面的 skill.md。

skill.md 可以想成一份交給 Claude 的工作說明書：它用文字寫出 Claude 應該怎麼辨識並修改內容。

  1. 開啟瀏覽器，前往 https://github.com/blader/humanizer。
  2. 在專案中找到 skill.md，並下載這個檔案。
  3. 用任何文字編輯器開啟它，先把內容讀過一遍。

你會看到一份寫給 Claude 的指令，內容包含辨識並移除 AI 寫作特徵，例如浮誇的字眼、被濫用的破折號，以及刻意營造的熱情。這些規則參考了 Wikipedia 整理、用來清理 AI 生成內容的 33 種模式。

先讀，再安裝。Skill 本質上是一串交給 Claude 執行的指令，因此只安裝你信任的來源。開源專案的好處是內容公開、可以自行檢查；如果看不懂，或覺得內容可疑，就不要安裝。

Step 2：在 Claude 上傳並啟用 skill

拿到 skill.md 後，就可以把它加入 Claude。操作路徑如下：

  1. 開啟 Claude，進入 Customize（自訂）。
  2. 點進 Skills。這裡會列出目前的 Skills 與 connector，預設也會看到 Anthropic 內建的「Skill Creator」。
  3. 選擇 Create skill（建立技能），上傳剛才下載的 skill.md。

上傳完成後，Humanizer 應該會出現在 Skills 清單裡。請確認它是啟用狀態；如果沒有啟用，Claude 就不會讀取這份 skill。

這套「取得檔案 → Create skill → 上傳」的流程，不只適用於 Humanizer。之後如果你找到其他開源 skill，只要換成對方提供的 skill.md，就能用同樣的方法安裝。

Step 3：先跑一個實際情境

假設你想寄一封開發信給當地商家，介紹自己的 AI agency 服務。你可以直接在 Claude 的對話框輸入下面這段 slash command：

/humanizer Write a cold outreach email to a local business offering my AI agency services. Make it professional and persuasive.

送出後，Claude 會依照 Humanizer 的規則處理文字，讓內容更接近真人寫作的語氣。這種方式適合你已經有一段文字或明確需求，只想請 Humanizer 幫忙清理語氣的情況。

Step 4：用兩種方式觸發 Humanizer

安裝完成後，你可以在任何對話中使用它。選哪一種方式，取決於你手上是否已經有現成文字。

方式一：用 slash command 處理既有文字

如果你已經寫好草稿，想把它改得自然一點，就在對話框輸入 /humanizer，後面接著你的要求：

/humanizer Write a cold outreach email to a local business offering my AI agency services. Make it professional and persuasive.

送出後，Claude 會按照 Humanizer 的規則重新處理內容。這種方式適合「素材已經在手上，只想降低 AI 味」的情境。

方式二：用自然語言邊生成、邊改寫

如果你還沒有草稿，也可以直接用自然語言描述需求，請 Claude 先寫內容，再把它改得像真人寫的：

Write me a catchy cold outreach email to a potential client I want to pitch my AI agency services to. Then humanize it — make it sound like a real person wrote it, not an AI.

這段話裡的關鍵是 humanize it。你不一定要輸入 slash command，只要在要求中使用「humanize it」或「make it sound more human」這類自然語言提示，Claude 就會把 Humanizer 叫進來，完成生成與改寫。

Step 5：做一個小重現，確認真的能用

現在可以用最小的方式再試一次：

  1. 開啟 Claude 的新對話。
  2. 輸入一段你想改寫的文字，或直接貼上剛才的開發信需求。
  3. 在前面加上 /humanizer，再送出。
  4. 檢查輸出是否少了浮誇字眼、過度用力的熱情，讀起來也更像真人寫的。

如果你還沒有文字素材，則改用自然語言提出要求，並在句子中加入 humanize it。這樣就能重現「邊生成、邊改寫」的用法。

確認安裝成功

你可以從三個地方檢查結果：

  • Skills 清單裡看得到 Humanizer，而且顯示為啟用中。
  • Claude 動用這個 skill 時，通常會主動說明自己正在使用 Humanizer。
  • 處理後的文字比原本更像人寫的，少掉浮誇字眼與硬湊出來的熱情。

三項都符合，就代表你已經完成一次可驗證的「取得 → 安裝 → 觸發」流程。

你現在完成了什麼

安裝一個開源 skill 可以照四個動作完成：先從 GitHub 取得單一的 skill.md 並讀過內容；接著到 Customize → Skills → Create skill 上傳；確認 skill 已啟用；最後用 /humanizer 處理既有文字，或用「humanize it」這類自然語言讓它邊生成邊改寫。

這套流程同樣適用於其他社群 skill，只要換成另一份 skill.md 即可。你現在已經能安裝並使用別人寫好的 skill；下一步則是把自己反覆使用的一套做法，寫成可重複使用的 skill，並把需要的背景一起打包帶走。
