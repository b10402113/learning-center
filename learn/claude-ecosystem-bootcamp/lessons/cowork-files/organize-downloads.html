實戰一：把一團亂的 Downloads 整理好

Step 3/4 · Cowork 接手本機檔案

學習目標

能寫出一段整理 Downloads 的任務指令，讓 Cowork 分類檔案、重新命名、列出重複檔並在刪除前先問過，最後產出一份摘要。

前言：從最有感的那個抽屜開始

上一節我們把規矩立好了，現在終於可以真的交辦事情。而第一個任務，就挑最有感的那個：Downloads 資料夾。

它大概是每台電腦裡最誠實的地方。三個月前下載的安裝檔、隨手存的圖片、名字長得像亂碼的 PDF、還有好幾個「未命名」的壓縮檔，全擠在同一層。你每次都告訴自己週末要來整理，但打開看到那一片混亂，就又默默關掉。這一節就是把這個抽屜交給 Cowork，讓它替你收乾淨。

第一步：先讓它看清楚裡面有什麼

別急著叫它分類。先下一個簡單的指令，讓它摸清這個資料夾的底細：

Summarize what's in my Downloads folder

這句話只要求它「摘要一下這裡面有什麼」。你會拿到一份概觀：大概有哪些類型的檔案、各有多少、有沒有明顯的異常。這一步看似多餘，其實很重要：你和它都先在腦中建立一張地圖，之後要分類、要判斷，才有依據，而不是憑空猜。

第二步：下完整的分類任務

心裡有底之後，再下真正的任務指令。這是一段可以直接照抄的範例：

Organize this Downloads folder. Sort all files into subfolders by type: Documents, Images, Videos, Installers, Archives, and Other. Rename any files with generic names like IMG_, Screenshot_, or Download_ to something descriptive based on the file's content. If you find any duplicates, list them and ask me before deleting anything. When you're done, give me a summary of what you did.

這段話不算長，但它其實把五件要求一次講完了。拆開來看，它交辦了這些事：

要求指令裡怎麼寫
按類型分類分成 Documents、Images、Videos、Installers、Archives 與 Other 六個子資料夾
重新命名泛用檔名把 IMG_、Screenshot_、Download_ 這類名稱改成依內容判斷的描述性名稱
揪出重複檔發現重複的檔案要列出來
刪除前先問要刪任何東西之前，先問過你
回報結果做完之後，給一份「你做了什麼」的摘要

為什麼這樣寫是一段好的交辦

把這段指令對照前面談過的「把話講具體」，就會發現它示範了交辦的關鍵：它沒有只說「幫我整理 Downloads」，還把結果長什麼樣子講清楚：分成哪幾類、泛用檔名怎麼處理、遇到重複檔怎麼辦、最後要回報。每一條都是可以驗收的具體要求。

尤其注意「刪除前先問」那一句。它對應的正是上一節寫進全域指令的底線。你可以在任務指令裡再強調一次，而 Cowork 也會照著這個原則走：找到重複檔先列出來，不會自作主張清掉。

執行的樣子：先計畫，你同意，才動手

按下送出之後，你不會看到它馬上開始搬檔案。因為上一節那條「動手前先給計畫」的規則，它會先回你一份執行計畫：打算建哪幾個資料夾、怎麼分類、哪些檔名要改。你看過、覺得沒問題、同意之後，它才真正開始動作。中間如果遇到它判斷不了的情況，它也會回來問你。

跑完之後，你會看到原本混亂的一堆檔案，變成了幾個分類清楚的資料夾，泛用檔名也換成了看得懂的名字，而且它會給你一份摘要，告訴你總共處理了什麼、刪掉了哪些（經你同意的）重複檔。在真實的示範裡，原本 54 個亂七八糟的項目，最後變成整齊分類好的資料夾。

最後再強調一次為什麼這件事非 Cowork 不可：這種直接讀寫、搬移本機檔案的操作，Chat 完全做不到。Chat 頂多把「你應該先建六個資料夾、再把檔案拖進去」寫成一份教學，而真正動手的還是你。Cowork 厲害的地方在於，它講的和它做的，是同一件事。

小結

整理 Downloads 分兩步：先請 Cowork 摘要資料夾裡有什麼，建立一張地圖；再下完整的任務指令，把分類方式、泛用檔名的處理、重複檔怎麼處理、要不要回報，一次講清楚。因為有全域指令的「先給計畫」規則，它會先給你看計畫、等你同意才動手，途中遇到不確定的事也會問你。這種本機檔案操作是 Chat 做不到的，只有 Cowork 能真的搬動你的檔案。

整理 Downloads 是「看得到成果」的暖身，檔案分類完，成就感很直接。下一節要換一個更高價值的任務：把一整個資料夾的收據與發票，變成一份帶有分類彙總的 Excel 報表，這種事平常可能得花你一個下午。
