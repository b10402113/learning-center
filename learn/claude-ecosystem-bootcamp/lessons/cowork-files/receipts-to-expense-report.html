實戰二：把收據與發票彙整成 Excel 報表

Step 4/4 · Cowork 接手本機檔案

學習目標

能讓 Cowork 掃描一整個資料夾的 PDF 與圖片收據，擷取日期、商家、金額、幣別與類別，產出依日期排序、含分類彙總與疑義標註的 Excel 報表。

前言：每季都會來一次的報帳地獄

上一節把資料夾收乾淨了，那是個看得到成果的暖身。這一節要處理的，是很多人每年都逃不掉的那件事：報帳。

想像一下，一季下來，你的報帳資料散落各處。有從信箱下載的 PDF 電子發票，有紙本收據用手機拍的照，還有一些是螢幕截圖。有的是掃描得歪歪的、有的是英文、有的幣別還不一樣。以往你要一張一張點開、把日期金額抄進 Excel，做著做著一個下午就過去了；不想自己做，就得花錢請人。這一節要讓 Cowork 替你讀懂這些檔案，直接吐出一份可以交出去的報表。

把資料夾交給它，下一段指令

任務本身的形狀跟上一節很像：指定一個資料夾，把要做的事講清楚，剩下的交給它。指令可以這樣寫：

Scan all the files in this folder. They include PDFs, JPEGs, and PNGs of receipts and invoices. For each one, extract: the date, the vendor or merchant name, the amount, the currency, and the category (such as Software, Travel, Office Supplies, Meals, Advertising, or Other). Once you've gone through all of them, create an Excel file called Expenses_Report_2026.xlsx with the following columns: Date, Vendor, Amount, Currency, Category, and Notes. Sort the rows by date. Add a summary tab at the top that totals spending by category. Flag any receipts where the amount or date is unclear and add a note in the Notes column.

這段話讀起來長，但它其實只是把「輸入是什麼、要輸出什麼」交代得夠完整。拆解如下：

步驟指令要求
掃描所有檔案PDF、JPEG、PNG 都要讀，包括圖片型的收據與發票
擷取五個欄位日期、商家名稱、金額、幣別、類別
產出 Excel檔名 Expenses_Report_2026.xlsx，欄位為 Date、Vendor、Amount、Currency、Category、Notes
依日期排序資料列按日期先後排列
加上彙總頁在報表最前面加一個 summary tab，依類別加總花費
標註疑義金額或日期看不清楚的，在 Notes 欄加註記

為什麼它讀得懂「拍照的收據」

這一段指令裡最關鍵的一句話，是它明講了「PDF、JPEG、PNG 都要讀」。這代表 Cowork 除了文字檔，也讀得懂圖片裡的內容：它會先「看」那張紙本收據的照片或掃描檔，辨識出上面的日期、金額、商家，再轉成結構化的資料。

所以你的輸入亂一點沒關係：電子發票的 PDF、手機拍的 JPEG、螢幕截圖的 PNG，全部丟進同一個資料夾就好，它會一視同仁地處理過去。這正是這類收據任務過去很難自動化的地方：檔案格式太雜、又有圖片，對 Cowork 來說卻不是問題。

執行的過程：一趟自動跑完的多步驟流程

送出後，它會把整個任務拆成幾個階段自動跑：先掃描資料夾裡所有檔案，再逐一擷取欄位資料，最後組成 Excel 報表。中間不需要你盯在旁邊，這就是 Cowork 相對於一問一答的差別。

指令裡還加了一條：標註疑義。如果某張收據的金額模糊、看不清楚，或者日期和幣別看起來對不上，它不會硬猜一個數字塞進去，會主動把那筆 flag 出來，在你的 Notes 欄寫上說明。等你打開報表，一眼就看到哪幾筆需要人工再確認，不必把整份報表重新核對一次。

這才是真正省時間的地方

同樣一份報表，手動做要好幾個小時，不然就要花錢外包；Cowork 幾分鐘就做完。而且它附上的彙總頁讓你直接看到各類別花了多少，不用自己拉樞紐分析。對忙碌的人來說，這不只是快，還把一件你一直拖著不想做的事，變成一件「丟出去、等一下、回來拿成品」的事。

這也是 Cowork 的價值縮影：它處理的是真實的文件、真實的數字，產出的是一份可以直接用的檔案，而不是一段你需要動手實作的說明。

小結

把一整個裝了收據與發票的資料夾交給 Cowork，用一段指令講清楚要擷取哪五個欄位、輸出成什麼檔名的 Excel、怎麼排序、要不要彙總、遇到看不清的怎麼辦。它讀得懂圖片型的收據，會自己拆成「掃描 → 擷取 → 報表」多個階段自動跑完，還會主動把看不清楚的金額或日期標註出來，等你確認。原本要好幾個小時的工作，變成幾分鐘。

走到這裡，這個節點就完整了：你知道 Cowork 為什麼存在、怎麼設定它、怎麼交辦單一資料夾的任務。接下來的節點會把這些做法升級成可重複的 Cowork 專案與排程任務，讓它按時自己跑起來，你只要設定一次，之後就交給它。
