四種工具、同一顆大腦：Chat、Cowork、Code、Design

Step 3/4 · Claude 是什麼、生態系長怎樣

學習目標

能為一個具體任務挑出正確的工具（Chat / Cowork / Code / Design），並說明為什麼。

前言：網頁版不是 Claude 的全部

上一節把 Claude 從「客服機器人」的框架裡拉出來，說它是能讀、能寫、能推理的協作夥伴。但接著有一個很容易踩到的坑：很多人只打開過 claude.ai 的網頁對話框，就以為自己認識 Claude 了。但在它底下有四種工具，各自為了很不一樣的工作而設計。

這一節的目標很實際。看完之後，你眼前出現任何一個任務，都能馬上知道該打開哪一個工具，而不是全丟進同一個對話框裡，然後覺得「怎麼卡卡的」。

先講清楚：網頁對話框什麼時候會卡住

你熟悉的 claude.ai 網頁版，對大多數問題其實夠用了，這點先講清楚。但有幾種情境，它就是不夠：

  • 客戶丟來一個資料夾，裡面有 50 份 PDF，你要它一次全部讀完並摘要，不是一份一份來。
  • 你想要每天早上七點自動跑一份晨間簡報，從 Slack、Calendar、Gmail 撈資料，在你打開 App 之前就準備好。
  • 你是開發者，想讓它讀完整個專案程式碼、跑測試、提交變更，而不是每次把程式碼複製貼上、來回搬運。

這些都是真實的瓶頸。網頁對話框收不了你的本機檔案，不支援排程，不能在你自己的電腦上執行程式，也沒有設計用的視覺畫布。Claude 的專門工具，就是為了接住這些網頁版做不到的事。

一個關鍵理解：四種工具，同一顆大腦

看懂這四種工具之前，先抓住一個重點：它們跑的是同一顆 Claude 智慧，同一個模型、同樣的能力。差別不在聰明程度，而在每一種工具被配備了什麼、能碰到什麼。就像同一位師傅，換上不同裝備去做不同工作。理解這件事，你就不會把它們想成四個互相競爭的產品，而是一個人手上的四套工具。

工具比喻適合的工作在哪裡用
Chat你的書桌快速思考、即時問答、日常對話web / desktop / mobile
Cowork你的工作坊給它一個目標，它自己讀檔案、連 App、跑多步驟任務desktop
Code你的機房完整程式碼、終端機、版本控制、本機檔案desktop / IDE / terminal
Design你的創作工作室描述你想要的，它做出原型、簡報、landing page、ebookclaude.ai 的 Design 分頁

Chat 是你的書桌，適合快速想事情、問問題、日常來回。你已經很熟。Cowork 是你的工作坊，你把手上的目標交出去，它會自己去讀你的檔案、連上你的 App、執行一連串步驟，把事情做完。Code 是你的機房，它有完整的程式碼、終端機、版本控制與本機檔案權限，是給會寫程式的人用的重裝環境。Design 是你的創作工作室，你用白話描述你要什麼，它幫你做出原型、簡報、landing page、電子書，而且是活的、可互動的成品，不需要任何設計背景。

還有一件容易搞混的事先講：Design 就在 claude.ai 裡，找側邊欄的 Design 分頁；而 Chat、Cowork、Code 這三個都住在 Claude 的桌面 App 裡，Mac 和 Windows 都有。

用幾個任務，把選擇變成直覺

規則背下來沒有用，看例子最快。下面這幾個任務，你可以先自己在心裡猜一下該用哪個工具，再看答案。

你手上的任務該用哪個為什麼
把這封 email 改得更委婉一點Chat單純的來回對話與文字修飾，書桌上就能解決
把 Downloads 資料夾整理好，把發票彙整成 ExcelCowork要碰本機檔案、執行多個步驟，這是工作坊的活
修好這個專案登入流程的 bug，並跑測試Code需要完整程式碼、執行與版本控制，機房的範圍
照我們的品牌做一份募資簡報Design要產出視覺化、可交付的成品，交給創作工作室

多看幾次之後，你會發現判斷很單純：只是要用文字想事情、問問題，用 Chat；要它去碰你的檔案、動你的電腦、做一連串步驟，就往 Cowork 或 Code 走；要生出設計成品，找 Design。網頁對話框做不到的那些事，正好就是後面三種工具存在的理由。

小結

Claude 有四種工具，但共用同一顆智慧：Chat 是書桌，適合快速思考與日常對話；Cowork 是工作坊，接手本機檔案與多步驟任務；Code 是機房，處理完整程式碼、終端機與版本控制；Design 是創作工作室，用白話生出原型、簡報與 landing page。選工具的原則是看它需不需要碰你的檔案、跑你的機器，或產出視覺成品。

到這裡，你已經知道 Claude 有四種工具、也知道每種工具解決什麼問題。最後一節要把鏡頭拉遠，讓你看見這四級 bootcamp 會依序把你帶到哪裡，以及 Level 1 結束時你應該能做出什麼。
