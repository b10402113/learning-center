第一次對話：一句 prompt 到語音、搜尋、看圖與延伸思考

Step 2/3 · 第一次對話與第一個 Artifact

學習目標

能完成一次包含具體 prompt、語音、網路搜尋、看圖與延伸思考的對話。

前言：為什麼我問了，它回的卻像罐頭訊息？

上一節我們先解決了「要用哪顆引擎」，知道日常交給 Sonnet、重要的事再切 Opus。引擎選好了，接下來就是真正坐下來跟它講第一句話。而大多數人第一次使用時，都在這裡踢到鐵板。

你可能打了一句「幫我寫一封自我介紹信」，送出，幾秒後拿到一封信。讀完卻覺得哪裡怪：沒有名字、沒有公司、語氣也跟你不太搭，換成任何一個人都能用。於是你心裡冒出一個結論：「AI 好像也沒那麼神。」但問題真的不在它。同一顆 Sonnet，換一句話問，結果可以天差地遠。這節要把「怎麼把話講清楚」這件事拆開來看，順便把對話框裡那幾個好用但容易被忽略的能力（語音、網路搜尋、看圖、延伸思考）一起用過一遍。

關鍵一：把 prompt 講具體，罐頭訊息就消失了

先看一組對照。假設你想寫一封給新同事的自我介紹信。

空泛版：幫我寫一封自我介紹信。

這句話只給了「寫信」這個動作，至於你叫什麼、做什麼、想給誰看、要多長、語氣如何，Claude 一概不知道。它只能拿最常見的模板來猜，於是你就得到一封誰都能用的信。

具體版：write a short intro email to my new team. My name is Leo. I'm joining as a marketing manager. Keep it friendly and under 100 words.

同樣是「寫一封自我介紹信」，差別在於第二句多補了四樣東西。把它拆開來看，這四樣就是讓 prompt 從空泛變可用的關鍵：

元素在這句話裡對應到什麼少了它會怎樣
對象與目的寫給新團隊（to my new team）不知道要對誰說話，語氣抓不準
你的身分Leo，行銷經理（My name is Leo. I'm joining as a marketing manager.）內容空洞，沒有任何個人資訊
語氣友善（Keep it friendly）可能寫得過度正式或過度隨便
長度100 字以內（under 100 words）篇幅失控，或短到講不清楚

記住這個習慣：每次送出前，快速掃一眼你的句子裡有沒有交代「給誰、我是誰、什麼口氣、多長」。不需要每次都四樣齊全，但缺得越多，它就越只能靠猜。

關鍵二：用說的也通，語音輸入與語音模式

打字不是唯一的路。Claude 有兩種跟「講話」有關的功能，很多人會把它們混在一起，但用途其實不一樣。

第一種是語音輸入，也有人叫聽寫。它做的事就是幫你把講出來的話轉成文字，填進輸入框。你講完，文字還是會出現在框裡，你可以改一改再送出。適合的場合是你懶得打字、手不方便，或者想法很多想一次倒出來的時候。它本質上只是打字的替代品，對話的節奏沒有變。

第二種是語音模式，這才是真的「用講的對話」。開啟之後你不需要打字，直接開口說，Claude 用語音回答你，一來一往像在講電話。適合你想邊走邊想、或是需要即時反覆討論的時候。要注意一件事：語音模式比純打字更耗 token，因為它多了語音辨識與語音合成這段處理。如果你當天的用量已經很緊，用講的可能一下就見底，這時候回頭打字會比較省。

關鍵三：要問「最近」「現在」，記得把網路搜尋打開

再來是一個很容易踩到的坑。假設你問：「特斯拉（Tesla）現在股價多少？」如果網路搜尋沒有開，Claude 只能用它訓練時看過的資料回答，而股價這種東西每天都在變，它給你的不是過時，就是直接告訴你它不確定。兩種答案都沒辦法用。

把網路搜尋打開之後，它會去網路上查即時資訊，回來告訴你目前大約是 396 美元，並且附上資料來源，例如 Yahoo Finance、Google Finance、MarketWatch 這幾個網站。你看到的不只是數字，還知道這個數字是從哪裡來的，可以自己點進去看。

所以這裡有一條簡單的規則：只要你的問題牽涉到「最近」「目前」「現在」「最新」這類會隨時間變動的資訊，先確認網路搜尋是開著的。如果是問概念、問寫法、問歷史這種不會天天變的東西，不開也沒關係。

關鍵四：上傳圖片，讓它幫你「看」

Claude 不只能讀文字，也能讀圖片。你把圖丟進對話框，它可以辨識裡面的內容並用文字回答你。這個能力叫做 vision（視覺辨識）。

一個很實用的例子：你在日本旅遊，拿到一張 7-Eleven 的收據，上面全是日文。你直接把收據拍照上傳，請它幫你整理，它會用英文把每一項商品列出來，告訴你買了什麼、多少錢。對看不懂當地文字的人來說，這比一句一句查字典快得多。

除了收據，還能派上用場的包括：軟體出錯時的截圖（請它讀出錯誤訊息並解釋）、手寫的筆記（請它整理成打字稿）、看得懂但懶得抄的表格或發票。共同點是：只要「內容卡在圖片裡、你需要它變成可用的文字」，就交給 vision。

關鍵五：答案錯了有後果，就開延伸思考

最後一個能力叫延伸思考（extended thinking）。打開之後，Claude 在給出答案前會先在內部把問題想過一遍：檢查前提、拆解步驟、推演不同可能，再把結論端給你。你可以把它想成「讓它先在草稿紙上演算，再交答案」。

延伸思考有不同的投入程度（effort），由低到高分成 low、medium、high、extra、max 五級。級數越高，它想得越周詳，但代價是花更久的時間，也更快燒掉你的用量。所以並不是無腦開到最大就好。

什麼時候值得開？原則是：當這個答案如果錯了，會帶來真實的後果。例如要做一個會影響決策的取捨、要在兩個做法之間選一個、要判斷一段程式為什麼出錯。這種題目多想幾步是值得的。如果只是問天氣、請它改個錯字，開延伸思考只是浪費等待時間。把 effort 當成一個轉盤，依照「答錯的代價」決定要轉到哪一格。

串起來：跑完你第一次真正的對話

把上面五件事放進同一次對話，流程大概長這樣。你可以照著做一次，感受每個能力在什麼時機登場：

  1. 想好開場的 prompt。先確認句子裡交代了「給誰、我是誰、什麼口氣、多長」，例如前面那封自我介紹信。
  2. 選對模型。這種日常寫作任務用 Sonnet 就好，不必動用 Opus。
  3. 不想打字就用說的。選語音輸入把想法轉成文字，或開語音模式直接跟它對話。記得語音模式的用量消耗比較快。
  4. 問題涉及最新資訊就開搜尋。例如「幫我查一下這家公司最近的股價，再寫進信裡」，先把網路搜尋打開。
  5. 有圖片就丟上去。如果手上有截圖、收據或手寫筆記，直接上傳讓它讀。
  6. 需要判斷就開延伸思考。如果這封信牽涉到一個重要的決定，把 effort 調高，讓它多想幾步再給建議。

做完這一輪，你會發現「跟 Claude 對話」不是單一動作，而是可以根據任務需要，組合不同的輸入方式。這套組合能力就是你之後所有工作的底層操作。

小結

一次好用的對話，關鍵在兩件事：把 prompt 講具體，以及用對工具。具體的 prompt 要交代對象與目的、你的身分、語氣、長度；工具方面，語音輸入是把話轉成文字，語音模式是免持對話但更耗用量；網路搜尋在問題涉及最新資訊時必須打開；vision 讓它讀圖片裡的收據、截圖與手寫筆記；延伸思考在答案錯了有真實後果時開啟，effort 高低對應想得多深與燒得多快。

到這裡，你已經很會「跟 Claude 講話」了。但你有沒有發現一個限制：不管聊得多好，所有東西都擠在對話裡，捲一捲就找不到，而且只能讀、不能操作。下一節要把層級往上跳一階：讓 Claude 在旁邊開一個獨立面板，當場做一個你按得下去、能下載、能分享的小工具。這就是 artifact。
