選介面：Web、Desktop、Mobile 怎麼挑

Step 3/3 · 註冊、選方案、登入三種介面

學習目標

能分辨 Web、Desktop、Mobile 三種 Claude 介面的差別，並判斷自己的工作流程該用哪一種，尤其要知道哪些功能一定要桌面版才跑得動。

前言：Claude 不是一個 App，是三個入口

上一節你把方案選定了。到這裡，帳號有了、方案也有了，最後一個問題是：我到底要在哪裡用它？

這件事比想像中重要。很多人的第一印象是「網頁版跟桌面版應該差不多吧，只是桌面版視窗比較漂亮」。但實際上，Claude 有三個入口，其中有些功能是綁在特定入口上的。假如你只開網頁版，然後照著教學去找 Cowork，你會找不到，還可能以為是自己帳號有問題。其實不是，是你站錯門口了。這一節就把三個入口的差別講清楚，讓你之後遇到「這個功能怎麼不見了」的時候，知道該換到哪邊。

三個入口，先看一眼全貌

介面平台最快記法
Web（網頁版）瀏覽器，開 claude.ai 就能用什麼都不用裝，快速用一下
Desktop（桌面版）Mac 與 Windows要碰本機檔案、跑程式，就靠它
Mobile（手機版）iPhone 與 Android隨手丟想法、隨時問一句

網頁版：什麼都不用裝的入口

網頁版就是 claude.ai。你用瀏覽器打開、登入，結束，不用安裝任何東西。聊天該有的東西這裡都有：對話、專案、artifact，還有自訂角色與風格，整個體驗是完整的。

它最適合的情境，是快速跳進來用一下、在共用電腦或公司電腦上使用，或是你根本不想在裝置上裝東西。它的限制也很明確：有幾個比較強大的功能跑不起來，例如 Cowork，以及部分 Claude Code 的任務。這些功能需要桌面版，原因是它們必須碰觸你電腦上真正的檔案與程式，而瀏覽器沒有這種權限。

桌面版：多了一整批網頁版沒有的功能

桌面版有 Mac 與 Windows 兩種版本。如果你打算認真、固定地使用 Claude，這一版建議裝起來。它跟網頁版最大的差別，在於它解鎖了一批網頁版根本沒有的功能。

首先要認識的功能是 Cowork。它是一個本機檔案管理員，能直接讀取、寫入、整理你電腦上的檔案。這件事之所以只有桌面版做得到，是因為它需要存取你真正的檔案系統，而瀏覽器根本碰不到你的硬碟。你想請 Claude 整理一團亂的下載資料夾、或把散落的收據彙整成一份 Excel 報表，靠的就是它。

第二個是 Claude Code 的部分任務。Claude Code 在瀏覽器裡也能做某些事，但只要是會碰到你本機電腦的工作，例如執行你的腳本、讀你的本機資料夾、在你的電腦上執行程式，就一定要桌面版。如果沒有桌面版，Claude Code 其實是在雲端上跑，不是在你的電腦上跑。這個差別在你需要它動到你電腦裡的真實檔案時，會變得非常明顯。

所以桌面版最適合的，是你的主要工作機，以及任何牽涉到本機檔案或執行程序的工作流程。對這樣的人來說，它是必須安裝的。

手機版：隨身的入口

手機版有 iPhone 與 Android 兩種。它的價值在於「隨時在身邊」：通勤途中突然想到一個點子、排隊時想問一句、睡前想記下一件事，手機版讓你不用走到電腦前面就能用它。

不過它的限制跟網頁版類似。需要本機檔案、要跑程式的任務，最終還是得回到電腦上處理。手機版適合的是「隨手」的用法，不適合拿來做需要動到你電腦的專案。

怎麼挑：看你的任務碰到什麼

選擇介面不需要背規格，只要問一個問題：這個任務會不會碰到我電腦裡的真實檔案或程式？不會的話，網頁版或手機版都可以；會的話，就一定得用桌面版。

你要做的事該用的介面
快速問一個問題，或是在公司電腦上用Web
整理下載資料夾、把收據變成 Excel、跑本機程式Desktop（必須）
通勤時丟想法、隨時隨手問一句Mobile

一句話記住：Web 和 Mobile 是隨時可用的入口，Desktop 才是你的工作站。凡是需要碰到你電腦裡真實檔案的任務，只有 Desktop 做得到。

動手做：把桌面版裝起來

如果你用的是 Mac 或 Windows，而且打算長期使用，建議現在就把桌面版裝好。步驟比你想的簡單。

  1. 用瀏覽器前往 claude.ai，找到下載桌面版的入口。
  2. 選擇你的系統：Mac 或 Windows。
  3. 下載安裝檔。Mac 的話，把應用程式拖進「應用程式」資料夾；Windows 的話，照畫面指示安裝。
  4. 打開應用程式，按開始使用，用 Google 或 email 登入你剛才建立的帳號。
  5. 登入後，確認左側側邊欄出現了 Cowork（本機檔案管理員）這個入口。有看到它，就代表你已經站在可以碰本機檔案的那一邊了。

小結

Claude 有三個入口。網頁版在 claude.ai，不用安裝，聊天體驗完整，適合快速使用與共用電腦，但 Cowork 和部分 Claude Code 任務跑不動。桌面版（Mac、Windows）解鎖了這些功能，因為 Cowork 需要直接讀寫你的檔案系統，Claude Code 要碰本機檔案、跑腳本也得靠它；沒有桌面版時，Claude Code 是在雲端跑。手機版（iPhone、Android）是隨身入口，適合隨手問、隨手記。挑選原則只有一句：任務會不會碰到電腦裡的真實檔案？會，就用桌面版。
