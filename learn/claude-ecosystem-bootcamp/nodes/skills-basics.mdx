# Skill 是什麼、安裝一個來用

## Learning goal

能說明 skill 是什麼、何時該用 skill 而非重打提示詞，並安裝一個社群 skill 來用。

## Steps

1. [[learn/claude-ecosystem-bootcamp/nodes/skills-basics/what-is-a-skill|Skill 是什麼：把「你怎麼做事」存成一份檔案]] — 從「每次都在重講同一套做法」出發，認識 skill 是一份可被自動觸發的指令包，以及它和專案的分工
2. [[learn/claude-ecosystem-bootcamp/nodes/skills-basics/when-to-use-a-skill|何時該用 skill，而非每次重打提示詞]] — 用「重複性、一致性、跨專案」三條判準，分辨該隨手打提示詞、開專案，還是做成 skill（after step 1）
3. [[learn/claude-ecosystem-bootcamp/nodes/skills-basics/install-an-open-source-skill|安裝一個社群 skill 來用（以 Humanizer 為例）]] — 從 GitHub 取得 skill.md，上傳到 Customize → Skills，啟用並觸發它（after steps 1、2）

## Lesson

你已經會用 Chat 對話，也知道專案能幫你記住背景。但你可能遇到另一種麻煩：有些工作你每次做的「步驟」都一模一樣，例如寫產品上線信要先點出問題、再介紹產品、字數壓在一百八十字以內、不准用「超興奮」這種字眼；每次開新對話，你又得把這套規則從頭交代一次。專案記的是「你是誰、你在做哪件事」，但記不了「這件事你習慣怎麼做」。這個節點處理的就是這一層。

Skill 就是把「做法」本身存成一份檔案。它是一份 Claude 看得懂的指令包，你寫一次，之後遇到對應任務時 Claude 會自己把它讀進來照著做。它和專案是互補的：專案提供背景（context），skill 提供流程（process）。這裡的三步依序回答：skill 到底是什麼、為什麼 Claude 需要它；什麼時候該用 skill，而不是隨手打一段提示詞；以及怎麼從 GitHub 上拿一個現成的社群 skill 裝進 Claude 來用。走完之後，你應該能把一件反覆重講的事，從「每次都要打字」變成「裝一次、之後自動生效」。
