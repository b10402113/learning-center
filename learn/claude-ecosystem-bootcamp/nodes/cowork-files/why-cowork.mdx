# 為什麼要用 Cowork：把工作交出去，而不是一直對話

## Learning goal

能說出 Cowork 與 Chat 的差別，判斷哪些任務該交給 Cowork，並認得它的核心能力（資料夾存取、排程、sub-agents、dispatch、瀏覽器自動化）。

## Lesson

Chat 幫你想，Cowork 幫你做。Chat 碰不到本機檔案系統，也撐不住長時間的多步驟任務；Cowork 是桌面應用，直接連上你指定的資料夾，讀寫檔案、產出真實的成品。它身上有五樣工具：資料夾存取、排程任務、sub-agents、dispatch 與瀏覽器自動化。選擇的判準是「手動做會超過 30 分鐘、又牽涉檔案或資訊蒐集的任務就交給它」，多步驟工作用 Opus 或 Sonnet 較穩。
