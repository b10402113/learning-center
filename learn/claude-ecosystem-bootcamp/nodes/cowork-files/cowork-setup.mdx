# 開始前的設定：工作資料夾與全域指令

## Learning goal

能開啟 Dispatch、指定預設工作資料夾，並寫出一段讓 Cowork 先問清楚、先給計畫、命名清楚、刪除前先問過的全域指令。

## Lesson

交辦之前先立規矩：開啟 Dispatch、指定一個預設工作資料夾，把 Cowork 圈在安全範圍內；再寫一段全域指令，讓它先問清楚、先給計畫、命名清楚、刪除前先問過。其中「先給計畫」最關鍵，它把執行拆成「先規劃、你同意、再動手」兩段，讓你在它真正動作前有機會修正。這些規則設定一次，之後每個任務都自動套用。
