# 實戰二：把收據與發票彙整成 Excel 報表

## Learning goal

能讓 Cowork 掃描一整個資料夾的 PDF 與圖片收據，擷取日期、商家、金額、幣別與類別，產出依日期排序、含分類彙總與疑義標註的 Excel 報表。

## Lesson

把裝滿收據與發票的資料夾交給 Cowork，用一段指令講清楚要擷取哪五個欄位、輸出成什麼檔名的 Excel、怎麼排序、要不要彙總、遇到看不清的怎麼辦。它讀得懂圖片型的收據，會自己拆成掃描、擷取、報表多個階段自動跑完，還會主動標註看不清楚的金額或日期，把原本要好幾個小時的工作變成幾分鐘。
