# 實戰一：把一團亂的 Downloads 整理好

## Learning goal

能寫出一段整理 Downloads 的任務指令，讓 Cowork 分類檔案、重新命名、列出重複檔並在刪除前先問過，最後產出一份摘要。

## Lesson

整理 Downloads 分兩步：先請 Cowork 摘要資料夾裡有什麼，建立一張地圖；再下完整的任務指令，把分類方式、泛用檔名的處理、重複檔怎麼處理、要不要回報一次講清楚。因為有全域指令的「先給計畫」規則，它會先給你看計畫、等你同意才動手。這種本機檔案操作是 Chat 做不到的，只有 Cowork 能真的搬動你的檔案。
