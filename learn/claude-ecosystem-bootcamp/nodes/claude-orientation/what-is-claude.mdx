# Claude 是什麼：跟聊天機器人不一樣在哪

<LearningGoal>
能用自己的話說明 Claude 是什麼，並說出它跟一般聊天機器人的關鍵差別。
</LearningGoal>

## Lesson

Claude 是 Anthropic 開發的 AI 助理，以 Capable、Stable、Responsible 定位，差別在它與一般聊天機器人的上下文記憶、任務範圍、輸入輸出、推理方式與工具整合。
