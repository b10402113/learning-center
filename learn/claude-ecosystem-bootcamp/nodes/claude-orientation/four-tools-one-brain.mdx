# 四種工具、同一顆大腦：Chat、Cowork、Code、Design

<LearningGoal>
能為一個具體任務挑出正確的工具（Chat / Cowork / Code / Design），並說明為什麼。
</LearningGoal>

## Lesson

Claude 有四種工具但共用同一顆智慧：Chat 是書桌、Cowork 是工作坊、Code 是機房、Design 是創作工作室，選工具看它需不需要碰你的檔案、跑你的機器或產出視覺成品。
