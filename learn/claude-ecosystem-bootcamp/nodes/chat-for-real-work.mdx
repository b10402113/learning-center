# 用 Chat 做真實工作

## Learning goal

能判斷哪些任務該交給 Chat，並用它完成寫作、解釋、腦力激盪與快速分析。

## Steps

1. [[learn/claude-ecosystem-bootcamp/nodes/chat-for-real-work/chat-desktop-surface|Chat 的完整版在桌面 App：web 版少了什麼]] — 認清 Chat 的完整能力在桌面 App，web 版只是基本款（deep）
2. [[learn/claude-ecosystem-bootcamp/nodes/chat-for-real-work/chat-strengths|Claude Chat 是什麼、它特別強在哪]] — 對話式介面，以及寫作、長文件、逐步拆解三個強項（deep，after step 1）
3. [[learn/claude-ecosystem-bootcamp/nodes/chat-for-real-work/chat-use-cases|六種最適合交給 Chat 的任務]] — 六類用途與各自的操作重點（deep，after step 2）
4. [[learn/claude-ecosystem-bootcamp/nodes/chat-for-real-work/chat-limits|Chat 的界線：什麼時候該改找 Cowork 或 Code]] — 三個限制，以及換工具的時機（deep，after step 3）

## Lesson

這個節點只回答一件事：什麼時候該找 Chat。它把「Claude 是聊天機器人」的舊印象，換成「把對的任務交給對的工具」。四步依序拆開：先確認 Chat 的完整版住在桌面 App，知道要去哪裡用它；再看清楚 Chat 的體質——它是一個對話式的思考夥伴，最強的是寫作、讀懂長文件，以及把複雜問題一步步拆開；接著把六種最常交給它的任務（寫作編輯、解釋、腦力激盪、快速分析、研究問答、一次性草稿）逐一講清楚；最後畫出它的界線——不碰本機檔案、不排程、不代你操作電腦，這三件事要交給 Cowork 與 Code。

四步走完，你拿到的不只是「會用 Chat」，而是判斷力：看到一個任務，你能馬上決定它是 Chat 的活，還是該換工具。後面幾個節點（Cowork、Projects、Skill）都建立在這個判斷之上。
