# 選對模型：Haiku、Sonnet、Opus 差在哪、什麼時候用哪個

## Learning goal

能說出 Haiku、Sonnet、Opus 各自適合什麼任務，並依「日常或高風險」選對模型。

## Lesson

Claude 底下是一個模型家族，不是單一顆模型：Haiku 最快最輕，適合簡單、大量、重複的雜事；Sonnet 是日常預設（目前主力 Sonnet 4.6，擁有 100 萬 token 上下文）；Opus 4.8 最強但慢又貴，留給高風險難題。選擇原則是日常用 Sonnet、重要用 Opus、雜事用 Haiku；再往上的 Mythos 與 Faber 5 因出口管制目前停售。
