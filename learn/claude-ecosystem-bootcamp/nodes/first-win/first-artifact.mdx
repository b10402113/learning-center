# 第一個 Artifact：用一句話讓 Claude 做出可互動的工具

## Learning goal

能寫出一個 artifact prompt，讓 Claude 在側邊面板生出可互動、可分享的工具。

## Lesson

Artifact 是 Claude 在對話旁邊開一個獨立面板、當場替你做出來的成品，可以互動、下載與分享。寫 artifact prompt 時把「是什麼、輸入什麼、輸出什麼」講清楚；Claude 通常先在對話裡用 inline visualizer 內嵌畫出來讓你確認，滿意後說一句「regenerate this as an artifact」，就轉成側邊面板裡的獨立成品，之後還能下載成 HTML 或發布取得分享連結。
