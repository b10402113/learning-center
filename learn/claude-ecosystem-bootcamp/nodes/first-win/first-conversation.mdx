# 第一次對話：一句 prompt 到語音、搜尋、看圖與延伸思考

## Learning goal

能完成一次包含具體 prompt、語音、網路搜尋、看圖與延伸思考的對話。

## Lesson

一次好用的對話看兩件事：把 prompt 講具體（交代對象與目的、你的身分、語氣、長度），並依任務選對工具。語音輸入把話轉成文字，語音模式是免持對談但更耗用量；網路搜尋在問題涉及最新資訊時要打開；vision 讓 Claude 讀圖片裡的收據、截圖與手寫筆記；延伸思考在答案錯了有真實後果時開啟，effort 高低對應想得多深與燒得多快。
