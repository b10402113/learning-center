# 動手開一個 Chat 專案

<LearningGoal>
能照著步驟建立一個範圍明確的 Chat 專案：寫好自訂指令、把兩個參考檔案放進知識庫，並用一句話在專案裡直接下新需求。
</LearningGoal>

## Lesson

開一個範圍明確的 Chat 專案：建立專案並寫好自訂指令、用連接器（Firecrawl）爬網站產出品牌指南、用研究模式設計課程結構，最後把兩份文件放進知識庫，之後就能用一句話直接下新需求。
