# 「專案」是什麼：把重複的背景一次講清楚

<LearningGoal>
能說明專案是什麼、由哪三個部分組成，並用「工作會重複、常重講背景、成果取決於你的情境」三條規則判斷何時該開一個專案，以及為什麼一次只做一件事。
</LearningGoal>

## Lesson

專案是會記住背景的專屬工作空間，由自訂指令、檔案／知識庫、對話歷史三個部分組成；當工作會重複、你常重講背景，或成果取決於 Claude 懂不懂你的情境時就該開一個，並謹守「一個專案，只做一件事」。
