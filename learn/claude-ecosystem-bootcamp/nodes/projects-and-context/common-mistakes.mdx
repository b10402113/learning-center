# 五個常見錯誤與修法

<LearningGoal>
能認出專案最常見的五個錯誤（範圍太廣、檔案太大、檔案命名混亂、該用 skill 卻開專案、把 Chat 專案當 Cowork 專案用），並說出各自的修法。
</LearningGoal>

## Lesson

專案最常見的五個錯誤是範圍太廣、上傳檔案太大、檔案命名混亂、該用 skill 卻開專案，以及把 Chat 專案當 Cowork 專案用；各自對應的修法是拆成單一任務專案、修剪檔案、用清楚檔名與 CSV、改用可帶著跑的 skill，以及分清「記得脈絡」與「動手做檔案」的定位。
