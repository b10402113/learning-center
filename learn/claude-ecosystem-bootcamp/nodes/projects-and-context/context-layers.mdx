# 三層 context 與覆蓋規則

<LearningGoal>
能畫出 Cowork 的 context 分層（global 指令、專案 claude.md、子資料夾 claude.md、參考檔案、你的提示），說明衝突時由「越具體的那一層」勝出，並用一句測試提示檢查 context 有沒有生效。
</LearningGoal>

## Lesson

Cowork 的 context 是一層一層疊起來的：global 指令、專案 claude.md、子資料夾 claude.md、資料夾內參考檔案、你當下的提示，衝突時越具體的那一層勝出；只寫「Claude 不講就會做錯的事」，並用「你知道我在這個專案裡是怎麼工作的嗎？」測試它有沒有生效。
