# Cowork 專案：會動手的專案

<LearningGoal>
能說出 Cowork 專案和 Chat 專案差在哪裡、它多出哪四樣東西，以及建立 Cowork 專案的三種方式。
</LearningGoal>

## Lesson

Cowork 專案是能讀寫本機檔案的桌面代理，比 Chat 專案多出持久工作空間、自訂指令、範圍化記憶與排程任務，並可用從零開始、從 Claude chat 匯入、包在既有資料夾外三種方式建立；開好後先用「讀完所有檔案並回報」讓它自我報到。
