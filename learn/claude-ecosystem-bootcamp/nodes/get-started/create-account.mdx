<LearningGoal>
能在 claude.ai 用 Google 帳號或 Email 建立 Claude 帳號並登入，並說出登入後聊天介面上看得到的主要入口。
</LearningGoal>

## Lesson

Claude 的入口是 claude.ai，你可以用 Google 或 email 建立帳號、五分鐘內登入；登入後看到的是分成對話區與左側側邊欄的聊天介面，而免費方案看不到 Claude Code、Cowork、Design 這幾個付費功能。
