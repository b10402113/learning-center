<LearningGoal>
能分辨 Web、Desktop、Mobile 三種 Claude 介面的差別，並判斷自己的工作流程該用哪一種，尤其是哪些功能一定要用桌面版才能跑。
</LearningGoal>

## Lesson

Claude 有 Web、Desktop、Mobile 三種入口；只要任務會碰到電腦裡的真實檔案或程式（例如 Cowork 與部分 Claude Code 任務），就一定得用桌面版，因為瀏覽器碰不到你的檔案系統。
