# Skill 是什麼：把「你怎麼做事」存成一份檔案

<LearningGoal>
能說明 skill 是什麼、為什麼需要它，並說出 skill 與專案的分工：專案給背景、skill 給做法。
</LearningGoal>

## Lesson

Skill 是一份可被自動觸發的指令包，把「怎麼做一件事」寫成 Claude 看得懂的檔案；它由名稱、描述（觸發器）與做法規則組成，底層是含 skill.md 的資料夾，和專案互補：專案記背景，skill 記做法，適合反覆發生且要求一致的工作。
