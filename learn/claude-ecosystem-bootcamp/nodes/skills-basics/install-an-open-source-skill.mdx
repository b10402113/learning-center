# 安裝一個社群 skill 來用（以 Humanizer 為例）

<LearningGoal>
能從 GitHub 取得一個開源 skill 的 skill.md，透過 Customize → Skills → Create skill 上傳並啟用，再用 slash command 或自然語言觸發它。
</LearningGoal>

## Lesson

從 GitHub 取得開源 skill 的單一 skill.md（先讀再裝），到 Customize → Skills → Create skill 上傳並啟用，之後用 /humanizer 這種 slash command 處理既有文字，或用「humanize it」這類自然語言邊生成邊改。
