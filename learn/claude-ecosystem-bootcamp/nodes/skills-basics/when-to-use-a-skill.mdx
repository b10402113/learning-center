# 何時該用 skill，而非每次重打提示詞

<LearningGoal>
能用「重複性、一致性、跨專案」三條判準，決定一件事該隨手打一段提示詞、開一個專案，還是做成一個 skill。
</LearningGoal>

## Lesson

用「重複性、一致性、跨專案」三條判準決定工具：三者都成立就做成 skill，只缺背景資料就開專案，只做一次或還在摸索就直接打提示詞，要接外部工具就用 connector。專案跟著場合走，skill 跟著你走。
