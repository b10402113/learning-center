# 第一次對話與第一個 Artifact

## Learning goal

能完成一次包含語音、網路搜尋、看圖與延伸思考的對話，並用一句話讓 Claude 生出一個可用的 artifact。

## Steps

1. [[learn/claude-ecosystem-bootcamp/nodes/first-win/model-selection|選對模型：Haiku、Sonnet、Opus 差在哪、什麼時候用哪個]] — 認識模型家族與 Haiku / Sonnet / Opus 的選擇時機（deep）
2. [[learn/claude-ecosystem-bootcamp/nodes/first-win/first-conversation|第一次對話：一句 prompt 到語音、搜尋、看圖與延伸思考]] — 用具體 prompt 加上四種對話能力跑完一次真實互動（deep，after step 1）
3. [[learn/claude-ecosystem-bootcamp/nodes/first-win/first-artifact|第一個 Artifact：用一句話讓 Claude 做出可互動的工具]] — 把需求寫成 artifact prompt，生出可互動、可分享的成品（deep，after step 2）

## Lesson

這個節點是「從會聊天」跨到「會做出東西」的那一步。拆成三步，是因為背後有三件不同的事要先後搞定：先知道要用哪顆引擎，才不會用貴的模型跑雜事、或用便宜的模型做高風險決定；接著親手跑完一次真正的對話，把 prompt 加上語音、網路搜尋、看圖與延伸思考這幾種輸入方式都用過一遍；最後把對話升級成 artifact——Claude 不再只是回你一段文字，而是在旁邊開一個面板，當場做出一個可互動、能下載、能分享的工具。

三步都走完，你會拿到兩個具體成果：一次「感覺 Claude 真的在幫我做事」的對話，以及一個屬於自己的小工具。這也是整個 bootcamp 反覆回來用的基本功，後面的 Projects、Skills、Connectors 都建立在「你已經知道怎麼把需求講清楚、怎麼讓 Claude 產出東西」之上。
