# Cowork 接手本機檔案

## Learning goal

能讓 Cowork 接手本機資料夾，完成整理 Downloads 與把收據彙整成 Excel 報表這類多步驟任務。

## Steps

1. [[learn/claude-ecosystem-bootcamp/nodes/cowork-files/why-cowork|為什麼要用 Cowork：把工作交出去，而不是一直對話]] — 分清 Chat 與 Cowork，判斷什麼任務該交出去（deep）
2. [[learn/claude-ecosystem-bootcamp/nodes/cowork-files/cowork-setup|開始前的設定：工作資料夾與全域指令]] — 開啟 Dispatch、指定工作資料夾、寫出全域指令（deep，after step 1）
3. [[learn/claude-ecosystem-bootcamp/nodes/cowork-files/organize-downloads|實戰一：把一團亂的 Downloads 整理好]] — 用一段任務指令完成分類、改名、去重與摘要（deep，after step 2）
4. [[learn/claude-ecosystem-bootcamp/nodes/cowork-files/receipts-to-expense-report|實戰二：把收據與發票彙整成 Excel 報表]] — 掃描收據、擷取欄位、產出含彙總與標註的報表（deep，after step 3）

## Lesson

前面幾節你都在「跟 Claude 對話」：你問一句、它回一段，答案再怎麼好，最後還是得由你複製貼上、自己動手。這個節點要把角色換掉——你從「開車的人」變成「交辦事情的人」，把一整個資料夾交給 Claude，讓它自己規劃步驟、動手做，最後把做好的檔案放回你的電腦。

Cowork 就是這台「代辦機器」。它能直接連上你指定的本機資料夾，讀取裡面的檔案、產生新的檔案、把東西搬來搬去，而不只是回你一段文字。這也是它和 Chat 最根本的分界：Chat 幫你想，Cowork 幫你做。走完這個節點，你會用兩個真實情境把它跑過一遍——先把一團亂的 Downloads 資料夾整理乾淨，再把散落的收據與發票變成一份帶彙總的 Excel 報表。

四步的安排是有原因的。第一步先建立心智模型：知道 Chat 的天花板在哪、什麼任務該改交給 Cowork，你才不會拿錯工具。第二步把環境準備好：開啟 Dispatch、指定工作資料夾、寫一段全域指令，讓 Claude 動手前先問清楚、先給計畫、刪東西前先問過。有了這層安全網，第三步與第四步才是把工作真的交出去——先做檔案整理這種「看得到成果」的任務，再做收據轉報表這種「省下好幾小時」的高價值任務。這套「先設定、再交辦」的節奏，也是後面所有 Cowork 專案都會沿用的基本動作。
