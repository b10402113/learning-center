# Claude Chat 是什麼、它特別強在哪

## Learning goal

能說明 Chat 是對話式任務的介面，並指出寫作、長文件理解與逐步拆解三個核心強項。

## Lesson

Chat 是你處理對話式任務的介面：打字、回應、你來我往。它的三個核心強項是寫作（跟得上語氣、產出自然）、理解長文件（長上下文讀完也不迷失）、逐步拆解複雜問題。定位是日常思考夥伴——你帶問題來，它帶答案來；也因為本質是對話，它給的是答案而非替你動手的結果。
