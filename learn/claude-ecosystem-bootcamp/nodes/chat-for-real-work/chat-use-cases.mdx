# 六種最適合交給 Chat 的任務

## Learning goal

能用寫作編輯、解釋、腦力激盪、快速分析、研究問答、一次性草稿這六類，判斷什麼任務交給 Chat。

## Lesson

六類最適合交給 Chat 的任務：寫作與編輯、解釋複雜的東西、腦力激盪、快速分析、研究與問答（要開網路搜尋）、一次性草稿。共同判準是「你需要想、寫、讀，產出的是文字或判斷」，而不是要電腦替你動手。
