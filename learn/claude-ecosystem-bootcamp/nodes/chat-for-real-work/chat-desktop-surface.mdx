# Chat 的完整版在桌面 App：web 版少了什麼

## Learning goal

能說明為什麼要從 Claude 桌面應用開始，並指出 web 版缺少的本機檔案、排程與背景自動化能力。

## Lesson

web 版是基本款：打開、聊天、拿答案，每次對話各自獨立，也碰不到本機資源。完整版在桌面 App，它把 Chat、Cowork、Code 收在同一個地方，並解鎖存取本機檔案、設定排程、背景自動化與串接本機工具；免費、Mac 與 Windows 都支援，約五分鐘裝好。從這個節點起都在桌面 App 操作。
