# Chat 的界線：什麼時候該改找 Cowork 或 Code

## Learning goal

能指出 Chat 的三個限制，並在需要碰本機檔案、排程或代操作電腦時改找 Cowork 或 Code。

## Lesson

Chat 的三條界線：不存取本機檔案、不照排程自動執行、不在你電腦上代你操作——它是對話工具，不是替你動手的工作工具。越界就換工具：接手本機資料夾、設定排程、執行多步驟電腦工作找 Cowork；讀懂整個專案、跑程式、改多個檔案找 Code。實用判準：手動超過三十分鐘又牽涉檔案或資訊彙整，通常不是 Chat 的活。
