# 註冊、選方案、登入三種介面

## Learning goal

能建立 Claude 帳號、依用量選對 Free / Pro / Max 方案，並在 web、desktop、mobile 任一介面登入開始使用。

## Steps

1. [[learn/claude-ecosystem-bootcamp/nodes/get-started/create-account|建立帳號：用 Google 或 Email 登入]] — 在 claude.ai 開好帳號，認得登入後看到的介面
2. [[learn/claude-ecosystem-bootcamp/nodes/get-started/choose-your-plan|選方案：Free、Pro、Max 差在哪]] — 看懂四種方案的價格、用量與解鎖的功能，選出適合自己的（after step 1）
3. [[learn/claude-ecosystem-bootcamp/nodes/get-started/pick-your-surface|選介面：Web、Desktop、Mobile 怎麼挑]] — 分清楚哪些功能只有桌面版才跑得動，替自己的工作流程選對入口（after steps 1–2）

## Lesson

把 Claude 用起來的第一步，不是學怎麼下指令，而是先把自己「安頓好」：開一個帳號、決定要不要付費、然後在對的裝置上登入。這三件事看起來瑣碎，卻決定了後面幾十節課你能不能用得到那些功能。有些功能是付了錢才出現，有些是裝了桌面版才跑得動。

這個節點就走完這條開通流程。先建立帳號，認得登入後那個乾淨的聊天介面；再攤開 Free、Pro、Max、Max 20x 四種方案的價格與用量，用「我一個禮拜大概用幾次、需不需要 Claude Code 或 Cowork」來做決定；最後分辨 Web、Desktop、Mobile 三種介面的差別，替自己的工作流程選對入口。走完之後，你手上會有一個可以立刻開始用的 Claude，而且知道自己為什麼用這個方案、這個介面。
