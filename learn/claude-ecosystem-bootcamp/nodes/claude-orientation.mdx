# Claude 是什麼、生態系長怎樣

## Learning goal

能用自己的話說明 Claude 是什麼、它與聊天機器人的差別，以及 Chat / Cowork / Code / Design 四種工具各在解決什麼問題。

## Steps

1. [[learn/claude-ecosystem-bootcamp/nodes/claude-orientation/ai-is-infrastructure|AI 已經是基礎設施：你站在哪一層]] — 用 91% 這個數字與三層產業，看清 AI 的位置與自己的急迫性
2. [[learn/claude-ecosystem-bootcamp/nodes/claude-orientation/what-is-claude|Claude 是什麼：跟聊天機器人不一樣在哪]] — Capable / Stable / Responsible 三個字，加上六個對照面向（after step 1）
3. [[learn/claude-ecosystem-bootcamp/nodes/claude-orientation/four-tools-one-brain|四種工具、同一顆大腦：Chat、Cowork、Code、Design]] — 同一顆智慧、四種裝備，為每個任務選對工具（after step 2）
4. [[learn/claude-ecosystem-bootcamp/nodes/claude-orientation/your-learning-map|你的學習地圖：四級 bootcamp 會把你帶到哪]] — 從 Fundamental 到自建 AI 系統的路線，以及 Level 1 的終點（after step 3）

## Lesson

這門課要教你的，不是「怎麼跟 Claude 聊天」，而是「怎麼用 Claude 把工作做出來」。所以在打開對話框之前，得先花一點時間看清楚局勢：AI 在 2026 年已經不是新奇玩具，它像電力或 Wi-Fi 一樣，安靜地跑在企業運作的底層。你不需要成為 AI 工程師，但要先知道自己站在這張地圖的哪裡。

這個節點的四步，依序回答四個問題。AI 現在到底走到哪一步，你所在的行業有多急？Claude 是什麼，它跟那些「您好，需要什麼協助」的客服機器人差在哪？它有哪四種工具，什麼任務該交給哪一種？以及往前看，這四級 bootcamp 會把你帶到什麼地方？這四題答得出來，你對整個生態系就有了骨架，後面每一課都只是往這根骨架上掛細節。

走完之後，你手上會有三樣東西：一個判斷急迫性的框架、一套挑工具的直覺，以及知道每一步在整條路上的位置。這三樣不會直接讓你做出成果，但會讓你不會在錯的地方花力氣。
