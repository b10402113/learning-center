目標層級 (Goal Hierarchy)

為什麼「減十公斤」「臥推一百二十公斤」這種明確的目標，常常最後還是失敗？——把「為什麼」拆成每天能執行的「做什麼」。

#問題陳述

為什麼「減十公斤」「臥推一百二十公斤」這種明確的目標，常常最後還是失敗？

#為何重要

一個精確的目標如果不連到「為什麼」，就撐不過低潮期——你會在看不到成果時懷疑自己為什麼要繼續。

#如何運作

作者引介一套三層的目標結構（來自一份 2018 年伯恩大學的研究）：

  • 核心目標（core goal）：你「為什麼」要練——想變健康、想更有自信、想當孩子的榜樣。它最模糊，但提供最持久的動力。
  • 過程目標（process goal）：通往核心目標的階段里程碑，例如「力量明顯進步」「體脂降一截」。
  • 子目標（sub-goal）：最底下、最可執行的具體行動，例如「一週練四次」「每天吃足蛋白質」。

三層串在一起：子目標告訴你今天做什麼，過程目標告訴你這陣子往哪走，核心目標告訴你為什麼要撐下去。

白話來說

先想清楚「為什麼」，再把它拆成「下一步做什麼」。只盯著數字（結果）會焦慮，盯著每天能做的小事（過程）才走得遠。

類比

像爬一座山：山頂是核心目標（為什麼要爬），半山腰的營地是過程目標（階段進度），你腳下踩的每一塊石頭是子目標（今天的動作）。

#實際運用

寫下你自己的三層：為什麼想增肌和變壯（核心目標）、這個月想推進哪個數字（過程目標）、今天和這週具體做哪幾件事（子目標）。每天只對「子目標」負責，別每天秤體重、查成績。

#測驗

Q1. 核心目標、過程目標、子目標三者的關係是什麼？

核心目標回答「為什麼」，過程目標是通往它的階段里程碑，子目標是最底層、每天可執行的具體行動，三者串成一條由上到下的鏈。

Q2. 為什麼「只盯結果」的目標容易失敗？

因為結果受你控制不了的因素影響，沒達成就會挫敗；而子目標是你能控制的具體行動，每完成一件都算一次成功，心態才能撐得久。

Q3. 某人目標是「三個月後深蹲一百公斤」，你怎麼幫他改寫成三層？

核心目標是他為什麼想變強；過程目標是每四週推進一次重量的小里程碑；子目標是「本週練腿兩次、每次做足有效組數、記錄每組重量」。每天只對子目標負責。
