# 型別：reference（查閱）

**用途**：讓讀者能快速找到準確資訊，確認某個項目的用途、用法與限制。

## 寫法

開頭用一行說明查閱對象與用途，並交代適用版本或範圍；無法確認時明確標示。

依穩定順序組織內容。同類項目使用相同欄位，例如：

| 項目 | 用途 | 可用值／型別 | 預設值 | 限制 |
| ---- | ---- | ------------ | ------ | ---- |

列齊本課範圍內、來源可確認的項目。區分「沒有預設值」「不適用」與「來源未說明」，不要把缺少資訊當成沒有此功能。

描述保持簡短，但要足以理解。必要術語在首次出現時簡要解釋；不能只用另一個陌生名詞替代。

附最小使用範例，指出必要輸入與預期結果。容易混淆的選項，可加一句差異說明；深入原理與完整操作連到其他課程。

結尾連到存在的 procedure 與 concept 課程，分別標明「如何操作」與「理解原理」。

**避免**：未限定範圍就宣稱完整、照抄術語卻不說用途、加入無來源的建議，或為追求中性而刪掉必要解釋。
