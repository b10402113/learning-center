_

Resources

AI morning briefing prompt

Be intentional about how you learn. Set up a daily briefing instead of doom-scrolling.

Tip: Send this prompt to your agent to set up your learning system:

"""

I want you to be my AI learning assistant. Every morning, I want you to:

Find the top 3 AI developments from the last 24 hours (from X, YouTube, and news)

Summarize each in 2-3 sentences

Tell me which ones are relevant to my AI practice and why

Suggest one thing I should build or try based on what's new

My practice focuses on: [DESCRIBE YOUR NICHE] """

Book digest prompt

Read a book a day using summaries.

"""

Give me 3 book recommendations relevant to building an AI services business. For each, give the title, author, and a one-line hook. I'll pick one and you give me a full digest with key takeaways and how it applies to my practice. Do this daily

"""

Chrome extension for YouTube summaries
(see file at bottom of page)

A Chrome extension that adds a Gemini button to any YouTube video. One click copies a summary prompt to your clipboard so you can get a digest instead of watching the full 20-minute video.

How to install

Download the zip file attached below

Unzip it to a folder on your computer

Open Chrome and go to chrome://extensions

Turn on "Developer mode" (toggle in the top right)

Click "Load unpacked" and select the unzipped folder
