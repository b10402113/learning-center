# YouTube Gemini Summarizer — Chrome Extension

Adds a Gemini button to YouTube videos for quick summarization.

## How to Install

1. Download and unzip this folder
2. Open Chrome and go to `chrome://extensions`
3. Turn on **Developer mode** (toggle in the top-right corner)
4. Click **Load unpacked**
5. Select the unzipped folder (the one containing `manifest.json`)
6. Done — go to any YouTube video and you'll see the Gemini button

## How to Use

1. Open any YouTube video
2. Click the **Gemini** button near the video
3. Gemini opens with a prompt to summarize the video for you

## Notes

- This extension does NOT collect any data
- It only runs on YouTube pages
- You need a Google account with access to Gemini
