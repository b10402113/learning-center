2️⃣ The Integrate Phase

Jay covers the second phase of delivery: getting your solution into the client's world.

This is often the hardest part because you're working with real systems and live data.

He also covers getting access, training before handoff, and credential security.

_

What You'll Learn

  • Three integration models: managed service, implementation, build-operate-transfer

  • How to get client access via a quick call instead of insecure email

  • Why proper handoff training protects your reputation and earns referrals

    Handover Packaging Prompt
    When it's time to hand over your build to a client, package it cleanly.

    Tip: Send this prompt to your agent to prepare a handover package:

    """
    I want to hand this project over to a client. Can you:

    Organize all files into a clean folder structure

    Remove any API keys or credentials from the code

    Write a README with instructions for their team on how to operate this automation

    Package everything into a zip file

    Let me know the steps you'll take so I can guide you through the setup.
    """

    Terms Used

  • BOT (Build, Operate, Transfer) — An integration model where you build and run the system, then hand everything over to the client

  • Managed service (Done-For-You) — You run the system on an ongoing basis and the client pays a retainer

  • .env file — A text file that stores API keys and passwords securely, with built-in protections that prevent accidental sharing
