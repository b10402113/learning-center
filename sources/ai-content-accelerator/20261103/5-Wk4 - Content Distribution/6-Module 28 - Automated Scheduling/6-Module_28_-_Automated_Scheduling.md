## 為什麼你需要排程工具

我們來談**自動排程**跟 **cross posting**。

這堂課我會帶你走過我們實際在用的工具，用它在好幾個社群平台排程貼文，包括我前面提過的所有大平台。

如果你照前面幾個模組的步驟走過，你就知道：如果你要**手動**一個一個發到每個平台，那真的很花時間。

不只是每一份內容都要上傳，你還得把 caption **複製貼上**，而且每一個平台都要**一個一個手動做**——即使你發的是**一模一樣**的內容。

所以排程工具的價值就在這裡：**它把這件差事從你身上拿走**。

## Blotato：我們在 RoboNuggets 用的那一個

我們在 **RoboNuggets** 用的工具叫 **Blotato**。

我們大概是最早的一批使用者，因為它是 **Sabrina** 開發的，她是我們社群裡認識很久的朋友。她還給我們這裡所有成員一個**很不錯的折扣**，如果你還沒有 Blotato 帳號，可以從下面拿。

Blotato 基本上——我等一下會示範——讓你**拿一支影片，發到九個社群平台**，時間由你挑。

它很吸引人的一點是，Sabrina 在這件事上做得很好：**它讓你的 agent 可以去操作它**。

所以如果你用的是 **Codex** 或 **Claude Code**，你只要跟你的 agent 說：我要這些東西今天幾點出去、要送哪些影片或 captions，它就能幫你把這些內容全部排好，你在行事曆上就看得見。

## 它可以連到哪九個平台

如果你好奇，Blotato 能連接的平台是這九個：

- **Instagram**
- **Facebook**

## 替代方案一：Postiz，開源但門檻高

先講清楚，Blotato **不是**唯一做這件事的工具。

我只是因為這是我們在用的，所以這堂課推薦它、帶你走一遍。但業界另一個很有名的選項叫 **Postiz**，它有名的原因是：**它是開源的**。

所以它**免費**，但設定起來**久很多、複雜很多**。原因基本上就兩個。

第一個：你要用 Postiz，得**懂一點技術**。你要知道怎麼架自己的 **Docker server**，還要知道怎麼架自己的資料庫，例如 **Postgres**。如果這在你能力範圍內，或者你想學，那 Postiz 是可以去看看的。

第二個原因更重要一點：當你把 Postiz 的開源碼複製下來，本質上你是在**做一個自己的應用程式**——你自己的「Blotato」。而這個你自己做的排程 App，要能真的自動發到 TikTok、Instagram 或其他平台，你得走過它們的**審核流程（audit process）**。那有自己的要求，有時候要**好幾週**才會通過。

所以如果你真的很想走這條路——也許你現在的狀況就是**沒有預算**投資像 Blotato 這樣的排程工具——那這對你來說是個選項。但決定去看 Postiz 之前，請記得這些**前提跟代價**。

## 替代方案二：先手動發

當然，第三個選項就是：**先手動發**。

至少發到你自己覺得「投資一個排程工具是划算的」那個時間點為止。這完全還在你的選項裡。

## /post 這個 skill：我怎麼一次排多篇

話說回來，這堂課我的任務，就是示範我怎麼運作、怎麼**一次排好多篇貼文**。

我用的方式是一個叫 **/post** 的 skill。同樣地，你可以從下面拿到一個**基礎版本**，自己再調整。

在這個 skill 裡面，我已經把規則設好了：我要我的貼文在**哪些時間**出去。關於我排這些時間背後的邏輯，我後面會再講。重點是，你當然可以改成你喜歡的。

- 你想**一天發五次**，完全可以。
- 你想**一天只發一次**，也完全可以。

你可以直接改這個 skill，或者叫你的 agent 依你的需求去變化。

預設上，這個 **/post** 會連到 **Blotato**，而 Blotato 已經連著我不同的帳號，排程就由我的 agent 去處理。

## 一次性設定：API key 跟 account ID

跟很多這類工具一樣，一開始通常需要**一點初始設定**。設定完之後，你其實就不需要再打開 Blotato 的 UI 了，因為你的 agent 會幫你做掉。

但要設定那一次，你當然會需要：

1. **一個 Blotato 帳號**。
2. **你的 API key** — 如果你照下面的安裝提示、還有 /post 這個 skill 走，它會告訴你去哪裡找。基本上就在 Blotato 的**設定**裡面。
3. **把帳號連接一次**。

連帳號長什麼樣子？你可以看到，在我們其中一個 Blotato 帳號裡——當然我不能在這邊秀出實際細節——設定好之後，你只要按最上面那顆按鈕去連接帳號，它會帶你到一個 **single sign-on** 頁面，讓你逐一授權你的帳號。

最後你會拿到一組 **account ID**，你的 agent 會跟你要這組 ID。你把 ID 給它，再加上你從設定裡拿到的 **API key**——這兩樣加起來，就等於給你的 agent 直接發文到這些平台的能力。

到那個時候，帳號都連好了，剩下就只是**叫你的 agent 幫你排程**而已。

而 /post 這個 skill 的存在意義，基本上就是把我們要給 Blotato（更精確地說，是給我們的 agent）的一堆指令**寫成程式碼**，把我們的偏好存起來：排程時間、要發到哪些帳號、要發到哪裡。

## 實戰演練：從 Rubric Editor 到七天排程

給你一個工作流程的模擬。

假設我用 **Rubric Editor** 來剪我的原始素材，就像前面模組示範的那樣。剪到我們滿意之後，你可以把它**匯出**、按下 **render all**，它就會把那些指令**複製到你的剪貼簿**。

當你在跟 agent 對話時，你就把那段指令貼給它，裡面就有你要的那些 reels 的所有細節。

假設我現在準備好用 **Blotato** 排程了。我只要打 **/post**。

如果我就這樣送出，它會用我的**預設值**。但假設我想給它一些指示，比如：

> 把這些 clips 從今天開始，一天一支，排到七天後，發到我平常發 shorts 的社群通路，也就是 **IG、YouTube Shorts、TikTok**。

這樣一來，你這 **7 支 clips** 就會自動被 render，並透過 Blotato 排程出去。

## 到 Blotato 檢查你的行事曆

現在示範一下：如果你想看排程行事曆，就到 Blotato 裡的 **calendar** 分頁。

你可以看到，每一天現在都已經有**三篇貼文**，分別排在 TikTok、YouTube Shorts、Instagram，就跟我們交代 agent 的一樣，一路排到接下來這七天。

如果你點進其中任何一篇，你也可以在這裡檢查每一則 **caption**。

## 想更精細控制？先看過再發

到這裡，其實**你要給 agent 多大的自由度，完全由你決定**。

因為前面那個例子裡，你有沒有注意到——我們**根本沒有先檢查**要跟著影片一起出去的 caption，對吧？

如果你想要更細緻的控制，你可以這樣做：

1. 把同一段從 **Rubric Editor** 來的指令貼進去，讓它把所有 clips 都 render 出來；或者如果你手上已經有 reels，就直接把你機器上那些 **MP4** 檔案指給你的 agent。
2. 這次**不要**直接用 /post 去排程，而是說：我想先在 **Rubric Scripts** 裡看過，這樣我們可以在發佈前檢查 captions。

這樣做的話，你會看到類似這樣的畫面：在 Rubric Scripts 裡，**video 分頁**已經被填好、影片已經在裡面了。你可以播放它、檢查你剛講的內容的**逐字稿**，還有要出去的 **caption**。

從這裡，如果你偏好更細的控制、想自己按按鈕，而不是全部叫 agent 幫你做，你可以：

- **停用**某些社群平台，或
- **增加**更多平台，看你需要什麼，只要跟你的 agent 說一聲。

整個 template 就會幫你填好。比如說，我們現在因為某個原因**只想排 TikTok**，那就這樣做。它會再把指令複製到你的剪貼簿，你就可以把它送給 **Claude**，或你用的任何 agent 平台。

## 核心概念：把偏好寫成 skill

所以這整件事的精髓就是這樣。

你真正需要的，就是一個 **skill**，讓你能**走捷徑**——本質上就是把你想要的指令包成一個快捷方式，這樣你的偏好就被存下來了：你要用這個排程工具發到哪裡、怎麼發。

順帶一提，Blotato 其實還有很多其他功能，我們會在比較進階的課裡談，例如 **auto-DM 自動化**，那個在 Instagram 上非常有效。但那超出這堂課的範圍。

## 發文時間到底重不重要？

不過有一件事我想聊一下：**排程時間**。

你可能會想：到底什麼時間才是對的？我希望我的內容在什麼時候被推出去？

在我看來，講到**一天的哪個時段**、或**一週的哪一天**發文，其實**沒有很多人想得那麼重要**。

說到底，如我一直在說的：真正重要的是那一份內容的**品質**，也就是它的**用處**。而且你應該**能發多少就發多少**，這樣才能快速迭代。

所以，我這裡時間設成 **9am、1pm、5pm**，唯一的理由就是：**那些時間我醒著**。

這樣如果發錯了——不管是我的 agent 還是我的疏失——我可以很快手動刪掉那則貼文，把它收回來。

## TikTok 的地區特性

還有一件事要提。

至少在 **TikTok** 上，我觀察到：它會**先把你的內容推給你所在的國家**。所以它是**非常地區性**的。

比如我一開始在 TikTok 的時候，最早看到我內容的人——尤其是新帳號——其實大多是**澳洲**的人。

所以這是你要注意的事。而這大概也是為什麼，你的排程時間**更該設在你醒著的時段**——這樣你才有辦法處理。

如果你想複製我的做法，可以採用這個策略。但就像我說的，**不要為這件事太焦慮**，因為你真正該追的北極星，是做出**有品質的內容**，而說到底那就是「有用」。

而你到達那個品質的方式，就是**大量出貨**，並且確保你邊做邊進步：試不同的 **hooks**、試不同的講法、試不同的說法、在鏡頭前隨著 reps 增加越來越**有自信**。

這樣你一定會走到那個點：人們追蹤你，是因為他們**信任你**，而且你講的東西對他們的產業**真的有用**。
