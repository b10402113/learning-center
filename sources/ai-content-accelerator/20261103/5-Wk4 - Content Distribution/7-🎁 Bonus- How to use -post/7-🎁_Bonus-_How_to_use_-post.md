## /post 到底在做什麼

嗨，這段我要帶你走一遍 **/post**。

用在什麼時候？就是你的影片做好了，你只想讓它**立刻出現在所有地方**的時候。

它基本上會把你的內容——不管是**一支影片**還是**多則貼文**——排程到 **Instagram、TikTok、YouTube Shorts 跟 Threads**，然後回給你一份你的內容**行事曆**。

## 底層是怎麼運作的

底層的運作是這樣：你的 agent 把影片送給 **Blotato**——一個已經連著你帳號的排程工具——由 **Blotato** 去執行發佈。

而 Blotato 其實也能發到**其他社群平台**，不只這四個。

## 設定：四步就好

設定的流程是這樣：

1. 從**課程頁面**下載 zip 檔。
2. 把**安裝提示（install prompt）**貼進你的 agent，它會一步一步帶你走。
3. 你需要一個 **Blotato 帳號**，如果還沒有，先去註冊一個。
4. 在 Blotato 裡**連接你的社群帳號**，然後**複製你的 API key**。

最後那一步有個小細節：請你的 agent **開一個安全檔案**，然後由你**自己**把 API key 貼進去。

## 發文前，先讓你點頭

設定好之後，你就只要打 **/post**，附上你的影片。

**在你核准之前，什麼都不會出去。** 你要核准兩件事：

- 每個平台要用的**文字（caption）**
- 它挑的**封面（cover）**

你說一聲 **go**，它就會把每一則貼文直接排進你的行事曆。

## 一個重要的差別：排程不等於已發佈

這裡要注意：**排程不等於已經發佈**。

要等到**連結打開**，那則貼文才算真的上線。

## 連結回來之後，可以做兩件事

接著，把那些連結送給你的 agent，你可以做兩件事：

1. **請它幫你排一整週** — 比如說一天三篇，這樣你的影片就會自己持續出去。
2. **請它把 /post 這個 skill 依你改過的地方優化** — 這樣它會隨著時間**學會你喜歡怎麼發**。

## 新帳號的注意事項

還有一件事要記得：如果某個帳號是**全新的**，尤其是在 **TikTok** 上，先**正常使用幾週**，再把它連進來。

這也是 **Blotato 官方自己的建議**。
