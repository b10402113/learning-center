## 現在最被問爆的主題

來談**自動剪輯**，這是目前內容創作圈被問最多的題目之一。

我不只要教你**用 agent 做自動剪輯的原理**，我還要給你一套軟體，另一套叫 **Rubric Editor** 的工具，讓你把工作流程渦輪增壓，真的做到**規模化剪片**。

## 先自己剪個一兩支

但在深入之前，我要再強調一次：**先自己動手剪幾支影片，永遠是好習慣**。你要先抓到**剪點（cut）**的手感，也要有自己剪過影片的經驗。

你不需要剪到 10 支、20 支，**第一支、第二支就夠了**。你可以去 TikTok 用它內建的剪輯器，再去 Instagram 用它的剪輯器。這不只讓你體驗剪片是什麼感覺，**它其實還會順便養你的帳號（warm up）**。

那個主題我留到下一支模組講，因為它很重要，特別是當你要為事業**開一個全新的帳號**來發內容的時候。

## Rubric Editor 怎麼裝

**Rubric Editor** 跟 Rubric Scripts 一樣，下面有連結可以下載，安裝一樣用附帶的 **install prompt**。

裝好之後，你會進到這個介面，它跑在**另一個 local host 網址**，也就是**跑在你自己的電腦上**，Claude 可以直接在 Chrome 裡把它打開來驅動。

## slash cut 怎麼用

它的用法是這樣：它附了一個 skill 叫 **slash cut**。

假設你已經錄好一段自己的素材——我就是——而且它是一個 **MKV** 檔。你呼叫那個 skill，這次我多給了它一點上下文，說明這段影片的內容是什麼。

其實你不一定每次都要給，因為現在很多模型已經很聰明，可以直接把每一支 reel 清楚切開。但**多給一點上下文，它第一次就切對的機率會高很多**。

如果你看那段 MKV，它就是我在上一課提到的：我對著 teleprompter 念，**全長大約 14 分鐘**，總共**八支 reels**。等於我只花了 14 分鐘，就錄完八支。

因為大部分流程都交給 Claude 自動化，所以只要跑**一個指令**，我就會拿到一份可以開始審的 Rubric Editor。

## 打開來長怎樣

先看輸出。畫面上現在有那**七支 reels**。

如果你用過 **Premiere** 之類的工具，很多快捷鍵你會很熟：

- 按住 **Ctrl** 可以在時間軸上**放大**
- 按住 **Shift** 可以**左右平移**瀏覽
- 按 **R**，或點這個原始素材，就可以只播**原始素材**

我播一次給你看，你可以聽到它把「我說 number one」那一段切掉了，因為那段不是正片。順帶一提，它播這麼快是因為我設在 **2.1 倍速**，你可以用 **S** 或 **D** 調快調慢。

這些功能是我照自己的工作方式內建的。你想改功能、改快捷鍵，完全隨你；想多加幾個面板，也隨你喜好。

## 它怎麼知道要剪哪裡

在示範我怎麼用 Rubric Editor 回饋給 Claude 之前，我想先講清楚一件事：**Claude 到底怎麼知道要從原始素材裡剪掉什麼？** 這很重要，特別是當你想教它「依照你講話的方式」判斷哪段留、哪段剪。

你呼叫 **slash cut**、把影片給 Claude 之後，背後其實發生兩件事。

1. **你透過檔案路徑，把原始錄影交給 Claude**，也就是那個 MKV 或 MP4。
2. **你的 agent 會把影片內容轉錄（transcribe）出來。**

第二步很關鍵。因為轉錄不只抓到你腳本裡的字，它還會替**每一個字加上時間戳記**。這就是 Claude 能知道「哪些字要留、哪些要剪、在影片的哪個位置」的原因。

## 轉錄工具有哪些

我自己用的是 **AssemblyAI**，但你不一定要用它。

- **免費方案：Whisper**，OpenAI 出的。你可以在 slash cut 裡設定，叫 agent 把預設從 AssemblyAI 換成 Whisper。**它免費，但轉錄慢很多。** 一支**一小時的影片大概要花 15 分鐘**轉錄，因為它是**跑在你的電腦上**，所以快慢取決於你 **CPU 的效能**。
- **AssemblyAI**：**一小時的影片只要 33 秒**。你可以想像，我剛剛那段 **14 分鐘**的素材，轉錄**不到 10 秒**就完成。
- **ElevenLabs**：如果你是訂閱戶，他們也有這個服務，叫 **Scribe**。速度跟 AssemblyAI 差不多，但**貴一點**。如果你本來就有 ElevenLabs 訂閱，我會建議就用它。

這幾個工具的做法都一樣，Claude 也會帶你：**打開 ElevenLabs 或 AssemblyAI 的網站，拿一組 API key，然後問 Claude 怎麼把 key 給它**，讓它連到你的帳號。

這樣一來，你的影片就會有**字級時間戳（word-level timestamps）**。你同時有「字」跟「字被說出來的時間」這兩組資料，接下來就交給 Claude 判斷**哪些段落留、哪些不留**。

## 預設規則是什麼

預設情況下——因為很多人講話就是這樣——如果開頭有**假開場（false start）**，**最後那一次 take 才是被保留的**。

這是 **slash cut** 內建的規則。但問題是，**每個人講話、溝通的方式都略有不同**。所以後面我會教你怎麼改，讓你可以微調 slash cut，隨著你愈用 Rubric Editor、愈用這個 skill，它會慢慢學會**哪些 take 該剪、哪些停頓該留**。

整個流程的最後一步，就是你的 agent 讀它剛剪好的成品，**上傳到 Rubric Editor 給你審**。

## 每個人都講得不一樣

就像我說的，有人停頓很多，有人一句話一直重來，有人講得飛快。

所以這裡最重要的一件事是：**你要把 agent 訓練成你的講話方式**，目標是每次你用 slash cut，它都直接給你你要的結果。做法就是**用 Rubric Editor 審你的 clips**。

我自己的習慣是：**一次把所有 clips 播完**，通常用 **2 倍速**聽，看它有沒有把**假開場**留下來。

舉個例子。假設它把這段剪掉了，但我其實需要它出現在正片裡，我就把這個 clip **拉長**。它會自動在這一小段上**留一則評論**，說明你想延長哪裡。

又比如這裡有一段明顯的停頓——你看，那裡沒有聲音——我只想抓這一段，就按 **C**，它會把 clip **切開**，然後我把它拖過去，跟我在其他剪輯軟體裡的做法一樣。這樣你就可以邊看邊改。

如果某個 clip 太長，就把它拖短，把不要的部分刪掉。

## 這就是強化學習

到這裡為止，它還比較偏**手動剪、手動審**。但重點是：**你愈用 Rubric Editor，你的 agent 就愈懂你的偏好。**

畫面上方有兩個開關：**teach your slash cut skill** 跟 **teach your slash animate skill**，後者我待會講。把開關打開，然後按 **copy comments for all clips**，它會把**所有 clips 上所有未結案的項目**全部複製起來。你直接貼給 Claude，裡面就帶著所有有用的資訊，Claude 馬上知道下一步要做什麼。

這比你自己打字跟 Claude 描述**精準得多**，也比你自己動手剪**快得多**。

老實說，一開始依你講話的方式，你可能會對 Claude 的剪法有點失望。但我跟你保證，**一旦你把它訓練好**，訓練到它懂你怎麼講、你想怎麼剪，它會走到一個境界：**幾乎每一次剪出來的 clips 都是對的**。

為什麼會這樣？因為這件事的本質，就是**強化學習（reinforcement learning）**。如果你混 AI 圈，應該聽過這個詞。你在 Rubric Editor 裡做的，就是一個**迷你版的強化學習**。

## 想要動畫的話

順帶提一下，如果你比較進階，想在影片裡加**動畫**，那是完全獨立的主題。我會加一個 **bonus 模組**讓你自己去看，因為我們之前拍過幾支影片講 **slash animate** 這個 skill，你可以從社群裡拿到。

它就是讓 Claude 幫你加動畫的工具，像我們最近影片裡那種效果。比如你剪好、排好原始素材之後，套上 **slash animate**，就能做出那種比「只有你一個人站在畫面上」更有動態感的 reels。

你當然不必從這裡開始。我看過很多創作者，一開始就是手機對著螢幕拍，然後只把不要的段落剪掉。但如果你想往更複雜的動畫走，就去看那些 bonus 模組。

## 輸出

等 clips 都剪好、Claude 也把你在 Rubric Editor 留的評論全部處理完，我通常就直接叫 Claude **render** 出來。

如果你想手動一點，這裡也有一個 **export** 按鈕，可以選不同**解析度**。這樣一來，所有粗活都交給 Claude，你就拿到好幾支 reels，可以直接拿去**分發、排程**——那是下週要談的。

## 如果你本來就有剪輯軟體

再提一件事。有些人進來時心裡已經有慣用的剪輯軟體，比如你是 **Adobe Premiere** 的使用者，或你在用 **Final Cut Pro**。你其實可以讓 **Claude Code 透過 MCP connector 去操作那些工具**。

如果你不知道 MCP connector 是什麼，下面我會連結一支教學，帶你了解。簡單說，它就是**加在 Claude Code 上的外掛**，讓它可以去驅動 Premiere Pro 這類軟體。

我自己就是這樣做的，特別是**長格式影片**。短影音我直接 render，但長格式我有時候會想在 **Premiere Pro** 裡自己審一遍。我用的那個 Premiere Pro connector 會放在下面。

如果你用的是 **DaVinci Resolve** 或 **Final Cut Pro**，同樣可以拿我們的 **search connectors** skill，去找目前最新的 connector。

好消息是，因為 AI agent 興起、需求又大，現在已經有很多**開源工具**出現，讓我們可以更順地把這些軟體接起來。

## 收尾

以上就是用 **Rubric Editor** 幫你做**自動剪輯**的方法。

等你把這些 skill 練順，你一定會走到一個狀態：**Claude 一次就把你的剪輯做好**，而且你有信心，即使只是**第一次 prompt**，你的 agent 也會做對。
