## 這支是快速導覽

嗨，這裡我用最快的速度帶你走一遍 **Rubric Scripts**：你的腳本被寫出來、被審過、準備進錄影的地方。

說穿了，它就是**一頁管好你所有腳本**，你不用再翻舊對話，去找那支你當初想錄的腳本。

## 開始的兩步

1. 把 **install prompt** 貼進你的 agent
2. 輸入 **slash rubric scripts**，頁面就打開了

## 把你的點子載進來

接著把你上週用 **slash latest** 跟 **slash outliers** 收集到的**shortlist** 載進去，或直接再跑一次那兩個 skill 也行。

你的 agent 會用 **slash script** skill，替每一個點子寫一份腳本，附上**三個 hook 選項**，那三個 hook 來自 **slash hooks**；整份腳本用的則是你的**語氣**，來自 **slash tone**。

每一份腳本進到頁面時，**hook 都會被標亮**，你一眼就能看出第一句話到底抓不抓人。

## 留評論，然後複製

如果哪一句話聽起來不像你，就把那段文字**反白**，在上面留一則評論，就像你在 Google Doc 裡那樣。

你還會看到一個**影片區**跟一個**頻道區**，那兩個我們會在內容分發的模組裡再回來講。

評論留完之後，把它們複製起來，丟給你的 agent。接下來你可以做兩件事。

## 兩件事

第一，**叫它照你的評論重寫腳本**。等某一份讀起來順了，就叫 agent 把它送到你錄影時會看的地方，比如你的 **Telegram**，或你自己的 **teleprompter**。另外，**不要等完美**，因為**量才是重點**。

第二，把 **Teach My Tone** 打開。它會用同一批評論去**修你的 slash tone skill**，所以之後每一份腳本都會再像你一點。

## 幾個小技巧

- **評論要具體。** 不要寫「這段好一點」，要寫「這個 hook 太長，砍成一行」。
- 或者更直接：**寫下你真正會怎麼講**，用你自己的話。
- **錄之前，每一份腳本都要出聲念過。** 如果你在哪一句卡住，那一句就是該改的地方。
