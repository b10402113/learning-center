Module 21 - Camera and Setup

You don't need a new camera to start. The one in your pocket is enough.

If you upgrade one thing, make it your audio, because people tune out if they can't hear you.

_

What You'll Learn

  • 💻 OBS, a free app that records your screen and camera, set up by your agent with you

  • 🔌 /search-connectors, to find a connector so your agent can drive OBS itself

  • 📃 A teleprompter, so you can read your script and still look at the viewer

    • _

    🚀 Recommended Action: set up what you have and record one clean take today.

    Your fifth piece will beat your first, and it won't be because of the camera.

    _

    Prompt to Send Your Agent

    Set up OBS with your agent: it starts with your audio and checks a test recording, so send this:

    """Help me set up OBS Studio so I can record my screen and my camera together. Go one step at a time, and wait for me after each one.

    1. Ask me, one at a time: am I on Windows or Mac, which camera and mic I'm using, and am I recording landscape (lessons on my computer) or vertical (shorts).

    2. Check if OBS is installed. If it isn't, install it from obsproject.com, or give me the link if you can't install apps.

    3. Check for a connector: run /search-connectors for OBS (or search for an OBS MCP server). If there's one that's still looked after, tell me what it can do and help me turn on the WebSocket server in OBS (Tools, WebSocket Server Settings), so you can control OBS yourself. If not, walk me through each click instead.

    4. Audio first: add my mic, have me talk for 10 seconds at my normal volume, and help me set the level so my voice sits in the upper yellow of the meter and only just touches the red when I'm loud. Mute any sound I don't need.

    5. Make two scenes: "Screen + camera" (my screen full size, my camera in a corner) and "Camera" (just me, full frame). Set the canvas to the shape I picked.

    6. Ask me which editing app I use, then set where my recordings save, in a format that app can open.

    7. Do a 30-second test recording. Check the file plays, has sound and has the right shape, and tell me in plain words what to fix.

    This is for recording only, so never start a stream."""

    Switch scenes with hotkeys: so you never have to stop recording to change the view, send this:

    """Set up hotkeys in OBS so I can switch views while I record, without stopping. Go one step at a time.

    1. Show me the scenes I have, and ask which views I want, for example: me large, my full screen, and a blank screen to hide what I'm doing.

    2. Make any scene that's missing. For the blank screen, use a plain black or white colour and mute my mic in that scene.

    3. Set a hotkey for each scene (for example Ctrl+Shift+1, 2 and 3), using keys no other app I use already takes.

    4. Make a vertical version of my main scene too, for shorts.

    5. Do a short test recording where I switch between them, and check each switch shows up in the file."""

    🔌 The OBS connector I use isn't an official one. Depending on when you watch this, run /search-connectors to find the latest. There may be an official one by then.
