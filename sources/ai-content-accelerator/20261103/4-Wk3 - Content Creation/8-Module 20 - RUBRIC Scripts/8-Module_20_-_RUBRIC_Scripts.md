## 這一課要講什麼

這一課，我要帶你認識 **Rubric Scripts** 這個工具。

如果你剛進這個社群，先解釋一下：**Rubric** 是我們為 RoboNuggets 社群自己開發、自己維護的一整套**客製化軟體與系統**。裡面每一個工具，包括 Rubric Scripts，都是設計成可以**跟 AI agent 一起用**的，也就是所謂的 **agent-ready**。等一下你會看到，這件事在實際介面上長什麼樣子。

## 為什麼需要一個「作業系統」

先講脈絡。你現在手上已經有 **slash hooks**、也有你自己版本的 **tone of voice** skill。這些東西你當然可以在 Claude 或 Codex 的聊天視窗裡直接用，但對於大量的創意工作，我發現一件事：**如果你有一個專門的作業系統、一套客製軟體，用更舒服的介面幫你檢視這些產出，效率會高非常多。**

回頭看前面幾課。假設你已經有一份點子清單，可能來自你的 **outliers** skill、來自你產業裡最新的新聞，或就是你自己想到的。要把這些點子變成腳本，做法其實很單純：把點子丟給 Claude，呼叫 **hook** 跟 **tone** skill，讓它產出一份為 Instagram 或 TikTok 最佳化的腳本。通常這樣出來的腳本已經相當不錯了。

## 為什麼不停在聊天視窗

但我們不打算停在這裡。因為如果所有腳本都只是躺在聊天視窗裡，**大部分的腳本最後都會消失**，而且之後要整理、要優化都非常困難。

Rubric Scripts 就是為了解決這件事：它把你所有的內容集中到一個地方，讓你可以輕鬆檢視，同時也讓你**回頭更新、改進你的 skill**，形成一個**遞迴的迴圈**。你可以在這個迴圈裡順暢地把自己的設定跟作業系統愈磨愈利，而不用每次都要重新 prompt 一次 Claude。

## 怎麼開始

第一步，去下面說明欄把 **Rubric Scripts** 下載下來，順便把裡面的 **install prompt** 複製起來。

把那段 install prompt 丟給 Claude、丟給 Codex，或任何你在用的 agent 平台。它會幫你打開你那份 Rubric Scripts，這是一套**瀏覽器端的軟體**，基本上就是在你的 **Google Chrome** 裡跑起來。

它同時會附上一個 skill 指令：**slash rubric scripts**。所以你只要把點子餵給 agent，它就會自動依照你的**語氣**、依照最適合的 **hook**，把點子轉成腳本，還會給你幾個版本可以選，然後直接載入 Rubric Scripts 讓你檢視。

## 實際流程長怎樣

整個流程大概是這樣：

- 你已經有一批確定的點子，或已經決定這週要產出什麼內容
- 你輸入 **slash rubric scripts**，後面接著那些點子
- agent 把它們載進 scripts 介面

Rubric Scripts 也是專門為你的 **hooks** 跟 **tone** skill 最佳化的。預設情況下，它會去找這兩個 skill；如果你還沒建，它也會教你怎麼建。這樣一來，你只要下**一個指令**，左邊是你的點子，右邊就是你可以直接拿來讀的腳本。

順帶一提，從這裡就能看出它有多 **agent-ready**：整個操作就是靠 skill 在驅動。而如果你學過我們課程的其他部分，你就知道 skill 有多彈性。比如你的 **tone of voice** skill 愈改愈好，Rubric Scripts 也會跟著變強。

而且你不只限於這兩個 skill。如果你後來自己做了其他 skill、規則，甚至其他軟體，想整合進 Rubric Scripts，也完全可以。等一下帶你看介面時你會發現，這裡的 UI **幾乎全部都可以改**，你只要叫 agent 加一個功能，它就加給你。

## 現場示範

我現在用的是 **Claude Code**。你只要呼叫 **slash rubric scripts**，把點子給它。點子可以寫得很細，也可以只寫幾個字；當然，**寫得愈細，agent 愈有方向**。如果你想多給一點指引，也可以加上那段說明段落。

接下來 agent 會給你一個連結，指向 Rubric Scripts 被託管的位置。大部分使用者會看到 **local host**，也就是**你自己的電腦、你自己的機器**在跑這套軟體。

點進那個連結，你就進到 Rubric Scripts 了。畫面上我已經有三份腳本等著我審。點子一多，你可以用**搜尋**或**篩選器**過濾，也可以自己排序：

- 依**自訂順序**重新排列
- 依**最後編輯**時間
- 依**最新加入**
- 依**閱讀時間最短**
- 或直接**字母排序**

這些同樣都能改，你想要更多排序方式、想要自動分組，都可以。檢視方式也能切換：**卡片式**或**清單式**。要新增腳本時，跳出的視窗會直接告訴你「用 rubric scripts skill」。另外還有**淺色模式**跟**深色模式**。

## 打開一份腳本

打開其中一份，左邊就是我們所有的點子，可以直接切換。預設情況下，Rubric Scripts 會給你**三個 hook** 讓你選，每一個你都可以自己編輯。如果你偏好手動微調，直接打字改也行。

但以大多數情況、尤其是我自己的用法來說，回饋的方式是這樣：假設這個點子是我要產出的內容，我就先挑一個 hook。很多時候，只要你的 **tone of voice** 跟 **hooks** skill 已經調準了，你其實**不需要每一份腳本、每一個 hook 都逐一審**。

如果你真的想留評論，就把想講的那句話或那段文字**反白**，會跳出一個小視窗。比如我覺得這段太長，就寫「這裡短一點」。你也可以用語音工具講，像 **Aqua** 或 **Whisper Flow**，這樣快很多。這些評論會進到一個**滾動的清單**裡，你可以隨時打開來看。

## 為什麼要有專屬介面

這就是我說「客製作業系統比較好審」的意思。除了內容本身，你至少還需要看到 **caption**。如果全部擠在一個聊天視窗裡，畫面會非常亂。在這裡，caption 已經幫你準備好，還附上 **SEO 的最佳實踐**，以及這支影片整體在講什麼的細節。

而這些都能客製。你想要 caption 每次都短一點，就叫 agent 去改 Rubric Scripts，讓它以後都給短版。你想要**四個 hook** 而不是三個，也只要跟 agent 說，它就去改整套軟體。

重點是：**agent-ready 的應用程式，就是拿來改的。** 這類工具只會愈來愈多，因為 agentic 平台正在滲透每一個工作場域。所以你手上有一套軟體，就放心去改它、加功能。比如這裡還有幾個視窗，如果你根本沒在用，就叫 agent 把它們拿掉。

這個視窗之後會是**影片發佈到各頻道前的預覽**，那是第四週會談的內容。最下面我喜歡放**參考資料**，這樣我需要核對正確性時，可以直接在這裡看。

## 一次改完所有腳本

接著要跳到下一個點子。假設你總共三個點子，就快速讀過去、確認 caption、留一些評論。比如這一份，我想把第一點跟第二點對調，就把這個意見寫下來。你留的評論會自動存進那張 **comments card**。第三份也一樣。

全部看完之後，你**不需要自己重寫**，也不需要一個一個 prompt Claude Code 去修。你只要按 **copy comments for all scripts**，它會把整段指令複製到剪貼簿。

如果你把 **teach my slash tone** 這個開關打開，它還會順便叫 Claude Code 去**修改你的 slash tone skill**。也就是說，你剛剛留的那些評論，會被寫進你的 tone 裡，讓它愈來愈貼近你講話的方式、你希望給人的感覺。

實際操作一次：複製所有評論、貼上、送出。你看，它自動把那些評論整理好了，我直接送出，Claude 或你用的任何 agent 就會**一次把所有腳本修好**。

## 腳本要去哪裡讀

腳本好了之後，你只需要把它送到你**真的能讀**的地方。

- **Telegram**：把 Claude Code 接上你的 Telegram 帳號，下面有對應的 prompt 可以帶你設定。它會把整份腳本傳到 Telegram，你就可以用手機讀。
- **Artifact 或網頁**：如果你在電腦上讀，就叫 Claude 做一個 artifact 或一個頁面，把腳本放在裡面。

我自己用的是**自己做的 teleprompter**。這個 teleprompter 我也會放在下面分享。它是一套很個人的軟體，我沒有特別去優化它，因為它只有一個用途：當我有腳本要照著讀，我就叫 Claude Code 把它送進 teleprompter。它已經知道怎麼做，用的是下面那個 zip 檔。

## Teleprompter 長怎樣

快速帶你看一下，這完全是選用的。這類 app 你都可以照自己喜好改。

畫面上這份腳本，是我們某支影片的 hook，主題跟 **Claude 5.5 模型**發布有關。我點 **desktop view**，這就是 teleprompter。按 play 它就會一直往下跑，速度可以調，字級也可以調。

這是桌機版。下面那個 zip 檔裡也有**手機版**。手機版就是一個在 Chrome 瀏覽器裡打開的頁面，長得跟這個很像，直接在螢幕上按播放、暫停就好。如果對你有幫助，就當作這門課的**bonus** 拿去用。

## 一次錄完，之後再切

腳本有了之後，我自己的做法是把它們全部載進 teleprompter，變成**一整頁長長的文件**。

畫面上這份，是**八支 reels** 的腳本。我就照著這份文件，從第一支、第二支、第三支，一路**不間斷地錄**，一次錄完。之後進到自動剪輯，你就是把這一份原始素材丟給 Claude，讓它切出你要的段落、把每支 clip 分好，最後換回**八支影片**。

這樣做的好處是，你把整個創作流程**批次化**。假設你把星期六訂為內容創作日，那就在那個週末撥一個小時，對著一份長文件念，一次錄 **15 支 reels**。靠批次生產，你就可以穩定產出影片與教學內容，又不用犧牲平日的正職工作時間。
