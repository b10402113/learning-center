## Outlier 不需要幾百萬觀看

這一段我來講 **/outliers**。先講一個重點：outlier **不需要幾百萬觀看**。如果一個頻道平常是 **4,000**，有一支影片拿到 **33,000**，那就是他平常的 **8 倍**——那個主題顯然奏效了。

## 底層就是一道數學題

它做的事很單純，就是數學：**每一則貼文的觀看數，除以那個帳號平常的觀看數**，橫跨 **YouTube、TikTok、X 和其他平台**。

## 安裝

1. 下載 zip。
2. 把安裝 prompt 貼進 Claude 或你的 agent。
3. 它會給你設定需要的連結。

這些**只有第一次要設定**，之後就都不用再管了。

## 要抓 YouTube 資料，得先開 API

你需要開啟 **YouTube Data API**，這是**免費**的，然後建立一把 **key**。所有連結你的 agent 在 skill 設定過程中都會給你。接著把 key 傳給 Claude，或請它開一個安全檔案，讓你自己貼進去。

## 跑起來

然後請 Claude 執行 **/outliers**。因為這支 skill 附模板，結果會開成一個頁面，裡面有**縮圖**和**倍數**。把你喜歡的加進購物車，特別是那些**你有感**、而且**這週就能講**的。

## 選好之後，丟回 Claude 做兩件事

- 第一，請它寫成**你可以直接講的腳本**，用在 TikTok 或 Instagram 貼文，用**你自己的語氣**。如果還不夠好，別擔心，後面的模組會教怎麼變好。現在，就像我說的，**量才是關鍵，先開始錄**。
- 第二，請你的 agent 依這次挑的結果**調整 /outliers 這支 skill**，讓它愈來愈懂你的口味。

## 幾個小技巧

- 結果太少，就**把主題放寬**：搜一個比你原本更寬的領域。
- 或者**往更早看**：要一個比預設更長的時間範圍。
- 主題要有創意，而且**盡量具體**。比如不要只講 AI，可以講**本地 AI**、**醫療裡的 AI**、**給系統工程師用的 AI**。
- 也可以**完全不是 AI**：你的嗜好、你的工作、你的生意，都算。
