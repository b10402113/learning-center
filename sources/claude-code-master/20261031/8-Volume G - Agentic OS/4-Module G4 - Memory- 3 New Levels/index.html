Module G4 - Memory: 3 New Levels

🎬 Video: part 4 of 5 of the Agentic OS v2 update, above.

Memory is everything Claude knows about you and your work, and how fast and cheaply it can find it. This part covers 3 new levels for a workspace that keeps growing.

Level 1 is long-term memory: give Claude a plain text map of your workspace (memory.md, claude.md as a map, a router file per department, database skills), plus text descriptions for your images, with no vector database. Level 2 is short-term memory: the context window, compacting with a purpose, and keeping your prompt cache warm so an idle chat doesn't reload at full price. Level 3 is self-evolving memory: a backlog of fixes per skill, a calibrate step that saves what you teach Claude, and RUBRIC Recos suggesting memory fixes.

What you will learn:

🗺️ How to map your workspace in plain text, so Claude finds anything without burning usage

🧊 How to keep your cache warm, so an idle chat doesn't reload at full price

🧠 How to make memory improve itself, so you never correct Claude on the same thing twice
