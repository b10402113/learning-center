Module G2 - Skills: 3 New Levels

🎬 Video: part 2 of 5 of the Agentic OS v2 update, above.

Skills are the saved instructions Claude follows whenever you call them, and this part covers 3 new levels for using them on the 5.5 models.

Level 1 is knowing your skill types: database skills that hold knowledge (like your tone of voice or a thumbnail library), wildcards so your references don't make Claude overfit, artifact skills tied to your brand book, and self-triggered skills you run from a button with claude -p. Level 2 is model routing: each skill runs on the cheapest model that can do it, with Jev picking the model in about 0.6 seconds. Level 3 is self-improving skills: the feedback you give in your review apps updates the skill every time you use it.

What you will learn:

🗄️ How to use skills as databases, so your agent writes and designs like you from the first draft

🔀 How to route skills by model, so a grammar check never runs on Opus

🔁 How to make skills learn from your feedback, so they get better every week
