Module G5 - Apps: 3 New Levels

🎬 Video: part 5 of 5 of the Agentic OS v2 update, above.

Apps are every outside tool Claude can reach, plus the apps you build yourself. This part covers 3 new levels, ending with work moving out of the chat window.

Level 1 is connecting everything, even apps with no official connector, by checking in this order: the maker's own tools, a CLI, the API, then an MCP. Level 2 is mods: small add-ons that change how Claude Code looks and works, and Chrome extensions as mods for your browser. Level 3 is a micro app for every big job, like reviewing cuts or approving carousels, built from a reusable library of UI parts so every new app looks the same.

What you will learn:

🔌 How to connect apps in the right order, so MCPs stop filling every chat

🧩 How to mod Claude Code and Chrome, so your tools fit how you work

🖥️ How to move big jobs into micro apps, so you review work instead of scrolling a chat
