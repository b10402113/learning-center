Module F3 - Awesome Design Systems

This is how you take a generic AI-looking site and make it unmistakably yours with a design system ✨

You see the /robo system transform a plain page in one prompt, then learn to build your own reusable Design System X skill by combining a base aesthetic with a brand colour palette, so every future build can adopt your look instantly.

What you'll learn:

🎨 What a design system is and why taste is your advantage, so you can stop shipping generic gradients

🗂️ How to turn a look into a reusable skill (fonts, palette, components), so one prompt restyles any build into your brand

🧱 How the system keeps growing with animations and modular components, so it gets more powerful the more you use it

Resources:

/robo design system - the ready-made design system to test and adapt to your brand - link

Design systems toolkit - 35 complete, fundamentally different website systems to pick from - link

Colour palettes toolkit - brand palettes and references (Apple, Airbnb, Uber and more) - link

Prompt for making a design system skill:

Make a skill called /design-system-x, so any time i say /design-system-x you build whatever i ask in our visual language

here's the reference design system to base it on: [PASTE DESIGN SYSTEM]

and here's the colour palette: [PASTE COLOUR PALETTE]

write all of that down inside the skill as locked rules, not vague vibes: the exact colours with their codes and what each one is for, the fonts with their exact weights and where each is used, spacing, corner styles, shadows, and how buttons and cards look

include a small copy-paste starter block - the fonts import and the base styles - so every new build starts

from the same foundation

add a "what this style is NOT" list at the bottom - the fonts, colours, and effects to never use - so the style can't drift over time
