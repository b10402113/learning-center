Module F8 - Backend Rig and Audit

This is the Rig and Audit steps of CRAFT, giving your beautiful front end real, working functionality 🔌

Using the restaurant front-of-house versus kitchen analogy, you wire a contact form to send real emails through Resend with an API key, test it live, then have your agent self-audit the whole site with Playwright before shipping.

What you'll learn:

📧 How to wire a contact form to a real email service with an API key, so your site actually does something when someone clicks

🧪 How to have your agent test every button and form with Playwright, so you catch issues before you ship

🔁 The repeatable rig-then-audit loop for any build, so you add and verify functionality the same way every time

Resources:

Resend - the email service you wire the contact form to via an API key - resend.com

Playwright - free tool that lets your agent drive the browser to test your site - playwright.dev
