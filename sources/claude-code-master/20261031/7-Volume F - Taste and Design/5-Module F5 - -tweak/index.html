Module F5 - /tweak

This is how you stop re-prompting for every little visual change and dial in your design with sliders instead 🎛️

The /tweak skill drops a live panel of sliders onto your page so you can adjust sizes, edit text inline, and remove elements by clicking them, then bakes all the changes back into the final design in one prompt.

What you'll learn:

🎚️ Why prompting every visual tweak wastes tokens and misses your taste, so you know when to switch tools

✏️ How to adjust, edit, and remove elements live on the page, so you shape the look directly instead of describing it

✅ How to bake the changes back into the source, so your final front end matches exactly what you set
