Module F2 - Creating the Base

This is the Create step of CRAFT, where you plan and build the front end of your website 🎯

You research the right sections for an agency site, use good judgment to trim the list for a first build, then have your agent generate the actual one-page front end - the /html skill renders the plan visually so it is easy to review before you build.

What you'll learn:

📋 How to research the sections a site actually needs in 2026, so your build starts from best practice not guesswork

✂️ How to cut the section list down for a first version, so beginners ship the quickest way possible

🖥️ How to turn the approved plan into a real front end, so you have a working page ready for a design system
