Module C7 - Memory in context

Both memory files load every single session, so it pays to know what they cost. 📏

Your CLAUDE.md and memory.md are pre-injected into every chat, so I show how to check their token cost with the context command, what a healthy size looks like, and when it is worth auditing so they do not quietly eat your usage.

What you'll learn:

  • 📥 Why both files load every session, so you understand what is always taking up part of your window

  • 📊 How to check their token cost, so you can see exactly how big your memory really is

  • ⚠️ When to audit them, so you trim things if they creep past a level that dents your plan
