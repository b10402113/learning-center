Module D4 - Deterministic Routines

This is the third kind of routine, and it runs without spending any tokens. 🆓

Using modal.com, I have Claude design and code an automation, then deploy it to Modal, which handles the scheduling. The demo builds a digest that grabs top posts and emails you a summary (now using Hacker News rather than Reddit, due to new Reddit limits). Because it is deterministic code with no LLM in the loop, it costs nothing to run, the same way my auto-clipper makes our YouTube Shorts every day.

What you'll learn:

  • 🆓 Why Modal routines cost no tokens, so deterministic automations run for free on a schedule

  • 🛠️ How Claude builds and deploys it for you, so you just send a prompt and it ships to Modal

  • 🧠 When to use Modal versus a Claude routine, so you only pay tokens when the job needs a brain
