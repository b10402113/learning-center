Module D1 - Intro to Routines

Routines are where Claude Code stops waiting for you and starts working on its own. 🔁

This is the third part of the ARMS framework, and it only pays off once your skills and memory are set, otherwise you just automate work that misses the mark. I cover what routines unlock, the token trade-off as you automate more, and a preview of the three routine types we build next: local, cloud, and the token-free kind.

What you'll learn:

  • 🔁 What routines actually are, so Claude can run tasks day after day without you prompting it

  • ⚖️ The token trade-off of automating, so you know more routines means more usage to manage

  • 🗺️ The three types coming up, so you know local, cloud, and token-free each have a place
