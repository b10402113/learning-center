🎁 The Hermes Agent Masterclass

Here is the setup I actually use now for routines that run 24/7. It's a bit more complex to set up, but worth it in my opinion 🤖

Instead of the cloud desktop app, I run my always-on routines through my Hermes agent, a real 24/7 agent with its own computer (a VPS) that I message on Telegram. Because I sync my skill files from my laptop to Hermes, it can use skills like /last30days and /robo, which makes recurring routines far easier to run.
