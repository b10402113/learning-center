Module D3 - Cloud Routines

Cloud routines keep running even when your computer is switched off. ☁️

I walk through setting one up from the routines tab, and the big catch: cloud routines run on Anthropic's servers, so they cannot see the skills living on your local machine. I show the fix, giving the routine a private GitHub repo of your skills, plus how to connect GitHub through the connectors menu.

What you'll learn:

  • ☁️ How to set up a cloud routine, so your automations run even with your device powered down

  • ⚠️ Why your local skills go missing in the cloud, so you understand the local-versus-cloud trade-off

  • 📦 How to fix it with a private repo, so you upload your skills to GitHub for cloud routines to use

    • Resources:

  • The cloud routine prompt - the daily AI trends and news example to paste in: [add link]

    • Create this as a weekly cloud routine:

    Pull the latest news, trends, and chatter on [AI trends and news] from the last 30 days with /last30days - tell me what's the latest.

    Turn it into a short business report and build it with /robo as a PDF (light mode).

    Cover: the headline takeaway, the 3-5 biggest shifts (each with a plain-English why-it-matters), what people are actually saying, and 2-3 opportunities for me.

    Save it to a dedicated folder (output/ai-trends-reports/) and open it in Chrome when done.

    Keep it tight, plain English, no made-up numbers, nothing older than 30 days.

  • The private-repo prompt - makes Claude Code create a GitHub repo to hold your skills for cloud routines:

    • Build me a private GitHub repo called claude-routines that I'll use as the home for all my Claude cloud routines.

    Steps:

    1. Run gh auth status. If I'm not logged in, stop and tell me to run gh auth login first.

    2. Create a new PRIVATE repo named claude-routines on my GitHub account using gh repo create.

    3. Clone it locally and scaffold it:

    - README.md - what this repo is (the home for my Claude cloud routines), how to add a new routine, and a running list of my routines.

    - routines/ - one markdown file per routine.

    - routines/_template.md - the fields for every routine: name, schedule (cron + plain-English time), what it does, the full prompt, allowed tools, and what it outputs.

    - .gitignore - ignore secrets, .env, and key files.

    4. Add one example routine at routines/daily-gmail-digest.md so I can see the format filled in.

    5. Commit it ("Initial claude-routines scaffold") and push.

    6. Print the repo URL when you're done.

    Keep it clean and don't ask me follow-up questions unless you're truly blocked.
