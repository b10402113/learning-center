Module D2 - Local Routines

Local routines are the easiest automation to set up, a prompt Claude sends itself on a schedule. 🖥️

I show how to build one from the Claude desktop app's routines tab, using a real example that pulls the latest news on a topic with the /last30days skill and builds a clean PDF with /robo. You let Claude write the routine for you from a chat, check its first run, then set the schedule and even ping yourself on Telegram when it is done.

What you'll learn:

  • 🖥️ How to set up a local routine, so a scheduled prompt runs on your computer with no manual work

  • 📄 How to fold skills into it, so /last30days and /robo turn it into a polished report

  • 🔧 How to optimise it later, so you open its session and tweak the routine in plain English

    • Resources:

  • The report-routine prompt - builds a scheduled PDF report on a topic of your choice

    • Create this as a daily local routine:

    Pull the latest news, trends, and chatter on [AI trends and news] from the last 30 days with /last30days - tell me what's the latest.

    Turn it into a short business report and build it with /robo as a PDF (light mode).

    Cover: the headline takeaway, the 3-5 biggest shifts (each with a plain-English why-it-matters), what people are actually saying, and 2-3 opportunities for me.

    Save it to a dedicated folder (output/ai-trends-reports/) and open it in Chrome when done.

    Keep it tight, plain English, no made-up numbers, nothing older than 30 days.
