Module B1 - Skills Explained

Skills are the most useful thing in Claude Code, and the fastest way to feel the power of these agentic tools. 🃏

I explain what a skill really is, which is a recipe card your agent follows, show that it is just a markdown file with a description up top and instructions in the body, and how Claude Code only preloads each skill's name, description, and triggers until you actually invoke it.

What you'll learn:

  • 📄 What a skill actually is, so you can see it is just a plain text recipe card your agent reads

  • 🏷️ Why only the name, description, and triggers are preloaded, so your skills stay light on the context window

  • 🤖 The different ways to invoke a skill, so you can call it by name, with a slash, or let Claude pick it for you
