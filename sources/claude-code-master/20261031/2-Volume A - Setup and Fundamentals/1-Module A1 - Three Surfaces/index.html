Module A1 - Three Surfaces

Claude Code runs in three different places, and picking the right one changes how fast and how comfortably you work. 🚀

I walk through all three surfaces - the desktop app, the VS Code extension, and the terminal - what each one is good at, why the models and the harness underneath stay exactly the same across all of them, and which one I actually reach for day to day.

What you'll learn:

  • 💻 The three surfaces and what each is best at, so you can pick the one that fits your comfort level

  • 💎 Why the desktop app is the least intimidating but the most limited, so you know when to graduate off it

  • 🧩 Why the VS Code extension is my pick for most people, so you can run several agents side by side and do far more in one sitting
