Module A2 - My VS Code x Claude Code Setup

This is the quick-start to get Claude Code running in VS Code from a blank slate. ☕

I show you how to install the extension, pick an empty folder as your workspace, run the setup so Claude Code builds your starter files, and edit your CLAUDE.md so the agent remembers your context, like your name and where you live, in every new chat.

What you'll learn:

  • 🛠️ How to install the extension and open a workspace folder, so Claude Code has a home to work in

  • 📂 Why that folder becomes your operating system or second brain, so everything you build lives in one place

  • 📝 What the CLAUDE.md file does, so every new session already knows your context without you repeating it

    • Resources:

  • Visual Studio Code - free, open source, my preferred way to use Claude Code: code.visualstudio.com

  • Claude Code extension - search "Claude Code" by Anthropic in the VS Code Extensions tab and install it
