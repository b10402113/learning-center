Tip - Searching for Connectors

A bonus prompt that finds the best way to connect any app you have in mind. 🔎

Now that you know the three connection methods, this template has your agent check an app and rank the options, CLI, API or MCP, explaining what exists and the pros and cons of each. You can also turn it into a skill so it is ready whenever you want to automate a new tool.

Resources:

  • The connector-finder prompt - a paste-ready template to rank how to connect a given app:

    • figure out the best way to connect my agent to [tool x] and tell me which one to use.

    - look for three ways to connect to it: a CLI (a command line tool), an API (a direct connection to the app), and an MCP (a plug-in style tool menu the agent can load)

    - check which of these actually exist for [tool x] right now - don't guess. find the real ones and link me to where they live (the official site, github, or wherever you install them from)

    - rank them in this exact order of preference: CLI first, API second, MCP third. always point me to the best one that genuinely exists, and only drop down to the next one when the one above it isn't available or can't do the job - and tell me which it was

    - for each one, in plain words: does it exist (yes / no / sort of), what it can do, what it can't, what setup it needs, and roughly how heavy it is on tokens and cost - CLI is usually the lightest, MCP the heaviest because its whole tool list sits in memory the whole time

    - end with one clear pick: which connection to use, why it won, and the first step to set it up

    if there's no CLI, API, or MCP for [tool x], just say so plainly - don't invent one. a community or unofficial option is fine to mention, just label it as that.
