Module E2 - Using MCPs

MCP connectors are the simplest way to plug a third-party tool straight into Claude Code. 🧩

I show how to connect one fast by handing Claude the MCP server URL directly (cheaper than asking it to research), using Higgsfield as the example, then generating a GPT Image 2 image from inside Claude Code. I also cover the upsides (they are official and show nicely in Claude desktop and Claude design) and a real limitation: the Gmail MCP still cannot mark emails as read.

What you'll learn:

  • 🧩 How to connect an MCP fast, so handing over the server URL saves the tokens of researching it

  • 🎨 Why MCPs shine in Claude design, so you can pull images and video into slides and prototypes

  • ⚠️ Where MCPs fall short, so you know things like the Gmail connector can't mark emails as read
