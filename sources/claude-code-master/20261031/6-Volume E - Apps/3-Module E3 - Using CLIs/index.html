Module E3 - Using CLIs

CLIs are the leanest way to connect an app, and the one I reach for most. ⌨️

A CLI lets your agent type a clean command and get back exactly what it needs, instead of wading through verbose data. I show how to set up the Google Workspace CLI by handing Claude the GitHub link, then how it unlocks things the MCP cannot, like marking Gmail emails as read. Pair this with skills and routines and you can truly automate your real work.

What you'll learn:

  • ⌨️ How CLIs work, so your agent runs a clean command and uses far less context than an MCP

  • 📧 How to set up the Google Workspace CLI, so Claude can fully control Gmail, drafts and reads

  • 🔓 Why CLIs unlock more, so you can do things the MCP can't and even build your own later
