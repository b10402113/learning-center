# 型別：concept（觀念）

**用途**：讓讀者能用自己的話解釋觀念、辨認實例，並區分容易混淆的情況。

## 寫法

從一個具體情境或「為什麼會這樣」的問題開始，讓讀者先知道學這個觀念有什麼用。

先用例子建立直覺，再介紹術語與定義。定義中若包含尚未介紹的概念，先補上必要解釋。

沿用同一個例子說明運作機制，把「原因 → 過程 → 結果」講清楚。不要只列特徵，或用另一個陌生術語解釋原本的術語。

加入一組容易混淆的正反例，指出差異落在哪個條件。使用生活類比時，要說明對應關係，以及哪裡不能照搬。

結尾連回前面已學的觀念，說明兩者如何相連，以及這個觀念能幫助理解什麼。

## 適合的呈現方式

以連續散文為主；差異多時用對比表，因果或組成關係複雜時用機制圖。圖表後仍須解釋讀者應看見的重點。

**避免**：開頭堆疊定義、換句話重複術語、只有類比沒有機制，或把觀念課寫成操作清單。
