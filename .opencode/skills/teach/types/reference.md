# 型別：reference（查閱）

**用途**：提供可查閱的權威事實 —— 術語、API 簽名、選項、預設值、限制。讀者是**查**，不是**讀**。

**開頭**：實體名稱加一行定義。

**主體**：中性、格式一致的描述 —— 所有選項、旗標、預設值與限制都要列齊，附一個最小使用範例。只描述，不解釋、不教。程式碼範例有原始碼就逐字引用，並在 `<pre>` 標出處；原始碼沒有才依內文編寫（見 `docs/reference/source-reading.md` 的「Source-grounded teaching」）。

**結尾**：交錯連結到對應的 how-to 與 explanation。

**元件偏好**：一致的表格、最小程式碼範例。

**不要**：加入意見、建議或原理說明。
